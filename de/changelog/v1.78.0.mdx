## Neue Funktionen

### 1. **Kommunikationspräferenzen**

   Übernehmen Sie die Kontrolle darüber, wie Sie Benachrichtigungen erhalten, mit unseren überarbeiteten Kommunikationspräferenzen. Konfigurieren Sie E-Mail-, Push- und In-App-Benachrichtigungen entsprechend Ihrem Workflow.

   <Frame>
     <img src="/images/communication-preferences/overview.png" alt="Übersicht der Kommunikationspräferenzen, die Benachrichtigungseinstellungen zeigt" />
   </Frame>

   **Wichtige Funktionen**

   - **Überarbeitete E-Mail-Designs**: Frische, moderne E-Mail-Vorlagen mit klaren Handlungsaufforderungen und verbesserter Lesbarkeit
   - **Push-Benachrichtigungen**: Erhalten Sie sofortige Benachrichtigungen auf Ihrem mobilen Gerät für wichtige Ereignisse wie neue Verkäufe, Streitigkeiten und Auszahlungen
   - **Feinsteuerung**: Wählen Sie genau aus, welche Ereignisse Benachrichtigungen auslösen und über welche Kanäle
   - **Unterstützung mehrerer E-Mails**: Fügen Sie mehrere E-Mail-Adressen hinzu, um Benachrichtigungen zu erhalten
   - **E-Mail-Präferenzen der Kunden**: Konfigurieren Sie, welche E-Mails Ihre Kunden erhalten

   **Benachrichtigungskategorien**

   | Kategorie | Beschreibung |
   |----------|-------------|
   | **Verkäufe & Zahlungen** | Neue Verkäufe, erfolgreiche Zahlungen, fehlgeschlagene Zahlungen |
   | **Auszahlungen & Rückerstattungen** | Abschluss von Auszahlungen, Rückerstattungsanfragen, Rückerstattungen abgeschlossen |
   | **Abonnements** | Neue Abonnements, Verlängerungen, Stornierungen, Planänderungen |
   | **Streitigkeiten** | Streitigkeit eröffnet, Beweismittel erforderlich, Streitigkeit gelöst |

   <Check>
   Ergebnis: Bleiben Sie über Ihr Unternehmen informiert mit Benachrichtigungen, die genau so und wann Sie es möchten, zugestellt werden.
   </Check>

   Erfahren Sie mehr: [Kommunikationspräferenzen-Guide](/features/communication-preferences)

### 2. **Benutzerdefinierte Felder in Checkout-Sitzungen**

   Sammeln Sie während des Checkouts zusätzliche Informationen von Kunden mit benutzerdefinierten Feldern. Fügen Sie Texteingaben, Dropdowns, Daten und mehr hinzu, um die benötigten Daten zu erfassen.

   **Unterstützte Feldtypen**

   | Typ | Beschreibung | Anwendungsfall |
   |------|-------------|----------|
   | `text` | Einzelzeileneingabe | Firmenname, Bestellnotizen |
   | `number` | Numerische Eingabe | Menge, Alter |
   | `email` | E-Mail-Eingabe mit Überprüfung | E-Mail für Rechnungsanschrift |
   | `url` | URL-Eingabe mit Überprüfung | Website, soziales Profil |
   | `date` | Datumswähler | Lieferdatum, Veranstaltungsdatum |
   | `dropdown` | Auswahl aus vordefinierten Optionen | Größe, Farbe, Planart |
   | `boolean` | Kontrollkästchen für Ja/Nein-Werte | Zustimmung zu den Bedingungen, Newsletter-Anmeldung |

   **So funktioniert es**

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     custom_fields: [
       {
         name: 'company_name',
         label: 'Company Name',
         type: 'text',
         required: true
       },
       {
         name: 'team_size',
         label: 'Team Size',
         type: 'dropdown',
         options: ['1-10', '11-50', '51-200', '200+'],
         required: true
       },
       {
         name: 'newsletter',
         label: 'Subscribe to our newsletter',
         type: 'boolean',
         required: false
       }
     ],
     return_url: 'https://yoursite.com/success'
   });
   ```

   **Vorteile**

   - **Flexibles Datensammeln**: Erfassen Sie alle Informationen, die für die Erfüllung oder Personalisierung benötigt werden
   - **Überprüfung integriert**: E-Mail- und URL-Felder überprüfen automatisch das Eingabeformat
   - **Erforderlich/optional-Steuerung**: Markieren Sie Felder je nach Bedarf als erforderlich oder optional
   - **Webhook-Zustellung**: Werte benutzerdefinierter Felder werden in Zahlungs-Webhook-Ereignissen enthalten

   <Info>
   Werte benutzerdefinierter Felder werden im `custom_fields`-Objekt innerhalb der Zahlungs- und Checkout-Sitzungsantworten zurückgegeben.
   </Info>

   Erfahren Sie mehr: [Benutzerdefinierte Felder für Checkout-Sitzungen](/developer-resources/checkout-session#custom-fields)

### 3. **Erweiterte Unterstützung für Checkout-Sprachen**

   Die Checkout-Seite unterstützt jetzt **21 Sprachen**, von 16 erhöht. Erreichen Sie mehr Kunden in ihrer Muttersprache für ein besseres Checkout-Erlebnis.

   **Neue hinzugefügte Sprachen**

   | Sprache | Code |
   |----------|------|
   | Koreanisch | `ko` |
   | Malaiisch | `ms` |
   | Rumänisch | `ro` |
   | Russisch | `ru` |
   | Thailändisch | `th` |

   **Alle unterstützten Sprachen**

   Arabisch, Chinesisch, Niederländisch, Englisch, Französisch, Deutsch, Hindi, Indonesisch, Italienisch, Japanisch, Koreanisch, Malaiisch, Portugiesisch, Rumänisch, Russisch, Spanisch, Schwedisch, Thailändisch, Türkisch, Ukrainisch, Vietnamesisch.

   **Eine spezifische Sprache erzwingen**

   Verwenden Sie den `force_language`-Parameter, um die automatische Spracherkennung zu überschreiben:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     force_language: 'ko', // Force Korean language
     return_url: 'https://yoursite.com/success'
   });
   ```

   <Tip>
   Standardmäßig erkennt die Checkout-Seite automatisch die bevorzugte Sprache des Kunden anhand der Browsereinstellungen. Verwenden Sie `force_language`, wenn Sie Konsistenz mit der Sprache Ihrer Website gewährleisten möchten.
   </Tip>

   Erfahren Sie mehr: [Unterstützung für Checkout-Sprachen](/features/checkout#supported-languages)
