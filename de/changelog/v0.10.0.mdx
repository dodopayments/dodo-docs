## Neue Funktionen
- **Atlas als Open Source veröffentlicht**: Eine in Next.js geschriebene Demoanwendung zur Demonstration der Integration von Dodo Payments. Erkunden Sie das [GitHub-Repository](https://github.com/dodopayments/dodo-checkout-demo) und die Dokumentation [hier](/developer-resources/integration-guide).
- **Bereich für Feature-Anfragen**: Im Dashboard von Dodo Payments wurde ein Bereich für Feature-Anfragen eingeführt, um die Produkt-Roadmap auf Grundlage von Nutzerfeedback zu priorisieren.
- **API für Webhook-Anforderungsprotokolle**: APIs zum Auflisten und Anzeigen von Details zu Webhook-Anforderungsprotokollen wurden hinzugefügt.
- **Statische Payment Links**: Den statischen Payment Links wurden weitere Query-Parameter hinzugefügt, um mehr Flexibilität im Checkout-Prozess zu bieten. Weitere Informationen finden Sie [hier](/developer-resources/integration-guide#4-static-payment-links).
- **API zum Auflisten von Abonnements**: Eine API zum Abrufen aller Abonnements wurde hinzugefügt. Weitere Informationen finden Sie in der [API-Referenz](/api-reference/subscriptions/get-subscriptions-1).

## Kleinere Verbesserungen und Fehlerbehebungen
- Verbesserung der Antworten der Produkt- und Abonnement-APIs mit zusätzlichen Parametern.
- Implementierung von Ratenbegrenzungen für API-Anfragen, derzeit auf 20 Anfragen pro Sekunde festgelegt.
- Verbesserung der Dokumentation, um benutzerfreundlicher und einfacher zu navigieren zu sein.
- Verschiedene kleinere Fehlerbehebungen und Verbesserungen.
