## Neue Funktionen

### 1. **Wiederherstellung verlassener Einkaufswagen**

Automatisches Erkennen unvollständiger oder fehlgeschlagener Checkouts und Senden gezielter E-Mail-Sequenzen, um Kunden zurückzuholen. ACR überwacht Zahlungen, die nach 60 Minuten nicht erfolgreich waren, und klassifiziert sie als entweder **Zahlung fehlgeschlagen** oder **Checkout unvollständig**. Anschließend werden bis zu 3 konfigurierbare Wiederherstellungs-E-Mails pro Sequenz gesendet.

<Frame>
<img src="/images/recovery/recovery-analytics.png" alt="Analyse-Dashboard zur Wiederherstellung, das verlassene Checkout-Zählungen, Wiederherstellungsraten und wiederhergestellten Umsatz zeigt" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Wichtige Funktionen:
- **Zwei E-Mail-Sequenzen** — Zahlung fehlgeschlagen und Checkout unvollständig, jede mit bis zu 3 E-Mails
- **Wiederherstellungsrabatte** — Optional automatisches Generieren von einmaligen Rabattcodes, um Anreize zur Wiederherstellung zu bieten
- **Kundenseite zur Wiederherstellung** — Einzigartige Wiederherstellungslinks führen Kunden zu einer dedizierten Seite, um ihren Kauf abzuschließen
- **Analyse zur Wiederherstellung** — Verfolgen von verlassenen Checkout-Zählungen, Wiederherstellungsraten, wiederhergestelltem Umsatz und Aufschlüsselungen pro E-Mail/pro Produkt

<Tip>
Beginnen Sie mit dem Standard-E-Mail-Timing (1 Stunde, 24 Stunden, 72 Stunden) und iterieren Sie basierend auf Ihren Wiederherstellungsanalysedaten.
</Tip>

Erfahren Sie mehr: [Wiederherstellung verlassener Einkaufswagen](/features/recovery/abandoned-cart-recovery)

### 2. **Abonnement-Dunning**

Automatisches Senden von E-Mail-Sequenzen zur Wiederherstellung ausgelaufener oder stornierter Abonnements. Dunning wird ausgelöst, wenn ein Abonnement in den Status **on hold** (Zahlungsfehler) wechselt oder vom Kunden im Kundenportal **storniert** wird.

Wichtige Funktionen:
- **Zwei E-Mail-Sequenzen** — On hold und storniert, jede mit bis zu 4 E-Mails
- **Automatische Belastung** — Wenn ein Kunde seine Zahlungsmethode aktualisiert, werden ausstehende Beträge automatisch belastet
- **Konfigurierbares Timing** — Standardintervalle bei 1, 3, 5 und 7 Tagen, vollständig anpassbar pro E-Mail

Erfahren Sie mehr: [Abonnement-Dunning](/features/recovery/subscription-dunning)

### 3. **Rabatt-Metadaten**

Es ist jetzt möglich, **Metadaten** (Schlüssel-Wert-Paare) zu Rabatten hinzuzufügen, wenn diese über die API erstellt oder aktualisiert werden. Verwenden Sie Metadaten, um Rabatte nach Kampagne, Quelle oder interner Referenz für die Nachverfolgung und Abstimmung zu kennzeichnen.

```typescript
const discount = await client.discounts.create({
  type: 'percentage',
  amount: 1500, // 15%
  code: 'SUMMER2025',
  metadata: {
    campaign: 'summer_promo',
    source: 'email_blast'
  }
});
```

Erfahren Sie mehr: [Rabattcodes](/features/discount-codes) | [Metadaten-Leitfaden](/api-reference/metadata)

### 4. **Recovery Webhooks**

Neue Webhook-Ereignisse zur Verfolgung des Wiederherstellungs-Lebenszyklus:

| Ereignis | Beschreibung |
|-------|-------------|
| `abandoned_checkout.detected` | Ein verlassener Checkout wurde erkannt |
| `abandoned_checkout.recovered` | Kunde hat die Zahlung über einen Wiederherstellungslink abgeschlossen |
| `dunning.started` | Ein Dunning-Versuch wurde für ein Abonnement gestartet |
| `dunning.recovered` | Kunde hat die Zahlungsmethode aktualisiert und Zahlung war erfolgreich |

Erfahren Sie mehr: [Recovery Webhooks](/developer-resources/webhooks/intents/recovery)

### 5. **Pix-Zahlungen für Brasilien**

Akzeptieren Sie **Pix** — das von der Zentralbank Brasiliens erstellte Sofortzahlungssystem — in Ihrem Dodo Payments-Checkout. Pix ist jetzt die meistgenutzte Zahlungsmethode in Brasilien und übertrifft sowohl Kreditkarten als auch Boleto, und bestätigt Zahlungen in Sekunden rund um die Uhr.

**Abdeckung**

| Detail | Wert |
|--------|-------|
| Abrechnungswährung | BRL |
| Unterstützte Länder | Brasilien |
| Abonnements | Nicht unterstützt (nur Einmalzahlungen) |
| Mindestbetrag | $0,50 |
| Abrechnung | Sofort |

**Konfiguration**

Übergeben Sie `pix` in `allowed_payment_method_types` und setzen Sie die Abrechnungswährung auf `BRL`:

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['pix', 'credit', 'debit'],
  billing_currency: 'BRL',
  return_url: 'https://example.com/success'
});
```

Dem Kunden wird ein Pix-QR-Code und ein Copy-Paste-Schlüssel beim Checkout angezeigt. Sie öffnen ihre Banking-App, scannen oder fügen ein, und die Zahlung wird sofort bestätigt.

<Tip>
Pix-QR-Codes laufen nach einem festgelegten Zeitraum ab — gestalten Sie Ihren Checkout-Fluss so, dass Kunden den Code bei Bedarf regenerieren können. Bieten Sie immer Karten-Alternativen für Kunden, die lieber mit Karte bezahlen.
</Tip>

Erfahren Sie mehr: [Pix-Zahlungen](/features/payment-methods/pix)

### 6. **WeChat Pay für chinesische Kunden**

Akzeptieren Sie **WeChat Pay** — genutzt von über einer Milliarde Menschen in ganz China — direkt in Ihrem Dodo Payments-Checkout. Kunden scannen einen QR-Code mit ihrer WeChat-App und bestätigen die Zahlung in Sekunden, alles ohne das WeChat-Ökosystem zu verlassen.

**Abdeckung**

| Detail | Wert |
|--------|-------|
| Abrechnungswährungen | USD, CNY |
| Abonnements | Nicht unterstützt (nur Einmalzahlungen) |
| Mindestbetrag | $0,50 / ¥1,00 |
| Abrechnung | USD |

**Konfiguration**

Übergeben Sie `wechat_pay` in `allowed_payment_method_types` bei der Erstellung einer Checkout-Sitzung:

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['wechat_pay', 'credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

WeChat Pay unterstützt sowohl **USD** (für grenzüberschreitende Händler, die chinesische Kunden ansprechen) als auch **CNY** (für inländische chinesische Transaktionen). Die Abrechnung mit Händlern erfolgt in USD, unabhängig von der Abrechnungswährung.

<Tip>
Zeigen Sie den Checkout auf einem Desktop oder Tablet an, damit Kunden den QR-Code mit ihrem Telefon scannen können — dies ist der vertrauteste Ablauf für WeChat-Pay-Nutzer.
</Tip>

Erfahren Sie mehr: [WeChat Pay](/features/payment-methods/wechat)
