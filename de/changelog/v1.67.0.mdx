## Neue Funktionen 🚀

1. **Gemischter Warenkorb-Abschluss: Einmalige und Abonnementprodukte in einem Warenkorb**  
   Der Checkout unterstützt jetzt die Kombination von Einmalzahlungsprodukten und Abonnementprodukten in einem einzigen Warenkorb und ermöglicht so neue, leistungsstarke Abrechnungsanwendungen.
   
   <Frame>
   <img src="/images/changelog/mixed-checkout.png" alt="Gemischter Checkout mit Einmal- und Abonnementprodukten" style={{ maxHeight: '500px', width: 'auto' }} />
   </Frame>
   
   ### Was Dies Ermöglicht
   
   - **Einrichtungsgebühren + Abonnements**: Erheben Sie eine einmalige Einrichtungsgebühr zusammen mit einem wiederkehrenden Abonnement in einem einzigen Checkout
   - **Pakete mit wiederkehrenden Komponenten**: Verkaufen Sie ein Produkt (einmalig) gebündelt mit fortlaufendem Servicezugang (Abonnement)
   - **Kurs- + Mitgliedschaftskombinationen**: Bieten Sie einen Kurskauf mit optionalem Community-Mitgliedschaftsabonnement an
   - **Lebenslange + Zusatz-Abonnements**: Kombinieren Sie lebenslangen Produktzugang mit optionalen wiederkehrenden Premium-Funktionen
   
   ### Wie Es Funktioniert
   
   Fügen Sie einfach sowohl Einmal- als auch Abonnementprodukte zu Ihrer Checkout-Sitzung hinzu:
   

   ```javascript
   const session = await client.checkoutSessions.create({
     product_cart: [
       // One-time setup fee
       { product_id: 'prod_setup_fee', quantity: 1 },
       // Monthly subscription
       { product_id: 'prod_monthly_plan', quantity: 1 }
     ],
     customer: {
       email: 'customer@example.com',
       name: 'Jane Doe'
     },
     return_url: 'https://yourapp.com/success'
   });
   ```

   
   <Check>
   Ergebnis: Ein einzelner Checkout-Ablauf, der die einmalige Zahlung verarbeitet und das Abonnement initiiert – wodurch Reibung reduziert und die Conversion-Rate erhöht wird.
   </Check>
   
   <Info>
   Beim Mischen von Produkttypen wird die einmalige Zahlung sofort belastet, während das Abonnement seinem konfigurierten Abrechnungszyklus folgt (einschließlich etwaiger Testzeiträume, die Sie festgelegt haben).
   </Info>
   
   Mehr erfahren: [Checkout-Sitzungen](/developer-resources/checkout-session)

2. **Vereinheitlichtes Kundenportal**  
   
   Ein neues, zentrales Kundenportal unter [customer.dodopayments.com](https://customer.dodopayments.com), wo Kunden alle ihre Käufe und Abonnements über verschiedene Unternehmen auf Dodo Payments einsehen und verwalten können.
   
   <Frame>
   <img src="/images/changelog/unified-customer-portal.png" alt="Vereinheitlichtes Kundenportal" style={{ maxHeight: '500px', width: 'auto' }} />
   </Frame>
   
   ### Portal-Funktionen
   
   - **Unternehmensübergreifende Sichtbarkeit**: Alle Käufe und Abonnements von jedem Unternehmen, das Dodo Payments verwendet, an einem Ort anzeigen
   - **Zentralisierte Abonnementverwaltung**: Verwalten Sie Abonnements über verschiedene Händler hinweg von einem einzigen Dashboard aus
   - **Vereinheitlichte Abrechnungshistorie**: Greifen Sie auf Rechnungen und Zahlungshistorie von all Ihren Käufen zu
   - **Einmalige Anmeldung**: Melden Sie sich einmal mit Ihrer E-Mail an, um Zugriff auf Käufe von allen Dodo Payments-Händlern zu erhalten
   
   ### Wie Es Funktioniert
   
   Kunden besuchen einfach [customer.dodopayments.com](https://customer.dodopayments.com) und geben ihre E-Mail-Adresse ein. Sie erhalten einen sicheren Anmeldelink, der Zugriff auf alle ihre Käufe im Dodo Payments-Ökosystem gewährt.
   
   <Tip>
   Das vereinheitlichte Kundenportal ergänzt geschäftsspezifische Kundenportale. Kunden können weiterhin auf individuelle Händlerportale für eine Marken-Erfahrung zugreifen oder das vereinheitlichte Portal für eine konsolidierte Ansicht nutzen.
   </Tip>
   
   <Note>
   Das vereinheitlichte Portal verwendet dieselbe E-Mail-basierte Authentifizierung wie die geschäftsspezifischen Portale und gewährleistet eine konsistente und sichere Erfahrung.
   </Note>
  

3. **Rechnungs-ID in der Zahlungsantwort**  
   Die Zahlungsantwort enthält nun ein `invoice_id`-Feld, wodurch das Abgleichen von Zahlungen mit Rechnungen erleichtert und die Integration in Buchhaltungssysteme vereinfacht wird.
   

   ```json
   {
     "payment_id": "pay_2IjeQm4hqU6RA4Z4kwDee",
     "status": "succeeded",
     "invoice_id": "inv_2IsUnWGtRKFLxk7xAQeyt",
     "total_amount": 9900,
     "currency": "USD",
     // ... other fields
   }
   ```

   
   ### Anwendungsfälle
   
   - **Buchhaltungsintegration**: Verknüpfen Sie Zahlungen direkt mit Rechnungen in Ihrer Buchhaltungssoftware
   - **Kundensupport**: Finden Sie schnell die Rechnung zu einer Zahlung, wenn Sie Support-Anfragen bearbeiten
   - **Abstimmung**: Vereinfachen Sie die finanzielle Abstimmung, indem Sie Zahlungen programmatisch mit Rechnungen abgleichen
   - **Compliance**: Führen Sie genaue Aufzeichnungen, indem Sie Zahlungen mit den entsprechenden Steuerrechnungen verknüpfen
   
   <Info>
   Das `invoice_id`-Feld verwendet indien-spezifische Rechnungs-IDs, wenn verfügbar, und stellt so die Einhaltung lokaler Rechnungsanforderungen sicher.
   </Info>
   
   Mehr erfahren: [Get Payment Detail API](/api-reference/payments/get-payments-1)
