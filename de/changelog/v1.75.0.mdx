## Neue Features

### 1. **Produktkollektionen**  
   
   Gruppiere verwandte Produkte für ein einheitliches Checkout-Erlebnis, Plan-Auswahl und nahtlose Upgrade/Downgrade-Pfade im Kundenportal.

   <Frame>
     <img src="/images/product-collection/checkout-page.png" alt="Checkout-Seite der Produktkollektion, die mehrere Planoptionen zeigt" />
   </Frame>

  **Wichtige Vorteile**

   - **Kollektionsbasiertes Checkout**: Alle Produkte einer Kollektion in einer Checkout-Ansicht anzeigen, sodass Kunden vergleichen und ihren bevorzugten Plan auswählen können
   - **Organisierte Produktverwaltung**: Verwandte Produkte (z.B. Starter, Pro, Enterprise) unter einer einzigen Kollektion zusammenfassen
   - **Integration mit dem Kundenportal**: Kunden die Möglichkeit geben, zwischen Produkten innerhalb derselben Kollektion zu wechseln
   - **Händlerkontrolle**: Produkte innerhalb jeder Kollektion aktivieren, deaktivieren und neu anordnen

   **So funktioniert es**

   Eine Checkout-Sitzung für eine Kollektion erstellen:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_collection_id: 'pdc_abc123',
     product_cart: [], // Required: pass an empty array for collection checkout
     return_url: 'https://yoursite.com/return'
   });

   // Redirect customer to the checkout
   window.location.href = session.url;
   ```

   <Check>
   Ergebnis: Ein einheitliches Checkout-Erlebnis, bei dem Kunden alle verfügbaren Produkte in deiner Kollektion sehen und auswählen können.
   </Check>

   <Info>
   Das Kollektion-Checkout ist ideal für Abonnement-Geschäfte, bei denen du möchtest, dass Kunden die Pläne nebeneinander vergleichen, bevor sie einen Kauf tätigen.
   </Info>

   Weitere Informationen: [Produktkollektionen-Guide](/features/product-collections)

### 2. **RevolutPay & Billie-Zahlungsmethoden für GBP-Währung**  
   
   Erweiterte Zahlungsmethoden mit RevolutPay und Billie sind jetzt weltweit für GBP-Einmalzahlungstransaktionen verfügbar und bieten deinen Kunden mehr Flexibilität bei der Bezahlung.

   **Neue Zahlungsmethoden**

   | Zahlungsmethode | Unterstützte Länder | Währung | Abonnementsupport |
   |----------------|---------------------|---------|-------------------|
   | **RevolutPay** | Global | GBP | Nein (nur einmal) |
   | **Billie** | Global | GBP | Nein (nur einmal) |

   - **RevolutPay** – Schnelle und nahtlose Zahlungen für Revolut-Nutzer weltweit
   - **Billie** – B2B-Kaufe jetzt, zahle später-Lösung, die Unternehmen ermöglicht, ihren Kunden flexible Zahlungsbedingungen anzubieten

   <Info>
   Diese Zahlungsmethoden sind automatisch für GBP-Transaktionen verfügbar. Es sind keine zusätzlichen Konfigurationen erforderlich.
   </Info>

   Weitere Informationen: [Zahlungsmethoden](/features/payment-methods)

### 3. **Vorschau der Checkout-Sitzung**  
   
   Vorschau von Checkout-Sitzungen vor deren Erstellung zur genauen Berechnung von Preisen, Steuern, Rabatten und Gesamtsummen. Zeige den Kunden die realen Preise, bevor sie zur Kasse gehen.

   **So funktioniert es**

   ```typescript
   const preview = await client.checkoutSessions.preview({
     product_cart: [
       { product_id: 'prod_123', quantity: 1 }
     ],
     billing_address: {
       country: 'US',
       state: 'CA',
       zipcode: '94102'
     },
     discount_code: 'SAVE20'
   });

   console.log('Subtotal:', preview.subtotal);
   console.log('Tax:', preview.tax);
   console.log('Discount:', preview.discount);
   console.log('Total:', preview.total);
   ```

   **Anwendungsfälle**

   - **Benutzerdefinierte Preisanzeigen**: Zeige genaue Gesamtsummen einschließlich Steuern vor dem Checkout an
   - **Rabattvalidierung**: Überprüfe Rabattcodes und zeige den Kunden Ersparnisse an
   - **Mehrwährungsunterstützung**: Preisvorschau in verschiedenen Währungen
   - **Warenkorbzusammenfassungen**: Erstelle benutzerdefinierte Warenkorb-UIs mit Echtzeitpreisen

### 4. **Metadatensupport in Änderungsanfragen für Pläne**  
   
   Übergib benutzerdefinierte Metadaten beim Ändern von Abonnementplänen, um eine bessere Nachverfolgung und Integration mit deinen internen Systemen während der Planänderungen zu ermöglichen.

   ```javascript
   // Adding metadata when changing a subscription plan
   await client.subscriptions.changePlan('sub_123', {
     product_id: 'prod_premium',
     proration_billing_mode: 'prorated_immediately',
     quantity: 1,
     metadata: {
       upgrade_reason: 'feature_request',
       previous_plan: 'basic',
       sales_rep: 'john@company.com'
     }
   });
   ```

  **Anwendungsfälle**

   - **Upgrade/Downgrade-Gründe nachverfolgen**: Speichere, warum Kunden ihre Pläne geändert haben
   - **Zu CRM-Datensätzen verlinken**: Verknüpfe Planänderungen mit Verkaufsaktivitäten
   - **Interne Kategorisierung**: Tagge Planänderungen für Berichterstattung und Analytik
   - **Audit-Trails**: Halte Aufzeichnungen darüber, wer Planänderungen initiiert hat

   <Info>
   Metadaten sind in Webhook-Ereignissen enthalten, was die Verarbeitung von Planänderungen mit deinen benutzerdefinierten Daten erleichtert.
   </Info>

   Weitere Informationen: [Metadaten-Guide](/api-reference/metadata) | [Ändere Plan API](/api-reference/subscriptions/change-plan)

### 5. **`invoice_url`-Feld in Zahlung-Antwort und Zahlung-Link-Antwort**  
   
   Die Zahlung-Antwort und Zahlung-Link-Antwort beinhalten nun ein `invoice_url`-Feld, das direkten Zugriff auf die Rechnung ermöglicht, die mit jeder Zahlung verbunden ist.

   ```json
   {
     "payment_id": "pay_2IjeQm4hqU6RA4Z4kwDee",
     "status": "succeeded",
     "invoice_url": "https://dodopayments.com/invoices/inv_2IsUnWGtRKFLxk7xAQeyt",
     "amount": 9900,
     "currency": "USD",
     // ... other fields
   }
   ```

  **Anwendungsfälle**

   - **Kommunikation mit Kunden**: Sende Rechnungslinks direkt an Kunden
   - **Integration in Buchhaltungssoftware**: Verlinke Zahlungen mit Rechnungen in deiner Buchhaltungssoftware
   - **Self-Service-Portale**: Erlaube Kunden den einfachen Zugang zu ihren Rechnungen
   - **Dokumentenverwaltung**: Halte direkte Verweise auf Rechnungsdokumente

### 6. **Endpunkt zur Validierung von Rabatten nach Code-Name**  
   
   Neuer API-Endpunkt zur Validierung und Abruf von Rabattcodes nach ihrem Code-Namen (z.B. "SAVE20") anstelle der Verwendung der internen Rabatt-ID. Überprüfe die Rabattberechtigung, bevor du sie beim Checkout anwendest.

   ```javascript
   // Validate a discount code before checkout
   const discount = await client.discounts.getByCode('SAVE20');

   console.log('Discount type:', discount.type);
   console.log('Discount value:', discount.amount);
   console.log('Valid until:', discount.expires_at);
   ```

  **Vorteile**

   - **Inspektionsvalidierung vor dem Checkout**: Überprüfe Rabattcodes, bevor du Checkout-Sitzungen erstellst
   - **Echtzeit-Feedback**: Zeige den Kunden, ob ihr Code gültig ist
   - **Fehlerbehandlung**: Fange ungültige oder abgelaufene Codes frühzeitig ab
   - **Benutzerdefinierte Rabatt-UIs**: Erstelle Eingabefelder für Rabattcodes mit sofortiger Validierung

### 7. **Erweiterte Filtermöglichkeiten für Kunden, Rabatte und Lizenzschlüssel**  
   
   Neue API-Filter für die Auflistung von Kunden, Rabatten und Lizenzschlüsseln, die es einfacher machen, Daten programmgesteuert zu finden und zu verwalten.

   **Kunden-API-Filter**

   | Filter | Beschreibung |
   |--------|-------------|
   | `email` | Nach Kunden-E-Mail filtern |
   | `name` | Nach Kundenname filtern (teilweise Übereinstimmung, nicht groß-/kleinschreibungssensitiv) |
   | `created_at_gte` | Kunden filtern, die an oder nach diesem Zeitstempel erstellt wurden |
   | `created_at_lte` | Kunden filtern, die an oder vor diesem Zeitstempel erstellt wurden |

   ```javascript
   // Find customers by name created in the last 30 days
   const customers = await client.customers.list({
     name: 'John',
     created_at_gte: '2026-01-01T00:00:00Z'
   });
   ```

   **Rabatte-API-Filter**

   | Filter | Beschreibung |
   |--------|-------------|
   | `code` | Nach Rabattcode filtern (teilweise Übereinstimmung, nicht groß-/kleinschreibungssensitiv) |
   | `discount_type` | Nach Rabattart filtern (Prozentsatz) |
   | `active` | Nach aktivem Status filtern (true = nicht abgelaufen, false = abgelaufen) |
   | `product_id` | Nach Produktbeschränkung filtern (nur Rabatte, die auf dieses Produkt anwendbar sind) |

   ```javascript
   // Find active percentage discounts for a specific product
   const discounts = await client.discounts.list({
     active: true,
     discount_type: 'percentage',
     product_id: 'prod_123'
   });
   ```

   **Lizenzschlüssel-API-Filter**

   | Filter | Beschreibung |
   |--------|-------------|
   | `customer_id` | Nach Kunden-ID filtern |
   | `status` | Nach Status des Lizenzschlüssels filtern (`active`, `expired`, `disabled`) |
   | `product_id` | Nach Produkt-ID filtern |
   | `created_at_gte` | Lizenzschlüssel filtern, die an oder nach diesem Zeitstempel erstellt wurden |
   | `created_at_lte` | Lizenzschlüssel filtern, die an oder vor diesem Zeitstempel erstellt wurden |

   ```javascript
   // Find active license keys for a specific product
   const licenseKeys = await client.licenseKeys.list({
     status: 'active',
     product_id: 'prod_123'
   });
   ```
