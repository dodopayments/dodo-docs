## Overview

Agent Skills are reusable capabilities that enhance what AI coding assistants can do when working with Dodo Payments. They provide procedural knowledge and best practices that help agents accomplish specific tasks more effectively - from integrating checkout flows to setting up usage-based billing.

<Info>
**Think of skills as plugins for your AI assistant.** They teach your agent how to implement Dodo Payments features correctly, following our recommended patterns and best practices.
</Info>

Skills funktionieren mit jedem AI agent, der das Skills-Protokoll unterstützt, darunter:
- **Claude Code** – Anthropic's CLI-Coding-Assistent
- **Codex CLI** – OpenAI's CLI-Coding-Agent
- **Cursor** – AI-first-Code-Editor
- **VS Code / GitHub Copilot** – über das Agent Plugin
- **Kiro** – lädt Skills als Power
- **OpenCode** – Open-Source-AI-Coding-Agent
- **Andere Clients** – jeder Agent, der das Skills-Protokoll unterstützt

<Note>
**Gemini CLI ist die Ausnahme.** Es verfügt über kein Agent-Skill-Primitive, daher sind Skills dort nicht verfügbar – nur die beiden [MCP-Server](/developer-resources/mcp-server).
</Note>

## Installation

Wähle deine bevorzugte Installationsmethode passend zu deinem AI-Coding-Assistenten.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Wenn du Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro oder OpenCode verwendest, installiert das [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) alle siebzehn Skills sowie beide MCP-Server in einem Schritt. Skills werden automatisch geladen, sobald dein Agent eine relevante Aufgabe erkennt.

Weitere Informationen zu den Installationsbefehlen für die einzelnen Agents findest du im [Leitfaden zu AI-Coding-Agents](/developer-resources/build-with-ai-coding-agents).
</Tab>

<Tab title="Skills CLI">
Installiere Skills mit der universellen Skills CLI, die mit jedem MCP-kompatiblen Agent funktioniert:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Oder installiere einzelne Skills nach Bedarf:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/dodo-best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
Installiere nur die benötigten Skills, damit dein Agent fokussiert bleibt und der Kontextaufwand reduziert wird.
</Tip>
</Tab>

<Tab title="OpenCode">
OpenCode lädt Skills aus Verzeichnissen, auf die du verweist. Es durchsucht **keine** installierten Pakete, daher ist ein expliziter `skills.paths`-Eintrag erforderlich.

Mit dem Agent Plugin-Paket:

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

Relative Pfade werden relativ zum **Projektverzeichnis** aufgelöst, daher muss das Paket im `node_modules` dieses Projekts vorhanden sein. Ein absoluter Pfad funktioniert ebenfalls und vermeidet die Anforderung einer lokalen Installation.

<Warning>
Ein nicht vorhandener Skills-Pfad wird **still** ignoriert – ohne Fehler und ohne Warnung. Bestätige, dass die Skills tatsächlich geladen wurden:

```bash
opencode run "List every skill available to you by name."
```

Es sollten alle siebzehn angezeigt werden.
</Warning>
</Tab>

## Skills verwenden

Nach der Installation lädt dein AI-Assistent automatisch den relevanten Skill, wenn du ihn aufforderst, eine Dodo Payments-Funktion zu implementieren. Du musst den Skill nicht benennen – beschreibe einfach die Aufgabe.

| Beispiel-Prompt | Geladener Skill |
|----------------|------------------|
| Hilf mir, Dodo Payments nach Best Practices in meine Next.js-App zu integrieren | `dodo-best-practices` |
| Füge meiner Hono-App einen Dodo Payments-Checkout-Route-Handler hinzu | `framework-adapters` |
| Führe mich durch das Testen von Zahlungen und den Go-live | `testing-and-go-live` |
| Erstelle eine Checkout Session für mein SaaS-Produkt | `checkout-integration` |
| Implementiere einen Abonnementablauf mit einer kostenlosen Testphase und mehreren Preisstufen | `subscription-integration` |
| Füge meiner React-Native-App einen In-App-Checkout hinzu | `mobile-checkout` |
| Richte Webhook-Handler für Zahlungs- und Abonnementereignisse ein | `webhook-integration` |
| Richte Credit-Berechtigungen und einen meterbasierten Credit-Abzug für mein AI-Produkt ein | `credit-based-billing` |
| Füge meinem AI-Produkt eine nutzungsbasierte Abrechnung hinzu, um API-Aufrufe zu erfassen | `usage-based-billing` |
| Implementiere die Validierung von Lizenzschlüsseln für meine Desktop-App | `license-keys` |
| Erstelle einen Produktkatalog mit Add-ons und abgestuften Preisen | `product-catalog-management` |
| Füge einen Promo-Code hinzu, der in den ersten drei Abrechnungszyklen 20 % Rabatt gewährt | `discounts-and-promotions` |
| Zeige Preise in der lokalen Währung des Besuchers mit Kaufkraftparität an | `localized-pricing` |
| Gib Kunden ein Self-Service-Portal zur Verwaltung ihrer Zahlungsmethoden | `customer-management` |
| Stelle eine teilweise Rückerstattung aus und entziehe den Zugriff, wenn ein Dispute eröffnet wird | `refunds-and-disputes` |
| Füge eine Preisseite mit BillingSDK-Komponenten hinzu | `billing-sdk` |
| Integriere Dodo Payments in meine Better-Auth-Einrichtung | `better-auth-integration` |

## So funktionieren Skills

Skills stellen deinem AI-Assistenten Folgendes bereit:

1. **Prozedurales Wissen** – Schritt-für-Schritt-Anleitungen zur Implementierung von Funktionen
2. **Codevorlagen** – produktionsreife Code-Muster und Snippets
3. **Best Practices** – empfohlene Ansätze für Sicherheit, Fehlerbehandlung und UX
4. **Kontextverständnis** – Verständnis dafür, wie verschiedene Dodo Payments-Funktionen zusammenspielen

Wenn du deinen AI-Assistenten aufforderst, eine Funktion zu implementieren, verwendet er den relevanten Skill, um:
- den richtigen Implementierungsansatz zu verstehen
- korrekten, funktionierenden Code zu generieren
- den Konventionen von Dodo Payments zu folgen
- Edge Cases und Fehler ordnungsgemäß zu behandeln

<Note>
Skills ergänzen den [MCP Server](/developer-resources/mcp-server) und [Sentra](/developer-resources/sentra). Verwende MCP für API-Operationen, Sentra für eine geführte Integration und Skills für erweiterte Funktionen des AI-Assistenten.
</Note>

## Vergleich mit anderen Tools

| Tool | Zweck | Am besten geeignet für |
|------|---------|----------|
| **Agent Skills** | Wissen des AI-Assistenten erweitern | AI-gestützte Entwicklung mit jedem MCP-Client |
| **MCP Server** | API-Operationen ausführen | Direkter API-Zugriff über AI-Assistenten |
| **Sentra** | Assistent für geführte Integrationen | Interaktive Billing-Integration in der IDE |
