## Overview

Agent Skills are reusable capabilities that enhance what AI coding assistants can do when working with Dodo Payments. They provide procedural knowledge and best practices that help agents accomplish specific tasks more effectively - from integrating checkout flows to setting up usage-based billing.

<Info>
**Think of skills as plugins for your AI assistant.** They teach your agent how to implement Dodo Payments features correctly, following our recommended patterns and best practices.
</Info>

Skills work with any MCP-compatible AI agent, including:
- **Claude Code** - Anthropic's CLI coding assistant
- **OpenCode** - Open source AI coding agent
- **Cursor** - AI-first code editor
- **Other MCP clients** - Any agent supporting the skills protocol

## Installation

Wählen Sie Ihre bevorzugte Installationsmethode basierend auf Ihrem AI-Coding-Assistenten.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Wenn Sie Claude Code, Codex CLI, Cursor oder OpenCode verwenden, installiert das [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) alle siebzehn Skills sowie beide MCP-Server in einem Schritt. Skills werden automatisch geladen, sobald Ihr Agent eine relevante Aufgabe erkennt.

Eine Anleitung zu den agentenspezifischen Installationsbefehlen finden Sie im [Leitfaden zu AI-Coding-Agenten](/developer-resources/build-with-ai-coding-agents).
</Tab>

<Tab title="Skills CLI">
Installieren Sie Skills mit der universellen Skills-CLI, die mit jedem MCP-kompatiblen Agenten funktioniert:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Oder installieren Sie einzelne Skills nach Bedarf:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
Installieren Sie nur die Skills, die Sie benötigen, damit Ihr Agent fokussiert bleibt und der Kontextaufwand reduziert wird.
</Tip>
</Tab>

<Tab title="OpenCode">
Skills sind automatisch verfügbar, sobald sie in Ihren OpenCode-Einstellungen konfiguriert wurden. Fügen Sie das Dodo Payments-Skills-Repository zu Ihrer Konfiguration hinzu:

## Skills verwenden

Nach der Installation lädt Ihr AI-Assistent automatisch den relevanten Skill, wenn Sie ihn auffordern, eine Dodo Payments-Funktion zu implementieren. Sie müssen den Skill nicht benennen – beschreiben Sie einfach die Aufgabe.

| Beispiel-Prompt | Geladener Skill |
|----------------|------------------|
| Hilf mir, Dodo Payments gemäß den Best Practices in meine Next.js-App zu integrieren | `dodo-best-practices` |
| Füge meiner Hono-App einen Dodo Payments-Checkout-Route-Handler hinzu | `framework-adapters` |
| Führe mich durch das Testen von Zahlungen und den Produktionsstart | `testing-and-go-live` |
| Erstelle eine Checkout Session für mein SaaS-Produkt | `checkout-integration` |
| Implementiere einen Abonnementablauf mit einem kostenlosen Testzeitraum und mehreren Preisstufen | `subscription-integration` |
| Füge meiner React-Native-App einen In-App-Checkout hinzu | `mobile-checkout` |
| Richte Webhook-Handler für Zahlungs- und Abonnementereignisse ein | `webhook-integration` |
| Richte Credit-Berechtigungen und einen meterbasierten Credit-Abzug für mein AI-Produkt ein | `credit-based-billing` |
| Füge meinem AI-Produkt eine nutzungsbasierte Abrechnung hinzu, um API-Aufrufe zu erfassen | `usage-based-billing` |
| Implementiere die Validierung von Lizenzschlüsseln für meine Desktop-App | `license-keys` |
| Erstelle einen Produktkatalog mit Add-ons und gestaffelten Preisen | `product-catalog-management` |
| Füge einen Promo-Code hinzu, der in den ersten drei Abrechnungszyklen 20 % Rabatt gewährt | `discounts-and-promotions` |
| Zeige Preise in der lokalen Währung des Besuchers unter Verwendung der Kaufkraftparität an | `localized-pricing` |
| Stelle Kunden ein Self-Service-Portal zur Verwaltung ihrer Zahlungsmethoden bereit | `customer-management` |
| Stelle eine teilweise Rückerstattung aus und entziehe den Zugriff, wenn ein Streitfall eröffnet wird | `refunds-and-disputes` |
| Füge eine Preisseite mit BillingSDK-Komponenten hinzu | `billing-sdk` |
| Binde Dodo Payments in meine Better-Auth-Einrichtung ein | `better-auth-integration` |

## Funktionsweise von Skills

Skills stellen Ihrem AI-Assistenten Folgendes bereit:

1. **Prozedurales Wissen** – Schritt-für-Schritt-Anleitungen zur Implementierung von Funktionen
2. **Codevorlagen** – Produktionsreife Code-Muster und Snippets
3. **Best Practices** – Empfohlene Ansätze für Sicherheit, Fehlerbehandlung und UX
4. **Kontextverständnis** – Verständnis dafür, wie verschiedene Dodo Payments-Funktionen zusammenwirken

Wenn Sie Ihren AI-Assistenten auffordern, eine Funktion zu implementieren, verwendet er den relevanten Skill, um:
- den richtigen Implementierungsansatz zu verstehen
- korrekten, funktionsfähigen Code zu generieren
- die Konventionen von Dodo Payments zu befolgen
- Sonderfälle und Fehler ordnungsgemäß zu behandeln

<Note>
Skills ergänzen den [MCP Server](/developer-resources/mcp-server) und [Sentra](/developer-resources/sentra). Verwenden Sie MCP für API-Operationen, Sentra für eine geführte Integration und Skills für erweiterte Funktionen des AI-Assistenten.
</Note>
