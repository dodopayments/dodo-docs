<Note>
Dieser Leitfaden behandelt ausschließlich **Einmalzahlungen** mit **Karten, Apple Pay und Google Pay**.
</Note>

## API-Endpunkte

| Umgebung | Basis-URL | Bestätigungszahlungs-Endpunkt |
| --- | --- | --- |
| **Testmodus** | `https://test.dodopayments.com` | `https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm` |
| **Live-Modus** | `https://live.dodopayments.com` | `https://api.hs.dodopayments.com/payments/<payment_id>/confirm` |

## Schritt-für-Schritt-Kartenzahlungsablauf

### Schritt 1: Geheime Schlüssel abrufen

Beginnen Sie mit der Erstellung einer Zahlung über die folgende API:

- **Zahlungen**: [Zahlung erstellen API](/api-reference/payments/post-payments)

Diese API gibt eine **`secret_key`** zurück, die für die nachfolgenden Schritte erforderlich ist.

### Schritt 2: Die Zahlung bestätigen

Bestätigen Sie die Zahlung, indem Sie den `payments confirm`-Endpunkt aufrufen:

- **Testmodus**: `POST https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm`
- **Live-Modus**: `POST https://api.hs.dodopayments.com/payments/<payment_id>/confirm`

Fügen Sie die folgenden Details in den Anfragekörper ein:

- `client_secret`: Geheimer Schlüssel aus Schritt 1
- `payment_method`: Setzen Sie auf `card`
- `payment_method_data`: Karten- und Rechnungsdetails
- `browser_info`: Browser-spezifische Daten (Benutzer-Agent, Bildschirmdetails usw.)
- `payment_type`: Setzen Sie ausdrücklich auf `normal` (für Einmalzahlungen)

Benötigte Header:

- Holen Sie sich Ihren veröffentlichbaren Schlüssel von DodoPayments Support
- `api-key`: Ihr veröffentlichbarer Schlüssel (Holen Sie ihn sich vom Dodo Payments Team)
- `content-type`: `application/json`

**Beispiel-Anfragekörper:**

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "card",
  "payment_method_data": {
    "card": {
      "card_number": "<card_number>",
      "card_exp_month": "<exp_month>",
      "card_exp_year": "<exp_year>",
      "card_holder_name": "<cardholder_name>",
      "card_cvc": "<cvc>",
      "card_network": "<network>"
    },
    "billing": {
      "address": {
        "first_name": "<first_name>",
        "last_name": "<last_name>"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
```

### Verarbeitung der Antwort

- Wenn die Antwort **`status`** **`requires_customer_action`** ist, leiten Sie den Kunden zur URL, die im Feld **`next_action`** bereitgestellt wird, für weitere Authentifizierung um.

<Warning>
Stellen Sie sicher, dass Sie die PCI-Compliance-Richtlinien einhalten, wenn Sie mit rohen Kartendaten umgehen.
</Warning>

## Apple Pay-Integration

Um Apple Pay zu verwenden, setzen Sie `payment_method` auf `wallet` und fügen Sie die Apple Pay-Daten in `payment_method_data` ein.

### Struktur des Anfragekörpers

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "apple_pay": {
        "payment_data": "<decrypted_payment_data>",
        "payment_method": {
          "display_name": "Visa 1234",
          "network": "Visa",
          "type": "debit"
        },
        "transaction_identifier": "UNIQUE_TRANSACTION_ID_FROM_APPLE"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Apple Pay-Feldreferenz

| Feld | Typ | Erforderlich | Beschreibung |
| --- | --- | --- | --- |
| `payment_data` | string | Ja | Dieses Enum wird verwendet, um die Apple Pay-Zahlungsdaten darzustellen, die entweder verschlüsselt oder entschlüsselt sein können. |
| `payment_method.display_name` | string | Ja | Anzeigename, der auf der Apple Pay-Schaltfläche angezeigt wird (z. B. „Visa 1234“) |
| `payment_method.network` | string | Ja | Kartennetzwerk (z. B. „Visa“, „Mastercard“, „Amex“) |
| `payment_method.type` | string | Ja | Zahlungsmethodenart (z. B. „Debit“, „Kredit“) |
| `payment_method.card_exp_month` | string | Nein | Monat des Kartenauslaufdatums (z. B. „12“) |
| `payment_method.card_exp_year` | string | Nein | Jahr des Kartenauslaufdatums (z. B. „25“) |
| `transaction_identifier` | string | Ja | Eindeutige Transaktionskennung von Apple Pay |

## Google Pay-Integration

Um Google Pay zu verwenden, setzen Sie `payment_method` auf `wallet` und fügen Sie die Google Pay-Daten in `payment_method_data` ein.

### Struktur des Anfragekörpers

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "google_pay": {
        "type": "CARD",
        "description": "Visa ending in 1234",
        "info": {
          "card_network": "VISA",
          "card_details": "1234"
        },
        "tokenization_data": {
          "type": "PAYMENT_GATEWAY",
          "token": "<encrypted_payment_token>"
        }
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Google Pay-Feldreferenz

| Feld | Typ | Erforderlich | Beschreibung |
| --- | --- | --- | --- |
| `type` | string | Ja | Zahlungsmethodenart (typischerweise „KARTE“) |
| `description` | string | Ja | Benutzerseitige Beschreibung der Zahlungsmethode |
| `info.card_network` | string | Ja | Kartennetzwerk (z. B. „VISA“, „MASTERCARD“, „AMEX“) |
| `info.card_details` | string | Ja | Letzte 4 Ziffern der Karte |
| `info.assurance_details` | object | Nein | Details zur Authentifizierungssicherung |
| `tokenization_data.type` | string | Ja | Tokenisierungstyp (z. B. „ZAHLUNGSGATEWAY“) |
| `tokenization_data.token` | string | Ja | Verschlüsseltes Zahlungstoken von Google Pay |
