## Übersicht

Das Astro-Minimalboilerplate bietet einen sofort einsatzbereiten Ausgangspunkt für die Integration von Dodo Payments in Ihre Astro-Anwendung. Diese Vorlage umfasst Authentifizierung, Webhook-Verarbeitung und grundlegende Zahlungssetup, um Ihnen zu helfen, schnell Zahlungen zu akzeptieren.

<Info>
Dieses Boilerplate verwendet Astro mit TypeScript und enthält Beispielimplementierungen für Checkout-Sitzungen und Webhook-Überprüfung.
</Info>

## Schnellstart

<Steps>
<Step title="Repository klonen">
Klonen Sie das Boilerplate-Repository und navigieren Sie zum Projektverzeichnis:

```bash
git clone https://github.com/dodopayments/dodo-astro-minimal-boilerplate.git
cd dodo-astro-minimal-boilerplate
```

</Step>

<Step title="API-Anmeldeinformationen abrufen">
Erhalten Sie Ihre Anmeldeinformationen vom Dodo Payments-Dashboard im Testmodus:

- **API-Schlüssel**: Navigieren Sie zu **Entwickler → API-Schlüssel** in Ihrem [Dashboard](https://app.dodopayments.com)
- **Webhook-Signaturschlüssel**: Navigieren Sie zu **Entwickler → Webhooks** in Ihrem [Dashboard](https://app.dodopayments.com)

<Tip>
Beginnen Sie mit dem Testmodus, um Ihre Integration sicher zu testen, ohne echte Zahlungen zu verarbeiten.
</Tip>
</Step>

<Step title="Umgebungsvariablen konfigurieren">
Erstellen Sie eine `.env` Datei im Stammverzeichnis:

```bash
touch .env
```

Fügen Sie Ihre Dodo Payments-Anmeldeinformationen hinzu:

```bash .env
DODO_API_KEY_TEST=your_test_api_key_here
DODO_PAYMENTS_WEBHOOK_KEY=your_webhook_signing_key_here
```

<Warning>
Verpflichten Sie niemals Ihre `.env` Datei zur Versionskontrolle. Sie ist bereits in `.gitignore` enthalten.
</Warning>
</Step>

<Step title="Webhook-Localhost konfigurieren">
Wenn Sie Webhooks lokal testen, exponieren Sie Ihr Localhost mit Tools wie [ngrok](https://ngrok.com):

```bash
ngrok http 4321
```

Fügen Sie die ngrok-URL zur `allowed_hosts` Liste in `astro.config.mjs` für die Webhook-Zustellung hinzu:

```javascript astro.config.mjs
export default defineConfig({
  server: {
    host: true,
    allowedHosts: ['your-ngrok-url.ngrok.io']
  }
});
```

<Note>
Dieser Schritt ist erforderlich, damit Webhooks an Ihre lokale Entwicklungsumgebung geliefert werden.
</Note>
</Step>

<Step title="Abhängigkeiten installieren">
Installieren Sie die erforderlichen npm-Pakete:

```bash
npm install
```

</Step>

<Step title="Entwicklungsserver starten">
Starten Sie den Astro-Entwicklungsserver:

```bash
npm run dev
```

Ihre Anwendung ist unter `http://localhost:4321` verfügbar.

<Check>
Sie sind bereit, mit dem Bauen zu beginnen! Das Boilerplate enthält Beispielrouten und -komponenten, um Ihnen das Verständnis der Integration zu erleichtern.
</Check>
</Step>
</Steps>

## Projektstruktur

```
dodo-astro-minimal-boilerplate/
├── src/
│   ├── pages/
│   │   ├── api/
│   │   │   └── webhooks.ts     # Webhook handler
│   │   └── index.astro         # Home page with examples
│   └── lib/
│       └── dodo.ts             # Dodo Payments client setup
├── .env.example                # Environment variables template
├── astro.config.mjs            # Astro configuration
└── package.json
```

## Nächste Schritte

Sobald Sie das Boilerplate ausgeführt haben:

<Steps>
<Step title="Erstellen Sie Ihre Produkte">
Fügen Sie Produkte in Ihrem [Dodo Payments-Dashboard](https://app.dodopayments.com) hinzu, um die Checkout-Funktionalität zu aktivieren.
</Step>

<Step title="Webhook lokal testen">
Verwenden Sie [ngrok](https://ngrok.com), um Ihren lokalen Webhook-Endpunkt zu exponieren und aktualisieren Sie die `allowed_hosts` in `astro.config.mjs`:

```bash
ngrok http 4321
```

Fügen Sie die ngrok-URL zu Ihren Webhook-Einstellungen im Dashboard hinzu.
</Step>

<Step title="Integration anpassen">
Passen Sie den Beispielcode an die Bedürfnisse und das Design Ihrer Anwendung an.
</Step>

<Step title="Live gehen">
Wenn Sie bereit sind, wechseln Sie zu Live-Modus-API-Schlüsseln und stellen Sie Ihre Anwendung bereit.
</Step>
</Steps>
