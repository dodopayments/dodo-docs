Dodo Payments provides official SDKs for multiple programming languages, each designed with language-specific best practices and modern features for seamless payment integration.

<Tip>
Always use the latest SDK version to access the newest features and improvements. Check your package manager for updates regularly to ensure you have access to all Dodo Payments capabilities.
</Tip>

## Schnellstart

Beginnen Sie innerhalb von Minuten mit jedem SDK:

<Steps>
<Step title="Install the SDK">
  Verwenden Sie den Paketmanager Ihrer Sprache, um das SDK zu installieren
  
  <Tabs>
  <Tab title="TypeScript/Node.js">

  ```bash
  npm install dodopayments
  ```

  </Tab>
  
  <Tab title="Python">

  ```bash
  pip install dodopayments
  ```

  </Tab>
  
  <Tab title="PHP">

  ```bash
  composer require dodopayments/client
  ```

  </Tab>
  
  <Tab title="Go">

  ```bash
  go get github.com/dodopayments/dodopayments-go
  ```

  </Tab>

  <Tab title="Rust">

  ```bash
  cargo add dodopayments
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Initialize the Client">
  Konfigurieren Sie den Client mit Ihrem API-Schlüssel
  
  <Tabs>
  <Tab title="TypeScript">

  ```typescript
  import DodoPayments from 'dodopayments';
  const client = new DodoPayments({ bearerToken: 'your_api_key' });
  ```

  </Tab>
  
  <Tab title="Python">

  ```python
  from dodopayments import DodoPayments
  client = DodoPayments(bearer_token="your_api_key")
  ```

  </Tab>
  
  <Tab title="PHP">

  ```php
  use Dodopayments\Client;
  $client = new Client(bearerToken: 'your_api_key');
  ```

  </Tab>
  
  <Tab title="Go">

  ```go
  import "github.com/dodopayments/dodopayments-go"
  client := dodopayments.NewClient(option.WithBearerToken("your_api_key"))
  ```

  </Tab>

  <Tab title="Rust">

  ```rust
  use dodopayments::Client;
  let client = Client::from_env()?; // reads DODO_PAYMENTS_API_KEY
  ```

  </Tab>
  </Tabs>
  
  <Warning>
  Speichern Sie Ihre API-Schlüssel immer sicher mit Umgebungsvariablen. Niemals in die Versionskontrolle einfügen.
  </Warning>
</Step>

<Step title="Make Your First API Call">
  Erstellen Sie eine Checkout-Session oder Zahlung
  
  <Check>
  Sie sind nun bereit, Zahlungen zu verarbeiten! Besuchen Sie die einzelnen SDK-Seiten für detaillierte Anleitungen und Beispiele.
  </Check>
</Step>
</Steps>

## Hauptfunktionen

Alle **Backend**-SDKs verfügen über diese Kernfunktionen. Die unten aufgeführten Mobile Checkout SDKs
sind bewusst eingeschränkter — sie enthalten keinen API key und rufen die API niemals auf:

- **Typsicherheit**: Strenge Typisierung für Sicherheit zur Compile-Zeit und bessere IDE-Unterstützung
- **Fehlerbehandlung**: Umfassende Ausnahmebehandlung mit detaillierten Fehlermeldungen
- **Authentifizierung**: Einfache API-Key-Authentifizierung mit Unterstützung für Umgebungsvariablen
- **Asynchrone Unterstützung**: Moderne async/await-Muster, sofern zutreffend
- **Automatische Paginierung**: Automatische Paginierung für Listenantworten
- **Nutzungsbasierte Abrechnung**: Integrierte Unterstützung für die Verfolgung und Erfassung von Nutzungsereignissen
- **Tests**: Vollständige Unterstützung des Test Mode für Entwicklung und Tests

## Mobile Checkout SDKs

Wenn Sie lieber Dodo's **gehostete Checkout-Seite** öffnen möchten, anstatt eine native
Zahlungsansicht zu erstellen, verwenden Sie das Mobile Checkout SDK für Ihre Plattform. Alle vier teilen
den gleichen One-Call-Vertrag: `start(...)` gibt ein typisiertes `CheckoutResult` zurück,
keines von ihnen enthält einen API key, und Apple Pay/Google Pay funktionieren genauso wie
im offenen Web, da der Checkout in der echten Browser-Oberfläche der Plattform geöffnet wird
(`SFSafariViewController` / Custom Tabs) und nicht in einem `WebView`:

</Card>

## Befehlszeilenschnittstelle

Für terminalbasierte Abläufe und Automatisierung:

<Card title="CLI" icon="terminal" href="/developer-resources/sdks/cli">
  Automatisch generierte Befehlszeilenschnittstelle mit Unterstützung für die Dodo Payments API
</Card>

**Funktionen:**
- Ressourcenbasierte Befehlsstruktur für eine intuitive Nutzung
- Mehrere Ausgabeformate (JSON, YAML, formatiert, interaktiv)
- Shell-Vervollständigung für bash, zsh und fish
- Ideal für Skripting und CI/CD-Automatisierung

```bash
# Quick example
dodopayments payments list --format json | jq '.items[] | {payment_id, total_amount}'
```
