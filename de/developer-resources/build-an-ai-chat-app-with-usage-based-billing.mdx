In diesem Tutorial erstellst du eine **KI-Chat-Anwendung** mit automatischer nutzungsbasierter Abrechnung. Wir erstellen alles von Grund auf: den Abrechnungsmesser, die Produktkonfiguration und den Anwendungscode, der die Unterhaltungen ermöglicht und die Token-Nutzung in Echtzeit erfasst.

<Note>
Dieses Tutorial stellt eine vollständige, funktionsfähige Anwendung mit Backend und Frontend bereit. Die Chat-App verwendet Googles Gemini-KI und erfasst die Token-Nutzung automatisch, ohne dass eine manuelle Zählung erforderlich ist.
</Note>

Am Ende dieses Tutorials verfügst du über eine funktionierende Chat-Anwendung, die:
- KI-Unterhaltungen mit Google Gemini (AI SDK) ermöglicht
- die Token-Nutzung automatisch erfasst (kein manueller Code erforderlich)
- Kunden basierend auf ihrem tatsächlichen Token-Verbrauch abrechnet
- eine ansprechende Chat-Oberfläche enthält

## Was wir erstellen

Beginnen wir damit, unseren KI-Chat-Service zu verstehen:

- **Service**: KI-gestützter Chat mit Google Gemini (AI SDK)
- **Preismodell**: Zahlung pro Token (0,01 $ pro 1.000 Token)
- **Kostenlose Stufe**: 10.000 kostenlose Token pro Kunde und Monat
- **Funktionen**: Unterhaltungsverlauf, automatische Token-Erfassung

<Info>
Bevor wir beginnen, stelle sicher, dass du Folgendes hast:
- Ein Dodo Payments-Konto
- Einen Google-AI-API-Schlüssel ([Einen bei aistudio erhalten](https://aistudio.google.com/api-keys))
- Node.js v16+ installiert
</Info>

## Schritt 1: Erstelle deinen Nutzungszähler

Zunächst erstellen wir in deinem Dodo Payments-Dashboard einen Zähler, der die Nutzung von KI-Token erfasst.

<Tip>
**Was wir erstellen**: Einen Zähler namens "AI Token Usage Meter", der alle in Chat-Unterhaltungen verbrauchten Token summiert.
</Tip>

<Steps>
<Step title="Open the Meters section">
1. Melde dich in deinem Dodo Payments-Dashboard an
2. Klicke in der linken Seitenleiste auf Products
3. Klicke auf **Meters**
4. Klicke auf die Schaltfläche **Create Meter**

<Frame>
  <img src="/images/cookbooks/ai-chat-app/create-meter.png" alt="Create Meter" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Du solltest ein Formular sehen, in dem wir die Token-Erfassung konfigurieren.
</Step>

<Step title="Fill in the basic meter information">
Jetzt geben wir die spezifischen Details für unseren KI-Chat-Service ein:

**Meter Name** → `AI Token Usage Meter`

**Description** → `Tracks token consumption from AI chat conversations using AI SDK`

**Event Name** → `ai_chat_usage`

<Warning>
Der Ereignisname `ai_chat_usage` muss exakt mit dem übereinstimmen, was wir später aus unserem Anwendungscode senden. Bei Ereignisnamen wird zwischen Groß- und Kleinschreibung unterschieden!
</Warning>
</Step>

<Step title="Configure how we count tokens">
Richte die Aggregation ein (wie der Zähler unsere Ereignisse zählt):

**Aggregation Type**: Wähle **Sum** aus dem Dropdown-Menü

**Aggregate Over**: Type → `totalTokens`

**Measurement Unit**: Type → `tokens`

<Info>
Wir verwenden "Sum", weil wir alle über mehrere Chat-Nachrichten hinweg verbrauchten Token addieren möchten. Das SDK sendet `totalTokens` automatisch in jedem Ereignis.
</Info>
</Step>

<Step title="Create your meter">
1. Überprüfe noch einmal, ob alle Einstellungen den oben genannten Werten entsprechen
2. Klicke auf **Create Meter**

<Frame>
  <img src="/images/cookbooks/ai-chat-app/meter-configuration.png" alt="Meter Configuration" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Check>
**Zähler erstellt!** Dein "AI Token Usage Meter" ist jetzt bereit, Token zu zählen. Als Nächstes verbinden wir ihn mit einem Abrechnungsprodukt.
</Check>
</Step>
</Steps>

## Schritt 3: Erstelle dein Abrechnungsprodukt

Jetzt müssen wir ein Produkt erstellen, das unsere Preise definiert (0,01 $ pro 1.000 Token mit 10.000 kostenlosen Token). Dadurch wird unser Zähler mit der tatsächlichen Abrechnung verbunden.

<Tip>
**Was wir erstellen**: Ein Produkt namens "AI Chat Service", das den Token-Verbrauch mit einer großzügigen kostenlosen Stufe abrechnet.
</Tip>

<Steps>
<Step title="Navigate to Products">
1. Klicke in deinem Dodo Payments-Dashboard in der linken Seitenleiste auf **Products**
2. Klicke auf **Create Product**
3. Wähle **Usage-Based** als Produkttyp aus

Damit weiß Dodo Payments, dass die Abrechnung auf der Zählernutzung und nicht auf einem festen Abonnement basiert.
</Step>

<Step title="Enter product details">
Fülle die erforderlichen Angaben aus:

**Product Name**: → `AI Chat Service`

**Description**: → `AI-powered chat service with automatic token-based billing`

**Product Image**: Lade ein passendes Bild hoch

<Info>
Diese Angaben erscheinen auf Kundenrechnungen. Formuliere sie daher klar und professionell.
</Info>
</Step>

<Step title="Connect your meter">
Bevor du deinen Zähler verbindest, stelle sicher, dass du **Usage Based Billing** als Preistyp für dein Produkt ausgewählt hast.

Setze außerdem den **Fixed Price** auf `0`, damit Kunden ausschließlich auf Grundlage ihrer Nutzung und ohne Grundgebühr abgerechnet werden.

Verknüpfe nun den gerade erstellten Zähler:

1. Scrolle nach unten zum Abschnitt **Associated Meter**
2. Klicke auf **Add Meters**
3. Wähle im Dropdown-Menü **"AI Token Usage Meter"** aus (den zuvor erstellten Zähler)
4. Vergewissere dich, dass er in deiner Produktkonfiguration angezeigt wird

<Check>
Dein Zähler ist jetzt erfolgreich mit diesem Produkt verbunden.
</Check>
</Step>

<Step title="Set your pricing">
Hier definieren wir unser Geschäftsmodell:

**Price Per Unit**: Gib → `0.00001` ein (das entspricht 0,01 $ pro 1.000 Token bzw. 0,00001 $ pro Token)

**Free Threshold**: Gib → `10000` ein (Kunden erhalten 10.000 kostenlose Token pro Monat)

<Frame>
  <img src="/images/cookbooks/ai-chat-app/product-pricing.png" alt="Product Pricing" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Tip>
**So funktioniert die Abrechnung**: Wenn ein Kunde in einem Monat 25.000 Token verwendet, werden ihm 15.000 Token berechnet (25.000 – 10.000 kostenlose Token) = 15.000 × 0,00001 $ = 0,15 $
</Tip>
</Step>

<Step title="Save your product">
1. Überprüfe alle deine Einstellungen:
   - Name: AI Chat Service
   - Zähler: AI Token Usage Meter
   - Preis: 0,01 $ pro 1.000 Token
   - Kostenlose Stufe: 10.000 Token
2. Klicke auf **Save Changes**

<Check>
**Produkt erstellt!** Deine Abrechnung ist jetzt konfiguriert. Kunden werden automatisch basierend auf ihrer Token-Nutzung abgerechnet.
</Check>
</Step>
</Steps>

```typescript src/server.ts expandable
import express, { Request, Response } from 'express';
import { generateText } from 'ai';
import { google } from '@ai-sdk/google';
import { createLLMTracker } from '@dodopayments/ingestion-blueprints';
import 'dotenv/config';

const app = express();
app.use(express.json());
app.use(express.static('public'));

// Replace with your test customer ID
const CUSTOMER_ID = 'cus_123';

// Create tracker once with your meter event name
const llmTracker = createLLMTracker({
  apiKey: process.env.DODO_PAYMENTS_API_KEY!,
  environment: process.env.DODO_ENVIRONMENT as 'test_mode' | 'live_mode',
  eventName: 'ai_chat_usage', // Must match your meter configuration
});

// Chat endpoint with conversation support
app.post('/chat', async (req: Request, res: Response) => {
  try {
    const { messages } = req.body;

    if (!messages || !Array.isArray(messages)) {
      return res.status(400).json({ 
        error: 'Missing required field: messages (array)' 
      });
    }

    // Wrap AI SDK with automatic token tracking
    const trackedClient = llmTracker.wrap({
      client: { generateText },
      customerId: CUSTOMER_ID
    });

    // Generate AI response - tokens are automatically tracked!
    const response = await trackedClient.generateText({
      model: google('gemini-2.5-flash'),
      messages: messages
    });

    res.json({
      message: response.text,
      usage: {
        totalTokens: response.usage.totalTokens
      }
    });

  } catch (error: any) {
    console.error('Chat error:', error);
    res.status(500).json({ 
      error: 'Failed to process chat',
      details: error.message 
    });
  }
});

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
  console.log(`🚀 Server running at http://localhost:${PORT}`);
  console.log(`📊 Tracking event: ai_chat_usage`);
  console.log(`👤 Customer ID: ${CUSTOMER_ID}`);
  console.log(`🔧 Environment: ${process.env.DODO_ENVIRONMENT}`);
});
```

    <script>
      let conversationHistory = [];

      const messageInput = document.getElementById("messageInput");
      let resizeTimeout;
      messageInput.addEventListener("input", function () {
        clearTimeout(resizeTimeout);
        resizeTimeout = setTimeout(() => {
          this.style.height = "auto";
          this.style.height = Math.min(this.scrollHeight, 120) + "px";
        }, 10);

      // Send message on Enter (Shift+Enter for new line)
      messageInput.addEventListener("keydown", function (e) {
        if (e.key === "Enter" && !e.shiftKey) {
          e.preventDefault();
          sendMessage();
        }
      });

      async function sendMessage() {
        const input = document.getElementById("messageInput");
        const message = input.value.trim();

        if (!message) return;

        // Hide empty state
        document.getElementById("emptyState").style.display = "none";

        // Hide error
        document.getElementById("errorMessage").classList.remove("show");

        // Add user message to UI
        addMessage("user", message);

        // Add to conversation history
        conversationHistory.push({
          role: "user",
          content: message,
        });

        // Clear input
        input.value = "";
        input.style.height = "auto";

        // Show typing indicator
        showTypingIndicator();

        // Disable send button
        const sendBtn = document.getElementById("sendBtn");
        sendBtn.disabled = true;

        try {
          const response = await fetch("/chat", {
            method: "POST",
            headers: {
              "Content-Type": "application/json",
            },
            body: JSON.stringify({
              messages: conversationHistory,
            }),
          });

          const data = await response.json();

          if (!response.ok) {
            throw new Error(data.error || "Failed to get response");
          }

          // Hide typing indicator
          hideTypingIndicator();

          // Add assistant response to UI
          addMessage("assistant", data.message, data.usage);

          // Add to conversation history
          conversationHistory.push({
            role: "assistant",
            content: data.message,
          });
        } catch (error) {
          hideTypingIndicator();
          showError(error.message);
          // Remove the last user message from history since it failed
          conversationHistory.pop();
        } finally {
          sendBtn.disabled = false;
        }
      }

      function addMessage(role, content, usage = null) {
        const messagesDiv = document.getElementById("chatMessages");

        const messageDiv = document.createElement("div");
        messageDiv.className = `message ${role}`;

        const avatar = role === "user" ? "👤" : "🤖";

        let metaHTML = "";
        if (usage) {
          metaHTML = `
                    <div class="message-meta">
                        <span class="token-badge">📊 ${usage.totalTokens} tokens</span>
                    </div>
                `;
        }

        messageDiv.innerHTML = `
                <div class="message-avatar">${avatar}</div>
                <div class="message-content">
                    <div class="message-bubble">${escapeHtml(content)}</div>
                    ${metaHTML}
                </div>
            `;

        messagesDiv.appendChild(messageDiv);
        requestAnimationFrame(() => {
          messagesDiv.scrollTop = messagesDiv.scrollHeight;
        });
      }

      function showTypingIndicator() {
        const messagesDiv = document.getElementById("chatMessages");

        const typingDiv = document.createElement("div");
        typingDiv.className = "message assistant";
        typingDiv.id = "typingIndicator";
        typingDiv.innerHTML = `
                <div class="message-avatar">🤖</div>
                <div class="typing-indicator show">
                    <div class="typing-dots">
                        <span></span>
                        <span></span>
                        <span></span>
                    </div>
                </div>
            `;

        messagesDiv.appendChild(typingDiv);
        requestAnimationFrame(() => {
          messagesDiv.scrollTop = messagesDiv.scrollHeight;
        });
      }

      function hideTypingIndicator() {
        const typingIndicator = document.getElementById("typingIndicator");
        if (typingIndicator) {
          typingIndicator.remove();
        }
      }

      function showError(message) {
        const errorDiv = document.getElementById("errorMessage");
        errorDiv.textContent = "❌ " + message;
        errorDiv.classList.add("show");
      }

      function escapeHtml(text) {
        const div = document.createElement("div");
        div.textContent = text;
        return div.innerHTML.replace(/\n/g, "<br>");
      }
    </script>
  </body>
</html>

## Fehlerbehebung

Häufige Probleme und ihre Lösungen:

<AccordionGroup>
<Accordion title="Events not appearing in dashboard">
**Mögliche Ursachen:**
- Der Ereignisname stimmt nicht exakt mit der Zählerkonfiguration überein
- Die Kunden-ID existiert nicht in deinem Konto
- Der API-Schlüssel ist ungültig oder abgelaufen
- Probleme mit der Netzwerkverbindung

**Lösungen:**
1. Überprüfe, ob der Ereignisname exakt mit der Zählerkonfiguration übereinstimmt (Groß-/Kleinschreibung beachten: `ai_chat_usage`)
2. Überprüfe, ob die Kunden-ID im Dodo Payments-Dashboard vorhanden ist
3. Teste den API-Schlüssel mit einem einfachen API-Aufruf
4. Überprüfe die Serverprotokolle auf Fehlermeldungen
</Accordion>

<Accordion title="Token counts showing zero">
**Mögliche Ursachen:**
- Das Modell gibt keine Nutzungsinformationen zurück
- Falsche SDK-Version

**Lösungen:**
1. Teste, ob das Modell die Nutzung zurückgibt:

```typescript
const response = await generateText({...});
console.log('Usage:', response.usage);
```

2. Aktualisiere auf die neueste Blueprints SDK-Version: `npm install @dodopayments/ingestion-blueprints@latest`
</Accordion>

<Accordion title="API key invalid error">
**Mögliche Ursachen:**
- Falscher API-Schlüssel für die Umgebung
- Zusätzliche Leerzeichen oder Anführungszeichen in der Datei `.env`

**Lösungen:**
- Stelle sicher, dass der Testschlüssel mit `test_` beginnt und der Live-Schlüssel mit `live_`
- Entferne alle Anführungszeichen um die Schlüssel in der Datei `.env`
- Erzeuge bei Bedarf einen neuen Schlüssel
</Accordion>
</AccordionGroup>
