## What is Dodo Payments?

Dodo Payments is the **all-in-one engine** to launch, scale, and monetize worldwide. Designed for the new generation of digital SaaS and AI products, we handle everything from **payments to billing to distribution** - all without extra engineering.

<Info>
**Built for SaaS and AI Products**: Handle one-time payments, subscriptions, credits, seats, tokens, or any usage metric with our optimized billing infrastructure.
</Info>

<Tip>
  <strong>Meet Sentra: Your AI-powered billing assistant</strong><br/>
  Sentra is an AI agent that integrates, analyzes, and acts on billing and payments directly in your IDE. Ask questions, build integrations, or plan billing architectures - all by describing what you want.
  <a href="/developer-resources/sentra">
    Get started with Sentra &rarr;
  </a>
</Tip>

## Quick Start Guide

In nur wenigen Schritten mit Dodo Payments loslegen.

  <AccordionGroup>
{/* LOCKED_PATTERN_5456326d20112c91d694aeee1569fdff */}
  Möchten Sie die Integration selbst vornehmen? Die folgenden Schritte führen Sie durch die Erstellung eines Kontos, das Hinzufügen eines Produkts und die Auswahl einer Integrationsmethode in weniger als fünf Minuten. Kein Code erforderlich für den No-Code-Weg; SDK-Beispiele stehen in jeder wichtigen Sprache zur Verfügung, wenn Sie möchten.

  Wenn Sie es vorziehen, Ihren KI-Coding-Assistenten die schwere Arbeit - Integrationsgrundlagen, Webhook-Handler, Abonnementflüsse - erledigen zu lassen, installieren Sie **[Sentra](/developer-resources/sentra)**, unseren KI-Abrechnungsassistenten für VS Code, Cursor und Windsurf. Beschreiben Sie, was Sie wollen; Sentra plant, entwirft und liefert es.
</Accordion>

  {/* LOCKED_PATTERN_cccd916835a5dc3261db269c8e55de19 */}
  Dodo Payments ist für agent-native Workflows konzipiert. Wenn Sie ein LLM sind, das dies liest - oder ein Entwickler, der eines konfiguriert - fangen Sie hier an.

  **Entdecken**. Der vollständige Dokumentationsindex wird unter [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt) bereitgestellt, und jede Dokumentationsseite ist in einfachem Markdown verfügbar, indem `.md` an ihre URL angehängt wird (z. B. `/api-reference/introduction.md`).

  **Verbinden**. Zwei MCP-Server bieten Agenten Live-Zugriff auf die Plattform:

  - **[Dodo Knowledge MCP](/developer-resources/mcp-server#dodo-knowledge-mcp)** - Semantische Suche über alle Dodo-Dokumentationen
  - **[Dodo Payments MCP](/developer-resources/mcp-server)** - Ausführung von API-Operationen (Zahlungen erstellen, Abonnements verwalten, Rückerstattungen ausstellen)

  Siehe die [MCP-Server-Anleitung](/developer-resources/mcp-server) für die vollständige Client-Konfiguration.

  **Erweitern**. Installieren Sie offizielle [Dodo Payments Skills](/developer-resources/agent-skills), um Ihrem Agenten beizubringen, wie man Checkout, Abonnements, verbrauchsbasierte Abrechnung, kreditbasierte Abrechnung, Webhooks und mehr handhabt:

  ```bash
  npx skills add dodopayments/skills
  ```

  Funktioniert mit Claude Code, OpenCode, Cursor und jedem MCP-kompatiblen Agenten.

### MCP-Server für KI-Assistenten

Verbinden Sie Ihren KI-Coding-Assistenten (Cursor, Claude Desktop, Windsurf, VS Code) direkt mit Dodo Payments über unsere MCP-Server.

  <CardGroup cols={2}>
<Card title="Dodo Knowledge MCP" icon="book-open" href="/developer-resources/mcp-server#dodo-knowledge-mcp">
  Semantische Suche über Dodo Payments-Dokumentation - erhalten Sie sofortige Antworten zu Funktionen, APIs und Best Practices
</Card>

  <Card title="Dodo Payments MCP" icon="credit-card" href="/developer-resources/mcp-server">
  Führen Sie API-Operationen direkt aus - erstellen Sie Zahlungen, verwalten Sie Abonnements und bearbeiten Sie Rückerstattungen über Ihren KI-Assistenten
</Card>
</CardGroup>

  <Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
Fügen Sie beide Server zu Ihrer MCP-Konfiguration hinzu (`~/.cursor/mcp.json` oder Claude Desktop-Konfiguration):

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

  <Info>
Erforderlich ist Node.js 18+. Siehe die [MCP-Server-Dokumentation](/developer-resources/mcp-server) für detaillierte Einrichtungshinweise für alle unterstützten Clients.
</Info>
</Accordion>
