## Einführung

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) ist eine Plattform, die standortbasierte Kaufkraftparitäts-Rabattcoupons erstellt und mit Ihrem Dodo Payments-Konto synchronisiert. Sie unterstützt sowohl Einmal- als auch Abonnementprodukte und generiert automatisch Rabattcodes, die nach einem von Ihnen festgelegten Zeitplan wechseln.

  <img src="/images/integrations/evendeals/hero.png" alt="Übersicht über die Evendeals-Integration mit Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Note>
Dodo Payments bietet native [Purchasing Power Parity](/features/purchasing-power-parity), wodurch Preise beim Checkout nach Land reduziert werden – ohne Banner, ohne Script und ohne zu verwaltende Rabattcodes. Evendeals richtet sich an Händler, die ausdrücklich den Rabattcode-Ansatz mit automatischer Coupon-Rotation nutzen möchten.
</Note>

## Funktionsweise

Evendeals verbindet sich über einen API key mit Ihrem Dodo Payments-Konto. Nach der Verbindung konfigurieren Sie pro Ländergruppe prozentuale Rabatte. Evendeals erstellt anschließend automatisch Rabattcodes in Ihrem Dodo Payments-Konto und wechselt diese nach einem von Ihnen festgelegten Zeitplan (nach Zeitintervall, Einlösungsanzahl oder Aufrufanzahl), um Missbrauch zu verhindern.

## Evendeals im Vergleich zu nativem PPP

Native Purchasing Power Parity ist die empfohlene Methode zur länderabhängigen Preisgestaltung, da keine Rabattcodes erforderlich sind und die Preise nicht geteilt oder missbraucht werden können. Wählen Sie Evendeals, wenn Sie ausdrücklich den Rabattcode-Ansatz nutzen möchten.

| | Natives PPP | Evendeals |
| :--- | :--- | :--- |
| Funktionsweise | Ein Prozentsatz pro Land, der beim Checkout angewendet wird | Ein prozentualer Rabatt, der über einen Code angewendet wird |
| Konfiguration | In Dodo Payments integriert | Evendeals-Dashboard |
| Banner oder Script erforderlich | Nicht erforderlich | Nicht erforderlich |
| Coupon-Rotation / automatische Aktualisierung | Nicht zutreffend | Ja |
| Unterstützung von Abonnements | Ja | Ja |
| Am besten geeignet für | Korrekte Preise ohne Änderungen an der Website | Rabattcode-Ansatz mit automatischer Rotation |

## Hauptfunktionen

- **Automatische Coupon-Synchronisierung** — Coupons werden automatisch in Dodo Payments erstellt und verwaltet
- **Prozentuale Rabatte** — Bieten Sie pro Ländergruppe prozentuale Rabatte an
- **Unterstützung von Abonnements** — Rabatte gelten über alle Abrechnungszyklen eines Abonnements hinweg
- **Regeln zur automatischen Aktualisierung** — Wechseln Sie Rabattcodes automatisch nach Zeitintervall, Einlösungsanzahl oder Aufrufanzahl, um Missbrauch zu verhindern

<Info>
Von Evendeals erstellte Rabattcodes erscheinen automatisch in Ihrem Dodo Payments-Dashboard unter **Sales → Discounts**.
</Info>

## Voraussetzungen

Stellen Sie vor der Einrichtung dieser Integration sicher, dass Sie über Folgendes verfügen:

1. Ein [Dodo Payments-Konto](https://app.dodopayments.com)
2. Ein [Evendeals-Konto](https://www.evendeals.com/signin)
3. Einen Dodo Payments API key

## Erste Schritte

<Steps>
  <Step title="Create a Dodo Payments API Key">
    Gehen Sie in Ihrem Dodo Payments-Dashboard zu **Developers → API Keys** und klicken Sie auf **Create New API**. Geben Sie einen aussagekräftigen Namen ein (z. B. "Evendeals"), damit Sie den API key später wiedererkennen.
  </Step>

  <Step title="Connect in Evendeals">
    Navigieren Sie in Ihrem [Evendeals-Dashboard](https://www.evendeals.com/signin) zu **Integrations**, suchen Sie die Dodo Payments-Karte und fügen Sie Ihren API key ein.
  </Step>

  <Step title="Configure Regional Discounts">
    Legen Sie pro Ländergruppe prozentuale Rabatte fest und klicken Sie auf „Synchronisieren“. Evendeals erstellt automatisch Coupons in Dodo Payments.

    <Check>
    Öffnen Sie nach der Synchronisierung **Sales → Discounts** in Ihrem Dodo Payments-Dashboard, um zu bestätigen, dass die generierten Coupons angezeigt werden. Jeder Coupon verfügt über ein erkennbares Evendeals-Präfix.
    </Check>
  </Step>
</Steps>
