## Einführung

[ParityDeals](https://www.paritydeals.com/) ist eine Plattform, die berechtigten Besuchern auf deiner Website standortbasierte Rabattbanner anzeigt und automatisch die passenden Rabattcodes in Dodo Payments generiert. Wenn ein Besucher das Banner sieht, erhält er einen Code, den er beim Checkout verwenden kann. Diese Codes erscheinen in deinem Dodo Payments-Dashboard unter **Sales → Discounts**.

<Note>
Dodo Payments bietet native [Purchasing Power Parity](/features/purchasing-power-parity), wodurch Preise beim Checkout nach Land reduziert werden – ohne Banner und ohne Script. ParityDeals ist für Händler gedacht, die ein sichtbares Rabattbanner auf ihrer eigenen Website anzeigen oder zeitlich begrenzte und Feiertagsangebote durchführen möchten.
</Note>

## So funktioniert es

ParityDeals ermittelt den Standort eines Besuchers, zeigt ihm auf deiner Website ein anpassbares Rabattbanner an und generiert einen Rabattcode, den er beim Checkout anwenden kann. Der Code wird automatisch in deinem Dodo Payments-Konto erstellt und funktioniert für die von dir konfigurierten Produkte.

1. Ein Besucher öffnet deine Website und ParityDeals ermittelt seinen Standort.
2. Wenn der Besucher für einen Rabatt berechtigt ist, erscheint ein Banner mit einem standortbasierten Code.
3. Der Besucher verwendet diesen Code beim Checkout und Dodo Payments wendet den Rabatt an.
4. Der Code erscheint in deinem Dashboard unter **Sales → Discounts**.

## ParityDeals im Vergleich zu nativer PPP

Native Purchasing Power Parity ist die empfohlene Methode für eine länderabhängige Preisgestaltung. Wähle ParityDeals, wenn du ausdrücklich ein Rabattbanner auf deiner eigenen Website oder Feiertags- und zeitlich begrenzte Kampagnen benötigst.

| | Native PPP | ParityDeals |
| :--- | :--- | :--- |
| Funktionsweise | Ein Prozentsatz pro Land, der beim Checkout angewendet wird | Ein prozentualer Rabatt, der über einen Code angewendet wird |
| Konfiguration | In Dodo Payments integriert | ParityDeals-Dashboard |
| Banner oder Script auf deiner Website | Nicht erforderlich | Erforderlich |
| Feiertags- und zeitlich begrenzte Angebote | Nein | Ja |
| Am besten geeignet für | Korrekte Preise ohne Änderungen an der Website | Werbebanner und saisonale Angebote |

<Info>
Du kannst das ParityDeals-Banner nicht in einen von Dodo Payments gehosteten Checkout oder Storefront einbetten, da benutzerdefinierte Scripts dort nicht unterstützt werden. Das Banner wird auf deiner eigenen Website oder in deiner eigenen App eingebunden.
</Info>

## Voraussetzungen

Stelle vor der Einrichtung dieser Integration sicher, dass du Folgendes hast:

1. Ein [Dodo Payments-Konto](https://app.dodopayments.com)
2. Ein [ParityDeals-Konto](https://app.paritydeals.com/)
3. Einen Dodo Payments API key

## Erste Schritte

<Steps>
  <Step title="Sign up on ParityDeals">
    Besuche [app.paritydeals.com](https://app.paritydeals.com/) und erstelle ein Konto.
  </Step>

  <Step title="Create Deals">
    Suche nach der Option zum Erstellen von Angeboten. Wähle im Dropdown-Menü **"Create Deals via Dodo Payments"** aus.

    <Frame>
      <img src="/images/integrations/paritydeals/create-deals.png" alt="Erstellen von Angeboten über Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Melde dich bei deinem **Dodo Payments-Dashboard** an und gehe zu **Developers → API Keys**. Klicke auf **"Create New API"**.

    <Tip>
      Benenne deinen API key aussagekräftig (z. B. 'ParityDeals'), damit du ihn später identifizieren kannst.
    </Tip>

    <Frame>
      <img src="/images/integrations/paritydeals/api-key.png" alt="Erstellen eines neuen API keys in Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Kopiere den erstellten API key und füge ihn in die ParityDeals-Oberfläche ein, um die Verbindung mit deinem Dodo Payments-Konto herzustellen.

    <Frame>
      <img src="/images/integrations/paritydeals/connect-api-key.png" alt="Verbinden eines API keys mit ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Sobald die Verbindung hergestellt ist, ruft ParityDeals deinen Dodo Payments-Produktkatalog ab. Wähle die Produkte aus, die du mit deinen Angeboten verknüpfen möchtest.

    <Frame>
      <img src="/images/integrations/paritydeals/select-products.png" alt="Auswählen von Produkten für ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Gib die URL deiner Website ein und wähle optional bestimmte Zielseiten aus, auf denen das Rabattbanner erscheinen soll. Wähle anschließend deinen bevorzugten Angebotstyp:
    - Standortbasierte Angebote
    - Feiertagsangebote
    - Zeitlich begrenzte Flash-Angebote

    <Frame>
      <img src="/images/integrations/paritydeals/deal-settings.png" alt="Konfigurieren der Angebotseinstellungen" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Wähle die Länder aus, für die du lokalisierte Rabatte anbieten möchtest, und lege den Rabattprozentsatz für jedes Land fest. ParityDeals stellt empfohlene Standardwerte bereit, die du nach Bedarf anpassen kannst.

    <Frame>
      <img src="/images/integrations/paritydeals/country-rules.png" alt="Festlegen länderbasierter Rabattregeln" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Gestalte dein Rabattbanner, indem du den Text anpasst, Farben und Layout auswählst und die Bannerposition festlegst (oben oder unten auf der Seite). Dieses Banner wird berechtigten Besuchern auf Grundlage deiner konfigurierten Regeln angezeigt.

    <Frame>
      <img src="/images/integrations/paritydeals/customize-banner.png" alt="Anpassen des Rabattbanners" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Nach dem Speichern deines Angebots generiert ParityDeals ein Script. Füge dieses Script in den Code deiner Website ein (normalerweise in den Abschnitt `<head>`). Dieses Script ermittelt automatisch die Standorte der Besucher und zeigt das passende Rabattbanner an.

    <Frame>
      <img src="/images/integrations/paritydeals/script.png" alt="ParityDeals-Integrationsscript" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>
