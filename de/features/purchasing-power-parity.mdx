Die Preisgestaltung nach Kaufkraftparität (PPP) passt Ihre Preise an die Kaufkraft des Standorts jedes Kunden an. Es gibt zwei Möglichkeiten, dies bei Dodo Payments zu tun.

<Info>
**Empfohlen:** Verwenden Sie die native [Lokalisierte Preisgestaltung](/features/localized-pricing), um einen festen lokalen Preis pro Land festzulegen, z. B. ₹999 in Indien für ein Produkt mit einem Basispreis von $20. Sie kontrollieren den genauen Betrag, es gilt für einmalige, abonnementbasierte und nutzungsbasierte Produkte, und es ist kein Banner oder Skript zu installieren.
</Info>

## Zwei Möglichkeiten zur Durchführung der PPP

| | Lokalisierte Preisgestaltung (native) | Standortbasierte Rabattcodes |
| :--- | :--- | :--- |
| Funktionsweise | Sie setzen einen festen lokalen Preis pro Land/Währung | Ein Prozentsatz Ihres Basispreises, angewendet über einen Code |
| Tools | Direkt in Dodo Payments integriert | [ParityDeals](https://www.paritydeals.com/) / [Evendeals](https://www.evendeals.com/integrations/dodo-payments) |
| Banner/Skript auf Ihrer Website | Nicht erforderlich | Erforderlich, um den Code anzuzeigen |
| Preis, den der Kunde sieht | Der genau von Ihnen festgelegte Betrag | Basispreis minus Rabatt |
| Am besten geeignet für | Klare, marktorientierte Preise, die Sie vollständig kontrollieren | Werbebanner und zeit-/feiertagsbasierte Angebote |

Für die native Einrichtung siehe [Lokalisierte Preisgestaltung](/features/localized-pricing). Der Rest dieser Seite befasst sich mit dem standortbasierten Rabattcode-Ansatz mit ParityDeals und Evendeals.

## Standortbasierte Rabattcodes

[ParityDeals](https://www.paritydeals.com/) und [Evendeals](https://www.evendeals.com/integrations/dodo-payments) sind Plattformen, die eine automatische Preisoptimierung basierend auf dem geografischen Standort eines Kunden ermöglichen, indem Rabattcodes generiert werden.

<Info>
Während Sie Rabattbanner nicht direkt in einem Dodo Payments-Shop einbetten können (da benutzerdefinierte Skripte nicht unterstützt werden), können Sie diese Tools trotzdem effektiv auf Ihrer eigenen Website oder Anwendung implementieren.
</Info>

### Auswahl einer Integration

Beide Plattformen integrieren sich direkt mit Dodo Payments, um Rabattcodes automatisch zu erstellen und zu verwalten. Verwenden Sie den Vergleich unten, um das Tool auszuwählen, das am besten zu Ihren Bedürfnissen passt.

| Funktion | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| PPP / Standortbasierte Preisgestaltung | Ja | Ja |
| Feiertags-/zeitbasierte Angebote | Ja | Nein |
| Abonnement-Unterstützung | Ja | Ja |
| Automatische Gutscheinaktualisierung | — | Ja |
| Bannergestaltung | Ja | Nein |
| Preisgestaltung | [Preise anzeigen](https://www.paritydeals.com/pricing/) | [Preise anzeigen](https://www.evendeals.com/pricing) |

### ParityDeals

Wenn ParityDeals in Ihre Website integriert ist, sehen berechtigte Besucher ein Banner, das einen standortbasierten Rabattcode enthält, den sie beim Checkout verwenden können. Diese Rabattcodes werden automatisch von ParityDeals erstellt und verwaltet und erscheinen in Ihrem **Dodo Payments-Dashboard** unter **Verkäufe → Rabatte**.

#### Einrichtung

<Steps>
  <Step title="Sign up on ParityDeals">
    Besuchen Sie [app.paritydeals.com](https://app.paritydeals.com/) und erstellen Sie ein Konto.
  </Step>

  <Step title="Create Deals">
    Nach der Anmeldung finden Sie die Option, Deals zu erstellen. Wählen Sie im Dropdown-Menü **"Deals über Dodo Payments erstellen"**.
    <Frame>
      <img src="/images/ppp/2.png" alt="Deals über Dodo Payments erstellen" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Melden Sie sich in Ihrem **Dodo Payments-Dashboard** an und navigieren Sie zu **Entwickler → API-Schlüssel**. Klicken Sie auf **"Neue API erstellen"**.
    <Tip>
      Nennen Sie Ihren API-Schlüssel beschreibend (z.B. 'ParityDeals'), damit Sie ihn später identifizieren können.
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="Einen neuen API-Schlüssel in Dodo Payments erstellen" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Kopieren Sie den erstellten API-Schlüssel und fügen Sie ihn in die ParityDeals-Oberfläche ein, um die Verbindung zu Ihrem Dodo Payments-Konto herzustellen.
    <Frame>
      <img src="/images/ppp/4.png" alt="API-Schlüssel mit ParityDeals verbinden" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Sobald verbunden, wird ParityDeals Ihren Dodo Payments-Produktkatalog abrufen. Wählen Sie die Produkte aus, die Sie mit Ihren Deals verknüpfen möchten.
    <Frame>
      <img src="/images/ppp/5.png" alt="Produktauswahl für ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Geben Sie Ihre Website-URL ein und wählen Sie optional bestimmte Zielseiten aus, auf denen das Rabattbanner erscheinen soll. Wählen Sie dann Ihren bevorzugten Deal-Typ:
    - Standortbasierte Deals
    - Feiertags-Deals
    - Zeitbasierte Flash-Deals
    <Frame>
      <img src="/images/ppp/6.png" alt="Deal-Einstellungen konfigurieren" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Wählen Sie die Länder aus, in denen Sie lokalisierte Rabatte anbieten möchten, und definieren Sie den Rabattprozentsatz für jedes Land. ParityDeals bietet empfohlene Standardwerte, die Sie bei Bedarf anpassen können.
    <Frame>
      <img src="/images/ppp/7.png" alt="Einstellen der länderbasierten Rabattregeln" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Gestalten Sie Ihr Rabattbanner, indem Sie den Text anpassen, Farben und das Layout auswählen und die Bannerposition (oben oder unten auf der Seite) festlegen. Dieses Banner wird berechtigten Besuchern basierend auf Ihren konfigurierten Regeln angezeigt.
    <Frame>
      <img src="/images/ppp/8.png" alt="Das Rabattbanner anpassen" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Nachdem Sie Ihren Deal gespeichert haben, generiert ParityDeals ein Skript. Fügen Sie dieses Skript zu Ihrem Website-Code hinzu (typischerweise im `<head>`-Abschnitt). Dieses Skript erkennt automatisch Besucherstandorte und zeigt das entsprechende Rabattbanner an.
    <Frame>
      <img src="/images/ppp/9.png" alt="ParityDeals-Integrationsskript" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

#### Zusätzliche Funktionen

Mit ParityDeals können Sie auch automatische [zeitbasierte Rabatte](https://www.paritydeals.com/features/time-based-discounts/) und [feiertagsbasierte Aktionen](https://www.paritydeals.com/features/holiday-based-discounts/) über das Jahr hinweg anbieten. Für detaillierte Informationen siehe die [ParityDeals-Dokumentation](https://www.paritydeals.com/docs/).

### Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) ist eine weitere Plattform, die sich mit Dodo Payments integriert, um eine standortbasierte Kaufkraftparitätspreisgestaltung anzubieten. Es unterstützt sowohl einmalige als auch abonnementbasierte Produkte.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Evendeals-Übersicht zur Dodo Payments-Integration" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### Hauptfunktionen

- **Automatische Gutscheinsynchronisierung** — Gutscheine werden automatisch in Dodo Payments erstellt und verwaltet
- **Prozentuale Rabatte** — Bieten Sie prozentuale Rabatte pro Ländergruppe
- **Abonnementunterstützung** — Rabatte gelten über Abrechnungszyklen hinweg
- **Automatische Aktualisierungsregeln** — Wechseln Sie die Gutscheincodes automatisch nach Zeitintervallen, Einlöseranzahl oder Ansichtsanzahl, um Missbrauch zu verhindern

<Info>
Von Evendeals erstellte Rabattcodes erscheinen automatisch in Ihrem Dodo Payments-Dashboard unter Sales → Discounts.
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="Hauptfunktionen von Evendeals für die Dodo Payments-Integration" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### Einrichtung

<Steps>
  <Step title="Create a Dodo Payments API key">
    Gehen Sie in Ihrem Dodo Payments-Dashboard zu **Entwickler → API-Schlüssel** und generieren Sie einen neuen Schlüssel.
  </Step>

  <Step title="Connect in Evendeals">
    Gehen Sie in Ihrem [Evendeals-Dashboard](https://www.evendeals.com/signin) zu **Integrations**, finden Sie die Dodo Payments-Karte und fügen Sie Ihren API-Schlüssel ein.
  </Step>

  <Step title="Configure regional discounts">
    Legen Sie prozentuale Rabatte für jede Ländergruppe fest und klicken Sie auf Sync. Evendeals erstellt Gutscheine automatisch in Dodo Payments.
    <Check>
    Nach dem Synchronisieren öffnen Sie **Sales → Discounts** in Ihrem Dodo Payments-Dashboard, um zu bestätigen, dass die generierten Gutscheine angezeigt werden. Jeder Gutschein wird ein erkennbares Evendeals-Präfix haben.
    </Check>
  </Step>
</Steps>

#### Setup

<Steps>
  <Step title="Create a Dodo Payments API key">
    In your Dodo Payments dashboard, go to **Developers → API Keys** and generate a new key.
  </Step>

  <Step title="Connect in Evendeals">
    In your [Evendeals dashboard](https://www.evendeals.com/signin), navigate to **Integrations**, find the Dodo Payments card, and paste your API key.
  </Step>

  <Step title="Configure regional discounts">
    Set percentage discounts for each country group and hit sync. Evendeals creates coupons in Dodo Payments automatically.

    <Check>
    After syncing, open **Sales → Discounts** in your Dodo Payments dashboard to confirm the generated coupons appear. Each coupon will have a recognizable Evendeals prefix.
    </Check>
  </Step>
</Steps>
