[ParityDeals](https://www.paritydeals.com/) und [Evendeals](https://www.evendeals.com/integrations/dodo-payments) sind Plattformen, die automatische Preisoptimierung basierend auf dem geografischen Standort eines Kunden ermöglichen, allgemein bekannt als "Kaufkraftparität" (PPP) Preisgestaltung.

<Info>
Obwohl Sie keine Rabattbanner direkt in einem Dodo Payments Storefront einbetten können (da benutzerdefinierte Skripte nicht unterstützt werden), können Sie diese Tools dennoch effektiv auf Ihrer eigenen Website oder Anwendung implementieren.
</Info>

## Auswahl einer Integration

Beide Plattformen integrieren sich direkt mit Dodo Payments, um Rabattcodes automatisch zu erstellen und zu verwalten. Verwenden Sie den folgenden Vergleich, um das Tool auszuwählen, das am besten zu Ihren Bedürfnissen passt.

| Funktion | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| PPP / Standortbasierte Preisgestaltung | Ja | Ja |
| Feiertags- / Zeitbasierte Angebote | Ja | Nein |
| Unterstützung für Abonnements | Ja | Ja |
| Automatische Gutscheinaktualisierung | — | Ja |
| Bannergestaltung | Ja | Nein |
| Preise | [Preise anzeigen](https://www.paritydeals.com/pricing/) | [Preise anzeigen](https://www.evendeals.com/pricing) |

## ParityDeals

Wenn ParityDeals in Ihre Website integriert wird, sehen berechtigte Besucher ein Banner, das einen standortbasierten Rabattcode enthält, den sie beim Checkout verwenden können. Diese Rabattcodes werden automatisch von ParityDeals erstellt und verwaltet und erscheinen in Ihrem **Dodo Payments Dashboard** unter **Sales → Discounts**.

### Einrichtung

<Steps>
  <Step title="Sign up on ParityDeals">
    Besuchen Sie [app.paritydeals.com](https://app.paritydeals.com/) und erstellen Sie ein Konto.
  </Step>

  <Step title="Create Deals">
    Nach dem Anmelden finden Sie die Option zum Erstellen von Angeboten. Wählen Sie im Dropdown-Menü **"Create Deals via Dodo Payments"** aus.

    <Frame>
      <img src="/images/ppp/2.png" alt="Angebote erstellen über Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Melden Sie sich in Ihrem **Dodo Payments Dashboard** an und navigieren Sie zu **Developers → API Keys**. Klicken Sie auf **"Create New API"**.

    <Tip>
      Benennen Sie Ihren API-Schlüssel beschreibend (z.B. 'ParityDeals'), damit Sie ihn später identifizieren können.
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="Erstellen eines neuen API-Schlüssels bei Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Kopieren Sie den erstellten API-Schlüssel und fügen Sie ihn in die ParityDeals-Oberfläche ein, um die Verbindung mit Ihrem Dodo Payments-Konto herzustellen.

    <Frame>
      <img src="/images/ppp/4.png" alt="API-Schlüssel mit ParityDeals verbinden" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Sobald verbunden, holt ParityDeals Ihren Dodo Payments-Produktkatalog ab. Wählen Sie die Produkte aus, die Sie mit Ihren Angeboten verknüpfen möchten.

    <Frame>
      <img src="/images/ppp/5.png" alt="Produkte für ParityDeals auswählen" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Geben Sie Ihre Website-URL ein und wählen Sie optional spezifische Zielseiten, auf denen das Rabattbanner erscheinen soll. Wählen Sie dann Ihren bevorzugten Angebotstyp:
    - Standortbasierte Angebote
    - Festtagsangebote
    - Zeitbasierte Blitzangebote

    <Frame>
      <img src="/images/ppp/6.png" alt="Angebots-Einstellungen konfigurieren" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Wählen Sie die Länder aus, für die Sie lokalisierte Rabatte anbieten möchten, und definieren Sie den Rabattprozentsatz für jedes. ParityDeals bietet empfohlene Standardwerte, die Sie nach Bedarf anpassen können.

    <Frame>
      <img src="/images/ppp/7.png" alt="Länderspezifische Rabattregeln festlegen" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Gestalten Sie Ihr Rabattbanner, indem Sie den Text anpassen, Farben und Layout auswählen und die Bannerposition (oben oder unten auf der Seite) wählen. Dieses Banner wird berechtigten Besuchern basierend auf Ihren konfigurierten Regeln angezeigt.

    <Frame>
      <img src="/images/ppp/8.png" alt="Anpassung des Rabattbanners" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Nach dem Speichern Ihres Angebots generiert ParityDeals ein Skript. Fügen Sie dieses Skript in Ihren Website-Code ein (normalerweise im `<head>` Abschnitt). Dieses Skript erkennt automatisch die Standorte der Besucher und zeigt das entsprechende Rabattbanner an.

    <Frame>
      <img src="/images/ppp/9.png" alt="ParityDeals Integrationsskript" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

### Zusätzliche Funktionen

## Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) ist eine weitere Plattform, die sich mit Dodo Payments integriert, um standortbasierte Kaufkraftparitätspreisgestaltung zu bieten. Es unterstützt sowohl Einmal- als auch Abonnementprodukte.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Evendeals Dodo Payments Integrationsübersicht" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

### Hauptmerkmale

- **Automatische Gutscheinsynchronisierung** — Gutscheine werden in Dodo Payments automatisch erstellt und verwaltet
- **Prozentsatz-Rabatte** — Prozentrabatte pro Ländergruppe anbieten
- **Unterstützung für Abonnements** — Rabatte gelten über Abrechnungszyklen von Abonnements hinweg
- **Automatische Aktualisierungsregeln** — Rotieren Sie Gutscheincodes automatisch nach Zeitintervall, Einlösungsanzahl oder Ansichtsanzahl, um Missbrauch zu vermeiden

<Info>
Von Evendeals erstellte Rabattcodes erscheinen automatisch in Ihrem Dodo Payments Dashboard unter Sales → Discounts.
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="Evendeals Schlüsselfunktionen für Dodo Payments Integration" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

### Einrichtung

<Steps>
  <Step title="Create a Dodo Payments API key">
    Gehen Sie in Ihrem Dodo Payments Dashboard zu **Developers → API Keys** und generieren Sie einen neuen Schlüssel.
  </Step>

  <Step title="Connect in Evendeals">
    Navigieren Sie in Ihrem [Evendeals Dashboard](https://www.evendeals.com/signin) zu **Integrations**, finden Sie die Dodo Payments-Karte und fügen Sie Ihren API-Schlüssel ein.
  </Step>

  <Step title="Configure regional discounts">
    Legen Sie Prozentsatz-Rabatte für jede Ländergruppe fest und synchronisieren Sie. Evendeals erstellt automatisch Gutscheine in Dodo Payments.

    <Check>
    Nach der Synchronisierung öffnen Sie **Sales → Discounts** in Ihrem Dodo Payments Dashboard, um zu bestätigen, dass die generierten Gutscheine erscheinen. Jeder Gutschein wird ein erkennbares Evendeals-Präfix haben.
    </Check>
  </Step>
</Steps>
