<Info>
Die Kaufkraftparität (PPP) berechnet einem Kunden einen Anteil deines Listenpreises, basierend auf dem Land, aus dem er kauft. Ein Produkt für \$20 kann in **Indien für \$6,00 verkauft werden**, ohne Rabattcode und ohne eine zweite Preisliste.
</Info>

## Was ist die Kaufkraftparität?

Derselbe Preis ist nicht überall gleich erschwinglich. \$20 sind in den Vereinigten Staaten ein kleiner Kauf, auf den Philippinen jedoch ein großer. PPP-Preise gleichen diesen Unterschied aus.

Dodo Payments hinterlegt für jedes Land einen Prozentsatz. Der Prozentsatz ist der **Anteil deines Listenpreises, den der Kunde bezahlt**. Für Indien beträgt er 30, also bezahlt ein Kunde in Indien 30 % des Preises. Für die Vereinigten Staaten beträgt er 100, dort ändert sich also nichts.

Du aktivierst PPP für jeden Produktpreis, auf den die Funktion angewendet werden soll. Produkte, für die du die Funktion nicht aktivierst, behalten überall ihren normalen Preis.

<Note>
PPP benötigt [Adaptive Currency](/features/adaptive-currency). Aktiviere zuerst Adaptive Currency.
</Note>

## Die wichtigsten Vorteile

- **Preissensible Märkte erreichen**: Verkaufe zu einem lokalen Preis, ohne deinen Preis im Heimatmarkt zu senken.
- **Kein Banner und kein Skript**: Der Preis ist beim Checkout korrekt. Deiner Website wird nichts hinzugefügt.
- **Keine Rabattcodes zu verwalten**: Du musst nichts erstellen, rotieren oder widerrufen.
- **Steuerung pro Produkt**: Aktiviere die Funktion für einen Einsteigerplan und lasse einen Enterprise-Plan unverändert.
- **Funktioniert überall**: Einmalige, wiederkehrende und nutzungsbasierte Produkte.

## Kaufkraftparität aktivieren

<Steps>
<Step title="Enable Adaptive Currency">
Gehe zu **Settings → Business**. Aktiviere in den **Business Settings** die Option **Adaptive Currency**. Ohne diese Option hat PPP keine Wirkung.

<Frame>
  <img src="/images/ppp/adaptive-currency-toggle.png" alt="Adaptive Currency und Kaufkraftparität in den Business Settings" style={{ maxHeight: '360px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Review your country percentages">
Klicke unter **Purchasing Power Parity** auf **Edit**, um **Country Prices** zu öffnen. Ändere den Prozentsatz für ein beliebiges Land und klicke anschließend auf **Save Changes**.

Lege unter **Example product price** einen Wert fest, um zu sehen, was jedes Land bezahlt. Die Spalte **Your Price** wird während der Eingabe aktualisiert. Verwende das Suchfeld, um ein Land nach Namen oder Code zu finden.

<Frame>
  <img src="/images/ppp/country-percentages.png" alt="Dialog Country Prices mit einem Prozentsatz und dem daraus resultierenden Preis für jedes Land" style={{ maxHeight: '620px', width: 'auto' }} />
</Frame>

<Note>
Diese Prozentsätze gelten für das gesamte Unternehmen. Jedes Produkt, für das Purchasing Power Parity aktiviert ist, verwendet sie.
</Note>
</Step>

<Step title="Turn PPP on for a product">
Öffne das Produkt. Aktiviere im Abschnitt **Pricing** die Option **Purchasing Power Parity** und speichere anschließend das Produkt.

Produkte, für die du die Option nicht aktivierst, behalten überall ihren normalen Preis.

<Frame>
  <img src="/images/ppp/product-toggle.png" alt="Purchasing Power Parity im Abschnitt Pricing des Produkts aktiviert" style={{ maxHeight: '440px', width: 'auto' }} />
</Frame>

<Warning>
Diese Option kann nicht aktiviert werden, solange Adaptive Currency deaktiviert ist. Aktiviere zuerst Adaptive Currency.
</Warning>
</Step>

<Step title="Confirm at checkout">
<Check>
Öffne einen Test-Checkout mit einem Abrechnungsland, für das ein Prozentsatz unter 100 festgelegt ist. Bestätige, dass der reduzierte Preis angezeigt wird.
</Check>
</Step>
</Steps>

## So wird der Preis berechnet

Der Länderprozentsatz wird mit deinem Listenpreis multipliziert:

```
price paid = list price × country percentage ÷ 100
```

Ein Produkt für \$20,00 für einen Kunden in Indien mit dem Wert 30:

```
2000 × 30 ÷ 100 = 600   →   $6.00
```

Dodo Payments wendet den Prozentsatz auf den Basispreis an, bevor die Währungsumrechnung erfolgt. [Adaptive Currency](/features/adaptive-currency) rechnet das Ergebnis anschließend in die Währung des Kunden um.

<Info>
Dodo Payments liest das Land beim Checkout aus dem **Abrechnungsland** des Kunden aus.
</Info>

### Länderprozentsätze

Für jedes Land gilt ein Prozentsatz zwischen **30 und 100**:

- **100** bedeutet, dass der Kunde den vollständigen Preis bezahlt. Es gibt keine Reduzierung.
- **30** ist der niedrigste Wert, den du festlegen kannst. Die maximale Reduzierung beträgt daher 70 %.

Die Standardwerte stammen aus den Daten zum Preisniveauindex der Weltbank. Dodo Payments rundet jeden Wert auf die nächsten 5, wendet einen Mindestwert von 30 an und begrenzt ihn auf 100. Für jedes unterstützte Land gibt es einen Wert. Du kannst jeden dieser Werte ändern.

Dies sind einige der Standardwerte, um die Bandbreite zu veranschaulichen:

| Land | Prozentsatz | Ein Produkt für \$20 wird verkauft für |
| :--- | :---: | :--- |
| Vereinigte Staaten | 100 | \$20,00 |
| Vereinigtes Königreich | 85 | \$17,00 |
| Deutschland | 75 | \$15,00 |
| Japan | 60 | \$12,00 |
| Brasilien | 45 | \$9,00 |
| Südafrika | 40 | \$8,00 |
| Philippinen | 35 | \$7,00 |
| Indien | 30 | \$6,00 |

<Note>
Die vollständige Liste umfasst 217 Länder. Öffne die Ländertabelle in deinem Dashboard, um alle Werte zu sehen.
</Note>

## Über die API aktivieren

PPP wird pro Produkt über das Feld `purchasing_power_parity` aktiviert. Der Standardwert ist `false`.

<Info>
Länderprozentsätze werden ausschließlich im Dashboard verwaltet. Sie sind nicht Teil der öffentlichen API.
</Info>

<CodeGroup>

```typescript theme={null}
import DodoPayments from 'dodopayments';

const client = new DodoPayments({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: 'test_mode',
});

const product = await client.products.create({
  name: 'Starter Plan',
  tax_category: 'saas',
  price: {
    type: 'one_time_price',
    currency: 'USD',
    price: 2000,
    discount: 0,
    purchasing_power_parity: true,
  },
});
```

import os
from dodopayments import DodoPayments

client = DodoPayments(
    bearer_token=os.environ.get("DODO_PAYMENTS_API_KEY"),

    name="Starter Plan",
    tax_category="saas",

        "currency": "USD",

```go theme={null}
package main

import (
	"context"
	"os"

	"github.com/dodopayments/dodopayments-go"
	"github.com/dodopayments/dodopayments-go/option"
)

func main() {
	client := dodopayments.NewClient(
		option.WithBearerToken(os.Getenv("DODO_PAYMENTS_API_KEY")),
	)

	_, err := client.Products.New(context.TODO(), dodopayments.ProductNewParams{
		Name:        dodopayments.F("Starter Plan"),
		TaxCategory: dodopayments.F(dodopayments.ProductNewParamsTaxCategorySaas),
		Price: dodopayments.F[dodopayments.PriceUnionParam](
			dodopayments.PriceOneTimePriceParam{
				Type:                  dodopayments.F(dodopayments.PriceOneTimePriceTypeOneTimePrice),
				Currency:              dodopayments.F(dodopayments.CurrencyUsd),
				Price:                 dodopayments.F(int64(2000)),
				Discount:              dodopayments.F(int64(0)),
				PurchasingPowerParity: dodopayments.F(true),
			},
		),
	})
	if err != nil {
		panic(err)
	}
}
```

## Wichtige Verhaltensweisen

| Verhalten | Details |
| :--- | :--- |
| **Benötigt Adaptive Currency** | PPP hat keine Wirkung, solange Adaptive Currency deaktiviert ist. |
| **Standardmäßig deaktiviert** | Jeder Preis beginnt mit `purchasing_power_parity: false`. |
| **Lokalisierte Preise haben Vorrang** | Ein Produkt mit einer passenden Regel für [Localized Pricing](/features/localized-pricing) wird niemals durch PPP angepasst. Der von dir festgelegte exakte Betrag wird angewendet. |
| **Vor der Umrechnung angewendet** | Der Prozentsatz wird auf deinen Basispreis angewendet. Adaptive Currency rechnet das Ergebnis um. |
| **Vor Rabatten** | Ein [Rabattcode](/features/discount-codes) wird auf den reduzierten Preis angewendet, sodass sich die beiden Reduzierungen kombinieren. |
| **Nur feste Gebühren bei nutzungsbasierten Produkten** | PPP wird auf die feste Gebühr eines nutzungsbasierten Produkts angewendet, niemals auf die gemessene Nutzung. |
| **Nicht für Pay What You Want** | Der Kunde wählt den Betrag, daher gilt PPP nicht. Siehe [Pay What You Want](/features/pay-what-you-want). |
| **Prozentsatzbereich** | Ein Länderprozentsatz liegt zwischen 30 und 100. Die maximale Reduzierung beträgt 70 %. |
| **Kein eigener Webhook** | Der reduzierte Betrag wird wie jeder andere Preis bei der Zahlung oder dem Abonnement angezeigt. |

## Best Practices

- **Aktiviere die Funktion zunächst für ein Produkt.** Bestätige den Checkout-Preis, bevor du sie für deinen Katalog aktivierst.
- **Behalte die Rabattkombination im Blick.** Ein Rabattcode wird zusätzlich zum PPP-Preis angewendet. Ein Länderwert von 30 plus ein Code von 20 % ergibt 24 % deines Listenpreises.
- **Lasse Enterprise-Pläne außen vor.** Ein ausgehandelter Plan benötigt nur selten eine Länderanpassung.
- **Lege dort eigene Werte fest, wo es wichtig ist.** Die Standardwerte sind ein Ausgangspunkt, keine Vorgabe.
- **Prüfe die Auswirkungen auf Abonnements.** Ein Abonnent, der sich zum reduzierten Preis anmeldet, verlängert zum selben Preis.
