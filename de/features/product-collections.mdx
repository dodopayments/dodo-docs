<Info>
Produktkollektionen ermöglichen es Ihnen, verwandte Produkte (z. B. Starter-, Pro-, Enterprise-Pläne) unter einem Dach zu gruppieren. Zeigen Sie alle Optionen in einem einzigen Checkout an, definieren Sie Upgrade-/Downgrade-Pfade und geben Sie den Kunden die Flexibilität, Pläne direkt im Kundenportal zu wechseln.
</Info>

## Wichtige Highlights

- **Sammlungsbasierte Struktur**: Gruppieren Sie verwandte Produkte (Pläne, Stufen, Preisoptionen) unter einer einzigen Sammlung für eine organisierte Verwaltung.
- **Eine Sammlung, viele Produkte**: Fügen Sie mehrere Produkte wie Starter, Pro, Lifetime usw. hinzu, jeweils mit einem eigenen Preismodell.
- **Dynamisches Checkout-Erlebnis**: Zeigen Sie alle Produkte aus einer Sammlung in einer Checkout-Ansicht an, damit die Kunden ihren gewünschten Plan auswählen können.
- **Händlerkontrolle**: Aktivieren, deaktivieren und sortieren Sie Produkte innerhalb jeder Sammlung. Das erste Produkt wird beim Checkout automatisch vorausgewählt.
- **Lebenszyklusbewusstsein**: Ermöglichen Sie es den Kunden, zwischen Produkten in derselben Sammlung über das Kundenportal zu upgraden oder downgraden.

## Erstellen einer Produktkollektion

Produktkollektionen werden vom Dashboard aus oder über die API erstellt und verwaltet. Jede Sammlung fungiert als Behälter für verwandte Produkte.

<Steps>
<Step title="Erstellen Sie die Sammlung">
Definieren Sie die Sammlung mit einem Namen und einer optionalen Beschreibung. Laden Sie ein Bild hoch, um die Sammlung im Checkout visuell darzustellen.

<Frame>
  <img 
    src="/images/product-collection/collection-form.png" 
    alt="Screenshot des Formulars zur Erstellung der Produktkollektion im Dashboard mit Feldern für Name, Beschreibung und Bild-Upload" 
  />
</Frame>

**Sammlungsfelder:**
- **Name** (erforderlich): Anzeigename für die Sammlung (z. B. "SaaS-Pläne", "Lizenzstufen")
- **Beschreibung** (optional): Kurze Erklärung, die im Checkout angezeigt wird
- **Bild** (optional): Visuelle Markenbildung für die Sammlung

</Step>

<Step title="Produkte zur Sammlung hinzufügen">
Fügen Sie vorhandene Produkte zu Ihrer Sammlung hinzu. Produkte können in Gruppen organisiert werden, um eine bessere Struktur zu gewährleisten.

<Frame>
  <img 
    src="/images/product-collection/collection-form-products.png" 
    alt="Screenshot der Produktseite der Produktkollektion, die eine Liste von Produkten und die Möglichkeit zeigt, diese zur Sammlung hinzuzufügen" 
  />
</Frame>

**Produktorganisation:**
- **Gruppen**: Organisieren Sie Produkte optional in benannten Gruppen (z. B. "Monatspläne", "Jahrespläne")
- **Ungruppierte Produkte**: Produkte ohne Gruppe erscheinen auf der Sammlungsebene
- **Reihenfolge**: Ziehen und ablegen, um die Anzeigeordnung festzulegen

<Warning>
Jedes Produkt kann nur einer Sammlung angehören. Wenn ein Produkt bereits in einer anderen Sammlung enthalten ist, müssen Sie es zuerst entfernen.
</Warning>

</Step>

<Step title="Bestellung und Sichtbarkeit konfigurieren">
Steuern Sie die Anzeigeordnung und Sichtbarkeit der Produkte innerhalb der Sammlung.

**Konfigurationsoptionen:**
- **Produktstatus**: Aktivieren oder deaktivieren Sie einzelne Produkte innerhalb der Sammlung
- **Anzeigeordnung**: Ziehen und ablegen, um die Reihenfolge festzulegen, in der Produkte im Checkout erscheinen

<Info>
Das erste Produkt in der Sammlung wird automatisch als Standard im Checkout vorausgewählt. Ändern Sie die Reihenfolge der Produkte, um festzulegen, welches Produkt standardmäßig ausgewählt wird.
</Info>

</Step>
</Steps>

## Sammlung Checkout

Sammlungen ermöglichen ein einheitliches Checkout-Erlebnis, bei dem Kunden alle verfügbaren Produkte an einem Ort anzeigen und auswählen können.

### Checkout-Typen

| Typ | Beschreibung | Anwendungsfall |
|------|-------------|----------|
| **Sammlung Checkout** | Zeigt alle aktiven Produkte innerhalb einer Sammlung an | Auswahl des Abonnementplans, gestaffelte Preisgestaltung |
| **Einzelprodukt-Checkout** | Zeigt nur ein spezifisches Produkt an | Direkter Kauf, Werbelinks |

### Erfahrung im Sammlung Checkout

Bei Verwendung eines Sammlung Checkouts:

1. **Alle aktiven Produkte angezeigt**: Kunden sehen jedes aktivierte Produkt in der Sammlung
2. **Erstes Produkt vorausgewählt**: Das erste Produkt in der Sammlungsreihenfolge wird automatisch ausgewählt
3. **Produktdetails angezeigt**: Jedes Produkt zeigt seinen Namen, Beschreibung und Preis an
4. **Einzelauswahl**: Der Kunde wählt ein Produkt zum Kauf aus
5. **Standardablauf fortgesetzt**: Nach der Auswahl fährt der Checkout mit den Preis- und Abrechnungseinstellungen des gewählten Produkts fort

  <img 
    src="/images/product-collection/checkout-page.png" 
    alt="Screenshot der Produktkollektion-Checkout-Seite, die mehrere angezeigte Produkte zeigt"

<Tip>
Der Sammlung Checkout ist ideal für Abonnementunternehmen, bei denen Sie möchten, dass Kunden Pläne nebeneinander vergleichen, bevor sie kaufen.
</Tip>

### API-Integration

Erstellen Sie eine Checkout-Sitzung für eine Sammlung:

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});

// Redirect customer to the checkout
window.location.href = session.url;
```

<Warning>
Bei Verwendung von `product_collection_id` können Rabattcodes nicht bei der Sitzungscreatation angewendet werden. Kunden können jedoch Rabattcodes im Checkout eingeben, wenn dies aktiviert ist.
</Warning>

## Integration des Kundenportals

Kunden können innerhalb desselben Kollektion direkt im Kundenportal upgraden oder downgraden.

<Tip>
**Haben Sie bereits Abonnementprodukte?** Fügen Sie diese einfach einer Produktkollektion hinzu, um Upgrade-/Downgrade-Abläufe im Kundenportal zu aktivieren. Es ist nicht notwendig, Ihre Produkte neu zu erstellen.
</Tip>

### Aktionen zur Planverwaltung

| Aktion | Beschreibung | Händlerkontrolle |
|--------|-------------|------------------|
| **Aktuellen Plan anzeigen** | Anzeigen des aktuellen Produktnamens, Preises und des Verlängerungsdatums | Immer verfügbar |
| **Plan upgraden** | Wechsel zu einem höherwertigen Produkt in derselben Sammlung | Konfigurierbar (Standard: erlaubt) |
| **Plan downgraden** | Wechsel zu einem niedrigwertigen Produkt in derselben Sammlung | Konfigurierbar (Standard: erlaubt) |
| **Abbrechen** | Abonnement vollständig stornieren | Immer verfügbar |

  <img

### Upgrade-/Downgrade-Regeln

- Upgrades und Downgrades sind nur zwischen Produkten **innerhalb derselben Sammlung** verfügbar
- Proration wird basierend auf Ihren Abonnement-Einstellungen angewendet
- E-Mail-Benachrichtigungen werden bei jedem Upgrade, Downgrade oder Stornierung an das Unternehmen gesendet

<Frame>
  <img 
    src="/images/product-collection/portal-change-plan.png"

  />
</Frame>

<Info>
Kunden können nicht auf Produkte außerhalb ihrer aktuellen Sammlung wechseln. Erstellen Sie separate Sammlungen für unterschiedliche Produktlinien.
</Info>

## Abonnementeinstellungen

Konfigurieren Sie, wie Abonnements und Planänderungen in Ihrem Unternehmen aus dem Abschnitt "Abonnementeinstellungen" in Ihrem Dashboard funktionieren.

  <img

### Verfügbare Einstellungen

| Einstellung | Beschreibung | Standard |
|---------|-------------|---------|
| **Erlaube mehrere Abonnements** | Kunden können mehr als ein aktives Abonnement gleichzeitig haben | Aktiviert |
| **Erlaube Abonnementaktualisierungen** | Kunden können ihre bestehenden Abonnements jederzeit über das Kundenportal upgraden oder downgraden | Deaktiviert |

<Info>
Planänderungen über das Kundenportal sind standardmäßig deaktiviert. Aktivieren Sie "Erlaube Abonnementaktualisierungen" in Ihren Abonnementeinstellungen, um es den Kunden zu ermöglichen, zwischen Produkten in derselben Sammlung upzugraden oder downgraden.
</Info>

## Verwaltung von Sammlungen

Produktkollektionen werden exklusiv über das Dodo Payments Dashboard erstellt und verwaltet.

<Info>
Das Erstellen, Aktualisieren und Löschen von Sammlungen ist nur über das Dashboard möglich. Die API bietet nur Lesezugriff, um Sammlungsdaten für Integrationszwecke abzurufen.
</Info>

### Dashboard-Operationen

- **Erstellen**: Richten Sie neue Sammlungen mit Produkten und Gruppen ein
- **Aktualisieren**: Ändern Sie Name, Beschreibung, Bild und Produktorganisation
- **Neuordnen**: Ziehen und ablegen, um die Anzeigereihenfolge der Produkte zu ändern
- **Produkte aktivieren/deaktivieren**: Steuern Sie, welche Produkte im Checkout angezeigt werden
- **Löschen**: Entfernen Sie eine Sammlung (Produkte bleiben erhalten, sind jedoch nicht verlinkt)

## Beste Praktiken

- **Logisch gruppieren**: Organisieren Sie Produkte nach Abrechnungsintervall (monatlich/jährlich) oder Funktionsstufe (Starter/Pro/Enterprise)
- **Strategisch anordnen**: Platzieren Sie Ihren beliebtesten oder empfohlenen Plan zuerst, da dieser im Checkout vorausgewählt wird
- **Klare Benennungen verwenden**: Produktnamen sollten die Wertunterschiede klar kommunizieren
- **Beide Richtungen aktivieren**: Erlauben Sie sowohl Upgrades als auch Downgrades, um den Kunden Flexibilität zu geben
- **Proration berücksichtigen**: Wählen Sie einen Prorationsmodus, der zu Ihrem Geschäftsmodell passt
- **Umfassend testen**: Überprüfen Sie den Checkout- und Planänderungsablauf im Testmodus, bevor Sie live gehen
