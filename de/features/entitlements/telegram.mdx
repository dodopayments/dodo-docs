<Info>
Die Telegram-Berechtigung gibt zahlenden Kunden Zugang zu einem privaten Chat oder Kanal. Der Dodo Payments Telegram-Bot generiert für jeden Kunden einen einmaligen Einladungslink und entfernt sie bei Kündigung.
</Info>

## Was geliefert wird

- Der Grant wird in `Pending` erstellt, während der Bot die Einladung vorbereitet, und wechselt zu `Delivered`, sobald der Link bereit ist.
- Der Kunde erhält einen einmalig verwendbaren Telegram-Einladungslink per Zustell-E-Mail und im Customer Portal.
- Der Kunde tippt auf den Link, woraufhin der Bot ihn dem konfigurierten Chat hinzufügt.
- Bei Stornierung, Rückerstattung oder manuellem Widerruf entfernt der Bot den Kunden aus dem Chat.

Häufige Anwendungsfälle sind private Alpha-Kanäle, bezahlte Signalgruppen und Community-Vorteile.

## Telegram verbinden

<Steps>
<Step title="Open Entitlements">
Gehen Sie in Ihrem Dodo Payments-Dashboard zu **Berechtigungen** und klicken Sie auf **+**, um **Telegram-Zugang** als Integration auszuwählen. Das Dashboard fragt nach Ihrer Telegram-Benutzer-ID, damit der Bot die Eigentümerschaft der von ihm verwalteten Chats überprüfen kann.

<Frame caption="New Entitlement → Telegram Access. The dashboard needs your Telegram user ID before it lists chats.">
<img src="/images/entitlements/telegram/connect-prompt.png" alt="Neues Berechtigungsformular für Telegram-Zugang, das nach der Telegram-Benutzer-ID und dem Verbinden-Button fragt" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Tip>
Die nächsten beiden Schritte sind Einrichtungsschritte in Telegram und können in beliebiger Reihenfolge abgeschlossen werden — holen Sie sich Ihre Benutzer-ID und fügen Sie den Bot als Admin zu Ihrem Chat hinzu. Sobald beide abgeschlossen sind, kehren Sie zum Dashboard für den letzten Schritt zurück.
</Tip>
</Step>

<Step title="Get your Telegram user ID">
Nachricht an **`/start`** auf Telegram, um:

- **`@dodo_payments_bot`** zu senden, wenn Sie den **Live-Modus** verwenden
- **`@DodoPaymentsTestBot`** zu senden, wenn Sie den **Testmodus** verwenden

Der Bot antwortet mit Ihrer numerischen Telegram-Benutzer-ID. Kopieren Sie diese — Sie werden sie im letzten Schritt in das Dashboard einfügen.
</Step>

<Step title="Add the bot to your chat as an admin">
Öffnen Sie in der Telegram-Gruppe oder -Kanal, die Sie steuern möchten, die Mitgliederliste und **fügen Sie denselben Bot als Admin hinzu** (`@dodo_payments_bot` für live, `@DodoPaymentsTestBot` für Test) mit diesen zwei aktiven Berechtigungen:

- **Benutzer sperren** — erforderlich, um Mitglieder bei Widerruf zu entfernen
- **Benutzer hinzufügen** — erforderlich, um zahlende Kunden einzuladen

Lassen Sie alle anderen Admin-Berechtigungen deaktiviert.

<Frame caption="Telegram → Promote to admin. Only Ban Users and Add Users need to be enabled.">
<img src="/images/entitlements/telegram/promote-bot-admin.png" alt="Telegram zu Admin befördern Bildschirm, der zeigt, dass Benutzer sperren und Benutzer hinzufügen für den Dodo Payments-Bot aktiviert sind" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Connect Telegram and pick the chat">
Zurück im Dashboard, fügen Sie die Benutzer-ID aus Schritt 2 in **Telegram-Benutzer-ID** ein und klicken auf **Telegram verbinden**. Der Chat-Auswahlbildschirm zeigt nun jede Gruppe und jeden Kanal an, in dem der Bot ein Admin ist — wählen Sie den aus, den Sie steuern möchten, geben Sie der Berechtigung einen Namen und klicken Sie auf **Berechtigung erstellen**.
</Step>
</Steps>

## Kundenfluss

1. Der Kunde schließt den Checkout ab.
2. Dodo Payments erstellt einen `Pending`-Grant und fordert den Bot auf, einen einmalig verwendbaren Einladungslink für den konfigurierten Chat zu generieren.
3. Sobald der Link bereit ist, wechselt der Grant zu `Delivered`, und der Link wird in die Zustell-E-Mail und das Customer Portal aufgenommen.
4. Der Kunde tippt auf den Link und wird dem Chat hinzugefügt.
5. Bei einem Widerruf entfernt der Bot den Kunden aus dem Chat.

<Tip>
Der Einladungslink ist einmalig und verfällt, nachdem der Kunde beigetreten ist. Wenn sie den Link vor dem Beitritt verlieren, generieren Sie ihn neu, indem Sie die Liefer-E-Mail erneut senden oder die Berechtigung über das Dashboard widerrufen und neu erstellen.
</Tip>

## Erforderliche Konfiguration

| Feld | Erforderlich | Beschreibung |
|---|---|---|
| `chat_id` | Ja | Die Telegram-Chat-ID (numerisch, oft negativ für Gruppen/Kanäle). Der Dashboard-Auswahlbildschirm füllt dies für Sie aus. |

## Über API erstellen

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Premium Signals Group',
  integration_type: 'telegram',
  integration_config: {
    chat_id: '-1001234567890',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Premium Signals Group",
    integration_type="telegram",
    integration_config={"chat_id": "-1001234567890"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Premium Signals Group"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeTelegram),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigTelegramConfigParam{
      ChatID: dodopayments.F("-1001234567890"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

Siehe [`entitlement_grant.*` Webhook-Events](/developer-resources/webhooks/intents/entitlement-grant). Telegram-Grants werden in `Pending` erstellt und wechseln zu `Delivered`, sobald der Bot den Einladungslink ausgestellt hat.

## Problembehandlung

<AccordionGroup>
<Accordion title="Chat doesn't appear in the picker">
Der Dodo Payments Bot muss dem Chat **als Admin** mit aktivierter **Benutzer hinzufügen**-Berechtigung hinzugefügt werden. Der Auswahlbildschirm liest den Live-Status, sodass der Chat erscheint, sobald der Bot ein Admin ist.
</Accordion>

<Accordion title="Customer says the invite link doesn't work">
Telegram-Einmal-Links laufen nach der ersten Verwendung ab. Wenn der Kunde ihn auf einem ausgeloggten Gerät getippt hat oder den Link verloren hat, widerrufen Sie die Berechtigung und geben sie erneut aus.
</Accordion>

<Accordion title="Customer cancelled but is still in the chat">
Der Bot benötigt die Admin-Berechtigung **Benutzer sperren**, um Mitglieder zu entfernen. Öffnen Sie die Chateinstellungen und bestätigen Sie, dass sowohl **Benutzer sperren** als auch **Benutzer hinzufügen** beim Dodo Payments Bot aktiviert sind.
</Accordion>
</AccordionGroup>
