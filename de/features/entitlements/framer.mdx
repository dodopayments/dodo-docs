<Info>
Das Framer-Entitlement schaltet einen Framer-Template-Remix-Link für zahlende Kunden frei. Du lädst das Template in Dodo Payments hoch, verknüpfst das Entitlement mit einem Produkt, und Kunden erhalten einen Remix-Link, über den sie das Template in ihr eigenes Framer-Konto kopieren können.
</Info>

## Was bereitgestellt wird

- Ein eindeutiger Remix-Link zu dem von dir hochgeladenen Framer-Template.
- Der Kunde klickt auf den Link, um das Template in seinen eigenen Framer-Arbeitsbereich zu remixen.
- Bei einer Kündigung oder Rückerstattung wird der Remix-Link ungültig.

Typische Anwendungsfälle sind kostenpflichtige Framer-Landingpage-Templates, Portfolio-Kits und Komponentenbibliotheken.

## Framer verbinden

Framer wird implizit verbunden, wenn du zum ersten Mal ein Template-Entitlement erstellst. Es ist kein separater OAuth-Schritt erforderlich.

<Steps>
<Step title="Open Entitlements">
Gehe in deinem Dodo Payments-Dashboard zu **Entitlements** und klicke auf **+**.
</Step>

<Step title="Pick Framer">
Wähle **Framer Template** als Integration aus.
</Step>

<Step title="Grab the remix link from Framer">
Öffne dein Framer-Projekt. Öffne im Menü oben links **File → Copy Remix Link**. Dadurch wird eine öffentliche Remix-URL erstellt, über die jeder das Projekt in sein eigenes Framer-Konto kopieren kann — den Link Dodo Payments teilst du mit zahlenden Kunden.

<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">
<img src="/images/entitlements/framer/copy-remix-link.png" alt="Framer-Dateimenü mit hervorgehobener Option Copy Remix Link" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Add the template and create the entitlement">
Wähle im Dodo Payments-Dashboard das Template aus dem Dropdown **Template** aus. Wenn du dies zum ersten Mal für ein neues Template tust, füge den kopierten Remix-Link ein, um es zu registrieren. Gib dem Entitlement einen **Namen** und klicke auf **Create Entitlement**.

<Frame>
<img src="/images/entitlements/framer/create.png" alt="Framer-Template-Entitlement-Formular mit Template-Auswahl und Namensfeld" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Dodo Payments registriert das Template und gibt ein `framer_template_id` zurück, auf das du programmgesteuert verweisen kannst.
</Step>
</Steps>

## Kundenablauf

1. Der Kunde schließt den Checkout ab.
2. Dodo Payments erstellt einen `pending`-Grant und stellt einen eindeutigen, an diesen Kunden gebundenen Remix-Link aus.
3. Der Grant wechselt zu `delivered`, sobald der Remix-Link bereitgestellt wurde, und der Link wird in die E-Mail und das Portal des Kunden aufgenommen.
4. Der Kunde klickt auf den Link, meldet sich bei Framer an und remixt das Template.
5. Bei einem Widerruf wird der Remix-Link ungültig. Bereits geremixte Kopien im Framer-Konto des Kunden bleiben erhalten, da Framer keine Möglichkeit bietet, sie zu widerrufen.

## Erforderliche Konfiguration

| Feld | Erforderlich | Beschreibung |
|---|---|---|
| `framer_template_id` | Ja | Die Template-ID, die beim Hochladen des Templates zurückgegeben wird. |

## Über die API erstellen

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Portfolio Kit',
  integration_type: 'framer',
  integration_config: {
    framer_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Portfolio Kit",
    integration_type="framer",
    integration_config={"framer_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Portfolio Kit"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFramer),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFramerConfigParam{
      FramerTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

Siehe [`entitlement_grant.*` Webhook-Ereignisse](/developer-resources/webhooks/intents/entitlement-grant). Framer-Grants treffen als `pending` ein und wechseln zu `delivered`, sobald der Remix-Link bereitgestellt wurde.

## Fehlerbehebung

<AccordionGroup>
<Accordion title="Customer's remix link doesn't work">
Der Remix-Link kann nur einmal verwendet werden und ist an den Kunden gebunden. Wenn der Kunde den Link gelöscht hat, bevor er das Template remixt hat, widerrufe den Grant und stelle ihn erneut aus.
</Accordion>

<Accordion title="Refunded customer still has a remixed copy">
Das ist erwartungsgemäß. Framer behandelt einen Remix nach dem Kopieren als eigenes Projekt des Kunden; Dodo Payments macht den ursprünglichen Link ungültig, kann aber keine Kopien im Kundenkonto löschen.
</Accordion>
</AccordionGroup>
