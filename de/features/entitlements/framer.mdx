<Info>
Die Framer-Berechtigung entsperrt einen Framer-Vorlagen-Remix-Link für zahlende Kunden. Du lädst die Vorlage zu Dodo Payments hoch, verknüpfst die Berechtigung mit einem Produkt, und die Kunden erhalten einen Remix-Link, der ihnen erlaubt, die Vorlage in ihr eigenes Framer-Konto zu klonen.
</Info>

## Was geliefert wird

- Ein einzigartiger Remix-Link zur hochgeladenen Framer-Vorlage.
- Der Kunde klickt auf den Link, um die Vorlage in seinen eigenen Framer-Arbeitsbereich zu remixieren.
- Bei Stornierung oder Erstattung wird der Remix-Link ungültig gemacht.

Gängige Anwendungen sind bezahlte Framer Landing-Page-Vorlagen, Portfolio-Kits und Komponentenbibliotheken.

## Framer verbinden

Framer wird implizit verbunden, wenn du zum ersten Mal eine Vorlagenberechtigung erstellst. Es gibt keinen separaten OAuth-Schritt.

<Steps>
<Step title="Open Entitlements">
Gehe in deinem Dodo Payments-Dashboard zu **Berechtigungen** und klicke auf **+**.
</Step>

<Step title="Pick Framer">
Wähle **Framer Vorlage** als die Integration.
</Step>

<Step title="Grab the remix link from Framer">
Öffne dein Framer-Projekt. Gehe im oberen linken Menü zu **Datei → Remix-Link kopieren**. Dies erzeugt eine öffentliche Remix-URL, die es jedem erlaubt, das Projekt in sein eigenes Framer-Konto zu klonen — der Link, den Dodo Payments mit zahlenden Kunden teilen wird.
</Step>

<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">
<img src="/images/entitlements/framer/copy-remix-link.png" alt="Framer-Dateimenü mit hervorgehobener Remix-Link-Kopieroption" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Add the template and create the entitlement">
Zurück im Dodo Payments-Dashboard, wähle die Vorlage aus dem **Vorlagen**-Dropdown aus. Beim ersten Mal für eine neue Vorlage füge den kopierten Remix-Link ein, um ihn zu registrieren. Gib der Berechtigung einen **Namen** und klicke auf **Berechtigung erstellen**.
<Frame>

<Frame>
<img src="/images/entitlements/framer/create.png" alt="Framer-Vorlagen-Berechtigungsformular mit Vorlagenauswahl und Namensfeld" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Dodo Payments registriert die Vorlage und gibt eine `framer_template_id` zurück, die du programmatisch referenzieren kannst.
</Step>
</Steps>

## Kundenfluss

1. Der Kunde schließt den Checkout ab.
2. Dodo Payments erstellt eine `pending`-Berechtigung und gibt einen einzigartigen Remix-Link aus, der an diesen Kunden gebunden ist.
3. Die Berechtigung wechselt zu `delivered`, sobald der Remix-Link bereitgestellt wird, und der Link ist in der E-Mail und im Portal des Kunden enthalten.
4. Der Kunde klickt auf den Link, meldet sich bei Framer an und remixiert die Vorlage.
5. Bei Widerruf wird der Remix-Link ungültig gemacht. Bereits remixte Kopien im Framer-Konto des Kunden verbleiben, da Framer keine Möglichkeit bietet, sie zu widerrufen.

## Erforderliche Konfiguration

| Feld | Erforderlich | Beschreibung |
|---|---|---|
| `framer_template_id` | Ja | Die Vorlagen-ID, die bei Hochladen der Vorlage zurückgegeben wird. |

## Erstellen über API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Portfolio Kit',
  integration_type: 'framer',
  integration_config: {
    framer_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Portfolio Kit",
    integration_type="framer",
    integration_config={"framer_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Portfolio Kit"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFramer),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFramerConfigParam{
      FramerTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

Siehe [`entitlement_grant.*` webhook events](/developer-resources/webhooks/intents/entitlement-grant). Framer-Berechtigungen kommen `pending` an und wechseln zu `delivered`, sobald der Remix-Link bereitgestellt wird.

## Fehlerbehebung

<AccordionGroup>
<Accordion title="Customer's remix link doesn't work">
Der Remix-Link ist einmalig und an den Kunden gebunden. Wenn er den Link vor dem Remixieren gelöscht hat, widerrufe die Berechtigung und erstelle sie neu.
</Accordion>

<Accordion title="Refunded customer still has a remixed copy">
Dies wird erwartet. Framer behandelt einen Remix als das eigene Projekt des Kunden, sobald es geklont ist; Dodo Payments macht den ursprünglichen Link ungültig, kann jedoch keine Kopien im Kundenkonto löschen.
</Accordion>
</AccordionGroup>
