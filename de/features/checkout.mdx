## Adaptive Währung

Adaptive Währung ermöglicht es Kunden, in ihrer bevorzugten lokalen Währung zu bezahlen, was Vertrauen und Konversionsraten verbessert.

### So funktioniert es

1. **Aktivieren**: Aktivieren Sie die Adaptive Währung in Ihren Geschäftseinstellungen
2. **Auswählen**: Kunden können Währungen direkt beim Checkout wechseln
3. **Konvertieren**: Preise werden dynamisch mit Echtzeit-Wechselkursen umgerechnet
4. **Anzeigen**: Der endgültige zu zahlende Betrag wird transparent vor der Zahlung angezeigt

## Automatische Steuerberechnung

Steuern werden automatisch basierend auf dem Rechnungsort des Kunden berechnet, um die Einhaltung der Anforderungen an GST, VAT und Verkaufssteuer ohne manuelle Einrichtung sicherzustellen.

### Wie die Steuerberechnung funktioniert

<Steps>
<Step title="Standorterkennung">
  Steuerregelungen werden basierend auf dem Land des Kunden (und der Region, wo anwendbar) angewendet.
</Step>

<Step title="Dynamische Updates">
  Der Steuerbetrag wird automatisch aktualisiert, wenn:
  - Das Land wechselt
  - Die Adresse aktualisiert wird
</Step>

<Step title="Transparentes Display">
  Der endgültige Steueraufteilung wird klar vor der Zahlung angezeigt.
</Step>
</Steps>

<Tip>
Die Steuerberechnung ist vollständig automatisiert. Keine manuelle Konfiguration für Standard-Digitalgüter und SaaS-Produkte erforderlich.
</Tip>

## Unterstützung für Geschäftsteuernummern

Für registrierte Unternehmen ermöglicht der Checkout den Kunden die Eingabe ihrer Geschäftsteuernummer (z. B. VAT/GST-Nummer).

### Was passiert, wenn eine Steuernummer eingegeben wird

- Die Steuerberechtigung wird in Echtzeit validiert
- Anwendbare Steuerbefreiungen oder Rückerstattungsregelungen werden angewendet
- Der Steuerbetrag wird beim Checkout sofort aktualisiert

<Frame>
  <img src="/images/checkout/c3.png" alt="Eingabe der Geschäftsteuernummer beim Checkout" style={{ width: '70%' }}/>
</Frame>

<Info>
Dies ist besonders nützlich für B2B-SaaS und digitale Dienste, bei denen Geschäftskunden möglicherweise für Steuerbefreiungen berechtigt sind.
</Info>

## Rabattcodes

Kunden können Rabatt- oder Aktionscodes, die Sie im Dashboard erstellt haben, direkt auf der Checkout-Seite anwenden.

### Checkout-Erlebnis

1. Der Kunde gibt den Rabattcode ein
2. Der Rabatt wird sofort validiert
3. Der aktualisierte Preis und die Einsparungen werden klar angezeigt

<Frame>
  <img src="/images/checkout/c4.png" alt="Eingabe des Rabattcodes beim Checkout" style={{ width: '70%' }}/>
</Frame>

### API-Integration

Ein Rabattcode vorbelegen oder das Eingabefeld für Rabatte aktivieren:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  discount_code: 'WELCOME20', // Pre-apply a code
  feature_flags: {
    allow_discount_code: true // Show discount input field
  },
  return_url: 'https://yoursite.com/return'
});
```

## Intelligente Adressensammlung

Der Checkout unterstützt eine flexible Adresseingabe für schnellere Abwicklung.

### Verfügbare Optionen

| Option | Beschreibung |
|--------|-------------|
| **Google Adress-Autocomplete** | Schnellauswahl mit Autocomplete |
| **Manuelle Eingabe** | Volle Kontrolle über vollständige Adressen |

<Tip>

## Benutzerdefinierte Felder

Sammeln Sie zusätzliche Informationen von Kunden während des Checkouts, indem Sie benutzerdefinierte Formularfelder definieren. Dies ist nützlich, um Daten wie Firmennamen, Teamgröße, Empfehlungsquelle oder andere geschäftsspezifische Informationen zu erfassen.

### Verfügbare Feldtypen

| Typ | Beschreibung |
|------|-------------|
| `text` | Einzelzeileneingabe |
| `number` | Numerische Eingabe |
| `email` | E-Mail-Adresse mit Validierung |
| `url` | URL mit Validierung |
| `date` | Datumsauswähler |
| `dropdown` | Auswahl aus vordefinierten Optionen |
| `boolean` | Ja/Nein-Schalter |

### Beispiel

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Kundenantworten sind automatisch in den Webhook-Nutzlasten (`payment.succeeded`, `subscription.created`) und API-Antworten über das `custom_field_responses` Array enthalten. Sie können bis zu 5 benutzerdefinierte Felder pro Checkout-Sitzung definieren.
</Info>

## SammlungCheckout

Produktkollektionen ermöglichen ein einheitliches Checkout-Erlebnis, bei dem Kunden aus mehreren verwandten Produkten (z. B. Starter-, Pro- und Enterprise-Pläne) in einem einzigen Checkout auswählen können.

### So funktioniert es

1. **Alle Produkte angezeigt**: Kunden sehen jedes aktive Produkt in der Sammlung
2. **Erstes Produkt vorab ausgewählt**: Das erste Produkt in der Sammlung wird automatisch ausgewählt
3. **Optionen vergleichen**: Kunden können Preise und Funktionen vergleichen, bevor sie wählen
4. **Einzelauswahl**: Nach der Auswahl eines Produkts wird der Checkout mit dem standardmäßigen Zahlungsablauf fortgesetzt

### Erstellung eines Sammlungscheckouts

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
Wenn Sie `product_collection_id` verwenden, übergeben Sie ein leeres `product_cart` Array. Rabattcodes können nicht bei der SitzungsCreation voraus angewendet werden.
</Warning>

## Konfiguration der Checkout-Sitzung

Steuern Sie das Checkout-Verhalten mit der Checkout-Sitzungen API:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_code: 'PROMO10',
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
Nach der Zahlung werden die Kunden automatisch an Ihre `return_url` mit angehängten Abfrageparametern umgeleitet - einschließlich `payment_id` oder `subscription_id`, `status`, `email` und `license_key` (wenn zutreffend). Siehe die [Leitfäden zu Checkout-Sitzungen](/developer-resources/checkout-session#request-body) für die vollständige Liste.
</Info>

## Anpassung des Checkout-Themes

Passen Sie das Erscheinungsbild der Checkout-Seite an, um mit Ihrer Marke übereinzustimmen, indem Sie den `customization.theme_config` Parameter beim Erstellen einer Checkout-Sitzung über die API verwenden. Konfigurieren Sie Farben, Schriftarten, Rahmenradius und Schaltflächentext für den hellen und den dunklen Modus.

<Frame>
  <img src="/images/checkout/theme-example.png" alt="Benutzerdefinierte thematisierte Checkout-Seite"/>
</Frame>

<Info>
Dieser Abschnitt behandelt die **serverseitige API** Themenkonfiguration mit `customization.theme_config`. Wenn Sie das **Checkout SDK** (Overlay- oder Inline-Checkout) verwenden, siehe die Abschnitte zur Themenanpassung in [Overlay Checkout](/developer-resources/overlay-checkout#theme-customization) oder [Inline Checkout](/developer-resources/inline-checkout#theme-customization), die camelCase-Eigenschaften verwenden (z. B. `bgPrimary` anstelle von `bg_primary`).
</Info>

### Optionen zur Themenkonfiguration

| Eigenschaft | Beschreibung |
|----------|-------------|
| `light` | Farbkonfiguration für den hellen Modus |
| `dark` | Farbkonfiguration für den dunklen Modus |
| `font_primary_url` | URL für die primäre Schriftart |
| `font_secondary_url` | URL für die sekundäre Schriftart |
| `font_size` | Schriftgröße: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `font_weight` | Schriftgewicht: `normal`, `medium`, `bold`, `extraBold` |
| `radius` | Rahmenradius für UI-Elemente (z. B. `4px`, `0.5rem`, `8px`) |
| `pay_button_text` | Benutzerdefinierter Text für die Zahlungsschaltfläche (z. B. "Kauf abschließen", "Jetzt abonnieren") |

### Farbkonfiguration (Heller/Dunkler Modus)

Jeder Modus (`light` und `dark`) unterstützt die folgenden Farbwerte:

| Eigenschaft | Beschreibung |
|----------|-------------|
| `bg_primary` | Hintergrundfarbe primär |
| `bg_secondary` | Hintergrundfarbe sekundär |
| `text_primary` | Textfarbe primär |
| `text_secondary` | Textfarbe sekundär |
| `text_placeholder` | Textplatzhalterfarbe |
| `text_error` | Textfehlerfarbe |
| `text_success` | Textfarbe für Erfolg |
| `border_primary` | Rahmenfarbe primär |
| `border_secondary` | Rahmenfarbe sekundär |
| `button_primary` | Hintergrundfarbe der primären Schaltfläche |
| `button_primary_hover` | Farbe beim Hover für die primäre Schaltfläche |
| `button_secondary` | Hintergrundfarbe der sekundären Schaltfläche |
| `button_secondary_hover` | Farbe beim Hover für die sekundäre Schaltfläche |
| `button_text_primary` | Textfarbe der primären Schaltfläche |
| `button_text_secondary` | Textfarbe der sekundären Schaltfläche |
| `input_focus_border` | Eingabefokus-Rahmenfarbe |

<Info>
Alle Farbfelder akzeptieren Standard-CSS-Farbformate:
- Hex: `#fff`, `#ffffff`, `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`, `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`, `hsla(120, 100%, 50%, 0.5)`
- Benannte Farben: `red`, `blue`, `transparent`
</Info>

### Beispiel

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
Sie müssen nicht alle Farbeigenschaften angeben. Alle nicht angegebenen Eigenschaften verwenden die Standardwerte des Themas.
</Tip>
