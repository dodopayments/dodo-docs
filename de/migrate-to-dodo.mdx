**Wechseln Sie von einem anderen Zahlungsanbieter zu Dodo Payments?** Unser Migrationstool erleichtert die Übertragung Ihrer **Produkte, Kunden, Rabattcodes und Lizenzschlüssel, ohne dass Daten verloren gehen.** Der Prozess ist sicher, geführt und kann in nur wenigen Minuten durchgeführt werden.

Derzeit unterstützen wir Migrationen von **Lemon Squeezy, Stripe, Polar.sh und Paddle**.

## Erste Schritte

Zuerst installieren Sie das Migrationstool:

```bash
npm install -g dodo-migrate
```

<Note>
Sie benötigen Node.js ≥ 18 auf Ihrem Computer installiert.
</Note>

## Migrieren Sie Ihre Daten

### Wenn Sie von Lemon Squeezy kommen:

```bash
dodo-migrate lemonsqueezy
```

### Wenn Sie von Stripe kommen:

```bash
dodo-migrate stripe
```

### Wenn Sie von Polar.sh kommen:

```bash
dodo-migrate polar
```

### Wenn Sie von Paddle kommen:

```bash
dodo-migrate paddle
```

Das Tool wird Sie Schritt für Schritt durch alles führen. Sie benötigen:
- Den API-Schlüssel Ihres Anbieters (Lemon Squeezy, Stripe, Polar.sh, Paddle, etc.)
- Ihren Dodo Payments API-Schlüssel  
- Ob Sie zuerst testen möchten (empfohlen) oder live gehen
- Zu welcher Dodo Payments-Marke Sie migrieren möchten
- Welche Daten migriert werden sollen (Produkte, Kunden, Rabatte, Lizenzschlüssel)

## Warum unser Migrationstool verwenden?

- **Kein Datenverlust** - Alles wird sicher übertragen
- **Zuerst testen** - Probieren Sie es im Testmodus aus, bevor Sie live gehen
- **Geleiteter Prozess** - Wir führen Sie durch jeden Schritt
- **Fortsetzen, wenn nötig** - Wenn etwas schiefgeht, können Sie dort weitermachen, wo Sie aufgehört haben

## Erweiterte Nutzung

Wenn Sie die Migration ohne Eingabeaufforderungen durchführen möchten, können Sie alle Details im Voraus angeben:

### Lemon Squeezy Migration:

```bash
dodo-migrate lemonsqueezy \
  --provider-api-key=lsq_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX
```

### Stripe Migration:

```bash
dodo-migrate stripe \
  --provider-api-key=sk_test_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX \
  --migrate-types=products,coupons
```

### Polar.sh Migration:

```bash
dodo-migrate polar \
  --provider-api-key=polar_org_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX \
  --migrate-types=products,discounts,customers,license_keys
```

### Paddle Migration:

```bash
dodo-migrate paddle \
  --provider-api-key=paddle_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX
```

## Lizenzschlüssel-Migration

Lizenzschlüssel-Migration wird für **Polar.sh** und **Lemon Squeezy** unterstützt. Wenn Sie in der interaktiven Eingabeaufforderung Lizenzschlüssel auswählen (oder `license_keys` in `--migrate-types` übergeben), wird das Tool Ihre vorhandenen Lizenzschlüssel mit den richtigen Kunden- und Produktzuordnungen in Dodo Payments importieren.

<Warning>
Die Lizenzschlüssel-Migration erfordert, dass **Produkte und Kunden** in derselben Sitzung migriert werden. Das Tool erstellt während des Prozesses eine In-Memory-Zuordnung von Anbieter-IDs zu Dodo-IDs — wenn Produkte oder Kunden fehlen, können Lizenzschlüssel nicht korrekt verknüpft werden.
</Warning>

### Was wird migriert

- Lizenzschlüssel-Strings
- Aktivierungsgrenzen
- Ablaufdaten
- Kunden- und Produktzuordnungen

### Was wird nicht migriert

- **Lizenzschlüssel-Aktivierungen** — Kunden müssen nach der Migration auf ihren Geräten neu aktivieren
- **Widerrufene oder deaktivierte Schlüssel** — nur aktive Schlüssel werden migriert
- Schlüssel ohne passendes Produkt oder Kunden werden mit einer Warnung übersprungen

<Tip>
Doppelte Lizenzschlüssel werden problemlos gehandhabt. Wenn Sie die Migration erneut durchführen, werden bereits importierte Schlüssel erkannt und übersprungen, was den Prozess sicher zum Wiederholen macht.
</Tip>
