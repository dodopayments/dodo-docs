<Tip> Sie erhalten eine Liste von [ISO Alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) Ländercodes, die die Länder darstellen, die wir **derzeit für Zahlungen unterstützen**. Sie können die vollständige Liste der unterstützten Länder [hier](/miscellaneous/list-of-countries-we-accept-payments-from) einsehen. Diese Liste wird regelmäßig aktualisiert, während wir unser Angebot erweitern. </Tip>

<Tip> Hinweis: Die verfügbaren Optionen umfassen ISO Alpha-2-Codes für **alle Länder**, nicht nur für diejenigen, die wir derzeit unterstützen. Bitte konsultiere die Liste der unterstützten Länder, um die Verfügbarkeit zu bestätigen. </Tip>
