**Veraltete API**: Lizenzschlüssel werden jetzt über das [Entitlements](/features/entitlements/introduction)-System verwaltet. Verwenden Sie [List Grants](/api-reference/entitlements/list-grants), um ausgegebene Lizenzschlüssel aufzulisten (filtern mit `integration_type=license_key`); jede Berechtigung trägt ihre `license_key` Details. Dieser Endpunkt wird in einer zukünftigen Version entfernt.
</Warning>
