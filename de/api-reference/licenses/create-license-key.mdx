<Info>
Lizenzschlüssel, die über die API erstellt oder aktualisiert werden, lösen keine E-Mail-Benachrichtigungen an Kunden aus. Wenn Sie Kunden über ihren Lizenzschlüssel informieren müssen, müssen Sie dies separat in Ihrer Anwendung handhaben.
</Info>
