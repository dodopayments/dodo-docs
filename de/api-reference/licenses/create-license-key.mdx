<Info>
Dieser Endpunkt importiert einen bereits vorhandenen Schlüssel — `key`, `customer_id` und `product_id` sind alle erforderlich. Es wird kein Schlüsselwert für Sie generiert. Der Import eines `key`, der bereits vorhanden ist, gibt `409 Conflict` zurück.
</Info>

<Info>
Über die API erstellte oder aktualisierte Lizenzschlüssel lösen keine E-Mail-Benachrichtigungen für Kunden aus. Wenn Sie Kunden über ihren Lizenzschlüssel benachrichtigen müssen, müssen Sie dies separat in Ihrer Anwendung handhaben.
</Info>
