<Warning>
**Veraltete API**: Lizenzschlüssel werden jetzt über das [Entitlements](/features/entitlements/introduction) System verwaltet. Konfigurieren Sie Aktivierungslimits und -dauern in der [License Key entitlement](/api-reference/entitlements/update-entitlement), und verwenden Sie [Revoke Grant](/api-reference/entitlements/revoke-grant), um den Schlüssel eines Kunden zu deaktivieren. Dieser Endpunkt wird in einem zukünftigen Release entfernt.
</Warning>

<Info>
Das Aktualisieren eines Lizenzschlüssels über die API löst keine E-Mail-Benachrichtigungen an den Kunden aus.
</Info>
