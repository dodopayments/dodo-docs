**Veraltete API**: Lizenzschlüssel werden jetzt über das [Entitlements](/features/entitlements/introduction) System verwaltet. Verwenden Sie [List Customer Grants](/api-reference/entitlements/list-customer-grants) (filtern mit `integration_type=license_key`), um die Berechtigung eines Schlüssels und dessen `license_key` Details abzurufen. Dieser Endpunkt wird in einer zukünftigen Version entfernt.
</Warning>
