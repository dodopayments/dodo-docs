Entfernen Sie eine gespeicherte Zahlungsmethode aus dem Konto eines Kunden. Verwenden Sie dies, um veraltete oder unerwünschte Zahlungsmethoden zu bereinigen.

<Warning>
Sie können keine Zahlungsmethode löschen, die von einem aktiven Abonnement verwendet wird. Die API gibt `409 Conflict` mit `Payment method is in use by an active subscription` zurück. Verschieben Sie das Abonnement zuerst mithilfe von [Zahlungsmethode aktualisieren](/api-reference/subscriptions/update-payment-method) auf eine andere Zahlungsmethode und löschen Sie anschließend die alte.
</Warning>

Eine erfolgreiche Löschung gibt `204 No Content` zurück.

## Anwendungsfälle

- **Kundenanfrage**: Eine Zahlungsmethode entfernen, die der Kunde nicht mehr hinterlegt haben möchte
- **Abgelaufene Karten**: Zahlungsmethoden mit abgelaufenen Kartendaten bereinigen
- **Sicherheit**: Kompromittierte Zahlungsmethoden sofort entfernen
