---
title: Erfüllung der Lizenzschlüsselzuteilung
description: Erfüllen Sie manuell eine ausstehende Lizenzschlüsselzuteilung,
  indem Sie den Schlüsselwert angeben. Fügt den Schlüssel ein, liefert ihn per
  E-Mail an den Kunden und ändert den Status der Zuteilung auf 'geliefert'.
keywords:
  - Dodo Payments
  - API-Referenz
  - REST API
  - Lizenzschlüssel erfüllen
  - manuelle Erfüllung
openapi: post /grants/{grant_id}/license-key
---

<Info>
Verwenden Sie diesen Endpoint nur für Grants, die unter einem License-Key-Entitlement mit `fulfillment_mode: manual` erstellt wurden. Der Grant muss den Status `Pending` haben, ohne dass ein Schlüssel angehängt ist. Weitere Informationen zum vollständigen Ablauf finden Sie unter [Manuelle Erfüllung](/features/license-keys#manual-fulfillment) und im [Integrationsleitfaden zur manuellen Erfüllung von License Keys](/developer-resources/manual-license-key-fulfillment).
</Info>
