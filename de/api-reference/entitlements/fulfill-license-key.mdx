---
title: Erfüllung der Lizenzschlüsselzuteilung
description: Erfüllen Sie manuell eine ausstehende Lizenzschlüsselzuteilung,
  indem Sie den Schlüsselwert angeben. Fügt den Schlüssel ein, liefert ihn per
  E-Mail an den Kunden und ändert den Status der Zuteilung auf 'geliefert'.
keywords:
  - Dodo Payments
  - API-Referenz
  - REST API
  - Lizenzschlüssel erfüllen
  - manuelle Erfüllung
openapi: post /grants/{grant_id}/license-key
---

<Info>
Verwenden Sie diesen Endpunkt nur für Zuteilungen, die unter einer Lizenzschlüsselberechtigung mit `fulfillment_mode: manual` erstellt wurden. Die Zuteilung muss im `pending`-Status ohne angehängten Schlüssel sein. Siehe [Manuelle Erfüllung](/features/license-keys#manual-fulfillment) und den [Leitfaden zur manuellen Lizenzschlüssel-Erfüllungsintegration](/developer-resources/manual-license-key-fulfillment) für den vollständigen Ablauf.
</Info>
