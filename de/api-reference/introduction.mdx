## API-Schlüsselverwaltung und Authentifizierung

<Steps>
<Step title="API-Schlüssel abrufen">
Navigieren Sie zu **Entwickler → API-Schlüssel** in Ihrem Dashboard, um Ihre Schlüssel zu verwalten.
</Step>

<Step title="Neuen Schlüssel generieren">
Wählen Sie **API-Schlüssel hinzufügen**, geben Sie einen beschreibenden Namen ein und konfigurieren Sie den Schreibzugriff:

- **Schreibzugriff aktivieren** (aktiviert): Vollständige Lese- und Schreibberechtigungen für alle API-Operationen
- **Schreibzugriff aktivieren** (deaktiviert): Nur Lesezugriff - kann nur Daten abrufen (Zahlungen, Abonnements, Kunden, Produkte). Kann keine Ressourcen erstellen oder ändern.

<Tip>
Deaktivieren Sie "Schreibzugriff aktivieren" für Dashboard-Integrationen, Analysetools und jedes System, das nur Daten anzeigen muss, ohne Änderungen vorzunehmen.
</Tip>
</Step>

<Step title="Speichern Sie Ihren Schlüssel sicher">
Kopieren Sie den generierten Schlüssel sofort und stellen Sie sicher, dass er sicher gespeichert wird.
</Step>

<Step title="Authentifizieren Sie Ihre API-Anfragen">
Verwenden Sie Ihre API-Schlüssel, um alle Anfragen zu authentifizieren. Wenden Sie das folgende Autorisierungsformat an:

```bash 
Authorization: Bearer YOUR_API_KEY
```

<Warning>
Geben Sie Ihre geheimen API-Schlüssel niemals im Client-Code oder in öffentlichen Repositories preis.
</Warning>
</Step>
</Steps>

## Ratenlimits

Unsere API verwendet ein duales Ratenbegrenzungssystem mit Burst-Schutz. Die Limits werden basierend auf Ihrer Authentifizierungsmethode und Geschäftsstufe angewendet.

### Standardlimits (Stufe 0)

| Fenster | Limit |
|--------|-------|
| Pro Sekunde (Burst) | 40 Anfragen |
| Pro Minute (Nachhaltig) | 240 Anfragen |

### Geschäftsstufen

Höhere Ratenlimits sind für Unternehmen mit erhöhtem API-Bedarf verfügbar:

| Stufe | Burst (pro Sekunde) | Nachhaltig (pro Minute) |
|------|-------------------|------------------------|
| Stufe 0 (Standard) | 40 | 240 |
| Stufe 1 | 100 | 1.000 |
| Stufe 2 | 500 | 5.000 |

<Tip>
Kontaktieren Sie den Support, um Ihr Unternehmen auf eine höhere Ratenlimitstufe hochzustufen.
</Tip>

### Unauthentifizierte Anfragen

Anfragen ohne gültige Authentifizierungsheader werden nach IP-Adresse begrenzt:

| Fenster | Limit |
|--------|-------|
| Pro Sekunde (Burst) | 20 Anfragen |
| Pro Minute (Nachhaltig) | 100 Anfragen |

### Ratenlimit-Header

Überwachen Sie Ihre Nutzung mit diesen Antwort-Headern:

- `X-RateLimit-Limit` - Maximale erlaubte Anfragen
- `X-RateLimit-Remaining` - Verbleibende Anfragen im aktuellen Fenster
- `X-RateLimit-Reset` - Zeitpunkt, zu dem das Ratenlimit zurückgesetzt wird

<Note>
Wenn Sie die Ratenlimits überschreiten, gibt die API eine `429 Too Many Requests`-Antwort zurück. Implementieren Sie exponentielles Backoff in Ihrer Wiederholungslogik.
</Note>
