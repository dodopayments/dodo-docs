## Umgang mit Zahlungsfehlern

Verwenden Sie den `on_payment_failure` Parameter, um zu steuern, was passiert, wenn die Zahlungsänderung für den Plan fehlschlägt:

| Wert | Verhalten |
|-------|----------|
| `prevent_change` | Halten Sie das Abonnement im aktuellen Plan, bis die Zahlung erfolgreich ist. Die Planänderung bleibt ausstehend. |
| `apply_change` | Wenden Sie die Planänderung sofort an, unabhängig vom Zahlungsergebnis. Dies ist die Standardoption. |

<Info>
Wenn `on_payment_failure` nicht angegeben ist, fällt das Verhalten standardmäßig auf Ihre geschäftsseitige Einstellung zurück, die im Dashboard konfiguriert ist.
</Info>

<Tip>
Verwenden Sie `prevent_change` für kritische Upgrades, bei denen Sie sicherstellen möchten, dass die Zahlung erfolgt, bevor der Zugriff auf Premiumfunktionen gewährt wird.
</Tip>
