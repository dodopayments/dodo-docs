## New Features

### 1. **New `subscription.unpaused` Webhook**

Dodo Payments now emits a `subscription.unpaused` webhook when a paused subscription is resumed. This completes the pause lifecycle — you already receive `subscription.paused` when a subscription is paused, and now receive `subscription.unpaused` when it becomes active again — so you can drive entitlement logic off webhooks without polling.

The payload carries the full [Subscription](/developer-resources/webhooks/intents/subscription) object, identical in shape to every other subscription lifecycle event.

<Info>
No integration work is required. If you already filter on specific event types, add `subscription.unpaused` to the events your endpoint subscribes to in order to react to resumed subscriptions.
</Info>
