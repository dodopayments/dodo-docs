## 概述

Dodo Payments 提供与流行平台和工具的本地集成，帮助您简化支付操作并自动化工作流程。无论您是需要向团队发送通知，将客户数据同步到 CRM，触发电子邮件活动，还是连接您喜欢的开发工具，我们都有适合您需求的集成。

我们的集成设计简单，配置要求极少。大多数集成可以直接从您的 Dodo Payments 仪表板中通过几次点击连接，让您立即开始自动化支付工作流程。

在下方浏览可用的集成，或使用搜索快速找到您正在寻找的集成。每个集成都包含分步设置说明，帮助您开始使用。

## 集成的好处

保持对发生的重要支付事件的知情，确保您绝不会错过关于您业务的关键更新。
减少手动任务，通过基于支付事件自动触发操作，节省时间并减少错误。
通过跨您喜爱的工具的集中通知和报告，获得更好的支付操作见解。
通过与现有工具和工作流程集成，提供无缝的支付体验。

每个集成都包含详细的设置说明和示例配置，帮助您快速入门。

将实时 Dodo Payments 通知发送到您的 Discord 频道。

使用 SendGrid 的邮件发送 API 基于 Dodo Payments 事件发送事务性电子邮件。
将 Dodo Payments 事件发送到 Customer.io 以触发电子邮件自动化和客户旅程。
通过 Loops 管理客户通信并基于 Dodo Payments 事件发送事务性电子邮件。
根据 Dodo Payments 事件自动将客户添加到 MailerLite 订阅者列表并触发电子邮件自动化。
使用 AutoSend 的电子邮件 API 为您的 Dodo Payments 交易、退款和支付事件发送自动化的事务性电子邮件。
通过 Keplars 上的优先级队列基于 Dodo Payments 事件发送事务性电子邮件。
将 Dodo Payments 事件发送到 Segment 以进行分析和客户数据平台集成。
使用 DataFast 分析将收入归因于营销渠道。跟踪哪些流量来源推动了付费客户并优化您的增长。
在客户完成购买时跟踪 Dub 中的销售转化事件。衡量营销活动和推荐计划的 ROI。
通过 Inngest 基于 Dodo Payments 事件触发无服务器功能和后台作业。
通过 Zapier 将 Dodo Payments 连接到 5000 多个应用，实现无限自动化可能性。
基于 Dodo Payments 事件触发 Windmill 工作流和脚本以实现自定义自动化。
同步 Dodo Payments 数据与 Close CRM 以跟踪潜在客户并管理销售管道。
使用 Dodo Payments 许可密钥验证和激活构建 Figma 插件。
将 Dodo Payments 结账功能集成到您的 Framer 项目中，并定制结账体验。
安装 Raycast 扩展从键盘浏览和管理 Dodo Payments 资源。

## 集成类别

我们的集成分为几个类别，帮助您找到所需的内容：

- **通讯和协作**：通过 Slack、Discord 和 Microsoft Teams 中的实时通知让您的团队保持知情
- **电子邮件服务**：通过 Resend、SendGrid、Customer.io、Loops、MailerLite、AutoSend 和 Keplars 自动化事务性电子邮件和客户通信
- **CRM 和销售**：同步支付数据和客户信息到 HubSpot 和 Close CRM
- **自动化平台**：通过 Zapier、N8N、Inngest 和 Windmill 构建自定义工作流程
- **分析**：使用 Segment 和 DataFast 跟踪和分析支付事件
- **电子商务**：将支付无缝集成到您的 WooCommerce 商店
- **设计工具**：为 Figma 和 Framer 构建插件和扩展
- **开发者工具**：从 Raycast 访问 Dodo Payments 功能
