## 简介

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) 是一个平台，可将基于位置的购买力平价折扣优惠券创建并同步到您的 Dodo Payments 账户。它同时支持一次性产品和订阅产品，并根据您定义的计划自动生成定期轮换的折扣码。

<Frame>
  <img src="/images/integrations/evendeals/hero.png" alt="Evendeals Dodo Payments integration overview" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Note>
Dodo Payments 原生支持 [Purchasing Power Parity](/features/purchasing-power-parity)，可在结账时按国家/地区降低价格，无需横幅、脚本或管理优惠券代码。对于明确希望采用折扣码方式并自动轮换优惠券的商家，Evendeals 是理想选择。
</Note>

## 工作原理

Evendeals 通过 API key 连接到您的 Dodo Payments 账户。连接后，您可以为每个国家/地区组配置百分比折扣。随后，Evendeals 会自动在您的 Dodo Payments 账户中创建折扣码，并按照您设定的计划进行轮换（按时间间隔、兑换次数或查看次数），以防止滥用。

## Evendeals 与原生 PPP 的比较

原生 Purchasing Power Parity 是按国家/地区定价的推荐方式，因为它不需要优惠券代码，也无法被共享或滥用。如果您明确希望采用折扣码方式，请选择 Evendeals。

| | 原生 PPP | Evendeals |
| :--- | :--- | :--- |
| 工作原理 | 按国家/地区设置百分比，在结账时应用 | 提供百分比折扣，通过代码应用 |
| 配置位置 | 内置于 Dodo Payments | Evendeals 控制台 |
| 是否需要横幅或脚本 | 不需要 | 不需要 |
| 优惠券轮换 / 自动刷新 | 不适用 | 支持 |
| 订阅支持 | 支持 | 支持 |
| 最适用于 | 无需修改网站即可提供正确价格 | 采用带自动轮换的折扣码方式 |

## 主要功能

- **优惠券自动同步** — 自动在 Dodo Payments 中创建和管理优惠券
- **百分比折扣** — 为每个国家/地区组提供百分比折扣
- **订阅支持** — 折扣适用于整个订阅计费周期
- **自动刷新规则** — 按时间间隔、兑换次数或查看次数自动轮换优惠券代码，以防止滥用

<Info>
由 Evendeals 创建的折扣码会自动显示在您的 Dodo Payments 控制台的 **Sales → Discounts** 下。
</Info>

## 前提条件

设置此集成前，请确保您拥有：

1. 一个 [Dodo Payments 账户](https://app.dodopayments.com)
2. 一个 [Evendeals 账户](https://www.evendeals.com/signin)
3. 一个 Dodo Payments API key

## 开始使用

<Steps>
  <Step title="Create a Dodo Payments API Key">
    在您的 Dodo Payments 控制台中，前往 **Developers → API Keys**，然后点击 **Create New API**。为其设置具有描述性的名称（例如“Evendeals”），以便日后识别。
  </Step>

  <Step title="Connect in Evendeals">
    在您的 [Evendeals 控制台](https://www.evendeals.com/signin)中，前往 **Integrations**，找到 Dodo Payments 卡片，然后粘贴您的 API key。
  </Step>

  <Step title="Configure Regional Discounts">
    为每个国家/地区组设置百分比折扣，然后点击同步。Evendeals 会自动在 Dodo Payments 中创建优惠券。

    <Check>
    同步后，在您的 Dodo Payments 控制台中打开 **Sales → Discounts**，确认生成的优惠券是否显示。每张优惠券都会带有易于识别的 Evendeals 前缀。
    </Check>
  </Step>
</Steps>
