## 新功能

### 1. **弃单恢复**

自动检测未完成或失败的结账，并发送有针对性的电子邮件系列以召回客户。ACR监控60分钟后未成功的付款，将其分类为**付款失败**或**结账未完成**，然后每个系列发送最多3封可配置的恢复电子邮件。

<Frame>
<img src="/images/recovery/recovery-analytics.png" alt="恢复分析仪表板显示弃单次数、恢复率和恢复收入" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

关键功能：
- **两种电子邮件系列** — 付款失败和结账未完成，每种最多3封电子邮件
- **恢复折扣** — 可选择自动生成一次性折扣码以激励恢复
- **客户恢复页面** — 独特的恢复链接将客户带到专用页面以完成购买
- **恢复分析** — 跟踪弃单次数、恢复率、恢复收入和每封邮件/每产品的详细信息

<Tip>
从默认的电子邮件发送时间（1小时、24小时、72小时）开始，并根据您的恢复分析数据进行迭代。
</Tip>

了解更多：[弃单恢复](/features/recovery/abandoned-cart-recovery)

### 2. **订阅扣款**

自动发送电子邮件系列以恢复中断或取消的订阅。扣款在订阅进入**暂停**（付款失败）或客户从客户门户**取消**时触发。

关键功能：
- **两种电子邮件系列** — 暂停和取消，每种最多4封电子邮件
- **自动扣款** — 当客户更新其付款方式时，未结费用会自动扣款
- **可配置的时间间隔** — 默认间隔为1、3、5和7天，每封邮件均可完全自定义

了解更多：[订阅扣款](/features/recovery/subscription-dunning)

### 3. **折扣元数据**

您现在可以在通过API创建或更新折扣时附加**元数据**（键值对）。使用元数据通过活动、来源或内部参考来标记折扣以进行跟踪和对账。

```typescript
const discount = await client.discounts.create({
  type: 'percentage',
  amount: 1500, // 15%
  code: 'SUMMER2025',
  metadata: {
    campaign: 'summer_promo',
    source: 'email_blast'
  }
});
```

了解更多：[折扣码](/features/discount-codes) | [元数据指南](/api-reference/metadata)

### 4. **恢复Webhooks**

新的Webhook事件以跟踪恢复生命周期：

| 事件 | 描述 |
|-------|-------------|
| `abandoned_checkout.detected` | 已检测到弃单 |
| `abandoned_checkout.recovered` | 客户通过恢复链接完成付款 |
| `dunning.started` | 已为订阅启动扣款尝试 |
| `dunning.recovered` | 客户更新了付款方式并且付款成功 |

了解更多：[恢复Webhooks](/developer-resources/webhooks/intents/recovery)
