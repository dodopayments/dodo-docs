## 新功能

### 1. **弃单恢复**

自动检测未完成或失败的结账，并发送有针对性的电子邮件系列以召回客户。ACR监控60分钟后未成功的付款，将其分类为**付款失败**或**结账未完成**，然后每个系列发送最多3封可配置的恢复电子邮件。

<Frame>
<img src="/images/recovery/recovery-analytics.png" alt="恢复分析仪表板显示弃单次数、恢复率和恢复收入" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

关键功能：
- **两种电子邮件系列** — 付款失败和结账未完成，每种最多3封电子邮件
- **恢复折扣** — 可选择自动生成一次性折扣码以激励恢复
- **客户恢复页面** — 独特的恢复链接将客户带到专用页面以完成购买
- **恢复分析** — 跟踪弃单次数、恢复率、恢复收入和每封邮件/每产品的详细信息

<Tip>
从默认的电子邮件发送时间（1小时、24小时、72小时）开始，并根据您的恢复分析数据进行迭代。
</Tip>

了解更多：[弃单恢复](/features/recovery/abandoned-cart-recovery)

### 2. **订阅扣款**

自动发送电子邮件系列以恢复中断或取消的订阅。扣款在订阅进入**暂停**（付款失败）或客户从客户门户**取消**时触发。

关键功能：
- **两种电子邮件系列** — 暂停和取消，每种最多4封电子邮件
- **自动扣款** — 当客户更新其付款方式时，未结费用会自动扣款
- **可配置的时间间隔** — 默认间隔为1、3、5和7天，每封邮件均可完全自定义

了解更多：[订阅扣款](/features/recovery/subscription-dunning)

### 3. **折扣元数据**

您现在可以在通过API创建或更新折扣时附加**元数据**（键值对）。使用元数据通过活动、来源或内部参考来标记折扣以进行跟踪和对账。

```typescript
const discount = await client.discounts.create({
  type: 'percentage',
  amount: 1500, // 15%
  code: 'SUMMER2025',
  metadata: {
    campaign: 'summer_promo',
    source: 'email_blast'
  }
});
```

了解更多：[折扣码](/features/discount-codes) | [元数据指南](/api-reference/metadata)

### 4. **恢复Webhooks**

新的Webhook事件以跟踪恢复生命周期：

| 事件 | 描述 |
|-------|-------------|
| `abandoned_checkout.detected` | 已检测到弃单 |
| `abandoned_checkout.recovered` | 客户通过恢复链接完成付款 |
| `dunning.started` | 已为订阅启动扣款尝试 |
| `dunning.recovered` | 客户更新了付款方式并且付款成功 |

了解更多：[恢复Webhooks](/developer-resources/webhooks/intents/recovery)

### 5. **巴西的 Pix 支付**

在您的 Dodo Payments 结账中接受 **Pix** —— 巴西中央银行创建的即时支付系统。Pix 现在是巴西使用最多的支付方式，超过了信用卡和 boleto，并且在 24/7/365 内几秒钟内确认。

**覆盖范围**

| 细节 | 值 |
|--------|-------|
| 计费货币 | BRL |
| 支持国家 | 巴西 |
| 订阅 | 不支持（仅限一次性支付） |
| 最低金额 | $0.50 |
| 结算 | 即时 |

**配置**

在 `allowed_payment_method_types` 中传递 `pix`，并将计费货币设置为 `BRL`：

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  allowed_payment_method_types: ['pix', 'credit', 'debit'],
  billing_currency: 'BRL',
  return_url: 'https://example.com/success'
});
```

客户在结账时会看到 Pix 的二维码和一个复制粘贴密钥。他们打开银行应用程序，扫描或粘贴，支付立即确认。

<Tip> Pix 二维码在设定的时间窗后会过期——设计您的结账流程，以便客户在需要时可以重新生成代码。始终为喜欢使用卡支付的客户提供卡片替代选项。 </Tip>

了解更多：[Pix 支付](/features/payment-methods/pix)

### 6. **中国客户的微信支付**

在您的 Dodo Payments 结账中直接接受 **微信支付** —— 中国超过十亿人使用。客户使用微信应用程序扫描二维码，几秒内确认支付，全程不离开微信生态系统。

**覆盖范围**

| 细节 | 值 |
|--------|-------|
| 计费货币 | USD, CNY |
| 订阅 | 不支持（仅限一次性支付） |
| 最低金额 | $0.50 / ¥1.00 |
| 结算 | USD |

**配置**

在创建结账会话时，传递 `we_chat_pay` 到 `allowed_payment_method_types`：

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  allowed_payment_method_types: ['we_chat_pay', 'credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

微信支付支持 **USD**（针对中国客户的跨境商家）和 **CNY**（国内中国交易）。无论计费货币如何，结算给商家都是 USD。

<Tip> 在桌面或平板电脑上显示结账，以便客户可以用手机扫描二维码——这是微信支付用户最熟悉的流程。 </Tip>

了解更多：[微信支付](/features/payment-methods/wechat)
