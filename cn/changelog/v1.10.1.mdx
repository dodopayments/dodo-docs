## 新功能 🚀

- **结账 2.0**: 引入全新设计的结账体验，具有以下特点：
    - 简化且现代化的界面，提升用户体验
    - 新的查询收集系统将参数存储在会话存储中，带有唯一ID（例如，`sess_1a2b3c4d`）
    - 在整个结账流程中保持数据的可用性
    - 计划在未来版本中进行更多增强！
  
    <Frame><img src="/images/changelog/checkout_2.png" alt="Checkout 2.0" style={{ maxHeight: '500px', width: 'auto' }} /></Frame>

- **可配置的支付方式**：新增 `allowed_payment_method_types` 配置，支持商户在结账过程中自定义可用的支付选项。有关实施详情，请参阅[允许的支付方式](/features/payment-methods#per-checkout-payment-method-configuration)文档。

- **动态税率计算**: 基于客户账单地址的实时税率计算，以便在静态支付链接上提供更准确的定价。

- **按需订阅**：新增用于灵活订阅计费的 API 端点（适用于部分商户）。请参阅[按需订阅](/developer-resources/ondemand-subscriptions)指南了解更多信息。

- **其他更新**:
    - 性能优化
    - 错误修复
    - 一般系统改进
