## 新功能

### 1. **产品集合**  
   
   将相关产品组合在一起，以便在客户门户内提供统一的结账体验、计划选择以及无缝的升级/降级路径。

   <Frame>
     <img src="/images/product-collection/checkout-page.png" alt="产品集合结账页面显示多个计划选项" />
   </Frame>

  **主要好处**

   - **基于集合的结账**：在一个结账视图中显示来自集合的所有产品，让客户比较并选择他们喜欢的计划
   - **有序的产品管理**：将相关产品（例如，Starter，Pro，Enterprise）组合在一个集合中
   - **客户门户集成**：允许客户在同一集合中升级或降级产品
   - **商户控制**：可以启用、禁用并重新排序每个集合中的产品

   **工作原理**

   为集合创建结账会话：

   ```typescript
   const session = await client.checkoutSessions.create({
     product_collection_id: 'pdc_abc123',
     product_cart: [], // Required: pass an empty array for collection checkout
     return_url: 'https://yoursite.com/return'
   });

   // Redirect customer to the checkout
   window.location.href = session.url;
   ```

   <Check>
   结果：统一的结账体验，客户可以查看并从您的集合中选择所有可用产品。
   </Check>

   <Info>
   集合结账非常适合订阅业务，您希望客户在购买之前并排比较计划。
   </Info>

   了解更多：[产品集合指南](/features/product-collections)

### 2. **RevolutPay 和 Billie 支付方式用于 GBP 货币**  
   
   通过 RevolutPay 和 Billie 扩展的支付选项现已在全球范围内提供，适用于 GBP 一次性支付交易，为您的客户提供更多支付灵活性。

   **新支付方式**

   | 支付方式 | 支持国家 | 货币 | 订阅支持 |
   |---------|----------|------|-----------|
   | **RevolutPay** | 全球 | GBP | 否（仅一次性） |
   | **Billie** | 全球 | GBP | 否（仅一次性） |

   - **RevolutPay** – 全球 Revolut 用户的快速无缝支付
   - **Billie** – B2B 先买后付解决方案，使企业能够为其客户提供灵活的支付条款

   <Info>
   这些支付方式自动可用于 GBP 交易。无需其他配置。
   </Info>

   了解更多：[支付方式](/features/payment-methods)

### 3. **结账会话预览**  
   
   在创建结账会话之前预览结账会话，以计算准确的定价、税费、折扣和总额。在客户结账之前显示真实价格。

   **工作原理**

   ```typescript
   const preview = await client.checkoutSessions.preview({
     product_cart: [
       { product_id: 'prod_123', quantity: 1 }
     ],
     billing_address: {
       country: 'US',
       state: 'CA',
       zipcode: '94102'
     },
     discount_code: 'SAVE20'
   });

   console.log('Subtotal:', preview.subtotal);
   console.log('Tax:', preview.tax);
   console.log('Discount:', preview.discount);
   console.log('Total:', preview.total);
   ```

   **用例**

   - **自定义定价显示**：在结账之前显示包括税费的准确总额
   - **折扣验证**：验证折扣代码并向客户显示节省的费用
   - **多货币支持**：预览不同货币的定价
   - **购物车摘要**：构建带有实时定价的自定义购物车 UI

### 4. **变更计划请求中的元数据支持**  
   
   在更改订阅计划时传递自定义元数据，以便在计划过渡期间更好地跟踪和与您的内部系统集成。

   ```javascript
   // Adding metadata when changing a subscription plan
   await client.subscriptions.changePlan('sub_123', {
     product_id: 'prod_premium',
     proration_billing_mode: 'prorated_immediately',
     quantity: 1,
     metadata: {
       upgrade_reason: 'feature_request',
       previous_plan: 'basic',
       sales_rep: 'john@company.com'
     }
   });
   ```

  **用例**

   - **跟踪升级/降级原因**：记录客户更改计划的原因
   - **链接到 CRM 记录**：将计划更改与销售活动关联
   - **内部分类**：标记计划更改以便报告和分析
   - **审计追踪**：维护谁发起了计划更改的记录

   <Info>
   元数据包含在 webhook 事件中，便于使用您的自定义数据处理计划更改。
   </Info>

   了解更多：[元数据指南](/api-reference/metadata) | [变更计划 API](/api-reference/subscriptions/change-plan)

### 5. **`invoice_url` 字段在支付响应和支付链接响应中**  
   
   支付响应和支付链接响应现在包含 `invoice_url` 字段，提供对与每笔支付相关的发票的直接访问。

   ```json
   {
     "payment_id": "pay_2IjeQm4hqU6RA4Z4kwDee",
     "status": "succeeded",
     "invoice_url": "https://dodopayments.com/invoices/inv_2IsUnWGtRKFLxk7xAQeyt",
     "amount": 9900,
     "currency": "USD",
     // ... other fields
   }
   ```

  **用例**

   - **客户沟通**：直接将发票链接发送给客户
   - **会计集成**：将支付与您会计软件中的发票链接
   - **自助服务门户**：允许客户轻松访问他们的发票
   - **记录保存**：保持对发票文档的直接引用

### 6. **通过代码名称验证折扣端点**  
   
   新的 API 端点可通过折扣代码名称（例如，"SAVE20"）验证和检索折扣代码，而无需使用内部折扣 ID。在结账时在应用之前验证折扣资格。

   ```javascript
   // Validate a discount code before checkout
   const discount = await client.discounts.getByCode('SAVE20');

   console.log('Discount type:', discount.type);
   console.log('Discount value:', discount.amount);
   console.log('Valid until:', discount.expires_at);
   ```

  **好处**

   - **结账前验证**：在创建结账会话之前验证折扣代码
   - **实时反馈**：告诉客户他们的代码是否有效
   - **错误处理**：提前捕获无效或过期的代码
   - **自定义折扣 UI**：构建即时验证的折扣代码输入字段

### 7. **客户、折扣和许可证密钥的增强过滤能力**  
   
   新的 API 过滤器用于列出客户、折扣和许可证密钥，使得以编程方式查找和管理数据变得更容易。

   **客户 API 过滤器**

   | 过滤器 | 描述 |
   |--------|-------------|
   | `email` | 按客户电子邮件过滤 |
   | `name` | 按客户名称过滤（部分匹配，不区分大小写） |
   | `created_at_gte` | 过滤在此时间戳之后创建的客户 |
   | `created_at_lte` | 过滤在此时间戳之前创建的客户 |

   ```javascript
   // Find customers by name created in the last 30 days
   const customers = await client.customers.list({
     name: 'John',
     created_at_gte: '2026-01-01T00:00:00Z'
   });
   ```

   **折扣 API 过滤器**

   | 过滤器 | 描述 |
   |--------|-------------|
   | `code` | 按折扣代码过滤（部分匹配，不区分大小写） |
   | `discount_type` | 按折扣类型过滤（百分比） |
   | `active` | 按活动状态过滤（true = 未过期，false = 已过期） |
   | `product_id` | 按产品限制过滤（仅适用此产品的折扣） |

   ```javascript
   // Find active percentage discounts for a specific product
   const discounts = await client.discounts.list({
     active: true,
     discount_type: 'percentage',
     product_id: 'prod_123'
   });
   ```

   **许可证密钥 API 过滤器**

   | 过滤器 | 描述 |
   |--------|-------------|
   | `customer_id` | 按客户 ID 过滤 |
   | `status` | 按许可证密钥状态过滤（`active`, `expired`, `disabled`） |
   | `product_id` | 按产品 ID 过滤 |
   | `created_at_gte` | 过滤在此时间戳之后创建的许可证密钥 |
   | `created_at_lte` | 过滤在此时间戳之前创建的许可证密钥 |

   ```javascript
   // Find active license keys for a specific product
   const licenseKeys = await client.licenseKeys.list({
     status: 'active',
     product_id: 'prod_123'
   });
   ```
