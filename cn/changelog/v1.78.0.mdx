## 新特性

### 1. **通信偏好设置**

   通过我们改版的通信偏好设置，掌控如何接收通知。配置电子邮件、推送和应用内通知，以适应您的工作流程。

   <Frame>
     <img src="/images/communication-preferences/overview.png" alt="通信偏好设置概览，显示通知设置" />
   </Frame>

   **主要特性**

   - **电子邮件设计焕然一新**：新鲜、现代的电子邮件模板，明确的行动呼吁和改善的可读性
   - **推送通知**：在您的移动设备上获取关键事件（如新销售、争议和支付）的即时提醒
   - **细分控制**：精确选择触发通知的事件及其渠道
   - **多电子邮件支持**：添加多个电子邮件地址以接收通知
   - **客户电子邮件偏好**：配置客户可接收的电子邮件

   **通知类别**

   | 类别 | 描述 |
   |------|-------------|
   | **销售与付款** | 新销售、成功付款、失败付款 |
   | **支付与退款** | 完成支付、退款请求、退款完成 |
   | **订阅** | 新订阅、续订、取消、计划变更 |
   | **争议** | 争议已开启，需要证据，争议已解决 |

   <Check>
   结果：通过您所需的方式和时间接收通知，保持对业务的了解。
   </Check>

   了解更多：[通信偏好设置指南](/features/communication-preferences)

### 2. **结账会话中的自定义字段**

   在结账过程中通过自定义字段收集客户的额外信息。添加文本输入、下拉菜单、日期等，以获取所需的数据。

   **支持的字段类型**

   | 类型 | 描述 | 用例 |
   |------|-------------|----------|
   | `text` | 单行文本输入 | 公司名称、订单备注 |
   | `number` | 数字输入 | 数量、年龄 |
   | `email` | 电子邮件输入（带验证） | 账单联系电子邮件 |
   | `url` | URL 输入（带验证） | 网站、社交资料 |
   | `date` | 日期选择器 | 交货日期、事件日期 |
   | `dropdown` | 从预定义选项中选择 | 尺寸、颜色、计划类型 |
   | `boolean` | 是/否值的复选框 | 条款接受、新闻通讯选择 |

   **工作原理**

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     custom_fields: [
       {
         name: 'company_name',
         label: 'Company Name',
         type: 'text',
         required: true
       },
       {
         name: 'team_size',
         label: 'Team Size',
         type: 'dropdown',
         options: ['1-10', '11-50', '51-200', '200+'],
         required: true
       },
       {
         name: 'newsletter',
         label: 'Subscribe to our newsletter',
         type: 'boolean',
         required: false
       }
     ],
     return_url: 'https://yoursite.com/success'
   });
   ```

   **好处**

   - **灵活的数据收集**：收集实现或个性化所需的任何信息
   - **内置验证**：电子邮件和URL字段自动验证输入格式
   - **必填/选填控制**：根据需要将字段标记为必填或可选
   - **Webhook交付**：自定义字段值包含在支付Webhook事件中

   <Info>
   自定义字段值在支付和结账会话响应中返回至 `custom_fields` 对象。
   </Info>

   了解更多：[结账会话自定义字段](/developer-resources/checkout-session#custom-fields)

### 3. **扩展的结账语言支持**

   结账页面现在支持 **21 种语言**，从16种增加到21种。用客户的母语吸引更多客户，提高结账体验。

   **新增语言**

   | 语言 | 代码 |
   |------|------|
   | 韩语 | `ko` |
   | 马来语 | `ms` |
   | 罗马尼亚语 | `ro` |
   | 俄语 | `ru` |
   | 泰语 | `th` |

   **所有支持的语言**

阿拉伯语、中文、荷兰语、英语、法语、德语、印地语、印尼语、意大利语、日语、韩语、马来语、葡萄牙语、罗马尼亚语、俄语、西班牙语、瑞典语、泰语、土耳其语、乌克兰语、越南语。

   **强制使用特定语言**

   使用 `force_language` 参数来覆盖自动语言检测：

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     force_language: 'ko', // Force Korean language
     return_url: 'https://yoursite.com/success'
   });
   ```

   <Tip>
   默认情况下，结账页面会根据客户的浏览器设置自动检测其首选语言。当您希望确保与网站语言一致时，请使用 `force_language`。
   </Tip>

   了解更多：[结账语言支持](/features/checkout#supported-languages)
