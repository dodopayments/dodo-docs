## 新功能

### 1. **第三方分析支持**

使用Google Analytics 4、Google Tag Manager和Meta Pixel跟踪客户在商店前端、结账和客户门户的行为。将您的跟踪ID添加到**设置 → 分析**中以开始收集电子商务事件。

**支持的平台**

| 平台 | ID格式 |
|----------|-----------|
| Google Analytics 4 | `G-XXXXXXXXXX` |
| Google Tag Manager | `GTM-XXXXXXX` |
| Meta Pixel | 数字（10-20位） |

**跟踪事件**

像`purchase`, `add_payment_info`, `view_item`和`view_item_list`这样的事件在客户浏览和完成购买时自动发送到您的分析平台。

<Check>
支持在商店前端、托管结账、覆盖/内联结账和客户门户上。
</Check>

了解更多：[第三方分析](/features/analytics)

### 2. **结账主题自定义**

在创建结账会话时，通过`customization.theme_config`参数自定义结账外观。配置颜色、字体、边框半径和按钮文本，以适应明暗模式。

**配置选项**

| 属性 | 描述 |
|----------|-------------|
| `light` / `dark` | 每种模式的配色方案 |
| `font_primary_url` | 自定义字体URL |
| `font_size` | `xs`，`sm`，`md`，`lg`，`xl`，`2xl` |
| `radius` | 边框半径（例如，`8px`） |
| `pay_button_text` | 自定义按钮文本 |

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  customization: {
    theme_config: {
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      light: { button_primary: '#0066ff', text_primary: '#1a1a1a' },
      dark: { button_primary: '#3385ff', text_primary: '#ffffff' }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

了解更多：[结账主题自定义](/features/checkout#checkout-theme-customization)

### 3. **在支付失败时防止变更计划**

新的`on_payment_failure`参数用于控制支付失败时订阅计划变更的行为。

| 模式 | 行为 |
|------|----------|
| `prevent_change` | 在支付成功之前保持当前计划 |
| `apply_change` | 无论支付结果如何立即应用计划变更（默认） |

```typescript
await client.subscriptions.changePlan('sub_123', {
  product_id: 'prod_pro',
  proration_billing_mode: 'prorated_immediately',
  on_payment_failure: 'prevent_change'
});
```

<Tip>
对于希望在授予访问高级功能之前确保支付的关键升级，请使用`prevent_change`。
</Tip>

了解更多：[处理支付失败](/developer-resources/subscription-upgrade-downgrade#handling-payment-failures)

## API 更新

### 余额分类账 API

新的`GET /balances/ledger`端点可用于检索您账户的分类账条目，并支持过滤和分页。

| 参数 | 描述 |
|-----------|-------------|
| `created_at_gte` / `created_at_lte` | 按日期范围过滤 |
| `event_type` | 按`payment`，`refund`，`dispute`，`payout`等过滤 |
| `currency` | 按货币代码过滤 |
| `reference_object_id` | 按特定支付/退款/争议ID过滤 |

了解更多：[余额分类账 API](/api-reference/balance-ledger/list-ledger-entries)

### 支付响应：`refund_status`

在`GET /payments/{paymentId}`响应中添加了`refund_status`字段，以便快速检查支付是否已退款，而无需单独查询退款端点。
