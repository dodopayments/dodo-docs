## 新功能 🚀

1. **混合购物车结账：一次性和订阅产品在单个购物车中**  
   结账现在支持在单个购物车中组合一次性支付产品和订阅产品，解锁强大的新计费用例。
   
   <Frame>
   <img src="/images/changelog/mixed-checkout.png" alt="Mixed checkout with one-time and subscription products" style={{ maxHeight: '500px', width: 'auto' }} />
   </Frame>
   
   ### 实现的功能
   
   - **设置费用 + 订阅**：在单次结账中收取一次性设置费用并同时进行重复订阅
   - **含有重复组件的捆绑包**：销售捆绑有持续访问服务的产品（一次性）
   - **课程 + 会员组合**：提供课程购买和可选的社区会员订阅
   - **终身 + 附加订阅**：结合终身产品访问和可选的重复高级功能
   
   ### 工作原理
   
   只需将一次性和订阅产品同时添加到您的结账会话中：
   

   ```javascript
   const session = await client.checkoutSessions.create({
     product_cart: [
       // One-time setup fee
       { product_id: 'prod_setup_fee', quantity: 1 },
       // Monthly subscription
       { product_id: 'prod_monthly_plan', quantity: 1 }
     ],
     customer: {
       email: 'customer@example.com',
       name: 'Jane Doe'
     },
     return_url: 'https://yourapp.com/success'
   });
   ```

   
   <Check>
   结果：单一结账流程既处理一次性付款，又启动订阅 —— 减少摩擦并提升转化率。
   </Check>
   
   <Info>
   在混合产品类型时，一次性付款会立即扣款，而订阅则按照其配置的计费周期（包括您设置的任何试用期）进行。
   </Info>
   
   了解更多：[Checkout Sessions](/developer-resources/checkout-session)

2. **统一客户门户**  
   
   在[customer.dodopayments.com](https://customer.dodopayments.com)上推出新的集中式客户门户，客户可以在Dodo Payments的不同业务中查看和管理他们的所有购买和订阅。
   
   <Frame>
   <img src="/images/changelog/unified-customer-portal.png" alt="Unified Customer Portal" style={{ maxHeight: '500px', width: 'auto' }} />
   </Frame>
   
   ### 门户功能
   
   - **跨业务可见性**：在一个地方查看使用Dodo Payments的任何业务中的所有购买和订阅
   - **集中订阅管理**：从单一仪表板管理不同商家的订阅
   - **统一账单历史**：访问所有购买的发票和付款历史
   - **单点登录体验**：只需使用邮件登录一次，即可访问所有Dodo Payments商家的购买
   
   ### 工作原理
   
   客户只需访问[customer.dodopayments.com](https://customer.dodopayments.com)并输入他们的邮箱地址。他们将收到一个安全的登录链接，允许访问他们在Dodo Payments生态系统中的所有购买。
   
   <Tip>
   统一客户门户补充了特定业务的客户门户。客户仍然可以访问个别商户门户以获得品牌体验，或使用统一门户查看整合视图。
   </Tip>
   
   <Note>
   统一门户使用与特定业务门户相同的基于邮件的身份验证，确保一致和安全的体验。
   </Note>

3. **支付响应中的发票 ID**  
   支付响应现在包含 `invoice_id` 字段，使支付与发票对账和会计系统集成更方便。
   

   ```json
   {
     "payment_id": "pay_2IjeQm4hqU6RA4Z4kwDee",
     "status": "succeeded",
     "invoice_id": "inv_2IsUnWGtRKFLxk7xAQeyt",
     "amount": 9900,
     "currency": "USD",
     // ... other fields
   }
   ```

   
   ### 使用场景
   
   - **会计集成**：在会计软件中直接将支付与发票关联
   - **客户支持**：在处理支持请求时快速找到与支付对应的发票
   - **对账**：通过编程方式将支付匹配到发票，简化财务对账
   - **合规**：保持准确记录，将支付与其对应的税务发票关联
   
   <Info>
   `invoice_id` 字段在可用时使用印度特定的发票 ID，确保符合当地开票要求。
   </Info>
   
   了解更多：[Get Payment Detail API](/api-reference/payments/get-payments-1)
