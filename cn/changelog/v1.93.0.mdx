## 新功能

### 1. **结账重设计**

结账体验经过完全重设计，具有**改进的加载状态**，可以防止页面过渡期间闪烁。客户现在可以看到流畅的骨架加载，而不是生硬的内容转换，创造出更加精致的支付体验。

此外，**取消 URL 支持**现已可用——如果客户决定不完成购买，他们可以返回到您的网站。

<Frame>
<img src="/images/changelog/v1.93.0/checkout-redesign.png" alt="改进加载状态的重新设计的结账" />
</Frame>

<Tip>
在创建结账会话时配置 `cancel_url`，为客户提供回到您网站的明确退出路径。
</Tip>

### 2. **净收入分析**

分析页面现已提供新的**净收入**指标，可清晰查看实际收入，扣除退款、争议和费用后的净收入。跟踪净收入的时间趋势，并跨不同时期进行比较，以了解真实的业务表现。

<Frame>
<img src="/images/changelog/v1.93.0/net-revenue-analytics.png" alt="仪表板上的净收入分析" />
</Frame>

### 3. **业务级支付方式禁用**

现在可以**在业务级禁用特定支付方式**。这使您可以在所有结账会话中对客户可用的支付选项进行细致控制，无需为每个产品或会话配置。

<Frame>
<img src="/images/changelog/v1.93.0/payment-method-disabling.png" alt="设置中的业务级支付方式禁用" />
</Frame>

<Tip>
使用此功能禁用在您所在地区具有高欺诈率的支付方式，或限制仅支持您业务运作的方式。
</Tip>

### 4. **支付明细**

支付部分现在包括**详细的支付细目**，显示每笔支付金额的具体计算方式。直接从仪表板查看构成每笔支付的各个交易——支付、退款、争议和费用。

还提供了新的**支付明细 API**，用于以编程方式访问支付组成数据。

<Frame>
<img src="/images/changelog/v1.93.0/payout-breakdown.png" alt="显示交易级详细信息的支付明细" />
</Frame>

### 5. **Visa RDR 配置**

现在可以直接在业务设置中**配置 Visa 快速争议解决（RDR）**。设置 RDR 阈值并启用自动争议解决，无需联系支持。

<Frame>
<img src="/images/changelog/v1.93.0/rdr-configuration.png" alt="业务设置中的 Visa RDR 配置" />
</Frame>

<Tip>
RDR 自动解决合格的 Visa 争议，使其在成为正式拒付之前得到解决，帮助您保持在 Visa 0.9% 的争议率阈值以下。
</Tip>

了解更多：[Visa RDR](/features/transactions/disputes#visa-rapid-dispute-resolution-rdr)

### 6. **结账和客户门户的返回按钮**

结账会话和客户门户现在包括**返回按钮**，允许客户在不丢失进度的情况下导航至上一步。

<Frame>
<img src="/images/changelog/v1.93.0/back-button.png" alt="结账会话中的返回按钮" />
</Frame>

### 7. **变更计划在下一个计费日期生效**

现在可以安排订阅计划变更在**下一个计费日期生效**，而不是立即生效。这为客户带来了更顺畅的过渡体验，特别是在降级时，他们在计费周期结束前继续享受当前计划的访问权限。

了解更多：[变更计划 API](/api-reference/subscriptions/change-plan)

### 8. **DoNotBill 按比例分配模式**

新的 `do_not_bill` 按比例分配模式适用于订阅计划变更。在使用此模式时，不会计算按比例收费或折扣——客户只是切换到新计划，而无需进行任何计费调整。

| 按比例分配模式 | 行为 |
|----------------|----------|
| `prorated_immediately` | 立即计费或信用差额 |
| `prorated_next_billing` | 在下一个计费周期应用按比例分配 |
| `do_not_bill` | 无按比例分配——无计费调整地切换计划 |

了解更多：[订阅升级与降级](/developer-resources/subscription-upgrade-downgrade)

### 9. **删除客户支付方式**

新的 API 端点允许您以编程方式**删除客户保存的支付方式**。通过 API 或仪表板从客户账户中移除过时或不需要的支付方式。

了解更多：[客户支付方式](/features/customers)

## 改进

- 仪表板上实施了**骨架加载**以实现更快的感知加载时间
- 在页面间导航时的**过滤器持久化**——当您离开并返回时，所选过滤器将被保存
- 为更轻松的数据探索在仪表板视图中新增了**上下文钻取导航**
- 为测试基于信用的计费流程将**CBB 演示**添加到 Atlas

## 错误修复

- 修复了某些订阅视图中的错误过期时间显示
- 修复了 iOS 推送通知未播放通知声音的问题
