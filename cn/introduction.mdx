## 什么是 Dodo Payments？

Dodo Payments 是一个**一体化引擎**，可在全球范围内启动、扩展和货币化。专为新一代数字 SaaS 和 AI 产品设计，我们处理从**支付到账单到分发**的一切——无需额外的工程努力。

    <Info>
**为 SaaS 和 AI 产品构建**：使用我们的优化账单基础设施处理一次性支付、订阅、积分、座位、令牌或任何使用指标。
    </Info>

    <Tip>
  <strong>认识 Sentra：您的 AI 驱动账单助理</strong><br/>
  Sentra 是一个 AI 代理，直接在您的 IDE 中集成、分析和处理账单和支付。提问、构建集成或规划账单架构——只需描述您想要的即可。
  <a href="/developer-resources/sentra">
    开始使用 Sentra &rarr;
  </a>
</Tip>

## 快速开始指南

只需几个步骤即可使用 Dodo Payments。

    <AccordionGroup>

  **安装**。对于 Claude Code、Codex CLI、Cursor 或 OpenCode，[Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) 一步连接 MCP 服务器和所有技能。每个代理的安装命令请参见 [AI Coding Agents guide](/developer-resources/build-with-ai-coding-agents)。

  **连接**。两个 MCP 服务器使代理实时访问平台：

  - **[Dodo Knowledge MCP](/developer-resources/mcp-server#dodo-knowledge-mcp)** - 跨所有 Dodo 文档的语义搜索

    <Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
将两个服务器添加到您的 MCP 配置中（`~/.cursor/mcp.json` 或 Claude Desktop 配置）：

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

    <Info>
需要 Node.js 18+。有关所有支持客户端的详细设置说明，请参见 [MCP Server 文档](/developer-resources/mcp-server)。
</Info>
</Accordion>
