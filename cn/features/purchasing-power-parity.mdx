[ParityDeals](https://www.paritydeals.com/) 和 [Evendeals](https://www.evendeals.com/integrations/dodo-payments) 是可以根据客户地理位置自动优化定价的平台，通常称为"购买力平价"(PPP) 定价。

当你无法在 Dodo Payments 商店直接嵌入折扣横幅（因为不支持自定义脚本）时，仍然可以在自己的网站或应用程序中有效实施这些工具。

设置基于位置、假期和时间的优惠，并通过可自定义的横幅进行展示。
自动进行一次性和订阅产品的优惠券同步和刷新规则。
了解如何在 Dodo Payments 仪表板中手动创建和管理折扣代码。
在中央仪表板中访问你的销售、折扣和 API 密钥。

## 选择集成

这两个平台都直接与 Dodo Payments 集成，可自动创建和管理折扣代码。使用下面的比较来选择最适合你需求的工具。

| 功能 | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| PPP / 基于位置的定价 | 是 | 是 |
| 假期 / 基于时间的优惠 | 是 | 否 |
| 订阅支持 | 是 | 是 |
| 自动优惠券刷新 | — | 是 |
| 横幅自定义 | 是 | 否 |
| 定价 | [查看定价](https://www.paritydeals.com/pricing/) | [查看定价](https://www.evendeals.com/pricing) |

## ParityDeals

当 ParityDeals 集成到你的网站时，符合条件的访问者将看到一个横幅，其中包含可在结账时使用的基于位置的折扣代码。这些折扣代码由 ParityDeals 自动创建和管理，并将在你的 **Dodo Payments 仪表板** 中的 **销售 → 折扣** 下出现。

<img src="/images/ppp/1.png" alt="ParityDeals 折扣横幅示例" />

### 设置

访问 [app.paritydeals.com](https://app.paritydeals.com/) 并创建一个账户。

登录后，找到创建优惠的选项。从下拉菜单中选择 **"通过 Dodo Payments 创建优惠"**。

<img src="/images/ppp/2.png" alt="通过 Dodo Payments 创建优惠" />

登录你的 **Dodo Payments 仪表板**，导航到 **开发人员 → API 密钥**。点击 **"创建新 API"**。

以描述性名称命名你的 API 密钥（例如，'ParityDeals'），以便你以后识别它。

<img src="/images/ppp/3.png" alt="在 Dodo Payments 中创建新 API 密钥" />

复制你创建的 API 密钥，并将其粘贴到 ParityDeals 界面中以建立与你的 Dodo Payments 账户的连接。

<img src="/images/ppp/4.png" alt="将 API 密钥连接到 ParityDeals" />

连接后，ParityDeals 将获取你的 Dodo Payments 产品目录。选择你想要与你的优惠关联的产品。

<img src="/images/ppp/5.png" alt="为 ParityDeals 选择产品" />

输入你的网站 URL，并可选择在特定目标页面上显示折扣横幅。然后选择你喜欢的优惠类型：
- 基于位置的优惠
- 假期优惠
- 基于时间的限时优惠

<img src="/images/ppp/6.png" alt="配置优惠设置" />

选择你想提供本地化折扣的国家并定义每个国家的折扣百分比。ParityDeals 提供推荐的默认值，你可以根据需要进行调整。

<img src="/images/ppp/7.png" alt="设置基于国家的折扣规则" />

通过自定义文本、选择颜色和布局以及选择横幅位置（页面顶部或底部），设计你的折扣横幅。此横幅将根据你配置的规则向符合条件的访问者展示。

<img src="/images/ppp/8.png" alt="自定义折扣横幅" />

保存优惠后，ParityDeals 将生成一个脚本。将此脚本添加到你的网站代码中（通常在 `<head>` 部分）。此脚本会自动检测访问者位置并显示相应的折扣横幅。

<img src="/images/ppp/9.png" alt="ParityDeals 集成脚本" />

### 附加功能

使用 ParityDeals，你还可以在全年提供[自动时间优惠](https://www.paritydeals.com/features/time-based-discounts/)和[假期促销](https://www.paritydeals.com/features/holiday-based-discounts/)。有关更详细的信息，请参考 [ParityDeals 文档](https://www.paritydeals.com/docs/)。

## Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) 是另一个与 Dodo Payments 集成的平台，提供基于位置的购买力平价定价。它支持一次性和订阅产品。

<img src="/images/ppp/evendeals-hero.png" alt="Evendeals Dodo Payments 集成概述" />

### 关键特性

- **自动优惠券同步** — 优惠券在 Dodo Payments 中自动创建和管理
- **百分比折扣** — 为每个国家组提供百分比折扣
- **订阅支持** — 折扣适用于整个订阅账单周期
- **自动刷新规则** — 按时间间隔、兑换次数或查看次数自动轮换优惠券代码，以防滥用

由 Evendeals 创建的折扣代码将自动出现在你的 Dodo Payments 仪表板的销售 → 折扣下。

<img src="/images/ppp/evendeals-features.png" alt="Evendeals 针对 Dodo Payments 集成的关键特性" />

### 设置

在你的 Dodo Payments 仪表板中，转到 **开发人员 → API 密钥** 并生成一个新密钥。

在你的 [Evendeals 仪表板](https://www.evendeals.com/signin)中，导航到 **集成**，找到 Dodo Payments 卡片，并粘贴你的 API 密钥。

为每个国家组设置百分比折扣并点击同步。Evendeals 在 Dodo Payments 中自动创建优惠券。

同步后，打开你 Dodo Payments 仪表板中的 **销售 → 折扣**，确认生成的优惠券出现。每个优惠券都带有可识别的 Evendeals 前缀。

<img src="/images/ppp/evendeals-setup.png" alt="Evendeals 针对 Dodo Payments 的设置指南" />

ParityDeals 和 Evendeals 都能与 Dodo Payments 无缝协作，帮助你优化全球定价策略。有关更多详细信息，请访问 [ParityDeals 文档](https://www.paritydeals.com/docs/) 或 [Evendeals Dodo Payments 集成页面](https://www.evendeals.com/integrations/dodo-payments)。
