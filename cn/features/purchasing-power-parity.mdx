<Info>
购买力平价（PPP）会根据客户购买所在的国家/地区，让客户支付列表价格的一定比例。一个 \$20 的产品可以在**印度以 \$6.00 售出**，无需折扣码，也无需维护第二份价格列表。
</Info>

## 什么是购买力平价？

同一个价格在不同地方的可负担程度并不相同。\$20 在美国是一笔小额消费，在菲律宾却是一笔较大的消费。PPP 定价可以修正这种差异。

Dodo Payments 为每个国家/地区保留一个百分比。该百分比是**客户需要支付的列表价格比例**。印度的比例为 30，因此印度客户支付价格的 30%。美国的比例为 100，因此价格不变。

你可以为需要应用 PPP 的每个产品价格单独启用该功能。未选择启用的产品在任何地方都保持正常价格。

<Note>
PPP 需要 [Adaptive Currency](/features/adaptive-currency)。请先启用 Adaptive Currency。
</Note>

## 主要优势

- **触达价格敏感型市场**：以本地价格销售，同时不降低你的本地价格。
- **无需横幅和脚本**：价格会在结账时自动正确显示。无需向网站添加任何内容。
- **无需管理折扣码**：无需创建、轮换或撤销折扣码。
- **按产品控制**：可以为入门版套餐启用，同时不影响企业版套餐。
- **适用于各种产品**：一次性产品、订阅产品和基于用量的产品。

## 启用购买力平价

<Steps>
<Step title="Enable Adaptive Currency">
前往 **Settings → Business**。在 **Business Settings** 中启用 **Adaptive Currency**。未启用该功能时，PPP 不会生效。

<Frame>
  <img src="/images/ppp/adaptive-currency-toggle.png" alt="Business Settings 中的 Adaptive Currency 和购买力平价" style={{ maxHeight: '360px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Review your country percentages">
在 **Purchasing Power Parity** 下，点击 **Edit** 打开 **Country Prices**。修改任意国家/地区的百分比，然后点击 **Save Changes**。

设置 **Example product price**，即可查看每个国家/地区需要支付的价格。输入时，**Your Price** 列会随之更新。使用搜索框按名称或代码查找国家/地区。

<Frame>
  <img src="/images/ppp/country-percentages.png" alt="Country Prices 对话框，其中显示每个国家/地区的百分比和相应价格" style={{ maxHeight: '620px', width: 'auto' }} />
</Frame>

<Note>
这些百分比适用于整个企业。所有启用了购买力平价的产品都会使用这些百分比。
</Note>
</Step>

<Step title="Turn PPP on for a product">
打开产品。在 **Pricing** 部分勾选 **Purchasing Power Parity**，然后保存产品。

未勾选的产品在任何地方都保持正常价格。

<Frame>
  <img src="/images/ppp/product-toggle.png" alt="产品 Pricing 部分中已勾选 Purchasing Power Parity" style={{ maxHeight: '440px', width: 'auto' }} />
</Frame>

<Warning>
Adaptive Currency 关闭时，无法勾选此选项。请先启用 Adaptive Currency。
</Warning>
</Step>

<Step title="Confirm at checkout">
<Check>
使用百分比低于 100 的结账国家/地区打开测试结账页面。确认页面显示了降低后的价格。
</Check>
</Step>
</Steps>

## 价格如何计算

国家/地区百分比会乘以你的列表价格：

```
price paid = list price × country percentage ÷ 100
```

对于印度客户，价格为 30 的 \$20.00 产品：

```
2000 × 30 ÷ 100 = 600   →   $6.00
```

Dodo Payments 会在货币转换之前，将百分比应用于基础价格。然后，[Adaptive Currency](/features/adaptive-currency) 会将结果转换为客户使用的货币。

<Info>
Dodo Payments 会在结账时从客户的**账单国家/地区**读取所在国家/地区。
</Info>

### 国家/地区百分比

每个国家/地区都有一个介于**30 和 100 之间**的百分比：

- **100** 表示客户支付完整价格，不会减少。
- **30** 是你可以设置的最低值，因此最大降幅为 70%。

默认值来自世界银行的价格水平指数数据。Dodo Payments 会将每个值四舍五入到最接近的 5，设置最低值 30，并将最高值限制为 100。每个受支持的国家/地区都有对应值，你可以修改其中任何一个值。

以下是部分默认值，用于展示价格范围：

| 国家/地区 | 百分比 | \$20 产品的售价 |
| :--- | :---: | :--- |
| 美国 | 100 | \$20.00 |
| 英国 | 85 | \$17.00 |
| 德国 | 75 | \$15.00 |
| 日本 | 60 | \$12.00 |
| 巴西 | 45 | \$9.00 |
| 南非 | 40 | \$8.00 |
| 菲律宾 | 35 | \$7.00 |
| 印度 | 30 | \$6.00 |

<Note>
完整列表涵盖 217 个国家/地区。打开 dashboard 中的国家/地区表格，即可查看所有值。
</Note>

## 通过 API 启用

PPP 按产品启用，使用 `purchasing_power_parity` 字段。默认值为 `false`。

<Info>
国家/地区百分比只能在 dashboard 中管理，不属于公共 API 的一部分。
</Info>

<CodeGroup>

```typescript theme={null}
import DodoPayments from 'dodopayments';

const client = new DodoPayments({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: 'test_mode',
});

const product = await client.products.create({
  name: 'Starter Plan',
  tax_category: 'saas',
  price: {
    type: 'one_time_price',
    currency: 'USD',
    price: 2000,
    discount: 0,
    purchasing_power_parity: true,
  },
});
```

```python theme={null}
import os
from dodopayments import DodoPayments

client = DodoPayments(
    bearer_token=os.environ.get("DODO_PAYMENTS_API_KEY"),
    environment="test_mode",
)

product = client.products.create(
    name="Starter Plan",
    tax_category="saas",
    price={
        "type": "one_time_price",
        "currency": "USD",
        "price": 2000,
        "discount": 0,
        "purchasing_power_parity": True,
    },
)
```

```go theme={null}
package main

import (
	"context"
	"os"

	"github.com/dodopayments/dodopayments-go"
	"github.com/dodopayments/dodopayments-go/option"
)

func main() {
	client := dodopayments.NewClient(
		option.WithBearerToken(os.Getenv("DODO_PAYMENTS_API_KEY")),
	)

	_, err := client.Products.New(context.TODO(), dodopayments.ProductNewParams{
		Name:        dodopayments.F("Starter Plan"),
		TaxCategory: dodopayments.F(dodopayments.ProductNewParamsTaxCategorySaas),
		Price: dodopayments.F[dodopayments.PriceUnionParam](
			dodopayments.PriceOneTimePriceParam{
				Type:                  dodopayments.F(dodopayments.PriceOneTimePriceTypeOneTimePrice),
				Currency:              dodopayments.F(dodopayments.CurrencyUsd),
				Price:                 dodopayments.F(int64(2000)),
				Discount:              dodopayments.F(int64(0)),
				PurchasingPowerParity: dodopayments.F(true),
			},
		),
	})
	if err != nil {
		panic(err)
	}
}
```

</CodeGroup>

## 重要行为

| 行为 | 详情 |
| :--- | :--- |
| **需要 Adaptive Currency** | Adaptive Currency 关闭时，PPP 不会生效。 |
| **默认关闭** | 每个价格最初都设置为 `purchasing_power_parity: false`。 |
| **本地化价格优先** | 如果产品匹配 [Localized Pricing](/features/localized-pricing) 规则，则 PPP 不会调整该产品价格。你设置的确切金额会直接生效。 |
| **在转换前应用** | 百分比会应用于基础价格。Adaptive Currency 会转换结果。 |
| **在折扣前应用** | [折扣码](/features/discount-codes) 会应用于降低后的价格，因此两种降价会叠加。 |
| **基于用量的产品仅适用于固定费用** | PPP 会应用于基于用量产品的固定费用，但不会应用于计量用量。 |
| **不适用于 Pay What You Want** | 客户自行选择金额，因此 PPP 不适用。请参阅 [Pay What You Want](/features/pay-what-you-want)。 |
| **百分比范围** | 国家/地区百分比介于 30 和 100 之间，最大降幅为 70%。 |
| **没有专属 webhook** | 降低后的金额会像其他价格一样显示在 payment 或 subscription 上。 |

## 最佳实践

- **先为一个产品启用。** 在为产品目录启用之前，先确认结账价格。
- **留意折扣叠加。** 折扣码会叠加在 PPP 价格之上。国家/地区折扣 30% 加上代码折扣 20% 后，客户将支付列表价格的 24%。
- **不要为企业版套餐启用。** 协商确定的套餐通常不需要进行国家/地区价格调整。
- **在重要的地方设置自定义值。** 默认数字只是起点，并非硬性规则。
- **检查对订阅的影响。** 以降低后的价格注册的订阅者会以该价格续订。
