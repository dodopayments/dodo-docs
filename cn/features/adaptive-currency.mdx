<Info>
Adaptive Currency 可让您展示本地化价格并以客户的本地货币接受付款。这有助于减少结账摩擦并建立信任。
</Info>

## 什么是自适应货币？

Adaptive Currency 会以客户的本地货币显示产品价格，而不是仅显示您的基础货币。启用后，对于受支持的国家/地区，checkout 默认使用检测到的本地货币，同时提供切换回基础货币的选项。

您的基础货币就是您为产品或附加项定价时使用的货币——可以是 Dodo Payments 支持收款的任何货币，而不仅仅是 USD。Adaptive Currency 会按照实时汇率转换该基础价格。如果您希望为每种货币或国家/地区设置自己的固定价格，请参阅[本地化定价](/features/localized-pricing)。

## 主要优势

- **本地化支付体验**：默认以当地货币显示价格。
- **更多支付方式**：解锁当地货币可用的支付方式。
- **同币种退款**：使用客户付款时所用的货币向客户退款。
- **解锁高级定价**：启用 [购买力平价](/features/purchasing-power-parity) 和 [魅力定价](/features/charm-pricing)，按市场自动优化价格。

## 启用自适应货币

<Steps>
<Step title="Open Settings">
登录您的商家仪表板并前往设置 → 业务。
</Step>

<Step title="Toggle Adaptive Currency">
启用 Adaptive Currency 开关。你可以随时将其禁用。

<Warning>
更改仅适用于未来的交易。
</Warning>
</Step>

<Step title="Confirm and Save">
保存您的设置。

<Check>
验证测试结账时，在支持的情况下价格显示为当地货币。
</Check>
</Step>
</Steps>

## 客户体验

1. **检测**：系统根据账单地址检测客户所在的国家/地区。
2. **货币选择**：如果该国家/地区受支持，价格默认以当地货币显示。客户可以切换回您的基础货币。
3. **支付方式**：在适用的情况下显示本地化支付方式。
4. **checkout**：使用所选货币完成支付。

## 转换和费用

自适应货币使用最新汇率以当地货币向客户收费。

- **您支付**：0%（默认）或2-4%（启用费用包含时）
- **您的客户支付**：基于订单价值的2-4%（默认）或0%（启用费用包含时）

结账时应用分级费用：

- 订单低于$500的费用为4%
- $500到$1,500的费用为3%
- 超过$1,500的费用为2%

### 选择谁承担费用

默认情况下，自适应货币费用会添加到显示价格上，由客户承担。使用**费用包含**设置，您可以自己承担费用：客户看到的始终是相同的本地货币价格，并且费用从您的结算中扣除。

<Steps>
<Step title="Enable Adaptive Currency">
前往 **Settings → Business**，如果尚未启用 Adaptive Currency 开关，请将其启用。
</Step>

<Step title="Toggle Fees Inclusive">
启用 Adaptive Currency 后，在同一部分启用 **Fees Inclusive** 子开关。
</Step>
</Steps>

| 模式 | 客户看到 | 商家结算 |
|------|---------------|------------------|
| 独占 (默认) | 本地价格加2-4%费用 | 全额基础价格 |
| 包含 | 本地价格（不变） | 基础价格减去2-4%费用 |

您还可以通过在一次性付款、按需订阅（`on_demand.adaptive_currency_fees_inclusive`）、订阅扣款或计划变更中传递 `adaptive_currency_fees_inclusive`（布尔值）来按请求覆盖商户默认设置。结账会话不接受此参数：

```typescript
const payment = await client.payments.create({
  product_cart: [{ product_id: 'pdt_abc', quantity: 1 }],
  customer: { customer_id: 'cus_123' },
  billing: { country: 'US' },
  adaptive_currency_fees_inclusive: true, // override the business setting for this payment
  return_url: 'https://yoursite.com/return'
});
```

<Info>
INR → INR 交易始终被视为包含费用，无论业务设置或每个请求的覆盖如何。
</Info>

<Info>
当[Localized Pricing](/features/localized-pricing)规则匹配时，该交易始终被视为包含费用，无论您的**费用包含**设置或每个请求的覆盖如何。客户支付您设定的准确本地化金额，转换费从您的结算中扣除。
</Info>

## 退款和调整

Dodo Payments 使用客户最初付款时的货币发起退款，并采用最新汇率。您的基础货币金额在控制面板、发票和退款记录中保持不变。这意味着根据 FX 变化，客户收到的金额可能高于或低于最初的本地货币金额。

<Info>
自适应货币费用通常是外汇费用，不予退款。
</Info>

**退款示例**

1. 您以100美元的价格销售产品，并启用了自适应货币。
2. 加拿大客户看到137加元，汇率为1美元兑1.37加元，并完成购买。
3. 我们处理付款，将137加元转换为100美元转入您的结算账户。
4. 后来，汇率变为1美元兑1.40加元，您发起全额退款。
5. 我们扣除100美元，并退还给客户140加元。

## 发票与税收

- 发票仅显示结算货币金额。
- 税费和平台费用根据结算货币金额计算。
- 示例：$10的销售额转换为36 AED，仍在仪表板和发票中显示为$10。

<Info>
所有金额根据Dodo Payments的内部舍入逻辑进行舍入。
</Info>

## 集成示例

**含账单货币的结账会话**

传递`billing_currency`以明确设置会话的账单货币。

<Info>
禁用 Adaptive Currency 后，`billing_currency` 将被忽略。
</Info>

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    {
      product_id: 'pdt_one_time_or_subscription',
      quantity: 1
    }
  ],
  billing_currency: 'AED',
  return_url: 'https://example.com/return'
});
```
