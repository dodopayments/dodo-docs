<Info>
魅力定价会在每次结账时，将换算后的价格舍入为 **49.99** 等简洁的尾数。你只需设置一次规则，Dodo Payments 就会将其应用于每位客户使用的货币。
</Info>

## 什么是魅力定价？

[Adaptive Currency](/features/adaptive-currency) 会按照实时汇率换算你的基础价格。结果虽然准确，却很少具有吸引力：一款售价为 \$47.00 的产品今天可能显示为 **€43.12**，明天则显示为 **€43.47**。

魅力定价会将换算后的金额调整为最近的简洁尾数。客户看到的是 **49.99**，而不是 43.12。汇率波动时，尾数仍保持稳定。

你无需为每个市场分别设置价格。选择一条舍入规则，它就会应用于每种货币。

<Note>
魅力定价需要 [Adaptive Currency](/features/adaptive-currency)。请先启用 Adaptive Currency。
</Note>

## 主要优势

- **每种货币都显示简洁价格**：一条规则覆盖所有市场，无需维护价格列表。
- **稳定的尾数**：汇率小幅波动时，尾数不会随之变化。
- **没有换算痕迹**：客户不会看到 43.12 或 1043.87。
- **新市场自动生效**：即使你从未为某种货币定价，也能得到简洁的金额。

<Info>
如果要手动为某个市场设置确切价格，请改用 [Localized Pricing](/features/localized-pricing)。对于该产品，Localized Pricing 始终优先于魅力定价。
</Info>

## 启用魅力定价

<Steps>
<Step title="Enable Adaptive Currency">
前往 **Settings → Business**。在 **Business Settings** 中启用 **Adaptive Currency**。未启用该功能时，魅力定价不会生效。

<Frame>
  <img src="/images/charm-pricing/adaptive-currency-toggle.png" alt="Business Settings 中的 Adaptive Currency 开关" style={{ maxHeight: '360px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Turn on Charm Pricing">
在同一 **Business Settings** 部分中，启用 **Charm Pricing** — *将价格舍入为更简洁、更具吸引力的数字*。当前的舍入类型会显示在开关下方。

<Frame>
  <img src="/images/charm-pricing/charm-toggle.png" alt="Business Settings 中已启用的 Charm Pricing" style={{ maxHeight: '400px', width: 'auto' }} />
</Frame>

<Warning>
更改仅适用于未来的交易。现有订阅会继续使用创建时采用的舍入规则。请参阅 [Subscriptions](#subscriptions)。
</Warning>
</Step>

<Step title="Set the rounding type and steps">
点击 **Edit** 打开 **Set up Charm Pricing**。选择 **Rounding type**，然后为任意价格范围调整 **Rounding step**。点击 **Save Changes**。

<Frame>
  <img src="/images/charm-pricing/rounding-type.png" alt="Set up Charm Pricing 对话框，其中包含舍入类型选择器和 Try it 预览" style={{ maxHeight: '620px', width: 'auto' }} />
</Frame>

使用 **Try it** 在保存前检查数值。输入金额和货币后，对话框会显示结果及所使用的步长。

Dodo Payments 会为每个范围提供默认步长。请参阅 [Rounding types](#rounding-types) 和 [Rounding steps](#rounding-steps)。

<Frame>
  <img src="/images/charm-pricing/bands.png" alt="舍入步长表，每个价格范围对应一个步长" style={{ maxHeight: '440px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Confirm at checkout">
<Check>
打开测试结账，并将账单国家/地区设置为使用另一种货币的国家/地区。确认价格显示了你期望的尾数。
</Check>
</Step>
</Steps>

## 价格如何计算

Dodo Payments 会在货币换算和任何折扣之后、税费之前，对**单价**应用魅力定价。

1. **确定步长。** 金额会从舍入步长表中选择一个步长。\$47 的价格位于 10–99 范围内，因此步长为 **10**。
2. **选择目标值。** 步长提供两个候选值：**40** 和 **50**。舍入类型决定选择哪一个。使用 **Nearest** 时，47 更接近 50。
3. **削减尾数。** Dodo Payments 会减去步长的千分之一，因此 50 会变成 **49.99**。削减值绝不会小于一个最小货币单位。**Whole** 会跳过此步骤。

### 舍入类型

| 类型 | 选择规则 | \$47 变为 |
| :--- | :--- | :--- |
| **Nearest** | 选择两个候选值中更接近价格的一个。相等时向上取整。 | \$49.99 |
| **Floor** | 始终选择低于价格的候选值。 | \$39.99 |
| **Ceiling** | 始终选择高于价格的候选值。 | \$49.99 |
| **Whole** | 选择最近的候选值，但不削减尾数。 | \$50.00 |

<Warning>
**Floor** 可能会将价格降低接近一个完整步长。\$47 的价格会变为 \$39.99，降幅达 15%。选择前，请检查它对价格范围的影响。
</Warning>

### 舍入步长

步长取决于价格的大小，单位为该货币的主要单位。以下是默认值。你可以为任意范围更改 **Rounding step**，但不能更改范围本身。

| 价格范围 | 步长 |
| :--- | :--- |
| 1 – 9 | 1 |
| 10 – 99 | 10 |
| 100 – 999 | 100 |
| 1,000 – 9,999 | 1,000 |
| 10,000 – 99,999 | 10,000 |
| 100,000 – 999,999 | 10,000 |
| 1,000,000 – 9,999,999 | 10,000 |
| 10,000,000 及以上 | 10,000 |

步长增长会在 10,000 处停止。这样可以减少大额价格的变化；对于每美元对应许多货币单位的货币（例如 IDR 和 VND），这一点尤为重要。

<Note>
较大的步长会使价格移动较远。使用默认的 1,000 步长时，换算价格 **\$1,234** 会变为 **\$999.00**。如果变化幅度对你的产品目录来说过大，请降低该范围的步长。
</Note>

### 示例

| 换算价格 | 货币 | 步长 | 舍入类型 | 客户支付 |
| :--- | :--- | :--- | :--- | :--- |
| \$47.00 | USD | 10 | Nearest | **\$49.99** |
| \$47.00 | USD | 10 | Whole | **\$50.00** |
| \$47.00 | USD | 10 | Floor | **\$39.99** |
| \$5.00 | USD | 1 | Nearest | **\$4.99** |
| ¥4,700 | JPY | 1,000 | Nearest | **¥4,999** |
| ¥5 | JPY | 1 | Nearest | **¥4** |

<Info>
对于 JPY 等没有小数位的货币，系统会削减一个完整单位。尾数是 ¥4,999，而不是 ¥4,999.99。
</Info>

### 魅力定价不适用的情况

在以下情况下，Dodo Payments 会保持换算后的价格不变：

- 步长大于价格。价格无法移动小于一个完整步长的距离。
- 结果将为零或负数。
- 没有步长与该金额匹配。

## 结账时的应用方式

魅力定价是价格计算的最后一步。对于没有本地化价格的产品，计算顺序如下：

1. **基础价格** — 你在产品上设置的价格。
2. **[Purchasing Power Parity](/features/purchasing-power-parity)** — 如果产品已选择启用，则应用国家/地区百分比。
3. **折扣** — 应用产品折扣和 [discount code](/features/discount-codes)。
4. **[货币换算](/features/adaptive-currency)** — 按实时汇率将折后金额换算为客户的货币。
5. **魅力舍入** — 将结果调整为简洁尾数。
6. **税费** — 根据应用魅力定价后的金额计算。请参阅 [Tax-Inclusive Pricing](/features/tax-inclusive-pricing)。

每个购物车行项目都会单独计算。划线显示的“折扣前”价格使用与实际收取价格相同的舍入步长，因此魅力定价不会显示为你未提供的折扣。

<Warning>
**应用魅力定价的行项目会使整笔交易包含费用。** 客户支付的金额正好是他们看到的尾数，因此不能再额外收取 Adaptive Currency 换算费用。该费用由你承担。请参阅 [选择费用承担方](/features/adaptive-currency#choose-who-bears-the-fee)。
</Warning>

## 订阅

客户订阅时，订阅会记录舍入步长和舍入类型。Dodo Payments 会在每次续订时重复使用相同的规则。

**固定内容：** 舍入步长和舍入类型。如果你编辑步长或更改舍入类型，现有订阅不会重新定价。客户继续使用他们同意的规则。

**可能变化的内容：** 金额。每次续订都会按当前汇率换算价格，然后应用固定规则。即使规则未变，汇率的大幅波动也可能改变续订金额。

<Warning>
**更改方案会移除该订阅的魅力定价。** 当订阅者[更改方案](/features/subscription#subscription-plan-changes)时，新方案会收取方案变更报价中显示的金额。Dodo Payments 不会对该金额应用魅力定价，也不会对该订阅后续的续订应用魅力定价。
</Warning>

## 重要行为

| 行为 | 详情 |
| :--- | :--- |
| **需要 Adaptive Currency** | Adaptive Currency 关闭时，魅力定价不会生效。 |
| **本地化价格优先** | 具有匹配 [Localized Pricing](/features/localized-pricing) 规则的产品不会应用魅力定价。你设置的确切金额会直接生效。 |
| **按单价应用** | 先对单价应用魅力定价，再乘以数量。 |
| **折扣之后应用** | 先以基础货币应用折扣，再对换算后的结果进行魅力舍入。 |
| **税费之前应用** | 根据应用魅力定价后的金额计算税费，因此总额保持一致。 |
| **强制包含费用** | 应用魅力定价的交易中，货币换算费用由你承担。 |
| **不适用于 Pay What You Want** | 客户自行选择金额，因此不会应用魅力定价。请参阅 [Pay What You Want](/features/pay-what-you-want)。 |
| **按用量计费时仅适用于固定费用** | 按计量用量收取的费用不会应用魅力定价。 |
| **没有专属 webhook** | 应用魅力定价后的金额会像其他价格一样显示在支付或订阅中。 |

## 最佳实践

- **从 Nearest 开始。** 它对价格的移动幅度最小。只有在你接受它产生的折扣时，才使用 Floor。
- **检查产品中的最高价和最低价。** 步长会随价格范围变化，因此 \$5 的产品和 \$1,200 的产品表现不同。
- **检查高单位货币的步长。** IDR、VND 和 KRW 的价格会落入最高范围，此时步长固定为 10,000。
- **在发布前确定订阅价格。** 之后编辑步长不会为现有订阅者重新定价。
- **将换算费用计入考虑。** 应用魅力定价的行项目包含费用，因此费用会从你的收入中扣除。
