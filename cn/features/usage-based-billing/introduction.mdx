基于使用量的计费允许您根据客户实际使用的内容进行收费，例如 API 调用、存储、AI 令牌或任何您定义的指标。客户支付的是使用量，而不是固定费用。

<Info>
**非常适合**：API、AI 服务、基础设施平台，以及任何价值随使用量变化的产品。
</Info>

## 原理

<Steps>
<Step title="Send Usage Events">
您的应用在发生可计费操作时发送事件。

```javascript
{
  "event_id": "evt_123",
  "customer_id": "cus_abc",
  "event_name": "api.call",
  "metadata": { "endpoint": "/v1/users" }
}
```

</Step>

<Step title="Meters Aggregate Usage">
计量器使用计数、总和、最大值或最后一个聚合事件以转换为可计费的数量。
</Step>

<Step title="Automatic Billing">
设定每单位价格和免费阈值。客户会在每个周期自动计费。
</Step>
</Steps>

## 核心概念

### 事件

事件代表您应用中的使用行为。每个事件包括：
- **事件名称**：使用类型（例如，`api.call`）
- **客户 ID**：使用者
- **元数据**：用于聚合的附加属性

### 计量器

计量器将事件聚合为可计费数量：
- **计数**：总事件数（API 调用）
- **总和**：累加值（总字节数）
- **最大值**：最高值（峰值用户数）
- **最后一个**：最近的值

### 基于使用量定价的产品

设置每单位价格和可选的免费阈值：

<Frame>

**示例**：2500 次调用 - 1000 次免费 = 1500 × $0.02 = $30.00

### 基于积分的扣除

可以配置计量器从客户的[积分余额](/features/credit-based-billing)中扣除，而不是按单位按美元收费。积分在每个计费周期刷新，并在任何超额费用之前应用。

## 快速入门

<Steps>
<Step title="Create a Meter">
在您的仪表板中：**计量器** → **创建计量器**

1. 设置事件名称（例如，`api.call`）
2. 选择聚合方式（计数、总和、最大值、最后一个）
3. 添加可选筛选条件
</Step>

<Step title="Add to Product">
将计量器与定价产品关联：

<Frame>
<img src="/images/usage-based/UBB-5.png" alt="将计量器添加到产品" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

1. 选择**基于使用量的计费**
2. 选择您的计量器
3. 设置每单位价格和免费阈值
</Step>

<Step title="Send Events">

```javascript
await fetch('https://test.dodopayments.com/events/ingest', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.DODO_PAYMENTS_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    events: [{
      event_id: "unique_event_id",
      customer_id: "cus_abc123",
      event_name: "api.call",
      metadata: { endpoint: "/v1/users" }
    }]
  })
});
```

</Step>

<Step title="Monitor Usage">
<Frame>
<img src="/images/guides/usage-based-billing/meter-quantities-chart.png" alt="计量器仪表板" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

查看您的计量器仪表板以查看事件和使用聚合。客户会在每个周期自动计费。
</Step>
</Steps>

## 使用案例

<CardGroup cols={2}>
<Card title="APIs & Infrastructure" icon="cloud">
追踪 API 调用、计算小时、带宽、存储。例如：每次调用 $0.001，前 10000 次免费。
</Card>

<Card title="AI Usage Tracking" icon="brain">
追踪令牌、生成次数、处理时间。例如：每个标准图像收费 $0.04，每个高清收费 $0.08。
</Card>

<Card title="Data & Analytics" icon="chart-line">
按处理数据量、查询数量、分析记录数计费。例如：前 10 GB 免费，超过部分每 GB 收费 $5。
</Card>

<Card title="Communication" icon="message">
计数消息、分钟、已传输数据。例如：每条发送的 SMS 收费 $0.01。
</Card>
</CardGroup>
