## 什么是客户门户？

该门户为客户提供了一个可信的、品牌化的自助服务体验，客户可以：

- **访问账单历史记录**：查看发票并下载收据。
- **管理订阅**：查看订阅详情，暂停和恢复订阅，并立即或在下一个账单日期取消订阅。
- **更新支付方式**：更改有效订阅的支付方式，或重新激活处于暂停状态的订阅。
- **获取许可证密钥**：访问与购买相关联的所有密钥。
- **轻松导航**：使用返回按钮在门户的各个部分之间切换，同时不会丢失上下文。

## 主要好处

- **降低支持量**：客户自行解决常见的账单请求。
- **更快的价值实现**：立即访问发票和密钥。
- **降低流失风险**：清晰可见的续订和计划详情。
- **安全设计**：使用过期链接的令牌化访问。

## 访问方式

客户可以通过静态链接或一次性动态链接访问门户。

### 静态链接（基于电子邮件的访问）

客户可以通过在一个永不过期的静态链接中输入他们的电子邮件来请求门户访问。

静态门户链接格式因环境而异：

**测试模式**（用于测试和开发）：

```bash
https://test.customer.dodopayments.com/login/{business_id}
```

**实时模式**（用于真实交易的生产环境）：

```bash
https://customer.dodopayments.com/login/{business_id}
```

将 `{business_id}` 替换为您的实际业务标识符，然后与客户分享相应链接，以便他们输入电子邮件并获取安全的门户访问权限。

## 计划变更（升级/降级）

当产品被归类到 **产品集合** 中时，客户可以直接在客户门户内在计划之间升级或降级。

<Tip>
**想为现有订阅启用升级/降级？** 将您的订阅产品添加到产品集合。一旦归组，客户即可通过客户门户在同一集合内的计划之间切换。
</Tip>

- **自动检测**：首次访问时，门户会根据客户的浏览器设置检测其首选语言，并加载相应的翻译（如果有）。默认情况下使用英语。
- **手动覆盖**：客户可以随时通过门户标题中的语言选择器更改活动语言（适用于电脑和移动设备）。
- **持久偏好**：所选语言将存储在 `NEXT_LOCALE` cookie 中（有效期为1年），以便在会话之间记住选择。

| 操作 | 描述 | 何时可用 |
|--------|-------------|----------------|
| **Upgrade** | 在同一集合内切换至更高等级计划 | 企业已启用订阅更新 |
| **Downgrade** | 在同一集合内切换至更低等级计划 | 企业已启用订阅更新 |

### 计划变更的工作原理

1. 客户在门户中查看当前订阅
2. 根据产品集合显示可用的升级/降级选项
3. 客户选择新计划
4. 按比例分摊会被计算并（如适用）立即处理付款
5. 订阅被更新至新计划

<Info>
计划变更仅在同一集合内的产品之间可用。产品必须是订阅或基于使用量计费类型。
</Info>

### 企业控制

企业可在订阅设置中配置计划变更行为：

- **Allow Subscription Updates**：启用或禁用客户升级或降级其订阅的能力

## 订阅详情

当客户在任意活跃订阅上点击“Manage subscription”时，他们会进入订阅详情页面。该页面显示：

- **Plan details**：订阅名称、价格、续订日期以及有效期
- **Payment method**：连接到订阅的卡或支付方式，附有“Edit”按钮
- **Billing information**：姓名、电子邮件、电话号码和账单地址，附有“Edit”按钮
- **Billing history**：该订阅所有付款的详细表格
- **Cancel Subscription**：一个显眼的按钮，用于取消订阅

企业可以在订阅设置中配置门户订阅行为：

- **允许更新订阅**：启用或禁用客户升级或降级其订阅的功能
- **允许取消订阅**：启用或禁用客户取消其订阅的功能
- **允许暂停订阅**：启用或禁用客户暂停和恢复其订阅的功能

客户可以直接在订阅详情页取消订阅。点击“Cancel Subscription”会打开一个确认对话框，提供两个选项：

- **Cancel at next billing date**：订阅在当前计费期结束后自动取消。
- **Cancel now**：订阅立即取消。

<Frame>
    <img src="/images/customer-portal/cance-sub.png" alt="带有下一个计费日取消或立即取消选项的取消订阅对话框"/>
</Frame>

- **计划详情**：订阅名称、价格、续订日期和有效期
- **支付方式**：与订阅关联的卡或支付方式，以及“编辑”按钮
- **账单信息**：姓名、电子邮件、电话号码和账单地址，以及“编辑”按钮
- **账单历史记录**：此订阅的所有付款的详细表格
- **暂停**：暂停订阅的选项，在允许自助暂停时显示
- **取消订阅**：用于取消订阅的醒目按钮

客户可以通过点击支付方式旁的“Edit”按钮，在订阅详情页直接更新支付方式。此功能对于因付款失败而被暂停的订阅的重新激活尤为重要。

### 重新激活被暂停的订阅

当订阅因付款失败而被置于 `on_hold` 状态时，客户必须更新支付方式以重新激活。更新流程会自动：

1. **Creates a charge** 用于结清剩余欠款
2. **Generates an invoice** 用于该费用
3. **Processes the payment** 使用新支付方式处理付款
4. **Reactivates the subscription**，在付款成功后将其恢复至 `active` 状态

<Info>
自助取消功能由 **设置 → 订阅** 下的 **允许取消订阅** 设置控制，该设置默认启用。关闭后，取消订阅按钮将被禁用，并显示提示，要求客户联系您；门户中的两种取消路径——立即取消和在下一个账单日取消——都会被拒绝。已经安排取消的客户仍可撤销取消，因此可以选择继续订阅。您自行执行的取消操作不受影响。
</Info>

    <img src="/images/customer-portal/cance-sub.png" alt="取消订阅对话框，其中包含在下一个账单日取消或立即取消的选项" style={{ maxHeight: '500px', width: 'auto' }} />

### 取消原因

确认取消前，系统会询问客户 **“您为什么要取消？”**，并提示客户从预设列表中选择原因。该原因会存储在订阅中，并显示在 webhook payload 和 API 中，因此您可以分析流失原因并定制挽回流程。

<Frame>
    <img src="/images/customer-portal/cancellation-reasons.png" alt="取消对话框，其中“您为什么要取消？”下拉菜单显示了“价格太高”“缺少功能”和“其他”等原因" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

| Value | Customer-facing label |
|-------|----------------------|
| `too_expensive` | 价格太高 |
| `missing_features` | 缺少功能 |
| `switched_service` | 已改用其他服务 |
| `unused` | 使用频率不高 |
| `customer_service` | 客户服务质量差 |
| `low_quality` | 质量低 |
| `too_complex` | 过于复杂 |
| `other` | 其他 |

所选值会写入订阅的 `cancellation_feedback` 字段。还可以选择性地记录自由文本 `cancellation_comment`。

```typescript
// Read the captured feedback after a customer cancels
const subscription = await client.subscriptions.retrieve('sub_123');
console.log(subscription.cancellation_feedback); // e.g., "too_expensive"
console.log(subscription.cancellation_comment);  // e.g., "Switching to a competitor"
```

这两个字段也包含在 `subscription.cancelled` webhook payload 中，在通过 API 安排或执行取消操作时，您可以通过 `PATCH /subscriptions/{subscription_id}` 以编程方式填充这些字段。

<Tip>
将 `cancellation_feedback` 与 [Subscription Dunning](/features/recovery/subscription-dunning) 结合使用，以定制挽回邮件——例如，向因 `too_expensive` 取消的客户发送折扣码，向因 `missing_features` 取消的客户发送“缺少什么功能？”调查。
</Tip>

## 暂停订阅

暂停为客户提供了一个介于保留订阅和直接取消订阅之间的选择。暂停的订阅会停止计费，但会保留其计划和历史记录，因此客户稍后可以继续使用，而不必重新开始。

客户从订阅详情页面打开暂停对话框。对话框会显示当前计划，警告访问权限将立即结束，并说明账单日期将如何顺延。客户点击 **暂停订阅** 进行确认。

<Frame>
    <img src="/images/customer-portal/pause-subscription.png" alt="显示当前计划、访问权限将立即撤销的警告以及暂停确认按钮的暂停订阅对话框" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

客户会看到什么，以及实际会发生什么：

- **访问权限会立即停止。** 订阅包含的功能、下载内容和许可证密钥将停止工作，直到恢复订阅。
- **暂停没有结束日期。** 订阅会一直处于暂停状态，直到客户恢复订阅。
- **不会损失时间。** 下一个账单日期和续订日期都会向后顺延，顺延时长等于暂停时长。

恢复订阅的流程相同。订阅会恢复为 `active` 状态，并恢复访问权限。

<Info>
自助暂停由 **Settings → Subscriptions** 下的 **Allow Subscription Pause** 设置控制，且**默认禁用**。该设置关闭时，客户无法开始新的暂停；但已经处于暂停状态的客户仍然可以恢复自己发起的暂停。您从仪表板手动执行的暂停不受影响。
</Info>

完整的暂停行为，包括账单影响、用量结算和 webhooks。
</Card>

## 更新支付方式

客户可以直接在订阅详情页面中点击支付方式旁边的“编辑”来更新支付方式。对于重新激活因付款失败而处于暂停状态的订阅，此功能尤为重要。

### 重新激活处于暂停状态的订阅

当订阅因付款失败而进入 `on_hold` 状态时，客户必须更新支付方式才能重新激活订阅。更新过程会自动：

1. **为剩余欠款创建扣款**
2. **为扣款生成发票**
3. **使用新的支付方式处理付款**
4. **付款成功后将订阅重新激活为** `active` **状态**

<Warning>
处于 `on_hold` 状态的订阅不会自动续订。客户必须更新支付方式以结清欠款并重新激活订阅。
</Warning>

<Info>
成功更新 `on_hold` 订阅的支付方式后，客户会看到确认页面，并收到有关付款成功和订阅重新激活的电子邮件通知。
</Info>

### 支付方式更新流程

<Steps>
<Step title="Access subscription details">
在门户主页中，点击任意有效订阅上的“管理订阅”。
</Step>

<Step title="Click Edit on payment method">
点击支付方式旁边的“编辑”按钮，打开支付方式更新界面。
</Step>

<Step title="Select or add payment method">
选择现有的已保存支付方式，或安全输入卡片详细信息来添加新的支付方式。
</Step>

<Step title="Confirm changes">
确认更新。对于 `on_hold` 订阅，系统会自动为剩余欠款创建扣款。
</Step>

<Step title="Complete payment (if on hold)">
如果订阅处于暂停状态，客户将被重定向以完成剩余欠款的付款。付款成功后，订阅会自动重新激活。
</Step>

<Step title="Confirmation">
客户会收到支付方式已更新的确认信息；如适用，还会收到订阅已重新激活的确认信息。
</Step>
</Steps>

## Unified Customer Portal

除了面向特定企业的客户门户外，Dodo Payments 还在 [customer.dodopayments.com](https://customer.dodopayments.com) 提供 **Unified Customer Portal**，客户可以在其中查看和管理通过 Dodo Payments 向不同企业购买的所有产品和订阅。

    <img src="/images/changelog/unified-customer-portal.png" alt="Unified Customer Portal" style={{ maxHeight: '500px', width: 'auto' }} />

### Unified Portal 功能

- **跨企业可见性**：在一个位置查看来自任何 Dodo Payments 商家的所有购买记录和订阅
- **集中管理**：从单个仪表板管理不同企业的订阅
- **统一账单历史记录**：访问所有购买记录的发票和付款历史
- **单点登录**：使用电子邮件登录一次，即可访问所有 Dodo Payments 商家的购买记录

<Tip>
Unified Customer Portal 是面向特定企业的客户门户的补充。客户可以根据偏好使用品牌商家门户或统一门户。
</Tip>

## 故障排除

- **链接已过期**：生成并发送新的动态链接。
- **无法识别电子邮件**：要求客户使用与其购买记录关联的电子邮件
- **订阅处于暂停状态**：如果订阅处于暂停状态，客户必须通过门户更新支付方式，以结清欠款并重新激活订阅。更新过程会自动收取剩余欠款。
- **支付方式更新失败**：如果在更新 `on_hold` 订阅的过程中付款失败，订阅将继续处于暂停状态。客户可以尝试使用其他支付方式再次更新。
