<Note>
当您通过[自带处理器 (BYOP)](/features/byop)连接 **Adyen** 作为您自己的处理器时，本指南适用。如果您需要帮助，请[联系我们](mailto:founders@dodopayments.com)。
</Note>

## 启用原始卡数据访问

在 Dodo 通过 Adyen 路由付款之前，您的 Adyen 账户需要启用**原始卡数据访问**。Adyen 要求通过 PCI DSS 合规性来保护此访问。由于 **Dodo Payments 代表您处理原始卡数据**并且是**PCI DSS 一级合规**，您只需向 Adyen 提供**Dodo Payments 的合规证明 (AOC)**，无需您自己的认证。

<Card title="Dodo Payments PCI DSS Attestation of Compliance (AOC)" icon="file-shield" href="https://pub-2a89184e4c954b599464449d23f506bb.r2.dev/dodo-payments-pci-dss-aoc.pdf">
下载 Dodo Payments 的当前 AOC 并提交给 Adyen 支持以启用原始卡数据访问。
</Card>

联系 Adyen 支持以请求为您的商家账户开启原始卡数据访问，并附上上述 AOC。

## 您需要准备的事项

要在 **设置 → BYOP** 中连接 Adyen，请从您的 Adyen 客户端区域收集三个值：

| 值 | 来源 |
|-------|---------------------|
| **API 密钥** | 开发者 → API 凭证 |
| **商家账户** | 您的 Adyen 商家账户标识符 |
| **HMAC 密钥** | 在设置 webhook 时生成 |

<Info>
Adyen 将 **测试** (`ca-test.adyen.com`) 和 **实时** (`ca-live.adyen.com`) 凭证分开。在与您在 Dodo 中配置的模式匹配的环境中生成凭证。
</Info>

## 步骤 1：生成 API 密钥

<Steps>
<Step title="Open API credentials">
在 Adyen 客户端区域，转到 **开发者 → API 凭证**。您需要**管理 API 凭证**或**商家管理员**角色。
</Step>

<Step title="Select your credential">
选择 **支付**选项卡并选择您的凭证用户名（看起来像 `ws_123456@Company.YourCompanyAccount`）。
</Step>

<Step title="Generate the key">
转到 **服务器设置 → 认证**，打开 **API 密钥**选项卡，然后选择 **生成 API 密钥**。
</Step>

<Step title="Copy it immediately">
复制并安全储存密钥；离开页面后您将无法再次复制。新生成的密钥会立即生效，而以前的密钥在 24 小时内会继续工作。
</Step>
</Steps>

## 步骤 2：找到您的商家账户

您的**商家账户**是 Adyen 用于处理交易的账户标识符。它显示在客户端区域顶部的账户选择器中（例如，`YourCompany_ECOM`）。您需要将其粘贴到 Dodo 的**商家账户**字段中。

## 步骤 3：设置 webhook 和 HMAC 密钥

当您保存 Adyen 连接时，Dodo 会生成一个**Webhook Endpoint** URL。将其添加为 Adyen 中的一项 webhook，并生成一个 HMAC 密钥。您需要**商家管理员**或**商家技术整合人**角色。

<Steps>
<Step title="Create a webhook">
在客户端区域，转到 **开发者 → Webhooks** 并选择 **创建新 webhook**。从列表中选择为**标准 webhook**类型选择**添加**。
</Step>

<Step title="Configure the webhook">
- 输入**描述**。
- 切换**启用**，使其生效。
- 在**服务器配置**下，将 Dodo 生成的 **Webhook Endpoint** URL 粘贴到 **URL** 字段中（必须是 HTTPS 并且可公开访问）。
</Step>

<Step title="Generate the HMAC key">
在**安全性**下，在 **HMAC 密钥** 部分，选择 **生成**以创建新 HMAC 密钥。复制并安全储存它；稍后您将无法再次复制。然后选择 **保存配置**。
</Step>

<Step title="Paste the HMAC key into Dodo">
返回 **设置 → BYOP**，将 HMAC 密钥粘贴到**Webhook 签名密钥**字段中，以完成连接。

<Card title="Set up BYOP" icon="shuffle" href="/features/byop">
按照完整的自带处理器设置流程。
</Card>
</Step>
</Steps>

<Tip>
保存后，使用 Dodo 中的**验证连接**来对 Adyen 进行测试调用，并在上线前确认您的 API 密钥、商家账户和 HMAC 密钥是否有效。
</Tip>

## 常见问题解答

<AccordionGroup>
<Accordion title="What is the HMAC key for?">
Adyen 为每个 webhook 签名一个 HMAC 签名，以便接收者能够验证通知的完整性和来源。Dodo 使用您提供的 HMAC 密钥来验证来自您 Adyen 帐户的 webhooks。
</Accordion>

<Accordion title="I lost my API key or HMAC key, what now?">
创建后无法检索。请在 **开发者 → API 凭证**下生成新的 API 密钥，或在 webhook 设置中生成新的 HMAC 密钥，然后在 **设置 → BYOP** 中更新值。
</Accordion>

<Accordion title="Do test and live use the same credentials?">
不可以。请在匹配的环境（测试 `ca-test.adyen.com` 或实时 `ca-live.adyen.com`）中生成凭证，并在 Dodo 中的相应模式下进行配置。
</Accordion>
</AccordionGroup>
