<Info>
Framer 权限为付费客户解锁 Framer 模板 remix 链接。您将模板上传到 Dodo Payments，附加权限到产品，客户会收到可以将模板克隆到他们自己 Framer 帐户的 remix 链接。
</Info>

## 交付内容

- 您上传的 Framer 模板的唯一 remix 链接。
- 客户点击链接将模板 remix 到他们自己的 Framer 工作空间。
- 取消或退款后，remix 链接将失效。

常见用途包括付费 Framer 登陆页面模板、作品集工具包和组件库。

## 连接 Framer

首次创建模板权限时，Framer 会隐式连接。无需单独的 OAuth 步骤。

<Steps>
<Step title="Open Entitlements">
在您的 Dodo Payments 仪表板中，进入 **Entitlements** 并点击 **+**。
</Step>

<Step title="Pick Framer">
选择 **Framer Template** 作为集成。
</Step>

<Step title="Grab the remix link from Framer">
打开您的 Framer 项目。从左上菜单，进入 **File → Copy Remix Link**。这会生成一个公共 remix URL，允许任何人将项目克隆到他们自己的 Framer 帐户——这是 Dodo Payments 会与付费客户分享的链接。
<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">

<img src="/images/entitlements/framer/copy-remix-link.png" alt="Framer 文件菜单中高亮显示的 Copy Remix Link 选项" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

返回 Dodo Payments 仪表板，从 **Template** 下拉菜单中选择模板。首次为新模板执行此操作时，粘贴您复制的 remix 链接以注册。给权限一个**名称**，然后点击 **Create Entitlement**。

<img src="/images/entitlements/framer/create.png" alt="带有模板选择器和名称字段的 Framer 模板权限表单" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Dodo Payments 注册模板并返回一个 `framer_template_id`，您可以以编程方式引用。
</Step>
</Steps>

## 客户流程

1. 客户完成结账。
2. Dodo Payments 创建一个 `pending` 授权并分发一个与该客户绑定的唯一 remix 链接。
3. 一旦 remix 链接配置完成，授权转换为 `delivered`，链接将包括在客户的电子邮件和门户中。
4. 客户点击链接，登录 Framer，remix 模板。
5. 当授权被撤销时，remix 链接无效。但由于 Framer 不提供撤销方式，已经 remix 的副本会保留在客户的 Framer 帐户中。

## 所需配置

| 字段 | 必需 | 描述 |
|---|---|---|
| `framer_template_id` | 是 | 当您上传模板时返回的模板 ID。|

## 通过 API 创建

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Portfolio Kit',
  integration_type: 'framer',
  integration_config: {
    framer_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Portfolio Kit",
    integration_type="framer",
    integration_config={"framer_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Portfolio Kit"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFramer),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFramerConfigParam{
      FramerTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

参见 [`entitlement_grant.*` webhook 事件](/developer-resources/webhooks/intents/entitlement-grant)。Framer 授权到达 `pending`，并在配置 remix 链接后转换为 `delivered`。

## 故障排除

<AccordionGroup>
<Accordion title="Customer's remix link doesn't work">
remix 链接是一次性的并与客户绑定。如果他们在 remix 前清除了链接，请撤销授权并重新发布。
</Accordion>

这是预期现象。Framer 将 remix 视为客户自己的项目，一旦克隆；Dodo Payments 作废原始链接但无法删除客户帐户中的副本。
</Accordion>
</AccordionGroup>
