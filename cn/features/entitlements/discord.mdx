<Info>
Discord 权限会在支付客户的订阅激活或一次性购买完成时，将他们添加到您的服务器（并可选择分配角色）。取消、退款和计划更改会自动撤销角色。
</Info>

## 提供的内容

- 客户通过其交付邮件或客户门户中的 OAuth 链接连接其 Discord 账户。
- 一旦授权，Dodo Payments 会将其添加到您的服务器（或找到其现有会员身份）并分配您配置的角色。
- 如果您没有选择特定角色，仅授予服务器会员身份。

此集成非常适合于付费社区、支持者福利和分级访问频道。

## 客户流程

1. 客户完成结账。
2. Dodo Payments 创建一个状态为 `pending`，指向 Discord 的 `oauth_url` 的授权。
3. 客户收到一封带有“加入 Discord”按钮的邮件（OAuth 链接）。该链接也在他们的客户门户中可见。
4. 客户授权后，机器人将其添加到服务器并分配配置的角色。授权状态移动到 `delivered`。
5. 如果订阅被取消、暂停或过期，或者商家手动撤销，机器人将移除角色并将授权移动到 `revoked`。

 <Tip>
确保 Dodo Payments 机器人的角色位置在您授予的角色之上。Discord 会防止机器人分配高于自身的角色。
</Tip>

## 必需的配置

| 字段 | 必需 | 描述 |
|---|---|---|
| `guild_id` | 是 | Discord 服务器 ID。仪表板选择器为您完成此操作。 |
| `role_id` | 否 | 交付时分配的角色。省略表示仅服务器会员访问。 |

## 通过 API 创建

 <CodeGroup>

```typescript TypeScript theme={null}
import DodoPayments from 'dodopayments';

const client = new DodoPayments({
  bearerToken: process.env['DODO_PAYMENTS_API_KEY'],
  environment: 'test_mode',
});

const entitlement = await client.entitlements.create({
  name: 'Patrons Discord Role',
  integration_type: 'discord',
  integration_config: {
    guild_id: '123456789012345678',
    role_id: '987654321098765432',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Patrons Discord Role",
    integration_type="discord",
    integration_config={
        "guild_id": "123456789012345678",
        "role_id": "987654321098765432",
    },
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{

  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeDiscord),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigDiscordConfigParam{

      RoleID:  dodopayments.F("987654321098765432"),

```

## Webhooks

订阅 [`entitlement_grant.*` webhook 事件](/developer-resources/webhooks/intents/entitlement-grant) 以跟踪 Discord 授权：

- `entitlement_grant.created` 触发，带有 `status: "pending"` 和客户授权的 `oauth_url`。
- `entitlement_grant.delivered` 在角色分配后触发。
- `entitlement_grant.revoked` 在角色移除时触发。

## 故障排除

 <AccordionGroup>
<Accordion title="Customer never sees the role assigned">
授予在客户完成 OAuth 流程前，状态为 `pending`。检查权限的授权列表并确认客户是否点击了 OAuth 链接。如有需要，重新发送交付邮件。
</Accordion>

 <Accordion title="Grant moves to failed with permission errors">
确保 Dodo Payments 机器人停留在服务器中，具有 `Manage Roles` 权限，并且位置高于被分配的角色。重新保存权限会重新运行验证。
</Accordion>

 <Accordion title="Customer cancelled but still has the role">
Discord 会立即传播角色移除，但客户的本地 Discord 客户端可能缓存。他们应重新连接或刷新；服务器端状态是正确的。
</Accordion>
</AccordionGroup>
