跟踪客户从您的门店到结账再到购买完成的旅程。Dodo Payments 与 Google Analytics 4、Google Tag Manager 和 Meta Pixel 集成，为您托管的所有页面提供全面的分析。

<Info>
一旦您在仪表盘中添加了跟踪 ID，您的商店、结账页面和客户门户上的分析跟踪将自动启用。
</Info>

<Warning>
客户浏览器中的广告拦截器可能会导致部分访客无法正常工作分析跟踪。
</Warning>

## 快速入门

<Steps>
<Step title="打开商业设置">
  在您的 Dodo Payments 仪表盘中，导航到 **设置** 并滚动到 **分析** 部分。
</Step>

<Step title="启用您的跟踪平台">
  启用您想要使用的分析平台并输入您的跟踪 ID：
  - **Google Analytics**：输入您的测量 ID（格式：`G-XXXXXXXXXX`）
  - **Google Tag Manager**：输入您的容器 ID（格式：`GTM-XXXXXXX`）
  - **Meta Pixel**：输入您的 Pixel ID（数字，10-20 位）
</Step>

<Step title="保存您的设置">
  单击 **保存** 以应用您的跟踪配置。
</Step>

<Step title="验证跟踪">
  访问您的商店或创建一个测试结账以验证事件是否在您的分析仪表盘中被跟踪。
</Step>
</Steps>

## Google Analytics 4

[Google Analytics 4](https://marketingplatform.google.com/about/analytics/) 提供全面的网站分析和电子商务跟踪功能。借助 Dodo Payments 的集成，您可以跟踪客户从浏览商店到完成购买的完整旅程。

### 添加您的 Google Analytics 测量 ID

1. 在 Google Analytics 中，转到 **管理员** → **数据流** → 选择您的网络流
2. 复制 **测量 ID**（以 `G-` 开头）
3. 在 Dodo Payments 仪表盘中，转到 **设置** → **分析**
4. 启用 **Google Analytics** 并粘贴您的测量 ID
5. 单击 **保存**

<Tip>
如果您还没有 Google Analytics 财产，请按照 [Google 的设置指南](https://support.google.com/analytics/answer/9304153) 创建一个。
</Tip>

### 在 Google Analytics 中跟踪的事件

我们在您的托管商店和结账页面上跟踪以下事件。事件数据包括产品信息、交易总额和货币，随每个事件发送。

#### 门店事件

| 事件 | 描述 |
|-------|-------------|
| `view_item_list` | 当门店页面加载产品时触发 |
| `select_item` | 当客户点击产品以开始结账时触发 |

#### 结账事件

| 事件 | 描述 |
|-------|-------------|
| `view_item` | 当结账页面加载时触发 |
| `view_cart` | 当结账加载并选择变体时触发 |
| `apply_discount`* | 当有效的折扣代码成功应用时触发 |
| `remove_discount`* | 当折扣代码被移除时触发 |
| `add_payment_info` | 当客户提交支付表单时触发 |
| `purchase` | 当支付成功时触发 |

<Note>
`apply_discount` 和 `remove_discount` 是自定义事件，不包含在 [标准 Google Analytics 电子商务事件](https://support.google.com/analytics/answer/9267735) 中。
</Note>

### 使用 GA4 进行叠加/内嵌结账

为了跟踪嵌入在您自己网站上的叠加或内嵌结账中的 Google Analytics 事件，您需要在网站上安装 Google Analytics 跟踪代码。

安装后，所有上述列出的跟踪事件将自动发送到您的 Google Analytics 账户中，无需额外配置。

## Google Tag Manager

[Google Tag Manager](https://marketingplatform.google.com/about/tag-manager/) 允许您管理营销和分析标签，而无需修改代码。通过 GTM 部署的标签将在所有 Dodo Payments 托管页面上触发。

### 添加您的 GTM 容器 ID

1. 在 Google Tag Manager 中，复制您的 **容器 ID**（以 `GTM-` 开头）
2. 在 Dodo Payments 仪表盘中，转到 **设置** → **分析**
3. 启用 **Google Tag Manager** 并粘贴您的容器 ID
4. 单击 **保存**

<Info>
使用 GTM 时，您可以在 GTM 容器中直接配置额外的跟踪（例如 Google Ads 转化）。Dodo Payments 集成注入了 GTM 脚本和 noscript 备用，以确保最大兼容性。
</Info>

### 使用 GTM 进行叠加/内嵌结账

对于嵌入在您网站上的叠加或内嵌结账，请在您自己的网站上安装 GTM。结账将继承您的 GTM 配置，并在嵌入的框架内触发事件。

## Meta Pixel

[Meta Pixel](https://www.facebook.com/business/tools/meta-pixel/) 跟踪客户在您商店中的行为，以测量您 Facebook 和 Instagram 广告活动的有效性。从广告点击到购买完成进行转化跟踪。

### 添加您的 Meta Pixel ID

1. 在 [Meta 事件管理器](https://www.facebook.com/events_manager2/) 中，创建或选择您的 Pixel
2. 复制 **Pixel ID**（数字，通常为 15-16 位）
3. 在 Dodo Payments 仪表盘中，转到 **设置** → **分析**
4. 启用 **Meta Pixel** 并粘贴您的 Pixel ID
5. 单击 **保存**

<Tip>
如果您还没有创建 Pixel，请遵循 Meta 的 [Pixel 设置指南](https://www.facebook.com/business/help/952192354843755)。
</Tip>

### 使用 Meta Pixel 跟踪的事件

我们跟踪以下事件，这些事件会出现在您的 [Meta 事件管理器](https://www.facebook.com/events_manager2/) 中。事件数据包括内容 ID、值和货币，随每个事件发送。

<Note>
事件可能不会立即出现在 Meta 事件管理器中 - 可能会有几分钟的延迟。
</Note>

#### 门店事件

| 事件 | 描述 |
|-------|-------------|
| `PageView` | 当门店页面加载时触发 |
| `ViewContent` | 当门店加载产品时触发 |
| `InitiateCheckout` | 当客户点击产品以开始结账时触发 |

#### 结账事件

| 事件 | 描述 |
|-------|-------------|
| `PageView` | 当结账页面加载时触发 |
| `AddToCart` | 当结账加载并选择变体时触发 |
| `ApplyDiscount`* | 当有效的折扣代码成功应用时触发 |
| `RemoveDiscount`* | 当折扣代码被移除时触发 |
| `AddPaymentInfo` | 当客户提交支付表单时触发 |
| `Purchase` | 当支付成功时触发 |

<Note>
`ApplyDiscount` 和 `RemoveDiscount` 是自定义事件，不包含在 [Meta 的标准事件](https://developers.facebook.com/docs/meta-pixel/reference#standard-events) 中。
</Note>

## 完整的事件参考

此表格展示了 Google Analytics 4 和 Meta Pixel 上跟踪的所有事件：

| 触发器 | GA4 事件 | Meta Pixel 事件 | 位置 |
|---------|-----------|------------------|----------|
| 门店页面加载 | `view_item_list` | `ViewContent` | 门店 |
| 客户点击产品 | `select_item` | `InitiateCheckout` | 门店 |
| 结账页面加载 | `view_item` | `AddToCart` | 结账 |
| 购物车查看/变体选择 | `view_cart` | - | 结账 |
| 折扣代码应用 | `apply_discount` | `ApplyDiscount` | 结账 |
| 折扣代码移除 | `remove_discount` | `RemoveDiscount` | 结账 |
| 提交支付表单 | `add_payment_info` | `AddPaymentInfo` | 结账 |
| 支付成功 | `purchase` | `Purchase` | 结账 |

## 平台覆盖

分析跟踪可在不同的 Dodo Payments 界面上使用：

| 界面 | Google Analytics 4 | Google Tag Manager | Meta Pixel |
|---------|-------------------|-------------------|------------|
| 门店 | 是 | 是 | 是 |
| 结账（托管） | 是 | 是 | 是 |
| 结账（叠加/内嵌）* | 是 | 是 | 是 |
| 客户门户 | 是 | 是 | 否 |

<Info>
*对于叠加和内嵌结账，请在您自己的网站上安装跟踪代码以获得完整的归因。嵌入结账的事件将自动被跟踪。
</Info>

## 事件数据包含

每个跟踪事件都包括相关的电子商务数据，以帮助您分析客户行为：

### 产品数据
- 产品 ID
- 产品名称
- 价格
- 货币
- 数量

### 交易数据（购买事件）
- 交易/支付 ID
- 总金额
- 税额
- 货币
- 应用的折扣

### 客户数据
- 客户 ID（对于回头客）
- 电子邮件（根据需要已加密以保护隐私）

## 最佳实践

<AccordionGroup>
<Accordion title="测试您的集成">
在添加您的跟踪 ID 后，访问您的门店并完成测试结账，以验证事件是否出现在您的分析仪表盘中。使用 Google Analytics 实时报告或 Meta 事件管理器的测试事件功能。
</Accordion>

<Accordion title="使用 UTM 参数">
在您的营销链接中添加 UTM 参数，以跟踪哪些活动推动转化。Dodo Payments 在整个结账流程中保留 UTM 参数。
</Accordion>

<Accordion title="设置转化目标">
在 Google Analytics 中，为 `purchase` 创建转化事件，以跟踪您的转化率。在 Meta 广告管理器中，使用 `Purchase` 事件作为活动的优化目标。
</Accordion>

<Accordion title="启用扩展电子商务">
如果使用 Google Tag Manager，考虑为详细的漏斗分析和产品表现指标设置扩展电子商务报告。
</Accordion>
</AccordionGroup>

## 疑难解答

<AccordionGroup>
<Accordion title="事件未出现在 Google Analytics 中">
- 验证您的测量 ID 是否正确（格式：`G-XXXXXXXXXX`）
- 检查 Google Analytics 实时报告 - 事件首先会出现在那里
- 确保在您的 Dodo Payments 设置中启用了切换
- 等待几分钟，因为可能会有处理延迟
- 在隐身窗口中测试以排除广告拦截器
</Accordion>

<Accordion title="事件未出现在 Meta 事件管理器中">
- 验证您的 Pixel ID 是否正确（数字，10-20 位）
- 使用 Meta Pixel Helper 浏览器扩展进行调试
- 检查事件管理器中的测试事件选项卡
- 事件可能需要几分钟才能出现
- 测试时确保禁用广告拦截器
</Accordion>

<Accordion title="GTM 标签未触发">
- 确认您的容器 ID 是否正确（格式：`GTM-XXXXXXX`）
- 使用 GTM 预览模式进行标签触发的调试
- 检查您的 GTM 容器中触发器是否配置正确
- 确保容器已发布（而不仅仅是草稿）
</Accordion>

<Accordion title="叠加/内嵌结账未跟踪">
- 首先在您自己的网站上安装跟踪代码
- 确保在结账叠加打开之前加载跟踪
- 检查浏览器控制台是否存在任何 JavaScript 错误
- 验证如果使用 GA4，则跨域跟踪是否已配置
</Accordion>

<Accordion title="购买事件显示错误金额">
- 金额以最小货币单位（分）发送
- 验证您的分析工具是否配置为显示正确的货币
- 检查税费是否按预期包含/排除
</Accordion>
</AccordionGroup>
