## Adaptive Currency

Adaptive Currency 允许客户使用首选的本地货币付款，从而提升信任度和转化率。

### 工作原理

1. **启用**：从 **Settings → Business** 中启用 Adaptive Currency
2. **选择**：客户可以直接在结账页面切换货币
3. **应用 PPP**：如果产品已启用 [Purchasing Power Parity](/features/purchasing-power-parity)，国家/地区百分比会降低基础价格
4. **转换**：价格（或经过 PPP 调整的价格）会按照实时 FX 汇率转换为客户的货币
5. **取整**：如果已启用 [Charm Pricing](/features/charm-pricing)，转换后的金额会取整为类似 49.99 的简洁尾数
6. **显示**：付款前会透明地显示最终应付金额

## 自动税费计算

系统会根据客户的账单地址自动计算税费，确保符合 GST、VAT 和 sales tax 要求，无需手动设置。

### 税费计算方式

<Steps>
<Step title="Location Detection">
  系统会根据客户所在国家（以及适用时的地区）应用税务规则。
</Step>

<Step title="Dynamic Updates">
  以下情况发生时，税额会自动更新：
  - 国家/地区发生变化
  - 地址更新
</Step>

<Step title="Transparent Display">
  付款前会清晰显示最终税费明细。
</Step>
</Steps>

<Tip>
税费计算完全自动化。对于标准数字商品和 SaaS 产品，无需手动配置。
</Tip>

## 企业税号支持

对于已注册的企业，结账页面允许客户输入 Business Tax ID（例如 VAT/GST number）。

### 输入税号后会发生什么

- 实时验证税务资格
- 应用适用的税收豁免或 reverse-charge 规则
- 结账页面上的税额即时更新

## 折扣码

客户可以直接在结账页面使用你在 dashboard 中创建的折扣码或促销码。

### 结账体验

1. 客户输入折扣码
2. 系统即时验证折扣码
3. 清晰显示更新后的价格和节省金额

在产品上启用 [Purchasing Power Parity](/features/purchasing-power-parity) 后，折扣将应用于经过 PPP 调整的价格，而不是基础价格。

<Frame>
  <img src="/images/checkout/c4.png" alt="结账页面上的折扣码输入" style={{ maxHeight: '500px', width: '70%' }}/>
</Frame>

### API 集成

预先应用一个或多个可叠加的折扣码，或启用折扣输入字段：

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  discount_codes: ['WELCOME20'], // Pre-apply one or more codes (max 20, applied in order)
  feature_flags: {
    allow_discount_code: true // Shown by default; set to false to hide the field
  },
  return_url: 'https://yoursite.com/return'
});
```

<Info>
`discount_codes` 接受最多包含 20 个代码的数组，并按顺序叠加应用。单数形式的 `discount_code` 字段已弃用，但仍可使用——现有集成无需立即更改。为使用叠加功能和更丰富的响应结构，请在方便时迁移到 `discount_codes`。
</Info>

## 智能地址收集

结账支持灵活的地址输入方式，以加快完成速度。

### 可用选项

| 选项 | 描述 |
|--------|-------------|
| **Google 地址自动填充** | 通过自动补全快速选择 |
| **手动输入** | 完整地址可完全由用户控制 |
| **国家/地区选择** | 驱动税务和合规逻辑 |
| **最小地址** | 仅收集国家/地区（以及税务所需的 ZIP 邮政编码）——请参阅 [最小地址模式](#minimal-address-mode) |

<Tip>
地址收集在速度、准确性和全球覆盖范围之间取得平衡，从而在确保合规的同时最大限度地提高转化率。
</Tip>

### 最小地址模式

为了最大限度地提高转化率，请启用最小地址收集，以减少结账阻力。当 `minimal_address` 设置为 `true` 时，结账页面只会收集：

- **国家/地区** — 税务确定始终需要
- **ZIP/邮政编码** — 仅在销售税、VAT 或 GST 计算所需的地区收集

所有其他地址字段（街道、城市、州/省）都会跳过，从而显著加快结账完成速度。

<Frame>
  <img src="/images/changelog/minimal-address.png" alt="最小地址模式，仅在结账页面显示国家/地区和 ZIP/邮政编码字段" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  minimal_address: true,
  return_url: 'https://yoursite.com/return'
});
```

<Info>
完整地址收集仍为默认设置。对于不需要完整账单详细信息的数字产品和 SaaS 流程，请启用 `minimal_address`。
</Info>

<Card title="Minimal Address Reference" icon="address-card" href="/developer-resources/checkout-session#request-body">
  请参阅 Checkout Sessions API 指南中完整的 `minimal_address` 参数参考。
</Card>

## 电话号码收集

使用结账会话功能标志控制结账页面是否显示电话号码字段，以及该字段是否为必填项。

| 标志 | 默认值 | 行为 |
|------|---------|----------|
| `allow_phone_number_collection` | `true` | 在结账表单中显示电话号码字段 |
| `require_phone_number` | `false` | 将电话号码字段设为必填项（表单验证会强制要求非空值） |

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_abc', quantity: 1 }],
  feature_flags: {
    allow_phone_number_collection: true,
    require_phone_number: true
  },
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
`require_phone_number: true` 需要 `allow_phone_number_collection: true`。禁用电话号码收集但将电话号码设为必填项时，API 会拒绝此类会话。
</Warning>

<Tip>
对于 B2B SaaS、受监管行业，或任何需要经过验证的支持、欺诈审核或合规联系渠道的流程，请使用 `require_phone_number`。
</Tip>

## 自定义字段

通过定义自定义表单字段，在结账期间收集客户的其他信息。这适合收集公司名称、团队规模、推荐来源或任何其他特定于业务的信息。

### 可用字段类型

| 类型 | 描述 |
|------|-------------|
| `text` | 单行文本输入 |
| `number` | 数字输入 |
| `email` | 带验证的电子邮件地址 |
| `url` | 带验证的 URL |
| `date` | 日期选择器 |
| `dropdown` | 从预定义选项中选择 |
| `boolean` | 是/否切换开关 |

### 示例

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
客户响应会自动包含在 webhook payload（`payment.succeeded`、`subscription.active`）以及通过 `custom_field_responses` 数组返回的 API 响应中。每个结账会话最多可以定义 5 个自定义字段。
</Info>

## 集合结账

产品集合提供统一的结账体验，客户可以在一次结账中查看并选择多个相关产品（例如 Starter、Pro 和 Enterprise 计划）。

### 工作原理

1. **显示所有产品**：客户可以看到集合中的每个有效产品
2. **预选第一个产品**：系统会自动选择集合中的第一个产品
3. **比较选项**：客户可以在选择前比较价格和功能
4. **单项选择**：选择产品后，结账会按照标准付款流程继续

### 创建集合结账

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
使用 `product_collection_id` 时，请传入空的 `product_cart` 数组。无法在创建会话时预先应用折扣码。
</Warning>

## 结账会话配置

使用 Checkout Sessions API 控制结账行为：

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_codes: ['PROMO10'],
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  cancel_url: 'https://yoursite.com/pricing', // Optional: where to redirect on cancel
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
付款后，客户会被重定向到你的 `return_url`，系统会自动附加查询参数——包括 `payment_id` 或 `subscription_id`、`status`、`email` 以及 `license_key`（如适用）。完整列表请参阅 [Checkout Sessions 指南](/developer-resources/checkout-session#request-body)。
</Info>

<Card title="Design & Theme Customization" icon="palette" href="/features/design">
  从控制台以可视化方式配置主题，包括预构建主题、字体排版、颜色和实时预览。
</Card>

<Info>
本节介绍使用 `customization.theme_config` 进行 **server-side API** 主题配置。如果你使用的是 **Checkout SDK**（叠加式或内嵌式结账），请参阅 [Overlay Checkout](/developer-resources/overlay-checkout#theme-customization) 中的主题自定义部分，该部分使用 camelCase 属性（例如使用 `bgPrimary`，而不是 `bg_primary`）。
</Info>

### 主题配置选项

| 属性 | 描述 |
|----------|-------------|
| `light` | 浅色模式的颜色配置 |
| `dark` | 深色模式的颜色配置 |
| `font_primary_url` | 主字体的 URL |
| `font_secondary_url` | 次要字体的 URL |
| `font_size` | 字体大小：`xs`、`sm`、`md`、`lg`、`xl`、`2xl` |
| `font_weight` | 字体粗细：`normal`、`medium`、`bold`、`extraBold` |
| `radius` | UI 元素的边框半径（例如 `4px`、`0.5rem`、`8px`） |
| `pay_button_text` | 付款按钮的自定义文本（例如 “Complete Purchase”、“Subscribe Now”） |

### 颜色配置（浅色/深色模式）

每种模式（`light` 和 `dark`）都支持以下颜色属性：

| 属性 | 描述 |
|----------|-------------|
| `bg_primary` | 主要背景颜色 |
| `bg_secondary` | 次要背景颜色 |
| `text_primary` | 主要文本颜色 |
| `text_secondary` | 次要文本颜色 |
| `text_placeholder` | 文本占位符颜色 |
| `text_error` | 错误文本颜色 |
| `text_success` | 成功文本颜色 |
| `border_primary` | 主要边框颜色 |
| `border_secondary` | 次要边框颜色 |
| `button_primary` | 主要按钮背景颜色 |
| `button_primary_hover` | 主要按钮悬停颜色 |
| `button_secondary` | 次要按钮背景颜色 |
| `button_secondary_hover` | 次要按钮悬停颜色 |
| `button_text_primary` | 主要按钮文本颜色 |
| `button_text_secondary` | 次要按钮文本颜色 |
| `input_focus_border` | 输入框聚焦边框颜色 |

<Info>
所有颜色字段都接受标准 CSS 颜色格式：
- Hex：`#fff`、`#ffffff`、`#ffffffff`
- RGB/RGBA：`rgb(255, 255, 255)`、`rgba(255, 255, 255, 0.5)`
- HSL/HSLA：`hsl(120, 100%, 50%)`、`hsla(120, 100%, 50%, 0.5)`
- 命名颜色：`red`、`blue`、`transparent`
</Info>

### 示例

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
无需指定所有颜色属性。未指定的属性将使用默认主题值。
</Tip>
