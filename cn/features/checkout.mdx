## 自适应货币

自适应货币允许客户以他们首选的本地货币付款，从而提高信任度和转化率。

### 工作原理

1. **启用**：在您的业务设置中启用自适应货币
2. **选择**：客户可以在结账时直接切换货币
3. **转换**：价格使用实时外汇汇率动态转换
4. **显示**：最终应付金额在付款前透明显示

## 自动税务计算

税务将根据客户的账单地点自动计算，确保符合 GST、增值税和销售税要求，无需手动设置。

### 税务计算如何工作

<Steps>
<Step title="位置检测">
  根据客户的国家（在适用的情况下包括地区）应用税务规则。
</Step>

<Step title="动态更新">
  税额会在以下情况下自动更新：
  - 国家更改
  - 地址更新
</Step>

<Step title="透明显示">
  最终税务细目在付款前清晰显示。
</Step>
</Steps>

<Tip>
税务计算是完全自动化的。对于标准数字商品和 SaaS 产品，无需手动配置。
</Tip>

## 商业税号支持

对于注册企业，结账允许客户输入其商业税号（例如增值税/GST号）。

### 输入税号时会发生什么

- 税务资格实时验证
- 应用相关的税收豁免或反向收费规则
- 税额在结账时即时更新

## 自定义字段

通过定义自定义表单字段在结账时收集客户的额外信息。这对于收集公司名、团队规模、推荐来源或任何其他业务特定信息非常有用。

### 可用字段类型

| 类型 | 描述 |
|------|-------------|
| `text` | 单行文本输入 |
| `number` | 数字输入 |
| `email` | 带验证的电子邮件地址 |
| `url` | 带验证的 URL |
| `date` | 日期选择器 |
| `dropdown` | 从预定义选项中选择 |
| `boolean` | 是/否切换 |

### 示例

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
客户响应将自动包含在 webhook 有效负载 (`payment.succeeded`, `subscription.created`) 和 API 响应中，通过 `custom_field_responses` 数组。您可以为每个结账会话定义最多 5 个自定义字段。
</Info>

## 收集结账

产品集合允许统一的结账体验，客户可以在单个结账中查看和选择多个相关产品（例如，Starter、Pro、Enterprise 计划）。

### 工作原理

1. **显示所有产品**：客户看到集合中的每个活跃产品
2. **首个产品预选中**：集合中的第一个产品自动选中
3. **比较选项**：客户可以在选择之前比较定价和功能
4. **单一选择**：选择产品后，结账将按标准支付流程进行

### 创建集合结账

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
使用 `product_collection_id` 时，传递一个空的 `product_cart` 数组。折扣码不能在会话创建时预先应用。
</Warning>

## 结账会话配置

使用结账会话 API 控制结账行为：

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_code: 'PROMO10',
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
付款后，客户将自动重定向到您的 `return_url`，并附加自动生成的查询参数——包括 `payment_id` 或 `subscription_id`、`status`、`email` 和 `license_key`（如适用）。请参阅 [结账会话指南](/developer-resources/checkout-session#request-body) 获取完整列表。
</Info>

## 结账主题自定义

使用 `customization.theme_config` 参数自定义结账页面外观，以匹配您的品牌，通过 API 创建结账会话。配置颜色、字体、边框半径和按钮文本，以适用于明亮和黑暗模式。

<Frame>
  <img src="/images/checkout/theme-example.png" alt="自定义主题结账页面"/>
</Frame>

<Info>
本节涵盖使用 `customization.theme_config` 的 **服务器端 API** 主题配置。如果您使用 **结账 SDK**（覆盖或内联结账），请参见 [Overlay Checkout](/developer-resources/overlay-checkout#theme-customization) 或 [Inline Checkout](/developer-resources/inline-checkout#theme-customization) 中的主题自定义部分，这些部分使用 camelCase 属性（例如，`bgPrimary` 而不是 `bg_primary`）。
</Info>

### 主题配置选项

| 属性 | 描述 |
|----------|-------------|
| `light` | 明亮模式的颜色配置 |
| `dark` | 黑暗模式的颜色配置 |
| `font_primary_url` | 主要字体的 URL |
| `font_secondary_url` | 次要字体的 URL |
| `font_size` | 字体大小：`xs`、`sm`、`md`、`lg`、`xl`、`2xl` |
| `font_weight` | 字体粗细：`normal`、`medium`、`bold`、`extraBold` |
| `radius` | UI 元素的边框半径（例如， `4px`、`0.5rem`、`8px`） |
| `pay_button_text` | 自定义文本，例如 "完成购买"、"立即订阅" |

### 颜色配置（明亮/黑暗模式）

每种模式（`light` 和 `dark`）支持以下颜色属性：

| 属性 | 描述 |
|----------|-------------|
| `bg_primary` | 背景主颜色 |
| `bg_secondary` | 背景次颜色 |
| `text_primary` | 文本主颜色 |
| `text_secondary` | 文本次颜色 |
| `text_placeholder` | 文本占位符颜色 |
| `text_error` | 文本错误颜色 |
| `text_success` | 文本成功颜色 |
| `border_primary` | 边框主颜色 |
| `border_secondary` | 边框次颜色 |
| `button_primary` | 主按钮背景颜色 |
| `button_primary_hover` | 主按钮悬停颜色 |
| `button_secondary` | 次按钮背景颜色 |
| `button_secondary_hover` | 次按钮悬停颜色 |
| `button_text_primary` | 主按钮文本颜色 |
| `button_text_secondary` | 次按钮文本颜色 |
| `input_focus_border` | 输入聚焦边框颜色 |

<Info>
所有颜色字段均接受标准 CSS 颜色格式：
- Hex: `#fff`、`#ffffff`、`#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`、`rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`、`hsla(120, 100%, 50%, 0.5)`
- 命名颜色: `red`、`blue`、`transparent`
</Info>

### 示例

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
您不需要指定所有颜色属性。任何未指定的属性将使用默认主题值。
</Tip>
