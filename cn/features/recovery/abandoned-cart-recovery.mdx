<Info>
购物车恢复（ACR）检测未完成或失败的结账并发送自动电子邮件序列以带回顾客。结合可选折扣激励以最大化恢复率。
</Info>

## 什么是购物车恢复？

ACR 自动识别开始但未完成结账的顾客——无论是付款失败还是在付款之前离开——并发送恢复邮件序列将他们带回。

- **付款失败**：顾客尝试付款但被拒或出错
- **未完成结账**：顾客访问结账但从未尝试付款

## ACR 如何工作

<Steps>
<Step title="Detection">
我们会扫描超过 60 分钟的付款且未成功的情况。这包括失败的付款和顾客从未尝试付款的结账。
</Step>

<Step title="Classification">
每个被遗弃的结账都根据原因进行分类：
- **支付失败**：顾客尝试付款但失败
- **结账未完成**：顾客访问了结账但从未尝试过付款
</Step>

<Step title="Email Sequence">
根据分类，系统在配置间隔内发送最多 3 封恢复邮件。每封邮件包含一个独特的恢复链接。
</Step>

<Step title="Recovery">
当顾客点击恢复链接时，他们将被带到显示原始购物车的恢复页面。他们可以在新的结账会话中完成付款。
</Step>
</Steps>

## 状态生命周期

每个被遗弃的结账都会经历以下状态：

| 状态 | 描述 |
|--------|-------------|
| `abandoned` | 结账被检测为已遗弃，尚未发送任何邮件 |
| `recovering` | 至少发送了一封恢复邮件 |
| `recovered` | 顾客通过恢复链接完成了付款 |
| `exhausted` | 所有邮件发送完毕没有恢复，或更新的结账取代了这一结账 |
| `opted_out` | 顾客取消订阅恢复邮件 |

### 全局设置

| 设置 | 描述 | 默认 |
|---------|-------------|---------|
| **启用** | ACR 的主切换开关 | 关闭 |
| **启用折扣** | 自动生成恢复邮件的折扣代码 | 关闭 |
| **折扣百分比** | 将应用于该顾客结账的百分比折扣 | 0 |
| **折扣有效天数** | 自动生成的折扣码保持有效的天数 | 5 |

### 电子邮件序列

ACR 支持两种电子邮件序列 — **付款失败**和**结账未完成** — 每个序列最多可配置 3 封邮件。

<Frame caption="ACR email sequence configuration">
<img src="/images/recovery/acr-email-config.png" alt="显示主题，正文，时间和启用切换的电子邮件序列编辑器" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

| 设置 | 描述 |
|---------|-------------|
| **启用** | 在不删除的情况下切换单个邮件打开或关闭 |
| **延迟** | 发现遗弃后多长时间发送此邮件 |
| **主题** | 带变量占位符的邮件主题行 |
| **正文** | 带变量占位符的 HTML 邮件正文 |
| **回复至** | 顾客回复的邮箱地址 |

**默认邮件时间：**

| 邮件号 | 默认延迟 |
|---------|---------------|
| 1 | 1 小时 |
| 2 | 24 小时 |
| 3 | 72 小时 |

## 恢复折扣

启用折扣时，ACR 自动为每个被遗弃的结账生成一个独特的单次折扣码。折扣：

- 限制在原始结账的产品上
- 具有可配置的过期期限
- 限制为一次兑换
- 在仪表板折扣列表中隐藏（仅限内部使用）

<Tip>
从适度的折扣（5-10%）开始测试转化影响，然后再增加。即使是小的激励也能显著提高恢复率。
</Tip>

## 顾客恢复体验

当顾客点击电子邮件中的恢复链接时，他们会回到
他们的原始结账会话。页面显示他们留下的产品，
如果配置了折扣码的话一起显示。

## 边缘情况

| 场景 | 行为 |
|----------|----------|
| 顾客在下一封邮件之前完成购买 | 发送时间检测到恢复；如果符合条件，结账标记为已恢复 |
| 顾客开始新的结账 | 旧的遗弃结账被标记为 `exhausted` |
| 顾客在已经恢复后点击“付款” | 恢复页面显示确认付款已完成 |
| 顾客取消订阅 | 被遗弃的结账标记为 `opted_out`；不再发送进一步的邮件 |

## 最佳实践

- **从默认开始**：默认的邮件时间和主题已针对常见的恢复模式进行优化。在您有基线数据后进行自定义。
- **个性化邮件**：使用模板变量使邮件感觉个性化且与顾客相关。
- **监控分析**：跟踪邮件的恢复率以确定哪些消息推动了最多转换。禁用表现不佳的邮件。
- **战略性地使用折扣**：从小开始（5-10%）以在测试转化影响时保护利润。
- **保持邮件简洁**：恢复邮件应简短且以行动为导向。明确的行动号召比冗长的解释效果更好。

<Info>
ACR 设计为一旦启用即可自动工作。使用默认设置开始，监控您的分析，然后根据性能数据进行迭代。
</Info>
