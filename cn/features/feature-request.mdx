## **请求新功能**

如果您有能够提升 Dodo Payments 使用体验的功能想法，可以在我们的反馈门户直接提交功能请求。

<img src="/images/feature-request/Feature.png" alt="功能请求" style={{ maxHeight: '500px', width: 'auto' }} />

- **如何请求功能**:
    1. 访问我们的[反馈门户](https://feedback.dodopayments.com/)。
    2. 点击 **“发布想法”** 或 **“提交功能请求”**。
    3. 提供以下信息：
        - **功能名称**：为您的功能想法提供一个简明的标题。
        - **功能描述**：简要说明功能的重要性及其对您的业务帮助。
    4. 提交请求。
- **有效请求的提示**：
    - 语言清晰简洁。
    - 突出功能的业务影响。
    - 提供示例（如果适用）。
    - 包括展示价值的使用案例。

## **为现有功能请求投票**

我们优先考虑对多数商家有益的功能。您可以在我们的反馈门户浏览现有功能请求，并为您认为有价值的请求投票。

- **如何投票**:
    1. 访问我们的[反馈门户](https://feedback.dodopayments.com/)。
    2. 浏览提交的请求列表。
    3. 点击您支持的功能旁的 **上投票** 按钮 (👍)。
- **投票的好处**：
    - 影响您关心的功能的开发优先级。
    - 帮助我们的团队识别广泛需求的功能。
    - 在您投票的功能发布时获得通知。

## **查看产品路线图**

通过我们的公共路线图了解功能开发状态。

- **路线图功能**：
    - **计划中**：已获批并安排开发的功能。
    - **进行中**：我们的团队正在开发的功能。
    - **已完成**：已成功实现并上线的功能。
- **如何访问**：
    - 访问我们的[反馈门户](https://feedback.dodopayments.com/)。
    - 导航到 **路线图** 部分查看按状态分类的功能。
    - 浏览功能类别及其当前状态。
    - 按状态、类别筛选或搜索特定功能。
