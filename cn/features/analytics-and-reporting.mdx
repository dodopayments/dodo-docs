## 企业级分析

主分析仪表板提供整个业务的全面洞察。可通过侧边栏的**主页**访问。

仪表板分为六个标签页，每个有其自己的过滤器：

<CardGroup cols={3}>
<Card title="Revenue" icon="chart-line">
毛利/净利收入、支付活动、增长和主要国家。
</Card>
<Card title="Customers" icon="users">
ARPU、活跃客户、新旧客户对比以及最高客户。
</Card>
<Card title="Subscriptions" icon="rectangle-list">
当前MRR、预期ARR、活跃订阅和MRR阶梯图。
</Card>
<Card title="Retention" icon="arrows-rotate">
客户和收入流失率、趋势和群体留存。
</Card>
<Card title="Success Rate" icon="circle-check">
支付和退款成功率及失败原因分析。
</Card>
<Card title="Recovery" icon="life-ring">
支付重试、账单催款和被遗弃购物车恢复表现。
</Card>
</CardGroup>

### 过滤与自定义

大多数标签支持以下过滤器：

- **时间段：** 今天、昨天、这周/上周、这个月/上个月、今年/去年、所有时间或自定义日期范围。
- **产品：** 分析范围限制为单个产品。
- **产品类型：** 一次性与订阅（客户和留存标签）。
- **支付方式：** 通过支付方式过滤成功率标签。

<Tip>
使用过滤器深入到特定产品、时间段或支付方式，以获取目标洞察。
</Tip>

### 收入标签

追踪您的收入和支付活动，以了解收入趋势并识别表现最佳的市场。

<Frame caption="Total revenue and 30-day trend">
  <img src="/images/analytics/revenue.png" alt="总收入和收入趋势图表" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

- **毛利/净利收入切换：** 使用**毛利/净利**下拉菜单切换标题收入数字、30日图表、月度柱和值国家排行的毛利和净利值。
  - **毛利收入：** 扣除前的总收入。
  - **净利收入：** 退款和损失或接受争议后的实际收入，提供真正的业务表现概况。
- **收入（最近30天）：** 一个帮助您发现收入峰值或低谷的趋势图表。在累积和每日视图之间切换。
- **支付次数，总退款数，收到的付款数:** 选定期间的支持活动指标。

<Frame caption="Top 5 revenue-generating countries and growth rate">
  <img src="/images/analytics/revenue-2.png" alt="主要收入国家和增长率图表" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

- **增长率：** 跟踪月度收入增长（订阅、非订阅和总收入）以衡量业务发展势头。
- **地理洞察：** 以毛利或净利收入排名可视化您的前五大收入国家。

<Tip>
使用这些洞察，将您的营销和产品工作重点放在高表现区域和增长期。
</Tip>

### 客户标签

分析客户获取、留存和消费模式，以优化客户策略。

<Frame caption="ARPU, active customers, customer split, and top customers">
  <img src="/images/analytics/customer.png" alt="客户分析：ARPU，活跃客户，客户分裂，顶级客户" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

- **每用户收入（ARPU）：** 了解每位客户平均贡献多少。**毛利/净利**切换在毛利和净利ARPU之间转换。
- **活跃客户：** 查看有多少客户正在与您的业务互动，包括那些有活跃订阅的客户。
- **客户分裂：** 立即查看**新客户与回头客**的比例。
- **顶级客户（按收入）：** 识别您最高消费的客户以进行目标参与（尊重毛利/净利切换）。

<Tip>
监控ARPU和客户分裂以优化您的留存和获取策略。
</Tip>

### 订阅标签

监控您的经常性收入，并了解您的月度经常性收入（MRR）如何随时间变化。

<Frame caption="Revenue Breakdown dashboard showing projected ARR, MRR breakdown, and growth rates">
  <img src="/images/analytics/revenue-breakdown.png" alt="收入拆分仪表板显示预计ARR、MRR拆分和增长率" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

三个标题图块总结您的订阅业务：

- **当前MRR：** 当前月份的月度经常性收入。
- **预计ARR：** 年度经常性收入预计（当前MRR × 12）。
- **活跃订阅：** 当前活跃的订阅数量。

**MRR图表**按月可视化经常性收入组成，以下是对应的细分指标：

| 指标 | 描述 |
|--------|-------------|
| **新MRR** | 本月获得的新订阅收入 |
| **扩展MRR** | 现有订阅者升级或增加计划的附加收入 |
| **缩减MRR** | 现有订阅者降低（但未完全取消）的收入损失 |
| **流失MRR** | 取消订阅的收入损失 |
| **净新增MRR** | 净结果：新MRR + 扩展MRR − 缩减MRR − 流失MRR |

每个细分卡都包含一个趋势迷你图和与上个月相比的百分比变化。

<Note>
MRR计算考虑了**并行订阅**（一个客户持有多个活跃计划贡献它们的总和）并根据每个订阅已付费用期间分配收入。提前支付几个月的订阅将继续在其付费期间贡献MRR。
</Note>

### 留存标签

监控客户留存和流失模式。

<Frame caption="Retention Analytics showing churn rates and trends">
  <img src="/images/analytics/retention.png" alt="留存分析仪表板显示客户流失率、收入流失率和流失率趋势" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

- **客户流失率：** 取消订阅的客户百分比。
- **收入流失率：** 取消和降级导致的收入损失百分比。现在包括**一次性支付收入**及经常性收入，因此客户和收入流失覆盖相同人口。
- **流失率趋势：** 随时间对客户和收入流失进行历史跟踪。
- **用户留存矩阵：** 显示不同时间段的客户留存率群体分析。

### 成功率标签

监控支付和退款成功率，以快速识别和解决交易问题。

<Frame caption="Payment/refund success rates, failure reasons, and payment breakdown">
  <img src="/images/analytics/success-rate.png" alt="支付和退款成功率，失败原因和支付分解" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

- **支付成功率：** 跟踪支付尝试的成功百分比。
- **退款成功率：** 监控成功处理的退款数量。
- **失败原因：** 快速识别常见问题（例如，过期卡，不支持的方法），按客户端和网络端错误划分。

  <Card title="Transaction Failure Reference" icon="circle-exclamation" href="/api-reference/transaction-failures">
    获取所有可能的交易失败代码及其原因。
  </Card>
- **支付分解：** 可视化成功和失败交易的分布。

<Warning>
如果您注意到成功率下降或失败激增，请审查失败原因并及时解决以减少收入损失。
</Warning>

### 恢复标签

跟踪Dodo Payments为您恢复的收入，通过自动重试、账单催款邮件及遗弃购物车恢复。

<Frame caption="Recovery analytics showing payment retries, dunning, and abandoned cart recovery">
  <img src="/images/recovery/recovery-analytics.png" alt="恢复分析仪表板显示重试、催款和遗弃购物车恢复指标" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

恢复标签分为三组：

- **支付重试：** 通过自动重试支付恢复失败的订阅续订。显示重试尝试、成功重试、重试成功率、保存的订阅及“按尝试重试”图表的尝试与成功比。
- **催款：** 通过一系列提醒邮件恢复失败的订阅支付。显示催款条目、恢复收入、发送的邮件、平均恢复时间，恢复率饼图，以邮件为单位的恢复率。
- **遗弃购物车恢复：** 恢复在完成结账前离开的购物者。显示遗弃结账、恢复率、恢复收入、平均恢复时间，按产品和邮件的恢复率。

<Card title="Recovery Features" icon="life-ring" href="/features/recovery/overview">
了解更多关于配置支付重试、催款和遗弃购物车恢复。
</Card>

## 产品级分析

除了企业范围的指标，您还可以查看**每个产品**的详细分析。导航到 **产品 > [选择一个产品]** 可以访问该产品的专用分析仪表板。

<Frame caption="Product analytics overview showing revenue summary and trend chart">
  <img src="/images/product-analytics/overview.png" alt="产品分析概览标签，显示总收入、成功支付和收入趋势图表" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

产品分析仪表板分为五个标签：

<CardGroup cols={3}>
<Card title="Overview" icon="chart-line">
收入汇总，趋势图和交易历史。
</Card>
<Card title="Customers" icon="users">
按花费排名的顶级客户及完整分解表。
</Card>
<Card title="Retention" icon="arrows-rotate">
客户和收入流失率及趋势分析。
</Card>
<Card title="Subscribers" icon="rectangle-list">
所有订阅的状态和账单详细信息。
</Card>
<Card title="MRR" icon="chart-bar">
月度经常性收入拆解——新订阅、扩展、流失和净。
</Card>
</CardGroup>

所有标签支持**日期过滤**（默认为所有时间），以便您可以专注于任何期间。

### 概览标签

概览标签提供产品财务表现的高层次快照。

- **总收入：** 该产品产生的累计收入。
- **成功支付次数：** 成功交易的总次数。
- **收入趋势图：** 一个30天的折线图，显示随时间的收入。使用**显示每日**按钮在累积和每日视图之间切换。

在图表下方，一个**交易**表列出了该产品的每笔支付：

| 列 | 描述 |
|--------|-------------|
| 支付ID | 交易的唯一标识符 |
| 状态 | `Successful` 或 `Failed` |
| 金额 | 带货币的交易金额 |
| 日期（UTC） | 交易的时间戳 |
| 支付方式 | 卡，UPI或其他方法 |
| 退款 | 发起退款的选项 |

## 页面高亮图块

仪表板中的许多列表页面现在在顶部显示**高亮图块**，让您无需打开完整的分析仪表板即可一目了然地看到关键摘要指标。这些图块遵循页面的活动过滤器。

| 页面 | 高亮图块 |
|------|-----------------|
| **产品** | 所有产品、活跃产品、已归档产品 |
| **附加商品** | 所有附加商品、活跃附加商品、与产品关联的 |
| **集合** | 所有集合、活跃集合、已归档集合 |
| **订阅** | 活跃订阅、暂停、已取消 |
| **支付** | 成功支付、支付量、失败支付 |
| **退款** | 成功退款、退款量、失败退款 |
| **争议** | 新建争议、赢得、接受、失败 |

<Note>
“活跃”的产品、附加商品、集合和计量表示至少参与过一次成功支付。
</Note>

## 报告

导航到仪表板中的**报告**部分以访问报告套件。每个报告都可以过滤（按支付方式、状态、产品类型、失败类型、争议状态或防碰适用的货币）并下载为CSV。

可用的报告包括：

- **支付报告：** 包含所有处理过的支付的详细记录，包括账单地址、卡详细信息、美元等价金额、结算详情、费用和失败代码。
- **退款报告：** 包含详细退款信息的全面退款活动日志。
- **付款报告：** 您账户已支付款项的摘要，并按总分类帐事件详细说明费用。
- **按产品销售报告：** 每个产品的销售表现，总销售量和净收入。
- **支付失败报告：** 包含失败原因（客户端vs网络端）的支付尝试失败摘要。
- **客户报告：** 按客户组织的支付、退款和争议摘要。
- **争议报告：** 包含解决状态和证据详细信息的支付争议摘要。
- **账薄报告：** 包含事件类型、金额和参考的详细余额分类账条目。

## 最佳实践
