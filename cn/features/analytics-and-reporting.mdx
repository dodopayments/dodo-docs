## 介绍

Dodo Payments 的 **分析与报告** 仪表板使您能够监控业务表现，了解客户行为，并做出数据驱动的决策。访问实时指标，可视化趋势，并导出详细报告——所有这些都可以通过一个直观的界面完成。

<CardGroup cols={2}>
<Card title="业务层分析" icon="chart-pie-simple">
跟踪您整个业务的综合收入、客户、留存率和交易健康状况。
</Card>
<Card title="产品层分析" icon="chart-mixed" href="#product-level-analytics">
深入了解各个产品的表现——收入、客户、流失、订阅者和月经常性收入（MRR）。
</Card>
<Card title="交易健康" icon="circle-check">
监控付款和退款成功率，并识别失败原因。
</Card>
<Card title="可导出报告" icon="file-csv">
下载自定义日期范围内的付款、退款和支付报告。
</Card>
</CardGroup>

## 业务层分析

主分析仪表盘提供有关您整个业务的全面洞察。您可以从侧边栏的 **业务 > 分析** 访问它。

### 收入分析

跟踪您的收入和付款活动，以了解收入趋势并识别您表现最佳的市场。

<Frame caption="总收入和30天趋势">
  <img src="/images/analytics/revenue.png" alt="总收入和收入趋势图表" />
</Frame>

- **总收入：** 立即查看您的历史总收入和最近趋势。
- **收入趋势：** 30天图表帮助您发现收入的波动或下降。

<Frame caption="前5个收入产生国和增长率">
  <img src="/images/analytics/revenue-2.png" alt="前收入国家和增长率图表" />
</Frame>

- **增长率：** 跟踪每月收入增长，以衡量业务势头。
- **地理洞察：** 可视化您前5个收入来源国。

<Tip>
利用这些洞察，专注于高效地区的市场营销和产品运营。
</Tip>

### 收入细分

跟踪您的经常性收入指标，提供详细细分：

- **预计年度经常性收入（ARR）：** 年度经常性收入预测及趋势分析
- **每月经常性收入（MRR）细分和增长率：** 每月经常性收入分析及环比增长指标
- **新增MRR图：** 新客户收入获取的可视化表示
- **扩展MRR图：** 跟踪现有客户的升级和扩展带来的收入增长
- **流失MRR图：** 监控因客户取消和降级而损失的收入
- **净新增MRR图：** 结合新增、扩展和流失MRR的净收入影响

<Frame caption="收入细分仪表盘，显示预计ARR、MRR细分和增长率">
  <img src="/images/analytics/revenue-breakdown.png" alt="收入细分仪表盘，显示预计ARR、MRR细分和增长率" />
</Frame>

### 留存分析

监控客户留存和流失模式：

- **客户流失率：** 取消订阅的客户百分比
- **收入流失率：** 由于取消和降级而损失的收入百分比
- **流失率趋势：** 随时间变化的客户和收入流失模式历史跟踪
- **用户留存矩阵：** 通过不同时间段展示的客户留存率的队列分析

<Frame caption="留存分析，显示流失率和趋势">
  <img src="/images/analytics/retention.png" alt="留存分析仪表盘，显示客户流失率、收入流失率和流失率趋势" />
</Frame>

### 客户分析

分析客户获取、留存和消费模式，以优化您的客户策略。

<Frame caption="ARPU、活跃客户、客户分布和顶级客户">
  <img src="/images/analytics/customer.png" alt="客户分析：ARPU、活跃客户、客户分布、顶级客户" />
</Frame>

- **ARPU（每用户平均收入）：** 理解每个客户的平均贡献。
- **活跃客户：** 查看多少客户参与了您的业务。
- **客户分布：** 立即查看新客户与回访客户的比率。
- **顶级客户：** 确定您最高消费的客户，以进行针对性互动。

<Tip>
监控ARPU和客户分布，以优化您的留存和获取策略。
</Tip>

### 交易成功与失败

监控付款和退款成功率，以快速识别和解决交易问题。

<Frame caption="付款/退款成功率、失败原因和付款细分">
  <img src="/images/analytics/success-rate.png" alt="付款和退款成功率、失败原因和付款细分" />
</Frame>

- **付款成功率：** 跟踪成功付款尝试的百分比。
- **退款成功率：** 监控成功处理的退款数量。
- **失败原因：** 快速识别常见问题（例如，卡过期、不支持的方法）。

  <Card title="交易失败参考" icon="circle-exclamation" href="/api-reference/transaction-failures">
    获取所有可能的交易失败代码及其原因。
  </Card>
- **付款细分：** 可视化成功和失败交易的分布。

<Warning>
如果您注意到成功率下降或失败激增，请查看失败原因并及时处理，以最小化收入损失。
</Warning>

### 过滤与定制化

您可以按以下条件过滤分析数据：
- **产品类型**（一次性支付与订阅）
- **日期范围**（可自定义）
- **付款方式**

<Tip>
使用过滤器深入了解特定产品、时间段或付款方式，获取有针对性的洞察。
</Tip>

## 产品层分析

除了业务层面的指标，您还可以查看 **每个产品** 的详细分析。导航到 **产品 > [选择一个产品]** 以访问该产品的专用分析仪表盘。

<Frame caption="产品分析概览，显示收入摘要和趋势图">
  <img src="/images/product-analytics/overview.png" alt="产品分析概览标签，包含总收入、成功付款和收入趋势图" />
</Frame>

产品分析仪表盘分为五个标签：

<CardGroup cols={3}>
<Card title="概览" icon="chart-line">
收入摘要、趋势图和交易历史。
</Card>
<Card title="客户" icon="users">
按消费排名的顶级客户和详细分解表。
</Card>
<Card title="留存" icon="arrows-rotate">
客户和收入流失率及其趋势分析。
</Card>
<Card title="订阅者" icon="rectangle-list">
所有订阅及其状态和计费细节。
</Card>
<Card title="MRR" icon="chart-bar">
每月经常性收入细分——新增、扩展、流失和净。
</Card>
</CardGroup>

所有标签都支持 **日期过滤器**（默认设置为所有时间），以便您聚焦于任何时间段。

### 概览标签

概览标签提供该产品财务表现的高水平快照。

- **总收入：** 由该产品产生的累计收入。
- **成功付款的数量：** 成功交易的总数。
- **收入趋势图：** 显示收入随时间变化的30天折线图。通过 **显示日常** 按钮切换累积和每日视图。

在图表下方，**交易** 表列出了与该产品相关的每一笔付款：

| 列 | 描述 |
|--------|-------------|
| 付款ID | 交易的唯一标识符 |
| 状态 | `Successful` 或 `Failed` |
| 金额 | 交易金额及货币 |
| 日期（UTC） | 交易时间戳 |
| 付款方式 | 使用的卡、UPI或其他方法 |
| 退款 | 启动退款的选项 |

<Frame caption="交易表，显示该产品的付款历史">
  <img src="/images/product-analytics/overview-transactions.png" alt="产品交易表，包含付款ID、状态、金额和退款操作" />
</Frame>

使用 **按状态过滤** 按钮将列表缩小为成功或失败交易。

### 客户标签

查看谁在购买该产品，及他们的消费情况。

<Frame caption="本月排名前三的客户，展示领奖台排名和客户表">
  <img src="/images/product-analytics/customers.png" alt="客户标签显示按收入排名的前三客户，含详细分解表" />
</Frame>

- **本月顶级客户：** 视觉领奖台突出您 **前三名客户**，按总消费排名，显示收入金额、姓名和电子邮件。
- **客户表：** 所有客户的详细分解，包含客户ID和该产品的总收入。

### 留存标签

了解该产品如何留住其订阅者。

<Frame caption="客户和收入流失率，及趋势分析">
  <img src="/images/product-analytics/retention.png" alt="留存标签显示客户流失率、收入流失率和流失率趋势图" />
</Frame>

- **客户流失率：** 取消的订阅者百分比。
- **收入流失率：** 由于取消和降级而损失的收入百分比。
- **流失率趋势：** 同时跟踪这两个指标的双线图，有助于您发现趋势并采取纠正措施。

### 订阅者标签

与该产品相关的所有订阅的完整列表。

<Frame caption="订阅者表，显示所有订阅的状态和计费细节">
  <img src="/images/product-analytics/subscribers.png" alt="订阅者标签，包含订阅ID、客户电子邮件、状态、开始日期和下次计费信息" />
</Frame>

| 列 | 描述 |
|--------|-------------|
| 订阅ID | 订阅的唯一标识符 |
| 客户电子邮件 | 订阅者的电子邮件地址 |
| 状态 | `Active`, `Failed`, `On hold` 或 `Pending` |
| 产品名 | 此订阅所属的产品 |
| 开始日期 | 订阅开始的日期 |
| 下次计费日期 | 即将到来的续订日期 |
| 下次计费金额 | 下次续订的到期金额（不含税） |

### MRR标签

对您的产品的每月经常性收入的详细细分。

<Frame caption="每月经常性收入堆叠条形图，显示每月收入组成">
  <img src="/images/product-analytics/mrr.png" alt="MRR标签，堆叠条形图显示按月的新增、扩展和流失MRR" />
</Frame>

该 **MRR图** 以堆叠条形图的形式可视化您的经常性收入组成情况，按月显示。

在图表下方，四个指标卡提供详细洞察：

<Frame caption="详细MRR细分，展示新增、扩展、流失和净新增MRR">
  <img src="/images/product-analytics/mrr-breakdown.png" alt="MRR细分，显示新增MRR、扩展MRR、流失MRR和净新增MRR，附带趋势图" />
</Frame>

| 指标 | 描述 |
|--------|-------------|
| **新增MRR** | 这个月通过新增订阅获得的收入，包括环比变化 |
| **扩展MRR** | 现有订阅者升级或增加计划带来的额外收入 |
| **流失MRR** | 由于取消或降级订阅而损失的收入 |
| **净新增MRR** | 净结果：新增MRR + 扩展MRR − 流失MRR |

每个卡片均包括一个趋势迷你图和相较于上个月的百分比变化指示器。

## 报告

导航到 **业务 > 报告** 以访问报告套件。

可用报告包括：

- **付款报告：** 所有处理付款的详细记录，附带交易状态跟踪
- **退款报告：** 所有退款活动的全面日志及详细退款信息
- **支付报告：** 汇总支付到账户的情况
- **产品销售报告：** 销售表现洞察，包含收入与业务增长指标
- **付款失败报告：** 失败付款尝试的汇总及失败原因
- **客户报告：** 按客户组织的付款汇总
- **争议报告：** 付款争议摘要及解决状态
- **账户汇总报告：** 完整的账户概览与总结

<Frame caption="报告仪表盘，显示可用报告类型">
  <img src="/images/analytics/reports.png" alt="报告2.0仪表盘，显示各种报告类型" />
</Frame>

### 支付报告

详细的支付报告提供了各支付的费用和交易明细的清晰可见性。您可以在 **业务 > 支付** 中访问这些报告。

<Frame caption="支付报告，详细费用和交易分解">
  <img src="/images/analytics/payout.png" alt="支付报告仪表盘，显示详细支付信息" />
</Frame>

### 下载报告

<Steps>
<Step title="打开报告部分">
在仪表盘中导航到 <strong>报告</strong> 区域。
</Step>
<Step title="选择报告类型和日期范围">
选择您所需的报告（付款、退款、支付），并指定日期范围。
</Step>
<Step title="下载报告">
点击 <strong>下载</strong> 以将报告导出为CSV格式。
<Check>
您的报告将保存到您的设备。
</Check>
</Step>
</Steps>

## 最佳实践

<Tip>
- 定期审查您的分析，以早期发现趋势和异常。
- 使用过滤器比较不同产品、时间段或地域的表现。
- 深入分析产品层面来了解哪些产品驱动了最高收入，哪些产品的流失率最高。
- 如果数据看起来不正确或缺失，首先检查您的过滤器和日期范围设置。
</Tip>

<Warning>
如果您注意到持续的不一致或缺失数据，请联系 <a href="mailto:support@dodopayments.com">support@dodopayments.com</a> 获取帮助。
</Warning>
