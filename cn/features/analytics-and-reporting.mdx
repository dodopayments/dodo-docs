## Home

**Home** 是侧边栏中的登录页，包含两个部分：**Today** 和 **Your overview**。

### Today

<Frame caption="Today: your day's pulse, hour by hour">
  <img src="/images/analytics/home-today.png" alt="Home Today view with an hourly volume chart, cash position, and next payout tiles" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

按小时显示当天的业务脉搏。

- **Headline chart:** 在 **Net volume** 和 **Gross volume** 之间切换（默认显示 Net volume），按小时绘制，并与昨天同一时间的曲线进行对比。
- **Cash Position:** 当前钱包余额和下一次 payout 日期。

<Note>
两张卡片都会显示信息提示框（ⓘ）和“Updated Xs ago”时间戳，让您始终了解数据的新鲜程度。
</Note>

### Your Overview

<Frame caption="Your overview: a fully customizable set of metric cards">
  <img src="/images/analytics/home-overview.png" alt="Home Your overview view with customizable cards for revenue by country, payouts received, top customers by spend, and refunds" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

完全可自定义——使用 **Customize** 选择、重新排列和移除卡片。

- **Default cards:** Net volume、Gross volume、Payments、Top customers by spend、New customers、Revenue by country 和 Refunds；此外，一次性/按用量计费商户还包括 **Average order value**，订阅商户则包括 **MRR** 和 **Net New MRR**。
- **Controls:**
  - **Period:** Daily/Weekly 或自定义范围。
  - **Compare:** Previous period 或 previous month（默认开启）。
  - **Product:** 单个产品或产品组。

## Analytics

从侧边栏访问 **Analytics**，它位于 **Home** 正下方，用于分析整个业务。Analytics 分为六个选项卡，每个选项卡都有自己的筛选条件。

<CardGroup cols={3}>
<Card title="Revenue" icon="chart-line">
Gross/net volume、payout、退款、争议和热门市场。
</Card>
<Card title="Customers" icon="users">
活跃客户和新客户、ARPU、热门客户以及建模 LTV。
</Card>
<Card title="Subscriptions" icon="rectangle-list">
MRR、Projected ARR、活跃订阅以及完整的 MRR 明细。
</Card>
<Card title="Retention" icon="arrows-rotate">
客户和收入流失、NRR/GRR、cohort 以及试用转化率。
</Card>
<Card title="Success Rate" icon="circle-check">
支付和退款成功率以及失败原因分析。
</Card>
<Card title="Recovery" icon="life-ring">
支付重试、催收以及弃购恢复表现。
</Card>
</CardGroup>

### Filtering & Customization

每个选项卡都有自己的筛选栏：

- **时间范围：** 预设范围 — **今天**、**过去 7 天**、**过去 30 天**、**本月至今**、**本季度至今**、**过去 6 个月**、**全部时间** — 或自定义日期范围，并支持 **每日/每周** 分组。新建仪表板默认使用 **过去 30 天**。
- **比较：** 上一时段或上个月（默认开启）。**全部时间** 不支持比较，因为没有更早的时间窗口可供比较。
- **产品：** 可在收入、订阅和留存选项卡中使用。产品支持多选，默认为 **全部**。

您的日期范围和比较选择会按业务记忆并同步到您的个人资料，因此切换业务、稍后返回，或在其他设备上登录时，每个业务都会保留您上次使用的时间窗口。

<Tip>
使用筛选器深入查看特定产品、时间段或支付方式，以获取有针对性的洞察。
</Tip>

### 收入选项卡

<Frame caption="Revenue tab: gross/net volume, payouts, and refunds">
  <img src="/images/analytics/revenue-tab.png" alt="显示总交易额、净交易额、已收款项和退款卡片及趋势图表的收入选项卡" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

跟踪您的收入、收款和争议活动，以了解收入趋势并识别表现最佳的市场。使用 **Gross/Net** 下拉菜单，在总额和净额之间切换标题数值、图表和国家排名。

| 指标 | 描述 |
|--------|-------------|
| **总交易额** | 该时段内所有成功付款的收费总额，未扣除费用、退款或争议款项。 |
| **净交易额** | 净交易额 = 总交易额 − 费用 − 退款 − 损失的争议款项。 |
| **收到的打款** | 打款 = 符合条件的销售额 − 税费 − 费用 − 退款 − 拒付。 |
| **退款率** | 退款率 = 退款金额 ÷ 总交易额。 |
| **争议** | 主要指标是按总额计算的拒付率：每笔收到的拒付都会计入，因此之后胜诉或被撤回的拒付不会降低该比率（银行卡组织正是以此评估风险）。胜诉 / 败诉 / 待处理会以数量显示，作为上下两个时段比较的参考。拒付率 = 收到的拒付 ÷ 付款次数。 |
| **付款次数** | 状态为 Successful 的付款数量。不包括进行中、失败和未发起的尝试。 |
| **平均订单金额** | AOV = 收入 ÷ 订单数量，涵盖一次性产品和按用量计费的产品。 |
| **按产品划分的收入** | 归因于各个产品的总收入，按从高到低排序。 |
| **按国家划分的收入** | 根据客户的账单国家/地区，将收入归因到各个国家/地区；以全宽卡片显示，旁边配有世界地图和按排名排列的国家/地区列表。颜色越深表示收入越高。排名前 150 的国家/地区会单独列出，其余国家/地区合并为一行“其他”。 |

### 客户选项卡

<Frame caption="Customers tab: active and new customers, ARPU, and top customers">
  <img src="/images/analytics/customers-tab.png" alt="显示活跃客户、新客户、ARPU 和按消费金额排名的顶级客户的客户选项卡" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

分析客户获取、留存和消费模式，以优化您的客户策略。

| 指标 | 描述 |
|--------|-------------|
| **活跃客户** | 在该时段内任何时间进行过付款或持有有效订阅的客户。 |
| **新客户** | 在该时段内首次成功向您付款的客户。 |
| **ARPU** | ARPU = 收入 ÷ 活跃客户数。 |
| **高价值客户** | 按该时段内的收入对客户进行排名，从高到低排列。每个条目使用客户姓名标识；如果没有记录姓名，则使用电子邮件地址。 |
| **新客户与回头客** | 新客户 = 在该时段内首次购买。回头客 = 在更早的时段曾向您购买。 |
| **模型估算 LTV** | 估算客户流失前产生的收入。 |

### 订阅选项卡

监控您的经常性收入，并了解月度经常性收入（MRR）如何随时间变化。

| 指标 | 描述 |
|--------|-------------|
| **MRR** | 预计一个月产生的经常性收入，所有计划均换算为月度金额（年度计划按 1/12 计）。不包括一次性支付。 |
| **预计 ARR** | 预计 ARR = 当前 MRR × 12。 |
| **净新增 MRR** | 净新增 MRR = 新增 + 扩张 − 收缩 − 流失。 |
| **活跃订阅** | 正在计费的订阅，包括仍处于试用期的订阅。 |
| **新增 MRR** | 该期间全新订阅带来的新增 MRR。 |
| **扩张 MRR** | 现有客户升级或购买附加项带来的额外 MRR。 |
| **收缩 MRR** | 现有客户转为更低价计划但仍保持订阅时损失的 MRR。 |
| **流失 MRR** | 客户在该期间取消订阅时损失的 MRR。 |

<Note>
MRR 会计算**并行订阅**（按客户求和），并根据每个订阅的付费有效期按比例计算。
</Note>

### 留存选项卡

<Frame caption="Retention tab: churn rates, retention matrix, and NRR/GRR">
  <img src="/images/analytics/retention-tab.png" alt="显示用户留存群组矩阵、客户流失率、收入流失率和净收入留存率的留存选项卡" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

监控客户留存和流失模式。

| 指标 | 描述 |
|--------|-------------|
| **用户留存矩阵** | 按注册月份（群组）对客户分组，然后显示每个群组在之后每个月仍保持活跃的客户占比。留存率（第 k 月）= 第 k 月仍活跃的群组客户数 ÷ 群组规模。 |
| **客户流失率** | 该期间内取消订阅的期初订阅者占比，旁边显示流失客户数量。客户流失率 = 流失订阅者 ÷ 期初订阅者。 |
| **收入流失率** | 收入流失率 = 流失 MRR ÷ 期初 MRR，其中期初 MRR 是现有客户在该期间开始时（即上一期间结束时）的经常性收入。 |
| **净收入留存率（NRR）** | 包括升级，因此可能超过 100%。NRR =（期初 MRR + 扩张 − 收缩 − 流失）÷ 期初 MRR。 |
| **总收入留存率（GRR）** | 不包括升级，因此最高为 100%。GRR =（期初 MRR − 收缩 − 流失）÷ 期初 MRR。 |
| **试用转化率** | 试用转化率 = 已转化试用数 ÷ 该期间结束的试用数。仅当您提供试用时显示。 |

### 成功率选项卡

<Frame caption="Success Rate tab: payment and refund success rates with failure analysis">
  <img src="/images/analytics/success-rate-tab.png" alt="显示支付成功率、支付明细、支付失败原因以及按支付方式划分的成功率的成功率选项卡" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

监控支付和退款成功率，以快速识别并解决交易问题。

| 指标 | 描述 |
|--------|-------------|
| **支付成功率** | 只有处理器或网络失败会影响该指标；客户可修复的失败（例如卡号错误或卡片过期）会从分母中排除。支付成功率 = 成功次数 ÷（尝试次数 − 客户可修复的失败次数）。 |
| **支付明细** | 将尝试分为总数、成功、失败（网络）、失败（客户）和未发起。 |
| **支付失败原因** | 按原因细分支付失败。 |
| **按支付方式** | 按每种方式（卡、钱包、UPI、BNPL）统计：成功率 = 成功次数 ÷ 尝试次数；交易量 = 成功金额。 |
| **结账次数** | 客户开始的结账会话数量，无论是否完成。 |
| **退款成功率** | 已发起退款中成功处理的比例。 |

<Card title="Transaction Failure Reference" icon="circle-exclamation" href="/api-reference/transaction-failures">
获取所有可能的交易失败代码及其原因。
</Card>

<Warning>
如果您发现成功率下降或失败次数激增，请查看失败原因并及时处理，以最大限度减少收入损失。
</Warning>

### 恢复选项卡

<Frame caption="Recovery tab: retries, dunning, and abandoned cart recovery">
  <img src="/images/analytics/recovery-tab.png" alt="显示恢复概览、按流程划分的恢复情况、支付重试和催收指标的恢复选项卡" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

跟踪 Dodo Payments 通过自动重试、催收邮件和弃购恢复代表您挽回了多少收入。

| 指标 | 描述 |
|--------|-------------|
| **恢复概览** | 该期间恢复的收入及整体恢复率。恢复率 = 已恢复金额 ÷ 可恢复的失败金额；硬拒绝（账户已关闭）不计入可恢复金额。 |
| **按流程划分的恢复情况** | 将恢复的收入按重试、催收和弃购进行细分。 |
| **支付重试** | 重试次数、成功重试次数、重试成功率和挽救的订阅数。 |
| **催收** | 催收记录、发送的邮件、恢复的收入、恢复率和平均恢复时间。 |
| **弃购** | 弃购结账、恢复的收入、恢复率和平均恢复时间。 |

| 列 | 描述 |

| Payment ID | 交易的唯一标识符 |
| Status | `Successful` 或 `Failed` |
| Amount | 包含货币的交易金额 |
| Date (UTC) | 交易时间戳 |
| Payment Method | 使用的卡、UPI 或其他方式 |
| Refund | 发起退款的选项 |

</Frame>

| 指标 | 描述 |
|--------|-------------|
| **新增 MRR** | 本月获取的新订阅带来的收入，并显示环比变化 |
| **扩张 MRR** | 现有订阅者升级或增加计划内容带来的额外收入 |
| **收缩 MRR** | 现有订阅者降级但未完全取消订阅所损失的收入 |
| **流失 MRR** | 取消订阅所损失的收入 |
| **净新增 MRR** | 净结果：新增 MRR + 扩张 MRR − 收缩 MRR − 流失 MRR |

每张卡片都包含趋势迷你图表，以及与上月相比的百分比变化指标。

## 报告

每份报告所在页面都有 **Build Report** 按钮。前往相关部分以访问并下载所需报告。

每份报告都可以按适用条件进行筛选（支付方式、状态、产品类型、失败类型、争议状态或货币），并下载为 CSV。

| 报告类型 | 描述 | 查找位置 |
|-------------|-------------|------------------|
| **支付报告** | 所有已处理支付的详细记录，包括账单地址、卡片详情、美元等值金额、结算详情、费用和失败代码。 | **Transactions → Payments** |
| **退款报告** | 所有退款活动的完整日志，包含详细退款信息。 | **Transactions → Refunds** |
| **争议报告** | 支付争议摘要，包括解决状态和证据详情。 | **Transactions → Disputes** |
| **客户报告** | 按客户整理的支付、退款和争议摘要。 | **Sales → Customers** |
| **收款报告** | 向您的账户支付的收款摘要，并按账本事件细分费用。 | **Payouts** |
| **账户摘要报告** | 详细的余额账本条目，包括事件类型、金额和引用信息。 | **Payouts → Balances** |

## 下载报告

<Steps>
<Step title="Navigate to the relevant page">
使用上表前往所需报告所在的页面。
</Step>
<Step title="Select a time period">
点击 <strong>Build Report</strong>，选择预设范围（Today、Last 7 days、Last 30 days、This month 等），或使用日历选择自定义日期范围。
