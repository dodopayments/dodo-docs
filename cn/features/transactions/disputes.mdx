## 介绍

争议部分提供了所有提出的争议的详细视图，以及这些争议的当前状态。您需要在您的端管理争议解决，但仪表板将提供状态、争议原因、争议 ID 的可见性，以方便访问信息。

## 查看和理解争议

<Steps>
<Step title="打开交易页面">
    在您的仪表板中转到 <strong>交易</strong> 页面并选择 <strong>争议</strong> 选项卡。这将显示与您的账户相关的所有争议的列表。
</Step>

<Step title="查看争议详情">
    点击任何争议条目旁边的 <strong>眼睛图标</strong> 以打开详细视图。在这里，您可以查看争议原因、状态、争议 ID 和其他相关信息。
</Step>

<Step title="访问相关支付信息">
    在争议详情中，找到 <strong>相关支付</strong> 字段。点击这里的 <strong>眼睛图标</strong> 以查看与争议相关的完整支付详情。
</Step>
</Steps>

## 回应争议

当您的交易被提出争议时，请按照以下步骤有效回应：

1. **检查您的仪表板**
   - 导航到交易 → 争议部分
   - 查找新的争议条目

2. **查看电子邮件通知**
   - 检查您注册的电子邮件以获取争议创建通知

3. **选择您的回应**
   - 您可以接受或反驳争议
   
   <Frame>
       <img src="/images/disputes/1.png" alt="争议创建" />
   </Frame>

4. **如果接受**
   - 不需要进一步操作
   - 您将失去争议

5. **如果反驳**
   - 准备提交证据
   - 遵循以下最佳实践

## Visa 快速争议解决 (RDR)

Visa 快速争议解决 (RDR) 是一种自动化的争议预防工具，可以在争议 **成为正式的退单之前** 解决合格的争议。当持卡人与其银行发起争议时，如果交易低于您配置的门槛，RDR 会拦截争议并自动为您发放退款—从而防止退单的产生。

### RDR 重要性

争议是数字企业面临的最昂贵和耗时的挑战之一。除了直接的财务影响，高争议率还可能带来严重后果：

<CardGroup cols={2}>
<Card title="财务影响" icon="money-bill">
  每个争议都会使您损失交易金额 **加上** 一笔不可退还的争议费用，无论您是赢还是输。
</Card>
<Card title="争议率处罚" icon="chart-line-down">
  卡网络会监控您的争议与交易比率。Visa 的门槛是 **0.9%** -- 超过此比例会使您进入监控程序，并面临逐步增加的罚款。
</Card>
<Card title="账户风险" icon="triangle-exclamation">
  持续的高争议率可能导致处理费用增加、准备金要求增加，甚至可能被支付处理方终止帐户。
</Card>
<Card title="运营开销" icon="clock">
  每个争议都需要收集证据、准备回应和跟进--消耗了宝贵的时间，这些时间本可以用于构建您的产品。
</Card>
</CardGroup>

<Warning>
当您的争议率超过 **0.9%** 或每月收到 **超过 100 个争议** 时，Visa 的争议监控程序 (VDMP) 将启动。罚款会每月增加，可能每月高达 **$50,000+** 罚款，适用于仍在该程序中的商户。
</Warning>

### RDR 的工作原理

<Steps>
<Step title="持卡人发起争议">
  客户联系其银行，对账单上的 Visa 交易提出争议。
</Step>

<Step title="RDR 拦截争议">
  在争议成为正式的退单之前，Visa 的 RDR 系统会检查该交易是否符合根据您的配置规则自动解决的条件。
</Step>

<Step title="自动退款发放">
  如果交易金额在您的门槛内，退款将通过 Visa 的网络自动发放给持卡人。争议立即得到解决。
</Step>

<Step title="未记录退单">
  因为争议在变成正式退单之前得到了解决，所以它 **不计入您与 Visa 的争议率**。您避免了争议费用和对您账户的负面影响。
</Step>
</Steps>

<Info>
通过 RDR 自动退款的交易将在您的 Dodo Payments 控制面板中显示为 **失去的争议**。这是预期的行为--退款是自动发放的，以防止正式退单，"失去"状态反映了资金已退还给持卡人。
</Info>

### 关键好处

| 好处 | 描述 |
|---------|-------------|
| **降低争议率** | RDR 解决的争议不计入您的 Visa 争议比率，保持在 0.9% 门槛以下 |
| **无需争议费用** | 避免不可退还的争议费用（通常每个争议为 $15-$25），因为争议从未成为正式退单 |
| **零运营开销** | 无需收集证据、撰写回应或跟踪争议截止日期--解决完全自动化 |
| **更好的客户体验** | 持卡人可以立即收到退款，而不是等待几周来解决争议 |
| **保护您的账户状态** | 避免进入 Visa 的监控程序，从而避免不断增加的罚款和处理限制 |

### 配置

RDR 按 **美元门槛** 配置--任何在该金额或以下的 Visa 争议都会自动通过退款解决。门槛以上的争议会经过正常的争议流程，让您有机会用证据反驳它们。

<Info>
例如，对于 100 美元的门槛：75 美元的争议将自动解决（退款），而 150 美元的争议将正常流程，让您审查并响应。
</Info>
