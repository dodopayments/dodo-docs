数字钱包允许客户使用其设备上保存的支付方式一键支付。它们提供更高的转化率、通过标记化增强的安全性以及简化的结账体验。

## 支持的钱包

| 钱包 | 可用性 | 货币 | 订阅 | 所需设置 |
| :----- | :----------- | :--------- | :-----------: | :------------- |
| **Apple Pay** | 全球（不包括印度） | 全部 | 是 | 域名验证 |
| **Google Pay** | 全球（不包括印度） | 全部 | 是 | 无 |
| **Amazon Pay** | 全球（不包括印度） | USD | 否 | 无 |
| **Cash App Pay** | 仅限美国 | USD | 是 | 无 |
| **RevolutPay** | 全球 | GBP | 否 | 无 |

<Warning>
**PayPal 支持暂停：**PayPal 暂时无法用于新交易。
</Warning>

## Apple Pay

Apple Pay 允许客户使用 Apple Wallet 中保存的卡片支付，支持 Face ID 或 Touch ID 认证。

<Info>
即使首次收费为 **$0**（如免费试用），Apple Pay 也可用于订阅，这样可以在注册时设置支付授权。对于一次性支付，只有金额大于 $0 时才会显示 Apple Pay。
</Info>

### 要求
- **设备:** iOS 17+，iPadOS 17+，macOS 上的 Safari 17+
- **协议:** 需要 HTTPS
- **域名:** 必须通过 Apple 验证

### 域名验证

<Info>
仅**内联（嵌入）结账**需要域名验证。覆盖层结账、托管结账和支付链接不需要。
</Info>

<Steps>
<Step title="Open Wallet domains">
在您的仪表板中，进入 **Settings → Payment Methods**，在 **Apple Pay** 行上，点击 **Manage domains**。

<Frame caption="Open Wallet domains from the Apple Pay row">
  <img src="/images/apple-pay-domains/manage-domains.png" alt="Manage domains button on the Apple Pay row in Payment Methods settings" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Download the domain association file">
在钱包域名面板中，下载关联文件。

<Frame caption="Download the Apple Pay domain association file">
  <img src="/images/apple-pay-domains/wallet-domains-panel.png" alt="Wallet domains panel with the Download file button" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Register your domain">
点击 **Register domain** 并输入您嵌入结账的域名（例如，`shop.example.com`），然后 **Continue**。

<Frame caption="Register the domain where you embed checkout">
  <img src="/images/apple-pay-domains/register-domain.png" alt="Register a domain form with a domain entered" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Host the file on your domain">
上传到您的服务器路径：

```
https://shop.example.com/.well-known/apple-developer-merchantid-domain-association
```

文件必须通过 HTTPS 提供、无重定向可访问，并使用 `Content-Type: application/octet-stream` 或 `text/plain` 提供。
</Step>

<Step title="Verify the domain">
点击 **Verify domain**。Dodo Payments 会检查托管文件并提交您的域名给 Apple 验证。

<Frame caption="Verify the hosted association file">
  <img src="/images/apple-pay-domains/verify-domain.png" alt="Verify your domain screen with the association file host path and Verify domain button" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Confirm it's active">
状态显示为 **Active** 时，Apple Pay 在该域名上启用。使用 **Enabled** 开关来启用或禁用每个域名。

<Frame caption="Verified domains show an Active status">
  <img src="/images/apple-pay-domains/domains-active.png" alt="Wallet domains list showing domains with an Active Apple Pay status and Enabled toggles" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Test the integration">
1. 在 Apple 设备上打开结账
2. 确认 Apple Pay 按钮出现
3. 完成一次测试交易
</Step>
</Steps>

### 配置

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  allowed_payment_method_types: ['apple_pay', 'credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

## Google Pay

Google Pay 允许客户使用其 Google 账户中保存的卡片支付，并内置了欺诈保护。

### 要求
- **浏览器:** Chrome（桌面/移动）、Safari、Firefox
- **设备:** 安装了 Google Pay 应用的 Android 设备
- **设置:** 在 Chrome 中启用“允许网站查看您是否有支付方式”

### 配置

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  allowed_payment_method_types: ['google_pay', 'credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

<Info>
Google Pay 无需域名验证——一旦您的账户激活后即自动工作。
</Info>

## Amazon Pay

Amazon Pay 允许客户使用其亚马逊账户凭证和保存的支付方式，提供熟悉的结账体验。

### 可用性
- **地区：** 全球，不包括印度
- **货币：** 仅限 USD
- **订阅：** 不支持

### 配置

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  allowed_payment_method_types: ['amazon_pay', 'credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

## Cash App Pay

Cash App Pay 支持来自 Cash App 的支付，这项服务在美国的消费者中广受欢迎，用于点对点支付。

### 可用性
- **地区：** 仅限美国
- **货币：** 仅限 USD
- **订阅：** 支持

### 配置

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  allowed_payment_method_types: ['cashapp', 'credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

## RevolutPay

RevolutPay 为全球 Revolut 用户提供快速、无缝的支付服务，利用其现有的 Revolut 账户余额或关联卡。

### 可用性
- **地区：** 全球
- **货币：** 仅限 GBP
- **订阅：** 不支持

### 配置

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  allowed_payment_method_types: ['revolut_pay', 'credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

## 测试

### Apple Pay 测试

<Steps>
<Step title="Use test mode">
在您的 Dodo Payments 仪表板中启用测试模式。
</Step>

<Step title="Add a card to Apple Wallet">
将一张真实的卡添加到您的 Apple Wallet 中。在测试模式下，该卡不会被扣款。
</Step>

<Step title="Complete test purchase">
在 Apple 设备上打开结账并完成 Apple Pay 流程。
</Step>
</Steps>

<Warning>
Apple Pay 需要 HTTPS。若无适当的 SSL 设置，将不会在 `localhost` 上显示。
</Warning>

### Google Pay 测试

<Steps>
<Step title="Join the test card group">
[加入 Google Pay 测试卡组](https://groups.google.com/g/googlepay-test-mode-stub-data)以自动将测试卡添加到您的钱包中。
</Step>

<Step title="Enable test mode">
使用您的 Dodo Payments 测试 API 密钥。
</Step>

<Step title="Complete test purchase">
选择 Google Pay 中的一张测试卡完成交易。
</Step>
</Steps>

### Amazon Pay 和 Cash App Pay

使用您的测试 API 密钥并按照标准结账流程。测试交易将被模拟，不会实际收费。

## SDK 支持

### Web SDKs
所有数字钱包均完全支持：
- 覆盖层结账
- 内联结账
- 直接 API 集成

### 移动 SDK（Checkout）

[Android](/developer-resources/sdks/android)、[iOS](/developer-resources/sdks/ios)、
[React Native](/developer-resources/sdks/react-native) 和
[Flutter](/developer-resources/sdks/flutter) Checkout SDK 会在平台的真实浏览器界面中打开 Dodo 的托管 Checkout
（`SFSafariViewController` /
Chrome Custom Tabs），而不是 WebView，因此 Apple Pay 和 Google Pay 的工作方式
与 Web 端相同。有关设置，请参阅[移动集成指南](/developer-resources/mobile-integration)。

## 最佳实践

<AccordionGroup>
<Accordion title="Prioritize wallets on mobile">
移动用户希望使用 Apple Pay 和 Google Pay。在移动端 Checkout 中突出显示这些选项。
</Accordion>

<Accordion title="Complete domain verification early">
Apple Pay 需要进行域名验证。不要等到发布当天才开始——应在开发期间启动此流程。
</Accordion>

<Accordion title="Always include card fallbacks">
并非所有客户都有数字钱包。始终将 `credit` 和 `debit` 包含在允许的方法中。
</Accordion>

<Accordion title="Test on real devices">
模拟器无法完全复现数字钱包的行为。请在发布前使用实际的 iOS 和 Android 设备进行测试。
</Accordion>

<Accordion title="Handle wallet unavailability gracefully">
如果数字钱包不可用（设备不兼容或未保存卡片），请确保其他支付选项清晰可见。
</Accordion>
</AccordionGroup>

## 故障排除

<AccordionGroup>
<Accordion title="Apple Pay button not appearing">
**检查：**
1. 是否已通过 Dodo Payments 完成域名验证？
2. 是否使用 HTTPS？
3. 设备是否为 iOS 17+ / Safari 17+ / iPadOS 17+？
4. 客户是否在 Apple Wallet 中保存了卡片？
5. 是否在 `allowed_payment_method_types` 中包含 `apple_pay`？

**解决方案：**完成域名验证并确保使用 HTTPS。在真实的 Apple 设备上进行测试。
</Accordion>

<Accordion title="Google Pay button not appearing">
**检查：**
1. 是否使用 Chrome 或兼容的浏览器？
2. 客户是否在 Google Pay 中保存了卡片？
3. 是否已启用 Chrome 设置“允许网站检查支付方式”？
4. 是否在 `allowed_payment_method_types` 中包含 `google_pay`？

**解决方案：**验证浏览器兼容性以及客户的 Google Pay 设置。
</Accordion>

<Accordion title="Wallet payment failed">
**常见原因：**
- 钱包中的卡片已过期或无效
- 银行拒绝了交易
- 网络连接问题

**解决方案：**客户应验证钱包中的卡片，或尝试其他支付方式。
</Accordion>

<Accordion title="Wrong device type">
数字钱包仅会显示在兼容的设备上：
- Apple Pay：仅限 Apple 设备
- Google Pay：Chrome 浏览器或 Android 设备

**解决方案：**这是预期行为。请确保提供卡片备用支付方式。
</Accordion>
</AccordionGroup>
