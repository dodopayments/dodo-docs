韩国客户强烈偏好使用本地钱包和国内卡，而非国际支付方式。Dodo Payments 支持主要的韩国钱包——**PAYCO**、**Naver Pay** 和 **Kakao Pay**——以及**韩国本地卡**和国际卡，所有结算均以**韩元（KRW）**进行。

## 为什么韩国支付方式很重要

<CardGroup cols={3}>
<Card title="Wallet-First Market" icon="wallet">
韩国购物者大多使用 Kakao Pay 和 Naver Pay 等本地钱包进行结账，而不是输入卡信息。
</Card>

<Card title="Domestic Card Networks" icon="credit-card">
许多韩国卡在本地网络上运行。支持韩国本地卡可以避免国际网络无法处理的卡被拒绝。
</Card>

<Card title="Higher Conversion" icon="chart-line">
提供熟悉的本地方法可以减少韩国客户在结账时的摩擦和放弃率。
</Card>
</CardGroup>

## 支持的方法

| 方法 | 类型 | 订阅 | 最低金额 |
| :----- | :--- | :-----------: | :--------- |
| **Kakao Pay** | 钱包 | 是 | ~$1.00 |
| **Naver Pay** | 钱包 | 是 | ~$1.00 |
| **PAYCO** | 钱包 | 否 | ~$1.00 |
| **韩国本地卡** | 卡 | 是 | ~$1.00 |
| **信用卡与借记卡** | 卡（国际） | 是 | ~$1.00 |

<Info>
钱包的可用性取决于交易类型。**Kakao Pay** 和 **Naver Pay** 可用于订阅，而 **PAYCO** 则用于一次性付款。所有要求**韩元（KRW）**结算货币。
</Info>

## 配置

### API 方法类型

| 类型 | 描述 |
| :--- | :---------- |
| `kakao_pay` | Kakao Pay 钱包 |
| `naver_pay` | Naver Pay 钱包 |
| `payco` | PAYCO 钱包 |
| `credit` | 信用卡，包括韩国本地卡 |
| `debit` | 借记卡，包括韩国本地卡 |

### 示例：以韩国为重点的结账

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  allowed_payment_method_types: [
    'kakao_pay',
    'naver_pay',
    'payco',
    'credit',
    'debit'
  ],
  billing_currency: 'KRW',
  billing_address: {
    country: 'KR',
    zipcode: '06236'
  },
  return_url: 'https://example.com/success'
});
```

### 要求

要在结账时出现韩国支付方式：

1. **计费国家**为韩国 (`KR`)
2. **货币**为韩元
3. 对于以其他货币计价的商家：必须启用**自适应货币**，以便客户以韩元结算

<Warning>
如果您以其他货币定价且未启用自适应货币，韩国客户将无法以韩元结算，韩国钱包将不可用。
</Warning>

<Note>
韩元是没有小数的货币——金额以完整的韩元表示，无次要单位。以整数值发送和读取韩元金额，而不是除以100。
</Note>

## 最佳实践

<AccordionGroup>
<Accordion title="Offer wallets prominently">
对于韩国客户，本地钱包应是主要选项。Kakao Pay 和 Naver Pay 是大多数韩国购物者最熟悉的结账方式。
</Accordion>

<Accordion title="Include card fallbacks">
始终包括 `credit` 和 `debit`，以便没有偏好钱包的客户以及使用韩国本地卡付款的客户仍然可以完成结账。
</Accordion>

<Accordion title="Match currency to region">
韩国支付方式需要韩元。如果您的目录以其他货币定价，请启用自适应货币，以便韩国客户可以以韩元报价和结算。
</Accordion>

<Accordion title="Choose wallets by transaction type">
使用 Kakao Pay 和 Naver Pay 订阅服务，而 PAYCO 用于一次性付款。包含所有三个选项可让 Dodo 根据结账上下文提供合适的选项。
</Accordion>
</AccordionGroup>

## 故障排除

<AccordionGroup>
<Accordion title="Korean wallets not appearing at checkout">
**检查：**
1. 计费国家设置为 `KR` 吗？
2. 货币设置为 `KRW` 吗？
3. 如果以其他货币定价：启用了自适应货币？
4. 钱包 (`kakao_pay`, `naver_pay`, 或 `payco`) 包含在 `allowed_payment_method_types` 中？

**解决方案：** 验证计费地址有 `country: "KR"` 和 `billing_currency: "KRW"`。
</Accordion>

<Accordion title="Wallet missing for a subscription">
**原因：** PAYCO仅用于一次性付款。对于定期计费，请使用 Kakao Pay 或 Naver Pay。

**解决方案：** 在 `allowed_payment_method_types` 中包含 `kakao_pay` 和 `naver_pay`，用于订阅结账。
</Accordion>

<Accordion title="Korean card declined on the international network">
**原因：** 一些韩国卡运行在国际网络无法处理的国内网络上。

**解决方案：** 始终启用 `credit` 和 `debit`，以便韩国本地卡能正确路由。
</Accordion>
</AccordionGroup>
