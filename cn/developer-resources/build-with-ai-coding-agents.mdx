Dodo Agent 插件将两个 MCP 服务器和八个集成技能接入到您的一次安装的 AI 编码代理中。它兼容 **Claude Code**、**Codex CLI**、**Cursor** 和 **OpenCode**——以及 MCP 服务器和技能 CLI，适用于任何 MCP 兼容客户端。

<Info>
**三个原语，一个插件。** Agent 插件将您所需的一切打包:
- **API MCP 服务器**——实时访问支付、订阅、客户、产品、退款、许可证和使用情况。通过浏览器 OAuth 进行身份验证（无需本地密钥）。
- **知识 MCP 服务器**——跨所有 Dodo Payments 文档的语义搜索。无需凭据。
- **八个代理技能**——辅助材料帮助您的代理按需加载结账、订阅、webhooks、基于使用的计费、基于信用的计费、许可证密钥、BillingSDK 和最佳实践。
</Info>

选择下方的编程代理。安装会自动添加两个 MCP 服务器和所有八个技能。


## 你会得到什么

安装插件后，你的代理可以访问两个 MCP 服务器和八个技能。

### MCP 服务器

| 服务器 | 目的 | 认证 |
|--------|---------|------|
| API 实时访问 — 支付、订阅、客户、产品、退款、许可证、使用情况 | OAuth (浏览器) |
| 跨所有 Dodo Payments 文档的语义搜索 | 无 |

这两个服务器通过连接，因此它们可以在任何 MCP 兼容的客户端运行。

### 代理技能

| 技能 | 描述 |
|-------|-------------|
| 综合指导，将 Dodo Payments 与最佳实践集成 |
| 创建结账会话和支付流程 |
| 实施订阅计费流程 |
| 为支付事件设置和处理 webhooks |
| 用事件和计量器实现计量计费 |
| 信用权利、余额、和计量信用扣除 |
| 管理数字产品的许可证密钥 |
| 使用 BillingSDK React 组件 |

技能会自动加载 — 代理在检测到相关任务时会选择合适的技能。详见 [Agent Skills 文档](/developer-resources/agent-skills) 的完整列表和单独安装。

## 安全性和最佳实践

**永远不要提交生产 API 密钥。** 开发过程中使用 [测试模式](/miscellaneous/test-mode-vs-live-mode)。Agent 插件默认使用浏览器 OAuth — 仅在工作流需要时切换到本地 API 密钥。

- **先使用测试模式。** 在使你的集成上线之前，用于密钥的沙盒化集成。参见 [Test Mode vs Live Mode](/miscellaneous/test-mode-vs-live-mode)。
- **OAuth 是默认设置。** Agent 插件通过浏览器 OAuth 进行身份验证 （无本地机密）。仅在需要时使用 API 密钥模式 — 参见下面的配置部分。
- **检查代理生成的代码。** 始终验证 webhook 处理程序包括遵循 [Standard Webhooks 规范](https://standardwebhooks.com/) 的签名验证。

## 配置 API 密钥

默认情况下，Agent 插件使用带有浏览器 OAuth 的远程 MCP 服务器 — 无需本地凭据。如果你的工作流需要本地 API 密钥（例如，CI 环境，无头服务器），你可以切换到 stdio 模式。

在 Claude Code 中打开，选择 **Dodo Payments**，并选择 **Configure options**。填写：

- — 你的 或 密钥
- — 你的 webhook 签名密钥
- — 或

然后编辑将指向本地 stdio 服务器：

运行以应用更改到当前会话。

在中自行声明 — 你的条目将取代插件的默认远程服务器：

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "mcp": {
    "dodopayments-api": {
      "type": "local",
      "command": ["npx", "-y", "dodopayments-mcp@latest"],
      "environment": {
        "DODO_PAYMENTS_API_KEY": "dodo_test_...",
        "DODO_PAYMENTS_WEBHOOK_KEY": "whsec_...",
        "DODO_PAYMENTS_ENVIRONMENT": "test_mode"
      },
      "enabled": true
    }
  }
}
```

重启 OpenCode 以应用。
