Dodo Payments为多种编程语言提供官方SDK，每种SDK都按照语言特定的最佳实践和现代特性设计，以实现无缝支付集成。

始终使用最新的SDK版本以获取最新的功能和改进。定期检查您的包管理器以确保您可以访问所有Dodo Payments功能。

## 可用的SDK

选择与您的技术栈匹配的SDK：

  支持TypeScript和Node.js的类型安全集成，具有基于Promise的API和自动分页功能

  针对Python 3.7+应用程序的Pythonic接口，支持async/await

  符合PSR-4的现代PHP 8.1+应用程序的SDK

  具有上下文支持和强类型的惯用Go接口

  遵循Ruby惯例和最佳实践的优雅Ruby接口

  针对Java 8+的强大且线程安全的SDK，支持Maven和Gradle

  现代Kotlin SDK，支持协程、空安全和扩展函数

  针对.NET 8+的类型安全SDK，具有异步Task-based API (Beta)

  基于Tokio和reqwest构建的异步优先SDK，具有强类型保护适用于Rust 1.75+

  原生移动SDK，用于在iOS和Android应用程序中构建安全的支付体验

  用于从终端与API交互的命令行接口

## 快速开始

在几分钟内开始使用任何SDK：

  使用您语言的包管理器安装SDK

  ```bash
  npm install dodopayments
  ```



  ```bash
  pip install dodopayments
  ```



  ```bash
  composer require dodopayments/client
  ```



  ```bash
  go get github.com/dodopayments/dodopayments-go
  ```





  ```bash
  cargo add dodopayments
  ```



  用您的API密钥配置客户端

  ```typescript
  import DodoPayments from 'dodopayments';
  const client = new DodoPayments({ bearerToken: 'your_api_key' });
  ```



  ```python
  from dodopayments import DodoPayments
  client = DodoPayments(bearer_token="your_api_key")
  ```



  ```php
  use Dodopayments\Client;
  $client = new Client(bearerToken: 'your_api_key');
  ```



  ```go
  import "github.com/dodopayments/dodopayments-go"
  client := dodopayments.NewClient(option.WithBearerToken("your_api_key"))
  ```





  ```rust
  use dodopayments::Client;
  let client = Client::from_env()?; // reads DODO_PAYMENTS_API_KEY
  ```



  创建结账会话或付款
  现在您已准备好处理付款！请访问单个SDK页面以获取详细指南和示例。

## 关键特性

所有SDK共享以下核心功能：

- **类型安全**：编译时安全性和更好的IDE支持 
- **错误处理**：全面的异常处理和详细的错误消息 
- **认证**：简单的API密钥认证，支持环境变量 
- **异步支持**：现代的异步/等待模式（如适用） 
- **自动分页**：列表响应的自动分页 
- **基于使用的计费**：内置的使用事件跟踪和获取支持 
- **测试**：完整的沙盒环境支持用于开发和测试

## React Native SDK

针对移动应用程序，我们提供专用的React Native SDK：

  使用本机UI组件和简化支付数据收集为iOS和Android应用程序构建安全的支付体验

**功能:** 
- Android和iOS的本机UI组件 
- 用于收集敏感支付数据的简化安全 
- 支持多种支付方式 
- 与React Native应用程序的无缝集成

苹果支付、谷歌支付、现金应用和UPI目前不支持React Native SDK。这些支付方式的支持计划在未来版本中推出。

## 命令行接口

用于基于终端的工作流程和自动化：

  支持所有78个API端点的自动生成命令行接口

**功能:**
- 资源为基础的命令结构，便于使用
- 多种输出格式（JSON，YAML，漂亮，互动）
- 支持bash，zsh和fish的shell自动补全
- 非常适合脚本和CI/CD自动化

```bash
# Quick example
dodopayments payments list --format json | jq '.data[] | {id, amount}'
```

## 从Node.js SDK迁移

我们从Node.js SDK迁移到新的TypeScript SDK。如果您正在使用旧版本的Node.js SDK，请参阅[迁移指南](https://github.com/dodopayments/dodopayments-typescript/blob/main/MIGRATION.md)以更新您的集成。

通过我们的框架适配器在不到10行代码中进行集成。从我们的推荐框架中选择或探索所有支持的选项。

### 推荐的框架

  具有内置集成的身份验证框架

  具有实时功能的后端即服务
