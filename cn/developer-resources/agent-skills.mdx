## 概述

Agent Skills 是可重用的能力，增强 AI 编程助手在使用 Dodo Payments 时可以完成的操作。它们提供过程知识和最佳实践，帮助代理更有效地完成特定任务——从集成结账流程到设置基于使用情况的计费。

<Info>
**将技能视为 AI 助手的插件。** 它们教会您的代理如何按照我们推荐的模式和最佳实践正确实施 Dodo Payments 功能。
</Info>

Skills 可与任何 MCP 兼容的 AI 代理一起使用，包括：
- **Claude Code** - Anthropic 的 CLI 编程助手
- **OpenCode** - 开源 AI 编程代理
- **Cursor** - 以 AI 为先的代码编辑器
- **其他 MCP 客户端** - 支持技能协议的任何代理

## 可用技能

## 安装

根据您使用的 AI coding assistant，选择首选的安装方式。

<Tabs>
<Tab title="Agent Plugin (recommended)">
如果您使用 Claude Code、Codex CLI、Cursor 或 OpenCode，[Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) 可以一步安装全部十七项技能和两个 MCP servers。当您的 agent 检测到相关任务时，技能会自动加载。

请参阅 [AI Coding Agents 指南](/developer-resources/build-with-ai-coding-agents)，了解各 agent 的安装命令。
</Tab>

<Tab title="Skills CLI">
使用适用于任何兼容 MCP 的 agent 的通用 skills CLI 安装技能：

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

或者根据需要单独安装技能：

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
仅安装您需要的技能，让 agent 专注于当前任务并减少上下文开销。
</Tip>
</Tab>

<Tab title="Claude Code">

```bash

```

然后安装单独的 plugins：

```bash expandable

# Accepting payments
/plugin install checkout-integration
/plugin install subscription-integration
/plugin install mobile-checkout
/plugin install webhook-integration

# Billing models

/plugin install license-keys

# Catalog and pricing
/plugin install product-catalog-management
/plugin install discounts-and-promotions
/plugin install localized-pricing

# Customers and operations
/plugin install customer-management
/plugin install refunds-and-disputes

# UI and integrations
/plugin install billing-sdk
/plugin install better-auth-integration
```

</Tab>

<Tab title="OpenCode">
在 OpenCode 设置中完成配置后，技能会自动可用。将 Dodo Payments skills repository 添加到您的配置中：

```json

  "skills": {

      "dodopayments/skills"
```

## 使用技能

安装后，当您要求 AI coding assistant 实现 Dodo Payments 功能时，它会自动加载相关技能。您无需指定技能名称，只需描述任务即可。

| 示例提示词 | 加载的技能 |
|----------------|------------------|
| 按照最佳实践，帮助我将 Dodo Payments 集成到我的 Next.js 应用中 | `dodo-best-practices` |
| 为我的 Hono 应用添加 Dodo Payments checkout route handler | `framework-adapters` |
| 带我完成 payment 测试和正式上线 | `testing-and-go-live` |
| 为我的 SaaS 产品创建一个 checkout session | `checkout-integration` |
| 实现带免费试用和多个定价层级的订阅流程 | `subscription-integration` |
| 为我的 React Native 应用添加应用内 checkout | `mobile-checkout` |
| 为 payment 和 subscription 事件设置 webhook handlers | `webhook-integration` |
| 为我的 AI 产品设置 credit 权益和基于 meter 的 credit 扣减 | `credit-based-billing` |
| 为我的 AI 产品添加基于用量的计费，以跟踪 API 调用 | `usage-based-billing` |
| 为我的桌面应用实现 license key 验证 | `license-keys` |
| 创建包含 add-ons 和分层定价的产品目录 | `product-catalog-management` |
| 添加一个首三个计费周期优惠 20% 的 promo code | `discounts-and-promotions` |
| 使用购买力平价，以访问者的本地货币显示价格 | `localized-pricing` |
| 为客户提供用于管理 payment methods 的自助服务门户 | `customer-management` |
| 发起部分退款，并在 dispute 开启时撤销访问权限 | `refunds-and-disputes` |
| 使用 BillingSDK components 添加定价页面 | `billing-sdk` |
| 将 Dodo Payments 接入我的 Better Auth 设置 | `better-auth-integration` |

## 技能的工作方式

技能为您的 AI coding assistant 提供：

1. **流程知识** - 实现功能的分步说明
2. **代码模板** - 可用于生产环境的代码模式和代码片段
3. **最佳实践** - 关于安全性、错误处理和 UX 的建议方案
4. **上下文感知** - 理解不同 Dodo Payments 功能如何协同工作

当您要求 AI coding assistant 实现某项功能时，它会使用相关技能来：
- 理解正确的实现方式
- 生成准确且可运行的代码
- 遵循 Dodo Payments 约定
- 正确处理边界情况和错误

<Note>
技能可以补充 [MCP Server](/developer-resources/mcp-server) 和 [Sentra](/developer-resources/sentra)。使用 MCP 执行 API 操作，使用 Sentra 获取引导式集成，并使用技能增强 AI coding assistant 的能力。
</Note>

## 与其他工具的比较

| 工具 | 用途 | 最适合 |
|------|---------|----------|
| **Agent Skills** | 增强 AI coding assistant 的知识 | 使用任何 MCP client 进行 AI 辅助开发 |
| **MCP Server** | 执行 API 操作 | AI coding assistant 的直接 API 访问 |
| **Sentra** | 引导式集成 assistant | IDE 中的交互式计费集成 |
