## 概述

Agent Skills 是可重用的能力，增强 AI 编程助手在使用 Dodo Payments 时可以完成的操作。它们提供过程知识和最佳实践，帮助代理更有效地完成特定任务——从集成结账流程到设置基于使用情况的计费。

<Info>
**将技能视为 AI 助手的插件。** 它们教会您的代理如何按照我们推荐的模式和最佳实践正确实施 Dodo Payments 功能。
</Info>

Skills 可与任何支持 skills protocol 的 AI agent 配合使用，包括：
- **Claude Code** - Anthropic 的 CLI coding assistant
- **Codex CLI** - OpenAI 的 CLI coding agent
- **Cursor** - AI-first code editor
- **VS Code / GitHub Copilot** - 通过 Agent Plugin
- **Kiro** - 将 skills 作为 Power 加载
- **OpenCode** - 开源 AI coding agent
- **其他客户端** - 任何支持 skills protocol 的 agent

<Note>
**Gemini CLI 是例外。** 它没有 agent-skill primitive，因此无法在其中使用 skills — 只能使用两个 [MCP servers](/developer-resources/mcp-server)。
</Note>

## 安装

根据你的 AI coding assistant 选择偏好的安装方式。

<Tabs>
<Tab title="Agent Plugin (recommended)">
如果你使用 Claude Code、Codex CLI、Cursor、VS Code / GitHub Copilot、Kiro 或 OpenCode，[Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) 可通过一步操作安装全部十七项 skills 和两个 MCP servers。你的 agent 检测到相关任务后，skills 会自动加载。

请参阅 [AI Coding Agents guide](/developer-resources/build-with-ai-coding-agents)，了解各个 agent 的安装命令。
</Tab>

<Tab title="Skills CLI">
使用适用于任何 MCP-compatible agent 的 universal skills CLI 安装 skills：

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

或者根据需要安装单项 skills：

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/dodo-best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
仅安装所需的 skills，让你的 agent 保持专注并减少 context overhead。
</Tip>
</Tab>

<Tab title="OpenCode">
OpenCode 会从你指定的目录加载 skills。它**不会**扫描已安装的 packages，因此必须提供明确的 `skills.paths` entry。

使用 Agent Plugin package：

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

Relative paths 会相对于 **project directory** 解析，因此 package 必须位于该项目的 `node_modules` 中。也可以使用 absolute path，从而无需本地安装。

<Warning>
不存在的 skills path 会被**静默**忽略 — 不会报错，也不会发出警告。确认 skills 确实已加载：

```bash
opencode run "List every skill available to you by name."
```

你应该会看到全部十七项。
</Warning>
</Tab>
</Tabs>

## 使用 Skills

安装完成后，当你要求 AI assistant 实现 Dodo Payments 功能时，它会自动加载相关 skill。你无需指定 skill 名称 — 只需描述任务即可。

| Example prompt | Skill that loads |
|----------------|------------------|
| 帮我按照最佳实践将 Dodo Payments 集成到我的 Next.js 应用中 | `dodo-best-practices` |
| 为我的 Hono 应用添加 Dodo Payments checkout route handler | `framework-adapters` |
| 带我完成 payments testing 和 go-live | `testing-and-go-live` |
| 为我的 SaaS product 创建一个 checkout session | `checkout-integration` |
| 实现一个包含 free trial 和多个 pricing tiers 的 subscription flow | `subscription-integration` |
| 为我的 React Native 应用添加 in-app checkout | `mobile-checkout` |
| 为 payment 和 subscription events 设置 webhook handlers | `webhook-integration` |
| 为我的 AI product 设置 credit entitlements 和 metered credit deduction | `credit-based-billing` |
| 为我的 AI product 添加 usage-based billing 以跟踪 API calls | `usage-based-billing` |
| 为我的 desktop app 实现 license key validation | `license-keys` |
| 创建包含 add-ons 和 tiered pricing 的 product catalog | `product-catalog-management` |
| 添加一个在前 3 个 billing cycles 提供 20% 折扣的 promo code | `discounts-and-promotions` |
| 使用 purchasing power parity，以访问者的 local currency 显示价格 | `localized-pricing` |
| 为 customers 提供 self-service portal，以管理其 payment methods | `customer-management` |
| 发起 partial refund，并在 dispute 开启时撤销 access | `refunds-and-disputes` |
| 使用 BillingSDK components 添加 pricing page | `billing-sdk` |
| 将 Dodo Payments 接入我的 Better Auth setup | `better-auth-integration` |

## Skills 的工作方式

Skills 会为你的 AI assistant 提供：

1. **Procedural Knowledge** - 实现功能的分步说明
2. **Code Templates** - 可用于生产环境的代码模式和代码片段
3. **Best Practices** - 针对 security、error handling 和 UX 的推荐方法
4. **Context Awareness** - 理解不同 Dodo Payments 功能如何协同工作

当你要求 AI assistant 实现某项功能时，它会使用相关 skill 来：
- 理解正确的实现方式
- 生成准确且可运行的代码
- 遵循 Dodo Payments conventions
- 正确处理 edge cases 和 errors

<Note>
Skills 可补充 [MCP Server](/developer-resources/mcp-server) 和 [Sentra](/developer-resources/sentra)。使用 MCP 执行 API operations，使用 Sentra 获得引导式集成，并使用 Skills 增强 AI assistant capabilities。
</Note>

## 与其他工具的比较

| Tool | Purpose | Best For |
|------|---------|----------|
| **Agent Skills** | 增强 AI assistant knowledge | 使用任何 MCP client 进行 AI-assisted development |
| **MCP Server** | 执行 API operations | 从 AI assistants 直接访问 API |
| **Sentra** | 引导式 integration assistant | IDE 中的交互式 billing integration |
