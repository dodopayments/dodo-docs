## 安装

<Steps>
<Step title="Install the package">
在项目根目录运行以下命令：

```bash
npm install @dodopayments/sveltekit
```

</Step>
<Step title="Set up environment variables">
在项目根目录创建一个 <code>.env</code> 文件：

```env expandable
DODO_PAYMENTS_API_KEY=your-api-key
DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
DODO_PAYMENTS_ENVIRONMENT="test_mode" or "live_mode"
DODO_PAYMENTS_RETURN_URL=https://yourdomain.com/checkout/success
```

<Warning>
切勿将 <code>.env</code> 文件或密钥提交到版本控制。
</Warning>
</Step>
</Steps>

## 路由处理器示例

<Info>
所有示例都假设您正在使用 SvelteKit App Router。
</Info>

<Tabs>
<Tab title="Checkout Handler">
  <Info>
  使用此处理程序将 Dodo Payments 结账集成到您的 SvelteKit 应用中。支持静态（GET）、动态（POST）和会话（POST）付款流程。
  </Info>
  <CodeGroup>

    ```typescript SvelteKit Route Handler expandable
    // src/routes/api/checkout/+server.ts
    import { Checkout } from "@dodopayments/sveltekit";
    import { DODO_PAYMENTS_API_KEY, DODO_PAYMENTS_RETURN_URL, DODO_PAYMENTS_ENVIRONMENT } from '$env/static/private';

    const checkoutGetHandler = Checkout({
        bearerToken: DODO_PAYMENTS_API_KEY,
        returnUrl: DODO_PAYMENTS_RETURN_URL,
        environment: DODO_PAYMENTS_ENVIRONMENT,
        type: "static",
    });

    const checkoutPostHandler = Checkout({
        bearerToken: DODO_PAYMENTS_API_KEY,
        returnUrl: DODO_PAYMENTS_RETURN_URL,
        environment: DODO_PAYMENTS_ENVIRONMENT,
        type: "session", // or "dynamic" for dynamic link
    });

    export const GET = checkoutGetHandler.GET;
    export const POST = checkoutPostHandler.POST;
    ```

  </CodeGroup>

## 结账路由处理器

<Info>
Dodo Payments 支持三种类型的支付流程将支付集成到您的网站中，此适配器支持所有类型的支付流程。
</Info>

- **静态支付链接：** 可即时分享的 URL，用于快速、无代码的支付收集。
- **动态支付链接：** 使用 API 或 SDK 程序化生成带有自定义详细信息的支付链接。
- **结账会话：** 创建安全、可自定义的结账体验，预配置产品购物车和客户详细信息。

<AccordionGroup>
<Accordion title="Static Checkout (GET)">

</Warning>

### 响应格式
静态结账返回一个包含结账 URL 的 JSON 响应：

```json
{
  "checkout_url": "https://checkout.dodopayments.com/"
}
```

</Accordion>
<Accordion title="Dynamic Checkout (POST)">
- 将参数作为 POST 请求的 JSON 正文发送。
- 支持一次性和周期性付款。
- 有关支持的 POST 正文字段的完整列表，请参阅：
  - [一次性付款产品的请求正文](https://docs.dodopayments.com/api-reference/payments/post-payments)
  - [订阅产品的请求正文](https://docs.dodopayments.com/api-reference/subscriptions/post-subscriptions)

<Warning>
Dynamic Checkout 代理已弃用的 `POST /payments` 和 `POST /subscriptions` endpoints。它会继续支持现有集成，但新集成应使用下方的 **Checkout Sessions**。
</Warning>

### Response Format

Dynamic checkout 返回包含 checkout URL 的 JSON response：

```json
{
  "checkout_url": "https://checkout.dodopayments.com/"
}
```

</Accordion>
<Accordion title="Checkout Sessions (POST)">
Checkout sessions 提供更安全的 hosted checkout experience，可为一次性购买和 subscriptions 处理完整的 payment flow，同时支持全面的 customization control。

有关更多详细信息以及完整的 supported fields 列表，请参阅 [Checkout Sessions Integration Guide](https://docs.dodopayments.com/developer-resources/checkout-session)。

### Response Format
Checkout sessions 返回包含 checkout URL 的 JSON response：

```json
{
  "checkout_url": "https://checkout.dodopayments.com/session/..."
}
```

</Accordion>
</AccordionGroup>

## Customer Portal Route Handler

Customer Portal Route Handler 让你能够将 Dodo Payments customer portal 无缝集成到 SvelteKit application 中。

### Query Parameters
<ParamField query="customer_id" type="string" required>
portal session 的 customer ID（例如 <code>?customer_id=cus_123</code>）。
</ParamField>
<ParamField query="send_email" type="boolean">
如果设置为 <code>true</code>，则会向 customer 发送包含 portal link 的 email。
</ParamField>

<Warning>
如果缺少 <code>customer_id</code>，则返回 400。
</Warning>

## Webhook Route Handler

- **Method:** 仅支持 POST requests。其他 methods 返回 405。
- **Signature Verification:** 使用 <code>webhookKey</code> 验证 webhook signature。验证失败时返回 401。
- **Payload Validation:** 使用 Zod 进行验证。payload 无效时返回 400。
- **Error Handling:**
  - 401：Invalid signature
  - 400：Invalid payload
  - 500：验证期间发生 Internal error
- **Event Routing:** 根据 payload type 调用相应的 event handler。
