## 概述

一个适用于将 Dodo Payments 集成到 Expo/React Native 应用程序的生产就绪模板。该模板包括结账会话创建、支付处理和适当的 TypeScript 配置，帮助您快速开始在移动应用中接受支付。

<Info>
该样板使用 Expo SDK 和 TypeScript，并包含用于结账会话和支付处理的示例实现。
</Info>

## 先决条件

- Node.js 18+
- Expo CLI 或 EAS CLI
- Dodo Payments 账户（来自仪表板的 API 密钥）
- iOS 模拟器或 Android 模拟器（或物理设备）

## 快速开始

<Steps>
<Step title="Clone the Repository">
克隆样板仓库并进入项目目录：

```bash
git clone https://github.com/dodopayments/expo-boilerplate.git
cd expo-boilerplate
```

</Step>

<Step title="Get Your API Credentials">
在测试模式下从 Dodo Payments 仪表板获取凭证：

- **API 密钥**：在您的 [仪表板](https://app.dodopayments.com) 中导航到 **开发者 → API 密钥**

<Tip>
从测试模式开始，安全地测试集成而无需处理真实支付。
</Tip>
</Step>

<Step title="Configure Environment Variables">
在根目录下创建 `.env` 文件：

```bash
touch .env
```

添加您的 Dodo Payments 凭据：

```bash .env
EXPO_PUBLIC_DODO_API_KEY=your_test_api_key_here
```

<Warning>
切勿将 `.env` 文件提交到版本控制中。它已经包含在 `.gitignore` 中。
</Warning>

<Warning>
`EXPO_PUBLIC_*` 变量会嵌入已发布的 JavaScript bundle 中，任何下载你应用的人都可以读取这些变量。Dodo Payments API keys 属于 bearer secrets，因此开发时只能使用 Test Mode key。在生产环境中，请在后端创建 checkout sessions，然后仅将生成的 `checkout_url` 传递给应用 — 参见 [Mobile Integration](/developer-resources/mobile-integration)。
</Warning>
</Step>

<Step title="Install Dependencies">
安装所需的 npm packages：

```bash
npm install
```

</Step>

<Step title="Start the Development Server">
启动 Expo development server：

```bash
npx expo start
```

使用设备上的 Expo Go app 扫描 QR code，或按 `i` 启动 iOS simulator，按 `a` 启动 Android emulator。

<Check>
现在可以开始构建了！boilerplate 包含示例 screens 和 components，可帮助你了解集成方式。
</Check>
</Step>
</Steps>

## 构建生产版本

<Steps>
<Step title="Install EAS CLI">

```bash
npm install -g eas-cli
```

</Step>

<Step title="Configure EAS">

```bash
eas build:configure
```

</Step>

<Step title="Build Your App">
iOS：

```bash
eas build --platform ios
```

Android：

```bash
eas build --platform android
```

</Step>
</Steps>
