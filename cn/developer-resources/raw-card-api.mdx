<Note>
本指南仅涵盖涉及卡片、Apple Pay 和 Google Pay 的一次性付款。
</Note>

## API 端点

| 环境 | 基本 URL | 确认付款端点 |
| --- | --- | --- |
| **测试模式** | `https://test.dodopayments.com` | `https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm` |
| **实时模式** | `https://live.dodopayments.com` | `https://api.hs.dodopayments.com/payments/<payment_id>/confirm` |

## 分步卡片支付流程

### 第1步：获取客户端秘密

首先使用以下 API 创建付款：

- **Payments**： [创建付款 API](/api-reference/payments/post-payments)

此 API 返回一个**`client_secret`**，这是后续步骤所需的。

<Warning>
`POST /payments` 已弃用。由于它是唯一返回 `client_secret` 的 endpoint，因此对于 raw-card 集成仍然可用；但对于其他所有一次性付款流程，请使用 [Checkout Sessions](/api-reference/checkout-sessions/create)。
</Warning>

### 步骤 2：确认付款

通过调用 `payments confirm` endpoint 确认付款：

- **Test Mode**：`POST https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm`
- **Live Mode**：`POST https://api.hs.dodopayments.com/payments/<payment_id>/confirm`

在请求正文中包含以下详细信息：

- `client_secret`：步骤 1 中的 `client_secret`
- `payment_method`：设置为 `card`
- `payment_method_data`：卡片和账单详细信息
- `browser_info`：浏览器特定数据（user agent、屏幕详细信息等）
- `payment_type`：明确设置为 `normal`（用于一次性付款）

所需 Headers：

- 从 DodoPayments 支持团队获取 publishable key
- `api-key`：您的 publishable key（从 Dodo Payments Team 获取）
- `content-type`：`application/json`

**请求正文示例：**

```json
{
  "client_secret": "<client_secret>",
  "payment_method": "card",
  "payment_method_data": {
    "card": {
      "card_number": "<card_number>",
      "card_exp_month": "<exp_month>",
      "card_exp_year": "<exp_year>",
      "card_holder_name": "<cardholder_name>",
      "card_cvc": "<cvc>",
      "card_network": "<network>"
    },
    "billing": {
      "address": {
        "first_name": "<first_name>",
        "last_name": "<last_name>"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### 处理响应

- 如果响应 **`status`** 为 **`requires_customer_action`**，请将客户重定向到 **`next_action`** 字段中提供的 URL，以进行进一步身份验证。

<Warning>
处理 raw card 数据时，请确保遵守 PCI 合规指南。
</Warning>

## Apple Pay 集成

要使用 Apple Pay，请将 `payment_method` 设置为 `wallet`，并将 Apple Pay 数据包含在 `payment_method_data` 中。

### 请求正文结构

```json
{
  "client_secret": "<client_secret>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "apple_pay": {
        "payment_data": "<decrypted_payment_data>",
        "payment_method": {
          "display_name": "Visa 1234",
          "network": "Visa",
          "type": "debit"
        },
        "transaction_identifier": "UNIQUE_TRANSACTION_ID_FROM_APPLE"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Apple Pay 字段参考

| 字段 | 类型 | 必需 | 描述 |
| --- | --- | --- | --- |
| `payment_data` | string | 是 | 此 enum 用于表示 Apple Pay 付款数据，该数据可以是加密或解密的。 |
| `payment_method.display_name` | string | 是 | Apple Pay 按钮上显示的名称（例如，"Visa 1234"） |
| `payment_method.network` | string | 是 | 卡片网络（例如，"Visa"、"Mastercard"、"Amex"） |
| `payment_method.type` | string | 是 | 付款方式类型（例如，"debit"、"credit"） |
| `payment_method.card_exp_month` | string | 否 | 卡片到期月份（例如，"12"） |
| `payment_method.card_exp_year` | string | 否 | 卡片到期年份（例如，"25"） |
| `transaction_identifier` | string | 是 | 来自 Apple Pay 的唯一交易标识符 |

## Google Pay 集成

要使用 Google Pay，请将 `payment_method` 设置为 `wallet`，并将 Google Pay 数据包含在 `payment_method_data` 中。

### 请求正文结构

```json
{
  "client_secret": "<client_secret>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "google_pay": {
        "type": "CARD",
        "description": "Visa ending in 1234",
        "info": {
          "card_network": "VISA",
          "card_details": "1234"
        },
        "tokenization_data": {
          "type": "PAYMENT_GATEWAY",
          "token": "<encrypted_payment_token>"
        }
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Google Pay 字段参考

| 字段 | 类型 | 必需 | 描述 |
| --- | --- | --- | --- |
| `type` | string | 是 | 付款方式类型（通常为 "CARD"） |
| `description` | string | 是 | 面向用户显示的付款方式描述 |
| `info.card_network` | string | 是 | 卡片网络（例如，"VISA"、"MASTERCARD"、"AMEX"） |
| `info.card_details` | string | 是 | 卡片的后 4 位数字 |
| `info.assurance_details` | object | 否 | 身份验证保证级别详细信息 |
| `tokenization_data.type` | string | 是 | Tokenization 类型（例如，"PAYMENT_GATEWAY"） |
| `tokenization_data.token` | string | 是 | 来自 Google Pay 的加密付款令牌 |
