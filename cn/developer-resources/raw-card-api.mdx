<Note>
本指南仅涵盖涉及**卡片、Apple Pay和Google Pay**的**一次性支付**。
</Note>

## API端点

| 环境 | 基础URL | 确认支付端点 |
| --- | --- | --- |
| **测试模式** | `https://test.dodopayments.com` | `https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm` |
| **实时模式** | `https://live.dodopayments.com` | `https://api.hs.dodopayments.com/payments/<payment_id>/confirm` |

## 卡支付流程步骤

### 第一步：获取密钥

首先使用以下API创建支付：

- **支付**: [创建支付API](/api-reference/payments/post-payments)

此API返回**`secret_key`**，这是后续步骤所需的。

### 第二步：确认支付

通过调用`payments confirm`端点来确认支付：

- **测试模式**: `POST https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm`
- **实时模式**: `POST https://api.hs.dodopayments.com/payments/<payment_id>/confirm`

在请求体中包括以下细节：

- `client_secret`: 第一步中的密钥
- `payment_method`: 设置为`card`
- `payment_method_data`: 卡片和账单详情
- `browser_info`: 浏览器特定数据（用户代理、屏幕详情等）
- `payment_type`: 明确设置为`normal`（用于一次性支付）

所需的请求头：

- 从DodoPayments支持获得您的发布密钥
- `api-key`: 您的发布密钥（从Dodo Payments团队获取）
- `content-type`: `application/json`

**示例请求体：**

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "card",
  "payment_method_data": {
    "card": {
      "card_number": "<card_number>",
      "card_exp_month": "<exp_month>",
      "card_exp_year": "<exp_year>",
      "card_holder_name": "<cardholder_name>",
      "card_cvc": "<cvc>",
      "card_network": "<network>"
    },
    "billing": {
      "address": {
        "first_name": "<first_name>",
        "last_name": "<last_name>"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### 处理响应

- 如果响应**`status`**为**`requires_customer_action`**，请将客户重定向到**`next_action`**字段中提供的URL，进行进一步的验证。

<Warning>
在处理原始卡数据时，确保遵守PCI合规性指南。
</Warning>

## Apple Pay集成

要使用Apple Pay，将`payment_method`设置为`wallet`，并在`payment_method_data`中包含Apple Pay数据。

### 请求体结构

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "apple_pay": {
        "payment_data": "<decrypted_payment_data>",
        "payment_method": {
          "display_name": "Visa 1234",
          "network": "Visa",
          "type": "debit"
        },
        "transaction_identifier": "UNIQUE_TRANSACTION_ID_FROM_APPLE"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Apple Pay字段参考

| 字段 | 类型 | 必需 | 描述 |
| --- | --- | --- | --- |
| `payment_data` | string | 是 | 此枚举用于表示Apple Pay支付数据，可以是加密或解密的。 |
| `payment_method.display_name` | string | 是 | 显示在Apple Pay按钮上的名称（例如，“Visa 1234”） |
| `payment_method.network` | string | 是 | 卡网络（例如，“Visa”、“Mastercard”、“Amex”） |
| `payment_method.type` | string | 是 | 支付方式类型（例如，“借记”、“信用”） |
| `payment_method.card_exp_month` | string | 否 | 卡有效期月份（例如，“12”） |
| `payment_method.card_exp_year` | string | 否 | 卡有效期年份（例如，“25”） |
| `transaction_identifier` | string | 是 | 来自Apple Pay的唯一交易标识符 |

## Google Pay集成

要使用Google Pay，将`payment_method`设置为`wallet`，并在`payment_method_data`中包含Google Pay数据。

### 请求体结构

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "google_pay": {
        "type": "CARD",
        "description": "Visa ending in 1234",
        "info": {
          "card_network": "VISA",
          "card_details": "1234"
        },
        "tokenization_data": {
          "type": "PAYMENT_GATEWAY",
          "token": "<encrypted_payment_token>"
        }
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Google Pay字段参考

| 字段 | 类型 | 必需 | 描述 |
| --- | --- | --- | --- |
| `type` | string | 是 | 支付方式类型（通常为“CARD”） |
| `description` | string | 是 | 显示给用户的支付方式描述 |
| `info.card_network` | string | 是 | 卡网络（例如，“VISA”、“MASTERCARD”、“AMEX”） |
| `info.card_details` | string | 是 | 卡的最后4位数字 |
| `info.assurance_details` | object | 否 | 认证保证详情 |
| `tokenization_data.type` | string | 是 | 令牌化类型（例如，“PAYMENT_GATEWAY”） |
| `tokenization_data.token` | string | 是 | 来自Google Pay的加密支付令牌 |
