管理您的 Dodo Payments 资源，创建结账会话，并直接从终端测试 Webhook。专为喜欢命令行的开发人员构建。

## 安装

<CodeGroup>

```bash npm (Recommended)
npm install -g dodopayments-cli
```

```bash Bun
bun install -g dodopayments-cli
```

</CodeGroup>

### 手动安装

1. 从 [GitHub Releases](https://github.com/dodopayments/dodopayments-cli/releases) 下载适用于您的系统的最新版本
2. 提取并将二进制文件重命名为 `dodo`
3. 移动到您 PATH 中的目录：

<CodeGroup>

```bash Linux
sudo mv ./dodo /usr/local/bin/
```

```text Windows
move .\dodo C:\Windows\System32\dodo
```

</CodeGroup>

## 认证

使用您的 API 密钥在使用 CLI 之前进行身份验证：

```bash
dodo login
```

这将：
1. 打开您的浏览器到 Dodo Payments API 密钥页面
2. 提示您输入您的 API 密钥
3. 询问您选择环境（**测试模式**或**实时模式**）
4. 将您的凭据本地存储到 `~/.dodopayments/api-key`

<Info>
CLI 支持每个环境存储一个 API 密钥。如果同时配置了测试模式和实时模式密钥，系统会提示您选择当前会话使用哪个环境。
</Info>

## 用法

一般语法是：

```bash
dodo ‹category› ‹sub-command›
```

运行 `dodo` 而不带参数时，将显示所有可用类别。运行 `dodo <category>` 而不带子命令时，将显示该类别的可用子命令。

### 产品

管理您的产品目录。

| 命令 | 描述 |
|---------|-------------|
| `dodo products list` | 列出所有产品（分页） |
| `dodo products create` | 打开仪表盘以创建产品 |
| `dodo products info` | 查看特定产品的详细信息 |

### 支付

查看支付交易。

| 命令 | 描述 |
|---------|-------------|
| `dodo payments list` | 列出所有支付（分页） |
| `dodo payments info` | 获取特定支付的信息 |

### 客户

管理您的客户群。

| 命令 | 描述 |
|---------|-------------|
| `dodo customers list` | 列出所有客户（分页） |
| `dodo customers create` | 创建一个新的客户档案 |
| `dodo customers update` | 更新现有客户的详细信息 |

### 折扣

管理优惠券和折扣。

| 命令 | 描述 |
|---------|-------------|
| `dodo discounts list` | 列出所有折扣（分页） |
| `dodo discounts create` | 创建一个新的基于百分比的折扣 |
| `dodo discounts delete` | 按 ID 删除折扣 |

### 许可证

管理软件许可证。

| 命令 | 描述 |
|---------|-------------|
| `dodo licences list` | 列出所有许可证密钥（分页） |

### 附加组件

管理产品附加组件。

| 命令 | 描述 |
|---------|-------------|
| `dodo addons list` | 列出所有附加组件（分页） |
| `dodo addons create` | 打开仪表盘以创建一个附加组件 |
| `dodo addons info` | 查看特定附加组件的详细信息 |

### 退款

查看退款信息。

| 命令 | 描述 |
|---------|-------------|
| `dodo refund list` | 列出所有退款（分页） |
| `dodo refund info` | 查看特定退款的详细信息 |

### 结账

创建结账会话。

| 命令 | 描述 |
|---------|-------------|
| `dodo checkout new` | 创建一个新的结账会话并获取结账 URL |

结账命令支持高级选项，包括最小地址收集、返回 URL、强制 3D 安全、折扣代码和元数据。

## Webhook 测试

CLI 包含两个强大的工具，用于在开发过程中测试 Webhook：一个 **监听器** 将实时测试 Webhook 转发到您的本地服务器，以及一个 **触发器** 将模拟 Webhook 有效负载发送到任何端点。

### 监听 Webhook

实时将 Dodo Payments 的 Webhook 转发到您的本地开发服务器。

```bash
dodo wh listen
```

<Steps>
<Step title="输入您的本地端点 URL">
  提供您希望接收 Webhook 的本地 URL（例如，`http://localhost:3000/webhook`）。
</Step>

<Step title="自动设置">
  如果尚未存在，CLI 会自动在您的 Dodo Payments 帐户上创建一个 Webhook 端点，然后打开 WebSocket 连接以实时接收事件。
</Step>

<Step title="接收并转发">
  当 Webhook 事件触发时（来自测试支付、订阅更改等），CLI 会接收它，记录事件类型，并将完整请求与头和正文转发到您的本地端点。您端点的响应将被记录并发送回去。
</Step>
</Steps>

<Warning>
Webhook 监听器仅适用于 **测试模式** API 密钥。在使用 `dodo wh listen` 之前，请确保您已使用测试模式密钥登录。
</Warning>

<Tip>
监听器在转发到您的本地端点时保留了原始 Webhook 头（`webhook-id`，`webhook-signature`，`webhook-timestamp`），因此您可以测试签名验证逻辑。
</Tip>

### 触发测试 Webhook

将模拟 Webhook 有效负载发送到任何端点，以便快速测试，无需创建真实交易。

```bash
dodo wh trigger
```

这将指导您：
1. 设置目标 **端点 URL**
2. 可选地配置 **业务 ID**、**产品 ID** 和 **元数据**
3. 从交互式菜单中选择特定 **事件** 进行触发
4. 发送模拟有效负载并查看响应

在每个事件后，您可以选择另一个事件进行触发或退出——使得在一个会话中轻松测试多个事件处理程序。

<Warning>
触发工具发送没有 Webhook 签名的模拟有效负载。通过在您的 Webhook 处理程序中使用 `unsafe_unwrap()` 而不是 `unwrap()` 禁用 Webhook 签名验证，以便测试。
</Warning>

### 支持的 Webhook 事件

| 类别 | 事件 |
|----------|--------|
| **订阅** | `subscription.active`, `subscription.updated`, `subscription.on_hold`, `subscription.renewed`, `subscription.plan_changed`, `subscription.cancelled`, `subscription.failed`, `subscription.expired` |
| **支付** | `payment.success`, `payment.failed`, `payment.processing`, `payment.cancelled` |
| **退款** | `refund.success`, `refund.failed` |
| **争议** | `dispute.opened`, `dispute.expired`, `dispute.accepted`, `dispute.cancelled`, `dispute.challenged`, `dispute.won`, `dispute.lost` |
| **许可证** | `licence.created` |

### 环境变量

| 变量 | 描述 |
|----------|-------------|
| `DODO_WH_TEST_SERVER_URL` | 覆盖 `dodo wh listen` 使用的默认 Webhook 中继服务器 URL |
