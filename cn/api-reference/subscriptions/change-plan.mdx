## 付款失败处理

使用 `on_payment_failure` 参数来控制当计划变更付款失败时发生的情况：

| 值 | 行为 |
|-------|----------|
| `prevent_change` | 保持订阅在当前计划，直到付款成功。计划变更保持待处理状态。 |
| `apply_change` | 无论付款结果如何，立即应用计划变更。这是默认设置。 |

<Info>
如果未指定 `on_payment_failure`，行为将默认使用您在仪表盘中配置的业务级设置。
</Info>

<Tip>
对于您希望在授予访问高级功能之前确保付款的关键升级，请使用 `prevent_change`。
</Tip>
