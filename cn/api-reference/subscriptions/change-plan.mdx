## 处理付款失败

使用 `on_payment_failure` 参数来控制计划变更付款失败时的处理方式：

| 值 | 行为 |
|-------|----------|
| `prevent_change` | 在付款成功之前保持订阅在当前计划上。计划变更保持待定状态。 |
| `apply_change` | 无论付款结果如何立即应用计划变更。这是默认行为。 |

 <Info>
如果未指定 `on_payment_failure`，则行为默认取决于仪表板中配置的业务级设置。
</Info>

## 折扣码

在更改计划时，可以通过传递 `discount_code` 参数来应用折扣码。

| 场景 | 行为 |
|----------|----------|
| 提供了 `discount_code` | 验证并应用折扣到新计划。 |
| 未提供 `discount_code`，现有折扣为 `preserve_on_plan_change=true` | 如果适用于新产品，则保留现有折扣。 |
| 未提供 `discount_code`，无可保留折扣 | 未应用折扣。 |

<Tip>
在计划更改时使用折扣码，为升级提供促销定价，或在将客户迁移到新计划等级时传递代码。
</Tip>

<Tip>
对于关键升级，使用 `prevent_change`，确保在授予高级功能访问权限之前收款。
</Tip>
