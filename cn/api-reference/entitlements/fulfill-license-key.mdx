<Info>
仅将此 endpoint 用于在带有 `fulfillment_mode: manual` 的 License Key entitlement 下创建的授权。该授权必须处于 `Pending` 状态，且未附加密钥。有关完整流程，请参阅 [手动履行](/features/license-keys#manual-fulfillment) 和 [手动 License Key 履行集成指南](/developer-resources/manual-license-key-fulfillment)。
</Info>
