<Info>
仅对在具有 `fulfillment_mode: manual` 的许可证密钥授权下创建的授予使用此端点。授予必须处于 `pending` 状态且没有附加密钥。有关完整流程，请参阅[手动履行](/features/license-keys#manual-fulfillment)和[手动许可证密钥履行集成指南](/developer-resources/manual-license-key-fulfillment)。
</Info>
