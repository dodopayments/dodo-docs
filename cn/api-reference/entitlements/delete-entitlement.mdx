<Warning>
删除权限是一个**软删除操作，它会隐藏客户门户中的现有权限授予**。它不会撤销平台端的访问：

- 与权限相关联的授予仍保留在数据库中，并保持当前的`status`。
- Discord角色、GitHub协作者访问、Notion访问、Telegram会员、许可证密钥和数字文件URL仍然有效。
- 不会触发`entitlement_grant.revoked` webhook，也不会设置`revoked_at` / `revocation_reason`。

客户在其客户门户中将不再看到这些授权，但其在基础平台上的访问权限将继续，直到订阅/付款生命周期撤销它（取消、退款），或者您通过[`DELETE /entitlements/{id}/grants/{grant_id}`](/api-reference/entitlements/revoke-grant)手动撤销每个授权。

如果需要完全切断访问，请先撤销授予，然后删除权限。
</Warning>
