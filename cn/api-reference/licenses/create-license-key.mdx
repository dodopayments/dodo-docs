<Info>
此端点会导入您已有的密钥——`key`、`customer_id` 和 `product_id` 均为必填项。它不会为您生成密钥值。导入已存在的 `key` 会返回 `409 Conflict`。
</Info>

<Info>
通过 API 创建或更新的许可证密钥不会触发向客户发送的电子邮件通知。如果您需要通知客户其许可证密钥，则必须在您的应用程序中单独处理。
</Info>
