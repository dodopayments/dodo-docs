<Warning>
**已弃用的 API**: 许可证密钥现在通过[权限](/features/entitlements/introduction)系统管理。在[许可证密钥权限](/api-reference/entitlements/update-entitlement)上配置激活限制和持续时间，并使用[撤销授权](/api-reference/entitlements/revoke-grant)来禁用客户的密钥。此端点将在将来的版本中移除。
</Warning>

<Info>
通过 API 更新许可证密钥不会向客户发送电子邮件通知。
</Info>
