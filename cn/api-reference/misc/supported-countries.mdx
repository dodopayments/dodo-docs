您将收到一个[ISO Alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2)国家代码的列表，代表我们**当前支持付款**的国家/地区。您可以在[此处](/miscellaneous/list-of-countries-we-accept-payments-from)查看支持的国家/地区的完整列表。随着我们扩展覆盖范围，此列表会定期更新。

<Tip> 注意：可用的选项包括**所有国家**的 ISO Alpha-2 代码，而不仅仅是我们当前支持的国家。请参考支持国家列表以确认可用性。</Tip>
