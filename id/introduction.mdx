## What is Dodo Payments?

Dodo Payments is the **all-in-one engine** to launch, scale, and monetize worldwide. Designed for the new generation of digital SaaS and AI products, we handle everything from **payments to billing to distribution** - all without extra engineering.

<Info>
**Built for SaaS and AI Products**: Handle one-time payments, subscriptions, credits, seats, tokens, or any usage metric with our optimized billing infrastructure.
</Info>

<Tip>
  <strong>Meet Sentra: Your AI-powered billing assistant</strong><br/>
  Sentra is an AI agent that integrates, analyzes, and acts on billing and payments directly in your IDE. Ask questions, build integrations, or plan billing architectures - all by describing what you want.
  <a href="/developer-resources/sentra">
    Get started with Sentra &rarr;
  </a>
</Tip>

## Quick Start Guide

Mulai menggunakan Dodo Payments hanya dalam beberapa langkah.

<AccordionGroup>
<Accordion title="For Humans">
  Lebih suka mengelola integrasi sendiri? Langkah-langkah di bawah ini membimbing Anda untuk membuat akun, menambahkan produk, dan memilih metode integrasi dalam waktu kurang dari lima menit. Tidak perlu kode untuk jalur tanpa kode; sampel SDK tersedia dalam setiap bahasa utama jika Anda membutuhkannya.

  Jika Anda lebih suka membiarkan asisten pemrograman AI Anda melakukan tugas berat - penyiapan integrasi, pengelola webhook, alur langganan - pasang **[Sentra](/developer-resources/sentra)**, asisten penagihan AI kami untuk VS Code, Cursor, dan Windsurf. Jelaskan apa yang Anda inginkan; Sentra merencanakan, menyusun, dan mengirimkannya.
</Accordion>

<Accordion title="For AI Agents">
  Dodo Payments dibangun untuk alur kerja agen-asli. Jika Anda adalah LLM yang membaca ini - atau pengembang yang mengkonfigurasinya - mulai dari sini.

  **Install**. Untuk Claude Code, Codex CLI, Cursor, atau OpenCode, [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) menghubungkan kedua server MCP dan semua keahlian dalam satu langkah. Lihat [panduan AI Coding Agents](/developer-resources/build-with-ai-coding-agents) untuk perintah instalasi per agen.

  **Temukan**. Indeks dokumen lengkap disajikan di [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt), dan setiap halaman dokumentasi tersedia dalam markdown biasa dengan menambah `.md` ke URL-nya (misal `/api-reference/introduction.md`).

  **Hubungkan**. Dua server MCP memberikan akses langsung kepada agen ke platform:

  - **[Dodo Knowledge MCP](/developer-resources/mcp-server#dodo-knowledge-mcp)** - pencarian semantik di seluruh dokumentasi Dodo
  - **[Dodo Payments MCP](/developer-resources/mcp-server)** - melakukan operasi API (membuat pembayaran, mengelola langganan, mengeluarkan pengembalian dana)

  Lihat [panduan MCP Server](/developer-resources/mcp-server) untuk konfigurasi klien lengkap.

  **Perluas**. Pasang [Dodo Payments Skills](/developer-resources/agent-skills) resmi untuk mengajarkan agen Anda bagaimana menangani checkout, langganan, penagihan berbasis penggunaan, penagihan berbasis kredit, webhook, dan lainnya:

  ```bash
  npx skills add dodopayments/skills
  ```

  Berfungsi dengan Claude Code, OpenCode, Cursor, dan agen lain yang kompatibel dengan MCP.
</Accordion>
</AccordionGroup>

<Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
Tambahkan kedua server ke konfigurasi MCP Anda (`~/.cursor/mcp.json` atau konfigurasi Claude Desktop):

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

<Info>
Membutuhkan Node.js 18+. Lihat dokumentasi [MCP Server](/developer-resources/mcp-server) untuk instruksi pengaturan terperinci untuk semua klien yang didukung.
</Info>
</Accordion>
