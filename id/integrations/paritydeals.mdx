## Pendahuluan

[ParityDeals](https://www.paritydeals.com/) adalah platform yang menampilkan banner diskon berbasis lokasi kepada pengunjung yang memenuhi syarat di situs web Anda dan secara otomatis membuat kode diskon yang sesuai di Dodo Payments. Saat pengunjung melihat banner tersebut, mereka mendapatkan kode yang dapat digunakan saat checkout. Kode tersebut muncul di dashboard Dodo Payments Anda, di **Sales → Discounts**.

<Note>
Dodo Payments memiliki [Purchasing Power Parity](/features/purchasing-power-parity) native, yang mengurangi harga berdasarkan negara saat checkout tanpa banner dan tanpa skrip. ParityDeals ditujukan bagi merchant yang ingin menampilkan banner diskon yang terlihat di situs mereka sendiri, atau yang ingin menjalankan penawaran liburan dan berbasis waktu.
</Note>

## Cara Kerja

ParityDeals mendeteksi lokasi pengunjung, menampilkan banner diskon yang dapat disesuaikan di situs web Anda, dan membuat kode diskon yang dapat digunakan saat checkout. Kode tersebut dibuat secara otomatis di akun Dodo Payments Anda dan berfungsi pada produk yang Anda konfigurasi.

1. Pengunjung membuka situs web Anda dan ParityDeals mendeteksi lokasi mereka.
2. Jika pengunjung memenuhi syarat untuk mendapatkan diskon, banner akan muncul dengan kode berbasis lokasi.
3. Pengunjung menggunakan kode tersebut saat checkout, dan Dodo Payments menerapkan diskonnya.
4. Kode tersebut muncul di dashboard Anda, di **Sales → Discounts**.

## ParityDeals vs PPP Native

Purchasing Power Parity native adalah cara yang direkomendasikan untuk menetapkan harga berdasarkan negara. Pilih ParityDeals jika Anda secara khusus memerlukan banner diskon di situs sendiri, atau kampanye liburan dan berbasis waktu.

| | PPP Native | ParityDeals |
| :--- | :--- | :--- |
| Cara kerja | Persentase per negara, diterapkan saat checkout | Persentase potongan, diterapkan melalui kode |
| Tempat konfigurasi | Terintegrasi di Dodo Payments | Dashboard ParityDeals |
| Banner atau skrip di situs Anda | Tidak diperlukan | Diperlukan |
| Penawaran liburan dan berbasis waktu | Tidak | Ya |
| Paling sesuai untuk | Harga yang tepat, tanpa perubahan pada situs | Banner promosi dan penawaran musiman |

<Info>
Anda tidak dapat menyematkan banner ParityDeals di checkout atau storefront yang di-host oleh Dodo Payments karena skrip kustom tidak didukung di sana. Banner tersebut harus ditempatkan di situs web atau aplikasi Anda sendiri.
</Info>

## Prasyarat

Sebelum menyiapkan integrasi ini, pastikan Anda memiliki:

1. [Akun Dodo Payments](https://app.dodopayments.com)
2. [Akun ParityDeals](https://app.paritydeals.com/)
3. API key Dodo Payments

## Memulai

<Steps>
  <Step title="Sign up on ParityDeals">
    Kunjungi [app.paritydeals.com](https://app.paritydeals.com/) dan buat akun.
  </Step>

  <Step title="Create Deals">
    Setelah masuk, cari opsi untuk membuat deals. Dari menu dropdown, pilih **"Create Deals via Dodo Payments"**.

    <Frame>
      <img src="/images/integrations/paritydeals/create-deals.png" alt="Creating deals via Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Masuk ke **dashboard Dodo Payments** Anda dan buka **Developers → API Keys**. Klik **"Create New API"**.

    <Tip>
      Beri nama API key Anda secara deskriptif (misalnya, 'ParityDeals') agar dapat diidentifikasi nanti.
    </Tip>

    <Frame>
      <img src="/images/integrations/paritydeals/api-key.png" alt="Creating a new API key in Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Salin API key yang Anda buat dan tempelkan ke antarmuka ParityDeals untuk menghubungkannya dengan akun Dodo Payments Anda.

    <Frame>
      <img src="/images/integrations/paritydeals/connect-api-key.png" alt="Connecting API key to ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Setelah terhubung, ParityDeals akan mengambil katalog produk Dodo Payments Anda. Pilih produk yang ingin dikaitkan dengan deals Anda.

    <Frame>
      <img src="/images/integrations/paritydeals/select-products.png" alt="Selecting products for ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Masukkan URL situs web Anda dan, secara opsional, pilih halaman target tertentu tempat banner diskon harus muncul. Lalu pilih jenis deal yang Anda inginkan:
    - Deal berbasis lokasi
    - Deal liburan
    - Deal kilat berbasis waktu

    <Frame>
      <img src="/images/integrations/paritydeals/deal-settings.png" alt="Configuring deal settings" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Pilih negara yang ingin Anda tawarkan diskon lokal dan tentukan persentase diskon untuk masing-masing negara. ParityDeals menyediakan nilai default yang direkomendasikan dan dapat Anda sesuaikan sesuai kebutuhan.

    <Frame>
      <img src="/images/integrations/paritydeals/country-rules.png" alt="Setting country-based discount rules" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Rancang banner diskon Anda dengan menyesuaikan teks, memilih warna dan tata letak, serta menentukan posisi banner (bagian atas atau bawah halaman). Banner ini akan ditampilkan kepada pengunjung yang memenuhi syarat berdasarkan aturan yang Anda konfigurasi.

    <Frame>
      <img src="/images/integrations/paritydeals/customize-banner.png" alt="Customizing the discount banner" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Setelah menyimpan deal, ParityDeals akan membuat skrip. Tambahkan skrip ini ke kode situs web Anda (biasanya di bagian `<head>`). Skrip ini secara otomatis mendeteksi lokasi pengunjung dan menampilkan banner diskon yang sesuai.

    <Frame>
      <img src="/images/integrations/paritydeals/script.png" alt="ParityDeals integration script" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>
