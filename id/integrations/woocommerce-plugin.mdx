## Pendahuluan

Plugin WooCommerce Dodo Payments menyediakan integrasi yang mulus dengan toko Anda, memungkinkan Anda untuk menerima pembayaran melalui berbagai metode termasuk UPI, kartu, perbankan internet, dan dompet digital. Panduan komprehensif ini akan memandu Anda melalui proses instalasi dan konfigurasi.

## Panduan Instalasi Langkah-demi-Langkah

1. Unduh zip terbaru dari plugin pembayaran WooCommerce.

    <Card title="Download Plugin" icon="download" href="https://github.com/dodopayments/dodo-woocommerce/releases">
    Dapatkan versi terbaru plugin WooCommerce kami
    </Card>

    Sebagai alternatif, Anda dapat menginstal langsung dari direktori plugin WordPress:
    
    <Card title="WordPress Plugin Directory" icon="wordpress" href="https://wordpress.org/plugins/dodo-payments-for-woocommerce/">
    Install Dodo Payments for WooCommerce from WordPress.org
    </Card>

2. Masuk ke situs web WordPress Anda sebagai administrator (kami menganggap Anda sudah menyiapkan WooCommerce)
3. Navigasikan ke **Plugins → Add New Plugin**
    
    <Frame>
        <img src="/images/woocommerce/1.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
4. Klik tombol **Upload Plugin** dan dialog pemilihan file akan muncul

    <Frame>
        <img src="/images/woocommerce/2.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
    <Frame>
        <img src="/images/woocommerce/3.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
5. Klik **Browse…** dan pilih file zip yang Anda unduh
6. Klik tombol **Install Now** untuk memulai proses instalasi
    
    <Frame>
        <img src="/images/woocommerce/4.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
7. Setelah instalasi selesai, klik **Activate Plugin** atau aktifkan dari bagian **Installed Plugins**
    
    <Frame>
        <img src="/images/woocommerce/5.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
8. Plugin sekarang terinstal, tetapi konfigurasi masih diperlukan. Lanjutkan ke panduan pengaturan di bawah ini.

## Panduan Konfigurasi

### Menyiapkan Kunci API dan Webhook

1. Navigasikan ke **WooCommerce → Settings → Payments** atau klik tombol **Payments** di bilah samping kiri di bawah item menu WooCommerce
    
    <Frame>
        <img src="/images/woocommerce/6.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
    <Frame>
        <img src="/images/woocommerce/7.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
2. Aktifkan penyedia pembayaran **Dodo Payments** jika belum diaktifkan, lalu klik **Manage** untuk mengonfigurasi plugin
3. Anda akan melihat berbagai opsi konfigurasi, masing-masing dengan teks penjelasan yang membantu. Mulailah dengan mengatur Live API Key Anda
    
    <Frame>
        <img src="/images/woocommerce/8.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
4. Masuk ke dasbor Dodo Payments Anda dalam **Live Mode**, lalu navigasikan ke **Dodo Payments (Live Mode) > Developer > API Keys** atau kunjungi [tautan langsung ini](https://app.dodopayments.com/developer/api-keys) dan klik **Add API Key**
    
    <Frame>
        <img src="/images/woocommerce/9.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
5. Beri nama yang deskriptif untuk API Key Anda dan klik **Create**
    
    <Frame>
        <img src="/images/woocommerce/10.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
6. Salin API Key yang dihasilkan dan tempelkan ke dalam field **Live API Key** di pengaturan plugin WooCommerce Anda
    
    <Frame>
        <img src="/images/woocommerce/11.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
    <Frame>
        <img src="/images/woocommerce/12.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
7. Selanjutnya, atur Webhook Signing Key untuk mengaktifkan sinkronisasi status pembayaran antara Dodo Payments dan WooCommerce
8. Gulir ke bagian bawah halaman pengaturan plugin dan salin URL webhook yang ditampilkan di sana
    
    <Frame>
        <img src="/images/woocommerce/13.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
9. Kembali ke dasbor Dodo Payments Anda dan navigasikan ke **Dodo Payments (Live Mode) > Developer > Webhooks** dan klik **Add Webhook**
    
    <Frame>
        <img src="/images/woocommerce/14.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
10. Tempelkan URL yang Anda salin pada langkah 8 ke dalam dialog dan klik **Add Webhook**
    
    <Frame>
        <img src="/images/woocommerce/15.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
11. Setelah membuat webhook, klik ikon mata di sebelah **Signing Key** yang disembunyikan untuk menampilkan dan menyalinnya
    
    <Frame>
        <img src="/images/woocommerce/16.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
12. Tempelkan Signing Key ke dalam field **Live Webhook Signing Key** di pengaturan plugin Anda dan simpan perubahan
    
    <Frame>
        <img src="/images/woocommerce/17.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
13. Tinjau pengaturan lainnya seperti **Global Tax Category** dan **All Prices are Tax Inclusive**, karena opsi-opsi ini menentukan bagaimana produk disinkronkan dari WooCommerce ke Dodo Payments. Perhatikan bahwa **Test API Key** dan **Test Webhook Signing Key** hanya diperlukan jika Anda berencana menggunakan Test Mode
    
    <Frame>
        <img src="/images/woocommerce/18.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>

## Fitur Utama

- **Pengalaman Checkout yang Mulus**: Arahkan pelanggan ke halaman checkout yang aman dan dioptimalkan
- **Berbagai Metode Pembayaran**: Dukungan untuk berbagai opsi pembayaran lokal dan internasional
- **Pembaruan Status Waktu Nyata**: Sinkronisasi status pesanan instan melalui webhook
- **Rekaman Transaksi yang Detail**: Riwayat pembayaran yang komprehensif di dasbor WooCommerce Anda
- **Dukungan Multi-mata Uang**: Terima pembayaran dalam berbagai mata uang

## Pemecahan Masalah

### Masalah Umum

1. **Kegagalan Pemrosesan Pembayaran**
   - Verifikasi kunci API telah dikonfigurasi dengan benar
   - Pastikan URL webhook telah diatur dengan benar
   - Periksa bahwa sertifikat SSL Anda valid

2. **Masalah Sinkronisasi Webhook**
   - Konfirmasi kunci penandatangan webhook cocok
   - Tinjau log server untuk potensi kesalahan
   - Verifikasi server Anda dapat menerima permintaan webhook yang masuk

### Sumber Daya Dukungan

Untuk bantuan tambahan:
- Hubungi kami di support@dodopayments.com
- Lihat [dokumentasi komprehensif kami](https://docs.dodopayments.com)

## Praktik Terbaik Pemeliharaan

1. Perbarui plugin secara berkala untuk mendapatkan security patches dan fitur baru
2. Uji semua alur pembayaran dalam Test Mode sebelum memproses transaksi live
3. Pastikan WordPress dan WooCommerce selalu diperbarui ke versi terbaru
4. Lakukan backup situs secara berkala
5. Pantau log transaksi untuk mendeteksi aktivitas yang tidak biasa
6. Simpan API keys dengan aman dan jangan pernah membagikannya secara publik
