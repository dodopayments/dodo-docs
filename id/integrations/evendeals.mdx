## Pendahuluan

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) adalah platform yang membuat dan menyinkronkan kupon diskon purchasing power parity berbasis lokasi ke akun Dodo Payments Anda. Platform ini mendukung produk sekali bayar dan berlangganan, serta secara otomatis membuat kode diskon yang berotasi sesuai jadwal yang Anda tentukan.

<Frame>
  <img src="/images/integrations/evendeals/hero.png" alt="Ikhtisar integrasi Evendeals dengan Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Note>
Dodo Payments memiliki [Purchasing Power Parity](/features/purchasing-power-parity) native, yang menurunkan harga berdasarkan negara saat checkout tanpa banner, script, atau kode kupon yang perlu dikelola. Evendeals ditujukan bagi merchant yang secara khusus menginginkan pendekatan berbasis kode diskon dengan rotasi kupon otomatis.
</Note>

## Cara Kerjanya

Evendeals terhubung ke akun Dodo Payments Anda melalui API key. Setelah terhubung, Anda mengonfigurasi diskon persentase untuk setiap grup negara. Evendeals kemudian membuat kode diskon di akun Dodo Payments Anda secara otomatis dan merotasinya sesuai jadwal yang Anda tetapkan (berdasarkan interval waktu, jumlah redemption, atau jumlah tampilan) untuk mencegah penyalahgunaan.

## Evendeals vs PPP Native

Purchasing Power Parity native adalah cara yang direkomendasikan untuk menetapkan harga berdasarkan negara, karena tidak memerlukan kode kupon dan tidak dapat dibagikan atau disalahgunakan. Pilih Evendeals jika Anda secara khusus menginginkan pendekatan berbasis kode diskon.

| | PPP Native | Evendeals |
| :--- | :--- | :--- |
| Cara kerja | Persentase per negara, diterapkan saat checkout | Persentase potongan harga, diterapkan melalui kode |
| Tempat dikonfigurasi | Terintegrasi dalam Dodo Payments | Dasbor Evendeals |
| Banner atau script diperlukan | Tidak diperlukan | Tidak diperlukan |
| Rotasi kupon / auto-refresh | Tidak berlaku | Ya |
| Dukungan berlangganan | Ya | Ya |
| Terbaik untuk | Harga yang tepat tanpa perubahan pada situs | Pendekatan berbasis kode diskon dengan rotasi otomatis |

## Fitur Utama

- **Sinkronisasi kupon otomatis** — Kupon dibuat dan dikelola di Dodo Payments secara otomatis
- **Diskon persentase** — Tawarkan diskon persentase untuk setiap grup negara
- **Dukungan berlangganan** — Diskon berlaku di seluruh siklus penagihan berlangganan
- **Aturan auto-refresh** — Rotasikan kode kupon secara otomatis berdasarkan interval waktu, jumlah redemption, atau jumlah tampilan untuk mencegah penyalahgunaan

<Info>
Kode diskon yang dibuat oleh Evendeals akan otomatis muncul di dasbor Dodo Payments Anda di **Sales → Discounts**.
</Info>

## Prasyarat

Sebelum menyiapkan integrasi ini, pastikan Anda memiliki:

1. [Akun Dodo Payments](https://app.dodopayments.com)
2. [Akun Evendeals](https://www.evendeals.com/signin)
3. API key Dodo Payments

## Memulai

<Steps>
  <Step title="Create a Dodo Payments API Key">
    Di dasbor Dodo Payments Anda, buka **Developers → API Keys** dan klik **Create New API**. Beri nama yang deskriptif (misalnya, "Evendeals") agar Anda dapat mengidentifikasinya nanti.
  </Step>

  <Step title="Connect in Evendeals">
    Di [dasbor Evendeals](https://www.evendeals.com/signin), buka **Integrations**, cari kartu Dodo Payments, lalu tempel API key Anda.
  </Step>

  <Step title="Configure Regional Discounts">
    Tetapkan diskon persentase untuk setiap grup negara dan klik sync. Evendeals membuat kupon di Dodo Payments secara otomatis.

    <Check>
    Setelah sinkronisasi, buka **Sales → Discounts** di dasbor Dodo Payments Anda untuk memastikan kupon yang dibuat telah muncul. Setiap kupon akan memiliki awalan Evendeals yang mudah dikenali.
    </Check>
  </Step>
</Steps>
