Kelola sumber daya Pembayaran Dodo Anda, buat sesi checkout, dan uji webhook langsung dari terminal. Dibangun untuk pengembang yang lebih memilih command line.

## Instalasi

<CodeGroup>

```bash npm (Recommended)
npm install -g dodopayments-cli
```

```bash Bun
bun install -g dodopayments-cli
```

</CodeGroup>

### Instalasi Manual

1. Unduh rilis terbaru dari [GitHub Releases](https://github.com/dodopayments/dodopayments-cli/releases) untuk sistem Anda
2. Ekstrak dan ganti nama biner menjadi `dodo`
3. Pindahkan ke direktori dalam PATH Anda:

<CodeGroup>

```bash Linux
sudo mv ./dodo /usr/local/bin/
```

```text Windows
move .\dodo C:\Windows\System32\dodo
```

</CodeGroup>

## Autentikasi

Sebelum menggunakan CLI, autentikasi dengan kunci API Anda:

```bash
dodo login
```

Ini akan:
1. Membuka browser Anda ke halaman Kunci API Pembayaran Dodo
2. Meminta Anda untuk memasukkan Kunci API Anda
3. Meminta Anda untuk memilih lingkungan (**Mode Uji** atau **Mode Langsung**)
4. Menyimpan kredensial Anda secara lokal ke `~/.dodopayments/api-key`

<Info>
CLI mendukung penyimpanan satu kunci API per lingkungan. Jika kunci mode uji dan mode langsung dikonfigurasi, Anda akan diminta untuk memilih lingkungan mana yang akan digunakan untuk sesi saat ini.
</Info>

## Penggunaan

Sintaks umum adalah:

```bash
dodo ‹category› ‹sub-command›
```

Menjalankan `dodo` tanpa argumen menampilkan semua kategori yang tersedia. Menjalankan `dodo <category>` tanpa subperintah menunjukkan subperintah yang tersedia untuk kategori tersebut.

## Pengujian Webhook

CLI menyertakan dua alat yang kuat untuk pengujian webhook selama pengembangan: **listener** yang meneruskan webhook pengujian langsung ke server lokal Anda, dan **trigger** yang mengirimkan beban payload webhook tiruan ke endpoint mana pun.

### Dengarkan Webhook

Teruskan webhook dari Pembayaran Dodo langsung ke server pengembangan lokal Anda secara real time.

```bash
dodo wh listen
```

<Steps>
<Step title="Masukkan URL endpoint lokal Anda">
  Berikan URL lokal di mana Anda ingin menerima webhook (mis. `http://localhost:3000/webhook`).
</Step>

<Step title="Pengaturan otomatis">
  CLI secara otomatis membuat endpoint webhook di akun Pembayaran Dodo Anda jika belum ada, kemudian membuka koneksi WebSocket untuk menerima acara secara real time.
</Step>

<Step title="Terima dan terusan">
  Ketika suatu event webhook terjadi (dari pembayaran uji, perubahan langganan, dll.), CLI menerima, mencatat jenis event tersebut, dan meneruskan permintaan lengkap dengan header dan body ke endpoint lokal Anda. Respon dari endpoint Anda dicatat dan dikirim kembali.
</Step>
</Steps>

<Warning>
Pendengar webhook hanya berfungsi dengan kunci API **mode uji**. Pastikan Anda masuk dengan kunci mode uji sebelum menggunakan `dodo wh listen`.
</Warning>

<Tip>
Pendengar mempertahankan header webhook asli (`webhook-id`, `webhook-signature`, `webhook-timestamp`) saat meneruskan ke endpoint lokal Anda, sehingga Anda dapat menguji logika verifikasi tanda tangan Anda.
</Tip>

### Pemicu Webhook Uji

Kirim payload webhook tiruan ke endpoint mana pun untuk pengujian cepat tanpa perlu membuat transaksi nyata.

```bash
dodo wh trigger
```

Ini memandu Anda melalui:
1. Menetapkan **URL endpoint** tujuan
2. Opsi mengonfigurasi **ID Bisnis**, **ID Produk**, dan **Metadata**
3. Memilih **event** tertentu untuk dipicu dari menu interaktif
4. Mengirimkan payload tiruan dan melihat responsnya

Setelah setiap event, Anda dapat memilih event lain untuk dipicu atau keluar -- membuatnya mudah untuk menguji beberapa pengelola event dalam satu sesi.

<Warning>
Alat pemicu mengirimkan payload tiruan tanpa tanda tangan webhook. Nonaktifkan verifikasi tanda tangan webhook selama pengujian dengan menggunakan `unsafe_unwrap()` alih-alih `unwrap()` dalam pengelola webhook Anda.
</Warning>

### Event Webhook yang Didukung

| Kategori | Event |
|----------|--------|
| **Langganan** | `subscription.active`, `subscription.updated`, `subscription.on_hold`, `subscription.renewed`, `subscription.plan_changed`, `subscription.cancelled`, `subscription.failed`, `subscription.expired` |
| **Pembayaran** | `payment.success`, `payment.failed`, `payment.processing`, `payment.cancelled` |
| **Pengembalian** | `refund.success`, `refund.failed` |
| **Perselisihan** | `dispute.opened`, `dispute.expired`, `dispute.accepted`, `dispute.cancelled`, `dispute.challenged`, `dispute.won`, `dispute.lost` |
| **Lisensi** | `licence.created` |

### Variabel Lingkungan

| Variabel | Deskripsi |
|----------|-------------|
| `DODO_WH_TEST_SERVER_URL` | Ganti URL server relay webhook default yang digunakan oleh `dodo wh listen` |
