## Overview

Agent Skills are reusable capabilities that enhance what AI coding assistants can do when working with Dodo Payments. They provide procedural knowledge and best practices that help agents accomplish specific tasks more effectively - from integrating checkout flows to setting up usage-based billing.

<Info>
**Think of skills as plugins for your AI assistant.** They teach your agent how to implement Dodo Payments features correctly, following our recommended patterns and best practices.
</Info>

Skills dapat digunakan dengan AI agent apa pun yang mendukung skills protocol, termasuk:
- **Claude Code** - asisten coding CLI dari Anthropic
- **Codex CLI** - coding agent CLI dari OpenAI
- **Cursor** - code editor yang mengutamakan AI
- **VS Code / GitHub Copilot** - melalui Agent Plugin
- **Kiro** - memuat skills sebagai Power
- **OpenCode** - AI coding agent open source
- **Klien lain** - agent apa pun yang mendukung skills protocol

<Note>
**Gemini CLI adalah pengecualian.** Gemini CLI tidak memiliki agent-skill primitive, sehingga skills tidak tersedia di sana — hanya dua [MCP servers](/developer-resources/mcp-server) yang tersedia.
</Note>

## Instalasi

Pilih metode instalasi yang Anda sukai berdasarkan AI coding assistant Anda.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Jika Anda menggunakan Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro, atau OpenCode, [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) menginstal ketujuh belas skills serta kedua MCP servers dalam satu langkah. Skills dimuat secara otomatis saat agent Anda mendeteksi tugas yang relevan.

Lihat [AI Coding Agents guide](/developer-resources/build-with-ai-coding-agents) untuk perintah instalasi per agent.
</Tab>

<Tab title="Skills CLI">
Instal skills menggunakan universal skills CLI yang berfungsi dengan agent apa pun yang kompatibel dengan MCP:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Atau instal skills satu per satu sesuai kebutuhan:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/dodo-best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
Instal hanya skills yang Anda perlukan agar agent tetap fokus dan mengurangi context overhead.
</Tip>
</Tab>

<Tab title="Claude Code">

<Tab title="OpenCode">
OpenCode memuat skills dari direktori yang Anda tentukan. OpenCode **tidak** memindai package yang terinstal, sehingga entri `skills.paths` eksplisit diperlukan.

Menggunakan package Agent Plugin:

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

Path relatif diselesaikan berdasarkan **direktori project**, sehingga package harus tersedia di `node_modules` project tersebut. Absolute path juga dapat digunakan dan tidak memerlukan instalasi lokal.

<Warning>
Skills path yang tidak ada akan diabaikan **secara diam-diam** — tanpa error atau warning. Konfirmasikan bahwa skills benar-benar dimuat:

```bash
opencode run "List every skill available to you by name."
```

Anda akan melihat ketujuh belas skills.
</Warning>
</Tab>
</Tabs>

## Menggunakan Skills

Setelah terinstal, AI assistant Anda akan memuat skill yang relevan secara otomatis saat Anda memintanya mengimplementasikan fitur Dodo Payments. Anda tidak perlu menyebutkan nama skill — cukup jelaskan tugasnya.

| Contoh prompt | Skill yang dimuat |
|----------------|------------------|
| Bantu saya mengintegrasikan Dodo Payments ke aplikasi Next.js saya sesuai best practices | `dodo-best-practices` |
| Tambahkan checkout route handler Dodo Payments ke aplikasi Hono saya | `framework-adapters` |
| Pandu saya menguji pembayaran dan melakukan go-live | `testing-and-go-live` |
| Buat checkout session untuk produk SaaS saya | `checkout-integration` |
| Implementasikan alur subscription dengan free trial dan beberapa pricing tier | `subscription-integration` |
| Tambahkan checkout in-app ke aplikasi React Native saya | `mobile-checkout` |
| Siapkan webhook handlers untuk event payment dan subscription | `webhook-integration` |
| Siapkan credit entitlements dan metered credit deduction untuk produk AI saya | `credit-based-billing` |
| Tambahkan usage-based billing untuk melacak API calls pada produk AI saya | `usage-based-billing` |
| Implementasikan license key validation untuk aplikasi desktop saya | `license-keys` |
| Buat product catalog dengan add-ons dan tiered pricing | `product-catalog-management` |
| Tambahkan promo code yang memberikan diskon 20% untuk tiga billing cycle pertama | `discounts-and-promotions` |
| Tampilkan harga dalam mata uang lokal pengunjung dengan purchasing power parity | `localized-pricing` |
| Berikan pelanggan portal self-service untuk mengelola payment methods mereka | `customer-management` |
| Terbitkan partial refund dan cabut akses saat dispute dibuka | `refunds-and-disputes` |
| Tambahkan halaman pricing menggunakan komponen BillingSDK | `billing-sdk` |
| Integrasikan Dodo Payments ke penyiapan Better Auth saya | `better-auth-integration` |

## Cara Kerja Skills

Skills memberikan AI assistant Anda:

1. **Pengetahuan Prosedural** - Instruksi langkah demi langkah untuk mengimplementasikan fitur
2. **Template Kode** - Pola dan snippet kode yang siap digunakan di production
3. **Best Practices** - Pendekatan yang direkomendasikan untuk security, error handling, dan UX
4. **Kesadaran Konteks** - Pemahaman tentang cara berbagai fitur Dodo Payments bekerja bersama

Saat Anda meminta AI assistant mengimplementasikan sebuah fitur, AI assistant tersebut menggunakan skill yang relevan untuk:
- Memahami pendekatan implementasi yang tepat
- Menghasilkan kode yang akurat dan berfungsi
- Mengikuti konvensi Dodo Payments
- Menangani edge cases dan error dengan tepat

<Note>
Skills melengkapi [MCP Server](/developer-resources/mcp-server) dan [Sentra](/developer-resources/sentra). Gunakan MCP untuk operasi API, Sentra untuk integrasi terpandu, dan Skills untuk meningkatkan kemampuan AI assistant.
</Note>
