## Overview

Agent Skills are reusable capabilities that enhance what AI coding assistants can do when working with Dodo Payments. They provide procedural knowledge and best practices that help agents accomplish specific tasks more effectively - from integrating checkout flows to setting up usage-based billing.

<Info>
**Think of skills as plugins for your AI assistant.** They teach your agent how to implement Dodo Payments features correctly, following our recommended patterns and best practices.
</Info>

Skills work with any MCP-compatible AI agent, including:
- **Claude Code** - Anthropic's CLI coding assistant
- **OpenCode** - Open source AI coding agent
- **Cursor** - AI-first code editor
- **Other MCP clients** - Any agent supporting the skills protocol

## Instalasi

Pilih metode instalasi yang Anda sukai berdasarkan AI coding assistant yang Anda gunakan.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Jika Anda menggunakan Claude Code, Codex CLI, Cursor, atau OpenCode, [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) menginstal ketujuh belas skill serta kedua MCP server dalam satu langkah. Skill dimuat secara otomatis saat agent Anda mendeteksi tugas yang relevan.

Lihat [panduan AI Coding Agents](/developer-resources/build-with-ai-coding-agents) untuk perintah instalasi per agent.
</Tab>

<Tab title="Skills CLI">
Instal skill menggunakan universal skills CLI yang berfungsi dengan agent apa pun yang kompatibel dengan MCP:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Atau instal skill individual sesuai kebutuhan:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
Instal hanya skill yang Anda perlukan agar agent tetap fokus dan mengurangi overhead konteks.
</Tip>
</Tab>

## Menggunakan Skill

Setelah diinstal, AI coding assistant Anda memuat skill yang relevan secara otomatis saat Anda memintanya mengimplementasikan fitur Dodo Payments. Anda tidak perlu menyebutkan nama skill - cukup jelaskan tugasnya.

| Contoh prompt | Skill yang dimuat |
|----------------|------------------|
| Bantu saya mengintegrasikan Dodo Payments ke aplikasi Next.js saya sesuai best practice | `dodo-best-practices` |
| Tambahkan route handler checkout Dodo Payments ke aplikasi Hono saya | `framework-adapters` |
| Pandu saya menguji pembayaran dan melakukan go-live | `testing-and-go-live` |
| Buat checkout session untuk produk SaaS saya | `checkout-integration` |
| Implementasikan alur subscription dengan free trial dan beberapa tingkatan harga | `subscription-integration` |
| Tambahkan checkout dalam aplikasi ke aplikasi React Native saya | `mobile-checkout` |
| Siapkan webhook handler untuk event pembayaran dan subscription | `webhook-integration` |
| Siapkan entitlement kredit dan pengurangan kredit bermeter untuk produk AI saya | `credit-based-billing` |
| Tambahkan usage-based billing untuk melacak panggilan API pada produk AI saya | `usage-based-billing` |
| Implementasikan validasi license key untuk aplikasi desktop saya | `license-keys` |
| Buat katalog produk dengan add-on dan harga bertingkat | `product-catalog-management` |
| Tambahkan kode promo yang memberikan diskon 20% untuk tiga siklus billing pertama | `discounts-and-promotions` |
| Tampilkan harga dalam mata uang lokal pengunjung dengan paritas daya beli | `localized-pricing` |
| Berikan pelanggan portal self-service untuk mengelola payment methods mereka | `customer-management` |
| Terbitkan refund sebagian dan cabut akses saat dispute dibuka | `refunds-and-disputes` |
| Tambahkan halaman harga menggunakan komponen BillingSDK | `billing-sdk` |
| Integrasikan Dodo Payments ke pengaturan Better Auth saya | `better-auth-integration` |

## Cara Kerja Skill

Skill memberikan AI coding assistant Anda:

1. **Pengetahuan Prosedural** - Instruksi langkah demi langkah untuk mengimplementasikan fitur
2. **Template Kode** - Pola dan snippet kode yang siap digunakan di production
3. **Best Practice** - Pendekatan yang direkomendasikan untuk keamanan, penanganan error, dan UX
4. **Kesadaran Konteks** - Pemahaman tentang cara berbagai fitur Dodo Payments bekerja bersama

Saat Anda meminta AI coding assistant mengimplementasikan fitur, assistant tersebut menggunakan skill yang relevan untuk:
- Memahami pendekatan implementasi yang tepat
- Menghasilkan kode yang akurat dan berfungsi
- Mengikuti konvensi Dodo Payments
- Menangani edge case dan error dengan benar

<Note>
Skill melengkapi [MCP Server](/developer-resources/mcp-server) dan [Sentra](/developer-resources/sentra). Gunakan MCP untuk operasi API, Sentra untuk integrasi terpandu, dan Skill untuk meningkatkan kemampuan AI coding assistant.
</Note>
