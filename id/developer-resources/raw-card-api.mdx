<Note>
Panduan ini hanya mencakup **pembayaran sekali** yang melibatkan **kartu, Apple Pay, dan Google Pay**.
</Note>

## Endpoint API

| Lingkungan | URL Dasar | Endpoint Konfirmasi Pembayaran |
| --- | --- | --- |
| **Mode Uji** | `https://test.dodopayments.com` | `https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm` |
| **Mode Langsung** | `https://live.dodopayments.com` | `https://api.hs.dodopayments.com/payments/<payment_id>/confirm` |

## Alur Pembayaran Kartu Langkah-demi-Langkah

### Langkah 1: Dapatkan Kunci Rahasia

Mulailah dengan membuat pembayaran menggunakan API berikut:

- **Pembayaran**: [Buat API Pembayaran](/api-reference/payments/post-payments)

API ini mengembalikan **`secret_key`**, yang diperlukan untuk langkah-langkah selanjutnya.

### Langkah 2: Konfirmasi Pembayaran

Konfirmasi pembayaran dengan memanggil endpoint `payments confirm`:

- **Mode Uji**: `POST https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm`
- **Mode Langsung**: `POST https://api.hs.dodopayments.com/payments/<payment_id>/confirm`

Sertakan rincian berikut dalam badan permintaan:

- `client_secret`: Kunci rahasia dari Langkah 1
- `payment_method`: Disetel ke `card`
- `payment_method_data`: Rincian kartu dan penagihan
- `browser_info`: Data spesifik browser (agen pengguna, rincian layar, dll.)
- `payment_type`: Disetel secara eksplisit ke `normal` (untuk pembayaran sekali)

Header yang diperlukan:

- Dapatkan kunci publik Anda dari dukungan DodoPayments
- `api-key`: Kunci publik Anda (Dapatkan ini dari Tim Dodo Payments)
- `content-type`: `application/json`

**Contoh Badan Permintaan:**


### Menangani Respons

- Jika respons **`status`** adalah **`requires_customer_action`**, arahkan pelanggan ke URL yang diberikan dalam field **`next_action`** untuk otentikasi lebih lanjut.

<Warning>
Pastikan untuk mematuhi pedoman kepatuhan PCI saat menangani data kartu mentah.
</Warning>

## Integrasi Apple Pay

Untuk menggunakan Apple Pay, set `payment_method` ke `wallet` dan sertakan data Apple Pay dalam `payment_method_data`.

### Struktur Badan Permintaan

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "apple_pay": {
        "payment_data": "<decrypted_payment_data>",
        "payment_method": {
          "display_name": "Visa 1234",
          "network": "Visa",
          "type": "debit"
        },
        "transaction_identifier": "UNIQUE_TRANSACTION_ID_FROM_APPLE"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Referensi Bidang Apple Pay

| Field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| `payment_data` | string | Ya | Enum ini digunakan untuk mewakili data pembayaran Apple Pay, yang bisa terenkripsi atau terdekripsi. |
| `payment_method.display_name` | string | Ya | Nama tampilan yang ditampilkan di tombol Apple Pay (misalnya, "Visa 1234") |
| `payment_method.network` | string | Ya | Jaringan kartu (misalnya, "Visa", "Mastercard", "Amex") |
| `payment_method.type` | string | Ya | Tipe metode pembayaran (misalnya, "debit", "kredit") |
| `payment_method.card_exp_month` | string | Tidak | Bulan kedaluwarsa kartu (misalnya, "12") |
| `payment_method.card_exp_year` | string | Tidak | Tahun kedaluwarsa kartu (misalnya, "25") |
| `transaction_identifier` | string | Ya | Identifikasi transaksi unik dari Apple Pay |

## Integrasi Google Pay

Untuk menggunakan Google Pay, set `payment_method` ke `wallet` dan sertakan data Google Pay dalam `payment_method_data`.

### Struktur Badan Permintaan

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "google_pay": {
        "type": "CARD",
        "description": "Visa ending in 1234",
        "info": {
          "card_network": "VISA",
          "card_details": "1234"
        },
        "tokenization_data": {
          "type": "PAYMENT_GATEWAY",
          "token": "<encrypted_payment_token>"
        }
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Referensi Bidang Google Pay

| Field | Tipe | Wajib | Deskripsi |
| --- | --- | --- | --- |
| `type` | string | Ya | Tipe metode pembayaran (biasanya "KARTU") |
| `description` | string | Ya | Deskripsi yang ditampilkan kepada pengguna untuk metode pembayaran |
| `info.card_network` | string | Ya | Jaringan kartu (misalnya, "VISA", "MASTERCARD", "AMEX") |
| `info.card_details` | string | Ya | 4 digit terakhir dari kartu |
| `info.assurance_details` | object | Tidak | Rincian jaminan otentikasi |
| `tokenization_data.type` | string | Ya | Tipe tokenisasi (misalnya, "PAYMENT_GATEWAY") |
| `tokenization_data.token` | string | Ya | Token pembayaran terenkripsi dari Google Pay |
