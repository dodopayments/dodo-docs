Dodo Agent Plugin menghubungkan dua MCP servers dan tujuh belas integration skills ke AI coding agent Anda dalam satu instalasi. Plugin ini berfungsi dengan **Claude Code**, **Codex CLI**, **Cursor**, **VS Code / GitHub Copilot**, **Kiro**, dan **OpenCode**. **Gemini CLI** hanya mendapatkan dua MCP servers. MCP servers dan skills CLI ini berfungsi dengan client apa pun yang kompatibel dengan MCP.

Plugin ini mengikuti spesifikasi [Agent Plugins 1.0.0](https://agent-plugins.org/specification), sehingga client dengan dukungan native dapat memuatnya langsung dari root `plugin.json` dan `mcp.json`. Client yang lebih lama dari spesifikasi ini memuat konten yang sama melalui compatibility manifests yang dibuat secara otomatis.

<Info>
**Tiga primitive, satu plugin.** Agent Plugin menyediakan semua yang Anda butuhkan:
- **API MCP server** — akses langsung ke payments, subscriptions, customers, products, refunds, licenses, dan usage. Melakukan autentikasi melalui browser OAuth (tidak memerlukan local keys).
- **Knowledge MCP server** — pencarian semantik di seluruh dokumentasi Dodo Payments. Tidak memerlukan credentials.
- **Tujuh belas agent skills** — cheat sheets yang dimuat agent sesuai kebutuhan untuk checkout, subscriptions, webhooks, usage-based dan credit-based billing, license keys, product catalog, discounts, localized pricing, mobile checkout, refunds dan disputes, customer management, framework adapters, BillingSDK, Better Auth, testing dan go-live, serta best practices.
</Info>

## Instal plugin

Pilih coding agent Anda di bawah ini. Setiap instalasi menambahkan kedua MCP servers; semua client kecuali Gemini CLI juga menambahkan tujuh belas skills.

<AccordionGroup>
<Accordion title="Claude Code" defaultOpen>
Instal dari marketplace:

```bash
claude plugins marketplace add dodopayments/dodo-agent-plugin
claude plugins install dodopayments@dodopayments
```

API MCP server menggunakan browser OAuth secara default — tidak diperlukan keys saat instalasi. Saat pertama kali agent Anda memanggil Dodo tool, Anda akan diminta untuk sign in.

<Card title="Dodo Agent Plugin on GitHub" icon="github" href="https://github.com/dodopayments/dodo-agent-plugin">
  Source code, configuration options, dan instruksi local development
</Card>
</Accordion>

<Accordion title="Codex CLI">
Codex menginstal plugins dalam dua langkah: daftarkan marketplace dari shell Anda, lalu instal plugin dari dalam Codex TUI.

<Steps>
<Step title="Register the marketplace">

```bash
codex plugin marketplace add dodopayments/dodo-agent-plugin
```

</Step>

<Step title="Install from the Codex TUI">
Buka Codex dan jalankan slash command `/plugins`:

```bash
codex
```

Kemudian ketik `/plugins`, beralih ke marketplace **Dodo Payments**, pilih plugin **dodopayments**, lalu pilih **Install plugin**.
</Step>
</Steps>

Kedua MCP servers dan seluruh tujuh belas skills akan didaftarkan secara otomatis setelah plugin terinstal.

<Note>
Codex CLI tidak memiliki subcommand `codex plugin install` — instalasi plugin selalu dilakukan melalui alur `/plugins` di dalam TUI. Lihat [official Codex plugins docs](https://developers.openai.com/codex/plugins).
</Note>

Jika sebelumnya Anda telah menambahkan marketplace tetapi plugin tidak muncul di bawah `/plugins`, refresh marketplace tersebut:

```bash
codex plugin marketplace upgrade dodopayments
```

</Accordion>

<Accordion title="Cursor">
Instalasi manual — clone repo ke local plugins directory milik Cursor:

```bash
git clone https://github.com/dodopayments/dodo-agent-plugin.git ~/.cursor/plugins/local/dodo-agent-plugin
```

Restart Cursor. Plugin memuat skills dari `skills/` dan MCP servers dari `.mcp.json`, sebagaimana dideklarasikan di `.cursor-plugin/plugin.json`.

<Info>
Build Cursor terbaru juga mengenali Agent Plugins 1.0.0 secara langsung dan menerima `.cursor-plugin/marketplace.json` atau `.claude-plugin/marketplace.json` sebagai marketplace source. Plugin ini menyediakan `.claude-plugin/marketplace.json` — gunakan path tersebut. `.cursor-plugin/plugin.json` yang dibuat secara otomatis dipertahankan untuk build yang lebih lama.
</Info>

<Warning>
Versi sebelum 0.5.0 menyediakan `skills/` sebagai symlinks ke git submodule, sehingga clone tersebut menghasilkan plugin dengan **skills yang tidak berfungsi**. Kini skills disediakan sebagai file nyata. Jika Anda menginstal versi sebelumnya, hapus directory tersebut lalu clone kembali.
</Warning>
</Accordion>

<Accordion title="OpenCode">
OpenCode didistribusikan melalui npm. Tambahkan plugin ke `opencode.json` Anda:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"]
}
```

Restart OpenCode. Kedua MCP servers (`dodopayments-api`, `dodo-knowledge`) didaftarkan secara otomatis melalui config hook plugin. Tidak diperlukan block `mcp` manual.

**Skills memerlukan satu baris tambahan.** OpenCode tidak memindai installed packages untuk mencari skills, jadi arahkan sendiri ke directory `skills/` milik package:

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

Entry `skills.paths` relatif diselesaikan berdasarkan **project directory**, sehingga package harus ada di `node_modules` project tersebut — plugin cache milik OpenCode berada di lokasi yang berbeda. Absolute path juga dapat digunakan dan menghindari persyaratan local install.

<Warning>
Path skills yang tidak ada akan diabaikan **secara diam-diam**. Verifikasi, jangan berasumsi:

```bash
opencode run "List every skill available to you by name."
```

Anda seharusnya melihat ketujuh belas skills. Versi sebelum 0.5.0 mendokumentasikan skills ini sebagai auto-discovered — kenyataannya tidak demikian, sehingga pengguna OpenCode memiliki MCP servers tetapi tidak memiliki skills.
</Warning>
</Accordion>

<Accordion title="VS Code / GitHub Copilot">
Clone repo di lokasi mana pun, lalu daftarkan:

```bash
git clone https://github.com/dodopayments/dodo-agent-plugin.git
```

Buka Chat view, buka **Plugins**, lalu tambahkan folder hasil clone. Anda juga dapat mendaftarkannya langsung di `settings.json`:

```json
{
  "chat.pluginLocations": { "~/dodo-agent-plugin": true }
}
```

Kuncinya adalah path, sedangkan nilainya mengaktifkan plugin. Absolute paths dan `~/` juga berfungsi; relative path diselesaikan berdasarkan setiap workspace folder. Setting ini dibaca secara live, sehingga window yang sedang berjalan dapat memuatnya tanpa restart. Skills dimuat dari `skills/`, dan kedua MCP servers dimuat dari `.mcp.json`.

<Note>
`chat.pluginLocations` ditandai **experimental** dan merupakan setting *restricted*, sehingga workspace harus dipercaya agar setting ini diterapkan. Dukungan agent-plugin secara keseluruhan merupakan fitur preview yang dikendalikan oleh `chat.plugins.enabled`, yang **aktif secara default** — Anda hanya perlu mengaturnya jika organisasi Anda menonaktifkannya berdasarkan policy.
</Note>

<Info>
VS Code tidak menggunakan Agent Plugins `$schema` sebagai key. Loader-nya memeriksa `.plugin/plugin.json`, kemudian `.claude-plugin/plugin.json`, lalu root `plugin.json`, dan menetapkan MCP ke `.mcp.json`, bukan `mcp.json`. Karena repo ini menyediakan `.claude-plugin/plugin.json` yang dibuat secara otomatis, VS Code memuatnya melalui compatibility branch tersebut dan mendapatkan bridge `mcp-remote`, bukan native transports di `mcp.json`. Semuanya tetap berfungsi — hanya path-nya yang berbeda.
</Info>
</Accordion>

<Accordion title="Kiro">
Kiro membaca Agent Plugins manifest secara native dan memuatnya sebagai Power.

<Steps>
<Step title="Clone the repository">

```bash
git clone https://github.com/dodopayments/dodo-agent-plugin.git
```

</Step>

<Step title="Open the Powers panel">
Di Kiro, buka panel Powers — ikon Ghosty dengan lightning bolt.
</Step>

<Step title="Import the folder">
Pilih **Add Custom Power → Import power from a folder**, pilih directory hasil clone (yang berisi `plugin.json`), lalu klik **Install**.
</Step>
</Steps>

Skills dimuat dari `skills/`, MCP servers dari `mcp.json`, dan presentasi khusus Kiro berasal dari extension namespace `dev.kiro` di `plugin.json`.

<Note>
Untuk plugin dalam format Agent Plugins, Kiro mengelola MCP servers secara internal — server tersebut **tidak** ditulis ke `~/.kiro/settings/mcp.json` tingkat pengguna, jadi jangan berharap menemukannya di sana. Kiro juga dapat menginstal Power langsung dari URL GitHub; lihat [Kiro's install docs](https://kiro.dev/docs/powers/installation/).
</Note>
</Accordion>

<Accordion title="Gemini CLI (MCP only)">
Gemini CLI tidak memiliki primitive agent-skill, sehingga **hanya dua MCP servers yang tersedia** — tujuh belas skills tidak tersedia. `dodo-knowledge` tetap mencakup sebagian besar kemampuan yang disediakan skills, dan selalu diperbarui secara otomatis.

```bash
git clone https://github.com/dodopayments/dodo-agent-plugin.git \
  ~/.gemini/extensions/dodopayments
```

Restart Gemini CLI. `gemini-extension.json` di root repo adalah manifest.
</Accordion>
</AccordionGroup>

Menggunakan agent yang berbeda? Panduan [MCP Server](/developer-resources/mcp-server) dan [Agent Skills](/developer-resources/agent-skills) mencakup Claude Desktop, Windsurf, Cline, Zed, dan client apa pun yang kompatibel dengan MCP.
</Info>

## Yang Anda dapatkan

Setelah plugin terinstal, agent Anda memiliki akses ke dua MCP servers dan tujuh belas skills.

### MCP servers

| Server | Tujuan | Auth |
|--------|---------|------|
| `dodopayments-api` | Akses API langsung — payments, subscriptions, customers, products, refunds, licenses, usage | OAuth (browser) |
| `dodo-knowledge` | Pencarian semantik di seluruh dokumentasi Dodo Payments | None |

Kedua server menggunakan Streamable HTTP. `mcp.json` canonical mendeklarasikannya secara native (`type: "streamable-http"`), yang digunakan oleh client native terhadap spesifikasi seperti Codex CLI dan Kiro. Compatibility manifest `.mcp.json` yang dibuat secara otomatis menghubungkan dua endpoint yang sama melalui `mcp-remote`, sehingga keduanya juga berjalan pada client yang tidak dapat terhubung langsung ke Streamable HTTP — Claude Code, VS Code, dan Cursor melalui instalasi git-clone yang didokumentasikan di atas, dengan `.cursor-plugin/plugin.json` yang mengarah ke `.mcp.json`.

### Agent skills

| Skill | Deskripsi |
|-------|-------------|
| `dodo-best-practices` | Penyiapan SDK, environments, API keys, dan arsitektur checkout-to-webhook canonical |
| `framework-adapters` | Route handlers resmi `@dodopayments/*` untuk Next.js, Express, Hono, Astro, Remix, SvelteKit, Nuxt, Fastify, TanStack, Bun, dan Convex |
| `testing-and-go-live` | Test mode, test payment methods, webhook testing, dan production launch checklist |
| `checkout-integration` | Checkout Sessions, payment links, dan checkout overlay atau inline |
| `subscription-integration` | Subscription lifecycle, trials, plan changes, proration, dan on-demand charges |
| `mobile-checkout` | In-app checkout untuk React Native, Flutter, iOS, dan Android |
| `webhook-integration` | Menerima dan memverifikasi webhooks menggunakan spesifikasi Standard Webhooks |
| `credit-based-billing` | Credit entitlements, balances, ledger, rollover, overage, dan meter-based deduction |
| `usage-based-billing` | Meters, event ingestion, aggregation, dan per-unit pricing |
| `license-keys` | Aktivasi dan validasi license key serta instance management |
| `product-catalog-management` | Products, pricing, add-ons, collections, images, dan digital product delivery |
| `discounts-and-promotions` | Discount codes, eligibility rules, stacking, dan subscription-cycle limits |
| `localized-pricing` | Localized pricing, adaptive currency, dan purchasing power parity |
| `customer-management` | Customers, self-service portal, saved payment methods, dan wallets |
| `refunds-and-disputes` | Menerbitkan refunds, menangani disputes dan chargebacks, serta merekonsiliasi akses |
| `billing-sdk` | Komponen BillingSDK React untuk pricing tables dan billing UI |
| `better-auth-integration` | Plugin `@dodopayments/better-auth` untuk customer sync, checkout, dan portal access |

Skills dimuat secara otomatis — agent Anda memilih skill yang tepat saat mendeteksi task yang relevan. Lihat [Agent Skills documentation](/developer-resources/agent-skills) untuk daftar lengkap dan instalasi individual.

### Coba prompt ini terlebih dahulu

Setelah plugin aktif, coba:

```
Set up Dodo Payments webhook handlers in my Next.js app for payment.succeeded and subscription.active events.
```

Agent Anda akan memuat skill `webhook-integration`, menggunakan MCP `dodo-knowledge` untuk mengambil payload shapes terbaru, lalu menulis handler dengan signature verification sesuai spesifikasi Standard Webhooks.

## Keamanan dan best practices

<Warning>
**Jangan pernah commit production API keys.** Gunakan [test mode](/miscellaneous/test-mode-vs-live-mode) selama development. Agent Plugin menggunakan browser OAuth secara default — beralihlah ke local API keys hanya jika workflow Anda memerlukannya.
</Warning>

- **Gunakan test mode terlebih dahulu.** Sandbox integrasi Anda dengan keys `dodo_test_...` sebelum go-live. Lihat [Test Mode vs Live Mode](/miscellaneous/test-mode-vs-live-mode).
- **OAuth adalah default.** Agent Plugin melakukan autentikasi melalui browser OAuth (tanpa local secrets). Gunakan API-key mode hanya jika diperlukan — lihat bagian Configure di bawah.
- **Tinjau code yang dibuat agent.** Selalu pastikan webhook handlers menyertakan signature verification sesuai [Standard Webhooks spec](https://standardwebhooks.com/).

## Konfigurasikan dengan API key

Secara default, Agent Plugin menggunakan remote MCP server dengan browser OAuth — tidak memerlukan local credentials. Jika workflow Anda memerlukan local API key (misalnya, CI environments atau headless servers), Anda dapat beralih ke stdio mode.

<AccordionGroup>
<Accordion title="Local API key mode — Claude Code">
Buka `/plugins` di Claude Code, pilih **Dodo Payments**, lalu pilih **Configure options**. Isi:

- `dodo_api_key` — key `dodo_test_...` atau `dodo_live_...` Anda
- `dodo_webhook_key` — webhook signing secret Anda
- `dodo_environment` — `test_mode` atau `live_mode`

Kemudian edit `.mcp.json` untuk mengarahkan `dodopayments-api` ke local stdio server:

```json
{
  "mcpServers": {
    "dodopayments-api": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "dodopayments-mcp@latest"],
      "env": {
        "DODO_PAYMENTS_API_KEY": "${user_config.dodo_api_key}",
        "DODO_PAYMENTS_WEBHOOK_KEY": "${user_config.dodo_webhook_key}",
        "DODO_PAYMENTS_ENVIRONMENT": "${user_config.dodo_environment}"
      }
    }
  }
}
```

Jalankan `/reload-plugins` untuk menerapkan perubahan ke current session Anda.
</Accordion>

<Accordion title="Local API key mode — OpenCode">
Deklarasikan sendiri `dodopayments-api` di `opencode.json` — entry Anda akan mengalahkan remote server default milik plugin:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "mcp": {
    "dodopayments-api": {
      "type": "local",
      "command": ["npx", "-y", "dodopayments-mcp@latest"],
      "environment": {
        "DODO_PAYMENTS_API_KEY": "dodo_test_...",
        "DODO_PAYMENTS_WEBHOOK_KEY": "whsec_...",
        "DODO_PAYMENTS_ENVIRONMENT": "test_mode"
      },
      "enabled": true
    }
  }
}
```

Restart OpenCode untuk menerapkan perubahan.
</Accordion>
</AccordionGroup>
