Dodo Agent Plugin menghubungkan dua server MCP dan tujuh belas integration skills ke AI coding agent Anda dalam satu kali instalasi. Plugin ini berfungsi dengan **Claude Code**, **Codex CLI**, **Cursor**, dan **OpenCode** — dan CLI server MCP serta skills dapat digunakan dengan client apa pun yang kompatibel dengan MCP.

<Info>
**Tiga primitive, satu plugin.** Agent Plugin menggabungkan semua yang Anda perlukan:
- **API MCP server** — akses langsung ke payments, subscriptions, customers, products, refunds, licenses, dan usage. Melakukan autentikasi melalui browser OAuth (tidak memerlukan key lokal).
- **Knowledge MCP server** — pencarian semantik di seluruh dokumentasi Dodo Payments. Tidak memerlukan kredensial.
- **Tujuh belas agent skills** — lembar contekan yang dimuat agent sesuai kebutuhan untuk checkout, subscriptions, webhooks, usage-based dan credit-based billing, license keys, product catalog, discounts, localized pricing, mobile checkout, refunds dan disputes, customer management, framework adapters, BillingSDK, Better Auth, testing dan go-live, serta best practices.
</Info>

## Instalasi plugin

Pilih coding agent Anda di bawah ini. Instalasi akan menambahkan kedua server MCP dan seluruh tujuh belas skills secara otomatis.

<AccordionGroup>
<Accordion title="Claude Code" defaultOpen>
Instal dari marketplace:

```bash
claude plugins marketplace add dodopayments/dodo-agent-plugin
claude plugins install dodopayments@dodopayments
```

Server MCP API menggunakan browser OAuth secara default — tidak diperlukan kunci saat waktu instalasi. Pertama kali agen Anda memanggil alat Dodo, Anda akan diminta untuk masuk.

<Card title="Dodo Agent Plugin on GitHub" icon="github" href="https://github.com/dodopayments/dodo-agent-plugin">
  Kode sumber, opsi konfigurasi, dan petunjuk pengembangan lokal
</Card>
</Accordion>

<Accordion title="Codex CLI">
Codex menginstal plugin dalam dua langkah: mendaftarkan marketplace dari shell Anda, lalu instal plugin dari dalam Codex TUI.

<Steps>
<Step title="Register the marketplace">

```bash
codex plugin marketplace add dodopayments/dodo-agent-plugin
```

</Step>

<Step title="Install from the Codex TUI">
Buka Codex dan jalankan perintah garis miring `/plugins`:

```bash
codex
```

Kemudian ketik `/plugins`, alihkan ke marketplace **Dodo Payments**, pilih plugin **dodopayments**, dan pilih **Install plugin**.
</Step>
</Steps>

Kedua server MCP dan seluruh tujuh belas skills akan terdaftar secara otomatis setelah plugin diinstal.

<Note>
Codex CLI tidak memiliki subcommand `codex plugin install` — pemasangan plugin selalu dilakukan melalui alur in-TUI `/plugins`. Lihat [dokumentasi plugin Codex resmi](https://developers.openai.com/codex/plugins).
</Note>

Jika Anda sebelumnya sudah menambahkan marketplace dan plugin tidak muncul di bawah `/plugins`, refresh:

```bash
codex plugin marketplace upgrade dodopayments
```

</Accordion>

<Accordion title="Cursor">
Instalasi manual — clone repo ke direktori plugin lokal Cursor:

```bash
git clone https://github.com/dodopayments/dodo-agent-plugin.git ~/.cursor/plugins/local/dodo-agent-plugin
```

Restart Cursor. Plugin memuat skills dari `.claude/skills/` (melalui lapisan kompatibilitas Claude Code Cursor) dan server MCP dari `.mcp.json`.

<Info>
Dukungan marketplace Cursor akan datang. Untuk saat ini, gunakan instalasi manual di atas.
</Info>
</Accordion>

<Accordion title="OpenCode">
OpenCode mendistribusikan melalui npm. Tambahkan plugin ke `opencode.json` Anda:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"]
}
```

Mulai ulang OpenCode. Kedua server MCP (`dodopayments-api`, `dodo-knowledge`) terdaftar secara otomatis melalui config hook plugin, dan tujuh belas skills ditemukan secara otomatis dari package yang diinstal. Tidak diperlukan block `mcp` manual.
</Accordion>
</AccordionGroup>

<Info>
Menggunakan agen yang berbeda? Panduan [MCP Server](/developer-resources/mcp-server) dan [Agent Skills](/developer-resources/agent-skills) mencakup Cursor, Claude Desktop, VS Code, Windsurf, Cline, Zed, dan klien yang kompatibel dengan MCP mana pun.
</Info>

## Apa yang Anda dapatkan

Setelah plugin diinstal, agent Anda memiliki akses ke dua server MCP dan tujuh belas skills.

### Server MCP

| Server | Tujuan | Auth |
|--------|---------|------|
| `dodopayments-api` | Akses API langsung — pembayaran, langganan, pelanggan, produk, pengembalian dana, lisensi, penggunaan | OAuth (browser) |
| `dodo-knowledge` | Pencarian semantik di seluruh dokumentasi Dodo Payments | None |

Kedua server terhubung melalui `mcp-remote` sehingga dapat berjalan di klien yang kompatibel dengan MCP.

### Agent skills

| Skill | Deskripsi |
|-------|-------------|
| `best-practices` | Penyiapan SDK, environment, API keys, dan arsitektur checkout-to-webhook kanonis |
| `framework-adapters` | Route handlers resmi `@dodopayments/*` untuk Next.js, Express, Hono, Astro, Remix, SvelteKit, Nuxt, Fastify, TanStack, Bun, dan Convex |
| `testing-and-go-live` | Test mode, test payment methods, pengujian webhook, dan checklist peluncuran production |
| `checkout-integration` | Checkout Sessions, payment links, dan checkout overlay atau inline |
| `subscription-integration` | Siklus hidup subscription, trial, perubahan plan, proration, dan biaya sesuai permintaan |
| `mobile-checkout` | Checkout dalam aplikasi untuk React Native, Flutter, iOS, dan Android |
| `webhook-integration` | Menerima dan memverifikasi webhook menggunakan spesifikasi Standard Webhooks |
| `credit-based-billing` | Credit entitlements, saldo, ledger, rollover, overage, dan deduction berbasis meter |
| `usage-based-billing` | Meter, ingestion event, agregasi, dan pricing per unit |
| `license-keys` | Aktivasi dan validasi license key, serta pengelolaan instance |
| `product-catalog-management` | Products, pricing, add-ons, collections, images, dan pengiriman produk digital |
| `discounts-and-promotions` | Discount codes, aturan kelayakan, stacking, dan batas siklus subscription |
| `localized-pricing` | Localized pricing, adaptive currency, dan purchasing power parity |
| `customer-management` | Customers, portal mandiri, saved payment methods, dan wallets |
| `refunds-and-disputes` | Menerbitkan refund, menangani dispute dan chargeback, serta merekonsiliasi akses |
| `billing-sdk` | Komponen React BillingSDK untuk tabel pricing dan UI billing |
| `better-auth-integration` | Plugin `@dodopayments/better-auth` untuk sinkronisasi customer, checkout, dan akses portal |

Skills dimuat secara otomatis — agen Anda memilih yang tepat saat mendeteksi tugas yang relevan. Lihat [dokumentasi Agent Skills](/developer-resources/agent-skills) untuk daftar lengkap dan instalasi individual.

### Coba prompt ini terlebih dahulu

Setelah plugin aktif, coba:

```
Set up Dodo Payments webhook handlers in my Next.js app for payment.succeeded and subscription.active events.
```

Agen Anda akan memuat skill `webhook-integration`, menggunakan MCP `dodo-knowledge` untuk menarik bentuk payload terbaru, dan menulis handler dengan verifikasi tanda tangan sesuai spesifikasi Standar Webhooks.

## Keamanan dan praktik terbaik

<Warning>
**Jangan pernah mengkomit kunci API produksi.** Gunakan [mode uji](/miscellaneous/test-mode-vs-live-mode) selama pengembangan. Plugin Agen menggunakan OAuth browser secara default — hanya beralih ke kunci API lokal jika diperlukan oleh alur kerja Anda.
</Warning>

- **Gunakan mode uji terlebih dahulu.** Sandarkan integrasi Anda dengan kunci `dodo_test_...` sebelum masuk ke mode live. Lihat [Mode Uji vs Mode Langsung](/miscellaneous/test-mode-vs-live-mode).
- **OAuth adalah defaultnya.** Plugin Agen mengautentikasi via OAuth browser (tanpa rahasia lokal). Hanya gunakan mode API-key jika Anda memerlukannya — lihat bagian Konfigurasi di bawah.
- **Tinjau kode yang dihasilkan oleh agen.** Selalu verifikasi bahwa handler webhook menyertakan verifikasi tanda tangan sesuai dengan [spesifikasi Standar Webhooks](https://standardwebhooks.com/).

## Konfigurasi dengan kunci API

Secara default, Plugin Agen menggunakan server MCP jarak jauh dengan OAuth browser — tidak memerlukan kredensial lokal. Jika alur kerja Anda memerlukan kunci API lokal (misalnya, lingkungan CI, server tanpa kepala), Anda dapat beralih ke mode stdio.

<AccordionGroup>
<Accordion title="Local API key mode — Claude Code">
Buka `/plugins` di Claude Code, pilih **Dodo Payments**, dan pilih **Configure options**. Isi:

- `dodo_api_key` — kunci `dodo_test_...` atau `dodo_live_...` Anda
- `dodo_webhook_key` — rahasia tanda tangan webhook Anda
- `dodo_environment` — `test_mode` atau `live_mode`

Kemudian edit `.mcp.json` untuk mengarahkan `dodopayments-api` ke server stdio lokal:

```json
{
  "mcpServers": {
    "dodopayments-api": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "dodopayments-mcp@latest"],
      "env": {
        "DODO_PAYMENTS_API_KEY": "${user_config.dodo_api_key}",
        "DODO_PAYMENTS_WEBHOOK_KEY": "${user_config.dodo_webhook_key}",
        "DODO_PAYMENTS_ENVIRONMENT": "${user_config.dodo_environment}"
      }
    }
  }
}
```

Jalankan `/reload-plugins` untuk menerapkan perubahan ke sesi Anda saat ini.
</Accordion>

<Accordion title="Local API key mode — OpenCode">
Deklarasikan `dodopayments-api` sendiri di `opencode.json` — entri Anda lebih diterima daripada server remote default plugin:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "mcp": {
    "dodopayments-api": {
      "type": "local",
      "command": ["npx", "-y", "dodopayments-mcp@latest"],
      "environment": {
        "DODO_PAYMENTS_API_KEY": "dodo_test_...",
        "DODO_PAYMENTS_WEBHOOK_KEY": "whsec_...",
        "DODO_PAYMENTS_ENVIRONMENT": "test_mode"
      },
      "enabled": true
    }
  }
}
```

Restart OpenCode untuk menerapkan.
</Accordion>
</AccordionGroup>
