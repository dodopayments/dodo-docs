## Ikhtisar

Sebuah boilerplate siap produksi untuk mengintegrasikan Dodo Payments ke dalam aplikasi Expo/React Native. Template ini mencakup pembuatan sesi checkout, penanganan pembayaran, dan konfigurasi TypeScript yang tepat untuk membantu Anda mulai menerima pembayaran di aplikasi mobile Anda dengan cepat.

<Info>
Boilerplate ini menggunakan Expo SDK dengan TypeScript dan menyertakan implementasi contoh untuk sesi checkout dan pemrosesan pembayaran.
</Info>

## Prasyarat

- Node.js 18+
- Expo CLI atau EAS CLI
- Akun Dodo Payments (API key dari dashboard)
- Simulator iOS atau Emulator Android (atau perangkat fisik)

## Memulai dengan Cepat

<Steps>
<Step title="Clone the Repository">
Clone repositori boilerplate dan masuk ke direktori proyek:

```bash
git clone https://github.com/dodopayments/expo-boilerplate.git
cd expo-boilerplate
```

</Step>

<Step title="Get Your API Credentials">
Dapatkan kredensial Anda dari dasbor Dodo Payments dalam Mode Tes:

- **API Key**: Navigasikan ke **Developer → API Keys** di [dashboard](https://app.dodopayments.com) Anda

<Tip>
Mulailah dengan Mode Tes untuk menguji integrasi Anda dengan aman tanpa memproses pembayaran nyata.
</Tip>
</Step>

<Step title="Configure Environment Variables">
Buat file `.env` di direktori root:

```bash
touch .env
```

Tambahkan kredensial Dodo Payments Anda:

```bash .env
EXPO_PUBLIC_DODO_API_KEY=your_test_api_key_here
```

<Warning>
Jangan pernah commit file `.env` ke version control. File tersebut sudah disertakan dalam `.gitignore`.
</Warning>

<Warning>
Variabel `EXPO_PUBLIC_*` disematkan dalam JavaScript bundle yang dikirimkan dan dapat dibaca oleh siapa pun yang mengunduh aplikasi Anda. API keys Dodo Payments adalah bearer secrets, jadi gunakan ini hanya dengan Test Mode key selama pengembangan. Untuk production, buat checkout sessions di backend Anda dan teruskan hanya `checkout_url` yang dihasilkan ke aplikasi — lihat [Mobile Integration](/developer-resources/mobile-integration).
</Warning>
</Step>

<Step title="Install Dependencies">
Instal paket npm yang diperlukan:

```bash
npm install
```

</Step>

<Step title="Start the Development Server">
Mulai Expo development server:

```bash
npx expo start
```

Pindai kode QR dengan aplikasi Expo Go di perangkat Anda, atau tekan `i` untuk iOS simulator atau `a` untuk Android emulator.

<Check>
Anda siap mulai membangun! Boilerplate ini mencakup contoh screen dan component untuk membantu Anda memahami integrasinya.
</Check>
</Step>
</Steps>

## Struktur Project

```
expo-boilerplate/
├── app/
│   ├── (tabs)/
│   │   └── index.tsx          # Home screen with examples
│   └── checkout.tsx           # Checkout screen
├── components/
│   └── PaymentButton.tsx      # Payment button component
├── lib/
│   └── dodo.ts                # Dodo Payments client setup
├── .env.example               # Environment variables template
└── package.json
```

## Langkah Berikutnya

Setelah boilerplate berjalan:

<Steps>
<Step title="Create Your Products">
Tambahkan produk di [dashboard Dodo Payments](https://app.dodopayments.com) Anda untuk mengaktifkan fungsionalitas checkout.
</Step>

<Step title="Customize the Integration">
Sesuaikan contoh code dengan kebutuhan dan design aplikasi Anda.
</Step>

<Step title="Test on Real Devices">
Uji alur pembayaran pada perangkat fisik untuk memastikan semuanya berfungsi dengan benar.
</Step>

<Step title="Go Live">
Setelah siap, beralihlah ke Live Mode API keys dan build aplikasi Anda untuk production.
</Step>
</Steps>

## Build untuk Production

<Steps>
<Step title="Install EAS CLI">

```bash
npm install -g eas-cli
```

</Step>

<Step title="Configure EAS">

```bash
eas build:configure
```

</Step>

<Step title="Build Your App">
Untuk iOS:

```bash
eas build --platform ios
```

Untuk Android:

```bash
eas build --platform android
```

</Step>
</Steps>
