## Ikhtisar

| Aplikasi | Metrik Utama | Inovasi Unik | Fitur Dodo |
| :--- | :--- | :--- | :--- |
| OpenAI | Token (dalam denominasi fiat) | Kredit prabayar fiat dengan saldo yang tidak pernah kadaluwarsa | Penagihan Berbasis Kredit (Kredit Fiat) |
| Cursor | Permintaan Premium | Penurunan kredit berbobot model (biaya berbeda per model) | Penagihan Berbasis Kredit (Unit Khusus) |
| ElevenLabs | Karakter | Kuota karakter dengan rollover + harga overage bertingkat | Penagihan Berbasis Kredit (Rollover + Overage) |
| Midjourney | Waktu GPU | Mode "Relax" sebagai cadangan tak terbatas setelah kuota | Langganan + Pengukur Penggunaan |
| Replicate | Detik Eksekusi | Pengukuran murni per-detik spesifik perangkat keras | Penagihan Murni Berbasis Penggunaan |
| Lovable | Pesan (kredit) | Bonus harian + kumpulan kredit berbagi tim | Penagihan Berbasis Kredit (Unit Khusus) + Langganan |

Setiap dekontruksi memecah model penagihan dari perusahaan nyata dan menunjukkan kepada Anda bagaimana mereplikasinya dengan Dodo Payments.

## Cetak Biru Ingestion

Setiap dekontruksi termasuk integrasi dengan [Cetak Biru Ingestion](/features/usage-based-billing/ingestion-blueprints) Dodo, SDK siap pakai yang menangani pelacakan acara secara otomatis. Daripada membangun acara penggunaan secara manual, gunakan cetak biru untuk mendapatkan pengukuran siap produksi dalam hitungan menit.
