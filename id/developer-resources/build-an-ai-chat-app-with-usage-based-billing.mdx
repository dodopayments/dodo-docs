## Apa yang Akan Kita Bangun

Mari kita mulai dengan memahami layanan chat AI kita:

- **Layanan**: Chat berbasis AI menggunakan Google Gemini (AI SDK)
- **Model Harga**: Bayar per token ($0.01 per 1.000 token)
- **Tingkat Gratis**: 10.000 token gratis per pelanggan per bulan
- **Fitur**: Riwayat percakapan, pelacakan token otomatis

<Info>
Sebelum memulai, pastikan Anda memiliki:
- Akun Dodo Payments
- API key Google AI ([Dapatkan dari aistudio](https://aistudio.google.com/api-keys))
- Node.js v16+ yang terpasang
</Info>

## Langkah 1: Buat Usage Meter Anda

Kita akan mulai dengan membuat meter di dashboard Dodo Payments untuk melacak penggunaan token AI.

<Tip>
**Yang kita bangun**: Meter bernama "AI Token Usage Meter" yang menjumlahkan semua token yang digunakan dalam percakapan chat.
</Tip>

<Steps>
<Step title="Open the Meters section">
1. Masuk ke dashboard Dodo Payments
2. Klik Products di sidebar kiri
3. Klik **Meters**
4. Klik tombol **Create Meter**

<Frame>
  <img src="/images/cookbooks/ai-chat-app/create-meter.png" alt="Create Meter" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Anda akan melihat formulir untuk mengonfigurasi pelacakan token.
</Step>

<Step title="Fill in the basic meter information">
Sekarang kita akan memasukkan detail khusus untuk layanan chat AI:

**Meter Name** → `AI Token Usage Meter`

**Description** → `Tracks token consumption from AI chat conversations using AI SDK`

**Event Name** → `ai_chat_usage`

<Warning>
Nama event `ai_chat_usage` harus sama persis dengan yang nantinya kita kirim dari kode aplikasi. Nama event peka huruf besar-kecil!
</Warning>
</Step>

<Step title="Configure how we count tokens">
Atur aggregation (cara meter menghitung event kita):

**Aggregation Type**: Pilih **Sum** dari dropdown

**Aggregate Over**: Type → `totalTokens`

**Measurement Unit**: Type → `tokens`

<Info>
Kita menggunakan "Sum" karena ingin menjumlahkan semua token yang digunakan dalam beberapa pesan chat. SDK secara otomatis mengirim `totalTokens` di setiap event.
</Info>
</Step>

<Step title="Create your meter">
1. Periksa kembali apakah semua pengaturan sesuai dengan nilai di atas
2. Klik **Create Meter**

<Frame>
  <img src="/images/cookbooks/ai-chat-app/meter-configuration.png" alt="Meter Configuration" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Check>
**Meter berhasil dibuat!** "AI Token Usage Meter" Anda kini siap mulai menghitung token. Berikutnya, kita akan menghubungkannya ke produk penagihan.
</Check>
</Step>
</Steps>

## Langkah 3: Buat Produk Penagihan Anda

Sekarang kita perlu membuat produk yang menentukan harga ($0.01 per 1.000 token dengan 10.000 token gratis). Ini menghubungkan meter dengan penagihan aktual.

<Tip>
**Yang kita bangun**: Produk bernama "AI Chat Service" yang mengenakan biaya berdasarkan konsumsi token dengan tingkat gratis yang besar.
</Tip>

<Steps>
<Step title="Navigate to Products">
1. Di dashboard Dodo Payments, klik **Products** di sidebar kiri
2. Klik **Create Product**
3. Pilih **Usage-Based** sebagai jenis produk

Ini memberi tahu Dodo Payments bahwa penagihan akan didasarkan pada penggunaan meter, bukan langganan tetap.
</Step>

<Step title="Enter product details">
Isi detail yang diperlukan:

**Product Name**: → `AI Chat Service`

**Description**: → `AI-powered chat service with automatic token-based billing`

**Product Image**: Unggah gambar yang relevan

<Info>
Detail ini akan muncul pada invoice pelanggan, jadi buatlah dengan jelas dan profesional.
</Info>
</Step>

<Step title="Connect your meter">
Sebelum menghubungkan meter, pastikan Anda telah memilih **Usage Based Billing** sebagai jenis harga produk.

Selain itu, atur **Fixed Price** ke `0` agar pelanggan hanya dikenai biaya berdasarkan penggunaan, tanpa biaya dasar.

Sekarang, hubungkan meter yang baru saja Anda buat:

1. Gulir ke bagian **Associated Meter**
2. Klik **Add Meters**
3. Dari dropdown, pilih **"AI Token Usage Meter"** (meter yang sebelumnya Anda buat)
4. Pastikan meter tersebut muncul dalam konfigurasi produk

<Check>
Meter Anda kini berhasil terhubung ke produk ini.
</Check>
</Step>

<Step title="Set your pricing">
Di sinilah kita menentukan model bisnis:

**Price Per Unit**: Masukkan → `0.00001` (yaitu $0.01 per 1.000 token atau $0.00001 per token)

**Free Threshold**: Masukkan → `10000` (pelanggan mendapatkan 10.000 token gratis per bulan)

<Frame>
  <img src="/images/cookbooks/ai-chat-app/product-pricing.png" alt="Product Pricing" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Tip>
**Cara kerja penagihan**: Jika pelanggan menggunakan 25.000 token dalam sebulan, mereka akan ditagih untuk 15.000 token (25.000 - 10.000 gratis) = 15.000 × $0.00001 = $0.15
</Tip>
</Step>

<Step title="Save your product">
1. Tinjau semua pengaturan:
   - Name: AI Chat Service
   - Meter: AI Token Usage Meter
   - Price: $0.01 per 1.000 token
   - Free tier: 10.000 token
2. Klik **Save Changes**

<Check>
**Produk berhasil dibuat!** Penagihan Anda kini telah dikonfigurasi. Pelanggan akan otomatis ditagih berdasarkan penggunaan token mereka.
</Check>
</Step>
</Steps>

## Langkah 5: Bangun Aplikasi Chat

Kini konfigurasi penagihan telah selesai dan pelanggan uji coba telah dibuat. Mari bangun aplikasi chat AI dengan pelacakan token otomatis.

<Steps>
<Step title="Set up your project">
Buat direktori baru dan inisialisasi project:

```bash
mkdir ai-chat-app
cd ai-chat-app
npm init -y
```

</Step>

<Step title="Install dependencies">
Instal package yang kita perlukan:

```bash
npm install express ai @ai-sdk/google @dodopayments/ingestion-blueprints dotenv
npm install --save-dev typescript @types/express @types/node tsx
```

</Step>

<Step title="Configure TypeScript">
Buat `tsconfig.json`:

```json tsconfig.json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "moduleResolution": "node",
    "esModuleInterop": true,
    "strict": true,
    "skipLibCheck": true,
    "outDir": "./dist",
    "rootDir": "./src"
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules"]
}
```

Perbarui `package.json` untuk menambahkan module type dan scripts:

```json package.json
{
  "type": "module",
  "scripts": {
    "dev": "tsx src/server.ts",
    "build": "tsc",
    "start": "node dist/server.js"
  }
}
```

</Step>

<Step title="Create project structure">
Buat folder dan file:

```bash
mkdir src public
```

</Step>

<Step title="Set up environment variables">
Buat file `.env` di root project Anda:


Ganti nilai placeholder dengan API key aktual Anda dari Langkah 2.
</Step>

<Step title="Create the backend server">
Buat `src/server.ts` dan salin kode server lengkap berikut:

</Step>
</Steps>

Berikut server chat AI lengkap dengan penagihan terintegrasi:

<CodeGroup>

```typescript src/server.ts expandable
import express, { Request, Response } from 'express';
import { generateText } from 'ai';
import { google } from '@ai-sdk/google';
import { createLLMTracker } from '@dodopayments/ingestion-blueprints';
import 'dotenv/config';

const app = express();
app.use(express.json());
app.use(express.static('public'));

// Replace with your test customer ID
const CUSTOMER_ID = 'cus_123';

// Create tracker once with your meter event name
const llmTracker = createLLMTracker({
  apiKey: process.env.DODO_PAYMENTS_API_KEY!,
  environment: process.env.DODO_ENVIRONMENT as 'test_mode' | 'live_mode',
  eventName: 'ai_chat_usage', // Must match your meter configuration
});

// Chat endpoint with conversation support
app.post('/chat', async (req: Request, res: Response) => {
  try {
    const { messages } = req.body;

    if (!messages || !Array.isArray(messages)) {
      return res.status(400).json({ 
        error: 'Missing required field: messages (array)' 
      });
    }

    // Wrap AI SDK with automatic token tracking
    const trackedClient = llmTracker.wrap({
      client: { generateText },
      customerId: CUSTOMER_ID
    });

    // Generate AI response - tokens are automatically tracked!
    const response = await trackedClient.generateText({
      model: google('gemini-2.5-flash'),
      messages: messages
    });

    res.json({
      message: response.text,
      usage: {
        totalTokens: response.usage.totalTokens
      }
    });

  } catch (error: any) {
    console.error('Chat error:', error);
    res.status(500).json({ 
      error: 'Failed to process chat',
      details: error.message 
    });
  }
});

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
  console.log(`🚀 Server running at http://localhost:${PORT}`);
  console.log(`📊 Tracking event: ai_chat_usage`);
  console.log(`👤 Customer ID: ${CUSTOMER_ID}`);
  console.log(`🔧 Environment: ${process.env.DODO_ENVIRONMENT}`);
});
```

```html public/index.html expandable
          <p>Ask me anything! Your token usage is automatically tracked.</p>

      <div class="chat-input-area">
        <div class="error-message" id="errorMessage"></div>

            id="messageInput"

    <script>
      let conversationHistory = [];

      const messageInput = document.getElementById("messageInput");
      let resizeTimeout;
      messageInput.addEventListener("input", function () {
        clearTimeout(resizeTimeout);
        resizeTimeout = setTimeout(() => {
          this.style.height = "auto";
          this.style.height = Math.min(this.scrollHeight, 120) + "px";
        }, 10);
      });

      // Send message on Enter (Shift+Enter for new line)
      messageInput.addEventListener("keydown", function (e) {
        if (e.key === "Enter" && !e.shiftKey) {
          e.preventDefault();
          sendMessage();
        }
      });

      async function sendMessage() {
        const input = document.getElementById("messageInput");
        const message = input.value.trim();

        if (!message) return;

        // Hide empty state
        document.getElementById("emptyState").style.display = "none";

        // Hide error
        document.getElementById("errorMessage").classList.remove("show");

        // Add user message to UI
        addMessage("user", message);

        // Add to conversation history
        conversationHistory.push({
          role: "user",
          content: message,
        });

        // Clear input
        input.value = "";
        input.style.height = "auto";

        // Show typing indicator
        showTypingIndicator();

        // Disable send button
        const sendBtn = document.getElementById("sendBtn");
        sendBtn.disabled = true;

        try {
          const response = await fetch("/chat", {
            method: "POST",
            headers: {
              "Content-Type": "application/json",
            },
            body: JSON.stringify({
              messages: conversationHistory,
            }),
          });

          const data = await response.json();

          if (!response.ok) {
            throw new Error(data.error || "Failed to get response");
          }

          // Hide typing indicator
          hideTypingIndicator();

          // Add assistant response to UI
          addMessage("assistant", data.message, data.usage);

          // Add to conversation history
          conversationHistory.push({
            role: "assistant",
            content: data.message,
          });
        } catch (error) {
          hideTypingIndicator();
          showError(error.message);
          // Remove the last user message from history since it failed
          conversationHistory.pop();
        } finally {
          sendBtn.disabled = false;
        }
      }

      function addMessage(role, content, usage = null) {
        const messagesDiv = document.getElementById("chatMessages");

        const messageDiv = document.createElement("div");
        messageDiv.className = `message ${role}`;

        const avatar = role === "user" ? "👤" : "🤖";

        let metaHTML = "";
        if (usage) {
          metaHTML = `
                    <div class="message-meta">
                        <span class="token-badge">📊 ${usage.totalTokens} tokens</span>
                    </div>
                `;
        }

        messageDiv.innerHTML = `
                <div class="message-avatar">${avatar}</div>
                <div class="message-content">
                    <div class="message-bubble">${escapeHtml(content)}</div>
                    ${metaHTML}
                </div>
            `;

        messagesDiv.appendChild(messageDiv);
        requestAnimationFrame(() => {
          messagesDiv.scrollTop = messagesDiv.scrollHeight;
        });
      }

      function showTypingIndicator() {
        const messagesDiv = document.getElementById("chatMessages");

        const typingDiv = document.createElement("div");
        typingDiv.className = "message assistant";
        typingDiv.id = "typingIndicator";
        typingDiv.innerHTML = `
                <div class="message-avatar">🤖</div>
                <div class="typing-indicator show">
                    <div class="typing-dots">
                        <span></span>
                        <span></span>
                        <span></span>
                    </div>
                </div>
            `;

        messagesDiv.appendChild(typingDiv);
        requestAnimationFrame(() => {
          messagesDiv.scrollTop = messagesDiv.scrollHeight;
        });
      }

      function hideTypingIndicator() {
        const typingIndicator = document.getElementById("typingIndicator");
        if (typingIndicator) {
          typingIndicator.remove();
        }
      }

      function showError(message) {
        const errorDiv = document.getElementById("errorMessage");
        errorDiv.textContent = "❌ " + message;
        errorDiv.classList.add("show");
      }

      function escapeHtml(text) {
        const div = document.createElement("div");
        div.textContent = text;
        return div.innerHTML.replace(/\n/g, "<br>");
      }
    </script>
  </body>
</html>
```

## Pemecahan Masalah

Masalah umum dan solusinya:

<AccordionGroup>
<Accordion title="Events not appearing in dashboard">
**Kemungkinan penyebab:**
- Nama event tidak sama persis dengan konfigurasi meter
- Customer ID tidak ada di akun Anda
- API key tidak valid atau sudah kedaluwarsa
- Masalah konektivitas jaringan

**Solusi:**
1. Pastikan nama event sama persis dengan konfigurasi meter (peka huruf besar-kecil: `ai_chat_usage`)
2. Pastikan customer ID ada di dashboard Dodo Payments
3. Uji API key dengan panggilan API sederhana
4. Periksa server logs untuk pesan error
</Accordion>

<Accordion title="Token counts showing zero">
**Kemungkinan penyebab:**
- Model tidak mengembalikan informasi penggunaan
- Versi SDK tidak sesuai

**Solusi:**
1. Uji apakah model mengembalikan penggunaan:

```typescript
const response = await generateText({...});
console.log('Usage:', response.usage);
```

2. Perbarui ke Blueprints SDK terbaru: `npm install @dodopayments/ingestion-blueprints@latest`
</Accordion>

<Accordion title="API key invalid error">
**Kemungkinan penyebab:**
- API key salah untuk environment
- Spasi atau tanda kutip tambahan dalam file `.env`

**Solusi:**
- Pastikan test key diawali `test_` dan live key diawali `live_`
- Hapus tanda kutip di sekitar key dalam file `.env`
- Buat key baru jika diperlukan
</Accordion>
</AccordionGroup>
