</Tip>

## Mulai Cepat

Mulai dengan salah satu SDK dalam hitungan menit:

<Steps>
<Step title="Install the SDK">
  Gunakan package manager bahasa Anda untuk menginstal SDK
  
  <Tabs>
  <Tab title="TypeScript/Node.js">

  ```bash
  npm install dodopayments
  ```

  </Tab>
  
  <Tab title="Python">

  ```bash
  pip install dodopayments
  ```

  </Tab>
  
  <Tab title="PHP">

  ```bash
  composer require dodopayments/client
  ```

  </Tab>
  
  <Tab title="Go">

  ```bash
  go get github.com/dodopayments/dodopayments-go
  ```

  </Tab>

  <Tab title="Rust">

  ```bash
  cargo add dodopayments
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Initialize the Client">
  Konfigurasikan klien dengan kunci API Anda
  
  <Tabs>
  <Tab title="TypeScript">

  ```typescript
  import DodoPayments from 'dodopayments';
  const client = new DodoPayments({ bearerToken: 'your_api_key' });
  ```

  </Tab>
  
  <Tab title="Python">

  ```python
  from dodopayments import DodoPayments
  client = DodoPayments(bearer_token="your_api_key")
  ```

  </Tab>
  
  <Tab title="PHP">

  ```php
  use Dodopayments\Client;
  $client = new Client(bearerToken: 'your_api_key');
  ```

  </Tab>
  
  <Tab title="Go">

  ```go
  import "github.com/dodopayments/dodopayments-go"
  client := dodopayments.NewClient(option.WithBearerToken("your_api_key"))
  ```

  </Tab>

  <Tab title="Rust">

  ```rust
  use dodopayments::Client;
  let client = Client::from_env()?; // reads DODO_PAYMENTS_API_KEY
  ```

  </Tab>
  </Tabs>
  
  <Warning>
  Selalu simpan kunci API Anda dengan aman menggunakan variabel lingkungan. Jangan pernah memasukkannya ke dalam versi kontrol.
  </Warning>
</Step>

<Step title="Make Your First API Call">
  Buat sesi checkout atau pembayaran
  
  <Check>
  Anda sekarang siap memproses pembayaran! Kunjungi halaman SDK individu untuk panduan dan contoh yang lebih rinci.
  </Check>
</Step>
</Steps>

## Fitur Utama

Semua SDK **backend** memiliki kapabilitas inti berikut. Mobile checkout SDK
di bawah sengaja dibuat lebih terbatas — SDK ini tidak menyimpan API key dan tidak pernah memanggil API:

- **Type Safety**: Pengetikan kuat untuk keamanan saat compile-time dan dukungan IDE yang lebih baik
- **Error Handling**: Penanganan exception yang komprehensif dengan pesan error yang mendetail
- **Authentication**: Autentikasi API key sederhana dengan dukungan untuk environment variable
- **Async Support**: Pola async/await modern jika berlaku
- **Auto-Pagination**: Pagination otomatis untuk respons list
- **Usage-Based Billing**: Dukungan bawaan untuk melacak dan memasukkan usage events
- **Testing**: Dukungan penuh untuk Test Mode dalam pengembangan dan pengujian

## Mobile Checkout SDKs

Jika Anda lebih suka membuka **hosted checkout page** milik Dodo daripada membuat
payment sheet native, gunakan mobile checkout SDK untuk platform Anda. Keempatnya memiliki
kontrak satu panggilan yang sama: `start(...)` mengembalikan `CheckoutResult` bertipe,
tidak satu pun menyimpan API key, dan Apple Pay/Google Pay bekerja dengan cara yang sama seperti
di open web karena checkout dibuka di permukaan browser sebenarnya milik platform
(`SFSafariViewController` / Custom Tabs), bukan `WebView`:

## Command-Line Interface

Untuk workflow berbasis terminal dan automation:

<Card title="CLI" icon="terminal" href="/developer-resources/sdks/cli">
  Antarmuka baris perintah yang dibuat secara otomatis dengan dukungan untuk Dodo Payments API
</Card>

**Fitur:**
- Struktur command berbasis resource untuk penggunaan yang intuitif
- Berbagai format output (JSON, YAML, pretty, interactive)
- Shell completion untuk bash, zsh, dan fish
- Sempurna untuk scripting dan automation CI/CD

```bash
# Quick example
dodopayments payments list --format json | jq '.items[] | {payment_id, total_amount}'
```
