Selalu gunakan versi SDK terbaru untuk mengakses fitur dan peningkatan terbaru. Periksa manajer paket Anda secara berkala untuk memastikan Anda memiliki akses ke semua kemampuan Dodo Payments.
</Tip>

## Mulai Cepat

Mulai dengan salah satu SDK dalam hitungan menit:

<Steps>
<Step title="Install the SDK">
  Gunakan package manager bahasa Anda untuk menginstal SDK
  
  <Tabs>
  <Tab title="TypeScript/Node.js">

  ```bash
  npm install dodopayments
  ```

  </Tab>
  
  <Tab title="Python">

  ```bash
  pip install dodopayments
  ```

  </Tab>
  
  <Tab title="PHP">

  ```bash
  composer require dodopayments/client
  ```

  </Tab>
  
  <Tab title="Go">

  ```bash
  go get github.com/dodopayments/dodopayments-go
  ```

  </Tab>

  <Tab title="Rust">

  ```bash
  cargo add dodopayments
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Initialize the Client">
  Konfigurasikan klien dengan kunci API Anda
  
  <Tabs>
  <Tab title="TypeScript">

  ```typescript
  import DodoPayments from 'dodopayments';
  const client = new DodoPayments({ bearerToken: 'your_api_key' });
  ```

  </Tab>
  
  <Tab title="Python">

  ```python
  from dodopayments import DodoPayments
  client = DodoPayments(bearer_token="your_api_key")
  ```

  </Tab>
  
  <Tab title="PHP">

  ```php
  use Dodopayments\Client;
  $client = new Client(bearerToken: 'your_api_key');
  ```

  </Tab>
  
  <Tab title="Go">

  ```go
  import "github.com/dodopayments/dodopayments-go"
  client := dodopayments.NewClient(option.WithBearerToken("your_api_key"))
  ```

  </Tab>

  <Tab title="Rust">

  ```rust
  use dodopayments::Client;
  let client = Client::from_env()?; // reads DODO_PAYMENTS_API_KEY
  ```

  </Tab>
  </Tabs>
  
  <Warning>
  Selalu simpan kunci API Anda dengan aman menggunakan variabel lingkungan. Jangan pernah memasukkannya ke dalam versi kontrol.
  </Warning>
</Step>

<Step title="Make Your First API Call">
  Buat sesi checkout atau pembayaran
  
  <Check>
  Anda sekarang siap memproses pembayaran! Kunjungi halaman SDK individu untuk panduan dan contoh yang lebih rinci.
  </Check>
</Step>
</Steps>

## Fitur Utama

Semua SDK memiliki kemampuan inti berikut:

- **Keamanan Tipe**: Pengetikan kuat untuk keamanan waktu kompilasi dan dukungan IDE yang lebih baik
- **Penanganan Kesalahan**: Penanganan pengecualian yang komprehensif dengan pesan kesalahan yang terperinci
- **Otentikasi**: Otentikasi kunci API yang sederhana dengan dukungan variabel lingkungan
- **Dukungan Async**: Pola async/await modern jika memungkinkan
- **Auto-Pagination**: Pagination otomatis untuk respon daftar
- **Penagihan Berdasarkan Penggunaan**: Dukungan bawaan untuk melacak dan memasukkan peristiwa penggunaan
- **Pengujian**: Dukungan lingkungan sandbox lengkap untuk pengembangan dan pengujian

## SDK React Native

Untuk aplikasi mobile, kami menyediakan SDK React Native khusus:

<Card title="React Native SDK" icon="mobile" href="/developer-resources/react-native-integration">
  Membangun pengalaman pembayaran yang aman untuk aplikasi iOS dan Android dengan komponen UI asli dan pengumpulan data pembayaran yang disederhanakan
</Card>

**Fitur:**
- Komponen UI asli untuk Android dan iOS
- Keamanan yang disederhanakan untuk mengumpulkan data pembayaran sensitif
- Dukungan untuk berbagai metode pembayaran
- Integrasi mulus dengan aplikasi React Native

<Info>
Apple Pay, Google Pay, Cash App, dan UPI saat ini tidak didukung dalam SDK React Native. Dukungan untuk metode pembayaran ini direncanakan dalam rilis mendatang.
</Info>

## Antarmuka Baris Perintah

Untuk alur kerja berbasis terminal dan otomatisasi:

<Card title="CLI" icon="terminal" href="/developer-resources/sdks/cli">
  Antarmuka baris perintah yang dihasilkan secara otomatis dengan dukungan untuk semua 78 endpoint API
</Card>

**Fitur:**
- Struktur perintah berbasis sumber daya untuk penggunaan yang intuitif
- Format keluaran yang berbeda (JSON, YAML, cantik, interaktif)
- Penyelesaian shell untuk bash, zsh, dan fish
- Sempurna untuk scripting dan otomatisasi CI/CD

```bash
# Quick example
dodopayments payments list --format json | jq '.data[] | {id, amount}'
```
