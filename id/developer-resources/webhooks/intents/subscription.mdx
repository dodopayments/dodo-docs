## Peristiwa Webhook Langganan

Peristiwa webhook berikut tersedia untuk melacak perubahan siklus hidup langganan:

| Peristiwa | Deskripsi |
|-------|-------------|
| `subscription.active` | Langganan berhasil diaktifkan |
| `subscription.updated` | Objek langganan diperbarui (perubahan pada bidang apa pun akan memicu peristiwa ini) |
| `subscription.on_hold` | Langganan ditangguhkan karena perpanjangan gagal |
| `subscription.paused` | Langganan dijeda |
| `subscription.unpaused` | Langganan dilanjutkan setelah dijeda |
| `subscription.renewed` | Langganan diperpanjang untuk periode penagihan berikutnya |
| `subscription.plan_changed` | Paket langganan ditingkatkan, diturunkan, atau diubah |
| `subscription.update_payment_method` | Metode pembayaran langganan diperbarui |
| `subscription.cancelled` | Langganan dibatalkan |
| `subscription.failed` | Pembuatan langganan gagal selama pembuatan mandat |
| `subscription.expired` | Langganan telah mencapai akhir masa berlakunya |

### Menggunakan `subscription.updated` untuk Sinkronisasi Waktu Nyata

Webhook `subscription.updated` dipicu setiap kali bidang langganan berubah, memungkinkan Anda menjaga status aplikasi tetap sinkron tanpa harus melakukan polling:

```javascript
app.post('/webhooks/dodo', async (req, res) => {
  const event = req.body;
  
  if (event.type === 'subscription.updated') {
    const subscription = event.data;
    
    // Sync subscription changes to your database
    await syncSubscription(subscription.subscription_id, {
      status: subscription.status,
      next_billing_date: subscription.next_billing_date,
      metadata: subscription.metadata,
      // ... other fields you want to track
    });
    
    console.log(`Subscription ${subscription.subscription_id} updated`);
  }
  
  res.json({ received: true });
});
```

<Tip>
Berlangganan ke `subscription.updated` untuk mendapatkan notifikasi waktu nyata tentang setiap perubahan langganan, sehingga Anda tidak perlu lagi melakukan polling pada API untuk pembaruan.
</Tip>
