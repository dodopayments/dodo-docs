**Dynamic pricing** memungkinkan Anda menawarkan harga variabel untuk produk tanpa membuat beberapa entri produk. Dengan mengaktifkan **Pay What You Want (PWYW)** pada satu produk, Anda dapat menetapkan batas harga minimum dan maksimum, lalu mengirimkan jumlah dinamis saat membuat tautan checkout session.

Pendekatan ini ideal jika Anda memerlukan:
- **Harga variabel** tanpa mengelola banyak produk
- **Harga yang ditentukan pelanggan** sehingga pembeli dapat memilih jumlahnya
- **Kontrol harga secara terprogram** sehingga Anda dapat menetapkan jumlah secara dinamis melalui API
- **Model harga fleksibel** untuk produk digital, donasi, atau peluncuran eksperimental

<Warning>
Pay What You Want hanya tersedia untuk produk **Single Payment** (satu kali). Fitur ini tidak dapat digunakan dengan produk subscription.
</Warning>

## Cara Kerjanya

Dengan Pay What You Want yang diaktifkan, Anda dapat:

1. **Menetapkan batas harga**: Tentukan harga minimum (wajib) dan harga maksimum secara opsional
2. **Mengirimkan jumlah dinamis**: Sertakan field `amount` dalam product cart saat membuat checkout session
3. **Membiarkan pelanggan memilih**: Jika tidak ada jumlah yang diberikan, pelanggan dapat memasukkan harga mereka sendiri (dalam batas yang Anda tetapkan)

<Info>
Saat Anda mengirimkan `amount` dalam product cart, jumlah tersebut digunakan untuk checkout. Jika Anda tidak menyertakan field `amount`, pelanggan dapat memilih harga mereka sendiri selama checkout (sesuai pengaturan minimum/maksimum Anda).
</Info>

## Langkah 1: Membuat Produk dengan Pay What You Want

Pertama, buat produk sekali bayar di dashboard Dodo Payments Anda dan aktifkan harga Pay What You Want.

<Steps>
<Step title="Create a new product">
Buka **Products** di dashboard Dodo Payments Anda, lalu klik **Add Product**.
</Step>

<Step title="Configure product details">
Isi informasi produk yang wajib diisi:
- **Product Name**: Nama tampilan untuk produk Anda
- **Product Description**: Deskripsi yang jelas tentang apa yang dibeli pelanggan
- **Product Image**: Unggah gambar (PNG/JPG/WebP, hingga 3 MB)
- **Tax Category**: Pilih kategori pajak yang sesuai
</Step>

<Step title="Set pricing type">
Pilih **Pricing Type** sebagai **Single Payment** (pembayaran satu kali).
</Step>

<Step title="Enable Pay What You Want">
Di bagian **Pricing**, aktifkan toggle **Pay What You Want**.
</Step>

<Step title="Set minimum price">
Masukkan **Minimum Price** yang harus dibayar pelanggan. Pengaturan ini wajib diisi dan memastikan Anda mempertahankan batas minimum pendapatan.

**Contoh**: Jika minimum Anda adalah $5.00, masukkan `5.00` (atau `500` sen).
</Step>

<Step title="Set maximum price (optional)">
Secara opsional, tetapkan **Maximum Price** untuk membatasi jumlah yang dapat dibayar pelanggan.
</Step>

<Step title="Set suggested price (optional)">
Secara opsional, masukkan **Suggested Price** yang akan ditampilkan untuk membantu pelanggan. Ini membantu membentuk ekspektasi dan dapat meningkatkan nilai pesanan rata-rata.
</Step>

<Step title="Save the product">
Klik **Add Product** untuk menyimpan. Catat ID produk Anda (misalnya, `pdt_123abc456def`) untuk digunakan dalam checkout session.
</Step>
</Steps>

<Tip>
Anda dapat menemukan ID produk di dashboard pada **Products** → **View Details**, atau dengan menggunakan [List Products API](/api-reference/products/get-products).
</Tip>

## Langkah 2: Membuat Checkout Session dengan Dynamic Pricing

Setelah produk dikonfigurasi dengan Pay What You Want, Anda dapat membuat checkout session dengan jumlah dinamis. Field `amount` dalam product cart memungkinkan Anda menetapkan harga secara terprogram untuk setiap checkout session.

### Memahami Field Amount

Saat membuat checkout session, Anda dapat menyertakan field `amount` dalam setiap item product cart:

- **Jika `amount` diberikan**: Checkout menggunakan jumlah persis tersebut (harus berada dalam batas minimum/maksimum Anda)
- **Jika `amount` tidak disertakan**: Pelanggan dapat memasukkan harga mereka sendiri selama checkout (dalam batas yang Anda tetapkan)

<Warning>
Field `amount` hanya berlaku untuk produk Pay What You Want. Untuk produk biasa, field ini diabaikan.
</Warning>

### Contoh Kode

<CodeGroup>

```typescript TypeScript
import DodoPayments from 'dodopayments';

// Initialize the Dodo Payments client
const client = new DodoPayments({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
});

async function createDynamicPricingCheckout(
  productId: string,
  amountInCents: number,
  returnUrl: string
) {
  try {
    const session = await client.checkoutSessions.create({
      product_cart: [
        {
          product_id: productId,
          quantity: 1,
          // Dynamic amount in cents (e.g., 1500 = $15.00)
          amount: amountInCents
        }
      ],
      return_url: returnUrl,
      // Optional: Pre-fill customer information
      customer: {
        email: 'customer@example.com',
        name: 'John Doe'
      },
      // Optional: Add metadata for tracking
      metadata: {
        order_id: 'order_123',
        pricing_tier: 'custom'
      }
    });

    console.log('Checkout URL:', session.checkout_url);
    console.log('Session ID:', session.session_id);
    
    return session;
  } catch (error) {
    console.error('Failed to create checkout session:', error);
    throw error;
  }
}

// Example: Create checkout with $25.00 (2500 cents)
const session = await createDynamicPricingCheckout(
  'pdt_123abc456def',
  2500, // $25.00 in cents
  'https://yoursite.com/checkout/success'
);

// Example: Create checkout with $10.00 (1000 cents)
const session2 = await createDynamicPricingCheckout(
  'pdt_123abc456def',
  1000, // $10.00 in cents
  'https://yoursite.com/checkout/success'
);
```

```python Python
import os
from dodopayments import DodoPayments

# Initialize the Dodo Payments client
client = DodoPayments(
    bearer_token=os.environ.get("DODO_PAYMENTS_API_KEY"),
)

def create_dynamic_pricing_checkout(
    product_id: str,
    amount_in_cents: int,
    return_url: str
):
    """
    Create a checkout session with dynamic pricing.
    
    Args:
        product_id: The product ID with Pay What You Want enabled
        amount_in_cents: The amount in cents (e.g., 2500 for $25.00)
        return_url: URL to redirect after payment completion
    
    Returns:
        Session object with checkout_url and session_id
    """
    try:
        session = client.checkout_sessions.create(
            product_cart=[
                {
                    "product_id": product_id,
                    "quantity": 1,
                    # Dynamic amount in cents (e.g., 1500 = $15.00)
                    "amount": amount_in_cents
                }
            ],
            return_url=return_url,
            # Optional: Pre-fill customer information
            customer={
                "email": "customer@example.com",
                "name": "John Doe"
            },
            # Optional: Add metadata for tracking
            metadata={
                "order_id": "order_123",
                "pricing_tier": "custom"
            }
        )
        
        print(f"Checkout URL: {session.checkout_url}")
        print(f"Session ID: {session.session_id}")
        
        return session
    except Exception as error:
        print(f"Failed to create checkout session: {error}")
        raise error

# Example: Create checkout with $25.00 (2500 cents)
session = create_dynamic_pricing_checkout(
    "pdt_123abc456def",
    2500,  # $25.00 in cents
    "https://yoursite.com/checkout/success"
)

# Example: Create checkout with $10.00 (1000 cents)
session2 = create_dynamic_pricing_checkout(
    "pdt_123abc456def",
    1000,  # $10.00 in cents
    "https://yoursite.com/checkout/success"
)
```

</CodeGroup>

<Note>
**Format Amount**: Field `amount` harus menggunakan denominasi terendah dari mata uang. Untuk USD, berarti sen (misalnya, $25.00 = `2500`). Untuk mata uang lain, gunakan unit terkecil (misalnya, paise untuk INR).
</Note>

## Langkah 3: Biarkan Pelanggan Memilih Harga Mereka

Jika Anda ingin pelanggan memilih harga mereka sendiri selama checkout, cukup hilangkan field `amount` dari product cart. Halaman checkout akan menampilkan field input tempat pelanggan dapat memasukkan jumlah apa pun dalam batas minimum dan maksimum Anda.

<CodeGroup>

### Kasus Penggunaan 2: Dynamic Pricing Berdasarkan Kuantitas

Sesuaikan harga berdasarkan kuantitas yang dibeli:

```typescript
async function createQuantityBasedCheckout(
  productId: string,
  quantity: number
) {
  // Base price: $20.00 per unit
  // Discount: 10% for 2+ items, 20% for 5+ items
  const basePrice = 2000; // $20.00 in cents
  let discount = 0;
  
  if (quantity >= 5) {
    discount = 0.20; // 20% off
  } else if (quantity >= 2) {
    discount = 0.10; // 10% off
  }
  
  const totalAmount = Math.round(basePrice * quantity * (1 - discount));
  
  const session = await client.checkoutSessions.create({
    product_cart: [
      {
        product_id: productId,
        quantity: quantity,
        amount: totalAmount
      }
    ],
    return_url: 'https://yoursite.com/success'
  });
  
  return session;
}
```

## Validasi dan Penanganan Error

Selalu validasi jumlah terhadap pengaturan minimum dan maksimum produk Anda:

<CodeGroup>

```typescript TypeScript
async function createValidatedCheckout(
  productId: string,
  amountInCents: number,
  minAmount: number,
  maxAmount: number | null
) {
  // Validate minimum
  if (amountInCents < minAmount) {
    throw new Error(
      `Amount ${amountInCents} is below minimum ${minAmount}`
    );
  }
  
  // Validate maximum (if set)
  if (maxAmount !== null && amountInCents > maxAmount) {
    throw new Error(
      `Amount ${amountInCents} exceeds maximum ${maxAmount}`
    );
  }
  
  // Create checkout session
  return await client.checkoutSessions.create({
    product_cart: [
      {
        product_id: productId,
        quantity: 1,
        amount: amountInCents
      }
    ],
    return_url: 'https://yoursite.com/success'
  });
}
```

def create_validated_checkout(
    product_id: str,
    amount_in_cents: int,
    min_amount: int,
    max_amount: int | None
):
    """
    Create a checkout session with amount validation.
    """
    # Validate minimum
    if amount_in_cents < min_amount:
        raise ValueError(
            f"Amount {amount_in_cents} is below minimum {min_amount}"

    # Validate maximum (if set)
    if max_amount is not None and amount_in_cents > max_amount:
        raise ValueError(
            f"Amount {amount_in_cents} exceeds maximum {max_amount}"
        )
    
    # Create checkout session
    return client.checkout_sessions.create(
        product_cart=[
            {
                "product_id": product_id,

## Pemecahan Masalah

<AccordionGroup>
<Accordion title="Amount is being ignored">
Jika field `amount` Anda diabaikan, pastikan bahwa:
- Produk telah mengaktifkan **Pay What You Want** di dashboard
- Produk merupakan produk **Single Payment** (satu kali), bukan subscription
- Jumlah menggunakan format yang benar (denominasi mata uang terendah, misalnya sen untuk USD)
</Accordion>

<Accordion title="Amount exceeds maximum or is below minimum">
API akan menolak checkout session jika jumlah melanggar batas harga produk Anda. Selalu validasi jumlah sebelum membuat checkout session, atau biarkan pelanggan memilih harga mereka dengan menghilangkan field `amount`.
</Accordion>

<Accordion title="Customer can't enter their own price">
Jika pelanggan tidak melihat field input harga, pastikan Anda telah menghilangkan field `amount` dari product cart. Jika `amount` diberikan, checkout akan menggunakan jumlah persis tersebut.
</Accordion>
</AccordionGroup>
