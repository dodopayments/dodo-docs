## Fitur Baru

### 1. **Koleksi Produk**  
   
   Mengelompokkan produk terkait bersama untuk pengalaman checkout yang terintegrasi, pemilihan rencana, dan jalur upgrade/downgrade yang mulus dalam Portal Pelanggan.

   <Frame>
     <img src="/images/product-collection/checkout-page.png" alt="Halaman checkout Koleksi Produk yang menampilkan beberapa opsi rencana" />
   </Frame>

  **Manfaat Utama**

   - **Checkout berbasis koleksi**: Tampilkan semua produk dari satu koleksi dalam satu tampilan checkout, memungkinkan pelanggan membandingkan dan memilih rencana yang mereka inginkan
   - **Manajemen produk yang terorganisir**: Kelompokkan produk terkait (misalnya, Starter, Pro, Enterprise) di bawah satu koleksi
   - **Integrasi Portal Pelanggan**: Memungkinkan pelanggan untuk melakukan upgrade atau downgrade antara produk dalam koleksi yang sama
   - **Kontrol Merchant**: Mengaktifkan, menonaktifkan, dan mengurutkan produk dalam setiap koleksi

   **Cara Kerjanya**

   Buat sesi checkout untuk sebuah koleksi:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_collection_id: 'pdc_abc123',
     product_cart: [], // Required: pass an empty array for collection checkout
     return_url: 'https://yoursite.com/return'
   });

   // Redirect customer to the checkout
   window.location.href = session.url;
   ```

   <Check>
   Hasil: Pengalaman checkout yang terintegrasi di mana pelanggan dapat melihat dan memilih dari semua produk yang tersedia dalam koleksi Anda.
   </Check>

   <Info>
   Checkout koleksi sangat ideal untuk bisnis berlangganan di mana Anda ingin pelanggan membandingkan rencana secara berdampingan sebelum melakukan pembelian.
   </Info>

   Pelajari lebih lanjut: [Panduan Koleksi Produk](/features/product-collections)

### 2. **Metode Pembayaran RevolutPay & Billie untuk Mata Uang GBP**  
   
   Pilihan pembayaran yang diperluas dengan RevolutPay dan Billie kini tersedia secara global untuk transaksi pembayaran satu kali GBP, memberikan pelanggan Anda lebih banyak fleksibilitas dalam cara mereka membayar.

   **Metode Pembayaran Baru**

   | Metode Pembayaran | Negara Yang Didukung | Mata Uang | Dukungan Berlangganan |
   |------------------|--------------------|----------|---------------------|
   | **RevolutPay**  | Global | GBP | Tidak (hanya satu kali) |
   | **Billie**      | Global | GBP | Tidak (hanya satu kali) |

   - **RevolutPay** – Pembayaran cepat dan mulus untuk pengguna Revolut di seluruh dunia
   - **Billie** – Solusi B2B Buy Now Pay Later yang memungkinkan bisnis menawarkan syarat pembayaran yang fleksibel kepada pelanggan mereka

   <Info>
   Metode pembayaran ini secara otomatis tersedia untuk transaksi GBP. Tidak ada konfigurasi tambahan yang diperlukan.
   </Info>

   Pelajari lebih lanjut: [Metode Pembayaran](/features/payment-methods)

### 3. **Pratinjau Sesi Checkout**  
   
   Pratinjau sesi checkout sebelum membuatnya untuk menghitung harga, pajak, diskon, dan total yang akurat. Tampilkan harga sebenarnya kepada pelanggan sebelum mereka melanjutkan ke checkout.

   **Cara Kerjanya**

   ```typescript
   const preview = await client.checkoutSessions.preview({
     product_cart: [
       { product_id: 'prod_123', quantity: 1 }
     ],
     billing_address: {
       country: 'US',
       state: 'CA',
       zipcode: '94102'
     },
     discount_code: 'SAVE20'
   });

   console.log('Subtotal:', preview.subtotal);
   console.log('Tax:', preview.tax);
   console.log('Discount:', preview.discount);
   console.log('Total:', preview.total);
   ```

   **Kasus Penggunaan**

   - **Tampilan harga kustom**: Tampilkan total akurat termasuk pajak sebelum checkout
   - **Validasi diskon**: Verifikasi kode diskon dan tampilkan penghematan kepada pelanggan
   - **Dukungan multi-mata uang**: Pratinjau harga dalam berbagai mata uang
   - **Ringkasan keranjang**: Buat antarmuka pengguna keranjang kustom dengan harga waktu nyata

### 4. **Dukungan Metadata dalam Permintaan Perubahan Rencana**  
   
   Kirim metadata kustom saat mengubah rencana langganan, memungkinkan pelacakan dan integrasi yang lebih baik dengan sistem internal Anda selama transisi rencana.

   ```javascript
   // Adding metadata when changing a subscription plan
   await client.subscriptions.changePlan('sub_123', {
     product_id: 'prod_premium',
     proration_billing_mode: 'prorated_immediately',
     quantity: 1,
     metadata: {
       upgrade_reason: 'feature_request',
       previous_plan: 'basic',
       sales_rep: 'john@company.com'
     }
   });
   ```

  **Kasus Penggunaan**

   - **Lacak alasan upgrade/downgrade**: Simpan mengapa pelanggan mengubah rencana
   - **Tautan ke catatan CRM**: Kaitkan perubahan rencana dengan aktivitas penjualan
   - **Kategorisasi internal**: Tandai perubahan rencana untuk pelaporan dan analitik
   - **Jejak audit**: Pertahankan catatan siapa yang memulai perubahan rencana

   <Info>
   Metadata termasuk dalam peristiwa webhook, memudahkan pemrosesan perubahan rencana dengan data kustom Anda.
   </Info>

   Pelajari lebih lanjut: [Panduan Metadata](/api-reference/metadata) | [API Perubahan Rencana](/api-reference/subscriptions/change-plan)

### 5. **`invoice_url` Field dalam Respon Pembayaran dan Respon Tautan Pembayaran**  
   
   Respon Pembayaran dan Respon Tautan Pembayaran kini menyertakan bidang `invoice_url`, memberikan akses langsung ke faktur yang terkait dengan setiap pembayaran.

   ```json
   {
     "payment_id": "pay_2IjeQm4hqU6RA4Z4kwDee",
     "status": "succeeded",
     "invoice_url": "https://dodopayments.com/invoices/inv_2IsUnWGtRKFLxk7xAQeyt",
     "amount": 9900,
     "currency": "USD",
     // ... other fields
   }
   ```

  **Kasus Penggunaan**

   - **Komunikasi pelanggan**: Kirim tautan faktur langsung kepada pelanggan
   - **Integrasi akuntansi**: Kaitkan pembayaran dengan faktur di perangkat lunak akuntansi Anda
   - **Portal mandiri**: Izinkan pelanggan untuk mengakses faktur mereka dengan mudah
   - **Pencatatan**: Pertahankan referensi langsung ke dokumen faktur

### 6. **Endpoint Validasi Diskon berdasarkan Nama Kode**  
   
   Endpoint API baru untuk memvalidasi dan mengambil kode diskon berdasarkan nama kodenya (misalnya, "SAVE20") daripada menggunakan ID diskon internal. Verifikasi kelayakan diskon sebelum menerapkannya saat checkout.

   ```javascript
   // Validate a discount code before checkout
   const discount = await client.discounts.getByCode('SAVE20');

   console.log('Discount type:', discount.type);
   console.log('Discount value:', discount.amount);
   console.log('Valid until:', discount.expires_at);
   ```

  **Manfaat**

   - **Validasi pra-checkout**: Verifikasi kode diskon sebelum membuat sesi checkout
   - **Umpan balik waktu nyata**: Tunjukkan kepada pelanggan jika kode mereka valid
   - **Penanganan kesalahan**: Tangkap kode yang tidak valid atau kedaluwarsa lebih awal
   - **Antarmuka diskon kustom**: Buat bidang input kode diskon dengan validasi instan

### 7. **Kemampuan Penyaringan yang Ditingkatkan untuk Pelanggan, Diskon, dan Kunci Lisensi**  
   
   NFT API baru untuk listing Pelanggan, Diskon, dan Kunci Lisensi, memudahkan untuk menemukan dan mengelola data Anda secara terprogram.

   **Filter API Pelanggan**

   | Filter | Deskripsi |
   |--------|-------------|
   | `email` | Filter berdasarkan email pelanggan |
   | `name` | Filter berdasarkan nama pelanggan (pencocokan sebagian, tidak case-sensitive) |
   | `created_at_gte` | Filter pelanggan yang dibuat pada atau setelah timestamp ini |
   | `created_at_lte` | Filter pelanggan yang dibuat pada atau sebelum timestamp ini |

   ```javascript
   // Find customers by name created in the last 30 days
   const customers = await client.customers.list({
     name: 'John',
     created_at_gte: '2026-01-01T00:00:00Z'
   });
   ```

   **Filter API Diskon**

   | Filter | Deskripsi |
   |--------|-------------|
   | `code` | Filter berdasarkan kode diskon (pencocokan sebagian, tidak case-sensitive) |
   | `discount_type` | Filter berdasarkan jenis diskon (persentase) |
   | `active` | Filter berdasarkan status aktif (benar = tidak kedaluwarsa, salah = kedaluwarsa) |
   | `product_id` | Filter berdasarkan batasan produk (hanya diskon yang berlaku untuk produk ini) |

   ```javascript
   // Find active percentage discounts for a specific product
   const discounts = await client.discounts.list({
     active: true,
     discount_type: 'percentage',
     product_id: 'prod_123'
   });
   ```

   **Filter API Kunci Lisensi**

   | Filter | Deskripsi |
   |--------|-------------|
   | `customer_id` | Filter berdasarkan ID pelanggan |
   | `status` | Filter berdasarkan status kunci lisensi (`active`, `expired`, `disabled`) |
   | `product_id` | Filter berdasarkan ID produk |
   | `created_at_gte` | Filter kunci lisensi yang dibuat pada atau setelah timestamp ini |
   | `created_at_lte` | Filter kunci lisensi yang dibuat pada atau sebelum timestamp ini |

   ```javascript
   // Find active license keys for a specific product
   const licenseKeys = await client.licenseKeys.list({
     status: 'active',
     product_id: 'prod_123'
   });
   ```
