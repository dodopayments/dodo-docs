## Fitur Baru 🚀

- **Checkout 2.0**: Memperkenalkan pengalaman checkout yang sepenuhnya didesain ulang dengan fitur:
    - Antarmuka yang modern dan terintegrasi untuk meningkatkan pengalaman pengguna
    - Sistem Query Collector baru yang menyimpan parameter di session storage dengan ID unik (misalnya, `sess_1a2b3c4d`)
    - Ketersediaan data yang persisten sepanjang alur checkout
    - Peningkatan lebih lanjut direncanakan untuk rilis mendatang! 
  
    <Frame><img src="/images/changelog/checkout_2.png" alt="Checkout 2.0" style={{ maxHeight: '500px', width: 'auto' }} /></Frame>

- **Metode Pembayaran yang Dapat Dikonfigurasi**: Konfigurasi `allowed_payment_method_types` baru memungkinkan merchant menyesuaikan opsi pembayaran yang tersedia selama checkout. Lihat dokumentasi [Metode Pembayaran yang Diizinkan](/features/payment-methods#per-checkout-payment-method-configuration) untuk detail implementasi.

- **Perhitungan Pajak Dinamis**: Perhitungan tarif pajak secara real-time berdasarkan alamat penagihan pelanggan untuk harga yang lebih akurat pada tautan pembayaran statis.

- **Subscription Sesuai Permintaan**: Endpoint API baru untuk penagihan subscription yang fleksibel (tersedia untuk merchant tertentu). Pelajari selengkapnya dalam panduan [Subscription Sesuai Permintaan](/developer-resources/ondemand-subscriptions).

- **Pembaruan Tambahan**:
    - Optimisasi kinerja
    - Perbaikan bug
    - Peningkatan sistem secara umum
