## Fitur Baru

### 1. **Preferensi Komunikasi**

   Kendalikan bagaimana Anda menerima notifikasi dengan Preferensi Komunikasi kami yang diperbaharui. Konfigurasikan notifikasi email, push, dan dalam aplikasi untuk mencocokkan alur kerja Anda.

   <Frame>
     <img src="/images/communication-preferences/overview.png" alt="Tampilan overview Preferensi Komunikasi yang menunjukkan pengaturan notifikasi" />
   </Frame>

   **Fitur Utama**

   - **Desain email yang diperbaharui**: Template email yang segar dan modern dengan panggilan untuk bertindak yang jelas dan keterbacaan yang lebih baik
   - **Notifikasi push**: Dapatkan peringatan instan di perangkat mobile Anda untuk acara kritis seperti penjualan baru, perselisihan, dan pembayaran
   - **Kontrol granular**: Pilih persis acara mana yang memicu notifikasi dan melalui saluran mana
   - **Dukungan multi-email**: Tambahkan beberapa alamat email untuk menerima notifikasi
   - **Preferensi email pelanggan**: Konfigurasikan email mana yang diterima oleh pelanggan Anda

   **Kategori Notifikasi**

   | Kategori | Deskripsi |
   |----------|-------------|
   | **Penjualan & Pembayaran** | Penjualan baru, pembayaran yang berhasil, pembayaran yang gagal |
   | **Pembayaran & Pengembalian** | Penyelesaian pembayaran, permintaan pengembalian, penyelesaian pengembalian |
   | **Langganan** | Langganan baru, perpanjangan, pembatalan, perubahan paket |
   | **Perselisihan** | Perselisihan dibuka, bukti diperlukan, perselisihan diselesaikan |

   <Check>
   Hasil: Tetap terinformasi tentang bisnis Anda dengan notifikasi yang dikirimkan persis seperti dan kapan Anda inginkan.
   </Check>

   Pelajari lebih lanjut: [Panduan Preferensi Komunikasi](/features/communication-preferences)

### 2. **Bidang Kustom dalam Sesi Checkout**

   Kumpulkan informasi tambahan dari pelanggan selama checkout dengan bidang kustom. Tambahkan input teks, dropdown, tanggal, dan lainnya untuk mengumpulkan data yang Anda butuhkan.

   **Tipe Bidang yang Didukung**

   | Tipe | Deskripsi | Kasus Penggunaan |
   |------|-------------|----------|
   | `text` | Input teks satu baris | Nama perusahaan, catatan pesanan |
   | `number` | Input numerik | Kuantitas, usia |
   | `email` | Input email dengan validasi | Email kontak penagihan |
   | `url` | Input URL dengan validasi | Situs web, profil sosial |
   | `date` | Pemilih tanggal | Tanggal pengiriman, tanggal acara |
   | `dropdown` | Seleksi dari opsi yang telah ditentukan | Ukuran, warna, jenis paket |
   | `boolean` | Kotak centang untuk nilai ya/tidak | Penerimaan syarat, opsi berlangganan buletin |

   **Cara Kerjanya**

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     custom_fields: [
       {
         name: 'company_name',
         label: 'Company Name',
         type: 'text',
         required: true
       },
       {
         name: 'team_size',
         label: 'Team Size',
         type: 'dropdown',
         options: ['1-10', '11-50', '51-200', '200+'],
         required: true
       },
       {
         name: 'newsletter',
         label: 'Subscribe to our newsletter',
         type: 'boolean',
         required: false
       }
     ],
     return_url: 'https://yoursite.com/success'
   });
   ```

   **Manfaat**

   - **Pengumpulan data yang fleksibel**: Kumpulkan informasi apa pun yang dibutuhkan untuk pemenuhan atau personalisasi
   - **Validasi terintegrasi**: Bidang email dan URL secara otomatis memvalidasi format input
   - **Kontrol wajib/opsional**: Tandai bidang sebagai wajib atau opsional berdasarkan kebutuhan Anda
   - **Pengiriman webhook**: Nilai bidang kustom disertakan dalam peristiwa webhook pembayaran

   <Info>
   Nilai bidang kustom dikembalikan dalam objek `custom_fields` dalam respons pembayaran dan sesi checkout.
   </Info>

   Pelajari lebih lanjut: [Bidang Kustom Sesi Checkout](/developer-resources/checkout-session#custom-fields)

### 3. **Dukungan Bahasa Checkout yang Diperluas**

   Halaman checkout sekarang mendukung **21 bahasa**, meningkat dari 16. Jangkau lebih banyak pelanggan dalam bahasa asli mereka untuk pengalaman checkout yang lebih baik.

   **Bahasa Baru Ditambahkan**

   | Bahasa | Kode |
   |----------|------|
   | Korea | `ko` |
   | Melayu | `ms` |
   | Rumania | `ro` |
   | Rusia | `ru` |
   | Thailand | `th` |

   **Semua Bahasa yang Didukung**

   Arab, Cina, Belanda, Inggris, Perancis, Jerman, Hindi, Indonesia, Italia, Jepang, Korea, Melayu, Portugis, Rumania, Rusia, Spanyol, Swedia, Thailand, Turki, Ukraina, Vietnam.

   **Paksa Bahasa Tertentu**

   Gunakan parameter `force_language` untuk mengesampingkan deteksi bahasa otomatis:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     force_language: 'ko', // Force Korean language
     return_url: 'https://yoursite.com/success'
   });
   ```

   <Tip>
   Secara default, halaman checkout secara otomatis mendeteksi bahasa preferensi pelanggan dari pengaturan browser mereka. Gunakan `force_language` saat Anda ingin memastikan konsistensi dengan bahasa situs web Anda.
   </Tip>

   Pelajari lebih lanjut: [Dukungan Bahasa Checkout](/features/checkout#supported-languages)
