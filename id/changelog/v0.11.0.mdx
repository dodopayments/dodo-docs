## Fitur Baru
- **Email Otomatis**: Menambahkan email otomatis untuk pembayaran, langganan, pengembalian dana, dan sengketa untuk menjaga agar pedagang dan pelanggan tetap informasi.
- **Log Acara Webhook**: Menambahkan log acara webhook di Dashboard Dodo Payments untuk melacak acara webhook dan memecahkan masalah. Akses log dengan mengunjungi `Settings > Webhooks > Webhook Logs`.
- **Panduan Pembuatan Kunci Lisensi**: Menambahkan panduan baru untuk menerapkan pembuatan kunci lisensi untuk produk digital. Lihat [panduan](/features/license-keys) untuk informasi lebih lanjut.

- Berbagai perbaikan kecil dan peningkatan.
