[ParityDeals](https://www.paritydeals.com/) dan [Evendeals](https://www.evendeals.com/integrations/dodo-payments) adalah platform yang memungkinkan optimisasi harga otomatis berdasarkan lokasi geografis pelanggan, yang umum dikenal sebagai penetapan harga "purchasing power parity" (PPP).

Sementara Anda tidak dapat langsung menyematkan spanduk diskon di toko Dodo Payments (karena dukungan skrip kustom tidak tersedia), Anda masih dapat menerapkan alat ini secara efektif di situs web atau aplikasi Anda sendiri.

Siapkan penawaran berdasarkan lokasi, liburan, dan waktu dengan spanduk yang dapat disesuaikan.
Otomatisasi penyinkronan kupon dan aturan penyegaran untuk produk satu kali dan berlangganan.
Pelajari cara membuat dan mengelola kode diskon secara manual di dasbor Dodo Payments.
Akses penjualan, diskon, dan kunci API Anda di dasbor pusat.

## Memilih Integrasi

Kedua platform terintegrasi langsung dengan Dodo Payments untuk membuat dan mengelola kode diskon secara otomatis. Gunakan perbandingan di bawah ini untuk memilih alat yang paling sesuai dengan kebutuhan Anda.

| Fitur | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| Harga PPP / Berbasis Lokasi | Ya | Ya |
| Penawaran Liburan / Berbasis Waktu | Ya | Tidak |
| Dukungan Langganan | Ya | Ya |
| Penyegaran Kupon Otomatis | — | Ya |
| Kustomisasi Spanduk | Ya | Tidak |
| Harga | [Lihat Harga](https://www.paritydeals.com/pricing/) | [Lihat Harga](https://www.evendeals.com/pricing) |

## ParityDeals

Ketika ParityDeals diintegrasikan ke dalam situs web Anda, pengunjung yang memenuhi syarat akan melihat spanduk yang mencakup kode diskon berbasis lokasi yang dapat mereka gunakan saat checkout. Kode diskon ini secara otomatis dibuat dan dikelola oleh ParityDeals dan akan muncul di **Dasbor Dodo Payments** Anda di bawah **Penjualan → Diskon**.

<img src="/images/ppp/1.png" alt="Contoh spanduk diskon ParityDeals" />

### Pengaturan

Kunjungi [app.paritydeals.com](https://app.paritydeals.com/) dan buat akun.

Setelah masuk, temukan opsi untuk membuat penawaran. Dari menu dropdown, pilih **"Buat Penawaran melalui Dodo Payments"**.

<img src="/images/ppp/2.png" alt="Membuat penawaran melalui Dodo Payments" />

Masuk ke **dasbor Dodo Payments** Anda dan navigasikan ke **Pengembang → Kunci API**. Klik **"Buat API Baru"**.

Beri nama kunci API Anda secara deskriptif (misalnya, 'ParityDeals') sehingga Anda dapat mengidentifikasinya nanti.

<img src="/images/ppp/3.png" alt="Membuat kunci API baru di Dodo Payments" />

Salin kunci API yang Anda buat dan tempelkan ke antarmuka ParityDeals untuk menetapkan koneksi dengan akun Dodo Payments Anda.

<img src="/images/ppp/4.png" alt="Menghubungkan kunci API ke ParityDeals" />

Setelah terhubung, ParityDeals akan mengambil katalog produk Dodo Payments Anda. Pilih produk yang ingin Anda asosiasikan dengan penawaran Anda.

<img src="/images/ppp/5.png" alt="Memilih produk untuk ParityDeals" />

Masukkan URL situs web Anda dan pilih halaman target spesifik di mana spanduk diskon harus muncul. Kemudian pilih jenis penawaran yang Anda pilih:
- Penawaran berbasis lokasi
- Penawaran liburan
- Penawaran kilat berbasis waktu

<img src="/images/ppp/6.png" alt="Mengonfigurasi pengaturan penawaran" />

Pilih negara yang ingin Anda tawarkan diskon lokal dan tentukan persentase diskon untuk masing-masing. ParityDeals menyediakan default yang direkomendasikan yang dapat Anda sesuaikan sesuai kebutuhan.

<img src="/images/ppp/7.png" alt="Mengatur aturan diskon berdasarkan negara" />

Desain spanduk diskon Anda dengan menyesuaikan teks, memilih warna dan tata letak, dan memilih posisi spanduk (atas atau bawah halaman). Spanduk ini akan ditampilkan kepada pengunjung yang memenuhi syarat berdasarkan aturan yang Anda konfigurasikan.

<img src="/images/ppp/8.png" alt="Mengatur kustomisasi spanduk diskon" />

Setelah menyimpan penawaran Anda, ParityDeals akan menghasilkan skrip. Tambahkan skrip ini ke kode situs web Anda (biasanya di bagian `<head>`). Skrip ini secara otomatis mendeteksi lokasi pengunjung dan menampilkan spanduk diskon yang sesuai.

<img src="/images/ppp/9.png" alt="Skrip integrasi ParityDeals" />

### Fitur Tambahan

Dengan ParityDeals, Anda juga dapat menawarkan [diskon otomatis berbasis waktu](https://www.paritydeals.com/features/time-based-discounts/) dan [promosi berbasis liburan](https://www.paritydeals.com/features/holiday-based-discounts/) sepanjang tahun. Untuk informasi lebih rinci, lihat [Dokumentasi ParityDeals](https://www.paritydeals.com/docs/).

## Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) adalah platform lain yang terintegrasi dengan Dodo Payments untuk menawarkan penetapan harga paritas daya beli berbasis lokasi. Ini mendukung produk satu kali dan berlangganan.

<img src="/images/ppp/evendeals-hero.png" alt="Tinjauan integrasi Evendeals Dodo Payments" />

### Fitur Utama

- **Sinkronisasi kupon otomatis** — Kupon dibuat dan dikelola di Dodo Payments secara otomatis
- **Diskon persentase** — Menawarkan diskon persentase per grup negara
- **Dukungan langganan** — Diskon berlaku di siklus penagihan langganan
- **Aturan penyegaran otomatis** — Gantilah kode kupon secara otomatis berdasarkan interval waktu, jumlah penukaran, atau jumlah tampilan untuk mencegah penyalahgunaan

Kode diskon yang dibuat oleh Evendeals akan secara otomatis muncul di dasbor Dodo Payments Anda di bawah Penjualan → Diskon.

<img src="/images/ppp/evendeals-features.png" alt="Fitur utama Evendeals untuk integrasi Dodo Payments" />

### Pengaturan

Di dasbor Dodo Payments Anda, buka **Pengembang → Kunci API** dan buat kunci baru.

Di [dasbor Evendeals](https://www.evendeals.com/signin) Anda, navigasikan ke **Integrations**, temukan kartu Dodo Payments, dan tempelkan kunci API Anda.

Tentukan diskon persentase untuk setiap grup negara dan tekan sinkronisasi. Evendeals secara otomatis membuat kupon di Dodo Payments.

Setelah sinkronisasi, buka **Penjualan → Diskon** di dasbor Dodo Payments Anda untuk memastikan kupon yang dihasilkan muncul. Setiap kupon akan memiliki prefiks Evendeals yang dapat dikenali.

<img src="/images/ppp/evendeals-setup.png" alt="Panduan pengaturan Evendeals untuk Dodo Payments" />

Baik ParityDeals maupun Evendeals bekerja dengan lancar dengan Dodo Payments untuk membantu Anda mengoptimalkan strategi penetapan harga global Anda. Untuk detail lebih lanjut, kunjungi [Dokumentasi ParityDeals](https://www.paritydeals.com/docs/) atau halaman [integrasi Evendeals Dodo Payments](https://www.evendeals.com/integrations/dodo-payments).
