Penetapan harga paritas daya beli (Purchasing Power Parity/PPP) menyesuaikan apa yang Anda kenakan untuk mencocokkan daya beli dari setiap lokasi pelanggan. Ada dua cara untuk melakukannya di Dodo Payments.

<Info>
**Disarankan:** Gunakan [Localized Pricing](/features/localized-pricing) asli untuk menetapkan harga lokal tetap per negara, misalnya ₹999 di India untuk produk dengan basis harga $20. Anda mengontrol angka persisnya, ini berlaku untuk produk sekali pembelian, berlangganan, dan berbasis penggunaan, dan tidak ada banner atau skrip yang perlu dipasang.
</Info>

## Dua cara untuk menjalankan PPP

| | Localized Pricing (asli) | Kode diskon berbasis lokasi |
| :--- | :--- | :--- |
| Cara kerjanya | Anda menetapkan harga lokal tetap per negara/mata uang | Persentase dari harga dasar Anda, diterapkan melalui kode |
| Alat | Tertanam dalam Dodo Payments | [ParityDeals](https://www.paritydeals.com/) / [Evendeals](https://www.evendeals.com/integrations/dodo-payments) |
| Banner / skrip di situs Anda | Tidak diperlukan | Diperlukan untuk menampilkan kode |
| Harga yang dilihat pelanggan | Jumlah persis yang Anda tetapkan | Harga dasar dikurangi diskon |
| Terbaik untuk | Harga bersih yang disesuaikan pasar yang sepenuhnya Anda kontrol | Banner promosi dan penawaran berbasis waktu/liburan |

Untuk pengaturan asli, lihat [Localized Pricing](/features/localized-pricing). Sisa halaman ini membahas pendekatan kode diskon berbasis lokasi dengan ParityDeals dan Evendeals.

## Kode diskon berbasis lokasi

[ParityDeals](https://www.paritydeals.com/) dan [Evendeals](https://www.evendeals.com/integrations/dodo-payments) adalah platform yang memungkinkan optimalisasi harga otomatis berdasarkan lokasi geografis pelanggan dengan membuat kode diskon.

<Info>
Meskipun Anda tidak dapat menyematkan banner diskon secara langsung di etalase Dodo Payments (karena skrip kustom tidak didukung), Anda masih dapat menerapkan alat ini secara efektif di situs web atau aplikasi Anda sendiri.
</Info>

### Memilih Integrasi

Kedua platform terintegrasi langsung dengan Dodo Payments untuk membuat dan mengelola kode diskon secara otomatis. Gunakan perbandingan di bawah untuk memilih alat yang paling sesuai dengan kebutuhan Anda.

| Fitur | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| Penetapan harga berbasis lokasi/PPP | Ya | Ya |
| Penawaran berbasis waktu atau liburan | Ya | Tidak |
| Dukungan berlangganan | Ya | Ya |
| Penyegaran kupon otomatis | — | Ya |
| Kustomisasi banner | Ya | Tidak |
| Harga | [Lihat Harga](https://www.paritydeals.com/pricing/) | [Lihat Harga](https://www.evendeals.com/pricing) |

### ParityDeals

Ketika ParityDeals diintegrasikan ke situs web Anda, pengunjung yang memenuhi syarat akan melihat banner yang mencakup kode diskon berbasis lokasi yang dapat mereka gunakan saat checkout. Kode diskon ini dibuat dan dikelola secara otomatis oleh ParityDeals dan akan muncul di **Dasbor Dodo Payments** Anda di bawah **Penjualan → Diskon**.

#### Pengaturan

<Steps>
  <Step title="Sign up on ParityDeals">
    Kunjungi [app.paritydeals.com](https://app.paritydeals.com/) dan buat akun.
  </Step>

  <Step title="Create Deals">
    Setelah login, cari opsi untuk membuat penawaran. Dari menu dropdown, pilih **"Create Deals via Dodo Payments"**.

    <Frame>
      <img src="/images/ppp/2.png" alt="Membuat penawaran via Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Masuk ke **dasbor Dodo Payments** Anda dan arahkan ke **Developers → API Keys**. Klik **"Create New API"**.

    <Tip>
      Beri nama API key Anda secara deskriptif (mis., 'ParityDeals') sehingga Anda dapat mengenalinya di kemudian hari.
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="Membuat API key baru di Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Salin API key yang Anda buat dan tempelkan ke antarmuka ParityDeals untuk menjalin koneksi dengan akun Dodo Payments Anda.

    <Frame>
      <img src="/images/ppp/4.png" alt="Menghubungkan API key ke ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Setelah terhubung, ParityDeals akan mengambil katalog produk Dodo Payments Anda. Pilih produk yang ingin Anda kaitkan dengan penawaran Anda.

    <Frame>
      <img src="/images/ppp/5.png" alt="Memilih produk untuk ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Masukkan URL situs web Anda dan pilihlah secara opsional halaman sasaran spesifik di mana banner diskon seharusnya muncul. Kemudian pilih jenis penawaran yang Anda inginkan:
    - Penawaran berbasis lokasi
    - Penawaran liburan
    - Penawaran kilat berbasis waktu

    <Frame>
      <img src="/images/ppp/6.png" alt="Mengonfigurasi pengaturan penawaran" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Pilih negara-negara yang ingin Anda tawarkan diskon terlokalisasi dan tentukan persentase diskon untuk masing-masing. ParityDeals memberikan default yang direkomendasikan yang dapat Anda sesuaikan sesuai kebutuhan.

    <Frame>
      <img src="/images/ppp/7.png" alt="Menetapkan aturan diskon berbasis negara" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Desain banner diskon Anda dengan menyesuaikan teks, memilih warna dan tata letak, dan memilih posisi banner (atas atau bawah halaman). Banner ini akan ditampilkan kepada pengunjung yang memenuhi syarat berdasarkan aturan yang Anda konfigurasikan.

    <Frame>
      <img src="/images/ppp/8.png" alt="Menyesuaikan banner diskon" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Setelah menyimpan penawaran Anda, ParityDeals akan menghasilkan skrip. Tambahkan skrip ini ke kode situs web Anda (biasanya di bagian `<head>`). Skrip ini secara otomatis mendeteksi lokasi pengunjung dan menampilkan banner diskon yang sesuai.

    <Frame>
      <img src="/images/ppp/9.png" alt="Skrip integrasi ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

#### Fitur Tambahan

Dengan ParityDeals, Anda juga dapat menawarkan [diskon otomatis berbasis waktu](https://www.paritydeals.com/features/time-based-discounts/) dan [promosi berbasis liburan](https://www.paritydeals.com/features/holiday-based-discounts/) sepanjang tahun. Untuk informasi lebih rinci, lihat [Dokumentasi ParityDeals](https://www.paritydeals.com/docs/).

### Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) adalah platform lain yang terintegrasi dengan Dodo Payments untuk menawarkan penetapan harga paritas daya beli berbasis lokasi. Ini mendukung produk satu kali dan berlangganan.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Ikhtisar integrasi Evendeals Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### Fitur Utama

- **Sinkronisasi kupon otomatis** — Kupon dibuat dan dikelola di Dodo Payments secara otomatis
- **Diskon persentase** — Tawarkan diskon persentase untuk setiap grup negara
- **Dukungan berlangganan** — Diskon berlaku di seluruh siklus penagihan berlangganan
- **Aturan penyegaran otomatis** — Rotasi kode kupon secara otomatis berdasarkan interval waktu, jumlah penukaran, atau jumlah tampilan untuk mencegah penyalahgunaan

<Info>
Kode diskon yang dibuat oleh Evendeals akan otomatis muncul di dasbor Dodo Payments Anda di bawah Penjualan → Diskon.
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="Fitur utama Evendeals untuk integrasi Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### Pengaturan

<Steps>
  <Step title="Create a Dodo Payments API key">
    Di dasbor Dodo Payments Anda, buka **Developers → API Keys** dan buat kunci baru.
  </Step>

  <Step title="Connect in Evendeals">
    Di dasbor [Evendeals](https://www.evendeals.com/signin), navigasikan ke **Integrations**, temukan kartu Dodo Payments, dan tempelkan API key Anda.
  </Step>

  <Step title="Configure regional discounts">
    Tetapkan diskon persentase untuk setiap grup negara dan tekan sinkronisasi. Evendeals membuat kupon di Dodo Payments secara otomatis.

    <Check>
    Setelah sinkronisasi, buka **Sales → Discounts** di dasbor Dodo Payments Anda untuk memastikan kupon yang dihasilkan muncul. Setiap kupon akan memiliki awalan Evendeals yang dapat dikenali.
    </Check>
  </Step>
</Steps>

<Frame>
  <img src="/images/ppp/evendeals-setup.png" alt="Panduan pengaturan Evendeals untuk Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Baik ParityDeals dan Evendeals bekerja dengan mulus dengan Dodo Payments untuk membantu Anda mengoptimalkan strategi penetapan harga global Anda. Untuk detail lebih lanjut, kunjungi [Dokumentasi ParityDeals](https://www.paritydeals.com/docs/) atau [halaman integrasi Dodo Payments di Evendeals](https://www.evendeals.com/integrations/dodo-payments).
