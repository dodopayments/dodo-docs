<Info>
Framer entitlement membuka tautan remix template Framer untuk pelanggan yang membayar. Anda mengunggah template ke Dodo Payments, melampirkan entitlement ke produk, dan pelanggan menerima tautan remix yang memungkinkan mereka menggandakan template ke akun Framer mereka sendiri.
</Info>

## Apa yang diberikan

- Tautan remix unik ke template Framer yang telah Anda unggah.
- Pelanggan mengklik tautan untuk meremix template ke dalam ruang kerja Framer mereka sendiri.
- Pada pembatalan atau pengembalian dana, tautan remix dibatalkan.

Penggunaan umum termasuk template halaman arahan berbayar Framer, kit portofolio, dan pustaka komponen.

## Hubungkan Framer

Framer dihubungkan secara implisit pada saat pertama kali Anda membuat entitlement template. Tidak ada langkah OAuth terpisah.

<Steps>
<Step title="Open Entitlements">
Di dasbor Dodo Payments Anda, buka **Entitlements** dan klik **+**.
</Step>

<Step title="Pick Framer">
Pilih **Framer Template** sebagai integrasi.
</Step>

<Step title="Grab the remix link from Framer">
Buka proyek Framer Anda. Dari menu kiri atas, buka **File → Copy Remix Link**. Ini menghasilkan URL remix publik yang memungkinkan siapa saja menggandakan proyek ke akun Framer mereka sendiri — tautan ini akan dibagi Dodo Payments kepada pelanggan yang membayar.
<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">

<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">
<img src="/images/entitlements/framer/copy-remix-link.png" alt="Menu File Framer dengan opsi Copy Remix Link yang disorot" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Add the template and create the entitlement">
Kembali ke dasbor Dodo Payments, pilih template dari dropdown **Template**. Untuk pertama kalinya Anda melakukan ini untuk template baru, tempelkan tautan remix yang Anda salin untuk mendaftarkannya. Beri entitlement **nama** dan klik **Create Entitlement**.
<Frame>

<Frame>
<img src="/images/entitlements/framer/create.png" alt="Form entitlement template Framer dengan pemilih template dan kolom nama" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Dodo Payments mendaftarkan template dan mengembalikan `framer_template_id` yang dapat Anda referensi secara programatik.
</Step>
</Steps>

## Alur pelanggan

1. Pelanggan menyelesaikan pembelian.
2. Dodo Payments membuat `pending` dan menerbitkan tautan remix unik yang terikat pada pelanggan tersebut.
3. Pemberian beralih ke `delivered` setelah tautan remix disediakan dan tautan tersebut disertakan dalam email dan portal pelanggan.
4. Pelanggan mengklik tautan, masuk ke Framer, dan meremix template.
5. Pada pencabutan, tautan remix dibatalkan. Salinan yang sudah diremix di akun Framer pelanggan tetap ada, karena Framer tidak menyediakan cara untuk mencabutnya.

## Konfigurasi yang dibutuhkan

| Field | Required | Description |
|---|---|---|
| `framer_template_id` | Ya | ID template yang dikembalikan saat Anda mengunggah template. |

## Buat melalui API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Portfolio Kit',
  integration_type: 'framer',
  integration_config: {
    framer_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Portfolio Kit",
    integration_type="framer",
    integration_config={"framer_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Portfolio Kit"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFramer),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFramerConfigParam{
      FramerTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

Lihat [`entitlement_grant.*` acara webhook](/developer-resources/webhooks/intents/entitlement-grant). Pemberian Framer tiba `pending` dan beralih ke `delivered` setelah tautan remix disediakan.

## Pemecahan Masalah

<AccordionGroup>
<Accordion title="Customer's remix link doesn't work">
Tautan remix adalah sekali pakai dan terkait dengan pelanggan. Jika mereka membersihkan tautan sebelum meremix, batalkan pemberian dan keluarkan ulang.
</Accordion>

<Accordion title="Refunded customer still has a remixed copy">
Ini adalah yang diharapkan. Framer memperlakukan remix sebagai proyek milik pelanggan setelah digandakan; Dodo Payments membatalkan tautan asli tetapi tidak dapat menghapus salinan di akun pelanggan.
</Accordion>
</AccordionGroup>
