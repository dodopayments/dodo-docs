<Info>
Entitlement Framer membuka tautan remix template Framer untuk pelanggan yang membayar. Anda mengunggah template ke Dodo Payments, mengaitkan entitlement tersebut ke suatu produk, dan pelanggan menerima tautan remix yang memungkinkan mereka mengkloning template ke akun Framer mereka sendiri.
</Info>

## Apa yang diberikan

- Tautan remix unik ke template Framer yang Anda unggah.
- Pelanggan mengeklik tautan tersebut untuk me-remix template ke workspace Framer mereka sendiri.
- Saat terjadi pembatalan atau pengembalian dana, tautan remix akan dibatalkan.

Penggunaan umumnya mencakup template landing page Framer berbayar, kit portofolio, dan pustaka komponen.

## Hubungkan Framer

Framer terhubung secara implisit saat pertama kali Anda membuat entitlement template. Tidak ada langkah OAuth terpisah.

<Steps>
<Step title="Open Entitlements">
Di dashboard Dodo Payments, buka **Entitlements** dan klik **+**.
</Step>

<Step title="Pick Framer">
Pilih **Framer Template** sebagai integrasi.
</Step>

<Step title="Grab the remix link from Framer">
Buka proyek Framer Anda. Dari menu kiri atas, buka **File → Copy Remix Link**. Tindakan ini menghasilkan URL remix publik yang memungkinkan siapa pun mengkloning proyek ke akun Framer mereka sendiri — tautan yang akan dibagikan oleh Dodo Payments kepada pelanggan yang membayar.

<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">
<img src="/images/entitlements/framer/copy-remix-link.png" alt="Menu File Framer dengan opsi Copy Remix Link yang disorot" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Add the template and create the entitlement">
Kembali ke dashboard Dodo Payments, pilih template dari dropdown **Template**. Saat pertama kali melakukan ini untuk template baru, tempelkan tautan remix yang Anda salin untuk mendaftarkannya. Berikan **nama** untuk entitlement tersebut, lalu klik **Create Entitlement**.

<Frame>
<img src="/images/entitlements/framer/create.png" alt="Form entitlement template Framer dengan pemilih template dan kolom nama" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Dodo Payments mendaftarkan template dan mengembalikan `framer_template_id` yang dapat Anda referensikan secara terprogram.
</Step>
</Steps>

## Alur pelanggan

1. Pelanggan menyelesaikan checkout.
2. Dodo Payments membuat grant `pending` dan menerbitkan tautan remix unik yang terikat pada pelanggan tersebut.
3. Grant beralih ke `delivered` setelah tautan remix disediakan, dan tautan tersebut disertakan dalam email serta portal pelanggan.
4. Pelanggan mengeklik tautan, masuk ke Framer, lalu me-remix template.
5. Saat dicabut, tautan remix akan dibatalkan. Salinan yang sudah di-remix di akun Framer pelanggan tetap ada, karena Framer tidak menyediakan cara untuk mencabutnya.

## Konfigurasi yang diperlukan

| Field | Required | Description |
|---|---|---|
| `framer_template_id` | Yes | ID template yang dikembalikan saat Anda mengunggah template. |

## Buat melalui API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Portfolio Kit',
  integration_type: 'framer',
  integration_config: {
    framer_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Portfolio Kit",
    integration_type="framer",
    integration_config={"framer_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Portfolio Kit"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFramer),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFramerConfigParam{
      FramerTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

Lihat [peristiwa webhook `entitlement_grant.*`](/developer-resources/webhooks/intents/entitlement-grant). Grant Framer tiba sebagai `pending` dan beralih ke `delivered` setelah tautan remix disediakan.

## Pemecahan masalah

<AccordionGroup>
<Accordion title="Customer's remix link doesn't work">
Tautan remix hanya dapat digunakan sekali dan terikat pada pelanggan. Jika mereka menghapus tautan sebelum melakukan remix, cabut grant tersebut lalu terbitkan kembali.
</Accordion>

<Accordion title="Refunded customer still has a remixed copy">
Hal ini memang diharapkan. Framer memperlakukan remix sebagai proyek milik pelanggan setelah dikloning; Dodo Payments membatalkan tautan asli, tetapi tidak dapat menghapus salinan di akun pelanggan.
</Accordion>
</AccordionGroup>
