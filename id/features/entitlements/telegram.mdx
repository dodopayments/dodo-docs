<Info>
Hak Telegram memberikan akses kepada pelanggan berbayar ke obrolan atau saluran pribadi. Bot Dodo Payments Telegram menghasilkan tautan undangan satu kali untuk setiap pelanggan dan mengeluarkan mereka jika ada pembatalan.
</Info>

## Apa yang disampaikan

- Hak dibuat dalam `pending` saat bot menyiapkan undangan, lalu beralih ke `delivered` setelah tautan siap.
- Pelanggan menerima tautan undangan Telegram satu kali dalam email pengiriman dan portal pelanggan mereka.
- Mereka mengetuk tautan dan bot menambahkan mereka ke obrolan yang dikonfigurasikan.
- Pada pembatalan, pengembalian dana, atau pencabutan manual, bot menghapus mereka dari obrolan.

Penggunaan umum termasuk saluran alpha pribadi, grup sinyal berbayar, dan keuntungan tingkat komunitas.

## Hubungkan Telegram

<Steps>
<Step title="Open Entitlements">
Di dasbor Dodo Payments Anda, pergi ke **Entitlements** dan klik **+**, lalu pilih **Telegram Access** sebagai integrasi. Dasbor meminta ID pengguna Telegram Anda sehingga bot dapat memverifikasi kepemilikan obrolan yang dikelolanya.

<Frame caption="New Entitlement → Telegram Access. The dashboard needs your Telegram user ID before it lists chats.">
<img src="/images/entitlements/telegram/connect-prompt.png" alt="Form akses Telegram Entitlement baru meminta ID pengguna Telegram dan tombol Hubungkan Telegram" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Tip>
Dua langkah berikutnya adalah tugas pengaturan di Telegram dan dapat diselesaikan dalam urutan apa pun — dapatkan ID pengguna Anda dan tambahkan bot ke obrolan Anda sebagai admin. Setelah keduanya selesai, kembali ke dasbor untuk langkah terakhir.
</Tip>
</Step>

<Step title="Get your Telegram user ID">
Di Telegram, pesan **`/start`** ke:

- **`@dodo_payments_bot`** jika Anda menggunakan **Live Mode**
- **`@DodoPaymentsTestBot`** jika Anda menggunakan **Test Mode**

Bot menjawab dengan ID pengguna Telegram numerik Anda. Salin ini — Anda akan menempelkannya ke dasbor pada langkah terakhir.
</Step>

<Step title="Add the bot to your chat as an admin">
Di grup atau saluran Telegram yang ingin Anda jaga, buka daftar anggota dan **tambahkan bot yang sama sebagai admin** (`@dodo_payments_bot` untuk live, `@DodoPaymentsTestBot` untuk test) dengan dua izin ini diaktifkan:

- **Ban Users** — diperlukan untuk menghapus anggota saat pencabutan
- **Add Users** — diperlukan untuk mengundang pelanggan berbayar

Nonaktifkan izin admin lainnya.

<Frame caption="Telegram → Promote to admin. Only Ban Users and Add Users need to be enabled.">
<img src="/images/entitlements/telegram/promote-bot-admin.png" alt="Layar Promosikan ke admin Telegram menunjukkan Ban Users dan Add Users diaktifkan untuk bot Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Connect Telegram and pick the chat">
Kembali ke dasbor, tempelkan ID pengguna dari langkah 2 ke **Telegram User ID** dan klik **Connect Telegram**. Pemilih obrolan sekarang mencantumkan setiap grup dan saluran di mana bot menjadi admin — pilih yang ingin Anda jaga, beri nama hak tersebut, dan klik **Create Entitlement**.
</Step>
</Steps>

## Alur pelanggan

1. Pelanggan menyelesaikan pembayaran.
2. Dodo Payments membuat `pending` grant dan meminta bot untuk menghasilkan tautan undangan satu kali ke obrolan yang dikonfigurasikan.
3. Setelah tautan siap, grant pindah ke `delivered` dan tautan dimasukkan dalam email pengiriman dan portal pelanggan.
4. Pelanggan mengetuk tautan dan ditambahkan ke obrolan.
5. Pada pencabutan, bot menghapus pelanggan dari obrolan.

<Tip>
Tautan undangan hanya dapat digunakan satu kali dan berakhir setelah pelanggan bergabung. Jika mereka kehilangan tautan sebelum bergabung, buatlah ulang dengan mengirim ulang email pengiriman atau mencabut dan membuat ulang grant dari dasbor.
</Tip>

## Konfigurasi yang diperlukan

| Field | Diperlukan | Deskripsi |
|---|---|---|
| `chat_id` | Ya | ID obrolan Telegram (numerik, sering kali negatif untuk grup/saluran). Pemilih dasbor mengisinya untuk Anda. |

## Membuat melalui API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Premium Signals Group',
  integration_type: 'telegram',
  integration_config: {
    chat_id: '-1001234567890',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Premium Signals Group",
    integration_type="telegram",
    integration_config={"chat_id": "-1001234567890"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Premium Signals Group"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeTelegram),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigTelegramConfigParam{
      ChatID: dodopayments.F("-1001234567890"),
    },
  ),
})
```

</CodeGroup>

## Webhook

Lihat [`entitlement_grant.*` acara webhook](/developer-resources/webhooks/intents/entitlement-grant). Grants Telegram datang `pending` dan beralih ke `delivered` setelah bot mengeluarkan tautan undangan.

## Pemecahan masalah

<AccordionGroup>
<Accordion title="Chat doesn't appear in the picker">
Bot Dodo Payments harus ditambahkan ke obrolan **sebagai admin** dengan **Add Users** diaktifkan. Pemilih membaca status hidup, sehingga obrolan muncul segera setelah bot menjadi admin.
</Accordion>

<Accordion title="Customer says the invite link doesn't work">
Tautan satu kali Telegram berakhir setelah penggunaan pertama. Jika pelanggan mengetuknya di perangkat yang keluar atau kehilangan tautan, cabut hak dan buat ulang.
</Accordion>

<Accordion title="Customer cancelled but is still in the chat">
Bot memerlukan izin admin **Ban Users** untuk menghapus anggota. Buka pengaturan obrolan dan konfirmasi bahwa **Ban Users** dan **Add Users** dicentang pada bot Dodo Payments.
</Accordion>
</AccordionGroup>
