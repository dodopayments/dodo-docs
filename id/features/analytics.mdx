Lacak perjalanan pelanggan dari etalase Anda melalui proses checkout hingga penyelesaian pembelian. Dodo Payments mengintegrasikan dengan Google Analytics 4, Google Tag Manager, dan Meta Pixel untuk memberikan analitik komprehensif di semua halaman yang dihosting.

<Info>
Pelacakan analitik secara otomatis diaktifkan di Etalase Anda, halaman Checkout, dan Portal Pelanggan setelah Anda menambahkan ID pelacakan Anda di dasbor.
</Info>

<Warning>
Pemblokir iklan di browser pelanggan dapat mencegah pelacakan analitik dari berfungsi untuk beberapa pengunjung ke toko Anda.
</Warning>

## Memulai

<Steps>
<Step title="Buka Pengaturan Bisnis">
  Di dasbor Dodo Payments Anda, buka **Pengaturan** dan gulir ke bagian **Analitik**.
</Step>

<Step title="Aktifkan Platform Pelacakan Anda">
  Aktifkan platform analitik yang ingin Anda gunakan dan masukkan ID pelacakan Anda:
  - **Google Analytics**: Masukkan ID Pengukuran Anda (format: `G-XXXXXXXXXX`)
  - **Google Tag Manager**: Masukkan ID Kontainer Anda (format: `GTM-XXXXXXX`)
  - **Meta Pixel**: Masukkan ID Pixel Anda (numeric, 10-20 digit)
</Step>

<Step title="Simpan Pengaturan Anda">
  Klik **Simpan** untuk menerapkan konfigurasi pelacakan Anda.
</Step>

<Step title="Verifikasi Pelacakan">
  Kunjungi etalase Anda atau buat checkout uji untuk memverifikasi bahwa peristiwa dilacak di dasbor analitik Anda.
</Step>
</Steps>

## Google Analytics 4

[Google Analytics 4](https://marketingplatform.google.com/about/analytics/) menyediakan analitik web yang komprehensif dengan kemampuan pelacakan e-commerce. Dengan integrasi Dodo Payments, Anda dapat melacak seluruh perjalanan pelanggan dari browsing toko Anda hingga menyelesaikan pembelian.

### Tambahkan ID Pengukuran Google Analytics Anda

1. Di Google Analytics, buka **Admin** → **Data Streams** → pilih aliran web Anda
2. Salin **ID Pengukuran** (dimulai dengan `G-`)
3. Di dasbor Dodo Payments, buka **Pengaturan** → **Analitik**
4. Aktifkan **Google Analytics** dan tempelkan ID Pengukuran Anda
5. Klik **Simpan**

<Tip>
Jika Anda belum memiliki properti Google Analytics, ikuti [panduan pengaturan Google](https://support.google.com/analytics/answer/9304153) untuk membuat satu.
</Tip>

### Peristiwa yang Dilacak di Google Analytics

Kami melacak peristiwa berikut di etalase dan halaman checkout yang dihosting. Data peristiwa termasuk informasi produk, total transaksi, dan mata uang dikirimkan dengan setiap peristiwa.

#### Peristiwa Etalase

| Peristiwa | Deskripsi |
|-----------|-----------|
| `view_item_list` | Ditembak saat halaman etalase dimuat dengan produk |
| `select_item` | Ditembak saat pelanggan mengklik produk untuk memulai checkout |

#### Peristiwa Checkout

| Peristiwa | Deskripsi |
|-----------|-------------|
| `view_item` | Ditembak saat halaman checkout dimuat |
| `view_cart` | Ditembak saat checkout dimuat dan saat varian dipilih |
| `apply_discount`* | Ditembak saat kode diskon yang valid diterapkan dengan sukses |
| `remove_discount`* | Ditembak saat kode diskon dihapus |
| `add_payment_info` | Ditembak saat pelanggan mengirimkan formulir pembayaran |
| `purchase` | Ditembak saat pembayaran berhasil |

<Note>
`apply_discount` dan `remove_discount` adalah peristiwa kustom yang tidak termasuk dalam [peristiwa e-commerce standar Google Analytics](https://support.google.com/analytics/answer/9267735).
</Note>

### Menggunakan GA4 dengan Checkout Overlay/Inline

Untuk melacak peristiwa Google Analytics di checkout overlay atau inline yang disematkan di situs web Anda sendiri, Anda perlu menginstal kode pelacakan Google Analytics di situs web Anda di mana checkout disematkan.

Setelah terinstal, semua peristiwa pelacakan yang tercantum di atas akan dikirim ke akun Google Analytics Anda secara otomatis - tidak diperlukan konfigurasi tambahan.

## Google Tag Manager

[Google Tag Manager](https://marketingplatform.google.com/about/tag-manager/) memungkinkan Anda mengelola tag pemasaran dan analitik tanpa memodifikasi kode. Tag yang diterapkan melalui GTM akan ditembakkan di semua halaman yang dihosting oleh Dodo Payments.

### Tambahkan ID Kontainer GTM Anda

1. Di Google Tag Manager, salin **ID Kontainer** Anda (dimulai dengan `GTM-`)
2. Di dasbor Dodo Payments, buka **Pengaturan** → **Analitik**
3. Aktifkan **Google Tag Manager** dan tempelkan ID Kontainer Anda
4. Klik **Simpan**

<Info>
Saat menggunakan GTM, Anda dapat mengonfigurasi pelacakan tambahan (seperti konversi Google Ads) langsung di kontainer GTM Anda. Integrasi Dodo Payments menyuntikkan skrip GTM dan fallback noscript untuk kompatibilitas maksimum.
</Info>

### Menggunakan GTM dengan Checkout Overlay/Inline

Untuk checkout overlay atau inline yang disematkan di situs web Anda, instal GTM di situs Anda sendiri. Checkout akan mewarisi konfigurasi GTM Anda dan menembakkan peristiwa dalam bingkai yang disematkan.

## Meta Pixel

[Meta Pixel](https://www.facebook.com/business/tools/meta-pixel/) melacak tindakan pelanggan di toko Anda untuk mengukur efektivitas kampanye iklan Facebook dan Instagram Anda. Lacak konversi mulai dari klik iklan hingga penyelesaian pembelian.

### Tambahkan ID Meta Pixel Anda

1. Di [Meta Events Manager](https://www.facebook.com/events_manager2/), buat atau pilih Pixel Anda
2. Salin **ID Pixel** (numeric, biasanya 15-16 digit)
3. Di dasbor Dodo Payments, buka **Pengaturan** → **Analitik**
4. Aktifkan **Meta Pixel** dan tempelkan ID Pixel Anda
5. Klik **Simpan**

<Tip>
Ikuti [panduan pengaturan Pixel Meta](https://www.facebook.com/business/help/952192354843755) jika Anda belum membuat Pixel.
</Tip>

### Peristiwa yang Dilacak dengan Meta Pixel

Kami melacak peristiwa berikut yang muncul di [Meta Events Manager](https://www.facebook.com/events_manager2/). Data peristiwa termasuk ID konten, nilai, dan mata uang dikirimkan dengan setiap peristiwa.

<Note>
Peristiwa mungkin tidak muncul segera di Meta Events Manager - mungkin ada keterlambatan beberapa menit.
</Note>

#### Peristiwa Etalase

| Peristiwa | Deskripsi |
|-----------|-----------|
| `PageView` | Ditembak saat halaman etalase dimuat |
| `ViewContent` | Ditembak saat etalase dimuat dengan produk |
| `InitiateCheckout` | Ditembak saat pelanggan mengklik produk untuk memulai checkout |

#### Peristiwa Checkout

| Peristiwa | Deskripsi |
|-----------|-----------|
| `PageView` | Ditembak saat halaman checkout dimuat |
| `AddToCart` | Ditembak saat checkout dimuat dan saat varian dipilih |
| `ApplyDiscount`* | Ditembak saat kode diskon yang valid diterapkan dengan sukses |
| `RemoveDiscount`* | Ditembak saat kode diskon dihapus |
| `AddPaymentInfo` | Ditembak saat pelanggan mengirimkan formulir pembayaran |
| `Purchase` | Ditembak saat pembayaran berhasil |

<Note>
`ApplyDiscount` dan `RemoveDiscount` adalah peristiwa kustom yang tidak termasuk dalam [peristiwa standar Meta](https://developers.facebook.com/docs/meta-pixel/reference#standard-events).
</Note>

## Referensi Lengkap Peristiwa

Tabel ini menunjukkan semua peristiwa yang dilacak di Google Analytics 4 dan Meta Pixel:

| Trigger | Peristiwa GA4 | Peristiwa Meta Pixel | Lokasi |
|---------|---------------|--------------------|--------|
| Halaman etalase dimuat | `view_item_list` | `ViewContent` | Etalase |
| Pelanggan mengklik produk | `select_item` | `InitiateCheckout` | Etalase |
| Halaman checkout dimuat | `view_item` | `AddToCart` | Checkout |
| Keranjang dilihat/varian dipilih | `view_cart` | - | Checkout |
| Kode diskon diterapkan | `apply_discount` | `ApplyDiscount` | Checkout |
| Kode diskon dihapus | `remove_discount` | `RemoveDiscount` | Checkout |
| Formulir pembayaran diserahkan | `add_payment_info` | `AddPaymentInfo` | Checkout |
| Pembayaran berhasil | `purchase` | `Purchase` | Checkout |

## Cakupan Platform

Pelacakan analitik tersedia di berbagai permukaan Dodo Payments:

| Permukaan | Google Analytics 4 | Google Tag Manager | Meta Pixel |
|---------|-------------------|-------------------|------------|
| Etalase | Ya | Ya | Ya |
| Checkout (Di-host) | Ya | Ya | Ya |
| Checkout (Overlay/Inline)* | Ya | Ya | Ya |
| Portal Pelanggan | Ya | Ya | Tidak |

<Info>
*Untuk checkout overlay dan inline, instal kode pelacakan di situs web Anda sendiri untuk atribusi penuh. Peristiwa dari checkout yang disematkan akan dilacak secara otomatis.
</Info>

## Data Peristiwa yang Dimasukkan

Setiap peristiwa pelacakan mencakup data e-commerce yang relevan untuk membantu Anda menganalisis perilaku pelanggan:

### Data Produk
- ID Produk
- Nama Produk
- Harga
- Mata Uang
- Kuantitas

### Data Transaksi (Peristiwa Pembelian)
- ID Transaksi/Pembayaran
- Jumlah total
- Jumlah pajak
- Mata Uang
- Diskon yang diterapkan

### Data Pelanggan
- ID Pelanggan (untuk pelanggan yang kembali)
- Email (hash untuk privasi jika berlaku)

## Praktik Terbaik

<AccordionGroup>
<Accordion title="Uji Integrasi Anda">
Setelah menambahkan ID pelacakan Anda, kunjungi etalase Anda dan selesaikan checkout uji untuk memverifikasi peristiwa muncul di dasbor analitik Anda. Gunakan laporan Waktu Nyata Google Analytics atau fitur Uji Peristiwa di Meta Events Manager.
</Accordion>

<Accordion title="Gunakan Parameter UTM">
Tambahkan parameter UTM ke tautan pemasaran Anda untuk melacak kampanye mana yang mendorong konversi. Dodo Payments mempertahankan parameter UTM sepanjang alur checkout.
</Accordion>

<Accordion title="Atur Tujuan Konversi">
Di Google Analytics, buat peristiwa konversi untuk `purchase` untuk melacak tingkat konversi Anda. Di Meta Ads Manager, gunakan peristiwa `Purchase` sebagai tujuan optimisasi untuk kampanye.
</Accordion>

<Accordion title="Aktifkan E-commerce yang Ditingkatkan">
Jika menggunakan Google Tag Manager, pertimbangkan untuk mengatur laporan E-commerce yang Ditingkatkan untuk analisis corong yang lebih mendetail dan metrik kinerja produk.
</Accordion>
</AccordionGroup>

## Pemecahan Masalah

<AccordionGroup>
<Accordion title="Peristiwa tidak muncul di Google Analytics">
- Verifikasi ID Pengukuran Anda benar (format: `G-XXXXXXXXXX`)
- Periksa laporan Waktu Nyata Google Analytics - peristiwa muncul di sana terlebih dahulu
- Pastikan toggle diaktifkan di pengaturan Dodo Payments Anda
- Tunggu beberapa menit karena mungkin ada keterlambatan pemrosesan
- Uji di jendela incognito untuk mengesampingkan pemblokir iklan
</Accordion>

<Accordion title="Peristiwa tidak muncul di Meta Events Manager">
- Verifikasi ID Pixel Anda benar (numeric, 10-20 digit)
- Gunakan ekstensi browser Meta Pixel Helper untuk debug
- Periksa tab Uji Peristiwa di Events Manager
- Peristiwa dapat memerlukan beberapa menit untuk muncul
- Pastikan pemblokir iklan dinonaktifkan selama pengujian
</Accordion>

<Accordion title="Tag GTM tidak berjalan">
- Konfirmasi ID Kontainer Anda benar (format: `GTM-XXXXXXX`)
- Gunakan mode Prabaca GTM untuk debug pelaksanaan tag
- Periksa apakah pemicu dikonfigurasi dengan benar di kontainer GTM Anda
- Verifikasi kontainer dipublikasikan (bukan hanya dalam draf)
</Accordion>

<Accordion title="Checkout Overlay/Inline tidak melacak">
- Instal kode pelacakan di situs web Anda sendiri terlebih dahulu
- Pastikan pelacakan dimuat sebelum overlay checkout dibuka
- Periksa konsol browser untuk kesalahan JavaScript apapun
- Verifikasi pelacakan lintas domain dikonfigurasi jika menggunakan GA4
</Accordion>

<Accordion title="Peristiwa Pembelian menunjukkan jumlah yang salah">
- Jumlah dikirim dalam unit mata uang terkecil (sen)
- Verifikasi alat analitik Anda dikonfigurasi untuk menampilkan mata uang yang benar
- Periksa apakah pajak sudah termasuk/eksklusif seperti yang diharapkan
</Accordion>
</AccordionGroup>
