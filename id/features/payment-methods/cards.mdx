Pembayaran kartu adalah fondasi pembayaran online, diterima di seluruh dunia dan dipercaya oleh pelanggan di berbagai negara. Dodo Payments mendukung semua jaringan kartu utama dengan perlindungan fraud bawaan dan kepatuhan PCI.

## Konfigurasi

Gunakan nilai-nilai ini di `allowed_payment_method_types`:

| Tipe | Deskripsi |
| :--- | :---------- |
| `credit` | Semua kartu kredit |
| `debit` | Semua kartu debit |

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

<Tip>
Sertakan `credit` dan `debit` kecuali Anda memiliki alasan khusus untuk mengecualikan salah satunya. Kartu debit lebih disukai oleh banyak pelanggan dan sering kali memiliki biaya yang lebih rendah.
</Tip>

## Autentikasi 3D Secure

3D Secure (3DS) menambahkan lapisan autentikasi yang mengurangi fraud dan chargeback dengan memverifikasi identitas pemegang kartu.

### Kapan 3DS Dipicu

3DS dipicu secara otomatis ketika:
- Diwajibkan oleh jaringan kartu
- Diwajibkan oleh regulasi regional (misalnya, PSD2 di Eropa)
- Transaksi ditandai sebagai berisiko tinggi

### Memaksa 3DS

Anda dapat mewajibkan 3DS pada semua transaksi:

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  force_3ds: true,
  return_url: 'https://example.com/success'
});
```

<Note>
Mengaktifkan 3DS untuk semua transaksi mengurangi fraud, tetapi dapat sedikit menurunkan konversi karena sebagian pelanggan meninggalkan proses selama autentikasi.
</Note>

### Menangani Kegagalan Autentikasi

Ketika pembayaran memerlukan autentikasi 3DS, pembayaran melewati status perantara sebelum berhasil atau gagal:

| Status | Arti | Tindakan yang harus dilakukan |
|--------|---------|------------|
| `requires_customer_action` | Pelanggan harus menyelesaikan challenge 3DS | Minta pelanggan menyelesaikan autentikasi selama checkout |
| `requires_payment_method` | Pelanggan tidak pernah memberikan metode pembayaran (tidak memasukkan detail atau meninggalkan permintaan) — biasanya merupakan drop-off, bukan penolakan | Hubungi kembali pelanggan agar menyelesaikan checkout; lihat [Pemulihan Keranjang yang Ditinggalkan](/features/recovery/abandoned-cart-recovery) |

Jika autentikasi tidak selesai, pembayaran gagal dengan salah satu decline code berikut:

- `AUTHENTICATION_FAILURE` — pelanggan tidak dapat diautentikasi.
- `AUTHENTICATION_REQUIRED` — autentikasi diperlukan tetapi tidak dilakukan.
- `AUTHENTICATION_TIMEOUT` — pelanggan tidak merespons tepat waktu.

Lihat referensi [Kegagalan Transaksi](/api-reference/transaction-failures) untuk tindakan yang direkomendasikan bagi setiap kode.

#### Saat Checkout vs. Saat Renewal

- **Saat checkout (pelanggan hadir):** Pelanggan hadir, sehingga challenge 3DS ditampilkan selama checkout. Jika gagal, minta mereka mencoba lagi atau menggunakan kartu lain.
- **Saat renewal subscription (pelanggan tidak hadir):** Pelanggan tidak hadir, sehingga challenge 3DS tidak dapat ditampilkan secara real time. Jika renewal memerlukan autentikasi, subscription berpindah ke `on_hold`. Pulihkan dengan meminta pelanggan kembali dan memperbarui metode pembayaran mereka — lihat [Menangani Kegagalan Pembayaran](/developer-resources/handle-payment-failures) dan [Dunning Subscription](/features/recovery/subscription-dunning).

### Mengaktifkan Kartu Tersimpan

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  show_saved_payment_methods: true,
  customer: { customer_id: 'cus_existing_123' },
  return_url: 'https://example.com/success'
});
```

### Pembelian Satu Klik

```javascript
// Get customer's saved payment methods
const methods = await client.customers.retrievePaymentMethods('cus_123');

// Use saved card for instant checkout
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  customer: { customer_id: 'cus_123' },
  payment_method_id: methods.items[0].payment_method_id,
  confirm: true,
  return_url: 'https://example.com/success'
});
```

## Pemecahan Masalah

<AccordionGroup>
<Accordion title="Card declined">
**Penyebab:** Dana tidak mencukupi, kartu kedaluwarsa, CVV salah, perlindungan fraud bank.

**Solusi:** Minta pelanggan memverifikasi detail atau mencoba kartu lain. Cari decline code tertentu di referensi [Kegagalan Transaksi](/api-reference/transaction-failures) beserta tindakan yang direkomendasikan, dan lihat [Menangani Kegagalan Pembayaran](/developer-resources/handle-payment-failures) untuk penanganan secara programmatic.
</Accordion>

<Accordion title="3DS authentication failed">
**Penyebab:** Pelanggan meninggalkan proses, sistem bank tidak tersedia, timeout.

**Solusi:** Coba lagi atau minta pelanggan menghubungi bank mereka. Lihat [Menangani Kegagalan Autentikasi](#handling-authentication-failures) untuk status pembayaran dan decline code yang terkait.
</Accordion>

<Accordion title="Card not supported">
**Penyebab:** Kartu regional tidak didukung, pembatasan kartu prabayar.

**Solusi:** Pelanggan sebaiknya mencoba kartu lain dari jaringan utama.
</Accordion>
</AccordionGroup>
