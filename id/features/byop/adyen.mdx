<Note>
Panduan ini berlaku ketika Anda menghubungkan **Adyen** sebagai pemroses Anda sendiri melalui [Bring Your Own Processor (BYOP)](/features/byop). [Hubungi kami](mailto:founders@dodopayments.com) jika Anda memerlukan bantuan.
</Note>

## Aktifkan akses data kartu mentah

Sebelum Dodo dapat merutekan pembayaran melalui Adyen, akun Adyen Anda perlu mengaktifkan **akses data kartu mentah**. Adyen mengatur ini di belakang kepatuhan PCI DSS. Karena **Dodo Payments menangani data kartu mentah atas nama Anda** dan **mematuhi PCI DSS Level 1**, Anda memberikan **Attestation of Compliance (AOC) Dodo Payments** kepada Adyen — Anda tidak perlu sertifikasi Anda sendiri.

<Card title="Dodo Payments PCI DSS Attestation of Compliance (AOC)" icon="file-shield" href="https://pub-2a89184e4c954b599464449d23f506bb.r2.dev/dodo-payments-pci-dss-aoc.pdf">
Unduh AOC terkini dari Dodo Payments dan ajukan ke dukungan Adyen untuk mengaktifkan akses data kartu mentah.
</Card>

Hubungi dukungan Adyen untuk meminta akses kartu mentah untuk akun merchant Anda, lampirkan AOC yang disebutkan di atas.

## Apa yang Anda perlukan

Untuk menghubungkan Adyen di **Pengaturan → BYOP**, kumpulkan tiga nilai dari Adyen Customer Area:

| Nilai | Asal |
|-------|---------------------|
| **API key** | Developers → API credentials |
| **Merchant Account** | Identifikasi akun merchant Adyen Anda |
| **HMAC key** | Dihasilkan saat Anda mengatur webhook |

<Info>
Adyen menyimpan kredensial **tes** (`ca-test.adyen.com`) dan **langsung** (`ca-live.adyen.com`) terpisah. Hasilkan kredensial di lingkungan yang sesuai dengan mode yang Anda konfigurasikan di Dodo.
</Info>

## Langkah 1: Hasilkan API key

<Steps>
<Step title="Open API credentials">
Di Adyen Customer Area, pergi ke **Developers → API credentials**. Anda memerlukan peran **Manage API credentials** atau **Merchant admin**.
</Step>

<Step title="Select your credential">
Pilih tab **Payments** dan pilih nama pengguna kredensial Anda (yang terlihat seperti `ws_123456@Company.YourCompanyAccount`).
</Step>

<Step title="Generate the key">
Pergi ke **Server settings → Authentication**, buka tab **API key**, dan pilih **Generate API key**.
</Step>

<Step title="Copy it immediately">
Salin dan simpan kuncinya secara aman; Anda tidak dapat menyimpan lagi setelah meninggalkan halaman. Kunci yang baru dihasilkan aktif segera, dan kunci sebelumnya tetap berfungsi selama 24 jam.
</Step>
</Steps>

## Langkah 2: Temukan akun merchant Anda

Akun **merchant** Anda adalah pengenal akun yang digunakan Adyen untuk memproses transaksi Anda. Ini ditampilkan di pemilih akun di bagian atas Customer Area (contoh, `YourCompany_ECOM`). Anda akan menempelkannya ke bidang **Merchant Account** di Dodo.

## Langkah 3: Atur webhook dan HMAC key

Dodo menghasilkan URL **Webhook Endpoint** ketika Anda menyimpan koneksi Adyen. Tambahkan sebagai webhook di Adyen dan hasilkan HMAC key. Anda memerlukan peran **Merchant admin** atau **Merchant technical integrator**.

<Steps>
<Step title="Create a webhook">
Di Customer Area, pergi ke **Developers → Webhooks** dan pilih **Create new webhook**. Dari daftar, pilih **Add** untuk tipe **Standard webhook**.
</Step>

<Step title="Configure the webhook">
- Masukkan **Description**.
- Geser **Enabled** untuk mengaktifkannya.
- Di bawah **Server configuration**, tempelkan URL **Webhook Endpoint** yang dihasilkan Dodo ke dalam bidang **URL** (harus HTTPS dan dapat diakses secara publik).
</Step>

<Step title="Generate the HMAC key">
Di bawah **Security**, dalam bagian **HMAC Key**, pilih **Generate** untuk membuat HMAC key baru. Salin dan simpan dengan aman; Anda tidak akan dapat menyalinnya lagi nanti. Kemudian pilih **Save configuration**.
</Step>

<Step title="Paste the HMAC key into Dodo">
Kembali ke **Settings → BYOP**, tempelkan HMAC key ke dalam bidang **Webhook Signing Secret** untuk menyelesaikan koneksi.

<Card title="Set up BYOP" icon="shuffle" href="/features/byop">
Ikuti alur lengkap pengaturan Bring Your Own Processor.
</Card>
</Step>
</Steps>

<Tip>
Setelah menyimpan, gunakan **Verify connection** di Dodo untuk menjalankan panggilan uji terhadap Adyen dan pastikan API key, akun merchant, dan HMAC key Anda valid sebelum Anda aktif secara langsung.
</Tip>

## Pertanyaan yang sering diajukan

<AccordionGroup>
<Accordion title="What is the HMAC key for?">
Adyen menandatangani setiap webhook dengan tanda tangan HMAC sehingga penerima dapat memverifikasi integritas dan asal pemberitahuan. Dodo menggunakan HMAC key yang Anda berikan untuk memvalidasi webhooks dari akun Adyen Anda.
</Accordion>

<Accordion title="I lost my API key or HMAC key, what now?">
Tidak satupun yang dapat diambil setelah pembuatan. Hasilkan API key baru di bawah **Developers → API credentials**, atau HMAC key baru di pengaturan webhook, kemudian perbarui nilai tersebut di **Settings → BYOP**.
</Accordion>

<Accordion title="Do test and live use the same credentials?">
Tidak. Hasilkan kredensial di lingkungan yang sesuai, tes (`ca-test.adyen.com`) atau langsung (`ca-live.adyen.com`), dan konfigurasikan dalam mode yang sesuai di Dodo.
</Accordion>
</AccordionGroup>
