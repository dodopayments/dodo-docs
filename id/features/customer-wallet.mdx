## Apa itu Dompet Pelanggan?

Dompet pelanggan adalah akun saldo moneter yang menyimpan dana nyata untuk pengguna Anda. Setiap pelanggan otomatis mendapatkan satu dompet saat Anda membuat akun mereka. Anda dapat menggunakan dompet ini untuk:

- **Menyimpan dana prabayar** untuk pembayaran langganan di masa mendatang
- **Menangani refund** sebagai saldo dompet, bukan refund kartu
- **Memberikan saldo promosi** seperti bonus selamat datang atau reward loyalitas
- **Menerapkan dana dompet ke faktur** secara otomatis selama penagihan
- **Melacak transaksi moneter** dengan riwayat ledger yang terperinci

<Info>
Setiap pelanggan secara otomatis mendapatkan dompet saat Anda membuat akun mereka. Dompet mendukung mata uang USD, EUR, dan GBP dengan saldo moneter terpisah untuk masing-masing mata uang.
</Info>

<Warning>
**Dompet Pelanggan ≠ Penagihan Berbasis Kredit**

Dompet pelanggan menyimpan **saldo moneter nyata** (USD, EUR, GBP) yang dapat digunakan untuk faktur dan pembayaran langganan.

Jika Anda ingin melacak unit penggunaan virtual (panggilan API, token, jam komputasi), lihat [Penagihan Berbasis Kredit](/features/credit-based-billing).
</Warning>

## Cara Kerjanya

Dompet pelanggan menyimpan dana yang dapat digunakan pelanggan untuk pembelian mereka. Saat pelanggan memiliki faktur atau tagihan langganan berulang, saldo dompet mereka akan diperiksa terlebih dahulu. Dana yang tersedia akan otomatis diterapkan ke faktur sebelum metode pembayaran utama mereka ditagih.

### Penyiapan Otomatis

Saat Anda membuat pelanggan baru, Dodo Payments secara otomatis membuat dompet dengan saldo nol. Dompet tersebut siap menerima dana segera melalui API kami.

### Dukungan Multi-Mata Uang

Setiap dompet dapat menyimpan saldo dalam mata uang yang berbeda:

<ResponseField name="USD Balance" type="integer">
Saldo dalam Dolar AS (disimpan dalam sen)
</ResponseField>

<ResponseField name="EUR Balance" type="integer">
Saldo dalam Euro (disimpan dalam sen)
</ResponseField>

<ResponseField name="GBP Balance" type="integer">
Saldo dalam Pound Sterling (disimpan dalam pence)
</ResponseField>

<Info>
Saat ini, hanya saldo **USD**, **EUR**, dan **GBP** yang tersedia. Dompet asli INR telah dihentikan — lihat [Struktur Payout](/features/payouts/payout-structure). INR tetap didukung sebagai mata uang transaksi untuk langganan UPI, RuPay, dan kartu India.
</Info>

## Contoh di Dunia Nyata

### Pengembalian Dana ke Dompet

Saat pelanggan meminta pengembalian dana, Anda dapat menambahkan jumlah tersebut ke saldo dompet mereka alih-alih melakukan pengembalian dana kartu secara tradisional. Dengan demikian, dana tetap berada dalam ekosistem Anda untuk pembelian di masa mendatang.

```javascript
async function refundToWallet(customerId, refundAmount, originalPaymentId) {
  await client.customers.wallets.ledgerEntries.create(customerId, {
    amount: refundAmount, // Amount in cents
    currency: 'USD',
    entry_type: 'credit',
    reason: `Refund for payment ${originalPaymentId}`,
    idempotency_key: `refund_${originalPaymentId}`
  });
}
```

### Bonus Selamat Datang / Saldo Promosi

Berikan bonus moneter selamat datang kepada pelanggan baru untuk mendorong pembelian pertama mereka.

```javascript
async function addWelcomeBonus(customerId) {
  await client.customers.wallets.ledgerEntries.create(customerId, {
    amount: 1000, // $10.00 promotional balance
    currency: 'USD',
    entry_type: 'credit',
    reason: 'Welcome bonus - $10 promotional balance',
    idempotency_key: `welcome_${customerId}`
  });
}
```

### Pembayaran Langganan dari Dompet

Kurangi dana dari dompet untuk menutupi biaya langganan atau pembelian manual.

```javascript
async function deductForPurchase(customerId, purchaseAmount, purchaseId) {
  try {
    await client.customers.wallets.ledgerEntries.create(customerId, {
      amount: purchaseAmount,
      currency: 'USD',
      entry_type: 'debit',
      reason: `Subscription charge - monthly billing`,
      idempotency_key: `charge_${purchaseId}`
    });
  } catch (error) {
    if (error.status === 400) {
      console.log('Insufficient wallet balance');
    }
  }
}
```

Izinkan pelanggan mendanai akun mereka di muka dan menggunakan saldo tersebut secara bertahap.

## Praktik Terbaik

### Mencegah Transaksi Duplikat

Gunakan kunci idempotensi untuk memastikan Anda tidak secara tidak sengaja menambahkan atau mengurangi dana dua kali untuk peristiwa yang sama.

```javascript
async function addFundsSafely(customerId, amount, reason) {
  const idempotencyKey = `${reason}_${customerId}_${Date.now()}`;
  
  try {
    const result = await client.customers.wallets.ledgerEntries.create(customerId, {
      amount: amount,
      currency: 'USD',
      entry_type: 'credit',
      reason: reason,
      idempotency_key: idempotencyKey
    });
    
    // Replaying the same idempotency_key returns the original entry rather than
    // creating a duplicate, so no special duplicate handling is required.
    return { success: true, wallet: result };
  } catch (error) {
    if (error.status === 400) {
      // e.g. insufficient balance on a debit
      return { success: false, reason: 'insufficient_balance' };
    }

    throw error;
  }
}
```

### Periksa Saldo Sebelum Menagih

Verifikasi bahwa pelanggan memiliki dana yang cukup sebelum mencoba memproses transaksi besar dari dompet.

```javascript
async function checkBalanceBeforeOperation(customerId, requiredAmount) {
  const wallets = await client.customers.wallets.list(customerId);
  const usdWallet = wallets.items.find(w => w.currency === 'USD');
  
  if (!usdWallet || usdWallet.balance < requiredAmount) {
    throw new Error('Insufficient funds for this operation');
  }
  
  return usdWallet.balance;
}
```

## Apa yang Akan Hadir Selanjutnya

<Warning>
Fitur-fitur berikut direncanakan untuk rilis mendatang:
</Warning>

- **Kedaluwarsa Saldo**: Tetapkan dana agar kedaluwarsa setelah jangka waktu tertentu
- **Analitik yang Lebih Baik**: Laporan pengeluaran terperinci dan tren saldo
- **Lebih Banyak Webhook**: Notifikasi real-time untuk perubahan saldo dan peringatan saldo rendah

<Tip>
Mulailah dengan operasi pendanaan dan pengurangan dasar, lalu integrasikan alur kerja penagihan otomatis yang lebih kompleks seiring pertumbuhan bisnis Anda.
