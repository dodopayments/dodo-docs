## Adaptive Currency

Adaptive Currency memungkinkan pelanggan membayar dalam mata uang lokal pilihan mereka, sehingga meningkatkan kepercayaan dan tingkat konversi.

### Cara Kerjanya

1. **Aktifkan**: Aktifkan Adaptive Currency dari **Settings → Business**
2. **Pilih**: Pelanggan dapat mengganti mata uang langsung di checkout
3. **Terapkan PPP**: Jika [Purchasing Power Parity](/features/purchasing-power-parity) diaktifkan pada produk, persentase negara akan mengurangi harga dasar
4. **Konversi**: Harga (atau harga yang disesuaikan dengan PPP) dikonversi ke mata uang pelanggan berdasarkan nilai FX terkini
5. **Bulatkan**: Jika [Charm Pricing](/features/charm-pricing) diaktifkan, jumlah yang dikonversi dibulatkan ke akhiran yang rapi seperti 49.99
6. **Tampilkan**: Jumlah akhir yang harus dibayar ditampilkan secara transparan sebelum pembayaran

## Penghitungan Pajak Otomatis

Pajak dihitung secara otomatis berdasarkan lokasi penagihan pelanggan, sehingga memastikan kepatuhan terhadap persyaratan GST, VAT, dan pajak penjualan tanpa penyiapan manual.

### Cara Kerja Penghitungan Pajak

<Steps>
<Step title="Location Detection">
  Aturan pajak diterapkan berdasarkan negara pelanggan (dan wilayah jika berlaku).
</Step>

<Step title="Dynamic Updates">
  Jumlah pajak diperbarui secara otomatis ketika:
  - Negara berubah
  - Alamat diperbarui
</Step>

<Step title="Transparent Display">
  Rincian pajak akhir ditampilkan dengan jelas sebelum pembayaran.
</Step>
</Steps>

<Tip>
Penghitungan pajak sepenuhnya otomatis. Tidak diperlukan konfigurasi manual untuk produk digital dan SaaS standar.
</Tip>

## Dukungan Business Tax ID

Untuk bisnis terdaftar, checkout memungkinkan pelanggan memasukkan Business Tax ID mereka (misalnya nomor VAT/GST).

### Yang Terjadi Saat Tax ID Dimasukkan

- Kelayakan pajak divalidasi secara real-time
- Pengecualian pajak atau aturan reverse charge yang berlaku diterapkan
- Jumlah pajak diperbarui secara instan di checkout

</Info>

## Kode Diskon

Pelanggan dapat menerapkan kode diskon atau promo yang Anda buat di dashboard langsung di halaman checkout.

### Pengalaman Checkout

1. Pelanggan memasukkan kode diskon
2. Diskon langsung divalidasi
3. Harga dan penghematan yang diperbarui ditampilkan dengan jelas

Jika [Purchasing Power Parity](/features/purchasing-power-parity) diaktifkan pada suatu produk, diskon diterapkan pada harga yang disesuaikan dengan PPP, bukan harga dasar.

<Frame>
  <img src="/images/checkout/c4.png" alt="Entri kode diskon di checkout" style={{ maxHeight: '500px', width: '70%' }}/>
</Frame>

### Integrasi API

Terapkan terlebih dahulu satu atau beberapa kode diskon bertingkat atau aktifkan kolom input diskon:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  discount_codes: ['WELCOME20'], // Pre-apply one or more codes (max 20, applied in order)
  feature_flags: {
    allow_discount_code: true // Shown by default; set to false to hide the field
  },
  return_url: 'https://yoursite.com/return'
});
```

<Info>
`discount_codes` menerima array yang berisi hingga 20 kode yang diterapkan secara berurutan. Kolom tunggal `discount_code` sudah tidak digunakan lagi, tetapi masih berfungsi — integrasi yang ada tidak perlu langsung diubah. Migrasikan ke `discount_codes` jika diperlukan untuk menggunakan penerapan bertingkat dan struktur respons yang lebih lengkap.
</Info>

## Pengumpulan Alamat Cerdas

Checkout mendukung entri alamat yang fleksibel untuk mempercepat penyelesaian.

### Opsi yang Tersedia

| Opsi | Deskripsi |
|--------|-------------|
| **Google Address Autofill** | Pemilihan cepat dengan autocomplete |
| **Entri Manual** | Kontrol penuh untuk alamat yang lengkap |
| **Pemilihan Negara** | Mengatur logika pajak dan kepatuhan |
| **Alamat Minimal** | Hanya mengumpulkan negara (dan ZIP jika diperlukan untuk pajak) — lihat [Mode Alamat Minimal](#minimal-address-mode) |

<Tip>
Pengumpulan alamat menyeimbangkan kecepatan, akurasi, dan cakupan global untuk memaksimalkan konversi sekaligus memastikan kepatuhan.
</Tip>

### Mode Alamat Minimal

Untuk memaksimalkan konversi, aktifkan pengumpulan alamat minimal guna mengurangi hambatan di checkout. Jika `minimal_address` diatur ke `true`, checkout hanya mengumpulkan:

- **Negara** — selalu diperlukan untuk menentukan pajak
- **Kode ZIP/pos** — hanya di wilayah yang memerlukannya untuk perhitungan pajak penjualan, VAT, atau GST

Semua kolom alamat lainnya (jalan, kota, negara bagian) dilewati, sehingga penyelesaian checkout menjadi jauh lebih cepat.

<Frame>
  <img src="/images/changelog/minimal-address.png" alt="Mode alamat minimal yang hanya menampilkan kolom negara dan kode ZIP/pos di checkout" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  minimal_address: true,
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Pengumpulan alamat lengkap tetap menjadi default. Aktifkan `minimal_address` untuk produk digital dan alur SaaS yang tidak memerlukan detail penagihan lengkap.
</Info>

<Card title="Minimal Address Reference" icon="address-card" href="/developer-resources/checkout-session#request-body">
  Lihat referensi parameter lengkap `minimal_address` di panduan API Checkout Sessions.
</Card>

## Pengumpulan Nomor Telepon

Kontrol apakah kolom nomor telepon muncul di checkout — dan apakah kolom tersebut wajib diisi — menggunakan feature flag checkout session.

| Flag | Default | Perilaku |
|------|---------|----------|
| `allow_phone_number_collection` | `true` | Menampilkan kolom nomor telepon pada formulir checkout |
| `require_phone_number` | `false` | Menjadikan kolom nomor telepon wajib diisi (validasi formulir menerapkan nilai yang tidak kosong) |

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_abc', quantity: 1 }],
  feature_flags: {
    allow_phone_number_collection: true,
    require_phone_number: true
  },
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
`require_phone_number: true` memerlukan `allow_phone_number_collection: true`. API menolak session ketika pengumpulan nomor telepon dinonaktifkan sementara nomor telepon diwajibkan.
</Warning>

<Tip>
Gunakan `require_phone_number` untuk B2B SaaS, industri yang teregulasi, atau alur apa pun yang memerlukan saluran kontak terverifikasi untuk dukungan, peninjauan penipuan, atau kepatuhan.
</Tip>

## Kolom Kustom

Kumpulkan informasi tambahan dari pelanggan selama checkout dengan menentukan kolom formulir kustom. Ini berguna untuk mengumpulkan data seperti nama perusahaan, ukuran tim, sumber rujukan, atau informasi khusus bisnis lainnya.

### Jenis Kolom yang Tersedia

| Jenis | Deskripsi |
|------|-------------|
| `text` | Input teks satu baris |
| `number` | Input numerik |
| `email` | Alamat email dengan validasi |
| `url` | URL dengan validasi |
| `date` | Pemilih tanggal |
| `dropdown` | Memilih dari opsi yang telah ditentukan |
| `boolean` | Toggle Ya/Tidak |

### Contoh

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Respons pelanggan secara otomatis disertakan dalam payload webhook (`payment.succeeded`, `subscription.active`) dan respons API melalui array `custom_field_responses`. Anda dapat menentukan hingga 5 kolom kustom per checkout session.
</Info>

## Checkout Koleksi

Product Collections memungkinkan pengalaman checkout terpadu, sehingga pelanggan dapat melihat dan memilih dari beberapa produk terkait (misalnya paket Starter, Pro, Enterprise) dalam satu checkout.

### Cara Kerjanya

1. **Semua produk ditampilkan**: Pelanggan melihat setiap produk aktif dalam koleksi
2. **Produk pertama dipilih sebelumnya**: Produk pertama dalam koleksi dipilih secara otomatis
3. **Bandingkan opsi**: Pelanggan dapat membandingkan harga dan fitur sebelum memilih
4. **Satu pilihan**: Setelah memilih produk, checkout dilanjutkan dengan alur pembayaran standar

### Membuat Checkout Koleksi

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
Saat menggunakan `product_collection_id`, teruskan array `product_cart` yang kosong. Kode diskon tidak dapat diterapkan sebelumnya saat pembuatan session.
</Warning>

## Konfigurasi Checkout Session

Kontrol perilaku checkout menggunakan API Checkout Sessions:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_codes: ['PROMO10'],
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  cancel_url: 'https://yoursite.com/pricing', // Optional: where to redirect on cancel
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
Setelah pembayaran, pelanggan dialihkan ke `return_url` Anda dengan parameter query yang ditambahkan secara otomatis -- termasuk `payment_id` atau `subscription_id`, `status`, `email`, dan `license_key` (jika berlaku). Lihat [panduan Checkout Sessions](/developer-resources/checkout-session#request-body) untuk daftar lengkapnya.
</Info>

## Kustomisasi Tema Checkout

Sesuaikan tampilan halaman checkout agar cocok dengan brand Anda menggunakan parameter `customization.theme_config` saat membuat checkout session melalui API. Konfigurasikan warna, font, radius border, dan teks tombol untuk mode terang dan gelap.

<Frame>
  <img src="/images/checkout/theme-example.png" alt="Halaman checkout dengan tema kustom" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Card title="Design & Theme Customization" icon="palette" href="/features/design">
  Konfigurasikan tema secara visual dari dashboard dengan tema siap pakai, tipografi, warna, dan pratinjau langsung.
</Card>

<Info>
Bagian ini membahas konfigurasi tema **server-side API** menggunakan `customization.theme_config`. Jika Anda menggunakan **Checkout SDK** (checkout overlay atau inline), lihat bagian kustomisasi tema di [Overlay Checkout](/developer-resources/overlay-checkout#theme-customization) yang menggunakan properti camelCase (misalnya `bgPrimary`, bukan `bg_primary`).
</Info>

### Opsi Konfigurasi Tema

| Properti | Deskripsi |
|----------|-------------|
| `light` | Konfigurasi warna untuk mode terang |
| `dark` | Konfigurasi warna untuk mode gelap |
| `font_primary_url` | URL untuk font utama |
| `font_secondary_url` | URL untuk font sekunder |
| `font_size` | Ukuran font: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `font_weight` | Ketebalan font: `normal`, `medium`, `bold`, `extraBold` |
| `radius` | Radius border untuk elemen UI (misalnya `4px`, `0.5rem`, `8px`) |
| `pay_button_text` | Teks kustom untuk tombol pembayaran (misalnya, "Complete Purchase", "Subscribe Now") |

### Konfigurasi Warna (Mode Terang/Gelap)

Setiap mode (`light` dan `dark`) mendukung properti warna berikut:

| Properti | Deskripsi |
|----------|-------------|
| `bg_primary` | Warna latar belakang utama |
| `bg_secondary` | Warna latar belakang sekunder |
| `text_primary` | Warna teks utama |
| `text_secondary` | Warna teks sekunder |
| `text_placeholder` | Warna teks placeholder |
| `text_error` | Warna teks error |
| `text_success` | Warna teks sukses |
| `border_primary` | Warna border utama |
| `border_secondary` | Warna border sekunder |
| `button_primary` | Warna latar belakang tombol utama |
| `button_primary_hover` | Warna hover tombol utama |
| `button_secondary` | Warna latar belakang tombol sekunder |
| `button_secondary_hover` | Warna hover tombol sekunder |
| `button_text_primary` | Warna teks tombol utama |
| `button_text_secondary` | Warna teks tombol sekunder |
| `input_focus_border` | Warna border fokus input |

<Info>
Semua kolom warna menerima format warna CSS standar:
- Hex: `#fff`, `#ffffff`, `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`, `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`, `hsla(120, 100%, 50%, 0.5)`
- Warna bernama: `red`, `blue`, `transparent`
</Info>

### Contoh

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
Anda tidak perlu menentukan semua properti warna. Properti apa pun yang tidak ditentukan akan menggunakan nilai tema default.
</Tip>
