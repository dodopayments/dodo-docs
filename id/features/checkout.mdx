## Adaptive Currency

Adaptive Currency memungkinkan pelanggan membayar dalam mata uang lokal pilihan mereka, sehingga meningkatkan kepercayaan dan tingkat konversi.

### Cara Kerjanya

1. **Aktifkan**: Aktifkan Adaptive Currency dari **Settings → Business**
2. **Pilih**: Pelanggan dapat mengganti mata uang langsung di checkout
3. **Konversi**: Harga dikonversi secara dinamis menggunakan nilai tukar FX real-time
4. **Tampilkan**: Jumlah akhir yang harus dibayar ditampilkan secara transparan sebelum pembayaran

## Penghitungan Pajak Otomatis

Pajak dihitung secara otomatis berdasarkan lokasi penagihan pelanggan, sehingga memastikan kepatuhan terhadap persyaratan GST, VAT, dan pajak penjualan tanpa penyiapan manual.

### Cara Kerja Penghitungan Pajak

<Steps>
<Step title="Location Detection">
  Aturan pajak diterapkan berdasarkan negara pelanggan (dan wilayah jika berlaku).
</Step>

<Step title="Dynamic Updates">
  Jumlah pajak diperbarui secara otomatis ketika:
  - Negara berubah
  - Alamat diperbarui
</Step>

<Step title="Transparent Display">
  Rincian pajak akhir ditampilkan dengan jelas sebelum pembayaran.
</Step>
</Steps>

<Tip>
Penghitungan pajak sepenuhnya otomatis. Tidak diperlukan konfigurasi manual untuk produk digital dan SaaS standar.
</Tip>

## Dukungan Business Tax ID

Untuk bisnis terdaftar, checkout memungkinkan pelanggan memasukkan Business Tax ID mereka (misalnya nomor VAT/GST).

### Yang Terjadi Saat Tax ID Dimasukkan

- Kelayakan pajak divalidasi secara real-time
- Pengecualian pajak atau aturan reverse charge yang berlaku diterapkan
- Jumlah pajak diperbarui secara instan di checkout

</Info>

## Kode Diskon

Pelanggan dapat menerapkan kode diskon atau promo yang Anda buat di dashboard langsung di halaman checkout.

### Pengalaman Checkout

1. Pelanggan memasukkan kode diskon
2. Diskon langsung divalidasi
3. Harga dan penghematan yang diperbarui ditampilkan dengan jelas

<Frame>
  <img src="/images/checkout/c4.png" alt="Discount code entry on checkout" style={{ maxHeight: '500px', width: '70%' }}/>
</Frame>

### Integrasi API

Terapkan satu atau beberapa kode diskon bertumpuk sebelumnya atau aktifkan kolom input diskon:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  discount_codes: ['WELCOME20'], // Pre-apply one or more codes (max 20, applied in order)
  feature_flags: {
    allow_discount_code: true // Show discount input field
  },
  return_url: 'https://yoursite.com/return'
});
```

<Info>
`discount_codes` menerima array hingga 20 kode yang ditumpuk sesuai urutan. Field tunggal `discount_code` sudah deprecated tetapi masih berfungsi — integrasi yang ada tidak perlu segera diubah. Migrasikan ke `discount_codes` jika memungkinkan untuk menggunakan stacking dan bentuk respons yang lebih lengkap.
</Info>

## Pengumpulan Alamat Cerdas

Checkout mendukung pengisian alamat yang fleksibel untuk mempercepat penyelesaian.

### Opsi yang Tersedia

| Opsi | Deskripsi |
|--------|-------------|
| **Google Address Autofill** | Pemilihan cepat dengan pelengkapan otomatis |
| **Entri Manual** | Kontrol penuh untuk alamat lengkap |
| **Pemilihan Negara** | Menentukan logika pajak dan kepatuhan |
| **Alamat Minimal** | Hanya mengumpulkan negara (dan ZIP jika diperlukan untuk pajak) — lihat [Mode Alamat Minimal](#minimal-address-mode) |

<Tip>
Pengumpulan alamat menyeimbangkan kecepatan, akurasi, dan cakupan global untuk memaksimalkan konversi sekaligus memastikan kepatuhan.
</Tip>

### Mode Alamat Minimal

Untuk memaksimalkan konversi, aktifkan pengumpulan alamat minimal guna mengurangi hambatan di checkout. Ketika `minimal_address` ditetapkan ke `true`, checkout hanya mengumpulkan:

- **Negara** — selalu diperlukan untuk menentukan pajak
- **Kode ZIP/Pos** — hanya di wilayah yang memerlukannya untuk penghitungan pajak penjualan, VAT, atau GST

Semua field alamat lainnya (jalan, kota, provinsi) dilewati, sehingga penyelesaian checkout menjadi jauh lebih cepat.

<Frame>
  <img src="/images/changelog/minimal-address.png" alt="Minimal address mode showing only country and ZIP/postal code fields on checkout" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  minimal_address: true,
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Pengumpulan alamat lengkap tetap menjadi default. Aktifkan `minimal_address` untuk produk digital dan alur SaaS yang tidak memerlukan detail penagihan lengkap.
</Info>

<Card title="Minimal Address Reference" icon="address-card" href="/developer-resources/checkout-session#request-body">
  Lihat referensi parameter lengkap `minimal_address` di panduan Checkout Sessions API.
</Card>

## Pengumpulan Nomor Telepon

Kontrol apakah field nomor telepon muncul di checkout — dan apakah field tersebut wajib diisi — menggunakan feature flags checkout session.

| Flag | Default | Perilaku |
|------|---------|----------|
| `allow_phone_number_collection` | `true` | Menampilkan field nomor telepon di formulir checkout |
| `require_phone_number` | `false` | Menjadikan field nomor telepon wajib diisi (validasi formulir memastikan nilainya tidak kosong) |

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_abc', quantity: 1 }],
  feature_flags: {
    allow_phone_number_collection: true,
    require_phone_number: true
  },
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
`require_phone_number: true` memerlukan `allow_phone_number_collection: true`. API menolak session ketika pengumpulan nomor telepon dinonaktifkan, tetapi nomor telepon diwajibkan.
</Warning>

<Tip>
Gunakan `require_phone_number` untuk B2B SaaS, industri yang diatur, atau alur apa pun yang memerlukan saluran kontak terverifikasi untuk dukungan, peninjauan fraud, atau kepatuhan.
</Tip>

## Field Kustom

Kumpulkan informasi tambahan dari pelanggan selama checkout dengan menentukan field formulir kustom. Ini berguna untuk mengumpulkan data seperti nama perusahaan, ukuran tim, sumber referral, atau informasi spesifik bisnis lainnya.

### Jenis Field yang Tersedia

| Jenis | Deskripsi |
|------|-------------|
| `text` | Input teks satu baris |
| `number` | Input numerik |
| `email` | Alamat email dengan validasi |
| `url` | URL dengan validasi |
| `date` | Pemilih tanggal |
| `dropdown` | Pilih dari opsi yang telah ditentukan |
| `boolean` | Toggle Ya/Tidak |

### Contoh

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Respons pelanggan otomatis disertakan dalam payload webhook (`payment.succeeded`, `subscription.active`) dan respons API melalui array `custom_field_responses`. Anda dapat menentukan hingga 5 field kustom per checkout session.
</Info>

## Checkout Koleksi

Product Collections menyediakan pengalaman checkout terpadu yang memungkinkan pelanggan melihat dan memilih dari beberapa produk terkait (misalnya paket Starter, Pro, dan Enterprise) dalam satu checkout.

### Cara Kerjanya

1. **Semua produk ditampilkan**: Pelanggan melihat setiap produk aktif dalam koleksi
2. **Produk pertama dipilih sebelumnya**: Produk pertama dalam koleksi otomatis dipilih
3. **Bandingkan opsi**: Pelanggan dapat membandingkan harga dan fitur sebelum memilih
4. **Satu pilihan**: Setelah memilih produk, checkout dilanjutkan dengan alur pembayaran standar

### Membuat Checkout Koleksi

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
Saat menggunakan `product_collection_id`, berikan array `product_cart` yang kosong. Kode diskon tidak dapat diterapkan sebelumnya saat pembuatan session.
</Warning>

## Konfigurasi Checkout Session

Kontrol perilaku checkout menggunakan Checkout Sessions API:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_codes: ['PROMO10'],
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  cancel_url: 'https://yoursite.com/pricing', // Optional: where to redirect on cancel
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
Setelah pembayaran, pelanggan diarahkan ke `return_url` Anda dengan query parameters yang ditambahkan secara otomatis -- termasuk `payment_id` atau `subscription_id`, `status`, `email`, dan `license_key` (jika berlaku). Lihat [panduan Checkout Sessions](/developer-resources/checkout-session#request-body) untuk daftar lengkapnya.
</Info>

Kustomisasikan tampilan halaman checkout agar sesuai dengan brand Anda menggunakan parameter `customization.theme_config` saat membuat checkout session melalui API. Konfigurasikan warna, font, radius border, dan teks tombol untuk mode terang maupun gelap.

<Frame>
  <img src="/images/checkout/theme-example.png" alt="Custom themed checkout page" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Card title="Design & Theme Customization" icon="palette" href="/features/design">
  Konfigurasikan tema secara visual dari dashboard dengan tema siap pakai, tipografi, warna, dan pratinjau langsung.
</Card>

<Info>
Bagian ini membahas konfigurasi tema **server-side API** menggunakan `customization.theme_config`. Jika Anda menggunakan **Checkout SDK** (overlay atau inline checkout), lihat bagian kustomisasi tema di [Overlay Checkout](/developer-resources/overlay-checkout#theme-customization) yang menggunakan properti camelCase (misalnya `bgPrimary`, bukan `bg_primary`).
</Info>

### Opsi Konfigurasi Tema

| Properti | Deskripsi |
|----------|-------------|
| `light` | Konfigurasi warna untuk mode terang |
| `dark` | Konfigurasi warna untuk mode gelap |
| `font_primary_url` | URL untuk font utama |
| `font_secondary_url` | URL untuk font sekunder |
| `font_size` | Ukuran font: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `font_weight` | Ketebalan font: `normal`, `medium`, `bold`, `extraBold` |
| `radius` | Radius border untuk elemen UI (misalnya `4px`, `0.5rem`, `8px`) |
| `pay_button_text` | Teks kustom untuk tombol pembayaran (misalnya "Complete Purchase", "Subscribe Now") |

### Konfigurasi Warna (Mode Terang/Gelap)

Setiap mode (`light` dan `dark`) mendukung properti warna berikut:

| Properti | Deskripsi |
|----------|-------------|
| `bg_primary` | Warna utama latar belakang |
| `bg_secondary` | Warna sekunder latar belakang |
| `text_primary` | Warna utama teks |
| `text_secondary` | Warna sekunder teks |
| `text_placeholder` | Warna placeholder teks |
| `text_error` | Warna teks error |
| `text_success` | Warna teks sukses |
| `border_primary` | Warna utama border |
| `border_secondary` | Warna sekunder border |
| `button_primary` | Warna latar belakang tombol utama |
| `button_primary_hover` | Warna hover tombol utama |
| `button_secondary` | Warna latar belakang tombol sekunder |
| `button_secondary_hover` | Warna hover tombol sekunder |
| `button_text_primary` | Warna teks tombol utama |
| `button_text_secondary` | Warna teks tombol sekunder |
| `input_focus_border` | Warna border fokus input |

<Info>
Semua field warna menerima format warna CSS standar:
- Hex: `#fff`, `#ffffff`, `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`, `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`, `hsla(120, 100%, 50%, 0.5)`
- Warna bernama: `red`, `blue`, `transparent`
</Info>

### Contoh

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
Anda tidak perlu menentukan semua properti warna. Properti yang tidak ditentukan akan menggunakan nilai tema default.
</Tip>
