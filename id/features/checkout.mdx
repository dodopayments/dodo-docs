## Mata Uang Adaptif

Mata Uang Adaptif memungkinkan pelanggan untuk membayar dalam mata uang lokal yang mereka pilih, meningkatkan kepercayaan dan tingkat konversi.

### Cara Kerjanya

1. **Aktifkan**: Aktifkan Mata Uang Adaptif dari Pengaturan Bisnis Anda
2. **Pilih**: Pelanggan dapat mengganti mata uang langsung di checkout
3. **Konversi**: Harga dikonversi secara dinamis menggunakan kurs FX waktu nyata
4. **Tampilkan**: Jumlah yang harus dibayar ditampilkan secara transparan sebelum pembayaran

## Perhitungan Pajak Otomatis

Pajak dihitung secara otomatis berdasarkan lokasi penagihan pelanggan, memastikan kepatuhan terhadap persyaratan GST, VAT, dan pajak penjualan tanpa pengaturan manual.

### Cara Perhitungan Pajak Bekerja

<Steps>
<Step title="Deteksi Lokasi">
  Aturan pajak diterapkan berdasarkan negara pelanggan (dan wilayah jika berlaku).
</Step>

<Step title="Pembaruan Dinamis">
  Jumlah pajak diperbarui secara otomatis ketika:
  - Negara berubah
  - Alamat diperbarui
</Step>

<Step title="Tampilan Transparan">
  Perincian pajak akhir ditampilkan dengan jelas sebelum pembayaran.
</Step>
</Steps>

<Tip>
Perhitungan pajak sepenuhnya otomatis. Tidak ada konfigurasi manual yang diperlukan untuk barang digital standar dan produk SaaS.
</Tip>

## Dukungan ID Pajak Bisnis

Untuk bisnis yang terdaftar, checkout memungkinkan pelanggan memasukkan ID Pajak Bisnis mereka (misalnya, nomor VAT/GST).

### Apa yang Terjadi Ketika ID Pajak Dimasukkan

- Kelayakan pajak divalidasi secara real-time
- Pengecualian pajak atau aturan reverse-charge yang berlaku diterapkan
- Jumlah pajak diperbarui secara instan di checkout

</Frame>

<Info>
Ini sangat berguna untuk SaaS B2B dan layanan digital di mana pelanggan bisnis mungkin memenuhi syarat untuk pengecualian pajak.
</Info>

## Kode Diskon

Pelanggan dapat menerapkan kode diskon atau promosi yang telah Anda buat di dasbor langsung di halaman checkout.

### Pengalaman Checkout

1. Pelanggan memasukkan kode diskon
2. Diskon divalidasi secara instan
3. Harga yang diperbarui dan penghematan ditampilkan dengan jelas

<Frame>
  <img src="/images/checkout/c4.png" alt="Pemasukan kode diskon di checkout" style={{ width: '70%' }}/>

### Integrasi API

Prabisa kode diskon atau aktifkan kolom input diskon:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  discount_code: 'WELCOME20', // Pre-apply a code
  feature_flags: {
    allow_discount_code: true // Show discount input field
  },
  return_url: 'https://yoursite.com/return'
});
```

## Bidang Kustom

Kumpulkan informasi tambahan dari pelanggan selama checkout dengan mendefinisikan kolom formulir kustom. Ini berguna untuk mengumpulkan data seperti nama perusahaan, ukuran tim, sumber referral, atau informasi spesifik bisnis lainnya.

### Jenis Kolom yang Tersedia

| Tipe | Deskripsi |
|------|-------------|
| `text` | Input teks satu baris |
| `number` | Input numerik |
| `email` | Alamat email dengan validasi |
| `url` | URL dengan validasi |
| `date` | Pemilih tanggal |
| `dropdown` | Pilih dari opsi yang telah ditentukan |
| `boolean` | Toggel Ya/Tidak |

### Contoh

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Respon pelanggan secara otomatis disertakan dalam payload webhook (`payment.succeeded`, `subscription.created`) dan respon API melalui array `custom_field_responses`. Anda dapat mendefinisikan hingga 5 bidang kustom per sesi checkout.
</Info>

## Checkout Koleksi

Koleksi Produk memungkinkan pengalaman checkout terpadu di mana pelanggan dapat melihat dan memilih dari beberapa produk terkait (misalnya, rencana Starter, Pro, Enterprise) dalam satu checkout.

### Cara Kerjanya

1. **Semua produk ditampilkan**: Pelanggan melihat setiap produk aktif dalam koleksi
2. **Produk pertama dipilih secara otomatis**: Produk pertama dalam koleksi dipilih secara otomatis
3. **Bandingkan opsi**: Pelanggan dapat membandingkan harga dan fitur sebelum memilih
4. **Seleksi tunggal**: Setelah memilih produk, checkout dilanjutkan dengan alur pembayaran standar

### Membuat Checkout Koleksi

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
Saat menggunakan `product_collection_id`, kirim array `product_cart` yang kosong. Kode diskon tidak dapat diterapkan sebelumnya saat pembuatan sesi.
</Warning>

## Konfigurasi Sesi Checkout

Kontrol perilaku checkout menggunakan API Sesi Checkout:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_code: 'PROMO10',
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
Setelah pembayaran, pelanggan akan dialihkan ke `return_url` dengan parameter query yang ditambahkan secara otomatis -- termasuk `payment_id` atau `subscription_id`, `status`, `email`, dan `license_key` (jika berlaku). Lihat [panduan Sesi Checkout](/developer-resources/checkout-session#request-body) untuk daftar lengkap.
</Info>

## Kustomisasi Tema Checkout

Sesuaikan tampilan halaman checkout agar sesuai dengan merek Anda menggunakan parameter `customization.theme_config` saat membuat sesi checkout melalui API. Atur warna, font, radius batas, dan teks tombol untuk mode terang dan gelap.

<Frame>
  <img src="/images/checkout/theme-example.png" alt="Halaman checkout bertema kustom"/>
</Frame>

<Info>
Bagian ini mencakup konfigurasi tema **API sisi server** menggunakan `customization.theme_config`. Jika Anda menggunakan **Checkout SDK** (checkout overlay atau inline), lihat bagian kustomisasi tema di [Checkout Overlay](/developer-resources/overlay-checkout#theme-customization) atau [Checkout Inline](/developer-resources/inline-checkout#theme-customization) yang menggunakan properti camelCase (misalnya, `bgPrimary` bukannya `bg_primary`).
</Info>

### Opsi Konfigurasi Tema

| Properti | Deskripsi |
|----------|-------------|
| `light` | Konfigurasi warna untuk mode terang |
| `dark` | Konfigurasi warna untuk mode gelap |
| `font_primary_url` | URL untuk font utama |
| `font_secondary_url` | URL untuk font sekunder |
| `font_size` | Ukuran font: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `font_weight` | Berat font: `normal`, `medium`, `bold`, `extraBold` |
| `radius` | Radius batas untuk elemen UI (misalnya, `4px`, `0.5rem`, `8px`) |
| `pay_button_text` | Teks kustom untuk tombol bayar (misalnya, "Selesaikan Pembelian", "Langganan Sekarang") |

### Konfigurasi Warna (Mode Terang/Gelap)

Setiap mode (`light` dan `dark`) mendukung properti warna berikut:

| Properti | Deskripsi |
|----------|-------------|
| `bg_primary` | Warna latar belakang utama |
| `bg_secondary` | Warna latar belakang sekunder |
| `text_primary` | Warna teks utama |
| `text_secondary` | Warna teks sekunder |
| `text_placeholder` | Warna placeholder teks |
| `text_error` | Warna kesalahan teks |
| `text_success` | Warna sukses teks |
| `border_primary` | Warna batas utama |
| `border_secondary` | Warna batas sekunder |
| `button_primary` | Warna latar belakang tombol utama |
| `button_primary_hover` | Warna tombol utama saat hover |
| `button_secondary` | Warna latar belakang tombol sekunder |
| `button_secondary_hover` | Warna tombol sekunder saat hover |
| `button_text_primary` | Warna teks tombol utama |
| `button_text_secondary` | Warna teks tombol sekunder |
| `input_focus_border` | Warna batas fokus input |

<Info>
Semua kolom warna menerima format warna CSS standar:
- Hex: `#fff`, `#ffffff`, `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`, `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`, `hsla(120, 100%, 50%, 0.5)`
- Warna bernama: `red`, `blue`, `transparent`
</Info>

### Contoh

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
Anda tidak perlu menentukan semua properti warna. Setiap properti yang tidak ditentukan akan menggunakan nilai tema default.
</Tip>
