## Manajemen Kunci API dan Otentikasi

<Steps>
<Step title="Akses Kunci API">
Navigasikan ke **Pengembang → Kunci API** di dasbor Anda untuk mengelola kunci Anda.
</Step>

<Step title="Hasilkan Kunci Baru">
Pilih **Tambahkan Kunci API**, berikan nama deskriptif, dan konfigurasikan akses tulis:

- **Aktifkan akses tulis** (dicentang): Izin baca dan tulis penuh untuk semua operasi API
- **Aktifkan akses tulis** (tidak dicentang): Akses hanya baca - hanya dapat mengambil data (pembayaran, langganan, pelanggan, produk). Tidak dapat membuat atau memodifikasi sumber daya.

<Tip>
Hapus centang "Aktifkan akses tulis" untuk integrasi dasbor, alat analitik, dan sistem apa pun yang hanya perlu melihat data tanpa melakukan perubahan.
</Tip>
</Step>

<Step title="Simpan Kunci Anda dengan Aman">
Salin kunci yang dihasilkan segera dan pastikan disimpan dengan aman.
</Step>

<Step title="Otentikasi Permintaan API Anda">
Gunakan kunci API Anda untuk mengotentikasi semua permintaan. Terapkan format otorisasi berikut:

```bash 
Authorization: Bearer YOUR_API_KEY
```

<Warning>
Jangan pernah mengekspos kunci API rahasia Anda dalam kode sisi klien atau repositori publik.
</Warning>
</Step>
</Steps>

## Batasan Laju

API kami menggunakan sistem pembatasan laju dengan dua jendela yang dilengkapi perlindungan lonjakan. Batasan diterapkan berdasarkan metode autentikasi dan tingkat bisnis Anda.

### Batas Default (Tingkat 0)

| Jendela | Batas |
|--------|-------|
| Per Detik (Lonjakan) | 40 permintaan |
| Per Menit (Sustained) | 240 permintaan |

### Tingkat Bisnis

Batas laju yang lebih tinggi tersedia untuk bisnis dengan kebutuhan API yang meningkat:

| Tingkat | Lonjakan (per detik) | Sustained (per menit) |
|------|-------------------|------------------------|
| Tingkat 0 (Default) | 40 | 240 |
| Tingkat 1 | 100 | 1,000 |
| Tingkat 2 | 500 | 5,000 |

<Tip>
Hubungi dukungan untuk meningkatkan bisnis Anda ke tingkat batas laju yang lebih tinggi.
</Tip>

### Permintaan Tanpa Autentikasi

Permintaan tanpa header autentikasi yang valid dibatasi berdasarkan alamat IP:

| Jendela | Batas |
|--------|-------|
| Per Detik (Lonjakan) | 20 permintaan |
| Per Menit (Terus-Menerus) | 100 permintaan |

### Header Pembatasan Laju

Pantau penggunaan Anda dengan header respons ini:

- `X-RateLimit-Limit` - Permintaan maksimum yang diizinkan
- `X-RateLimit-Remaining` - Permintaan yang tersisa di jendela saat ini
- `X-RateLimit-Reset` - Waktu ketika pembatasan laju direset

<Note>
Ketika Anda melampaui batas laju, API mengembalikan respons `429 Too Many Requests`. Terapkan exponential backoff dalam logika coba ulang Anda.
</Note>
