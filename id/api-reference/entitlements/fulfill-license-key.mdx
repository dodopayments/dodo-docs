<Info>
Gunakan endpoint ini hanya untuk hibah yang dibuat di bawah hak Kunci Lisensi dengan `fulfillment_mode: manual`. Hibah harus dalam status `pending` tanpa kunci terlampir. Lihat [Pemenuhan Manual](/features/license-keys#manual-fulfillment) dan [Panduan Integrasi Pemenuhan Kunci Lisensi Manual](/developer-resources/manual-license-key-fulfillment) untuk alur lengkap.
</Info>
