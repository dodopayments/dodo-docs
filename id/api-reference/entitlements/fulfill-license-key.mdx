<Info>
Gunakan endpoint ini hanya untuk grant yang dibuat berdasarkan entitlement License Key dengan `fulfillment_mode: manual`. Grant harus berada dalam status `Pending` tanpa key yang terpasang. Lihat [Pemenuhan Manual](/features/license-keys#manual-fulfillment) dan [Panduan Integrasi Pemenuhan License Key Manual](/developer-resources/manual-license-key-fulfillment) untuk alur lengkapnya.
</Info>
