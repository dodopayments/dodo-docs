<Info>
Endpoint ini mengimpor kunci yang sudah Anda miliki — `key`, `customer_id`, dan `product_id` semuanya wajib diisi. Endpoint ini tidak membuat nilai kunci untuk Anda. Mengimpor `key` yang sudah ada akan mengembalikan `409 Conflict`.
</Info>

<Info>
Kunci lisensi yang dibuat atau diperbarui melalui API tidak memicu notifikasi email kepada customer. Jika Anda perlu memberi tahu customer tentang kunci lisensi mereka, Anda harus menanganinya secara terpisah di aplikasi Anda.
</Info>
