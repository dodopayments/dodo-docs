<Warning>
**API Usang**: Kunci lisensi sekarang dikelola melalui sistem [Entitlements](/features/entitlements/introduction). Konfigurasikan batas dan durasi aktivasi pada [entitlement Kunci Lisensi](/api-reference/entitlements/update-entitlement), dan gunakan [Revoke Grant](/api-reference/entitlements/revoke-grant) untuk menonaktifkan kunci pelanggan. Endpoint ini akan dihapus dalam rilis mendatang.
</Warning>
