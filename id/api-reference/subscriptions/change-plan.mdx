## Penanganan Kegagalan Pembayaran

Gunakan parameter `on_payment_failure` untuk mengendalikan apa yang terjadi ketika pembayaran perubahan paket gagal:

| Value | Behavior |
|-------|----------|
| `prevent_change` | Pertahankan langganan pada paket saat ini hingga pembayaran berhasil. Perubahan paket tetap tertunda. |
| `apply_change` | Terapkan perubahan paket segera terlepas dari hasil pembayaran. Ini adalah bawaan. |

<Info>
Jika `on_payment_failure` tidak ditentukan, perilaku default mengikuti pengaturan tingkat bisnis Anda yang dikonfigurasi di dashboard.
</Info>

## Kode Diskon

Anda dapat menerapkan kode diskon saat mengubah paket dengan melewatkan parameter `discount_code`.

| Skenario | Perilaku |
|----------|----------|
| `discount_code` diberikan | Memvalidasi dan menerapkan diskon ke paket baru. |
| `discount_code` tidak diberikan, diskon yang ada dengan `preserve_on_plan_change=true` | Diskon yang ada dipertahankan jika berlaku untuk produk baru. |
| `discount_code` tidak diberikan, tidak ada diskon yang dapat dipertahankan | Tidak ada diskon yang diterapkan. |

<Tip>
Gunakan kode diskon selama perubahan paket untuk menawarkan harga promosi pada upgrade, atau serahkan kode saat memigrasikan pelanggan ke tingkat paket baru.
</Tip>

<Tip>
Gunakan `prevent_change` untuk upgrade kritis di mana Anda ingin memastikan pembayaran sebelum memberikan akses ke fitur premium.
</Tip>
