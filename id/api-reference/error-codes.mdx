## Ikhtisar

Dodo Payments API menggunakan kode status HTTP standar dan kode kesalahan kustom untuk menunjukkan keberhasilan atau kegagalan permintaan API. Ketika terjadi kesalahan, API mengembalikan kode status HTTP yang sesuai dan respons JSON yang berisi informasi rinci tentang kesalahan tersebut.

Setiap respons kesalahan mencakup:
- Kode status HTTP yang menunjukkan kategori umum dari kesalahan
- Kode kesalahan spesifik yang mengidentifikasi sifat tepat dari kesalahan
- Pesan kesalahan yang dapat dibaca manusia yang menjelaskan apa yang salah
- Rincian tambahan tentang kesalahan jika berlaku

Memahami kode kesalahan ini dan artinya sangat penting untuk:
- Memecahkan masalah integrasi
- Menerapkan penanganan kesalahan yang tepat dalam aplikasi Anda
- Memberikan umpan balik yang berarti kepada pengguna akhir
- Mempertahankan sistem pemrosesan pembayaran yang kuat

Bagian berikut memberikan informasi rinci tentang kode status HTTP standar dan kode kesalahan spesifik yang mungkin Anda temui saat menggunakan Dodo Payments API.

## Kode Kesalahan API Standar

| Kode kesalahan | Status HTTP | Deskripsi |
|----------------|-------------|-------------|
| **400** | Permintaan Buruk | Permintaan tidak terformat dengan baik atau mengandung parameter yang tidak valid |
| **401** | Tidak Terautentikasi | Autentikasi gagal atau kunci API tidak valid |
| **403** | Dilarang | Kunci API tidak memiliki izin untuk mengakses sumber daya yang diminta |
| **404** | Tidak Ditemukan | Sumber daya yang diminta tidak ada |
| **405** | Metode Tidak Diizinkan | Metode HTTP tidak didukung untuk endpoint ini |
| **409** | Konflik | Permintaan bertentangan dengan keadaan saat ini dari sumber daya |
| **422** | Entitas Tidak Dapat Diproses | Permintaan terformat dengan baik tetapi mengandung kesalahan semantik |
| **429** | Terlalu Banyak Permintaan | Batas laju terlampaui |
| **500** | Kesalahan Server Internal | Terjadi kesalahan yang tidak terduga di server kami |
| **502** | Gerbang Buruk | Server menerima respons tidak valid dari server hulu |
| **503** | Layanan Tidak Tersedia | Layanan tidak tersedia sementara |
| **504** | Waktu Habis Gerbang | Server kehabisan waktu saat menunggu respons dari server hulu |

## Format Respons Kesalahan

Ketika terjadi kesalahan, API mengembalikan respons JSON dengan struktur berikut:

```json
{
  "code": "UNSUPPORTED_COUNTRY",
  "message": "Country AI currently not supported"
}
```

## Referensi Kode Kesalahan

- `ACTIVATION_LIMIT_LESS_THAN_CURRENT_AMOUNT`
  - **Trigger:** Aktivasi kunci lisensi: batas baru < jumlah instansi yang ada
  - **Message:** Batas aktivasi baru tidak boleh kurang dari jumlah instansi saat ini

- `ADDONS_IN_USAGE_BASED_BILLING_NOT_SUPPORTED`
  - **Trigger:** Upaya untuk menambahkan addon ke langganan berbasis penggunaan
  - **Message:** Addon dalam Langganan tidak didukung untuk Penagihan Berdasarkan Penggunaan

- `ADDONS_NOT_ALLOWED_FOR_ON_DEMAND`
  - **Trigger:** Upaya untuk menambahkan addon ke langganan sesuai permintaan
  - **Message:** Addon tidak diizinkan untuk langganan sesuai permintaan

- `BRAND_MISMATCH`
  - **Trigger:** Item keranjang berasal dari merek yang berbeda
  - **Message:** Semua item dalam keranjang produk harus berasal dari merek yang sama

- `BRAND_NOT_ENABLED`
  - **Trigger:** Merek dinonaktifkan atau tidak aktif
  - **Message:** Merek yang diberikan tidak diaktifkan

- `BRAND_SUBMISSION_NOT_ENABLED`
  - **Trigger:** Fitur pengiriman ulang verifikasi merek tidak diaktifkan
  - **Message:** Pengiriman ulang verifikasi merek tidak diaktifkan

- `CHARGE_NOT_ALLOWED_FOR_SCHEDULED_CANCELLATION`
  - **Trigger:** Upaya untuk mengenakan biaya pada langganan yang dijadwalkan untuk dibatalkan
  - **Message:** Langganan dijadwalkan untuk dibatalkan

- `CHECKOUT_SESSION_CONSUMED`
  - **Trigger:** Sesi checkout telah menghasilkan pembayaran
  - **Message:** Sesi checkout telah digunakan

- `DISCOUNT_CODE_ALREADY_EXISTS`
  - **Trigger:** Pembuatan kode diskon duplikat
  - **Message:** Kode Diskon sudah ada

- `DISCOUNT_CODE_EXPIRED`
  - **Trigger:** Kode diskon melewati tanggal `expires_at`
  - **Message:** Kode diskon sudah kedaluwarsa

- `DISCOUNT_CODE_USAGE_LIMIT_EXCEEDED`
  - **Trigger:** Diskon digunakan kembali setelah `usage_limit` tercapai
  - **Message:** Batas penggunaan tidak boleh kurang dari times_used / Kode diskon mencapai batas penggunaan

- `DISCOUNT_NOT_AVAILABLE_FOR_ON_DEMAND`
  - **Trigger:** Kode diterapkan pada langganan sesuai permintaan
  - **Message:** Kupon diskon tidak tersedia untuk langganan sesuai permintaan

- `DISCOUNT_NOT_AVAILABLE_FOR_PRODUCT`
  - **Trigger:** Kode diterapkan pada produk yang tidak terkait
  - **Message:** Kupon diskon tidak tersedia untuk produk ini

- `DUPLICATE_LINE_ITEMS_IN_REQUEST`
  - **Trigger:** Item yang sama `item_id` muncul dua kali di `items[]`
  - **Message:** ID item duplikat ditentukan dalam array item

- `DUPLICATE_METER_IDS_IN_REQUEST`
  - **Trigger:** ID meter yang sama muncul beberapa kali dalam permintaan
  - **Message:** ID Meter duplikat tidak diperbolehkan

- `EXCHANGE_RATE_NOT_FOUND`
  - **Trigger:** Tidak ada tarif FX untuk pasangan mata uang `from → to`
  - **Message:** Kurs pertukaran tidak ditemukan untuk mengonversi dari Mata Uang ke Mata Uang

- `EXISTING_REFUND_REQUEST_PROCESSING`
  - **Trigger:** Permintaan pengembalian dana sebelumnya masih diproses
  - **Message:** Permintaan pengembalian dana dengan status "Pending" masih diproses

- `INACTIVE_LICENSE_KEY`
  - **Trigger:** Status kunci ≠ `ACTIVE`
  - **Message:** Kunci lisensi tidak aktif

- `INACTIVE_SUBSCRIPTION_PLAN_CHANGE_NOT_SUPPORTED`
  - **Trigger:** Perubahan rencana pada langganan tidak aktif
  - **Message:** Mengubah rencana tidak didukung untuk langganan yang tidak aktif

- `INSUFFICIENT_WALLET_FUNDS`
  - **Trigger:** Saldo dompet < jumlah debit
  - **Message:** Dana tidak cukup di dompet

- `INTEGER_CONVERSION_FAILURE`
  - **Trigger:** Konversi bilangan bulat ↔ string/decimal yang gagal di sisi server
  - **Message:** Kegagalan Konversi Bilangan Bulat

- `INTERNAL_SERVER_ERROR`
  - **Trigger:** Eksepsi yang tidak tertangkap; Anda harus mencatat rincian di sisi server
  - **Message:** *Tidak ada pesan publik (500 generik)*

- `INVALID_DISCOUNT_CODE`
  - **Trigger:** Kode tidak ada / tidak berlaku
  - **Message:** Kode Diskon Tidak Valid / Kode Diskon tidak dapat diterapkan pada produk apa pun di keranjang

- `INVALID_PERCENTAGE`
  - **Trigger:** Jumlah persen > 100% (atau 10.000 basis poin)
  - **Message:** Jumlah persentase tidak boleh lebih dari 10000 / Jumlah kode diskon tidak boleh lebih dari 100%

- `INVALID_QUANTITY`
  - **Trigger:** Jumlah yang tidak valid ditentukan untuk penetapan harga berbasis penggunaan
  - **Message:** Hanya 1 jumlah yang diperbolehkan dalam produk dengan harga berbasis penggunaan

- `INVALID_QUERY_PARAMS`
  - **Trigger:** Parameter kueri saling eksklusif / rusak
  - **Message:** Parameter kueri harus hanya mengandung waktu_frame atau (mulai, akhir)

- `INVALID_REQUEST_BODY`
  - **Trigger:** JSON rusak atau pelanggaran skema
  - **Message:** Isi permintaan Anda tidak valid. Silakan periksa header dan objek permintaan Anda.

- `INVALID_REQUEST_PARAMETERS`
  - **Trigger:** Semantik salah (misalnya tanggal di masa lalu)
  - **Message:** Tidak dapat mengubah next_billing_date ke waktu di masa lalu

- `INVALID_SUGGESTED_PRICE`
  - **Trigger:** Harga PWYW < harga minimum yang diizinkan
  - **Message:** Harga yang disarankan tidak boleh lebih rendah dari harga minimum. Dalam kasus bayar sekehendak Anda, harga dianggap sebagai jumlah minimum yang diterima

- `INVALID_TAX_ID`
  - **Trigger:** VAT/GST/TIN gagal validasi
  - **Message:** Identitas Pajak tidak valid

- `LICENSE_KEY_LIMIT_REACHED`
  - **Trigger:** Aktivasi = batas
  - **Message:** Batas aktivasi kunci lisensi tercapai

- `LICENSE_KEY_NOT_FOUND`
  - **Trigger:** ID instansi atau ID kunci tidak valid
  - **Message:** Instansi kunci lisensi tidak ditemukan atau tidak milik kunci lisensi ini

- `LINE_ITEM_FULLY_REFUNDED`
  - **Trigger:** Upaya untuk mengembalikan item yang sudah diajukan pengembalian secara penuh
  - **Message:** Item garis {id} telah diajukan pengembalian secara penuh dan tidak dapat diajukan pengembalian lebih lanjut.

- `LINE_ITEM_NOT_FOUND`
  - **Trigger:** ID item tidak menjadi bagian dari pembayaran yang dirujuk
  - **Message:** Item garis {id} tidak ditemukan dalam pembayaran

- `LINE_ITEM_PRORATED`
  - **Trigger:** Pengembalian dana atau pembaruan dicoba pada item garis prorata
  - **Message:** Item garis {id} tidak dapat diajukan pengembalian karena prorata

- `LINE_ITEM_REFUND_AMOUNT_TOO_HIGH`
  - **Trigger:** Jumlah pengembalian > jumlah yang dibayarkan (termasuk pajak)
  - **Message:** Jumlah pengembalian yang diminta item garis {id} termasuk pajak adalah {amount} yang di atas jumlah yang dibayarkan {amount}

- `LINE_ITEM_REFUND_AMOUNT_TOO_LOW`
  - **Trigger:** Jumlah pengembalian di bawah ambang batas minimum
  - **Message:** Jumlah pengembalian yang diminta item garis {id} adalah {amount} yang terlalu rendah

- `MAXIMUM_KEYS_REACHED`
  - **Trigger:** Metadata / bidang kustom melebihi 50 pasangan
  - **Message:** Melebihi 50 pasangan kunci-nilai

- `MERCHANT_NOT_LIVE`
  - **Trigger:** Bisnis masih dalam mode uji/sandbox
  - **Message:** Pedagang tidak aktif

- `METER_IS_DELETED`
  - **Trigger:** Upaya untuk menggunakan meter yang dihapus
  - **Message:** Meter telah dihapus

- `MISSING_ADDON_IDS`
  - **Trigger:** `addon_id` daftar kosong atau ID tidak dikenal
  - **Message:** Satu atau lebih ID produk tidak ada: {id}

- `MISSING_METER_IDS`
  - **Trigger:** Daftar ID meter kosong atau mengandung ID tidak valid
  - **Message:** Satu atau lebih ID Meter tidak ada: {id}

- `MISSING_PRODUCT_INFORMATION`
  - **Trigger:** Produk ada tetapi informasi wajib hilang
  - **Message:** Produk {id} ada tetapi informasi wajib lain hilang atau tidak valid

- `NEGATIVE_BALANCE_ADJUSTMENT`
  - **Trigger:** Upaya untuk membuat saldo dompet negatif
  - **Message:** Saldo dompet tidak boleh dibuat negatif

- `NO_ELIGIBLE_PAYMENT_METHODS`
  - **Trigger:** Setelah disaring, tidak ada yang tersisa
  - **Message:** Tidak ada metode pembayaran yang memenuhi syarat ditemukan

- `NO_EXPIRY_ON_SUBSCRIPTION_LICENSE_KEYS`
  - **Trigger:** Upaya untuk mengatur kadaluarsa pada kunci berbasis langganan
  - **Message:** Tidak dapat mengatur tanggal kadaluarsa untuk kunci lisensi berbasis langganan

- `NOT_FOUND`
  - **Trigger:** 404 generik untuk setiap sumber daya yang hilang
  - **Message:** Item tidak ditemukan *(atau lebih spesifik)*

- `ON_DEMAND_PLAN_CHANGE_NOT_SUPPORTED`
  - **Trigger:** Pertukaran rencana tidak diizinkan untuk sesuai permintaan
  - **Message:** Mengubah rencana tidak didukung untuk langganan sesuai permintaan

- `ON_DEMAND_SUBSCRIPTIONS_NOT_ENABLED`
  - **Trigger:** Bisnis memiliki fitur flag mati
  - **Message:** Langganan berdasarkan permintaan tidak diaktifkan untuk bisnis ini

- `ON_DEMAND_USAGE_BASED_BILLING_NOT_SUPPORTED`
  - **Trigger:** Upaya untuk menggunakan sesuai permintaan dengan penagihan berbasis penggunaan
  - **Message:** Langganan Sesuai Permintaan tidak didukung untuk Penagihan Berdasarkan Penggunaan

- `PAY_AS_YOU_WANT_AMOUNT_REQUIRED`
  - **Trigger:** Harga hilang untuk produk PWYW
  - **Message:** Jumlah wajib untuk produk bayar sekehendak Anda

- `PAYMENT_ALREADY_REFUNDED`
  - **Trigger:** Pengembalian duplikat
  - **Message:** Pembayaran ini telah diajukan pengembalian

- `PAYMENT_HAS_BEEN_REFUNDED`
  - **Trigger:** Pembayaran telah sepenuhnya dikembalikan
  - **Message:** ID Pembayaran telah sepenuhnya dikembalikan.

- `PAYMENT_NOT_SUCCEEDED`
  - **Trigger:** Upaya untuk mengembalikan/proses pembayaran yang tidak berhasil
  - **Message:** Pembayaran yang diberikan tidak berhasil

- `PLAN_CHANGE_NOT_ALLOWED_FOR_SCHEDULED_CANCELLATION`
  - **Trigger:** Perubahan rencana dicoba pada langganan yang dijadwalkan untuk dibatalkan
  - **Message:** Langganan dijadwalkan untuk dibatalkan

- `PREVIOUS_PAYMENT_PENDING`
  - **Trigger:** Upaya untuk membuat biaya saat yang sebelumnya dalam status non-terminal
  - **Message:** Tidak dapat membuat biaya baru karena pembayaran sebelumnya belum berhasil

- `PRODUCT_CART_EMPTY`
  - **Trigger:** Keranjang produk kosong diajukan
  - **Message:** keranjang_produk kosong

- `PRODUCT_IS_DELETED`
  - **Trigger:** Produk dihapus lembut
  - **Message:** *Tidak ada pesan*

- `REFUND_AMOUNT_EXCEEDS_PAID_AMOUNT`
  - **Trigger:** Jumlah total keranjang yang digabungkan > jumlah yang dibayarkan
  - **Message:** Jumlah pengembalian yang dihitung lebih besar dari jumlah yang dibayarkan

- `REFUND_WINDOW_EXPIRED`
  - **Trigger:** Di luar jendela pengembalian yang diizinkan
  - **Message:** Pengembalian tidak dapat diajukan {days} hari setelah pembuatan pembayaran. Hubungi support@dodopayments.com.

- `REQUEST_AMOUNT_BELOW_MINIMUM`
  - **Trigger:** Jumlah < produk minimum
  - **Message:** Jumlah tidak dapat kurang dari jumlah minimum yang ditentukan untuk produk

- `SUBSCRIPTION_EXPIRED`
  - **Trigger:** Penagihan melewati `ends_at`
  - **Message:** Langganan telah kedaluwarsa, tidak dapat membuat biaya baru

- `SUBSCRIPTION_INACTIVE`
  - **Trigger:** Status ≠ `ACTIVE`
  - **Message:** Langganan tidak aktif

- `SUBSCRIPTION_NOT_ON_DEMAND`
  - **Trigger:** Diharapkan sesuai permintaan tetapi mendapat interval tetap
  - **Message:** Langganan ini sudah tidak sesuai permintaan

- `SUBSCRIPTION_PAYMENT_RETRY_LIMIT_EXCEEDED`
  - **Trigger:** Upaya pembayaran langganan melebihi upaya maksimum
  - **Message:** Batas maksimum percobaan 10 kali untuk langganan ini terlampaui

- `TOO_MANY_REQUESTS`
  - **Trigger:** 429 batas tingkat
  - **Message:** *Tidak ada pesan*

- `TOTAL_PAYMENT_AMOUNT_BELOW_MINIMUM_AMOUNT`
  - **Trigger:** Total keranjang yang digabungkan < minimum gateway
  - **Message:** Jumlah minimum {display_str} diperlukan untuk memproses pembayaran

- `UNABLE_TO_EDIT_PRIMARY_BRAND`
  - **Trigger:** Upaya untuk memperbarui merek utama melalui API reguler
  - **Message:** Merek utama tidak dapat diperbarui melalui titik akhir API ini.

- `UNAUTHORIZED`
  - **Trigger:** Tidak ada kunci API atau token / ruang yang tidak valid
  - **Message:** Anda tidak berwenang untuk melakukan tindakan ini

- `UNSUPPORTED_ACTION`
  - **Trigger:** Tindakan tidak didukung untuk tipe sumber daya
  - **Message:** Mengubah rencana untuk langganan berbasis penggunaan tidak didukung

- `UNSUPPORTED_BILLING_CURRENCY`
  - **Trigger:** Langganan dibatasi pada USD
  - **Message:** Mata uang penagihan non-USD tidak didukung untuk langganan

- `UNSUPPORTED_COUNTRY`
  - **Trigger:** Geo belum didukung
  - **Message:** Negara {country_name} saat ini tidak didukung

- `UNSUPPORTED_CURRENCY`
  - **Trigger:** Produk atau mata uang addon tidak valid
  - **Message:** Mata uang saat ini tidak didukung / Hanya produk USD dan INR yang didukung saat ini / Hanya USD dan INR yang didukung untuk harga addon / Hanya bisa meminta USD atau INR untuk billing_currency / Mata uang Tidak Didukung / Mata uang yang tidak terduga untuk langganan kartu India

- `UNSUPPORTED_DISCOUNT_TYPE`
  - **Trigger:** Diskon jumlah tetap, dll., belum hidup
  - **Message:** Hanya kode diskon persentase yang didukung untuk sekarang

- `UNSUPPORTED_PAYMENT_CURRENCY`
  - **Trigger:** Mata uang pembayaran diblokir untuk konektor
  - **Message:** Transaksi INR tidak didukung untuk transaksi ini

- `UNSUPPORTED_TAX_CATEGORY`
  - **Trigger:** Kategori pajak string tidak dalam enum
  - **Message:** Kategori {category} saat ini tidak didukung

- `UNSUCCESSFUL_PAYMENT_ID`
  - **Trigger:** ID pembayaran merujuk pada pembayaran yang tidak berhasil
  - **Message:** ID Pembayaran memiliki status yang tidak berhasil.

- `ZERO_AMOUNT_PAYMENT_REFUND_NOT_ALLOWED`
  - **Trigger:** Upaya untuk mengembalikan pembayaran dengan jumlah nol
  - **Message:** Tidak dapat mengembalikan pembayaran dengan jumlah mata uang nol

## Praktik Terbaik

1. Selalu tangani kesalahan dengan baik dalam aplikasi Anda
2. Terapkan pencatatan kesalahan yang tepat
3. Gunakan pesan kesalahan yang sesuai untuk pengguna akhir
4. Terapkan logika pengulangan untuk kesalahan sementara
5. Hubungi dukungan untuk masalah yang belum terpecahkan
