---
title: Revoke Grant
description: Manually revoke a grant. The customer's platform access is removed (for OAuth/bot integrations) and license keys are disabled. Manual revokes use revocation_reason "manual" and are not auto-regranted on subscription renewal.
keywords: ["Dodo Payments", "API reference", "REST API", "revoke grant"]
openapi: delete /entitlements/{id}/grants/{grant_id}
