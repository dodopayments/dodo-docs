---
title: Fulfill License Key Grant
description: Manually fulfill a pending license-key grant by supplying the key value. Inserts the key, delivers it to the customer by email, and transitions the grant to delivered.
keywords: ["Dodo Payments", "API reference", "REST API", "fulfill license key", "manual fulfillment"]
openapi: post /grants/{grant_id}/license-key
---

<Info>
Use this endpoint only for grants created under a License Key entitlement with `fulfillment_mode: manual`. The grant must be in `pending` status with no key attached. See [Manual Fulfillment](/features/license-keys#manual-fulfillment) and the [Manual License Key Fulfillment Integration Guide](/developer-resources/manual-license-key-fulfillment) for the full flow.
</Info>
