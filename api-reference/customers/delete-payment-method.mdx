title: Delete Payment Method
description: Delete a payment method associated with a customer.
keywords: ["Dodo Payments", "API reference", "REST API", "delete payment method"]
---

Remove a saved payment method from a customer's account. Use this to clean up outdated or unwanted payment methods.

<Warning>
You cannot delete a payment method that is in use by an active subscription. The API returns `409 Conflict` with `Payment method is in use by an active subscription`. Move the subscription to another payment method first using [Update Payment Method](/api-reference/subscriptions/update-payment-method), then delete the old one.
</Warning>

A successful delete returns `204 No Content`.

## Use Cases

- **Customer request**: Remove a payment method the customer no longer wants on file
- **Expired cards**: Clean up payment methods with expired card details
- **Security**: Remove compromised payment methods immediately
