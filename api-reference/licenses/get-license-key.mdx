<Warning>
**Deprecated API**: License keys are now managed through the [Entitlements](/features/entitlements/introduction) system. Use [List Grants](/api-reference/entitlements/list-grants) (filter with `integration_type=license_key`) to retrieve a key's grant and its `license_key` details. This endpoint will be removed in a future release.
</Warning>
