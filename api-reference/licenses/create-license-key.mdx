---
title: Create License Key
description: Import an existing license key from another system. The key string, customer, and product are all required.
keywords: ["Dodo Payments", "API reference", "REST API", "create license key", "import license key"]
openapi: post /license_keys
---

<Info>
This endpoint imports a key you already have — `key`, `customer_id`, and `product_id` are all required. It does not generate a key value for you. Importing a `key` that already exists returns `409 Conflict`.
</Info>

<Info>
License keys created or updated through the API do not trigger email notifications to customers. If you need to notify customers about their license key, you must handle that separately in your application.
</Info>
