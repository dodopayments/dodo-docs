<Warning>
**Deprecated API**: License keys are now managed through the [Entitlements](/features/entitlements/introduction) system. Use [List Customer Grants](/api-reference/entitlements/list-customer-grants) to list issued license keys (filter with `integration_type=license_key`); each grant carries its `license_key` details. This endpoint will be removed in a future release.
</Warning>
