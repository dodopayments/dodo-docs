## Tổng quan

<Info>
Hướng dẫn này giải thích cách tích hợp Dodo Payments vào ứng dụng Nuxt bằng module Nuxt chính thức. Bạn sẽ tìm hiểu cách thiết lập các API route cho checkout, customer portal và webhook, cũng như cách quản lý an toàn các biến môi trường.
</Info>

## Cài đặt

<Steps>
<Step title="Install the Nuxt module">
Chạy lệnh sau trong thư mục gốc của dự án:

```bash
npm install @dodopayments/nuxt
```

</Step>
<Step title="Register the module in nuxt.config.ts">
Thêm <code>@dodopayments/nuxt</code> vào mảng <code>modules</code> và cấu hình module:

```typescript nuxt.config.ts expandable
export default defineNuxtConfig({
  modules: ["@dodopayments/nuxt"],
  devtools: { enabled: true },
  compatibilityDate: "2025-02-25",
  runtimeConfig: {
    private: {
      bearerToken: process.env.NUXT_PRIVATE_BEARER_TOKEN,
      webhookKey: process.env.NUXT_PRIVATE_WEBHOOK_KEY,
      environment: process.env.NUXT_PRIVATE_ENVIRONMENT,
      returnUrl: process.env.NUXT_PRIVATE_RETURNURL
    },
  }
});
```

</Step>
</Steps>

<Warning>
Không bao giờ commit tệp <code>.env</code> hoặc các secret vào hệ thống quản lý phiên bản.
</Warning>

## Checkout Route Handler

<Info>
Dodo Payments hỗ trợ ba loại luồng thanh toán để tích hợp thanh toán vào website của bạn; bộ chuyển đổi này hỗ trợ tất cả các loại luồng thanh toán.
</Info>

- **Payment Links Static:** URL có thể chia sẻ ngay để thu tiền nhanh mà không cần code.
- **Payment Links Dynamic:** Tạo payment link theo cách lập trình với thông tin tùy chỉnh bằng API hoặc SDK.
- **Checkout Sessions:** Tạo trải nghiệm checkout an toàn, có thể tùy chỉnh, với giỏ sản phẩm và thông tin khách hàng được cấu hình sẵn.

## Webhook Route Handler

- **Method:** Chỉ hỗ trợ yêu cầu POST. Các method khác trả về 405.
- **Xác minh chữ ký:** Xác minh chữ ký webhook bằng <code>webhookKey</code>. Trả về 401 nếu xác minh thất bại.
- **Xác thực payload:** Được xác thực bằng Zod. Trả về 400 nếu payload không hợp lệ.
- **Xử lý lỗi:**
  - 401: Chữ ký không hợp lệ
  - 400: Payload không hợp lệ
  - 500: Lỗi nội bộ trong quá trình xác minh
- **Định tuyến sự kiện:** Gọi event handler phù hợp dựa trên loại payload.

export default defineEventHandler((event) => {

    private: { webhookKey },

  const handler = Webhooks({
    webhookKey: webhookKey,

- 401: Invalid signature
- 400: Invalid payload
- 500: Internal error during verification
