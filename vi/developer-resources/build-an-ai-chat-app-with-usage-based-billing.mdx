<Note>
Hướng dẫn này cung cấp một ứng dụng hoàn chỉnh có thể hoạt động ngay, bao gồm cả backend và frontend. Ứng dụng trò chuyện sử dụng Gemini AI của Google và tự động theo dõi mức sử dụng token mà không cần tự đếm thủ công.
</Note>

Khi hoàn thành hướng dẫn này, bạn sẽ có một ứng dụng trò chuyện hoạt động với các khả năng:
- Vận hành các cuộc trò chuyện AI bằng Google Gemini (AI SDK)
- Tự động theo dõi mức sử dụng token (không cần mã thủ công)
- Tính phí khách hàng dựa trên lượng token thực tế đã sử dụng
- Bao gồm giao diện trò chuyện đẹp mắt

## Chúng ta sẽ xây dựng gì

Hãy bắt đầu bằng việc tìm hiểu dịch vụ trò chuyện AI của chúng ta:

- **Dịch vụ**: Trò chuyện được hỗ trợ bởi AI sử dụng Google Gemini (AI SDK)
- **Mô hình tính phí**: Tính phí theo token ($0.01 cho mỗi 1.000 token)
- **Gói miễn phí**: 10.000 token miễn phí cho mỗi khách hàng mỗi tháng
- **Tính năng**: Lịch sử trò chuyện, tự động theo dõi token

<Info>
Trước khi bắt đầu, hãy đảm bảo bạn có:
- Tài khoản Dodo Payments
- Google AI API key ([Lấy API key từ aistudio](https://aistudio.google.com/api-keys))
- Node.js v16+ đã được cài đặt
</Info>

## Bước 1: Tạo Usage Meter

Trước tiên, chúng ta sẽ tạo một meter trong dashboard Dodo Payments để theo dõi mức sử dụng token AI.

<Tip>
**Chúng ta sẽ xây dựng**: Một meter có tên "AI Token Usage Meter" để cộng tổng tất cả token được sử dụng trong các cuộc trò chuyện.
</Tip>

<Steps>
<Step title="Open the Meters section">
1. Đăng nhập vào dashboard Dodo Payments
2. Nhấp vào Products trong thanh bên trái
3. Nhấp vào **Meters**
4. Nhấp vào nút **Create Meter**

<Frame>
  <img src="/images/cookbooks/ai-chat-app/create-meter.png" alt="Tạo meter" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Bạn sẽ thấy một biểu mẫu để cấu hình tính năng theo dõi token.
</Step>

<Step title="Fill in the basic meter information">
Bây giờ, chúng ta sẽ nhập các thông tin cụ thể cho dịch vụ trò chuyện AI:

**Tên meter** → `AI Token Usage Meter`

**Mô tả** → `Tracks token consumption from AI chat conversations using AI SDK`

**Tên event** → `ai_chat_usage`

<Warning>
Tên event `ai_chat_usage` phải khớp chính xác với giá trị chúng ta sẽ gửi từ mã ứng dụng sau này. Tên event phân biệt chữ hoa chữ thường!
</Warning>
</Step>

<Step title="Configure how we count tokens">
Thiết lập phép tổng hợp (cách meter đếm các event của chúng ta):

**Loại tổng hợp**: Chọn **Sum** từ menu thả xuống

**Tổng hợp trên**: Nhập Type → `totalTokens`

**Đơn vị đo lường**: Nhập Type → `tokens`

<Info>
Chúng ta sử dụng "Sum" vì muốn cộng tất cả token đã sử dụng trong nhiều tin nhắn trò chuyện. SDK sẽ tự động gửi `totalTokens` trong mỗi event.
</Info>
</Step>

<Step title="Create your meter">
1. Kiểm tra lại để đảm bảo tất cả cài đặt khớp với các giá trị ở trên
2. Nhấp vào **Create Meter**

<Frame>
  <img src="/images/cookbooks/ai-chat-app/meter-configuration.png" alt="Cấu hình meter" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Check>
**Đã tạo meter!** "AI Token Usage Meter" hiện đã sẵn sàng bắt đầu đếm token. Tiếp theo, chúng ta sẽ kết nối meter với một sản phẩm tính phí.
</Check>
</Step>
</Steps>

## Bước 3: Tạo Billing Product

Bây giờ, chúng ta cần tạo một sản phẩm xác định mức giá ($0.01 cho mỗi 1.000 token với 10.000 token miễn phí). Sản phẩm này kết nối meter với hoạt động tính phí thực tế.

<Tip>
**Chúng ta sẽ xây dựng**: Một sản phẩm có tên "AI Chat Service", tính phí dựa trên mức sử dụng token với gói miễn phí hào phóng.
</Tip>

<Steps>
<Step title="Navigate to Products">
1. Trong dashboard Dodo Payments, nhấp vào **Products** trong thanh bên trái
2. Nhấp vào **Create Product**
3. Chọn **Usage-Based** làm loại sản phẩm

Điều này cho Dodo Payments biết rằng hoạt động tính phí sẽ dựa trên mức sử dụng meter, không phải gói đăng ký cố định.
</Step>

<Step title="Enter product details">
Điền các thông tin bắt buộc:

**Tên sản phẩm**: → `AI Chat Service`

**Mô tả**: → `AI-powered chat service with automatic token-based billing`

**Ảnh sản phẩm**: Tải lên một hình ảnh phù hợp

<Info>
Các thông tin này sẽ xuất hiện trên hóa đơn khách hàng, vì vậy hãy trình bày rõ ràng và chuyên nghiệp.
</Info>
</Step>

<Step title="Connect your meter">
Trước khi kết nối meter, hãy đảm bảo bạn đã chọn **Usage Based Billing** làm loại giá cho sản phẩm.

Ngoài ra, đặt **Fixed Price** thành `0` để đảm bảo khách hàng chỉ bị tính phí dựa trên mức sử dụng, không có phí cơ bản.

Bây giờ, hãy liên kết meter vừa tạo:

1. Cuộn xuống phần **Associated Meter**
2. Nhấp vào **Add Meters**
3. Từ menu thả xuống, chọn **"AI Token Usage Meter"** (meter bạn đã tạo trước đó)
4. Xác nhận meter xuất hiện trong cấu hình sản phẩm

<Check>
Meter của bạn hiện đã được kết nối thành công với sản phẩm này.
</Check>
</Step>

<Step title="Set your pricing">
Đây là nơi chúng ta xác định mô hình kinh doanh:

**Giá mỗi đơn vị**: Nhập → `0.00001` (tương đương $0.01 cho mỗi 1.000 token hoặc $0.00001 cho mỗi token)

**Ngưỡng miễn phí**: Nhập → `10000` (khách hàng được miễn phí 10.000 token mỗi tháng)

<Frame>
  <img src="/images/cookbooks/ai-chat-app/product-pricing.png" alt="Giá sản phẩm" style={{ maxHeight: '500px', width: 'auto' }} />

<Tip>
**Cách tính phí**: Nếu khách hàng sử dụng 25.000 token trong một tháng, họ sẽ bị tính phí cho 15.000 token (25.000 - 10.000 token miễn phí) = 15.000 × $0.00001 = $0.15
</Tip>
</Step>

<Step title="Save your product">
1. Xem lại tất cả cài đặt:
   - Tên: AI Chat Service
   - Meter: AI Token Usage Meter
   - Giá: $0.01 cho mỗi 1.000 token
   - Gói miễn phí: 10.000 token
2. Nhấp vào **Save Changes**

<Check>
**Đã tạo sản phẩm!** Hoạt động tính phí hiện đã được cấu hình. Khách hàng sẽ tự động bị tính phí dựa trên mức sử dụng token.
</Check>
</Step>
</Steps>

<CodeGroup>

```typescript src/server.ts expandable
import express, { Request, Response } from 'express';
import { generateText } from 'ai';
import { google } from '@ai-sdk/google';
import { createLLMTracker } from '@dodopayments/ingestion-blueprints';
import 'dotenv/config';

const app = express();
app.use(express.json());
app.use(express.static('public'));

// Replace with your test customer ID
const CUSTOMER_ID = 'cus_123';

// Create tracker once with your meter event name
const llmTracker = createLLMTracker({
  apiKey: process.env.DODO_PAYMENTS_API_KEY!,
  environment: process.env.DODO_ENVIRONMENT as 'test_mode' | 'live_mode',
  eventName: 'ai_chat_usage', // Must match your meter configuration
});

// Chat endpoint with conversation support
app.post('/chat', async (req: Request, res: Response) => {
  try {
    const { messages } = req.body;

    if (!messages || !Array.isArray(messages)) {
      return res.status(400).json({ 
        error: 'Missing required field: messages (array)' 
      });
    }

    // Wrap AI SDK with automatic token tracking
    const trackedClient = llmTracker.wrap({
      client: { generateText },
      customerId: CUSTOMER_ID
    });

    // Generate AI response - tokens are automatically tracked!
    const response = await trackedClient.generateText({
      model: google('gemini-2.5-flash'),
      messages: messages
    });

    res.json({
      message: response.text,
      usage: {
        totalTokens: response.usage.totalTokens
      }
    });

  } catch (error: any) {
    console.error('Chat error:', error);
    res.status(500).json({ 
      error: 'Failed to process chat',
      details: error.message 
    });
  }
});

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
  console.log(`🚀 Server running at http://localhost:${PORT}`);
  console.log(`📊 Tracking event: ai_chat_usage`);
  console.log(`👤 Customer ID: ${CUSTOMER_ID}`);
  console.log(`🔧 Environment: ${process.env.DODO_ENVIRONMENT}`);
});
```

    <script>
      let conversationHistory = [];

      const messageInput = document.getElementById("messageInput");
      let resizeTimeout;
      messageInput.addEventListener("input", function () {

          e.preventDefault();
          sendMessage();
        }
      });

      async function sendMessage() {
        const input = document.getElementById("messageInput");
        const message = input.value.trim();

        if (!message) return;

        // Hide empty state
        document.getElementById("emptyState").style.display = "none";

        // Hide error
        document.getElementById("errorMessage").classList.remove("show");

        // Add user message to UI
        addMessage("user", message);

        // Add to conversation history
        conversationHistory.push({
          role: "user",
          content: message,
        });

        // Clear input
        input.value = "";
        input.style.height = "auto";

        // Show typing indicator
        showTypingIndicator();

        // Disable send button
        const sendBtn = document.getElementById("sendBtn");
        sendBtn.disabled = true;

        try {
          const response = await fetch("/chat", {
            method: "POST",
            headers: {
              "Content-Type": "application/json",
            },
            body: JSON.stringify({
              messages: conversationHistory,
            }),
          });

          const data = await response.json();

          if (!response.ok) {
            throw new Error(data.error || "Failed to get response");
          }

          // Hide typing indicator
          hideTypingIndicator();

          // Add assistant response to UI
          addMessage("assistant", data.message, data.usage);

          // Add to conversation history
          conversationHistory.push({
            role: "assistant",
            content: data.message,
          });
        } catch (error) {
          hideTypingIndicator();
          showError(error.message);
          // Remove the last user message from history since it failed
          conversationHistory.pop();
        } finally {
          sendBtn.disabled = false;
        }
      }

      function addMessage(role, content, usage = null) {
        const messagesDiv = document.getElementById("chatMessages");

        const messageDiv = document.createElement("div");
        messageDiv.className = `message ${role}`;

        const avatar = role === "user" ? "👤" : "🤖";

        let metaHTML = "";
        if (usage) {
          metaHTML = `
                    <div class="message-meta">
                        <span class="token-badge">📊 ${usage.totalTokens} tokens</span>
                    </div>
                `;
        }

        messageDiv.innerHTML = `
                <div class="message-avatar">${avatar}</div>
                <div class="message-content">
                    <div class="message-bubble">${escapeHtml(content)}</div>
                    ${metaHTML}
                </div>
            `;

        messagesDiv.appendChild(messageDiv);
        requestAnimationFrame(() => {
          messagesDiv.scrollTop = messagesDiv.scrollHeight;
        });
      }

      function showTypingIndicator() {
        const messagesDiv = document.getElementById("chatMessages");

        const typingDiv = document.createElement("div");
        typingDiv.className = "message assistant";
        typingDiv.id = "typingIndicator";
        typingDiv.innerHTML = `
                <div class="message-avatar">🤖</div>
                <div class="typing-indicator show">
                    <div class="typing-dots">
                        <span></span>
                        <span></span>
                        <span></span>
                    </div>
                </div>
            `;

        messagesDiv.appendChild(typingDiv);
        requestAnimationFrame(() => {
          messagesDiv.scrollTop = messagesDiv.scrollHeight;
        });
      }

      function hideTypingIndicator() {
        const typingIndicator = document.getElementById("typingIndicator");
        if (typingIndicator) {
          typingIndicator.remove();
        }
      }

      function showError(message) {
        const errorDiv = document.getElementById("errorMessage");
        errorDiv.textContent = "❌ " + message;
        errorDiv.classList.add("show");
      }

      function escapeHtml(text) {
        const div = document.createElement("div");
        div.textContent = text;
        return div.innerHTML.replace(/\n/g, "<br>");
      }
    </script>

## Khắc phục sự cố

Các vấn đề thường gặp và cách giải quyết:

<AccordionGroup>
<Accordion title="Events not appearing in dashboard">
**Nguyên nhân có thể:**
- Tên event không khớp chính xác với cấu hình meter
- Customer ID không tồn tại trong tài khoản
- API key không hợp lệ hoặc đã hết hạn
- Sự cố kết nối mạng

**Giải pháp:**
1. Xác minh tên event khớp chính xác với cấu hình meter (phân biệt chữ hoa chữ thường: `ai_chat_usage`)
2. Kiểm tra customer ID tồn tại trong dashboard Dodo Payments
3. Kiểm thử API key bằng một API call đơn giản
4. Kiểm tra server logs để tìm thông báo lỗi
</Accordion>

<Accordion title="Token counts showing zero">
**Nguyên nhân có thể:**
- Model không trả về thông tin mức sử dụng
- Phiên bản SDK không chính xác

**Giải pháp:**
1. Kiểm tra model có trả về usage hay không:

```typescript
const response = await generateText({...});
console.log('Usage:', response.usage);
```

2. Cập nhật lên Blueprints SDK mới nhất: `npm install @dodopayments/ingestion-blueprints@latest`
</Accordion>

<Accordion title="API key invalid error">
**Nguyên nhân có thể:**
- API key không đúng với môi trường
- Có khoảng trắng hoặc dấu ngoặc kép thừa trong tệp `.env`

**Giải pháp:**
- Đảm bảo key thử nghiệm bắt đầu bằng `test_`, key live bắt đầu bằng `live_`
- Xóa mọi dấu ngoặc kép xung quanh key trong tệp `.env`
- Tạo key mới nếu cần
</Accordion>
</AccordionGroup>
