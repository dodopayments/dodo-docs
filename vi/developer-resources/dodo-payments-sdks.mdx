Dodo Payments cung cấp official SDKs cho nhiều ngôn ngữ lập trình, mỗi SDK được thiết kế theo các best practice dành riêng cho ngôn ngữ và các tính năng hiện đại để tích hợp thanh toán liền mạch.

<Tip>
Luôn sử dụng phiên bản SDK mới nhất để có thể truy cập các tính năng và cải tiến mới nhất. Hãy thường xuyên kiểm tra trình quản lý package để tìm các bản cập nhật, nhằm đảm bảo bạn có quyền truy cập vào tất cả khả năng của Dodo Payments.
</Tip>

## Bắt đầu nhanh

Bắt đầu sử dụng bất kỳ SDK nào chỉ trong vài phút:

<Steps>
<Step title="Install the SDK">
  Sử dụng trình quản lý package của ngôn ngữ bạn để cài đặt SDK
  
  <Tabs>
  <Tab title="TypeScript/Node.js">

  ```bash
  npm install dodopayments
  ```

  </Tab>
  
  <Tab title="Python">

  ```bash
  pip install dodopayments
  ```

  </Tab>
  
  <Tab title="PHP">

  ```bash
  composer require dodopayments/client
  ```

  </Tab>
  
  <Tab title="Go">

  ```bash
  go get github.com/dodopayments/dodopayments-go
  ```

  </Tab>

  <Tab title="Rust">

  ```bash
  cargo add dodopayments
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Initialize the Client">
  Cấu hình client bằng API key của bạn
  
  <Tabs>
  <Tab title="TypeScript">

  ```typescript
  import DodoPayments from 'dodopayments';
  const client = new DodoPayments({ bearerToken: 'your_api_key' });
  ```

  </Tab>
  
  <Tab title="Python">

  ```python
  from dodopayments import DodoPayments
  client = DodoPayments(bearer_token="your_api_key")
  ```

  </Tab>
  
  <Tab title="PHP">

  ```php
  use Dodopayments\Client;
  $client = new Client(bearerToken: 'your_api_key');
  ```

  </Tab>
  
  <Tab title="Go">

  ```go
  import "github.com/dodopayments/dodopayments-go"
  client := dodopayments.NewClient(option.WithBearerToken("your_api_key"))
  ```

  </Tab>

  <Tab title="Rust">

  ```rust
  use dodopayments::Client;
  let client = Client::from_env()?; // reads DODO_PAYMENTS_API_KEY
  ```

  </Tab>
  </Tabs>
  
  <Warning>
  Luôn lưu trữ API key an toàn bằng environment variable. Không bao giờ commit chúng vào hệ thống quản lý phiên bản.
  </Warning>
</Step>

<Step title="Make Your First API Call">
  Tạo checkout session hoặc khoản thanh toán
  
  <Check>
  Bạn đã sẵn sàng xử lý thanh toán! Truy cập các trang SDK riêng lẻ để xem hướng dẫn và ví dụ chi tiết.
  </Check>
</Step>
</Steps>

## Tính năng chính

Tất cả SDK **backend** đều có các khả năng cốt lõi này. Các mobile checkout SDK
bên dưới được thiết kế với phạm vi hẹp hơn — chúng không chứa API key và không bao giờ gọi API:

- **Type Safety**: Typing mạnh để đảm bảo an toàn tại thời điểm biên dịch và hỗ trợ IDE tốt hơn
- **Error Handling**: Xử lý exception toàn diện với thông báo lỗi chi tiết
- **Authentication**: Xác thực API key đơn giản với hỗ trợ environment variable
- **Async Support**: Các pattern async/await hiện đại khi phù hợp
- **Auto-Pagination**: Phân trang tự động cho các response dạng danh sách
- **Usage-Based Billing**: Hỗ trợ tích hợp sẵn để theo dõi và tiếp nhận usage event
- **Testing**: Hỗ trợ đầy đủ sandbox environment cho phát triển và kiểm thử

## Mobile Checkout SDKs

Nếu bạn muốn mở **hosted checkout page** của Dodo thay vì xây dựng payment sheet native,
hãy sử dụng mobile checkout SDK dành cho nền tảng của bạn. Cả bốn SDK đều dùng
cùng một contract gọi một lần: `start(...)` trả về một `CheckoutResult` có kiểu,
không SDK nào chứa API key, và Apple Pay/Google Pay hoạt động giống như trên web mở
vì checkout được mở trong browser surface thực của nền tảng
(`SFSafariViewController` / Custom Tabs), không phải một `WebView`:

## Command-Line Interface

Dành cho các quy trình dựa trên terminal và tự động hóa:

<Card title="CLI" icon="terminal" href="/developer-resources/sdks/cli">
  Giao diện dòng lệnh được tự động tạo, hỗ trợ Dodo Payments API
</Card>

**Tính năng:**
- Cấu trúc lệnh dựa trên resource để sử dụng trực quan
- Nhiều định dạng đầu ra (JSON, YAML, pretty, interactive)
- Shell completion cho bash, zsh và fish
- Phù hợp cho scripting và tự động hóa CI/CD

```bash
# Quick example
dodopayments payments list --format json | jq '.items[] | {payment_id, total_amount}'
```
