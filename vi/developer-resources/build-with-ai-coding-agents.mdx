Dodo Agent Plugin kết nối hai MCP server và mười bảy integration skill vào AI coding agent của bạn chỉ với một lần cài đặt. Plugin hoạt động với **Claude Code**, **Codex CLI**, **Cursor** và **OpenCode** — đồng thời MCP server và skills CLI cũng hoạt động với mọi MCP-compatible client.

<Info>
**Ba primitive, một plugin.** Agent Plugin tích hợp mọi thứ bạn cần:
- **API MCP server** — truy cập trực tiếp vào payments, subscriptions, customers, products, refunds, licenses và usage. Xác thực qua browser OAuth (không cần local key).
- **Knowledge MCP server** — tìm kiếm ngữ nghĩa trên toàn bộ tài liệu Dodo Payments. Không cần credentials.
- **Mười bảy agent skill** — các cheat sheet mà agent tải theo yêu cầu cho checkout, subscriptions, webhooks, billing dựa trên usage và credit, license key, product catalog, discounts, localized pricing, mobile checkout, refunds và disputes, customer management, framework adapter, BillingSDK, Better Auth, testing và go-live, cùng các best practice.
</Info>

## Cài đặt plugin

Chọn coding agent bên dưới. Quá trình cài đặt sẽ tự động thêm cả hai MCP server và toàn bộ mười bảy skill.

<AccordionGroup>
<Accordion title="Claude Code" defaultOpen>
Cài đặt từ marketplace:

```bash
claude plugins marketplace add dodopayments/dodo-agent-plugin
claude plugins install dodopayments@dodopayments
```

Máy chủ API MCP sử dụng OAuth trình duyệt theo mặc định — không cần khóa cài đặt. Lần đầu tiên agent của bạn gọi công cụ Dodo, bạn sẽ được nhắc đăng nhập.

<Card title="Dodo Agent Plugin on GitHub" icon="github" href="https://github.com/dodopayments/dodo-agent-plugin">
  Mã nguồn, tùy chọn cấu hình, và hướng dẫn phát triển cục bộ
</Card>
</Accordion>

<Accordion title="Codex CLI">
Codex cài đặt plugin qua hai bước: đăng ký marketplace từ shell của bạn, sau đó cài đặt plugin từ bên trong Codex TUI.

<Steps>
<Step title="Register the marketplace">

```bash
codex plugin marketplace add dodopayments/dodo-agent-plugin
```

</Step>

<Step title="Install from the Codex TUI">
Mở Codex và chạy lệnh slash `/plugins`:

```bash
codex
```

Sau đó nhập `/plugins`, chuyển sang marketplace **Dodo Payments**, chọn plugin **dodopayments**, và chọn **Cài đặt plugin**.
</Step>
</Steps>

Cả hai MCP server và toàn bộ mười bảy skill sẽ được tự động đăng ký sau khi plugin được cài đặt.

<Note>
Codex CLI không có lệnh con `codex plugin install` — việc cài đặt plugin luôn được thực hiện thông qua dòng `/plugins` trong TUI. Xem [tài liệu chính thức về plugin Codex](https://developers.openai.com/codex/plugins).
</Note>

Nếu bạn đã thêm marketplace trước đây và plugin không xuất hiện dưới `/plugins`, hãy làm mới nó:

```bash
codex plugin marketplace upgrade dodopayments
```

</Accordion>

<Accordion title="Cursor">
Cài đặt thủ công — clone repo vào thư mục plugin cục bộ của Cursor:

```bash
git clone https://github.com/dodopayments/dodo-agent-plugin.git ~/.cursor/plugins/local/dodo-agent-plugin
```

Khởi động lại Cursor. Plugin tải các kỹ năng từ `.claude/skills/` (thông qua lớp tương thích Claude Code của Cursor) và các máy chủ MCP từ `.mcp.json`.

<Info>
Hỗ trợ marketplace của Cursor sẽ sớm có. Hiện tại, hãy sử dụng cài đặt thủ công trên.
</Info>
</Accordion>

<Accordion title="OpenCode">
OpenCode phân phối qua npm. Thêm plugin vào `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"]
}
```

Khởi động lại OpenCode. Cả hai MCP server (`dodopayments-api`, `dodo-knowledge`) được tự động đăng ký thông qua config hook của plugin, còn mười bảy skill được tự động phát hiện từ package đã cài đặt. Không cần block `mcp` thủ công.
</Accordion>
</AccordionGroup>

<Info>
Sử dụng một agent khác? Hướng dẫn [MCP Server](/developer-resources/mcp-server) và [Agent Skills](/developer-resources/agent-skills) bao gồm Cursor, Claude Desktop, VS Code, Windsurf, Cline, Zed, và bất kỳ client tương thích nào với MCP.
</Info>

## Những gì bạn nhận được

Sau khi plugin được cài đặt, agent của bạn có quyền truy cập vào hai MCP server và mười bảy skill.

### Máy chủ MCP

| Máy chủ | Mục đích | Xác thực |
|--------|---------|------|
| `dodopayments-api` | Truy cập API trực tiếp — thanh toán, đăng ký, khách hàng, sản phẩm, hoàn tiền, giấy phép, sử dụng | OAuth (trình duyệt) |
| `dodo-knowledge` | Tìm kiếm ngữ nghĩa trong tất cả tài liệu của Dodo Payments | Không |

Cả hai máy chủ được kết nối thông qua `mcp-remote` để chúng chạy trong bất kỳ client nào tương thích với MCP.

### Kỹ năng của Agent

| Skill | Mô tả |
|-------|-------------|
| `best-practices` | Thiết lập SDK, environments, API key và kiến trúc checkout-to-webhook chuẩn |
| `framework-adapters` | Route handler `@dodopayments/*` chính thức cho Next.js, Express, Hono, Astro, Remix, SvelteKit, Nuxt, Fastify, TanStack, Bun và Convex |
| `testing-and-go-live` | Test mode, test payment method, kiểm thử webhook và checklist ra mắt production |
| `checkout-integration` | Checkout Sessions, payment link và checkout overlay hoặc inline |
| `subscription-integration` | Vòng đời subscription, trial, thay đổi plan, proration và khoản phí on-demand |
| `mobile-checkout` | Checkout trong ứng dụng cho React Native, Flutter, iOS và Android |
| `webhook-integration` | Nhận và xác minh webhook bằng đặc tả Standard Webhooks |
| `credit-based-billing` | Credit entitlement, số dư, ledger, rollover, overage và khấu trừ dựa trên meter |
| `usage-based-billing` | Meter, tiếp nhận event, aggregation và định giá theo đơn vị |
| `license-keys` | Kích hoạt và xác thực license key, cùng quản lý instance |
| `product-catalog-management` | Product, pricing, add-on, collection, image và phân phối sản phẩm kỹ thuật số |
| `discounts-and-promotions` | Discount code, quy tắc eligibility, stacking và giới hạn theo subscription cycle |
| `localized-pricing` | Localized pricing, Adaptive Currency và purchasing power parity |
| `customer-management` | Customer, self-service portal, payment method đã lưu và wallet |
| `refunds-and-disputes` | Phát hành refund, xử lý dispute và chargeback, đồng thời đối soát quyền truy cập |
| `billing-sdk` | Component BillingSDK React cho pricing table và giao diện billing |
| `better-auth-integration` | Plugin `@dodopayments/better-auth` cho đồng bộ customer, checkout và quyền truy cập portal |

Kỹ năng tải tự động — agent của bạn sẽ chọn cái phù hợp khi phát hiện nhiệm vụ liên quan. Xem [tài liệu về Agent Skills](/developer-resources/agent-skills) để biết danh sách đầy đủ và cài đặt từng cái.

### Thử nhắc nhở này trước

Khi plugin hoạt động, hãy thử:

```
Set up Dodo Payments webhook handlers in my Next.js app for payment.succeeded and subscription.active events.
```

Agent của bạn sẽ tải kỹ năng `webhook-integration`, sử dụng MCP `dodo-knowledge` để lấy các kiểu payload mới nhất, và viết một handler với xác minh chữ ký theo chuẩn Standard Webhooks.

## Bảo mật và các phương pháp tốt nhất

<Warning>
**Không bao giờ chuyển các khóa API sản xuất.** Sử dụng [chế độ thử nghiệm](/miscellaneous/test-mode-vs-live-mode) trong quá trình phát triển. Agent Plugin mặc định sử dụng OAuth qua trình duyệt — chỉ chuyển sang các khóa API cục bộ nếu quy trình làm việc của bạn yêu cầu.
</Warning>

- **Sử dụng chế độ thử nghiệm trước.** Cách ly tích hợp của bạn với các khóa `dodo_test_...` trước khi hoạt động thực tế. Xem [Chế độ thử nghiệm vs Chế độ hoạt động thực tế](/miscellaneous/test-mode-vs-live-mode).
- **OAuth là mặc định.** Agent Plugin xác thực qua OAuth trình duyệt (không có bí mật cục bộ). Chỉ sử dụng chế độ API-key nếu bạn cần — xem phần Cấu hình bên dưới.
- **Xem xét mã do agent tạo ra.** Luôn xác minh các webhook handler có chứa xác minh chữ ký theo [chuẩn Standard Webhooks](https://standardwebhooks.com/).

## Cấu hình với khóa API

Mặc định, Agent Plugin sử dụng máy chủ MCP từ xa với OAuth trình duyệt — không cần thông tin đăng nhập cục bộ. Nếu quy trình làm việc của bạn yêu cầu khóa API cục bộ (ví dụ: môi trường CI, máy chủ headless), bạn có thể chuyển sang chế độ stdio.

<AccordionGroup>
<Accordion title="Local API key mode — Claude Code">
Mở `/plugins` trong Claude Code, chọn **Dodo Payments**, và chọn **Cấu hình tùy chọn**. Điền vào:

- `dodo_api_key` — khóa `dodo_test_...` hoặc `dodo_live_...` của bạn
- `dodo_webhook_key` — bí mật chữ ký webhook của bạn
- `dodo_environment` — `test_mode` hoặc `live_mode`

Sau đó chỉnh sửa `.mcp.json` để hướng `dodopayments-api` đến máy chủ stdio cục bộ:

```json
{
  "mcpServers": {
    "dodopayments-api": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "dodopayments-mcp@latest"],
      "env": {
        "DODO_PAYMENTS_API_KEY": "${user_config.dodo_api_key}",
        "DODO_PAYMENTS_WEBHOOK_KEY": "${user_config.dodo_webhook_key}",
        "DODO_PAYMENTS_ENVIRONMENT": "${user_config.dodo_environment}"
      }
    }
  }
}
```

Chạy `/reload-plugins` để áp dụng thay đổi cho phiên hiện tại của bạn.
</Accordion>

<Accordion title="Local API key mode — OpenCode">
Tự khai báo `dodopayments-api` trong `opencode.json` — mục nhập của bạn sẽ thắng trên máy chủ từ xa mặc định của plugin:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "mcp": {
    "dodopayments-api": {
      "type": "local",
      "command": ["npx", "-y", "dodopayments-mcp@latest"],
      "environment": {
        "DODO_PAYMENTS_API_KEY": "dodo_test_...",
        "DODO_PAYMENTS_WEBHOOK_KEY": "whsec_...",
        "DODO_PAYMENTS_ENVIRONMENT": "test_mode"
      },
      "enabled": true
    }
  }
}
```

Khởi động lại OpenCode để áp dụng.
</Accordion>
</AccordionGroup>
