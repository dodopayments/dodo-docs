Dodo Agent Plugin kết nối hai máy chủ MCP và tám kỹ năng tích hợp vào agent coding AI của bạn trong một lần cài đặt. Nó hoạt động với **Claude Code**, **Codex CLI**, **Cursor**, và **OpenCode** — và các máy chủ MCP và kỹ năng CLI hoạt động với bất kỳ client tương thích MCP nào.

<Info>
**Ba nguyên thủy, một plugin.** Agent Plugin tổng hợp mọi thứ bạn cần:
- **API MCP server** — truy cập trực tiếp vào thanh toán, đăng ký, khách hàng, sản phẩm, hoàn tiền, giấy phép, và sử dụng. Xác thực qua OAuth trình duyệt (không cần khóa cục bộ).
- **Knowledge MCP server** — tìm kiếm ngữ nghĩa trên toàn bộ tài liệu Dodo Payments. Không cần thông tin xác thực.
- **Tám kỹ năng agent** — các ghi chú tóm tắt mà agent của bạn nạp khi cần cho quy trình thanh toán, đăng ký, webhooks, hóa đơn dựa trên sử dụng, hóa đơn dựa trên tín dụng, khóa giấy phép, BillingSDK, và các thực tiễn tốt nhất.
</Info>

## Cài đặt plugin

Chọn agent coding của bạn bên dưới. Việc cài đặt tự động thêm cả hai máy chủ MCP và tất cả tám kỹ năng.

<AccordionGroup>
<Accordion title="Claude Code" defaultOpen>
Cài đặt từ marketplace:

```bash
claude plugins marketplace add dodopayments/dodo-agent-plugin
claude plugins install dodopayments@dodopayments
```

Máy chủ API MCP sử dụng OAuth trình duyệt theo mặc định — không cần khóa cài đặt. Lần đầu tiên agent của bạn gọi công cụ Dodo, bạn sẽ được nhắc đăng nhập.

<Card title="Dodo Agent Plugin on GitHub" icon="github" href="https://github.com/dodopayments/dodo-agent-plugin">
  Mã nguồn, tùy chọn cấu hình, và hướng dẫn phát triển cục bộ
</Card>
</Accordion>

<Accordion title="Codex CLI">


<Accordion title="Cursor">
Cài đặt thủ công — clone repo vào thư mục plugin cục bộ của Cursor:

```bash
git clone https://github.com/dodopayments/dodo-agent-plugin.git ~/.cursor/plugins/local/dodo-agent-plugin
```

Khởi động lại Cursor. Plugin tải các kỹ năng từ `.claude/skills/` (thông qua lớp tương thích Claude Code của Cursor) và các máy chủ MCP từ `.mcp.json`.

<Info>
Hỗ trợ marketplace của Cursor sẽ sớm có. Hiện tại, hãy sử dụng cài đặt thủ công trên.
</Info>
</Accordion>

<Accordion title="OpenCode">
OpenCode phân phối qua npm. Thêm plugin vào `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"]
}
```

Khởi động lại OpenCode. Cả các máy chủ MCP (`dodopayments-api`, `dodo-knowledge`) đều được đăng ký tự động thông qua hook cấu hình của plugin, và tám kỹ năng được phát hiện tự động từ gói cài đặt. Không cần block `mcp` thủ công.
</Accordion>
</AccordionGroup>

## Những gì bạn nhận được

Khi plugin được cài đặt, agent của bạn có quyền truy cập vào hai máy chủ MCP và tám kỹ năng.

### Máy chủ MCP

| Máy chủ | Mục đích | Xác thực |
|--------|---------|------|
| `dodopayments-api` | Truy cập API trực tiếp — thanh toán, đăng ký, khách hàng, sản phẩm, hoàn tiền, giấy phép, sử dụng | OAuth (trình duyệt) |
| `dodo-knowledge` | Tìm kiếm ngữ nghĩa trong tất cả tài liệu của Dodo Payments | Không |


Cả hai máy chủ được kết nối thông qua `mcp-remote` để chúng chạy trong bất kỳ client nào tương thích với MCP.

### Kỹ năng của Agent

| Kỹ năng | Mô tả |
|-------|-------------|
| `best-practices` | Hướng dẫn toàn diện về tích hợp Dodo Payments với các phương pháp tốt nhất |
| `checkout-integration` | Tạo các phiên checkout và luồng thanh toán |
| `subscription-integration` | Triển khai các luồng thanh toán đăng ký |
| `webhook-integration` | Thiết lập và xử lý các webhook cho các sự kiện thanh toán |
| `usage-based-billing` | Triển khai thanh toán theo metering với các sự kiện và đồng hồ |
| `credit-based-billing` | Quyền lợi tín dụng, số dư, và khấu trừ tín dụng theo metering |
| `license-keys` | Quản lý các khoá cấp phép cho sản phẩm kỹ thuật số |
| `billing-sdk` | Sử dụng các thành phần React của BillingSDK |

Kỹ năng tải tự động — agent của bạn sẽ chọn cái phù hợp khi phát hiện nhiệm vụ liên quan. Xem [tài liệu về Agent Skills](/developer-resources/agent-skills) để biết danh sách đầy đủ và cài đặt từng cái.

### Thử nhắc nhở này trước

Khi plugin hoạt động, hãy thử:

```
Set up Dodo Payments webhook handlers in my Next.js app for payment.succeeded and subscription.active events.
```

Agent của bạn sẽ tải kỹ năng `webhook-integration`, sử dụng MCP `dodo-knowledge` để lấy các kiểu payload mới nhất, và viết một handler với xác minh chữ ký theo chuẩn Standard Webhooks.

## Các agent hỗ trợ khác

Agent Plugin bao gồm Claude Code, Codex CLI, Cursor, và OpenCode. Nếu bạn sử dụng một agent khác, hãy kết nối với Dodo Payments thông qua các máy chủ MCP và CLI kỹ năng:

| Agent | Đường dẫn nhanh nhất | Cũng hỗ trợ |
|-------|-------------|---------------|
| **Claude Code** | Agent Plugin (một lệnh) | Máy chủ MCP, kỹ năng cá nhân |
| **Codex CLI** | Agent Plugin (một lệnh) | Máy chủ MCP |
| **Cursor** | Agent Plugin (git clone) | Cấu hình máy chủ MCP, CLI kỹ năng |
| **OpenCode** | Agent Plugin (npm) | Cấu hình máy chủ MCP, CLI kỹ năng |
| GitHub Copilot (VS Code) | [Hướng dẫn MCP Server](/developer-resources/mcp-server) | [Skills CLI](/developer-resources/agent-skills) |
| Claude Desktop | [Hướng dẫn MCP Server](/developer-resources/mcp-server) | — |
| Windsurf | [Hướng dẫn MCP Server](/developer-resources/mcp-server) | [Skills CLI](/developer-resources/agent-skills) |
| Cline / Zed / others | [Hướng dẫn MCP Server](/developer-resources/mcp-server) | [Skills CLI](/developer-resources/agent-skills) |

## Những gì agent của bạn có thể làm

Với plugin được cài đặt, agent mã hóa của bạn có thể:

- **Tạo phiên checkout và các link thanh toán** — [One-time payments](/features/one-time-payment-products) và [subscriptions](/features/subscription)
- **Thiết lập thanh toán đăng ký và dựa trên sử dụng từ đầu đến cuối** — [Subscriptions](/features/subscription), [Usage-based billing](/features/usage-based-billing), [Credit-based billing](/features/credit-based-billing)
- **Tạo handler phù hợp với Standard Webhooks** với xác minh chữ ký — [Webhooks](/developer-resources/webhooks)
- **Kết nối các thành phần React của BillingSDK** cho các bảng giá và quản lý đăng ký — [BillingSDK](/developer-resources/billingsdk)
- **Tạo luồng khóa cấp phép** cho sản phẩm kỹ thuật số — [License keys](/features/license-keys)
- **Triển khai thanh toán dựa trên tín dụng** với quyền lợi, số dư, chuyển tiếp và sự vượt trội — [Credits](/features/credit-based-billing)

## Bảo mật và các phương pháp tốt nhất

<Warning>
**Không bao giờ chuyển các khóa API sản xuất.** Sử dụng [chế độ thử nghiệm](/miscellaneous/test-mode-vs-live-mode) trong quá trình phát triển. Agent Plugin mặc định sử dụng OAuth qua trình duyệt — chỉ chuyển sang các khóa API cục bộ nếu quy trình làm việc của bạn yêu cầu.
</Warning>

- **Sử dụng chế độ thử nghiệm trước.** Cách ly tích hợp của bạn với các khóa `dodo_test_...` trước khi hoạt động thực tế. Xem [Chế độ thử nghiệm vs Chế độ hoạt động thực tế](/miscellaneous/test-mode-vs-live-mode).
- **OAuth là mặc định.** Agent Plugin xác thực qua OAuth trình duyệt (không có bí mật cục bộ). Chỉ sử dụng chế độ API-key nếu bạn cần — xem phần Cấu hình bên dưới.
- **Xem xét mã do agent tạo ra.** Luôn xác minh các webhook handler có chứa xác minh chữ ký theo [chuẩn Standard Webhooks](https://standardwebhooks.com/).

## Cấu hình với khóa API

Mặc định, Agent Plugin sử dụng máy chủ MCP từ xa với OAuth trình duyệt — không cần thông tin đăng nhập cục bộ. Nếu quy trình làm việc của bạn yêu cầu khóa API cục bộ (ví dụ: môi trường CI, máy chủ headless), bạn có thể chuyển sang chế độ stdio.

<AccordionGroup>
<Accordion title="Local API key mode — Claude Code">
Mở `/plugins` trong Claude Code, chọn **Dodo Payments**, và chọn **Cấu hình tùy chọn**. Điền vào:

- `dodo_api_key` — khóa `dodo_test_...` hoặc `dodo_live_...` của bạn
- `dodo_webhook_key` — bí mật chữ ký webhook của bạn
- `dodo_environment` — `test_mode` hoặc `live_mode`

Sau đó chỉnh sửa `.mcp.json` để hướng `dodopayments-api` đến máy chủ stdio cục bộ:

```json
{
  "mcpServers": {
    "dodopayments-api": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "dodopayments-mcp@latest"],
      "env": {
        "DODO_PAYMENTS_API_KEY": "${user_config.dodo_api_key}",
        "DODO_PAYMENTS_WEBHOOK_KEY": "${user_config.dodo_webhook_key}",
        "DODO_PAYMENTS_ENVIRONMENT": "${user_config.dodo_environment}"
      }
    }
  }
}
```

Chạy `/reload-plugins` để áp dụng thay đổi cho phiên hiện tại của bạn.
</Accordion>

<Accordion title="Local API key mode — OpenCode">
Tự khai báo `dodopayments-api` trong `opencode.json` — mục nhập của bạn sẽ thắng trên máy chủ từ xa mặc định của plugin:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "mcp": {
    "dodopayments-api": {
      "type": "local",
      "command": ["npx", "-y", "dodopayments-mcp@latest"],
      "environment": {
        "DODO_PAYMENTS_API_KEY": "dodo_test_...",
        "DODO_PAYMENTS_WEBHOOK_KEY": "whsec_...",
        "DODO_PAYMENTS_ENVIRONMENT": "test_mode"
      },
      "enabled": true
    }
  }
}
```

Khởi động lại OpenCode để áp dụng.
</Accordion>
</AccordionGroup>
