Dodo Agent Plugin kết nối hai MCP servers và mười bảy integration skills với AI coding agent của bạn chỉ trong một lần cài đặt. Plugin hoạt động với **Claude Code**, **Codex CLI**, **Cursor**, **VS Code / GitHub Copilot**, **Kiro** và **OpenCode**. **Gemini CLI** chỉ nhận được hai MCP servers. MCP servers và skills CLI hoạt động với mọi MCP-compatible client.

Plugin tuân theo đặc tả [Agent Plugins 1.0.0](https://agent-plugins.org/specification), vì vậy các client có hỗ trợ native sẽ tải plugin trực tiếp từ root `plugin.json` và `mcp.json`. Các client có trước đặc tả này sẽ tải cùng nội dung thông qua các compatibility manifests được tạo tự động.

<Info>
**Ba primitive, một plugin.** Agent Plugin bao gồm mọi thứ bạn cần:
- **API MCP server** — truy cập trực tiếp đến payments, subscriptions, customers, products, refunds, licenses và usage. Xác thực qua browser OAuth (không cần local keys).
- **Knowledge MCP server** — tìm kiếm ngữ nghĩa trên toàn bộ tài liệu Dodo Payments. Không cần credentials.
- **Mười bảy agent skills** — các cheat sheet mà agent tải theo yêu cầu cho checkout, subscriptions, webhooks, usage-based và credit-based billing, license keys, product catalog, discounts, localized pricing, mobile checkout, refunds và disputes, customer management, framework adapters, BillingSDK, Better Auth, testing và go-live, cùng các best practices.
</Info>

## Cài đặt plugin

Chọn coding agent bên dưới. Mỗi cách cài đặt đều thêm cả hai MCP servers; tất cả trừ Gemini CLI cũng thêm mười bảy skills.

<AccordionGroup>
<Accordion title="Claude Code" defaultOpen>
Cài đặt từ marketplace:

```bash
claude plugins marketplace add dodopayments/dodo-agent-plugin
claude plugins install dodopayments@dodopayments
```

API MCP server sử dụng browser OAuth theo mặc định — không cần keys trong thời gian cài đặt. Lần đầu agent gọi một Dodo tool, bạn sẽ được yêu cầu đăng nhập.

<Card title="Dodo Agent Plugin on GitHub" icon="github" href="https://github.com/dodopayments/dodo-agent-plugin">
  Mã nguồn, các tùy chọn cấu hình và hướng dẫn phát triển cục bộ
</Card>
</Accordion>

<Accordion title="Codex CLI">
Codex cài đặt plugins theo hai bước: đăng ký marketplace từ shell, sau đó cài đặt plugin bên trong Codex TUI.

<Steps>
<Step title="Register the marketplace">

```bash
codex plugin marketplace add dodopayments/dodo-agent-plugin
```

</Step>

<Step title="Install from the Codex TUI">
Mở Codex và chạy slash command `/plugins`:

```bash
codex
```

Sau đó nhập `/plugins`, chuyển sang marketplace **Dodo Payments**, chọn plugin **dodopayments** và chọn **Install plugin**.
</Step>
</Steps>

Cả hai MCP servers và toàn bộ mười bảy skills sẽ được đăng ký tự động sau khi plugin được cài đặt.

<Note>
Codex CLI không có subcommand `codex plugin install` — việc cài đặt plugin luôn diễn ra thông qua flow `/plugins` trong TUI. Xem [tài liệu Codex plugins chính thức](https://developers.openai.com/codex/plugins).
</Note>

Nếu trước đây bạn đã thêm marketplace nhưng plugin không xuất hiện bên dưới `/plugins`, hãy làm mới marketplace:

```bash
codex plugin marketplace upgrade dodopayments
```

</Accordion>

<Accordion title="Cursor">
Cài đặt thủ công — clone repo vào thư mục plugins cục bộ của Cursor:

```bash
git clone https://github.com/dodopayments/dodo-agent-plugin.git ~/.cursor/plugins/local/dodo-agent-plugin
```

Khởi động lại Cursor. Plugin tải skills từ `skills/` và MCP servers từ `.mcp.json`, như được khai báo trong `.cursor-plugin/plugin.json`.

<Info>
Các bản build Cursor gần đây cũng nhận diện trực tiếp Agent Plugins 1.0.0 và chấp nhận `.cursor-plugin/marketplace.json` hoặc `.claude-plugin/marketplace.json` làm marketplace source. Plugin này cung cấp `.claude-plugin/marketplace.json` — hãy sử dụng path đó. `.cursor-plugin/plugin.json` được tạo tự động vẫn được giữ lại cho các bản build cũ.
</Info>

<Warning>
Các phiên bản trước 0.5.0 cung cấp `skills/` dưới dạng symlink vào git submodule, vì vậy clone này tạo ra plugin **không có skills hoạt động**. Hiện skills được cung cấp dưới dạng các file thực. Nếu bạn đã cài đặt phiên bản cũ hơn, hãy xóa thư mục và clone lại.
</Warning>
</Accordion>

<Accordion title="OpenCode">
OpenCode được phân phối qua npm. Thêm plugin vào `opencode.json` của bạn:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"]
}
```

Khởi động lại OpenCode. Cả hai MCP servers (`dodopayments-api`, `dodo-knowledge`) được đăng ký tự động thông qua config hook của plugin. Không cần block `mcp` thủ công.

**Skills cần thêm một dòng.** OpenCode không quét các packages đã cài đặt để tìm skills, vì vậy hãy tự trỏ đến thư mục `skills/` của package:

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

Các entry `skills.paths` tương đối được phân giải dựa trên **project directory**, vì vậy package phải tồn tại trong `node_modules` của project đó — plugin cache riêng của OpenCode nằm ở vị trí khác. Absolute path cũng hoạt động và tránh yêu cầu cài đặt cục bộ.

<Warning>
Một skills path không tồn tại sẽ bị bỏ qua **một cách im lặng**. Hãy kiểm tra thay vì giả định:

```bash
opencode run "List every skill available to you by name."
```

Bạn sẽ thấy đủ mười bảy skills. Tài liệu của các phiên bản trước 0.5.0 ghi rằng những skills này được tự động phát hiện — thực tế không phải vậy, nên người dùng OpenCode có MCP servers nhưng không có skills.
</Warning>
</Accordion>

<Accordion title="VS Code / GitHub Copilot">
Clone repo ở bất kỳ đâu, sau đó đăng ký repo:

```bash
git clone https://github.com/dodopayments/dodo-agent-plugin.git
```

Mở Chat view, đi đến **Plugins** và thêm thư mục đã clone. Bạn cũng có thể đăng ký trực tiếp trong `settings.json`:

```json
{
  "chat.pluginLocations": { "~/dodo-agent-plugin": true }
}
```

Key là một path, value bật plugin. Absolute paths và `~/` đều hoạt động; relative path được phân giải dựa trên từng workspace folder. Setting được đọc trực tiếp, nên cửa sổ đang chạy sẽ nhận thay đổi mà không cần khởi động lại. Skills được tải từ `skills/`, còn cả hai MCP servers được tải từ `.mcp.json`.

<Note>
`chat.pluginLocations` được đánh dấu là **experimental** và là một setting *restricted*, vì vậy workspace phải được tin cậy để setting này có hiệu lực. Hỗ trợ agent-plugin nói chung vẫn là một preview feature được điều khiển bởi `chat.plugins.enabled`, vốn **được bật theo mặc định** — bạn chỉ cần đặt setting này nếu tổ chức của bạn vô hiệu hóa nó theo policy.
</Note>

<Info>
VS Code không dựa trên `$schema` của Agent Plugins. Loader của nó kiểm tra `.plugin/plugin.json`, sau đó `.claude-plugin/plugin.json`, rồi root `plugin.json`; đồng thời mặc định MCP là `.mcp.json` thay vì `mcp.json`. Vì repo này cung cấp `.claude-plugin/plugin.json` được tạo tự động, VS Code tải plugin qua compatibility branch đó và nhận bridge `mcp-remote` thay vì native transports trong `mcp.json`. Mọi thứ vẫn hoạt động — chỉ khác path.
</Info>
</Accordion>

<Accordion title="Kiro">
Kiro đọc Agent Plugins manifest natively và tải plugin này dưới dạng một Power.

<Steps>
<Step title="Clone the repository">

```bash
git clone https://github.com/dodopayments/dodo-agent-plugin.git
```

</Step>

<Step title="Open the Powers panel">
Trong Kiro, mở Powers panel — biểu tượng Ghosty có tia sét.
</Step>

<Step title="Import the folder">
Chọn **Add Custom Power → Import power from a folder**, chọn thư mục đã clone (thư mục chứa `plugin.json`), rồi nhấp **Install**.
</Step>
</Steps>

Skills được tải từ `skills/`, MCP servers từ `mcp.json`, còn phần trình bày dành riêng cho Kiro đến từ extension namespace `dev.kiro` trong `plugin.json`.

<Note>
Đối với các plugin ở định dạng Agent Plugins, Kiro quản lý MCP servers nội bộ — chúng **không** được ghi vào `~/.kiro/settings/mcp.json` ở cấp user, vì vậy đừng mong tìm thấy chúng ở đó. Kiro cũng có thể cài đặt một Power trực tiếp từ GitHub URL; xem [tài liệu cài đặt của Kiro](https://kiro.dev/docs/powers/installation/).
</Note>
</Accordion>

<Accordion title="Gemini CLI (MCP only)">
Gemini CLI không có agent-skill primitive, vì vậy **chỉ hai MCP servers khả dụng** — mười bảy skills không khả dụng. `dodo-knowledge` vẫn bao quát phần lớn chức năng do các skills cung cấp và được tự động cập nhật.

```bash
git clone https://github.com/dodopayments/dodo-agent-plugin.git \
  ~/.gemini/extensions/dodopayments
```

Khởi động lại Gemini CLI. `gemini-extension.json` tại root của repo là manifest.
</Accordion>

## Bạn nhận được gì

Sau khi cài đặt plugin, agent của bạn có quyền truy cập vào hai MCP servers và mười bảy skills.

### MCP servers

| Server | Mục đích | Xác thực |
|--------|---------|------|
| `dodopayments-api` | Truy cập Live API — payments, subscriptions, customers, products, refunds, licenses, usage | OAuth (browser) |
| `dodo-knowledge` | Tìm kiếm ngữ nghĩa trên toàn bộ tài liệu Dodo Payments | Không có |

Cả hai servers đều sử dụng Streamable HTTP. `mcp.json` canonical khai báo chúng natively (`type: "streamable-http"`), đây là cách các client hỗ trợ native spec như Codex CLI và Kiro sử dụng. Compatibility manifest được tạo tự động `.mcp.json` kết nối cùng hai endpoints thông qua `mcp-remote`, nên chúng cũng chạy được trong các client không thể kết nối trực tiếp bằng Streamable HTTP — Claude Code, VS Code và Cursor thông qua cách cài đặt git-clone được mô tả ở trên, với `.cursor-plugin/plugin.json` trỏ đến `.mcp.json`.

### Agent skills

| Skill | Mô tả |
|-------|-------------|
| `dodo-best-practices` | Thiết lập SDK, environments, API keys và kiến trúc checkout-to-webhook canonical |
| `framework-adapters` | Các route handlers `@dodopayments/*` chính thức cho Next.js, Express, Hono, Astro, Remix, SvelteKit, Nuxt, Fastify, TanStack, Bun và Convex |
| `testing-and-go-live` | Test mode, test payment methods, webhook testing và production launch checklist |
| `checkout-integration` | Checkout Sessions, payment links và checkout dạng overlay hoặc inline |
| `subscription-integration` | Vòng đời subscription, trials, thay đổi plan, proration và on-demand charges |
| `mobile-checkout` | Checkout trong ứng dụng cho React Native, Flutter, iOS và Android |
| `webhook-integration` | Nhận và xác minh webhooks bằng đặc tả Standard Webhooks |
| `credit-based-billing` | Credit entitlements, balances, ledger, rollover, overage và meter-based deduction |
| `usage-based-billing` | Meters, event ingestion, aggregation và per-unit pricing |
| `license-keys` | Kích hoạt và xác thực license key, cùng quản lý instance |
| `product-catalog-management` | Products, pricing, add-ons, collections, images và digital product delivery |
| `discounts-and-promotions` | Discount codes, eligibility rules, stacking và subscription-cycle limits |
| `localized-pricing` | Localized pricing, Adaptive Currency và purchasing power parity |
| `customer-management` | Customers, self-service portal, saved payment methods và wallets |
| `refunds-and-disputes` | Phát hành refunds, xử lý disputes và chargebacks, đồng thời đối soát quyền truy cập |
| `billing-sdk` | BillingSDK React components cho pricing tables và billing UI |
| `better-auth-integration` | Plugin `@dodopayments/better-auth` cho customer sync, checkout và portal access |

Skills được tải tự động — agent chọn skill phù hợp khi phát hiện task liên quan. Xem [tài liệu Agent Skills](/developer-resources/agent-skills) để xem danh sách đầy đủ và cách cài đặt từng skill.

### Hãy thử prompt này trước

Sau khi plugin hoạt động, hãy thử:

```
Set up Dodo Payments webhook handlers in my Next.js app for payment.succeeded and subscription.active events.
```

Agent sẽ tải skill `webhook-integration`, sử dụng MCP `dodo-knowledge` để lấy các payload shapes mới nhất và viết handler có signature verification theo Standard Webhooks spec.

## Bảo mật và best practices

<Warning>
**Không bao giờ commit production API keys.** Sử dụng [test mode](/miscellaneous/test-mode-vs-live-mode) trong quá trình phát triển. Agent Plugin sử dụng browser OAuth theo mặc định — chỉ chuyển sang local API keys nếu workflow của bạn yêu cầu.
</Warning>

- **Trước tiên hãy sử dụng test mode.** Sandbox integration của bạn bằng các keys `dodo_test_...` trước khi go live. Xem [Test Mode vs Live Mode](/miscellaneous/test-mode-vs-live-mode).
- **OAuth là mặc định.** Agent Plugin xác thực qua browser OAuth (không có local secrets). Chỉ sử dụng API-key mode khi cần — xem phần Configure bên dưới.
- **Kiểm tra code do agent tạo.** Luôn xác minh rằng webhook handlers có signature verification theo [Standard Webhooks spec](https://standardwebhooks.com/).

## Cấu hình bằng API key

Theo mặc định, Agent Plugin sử dụng remote MCP server với browser OAuth — không cần local credentials. Nếu workflow yêu cầu local API key (ví dụ: CI environments, headless servers), bạn có thể chuyển sang stdio mode.

<AccordionGroup>
<Accordion title="Local API key mode — Claude Code">
Mở `/plugins` trong Claude Code, chọn **Dodo Payments** và chọn **Configure options**. Điền các thông tin sau:

- `dodo_api_key` — key `dodo_test_...` hoặc `dodo_live_...` của bạn
- `dodo_webhook_key` — webhook signing secret của bạn
- `dodo_environment` — `test_mode` hoặc `live_mode`

Sau đó chỉnh sửa `.mcp.json` để trỏ `dodopayments-api` đến local stdio server:

```json
{
  "mcpServers": {
    "dodopayments-api": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "dodopayments-mcp@latest"],
      "env": {
        "DODO_PAYMENTS_API_KEY": "${user_config.dodo_api_key}",
        "DODO_PAYMENTS_WEBHOOK_KEY": "${user_config.dodo_webhook_key}",
        "DODO_PAYMENTS_ENVIRONMENT": "${user_config.dodo_environment}"
      }
    }
  }
}
```

Chạy `/reload-plugins` để áp dụng thay đổi cho session hiện tại của bạn.
</Accordion>

<Accordion title="Local API key mode — OpenCode">
Tự khai báo `dodopayments-api` trong `opencode.json` — entry của bạn sẽ ghi đè remote server mặc định của plugin:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "mcp": {
    "dodopayments-api": {
      "type": "local",
      "command": ["npx", "-y", "dodopayments-mcp@latest"],
      "environment": {
        "DODO_PAYMENTS_API_KEY": "dodo_test_...",
        "DODO_PAYMENTS_WEBHOOK_KEY": "whsec_...",
        "DODO_PAYMENTS_ENVIRONMENT": "test_mode"
      },
```
