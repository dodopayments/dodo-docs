## Tổng quan

SDK Thanh toán Dodo cung cấp một cách tích hợp liền mạch để đưa overlay thanh toán của chúng tôi vào ứng dụng web của bạn. Được xây dựng bằng TypeScript và các tiêu chuẩn web hiện đại, nó cung cấp một giải pháp mạnh mẽ để xử lý thanh toán với việc xử lý sự kiện theo thời gian thực và các chủ đề tùy chỉnh.

## Bắt đầu nhanh

Bắt đầu với SDK Thanh toán Dodo chỉ trong vài dòng mã:

```typescript
import { DodoPayments } from "dodopayments-checkout";

// Initialize the SDK
DodoPayments.Initialize({
  mode: "test", // 'test' or 'live'
  displayType: "overlay", // Optional: defaults to 'overlay' for overlay checkout
  onEvent: (event) => {
    console.log("Checkout event:", event);
  },
});

// Open checkout
DodoPayments.Checkout.open({
  checkoutUrl: "https://checkout.dodopayments.com/session/cks_123"
});
```

<Tip>
Lấy URL thanh toán của bạn từ [API tạo phiên thanh toán](/api-reference/checkout-sessions/create).
</Tip>

```typescript
import { DodoPayments } from "dodopayments-checkout";

DodoPayments.Initialize({
  mode: "test", // Change to 'live' for production
  displayType: "overlay", // Optional: defaults to 'overlay' for overlay checkout
  onEvent: (event) => {
    console.log("Checkout event:", event);
    
    // Handle different events
    switch (event.event_type) {
      case "checkout.opened":
        // Checkout overlay has been opened
        break;
      case "checkout.closed":
        // Checkout has been closed
        break;
      case "checkout.error":
        // Handle errors
        console.error("Checkout error:", event.data?.message);
        break;
    }
  },
});
```

</Warning>

<Step title="Tạo thành phần nút thanh toán">

Tạo một thành phần mở overlay thanh toán:

```typescript
// components/CheckoutButton.tsx
"use client";

import { Button } from "@/components/ui/button";
import { DodoPayments } from "dodopayments-checkout";
import { useEffect, useState } from "react";

export function CheckoutButton() {
  const [isLoading, setIsLoading] = useState(false);

  useEffect(() => {
    // Initialize the SDK
    DodoPayments.Initialize({
      mode: "test",
      displayType: "overlay",
      onEvent: (event) => {
        switch (event.event_type) {
          case "checkout.opened":
            setIsLoading(false);
            break;
          case "checkout.error":
            setIsLoading(false);
            console.error("Checkout error:", event.data?.message);
            break;
        }
      },
    });
  }, []);

  const handleCheckout = async () => {
    try {
      setIsLoading(true);
      await DodoPayments.Checkout.open({
        checkoutUrl: "https://checkout.dodopayments.com/session/cks_123"
      });
    } catch (error) {
      console.error("Failed to open checkout:", error);
      setIsLoading(false);
    }
  };

  return (
    <Button 
      onClick={handleCheckout}
      disabled={isLoading}
    >
      {isLoading ? "Loading..." : "Checkout Now"}
    </Button>
  );
}
```

## Tài liệu API

### Cấu hình

#### Tùy chọn khởi tạo

```typescript
interface InitializeOptions {
  mode: "test" | "live";
  displayType?: "overlay" | "inline";
  onEvent: (event: CheckoutEvent) => void;
}
```

| Tùy chọn | Kiểu | Bắt buộc | Mô tả |
|--------|------|----------|-------------|
| `mode` | `"test" \| "live"` | Có | Chế độ môi trường: `'test'` cho phát triển, `'live'` cho sản xuất |
| `displayType` | `"overlay" \| "inline"` | Không | Loại hiển thị: `'overlay'` cho thanh toán modal (mặc định), `'inline'` cho thanh toán nhúng |
| `onEvent` | `function` | Có | Hàm callback để xử lý các sự kiện thanh toán |

#### Tùy chọn thanh toán

```typescript
interface CheckoutOptions {
  checkoutUrl: string;
  options?: {
    showTimer?: boolean;
    showSecurityBadge?: boolean;
    manualRedirect?: boolean;
  };
}
```

| Tùy chọn | Kiểu | Bắt buộc | Mô tả |
|--------|------|----------|-------------|
| `checkoutUrl` | `string` | Có | URL phiên thanh toán từ [API tạo phiên thanh toán](/api-reference/checkout-sessions/create) |
| `options.showTimer` | `boolean` | Không | Hiển thị hoặc ẩn bộ đếm thời gian thanh toán. Mặc định là `true`. Khi tắt, bạn sẽ nhận được sự kiện `checkout.link_expired` khi phiên hết hạn. |
| `options.showSecurityBadge` | `boolean` | Không | Hiển thị hoặc ẩn badge bảo mật. Mặc định là `true`. |
| `options.manualRedirect` | `boolean` | Không | Khi được kích hoạt, thanh toán sẽ không tự động chuyển hướng sau khi hoàn thành. Thay vào đó, bạn sẽ nhận được `checkout.status` và `checkout.redirect_requested` để tự xử lý chuyển hướng. |

### Phương thức

#### Mở thanh toán

Mở overlay thanh toán với URL phiên thanh toán đã chỉ định.

```typescript
DodoPayments.Checkout.open({
  checkoutUrl: "https://checkout.dodopayments.com/session/cks_123"
});
```

Bạn cũng có thể truyền thêm tùy chọn để tùy chỉnh hành vi thanh toán:

```typescript
DodoPayments.Checkout.open({
  checkoutUrl: "https://checkout.dodopayments.com/session/cks_123",
  options: {
    showTimer: false,
    showSecurityBadge: false,
    manualRedirect: true,
  },
});
```

Khi sử dụng `manualRedirect`, hãy xử lý hoàn thành thanh toán trong hàm callback `onEvent` của bạn:

```typescript
DodoPayments.Initialize({
  mode: "test",
  displayType: "overlay",
  onEvent: (event) => {
    if (event.event_type === "checkout.status") {
      const status = event.data?.message?.status;
      // Handle status: "succeeded", "failed", or "processing"
    }
    if (event.event_type === "checkout.redirect_requested") {
      const redirectUrl = event.data?.message?.redirect_to;
      // Redirect the customer manually
      window.location.href = redirectUrl;
    }
    if (event.event_type === "checkout.link_expired") {
      // Handle expired checkout session
    }
  },
});
```

#### Đóng Thanh Toán

Đóng overlay thanh toán một cách lập trình.

```typescript
DodoPayments.Checkout.close();
```

#### Kiểm Tra Trạng Thái

Trả về trạng thái hiện tại của overlay thanh toán.

```typescript
const isOpen = DodoPayments.Checkout.isOpen();
// Returns: boolean
```

### Sự Kiện

SDK cung cấp các sự kiện theo thời gian thực mà bạn có thể lắng nghe thông qua hàm callback `onEvent`:

#### Dữ Liệu Sự Kiện Trạng Thái Thanh Toán

Khi `manualRedirect` được kích hoạt, bạn sẽ nhận được sự kiện `checkout.status` với dữ liệu sau:

```typescript
interface CheckoutStatusEventData {
  message: {
    status?: "succeeded" | "failed" | "processing";
  };
}
```

#### Dữ Liệu Sự Kiện Yêu Cầu Chuyển Hướng Thanh Toán

Khi `manualRedirect` được kích hoạt, bạn sẽ nhận được sự kiện `checkout.redirect_requested` với dữ liệu sau:

```typescript
interface CheckoutRedirectRequestedEventData {
  message: {
    redirect_to?: string;
  };
}
```

```typescript
DodoPayments.Initialize({
  onEvent: (event: CheckoutEvent) => {
    switch (event.event_type) {
      case "checkout.opened":
        // Checkout overlay has been opened
        break;
      case "checkout.form_ready":
        // Checkout form is ready for user input
        break;
      case "checkout.payment_page_opened":
        // Payment page has been displayed
        break;
      case "checkout.customer_details_submitted":
        // Customer and billing details submitted
        break;
      case "checkout.closed":
        // Checkout has been closed
        break;
      case "checkout.redirect":
        // Checkout will perform a redirect
        break;
      case "checkout.error":
        // An error occurred
        console.error("Error:", event.data?.message);
        break;
      case "checkout.link_expired":
        // Checkout session has expired (only when showTimer is false)
        break;
      case "checkout.status":
        // Checkout status update (only when manualRedirect is enabled)
        const status = event.data?.message?.status;
        break;
      case "checkout.redirect_requested":
        // Redirect requested (only when manualRedirect is enabled)
        const redirectUrl = event.data?.message?.redirect_to;
        break;
    }
  }
});
```

| Loại sự kiện | Mô tả |
|------------|-------------|
| `checkout.opened` | Bảng điều khiển thanh toán đã được mở |
| `checkout.form_ready` | Mẫu thanh toán đã sẵn sàng nhận đầu vào của người dùng. Hữu ích để ẩn trạng thái tải. |
| `checkout.payment_page_opened` | Trang thanh toán đã được hiển thị |
| `checkout.customer_details_submitted` | Thông tin và chi tiết thanh toán của khách hàng đã được gửi |
| `checkout.closed` | Bảng điều khiển thanh toán đã đóng |
| `checkout.redirect` | Thanh toán sẽ thực hiện chuyển hướng |
| `checkout.error` | Một lỗi đã xảy ra trong quá trình thanh toán |
| `checkout.link_expired` | Xảy ra khi phiên thanh toán hết hạn. Chỉ nhận được khi `showTimer` được đặt thành `false`. |
| `checkout.status` | Xảy ra khi `manualRedirect` được kích hoạt. Chứa trạng thái thanh toán (`succeeded`, `failed`, hoặc `processing`). |
| `checkout.redirect_requested` | Xảy ra khi `manualRedirect` được kích hoạt. Chứa URL để chuyển hướng khách hàng đến. |

## Xử lý lỗi

SDK cung cấp thông tin chi tiết về lỗi thông qua hệ thống sự kiện. Luôn thực hiện xử lý lỗi đúng cách trong hàm callback `onEvent` của bạn:

```typescript
DodoPayments.Initialize({
  mode: "test",
  displayType: "overlay",
  onEvent: (event: CheckoutEvent) => {
    if (event.event_type === "checkout.error") {
      console.error("Checkout error:", event.data?.message);
      // Handle error appropriately
      // You may want to show a user-friendly error message
      // or retry the checkout process
    }
    if (event.event_type === "checkout.link_expired") {
      // Handle expired checkout session
      console.warn("Checkout session has expired");
    }
  }
});
```

<Warning>
Luôn xử lý sự kiện `checkout.error` để cung cấp trải nghiệm người dùng tốt khi có lỗi xảy ra.
</Warning>

## Thực hành tốt nhất

1. **Khởi tạo một lần**: Khởi tạo SDK một lần khi ứng dụng của bạn tải, không phải trên mỗi lần thử thanh toán
2. **Xử lý lỗi**: Luôn thực hiện xử lý lỗi đúng cách trong hàm callback sự kiện của bạn
3. **Chế độ thử nghiệm**: Sử dụng `test` trong quá trình phát triển và chuyển sang `live` chỉ khi sẵn sàng cho sản xuất
4. **Xử lý sự kiện**: Xử lý tất cả các sự kiện liên quan để có trải nghiệm người dùng hoàn chỉnh
5. **URL hợp lệ**: Luôn sử dụng URL thanh toán hợp lệ từ API tạo phiên thanh toán
6. **TypeScript**: Sử dụng TypeScript để có độ an toàn kiểu tốt hơn và trải nghiệm cho lập trình viên
7. **Trạng thái tải**: Hiển thị trạng thái tải trong khi thanh toán đang mở để cải thiện UX
8. **Chuyển hướng thủ công**: Sử dụng `manualRedirect` khi bạn cần kiểm soát tùy chỉnh về điều hướng sau thanh toán
9. **Quản lý bộ đếm thời gian**: Tắt bộ đếm (`showTimer: false`) nếu bạn muốn xử lý việc phiên hết hạn theo cách thủ công

## Thanh toán lớp phủ so với thanh toán nội tuyến

Chọn loại thanh toán phù hợp với trường hợp sử dụng của bạn:

| Tính năng | Thanh toán lớp phủ | Thanh toán nội tuyến |
|---------|-----------------|-----------------|
| Độ sâu tích hợp | Modal trên trang | Hoàn toàn nhúng trong trang |
| Kiểm soát bố cục | Hạn chế | Kiểm soát hoàn toàn |
| Thương hiệu | Tách biệt khỏi trang | Liền mạch |
| Nỗ lực thực hiện | Thấp hơn | Cao hơn |
| Tốt nhất cho | Tích hợp nhanh chóng, các trang hiện có | Trang thanh toán tùy chỉnh, quy trình chuyển đổi cao |

<Tip>
Sử dụng **thanh toán lớp phủ** để tích hợp nhanh hơn với những thay đổi tối thiểu trong các trang hiện có của bạn. Sử dụng **thanh toán nội tuyến** khi bạn muốn kiểm soát tối đa về trải nghiệm thanh toán và thương hiệu liền mạch.
</Tip>
