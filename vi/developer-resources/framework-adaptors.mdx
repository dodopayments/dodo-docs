Dodo Payments cung cấp các bộ chuyển đổi framework chính thức giúp đơn giản hóa việc tích hợp thanh toán. Mỗi bộ chuyển đổi được thiết kế để hoạt động liền mạch với các quy ước của framework của bạn, cung cấp chức năng thanh toán, cổng khách hàng và xử lý webhook ngay lập tức.

<Tip>
Các bộ chuyển đổi framework cho phép bạn tích hợp Dodo Payments trong dưới 10 dòng mã. Chúng tự động xử lý xác thực, phân tích yêu cầu và định dạng phản hồi.
</Tip>

## Tính Năng Chính

Tất cả các bộ chuyển đổi framework cung cấp các khả năng tích hợp sẵn sau:

| Tính Năng | Mô Tả |
|---------|-------------|
| **Xử Lý Thanh Toán** | Hỗ trợ các luồng thanh toán tĩnh, động và dựa trên phiên |
| **Cổng Khách Hàng** | Xử lý tích hợp sẵn cho quản lý đăng ký và thanh toán |
| **Xử Lý Webhook** | Xác minh chữ ký an toàn với các xử lý sự kiện có kiểu |
| **Cấu Hình Môi Trường** | Cài đặt đơn giản qua các biến môi trường |
| **Độ An Toàn Kiểu** | Hỗ trợ đầy đủ TypeScript với các payload có kiểu |

## Khởi Đầu Nhanh

Bắt đầu với bất kỳ bộ chuyển đổi framework nào trong ba bước:

<Steps>
<Step title="Cài Đặt Bộ Chuyển Đổi">
  Sử dụng trình quản lý gói của bạn để cài đặt bộ chuyển đổi cụ thể cho framework:

  <Tabs>
  <Tab title="Next.js">

  ```bash
  npm install @dodopayments/nextjs
  ```

  </Tab>
  
  <Tab title="Nuxt">

  ```bash
  npm install @dodopayments/nuxt
  ```

  </Tab>
  
  <Tab title="Express">

  ```bash
  npm install @dodopayments/express
  ```

  </Tab>
  
  <Tab title="Hono">

  ```bash
  npm install @dodopayments/hono
  ```

  </Tab>

  <Tab title="Astro">

  ```bash
  npm install @dodopayments/astro
  ```

  </Tab>

  <Tab title="SvelteKit">

  ```bash
  npm install @dodopayments/sveltekit
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Cấu Hình Biến Môi Trường">
  Thêm thông tin xác thực Dodo Payments của bạn vào môi trường:

  ```env
  DODO_PAYMENTS_API_KEY=your-api-key
  DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
  DODO_PAYMENTS_RETURN_URL=https://yourdomain.com/checkout/success
  DODO_PAYMENTS_ENVIRONMENT="test_mode" # or "live_mode"
  ```

  <Warning>
  Không bao giờ cam kết tập tin `.env` hoặc các bí mật vào điều khiển phiên bản.
  </Warning>
</Step>

<Step title="Tạo Bộ Xử Lý Đường Dẫn">
  Thiết lập các đường dẫn thanh toán, cổng khách hàng và webhook của bạn:

  <Tabs>
  <Tab title="Next.js">

  ```typescript
  // app/checkout/route.ts
  import { Checkout } from "@dodopayments/nextjs";

  export const GET = Checkout({
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
    environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  });
  ```

  </Tab>
  
  <Tab title="Express">

  ```typescript
  import { checkoutHandler } from '@dodopayments/express';

  app.get('/api/checkout', checkoutHandler({
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
    environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  }));
  ```

  </Tab>
  
  <Tab title="Hono">

  ```typescript
  import { Checkout } from "@dodopayments/hono";

  app.get('/checkout', Checkout({
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
    environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  }));
  ```

  </Tab>
  </Tabs>

  <Check>
  Bạn đã sẵn sàng để xử lý thanh toán! Truy cập các trang bộ chuyển đổi riêng lẻ để xem hướng dẫn chi tiết và tất cả các tùy chọn có sẵn.
  </Check>
</Step>
</Steps>

## Các Loại Luồng Thanh Toán

Tất cả các bộ chuyển đổi hỗ trợ ba loại luồng thanh toán:

<AccordionGroup>
<Accordion title="Thanh Toán Tĩnh (GET)">
Sử dụng thanh toán tĩnh cho các liên kết thanh toán đơn giản, có thể chia sẻ. Truyền ID sản phẩm như một tham số truy vấn:

```
/api/checkout?productId=pdt_xxx&quantity=1
```

Hỗ trợ tùy chọn tự động điền khách hàng và tùy chỉnh qua các tham số truy vấn.
</Accordion>

<Accordion title="Thanh Toán Động (POST)">
Sử dụng thanh toán động để tạo thanh toán một cách lập trình với các chi tiết tùy chỉnh:

```json
{
  "product_id": "pdt_xxx",
  "customer": {
    "email": "customer@example.com",
    "name": "John Doe"
  },
  "quantity": 1
}
```

Hỗ trợ cả thanh toán một lần và đăng ký.
</Accordion>

<Accordion title="Phiên Thanh Toán (POST)">
Sử dụng phiên thanh toán cho trải nghiệm thanh toán linh hoạt nhất với hỗ trợ giỏ hàng:

```json
{
  "product_cart": [
    { "product_id": "pdt_xxx", "quantity": 1 },
    { "product_id": "pdt_yyy", "quantity": 2 }
  ],
  "customer": {
    "email": "customer@example.com"
  }
}
```

Tìm hiểu thêm trong [Hướng Dẫn Phiên Thanh Toán](/developer-resources/checkout-session).
</Accordion>
</AccordionGroup>

## Xử Lý Sự Kiện Webhook

Tất cả các bộ chuyển đổi cung cấp xử lý webhook an toàn có kiểu với các callback sự kiện chi tiết:

```typescript
Webhooks({
  webhookKey: process.env.DODO_PAYMENTS_WEBHOOK_KEY,
  onPayload: async (payload) => {
    // Handle any webhook event
  },
  onPaymentSucceeded: async (payload) => {
    // Handle successful payments
  },
  onSubscriptionActive: async (payload) => {
    // Handle new subscriptions
  },
  // ... 20+ event types supported
});
```

<Info>
Tất cả các bộ xử lý webhook tự động xác minh chữ ký và xác thực các payload bằng cách sử dụng các sơ đồ Zod. Các yêu cầu không hợp lệ sẽ bị từ chối với mã lỗi thích hợp.
</Info>

## Chọn Bộ Chuyển Đổi Phù Hợp

| Framework | Tốt Nhất Cho | Thời Gian Chạy |
|-----------|----------|---------|
| **Next.js** | Ứng dụng React full-stack với App Router | Node.js, Edge |
| **Nuxt** | Ứng dụng Vue.js full-stack | Node.js |
| **Express** | API REST và ứng dụng Node.js truyền thống | Node.js |
| **Fastify** | API hiệu suất cao | Node.js |
| **Hono** | Triển khai Edge, Cloudflare Workers | Edge, Node.js |
| **Astro** | Các trang nội dung với điểm cuối máy chủ | Node.js, Edge |
| **SvelteKit** | Ứng dụng Svelte full-stack | Node.js |
| **Remix** | React full-stack với định tuyến lồng ghép | Node.js |
| **TanStack Start** | React full-stack an toàn kiểu | Node.js |
| **Better Auth** | Ứng dụng đã sử dụng Better Auth | Nhiều |
| **Convex** | Ứng dụng sử dụng Convex cho backend | Convex Runtime |
| **Bun** | Ứng dụng máy chủ Bun bản địa | Bun |
