## Overview

Agent Skills are reusable capabilities that enhance what AI coding assistants can do when working with Dodo Payments. They provide procedural knowledge and best practices that help agents accomplish specific tasks more effectively - from integrating checkout flows to setting up usage-based billing.

<Info>
**Think of skills as plugins for your AI assistant.** They teach your agent how to implement Dodo Payments features correctly, following our recommended patterns and best practices.
</Info>

Skills work with any MCP-compatible AI agent, including:
- **Claude Code** - Anthropic's CLI coding assistant
- **OpenCode** - Open source AI coding agent
- **Cursor** - AI-first code editor
- **Other MCP clients** - Any agent supporting the skills protocol

## Available Skills

Mười bảy skill bao phủ toàn bộ phạm vi tích hợp, được nhóm theo tác vụ bạn đang thực hiện.

## Cài đặt

Chọn phương thức cài đặt phù hợp dựa trên AI coding assistant của bạn.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Nếu bạn sử dụng Claude Code, Codex CLI, Cursor hoặc OpenCode, [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) sẽ cài đặt toàn bộ mười bảy skill cùng cả hai MCP server chỉ trong một bước. Skill sẽ tự động được tải khi agent phát hiện một tác vụ phù hợp.

Xem [hướng dẫn AI Coding Agents](/developer-resources/build-with-ai-coding-agents) để biết lệnh cài đặt cho từng agent.
</Tab>

<Tab title="Skills CLI">
Cài đặt skill bằng universal skills CLI, công cụ hoạt động với mọi agent tương thích MCP:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Hoặc cài đặt từng skill riêng lẻ khi cần:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
Chỉ cài đặt những skill bạn cần để agent tập trung hơn và giảm context overhead.
</Tip>
</Tab>

## Sử dụng Skill

Sau khi cài đặt, AI coding assistant sẽ tự động tải skill phù hợp khi bạn yêu cầu triển khai một tính năng của Dodo Payments. Bạn không cần nêu tên skill - chỉ cần mô tả tác vụ.

| Prompt mẫu | Skill được tải |
|----------------|------------------|
| Giúp tôi tích hợp Dodo Payments vào ứng dụng Next.js theo các best practice | `dodo-best-practices` |
| Thêm route handler checkout của Dodo Payments vào ứng dụng Hono | `framework-adapters` |
| Hướng dẫn tôi kiểm thử thanh toán và triển khai production | `testing-and-go-live` |
| Tạo checkout session cho sản phẩm SaaS của tôi | `checkout-integration` |
| Triển khai flow subscription với thời gian dùng thử miễn phí và nhiều cấp định giá | `subscription-integration` |
| Thêm checkout trong ứng dụng vào ứng dụng React Native của tôi | `mobile-checkout` |
| Thiết lập webhook handler cho các event thanh toán và subscription | `webhook-integration` |
| Thiết lập quyền sử dụng credit và khấu trừ credit theo meter cho sản phẩm AI của tôi | `credit-based-billing` |
| Thêm usage-based billing để theo dõi các lệnh gọi API cho sản phẩm AI của tôi | `usage-based-billing` |
| Triển khai xác thực license key cho ứng dụng desktop của tôi | `license-keys` |
| Tạo catalog sản phẩm với add-on và định giá theo cấp | `product-catalog-management` |
| Thêm mã khuyến mãi giảm 20% trong ba chu kỳ thanh toán đầu tiên | `discounts-and-promotions` |
| Hiển thị giá theo tiền tệ địa phương của khách truy cập với purchasing power parity | `localized-pricing` |
| Cung cấp cho khách hàng portal self-service để quản lý phương thức thanh toán | `customer-management` |
| Phát hành refund một phần và thu hồi quyền truy cập khi dispute được mở | `refunds-and-disputes` |
| Thêm trang định giá bằng các component của BillingSDK | `billing-sdk` |
| Tích hợp Dodo Payments vào thiết lập Better Auth của tôi | `better-auth-integration` |

## Skill hoạt động như thế nào

Skill cung cấp cho AI coding assistant của bạn:

1. **Kiến thức quy trình** - Hướng dẫn từng bước để triển khai tính năng
2. **Mẫu code** - Các pattern và snippet code sẵn sàng cho production
3. **Best practice** - Các phương pháp được khuyến nghị về bảo mật, xử lý lỗi và UX
4. **Nhận biết context** - Hiểu cách các tính năng khác nhau của Dodo Payments hoạt động cùng nhau

Khi bạn yêu cầu AI coding assistant triển khai một tính năng, assistant sẽ sử dụng skill phù hợp để:
- Hiểu phương pháp triển khai chính xác
- Tạo code chính xác và hoạt động được
- Tuân thủ các quy ước của Dodo Payments
- Xử lý đúng các trường hợp biên và lỗi

<Note>
Skill bổ trợ cho [MCP Server](/developer-resources/mcp-server) và [Sentra](/developer-resources/sentra). Sử dụng MCP cho các thao tác API, Sentra cho tích hợp có hướng dẫn và Skill để nâng cao khả năng của AI coding assistant.
</Note>
