## Overview

Agent Skills are reusable capabilities that enhance what AI coding assistants can do when working with Dodo Payments. They provide procedural knowledge and best practices that help agents accomplish specific tasks more effectively - from integrating checkout flows to setting up usage-based billing.

<Info>
**Think of skills as plugins for your AI assistant.** They teach your agent how to implement Dodo Payments features correctly, following our recommended patterns and best practices.
</Info>

Skills hoạt động với mọi AI agent hỗ trợ skills protocol, bao gồm:
- **Claude Code** - trợ lý lập trình CLI của Anthropic
- **Codex CLI** - coding agent CLI của OpenAI
- **Cursor** - trình soạn thảo mã ưu tiên AI
- **VS Code / GitHub Copilot** - thông qua Agent Plugin
- **Kiro** - tải skills dưới dạng Power
- **OpenCode** - coding agent AI nguồn mở
- **Các client khác** - mọi agent hỗ trợ skills protocol

<Note>
**Gemini CLI là ngoại lệ.** Công cụ này không có agent-skill primitive, vì vậy skills không khả dụng ở đó — chỉ có hai [MCP servers](/developer-resources/mcp-server).
</Note>

## Cài đặt

Chọn phương thức cài đặt phù hợp dựa trên trợ lý lập trình AI của bạn.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Nếu bạn sử dụng Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro hoặc OpenCode, [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) sẽ cài đặt cả mười bảy skills cùng hai MCP servers chỉ trong một bước. Skills được tự động tải khi agent phát hiện một tác vụ phù hợp.

Xem [hướng dẫn AI Coding Agents](/developer-resources/build-with-ai-coding-agents) để biết lệnh cài đặt cho từng agent.
</Tab>

<Tab title="Skills CLI">
Cài đặt skills bằng universal skills CLI hoạt động với mọi agent tương thích MCP:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Hoặc cài đặt từng skill theo nhu cầu:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/dodo-best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
Chỉ cài đặt những skills bạn cần để agent tập trung hơn và giảm chi phí context.
</Tip>
</Tab>

<Tab title="Claude Code">

</Tab>

<Tab title="OpenCode">
OpenCode tải skills từ các thư mục mà bạn chỉ định. Công cụ này **không** quét các package đã cài đặt, vì vậy cần có mục `skills.paths` rõ ràng.

Sử dụng package Agent Plugin:

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

Các đường dẫn tương đối được phân giải dựa trên **thư mục project**, vì vậy package phải có trong `node_modules` của project đó. Bạn cũng có thể sử dụng đường dẫn tuyệt đối để tránh yêu cầu cài đặt cục bộ.

<Warning>
Đường dẫn skills không tồn tại sẽ bị bỏ qua **một cách im lặng** — không lỗi, không cảnh báo. Xác nhận rằng skills đã thực sự được tải:

```bash
opencode run "List every skill available to you by name."
```

Bạn sẽ thấy đủ mười bảy skill.
</Warning>
</Tab>
</Tabs>

## Sử dụng Skills

Sau khi cài đặt, trợ lý AI sẽ tự động tải skill phù hợp khi bạn yêu cầu triển khai một tính năng Dodo Payments. Bạn không cần nêu tên skill — chỉ cần mô tả tác vụ.

| Prompt mẫu | Skill được tải |
|----------------|------------------|
| Giúp tôi tích hợp Dodo Payments vào ứng dụng Next.js theo các phương pháp tốt nhất | `dodo-best-practices` |
| Thêm route handler checkout của Dodo Payments vào ứng dụng Hono | `framework-adapters` |
| Hướng dẫn tôi kiểm thử thanh toán và đưa vào hoạt động | `testing-and-go-live` |
| Tạo checkout session cho sản phẩm SaaS của tôi | `checkout-integration` |
| Triển khai quy trình subscription với free trial và nhiều pricing tier | `subscription-integration` |
| Thêm checkout trong ứng dụng vào app React Native của tôi | `mobile-checkout` |
| Thiết lập webhook handlers cho các sự kiện thanh toán và subscription | `webhook-integration` |
| Thiết lập quyền sử dụng credit và khấu trừ credit theo meter cho sản phẩm AI của tôi | `credit-based-billing` |
| Thêm usage-based billing để theo dõi các API call cho sản phẩm AI của tôi | `usage-based-billing` |
| Triển khai xác thực license key cho ứng dụng desktop của tôi | `license-keys` |
| Tạo product catalog với add-on và pricing theo tier | `product-catalog-management` |
| Thêm promo code giảm 20% cho ba billing cycle đầu tiên | `discounts-and-promotions` |
| Hiển thị giá bằng local currency của khách truy cập với purchasing power parity | `localized-pricing` |
| Cung cấp self-service portal để khách hàng quản lý payment methods | `customer-management` |
| Phát hành partial refund và thu hồi quyền truy cập khi dispute được mở | `refunds-and-disputes` |
| Thêm trang pricing bằng các component BillingSDK | `billing-sdk` |
| Tích hợp Dodo Payments vào thiết lập Better Auth của tôi | `better-auth-integration` |

## Skills hoạt động như thế nào

Skills cung cấp cho trợ lý AI của bạn:

1. **Kiến thức quy trình** - Hướng dẫn từng bước để triển khai tính năng
2. **Code template** - Các mẫu code và đoạn mã sẵn sàng cho production
3. **Best practices** - Phương pháp được đề xuất cho bảo mật, xử lý lỗi và UX
4. **Nhận biết context** - Hiểu cách các tính năng khác nhau của Dodo Payments phối hợp với nhau

Khi bạn yêu cầu trợ lý AI triển khai một tính năng, trợ lý sẽ sử dụng skill phù hợp để:
- Hiểu phương pháp triển khai chính xác
- Tạo code chính xác và hoạt động được
- Tuân thủ các quy ước của Dodo Payments
- Xử lý đúng các trường hợp đặc biệt và lỗi

<Note>
Skills bổ trợ cho [MCP Server](/developer-resources/mcp-server) và [Sentra](/developer-resources/sentra). Sử dụng MCP cho các thao tác API, Sentra cho tích hợp có hướng dẫn và Skills để nâng cao khả năng của trợ lý AI.
</Note>
