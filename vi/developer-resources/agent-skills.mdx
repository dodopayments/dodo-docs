## Tổng Quan

Kỹ Năng Đại Diện là những khả năng tái sử dụng giúp tăng cường những gì trợ lý mã hóa AI có thể làm khi làm việc với Dodo Payments. Chúng cung cấp kiến thức quy trình và các phương pháp tốt nhất giúp các đại diện thực hiện các nhiệm vụ cụ thể một cách hiệu quả hơn - từ việc tích hợp quy trình thanh toán đến thiết lập lập hóa đơn dựa trên mức sử dụng.

<Info>
**Hãy coi kỹ năng như các plugin cho trợ lý AI của bạn.** Chúng dạy đại diện của bạn cách triển khai các tính năng Dodo Payments một cách chính xác, theo các mẫu và phương pháp tốt nhất mà chúng tôi khuyến nghị.
</Info>

Các kỹ năng hoạt động với bất kỳ đại diện AI tương thích với MCP nào, bao gồm:
- **Claude Code** - Trợ lý mã hóa CLI của Anthropic
- **OpenCode** - Đại diện mã hóa AI mã nguồn mở
- **Cursor** - Trình biên tập mã đầu tiên AI
- **Các khách hàng MCP khác** - Bất kỳ đại diện nào hỗ trợ giao thức kỹ năng

## Cài Đặt

Chọn phương pháp cài đặt ưa thích của bạn dựa trên trợ lý mã hóa AI của bạn.

<Tabs>
<Tab title="Skills CLI">
Cài đặt các kỹ năng bằng cách sử dụng CLI kỹ năng toàn cầu hoạt động với bất kỳ đại diện tương thích với MCP nào:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Hoặc cài đặt các kỹ năng riêng lẻ khi cần:

```bash
# Best practices guide
npx skills add dodopayments/skills/dodo-best-practices

# Webhook integration
npx skills add dodopayments/skills/webhook-integration

# Subscription billing
npx skills add dodopayments/skills/subscription-integration

# Checkout flows
npx skills add dodopayments/skills/checkout-integration

# Usage-based billing
npx skills add dodopayments/skills/usage-based-billing

# BillingSDK components
npx skills add dodopayments/skills/billing-sdk

# License key management
npx skills add dodopayments/skills/license-keys
```

<Tip>
Chỉ cài đặt những kỹ năng bạn cần để giữ cho đại diện của bạn tập trung và giảm thiểu gánh nặng ngữ cảnh.
</Tip>
</Tab>

<Tab title="Claude Code">
Thêm thị trường kỹ năng thanh toán Dodo vào Claude Code:

```bash
/plugin marketplace add dodopayments/skills
```

Sau đó cài đặt các plugin riêng lẻ:

```bash
# Install best practices
/plugin install dodo-best-practices

# Install webhook integration
/plugin install webhook-integration

# Install subscription integration
/plugin install subscription-integration

# Install checkout integration
/plugin install checkout-integration

# Install usage-based billing
/plugin install usage-based-billing

# Install BillingSDK
/plugin install billing-sdk

# Install license keys
/plugin install license-keys
```

</Tab>

<Tab title="OpenCode">
Các kỹ năng tự động có sẵn khi được cấu hình trong cài đặt OpenCode của bạn. Thêm kho lưu trữ kỹ năng Dodo Payments vào cấu hình của bạn:

```json
{
  "skills": {
    "repositories": [
      "dodopayments/skills"
    ]
  }
}
```

</Tab>
</Tabs>

## Sử Dụng Kỹ Năng

Một khi được cài đặt, trợ lý AI của bạn có thể tận dụng những kỹ năng này khi bạn yêu cầu nó triển khai các tính năng Dodo Payments. Dưới đây là một số ví dụ về lời nhắc:

### Các Phương Pháp Tốt Nhất

```
Help me integrate Dodo Payments into my Next.js app following best practices
```

### Webhooks

```
Set up webhook handlers for payment and subscription events
```

### Đăng Ký

```
Implement a subscription flow with free trial and multiple pricing tiers
```

### Thanh Toán

```
Create a checkout session for my SaaS product
```

### Lập Hóa Đơn Dựa Trên Mức Sử Dụng

```
Add usage-based billing to track API calls for my AI product
```

### BillingSDK

```
Add a pricing page using BillingSDK components
```

### Khóa Bản Quyền

```
Implement license key validation for my desktop app
```

## Cách Kỹ Năng Hoạt Động

Kỹ năng cung cấp cho trợ lý AI của bạn:

1. **Kiến Thức Quy Trình** - Hướng dẫn từng bước để triển khai các tính năng
2. **Mẫu Mã** - Các mẫu và đoạn mã sẵn sàng cho sản xuất
3. **Các Phương Pháp Tốt Nhất** - Các cách tiếp cận được khuyến nghị cho bảo mật, xử lý lỗi và trải nghiệm người dùng
4. **Nhận Thức Ngữ Cảnh** - Hiểu cách các tính năng Dodo Payments khác nhau hoạt động với nhau.

Khi bạn yêu cầu trợ lý AI của bạn triển khai một tính năng, nó sử dụng kỹ năng liên quan để:
- Hiểu cách triển khai chính xác
- Tạo mã chính xác, hoạt động
- Theo dõi các quy ước của Dodo Payments
- Xử lý các trường hợp và lỗi kịp thời

<Note>
Kỹ năng bổ sung cho [MCP Server](/developer-resources/mcp-server) và [Sentra](/developer-resources/sentra). Sử dụng MCP cho các hoạt động API, Sentra cho tích hợp hướng dẫn và Kỹ năng để nâng cao khả năng của trợ lý AI.
</Note>
