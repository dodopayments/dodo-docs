Rust SDK cung cấp khả năng truy cập tiện lợi, ưu tiên bất đồng bộ đến REST API của Dodo Payments từ các ứng dụng viết bằng Rust. Nó cung cấp các yêu cầu và phản hồi định kiểu mạnh mẽ, công cụ phân trang tích hợp sẵn, và khả năng cấu hình thời gian chờ và môi trường.

## Cài đặt

Thêm SDK vào dự án của bạn với Cargo:

```bash
cargo add dodopayments
```

Hoặc thêm nó vào `Cargo.toml` của bạn thủ công:

```toml
[dependencies]
dodopayments = "1.106.0"
tokio = { version = "1", features = ["full"] }
serde_json = "1"
futures = "0.3" # required for streaming paginated results
```

<Info>
SDK yêu cầu Rust 1.75 hoặc mới hơn, tận dụng các tính năng bất đồng bộ hiện đại để đạt hiệu suất tối ưu.
</Info>

## Bắt đầu nhanh

Client đọc khóa API của bạn từ biến môi trường `DODO_PAYMENTS_API_KEY` theo mặc định. Khởi tạo client và tạo phiên checkout đầu tiên của bạn:

```rust
use dodopayments::Client;

#[tokio::main]
async fn main() -> dodopayments::Result<()> {
    let client = Client::from_env()?;

    let result = client
        .checkout_sessions()
        .create()
        .body(dodopayments::models::CheckoutSessionsCreateParams {
            product_cart: Some(vec![dodopayments::models::ProductItemReq {
                product_id: "product_id".to_string(),
                quantity: 1,
                addons: None,
                amount: None,
                credit_entitlements: None,
            }]),
            ..Default::default()
        })
        .await?;

    println!("{result:?}");
    Ok(())
}
```

<Warning>
Luôn lưu trữ khóa API của bạn một cách an toàn bằng cách sử dụng biến môi trường. Không bao giờ mã hóa cứng chúng trong mã nguồn của bạn.
</Warning>

## Cấu hình

### Biến môi trường

Theo mặc định, `Client::from_env()` đọc khóa API của bạn từ biến môi trường `DODO_PAYMENTS_API_KEY` và sử dụng URL nền tảng mặc định trừ khi bạn đặt `DODO_PAYMENTS_BASE_URL`:

```bash
export DODO_PAYMENTS_API_KEY="your_api_key"
export DODO_PAYMENTS_BASE_URL="https://test.dodopayments.com" # optional
```

Bạn cũng có thể cấu hình client rõ ràng. `Client::new` trả về một `Result`, vì vậy hãy mở nó ra với `?` bên trong một hàm trả về `dodopayments::Result`:

```rust
use dodopayments::{Client, ClientConfig};

#[tokio::main]
async fn main() -> dodopayments::Result<()> {
    let client = Client::new(
        ClientConfig::new("https://live.dodopayments.com").with_api_key("My API Key"),
    )?;
    println!("{}", client.base_url());
    Ok(())
}
```

### Môi trường

| Name        | Base URL                          |
| ----------- | --------------------------------- |
| `live_mode` | `https://live.dodopayments.com`   |
| `test_mode` | `https://test.dodopayments.com`   |

URL nền tảng mặc định là `https://live.dodopayments.com`. Chọn một môi trường khác với enum `Environment` thay vì mã hóa URL:

```rust
use dodopayments::{Client, ClientConfig, Environment};

let client = Client::new(
    ClientConfig::from_environment(Environment::TestMode).with_api_key("My API Key"),
)?;
```

Để tiếp tục đọc khóa API từ `DODO_PAYMENTS_API_KEY` qua `from_env()` trong khi nhắm mục tiêu đến một môi trường không mặc định, ghi đè nó trên cấu hình:

```rust
use dodopayments::{Client, ClientConfig, Environment};

let client = Client::new(ClientConfig::from_env()?.with_environment(Environment::TestMode))?;
```

### Thời gian chờ

Thời gian chờ mặc định của yêu cầu là 30 giây. Ghi đè nó theo từng client:

```rust
use std::time::Duration;
use dodopayments::{Client, ClientConfig};

let client = Client::new(
    ClientConfig::new("https://live.dodopayments.com")
        .with_api_key("My API Key")
        .with_timeout(Duration::from_secs(60)),
)?;
```

## Hoạt động phổ biến

### Tạo phiên Checkout

Tạo một phiên checkout:

```rust
let session = client
    .checkout_sessions()
    .create()
    .body(dodopayments::models::CheckoutSessionsCreateParams {
        product_cart: Some(vec![dodopayments::models::ProductItemReq {
            product_id: "pdt_123".to_string(),
            quantity: 1,
            addons: None,
            amount: None,
            credit_entitlements: None,
        }]),
        return_url: Some("https://yourdomain.com/return".to_string()),
        ..Default::default()
    })
    .await?;

println!("{session:?}");
```

### Quản lý Khách hàng

Tạo và lấy thông tin khách hàng:

```rust
// Create a customer
let customer = client
    .customers()
    .create()
    .body(dodopayments::models::CustomerCreateParams {
        email: "customer@example.com".to_string(),
        name: "John Doe".to_string(),
        ..Default::default()
    })
    .await?;

// Retrieve a customer
let customer = client
    .customers()
    .retrieve()
    .customer_id("cus_123")
    .await?;

println!("{customer:?}");
```

### Xử lý Đăng ký

Tạo và quản lý đăng ký định kỳ:

<Warning>
`POST /subscriptions` (phương thức `subscriptions.create` của SDK) đã deprecated. Phương thức này vẫn hoạt động đối với các tích hợp hiện có, nhưng các tích hợp mới nên tạo subscription thông qua [Checkout Session](/developer-resources/checkout-session).
</Warning>

```rust
let subscription = client
    .subscriptions()
    .create()
    .body(dodopayments::models::SubscriptionCreateParams {
        billing: dodopayments::models::BillingAddress {
            country: "US".to_string(),
            city: "San Francisco".to_string(),
            state: "CA".to_string(),
            street: "1 Market St".to_string(),
            zipcode: "94105".to_string(),
        },
        customer: dodopayments::models::CustomerRequest::AttachExisting(
            dodopayments::models::AttachExistingCustomer {
                customer_id: "cus_123".to_string(),
            },
        ),
        product_id: "pdt_456".to_string(),
        quantity: 1,
        ..Default::default()
    })
    .await?;

println!("{subscription:?}");
```

<Info>
`billing` yêu cầu tối thiểu mã `country` ISO gồm hai chữ cái. `customer` là một enum `CustomerRequest` — truyền `AttachExisting` cho customer hiện có hoặc `New` cho customer mới. Các field số tiền như `product_price` được tính theo đơn vị tiền tệ nhỏ nhất (ví dụ: `2500` = 25,00 USD).
</Info>

## Thanh toán theo mức sử dụng

### Tiếp nhận sự kiện sử dụng

Theo dõi các sự kiện tùy chỉnh:

```rust
let response = client
    .usage_events()
    .ingest()
    .body(dodopayments::models::UsageEventsIngestParams {
        events: Some(vec![dodopayments::models::EventInput {
            customer_id: "cus_abc123".to_string(),
            event_id: "api_call_12345".to_string(),
            event_name: "api_request".to_string(),
            metadata: None,
            timestamp: None,
        }]),
        ..Default::default()
    })
    .await?;

println!("{response:?}");
```

### Liệt kê sự kiện sử dụng

```rust
let events = client
    .usage_events()
    .list()
    .query(serde_json::json!({
        "customer_id": "cus_abc123",
        "event_name": "api_request",
    }))
    .await?;

for event in &events.items {
    println!("{event:?}");
}
```

## Phân trang

Các endpoint list trả về một trang có kiểu, trong đó field `items` chứa các kết quả của trang hiện tại. Stream mọi item trên tất cả các trang bằng `into_stream`:

```rust
use futures::StreamExt;

let mut items = Box::pin(
    client
        .payments()
        .list()
        .query(serde_json::json!({}))
        .await?
        .into_stream(),
);

while let Some(item) = items.next().await {
    let item = item?;
    println!("{item:?}");
}
```

Hoặc chuyển từng trang một bằng `get_next_page`:

```rust
let mut page = client
    .payments()
    .list()
    .query(serde_json::json!({}))
    .await?;

loop {
    for item in &page.items {
        println!("{item:?}");
    }
    match page.get_next_page().await? {
        Some(next) => page = next,
        None => break,
    }
}
```

## Xử lý lỗi

Mọi method đều trả về một `dodopayments::Result<T>`. Các lỗi được biểu diễn bằng enum `dodopayments::Error`. Hãy match trên enum này để xử lý riêng các lỗi API và lỗi transport:

```rust
let result = client
    .checkout_sessions()
    .create()
    .body(dodopayments::models::CheckoutSessionsCreateParams {
        product_cart: Some(vec![dodopayments::models::ProductItemReq {
            product_id: "product_id".to_string(),
            quantity: 1,
            addons: None,
            amount: None,
            credit_entitlements: None,
        }]),
        ..Default::default()
    })
    .await;

match result {
    Ok(value) => println!("{value:?}"),
    Err(dodopayments::Error::Api { status, message }) => {
        eprintln!("API returned {status}: {message}");
    }
    Err(err) => eprintln!("request failed: {err}"),
}
```

## Endpoint chưa được ghi nhận

Để gọi một endpoint chưa được cung cấp dưới dạng method có kiểu, hãy sử dụng builder cấp thấp `request`, builder này áp dụng authentication và base URL:

```rust
let response = client
    .request(reqwest::Method::GET, "/some/path")
    .send()
    .await?;
```
