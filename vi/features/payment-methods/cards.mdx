Thanh toán bằng thẻ là nền tảng của thanh toán trực tuyến, được chấp nhận trên toàn cầu và được khách hàng tin tưởng. Dodo Payments hỗ trợ tất cả các mạng thẻ lớn với bảo mật gian lận tích hợp và tuân thủ PCI.

## Cấu Hình

Sử dụng các giá trị này trong `allowed_payment_method_types`:

| Loại | Mô tả |
| :--- | :---------- |
| `credit` | Tất cả thẻ tín dụng |
| `debit` | Tất cả thẻ ghi nợ |

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

<Tip>
Bao gồm cả `credit` và `debit` trừ khi bạn có lý do cụ thể để loại bỏ một trong số đó. Nhiều khách hàng thích thẻ ghi nợ và thường có phí thấp hơn.
</Tip>

## Xác Thực 3D Secure

3D Secure (3DS) thêm một lớp xác thực làm giảm gian lận và chargeback bằng cách xác minh danh tính của chủ thẻ.

### Khi Nào 3DS Bị Kích Hoạt

3DS được kích hoạt tự động khi:
- Được yêu cầu bởi mạng thẻ
- Được yêu cầu bởi quy định khu vực (ví dụ: PSD2 ở châu Âu)
- Giao dịch bị đánh dấu là rủi ro cao

### Buộc 3DS

Bạn có thể yêu cầu 3DS cho tất cả giao dịch:

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  force_3ds: true,
  return_url: 'https://example.com/success'
});
```

<Note>
Kích hoạt 3DS cho tất cả giao dịch giảm thiểu gian lận nhưng có thể làm giảm một chút tỷ lệ chuyển đổi vì một số khách hàng từ bỏ trong quá trình xác thực.
</Note>

### Kích Hoạt Thẻ Đã Lưu

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  show_saved_payment_methods: true,
  customer: { customer_id: 'cus_existing_123' },
  return_url: 'https://example.com/success'
});
```

### Mua Hàng Bằng Một Cú Nhấp

```javascript
// Get customer's saved payment methods
const methods = await client.customers.getPaymentMethods('cus_123');

// Use saved card for instant checkout
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  customer: { customer_id: 'cus_123' },
  payment_method_id: methods[0].payment_method_id,
  confirm: true,
  return_url: 'https://example.com/success'
});
```
