## Tiền tệ Thích ứng

Tiền tệ Thích ứng cho phép khách hàng thanh toán bằng đồng tiền địa phương mà họ ưa thích, cải thiện độ tin cậy và tỷ lệ chuyển đổi.

### Cách Hoạt Động

1. **Bật**: Bật Tiền tệ Thích ứng từ Cài đặt Doanh nghiệp của bạn
2. **Chọn**: Khách hàng có thể chuyển đổi tiền tệ trực tiếp trên trang thanh toán
3. **Chuyển đổi**: Giá cả được chuyển đổi động sử dụng tỷ giá FX theo thời gian thực
4. **Hiển thị**: Số tiền phải trả cuối cùng được hiển thị một cách minh bạch trước khi thanh toán

## Tính Thuế Tự Động

Thuế được tính tự động dựa trên vị trí thanh toán của khách hàng, đảm bảo tuân thủ các yêu cầu về GST, VAT và thuế bán hàng mà không cần cài đặt thủ công.

### Cách Tính Thuế Hoạt Động

<Steps>
<Step title="Phát Hiện Vị Trí">
  Các quy tắc thuế được áp dụng dựa trên quốc gia của khách hàng (và vùng nếu cần).
</Step>

<Step title="Cập Nhật Động">
  Số tiền thuế được cập nhật tự động khi: 
  - Thay đổi quốc gia 
  - Cập nhật địa chỉ
</Step>

<Step title="Hiển Thị Minh Bạch">
  Phân tích thuế cuối cùng được hiển thị rõ ràng trước khi thanh toán.
</Step>
</Steps>

<Tip>
Tính thuế hoàn toàn tự động. Không cần cấu hình thủ công cho hàng hóa kỹ thuật số tiêu chuẩn và sản phẩm SaaS.
</Tip>

## Hỗ Trợ Mã Số Thuế Doanh Nghiệp

Đối với các doanh nghiệp đã đăng ký, trang thanh toán cho phép khách hàng nhập Mã Số Thuế Doanh Nghiệp của họ (ví dụ: số VAT/GST).

### Điều Gì Xảy Ra Khi Nhập Mã Số Thuế

- Tính đủ điều kiện thuế được xác thực theo thời gian thực
- Các miễn trừ thuế áp dụng hoặc các quy tắc chuyển giao ngược được áp dụng
- Số tiền thuế được cập nhật ngay lập tức trên trang thanh toán

## Mã Giảm Giá

Khách hàng có thể áp dụng mã giảm giá hoặc khuyến mại mà bạn đã tạo trong bảng điều khiển trực tiếp trên trang thanh toán.

### Trải Nghiệm Thanh Toán

1. Khách hàng nhập mã giảm giá
2. Giảm giá được xác thực ngay lập tức
3. Giá đã cập nhật và tiết kiệm được hiển thị rõ ràng

<Frame>
  <img src="/images/checkout/c4.png" alt="Nhập mã giảm giá trên trang thanh toán" style={{ width: '70%' }}/>
</Frame>

### Tích Hợp API

Áp dụng mã giảm giá trước hoặc kích hoạt trường nhập mã giảm giá:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  discount_code: 'WELCOME20', // Pre-apply a code
  feature_flags: {
    allow_discount_code: true // Show discount input field
  },
  return_url: 'https://yoursite.com/return'
});
```

## Thu Thập Địa Chỉ Thông Minh

Trang thanh toán hỗ trợ việc nhập địa chỉ linh hoạt để hoàn thành nhanh chóng.

### Các Tùy Chọn Có Sẵn

| Tùy Chọn | Mô Tả |
|--------|-------------|
| **Tự Động Điền Địa Chỉ Google** | Lựa chọn nhanh với tự động hoàn tất |
| **Nhập Thủ Công** | Toàn quyền kiểm soát cho các địa chỉ đầy đủ |
| **Lựa Chọn Quốc Gia** | Đẩy lùi logic thuế và tuân thủ |

<Tip>
Việc thu thập địa chỉ cân bằng giữa tốc độ, độ chính xác và phạm vi toàn cầu để tối đa hóa chuyển đổi trong khi đảm bảo tuân thủ.
</Tip>

## Trường Tùy Chỉnh

Thu thập thông tin bổ sung từ khách hàng trong quá trình thanh toán bằng cách định nghĩa các trường biểu mẫu tùy chỉnh. Điều này hữu ích cho việc thu thập dữ liệu như tên công ty, kích thước đội nhóm, nguồn giới thiệu hoặc bất kỳ thông tin cụ thể của doanh nghiệp nào.

### Các Loại Trường Có Sẵn

| Loại | Mô Tả |
|------|-------------|
| `text` | Nhập văn bản một dòng |
| `number` | Nhập số |
| `email` | Địa chỉ email với xác thực |
| `url` | URL với xác thực |
| `date` | Bộ chọn ngày |
| `dropdown` | Chọn từ các tùy chọn đã định nghĩa trước |
| `boolean` | Bật/Tắt Có/Không |

### Ví Dụ

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Các phản hồi của khách hàng sẽ tự động được bao gồm trong các payload webhook (`payment.succeeded`, `subscription.created`) và phản hồi API qua mảng `custom_field_responses`. Bạn có thể định nghĩa tối đa 5 trường tùy chỉnh cho mỗi phiên thanh toán.
</Info>

</Info>

## Thanh Toán Bộ Sưu Tập

Bộ sưu tập sản phẩm cho phép trải nghiệm thanh toán thống nhất nơi khách hàng có thể xem và chọn từ nhiều sản phẩm liên quan (ví dụ: các kế hoạch Starter, Pro, Enterprise) trong một lần thanh toán duy nhất.

### Cách Hoạt Động

1. **Tất cả sản phẩm được hiển thị**: Khách hàng thấy tất cả các sản phẩm hoạt động trong bộ sưu tập
2. **Sản phẩm đầu tiên được chọn trước**: Sản phẩm đầu tiên trong bộ sưu tập tự động được chọn
3. **So sánh các tùy chọn**: Khách hàng có thể so sánh giá cả và tính năng trước khi chọn
4. **Lựa chọn đơn**: Sau khi chọn một sản phẩm, thanh toán sẽ tiếp tục với quy trình thanh toán tiêu chuẩn

### Tạo Thanh Toán Bộ Sưu Tập

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
Khi sử dụng `product_collection_id`, hãy truyền một mảng `product_cart` trống. Mã giảm giá không thể được áp dụng trước ở lần tạo phiên.
</Warning>

## Cấu Hình Phiên Thanh Toán

Kiểm soát hành vi thanh toán bằng cách sử dụng API Phiên Thanh Toán:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_code: 'PROMO10',
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
Sau khi thanh toán, khách hàng sẽ được chuyển hướng đến `return_url` với các tham số truy vấn được thêm tự động -- bao gồm `payment_id` hoặc `subscription_id`, `status`, `email`, và `license_key` (nếu có). Xem [hướng dẫn Phiên Thanh Toán](/developer-resources/checkout-session#request-body) để biết danh sách đầy đủ.
</Info>

## Tùy Chỉnh Giao Diện Thanh Toán

Tùy chỉnh giao diện trang thanh toán để phù hợp với thương hiệu của bạn bằng cách sử dụng tham số `customization.theme_config` khi tạo phiên thanh toán thông qua API. Cấu hình màu sắc, phông chữ, bán kính viền và văn bản nút cho cả chế độ sáng và tối.

<Frame>
  <img src="/images/checkout/theme-example.png" alt="Trang thanh toán tùy chỉnh"/>
</Frame>

<Info>
Phần này đề cập đến cấu hình giao diện với **API phía máy chủ** bằng cách sử dụng `customization.theme_config`. Nếu bạn đang sử dụng **SDK Thanh Toán** (overlay hoặc inline), hãy xem các phần tùy chỉnh giao diện trong [Thanh Toán Overlay](/developer-resources/overlay-checkout#theme-customization) hoặc [Thanh Toán Inline](/developer-resources/inline-checkout#theme-customization) sử dụng các thuộc tính camelCase (ví dụ: `bgPrimary` thay vì `bg_primary`).
</Info>

### Tùy Chọn Cấu Hình Giao Diện

| Thuộc Tính | Mô Tả |
|----------|-------------|
| `light` | Cấu hình màu sắc cho chế độ sáng |
| `dark` | Cấu hình màu sắc cho chế độ tối |
| `font_primary_url` | URL cho phông chữ chính |
| `font_secondary_url` | URL cho phông chữ phụ |
| `font_size` | Kích thước phông chữ: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `font_weight` | Trọng số phông chữ: `normal`, `medium`, `bold`, `extraBold` |
| `radius` | Bán kính viền cho các phần tử UI (ví dụ: `4px`, `0.5rem`, `8px`) |
| `pay_button_text` | Văn bản tùy chỉnh cho nút thanh toán (ví dụ: "Hoàn Tất Mua Hàng", "Đăng Ký Ngay") |

### Cấu Hình Màu Sắc (Chế Độ Sáng/Tối)

Mỗi chế độ (`light` và `dark`) hỗ trợ các thuộc tính màu sắc sau:

| Thuộc Tính | Mô Tả |
|----------|-------------|
| `bg_primary` | Màu nền chính |
| `bg_secondary` | Màu nền phụ |
| `text_primary` | Màu chữ chính |
| `text_secondary` | Màu chữ phụ |
| `text_placeholder` | Màu văn bản chỗ trống |
| `text_error` | Màu văn bản lỗi |
| `text_success` | Màu văn bản thành công |
| `border_primary` | Màu viền chính |
| `border_secondary` | Màu viền phụ |
| `button_primary` | Màu nền nút chính |
| `button_primary_hover` | Màu nút chính khi di chuột |
| `button_secondary` | Màu nền nút phụ |
| `button_secondary_hover` | Màu nút phụ khi di chuột |
| `button_text_primary` | Màu chữ nút chính |
| `button_text_secondary` | Màu chữ nút phụ |
| `input_focus_border` | Màu viền khi có tiêu điểm vào nhập liệu |

<Info>
Tất cả các trường màu sắc chấp nhận các định dạng màu sắc CSS tiêu chuẩn:
- Hex: `#fff`, `#ffffff`, `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`, `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`, `hsla(120, 100%, 50%, 0.5)`
- Màu được đặt tên: `red`, `blue`, `transparent`
</Info>

### Ví Dụ

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
Bạn không cần chỉ định tất cả các thuộc tính màu sắc. Bất kỳ thuộc tính nào không được chỉ định sẽ sử dụng các giá trị mặc định của giao diện.
</Tip>
