## What is Dodo Payments?

Dodo Payments is the **all-in-one engine** to launch, scale, and monetize worldwide. Designed for the new generation of digital SaaS and AI products, we handle everything from **payments to billing to distribution** - all without extra engineering.

<Info>
**Built for SaaS and AI Products**: Handle one-time payments, subscriptions, credits, seats, tokens, or any usage metric with our optimized billing infrastructure.
</Info>

<Tip>
  <strong>Meet Sentra: Your AI-powered billing assistant</strong><br/>
  Sentra is an AI agent that integrates, analyzes, and acts on billing and payments directly in your IDE. Ask questions, build integrations, or plan billing architectures - all by describing what you want.
  <a href="/developer-resources/sentra">
    Get started with Sentra &rarr;

</Tip>

## Quick Start Guide

Khởi động và chạy với Dodo Payments chỉ trong vài bước.

<AccordionGroup>
<Accordion title="For Humans">
  Thích tự lái quá trình tích hợp? Các bước dưới đây hướng dẫn bạn tạo tài khoản, thêm sản phẩm và lựa chọn phương pháp tích hợp trong chưa đầy năm phút. Không cần mã cho con đường không mã; Mẫu SDK có sẵn ở mọi ngôn ngữ chính nếu bạn muốn.

  Nếu bạn thích để trợ lý mã hóa AI làm phần nặng nhọc - bộ khung tích hợp, trình xử lý webhook, luồng đăng ký - hãy cài đặt **[Sentra](/developer-resources/sentra)**, trợ lý thanh toán AI của chúng tôi cho VS Code, Cursor và Windsurf. Mô tả những gì bạn muốn; Sentra lên kế hoạch, dựng khung và chuyển giao nó.
</Accordion>

<Accordion title="For AI Agents">
  Dodo Payments được xây dựng cho các quy trình làm việc gốc tác nhân. Nếu bạn là một LLM đang đọc điều này - hoặc một nhà phát triển đang cấu hình một - hãy bắt đầu từ đây.

  **Cài đặt**. Đối với Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro hoặc OpenCode, [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) kết nối cả hai MCP servers và tất cả skills chỉ trong một bước. Gemini CLI chỉ nhận MCP servers. Xem [hướng dẫn AI Coding Agents](/developer-resources/build-with-ai-coding-agents) để biết các lệnh cài đặt cho từng agent.

  **Khám phá**. Danh mục tài liệu đầy đủ có tại [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt), và mọi trang tài liệu đều có sẵn dưới định dạng markdown bằng cách thêm `.md` vào URL của nó (ví dụ: `/api-reference/introduction.md`).

  **Kết nối**. Hai máy chủ MCP cung cấp cho các agent quyền truy cập trực tiếp vào nền tảng:

  - **[Dodo Knowledge MCP](/developer-resources/mcp-server#dodo-knowledge-mcp)** - tìm kiếm ngữ nghĩa trên toàn bộ tài liệu Dodo
  - **[Dodo Payments MCP](/developer-resources/mcp-server)** - thực hiện các thao tác API (tạo thanh toán, quản lý đăng ký, xử lý hoàn tiền)

  Xem [hướng dẫn máy chủ MCP](/developer-resources/mcp-server) để biết cấu hình khách hàng đầy đủ.

  **Mở rộng**. Cài đặt [Dodo Payments Skills](/developer-resources/agent-skills) chính thức để đào tạo agent xử lý thanh toán, đăng ký, thanh toán theo mức sử dụng, thanh toán bằng tín dụng, các webhook, và nhiều hơn nữa:

  ```bash
  npx skills add dodopayments/skills
  ```

  Hoạt động với Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro, OpenCode và mọi agent hỗ trợ skills protocol.
</Accordion>
</AccordionGroup>

<Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
Thêm cả hai máy chủ vào cấu hình MCP của bạn (`~/.cursor/mcp.json` hoặc cấu hình Claude Desktop):

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

<Info>
Yêu cầu Node.js 18+. Xem [tài liệu về máy chủ MCP](/developer-resources/mcp-server) để biết hướng dẫn cấu hình chi tiết cho tất cả các khách hàng được hỗ trợ.
