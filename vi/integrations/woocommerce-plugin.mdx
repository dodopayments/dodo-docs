## Giới thiệu

Plugin Dodo Payments WooCommerce cung cấp một tích hợp liền mạch với cửa hàng của bạn, cho phép bạn chấp nhận thanh toán qua nhiều phương thức bao gồm UPI, thẻ, ngân hàng trực tuyến và ví điện tử. Hướng dẫn toàn diện này sẽ hướng dẫn bạn qua quy trình cài đặt và cấu hình.

## Hướng dẫn cài đặt từng bước

1. Tải xuống phiên bản zip mới nhất của plugin thanh toán WooCommerce.

    <Card title="Download Plugin" icon="download" href="https://github.com/dodopayments/dodo-woocommerce/releases">
    Tải phiên bản mới nhất của plugin WooCommerce của chúng tôi
    </Card>

    Bạn cũng có thể cài đặt trực tiếp từ thư mục plugin của WordPress:
    
    <Card title="WordPress Plugin Directory" icon="wordpress" href="https://wordpress.org/plugins/dodo-payments-for-woocommerce/">
    Cài đặt Dodo Payments cho WooCommerce từ WordPress.org
    </Card>

2. Đăng nhập vào trang web WordPress của bạn với tư cách quản trị viên (chúng tôi giả định rằng bạn đã cài đặt WooCommerce)
3. Điều hướng đến **Plugins → Add New Plugin**
    
    <Frame>
        <img src="/images/woocommerce/1.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
4. Nhấp vào nút **Upload Plugin** và một hộp thoại chọn tệp sẽ xuất hiện

    <Frame>
        <img src="/images/woocommerce/2.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
    <Frame>
        <img src="/images/woocommerce/3.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
5. Nhấp vào **Browse…** và chọn tệp zip bạn đã tải về
6. Nhấp vào nút **Install Now** để bắt đầu quá trình cài đặt
    
    <Frame>
        <img src="/images/woocommerce/4.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
7. Sau khi cài đặt hoàn tất, nhấp vào **Activate Plugin** hoặc kích hoạt nó từ phần **Installed Plugins**
    
    <Frame>

8. Plugin hiện đã được cài đặt, nhưng vẫn cần cấu hình. Tiếp tục với hướng dẫn thiết lập dưới đây.

## Hướng dẫn cấu hình

### Thiết lập API Keys và Webhooks

1. Điều hướng đến **WooCommerce → Settings → Payments** hoặc nhấp vào nút **Payments** trong thanh bên trái dưới mục menu WooCommerce
    
    <Frame>
        <img src="/images/woocommerce/6.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
    <Frame>
        <img src="/images/woocommerce/7.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
2. Bật nhà cung cấp thanh toán **Dodo Payments** nếu chưa được bật, sau đó nhấp vào **Manage** để cấu hình plugin
3. Bạn sẽ thấy các tùy chọn cấu hình khác nhau, mỗi tùy chọn có văn bản giải thích hữu ích. Bắt đầu bằng cách thiết lập Live API Key của bạn
    
    <Frame>
        <img src="/images/woocommerce/8.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
4. Đăng nhập vào bảng điều khiển Dodo Payments của bạn trong **Live Mode**, sau đó điều hướng đến **Dodo Payments (Live Mode) > Developer > API Keys** hoặc truy cập [liên kết trực tiếp này](https://app.dodopayments.com/developer/api-keys) và nhấp vào **Add API Key**
    
    <Frame>
        <img src="/images/woocommerce/9.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
5. Đặt tên mô tả cho API Key của bạn và nhấp **Create**
    
    <Frame>
        <img src="/images/woocommerce/10.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
6. Sao chép API Key đã tạo và dán vào trường **Live API Key** trong cài đặt plugin WooCommerce của bạn
    
    <Frame>
        <img src="/images/woocommerce/11.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
    <Frame>
        <img src="/images/woocommerce/12.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
7. Tiếp theo, thiết lập Webhook Signing Key để cho phép đồng bộ hóa trạng thái thanh toán giữa Dodo Payments và WooCommerce
8. Cuộn xuống cuối trang cài đặt plugin và sao chép URL webhook được hiển thị ở đó
    
    <Frame>
        <img src="/images/woocommerce/13.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
9. Quay lại bảng điều khiển Dodo Payments của bạn và điều hướng đến **Dodo Payments (Live Mode) > Developer > Webhooks** và nhấp **Add Webhook**
    
    <Frame>
        <img src="/images/woocommerce/14.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
10. Dán URL bạn đã sao chép ở bước 8 vào hộp thoại và nhấp **Add Webhook**
    
    <Frame>
        <img src="/images/woocommerce/15.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
11. Sau khi tạo webhook, nhấp vào biểu tượng con mắt bên cạnh **Signing Key** đã che để hiện và sao chép nó
    
    <Frame>
        <img src="/images/woocommerce/16.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
12. Dán Signing Key vào trường **Live Webhook Signing Key** trong cài đặt plugin của bạn và lưu các thay đổi
    
    <Frame>
        <img src="/images/woocommerce/17.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
13. Xem xét các cài đặt còn lại như **Global Tax Category** và **All Prices are Tax Inclusive**, vì các tùy chọn này xác định cách sản phẩm được đồng bộ hóa từ WooCommerce sang Dodo Payments. Lưu ý rằng **Test API Key** và **Test Webhook Signing Key** chỉ cần thiết nếu bạn định sử dụng Test Mode
    
    <Frame>
        <img src="/images/woocommerce/18.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>

## Tính năng chính

- **Trải nghiệm thanh toán liền mạch**: Chuyển hướng khách hàng đến một trang thanh toán an toàn, tối ưu
- **Nhiều phương thức thanh toán**: Hỗ trợ nhiều tùy chọn thanh toán địa phương và quốc tế
- **Cập nhật trạng thái theo thời gian thực**: Đồng bộ hóa trạng thái đơn hàng ngay lập tức qua webhooks
- **Lịch sử giao dịch chi tiết**: Lịch sử thanh toán toàn diện trong bảng điều khiển WooCommerce của bạn
- **Hỗ trợ đa tiền tệ**: Chấp nhận thanh toán bằng nhiều loại tiền tệ

## Khắc phục sự cố

### Vấn đề thường gặp

1. **Lỗi xử lý thanh toán**
   - Xác minh rằng các API key được cấu hình đúng
   - Đảm bảo URL webhook được thiết lập chính xác
   - Kiểm tra rằng chứng chỉ SSL của bạn hợp lệ

2. **Vấn đề đồng bộ hóa Webhook**
   - Xác nhận rằng signing key webhook khớp
   - Xem lại nhật ký máy chủ để tìm lỗi tiềm ẩn
   - Xác minh rằng máy chủ của bạn có thể nhận yêu cầu webhook đến

### Tài nguyên hỗ trợ

Để được hỗ trợ thêm:
- Liên hệ với chúng tôi tại support@dodopayments.com
- Tham khảo [tài liệu toàn diện của chúng tôi](https://docs.dodopayments.com)

## Thực hành bảo trì tốt nhất

1. Thường xuyên cập nhật plugin để vá lỗi bảo mật và các tính năng mới
2. Kiểm tra tất cả các luồng thanh toán trong chế độ sandbox trước khi xử lý giao dịch trực tiếp
3. Giữ WordPress và WooCommerce được cập nhật lên các phiên bản mới nhất
4. Thực hiện sao lưu trang web định kỳ
5. Giám sát nhật ký giao dịch để phát hiện bất kỳ hoạt động bất thường nào
6. Lưu trữ API key một cách an toàn và không bao giờ chia sẻ chúng công khai
