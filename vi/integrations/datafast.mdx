## Giới thiệu

DataFast là một công cụ phân tích ưu tiên doanh thu giúp bạn khám phá các kênh tiếp thị nào tạo ra khách hàng trả tiền. Bằng cách tích hợp Dodo Payments với DataFast, bạn có thể gán doanh thu cho các nguồn lưu lượng truy cập của mình, xác định các phân khúc khách hàng có giá trị cao và đưa ra quyết định dựa trên dữ liệu để phát triển doanh nghiệp của bạn.

<Info>
Tích hợp này yêu cầu Khóa API DataFast của bạn, có thể lấy từ [bảng điều khiển DataFast](https://datafa.st/).
</Info>

## Cách hoạt động

DataFast theo dõi khách truy cập thông qua một ID khách truy cập duy nhất được lưu trữ trong cookie. Để gán doanh thu cho các kênh tiếp thị, bạn cần:

1. **Ghi lại ID khách truy cập của DataFast** từ cookie `datafast_visitor_id` khi tạo phiên thanh toán
2. **Lưu ID khách truy cập** trong metadata thanh toán của bạn
3. **Gửi dữ liệu thanh toán đến DataFast** khi thanh toán thành công bằng API Thanh toán của họ

Điều này cho phép DataFast khớp các khoản thanh toán thành công với nguồn lưu lượng truy cập ban đầu, mang lại cho bạn sự gán doanh thu hoàn chỉnh.

## Hướng dẫn triển khai

### Bước 1: Thêm ID khách truy cập vào Siêu dữ liệu Thanh toán

Khi tạo một phiên thanh toán, hãy bắt ID khách truy cập DataFast từ cookie và bao gồm nó trong siêu dữ liệu thanh toán của bạn.

<Note>
Các ví dụ bên dưới sử dụng `POST /payments`, hiện đã **deprecated**. Tính năng này vẫn hoạt động với các tích hợp hiện có, nhưng các tích hợp mới nên sử dụng [Checkout Sessions](/developer-resources/checkout-session) (`POST /checkouts`) — `metadata` được truyền theo cùng cách.
</Note>

<CodeGroup>

```typescript Next.js
import { cookies } from 'next/headers';
import { dodopayments } from '@/lib/dodopayments';

export async function createCheckout(productId: string) {
  // Capture DataFast visitor ID from cookie
  const datafastVisitorId = cookies().get('datafast_visitor_id')?.value;

  const payment = await dodopayments.payments.create({
    product_cart: [{ product_id: productId, quantity: 1 }],
    // ... other payment configuration
    metadata: {
      datafast_visitor_id: datafastVisitorId, // Store visitor ID in metadata
    },
  });

  return payment;
}
```

```javascript Express.js
const express = require('express');
const router = express.Router();

router.post('/create-checkout', async (req, res) => {
  // Capture DataFast visitor ID from cookie
  const datafastVisitorId = req.cookies?.datafast_visitor_id;

  const payment = await dodopayments.payments.create({
    product_cart: [{ product_id: req.body.productId, quantity: 1 }],
    // ... other payment configuration
    metadata: {
      datafast_visitor_id: datafastVisitorId, // Store visitor ID in metadata
    },
  });

  res.json({ payment });
});
```


## Ví dụ về mã chuyển đổi

### Gán thuộc tính thanh toán cơ bản

```javascript basic_payment.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    // Only send to DataFast if visitor ID exists in metadata
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      webhook.payload = {
        amount: payment.total_amount / 100, // Convert from cents to dollars
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

### Xử lý các loại tiền tệ không có chữ số thập phân

Một số loại tiền tệ (như JPY) không sử dụng chữ số thập phân. Hãy điều chỉnh cách tính amount cho phù hợp:

```javascript zero_decimal.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      // Zero decimal currencies: JPY, KRW, CLP, etc.
      const zeroDecimalCurrencies = ['JPY', 'KRW', 'CLP', 'VND', 'UGX', 'MGA'];
      const isZeroDecimal = zeroDecimalCurrencies.includes(payment.currency);
      
      webhook.payload = {
        amount: isZeroDecimal 
          ? payment.total_amount // Use amount as-is for zero decimal currencies
          : payment.total_amount / 100, // Convert from cents for other currencies
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

### Thanh toán subscription

Đối với các khoản thanh toán subscription định kỳ, bạn có thể theo dõi từng khoản thanh toán:

```javascript subscription_payment.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    // Check if this is a subscription payment
    const isSubscription = payment.subscription_id !== null;
    
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      webhook.payload = {
        amount: payment.total_amount / 100,
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
        // Optional: Add subscription context
        ...(isSubscription && {
          subscription_id: payment.subscription_id,
        }),
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

## Phương pháp hay nhất

<Tip>
**Thu thập visitor ID sớm**: Lưu visitor ID của DataFast sớm nhất có thể trong quy trình checkout để đảm bảo việc attribution chính xác, ngay cả khi người dùng rời đi rồi quay lại sau đó.
</Tip>

- **Luôn bao gồm visitor ID trong metadata**: Nếu không có visitor ID, DataFast không thể attribution doanh thu cho các kênh marketing
- **Xử lý các loại tiền tệ không có chữ số thập phân**: Một số loại tiền tệ (JPY, KRW, v.v.) không sử dụng chữ số thập phân — hãy điều chỉnh cách tính amount cho phù hợp
- **Kiểm thử bằng các khoản thanh toán mẫu**: Xác minh tích hợp hoạt động chính xác trước khi đưa vào vận hành
- **Theo dõi trang tổng quan DataFast**: Kiểm tra để đảm bảo các khoản thanh toán hiển thị chính xác với attribution phù hợp
- **Sử dụng webhook retries**: Payment API của DataFast có tính idempotent, vì vậy việc retry là an toàn nếu webhook thất bại

## Khắc phục sự cố

<AccordionGroup>
<Accordion title="Payments not appearing in DataFast">
- Xác minh DataFast API key của bạn chính xác và đang hoạt động
- Kiểm tra để đảm bảo `datafast_visitor_id` được thu thập và lưu trong payment metadata
- Đảm bảo webhook transformation đang định dạng payload chính xác
- Xác minh webhook được kích hoạt cho các sự kiện `payment.succeeded`
- Kiểm tra trang tổng quan DataFast để xem có thông báo lỗi hoặc API logs nào không
</Accordion>

<Accordion title="Revenue attribution not working">
- Xác nhận tracking script của DataFast đã được cài đặt và hoạt động trên website của bạn
- Xác minh cookie `datafast_visitor_id` được thiết lập chính xác
- Kiểm tra visitor ID khớp nhau giữa thời điểm tạo checkout và hoàn tất thanh toán
- Đảm bảo bạn thu thập visitor ID trước khi tạo checkout session
- Xem lại [tài liệu Payment API](https://datafa.st/docs/payments-api) của DataFast để biết thêm hướng dẫn
</Accordion>

<Accordion title="Transformation errors">
- Xác thực cấu trúc JSON khớp với định dạng Payment API của DataFast
- Kiểm tra để đảm bảo tất cả các trường bắt buộc (`amount`, `currency`, `transaction_id`, `datafast_visitor_id`) đều có mặt
- Đảm bảo amount được chuyển đổi chính xác (chia cho 100 đối với hầu hết các loại tiền tệ, ngoại trừ các loại tiền tệ không có chữ số thập phân)
- Xác minh URL API endpoint chính xác: `https://datafa.st/api/v1/payments`
- Kiểm thử transformation bằng các webhook payload mẫu
</Accordion>

<Accordion title="Currency conversion issues">
- Đối với các loại tiền tệ không có chữ số thập phân (JPY, KRW, CLP, VND, UGX, MGA), gửi amount nguyên trạng mà không chia cho 100
- Đối với tất cả các loại tiền tệ khác, chia amount cho 100 để chuyển đổi từ cents sang đơn vị cơ sở
- Kiểm tra lại để đảm bảo mã tiền tệ khớp với định dạng ISO 4217 (ví dụ: "USD", "EUR", "JPY")
</Accordion>
</AccordionGroup>
