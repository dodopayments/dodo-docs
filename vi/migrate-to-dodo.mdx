**Chuyển từ nhà cung cấp thanh toán khác sang Dodo Payments?** Công cụ chuyển đổi của chúng tôi giúp bạn dễ dàng di chuyển **sản phẩm, khách hàng, mã giảm giá và khóa giấy phép mà không mất dữ liệu.** Quá trình này an toàn, có hướng dẫn và có thể hoàn thành trong vài phút.

Chúng tôi hiện hỗ trợ di chuyển từ **Lemon Squeezy, Stripe, Polar.sh và Paddle**.

## Bắt Đầu

Đầu tiên, cài đặt công cụ di chuyển:

```bash
npm install -g dodo-migrate
```

<Note>
Bạn cần cài đặt Node.js ≥ 18 trên máy tính.
</Note>

## Di Chuyển Dữ Liệu Của Bạn

### Nếu bạn đến từ Lemon Squeezy:

```bash
dodo-migrate lemonsqueezy
```

### Nếu bạn đến từ Stripe:

```bash
dodo-migrate stripe
```

### Nếu bạn đến từ Polar.sh:

```bash
dodo-migrate polar
```

### Nếu bạn đến từ Paddle:

```bash
dodo-migrate paddle
```

Công cụ sẽ hướng dẫn bạn từng bước. Bạn sẽ cần:
- Khóa API của nhà cung cấp của bạn (Lemon Squeezy, Stripe, Polar.sh, Paddle, v.v.)
- Khóa API Dodo Payments của bạn  
- Bạn muốn thử nghiệm trước (khuyến nghị) hay chuyển trực tiếp
- Thương hiệu Dodo Payments để di chuyển đến
- Dữ liệu nào cần di chuyển (sản phẩm, khách hàng, mã giảm giá, khóa giấy phép)

## Tại Sao Nên Sử Dụng Công Cụ Di Chuyển Của Chúng Tôi?

- **Không mất dữ liệu** - Mọi thứ được chuyển an toàn
- **Thử nghiệm trước** - Thử nghiệm trong chế độ thử nghiệm trước khi đi vào hoạt động
- **Quy trình có hướng dẫn** - Chúng tôi sẽ hướng dẫn bạn qua từng bước
- **Tiếp tục nếu cần** - Nếu có điều gì đó không ổn, bạn có thể tiếp tục từ nơi bạn đã dừng lại

## Sử Dụng Nâng Cao

Nếu bạn muốn chạy quá trình di chuyển mà không có thông báo, bạn có thể cung cấp tất cả thông tin trước:

### Di chuyển từ Lemon Squeezy:

```bash
dodo-migrate lemonsqueezy \
  --provider-api-key=lsq_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX
```

### Di chuyển từ Stripe:

```bash
dodo-migrate stripe \
  --provider-api-key=sk_test_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX \
  --migrate-types=products,coupons
```

### Di chuyển từ Polar.sh:

```bash
dodo-migrate polar \
  --provider-api-key=polar_org_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX \
  --migrate-types=products,discounts,customers,license_keys
```

### Di chuyển từ Paddle:

```bash
dodo-migrate paddle \
  --provider-api-key=paddle_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX
```

## Chuyển đổi Khóa Giấy Phép

Chuyển đổi khóa giấy phép được hỗ trợ cho **Polar.sh** và **Lemon Squeezy**. Khi bạn chọn khóa giấy phép trong lời nhắc tương tác (hoặc chuyển `license_keys` trong `--migrate-types`), công cụ sẽ nhập các khóa giấy phép hiện có của bạn vào Dodo Payments với các liên kết đúng cho khách hàng và sản phẩm.

{/* LOCKED_PATTERN_4907e9f6f7fbd509120d7a87afc829e9 */}
Chuyển đổi khóa giấy phép yêu cầu **sản phẩm và khách hàng** phải được di chuyển trong cùng một phiên. Công cụ xây dựng một ánh xạ trong bộ nhớ của ID nhà cung cấp với ID Dodo trong suốt quá trình — nếu sản phẩm hoặc khách hàng bị thiếu, khóa giấy phép không thể được liên kết đúng.
{/* LOCKED_PATTERN_176d815432e7554ac558e8631b2bc397 */}

### Những gì được di chuyển

- Chuỗi khóa giấy phép
- Giới hạn kích hoạt
- Ngày hết hạn
- Liên kết khách hàng và sản phẩm

### Những gì không được di chuyển

- **Kích hoạt khóa giấy phép** — khách hàng sẽ cần kích hoạt lại trên thiết bị của họ sau khi di chuyển
- **Khóa bị thu hồi hoặc vô hiệu hóa** — chỉ di chuyển các khóa hoạt động
- Các khóa không có sản phẩm hoặc khách hàng phù hợp sẽ bị bỏ qua và có cảnh báo

{/* LOCKED_PATTERN_317ec56569e36d0c9e56c2648890a76e */}
Khóa giấy phép trùng lặp được xử lý một cách an toàn. Nếu bạn chạy lại quá trình chuyển đổi, các khóa đã nhập sẽ được phát hiện và bỏ qua, giúp quá trình an toàn để thử lại.
{/* LOCKED_PATTERN_4dec52ce04aa8849a8a60508baae30ae */}
