**Migrando de outro provedor de pagamento para o Dodo Payments?** Nossa ferramenta de migração facilita a movimentação dos seus **produtos, clientes, códigos de desconto e chaves de licença sem perder nenhum dado.** O processo é seguro, guiado e pode ser concluído em apenas alguns minutos.

Atualmente, suportamos migrações de **Lemon Squeezy, Stripe, Polar.sh e Paddle**.

## Comece

Primeiro, instale a ferramenta de migração:

```bash
npm install -g dodo-migrate
```

<Note>
Você precisará do Node.js ≥ 18 instalado em seu computador.
</Note>

## Migre Seus Dados

### Se você está vindo do Lemon Squeezy:

```bash
dodo-migrate lemonsqueezy
```

### Se você está vindo do Stripe:

```bash
dodo-migrate stripe
```

### Se você está vindo do Polar.sh:

```bash
dodo-migrate polar
```

### Se você está vindo do Paddle:

```bash
dodo-migrate paddle
```

A ferramenta irá guiá-lo passo a passo. Você precisará de:
- A chave da API do seu provedor (Lemon Squeezy, Stripe, Polar.sh, Paddle, etc.)
- Sua chave da API do Dodo Payments  
- Se deseja testar primeiro (recomendado) ou ir ao vivo
- Para qual marca do Dodo Payments deseja migrar
- Quais dados migrar (produtos, clientes, descontos, chaves de licença)

## Por Que Usar Nossa Ferramenta de Migração?

- **Sem perda de dados** - Tudo é transferido com segurança
- **Teste primeiro** - Experimente em modo de teste antes de ir ao vivo
- **Processo guiado** - Nós o guiamos em cada etapa
- **Retome se necessário** - Se algo der errado, você pode continuar de onde parou

## Uso Avançado

Se você preferir executar a migração sem prompts, pode fornecer todos os detalhes antecipadamente:

### Migração do Lemon Squeezy:

```bash
dodo-migrate lemonsqueezy \
  --provider-api-key=lsq_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX
```

### Migração do Stripe:

```bash
dodo-migrate stripe \
  --provider-api-key=sk_test_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX \
  --migrate-types=products,coupons
```

### Migração do Polar.sh:

```bash
dodo-migrate polar \
  --provider-api-key=polar_org_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX \
  --migrate-types=products,discounts,customers,license_keys
```

### Migração do Paddle:

```bash
dodo-migrate paddle \
  --provider-api-key=paddle_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
```

## Migração de Chave de Licença

A migração de chave de licença é suportada para **Polar.sh** e **Lemon Squeezy**. Quando você seleciona as chaves de licença no prompt interativo (ou passa `license_keys` em `--migrate-types`), a ferramenta importará suas chaves de licença existentes para o Dodo Payments com as associações corretas de clientes e produtos.

{/* LOCKED_PATTERN_4907e9f6f7fbd509120d7a87afc829e9 */}
A migração de chave de licença requer que **produtos e clientes** sejam migrados na mesma sessão. A ferramenta cria um mapeamento em memória de IDs do provedor para IDs do Dodo durante a execução — se produtos ou clientes estiverem ausentes, as chaves de licença não poderão ser vinculadas corretamente.
{/* LOCKED_PATTERN_176d815432e7554ac558e8631b2bc397 */}

### O que é migrado

- Strings de chaves de licença
- Limites de ativação
- Datas de expiração
- Associações de cliente e produto

### O que não é migrado

- **Ativações de chaves de licença** — os clientes precisarão reativar em seus dispositivos após a migração
- **Chaves revogadas ou desativadas** — apenas chaves ativas são migradas
- Chaves sem produto ou cliente correspondente são ignoradas com um aviso

{/* LOCKED_PATTERN_317ec56569e36d0c9e56c2648890a76e */}
Chaves de licença duplicadas são tratadas de forma graciosa. Se você executar novamente a migração, as chaves já importadas são detectadas e ignoradas, tornando o processo seguro para tentativas.
{/* LOCKED_PATTERN_4dec52ce04aa8849a8a60508baae30ae */}
