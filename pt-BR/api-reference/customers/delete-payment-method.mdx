Remova um método de pagamento salvo da conta de um cliente. Use isso para limpar métodos de pagamento desatualizados ou indesejados.

<Warning>
Você não pode excluir um método de pagamento que esteja sendo usado por uma assinatura ativa. A API retorna `409 Conflict` com `Payment method is in use by an active subscription`. Primeiro, mova a assinatura para outro método de pagamento usando [Atualizar método de pagamento](/api-reference/subscriptions/update-payment-method) e, em seguida, exclua o método antigo.
</Warning>

Uma exclusão bem-sucedida retorna `204 No Content`.

## Casos de uso

- **Solicitação do cliente**: Remover um método de pagamento que o cliente não deseja mais manter
- **Cartões expirados**: Limpar métodos de pagamento com dados de cartão expirados
- **Segurança**: Remover imediatamente métodos de pagamento comprometidos
