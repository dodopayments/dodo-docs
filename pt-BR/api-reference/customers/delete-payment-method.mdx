Remova um método de pagamento salvo da conta de um cliente. Use isso para limpar métodos de pagamento desatualizados ou indesejados.

<Warning>
Se o método de pagamento excluído for o único registrado para uma assinatura ativa, a assinatura pode não ser renovada no próximo ciclo de faturamento. Certifique-se de que o cliente tenha um método de pagamento alternativo antes de excluir.
</Warning>

## Casos de Uso

- **Solicitação do cliente**: Remova um método de pagamento que o cliente não deseja mais manter registrado
- **Cartões expirados**: Limpe métodos de pagamento com detalhes de cartões expirados
- **Segurança**: Remova imediatamente métodos de pagamento comprometidos
