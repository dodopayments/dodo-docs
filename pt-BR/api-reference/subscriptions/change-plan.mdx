## Tratamento de Falha no Pagamento

Use o parâmetro `on_payment_failure` para controlar o que acontece quando a mudança de plano falha no pagamento:

| Valor | Comportamento |
|-------|--------------|
| `prevent_change` | Manter a assinatura no plano atual até que o pagamento seja bem-sucedido. A mudança de plano permanece pendente. |
| `apply_change` | Aplicar a mudança de plano imediatamente, independentemente do resultado do pagamento. Este é o padrão. |

<Info>
Se `on_payment_failure` não for especificado, o comportamento padrão será baseado na configuração do nível de negócios definido no painel.
</Info>

<Tip>
Use `prevent_change` para atualizações críticas onde você deseja garantir o pagamento antes de conceder acesso a recursos premium.
</Tip>
