## Manipulação de Falha de Pagamento

Use o parâmetro `on_payment_failure` para controlar o que acontece quando o pagamento da alteração de plano falha:

| Value | Comportamento |
|-------|---------------|
| `prevent_change` | Mantenha a assinatura no plano atual até que o pagamento seja aprovado. A alteração de plano permanece pendente. |
| `apply_change` | Aplique a alteração de plano imediatamente independentemente do resultado do pagamento. Este é o padrão. |

<Info>
Se `on_payment_failure` não for especificado, o comportamento padrão será o definido nas configurações do nível empresarial no painel.
</Info>

## Códigos de Desconto

Você pode aplicar um código de desconto ao mudar de plano passando o parâmetro `discount_code`.

| Cenário | Comportamento |
|----------|----------|
| `discount_code` fornecido | Valida e aplica o desconto ao novo plano. |
| `discount_code` não fornecido, desconto existente com `preserve_on_plan_change=true` | Desconto existente é preservado se aplicável ao novo produto. |
| `discount_code` não fornecido, nenhum desconto preservável | Nenhum desconto aplicado. |

<Tip>
Use códigos de desconto durante mudanças de plano para oferecer preços promocionais em upgrades, ou passe um código ao migrar clientes para um novo nível de plano.
</Tip>

<Tip>
Use `prevent_change` para upgrades críticos onde você deseja garantir o pagamento antes de conceder acesso a recursos premium.
</Tip>
