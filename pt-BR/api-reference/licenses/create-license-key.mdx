<Info>
Este endpoint importa uma chave que você já possui — `key`, `customer_id` e `product_id` são todos obrigatórios. Ele não gera um valor de chave para você. Importar um `key` que já existe retorna `409 Conflict`.
</Info>

<Info>
As chaves de licença criadas ou atualizadas por meio da API não acionam notificações por e-mail para os clientes. Se precisar notificar os clientes sobre a chave de licença deles, você deverá fazer isso separadamente na sua aplicação.
</Info>
