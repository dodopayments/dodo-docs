<Warning>
**API Descontinuada**: As chaves de licença agora são gerenciadas através do sistema de [Direitos](/features/entitlements/introduction). Use [Listar Concessões de Cliente](/api-reference/entitlements/list-customer-grants) (filtrar com `integration_type=license_key`) para recuperar a concessão de uma chave e seus detalhes de `license_key`. Este endpoint será removido em uma versão futura.
</Warning>
