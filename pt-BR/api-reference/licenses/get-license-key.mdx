**API Obsoleta**: As chaves de licença agora são gerenciadas através do sistema de [Entitlements](/features/entitlements/introduction). Use [List Grants](/api-reference/entitlements/list-grants) (filtre com `integration_type=license_key`) para recuperar a concessão de uma chave e seus detalhes `license_key`. Este endpoint será removido em uma versão futura.
