<Warning>
**API Obsoleta**: As chaves de licença agora são gerenciadas através do sistema de [Entitlements](/features/entitlements/introduction). Use [List Customer Grants](/api-reference/entitlements/list-customer-grants) para listar chaves de licença emitidas (filtre com `integration_type=license_key`); cada concessão carrega seus detalhes `license_key`. Este endpoint será removido em uma versão futura.
</Warning>
