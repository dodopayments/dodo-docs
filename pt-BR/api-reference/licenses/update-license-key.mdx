<Warning>
**API Obsoleta**: As chaves de licença agora são gerenciadas através do sistema de [Entitlements](/features/entitlements/introduction). Configure limites de ativação e durações no [entitlement de chave de licença](/api-reference/entitlements/update-entitlement), e use [Revogar Concessão](/api-reference/entitlements/revoke-grant) para desativar a chave de um cliente. Este endpoint será removido em uma versão futura.
</Warning>

<Info>
Atualizar uma chave de licença através da API não aciona notificações por e-mail para o cliente.
</Info>
