## Gerenciamento de chaves de API e autenticação

<Steps>
<Step title="Access API Keys">
Acesse **Developer → API Keys** no seu dashboard para gerenciar suas chaves.
</Step>

<Step title="Generate a New Key">
Selecione **Add API Key**, forneça um nome descritivo e configure o acesso de gravação:

- **Enable write access** (marcado): permissões completas de leitura e gravação para todas as operações da API
- **Enable write access** (desmarcado): acesso somente leitura — pode apenas buscar dados (pagamentos, assinaturas, clientes, produtos). Não pode criar nem modificar recursos.

<Tip>
Desmarque "Enable write access" para integrações com o dashboard, ferramentas de análise e qualquer sistema que precise apenas visualizar dados sem fazer alterações.
</Tip>
</Step>

<Step title="Store Your Key Securely">
Copie a chave gerada imediatamente e certifique-se de armazená-la com segurança.
</Step>

<Step title="Authenticate Your API Requests">
Use suas chaves de API para autenticar todas as solicitações. Aplique o seguinte formato de autorização:

```bash 
Authorization: Bearer YOUR_API_KEY
```

<Warning>
Nunca exponha suas chaves secretas de API em código do lado do cliente ou repositórios públicos.
</Warning>
</Step>
</Steps>

## Limites de taxa

Nossa API usa um sistema de limitação de taxa com duas janelas e proteção contra rajadas. Os limites são aplicados com base no seu método de autenticação e no nível da sua empresa.

### Limites padrão (nível 0)

| Janela | Limite |
|--------|-------|
| Por segundo (rajada) | 40 solicitações |
| Por minuto (sustentado) | 240 solicitações |

### Níveis empresariais

Limites de taxa mais altos estão disponíveis para empresas com maiores necessidades de uso da API:

| Nível | Rajada (por segundo) | Sustentado (por minuto) |
|------|-------------------|------------------------|
| Nível 0 (padrão) | 40 | 240 |
| Nível 1 | 100 | 1.000 |
| Nível 2 | 500 | 5.000 |

<Tip>
Entre em contato com o suporte para atualizar sua empresa para um nível de limite de taxa mais alto.
</Tip>

### Solicitações não autenticadas

As solicitações sem cabeçalhos de autenticação válidos têm a taxa limitada pelo endereço IP:

| Janela | Limite |
|--------|-------|
| Por segundo (rajada) | 20 solicitações |
| Por minuto (sustentado) | 100 solicitações |

### Cabeçalhos de limite de taxa

Monitore seu uso com estes cabeçalhos de resposta:

- `X-RateLimit-Limit` — Máximo de solicitações permitidas
- `X-RateLimit-Remaining` — Solicitações restantes na janela atual
- `X-RateLimit-Reset` — Momento em que o limite de taxa é redefinido

<Note>
Quando você excede os limites de taxa, a API retorna uma resposta `429 Too Many Requests`. Implemente um backoff exponencial na sua lógica de novas tentativas.
</Note>
