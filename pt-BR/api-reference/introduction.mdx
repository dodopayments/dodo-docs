## Gerenciamento de Chaves da API e Autenticação

<Steps>
<Step title="Acessar Chaves da API">
Navegue até **Desenvolvedor → Chaves da API** em seu painel para gerenciar suas chaves.
</Step>

<Step title="Gerar uma Nova Chave">
Selecione **Adicionar Chave da API**, forneça um nome descritivo e configure o acesso de escrita:

- **Habilitar acesso de escrita** (marcado): Permissões completas de leitura e escrita para todas as operações da API
- **Habilitar acesso de escrita** (desmarcado): Acesso somente leitura - pode apenas buscar dados (pagamentos, assinaturas, clientes, produtos). Não pode criar ou modificar recursos.

<Tip>
Desmarque "Habilitar acesso de escrita" para integrações de painel, ferramentas de análise e qualquer sistema que precise apenas visualizar dados sem fazer alterações.
</Tip>
</Step>

<Step title="Armazene Sua Chave com Segurança">
Copie a chave gerada imediatamente e certifique-se de que ela seja armazenada com segurança.
</Step>

<Step title="Autentique Suas Requisições à API">
Use suas chaves da API para autenticar todas as requisições. Aplique o seguinte formato de autorização:

```bash 
Authorization: Bearer YOUR_API_KEY
```

<Warning>
Nunca exponha suas chaves secretas da API em código do lado do cliente ou repositórios públicos.
</Warning>
</Step>
</Steps>

## Limites de Taxa

Nosso API utiliza um sistema de controle de taxa de janela dupla com proteção contra picos. Os limites são aplicados com base no seu método de autenticação e nível de negócios.

### Limites Padrão (Nível 0)

| Janela | Limite |
|--------|-------|
| Por Segundo (Pico) | 40 solicitações |
| Por Minuto (Sustentado) | 240 solicitações |

### Níveis de Negócios

Limites de taxa mais altos estão disponíveis para empresas com necessidades aumentadas de API:

| Nível | Pico (por segundo) | Sustentado (por minuto) |
|------|-------------------|------------------------|
| Nível 0 (Padrão) | 40 | 240 |
| Nível 1 | 100 | 1.000 |
| Nível 2 | 500 | 5.000 |

<Tip>
Entre em contato com o suporte para atualizar seu negócio para um nível de limite de taxa mais alto.
</Tip>

### Solicitações Não Autenticadas

Solicitações sem cabeçalhos de autenticação válidos são limitadas por endereço IP:

| Janela | Limite |
|--------|-------|
| Por Segundo (Pico) | 20 solicitações |
| Por Minuto (Sustentado) | 100 solicitações |

### Cabeçalhos de Limite de Taxa

Monitore seu uso com estes cabeçalhos de resposta:

- `X-RateLimit-Limit` - Máximo de solicitações permitidas
- `X-RateLimit-Remaining` - Solicitações restantes na janela atual
- `X-RateLimit-Reset` - Hora em que o limite de taxa é redefinido

<Note>
Quando você excede os limites de taxa, a API retorna uma resposta `429 Too Many Requests`. Implemente uma lógica de desaceleração exponencial na sua lógica de repetição.
</Note>
