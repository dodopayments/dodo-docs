<Info>
Use este endpoint somente para grants criados sob um entitlement de License Key com `fulfillment_mode: manual`. O grant deve estar no status `Pending`, sem nenhuma key associada. Consulte [Cumprimento manual](/features/license-keys#manual-fulfillment) e o [Guia de integração para cumprimento manual de License Key](/developer-resources/manual-license-key-fulfillment) para ver o fluxo completo.
</Info>
