---
title: Revogar Concessão
description: Revogar manualmente uma concessão. O acesso à plataforma do cliente
  é removido (para integrações OAuth/bot) e as chaves de licença são
  desativadas. Revogações manuais usam revocation_reason "manual" e não são
  automaticamente concedidas novamente na renovação da assinatura.
keywords:
  - Dodo Payments
  - Referência da API
  - REST API
  - revogar concessão
openapi: delete /entitlements/{id}/grants/{grant_id}
