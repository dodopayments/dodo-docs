## Introdução

Este guia mostra como acompanhar indicações de afiliados, lidar com eventos de comissão e aumentar sua receita com parcerias de afiliados confiáveis por meio da Dodo Payments. Oferecemos integrações com as principais plataformas de afiliados, incluindo **Affonso**, **Dub Partners** e **Rekomi**, para ajudar você a gerenciar e acompanhar seus programas de afiliados de forma integrada.

## Opções de Integração

A Dodo Payments integra-se às principais plataformas de gerenciamento de afiliados:

- **[Affonso](https://affonso.io)**: uma plataforma completa de gerenciamento de afiliados, com rastreamento automatizado de comissões, relatórios em tempo real e dashboards dedicados para afiliados.
- **[Dub Partners](https://dub.co)**: use o gerenciamento de links e o rastreamento de conversões da Dub para impulsionar seu programa de afiliados com análises detalhadas de atribuição.
- **[Rekomi](https://rekomi.com)**: uma plataforma de rastreamento e gerenciamento de afiliados com uma conexão da Dodo Payments feita com uma única colagem, que também gerencia os pagamentos aos afiliados e os formulários fiscais para você.

Escolha a plataforma que melhor se adapta às suas necessidades ou use ambas para diferentes casos de uso.

## Integração com Affonso

Fizemos parceria com a Affonso, uma plataforma líder de gerenciamento de afiliados, para potencializar suas vendas. Siga os passos abaixo para conectar sua conta do Dodo Payments com a Affonso e começar a rastrear vendas impulsionadas por afiliados.

<Steps>
  <Step title="Connect with Dodo Payments">
    Para começar, conecte sua conta Dodo Payments adicionando sua chave de API.

    ### Como Obter Sua Chave de API do Dodo Payments

    - Faça login no seu **Painel do Dodo Payments**
    - Vá para a seção **Desenvolvedor** no menu à esquerda
    - Clique em **Chaves de API**
    - Selecione **Adicionar Chave de API**
    - Dê um nome (por exemplo, "Integração com Affonso")
    - Clique em **Criar** e **copie** sua chave de API

    ### Adicione Sua Chave de API ao Affonso

    - Abra seu **Painel do Affonso via** [affonso.io](https://affonso.io/)
    - Vá para **Detalhes do Programa > Conectar**
    - Clique no cartão de **integração do Dodo Payments**
    - Cole sua chave de API do Dodo Payments
    - Clique em **Conectar**

    <Callout type="info">
      Sua chave de API será criptografada com segurança pela Affonso.
    </Callout>
  </Step>

  <Step title="Add Webhook to Dodo Payments">
    Depois de conectada, você receberá uma URL de webhook exclusiva da Affonso. Isso permite o rastreamento de pagamentos e o acionamento de comissões de afiliados.

    ### Adicionar URL de Webhook no Dodo Payments

    - No seu Painel do Dodo Payments, vá para **Desenvolvedor → Webhooks**
    - Clique em **Adicionar Webhook**
    - Cole sua **URL de webhook do Affonso** (das configurações do seu programa)
    - Salve o webhook

    ### Adicionar Segredo do Webhook no Affonso

    - Após salvar o webhook no Dodo Payments, **copie a chave de assinatura** fornecida
    - Cole-a de volta no Affonso sob as **configurações de webhook do Dodo Payments**

    <Callout type="info">
      Isso permite que a Affonso verifique com segurança os eventos recebidos do Dodo Payments.
    </Callout>
  </Step>

  <Step title="Add the Tracking Script">
    Coloque o pixel da Affonso em seu site para começar a rastrear visitas e conversões de afiliados.

    ```html
    <!-- Place in <head> tag -->
    <script async defer
    src="https://affonso.io/js/pixel.min.js"
    data-affonso="YOUR_PUBLIC_PROGRAM_ID"
    data-cookie_duration="YOUR_COOKIE_DURATION">
    </script>
    ```

    Este script:
    - Rastreia visitas de afiliados
    - Define um cookie com a ID da indicação (`affonso_referral`)
    - Habilita o rastreamento de cadastros e pagamentos

    <Callout type="info">
      Coloque isso em todos os domínios onde os usuários visitam ou convertem (por exemplo, site de marketing, aplicativo).
    </Callout>
  </Step>

  <Step title="Track User Signups">
    Para obter visibilidade do funil e otimizar o desempenho dos afiliados, rastreie os cadastros de usuários como leads.

    ```js
    // After successful registration
    window.Affonso.signup(userEmail);
    ```

    Isso irá:
    - Registrar uma nova referência como um **LEAD** se o usuário veio por meio de um link de afiliado
    - Exibi-la no seu painel e nas estatísticas do afiliado

    <Callout type="info">
      Boa prática: acione isso após um registro bem-sucedido ou opt-in duplo (DOI).
    </Callout>
  </Step>

  <Step title="Pass Referral Data to Dodo Payments">
    Para atribuir comissões corretamente, passe a ID da indicação da Affonso para o Dodo Payments durante o checkout.

    ### Integração de Pagamentos

    ```js
    import DodoPayments from 'dodopayments';

    const referralId = window.affonso_referral;

    const client = new DodoPayments({
      bearerToken: process.env['DODO_PAYMENTS_API_KEY'],
    });

    async function main() {
      const payment = await client.payments.create({
        payment_link: true,
        billing: { city: 'city', country: 'AF', state: 'state', street: 'street', zipcode: '00000' },
        customer: { email: 'email@email.com', name: 'name' },
        product_cart: [{ product_id: 'product_id', quantity: 0 }],
        metadata: {
          affonso_referral: referralId,
        },
      });

      console.log(payment.payment_id);
    }

    main();
    ```

    ### Integração de Assinaturas

    ```js
    import DodoPayments from 'dodopayments';

    const referralId = window.affonso_referral;

    const client = new DodoPayments({
      bearerToken: process.env['DODO_PAYMENTS_API_KEY'],
    });

    async function main() {
      const subscription = await client.subscriptions.create({
        billing: { city: 'city', country: 'IN', state: 'state', street: 'street', zipcode: '89789' },
        customer: { customer_id: 'customer_id' },
        product_id: 'product_id',
        payment_link: true,
        return_url: 'https://example.com/success',
        quantity: 1,
        metadata: {
          affonso_referral: referralId,
        },
      });

      console.log(subscription.subscription_id);
    }

    main();
    ```

    ### Links de Pagamento

    ```js
    // Original Dodo Payments Link
    const originalLink = 'https://checkout.dodopayments.com/buy/<YOUR_PRODUCT_ID>';

    // Append referral ID as reference_id
    const linkWithReferral = `${originalLink}?metadata_affonso_referral=${window.affonso_referral}`;
    ```

    <Callout type="info">
      Para mais detalhes, consulte a [documentação da API do Dodo Payments](https://docs.dodopayments.com/api-reference/introduction)
    </Callout>
  </Step>

  <Step title="Testing Your Integration">
    Antes de lançar publicamente, teste sua configuração com links de afiliados ativos e transações de teste.

    **Checklist de testes:**
    - ✅ Crie um afiliado e gere um link de rastreamento
    - ✅ Visite seu site via o link do afiliado
    - ✅ Verifique se o script da Affonso é carregado e se o cookie `affonso_referral` é definido
    - ✅ Complete um cadastro (opcional)
    - ✅ Conclua um pagamento pelo Dodo Payments
    - ✅ Confirme o rastreamento e a atribuição no painel da Affonso
  </Step>
</Steps>

## Integração com Dub Partners

Você também pode usar [Dub Partners](https://dub.co) para rastrear referências e conversões de afiliados. O recurso de rastreamento de conversões do Dub permite que você atribua vendas aos seus links de afiliados, fornecendo análises detalhadas sobre quais parceiros geram mais receita.

<Info>
Para instruções detalhadas de configuração, consulte nosso [guia de integração com a Dub](/integrations/dub), que aborda como rastrear eventos de conversão de vendas e atribuir receita aos seus links de afiliados.
</Info>

### Configuração Rápida com Dub Partners

1. **Habilite o rastreamento de conversões** no seu painel da Dub para links de afiliados
2. **Capture o ID de clique da Dub** (cookie `dub_id`) ao criar sessões de checkout
3. **Armazene o ID de clique** nos metadados de pagamento junto com as informações do cliente
4. **Configure a integração via webhook** para enviar os dados de venda para a Dub quando os pagamentos forem aprovados

A integração rastreia automaticamente:
- Pagamentos únicos
- Ativações de assinatura
- Pagamentos de assinatura recorrentes

## Integração com a Rekomi

Você também pode usar a [Rekomi](https://rekomi.com) para gerenciar seu programa de afiliados de ponta a ponta. A Rekomi acompanha cliques e conversões, calcula comissões sobre o valor da venda antes dos impostos e paga seus afiliados por você em mais de 150 países, com os formulários fiscais incluídos.

<Info>
Para obter instruções detalhadas de configuração, consulte nosso [guia de integração da Rekomi](/integrations/rekomi). A conexão exige apenas a colagem de uma chave de API: a Rekomi cria o endpoint de webhook na sua conta da Dodo Payments, portanto não é necessário configurar o webhook manualmente.
</Info>

### Configuração rápida com a Rekomi

1. **Crie uma chave de API com acesso de gravação habilitado** no dashboard da Dodo Payments, em **Developer → API Keys**
2. **Cole a chave na Rekomi**, que a valida e cria o endpoint de webhook automaticamente
3. **Instale o script de rastreamento da Rekomi** no seu site para que os cliques de afiliados sejam capturados
4. **Passe a indicação** para o checkout como metadados `rekomi_ref` (ou como o parâmetro de payment-link `metadata_rekomi_ref`)

A integração acompanha automaticamente:
- Pagamentos únicos
- Ativações e renovações de assinaturas
- Reembolsos e disputas, com recuperação automática da comissão
