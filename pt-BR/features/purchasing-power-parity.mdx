<Info>
A Paridade do Poder de Compra (PPP) cobra do cliente uma parcela do seu preço de tabela, com base no país de onde ele compra. Um produto de \$20 pode ser vendido por **\$6,00 na Índia** sem um código de desconto e sem uma segunda tabela de preços.
</Info>

## O que é a Paridade do Poder de Compra?

O mesmo preço não é igualmente acessível em todos os lugares. \$20 é uma compra pequena nos Estados Unidos e uma compra grande nas Filipinas. Os preços PPP corrigem essa diferença.

Dodo Payments mantém uma porcentagem para cada país. A porcentagem é a **parcela do seu preço de tabela paga pelo cliente**. A Índia é 30, então um cliente na Índia paga 30% do preço. Os Estados Unidos são 100, então nada muda nesse país.

Você ativa a PPP para cada preço de produto ao qual deseja aplicá-la. Os produtos que não forem ativados mantêm o preço normal em todos os lugares.

<Note>
A PPP requer [Adaptive Currency](/features/adaptive-currency). Ative Adaptive Currency primeiro.
</Note>

## Principais benefícios

- **Alcance mercados sensíveis a preço**: venda por um preço local sem reduzir o preço do seu mercado principal.
- **Sem banner e sem script**: o preço está correto no checkout. Nada é adicionado ao seu site.
- **Sem códigos de desconto para gerenciar**: nada para criar, alternar ou revogar.
- **Controle por produto**: ative um plano inicial e deixe um plano empresarial sem alterações.
- **Funciona em todos os lugares**: produtos avulsos, de assinatura e baseados em uso.

## Ativar a Paridade do Poder de Compra

<Steps>
<Step title="Enable Adaptive Currency">
Acesse **Settings → Business**. Em **Business Settings**, ative **Adaptive Currency**. A PPP não funciona sem esse recurso.

<Frame>
  <img src="/images/ppp/adaptive-currency-toggle.png" alt="Adaptive Currency and Purchasing Power Parity in Business Settings" style={{ maxHeight: '360px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Review your country percentages">
Em **Purchasing Power Parity**, clique em **Edit** para abrir **Country Prices**. Altere a porcentagem de qualquer país e clique em **Save Changes**.

Defina o **Example product price** para ver quanto cada país paga. A coluna **Your Price** é atualizada conforme você digita. Use a caixa de pesquisa para encontrar um país pelo nome ou código.

<Frame>
  <img src="/images/ppp/country-percentages.png" alt="Country Prices dialog with a percentage and resulting price for each country" style={{ maxHeight: '620px', width: 'auto' }} />
</Frame>

<Note>
Essas porcentagens são aplicadas à empresa inteira. Todo produto com a Paridade do Poder de Compra ativada usa esses valores.
</Note>
</Step>

<Step title="Turn PPP on for a product">
Abra o produto. Na seção **Pricing**, marque **Purchasing Power Parity** e salve o produto.

Os produtos que não forem marcados mantêm o preço normal em todos os lugares.

<Frame>
  <img src="/images/ppp/product-toggle.png" alt="Purchasing Power Parity ticked in the product Pricing section" style={{ maxHeight: '440px', width: 'auto' }} />
</Frame>

<Warning>
Você não pode marcar esta opção enquanto Adaptive Currency estiver desativado. Ative Adaptive Currency primeiro.
</Warning>
</Step>

<Step title="Confirm at checkout">
<Check>
Abra um checkout de teste com um país de cobrança que tenha uma porcentagem abaixo de 100. Confirme se o preço reduzido é exibido.
</Check>
</Step>
</Steps>

## Como o preço é calculado

A porcentagem do país multiplica o seu preço de tabela:

```
price paid = list price × country percentage ÷ 100
```

Um produto de \$20,00 para um cliente na Índia, com valor 30:

```
2000 × 30 ÷ 100 = 600   →   $6.00
```

Dodo Payments aplica a porcentagem ao preço base, antes da conversão de moeda. Em seguida, [Adaptive Currency](/features/adaptive-currency) converte o resultado para a moeda do cliente.

<Info>
Dodo Payments lê o país a partir do **país de cobrança** do cliente no checkout.
</Info>

### Porcentagens dos países

Cada país tem uma porcentagem entre **30 e 100**:

- **100** significa que o cliente paga o preço integral. Não há redução.
- **30** é o menor valor que você pode definir. Portanto, a maior redução é de 70%.

Os valores padrão vêm dos dados do índice de nível de preços do Banco Mundial. Dodo Payments arredonda cada valor para o múltiplo de 5 mais próximo, aplica um piso de 30 e limita o valor máximo a 100. Todos os países compatíveis têm um valor. Você pode alterar qualquer um deles.

Estes são alguns dos valores padrão para mostrar o intervalo:

| País | Porcentagem | Um produto de \$20 é vendido por |
| :--- | :---: | :--- |
| Estados Unidos | 100 | \$20,00 |
| Reino Unido | 85 | \$17,00 |
| Alemanha | 75 | \$15,00 |
| Japão | 60 | \$12,00 |
| Brasil | 45 | \$9,00 |
| África do Sul | 40 | \$8,00 |
| Filipinas | 35 | \$7,00 |
| Índia | 30 | \$6,00 |

<Note>
A lista completa abrange 217 países. Abra a tabela de países no seu dashboard para ver todos os valores.
</Note>

## Ativar via API

A PPP é ativada por produto, com o campo `purchasing_power_parity`. O padrão é `false`.

<Info>
As porcentagens dos países são gerenciadas somente no dashboard. Elas não fazem parte da API pública.
</Info>

<CodeGroup>

```typescript theme={null}
import DodoPayments from 'dodopayments';

const client = new DodoPayments({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: 'test_mode',
});

const product = await client.products.create({
  name: 'Starter Plan',
  tax_category: 'saas',
  price: {
    type: 'one_time_price',
    currency: 'USD',
    price: 2000,
    discount: 0,
    purchasing_power_parity: true,
  },
});
```

```python theme={null}
import os
from dodopayments import DodoPayments

client = DodoPayments(
    bearer_token=os.environ.get("DODO_PAYMENTS_API_KEY"),
    environment="test_mode",
)

product = client.products.create(
    name="Starter Plan",
    tax_category="saas",
    price={
        "type": "one_time_price",
        "currency": "USD",
        "price": 2000,
        "discount": 0,
        "purchasing_power_parity": True,
    },
)
```

```go theme={null}
package main

import (
	"context"
	"os"

	"github.com/dodopayments/dodopayments-go"
	"github.com/dodopayments/dodopayments-go/option"
)

func main() {
	client := dodopayments.NewClient(
		option.WithBearerToken(os.Getenv("DODO_PAYMENTS_API_KEY")),
	)

	_, err := client.Products.New(context.TODO(), dodopayments.ProductNewParams{
		Name:        dodopayments.F("Starter Plan"),
		TaxCategory: dodopayments.F(dodopayments.ProductNewParamsTaxCategorySaas),
		Price: dodopayments.F[dodopayments.PriceUnionParam](
			dodopayments.PriceOneTimePriceParam{
				Type:                  dodopayments.F(dodopayments.PriceOneTimePriceTypeOneTimePrice),
				Currency:              dodopayments.F(dodopayments.CurrencyUsd),
				Price:                 dodopayments.F(int64(2000)),
				Discount:              dodopayments.F(int64(0)),
				PurchasingPowerParity: dodopayments.F(true),
			},
		),
	})
	if err != nil {
		panic(err)
	}
}
```

</CodeGroup>

## Comportamentos importantes

| Comportamento | Detalhe |
| :--- | :--- |
| **Requer Adaptive Currency** | A PPP não funciona enquanto Adaptive Currency estiver desativado. |
| **Desativada por padrão** | Todo preço começa em `purchasing_power_parity: false`. |
| **Preços localizados têm prioridade** | Um produto com uma regra correspondente de [Localized Pricing](/features/localized-pricing) nunca é ajustado pela PPP. O valor exato que você definiu é aplicado. |
| **Aplicada antes da conversão** | A porcentagem é aplicada ao seu preço base. Adaptive Currency converte o resultado. |
| **Antes dos descontos** | Um [código de desconto](/features/discount-codes) é aplicado ao preço reduzido, portanto as duas reduções são combinadas. |
| **Taxas fixas somente para produtos baseados em uso** | A PPP é aplicada à taxa fixa de um produto baseado em uso, nunca ao uso medido. |
| **Não disponível para Pay What You Want** | O cliente escolhe o valor, então a PPP não se aplica. Consulte [Pay What You Want](/features/pay-what-you-want). |
| **Intervalo de porcentagem** | A porcentagem de um país fica entre 30 e 100. A maior redução é de 70%. |
| **Sem webhook próprio** | O valor reduzido aparece no pagamento ou na assinatura como qualquer outro preço. |

## Práticas recomendadas

- **Ative primeiro um produto.** Confirme o preço no checkout antes de ativar a PPP para o seu catálogo.
- **Observe o acúmulo de descontos.** Um código de desconto é aplicado sobre o preço PPP. Um país com 30% mais um código de 20% deixa 24% do seu preço de tabela.
- **Deixe os planos empresariais de fora.** Um plano negociado raramente precisa de um ajuste por país.
- **Defina seus próprios valores onde for importante.** Os números padrão são um ponto de partida, não uma regra.
- **Verifique o efeito nas assinaturas.** Um assinante que se inscreve pelo preço reduzido renova por esse preço.
