A precificação de paridade de poder de compra (PPP) ajusta o que você cobra para corresponder ao poder de compra da localização de cada cliente. Existem duas maneiras de fazer isso na Dodo Payments.

<Info>
**Recomendado:** Use [Preços Localizados](/features/localized-pricing) nativos para definir um preço local fixo por país, por exemplo, ₹999 na Índia para um produto com base de $20. Você controla o valor exato, ele se aplica a produtos pontuais, por assinatura e baseados em uso, e não há banner ou script a instalar.
</Info>

## Duas maneiras de executar PPP

| | Preços Localizados (nativo) | Códigos de desconto baseados em localização |
| :--- | :--- | :--- |
| Como funciona | Você define um preço local fixo por país/moeda | Um percentual de desconto no seu preço base, aplicado via um código |
| Ferramentas | Integrado à Dodo Payments | [ParityDeals](https://www.paritydeals.com/) / [Evendeals](https://www.evendeals.com/integrations/dodo-payments) |
| Banner/script no seu site | Não requerido | Requerido para exibir o código |
| Preço que o cliente vê | O valor exato que você definiu | Preço base menos o desconto |
| Melhor para | Preços limpos e ajustados ao mercado que você controla totalmente | Banners promocionais e ofertas baseadas em tempo/feriados |

Para configuração nativa, veja [Preços Localizados](/features/localized-pricing). O restante desta página cobre a abordagem de código de desconto baseado em localização com ParityDeals e Evendeals.

## Códigos de desconto baseados em localização

[ParityDeals](https://www.paritydeals.com/) e [Evendeals](https://www.evendeals.com/integrations/dodo-payments) são plataformas que permitem a otimização automática de preços com base na localização geográfica do cliente gerando códigos de desconto.

<Info>
Embora você não possa incorporar banners de desconto diretamente em uma vitrine da Dodo Payments (já que scripts personalizados não são suportados), ainda pode implementar essas ferramentas eficazmente no seu próprio site ou aplicativo.
</Info>

### Escolhendo uma Integração

Ambas as plataformas se integram diretamente com a Dodo Payments para criar e gerenciar códigos de desconto automaticamente. Use a comparação abaixo para escolher a ferramenta que melhor se adapta às suas necessidades.

| Característica | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| Precificação baseada em PPP/localização | Sim | Sim |
| Ofertas baseadas em feriados/tempo | Sim | Não |
| Suporte a assinaturas | Sim | Sim |
| Atualização automática de cupons | — | Sim |
| Customização de banners | Sim | Não |
| Preço | [Ver Preço](https://www.paritydeals.com/pricing/) | [Ver Preço](https://www.evendeals.com/pricing) |

### ParityDeals

Quando o ParityDeals é integrado ao seu site, os visitantes elegíveis verão um banner que inclui um código de desconto baseado em localização que podem usar no checkout. Esses códigos de desconto são criados e gerenciados automaticamente pelo ParityDeals e aparecerão no seu **Painel de Controle Dodo Payments** em **Vendas → Descontos**.

#### Configuração

<Steps>
  <Step title="Sign up on ParityDeals">
    Visite [app.paritydeals.com](https://app.paritydeals.com/) e crie uma conta.
  </Step>

  <Step title="Create Deals">
    Após o login, localize a opção para criar ofertas. No menu suspenso, selecione **"Criar Ofertas via Dodo Payments"**.

    <Frame>
      <img src="/images/ppp/2.png" alt="Criando ofertas via Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Faça login no seu **painel da Dodo Payments** e navegue até **Desenvolvedores → Chaves de API**. Clique em **"Criar Nova API"**.

    <Tip>
      Nomeie sua chave de API descritivamente (por exemplo, 'ParityDeals') para que você possa identificá-la mais tarde.
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="Criando uma nova chave de API na Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Copie a chave de API que você criou e cole na interface do ParityDeals para estabelecer a conexão com sua conta Dodo Payments.

    <Frame>
      <img src="/images/ppp/4.png" alt="Conectando chave de API ao ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Uma vez conectado, o ParityDeals buscará o catálogo de produtos da Dodo Payments. Selecione os produtos que deseja associar às suas ofertas.

    <Frame>
      <img src="/images/ppp/5.png" alt="Selecionando produtos para ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Insira a URL do seu site e opcionalmente selecione páginas-alvo específicas onde o banner de desconto deve aparecer. Em seguida, escolha seu tipo de oferta preferido:
    - Ofertas baseadas em localização
    - Ofertas de feriados
    - Ofertas relâmpago baseadas em tempo

    <Frame>
      <img src="/images/ppp/6.png" alt="Configurando as configurações de ofertas" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Selecione os países para os quais deseja oferecer descontos localizados e defina o percentual de desconto para cada. O ParityDeals fornece valores padrão recomendados que você pode ajustar conforme necessário.

    <Frame>
      <img src="/images/ppp/7.png" alt="Definindo regras de desconto com base no país" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Desenhe seu banner de desconto personalizando o texto, escolhendo cores e layout, e definindo a posição do banner (topo ou rodapé da página). Este banner será exibido para visitantes elegíveis com base nas suas regras configuradas.

    <Frame>
      <img src="/images/ppp/8.png" alt="Customizando o banner de desconto" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Após salvar sua oferta, o ParityDeals gerará um script. Adicione este script ao código do seu site (geralmente na seção `<head>`). Este script detecta automaticamente as localizações dos visitantes e exibe o banner de desconto apropriado.

    <Frame>
      <img src="/images/ppp/9.png" alt="Script de integração do ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

#### Recursos Adicionais

Com o ParityDeals, você também pode oferecer [descontos automáticos baseados em tempo](https://www.paritydeals.com/features/time-based-discounts/) e [promoções baseadas em feriados](https://www.paritydeals.com/features/holiday-based-discounts/) ao longo do ano. Para informações mais detalhadas, consulte a [Documentação do ParityDeals](https://www.paritydeals.com/docs/).

### Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) é outra plataforma que se integra com a Dodo Payments para oferecer precificação de paridade de poder de compra baseada em localização. Ele suporta produtos tanto pontuais quanto por assinatura.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Visão geral da integração Evendeals com Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### Recursos Principais

- **Sincronização automática de cupons** — Cupons são criados e gerenciados automaticamente na Dodo Payments
- **Descontos Percentuais** — Ofereça descontos percentuais por grupo de país
- **Suporte a assinaturas** — Descontos se aplicam aos ciclos de cobrança de assinaturas
- **Regras de atualização automática** — Rotacione os códigos de cupons automaticamente por intervalo de tempo, contagem de resgates ou de visualizações para prevenir abusos

<Info>
Os códigos de desconto criados pelo Evendeals aparecerão automaticamente no seu painel da Dodo Payments em Vendas → Descontos.
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="Recursos principais do Evendeals para integração com a Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### Configuração

<Steps>
  <Step title="Create a Dodo Payments API key">
    No painel da Dodo Payments, vá para **Desenvolvedores → Chaves de API** e gere uma nova chave.
  </Step>

  <Step title="Connect in Evendeals">
    No seu [painel do Evendeals](https://www.evendeals.com/signin), navegue até **Integrações**, encontre o cartão de Dodo Payments e cole sua chave de API.
  </Step>

  <Step title="Configure regional discounts">
    Defina descontos percentuais para cada grupo de países e clique em sincronizar. O Evendeals cria cupons na Dodo Payments automaticamente.

    <Check>
    Após a sincronização, abra **Vendas → Descontos** no seu painel da Dodo Payments para confirmar que os cupons gerados aparecem. Cada cupom terá um prefixo do Evendeals reconhecível.
    </Check>
  </Step>
</Steps>

Para mais detalhes, visite a [Documentação do ParityDeals](https://www.paritydeals.com/docs/) ou a página de integração do [Evendeals Dodo Payments](https://www.evendeals.com/integrations/dodo-payments).
