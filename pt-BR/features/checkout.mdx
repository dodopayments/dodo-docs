## Adaptive Currency

Adaptive Currency permite que os clientes paguem na moeda local de sua preferência, aumentando a confiança e as taxas de conversão.

### Como funciona

1. **Ativar**: ative o Adaptive Currency em **Configurações → Negócios**
2. **Selecionar**: os clientes podem trocar de moeda diretamente no checkout
3. **Aplicar PPP**: se a [Paridade do Poder de Compra](/features/purchasing-power-parity) estiver ativada para o produto, o percentual do país reduz o preço base
4. **Converter**: o preço (ou preço ajustado pelo PPP) é convertido para a moeda do cliente usando taxas de câmbio em tempo real
5. **Arredondar**: se o [Charm Pricing](/features/charm-pricing) estiver ativado, o valor convertido será arredondado para uma terminação adequada, como 49,99
6. **Exibir**: o valor final a pagar é mostrado de forma transparente antes do pagamento

## Cálculo automático de impostos

Os impostos são calculados automaticamente com base no local de cobrança do cliente, garantindo conformidade com os requisitos de GST, VAT e impostos sobre vendas sem configuração manual.

### Como funciona o cálculo de impostos

<Steps>
<Step title="Location Detection">
  As regras fiscais são aplicadas com base no país do cliente (e na região, quando aplicável).
</Step>

<Step title="Dynamic Updates">
  O valor do imposto é atualizado automaticamente quando:
  - O país é alterado
  - O endereço é atualizado
</Step>

<Step title="Transparent Display">
  O detalhamento final dos impostos é exibido claramente antes do pagamento.
</Step>
</Steps>

<Tip>
O cálculo de impostos é totalmente automatizado. Nenhuma configuração manual é necessária para produtos digitais e produtos SaaS padrão.
</Tip>

## Suporte a Business Tax ID

Para empresas registradas, o checkout permite que os clientes insiram seu Business Tax ID (por exemplo, número de VAT/GST).

### O que acontece quando um Tax ID é inserido

- A elegibilidade fiscal é validada em tempo real
- As isenções fiscais aplicáveis ou regras de reverse charge são aplicadas
- O valor do imposto é atualizado instantaneamente no checkout

## Códigos de desconto

Os clientes podem aplicar códigos de desconto ou promocionais criados no dashboard diretamente na página de checkout.

### Experiência de checkout

1. O cliente insere o código de desconto
2. O desconto é validado instantaneamente
3. O preço atualizado e a economia são exibidos claramente

Quando a [Paridade do Poder de Compra](/features/purchasing-power-parity) está ativada em um produto, o desconto é aplicado ao preço ajustado pelo PPP, não ao preço base.

<Frame>
  <img src="/images/checkout/c4.png" alt="Entrada de código de desconto no checkout" style={{ maxHeight: '500px', width: '70%' }}/>
</Frame>

### Integração com a API

Pré-aplique um ou mais códigos de desconto acumuláveis ou ative o campo de entrada de desconto:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  discount_codes: ['WELCOME20'], // Pre-apply one or more codes (max 20, applied in order)
  feature_flags: {
    allow_discount_code: true // Shown by default; set to false to hide the field
  },
  return_url: 'https://yoursite.com/return'
});
```

<Info>
`discount_codes` aceita uma matriz de até 20 códigos, que são acumulados na ordem informada. O campo singular `discount_code` está obsoleto, mas continua funcionando — as integrações existentes não precisam ser alteradas imediatamente. Migre para `discount_codes` quando for conveniente para usar o acúmulo e o formato de resposta mais completo.
</Info>

## Coleta inteligente de endereços

O checkout oferece uma entrada flexível de endereços para uma conclusão mais rápida.

### Opções disponíveis

| Opção | Descrição |
|--------|-------------|
| **Preenchimento automático de endereço do Google** | Seleção rápida com autocompletar |
| **Entrada manual** | Controle total para endereços completos |
| **Seleção de país** | Orienta a lógica tributária e de compliance |
| **Endereço mínimo** | Colete apenas o país (e o CEP quando exigido para fins tributários) — consulte [Modo de endereço mínimo](#minimal-address-mode) |

<Tip>
A coleta de endereços equilibra velocidade, precisão e cobertura global para maximizar a conversão e garantir o compliance.
</Tip>

### Modo de endereço mínimo

Para maximizar a conversão, ative a coleta de endereço mínimo para reduzir o atrito no checkout. Quando `minimal_address` está definido como `true`, o checkout coleta apenas:

- **País** — sempre obrigatório para determinar os impostos
- **CEP** — apenas em regiões onde ele é necessário para o cálculo de sales tax, VAT ou GST

Todos os outros campos de endereço (rua, cidade, estado) são ignorados, acelerando significativamente a conclusão do checkout.

<Frame>
  <img src="/images/changelog/minimal-address.png" alt="Modo de endereço mínimo mostrando apenas os campos de país e CEP no checkout" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  minimal_address: true,
  return_url: 'https://yoursite.com/return'
});
```

<Info>
A coleta completa de endereços continua sendo o padrão. Ative `minimal_address` para produtos digitais e fluxos de SaaS em que os dados completos de cobrança não são necessários.
</Info>

  Consulte a referência completa do parâmetro `minimal_address` no guia da API Checkout Sessions.
</Card>

## Coleta de número de telefone

Controle se o campo de número de telefone aparece no checkout — e se ele é obrigatório — usando os feature flags da sessão de checkout.

| Flag | Padrão | Comportamento |
|------|---------|----------|
| `allow_phone_number_collection` | `true` | Exibe o campo de número de telefone no formulário de checkout |
| `require_phone_number` | `false` | Torna o campo de número de telefone obrigatório (a validação do formulário exige um valor não vazio) |

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_abc', quantity: 1 }],
  feature_flags: {
    allow_phone_number_collection: true,
    require_phone_number: true
  },
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
`require_phone_number: true` requer `allow_phone_number_collection: true`. A API rejeita sessões em que a coleta de telefone está desativada enquanto o número de telefone é obrigatório.
</Warning>

<Tip>
Use `require_phone_number` para SaaS B2B, setores regulamentados ou qualquer fluxo em que você precise de um canal de contato verificado para suporte, análise de fraude ou compliance.
</Tip>

## Campos personalizados

Colete informações adicionais dos clientes durante o checkout definindo campos de formulário personalizados. Isso é útil para reunir dados como nome da empresa, tamanho da equipe, origem da indicação ou qualquer outra informação específica do negócio.

### Tipos de campo disponíveis

| Tipo | Descrição |
|------|-------------|
| `text` | Campo de texto de uma linha |
| `number` | Campo numérico |
| `email` | Endereço de e-mail com validação |
| `url` | URL com validação |
| `date` | Seletor de data |
| `dropdown` | Seleção entre opções predefinidas |
| `boolean` | Alternador Sim/Não |

### Exemplo

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
As respostas dos clientes são incluídas automaticamente nos payloads de webhook (`payment.succeeded`, `subscription.active`) e nas respostas da API por meio da matriz `custom_field_responses`. Você pode definir até 5 campos personalizados por sessão de checkout.
</Info>

## Checkout de coleção

As coleções de produtos permitem uma experiência de checkout unificada, em que os clientes podem visualizar e selecionar vários produtos relacionados (por exemplo, planos Starter, Pro e Enterprise) em um único checkout.

### Como funciona

1. **Todos os produtos são exibidos**: os clientes veem todos os produtos ativos da coleção
2. **Primeiro produto pré-selecionado**: o primeiro produto da coleção é selecionado automaticamente
3. **Comparação de opções**: os clientes podem comparar preços e recursos antes de escolher
4. **Seleção única**: após selecionar um produto, o checkout prossegue com o fluxo de pagamento padrão

### Criando um checkout de coleção

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
Ao usar `product_collection_id`, passe uma matriz `product_cart` vazia. Os códigos de desconto não podem ser pré-aplicados durante a criação da sessão.
</Warning>

## Configuração da sessão de checkout

Controle o comportamento do checkout usando a API Checkout Sessions:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_codes: ['PROMO10'],
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  cancel_url: 'https://yoursite.com/pricing', // Optional: where to redirect on cancel
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
Após o pagamento, os clientes são redirecionados para o seu `return_url`, com parâmetros de consulta adicionados automaticamente — incluindo `payment_id` ou `subscription_id`, `status`, `email` e `license_key` (quando aplicável). Consulte o [guia Checkout Sessions](/developer-resources/checkout-session#request-body) para ver a lista completa.
</Info>

Personalize a aparência da página de checkout para combiná-la com a sua marca usando o parâmetro `customization.theme_config` ao criar uma sessão de checkout por meio da API. Configure cores, fontes, raio da borda e texto do botão para os modos claro e escuro.

<Frame>
  <img src="/images/checkout/theme-example.png" alt="Página de checkout com tema personalizado" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Card title="Design & Theme Customization" icon="palette" href="/features/design">
  Configure visualmente os temas no dashboard com temas predefinidos, tipografia, cores e visualização em tempo real.

<Info>
Esta seção aborda a configuração de temas da **API no lado do servidor** usando `customization.theme_config`. Se você estiver usando o **Checkout SDK** (checkout em overlay ou inline), consulte a seção de personalização de temas em [Overlay Checkout](/developer-resources/overlay-checkout#theme-customization), que usa propriedades camelCase (por exemplo, `bgPrimary` em vez de `bg_primary`).
</Info>

### Opções de configuração do tema

| Propriedade | Descrição |
|----------|-------------|
| `light` | Configuração de cores para o modo claro |
| `dark` | Configuração de cores para o modo escuro |
| `font_primary_url` | URL da fonte primária |
| `font_secondary_url` | URL da fonte secundária |
| `font_size` | Tamanho da fonte: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `font_weight` | Peso da fonte: `normal`, `medium`, `bold`, `extraBold` |
| `radius` | Raio da borda dos elementos da interface (por exemplo, `4px`, `0.5rem`, `8px`) |
| `pay_button_text` | Texto personalizado para o botão de pagamento (por exemplo, "Concluir compra", "Assinar agora") |

### Configuração de cores (modo claro/escuro)

Cada modo (`light` e `dark`) é compatível com as seguintes propriedades de cor:

| Propriedade | Descrição |
|----------|-------------|
| `bg_primary` | Cor primária do plano de fundo |
| `bg_secondary` | Cor secundária do plano de fundo |
| `text_primary` | Cor primária do texto |
| `text_secondary` | Cor secundária do texto |
| `text_placeholder` | Cor de placeholder do texto |
| `text_error` | Cor de erro do texto |
| `text_success` | Cor de sucesso do texto |
| `border_primary` | Cor primária da borda |
| `border_secondary` | Cor secundária da borda |
| `button_primary` | Cor de fundo do botão primário |
| `button_primary_hover` | Cor ao passar o cursor sobre o botão primário |
| `button_secondary` | Cor de fundo do botão secundário |
| `button_secondary_hover` | Cor ao passar o cursor sobre o botão secundário |
| `button_text_primary` | Cor do texto do botão primário |
| `button_text_secondary` | Cor do texto do botão secundário |
| `input_focus_border` | Cor da borda ao focar o campo de entrada |

<Info>
Todos os campos de cor aceitam formatos padrão de cores CSS:
- Hex: `#fff`, `#ffffff`, `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`, `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`, `hsla(120, 100%, 50%, 0.5)`
- Cores nomeadas: `red`, `blue`, `transparent`
</Info>

### Exemplo

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
Você não precisa especificar todas as propriedades de cor. As propriedades não especificadas usarão os valores padrão do tema.
</Tip>
