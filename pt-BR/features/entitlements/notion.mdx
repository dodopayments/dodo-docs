<Info>
A autorização do Notion duplica um template que você preparou no espaço de trabalho do cliente pagante. O cliente autoriza através de OAuth, escolhe o espaço de trabalho no qual deseja que o template seja copiado, e o Dodo Payments gerencia a duplicação.
</Info>

## O que é entregue

- O cliente é solicitado a conectar seu workspace do Notion via OAuth.
- Depois de autorizado, o Dodo Payments duplica o template configurado no workspace escolhido.
- Em caso de cancelamento, o template duplicado permanece no workspace do cliente (o Notion não oferece suporte à exclusão remota). O grant é marcado como `Revoked` para fins de registro.

Usos comuns incluem templates pagos do Notion, sistemas de produtividade e templates de OS/CRM.

## Fluxo do cliente

1. O cliente conclui o checkout.
2. O Dodo Payments cria um grant com status `Pending` e um `oauth_url` do Notion para que o cliente conecte seu workspace.
3. O cliente autoriza por meio do link em seu e-mail ou no Customer Portal e escolhe o workspace no qual deseja duplicar o template.
4. O Dodo Payments duplica o template. O grant passa para `Delivered`.
5. Em caso de revogação, o grant é marcado como `Revoked`; a cópia duplicada permanece no workspace do cliente.

<Note>
O Notion trata intencionalmente uma página duplicada como conteúdo próprio do destinatário. O Dodo Payments não pode excluir a cópia em caso de revogação.
</Note>

## Configuração necessária

| Campo | Obrigatório | Descrição |
|---|---|---|
| `notion_template_id` | Sim | O ID do template. O seletor do dashboard preenche isso. |

## Criar via API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Study Notes',
  integration_type: 'notion',
  integration_config: {
    notion_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Study Notes",
    integration_type="notion",
    integration_config={"notion_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Study Notes"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeNotion),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigNotionConfigParam{
      NotionTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

Veja [eventos de webhook `entitlement_grant.*`](/developer-resources/webhooks/intents/entitlement-grant):

- `entitlement_grant.created` inclui o Notion `oauth_url`.
- `entitlement_grant.delivered` dispara assim que o template é duplicado.
- `entitlement_grant.revoked` dispara no cancelamento; a cópia do cliente permanece intocada.

## Solução de problemas

<AccordionGroup>
<Accordion title="Customer didn't get the template">
O grant permanece `Pending` até que o cliente conclua o OAuth do Notion. Reenvie o e-mail de entrega; o link do OAuth expira após uma semana. Depois disso, você pode revogar e recriar o grant.
</Accordion>

<Accordion title="Template picker is empty">
Reconecte o Notion de **Entitlements → Integrations → Notion** com o espaço de trabalho que possui os templates de origem.
</Accordion>

<Accordion title="Customer wants the template removed after refund">
O Notion não permite a exclusão remota de páginas duplicadas. O cliente deve excluir a cópia de seu próprio espaço de trabalho.
</Accordion>
</AccordionGroup>
