<Info>
A Recuperação de Carrinho Abandonado (ACR) detecta fechamentos de compra incompletos ou falhos e envia sequências de e-mails automatizados para trazer os clientes de volta. Combine com incentivos de desconto opcionais para maximizar as taxas de recuperação.
</Info>

## O que é a Recuperação de Carrinho Abandonado?

ACR identifica automaticamente clientes que iniciaram mas não completaram um fechamento de compra — seja porque o pagamento falhou ou porque eles saíram antes de pagar — e envia uma sequência de e-mails de recuperação para trazê-los de volta.

- **Pagamentos falhos**: Cliente tentou o pagamento, mas ele foi recusado ou deu erro
- **Fechamentos de compra incompletos**: Cliente visitou o fechamento de compra, mas nunca tentou o pagamento

## Como ACR Funciona

<Steps>
<Step title="Detection">
Monitoramos pagamentos com mais de 60 minutos que não foram bem-sucedidos. Isso inclui pagamentos falhos e fechamentos de compra onde o cliente nunca tentou o pagamento.
</Step>

<Step title="Classification">
Cada fechamento de compra abandonado é classificado por motivo:
- **Pagamento Falhou**: O cliente tentou o pagamento, mas falhou
- **Fechamento de Compra Incompleto**: O cliente visitou o fechamento de compra, mas nunca tentou o pagamento
</Step>

<Step title="Email Sequence">
Com base na classificação, o sistema envia até 3 e-mails de recuperação em intervalos configurados. Cada e-mail contém um link de recuperação único.
</Step>

<Step title="Recovery">
Quando o cliente clica no link de recuperação, ele é levado para uma página de recuperação exibindo seu carrinho original. Ele pode completar o pagamento com uma nova sessão de fechamento de compra.
</Step>
</Steps>

## Ciclo de Vida de Status

Cada fechamento de compra abandonado passa pelos seguintes estados:

| Status | Descrição |
|--------|-------------|
| `abandoned` | Fechamento de compra detectado como abandonado, sem e-mails enviados ainda |
| `recovering` | Pelo menos um e-mail de recuperação foi enviado |
| `recovered` | Cliente completou o pagamento via o link de recuperação |
| `exhausted` | Todos os e-mails enviados sem recuperação, ou um fechamento de compra mais recente substituiu este |
| `opted_out` | Cliente se descadastrou dos e-mails de recuperação |

### Configurações Globais

| Configuração | Descrição | Padrão |
|---------|-------------|---------|
| **Habilitado** | Alternância principal para ACR | Desligado |
| **Desconto Habilitado** | Gerar automaticamente um código de desconto para e-mails de recuperação | Desligado |
| **Porcentagem de Desconto** | Porcentagem de desconto que será aplicada ao fechamento de compra para este cliente | 0 |
| **Dias de Validade do Desconto** | Quantos dias o código de desconto gerado automaticamente permanece válido | 5 |

### Sequências de E-mails

ACR suporta duas sequências de e-mails — **Pagamento Falhou** e **Fechamento de Compra Incompleto** — cada uma com até 3 e-mails configuráveis.

<Frame caption="ACR email sequence configuration">
<img src="/images/recovery/acr-email-config.png" alt="Editor de sequência de e-mails mostrando assunto, corpo, tempo e alternância de habilitação para cada e-mail na sequência" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

| Configuração | Descrição |
|---------|-------------|
| **Habilitado** | Alternar e-mails individuais ativados ou desativados sem excluí-los |
| **Atraso** | Quanto tempo após a detecção de abandono para enviar este e-mail |
| **Assunto** | Linha de assunto do e-mail com espaços reservados de variável |
| **Corpo** | Corpo de e-mail HTML com espaços reservados de variável |
| **Responder para** | Endereço de e-mail para respostas dos clientes |

**Tempo padrão dos e-mails:**

| E-mail # | Atraso Padrão |
|---------|---------------|
| 1 | 1 hora |
| 2 | 24 horas |
| 3 | 72 horas |

## Descontos de Recuperação

Quando o desconto está habilitado, o ACR gera automaticamente um código de desconto único e de uso único para cada fechamento de compra abandonado. O desconto:

- É restrito ao(s) produto(s) do fechamento de compra original
- Tem um período de expiração configurável
- É limitado a uma redenção
- É oculto da lista de descontos do seu painel (uso interno apenas)

<Tip>
Comece com um desconto modesto (5-10%) para testar o impacto na conversão antes de aumentar. Mesmo um pequeno incentivo pode melhorar significativamente as taxas de recuperação.
</Tip>

## Experiência de Recuperação do Cliente

Quando um cliente clica no link de recuperação em um e-mail, ele é levado de volta para
sua sessão de fechamento de compra original. A página exibe o produto que ele deixou
para trás, junto com um código de desconto se um tiver sido configurado.

## Casos Especiais

| Cenário | Comportamento |
|----------|----------|
| Cliente completa a compra antes do próximo e-mail | A recuperação é detectada no momento do envio; o fechamento de compra é marcado como recuperado se elegível |
| Cliente inicia um novo fechamento de compra | Antigo fechamento de compra abandonado é marcado como `exhausted` |
| Cliente clica em "Pagar" após já ter recuperado | Página de recuperação mostra uma confirmação de que o pagamento já foi completado |
| Cliente se descadastra | Fechamento de Compra Abandonado é marcado como `opted_out`; nenhum e-mail adicional é enviado |

## Melhores Práticas

- **Comece com os padrões**: O tempo e os assuntos dos e-mails padrão são otimizados para padrões comuns de recuperação. Personalize após ter dados de base.
- **Personalize os e-mails**: Use variáveis de template para tornar os e-mails pessoais e relevantes para o cliente.
- **Monitore as análises**: Acompanhe as taxas de recuperação por e-mail para identificar quais mensagens geram mais conversões. Desative os e-mails com baixo desempenho.
- **Use descontos estrategicamente**: Comece pequeno (5-10%) para proteger as margens enquanto testa o impacto na conversão.
- **Mantenha os e-mails concisos**: E-mails de recuperação devem ser curtos e orientados para a ação. Um chamado claro para ação gera melhores resultados do que explicações longas.

<Info>
O ACR é projetado para funcionar automaticamente uma vez habilitado. Comece com as configurações padrão, monitore suas análises e itere com base nos dados de desempenho.
</Info>
