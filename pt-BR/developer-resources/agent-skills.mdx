## Overview

Agent Skills are reusable capabilities that enhance what AI coding assistants can do when working with Dodo Payments. They provide procedural knowledge and best practices that help agents accomplish specific tasks more effectively - from integrating checkout flows to setting up usage-based billing.

<Info>
**Think of skills as plugins for your AI assistant.** They teach your agent how to implement Dodo Payments features correctly, following our recommended patterns and best practices.
</Info>

As skills funcionam com qualquer agente de IA compatível com o protocolo de skills, incluindo:
- **Claude Code** - assistente de programação CLI da Anthropic
- **Codex CLI** - agente de programação CLI da OpenAI
- **Cursor** - editor de código com IA em primeiro lugar
- **VS Code / GitHub Copilot** - por meio do Agent Plugin
- **Kiro** - carrega skills como uma Power
- **OpenCode** - agente de programação de IA de código aberto
- **Outros clientes** - qualquer agente compatível com o protocolo de skills

<Note>
**Gemini CLI é a exceção.** Ele não tem uma primitiva de agent-skill, portanto as skills não estão disponíveis nele — apenas os dois [servidores MCP](/developer-resources/mcp-server) estão.
</Note>

## Instalação

Escolha seu método de instalação preferido com base no seu assistente de programação com IA.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Se você estiver usando Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro ou OpenCode, o [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) instalará todas as dezessete skills e os dois servidores MCP em uma única etapa. As skills são carregadas automaticamente quando seu agente detecta uma tarefa relevante.

Consulte o [guia de AI Coding Agents](/developer-resources/build-with-ai-coding-agents) para ver os comandos de instalação específicos de cada agente.
</Tab>

<Tab title="Skills CLI">
Instale as skills usando o skills CLI universal, que funciona com qualquer agente compatível com MCP:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Ou instale skills individuais conforme necessário:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/dodo-best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
Instale apenas as skills necessárias para manter seu agente focado e reduzir a sobrecarga de contexto.
</Tip>
</Tab>

<Tab title="OpenCode">
O OpenCode carrega skills dos diretórios indicados por você. Ele **não** verifica pacotes instalados, portanto é necessária uma entrada explícita de `skills.paths`.

Usando o pacote do Agent Plugin:

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

Os caminhos relativos são resolvidos com base no **diretório do projeto**, portanto o pacote deve estar presente no `node_modules` desse projeto. Um caminho absoluto também funciona e evita a exigência de instalação local.

<Warning>
Um caminho de skills que não existe é ignorado **silenciosamente** — sem erro e sem aviso. Confirme se as skills foram realmente carregadas:

```bash
opencode run "List every skill available to you by name."
```

Você deverá ver todas as dezessete.
</Warning>
</Tab>
</Tabs>

## Usando skills

Depois de instaladas, seu assistente de IA carrega automaticamente a skill relevante quando você solicita a implementação de um recurso do Dodo Payments. Não é necessário informar o nome da skill — basta descrever a tarefa.

| Exemplo de prompt | Skill carregada |
|----------------|------------------|
| Ajude-me a integrar o Dodo Payments ao meu aplicativo Next.js seguindo as práticas recomendadas | `dodo-best-practices` |
| Adicione um handler de rota de checkout do Dodo Payments ao meu aplicativo Hono | `framework-adapters` |
| Mostre-me como testar pagamentos e entrar em produção | `testing-and-go-live` |
| Crie uma sessão de checkout para meu produto SaaS | `checkout-integration` |
| Implemente um fluxo de assinatura com período de teste gratuito e vários níveis de preço | `subscription-integration` |
| Adicione checkout no aplicativo ao meu aplicativo React Native | `mobile-checkout` |
| Configure handlers de webhook para eventos de pagamento e assinatura | `webhook-integration` |
| Configure entitlements de créditos e dedução de créditos com medição para meu produto de IA | `credit-based-billing` |
| Adicione cobrança baseada em uso para acompanhar chamadas de API do meu produto de IA | `usage-based-billing` |
| Implemente a validação de chaves de licença para meu aplicativo desktop | `license-keys` |
| Crie um catálogo de produtos com complementos e preços por níveis | `product-catalog-management` |
| Adicione um código promocional que ofereça 20% de desconto nos três primeiros ciclos de cobrança | `discounts-and-promotions` |
| Mostre os preços na moeda local do visitante com paridade do poder de compra | `localized-pricing` |
| Ofereça aos clientes um portal de autoatendimento para gerenciar seus métodos de pagamento | `customer-management` |
| Emita um reembolso parcial e revogue o acesso quando uma disputa for aberta | `refunds-and-disputes` |
| Adicione uma página de preços usando componentes do BillingSDK | `billing-sdk` |
| Integre o Dodo Payments à minha configuração do Better Auth | `better-auth-integration` |

## Como as skills funcionam

As skills fornecem ao seu assistente de IA:

1. **Conhecimento procedural** - Instruções passo a passo para implementar recursos
2. **Modelos de código** - Padrões e snippets de código prontos para produção
3. **Práticas recomendadas** - Abordagens recomendadas para segurança, tratamento de erros e UX
4. **Consciência de contexto** - Compreensão de como os diferentes recursos do Dodo Payments funcionam em conjunto

Quando você solicita ao seu assistente de IA a implementação de um recurso, ele usa a skill relevante para:
- Entender a abordagem correta de implementação
- Gerar código preciso e funcional
- Seguir as convenções do Dodo Payments
- Lidar adequadamente com casos extremos e erros

<Note>
As skills complementam o [MCP Server](/developer-resources/mcp-server) e o [Sentra](/developer-resources/sentra). Use o MCP para operações de API, o Sentra para integração guiada e as Skills para aprimorar os recursos do assistente de IA.
</Note>

## Comparação com outras ferramentas

| Ferramenta | Finalidade | Melhor para |
|------|---------|----------|
| **Agent Skills** | Aprimorar o conhecimento do assistente de IA | Desenvolvimento assistido por IA com qualquer cliente MCP |
| **MCP Server** | Executar operações de API | Acesso direto à API por assistentes de IA |
| **Sentra** | Assistente de integração guiada | Integração interativa de cobrança na IDE |
