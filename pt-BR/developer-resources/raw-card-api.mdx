<Note>
Este guia cobre exclusivamente **pagamentos únicos** envolvendo **cartões, Apple Pay e Google Pay**.
</Note>

## Endpoints da API

| Ambiente | URL Base | Endpoint de Confirmação de Pagamento |
| --- | --- | --- |
| **Modo de Teste** | `https://test.dodopayments.com` | `https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm` |
| **Modo Ao Vivo** | `https://live.dodopayments.com` | `https://api.hs.dodopayments.com/payments/<payment_id>/confirm` |

## Fluxo de Pagamento com Cartão Passo a Passo

### Passo 1: Obter a Chave Secreta

Comece criando um pagamento usando a seguinte API:

- **Pagamentos**: [Criar API de Pagamento](/api-reference/payments/post-payments)

Esta API retorna um **`secret_key`**, necessário para os passos subsequentes.

### Passo 2: Confirmar o Pagamento

Confirme o pagamento chamando o endpoint `payments confirm`:

- **Modo de Teste**: `POST https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm`
- **Modo Ao Vivo**: `POST https://api.hs.dodopayments.com/payments/<payment_id>/confirm`

Inclua os seguintes detalhes no corpo da solicitação:

- `client_secret`: Chave secreta do Passo 1
- `payment_method`: Defina como `card`
- `payment_method_data`: Detalhes do cartão e de faturamento
- `browser_info`: Dados específicos do navegador (agente de usuário, detalhes da tela, etc.)
- `payment_type`: Defina explicitamente como `normal` (para pagamentos únicos)

Cabeçalhos necessários:

- Obtenha sua chave publicável no suporte da DodoPayments
- `api-key`: Sua chave publicável (Obtenha isso da equipe da Dodo Payments)
- `content-type`: `application/json`

**Exemplo de Corpo da Solicitação:**

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "card",
  "payment_method_data": {
    "card": {
      "card_number": "<card_number>",
      "card_exp_month": "<exp_month>",
      "card_exp_year": "<exp_year>",
      "card_holder_name": "<cardholder_name>",
      "card_cvc": "<cvc>",
      "card_network": "<network>"
    },
    "billing": {
      "address": {
        "first_name": "<first_name>",
        "last_name": "<last_name>"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",

```

### Tratando a Resposta

- Se a resposta **`status`** for **`requires_customer_action`**, redirecione o cliente para a URL fornecida no campo **`next_action`** para autenticação adicional.

<Warning>
Assegure-se de seguir as diretrizes de conformidade PCI ao lidar com dados de cartão em bruto.
</Warning>

## Integração do Apple Pay

Para usar o Apple Pay, defina `payment_method` como `wallet` e inclua os dados do Apple Pay em `payment_method_data`.

### Estrutura do Corpo da Solicitação

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "apple_pay": {
        "payment_data": "<decrypted_payment_data>",
        "payment_method": {
          "display_name": "Visa 1234",
          "network": "Visa",
          "type": "debit"
        },
        "transaction_identifier": "UNIQUE_TRANSACTION_ID_FROM_APPLE"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Referência de Campos do Apple Pay

| Campo | Tipo | Necessário | Descrição |
| --- | --- | --- | --- |
| `payment_data` | string | Sim | Este enum é usado para representar os dados de pagamento do Apple Pay, que podem ser criptografados ou descriptografados. |
| `payment_method.display_name` | string | Sim | Nome exibido no botão Apple Pay (ex: "Visa 1234") |
| `payment_method.network` | string | Sim | Rede do cartão (ex: "Visa", "Mastercard", "Amex") |
| `payment_method.type` | string | Sim | Tipo de método de pagamento (ex: "débito", "crédito") |
| `payment_method.card_exp_month` | string | Não | Mês de validade do cartão (ex: "12") |
| `payment_method.card_exp_year` | string | Não | Ano de validade do cartão (ex: "25") |
| `transaction_identifier` | string | Sim | Identificador de transação exclusivo do Apple Pay |

## Integração do Google Pay

Para usar o Google Pay, defina `payment_method` como `wallet` e inclua os dados do Google Pay em `payment_method_data`.

### Estrutura do Corpo da Solicitação

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "google_pay": {
        "type": "CARD",
        "description": "Visa ending in 1234",
        "info": {
          "card_network": "VISA",
          "card_details": "1234"
        },
        "tokenization_data": {
          "type": "PAYMENT_GATEWAY",
          "token": "<encrypted_payment_token>"
        }
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Referência de Campos do Google Pay

| Campo | Tipo | Necessário | Descrição |
| --- | --- | --- | --- |
| `type` | string | Sim | Tipo de método de pagamento (normalmente "CARD") |
| `description` | string | Sim | Descrição voltada para o usuário do método de pagamento |
| `info.card_network` | string | Sim | Rede do cartão (ex: "VISA", "MASTERCARD", "AMEX") |
| `info.card_details` | string | Sim | Últimos 4 dígitos do cartão |
| `info.assurance_details` | object | Não | Detalhes de garantia de autenticação |
| `tokenization_data.type` | string | Sim | Tipo de tokenização (ex: "PAYMENT_GATEWAY") |
| `tokenization_data.token` | string | Sim | Token de pagamento criptografado do Google Pay |
