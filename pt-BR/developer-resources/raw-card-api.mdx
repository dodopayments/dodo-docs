<Note>
Este guia cobre exclusivamente **pagamentos únicos** envolvendo **cartões, Apple Pay e Google Pay**.
</Note>

## API Endpoints

| Environment | Base URL | Confirm Payment Endpoint |
| --- | --- | --- |
| **Test Mode** | `https://test.dodopayments.com` | `https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm` |
| **Live Mode** | `https://live.dodopayments.com` | `https://api.hs.dodopayments.com/payments/<payment_id>/confirm` |

## Fluxo de Pagamento com Cartão Passo a Passo

### Etapa 1: Obter o Client Secret

Comece criando um pagamento usando a seguinte API:

- **Payments**: [Create Payment API](/api-reference/payments/post-payments)

Esta API retorna um **`client_secret`**, necessário para etapas subsequentes.

<Warning>
`POST /payments` está obsoleto. Ele continua disponível para integrações com raw-card porque é o único endpoint que retorna um `client_secret`, mas, para todos os outros fluxos de pagamento único, use [Checkout Sessions](/api-reference/checkout-sessions/create).
</Warning>

### Etapa 2: Confirmar o pagamento

Confirme o pagamento chamando o endpoint `payments confirm`:

- **Test Mode**: `POST https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm`
- **Live Mode**: `POST https://api.hs.dodopayments.com/payments/<payment_id>/confirm`

Inclua os seguintes detalhes no corpo da solicitação:

- `client_secret`: `client_secret` da Etapa 1
- `payment_method`: Defina como `card`
- `payment_method_data`: Dados do cartão e de cobrança
- `browser_info`: Dados específicos do navegador (user agent, detalhes da tela etc.)
- `payment_type`: Defina explicitamente como `normal` (para pagamentos únicos)

Headers obrigatórios:

- Obtenha sua chave publicável com o suporte da DodoPayments
- `api-key`: Sua chave publicável (obtenha-a com a equipe da Dodo Payments)
- `content-type`: `application/json`

**Corpo da solicitação de exemplo:**

```json
{
  "client_secret": "<client_secret>",
  "payment_method": "card",
  "payment_method_data": {
    "card": {
      "card_number": "<card_number>",
      "card_exp_month": "<exp_month>",
      "card_exp_year": "<exp_year>",
      "card_holder_name": "<cardholder_name>",
      "card_cvc": "<cvc>",
      "card_network": "<network>"
    },
    "billing": {
      "address": {
        "first_name": "<first_name>",
        "last_name": "<last_name>"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,

```

### Como lidar com a resposta

- Se **`status`** da resposta for **`requires_customer_action`**, redirecione o cliente para a URL fornecida no campo **`next_action`** para autenticação adicional.

<Warning>
Garanta a conformidade com as diretrizes do PCI ao lidar com dados brutos do cartão.
</Warning>

## Integração com Apple Pay

Para usar o Apple Pay, defina `payment_method` como `wallet` e inclua os dados do Apple Pay em `payment_method_data`.

### Estrutura do corpo da solicitação

```json
{
  "client_secret": "<client_secret>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "apple_pay": {
        "payment_data": "<decrypted_payment_data>",
        "payment_method": {
          "display_name": "Visa 1234",
          "network": "Visa",
          "type": "debit"
        },
        "transaction_identifier": "UNIQUE_TRANSACTION_ID_FROM_APPLE"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Referência dos campos do Apple Pay

| Campo | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `payment_data` | string | Sim | Este enum é usado para representar os dados de pagamento do Apple Pay, que podem estar criptografados ou descriptografados. |
| `payment_method.display_name` | string | Sim | Nome de exibição mostrado no botão do Apple Pay (por exemplo, "Visa 1234") |
| `payment_method.network` | string | Sim | Bandeira do cartão (por exemplo, "Visa", "Mastercard", "Amex") |
| `payment_method.type` | string | Sim | Tipo de método de pagamento (por exemplo, "debit", "credit") |
| `payment_method.card_exp_month` | string | Não | Mês de vencimento do cartão (por exemplo, "12") |
| `payment_method.card_exp_year` | string | Não | Ano de vencimento do cartão (por exemplo, "25") |
| `transaction_identifier` | string | Sim | Identificador exclusivo da transação do Apple Pay |

## Integração com Google Pay

Para usar o Google Pay, defina `payment_method` como `wallet` e inclua os dados do Google Pay em `payment_method_data`.

### Estrutura do corpo da solicitação

```json
{
  "client_secret": "<client_secret>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "google_pay": {
        "type": "CARD",
        "description": "Visa ending in 1234",
        "info": {
          "card_network": "VISA",
          "card_details": "1234"
        },
        "tokenization_data": {
          "type": "PAYMENT_GATEWAY",
          "token": "<encrypted_payment_token>"
        }
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Referência dos campos do Google Pay

| Campo | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `type` | string | Sim | Tipo de método de pagamento (normalmente "CARD") |
| `description` | string | Sim | Descrição do método de pagamento voltada para o usuário |
| `info.card_network` | string | Sim | Bandeira do cartão (por exemplo, "VISA", "MASTERCARD", "AMEX") |
| `info.card_details` | string | Sim | Últimos 4 dígitos do cartão |
| `info.assurance_details` | object | Não | Detalhes da garantia de autenticação |
| `tokenization_data.type` | string | Sim | Tipo de tokenização (por exemplo, "PAYMENT_GATEWAY") |
| `tokenization_data.token` | string | Sim | Token de pagamento criptografado do Google Pay |
