Dodo Payments fornece SDKs oficiais para várias linguagens de programação, cada um projetado com as melhores práticas específicas da linguagem e recursos modernos para uma integração de pagamento sem problemas.

<Tip>
Sempre use a versão mais recente do SDK para ter acesso aos recursos e melhorias mais recentes. Verifique regularmente o gerenciador de pacotes para atualizações e garantir o acesso a todas as capacidades da Dodo Payments.
</Tip>

## Início Rápido

Comece com qualquer SDK em minutos:

<Steps>
<Step title="Install the SDK">
  Use o gerenciador de pacotes da sua linguagem para instalar o SDK
  
  <Tabs>
  <Tab title="TypeScript/Node.js">

  ```bash
  npm install dodopayments
  ```

  </Tab>
  
  <Tab title="Python">

  ```bash
  pip install dodopayments
  ```

  </Tab>
  
  <Tab title="PHP">

  ```bash
  composer require dodopayments/client
  ```

  </Tab>
  
  <Tab title="Go">

  ```bash
  go get github.com/dodopayments/dodopayments-go
  ```

  </Tab>

  <Tab title="Rust">

  ```bash
  cargo add dodopayments
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Initialize the Client">
  Configure o cliente com sua chave de API
  
  <Tabs>
  <Tab title="TypeScript">

  ```typescript
  import DodoPayments from 'dodopayments';
  const client = new DodoPayments({ bearerToken: 'your_api_key' });
  ```

  </Tab>
  
  <Tab title="Python">

  ```python
  from dodopayments import DodoPayments
  client = DodoPayments(bearer_token="your_api_key")
  ```

  </Tab>
  
  <Tab title="PHP">

  ```php
  use Dodopayments\Client;
  $client = new Client(bearerToken: 'your_api_key');
  ```

  </Tab>
  
  <Tab title="Go">

  ```go
  import "github.com/dodopayments/dodopayments-go"
  client := dodopayments.NewClient(option.WithBearerToken("your_api_key"))
  ```

  </Tab>

  <Tab title="Rust">

  ```rust
  use dodopayments::Client;
  let client = Client::from_env()?; // reads DODO_PAYMENTS_API_KEY
  ```

  </Tab>
  </Tabs>
  
  <Warning>
  Sempre armazene suas chaves de API de forma segura usando variáveis de ambiente. Nunca as insira no controle de versão.
  </Warning>
</Step>

<Step title="Make Your First API Call">
  Crie uma sessão de checkout ou pagamento
  
  <Check>
  Você está pronto para processar pagamentos! Visite as páginas individuais dos SDKs para guias detalhados e exemplos.
  </Check>
</Step>
</Steps>

## Principais Funcionalidades

Todos os SDKs compartilham estas capacidades principais:

- **Segurança de Tipagem**: Tipagem forte para segurança em tempo de compilação e melhor suporte em IDE
- **Tratamento de Erros**: Tratamento abrangente de exceções com mensagens de erro detalhadas
- **Autenticação**: Autenticação simples de chave de API com suporte a variáveis de ambiente
- **Suporte a Async**: Padrões modernos de async/await onde aplicável
- **Paginação Automática**: Paginação automática para respostas de listas
- **Cobrança Baseada em Uso**: Suporte embutido para rastreamento e ingestão de eventos de uso
- **Teste**: Suporte completo para ambiente sandbox para desenvolvimento e testes

## SDK para React Native

Para aplicativos móveis, oferecemos um SDK dedicado para React Native:

<Card title="React Native SDK" icon="mobile" href="/developer-resources/react-native-integration">
  Crie experiências de pagamento seguras para apps iOS e Android com componentes de UI nativos e coleta simplificada de dados de pagamento
</Card>

**Funcionalidades:**
- Componentes de UI nativos para Android e iOS
- Segurança simplificada para coleta de dados de pagamento sensíveis
- Suporte a múltiplos métodos de pagamento
- Integração perfeita com apps React Native

<Info>
Apple Pay, Google Pay, Cash App e UPI não são atualmente suportados no SDK para React Native. O suporte para esses métodos de pagamento está planejado para lançamentos futuros.
</Info>

Para fluxos de trabalho baseados em terminal e automação:

<Card title="CLI" icon="terminal" href="/developer-resources/sdks/cli">

**Funcionalidades:**

- Conclusão de shell para bash, zsh e fish

```bash
dodopayments payments list --format json | jq '.data[] | {id, amount}'
```
