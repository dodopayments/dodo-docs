## Início rápido

Comece a rastrear automaticamente tokens de LLM em apenas 2 minutos:

<Steps>
<Step title="Install the SDK">
Instale os Blueprints de ingestão do Dodo Payments:

```bash
npm install @dodopayments/ingestion-blueprints
```

</Step>

<Step title="Get Your API Keys">
Você precisará de duas chaves de API:

- **Chave de API do Dodo Payments**: obtenha-a no [Dashboard do Dodo Payments](https://app.dodopayments.com/developer/api-keys)
- **Chave de API do provedor de LLM**: do AI SDK, OpenAI, Anthropic, Groq etc.

<Tip>
Armazene suas chaves de API com segurança em variáveis de ambiente. Nunca faça commit delas no controle de versão.
</Tip>
</Step>

<Step title="Create a Meter in Dodo Payments">
Antes de rastrear o uso, crie um medidor no seu dashboard do Dodo Payments:

1. **Faça login** no [Dashboard do Dodo Payments](https://app.dodopayments.com/)
2. **Acesse** Products → Meters
3. **Clique** em "Create Meter"
4. **Configure seu medidor**:
   - **Nome do medidor**: escolha um nome descritivo (por exemplo, "Uso de tokens de LLM")
   - **Nome do evento**: defina um identificador de evento exclusivo (por exemplo, `llm.chat_completion`)
   - **Tipo de agregação**: selecione `sum` para somar as contagens de tokens
   - **Sobre a propriedade**: escolha o que rastrear:
     - `inputTokens` - Rastrear tokens de entrada/prompt
     - `outputTokens` - Rastrear tokens de saída/conclusão (inclui tokens de raciocínio quando aplicável)
     - `totalTokens` - Rastrear tokens combinados de entrada + saída

<Info>
O **Nome do evento** definido aqui deve corresponder exatamente ao valor enviado ao SDK (diferencia maiúsculas de minúsculas).
</Info>

Para obter instruções detalhadas, consulte o [Guia de cobrança baseada em uso](/developer-resources/usage-based-billing-guide).
</Step>

<Step title="Track Token Usage">

## Configuração

### Configuração do rastreador

Crie um rastreador uma vez na inicialização do aplicativo com estes parâmetros obrigatórios:

<ParamField path="apiKey" type="string" required>
Sua chave de API do Dodo Payments. Obtenha-a na [página de chaves de API](https://app.dodopayments.com/developer/api-keys).

```javascript
apiKey: process.env.DODO_PAYMENTS_API_KEY
```

</ParamField>

<ParamField path="environment" type="string" required>
O modo de ambiente do rastreador.

- `test_mode` - Use em desenvolvimento e testes
- `live_mode` - Use em produção

```javascript
environment: 'test_mode' // or 'live_mode'
```

<Warning>
Sempre use `test_mode` durante o desenvolvimento para evitar afetar as métricas de produção.
</Warning>
</ParamField>

<ParamField path="eventName" type="string" required>
O nome do evento que aciona seu medidor. Deve corresponder exatamente ao que você configurou no medidor do Dodo Payments (diferencia maiúsculas de minúsculas).

```javascript
eventName: 'llm.chat_completion'
```

<Info>
Esse nome de evento vincula o uso rastreado ao medidor correto para os cálculos de cobrança.
</Info>
</ParamField>

### Configuração do wrapper

Ao envolver seu cliente de LLM, forneça estes parâmetros:

<ParamField path="client" type="object" required>
Sua instância de cliente de LLM (OpenAI, Anthropic, Groq etc.).

```javascript
client: openai
```

</ParamField>

<ParamField path="customerId" type="string" required>
O identificador exclusivo do cliente para cobrança. Deve corresponder ao ID do cliente em Dodo Payments.

```javascript
customerId: 'customer_123'
```

<Tip>
Use o ID de usuário ou de cliente do seu aplicativo para garantir uma cobrança precisa por cliente.
</Tip>
</ParamField>

<ParamField path="metadata" type="object">
Dados adicionais opcionais para anexar ao evento de rastreamento. Úteis para filtragem e análise.

```javascript
metadata: {
  feature: 'chat',
  userTier: 'premium',
  sessionId: 'session_123',
  modelVersion: 'gpt-4'
}
```

</ParamField>

### Exemplo completo de configuração

<CodeGroup>

```javascript Full Configuration
import { createLLMTracker } from "@dodopayments/ingestion-blueprints";
import { generateText } from "ai";
import { google } from "@ai-sdk/google";
import "dotenv/config";

async function aiSdkExample() {
  console.log("🤖 AI SDK Simple Usage Example\n");

  try {
    // 1. Create tracker
    const llmTracker = createLLMTracker({
      apiKey: process.env.DODO_PAYMENTS_API_KEY!,
      environment: "test_mode",
      eventName: "your_meter_event_name",
    });

    // 2. Wrap the ai-sdk methods
    const client = llmTracker.wrap({
      client: { generateText },
      customerId: "customer_123",
      metadata: {
        provider: "ai-sdk",
      },
    });

    // 3. Use the wrapped function
    const response = await client.generateText({
      model: google("gemini-2.5-flash"),
      prompt: "Hello, I am a cool guy! Tell me a fun fact.",
      maxOutputTokens: 500,
    });

    console.log(response);
    console.log(response.usage);
    console.log("✅ Automatically tracked for customer\n");
  } catch (error) {
    console.error(error);
  }
}

aiSdkExample().catch(console.error);
```

</CodeGroup>

<Info>
**Rastreamento automático:** o SDK rastreia automaticamente o uso de tokens em segundo plano sem modificar a resposta. Seu código permanece limpo e idêntico ao uso dos SDKs originais dos provedores.
</Info>

### Integração de API com Express.js

Exemplo completo de integração do rastreamento de LLM a uma API do Express.js:

<CodeGroup>

```javascript Express.js Server
import express from 'express';
import { createLLMTracker } from '@dodopayments/ingestion-blueprints';
import OpenAI from 'openai';

const app = express();
app.use(express.json());

// Initialize OpenAI client
const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

// Create tracker once at startup
const tracker = createLLMTracker({
  apiKey: process.env.DODO_PAYMENTS_API_KEY,
  environment: process.env.NODE_ENV === 'production' ? 'live_mode' : 'test_mode',
  eventName: 'api.chat_completion'
});

// Chat endpoint with automatic tracking
app.post('/api/chat', async (req, res) => {
  try {
    const { message, userId } = req.body;
    
    // Validate input
    if (!message || !userId) {
      return res.status(400).json({ error: 'Missing message or userId' });
    }
    
    // Wrap client for this specific user
    const trackedClient = tracker.wrap({
      client: openai,
      customerId: userId,
      metadata: { 
        endpoint: '/api/chat',
        timestamp: new Date().toISOString()
      }
    });
    
    // Make LLM request - automatically tracked
    const response = await trackedClient.chat.completions.create({
      model: 'gpt-4',
      messages: [{ role: 'user', content: message }],
      temperature: 0.7
    });
    
    const completion = response.choices[0].message.content;
    
    res.json({ 
      message: completion,
      usage: response.usage
    });
  } catch (error) {
    console.error('Chat error:', error);
    res.status(500).json({ error: 'Internal server error' });
  }
});

app.listen(3000, () => {
  console.log('Server running on port 3000');
});
```

</CodeGroup>

## O que é rastreado

Cada chamada à API de LLM envia automaticamente um evento de uso para Dodo Payments com a seguinte estrutura:

<CodeGroup>

```json Event Structure
{
  "event_id": "llm_1673123456_abc123",
  "customer_id": "customer_123",
  "event_name": "llm.chat_completion",
  "timestamp": "2024-01-08T10:30:00Z",
  "metadata": {
    "inputTokens": 10,
    "outputTokens": 25,
    "totalTokens": 35,
    "model": "gpt-4",
  }
}
```

</CodeGroup>

### Campos do evento

<ParamField path="event_id" type="string">
Identificador exclusivo deste evento específico. Gerado automaticamente pelo SDK.

Formato: `llm_[timestamp]_[random]`
</ParamField>

<ParamField path="customer_id" type="string">
O ID do cliente fornecido ao envolver o cliente. Usado para cobrança.
</ParamField>

<ParamField path="event_name" type="string">
O nome do evento que aciona seu medidor. Corresponde à configuração do rastreador.
</ParamField>

<ParamField path="timestamp" type="string">
Timestamp no formato ISO 8601 em que o evento ocorreu.
</ParamField>

<ParamField path="metadata" type="object">
Uso de tokens e dados adicionais de rastreamento:

- `inputTokens` - Número de tokens de entrada/prompt usados
- `outputTokens` - Número de tokens de saída/conclusão usados (inclui tokens de raciocínio quando aplicável)
- `totalTokens` - Total de tokens (entrada + saída)
- `model` - O modelo de LLM usado (por exemplo, "gpt-4")
- `provider` - O provedor de LLM (se incluído nos metadados do wrapper)
- Quaisquer metadados personalizados fornecidos ao envolver o cliente

<Note>
**Tokens de raciocínio:** para modelos com recursos de raciocínio, `outputTokens` inclui automaticamente os tokens de conclusão e de raciocínio.
</Note>
</ParamField>

<Info>
Seu medidor do Dodo Payments usa os campos `metadata` (especialmente `inputTokens`, `outputTokens` ou `totalTokens`) para calcular o uso e a cobrança.
</Info>
