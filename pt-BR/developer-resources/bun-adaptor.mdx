## Instalação

<Steps>
<Step title="Instale o pacote">
Execute o seguinte comando na raíz do seu projeto:

```bash
bun add @dodopayments/bun
```

</Step>
<Step title="Configure variáveis de ambiente">
Crie um <code>.env</code> na raíz do seu projeto:

```env expandable
DODO_PAYMENTS_API_KEY=your-api-key
DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
DODO_PAYMENTS_ENVIRONMENT="test_mode" or "live_mode"
DODO_PAYMENTS_RETURN_URL=your-return-url
```

<Warning>
Nunca comite seu arquivo <code>.env</code> ou segredos no controle de versão.
</Warning>
</Step>
</Steps>

## Exemplos de Manipuladores de Rota

<Info>
Todos os exemplos assumem que você está usando o servidor nativo do Bun com <code>Bun.serve()</code>.
</Info>

<Tabs>
<Tab title="Manipulador de Checkout">
  <Info>
  Use este manipulador para integrar o checkout dos Pagamentos Dodo em seu servidor Bun. Suporta fluxos de pagamento estáticos (GET), dinâmicos (POST) e de sessão (POST).
  </Info>
  <CodeGroup>

    ```typescript Bun Server Handler expandable
    import { Checkout } from '@dodopayments/bun';

    const staticCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "static"
    });

    const sessionCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "session"
    });

    const dynamicCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "dynamic"
    });

    Bun.serve({
      port: 3000,
      fetch(request) {
        const url = new URL(request.url);
        
        if (url.pathname === "/api/checkout") {
          if (request.method === "GET") {
            return staticCheckoutHandler(request);
          }
          if (request.method === "POST") {
            return sessionCheckoutHandler(request);
            // or return dynamicCheckoutHandler(request);
          }
        }
        
        return new Response("Not Found", { status: 404 });
      },
    });
    ```

  </CodeGroup>
  <CodeGroup>


## Manipulador de Rota do Checkout

<Info>
Os Pagamentos Dodo suportam três tipos de fluxos de pagamento para integrar pagamentos ao seu site, este adaptador suporta todos os tipos de fluxos de pagamento.
</Info>

- **Links de Pagamento Estáticos:** URLs instantaneamente compartilháveis para coleta de pagamento rápida e sem código.
- **Links de Pagamento Dinâmicos:** Geração programática de links de pagamento com detalhes personalizados usando a API ou SDKs.
- **Sessões de Checkout:** Crie experiências de checkout seguras e personalizáveis com carrinhos de produtos pré-configurados e detalhes do cliente.

### Formato de Resposta
O checkout estático retorna uma resposta JSON com a URL do checkout:

```json
{
  "checkout_url": "https://checkout.dodopayments.com/..."
}
```

</Accordion>
<Accordion title="Checkout Dinâmico (POST)">
- Envie parâmetros como um corpo JSON em uma requisição POST.
- Suporta pagamentos únicos e recorrentes.
- Para uma lista completa de campos do corpo POST suportados, consulte:
  - [Corpo da requisição para um Produto de Pagamento Único](https://docs.dodopayments.com/api-reference/payments/post-payments)
  - [Corpo da requisição para um Produto de Assinatura](https://docs.dodopayments.com/api-reference/subscriptions/post-subscriptions)

### Formato de Resposta
O checkout dinâmico retorna uma resposta JSON com a URL do checkout:

```json
{
  "checkout_url": "https://checkout.dodopayments.com/..."
}
```

</Accordion>
<Accordion title="Sessões de Checkout (POST)">
As sessões de checkout fornecem uma experiência de checkout hospedada mais segura que lida com o fluxo completo de pagamento para compras únicas e assinaturas com total controle de personalização.

Consulte o [Guia de Integração de Sessões de Checkout](https://docs.dodopayments.com/developer-resources/checkout-session) para mais detalhes e uma lista completa de campos suportados.

### Formato de Resposta

```json
}
```

## Manipulador de Rota do Portal do Cliente

O Manipulador de Rota do Portal do Cliente permite que você integre perfeitamente o portal do cliente dos Pagamentos Dodo em sua aplicação de servidor Bun.

### Parâmetros de Consulta
<ParamField query="customer_id" type="string" required>
O ID do cliente para a sessão do portal (ex: <code>?customer_id=cus_123</code>).
</ParamField>
<ParamField query="send_email" type="boolean">
Se definido como <code>true</code>, envia um e-mail ao cliente com o link do portal.
</ParamField>

<Warning>
Retorna 400 se <code>customer_id</code> estiver faltando.
</Warning>

## Manipulador de Rota de Webhook

- **Método:** Somente requisições POST são suportadas. Outros métodos retornam 405.
- **Verificação de Assinatura:** Verifica a assinatura do webhook usando <code>webhookKey</code>. Retorna 401 se a verificação falhar.
- **Validação de Payload:** validado com Zod. Retorna 400 para payloads inválidos.
- **Tratamento de Erros:**
  - 401: Assinatura inválida
  - 400: Payload inválido
  - 500: Erro interno durante a verificação
- **Roteamento de Eventos:** Chama o manipulador de evento apropriado com base no tipo de payload.

import { Checkout, CustomerPortal, Webhooks } from "@dodopayments/bun";

const staticCheckoutHandler = Checkout({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  type: "static",
});

const sessionCheckoutHandler = Checkout({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  type: "session",
});

const customerPortalHandler = CustomerPortal({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
});

const webhookHandler = Webhooks({
  webhookKey: process.env.DODO_PAYMENTS_WEBHOOK_KEY,
  onPaymentSucceeded: async (payload) => {
    console.log("Pagamento bem-sucedido:", payload);
    // Sua lógica de negócios aqui
  },
  onSubscriptionActive: async (payload) => {
    console.log("Assinatura ativada:", payload);
    // Sua lógica de negócios aqui
  },
});

Bun.serve({
  port: 3000,
  fetch(request) {
    const url = new URL(request.url);
    
    // Rotas de Checkout
    if (url.pathname === "/api/checkout") {
      if (request.method === "GET") {
        return staticCheckoutHandler(request);
      }
      if (request.method === "POST") {
        return sessionCheckoutHandler(request);
      }

      return webhookHandler(request);
    }
    
    return new Response("Não Encontrado", { status: 404 });
  },
});
