O Dodo Payments fornece notificações de webhook em tempo real para mantê-lo informado sobre eventos críticos relacionados a transações, assinaturas, reembolsos, disputas e gerenciamento de chaves de licença. Abaixo está um guia detalhado para esses eventos, categorizados para clareza, juntamente com dicas e considerações de implementação.

## **Eventos de Pagamento**

| **Nome do Evento**       | **Tipo de Evento**       | **Descrição**                                                                 |
|--------------------------|--------------------------|---------------------------------------------------------------------------------|
| **Pagamento Aprovado**   | `payment.succeeded`      | Disparado quando um pagamento é processado com sucesso.                         |
| **Pagamento Falhou**     | `payment.failed`         | Ocorre quando uma tentativa de pagamento falha devido a erros, cartões recusados ou outros problemas. |
| **Pagamento Processando** | `payment.processing`     | Indica que um pagamento está atualmente sendo processado.                        |
| **Pagamento Cancelado**   | `payment.cancelled`      | Disparado quando um pagamento é cancelado antes da conclusão.                   |

## **Eventos de Reembolso**

| **Nome do Evento**       | **Tipo de Evento**       | **Descrição**                                                                 |
|--------------------------|--------------------------|---------------------------------------------------------------------------------|
| **Reembolso Aprovado**   | `refund.succeeded`       | Disparado quando um reembolso é processado com sucesso.                         |
| **Reembolso Falhou**     | `refund.failed`          | Ocorre quando uma tentativa de reembolso falha devido a erros de processamento ou outros problemas. |

## **Eventos de Disputa**

| **Nome do Evento**       | **Tipo de Evento**       | **Descrição**                                                                 |
|--------------------------|--------------------------|---------------------------------------------------------------------------------|
| **Disputa Aberta**       | `dispute.opened`         | Disparado quando um cliente inicia uma disputa.                                 |
| **Disputa Expirada**     | `dispute.expired`        | Indica que uma disputa expirou sem resolução.                                   |
| **Disputa Aceita**       | `dispute.accepted`       | Disparado quando um comerciante aceita a disputa.                              |
| **Disputa Cancelada**    | `dispute.cancelled`      | Ocorre quando uma disputa é cancelada pelo cliente ou pelo sistema.             |
| **Disputa Contestada**    | `dispute.challenged`     | Disparado quando um comerciante contestar uma disputa.                          |
| **Disputa Ganha**        | `dispute.won`            | Indica que o comerciante ganhou com sucesso uma disputa.                        |
| **Disputa Perdida**      | `dispute.lost`           | Ocorre quando o comerciante perde uma disputa.                                  |

## **Eventos de Assinatura**

| **Nome do Evento**       | **Tipo de Evento**       | **Descrição**                                                                 |
|--------------------------|--------------------------|---------------------------------------------------------------------------------|
| **Assinatura Ativa**     | `subscription.active`    | Indica que uma assinatura está agora ativa e cobranças recorrentes estão programadas. |
| **Assinatura Atualizada**| `subscription.updated`   | Disparado quando qualquer campo da assinatura é atualizado (sincronização em tempo real sem polling). |
| **Assinatura Suspensa**  | `subscription.on_hold`   | Disparado quando uma assinatura é temporariamente suspensa devido a falha na renovação. |
| **Assinatura Renovada**  | `subscription.renewed`   | Ocorre quando uma assinatura é renovada com sucesso.                            |
| **Plano de Assinatura Alterado**| `subscription.plan_changed` | Disparado quando uma assinatura é atualizada, rebaixada ou modificada com diferentes complementos. |
| **Assinatura Cancelada** | `subscription.cancelled` | Disparado quando uma assinatura é cancelada pelo comerciante ou cliente.       |
| **Assinatura Falhou**    | `subscription.failed`    | Indica uma assinatura falhada. Isso significa que não conseguimos criar um mandato. |
| **Assinatura Expirada**  | `subscription.expired`   | Disparado quando uma assinatura atinge o fim de seu prazo e expira.             |

## **Eventos de Chave de Licença**

| **Nome do Evento**       | **Tipo de Evento**       | **Descrição**                                                                 |
|--------------------------|--------------------------|---------------------------------------------------------------------------------|
| **Chave de Licença Criada**| `license_key.created`    | Disparado quando uma nova chave de licença é criada para um produto.             |

Esses eventos de webhook são projetados para fornecer aos comerciantes atualizações críticas para gerenciar suas operações de forma eficaz. Implemente manipuladores robustos para cada evento relevante em sua integração de webhook para garantir uma funcionalidade suave e confiável.
