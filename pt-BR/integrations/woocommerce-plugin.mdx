## Introdução

O plugin Dodo Payments para WooCommerce fornece uma integração perfeita com sua loja, permitindo que você aceite pagamentos através de múltiplos métodos, incluindo UPI, cartões, internet banking e carteiras digitais. Este guia abrangente irá orientá-lo pelo processo de instalação e configuração.

## Guia de Instalação Passo a Passo

1. Baixe o arquivo zip mais recente do plugin de pagamento WooCommerce.

## Guia de Configuração

### Configurando Chaves de API e Webhooks

1. Navegue até **WooCommerce → Configurações → Pagamentos** ou clique no botão **Pagamentos** na barra lateral esquerda abaixo do item de menu WooCommerce
    
    <Frame>
        <img src="/images/woocommerce/6.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
    <Frame>
        <img src="/images/woocommerce/7.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
2. Ative o provedor de pagamento **Dodo Payments** se ainda não estiver ativado, então clique em **Gerenciar** para configurar o plugin
3. Você verá várias opções de configuração, cada uma com texto explicativo útil. Comece configurando sua Chave de API Live
    
    <Frame>
        <img src="/images/woocommerce/8.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
4. Faça login no seu dashboard do Dodo Payments em **Live Mode**, então navegue até **Dodo Payments (Live Mode) > Developer > API Keys** ou visite [este link direto](https://app.dodopayments.com/developer/api-keys) e clique em **Adicionar Chave de API**
    
    <Frame>
        <img src="/images/woocommerce/9.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
5. Dê à sua Chave de API um nome descritivo e clique em **Criar**
    
    <Frame>
        <img src="/images/woocommerce/10.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
6. Copie a Chave de API gerada e cole-a no campo **Live API Key** nas configurações do plugin WooCommerce
    
    <Frame>
        <img src="/images/woocommerce/11.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
    <Frame>
        <img src="/images/woocommerce/12.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
7. Em seguida, configure a Chave de Assinatura do Webhook para habilitar a sincronização do status de pagamento entre Dodo Payments e WooCommerce
8. Role até o final da página de configurações do plugin e copie a URL do webhook exibida
    
    <Frame>
        <img src="/images/woocommerce/13.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
9. Retorne ao seu dashboard do Dodo Payments e navegue até **Dodo Payments (Live Mode) > Developer > Webhooks** e clique em **Adicionar Webhook**
    
    <Frame>
        <img src="/images/woocommerce/14.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
10. Cole a URL que você copiou no passo 8 na caixa de diálogo e clique em **Adicionar Webhook**
    
    <Frame>
        <img src="/images/woocommerce/15.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
11. Após criar o webhook, clique no ícone de olho ao lado da **Chave de Assinatura** redigida para revelar e copiar
    
    <Frame>
        <img src="/images/woocommerce/16.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
12. Cole a Chave de Assinatura no campo **Live Webhook Signing Key** nas configurações do plugin e salve as alterações
    
    <Frame>
        <img src="/images/woocommerce/17.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
13. Revise as configurações restantes, como **Categoria Fiscal Global** e **Todos os Preços Incluem Impostos**, pois essas opções determinam como os produtos são sincronizados do WooCommerce para o Dodo Payments. Note que **Chave de API de Teste** e **Chave de Assinatura de Webhook de Teste** são necessárias apenas se você planeja usar o Modo de Teste
    
    <Frame>
        <img src="/images/woocommerce/18.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>

## Principais Recursos

- **Experiência de Checkout Sem Costura**: Redirecione os clientes para uma página de checkout segura e otimizada
- **Múltiplos Métodos de Pagamento**: Suporte para várias opções de pagamento locais e internacionais
- **Atualizações de Status em Tempo Real**: Sincronização instantânea do status do pedido via webhooks
- **Registros de Transação Detalhados**: Histórico abrangente de pagamentos no seu painel WooCommerce
- **Suporte a Múltiplas Moedas**: Aceite pagamentos em várias moedas

## Solução de Problemas

### Problemas Comuns

1. **Falhas no Processamento de Pagamentos**
   - Verifique se as chaves de API estão configuradas corretamente
   - Certifique-se de que a URL do webhook está configurada corretamente
   - Verifique se seu certificado SSL é válido

2. **Problemas de Sincronização de Webhook**
   - Confirme se a chave de assinatura do webhook corresponde
   - Revise os logs do servidor para possíveis erros
   - Verifique se seu servidor pode receber solicitações de webhook de entrada

## Melhores Práticas de Manutenção

1. Atualize regularmente o plugin para correções de segurança e novos recursos
2. Teste todos os fluxos de pagamento no modo sandbox antes de processar transações ao vivo
3. Mantenha o WordPress e o WooCommerce atualizados para as versões mais recentes
4. Implemente backups regulares do site
5. Monitore os logs de transação para qualquer atividade incomum
6. Armazene as chaves de API com segurança e nunca as compartilhe publicamente
