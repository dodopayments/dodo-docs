## Introdução

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) é uma plataforma que cria e sincroniza cupons de desconto de paridade do poder de compra baseados em localização com sua conta do Dodo Payments. Ela oferece suporte a produtos avulsos e de assinatura, gerando automaticamente códigos de desconto que são alternados de acordo com uma programação definida por você.

<Note>
O Dodo Payments oferece [Purchasing Power Parity](/features/purchasing-power-parity) nativo, que reduz os preços por país no checkout sem banner, script ou códigos de cupom para gerenciar. O Evendeals é destinado a merchants que desejam especificamente a abordagem baseada em códigos de desconto, com alternância automática de cupons.
</Note>

## Como funciona

O Evendeals se conecta à sua conta do Dodo Payments por meio de uma chave de API. Depois de conectado, você configura descontos percentuais para cada grupo de países. Em seguida, o Evendeals cria códigos de desconto automaticamente na sua conta do Dodo Payments e os alterna de acordo com uma programação definida por você (por intervalo de tempo, número de resgates ou número de visualizações) para evitar abusos.

## Evendeals vs. PPP nativo

O Purchasing Power Parity nativo é a forma recomendada de definir preços por país, pois não requer códigos de cupom e não pode ser compartilhado ou usado de forma abusiva. Escolha o Evendeals quando quiser especificamente a abordagem baseada em códigos de desconto.

| | PPP nativo | Evendeals |
| :--- | :--- | :--- |
| Como funciona | Uma porcentagem por país, aplicada no checkout | Uma porcentagem de desconto, aplicada por meio de um código |
| Onde é configurado | Integrado ao Dodo Payments | Painel do Evendeals |
| Banner ou script necessário | Não é necessário | Não é necessário |
| Alternância / atualização automática de cupons | Não se aplica | Sim |
| Suporte a assinaturas | Sim | Sim |
| Ideal para | Preços corretos sem alterações no site | Abordagem baseada em códigos de desconto com alternância automática |

## Principais recursos

- **Sincronização automática de cupons** — Os cupons são criados e gerenciados automaticamente no Dodo Payments
- **Descontos percentuais** — Ofereça descontos percentuais para cada grupo de países
- **Suporte a assinaturas** — Os descontos se aplicam a todos os ciclos de cobrança da assinatura
- **Regras de atualização automática** — Alterne os códigos de cupom automaticamente por intervalo de tempo, número de resgates ou número de visualizações para evitar abusos

<Info>
Os códigos de desconto criados pelo Evendeals aparecerão automaticamente no painel do Dodo Payments, em **Sales → Discounts**.
</Info>

## Pré-requisitos

Antes de configurar esta integração, certifique-se de ter:

1. Uma [conta do Dodo Payments](https://app.dodopayments.com)
2. Uma [conta do Evendeals](https://www.evendeals.com/signin)
3. Uma chave de API do Dodo Payments

## Primeiros passos

<Steps>
  <Step title="Create a Dodo Payments API Key">
    No painel do Dodo Payments, acesse **Developers → API Keys** e clique em **Create New API**. Dê um nome descritivo (por exemplo, "Evendeals") para identificá-la mais tarde.
  </Step>

  <Step title="Connect in Evendeals">
    No seu [painel do Evendeals](https://www.evendeals.com/signin), acesse **Integrations**, encontre o cartão do Dodo Payments e cole sua chave de API.
  </Step>

  <Step title="Configure Regional Discounts">
    Defina descontos percentuais para cada grupo de países e clique em sincronizar. O Evendeals criará os cupons automaticamente no Dodo Payments.

    <Check>
    Após a sincronização, abra **Sales → Discounts** no painel do Dodo Payments para confirmar que os cupons gerados aparecem. Cada cupom terá um prefixo Evendeals identificável.
    </Check>
  </Step>
</Steps>
