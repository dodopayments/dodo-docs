## Introdução

[ParityDeals](https://www.paritydeals.com/) é uma plataforma que exibe banners de desconto com base na localização para visitantes elegíveis em seu site e gera automaticamente os códigos de desconto correspondentes no Dodo Payments. Quando um visitante vê o banner, ele recebe um código que pode usar no checkout. Esses códigos aparecem no painel do Dodo Payments em **Sales → Discounts**.

<Note>
O Dodo Payments oferece o [Purchasing Power Parity](/features/purchasing-power-parity) nativo, que reduz os preços por país no checkout sem banner e sem script. O ParityDeals é destinado a merchants que querem um banner de desconto visível no próprio site ou que desejam realizar promoções de feriados e ofertas por tempo limitado.
</Note>

## Como funciona

O ParityDeals detecta a localização de um visitante, exibe um banner de desconto personalizável em seu site e gera um código de desconto que pode ser aplicado no checkout. O código é criado automaticamente na sua conta do Dodo Payments e funciona nos produtos que você configurar.

1. Um visitante acessa seu site e o ParityDeals detecta a localização dele.
2. Se o visitante for elegível para um desconto, um banner aparecerá com um código baseado na localização.
3. O visitante usa esse código no checkout, e o Dodo Payments aplica o desconto.
4. O código aparece no seu painel em **Sales → Discounts**.

## ParityDeals vs PPP nativo

O Purchasing Power Parity nativo é a forma recomendada de definir preços por país. Escolha o ParityDeals quando precisar especificamente de um banner de desconto no próprio site ou de campanhas de feriados e por tempo limitado.

| | PPP nativo | ParityDeals |
| :--- | :--- | :--- |
| Como funciona | Uma porcentagem por país, aplicada no checkout | Uma porcentagem de desconto, aplicada por meio de um código |
| Onde é configurado | Integrado ao Dodo Payments | Painel do ParityDeals |
| Banner ou script no site | Não é necessário | Necessário |
| Ofertas de feriados e por tempo limitado | Não | Sim |
| Mais indicado para | Preços corretos, sem alterações no site | Banners promocionais e ofertas sazonais |

<Info>
Você não pode incorporar o banner do ParityDeals em um checkout ou storefront hospedado pelo Dodo Payments, pois scripts personalizados não são compatíveis com esses ambientes. O banner deve ser inserido em seu próprio site ou aplicativo.
</Info>

## Pré-requisitos

Antes de configurar esta integração, certifique-se de ter:

1. Uma [conta do Dodo Payments](https://app.dodopayments.com)
2. Uma [conta do ParityDeals](https://app.paritydeals.com/)
3. Uma chave de API do Dodo Payments

## Primeiros passos

<Steps>
  <Step title="Sign up on ParityDeals">
    Acesse [app.paritydeals.com](https://app.paritydeals.com/) e crie uma conta.
  </Step>

  <Step title="Create Deals">
    Após fazer login, localize a opção para criar ofertas. No menu suspenso, selecione **"Create Deals via Dodo Payments"**.

    <Frame>
      <img src="/images/integrations/paritydeals/create-deals.png" alt="Criação de ofertas pelo Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Faça login no seu **painel do Dodo Payments** e acesse **Developers → API Keys**. Clique em **"Create New API"**.

    <Tip>
      Dê um nome descritivo à sua chave de API (por exemplo, 'ParityDeals') para identificá-la posteriormente.
    </Tip>

    <Frame>
      <img src="/images/integrations/paritydeals/api-key.png" alt="Criação de uma nova chave de API no Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Copie a chave de API criada e cole-a na interface do ParityDeals para estabelecer a conexão com sua conta do Dodo Payments.

    <Frame>
      <img src="/images/integrations/paritydeals/connect-api-key.png" alt="Conexão da chave de API com o ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Após a conexão, o ParityDeals buscará seu catálogo de produtos do Dodo Payments. Selecione os produtos que deseja associar às suas ofertas.

    <Frame>
      <img src="/images/integrations/paritydeals/select-products.png" alt="Seleção de produtos para o ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Insira a URL do seu site e, opcionalmente, selecione páginas de destino específicas onde o banner de desconto deverá aparecer. Em seguida, escolha seu tipo de oferta preferido:
    - Ofertas baseadas na localização
    - Ofertas de feriados
    - Ofertas relâmpago por tempo limitado

    <Frame>
      <img src="/images/integrations/paritydeals/deal-settings.png" alt="Configuração das ofertas" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Selecione os países nos quais deseja oferecer descontos localizados e defina a porcentagem de desconto para cada um. O ParityDeals fornece valores padrão recomendados que você pode ajustar conforme necessário.

    <Frame>
      <img src="/images/integrations/paritydeals/country-rules.png" alt="Configuração de regras de desconto por país" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Crie o design do seu banner de desconto personalizando o texto, selecionando as cores e o layout e escolhendo a posição do banner (na parte superior ou inferior da página). Esse banner será exibido para visitantes elegíveis com base nas regras configuradas.

    <Frame>
      <img src="/images/integrations/paritydeals/customize-banner.png" alt="Personalização do banner de desconto" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Após salvar sua oferta, o ParityDeals gerará um script. Adicione esse script ao código do seu site (normalmente na seção `<head>`). Esse script detecta automaticamente as localizações dos visitantes e exibe o banner de desconto apropriado.

    <Frame>
      <img src="/images/integrations/paritydeals/script.png" alt="Script de integração do ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>
