## Novos Recursos

### 1. **Preferências de Comunicação**

   Tome controle sobre como você recebe notificações com nossas novas Preferências de Comunicação. Configure notificações por email, push e no aplicativo para corresponder ao seu fluxo de trabalho.

   <Frame>
     <img src="/images/communication-preferences/overview.png" alt="Visão geral das Preferências de Comunicação mostrando configurações de notificação" />
   </Frame>

   **Principais Recursos**

   - **Designs de email reformulados**: Modelos de email modernos e frescos com chamadas claras para ação e melhor legibilidade
   - **Notificações push**: Receba alertas instantâneos em seu dispositivo móvel para eventos críticos, como novas vendas, disputas e pagamentos
   - **Controles granulares**: Escolha exatamente quais eventos acionam notificações e por quais canais
   - **Suporte a múltiplos emails**: Adicione vários endereços de email para receber notificações
   - **Preferências de email do cliente**: Configure quais emails seus clientes recebem

   **Categorias de Notificação**

   | Categoria                  | Descrição                                      |
   |----------------------------|------------------------------------------------|
   | **Vendas & Pagamentos**     | Novas vendas, pagamentos bem-sucedidos, pagamentos falhados |
   | **Pagamentos & Reembolsos** | Conclusões de pagamento, solicitações de reembolso, conclusões de reembolso |
   | **Assinaturas**             | Novas assinaturas, renovações, cancelamentos, mudanças de plano |
   | **Disputas**                | Disputa aberta, evidência necessária, disputa resolvida |

   <Check>
   Resultado: Mantenha-se informado sobre seu negócio com notificações entregues exatamente como e quando você deseja.
   </Check>

   Saiba mais: [Guia de Preferências de Comunicação](/features/communication-preferences)

### 2. **Campos Personalizados nas Sessões de Checkout**

   Colete informações adicionais dos clientes durante o checkout com campos personalizados. Adicione entradas de texto, menus suspensos, datas e mais para coletar os dados de que precisa.

   **Tipos de Campo Suportados**

   | Tipo                                              | Descrição                             | Caso de Uso                        |
   |-------------------------------------------------|-------------------------------------|------------------------------------|
   | `text`   | Entrada de texto de linha única       | Nome da empresa, notas do pedido   |
   | `number`   | Entrada numérica                     | Quantidade, idade                    |
   | `email`   | Entrada de email com validação       | Email de contato de cobrança        |
   | `url`   | Entrada de URL com validação        | Website, perfil social              |
   | `date`   | Seletor de data                      | Data de entrega, data do evento    |
   | `dropdown`   | Seleção de opções pré-definidas     | Tamanho, cor, tipo de plano        |
   | `boolean`   | Caixa de seleção para valores sim/não | Aceitação de termos, opt-in para newsletter |

   **Como Funciona**

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     custom_fields: [
       {
         name: 'company_name',
         label: 'Company Name',
         type: 'text',
         required: true
       },
       {
         name: 'team_size',
         label: 'Team Size',
         type: 'dropdown',
         options: ['1-10', '11-50', '51-200', '200+'],
         required: true
       },
       {
         name: 'newsletter',
         label: 'Subscribe to our newsletter',
         type: 'boolean',
         required: false
       }
     ],
     return_url: 'https://yoursite.com/success'
   });
   ```

   **Benefícios**

   - **Coleta de dados flexível**: Coleta qualquer informação necessária para cumprimento ou personalização
   - **Validação embutida**: Campos de email e URL validam automaticamente o formato de entrada
   - **Controle de obrigatório/opcional**: Marque campos como obrigatórios ou opcionais com base em suas necessidades
   - **Entrega via Webhook**: Valores de campos personalizados são incluídos em eventos de webhook de pagamento

   <Info>
   Os valores dos campos personalizados são retornados no objeto `custom_fields` dentro das respostas de pagamento e sessão de checkout.
   </Info>

   Saiba mais: [Campos Personalizados da Sessão de Checkout](/developer-resources/checkout-session#custom-fields)

### 3. **Suporte Expandido a Idiomas de Checkout**

   A página de checkout agora suporta **21 idiomas**, acima de 16. Alcance mais clientes em seu idioma nativo para uma melhor experiência de checkout.

   **Novos Idiomas Adicionados**

   | Idioma    | Código                   |
   |-----------|-------------------------|
   | Coreano   | `ko` |
   | Malaio    | `ms` |
   | Romeno    | `ro` |
   | Russo     | `ru` |
   | Tailandês | `th` |

   **Todos os Idiomas Suportados**

   Árabe, Chinês, Holandês, Inglês, Francês, Alemão, Hindi, Indonésio, Italiano, Japonês, Coreano, Malaio, Português, Romeno, Russo, Espanhol, Sueco, Tailandês, Turco, Ucraniano, Vietnamita.

   **Forçar um Idioma Específico**

   Use o parâmetro `force_language` para substituir a detecção automática do idioma:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     force_language: 'ko', // Force Korean language
     return_url: 'https://yoursite.com/success'
   });
   ```

   <Tip>
   Por padrão, a página de checkout detecta automaticamente o idioma preferido do cliente a partir das configurações do navegador. Use `force_language` quando quiser garantir a consistência com o idioma do seu site.
   </Tip>

   Saiba mais: [Suporte a Idiomas de Checkout](/features/checkout#supported-languages)
