## Novos Recursos 🚀

- **Checkout 2.0**: Apresentando uma experiência de checkout completamente redesenhada com:
    - Interface moderna e simplificada para uma melhor experiência do usuário
    - Novo Sistema de Coleta de Consultas que armazena parâmetros no armazenamento de sessões com IDs exclusivos (por exemplo, `sess_1a2b3c4d`)
    - Disponibilidade persistente dos dados ao longo de todo o fluxo de checkout
    - Mais melhorias planejadas para futuras versões!
  
    <Frame><img src="/images/changelog/checkout_2.png" alt="Checkout 2.0" style={{ maxHeight: '500px', width: 'auto' }} /></Frame>

- **Métodos de pagamento configuráveis**: a nova configuração `allowed_payment_method_types` permite que os merchants personalizem as opções de pagamento disponíveis durante o checkout. Consulte a documentação de [Métodos de pagamento permitidos](/features/payment-methods#configuring-payment-methods) para obter detalhes de implementação.

- **Cálculo Dinâmico de Impostos**: Cálculo em tempo real das taxas de impostos com base nos endereços de cobrança dos clientes para preços mais precisos nos links de pagamento estáticos.

- **Assinaturas Sob Demanda**: Novos endpoints de API para faturamento flexível de assinaturas (disponível para comerciantes selecionados). Saiba mais no guia de [Assinaturas Sob Demanda](/features/subscription#enabling-on-demand-subscriptions).

- **Atualizações Adicionais**:
    - Otimizações de desempenho
    - Correções de bugs
    - Melhorias gerais do sistema
