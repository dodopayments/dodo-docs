## Novos recursos
- **Atlas com código aberto**: Uma aplicação de demonstração escrita em Next.js para mostrar a integração com Dodo Payments. Explore o [Repositório no GitHub](https://github.com/dodopayments/dodo-checkout-demo) e a documentação [aqui](/developer-resources/integration-guide).
- **Seção de solicitações de recursos**: Foi introduzida uma seção de solicitações de recursos no dashboard do Dodo Payments para priorizar o roadmap do produto com base no feedback dos usuários.
- **API de logs de solicitações de Webhook**: Foram adicionadas APIs para listar e detalhar logs de solicitações de Webhook.
- **Links de pagamento estáticos**: Foram adicionados mais parâmetros de consulta aos links de pagamento estáticos para oferecer mais flexibilidade no processo de checkout. Para mais detalhes, clique [aqui](/developer-resources/integration-guide#4-static-payment-links).
- **API de listagem de assinaturas**: Foi adicionada uma API para buscar todas as assinaturas. Consulte a [Referência da API](/api-reference/subscriptions/get-subscriptions-1) para obter mais detalhes.

## Melhorias Menores e Correções de Bugs
- Aprimoradas as respostas da API de Produto e Assinatura com parâmetros adicionais.
- Implementado limite de taxa para solicitações de API, atualmente definido para 20 solicitações por segundo.
- Melhorada a documentação para ser mais amigável e fácil de navegar.
- Várias correções de bugs e melhorias menores.
