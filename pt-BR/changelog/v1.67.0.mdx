## Novos Recursos 🚀

1. **Checkout de Carrinho Misto: Produtos Únicos e de Assinatura em um Único Carrinho**  
   O checkout agora suporta a combinação de produtos com pagamento único e produtos de assinatura em um único carrinho, desbloqueando novos casos de uso poderosos de faturamento.
   
   <Frame>
   <img src="/images/changelog/mixed-checkout.png" alt="Checkout misto com produtos únicos e de assinatura" style={{ maxHeight: '500px', width: 'auto' }} />
   </Frame>
   
   ### O Que Isso Possibilita
   
   - **Taxas de configuração + assinaturas**: Cobre uma taxa de configuração única junto com uma assinatura recorrente em um único checkout
   - **Pacotes com componentes recorrentes**: Venda um produto (único) empacotado com acesso a serviços contínuos (assinatura)
   - **Combos de curso + associação**: Ofereça a compra de um curso com uma assinatura opcional de uma comunidade
   - **Acesso vitalício + assinaturas adicionais**: Combine acesso a produtos vitalício com recursos premium recorrentes opcionais
   
   ### Como Funciona
   
   Basta adicionar produtos únicos e de assinatura à sua sessão de checkout:
   

   ```javascript
   const session = await client.checkoutSessions.create({
     product_cart: [
       // One-time setup fee
       { product_id: 'prod_setup_fee', quantity: 1 },
       // Monthly subscription
       { product_id: 'prod_monthly_plan', quantity: 1 }
     ],
     customer: {
       email: 'customer@example.com',
       name: 'Jane Doe'
     },
     return_url: 'https://yourapp.com/success'
   });
   ```

   
   <Check>
   Resultado: um único fluxo de checkout que processa o pagamento único e inicia a assinatura — reduzindo atritos e aumentando as taxas de conversão.
   </Check>
   
   <Info>
   Ao misturar tipos de produtos, o pagamento único é cobrado imediatamente enquanto a assinatura segue seu ciclo de cobrança configurado (incluindo qualquer período de teste que você definiu).
   </Info>
   
   Saiba mais: [Checkout Sessions](/developer-resources/checkout-session)

2. **Portal do Cliente Unificado**  
   
   Um novo portal centralizado do cliente em [customer.dodopayments.com](https://customer.dodopayments.com) onde os clientes podem visualizar e gerenciar todas as suas compras e assinaturas em diferentes negócios no Dodo Payments.
   
   <Frame>
   <img src="/images/changelog/unified-customer-portal.png" alt="Portal do Cliente Unificado" style={{ maxHeight: '500px', width: 'auto' }} />
   </Frame>
   
   ### Recursos do Portal
   
   - **Visibilidade entre negócios**: Visualize todas as compras e assinaturas de qualquer negócio usando Dodo Payments em um só lugar
   - **Gerenciamento centralizado de assinaturas**: Gerencie assinaturas de diferentes comerciantes a partir de um único painel
   - **Histórico de faturamento unificado**: Acesse faturas e histórico de pagamentos de todas as suas compras
   - **Experiência de single sign-on**: Faça login uma vez com seu email para acessar compras de todos os comerciantes do Dodo Payments
   
   ### Como Funciona
   
   Os clientes simplesmente visitam [customer.dodopayments.com](https://customer.dodopayments.com) e inserem seu endereço de email. Eles receberão um link de login seguro que concede acesso a todas as suas compras no ecossistema Dodo Payments.
   
   <Tip>
   O Portal do Cliente Unificado complementa os portais de cliente específicos de negócios. Os clientes ainda podem acessar portais de comerciantes individuais para uma experiência personalizada, ou usar o portal unificado para uma visão consolidada.
   </Tip>
   
   <Note>
   O portal unificado usa a mesma autenticação baseada em email que os portais específicos de negócios, garantindo uma experiência consistente e segura.
   </Note>

3. **ID da Fatura na Resposta de Pagamento**  
   A resposta de pagamento agora inclui um campo `invoice_id`, facilitando a reconciliação de pagamentos com faturas e a integração com sistemas contábeis.
   

   ```json
   {
     "payment_id": "pay_2IjeQm4hqU6RA4Z4kwDee",
     "status": "succeeded",
     "invoice_id": "inv_2IsUnWGtRKFLxk7xAQeyt",
     "total_amount": 9900,
     "currency": "USD",
     // ... other fields
   }
   ```

   
   ### Casos de Uso
   
   - **Integração contábil**: Vincule diretamente pagamentos às faturas no seu software contábil
   - **Suporte ao cliente**: Encontre rapidamente a fatura associada a um pagamento ao lidar com solicitações de suporte
   - **Reconciliação**: Simplifique a reconciliação financeira ao combinar pagamentos com faturas programaticamente
   - **Conformidade**: Mantenha registros precisos vinculando pagamentos às respectivas faturas fiscais
   
   <Info>
   O campo `invoice_id` utiliza IDs de fatura específicos da Índia quando disponíveis, garantindo conformidade com os requisitos locais de faturamento.
   </Info>
   
   Saiba mais: [Get Payment Detail API](/api-reference/payments/get-payments-1)
