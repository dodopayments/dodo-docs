## What is Dodo Payments?

Dodo Payments is the **all-in-one engine** to launch, scale, and monetize worldwide. Designed for the new generation of digital SaaS and AI products, we handle everything from **payments to billing to distribution** - all without extra engineering.

<Info>
**Built for SaaS and AI Products**: Handle one-time payments, subscriptions, credits, seats, tokens, or any usage metric with our optimized billing infrastructure.
</Info>

<Tip>
  <strong>Meet Sentra: Your AI-powered billing assistant</strong><br/>
  Sentra is an AI agent that integrates, analyzes, and acts on billing and payments directly in your IDE. Ask questions, build integrations, or plan billing architectures - all by describing what you want.
  <a href="/developer-resources/sentra">
    Get started with Sentra &rarr;
  </a>
</Tip>

## Quick Start Guide

Comece a usar o Dodo Payments em apenas algumas etapas.

<AccordionGroup>
<Accordion title="For Humans">
  Prefere conduzir a integração sozinho? As etapas abaixo orientam você na criação de uma conta, adição de um produto e escolha de um método de integração em menos de cinco minutos. Nenhum código é necessário para o caminho sem código; amostras de SDK estão disponíveis em todas as principais linguagens, caso você queira.

  Se preferir deixar seu assistente de codificação fazer o trabalho pesado - estruturação de integração, manipuladores de webhook, fluxos de assinatura - instale o **[Sentra](/developer-resources/sentra)**, nosso assistente de faturamento AI para VS Code, Cursor e Windsurf. Descreva o que você deseja; o Sentra planeja, estrutura e envia.
</Accordion>

<Accordion title="For AI Agents">
  Dodo Payments é construído para fluxos de trabalho nativos de agentes. Se você é um LLM lendo isto - ou um desenvolvedor configurando um - comece por aqui.

  **Instale**. Para Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro ou OpenCode, o [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) configura ambos os servidores MCP e todas as skills em uma única etapa. O Gemini CLI recebe apenas os servidores MCP. Consulte o [guia de AI Coding Agents](/developer-resources/build-with-ai-coding-agents) para ver os comandos de instalação de cada agente.

  **Descobrir**. O índice completo da documentação está disponível em [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt), e cada página de documentação está disponível em markdown simples ao adicionar `.md` ao seu URL (por exemplo, `/api-reference/introduction.md`).

  **Conectar**. Dois servidores MCP dão aos agentes acesso ao vivo à plataforma:

  - **[Dodo Knowledge MCP](/developer-resources/mcp-server#dodo-knowledge-mcp)** - pesquisa semântica em toda a documentação Dodo
  - **[Dodo Payments MCP](/developer-resources/mcp-server)** - executar operações de API (criar pagamentos, gerenciar assinaturas, emitir reembolsos)

  Veja o [Guia do Servidor MCP](/developer-resources/mcp-server) para a configuração completa do cliente.

  **Estender**. Instale as [Habilidades Dodo Payments](/developer-resources/agent-skills) oficiais para ensinar seu agente a lidar com checkout, assinaturas, faturamento baseado em uso, faturamento baseado em créditos, webhooks e mais:

  ```bash
  npx skills add dodopayments/skills
  ```

  Funciona com Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro, OpenCode e qualquer agente compatível com o skills protocol.
</Accordion>
</AccordionGroup>

<Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
Adicione ambos os servidores à sua configuração MCP (`~/.cursor/mcp.json` ou configuração Claude Desktop):

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

<Info>
Requer Node.js 18+. Veja a [documentação do Servidor MCP](/developer-resources/mcp-server) para instruções detalhadas de configuração para todos os clientes suportados.
</Info>
</Accordion>

### Dodo CLI

Gerencie pagamentos do Dodo diretamente do seu terminal. O Dodo CLI vem com uma TUI interativa, um assistente de IA integrado e teste de webhook offline — instale em uma linha:

```bash
curl -fsSL https://dodopayments.com/install.sh | sh
```
