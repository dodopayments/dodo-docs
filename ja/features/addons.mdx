## アドオンとは？

アドオンは、顧客がメインのサブスクリプションと一緒に購入できる補足的な製品です。以下に最適です：

- **席数ベースの課金**：追加のチームメンバー、ユーザーライセンス、または同時ユーザー数
- **機能アップグレード**：プレミアム機能、高度な分析、または優先サポート
- **使用量の拡張**：追加ストレージ、APIコール、または帯域幅の割当
- **サービスアドオン**：プロフェッショナルサービス、トレーニング、または相談時間

## 主なメリット

- **柔軟な料金モデル**：ベースプランに任意のアドオンを組み合わせて高度な料金体系を構築できます。顧客のニーズの変化に合わせてアップグレードを提供し、さまざまなセグメントに対応できます。
- **収益の最適化**：関連性の高いアドオンを提示することで、ユーザーあたり平均収益（ARPU）を向上させられます。顧客が時間とともに機能を追加する際に自然なアップセルの機会を創出します。
- **管理の簡素化**：すべての料金コンポーネントを1つのダッシュボードで管理します。アドオンはチェックアウトセッションとサブスクリプション管理の両方に自動的に含まれます。
- **顧客の選択肢**：顧客が必要なアドオンだけを選択してサブスクリプションをカスタマイズできるようにし、満足度を高め、解約率を下げます。

## アドオンの作成

アドオンはDodo Paymentsのダッシュボードで別途製品として作成し、メインのサブスクリプション製品に接続します。この分離により以下が可能になります：

- 複数のサブスクリプション製品でアドオンを再利用
- 価格設定を独立して管理
- アドオンのパフォーマンスを個別に追跡
- ベースサブスクリプションに影響を与えずにアドオンを更新

### アドオンの構成

アドオンを作成する際に構成できる項目：

- **Pricing**: アドオン金額（`price`）を最小通貨単位で設定します。アドオンは親サブスクリプションのサイクルに基づいて請求されます
- **Currency**: Dodo Paymentsで請求可能な任意の通貨で基本価格を設定します。検索可能な通貨セレクターでは、**USD、GBP、EUR、INR** が上部に固定表示されます。基準通貨以外の通貨を使用する顧客には、[Adaptive Currency](/features/adaptive-currency) を通じて請求されます
- **Quantity**: 顧客はアドオンをサブスクリプションに追加する際に数量を選択します
- **Availability**: アドオンを利用できるサブスクリプション商品を制御します
- **Tax settings**: 適切な`tax_category`を設定します

## 統合例

### アドオン付きチェックアウトセッション
チェックアウトセッションを作成する際に、カスタム数量のアドオンを含めることができます：

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    {
      product_id: 'your_subscription_id',
      quantity: 1,
      addons: [
        {
          addon_id: 'your_addon_id',
          quantity: 3 // 3 additional seats
        }
      ]
    }
  ],
  // ... other checkout options
});
```

<Tip>
顧客がチェックアウトページで自分でアドオンを追加または削除できるようにするには、セッションを作成する際に[この機能フラグ](/developer-resources/checkout-session#optional-fields)を`true`に設定します。デフォルトは`false`で、サブスクリプション製品にのみ適用されます。

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'your_subscription_id', quantity: 1 }],
  feature_flags: {
    allow_editing_addons: true // customers can edit add-ons at checkout
  },
});
```

</Tip>

### アドオン付きプラン変更
既存のサブスクリプションを修正して、アドオンを追加、削除、または更新します。

```typescript
// Add add-ons to existing subscription
await client.subscriptions.changePlan('sub_123', {
  product_id: 'pdt_new',
  quantity: 1,
  proration_billing_mode: 'difference_immediately',
  addons: [
    { addon_id: 'addon_123', quantity: 2 }
  ]
});

// Remove all existing add-ons
await client.subscriptions.changePlan('sub_123', {
  product_id: 'pdt_new',
  quantity: 1,
  proration_billing_mode: 'difference_immediately',
  addons: [] // Empty array removes all existing add-ons
});
```

### 動的価格設定
アドオンの選択に基づいて総コストを動的に計算します。

```typescript
function calculateTotalCost(basePrice: number, addons: AddonSelection[]) {
  const addonTotal = addons.reduce((sum, addon) => 
    sum + (addon.price * addon.quantity), 0
  );
  return basePrice + addonTotal;
}
```

## ベストプラクティス

- **シンプルに始める**: 2〜3つのコアアドオンで開始し、顧客のフィードバックと使用状況に基づいてオプションを拡大します。
- **価格の明確さを維持する**: アドオンの価格と価値を明確に伝え、追加費用に対する理解を促します。
- **徹底的にテストする**: アドオンの組み合わせを検証し、価格計算が正確であることと、チェックアウトフローが円滑に機能することを確認します。

### デザイン考慮事項

- **明確な価値提案**: 各アドオンには顧客が容易に理解できる明確な利点があるべきです。
- **論理的なグループ化**: 関連するアドオンをチェックアウトフローでまとめます。
- **柔軟な数量**: 顧客が必要に応じてアドオンの数量を調整できるようにします。
- **透明な価格設定**: チェックアウトプロセス全体で総コストを明確に表示します。

<Info>
アドオンは、顧客とともに成長する柔軟でスケーラブルな価格モデルを作成するための強力な手段です。シンプルなユースケースから始めて、ビジネスと顧客に最適な方法を学びながら拡大しましょう。
</Info>
