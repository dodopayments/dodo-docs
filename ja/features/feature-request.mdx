私たちは[フィードバックポータル](https://feedback.dodopayments.com/)を使って機能リクエストを管理し、公開ロードマップを維持しています。このプラットフォームでは、アイデアを提出したり、見たい機能に投票したり、今後の改善の開発状況を追跡したりできます。

<Card title="Visit Our Public Roadmap" icon="external-link" href="https://feedback.dodopayments.com/">
すべての機能リクエストを表示し、アイデアに投票し、フィードバックポータルで製品のロードマップを追跡してください。
</Card>

## **新しい機能をリクエストする**

Dodo Paymentsの体験を向上させる機能のアイデアがある場合、直接フィードバックポータルで機能のリクエストを提出できます。

<img src="/images/feature-request/Feature.png" alt="機能リクエスト" style={{ maxHeight: '500px', width: 'auto' }} />

- **機能をリクエストする方法**:
    1. [フィードバックポータル](https://feedback.dodopayments.com/)にアクセスします。
    2. **"アイデアを投稿"**または**"機能リクエストを提出"**をクリックします。
    3. 次の詳細を提供します:
        - **機能名**: 機能アイデアの簡潔なタイトル。
        - **機能の説明**: 機能の説明、重要な理由とビジネスへのメリットを含む。
    4. リクエストを提出します。
- **効果的なリクエストのためのヒント**:
    - 明確かつ簡潔に。
    - 機能のビジネスへの影響を強調。
    - 可能であれば例を提供。
    - 価値を示すユースケースを含む。

## **既存の機能リクエストに投票する**

最も多くの加盟店に利益をもたらす機能を優先します。フィードバックポータルで既存の機能リクエストを閲覧し、価値があると思うものに投票できます。

- **投票方法**:
    1. [フィードバックポータル](https://feedback.dodopayments.com/)にアクセスします。
    2. 提出されたリクエストのリストを閲覧します。
    3. 支持する機能の横にある**アップボート**ボタン(👍)をクリックします。
- **投票の利点**:
    - 関心のある機能の開発優先度に影響を与える。
    - 私たちのチームが需要の高い機能を特定するのを助ける。
    - 投票した機能がリリースされると通知される。

## **製品ロードマップを表示する**

公開ロードマップを通じて機能開発の状況を把握しましょう。

- **ロードマップの機能**:
    - **計画中**: 承認され、開発が予定されている機能。
    - **進行中**: チームが現在取り組んでいる機能。
    - **完了**: 成功裏に実装され、稼働している機能。
- **アクセス方法**:
    - [フィードバックポータル](https://feedback.dodopayments.com/)にアクセスします。
    - **ロードマップ**セクションに移動して、ステータスごとに機能を表示します。
    - 機能のカテゴリと現在のステータスを閲覧します。
    - ステータス、カテゴリでフィルタリング、または特定の機能を検索します。

<Tip>
新機能の更新と重要なアイデアへの投票のために、[フィードバックポータル](https://feedback.dodopayments.com/)をブックマークしてください。
</Tip>
