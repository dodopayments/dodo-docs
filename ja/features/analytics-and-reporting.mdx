## はじめに

Dodo Payments の **Analytics & Reporting** は、ビジネスパフォーマンスのモニタリング、顧客行動の把握、データに基づく意思決定を支援します。**Home** は厳選された概要をひと目で確認できる画面で、**Analytics** は詳細なフィルター分析を行う場所です。

<CardGroup cols={2}>
<Card title="Home" icon="house" href="#home">
毎日の状況（**Today**）と、カスタマイズ可能な概要を確認できます。
</Card>
<Card title="Business Analytics" icon="chart-pie-simple" href="#analytics">
ビジネス全体の売上、顧客、サブスクリプション、リテンション、トランザクションの健全性、回収状況を確認できます。
</Card>
<Card title="Product-Level Analytics" icon="chart-mixed" href="#product-level-analytics">
個別の商品のパフォーマンス（売上、顧客、チャーン、サブスクライバー、MRR）を詳しく分析できます。
</Card>
<Card title="Page Highlight Tiles" icon="table-list" href="#page-highlight-tiles">
商品、サブスクリプション、決済などの一覧ページで、概要指標をひと目で確認できます。
</Card>
<Card title="Exportable Reports" icon="file-csv" href="#reports">
決済、返金、Payouts、Disputes などを、カスタム期間の CSV としてダウンロードできます。
</Card>
</CardGroup>

## Home

**Home** はサイドバーのランディングページで、**Today** と **Your overview** の2つのパートで構成されています。

### Today

<Frame caption="Today: your day's pulse, hour by hour">
  <img src="/images/analytics/home-today.png" alt="時間別のボリュームチャート、現金残高、次回Payoutのタイルを表示する Home Today ビュー" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

1日の状況を時間単位で確認できます。

- **Headline chart:** **Net volume** と **Gross volume** を切り替えられます（デフォルトは Net volume）。昨日の同じ時間帯の推移とともに、時間単位で表示されます。
- **Cash Position:** 現在のウォレット残高と次回Payoutの日付。

<Note>
両方のカードに情報ツールチップ（ⓘ）と「Xs 前に更新」というタイムスタンプが表示されるため、データの鮮度を常に確認できます。
</Note>

### Your Overview

<Frame caption="Your overview: a fully customizable set of metric cards">
  <img src="/images/analytics/home-overview.png" alt="国別売上、受け取ったPayouts、支出額上位の顧客、返金のカスタマイズ可能なカードを表示する Home Your overview ビュー" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

完全にカスタマイズできます。**Customize** を使用して、カードの選択、並べ替え、削除を行えます。

- **Default cards:** Net volume、Gross volume、Payments、Top customers by spend、New customers、Revenue by country、Refunds、および **Average order value**（one-time/usage の Merchant）または **MRR** と **Net New MRR**（サブスクリプションの Merchant）。
- **Controls:**
  - **Period:** Daily/Weekly またはカスタム期間。
  - **Compare:** Previous period または previous month（デフォルトで有効）。
  - **Product:** 単一の商品またはグループ。

## Analytics

サイドバーで **Home** のすぐ下にある **Analytics** から、ビジネス全体の詳細分析にアクセスできます。6つのタブで構成され、それぞれに固有のフィルターがあります。

<CardGroup cols={3}>
<Card title="Revenue" icon="chart-line">
Gross/net volume、Payouts、Refunds、Disputes、主要な市場。
</Card>
<Card title="Customers" icon="users">
アクティブな顧客と新規顧客、ARPU、主要な顧客、モデル化されたLTV。
</Card>
<Card title="Subscriptions" icon="rectangle-list">
MRR、Projected ARR、アクティブなサブスクリプション、MRRの詳細な内訳。
</Card>
<Card title="Retention" icon="arrows-rotate">
顧客と売上のチャーン、NRR/GRR、コホート、トライアルコンバージョン。
</Card>
<Card title="Success Rate" icon="circle-check">
Payment と Refund の成功率、および失敗理由の分析。
</Card>
<Card title="Recovery" icon="life-ring">
Payment retries、Dunning、Abandoned cart recovery のパフォーマンス。

### Filtering & Customization

各タブには固有のフィルターバーがあります。

- **Time Period:** プリセット期間またはカスタム期間、および **Daily/Weekly** のグループ化。
- **Compare:** Previous period または previous month（デフォルトで有効）。
- **Product:** Revenue、Subscriptions、Retention タブで利用できます。Product は複数選択に対応し、デフォルトは **All** です。

日付範囲と比較対象の選択はビジネスごとに記憶されるため、ビジネスを切り替えたり後で戻ったりしても、それぞれ最後に使用した期間が維持されます。

<Tip>
フィルターを使用して、特定のプロダクト、期間、または支払い方法に絞り込み、目的に沿ったインサイトを得られます。
</Tip>

### Revenue Tab

<Frame caption="Revenue tab: gross/net volume, payouts, and refunds">
  <img src="/images/analytics/revenue-tab.png" alt="総取引額、純取引額、受け取り済みPayouts、返金のカードとトレンドチャートを表示するRevenueタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

収益、Payouts、disputeのアクティビティを追跡して、収益の傾向を把握し、最も成果を上げている市場を特定します。**Gross/Net** ドロップダウンを使用すると、主要数値、チャート、国別ランキングを総額と純額の間で切り替えられます。

| Metric | Description |
|--------|-------------|
| **Gross volume** | 期間中に成功したすべての支払いで請求された合計金額。手数料、返金、disputeの損失を差し引く前の金額です。 |
| **Net volume** | Net volume = gross volume − fees − refunds − lost disputes。 |
| **Payouts received** | Payout = eligible sales − taxes − fees − refunds − chargebacks。 |
| **Refund rate** | Refund rate = refunded amount ÷ gross volume。 |
| **Disputes** | 見出しには結果を考慮する前のchargeback rateが表示されます。受け取ったすべてのchargebackがカウントされるため、後に勝訴したものや取り下げられたものも率を下げません（カードネットワークがリスクを評価する方法です）。コンテキストとして、勝訴・敗訴・保留中の件数が表示され、2つの期間で比較されます。Chargeback rate = chargebacks received ÷ payments。 |
| **Payments count** | Successfulステータスの支払い件数。処理中、失敗、未開始の試行は除外されます。 |
| **Average order value** | AOV = revenue ÷ number of orders。one-timeおよびusage-basedプロダクトが対象です。 |
| **Revenue by product** | 各プロダクトに帰属する総収益を、金額の高い順に表示します。 |
| **Revenue by country** | 顧客の請求先国に基づき、各国に帰属する収益を表示します。上位150か国は個別に表示され、残りは1つの「others」行にまとめられます。 |
| **Revenue by geography** | 国別の収益を地図で表示します。色が濃いほど収益が高いことを示します。 |

### Customers Tab

<Frame caption="Customers tab: active and new customers, ARPU, and top customers">
  <img src="/images/analytics/customers-tab.png" alt="アクティブ顧客、新規顧客、ARPU、支出額上位の顧客を表示するCustomersタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

顧客の獲得、維持、支出パターンを分析して、顧客戦略を最適化します。

| Metric | Description |
|--------|-------------|
| **Active customers** | 期間中のいずれかの時点で支払いを行った、または有効なサブスクリプションを保有していた顧客。 |
| **New customers** | この期間中に、あなたとの最初の成功した支払いを行った顧客。 |
| **ARPU** | ARPU = revenue ÷ active customers。 |
| **Top customers** | 期間中の収益に基づいて顧客をランキングし、上位から表示します。 |
| **New vs. returning** | New = この期間中の初回購入。Returning = 以前の期間にあなたから購入した顧客。 |
| **Modeled LTV** | 顧客がchurnするまでに見込まれる推定収益。 |

### Subscriptions Tab

継続収益を監視し、Monthly Recurring Revenue (MRR) が時間とともにどのように変化するかを把握します。

| Metric | Description |
|--------|-------------|
| **MRR** | 1か月に見込まれる継続収益。すべてのプランを月額に換算します（年間プランは1/12として計上）。one-time paymentsは除外されます。 |
| **Projected ARR** | Projected ARR = current MRR × 12。 |
| **Net New MRR** | Net New MRR = New + Expansion − Contraction − Churned。 |
| **Active subscriptions** | Trial中のものを含む、請求が有効なサブスクリプション。 |
| **New MRR** | 期間中に新規作成されたサブスクリプションによって追加されたMRR。 |
| **Expansion MRR** | 既存顧客が上位プランへ変更したりadd-onを購入したりすることで増加したMRR。 |
| **Contraction MRR** | 既存顧客がより安いプランへ変更し、サブスクリプションを継続したことで失われたMRR。 |
| **Churned MRR** | 期間中に顧客がサブスクリプションをキャンセルしたことで失われたMRR。 |

<Note>
MRRは**同時に存在するサブスクリプション**（顧客ごとに合算）を考慮し、各サブスクリプションの支払い済み期間に応じて日割り計算します。
</Note>

### Retention Tab

<Frame caption="Retention tab: churn rates, retention matrix, and NRR/GRR">
  <img src="/images/analytics/retention-tab.png" alt="ユーザーRetentionコホートマトリクス、顧客churn rate、収益churn rate、net revenue retentionを表示するRetentionタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

顧客の維持率とchurnのパターンを監視します。

| Metric | Description |
|--------|-------------|
| **User retention matrix** | 顧客を登録月（コホート）ごとにグループ化し、その後の各月でもアクティブなコホートの割合を表示します。Retention (month k) = month kにアクティブなコホート顧客 ÷ コホートサイズ。 |
| **Customer churn rate** | 期間中にキャンセルした開始時のサブスクライバーの割合。churnした顧客数も併記されます。Customer churn rate = churned subscribers ÷ 期間開始時のサブスクライバー。 |
| **Revenue churn rate** | Revenue churn rate = churned MRR ÷ starting MRR。starting MRRは、期間開始時（前期間の終了時点）における既存顧客からの継続収益です。 |
| **Net Revenue Retention (NRR)** | アップグレードを含むため、100%を超える場合があります。NRR = (starting MRR + Expansion − Contraction − Churned) ÷ starting MRR。 |
| **Gross Revenue Retention (GRR)** | アップグレードを除外するため、上限は100%です。GRR = (starting MRR − Contraction − Churned) ÷ starting MRR。 |
| **Trial conversion** | Trial conversion = 期間中に終了したtrialのうちコンバージョンした数 ÷ 期間中に終了したtrial数。trialを提供している場合のみ表示されます。 |

### Success Rate Tab

<Frame caption="Success Rate tab: payment and refund success rates with failure analysis">
  <img src="/images/analytics/success-rate-tab.png" alt="支払い成功率、支払いの内訳、支払い失敗理由、支払い方法別の成功率を表示するSuccess Rateタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

支払いと返金の成功率を監視して、取引上の問題を迅速に特定し解決します。

| Metric | Description |
|--------|-------------|
| **Payment success rate** | processor/network failureのみが分母に対して減算されます。顧客側で解決できるもの（カードの誤入力や期限切れなど）は分母から除外されます。Payment success rate = succeeded ÷ (attempts − customer-fixable failures)。 |
| **Payments breakdown** | 試行をtotal、success、failed (network)、failed (customer)、not initiatedに分けて表示します。 |
| **Payment failure reason** | 支払い失敗を理由別に分解して表示します。 |
| **By payment method** | 方法別（card、wallet、UPI、BNPL）：success rate = succeeded ÷ attempts、volume = succeeded amount。 |
| **Checkouts count** | 顧客が開始したcheckout sessionの数。完了したかどうかは問いません。 |
| **Refund success rate** | 開始された返金のうち、正常に処理された割合。 |

<Card title="Transaction Failure Reference" icon="circle-exclamation" href="/api-reference/transaction-failures">
考えられるすべての取引失敗コードとその理由を確認できます。
</Card>

<Warning>
成功率の低下や失敗の急増に気付いた場合は、失敗理由を確認して速やかに対処し、収益の損失を最小限に抑えてください。
</Warning>

### Recovery Tab

<Frame caption="Recovery tab: retries, dunning, and abandoned cart recovery">
  <img src="/images/analytics/recovery-tab.png" alt="Recoveryタブ。Recovery overview、Recovery by flow、支払い再試行、dunningの指標を表示" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

自動再試行、dunningメール、放棄されたカートのRecoveryを通じて、Dodo Paymentsがお客様に代わって回収した収益を追跡します。

| Metric | Description |
|--------|-------------|
| **Recovery overview** | 期間中に回収された収益と、全体のRecovery rateを表示します。Recovery rate = recovered ÷ recoverable failed amount。ハードdecline（アカウント閉鎖）は回収可能額から除外されます。 |
| **Recovery by flow** | 回収された収益を、再試行、dunning、放棄されたカート別に分解します。 |
| **Payment retries** | 再試行、成功した再試行、再試行成功率、維持されたサブスクリプション。 |
| **Dunning** | dunningエントリ、送信済みメール、回収収益、Recovery rate、回収までの平均時間。 |
| **Abandoned cart** | 放棄されたcheckout、回収収益、Recovery rate、回収までの平均時間。 |

<Card title="Recovery Features" icon="life-ring" href="/features/recovery/overview">
支払い再試行、dunning、放棄されたカートのRecoveryの設定について詳しく説明します。
</Card>

## Product-Level Analytics

ビジネス全体の指標に加えて、**各プロダクト**の詳細なAnalyticsを確認できます。**Products > [Select a Product]** に移動すると、そのプロダクト専用のAnalytics dashboardにアクセスできます。

</Frame>

Product analytics dashboardは5つのタブで構成されています。

<CardGroup cols={3}>
<Card title="Overview" icon="chart-line">
収益の概要、トレンドチャート、取引履歴。
</Card>
<Card title="Customers" icon="users">
支出額順にランキングした上位顧客と、詳細な内訳テーブル。

### Overview Tab

Overviewタブでは、プロダクトの財務パフォーマンスを大まかに把握できます。

- **Total Revenue**: このプロダクトが生み出した累積収益。
- **Number of Successful Payments**: 成功した取引の合計件数。
- **Revenue Trend Chart**: 収益の推移を示す30日間の折れ線グラフ。**Show Daily**ボタンで累積表示と日次表示を切り替えられます。

チャートの下には、このプロダクトのすべての支払いを一覧表示する**Transactions**テーブルがあります。

| Column | Description |
|--------|-------------|
| Payment ID | 取引の一意識別子 |
| Status | `Successful` または `Failed` |
| Amount | 通貨を含む取引金額 |
| Date (UTC) | 取引のタイムスタンプ |
| Payment Method | 使用されたCard、UPI、またはその他の方法 |
| Refund | 返金を開始するためのオプション |

### MRR Tab

プロダクトのMonthly Recurring Revenueを詳細に分解して表示します。

<Frame caption="MRR stacked bar chart showing monthly revenue composition">
  <img src="/images/product-analytics/mrr.png" alt="月別のnew、expansion、churned MRRを積み上げ棒グラフで表示するMRRタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

**MRR chart**では、継続収益の構成を月ごとの積み上げ棒グラフで可視化します。

チャートの下にある指標カードでは、詳細なインサイトを確認できます。

<Frame caption="Detailed MRR breakdown with New, Expansion, Churned, and Net New MRR">
  <img src="/images/product-analytics/mrr-breakdown.png" alt="New MRR、Expansion MRR、Churned MRR、Net New MRRとトレンドチャートを表示するMRRの内訳" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

| Metric | Description |
|--------|-------------|
| **New MRR** | 今月獲得した新規サブスクリプションによる収益と、前月比の変化。 |
| **Expansion MRR** | 既存サブスクライバーのアップグレードやプラン追加による追加収益。 |
| **Contraction MRR** | 既存サブスクライバーが完全にキャンセルせずにダウングレードしたことで失われた収益。 |
| **Churned MRR** | キャンセルされたサブスクリプションによって失われた収益。 |
| **Net New MRR** | 純粋な結果：New MRR + Expansion MRR − Contraction MRR − Churned MRR。 |

各カードにはトレンドのミニチャートと、前月と比較した変化率が表示されます。

## Downloading Reports

<Steps>
<Step title="Navigate to the relevant page">
上の表を使用して、必要なreportのページに移動します。
</Step>
<Step title="Select a time period">
<strong>Build Report</strong>をクリックし、プリセットの期間（Today、Last 7 days、Last 30 days、This monthなど）を選択するか、カレンダーでカスタムの日付範囲を指定します。
</Step>
<Step title="Download">
<strong>Download Report</strong>をクリックします。reportはCSVとしてexportされ、デバイスに保存されます。
</Step>
</Steps>

<Note>
手数料データはstandalone reportとしては利用できません。手数料（payment fees、refund fees、payout fees）の内訳は、**Payouts → Balances** の **Account Summary Report** 内のフィルターオプションから確認できます。
</Note>

## Best Practices

<Tip>
- Analyticsを定期的に確認し、傾向や異常を早期に把握します。
- フィルターを使用して、プロダクト、期間、地域間のパフォーマンスを比較します。
- Product-Level Analyticsを詳しく確認し、どのプロダクトが最も収益に貢献しているか、またどのプロダクトのchurnが最も高いかを把握します。
- データが正しくない、または不足しているように見える場合は、まずフィルターと日付範囲の設定を確認します。
</Tip>

<Warning>
不一致やデータ不足が継続する場合は、<a href="mailto:support@dodopayments.com">support@dodopayments.com</a>までお問い合わせください。
</Warning>
