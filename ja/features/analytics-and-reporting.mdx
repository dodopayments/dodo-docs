## はじめに

Dodo Paymentsの**分析と報告**ダッシュボードは、ビジネスパフォーマンスを監視し、顧客の行動を理解し、データに基づいた意思決定を行うための力を与えます。リアルタイムの指標にアクセスし、傾向を視覚化し、詳細なレポートをエクスポートすることができます—すべてが単一の直感的なインターフェースから。

<CardGroup cols={2}>
<Card title="ビジネスレベルの分析" icon="chart-pie-simple">
全体のビジネスを通じて、総収益、顧客、保持率、トランザクションの健全性を追跡します。
</Card>
<Card title="製品レベルの分析" icon="chart-mixed" href="#product-level-analytics">
個々の製品のパフォーマンス—収益、顧客、解約率、加入者、MRRに掘り下げます。
</Card>
<Card title="トランザクションの健全性" icon="circle-check">
支払いおよび返金の成功率を監視し、失敗の理由を特定します。
</Card>
<Card title="エクスポータブルレポート" icon="file-csv">
カスタム日付範囲の支払い、返金、および支払レポートをダウンロードします。
</Card>
</CardGroup>

## ビジネスレベルの分析

メインの分析ダッシュボードは、全体のビジネスに関する包括的なインサイトを提供します。**ビジネス > 分析**のサイドバーからアクセスします。

### 収益分析

収益トレンドを理解し、トップパフォーマンスを発揮している市場を特定するために、あなたの収入と支払い活動を追跡します。

<Frame caption="総収益および30日間のトレンド">
  <img src="/images/analytics/revenue.png" alt="総収益および収益トレンドチャート" />
</Frame>

- **総収益:** 過去のすべての収益と最近のトレンドをすぐに確認できます。
- **収益トレンド:** 30日間のチャートで、収入の急増や減少を見つけるのに役立ちます。

<Frame caption="収益を生み出す国トップ5および成長率">
  <img src="/images/analytics/revenue-2.png" alt="収益国および成長率チャート" />
</Frame>

- **成長率:** 月ごとの収益成長を追跡し、ビジネスのモメンタムを測ります。
- **地理的インサイト:** 収益を生み出すトップ5の国を視覚化します。

<Tip>
これらのインサイトを利用して、高パフォーマンスの地域と成長期にマーケティングや製品の努力を集中させてください。
</Tip>

### 収益内訳

周期的な収益指標を詳細な内訳で追跡します：

- **予測ARR**: 年間定期収益の予測とトレンド分析
- **MRR内訳および成長率**: 月間定期収益の分析と月ごとの成長指標
- **新しいMRRチャート**: 新規顧客収益の獲得を視覚的に表示
- **拡張MRRチャート**: 既存顧客のアップグレードおよび拡張からの収益成長を追跡
- **解約MRRチャート**: 顧客解除やダウングレードから失った収益を監視
- **ネット新規MRRチャート**: 新規、拡張、解約を組み合わせたネット収益影響

<Frame caption="収益内訳ダッシュボードにて予測ARR、MRR内訳、および成長率を表示">
  <img src="/images/analytics/revenue-breakdown.png" alt="予測ARR、MRR内訳、および成長率を表示した収益内訳ダッシュボード" />
</Frame>

###  retention分析

顧客保持と解約パターンを監視します：

- **顧客解約率**: 定期的に契約を解除する顧客の割合
- **収益解約率**: 解約やダウングレードからの失われた収益の割合
- **解約率トレンド**: 時間の経過に伴う顧客および収益の解約パターンの履歴追跡
- **ユーザー保持マトリックス**: 異なる期における顧客保持率を示すコホート分析

<Frame caption="解約率とトレンドを示す保持分析">
  <img src="/images/analytics/retention.png" alt="顧客解約率、収益解約率、解約率トレンドを表示した保持分析ダッシュボード" />
</Frame>

### 顧客分析

顧客の獲得、保持、および支出パターンを分析して、顧客戦略を最適化します。

<Frame caption="ARPU, アクティブ顧客, 顧客分割, トップ顧客">
  <img src="/images/analytics/customer.png" alt="顧客分析: ARPU, アクティブ顧客, 顧客分割, トップ顧客" />
</Frame>

- **ARPU (ユーザーあたり平均収益):** 各顧客が平均でどれだけ貢献しているかを理解します。
- **アクティブ顧客:** ビジネスに関与している顧客の数を確認します。
- **顧客分割:** 新規顧客とリピート顧客の比率を即座に確認します。
- **トップ顧客:** 最高の支出者を特定し、ターゲットを絞ったアプローチを実施します。

<Tip>
ARPUと顧客分割を監視して、保持および獲得戦略を改善しましょう。
</Tip>

### トランザクションの成功と失敗

支払いおよび返金の成功率を監視して、トランザクションの問題を迅速に特定し解決します。

<Frame caption="支払い/返金成功率、失敗理由、支払い内訳">
  <img src="/images/analytics/success-rate.png" alt="支払いと返金の成功率、失敗理由、支払い内訳" />
</Frame>

- **支払い成功率:** 成功した支払い試行の割合を追跡します。
- **返金成功率:** 成功裏に処理された返金の数を監視します。
- **失敗理由:** 迅速に一般的な問題（例: 期限切れのカード、サポートされていない方法）を特定します。

  <Card title="トランザクション失敗リファレンス" icon="circle-exclamation" href="/api-reference/transaction-failures">
    すべてのトランザクション失敗コードとその理由を取得します。
  </Card>
- **支払い内訳:** 成功したトランザクションと失敗したトランザクションの分布を視覚化します。

<Warning>
成功率の低下や失敗の急増に気付いた場合は、失敗理由を確認し、早急に対処して収益損失を最小限に抑えてください。
</Warning>

### フィルタリングとカスタマイズ

分析データを以下でフィルタリングできます：
- **製品タイプ**（単発 vs. 定期購読）
- **日付範囲**（カスタマイズ可能）
- **支払い方法**

<Tip>
フィルターを使用して、特定の製品、期間、または支払い方法に焦点を当てたインサイトを得てください。
</Tip>

## 製品レベルの分析

ビジネス全体の指標を超えて、**各製品**の詳細な分析を表示できます。**製品 > [製品を選択]**に移動して、その製品専用の分析ダッシュボードにアクセスします。

<Frame caption="製品分析の概要: 収益サマリーとトレンドチャート">
  <img src="/images/product-analytics/overview.png" alt="製品分析の概要タブ: 総収益、成功した支払い、および収益トレンドチャート" />
</Frame>

製品分析ダッシュボードは5つのタブに整理されています：

<CardGroup cols={3}>
<Card title="概要" icon="chart-line">
収益サマリー、トレンドチャート、トランザクション履歴。
</Card>
<Card title="顧客" icon="users">
支出によるトップ顧客のランクと詳細な内訳テーブル。
</Card>
<Card title="保持" icon="arrows-rotate">
顧客と収益の解約率とトレンド分析。
</Card>
<Card title="加入者" icon="rectangle-list">
すべての定期購読と状態、請求の詳細。
</Card>
<Card title="MRR" icon="chart-bar">
月間定期収益の内訳 — 新、拡張、解約、そしてネット。
</Card>
</CardGroup>

すべてのタブには**日付フィルター**（デフォルトは「すべての期間」）がサポートされているので、任意の期間に焦点を当てることができます。

### 概要タブ

概要タブは、製品の財務パフォーマンスを高レベルでスナップショットで提供します。

- **総収益**: この製品が生成した累積収益。
- **成功した支払いの数**: 成功したトランザクションの合計数。
- **収益トレンドチャート**: 時間の経過に伴う収益を示す30日間の折れ線グラフ。 **日次表示**ボタンを使用して、累積ビューモードと日次ビューモードを切り替えます。

チャートの下には、**トランザクション**テーブルに、この製品の支払いがリスト表示されます：

| カラム | 説明 |
|--------|-------------|
| 支払いID | トランザクションのユニーク識別子 |
| ステータス | `Successful` または `Failed` |
| 金額 | 通貨付きのトランザクション金額 |
| 日付（UTC） | トランザクションのタイムスタンプ |
| 支払い方法 | 使用されたカード、UPI、またはその他の方法 |
| 返金 | 返金を開始するオプション |

<Frame caption="製品の支払い履歴を示すトランザクションテーブル">
  <img src="/images/product-analytics/overview-transactions.png" alt="製品のトランザクションテーブル：支払いID、ステータス、金額、返金アクションを表示" />
</Frame>

フィルターを使用して成功したトランザクションまたは失敗したトランザクションにリストを絞り込みます。

### 顧客タブ

この製品を購入している人と彼らがどれだけ支出しているかを確認します。

<Frame caption="今月のトップ顧客：ポディウムランキングおよび顧客テーブル">
  <img src="/images/product-analytics/customers.png" alt="顧客タブ：収益による上位3顧客を示す視覚的ポディウムおよび詳細内訳テーブル" />
</Frame>

- **今月のトップ顧客**: 総支出による**上位3顧客**を強調したビジュアルポディウムが表示され、収益額、名前、メールが表示されます。
- **顧客テーブル**: 各顧客の顧客IDとこの製品の総収益を含む詳細な内訳。

### 保持タブ

この製品がその加入者をどれだけ保持しているかを理解します。

<Frame caption="顧客および収益の解約率とトレンド分析">
  <img src="/images/product-analytics/retention.png" alt="保持タブ：顧客解約率、収益解約率、解約率トレンドチャートを示す" />
</Frame>

- **顧客解約率**: 解約した加入者の割合。
- **収益解約率**: 解約やダウングレードから失われた収益の割合。
- **解約率のトレンド**: 時間経過による両方の指標を追跡する二本の線のグラフで、トレンドを見つけて是正措置を取るのに役立ちます。

### 加入者タブ

この製品に関連するすべての定期購読の完全なリスト。

<Frame caption="すべての定期購読と状態、請求の詳細を示す加入者テーブル">
  <img src="/images/product-analytics/subscribers.png" alt="加入者タブ：購読ID、顧客のメール、状態、開始日、次回の請求情報を示す" />
</Frame>

| カラム | 説明 |
|--------|-------------|
| 購読ID | 購読のユニーク識別子 |
| 顧客のメール | 加入者のメールアドレス |
| ステータス | `Active`、`Failed`、`On hold`、または`Pending` |
| 製品名 | この購読が属する製品 |
| 開始日 | 購読が開始された日 |
| 次回の請求日 | 次の更新日 |
| 次回の請求額 | 次回の更新時に支払う金額（税抜き） |

### MRRタブ

製品の月間定期収益の詳細な内訳。

<Frame caption="MRRスタックバーチャート：月ごとの収益構成を示す">
  <img src="/images/product-analytics/mrr.png" alt="MRRタブのスタックバーチャート：新、拡張、解約されたMRRを月ごとに示す" />
</Frame>

**MRRチャート**は、毎月の定期収益の構成をスタックバーチャートとして視覚化します。

チャートの下には、4つのメトリックカードが詳細なインサイトを提供します：

<Frame caption="詳細なMRR内訳：新、拡張、解約、ネット新規MRRを示す">
  <img src="/images/product-analytics/mrr-breakdown.png" alt="MRR内訳：新、拡張、解約、ネット新規MRRとトレンドチャート" />
</Frame>

| メトリック | 説明 |
|--------|-------------|
| **新MRR** | 今月取得した新規購読からの収益（月ごとの変化を含む） |
| **拡張MRR** | 既存の加入者がプランをアップグレードまたは追加したことで得られる追加収益 |
| **解約MRR** | 解約またはダウングレードされた購読から失った収益 |
| **ネット新規MRR** | ネット結果：新MRR + 拡張MRR − 解約MRR |

各カードにはトレンドミニチャートと前月比の変化率インジケーターが含まれています。

## レポート

**ビジネス > レポート**に移動して、レポーティングスイートにアクセスします。

利用可能なレポートは以下の通りです：

- **支払いレポート**: すべての処理された支払いの詳細な記録とトランザクションステータスの追跡
- **返金レポート**: 返金活動の包括的なログと詳細な返金情報
- **支払いレポート**: あなたのアカウントに対する支払いのサマリー
- **製品別販売レポート**: 収益とビジネス成長指標による販売のパフォーマンスインサイト
- **支払い失敗レポート**: 失敗した支払いの試行のサマリーと失敗理由
- **顧客レポート**: 顧客別に整理された支払いのサマリー
- **紛争レポート**: 支払いの紛争のサマリーと解決状況
- **アカウントサマリーレポート**: 完全なアカウントの概要とサマリー

<Frame caption="利用可能な報告タイプを示すレポートダッシュボード">
  <img src="/images/analytics/reports.png" alt="レポート 2.0 ダッシュボード: さまざまな報告タイプを示す" />

### 支払いレポート

詳細な支払いレポートは、各支払いの手数料やトランザクションの詳細を明確に表示します。これらは**ビジネス > 支払い**でアクセスできます。

<Frame caption="手数料およびトランザクションの詳細を示す支払いレポート">
  <img src="/images/analytics/payout.png" alt="手数料に関する詳細な情報を示す支払いレポートダッシュボード" />
</Frame>

### レポートのダウンロード

<Steps>
<Step title="レポートセクションを開く">
ダッシュボードの<strong>レポート</strong>エリアに移動します。
</Step>
<Step title="レポートタイプ & 日付範囲を選択">
必要なレポート（支払い、返金、支払い）を選択し、日付範囲を指定します。

<strong>ダウンロード</strong>をクリックして、CSV形式でレポートをエクスポートします。

</Check>
</Step>
</Steps>

## ベストプラクティス

<Tip>
- 定期的に分析を見直して、トレンドや異常を早期に発見してください。
- フィルタを使用して、製品、期間、または地理にわたるパフォーマンスを比較してください。
- 製品レベルの分析に掘り下げて、どの製品が最も多くの収益を上げ、どの製品が最も高い解約率を持っているかを理解してください。
- データに誤りや欠落がある場合は、最初にフィルターと日付範囲の設定を確認してください。
</Tip>

<Warning>
もし持続的な不一致や欠落データに気づいた場合は、<a href="mailto:support@dodopayments.com">support@dodopayments.com</a>に連絡してサポートを受けてください。
</Warning>
