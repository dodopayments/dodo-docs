## はじめに

Dodo Payments の **Analytics & Reporting** は、ビジネスパフォーマンスのモニタリング、顧客行動の把握、データに基づく意思決定を支援します。**Home** は厳選された概要をひと目で確認できる画面で、**Analytics** は詳細なフィルター分析を行う場所です。

<CardGroup cols={2}>
<Card title="Home" icon="house" href="#home">
毎日の状況（**Today**）と、カスタマイズ可能な概要を確認できます。
</Card>
<Card title="Business Analytics" icon="chart-pie-simple" href="#analytics">
ビジネス全体の売上、顧客、サブスクリプション、リテンション、トランザクションの健全性、回収状況を確認できます。
</Card>
<Card title="Product-Level Analytics" icon="chart-mixed" href="#product-level-analytics">
個別の商品のパフォーマンス（売上、顧客、チャーン、サブスクライバー、MRR）を詳しく分析できます。
</Card>
<Card title="Page Highlight Tiles" icon="table-list" href="#page-highlight-tiles">
商品、サブスクリプション、決済などの一覧ページで、概要指標をひと目で確認できます。
</Card>
<Card title="Exportable Reports" icon="file-csv" href="#reports">
決済、返金、Payouts、Disputes などを、カスタム期間の CSV としてダウンロードできます。
</Card>
</CardGroup>

## Home

**Home** はサイドバーのランディングページで、**Today** と **Your overview** の2つのパートで構成されています。

### Today

<Frame caption="Today: your day's pulse, hour by hour">
  <img src="/images/analytics/home-today.png" alt="時間別のボリュームチャート、現金残高、次回Payoutのタイルを表示する Home Today ビュー" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

1日の状況を時間単位で確認できます。

- **Headline chart:** **Net volume** と **Gross volume** を切り替えられます（デフォルトは Net volume）。昨日の同じ時間帯の推移とともに、時間単位で表示されます。
- **Cash Position:** 現在のウォレット残高と次回Payoutの日付。

<Note>
両方のカードに情報ツールチップ（ⓘ）と「Xs 前に更新」というタイムスタンプが表示されるため、データの鮮度を常に確認できます。
</Note>

### Your Overview

<Frame caption="Your overview: a fully customizable set of metric cards">
  <img src="/images/analytics/home-overview.png" alt="国別売上、受け取ったPayouts、支出額上位の顧客、返金のカスタマイズ可能なカードを表示する Home Your overview ビュー" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

完全にカスタマイズできます。**Customize** を使用して、カードの選択、並べ替え、削除を行えます。

- **Default cards:** Net volume、Gross volume、Payments、Top customers by spend、New customers、Revenue by country、Refunds、および **Average order value**（one-time/usage の Merchant）または **MRR** と **Net New MRR**（サブスクリプションの Merchant）。
- **Controls:**
  - **Period:** Daily/Weekly またはカスタム期間。
  - **Compare:** Previous period または previous month（デフォルトで有効）。
  - **Product:** 単一の商品またはグループ。

## Analytics

サイドバーで **Home** のすぐ下にある **Analytics** から、ビジネス全体の詳細分析にアクセスできます。6つのタブで構成され、それぞれに固有のフィルターがあります。

<CardGroup cols={3}>
<Card title="Revenue" icon="chart-line">
Gross/net volume、Payouts、Refunds、Disputes、主要な市場。
</Card>
<Card title="Customers" icon="users">
アクティブな顧客と新規顧客、ARPU、主要な顧客、モデル化されたLTV。
</Card>
<Card title="Subscriptions" icon="rectangle-list">
MRR、Projected ARR、アクティブなサブスクリプション、MRRの詳細な内訳。
</Card>
<Card title="Retention" icon="arrows-rotate">
顧客と売上のチャーン、NRR/GRR、コホート、トライアルコンバージョン。

Payment と Refund の成功率、および失敗理由の分析。

### Filtering & Customization

各タブには固有のフィルターバーがあります。

- **Time Period:** プリセット期間またはカスタム期間、および **Daily/Weekly** のグループ化。
- **Compare:** Previous period または previous month（デフォルトで有効）。
- **Product:** Revenue、Subscriptions、Retention タブで利用できます。Product は複数選択に対応し、デフォルトは **All** です。

<Tip>
特定の商品、期間、Payment method に絞り込むことで、目的に応じたインサイトを得られます。
</Tip>

### Revenue Tab

<Frame caption="Revenue tab: gross/net volume, payouts, and refunds">
  <img src="/images/analytics/revenue-tab.png" alt="Gross volume、Net volume、受け取ったPayouts、Refundsカードとトレンドチャートを表示するRevenueタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

収入、Payouts、Disputes の状況を追跡して、売上のトレンドを把握し、パフォーマンスの高い市場を特定できます。**Gross/Net** ドロップダウンを使用すると、主要数値、チャート、国別ランキングをGrossとNetの値で切り替えられます。

| Metric | Description |
|--------|-------------|
| **Gross volume** | 期間内に成功したすべてのPaymentで請求された合計金額。手数料、返金、Disputesの控除前の金額です。 |
| **Net volume** | Net volume = gross volume − fees − refunds − lost disputes。 |
| **Payouts received** | Payout = eligible sales − taxes − fees − refunds − chargebacks。 |
| **Refund rate** | Refund rate = refunded amount ÷ gross volume。 |
| **Disputes** | 主要数値は結果を問わないchargeback rateです。受け取ったすべてのchargebackがカウントされるため、後に勝訴したものや取り下げられたものによって低下することはありません（カードネットワークがリスクを評価する方法です）。Won / lost / pending は参考として件数で表示され、2つの期間で比較されます。Chargeback rate = chargebacks received ÷ payments。 |
| **Payments count** | Successful ステータスのPayment数。処理中、失敗、未開始の試行は除外されます。 |
| **Average order value** | AOV = revenue ÷ number of orders。one-time および usage-based の商品が対象です。 |
| **Revenue by product** | 各商品に帰属するGross revenueを、高い順に表示します。 |
| **Revenue by country** | 顧客の請求先国に基づき、各国に帰属するRevenueを表示します。 |
| **Revenue by geography** | 国別のRevenueを地図で表示します。色が濃いほど高いことを示します。 |

### Customers Tab

<Frame caption="Customers tab: active and new customers, ARPU, and top customers">
  <img src="/images/analytics/customers-tab.png" alt="アクティブな顧客、新規顧客、ARPU、支出額上位の顧客を表示するCustomersタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

顧客の獲得、リテンション、支出パターンを分析して、顧客戦略を最適化できます。

| Metric | Description |
|--------|-------------|
| **Active customers** | 期間中のいずれかの時点でPaymentを行ったか、アクティブなサブスクリプションを保持していた顧客。 |
| **New customers** | あなたとの最初のSuccessful Paymentがこの期間に発生した顧客。 |
| **ARPU** | ARPU = revenue ÷ active customers。 |
| **Top customers** | 期間内のRevenueで顧客を順位付けし、高い順に表示します。 |
| **New vs. returning** | New = この期間の初回購入。Returning = 以前の期間に購入した顧客。 |
| **Modeled LTV** | 顧客がチャーンするまでに生み出す推定Revenue。 |

### Subscriptions Tab

Recurring revenueを監視し、Monthly Recurring Revenue（MRR）が時間とともにどのように変化するかを把握できます。

| Metric | Description |
|--------|-------------|
| **MRR** | 1か月に見込まれるRecurring revenue。すべてのプランを月単位に換算します（年間プランは1/12として計上）。One-time Paymentは除外されます。 |
| **Projected ARR** | Projected ARR = current MRR × 12。 |
| **Net New MRR** | Net New MRR = New + Expansion − Contraction − Churned。 |
| **Active subscriptions** | トライアル中のものを含む、請求が有効なサブスクリプション。 |
| **New MRR** | 期間中に新しく開始されたサブスクリプションによって追加されたMRR。 |
| **Expansion MRR** | 既存顧客によるアップグレードやAdd-onの購入で増加したMRR。 |
| **Contraction MRR** | 既存顧客がより安いプランへ変更したものの、サブスクリプションを継続した場合に失われるMRR。 |
| **Churned MRR** | 期間中に顧客がサブスクリプションをキャンセルしたことで失われるMRR。 |

<Note>
MRRは **concurrent subscriptions**（顧客ごとの合計）を考慮し、各サブスクリプションの支払い済み期間に応じて日割り計算されます。
</Note>

### Retention Tab

<Frame caption="Retention tab: churn rates, retention matrix, and NRR/GRR">
  <img src="/images/analytics/retention-tab.png" alt="ユーザーリテンションコホートマトリクス、顧客チャーン率、売上チャーン率、Net Revenue Retentionを表示するRetentionタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

顧客のリテンションとチャーンのパターンを監視できます。

| Metric | Description |
|--------|-------------|
| **User retention matrix** | 顧客を登録月（コホート）ごとにグループ化し、その後の各月においてアクティブであり続けているコホートの割合を表示します。Retention（month k）= month kにアクティブなコホート顧客 ÷ コホートサイズ。 |
| **Customer churn rate** | 期間中にキャンセルした開始時サブスクライバーの割合。チャーンした顧客数も併記されます。Customer churn rate = churned subscribers ÷ subscribers at start of period。 |
| **Revenue churn rate** | Revenue churn rate = churned MRR ÷ starting MRR。starting MRRは、期間開始時（前の期間の終了時点）に既存顧客から得られるRecurring revenueです。 |
| **Net Revenue Retention (NRR)** | アップグレードを含むため、100%を超える場合があります。NRR = (starting MRR + Expansion − Contraction − Churned) ÷ starting MRR。 |
| **Gross Revenue Retention (GRR)** | アップグレードを除外するため、上限は100%です。GRR = (starting MRR − Contraction − Churned) ÷ starting MRR。 |
| **Trial conversion** | Trial conversion = trials converted ÷ trials that ended in the period。トライアルを提供している場合のみ表示されます。 |

### Success Rate Tab

<Frame caption="Success Rate tab: payment and refund success rates with failure analysis">
  <img src="/images/analytics/success-rate-tab.png" alt="Payment success rate、Payments breakdown、Payment failure reasons、Payment method別の成功率を表示するSuccess Rateタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

PaymentとRefundの成功率を監視し、トランザクションの問題を迅速に特定・解決できます。

| Metric | Description |
|--------|-------------|
| **Payment success rate** | Processor/network failureのみが分母に影響します。顧客側で修正可能な失敗（カード番号の誤りや有効期限切れ）は分母から除外されます。Payment success rate = succeeded ÷ (attempts − customer-fixable failures)。 |
| **Payments breakdown** | 試行をtotal、success、failed（network）、failed（customer）、not initiatedに分類します。 |
| **Payment failure reason** | Payment failureを理由別に分類します。 |
| **By payment method** | Payment method別（card、wallet、UPI、BNPL）：success rate = succeeded ÷ attempts、volume = succeeded amount。 |
| **Checkouts count** | 完了したかどうかを問わず、顧客が開始したCheckout session数。 |
| **Refund success rate** | 開始されたRefundのうち、正常に処理された割合。 |

<Card title="Transaction Failure Reference" icon="circle-exclamation" href="/api-reference/transaction-failures">
利用可能なすべてのトランザクション失敗コードとその理由を確認できます。
</Card>

<Warning>
成功率の低下や失敗の急増に気付いた場合は、失敗理由を確認し、Revenue lossを最小限に抑えるため速やかに対処してください。
</Warning>

### Recovery Tab

<Frame caption="Recovery tab: retries, dunning, and abandoned cart recovery">
  <img src="/images/analytics/recovery-tab.png" alt="Recovery overview、Flow別のRecovery、Payment retries、Dunning指標を表示するRecoveryタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

自動化されたRetry、Dunning email、Abandoned cart recoveryによって、Dodo Paymentsが代理で回収したRevenueを追跡できます。

| Metric | Description |
|--------|-------------|
| **Recovery overview** | 期間中に回収されたRevenueと全体のRecovery rate。Recovery rate = recovered ÷ recoverable failed amount。Hard decline（closed account）は回収可能額から除外されます。 |
| **Recovery by flow** | Retry、Dunning、Abandoned cartごとに回収Revenueを分類します。 |
| **Payment retries** | Retryの試行回数、成功したRetry、Retry success rate、救済されたサブスクリプション。 |
| **Dunning** | Dunning entry、送信メール数、回収Revenue、Recovery rate、回収までの平均時間。 |
| **Abandoned cart** | 放棄されたCheckout、回収Revenue、Recovery rate、回収までの平均時間。 |

<Card title="Recovery Features" icon="life-ring" href="/features/recovery/overview">
Payment retries、Dunning、Abandoned cart recoveryの設定方法について詳しく説明します。
</Card>

## Product-Level Analytics

ビジネス全体の指標に加えて、**各個別商品**の詳細なAnalyticsを確認できます。**Products > [Select a Product]** に移動すると、その商品の専用Analytics dashboardにアクセスできます。

<Frame caption="Product analytics overview showing revenue summary and trend chart">
  <img src="/images/product-analytics/overview.png" alt="Total revenue、Successful payments、Revenue trend chartを表示するProduct analytics overviewタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Product analytics dashboardは5つのタブで構成されています。

<CardGroup cols={3}>
<Card title="Overview" icon="chart-line">
Revenueの概要、トレンドチャート、トランザクション履歴。
</Card>
<Card title="Customers" icon="users">
支出額で順位付けされた主要顧客と、詳細な内訳テーブル。
</Card>
<Card title="Retention" icon="arrows-rotate">
顧客とRevenueのチャーン率、およびトレンド分析。
</Card>
<Card title="Subscribers" icon="rectangle-list">
ステータスと請求情報を含むすべてのサブスクリプション。
</Card>
<Card title="MRR" icon="chart-bar">
Monthly Recurring Revenueの内訳（New、Expansion、Churned、Net）。
</Card>
</CardGroup>

すべてのタブで **date filter** を使用できます（デフォルトはAll Time）。任意の期間に絞り込めます。

### Overview Tab

Overviewタブでは、商品の財務パフォーマンスを概観できます。

- **Total Revenue**: この商品によって累計で生み出されたRevenue。
- **Number of Successful Payments**: 成功したトランザクションの合計数。
- **Revenue Trend Chart**: Revenueの推移を示す30日間の折れ線グラフ。**Show Daily** ボタンで累計表示と日別表示を切り替えられます。

チャートの下にある **Transactions** テーブルには、この商品のすべてのPaymentが一覧表示されます。

| Column | Description |
|--------|-------------|
| Payment ID | トランザクションの一意識別子 |
| Status | `Successful` または `Failed` |
| Amount | Currency付きのトランザクション金額 |
| Date (UTC) | トランザクションのTimestamp |
| Payment Method | 使用されたCard、UPI、その他のPayment method |
| Refund | Refundを開始するオプション |

<Frame caption="Transactions table showing payment history for the product">
  <img src="/images/product-analytics/overview-transactions.png" alt="Payment ID、Status、Amount、Refund actionを表示するProduct transactionsテーブル" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

**Filter by status** ボタンを使用して、一覧をSuccessfulまたはFailedのトランザクションに絞り込めます。

### Customers Tab

この商品を購入している顧客と、その支出額を確認できます。

<Frame caption="Top customers of the month with podium ranking and customer table">
  <img src="/images/product-analytics/customers.png" alt="Revenueで順位付けされた上位3顧客と詳細な内訳テーブルを表示するCustomersタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

- **Top Customers of the Month**: 上位 **3顧客**をTotal spendで順位付けし、Revenue amount、名前、Emailを表示するビジュアルな表彰台です。
- **Customer Table**: 各顧客のCustomer IDと、この商品のTotal revenueを含む詳細な内訳。

### Retention Tab

この商品がサブスクライバーをどの程度維持できているかを把握できます。

<Frame caption="Customer and revenue churn rates with trend analysis">
  <img src="/images/product-analytics/retention.png" alt="Customer churn rate、Revenue churn rate、Churn rate trend chartを表示するRetentionタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

- **Customer Churn Rate**: キャンセルしたサブスクライバーの割合。
- **Revenue Churn Rate**: キャンセルとダウングレードによって失われたRevenueの割合。
- **Churn Rate Trend**: 両方の指標を時間の経過に沿って追跡する2本の折れ線グラフ。トレンドの把握と是正措置に役立ちます。

### Subscribers Tab

この商品に関連付けられたすべてのサブスクリプションの完全な一覧です。

<Frame caption="Subscribers table showing all subscriptions with statuses and billing details">
  <img src="/images/product-analytics/subscribers.png" alt="Subscription ID、Customer email、Status、Start date、Next billing informationを表示するSubscribersタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

| Column | Description |
|--------|-------------|
| Subscription ID | サブスクリプションの一意識別子 |
| Customer Email | サブスクライバーのEmail address |
| Status | `Active`、`Failed`、`On hold`、または `Pending` |
| Product Name | このサブスクリプションが属する商品 |
| Start Date | サブスクリプションが開始された日付 |
| Next Billing Date | 次回更新日 |
| Next Billing Amount | 次回更新時の請求額（Taxを除く） |

### MRR Tab

商品のMonthly Recurring Revenueの詳細な内訳です。

<Frame caption="MRR stacked bar chart showing monthly revenue composition">
  <img src="/images/product-analytics/mrr.png" alt="月ごとのNew、Expansion、Churned MRRを積み上げ棒グラフで表示するMRRタブ" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

**MRR chart** では、Recurring revenueの構成を月ごとの積み上げ棒グラフで可視化します。

チャートの下にある指標カードで、詳細なインサイトを確認できます。

<Frame caption="Detailed MRR breakdown with New, Expansion, Churned, and Net New MRR">
  <img src="/images/product-analytics/mrr-breakdown.png" alt="New MRR、Expansion MRR、Churned MRR、Net New MRRとトレンドチャートを表示するMRR breakdown" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

| Metric | Description |
|--------|-------------|
| **New MRR** | 今月獲得した新規サブスクリプションによるRevenueと、前月比の変化 |
| **Expansion MRR** | 既存サブスクライバーのアップグレードまたはプラン追加による追加Revenue |
| **Contraction MRR** | 既存サブスクライバーが完全にキャンセルせずダウングレードしたことで失われたRevenue |
| **Churned MRR** | キャンセルされたサブスクリプションによって失われたRevenue |
| **Net New MRR** | New MRR + Expansion MRR − Contraction MRR − Churned MRRによる純増減 |

各カードには、トレンドのミニチャートと前月比の変化率が表示されます。

## Page Highlight Tiles

ダッシュボードの多くの一覧ページでは、上部に **highlight tiles** が表示されるようになりました。Analytics dashboardを開かなくても主要な概要指標をひと目で確認できます。タイルには、ページで有効になっているフィルターが反映されます。

| Page | Highlight Tiles |
|------|-----------------|
| **Products** | All Products、Active Products、Archived Products |
| **Add-ons** | All Add-Ons、Active Add-Ons、Linked to Products |
| **Collections** | All Collections、Active Collections、Archived Collections |
| **Subscriptions** | Active Subscriptions、On Hold、Cancelled |
| **Payments** | Successful Payments、Payment Volume、Failed Payments |
| **Refunds** | Successful Refunds、Refund Volume、Failed Refunds |
| **Disputes** | Disputes Created、Won、Accepted、Lost |

<Note>
「Active」な商品、Add-on、Collection、Meterとは、少なくとも1回のSuccessful Paymentに参加したものを指します。
</Note>

## Reports

各Reportのページには **Build Report** ボタンがあります。該当するセクションに移動して、必要なReportにアクセスし、ダウンロードしてください。

各Reportは、該当する場合、Payment method、Status、Product type、Failure type、Dispute status、Currencyでフィルターし、CSVとしてダウンロードできます。

| Report Type | Description | Where to find it |
|-------------|-------------|------------------|
| **Payment Report** | Billing address、Card details、USD-equivalent amount、Settlement details、Fees、Failure codesを含む、処理済みすべてのPaymentの詳細記録。 | **Transactions → Payments** |
| **Refund Report** | Refundの詳細情報を含む、すべてのRefund activityの包括的なログ。 | **Transactions → Refunds** |
| **Disputes Report** | Resolution statusとEvidence detailsを含むPayment disputesの概要。 | **Transactions → Disputes** |
| **Customer Report** | 顧客ごとに整理されたPayment、Refund、Disputeの概要。 | **Sales → Customers** |
| **Payout Report** | Ledger eventごとのFeesの内訳を含む、アカウントへのPayoutの概要。 | **Payouts** |
| **Account Summary Report** | Event type、Amount、Referencesを含む、Balance ledger entryの詳細。 | **Payouts → Balances** |

## Downloading Reports

<Steps>
<Step title="Navigate to the relevant page">
上の表を使用して、必要なReportのページに移動します。
</Step>
<Step title="Select a time period">
<strong>Build Report</strong> をクリックし、プリセット期間（Today、Last 7 days、Last 30 days、This monthなど）を選択するか、カレンダーでカスタム期間を指定します。
</Step>
<Step title="Download">
<strong>Download Report</strong> をクリックします。ReportがCSVとしてエクスポートされ、デバイスに保存されます。
</Step>
</Steps>

<Note>
Fee dataはスタンドアロンReportとしては利用できません。Fees（Payment fees、Refund fees、Payout fees）の内訳は、**Payouts → Balances** の **Account Summary Report** 内にあるフィルターオプションから確認できます。
</Note>

## Best Practices

<Tip>
- Analyticsを定期的に確認し、トレンドや異常を早期に発見します。
- フィルターを使用して、商品、期間、地域ごとのパフォーマンスを比較します。
- Product-level analyticsを詳しく確認し、どの商品が最も多くのRevenueを生み、どの商品でチャーンが最も高いかを把握します。
- データが不正確または欠落しているように見える場合は、まずフィルターと期間の設定を確認します。
</Tip>

<Warning>
不一致やデータ欠落が継続する場合は、<a href="mailto:support@dodopayments.com">support@dodopayments.com</a> までお問い合わせください。
</Warning>
