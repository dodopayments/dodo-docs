<Info>
Framerの権限により、支払い顧客向けにFramerテンプレートのリミックスリンクが解除されます。テンプレートをDodo Paymentsにアップロードし、製品に権限を付与すると、顧客はテンプレートを自分のFramerアカウントにクローニングできるリミックスリンクを受け取ります。
</Info>

## 配信内容

- アップロードしたFramerテンプレートへのユニークなリミックスリンク。
- 顧客はそのリンクをクリックして、自分のFramerワークスペースにテンプレートをリミックスします。
- キャンセルまたは返金の場合、リミックスリンクは無効化されます。

一般的な用途には、有料のFramerランディングページテンプレート、ポートフォリオキット、コンポーネントライブラリが含まれます。

## Framerの接続

テンプレート権限を初めて作成するときに、Framerは自動的に接続されます。別のOAuthステップはありません。

<Steps>
<Step title="Open Entitlements">
Dodo Paymentsのダッシュボードで、**Entitlements**に移動し、**+**をクリックします。
</Step>

<Step title="Pick Framer">
**Framer Template**を統合として選択します。
</Step>

<Step title="Grab the remix link from Framer">
Framerプロジェクトを開きます。左上のメニューから、**File → Copy Remix Link**に移動します。これにより、誰でもプロジェクトを自分のFramerアカウントにコピーできる公開リミックスURLが生成されます — Dodo Paymentsが支払い顧客に共有するリンクです。

<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">
<img src="/images/entitlements/framer/copy-remix-link.png" alt="コピーリミックスリンクオプションが強調表示されたFramerファイルメニュー" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Add the template and create the entitlement">
Dodo Paymentsダッシュボードに戻り、**Template**ドロップダウンからテンプレートを選択します。新しいテンプレートの場合、コピーしたリミックスリンクを貼り付けて登録します。権限に**名前**を付け、**Create Entitlement**をクリックします。

<Frame>
<img src="/images/entitlements/framer/create.png" alt="テンプレートピッカーと名前フィールド付きのFramerテンプレート権限フォーム" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Dodo Paymentsはテンプレートを登録し、プログラム的に参照できる`framer_template_id`を返します。
</Step>
</Steps>

## 顧客フロー

1. 顧客がチェックアウトを完了します。
2. Dodo Paymentsは`pending`の付与を作成し、その顧客に結び付けられたユニークなリミックスリンクを発行します。
3. リミックスリンクが設定されると、付与は`delivered`に移行し、リンクは顧客のメールとポータルに含まれます。
4. 顧客はリンクをクリックし、Framerにサインインしてテンプレートをリミックスします。
5. 取り消されると、リミックスリンクは無効化されます。すでにリミックスされたコピーは顧客のFramerアカウントに残りますが、Framerはそれらを取り消す方法を公開していません。

## 必要な設定

| フィールド | 必須 | 説明 |
|---|---|---|
| `framer_template_id` | はい | テンプレートをアップロードした際に返されるテンプレートID。 |

## APIによる作成

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Portfolio Kit',
  integration_type: 'framer',
  integration_config: {
    framer_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Portfolio Kit",
    integration_type="framer",
    integration_config={"framer_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Portfolio Kit"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFramer),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFramerConfigParam{
      FramerTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

[`entitlement_grant.*` webhookイベント](/developer-resources/webhooks/intents/entitlement-grant)を参照してください。Framerの付与は`pending`で届き、リミックスリンクが設定されると`delivered`に移行します。

## トラブルシューティング

<AccordionGroup>
<Accordion title="Customer's remix link doesn't work">
リミックスリンクは一度だけ使用可能で、顧客に結びついています。リミックスする前にリンクを消去した場合、付与を取り消して再発行します。
</Accordion>

<Accordion title="Refunded customer still has a remixed copy">
これは予想通りです。Framerはリミックスしたプロジェクトを顧客のプロジェクトとして扱います。Dodo Paymentsは元のリンクを無効化しますが、顧客アカウントのコピーを削除することはできません。
</Accordion>
</AccordionGroup>
