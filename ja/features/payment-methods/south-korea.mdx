韓国の顧客は国際的な支払い方法よりも、ローカルウォレットや国内カードを強く好みます。Dodo Paymentsは主要な韓国ウォレット、**PAYCO**、**Naver Pay**、**Kakao Pay**に加え、**韓国のローカルカード**や国際カードをサポートし、すべて**KRW**（韓国ウォン）で請求されます。

## 韓国の支払い方法が重要な理由

韓国の買い物客はカード情報を入力するよりも、Kakao PayやNaver Payのようなローカルウォレットで決済することが圧倒的に多いです。

多くの韓国カードはローカルネットワーク上で動作しています。韓国のローカルカードをサポートすることで、国際的なレールでは処理できないカードの拒否を避けることができます。

なじみのあるローカル方法を提供することで、韓国のお客様のチェックアウト時の摩擦や放棄を減らします。

## サポートされる方法

| 方法 | 種類 | サブスクリプション | 最低額 |
| :----- | :--- | :-----------: | :--------- |
| **Kakao Pay** | ウォレット | はい | 約$1.00 |
| **Naver Pay** | ウォレット | はい | 約$1.00 |
| **PAYCO** | ウォレット | いいえ | 約$1.00 |
| **韓国のローカルカード** | カード | はい | 約$1.00 |
| **クレジット & デビットカード** | カード (国際) | はい | 約$1.00 |

ウォレットの利用可能性は取引の種類に依存します。**Kakao Pay**と**Naver Pay**はサブスクリプションに提供され、**PAYCO**は一回払いに提供されます。すべて**KRW**の請求通貨を必要とします。

## 設定

### API メソッドタイプ

| タイプ | 説明 |
| :--- | :---------- |
| `kakao_pay` | Kakao Payウォレット |
| `naver_pay` | Naver Payウォレット |
| `payco` | PAYCOウォレット |
| `credit` | クレジットカード（韓国のローカルカードを含む） |
| `debit` | デビットカード（韓国のローカルカードを含む） |

### 例: 韓国に焦点を当てたチェックアウト

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  allowed_payment_method_types: [
    'kakao_pay',
    'naver_pay',
    'payco',
    'credit',
    'debit'
  ],
  billing_currency: 'KRW',
  billing_address: {
    country: 'KR',
    zipcode: '06236'
  },
  return_url: 'https://example.com/success'
});
```

### 要件

韓国の支払い方法がチェックアウト時に表示されるために：

1. **請求国**が韓国 (`KR`)
2. **通貨**がKRW
3. 別の通貨で設定されたマーチャントの場合：**Adaptive Currency**が有効になっている必要があります。そうすることで、顧客がKRWで請求されます。

別の通貨で価格設定されており、Adaptive Currencyが有効でない場合、韓国の顧客はKRWで請求されず、韓国のウォレットは利用できません。

KRWは小数点のない通貨です。金額は少額単位なしの整数で表されます。KRWの金額を送受信する場合は、100で割らずに整数値として扱ってください。

## ベストプラクティス

韓国のお客様には、ローカルウォレットを主要なオプションとするべきです。Kakao PayとNaver Payは、ほとんどの韓国の買い物客にとって最もなじみのあるチェックアウト方法です。

常に`credit`と`debit`を含めて、好みのウォレットを持たない顧客や韓国のローカルカードで支払う顧客がチェックアウトを完了できるようにします。

韓国の支払い方法にはKRWが必要です。カタログが別の通貨で設定されている場合は、Adaptive Currencyを有効にして、韓国の顧客がKRWで見積もりされたり請求されたりするようにしてください。

Kakao PayやNaver Payをサブスクリプションに、PAYCOを一回払いに使用します。三者を全て含めることで、Dodoはチェックアウトのコンテキストに応じて適切なオプションを提示できます。

## トラブルシューティング

**確認事項：**
1. 請求国が`KR`に設定されているか？
2. 通貨が`KRW`に設定されているか？
3. 別の通貨で価格設定されている場合：Adaptive Currencyが有効か？
4. ウォレット (`kakao_pay`, `naver_pay`, または`payco`) が`allowed_payment_method_types`に含まれているか？

**解決策：** 請求先住所に`country: "KR"`と`billing_currency: "KRW"`があることを確認します。

**原因：** PAYCOは一回払いのみ提供されます。定期請求にはKakao PayやNaver Payを使用してください。

**解決策：** 定期購入のチェックアウトには`kakao_pay`と`naver_pay`を`allowed_payment_method_types`に含めてください。

一部の韓国カードは国際的なレールで処理できない国内ネットワークで動作しています。

**解決策：** 韓国のローカルカードが正しくルーティングされるように`credit`と`debit`を有効にしたままにします。
