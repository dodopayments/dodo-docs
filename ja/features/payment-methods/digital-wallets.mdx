デジタルウォレットは、顧客がデバイスに保存された支払い方法を使用してワンタップで支払うことを可能にします。コンバージョン率が高く、トークン化による強力なセキュリティ、および合理化されたチェックアウト体験を提供します。

## 対応ウォレット

| ウォレット | 利用可能地域 | 通貨 | 定期購読 | セットアップ必要 |
| :----- | :----------- | :--------- | :-----------: | :------------- |
| **Apple Pay** | 世界中（インドを除く） | すべて | はい | ドメインの検証 |
| **Google Pay** | 世界中（インドを除く） | すべて | はい | なし |
| **Amazon Pay** | 世界中（インドを除く） | USD | いいえ | なし |
| **Cash App Pay** | 米国のみ | USD | いいえ | なし |
| **RevolutPay** | 世界中 | GBP | いいえ | なし |

<Warning>
**PayPalサポート一時停止中**: PayPalは、新しい取引には一時的に利用できません。
</Warning>

## Apple Pay

Apple Payでは、顧客がApple Walletに保存されたカードを使用して、Face IDまたはTouch ID認証で支払うことができます。

### 要件
- **デバイス**: iOS 17以上、iPadOS 17以上、macOSのSafari 17以上
- **プロトコル**: HTTPSが必要
- **ドメイン**: Appleによる検証が必要

### ドメインの検証

<Steps>
<Step title="ドメイン関連ファイルをダウンロード">
[Apple Payのドメイン関連ファイルをダウンロード](http://checkout.dodopayments.com/.well-known/apple-developer-merchantid-domain-association)します。
</Step>

<Step title="ファイルをドメインにホスト">
サーバーにアップロードします: 

```
https://yourdomain.com/.well-known/apple-developer-merchantid-domain-association
```

ファイルはリダイレクトなしでアクセスでき、`Content-Type: application/octet-stream`または`text/plain`で提供される必要があります。
</Step>

<Step title="アクティベーションをリクエスト">
**support@dodopayments.com**にメールを送信し:
- あなたの本番ドメイン（例: `https://yourdomain.com`）
- ファイルがホストされていることの確認

私たちは、1〜2営業日内にApple Payを検証および有効化します。
</Step>

<Step title="統合をテスト">
確認後:
1. Appleデバイスでチェックアウトを開く
2. Apple Payボタンが表示されていることを確認
3. テスト取引を完了
</Step>
</Steps>

<Warning>
ドメインの検証が完了するまでApple Payはチェックアウトに表示されません。起動時にこれを計画してください。
</Warning>

### 設定

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['apple_pay', 'credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

## Google Pay

Google Payでは、顧客が自分のGoogleアカウントに保存されたカードを使用して、内蔵の詐欺防止機能で支払うことができます。

### 要件
- **ブラウザ**: Chrome（デスクトップ/モバイル）、Safari、Firefox
- **デバイス**: Google Payアプリを持つAndroidデバイス
- **設定**: Chromeで「支払い方法があるかどうかをサイトが確認することを許可」が有効

### 設定

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['google_pay', 'credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

<Info>
Google Payのためのドメインの検証は不要—アカウントがライブになれば自動的に機能します。
</Info>

## Amazon Pay

Amazon Payでは、顧客が自身のAmazonアカウントの認証情報と保存された支払い方法を利用して、なじみのあるチェックアウト体験を得ることができます。

### 制限
- **通貨**: USDのみ
- **定期購読**: サポートされていない
- **地域**: インドでは利用できない

### 設定

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['amazon_pay', 'credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

## Cash App Pay

Cash App Payは、米国の消費者の間で人気のあるpeer-to-peer決済を行うCash Appからの支払いを可能にします。

### 制限
- **地域**: 米国のみ
- **通貨**: USDのみ
- **定期購読**: サポートされていない

### 設定

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['cashapp', 'credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

## RevolutPay

RevolutPayは、Revolutユーザーに迅速でシームレスな支払いを提供し、既存のRevolutアカウントの残高やリンクされたカードを活用します。

### 制限
- **通貨**: GBPのみ
- **定期購読**: サポートされていない

### 設定

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['revolut_pay', 'credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

## テスト

### Apple Pay テスト

<Steps>
<Step title="テストモードを使用">
Dodo Paymentsのダッシュボードでテストモードを有効にします。
</Step>

<Step title="Apple Walletにカードを追加">
Apple Walletに実際のカードを追加します。テストモードでは、カードは請求されません。
</Step>

<Step title="テスト購入を完了">
Appleデバイスでチェックアウトを開き、Apple Payのフローを完了します。
</Step>
</Steps>

<Warning>
Apple PayはHTTPSを必要とします。正しいSSL設定がないと`localhost`には表示されません。
</Warning>

### Google Pay テスト

<Steps>
<Step title="テストカードグループに参加">
[Google Payテストカードグループに参加](https://groups.google.com/g/googlepay-test-mode-stub-data)して、テストカードを自動的にあなたのウォレットに追加します。
</Step>

<Step title="テストモードを有効にする">
Dodo PaymentsのテストAPIキーを使用します。
</Step>

<Step title="テスト購入を完了">
Google Payでテストカードの1つを選択し、取引を完了します。
</Step>
</Steps>

### Amazon Pay & Cash App Pay

テストAPIキーを使用し、標準のチェックアウトフローに従ってください。テスト取引は実際の請求額なしでシミュレートされます。

## SDKサポート

### Web SDKs
すべてのデジタルウォレットは、以下でフルサポートされています:
- オーバーレイチェックアウト
- インラインチェックアウト
- 直接API統合

### モバイルSDKs

<Warning>
**React Nativeの制限:** Apple Pay、Google Pay、Cash App Pay、UPIは、React Native SDKでは**現在サポートされていません**。これらの方法が必要なモバイルアプリには、ウェブベースのチェックアウトオーバーレイを使用してください。
</Warning>

ネイティブモバイルサポートを考慮する際は:
- WebViewでチェックアウトを開く
- ウェブコンテキストで[オーバーレイチェックアウト](/developer-resources/overlay-checkout)を使用
- プラットフォームネイティブのApple Pay / Google Pay SDKを別々に実装する

## ベストプラクティス

<AccordionGroup>
<Accordion title="モバイルでウォレットを優先する">
モバイルユーザーはApple PayとGoogle Payを期待します。モバイルチェックアウトでは、これらのオプションを明示的に表示してください。
</Accordion>

<Accordion title="ドメインの検証を早期に完了する">
Apple Payはドメインの検証を必要とします。ローンチ日まで待たないで—開発中にプロセスを開始してください。
</Accordion>

<Accordion title="常にカードフォールバックを含める">
すべての顧客がデジタルウォレットを持っているわけではありません。常に`credit`および`debit`を許可されている方法に含めてください。
</Accordion>

<Accordion title="実際のデバイスでテストする">
シミュレーターはウォレットの動作を完全には再現しません。起動前に実際のiOSおよびAndroidデバイスでテストしてください。
</Accordion>

<Accordion title="ウォレットの利用不可を優雅に処理する">
ウォレットが利用できない場合（誤ったデバイス、カードが保存されていないなど）、他の支払いオプションが見えるようにしてください。
</Accordion>
</AccordionGroup>

## トラブルシューティング

<AccordionGroup>
<Accordion title="Apple Payボタンが表示されない">
**確認:**
1. Dodo Paymentsでドメインが確認されていますか？
2. HTTPSを使用していますか？
3. デバイスはiOS 17+ / Safari 17+ / iPadOS 17+ですか？
4. 顧客はApple Walletにカードを持っていますか？
5. `apple_pay`は`allowed_payment_method_types`に含まれていますか？

**解決策:** ドメインの検証を完了し、HTTPSを確認してください。本物のAppleデバイスでテストしてください。
</Accordion>

<Accordion title="Google Payボタンが表示されない">
**確認:**
1. Chromeまたは互換性のあるブラウザを使用していますか？
2. 顧客はGoogle Payにカードを持っていますか？
3. Chromeの設定「支払い方法を確認することをサイトに許可」が有効ですか？
4. `google_pay`は`allowed_payment_method_types`に含まれていますか？

**解決策:** ブラウザの互換性および顧客のGoogle Pay設定を確認してください。
</Accordion>

<Accordion title="ウォレット支払いの失敗">
**一般的な原因:**
- ウォレット内のカードが期限切れまたは無効
- 銀行によって取引が拒否された
- ネットワーク接続の問題

**解決策:** 顧客はウォレット内のカードを確認するか、別の支払い方法を試みる必要があります。
</Accordion>

<Accordion title="誤ったデバイスタイプ">
デジタルウォレットは互換性のあるデバイスでのみ表示されます:
- Apple Pay: Appleデバイスのみ
- Google Pay: ChromeブラウザまたはAndroidデバイス

**解決策:** これは予期される動作です。カードフォールバックが利用可能であることを確認してください。
</Accordion>
</AccordionGroup>
