カード決済はオンライン決済の基盤であり、世界中で受け入れられ、顧客から信頼されています。Dodo Paymentsは、組み込みの不正防止とPCI準拠を備えたすべての主要カードネットワークをサポートします。

## 設定

以下の値を`allowed_payment_method_types`で使用してください:

| タイプ | 説明 |
| :--- | :---------- |
| `credit` | すべてのクレジットカード |
| `debit` | すべてのデビットカード |

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

<Tip>
特別な理由がない限り、`credit`と`debit`の両方を含めてください。デビットカードは多くの顧客に好まれ、手数料が低くなることが多いです。
</Tip>

## 3Dセキュア認証

3Dセキュア（3DS）は、カード保有者の身分を確認することで不正行為やチャージバックを減少させる認証レイヤーを追加します。

### 3DSがトリガーされる条件

3DSは次の場合に自動的にトリガーされます:
- カードネットワークによって要求される
- 地域規制（例：ヨーロッパのPSD2）によって要求される
- 取引が高リスクとフラグ付けされる

### 3DSの強制

すべての取引で3DSを要求することができます:

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  force_3ds: true,
  return_url: 'https://example.com/success'
});
```

<Note>
すべての取引で3DSを有効にすることで不正を減少させますが、一部の顧客は認証中に離脱するため、コンバージョンが若干減少する可能性があります。
</Note>

## 保存済み支払い方法

顧客は、将来のチェックアウトを迅速化するためにカードを保存できます。

<CardGroup cols={3}>
<Card title="トークン化された" icon="lock">
元のカード番号は一切保存されません。
</Card>
<Card title="PCI準拠" icon="shield-check">
Dodoがすべてのコンプライアンスを処理します。
</Card>
<Card title="顧客スコープ" icon="user">
特定の顧客に紐付けられたカード。
</Card>
</CardGroup>

### 保存済みカードを有効にする

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  show_saved_payment_methods: true,
  customer: { customer_id: 'cus_existing_123' },
  return_url: 'https://example.com/success'
});
```

### ワンクリック購入

```javascript
// Get customer's saved payment methods
const methods = await client.customers.getPaymentMethods('cus_123');

// Use saved card for instant checkout
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  customer: { customer_id: 'cus_123' },
  payment_method_id: methods[0].payment_method_id,
  confirm: true,
  return_url: 'https://example.com/success'
});
```

## トラブルシューティング

<AccordionGroup>
<Accordion title="カードが却下されました">
**原因:** 残高不足、カードの期限切れ、不正なCVV、銀行の不正防止。


**解決策:** 顧客に詳細を確認するように依頼するか、別のカードを試すように促します。
</Accordion>

<Accordion title="3DS認証に失敗しました">
**原因:** 顧客が放棄した、銀行システムが利用できない、タイムアウト。


**解決策:** 再試行するか、顧客に銀行に連絡するように依頼します。
</Accordion>

<Accordion title="カードがサポートされていません">
**原因:** 地域カードがサポートされていない、プリペイド制限。


**解決策:** 顧客が主要なネットワークの別のカードを試すように促します。
</Accordion>
</AccordionGroup>
