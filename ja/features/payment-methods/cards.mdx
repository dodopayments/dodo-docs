カード決済はオンライン決済の基盤であり、世界中で利用され、顧客から信頼されています。Dodo Paymentsは、組み込みの不正利用対策とPCIコンプライアンスにより、主要なカードネットワークすべてに対応しています。

## 対応カードネットワーク

### グローバルネットワーク

| ネットワーク | 対応範囲 |
| :------ | :------- |
| **Visa** | 世界的なリーダー、世界で40億枚以上のカード |
| **Mastercard** | 世界中で利用可能、高度なセキュリティ機能 |
| **American Express** | プレミアムカード会員、高い利用額 |
| **Discover** | 米国中心、世界で拡大中 |
| **JCB** | 日本で主要、アジア全域に拡大中 |
| **UnionPay** | 中国で圧倒的なシェア、80億枚以上のカード |
| **Diners Club** | 海外旅行の多いプレミアム層 |

### 地域ネットワーク

| ネットワーク | 地域 |
| :------ | :----- |
| **Interac** | カナダのデビットネットワーク |
| **Cartes Bancaires** | フランスの国内ネットワーク |
| **Korean Local Cards** | 韓国の国内ネットワーク |
| **Rupay** | インドの国内ネットワーク |

## 設定

`allowed_payment_method_types`で以下の値を使用します。

| 種類 | 説明 |
| :--- | :---------- |
| `credit` | すべてのクレジットカード |
| `debit` | すべてのデビットカード |

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  allowed_payment_method_types: ['credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

<Tip>
特別な理由がない限り、`credit`と`debit`の両方を含めてください。多くの顧客はデビットカードを好み、手数料も低いことがよくあります。
</Tip>

## 3D Secure認証

3D Secure（3DS）は、カード保有者の本人確認を行う認証レイヤーを追加し、不正利用やチャージバックを削減します。

### 3DSが実行されるタイミング

3DSは次の場合に自動的に実行されます。
- カードネットワークによって要求された場合
- 地域の規制（欧州のPSD2など）によって要求された場合
- 取引が高リスクと判定された場合

### 3DSの強制

すべての取引で3DSを必須にできます。

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  force_3ds: true,
  return_url: 'https://example.com/success'
});
```

<Note>
すべての取引で3DSを有効にすると不正利用は減少しますが、認証中に離脱する顧客がいるため、コンバージョンがわずかに低下する可能性があります。
</Note>

### 認証失敗への対応

支払いに3DS認証が必要な場合、成功または失敗する前に、支払いはいくつかの中間状態を経ます。

| ステータス | 意味 | 対応 |
|--------|---------|------------|
| `requires_customer_action` | 顧客が3DSチャレンジを完了する必要がある | チェックアウト中に顧客に認証を完了してもらう |
| `requires_payment_method` | 顧客が決済方法を一度も提供しなかった（詳細を入力しなかった、またはプロンプトを離脱した）—通常は拒否ではなく離脱 | 顧客に再度アプローチしてチェックアウトを完了してもらう。[放棄カートの回収](/features/recovery/abandoned-cart-recovery)を参照 |

認証が完了しない場合、支払いは次のいずれかの拒否コードで失敗します。

- `AUTHENTICATION_FAILURE` — 顧客を認証できなかった。
- `AUTHENTICATION_REQUIRED` — 認証が必要だったが実行されなかった。
- `AUTHENTICATION_TIMEOUT` — 顧客が時間内に応答しなかった。

それぞれの推奨対応については、[取引失敗](/api-reference/transaction-failures)リファレンスを参照してください。

#### チェックアウト時と更新時

- **チェックアウト時（顧客が присутствする場合）：** 顧客がその場にいるため、チェックアウト中に3DSチャレンジが表示されます。失敗した場合は、再試行するか別のカードを使うよう顧客に案内してください。
- **サブスクリプション更新時（顧客が присутствしない場合）：** 顧客がその場にいないため、3DSチャレンジをリアルタイムで表示できません。更新に認証が必要な場合、サブスクリプションは`on_hold`に移行します。顧客に戻って支払い方法を更新してもらうことで復旧できます。[支払い失敗への対応](/developer-resources/handle-payment-failures)および[サブスクリプションの督促](/features/recovery/subscription-dunning)を参照してください。

## 保存済み決済方法

顧客はカードを保存して、次回以降のチェックアウトを迅速に行えます。

<CardGroup cols={3}>
<Card title="Tokenized" icon="lock">
元のカード番号が保存されることはありません。
</Card>
<Card title="PCI Compliant" icon="shield-check">
Dodoがすべてのコンプライアンスに対応します。
</Card>
<Card title="Customer-Scoped" icon="user">
特定の顧客に紐付けられたカード。
</Card>
</CardGroup>

### 保存済みカードを有効にする

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  show_saved_payment_methods: true,
  customer: { customer_id: 'cus_existing_123' },
  return_url: 'https://example.com/success'
});
```

### ワンクリック購入

```javascript
// Get customer's saved payment methods
const methods = await client.customers.retrievePaymentMethods('cus_123');

// Use saved card for instant checkout
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  customer: { customer_id: 'cus_123' },
  payment_method_id: methods.items[0].payment_method_id,
  confirm: true,
  return_url: 'https://example.com/success'
});
```

## トラブルシューティング

<AccordionGroup>
<Accordion title="Card declined">
**原因：** 残高不足、カードの有効期限切れ、CVVの誤り、銀行の不正利用対策。

**解決策：** 顧客に詳細を確認してもらうか、別のカードを試してもらってください。具体的な拒否`Error Code`と推奨対応については[取引失敗](/api-reference/transaction-failures)リファレンスで確認し、プログラムによる処理については[支払い失敗への対応](/developer-resources/handle-payment-failures)を参照してください。
</Accordion>

<Accordion title="3DS authentication failed">
**原因：** 顧客の離脱、銀行システムの利用不可、タイムアウト。

**解決策：** 再試行するか、顧客に銀行へ問い合わせてもらってください。関連する支払い状態と拒否コードについては、[認証失敗への対応](#handling-authentication-failures)を参照してください。
</Accordion>

<Accordion title="Card not supported">
**原因：** 地域のカードに未対応、プリペイドカードの制限。

**解決策：** 顧客に、主要ネットワークの別のカードを試してもらってください。
</Accordion>
</AccordionGroup>
