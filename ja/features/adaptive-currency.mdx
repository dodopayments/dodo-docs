<Info>
Adaptive Currency lets you show localized prices and accept payments in customers' local currencies. This reduces friction at checkout and builds trust.
</Info>

## 適応通貨とは？

Adaptive Currencyは、商品の価格を基準通貨だけでなく、顧客の現地通貨で表示します。有効にすると、対応している国では、チェックアウト時に検出された現地通貨がデフォルトで使用され、基準通貨に戻すこともできます。

基準通貨とは、商品またはアドオンの価格設定に使用した通貨のことです。USDに限らず、Dodo Paymentsで請求できる任意の通貨を指定できます。Adaptive Currencyは、ライブの為替レートを使用して基準価格を換算します。通貨または国ごとに独自の固定価格を設定する場合は、[ローカライズ価格](/features/localized-pricing)をご覧ください。

## 主な利点

- **ローカライズされた支払い体験**: デフォルトで現地通貨で価格が表示されます。
- **支払方法が増える**: 現地通貨で利用可能な支払方法が解除されます。
- **同通貨での返金**: 顧客が支払った通貨での返金が可能になります。

## Adaptive Currencyを有効にする

<Steps>
<Step title="Open Settings">
Merchant Dashboardにログインし、設定 → ビジネスに進みます。
</Step>

<Step title="Toggle Adaptive Pricing">
Adaptive Pricingのトグルを有効にします。いつでも無効にすることができます。

<Warning>
変更は今後の取引のみに適用されます。
</Warning>
</Step>

<Step title="Confirm and Save">
設定を保存します。

<Check>
サポートされている場合、テストチェックアウトで現地通貨での価格が表示されることを確認してください。
</Check>
</Step>
</Steps>

## カスタマーエクスペリエンス

1. **検出**: システムは請求先住所に基づいて顧客の国を検出します。
2. **通貨の選択**: その国が対応している場合、価格はデフォルトで現地通貨で表示されます。顧客は基準通貨に戻すこともできます。
3. **Payment methods**: 該当する場合、現地向けのPayment methodsが表示されます。
4. **チェックアウト**: 選択した通貨で支払いが完了します。

## コンバージョンと手数料

Adaptive Currencyは、最新の為替レートを使用して顧客に現地通貨で請求します。

- **あなたが支払う**: 0%（デフォルト）または2–4%（手数料込みが有効な場合）
- **顧客が支払う**: 注文額に基づいて2–4%（デフォルト）または0%（手数料込みが有効な場合）

チェックアウトで適用される段階的な手数料:

- $500未満の注文に対して4%
- $500から$1,500に対して3%
- $1,500以上に対して2%

### 手数料を負担する者を選択

デフォルトでは、適応通貨の手数料が表示された価格に上乗せされ、顧客が負担します。**Fees Inclusive**設定で、手数料を自分で負担することができます。これは、顧客が常に同じ現地通貨価格を見て、手数料があなたの決済から差し引かれるというものです。

<Steps>
<Step title="Enable Adaptive Pricing">
**設定 → ビジネス** に進み、まだしていない場合はAdaptive Pricingのトグルを有効にします。
</Step>

<Step title="Toggle Fees Inclusive">
Adaptive Pricingをオンにしたら、同じセクションで**Fees Inclusive**サブトグルを有効にします。
</Step>
</Steps>

| モード | お客様の表示 | マーチャントの決済 |
|------|---------------|------------------|
| 排他的 (デフォルト) | 現地価格 + 2–4% の手数料 | 基本価格 |
| 包括的 | 現地価格（変更なし） | 基本価格から2–4% の手数料を引いた額 |

チェックアウトセッション、支払い、またはオンデマンドサブスクリプションで`adaptive_currency_fees_inclusive`（ブール値）を渡して、リクエストごとにマーチャントのデフォルトを上書きすることもできます:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_abc', quantity: 1 }],
  adaptive_currency_fees_inclusive: true, // override the business setting for this session
  return_url: 'https://yoursite.com/return'
});
```

<Info>
INR → INR 取引は、ビジネス設定やリクエストごとのオーバーライドに関係なく、常に包括的として扱われます。
</Info>

<Info>
[Localized Pricing](/features/localized-pricing)ルールが一致した場合、取引は常に包括的として扱われ、**Fees Inclusive**設定や任意のリクエストごとのオーバーライドに関係なく、顧客は設定したローカライズされた金額を正確に支払います。コンバージョンフィーはあなたの決済から差し引かれます。
</Info>

## 返金と調整

Dodo Paymentsは、顧客が最初に支払った通貨で、最新の為替レートを使用して返金を実行します。基準通貨での金額は、ダッシュボード、請求書、返金処理上で固定されたままです。そのため、為替レートの変動によって、顧客が受け取る金額は、元の現地通貨での金額より多くなる場合も少なくなる場合もあります。

<Info>
Adaptive Currencyの手数料（通常はFX手数料）は返金されません。
</Info>

**返金の例**

1. 商品を100 USDで販売し、Adaptive Currencyを有効にしています。
2. カナダの顧客が1USDあたり1.37 CADの為替レートで137 CADを見て、購入を完了します。
3. 支払い処理を行い、137 CADを100 USDに変換して決済します。
4. 後に為替レートが1USDあたり1.40 CADに変わり、全額返金を行います。
5. 100 USDを差し引き、顧客に140 CADを返金します。

## 請求書と課税

- 請求書には決済通貨の金額のみが表示されます。
- 税金とプラットフォーム手数料は決済通貨の金額に基づいて計算されます。
- 例: \$10 の販売が36 AEDに変換されても、ダッシュボードと請求書では$10のまま反映。

<Info>
すべての金額は、Dodo Paymentsの内部四捨五入ロジックに従って丸められます。
</Info>

## 統合例

**請求通貨を指定したチェックアウトセッション**

セッションの請求通貨を明示的に設定するために`billing_currency`を渡します。

<Info>
Adaptive Pricingが無効な場合、`billing_currency`は無視されます。
</Info>

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    {
      product_id: 'prod_one_time_or_subscription',
      quantity: 1
    }
  ],
  billing_currency: 'AED',
  return_url: 'https://example.com/return'
});
```
