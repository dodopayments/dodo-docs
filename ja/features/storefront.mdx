## 機能の主なハイライト

1. **ブランド化されたストアフロント**
    - ストア名、ロゴ、カバー画像でストアをカスタマイズします。
    - ストアのURL（例：`store.dodopayments.com/your-store`）を簡単に共有できます。
2. **製品の分類**
    - 製品を一括払いセクションとサブスクリプションセクションに自動的に整理します。
3. **シンプルなチェックアウトフロー**
    - 顧客は製品と数量を選択し、**「今すぐ購入」**をクリックしてDodopaymentsのチェックアウトにリダイレクトされます。
4. **公開/非公開**
    - ストアに表示する製品を管理：マーチャントダッシュボード内で素早く公開または非公開にできます。
5. **追加設定不要**
    - 別のCMSは不要。価格設定、説明、サブスクリプションの詳細を管理しているマーチャントダッシュボードですべての製品管理が行えます。
6. **モバイル対応**
    - ストアフロントのレイアウトはレスポンシブで、スマートフォン、タブレット、デスクトップでもシームレスなショッピング体験を提供します。

## ストアフロントの設定

以下は、マーチャントがストアフロントを設定し管理するためのステップバイステップのプロセスです:

<img src="/images/store-front/sf-1.png" style={{ maxHeight: '500px', width: 'auto' }} />

### ストアフロント設定へのアクセス

1. ビジネスセクションを開く → ストアフロントを選択

### ストアのブランディング

1. **ストア名**：ストアの公開名を入力します。これはストアフロントの上部に目立って表示されます。
2. **ロゴ**：ブランドロゴ用の画像（例：PNGまたはJPG）をアップロードします。
3. **カバー画像**：ストアフロントのホームページに表示されるバナー/カバー画像を選択またはアップロードします。
4. **ストアURL**：
    - 通常、事業名に基づいて自動生成されます（例：`business.dodopayments.com/my-store`）。
    - システムがカスタムスラッグをサポートしている場合、このURLを編集できます。
5. **製品**：ストアフロントに表示する製品を選択できます。

### ストアの保存と表示

<img src="/images/store-front/sf-2.png" style={{ maxHeight: '500px', width: 'auto' }} />

1. **公開をクリック**: ストアフロントの設定と製品の公開決定を確認するために公開をクリックします。
2. **ストアをプレビュー**: 生成されたURLでストアフロントをプレビューできます。
3. **URLを共有**: 満足したら、メール、ソーシャルメディア、またはウェブサイトを通じて顧客とリンクを共有します。

### テストモード

<img src="/images/store-front/sf-3.png" style={{ maxHeight: '500px', width: 'auto' }} />

テストモードとライブモードには別々のストアフロントがあります。テストモードのインジケーターがウェブサイトの上部に表示され、テストモードで生成されたストアフロントも表示されます。

テストモードは、ストアでのユーザーフローと購入体験を試すためのものです。実際の購入を促進するために、ユーザーにライブモードのストアリンクを共有してください。

テストモードでストアの表示に満足したら、デザインを作り直す代わりに、デザインとストアフロントのブランディングをそのままライブモードにコピーできます。[テストモードからライブモードへのデザインのコピー](/features/design#copy-design-from-test-to-live-mode)をご覧ください。

## 顧客体験

<img src="/images/store-front/sf-4.png" style={{ maxHeight: '500px', width: 'auto' }} />

### ストアフロントへの到着

- **ビジュアルブランディング**：顧客はすぐにストア名、ロゴ、カバー画像を確認できます。
- **整理された商品**：One-Time PaymentとSubscriptionの2つのカテゴリーが表示されます。

### 商品の閲覧

- **商品カード**：各商品には名前、説明、価格が表示されます。カードの右下にあるiアイコンをクリックすると、説明を確認できます。
- **数量の選択**：顧客は購入する商品の数量を選択できます。
- **Subscriptionの頻度とトライアル**：Subscription商品には、請求頻度（例：月次）とトライアルの有無（例：7日間の無料トライアル）が明示されます。

<img src="/images/store-front/sf-5.png" style={{ maxHeight: '500px', width: 'auto' }} />

### 購入プロセス

1. **「今すぐ購入」を選択**：準備ができたら、顧客は目的の商品で「購入」をクリックし、数量を選択して「今すぐ購入」をクリックします
2. **Dodo Paymentsのcheckoutへリダイレクト**：
    - 顧客はDodo Paymentsのcheckoutに移動します
    - 顧客はDodo Paymentsで安全なcheckoutフローを完了します。
3. **確認**：
    - 支払いが正常に完了すると、Dodo Paymentsに確認画面が表示されます。
    - 任意で、入力されたリダイレクトURLに基づき、顧客をストアフロントの「Thank You」ページへ戻すこともできます。
