## はじめに

このガイドでは、アフィリエイト紹介を追跡し、コミッションイベントを処理し、Dodo Payments を通じた信頼できるアフィリエイトパートナーシップで収益を伸ばす方法を説明します。**Affonso**、**Dub Partners**、**Rekomi** など、主要なアフィリエイトプラットフォームとの連携を提供しており、アフィリエイトプログラムをシームレスに管理・追跡できます。

## Integrationの選択肢

Dodo Payments は、主要なアフィリエイト管理プラットフォームと連携します。

- **[Affonso](https://affonso.io)**: コミッション追跡の自動化、リアルタイムレポート、専用アフィリエイトダッシュボードを備えた、包括的なアフィリエイト管理プラットフォームです。
- **[Dub Partners](https://dub.co)**: Dub のリンク管理とコンバージョン追跡を活用し、詳細なアトリビューション分析によってアフィリエイトプログラムを運用できます。
- **[Rekomi](https://rekomi.com)**: Dodo Payments と API キーを1回貼り付けるだけで接続できるアフィリエイト追跡・管理プラットフォームです。アフィリエイトへの支払いと税務フォームの処理も代行します。

ニーズに最も合うプラットフォームを選択するか、用途に応じて両方を使用してください。

販売を支援するため、主要なアフィリエイト管理プラットフォームであるAffonsoと提携しています。以下の手順に従って、Dodo PaymentsアカウントをAffonsoに接続し、アフィリエイト経由の売上の追跡を開始してください。

<Steps>
  <Step title="Connect with Dodo Payments">
    まず、API keyを追加してDodo Paymentsアカウントを接続します。

    ### Dodo Payments API Keyの取得方法

    - **Dodo Payments Dashboard**にログインします
    - 左側のメニューで**Developer**セクションに移動します
    - **API Keys**をクリックします
    - **Add API Key**を選択します
    - 名前を付けます（例: "Affonso Integration"）
    - **Create**をクリックし、API keyを**copy**します

    ### AffonsoにAPI Keyを追加する

    - [affonso.io](https://affonso.io/)から**Affonso Dashboard via**を開きます
    - **Program Details > Connect**に移動します
    - **Dodo Payments integration**カードをクリックします
    - Dodo Payments API keyを貼り付けます
    - **Connect**をクリックします

    <Callout type="info">
      API keyはAffonsoによって安全に暗号化されます。
    </Callout>
  </Step>

  <Step title="Add Webhook to Dodo Payments">
    接続すると、Affonsoから一意のwebhook URLが提供されます。これにより、決済の追跡とアフィリエイトコミッションのトリガーが可能になります。

    ### Dodo PaymentsにWebhook URLを追加する

    - Dodo Payments Dashboardで**Developer → Webhooks**に移動します
    - **Add Webhook**をクリックします
    - **Affonso webhook URL**（プログラム設定に記載）を貼り付けます
    - webhookを保存します

    ### AffonsoにWebhook Secretを追加する

    - Dodo Paymentsでwebhookを保存した後、提供された**signing key**を**copy**します
    - **Dodo Payments webhook settings**でAffonsoに貼り付けます

    <Callout type="info">
      これにより、AffonsoはDodo Paymentsから受信したeventを安全に検証できます。
    </Callout>
  </Step>

  <Step title="Add the Tracking Script">
    アフィリエイト訪問とコンバージョンの追跡を開始するには、サイトにAffonso pixelを配置します。

    ```html
    <!-- Place in <head> tag -->
    <script async defer
    src="https://affonso.io/js/pixel.min.js"
    data-affonso="YOUR_PUBLIC_PROGRAM_ID"
    data-cookie_duration="YOUR_COOKIE_DURATION">
    </script>
    ```

    このscriptは次の処理を行います。
    - アフィリエイト訪問を追跡します
    - 紹介IDを含むcookie（`affonso_referral`）を設定します
    - サインアップと決済の追跡を有効にします

    <Callout type="info">
      ユーザーが訪問またはコンバージョンするすべてのドメイン（例: marketing site、app）に配置してください。
    </Callout>
  </Step>

  <Step title="Track User Signups">
    ファネルの可視性を高め、アフィリエイトのパフォーマンスを最適化するには、ユーザーのサインアップをリードとして追跡します。

    ```js
    // After successful registration
    window.Affonso.signup(userEmail);
    ```

    これにより、次の処理が行われます。
    - アフィリエイトlink経由で訪問したユーザーの場合、新しい紹介を**LEAD**として記録します
    - ダッシュボードとアフィリエイトの統計に表示します

    <Callout type="info">
      ベストプラクティス: 登録の成功後、またはdouble opt-in（DOI）の後にトリガーしてください。
    </Callout>
  </Step>

  <Step title="Pass Referral Data to Dodo Payments">
    コミッションを正しく紐付けるには、checkout中にAffonsoからDodo Paymentsへ紹介IDを渡します。

    ### Payments Integration

    ```js
    import DodoPayments from 'dodopayments';

    const referralId = window.affonso_referral;

    const client = new DodoPayments({
      bearerToken: process.env['DODO_PAYMENTS_API_KEY'],
    });

    async function main() {
      const payment = await client.payments.create({
        payment_link: true,
        billing: { city: 'city', country: 'AF', state: 'state', street: 'street', zipcode: '00000' },
        customer: { email: 'email@email.com', name: 'name' },
        product_cart: [{ product_id: 'product_id', quantity: 0 }],
        metadata: {
          affonso_referral: referralId,
        },
      });

      console.log(payment.payment_id);
    }

    main();
    ```

    ### Subscription Integration

    ```js
    import DodoPayments from 'dodopayments';

    const referralId = window.affonso_referral;

    const client = new DodoPayments({
      bearerToken: process.env['DODO_PAYMENTS_API_KEY'],
    });

    async function main() {
      const subscription = await client.subscriptions.create({
        billing: { city: 'city', country: 'IN', state: 'state', street: 'street', zipcode: '89789' },
        customer: { customer_id: 'customer_id' },
        product_id: 'product_id',
        payment_link: true,
        return_url: 'https://example.com/success',
        quantity: 1,
        metadata: {
          affonso_referral: referralId,
        },
      });

      console.log(subscription.subscription_id);
    }

    main();
    ```

    ### Payment Links

    ```js
    // Original Dodo Payments Link
    const originalLink = 'https://checkout.dodopayments.com/buy/<YOUR_PRODUCT_ID>';

    // Append referral ID as reference_id
    const linkWithReferral = `${originalLink}?metadata_affonso_referral=${window.affonso_referral}`;
    ```

    <Callout type="info">
      詳細については、[Dodo Payments API documentation](https://docs.dodopayments.com/api-reference/introduction)を参照してください。
    </Callout>
  </Step>

  <Step title="Testing Your Integration">
    一般公開する前に、実際のアフィリエイトlinkとテスト取引を使用して設定をテストしてください。

    **Testing Checklist:**
    - ✅ アフィリエイトを作成し、tracking linkを生成する
    - ✅ アフィリエイトlink経由でWebサイトにアクセスする
    - ✅ Affonso scriptが読み込まれ、`affonso_referral` cookieが設定されていることを確認する
    - ✅ サインアップを完了する（任意）
    - ✅ Dodo Payments経由で決済を完了する
    - ✅ Affonso dashboardでtrackingとアトリビューションを確認する
  </Step>
</Steps>

## Dub Partners Integration

[Dub Partners](https://dub.co)を使用して、アフィリエイト紹介とコンバージョンを追跡することもできます。Dubのconversion tracking機能を使用すると、売上をアフィリエイトlinkに紐付け、どのパートナーが最も多くの収益を生み出しているかを詳細な分析で確認できます。

<Info>
詳細な設定手順については、[Dub integration guide](/integrations/dub)を参照してください。このガイドでは、sale conversion eventの追跡方法と、収益をアフィリエイトlinkに紐付ける方法を説明しています。
</Info>

### Dub Partnersですばやく設定する

1. アフィリエイトlinkのDub dashboardで**conversion trackingを有効化**します
2. checkout sessionの作成時に**Dub click ID**（`dub_id` cookie）を取得します
3. 顧客情報とともに、payment metadataに**click IDを保存**します
4. 決済成功時にsale dataをDubへ送信するよう、**webhook integrationを設定**します

このIntegrationでは、次の項目が自動的に追跡されます。
- 一回限りの決済
- サブスクリプションの有効化
- 継続的なサブスクリプション決済

## Rekomi との連携

[Rekomi](https://rekomi.com) を使用して、アフィリエイトプログラムを最初から最後まで運用することもできます。Rekomi はクリックとコンバージョンを追跡し、税引前の販売金額に基づいてコミッションを計算します。また、150か国以上で税務フォームを含むアフィリエイトへの支払いを代行します。

<Info>
詳しいセットアップ手順については、[Rekomi 連携ガイド](/integrations/rekomi)をご覧ください。接続は API キーを1回貼り付けるだけで完了します。Rekomi が Dodo Payments アカウント内に Webhook エンドポイントを自動的に作成するため、手動での Webhook 設定は必要ありません。
</Info>

### Rekomi を使った簡単なセットアップ

1. Dodo Payments ダッシュボードの **Developer → API Keys** で、**書き込みアクセスを有効にした API キーを作成**します
2. **キーを Rekomi に貼り付けます**。Rekomi がキーを検証し、Webhook エンドポイントを自動的に作成します
3. **Rekomi の追跡スクリプトをサイトにインストール**して、アフィリエイトクリックを取得できるようにします
4. 紹介情報を `rekomi_ref` メタデータ（または `metadata_rekomi_ref` payment-link パラメーター）としてチェックアウトに渡します

連携により、次の項目が自動的に追跡されます。
- 一回限りの支払い
- サブスクリプションの有効化と更新
- 返金と異議申し立て、およびコミッションの自動回収
