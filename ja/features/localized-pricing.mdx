## ローカライズ価格とは？

すべての製品には、基準通貨で設定された基準価格があります。ローカライズ価格を使用すると、その基準価格を**通貨ごと、または国ごとに設定した固定価格**で上書きできます。製品で `pricing_mode` を設定して有効にし、市場ごとに1つのルールを追加します。

国際価格設定のための、独立した3つの手段のうちの1つです。それぞれ異なる課題を解決します。

| 仕組み | 内容 | 顧客に表示される金額 |
| :--- | :--- | :--- |
| **ローカライズ価格** | 通貨または国ごとに設定する固定価格 | 設定した金額そのもの |
| [**Adaptive Currency**](/features/adaptive-currency) | 現在のFXレートで基準価格を自動変換 | 現在の為替レートで変換された基準価格 |
| [**割引コード**](/features/discount-codes) | 基準価格からの割合による値引き | 基準価格から割引額を差し引いた金額 |

<Info>
ローカライズ価格と Adaptive Currency は連携して動作します。ローカライズルールに一致しない場合、製品は基準価格にフォールバックします。顧客がすでに基準通貨を使用している場合は基準価格を直接請求し、それ以外の場合は Adaptive Currency を通じて変換します。
</Info>

## 基本概念

- **価格設定モード** — 製品は常に1つのモードのみを使用します。モードは `pricing_mode` で設定します。
  - `by_currency`：国に関係なく、通貨ごとに1つの価格を設定します。EURで支払うすべての顧客に€9.99が表示されます。
  - `by_country`：通貨を共有する国が複数ある場合でも、国ごとに固有の価格（インドでは₹999）を設定します。
- **最小単位で指定する固定金額** — ルールの `amount` は、APIの他の場所と同様、通貨の最小単位を表す整数です。`99900` は₹999.00、`999` は€9.99を意味します。設定した価格がそのまま適用され、変換された値ではありません。
- **一致するルールがない場合** — 製品は既存の動作を維持します。基準通貨の顧客には基準価格を直接請求し、それ以外の顧客には [Adaptive Currency](/features/adaptive-currency) を通じて変換した価格を請求します。
- **ルールが一致した場合、手数料は価格に含まれます** — 顧客が支払う金額は、設定した金額と**完全に同じ**です。 [Adaptive Currency](/features/adaptive-currency#choose-who-bears-the-fee) のFX手数料はDodoが負担し、その取引では手数料込みとして扱われるため、設定した現地価格が常に請求額になります。

<Steps>
<Step title="Open the product form">
Merchant Dashboardで **Products** に移動し、製品を作成します（または既存の製品を開いて編集します）。通常どおり、基準 **Price** と通貨を設定します。
</Step>

<Step title="Enable Localized Pricing and choose a mode">
**Pricing** セクションで **Localized Pricing** にチェックを入れ、**By Country** または **By Currency** を選択します。

## APIで管理する

ローカライズ価格はAPIで完全に利用できます。まず製品の価格設定モードを設定し、その後ルールを追加します。

### 価格設定モードを設定する

製品を作成するとき（または既存の製品を更新するとき）に `pricing_mode` を設定します。`null` は基準価格のみを意味し、既存の動作と同じです。

<CodeGroup>

```typescript theme={null}
import DodoPayments from 'dodopayments';

const client = new DodoPayments({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: 'test_mode',
});

const product = await client.products.update('pdt_premium_plan', {
  pricing_mode: 'by_country',
});
```

```python theme={null}
import os
from dodopayments import DodoPayments

client = DodoPayments(
    bearer_token=os.environ.get("DODO_PAYMENTS_API_KEY"),
    environment="test_mode",
)

product = client.products.update(
    "pdt_premium_plan",
    pricing_mode="by_country",
)
```

```go theme={null}
package main

import (
	"context"
	"os"

	"github.com/dodopayments/dodopayments-go"
	"github.com/dodopayments/dodopayments-go/option"
)

func main() {
	client := dodopayments.NewClient(
		option.WithBearerToken(os.Getenv("DODO_PAYMENTS_API_KEY")),
	)

	_, err := client.Products.Update(
		context.TODO(),
		"pdt_premium_plan",
		dodopayments.ProductUpdateParams{
			PricingMode: dodopayments.F(dodopayments.PricingModeByCountry),
		},
	)
	if err != nil {
		panic(err)
	}
}
```

</CodeGroup>

### ローカライズ価格を追加する

製品にルールを追加します。`by_country` モードでは `country_code` が必須です。`by_currency` モードでは省略する必要があります。

<CodeGroup>

```typescript theme={null}
// ₹999.00 for customers in India
const localizedPrice = await client.products.localizedPrices.create('pdt_premium_plan', {
  currency: 'INR',
  country_code: 'IN',
  amount: 99900,
});
```

```python theme={null}
# ₹999.00 for customers in India
localized_price = client.products.localized_prices.create(
    "pdt_premium_plan",
    currency="INR",
    country_code="IN",
    amount=99900,
)
```

```go theme={null}
// ₹999.00 for customers in India
localizedPrice, err := client.Products.LocalizedPrices.New(
	context.TODO(),
	"pdt_premium_plan",
	dodopayments.ProductLocalizedPriceNewParams{
		Currency:    dodopayments.F(dodopayments.CurrencyInr),
		CountryCode: dodopayments.F(dodopayments.CountryCodeIn),
		Amount:      dodopayments.F(int64(99900)),
	},
)
```

</CodeGroup>

`by_currency` 製品では `country_code` を省略します。たとえば、EURで支払うすべての顧客に一律の `€9.99` を設定できます（`currency: 'EUR'`、`amount: 999`）。

### 一覧表示、更新、アーカイブ

更新できるのはルールの `amount` のみです。通貨と国は作成後に変更できません。アーカイブは冪等なソフト削除であり、ルールは一致対象から外れますが、履歴には残ります。

<CodeGroup>

```typescript theme={null}
// List all active rules on a product
const rules = await client.products.localizedPrices.list('pdt_premium_plan');

// Change the amount (e.g. end a promo)
await client.products.localizedPrices.update('lcp_india_price', {
  product_id: 'pdt_premium_plan',
  amount: 119900,
});

// Archive a rule
await client.products.localizedPrices.archive('lcp_india_price', {
  product_id: 'pdt_premium_plan',
});
```

```python theme={null}
# List all active rules on a product
rules = client.products.localized_prices.list("pdt_premium_plan")

# Change the amount (e.g. end a promo)
client.products.localized_prices.update(
    "lcp_india_price",
    product_id="pdt_premium_plan",
    amount=119900,
)

# Archive a rule
client.products.localized_prices.archive(
    "lcp_india_price",
    product_id="pdt_premium_plan",
)
```

```go theme={null}

// Change the amount (e.g. end a promo)
```

## チェックアウトでの適用方法

ローカライズ価格はカート内の各明細行ごとに解決され、`pricing_mode` が設定された製品にのみ適用されます。Dodo Payments はリクエストから、顧客の**請求先国**と、任意の **`billing_currency`** の2つの情報を読み取ります（省略した場合、請求先国から通貨が導出されます）。

- **By Country**：請求先国に一致するルールを検索します。一致するルールがある場合、ルールの通貨で設定金額を顧客に請求します。
- **By Currency**：顧客の通貨（`billing_currency`、または国から導出された通貨）に一致するルールを検索します。一致するルールがある場合、その通貨でルールの設定金額を顧客に請求します。
- **一致するルールがない場合、または `pricing_mode` がない場合**：基準価格が適用されます。顧客の通貨が基準通貨と同じ場合は直接請求し、それ以外の場合は [Adaptive Currency](/features/adaptive-currency) を通じて変換します。

カートの各明細行は個別に解決されるため、同じチェックアウト内で1つの製品だけをローカライズし、他の製品には基準価格を適用できます。いずれかの明細行がローカライズルールに一致すると、取引全体が手数料込みになります（[基本概念](#core-concepts)を参照）。

## サブスクリプションプラン変更時の適用方法

ローカライズ価格は、プランを切り替えるサブスクライバーにも適用されます。既存のサブスクリプションで `pricing_mode` が設定された製品へ[プランを変更](/features/subscription#subscription-plan-changes)すると、チェックアウトと同じルールに従い、サブスクリプションに保存されている請求先国と通貨を使用して新しいプランの価格が解決されます。

- **By Country**：サブスクリプションの請求先国に一致するルールが適用されます。ルールの通貨がサブスクリプションの請求通貨と異なる場合、ルールの金額は現在のFXレートで変換されます。ルールは適用され、スキップされません。
- **By Currency**：顧客への請求に使用される通貨に一致するルールが適用され、ルールの金額がそのまま請求されます。
- **一致するルールがない場合、または `pricing_mode` がない場合**：新しいプランの基準価格が適用され、必要に応じて [Adaptive Currency](/features/adaptive-currency) を通じて変換されます。チェックアウトと同じフォールバック動作です。

これは、プラン変更が発生するすべての場所に適用されます。[Change Plan API](/api-reference/subscriptions/change-plan)、[Customer Portal](/features/customer-portal) のセルフサービスによるプラン変更、請求期間の終了時に予定された変更が対象です。

- **プレビューは正確です。** [Preview Change Plan](/api-reference/subscriptions/preview-change-plan) は、実際の変更時に請求されるものと同じローカライズ金額を返します。
- **更新時もローカライズ価格が維持されます。** 変更後、新しいプランはローカライズされた金額で更新され、同じ価格で作成されたサブスクリプションと同様に手数料込みの状態が維持されます。
- **日割り計算には実際の金額が使用されます。** アップグレード時、未使用期間に対するクレジットは顧客が旧プランに実際に支払った金額を基準に計算され、新しいプランにはローカライズルールの価格が適用されます。
- **予定された変更では、予定時点で価格が固定されます。** 請求期間終了時に予定された変更では、その間にルールを編集しても、予定時に計算された金額が請求されます。
- **請求通貨は変わりません。** プラン変更によってサブスクリプションの決済通貨が切り替わることはありません。別の通貨のルールはFX変換されます。
- **アドオンはローカライズされません。** 新しいプランのアドオン価格には、常に基準価格が使用されます。

## 重要な動作

| 動作 | 詳細 |
| :--- | :--- |
| **税抜き金額** | ローカライズ金額は税引き前の価格です。税抜き製品ではチェックアウト時に税が加算されるため、ローカライズ金額が最終合計額になるわけではありません。[Tax-Inclusive Pricing](/features/tax-inclusive-pricing)を参照してください。 |
| **Pay What You Wantには非対応** | 顧客が金額を選択する[Pay What You Want](/features/pay-what-you-want)製品には、ローカライズルールは適用されません。 |
| **By Currencyは基準価格と異なる必要があります** | `by_currency` ルールでは、製品の基準通貨とは異なる通貨を使用する必要があります。 |
| **市場ごとに1ルール** | 製品には、通貨ごと（By Currency）または国ごと（By Country）に、アクティブなルールを最大1つ設定できます。 |
| **すべての製品タイプ** | 1回限り、サブスクリプション、従量課金の製品に適用されます。既存のサブスクライバーが[プランを変更](#how-it-applies-on-subscription-plan-changes)する場合も対象です。 |

<Info>
ローカライズルールの変更によって、専用のwebhookが発行されることはありません。解決された金額は、他の価格と同様、結果として作成されるpaymentまたはsubscriptionに表示されます。
</Info>

## ベストプラクティス

- **適切な基準価格を設定する。** ルールがないすべての市場では、Adaptive Currency を通じて変換された基準価格がフォールバックとして使用されます。
- **現地向けのチャームプライスに丸める。** 固定金額の目的は、FX変換の結果ではなく、₹999、€9.99、¥1000のようなわかりやすい価格にすることです。
- **目的に合ったモードを選ぶ。** 購買力に基づく価格設定には `by_country` を使用し、通貨圏ごとに1つの価格で十分な場合は `by_currency` を使用します。
- **プロモーションでは再作成せずアーカイブする。** ルールをアーカイブすると、市場は履歴を保持したまま基準価格またはAdaptive Currencyに戻ります。必要に応じて後から再作成または再価格設定できます。
- **合計額を広告する前に税額を確認する。** 税抜き製品では、顧客はローカライズ金額に加えて税を支払います。広告で最終価格として表示しないでください。
