[ParityDeals](https://www.paritydeals.com/) と [Evendeals](https://www.evendeals.com/integrations/dodo-payments)は、顧客の地理的位置に基づく自動価格最適化を可能にするプラットフォームで、一般に「購買力平価」（PPP）価格設定として知られています。

<Info>
Dodo Payments ストアフロントに割引バナーを直接埋め込むことはできません（カスタムスクリプトはサポートされていませんが）、これらのツールを自分のウェブサイトやアプリケーションで効果的に実装することができます。
</Info>

## 統合の選択

両方のプラットフォームは、Dodo Paymentsと直接統合して割引コードを自動で作成・管理します。以下の比較を使用して、自分のニーズに最適なツールを選択してください。

| 機能 | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| PPP / 位置に基づく価格設定 | はい | はい |
| 休日 / 時刻に基づく取引 | はい | いいえ |
| サブスクリプション サポート | はい | はい |
| 自動クーポン更新 | — | はい |
| バナーカスタマイズ | はい | いいえ |
| 価格 | [価格を見る](https://www.paritydeals.com/pricing/) | [価格を見る](https://www.evendeals.com/pricing) |

## ParityDeals

ParityDeals をウェブサイトに統合すると、対象の訪問者はチェックアウト時に使用できる位置に基づいた割引コードを含むバナーを見ることができます。これらの割引コードは ParityDeals によって自動的に作成および管理され、**Dodo Payments ダッシュボード** の **販売→割引** に表示されます。

### 追加機能

ParityDeals では、年間を通じて[自動時間ベースの割引](https://www.paritydeals.com/features/time-based-discounts/)や[休日ベースのプロモーション](https://www.paritydeals.com/features/holiday-based-discounts/)も提供できます。詳細については、[ParityDeals ドキュメント](https://www.paritydeals.com/docs/)を参照してください。

## Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) は、Dodo Payments と統合して位置に基づく購買力平価価格設定を提供する別のプラットフォームです。これは、一回限りおよびサブスクリプション製品の両方をサポートしています。

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="EvendealsとDodo Paymentsの統合概要" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

### 主な機能

- **自動クーポン同期** — クーポンは Dodo Payments で自動的に作成・管理されます
- **パーセンテージ割引** — 国グループごとに割合オフの割引を提供
- **サブスクリプション サポート** — サブスクリプションの請求サイクル全体に割引が適用されます
- **自動更新規則** — 不正利用を防ぐために、時間間隔、利用回数、表示回数によってクーポンコードを自動的に回転

<Info>
Evendeals によって作成された割引コードは、Dodo Payments ダッシュボードの販売→割引に自動的に表示されます。
</Info>
