購買力平価 (PPP) 価格設定は、各顧客の場所の購買力に合わせて請求額を調整します。Dodo Paymentsでそれを実行する方法は2つあります。

<Info>
**推奨:** ネイティブの[Localized Pricing](/features/localized-pricing)を使用して、国ごとに固定ローカル価格を設定します。たとえば、インドでは20ドルのベース商品に対して₹999です。正確な数値を制御でき、一回限り、サブスクリプション、および使用量に基づく製品に適用され、バナーやスクリプトをインストールする必要がありません。
</Info>

  <Card title="Localized Pricing" icon="earth-americas" href="/features/localized-pricing">
    ネイティブで推奨されます。国ごとまたは通貨ごとに固定のローカル価格を設定し、サードパーティツールは不要です。
  </Card>
  <Card title="Discount Codes" icon="percent" href="/features/discount-codes">

## PPPを実行する2つの方法

| | ローカライズ価格（ネイティブ） | 場所ベースの割引コード |
| :--- | :--- | :--- |
| 動作方法 | 国/通貨ごとに固定価格を設定 | コードを通じてベース価格からの比率割引を適用 |
| ツール | Dodo Paymentsに組み込まれています | [ParityDeals](https://www.paritydeals.com/) / [Evendeals](https://www.evendeals.com/integrations/dodo-payments) |
| サイトのバナー/スクリプト | 必要なし | コードを表示するために必要 |
| 顧客が見る価格 | 設定した正確な金額 | 割引後のベース価格 |
| 最適な用途 | 完全に制御された市場調整価格 | プロモーションバナーおよび時間/休日ベースの取引 |

ネイティブ設定については、[Localized Pricing](/features/localized-pricing)をご覧ください。このページの残りは、ParityDealsおよびEvendealsを使用した場所ベースの割引コードのアプローチについて説明します。

## 場所ベースの割引コード

[ParityDeals](https://www.paritydeals.com/) および [Evendeals](https://www.evendeals.com/integrations/dodo-payments) は、顧客の地理的位置に基づいて割引コードを生成することで、価格の最適化を自動的に行うプラットフォームです。

<Info>
Dodo Paymentsのストアフロントに割引バナーを直接埋め込むことはできませんが（カスタムスクリプトはサポートされていません）、これらのツールを自分のウェブサイトやアプリケーションで効果的に実装できます。
</Info>

### 統合の選択

両方のプラットフォームはDodo Paymentsと直接統合され、割引コードを自動的に作成および管理します。以下の比較を使用して、ニーズに最適なツールを選択してください。

| 機能 | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| PPP / 場所ベースの価格設定 | はい | はい |
| 休日 / 時間ベースの取引 | はい | いいえ |
| サブスクリプションのサポート | はい | はい |
| クーポン自動更新 | — | はい |
| バナーカスタマイズ | はい | いいえ |
| 価格 | [View Pricing](https://www.paritydeals.com/pricing/) | [View Pricing](https://www.evendeals.com/pricing) |

### ParityDeals

ParityDealsがあなたのウェブサイトに統合されると、適格な訪問者は、チェックアウト時に使用できる場所ベースの割引コードを含むバナーを見ることができます。これらの割引コードはParityDealsによって自動的に作成および管理され、**Dodo Paymentsダッシュボード**の **Sales → Discounts** に表示されます。

#### セットアップ

<Steps>
  <Step title="Sign up on ParityDeals">
    [app.paritydeals.com](https://app.paritydeals.com/) にアクセスしてアカウントを作成します。
  </Step>

  <Step title="Create Deals">
    サインイン後、取引を作成するオプションを見つけます。ドロップダウンメニューから **"Create Deals via Dodo Payments"** を選択します。

    <Frame>
      <img src="/images/ppp/2.png" alt="Dodo Paymentsを通じた取引の作成" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    **Dodo Paymentsダッシュボード**にログインし、**Developers → API Keys** に移動します。**"Create New API"** をクリックします。

    <Tip>
      APIキーに説明的な名前を付けます（例: 'ParityDeals'）。後で識別できるようにします。
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="Dodo Paymentsでの新しいAPIキーの作成" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    作成したAPIキーをコピーして、ParityDealsのインターフェースに貼り付け、Dodo Paymentsアカウントとの接続を確立します。

    <Frame>
      <img src="/images/ppp/4.png" alt="APIキーのParityDealsへの接続" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    接続されると、ParityDealsはDodo Paymentsの製品カタログを取得します。取引に関連付ける製品を選択します。

    <Frame>
      <img src="/images/ppp/5.png" alt="ParityDealsの製品選択" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    ウェブサイトのURLを入力し、割引バナーを表示する特定のターゲットページを選択することができます。その後、希望する取引タイプを選択します:
    - 位置ベースの取引
    - 休日の取引
    - 時間ベースのフラッシュ取引

    <Frame>
      <img src="/images/ppp/6.png" alt="取引設定の設定" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    ローカル割引を提供する国を選択し、それぞれの割引率を定義します。ParityDealsは必要に応じて調整可能な推奨デフォルトを提供します。

    <Frame>
      <img src="/images/ppp/7.png" alt="国別の割引ルール設定" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    割引バナーのテキストをカスタマイズし、色とレイアウトを選択し、バナーの位置を決定してデザインします。設定したルールに基づいて適格な訪問者に表示されます。

    <Frame>
      <img src="/images/ppp/8.png" alt="割引バナーのカスタマイズ" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    取引を保存した後、ParityDealsはスクリプトを生成します。このスクリプトをウェブサイトコードに追加します（通常、`<head>`セクション）。このスクリプトは訪問者の場所を自動的に検出し、適切な割引バナーを表示します。

    <Frame>
      <img src="/images/ppp/9.png" alt="ParityDeals統合スクリプト" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

#### 追加機能

ParityDealsを使用すると、[自動時間ベースの割引](https://www.paritydeals.com/features/time-based-discounts/)や[休日ベースのプロモーション](https://www.paritydeals.com/features/holiday-based-discounts/)を年間を通じて提供することもできます。詳細については、[ParityDeals Documentation](https://www.paritydeals.com/docs/)を参照してください。

### Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) は、Dodo Paymentsと統合された、場所ベースの購買力平価価格設定を提供するプラットフォームです。それは一回限り及びサブスクリプション商品両方をサポートしています。

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Evendeals Dodo Payments統合の概要" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### 主な特長

- **自動クーポン同期** — クーポンはDodo Paymentsで自動的に作成および管理されます
- **割合割引** — 国別グループごとにパーセンテージの割引を提供
- **サブスクリプションサポート** — 割引はサブスクリプションの請求サイクル全体に適用されます
- **自動更新ルール** — 時間間隔、償還回数、または表示回数によってクーポンコードを自動的に更新し乱用を防止

<Info>
Evendealsによって作成された割引コードは、Dodo PaymentsダッシュボードのSales → Discountsに自動的に表示されます。
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="Dodo Payments統合用のEvendeals主な特長" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### セットアップ

<Steps>
  <Step title="Create a Dodo Payments API key">
    Dodo Paymentsダッシュボードで、**Developers → API Keys** に移動し、新しいキーを生成します。
  </Step>

  <Step title="Connect in Evendeals">
    [Evendealsダッシュボード](https://www.evendeals.com/signin) に移動して **Integrations** を開き、Dodo Paymentsカードを見つけてAPIキーを貼り付けます。
  </Step>

  <Step title="Configure regional discounts">
    各国グループの割引パーセンテージを設定し、同期を押します。EvendealsはDodo Paymentsでクーポンを自動的に作成します。

    <Check>
    同期後、Dodo Paymentsダッシュボードの **Sales → Discounts** を開いて、生成されたクーポンが表示されることを確認します。各クーポンには認識可能なEvendealsプレフィックスがあります。
    </Check>
  </Step>
</Steps>

<Frame>
  <img src="/images/ppp/evendeals-setup.png" alt="Dodo PaymentsのためのEvendealsセットアップガイド" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

ParityDealsとEvendealsの両方がDodo Paymentsとシームレスに連携して、グローバルな価格設定戦略を最適化するのをサポートします。詳細については、[ParityDeals Documentation](https://www.paritydeals.com/docs/) または [Evendeals Dodo Payments integration page](https://www.evendeals.com/integrations/dodo-payments)をご覧ください。
