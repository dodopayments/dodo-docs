<Info>
購買力平価（PPP）では、購入者の購入元の国に基づき、リスト価格の一定割合を顧客に請求します。\$20 の商品を、割引コードも2つ目の価格表も使わずに、**インドでは \$6.00 で販売**できます。
</Info>

## 購買力平価とは？

同じ価格でも、どこでも同じように手頃とは限りません。\$20 は米国では少額の購入ですが、フィリピンでは高額です。PPP pricing はこの差を調整します。

Dodo Payments は国ごとに1つの割合を保持します。この割合は、**顧客が支払うリスト価格の割合**です。インドは30なので、インドの顧客は価格の30%を支払います。米国は100なので、価格は変わりません。

適用したい各商品の価格で PPP を有効にします。オプトインしていない商品は、どの国でも通常価格が維持されます。

<Note>
PPP には [Adaptive Currency](/features/adaptive-currency) が必要です。先に Adaptive Currency を有効にしてください。
</Note>

## 主なメリット

- **価格に敏感な市場にリーチ**: 自国の価格を下げずに、現地価格で販売できます。
- **バナーもスクリプトも不要**: チェックアウト時に正しい価格が表示されます。ウェブサイトに何も追加する必要はありません。
- **管理する割引コードが不要**: 作成、入れ替え、無効化するものはありません。
- **商品ごとに制御**: スタータープランだけをオプトインし、エンタープライズプランには適用しないことができます。
- **あらゆる商品で利用可能**: 一回限り、サブスクリプション、使用量ベースの商品に対応します。

## 購買力平価を有効にする

<Steps>
<Step title="Enable Adaptive Currency">
**Settings → Business** に移動します。**Business Settings** で **Adaptive Currency** を有効にします。これがないと PPP は機能しません。

<Frame>
  <img src="/images/ppp/adaptive-currency-toggle.png" alt="Business Settings の Adaptive Currency と購買力平価" style={{ maxHeight: '360px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Review your country percentages">
**Purchasing Power Parity** の下にある **Edit** をクリックして **Country Prices** を開きます。任意の国の割合を変更し、**Save Changes** をクリックします。

各国の支払額を確認するには、**Example product price** を設定します。入力すると **Your Price** 列が更新されます。検索ボックスを使って、国名またはコードで国を検索できます。

<Frame>
  <img src="/images/ppp/country-percentages.png" alt="各国の割合と算出価格を表示する Country Prices ダイアログ" style={{ maxHeight: '620px', width: 'auto' }} />
</Frame>

<Note>
これらの割合はビジネス全体に適用されます。Purchasing Power Parity が有効なすべての商品で使用されます。
</Note>
</Step>

<Step title="Turn PPP on for a product">
商品を開きます。**Pricing** セクションで **Purchasing Power Parity** にチェックを入れ、商品を保存します。

チェックを入れていない商品は、どの国でも通常価格が維持されます。

<Frame>
  <img src="/images/ppp/product-toggle.png" alt="商品の Pricing セクションで Purchasing Power Parity にチェックが入っている状態" style={{ maxHeight: '440px', width: 'auto' }} />
</Frame>

<Warning>
Adaptive Currency がオフの場合、ここにチェックを入れることはできません。先に Adaptive Currency を有効にしてください。
</Warning>
</Step>

<Step title="Confirm at checkout">
<Check>
割合が100未満の請求先国を指定して、テストチェックアウトを開きます。値下げ後の価格が表示されることを確認します。
</Check>
</Step>
</Steps>

## 価格の計算方法

国別の割合をリスト価格に乗算します。

```
price paid = list price × country percentage ÷ 100
```

インドの顧客に、割合30で \$20.00 の商品を販売する場合:

```
2000 × 30 ÷ 100 = 600   →   $6.00
```

Dodo Payments は通貨換算の前に、基本価格へ割合を適用します。次に [Adaptive Currency](/features/adaptive-currency) が結果を顧客の通貨に換算します。

<Info>
Dodo Payments はチェックアウト時の顧客の **billing country** から国を判定します。
</Info>

### 国別の割合

各国には、**30〜100** の範囲で1つの割合があります。

- **100** は、顧客が全額を支払うことを意味します。値下げはありません。
- **30** は設定可能な最低値です。したがって、最大値下げ率は70%です。

デフォルト値は、World Bank の価格水準指数データに基づいています。Dodo Payments は各値を最も近い5の倍数に丸め、下限を30、上限を100として適用します。対応しているすべての国に値があります。任意の値を変更できます。

範囲を示すため、デフォルト値の一部を以下に示します。

| 国 | 割合 | \$20 の商品が販売される価格 |
| :--- | :---: | :--- |
| United States | 100 | \$20.00 |
| United Kingdom | 85 | \$17.00 |
| Germany | 75 | \$15.00 |
| Japan | 60 | \$12.00 |
| Brazil | 45 | \$9.00 |
| South Africa | 40 | \$8.00 |
| Philippines | 35 | \$7.00 |
| India | 30 | \$6.00 |

<Note>
全リストには217か国が含まれます。ダッシュボードで国別テーブルを開くと、すべての値を確認できます。
</Note>

## API で有効にする

PPP は `purchasing_power_parity` フィールドで商品ごとに有効にします。デフォルト値は `false` です。

<Info>
国別の割合はダッシュボードでのみ管理します。公開 API には含まれません。
</Info>

<CodeGroup>

```typescript theme={null}
import DodoPayments from 'dodopayments';

const client = new DodoPayments({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: 'test_mode',
});

const product = await client.products.create({
  name: 'Starter Plan',
  tax_category: 'saas',
  price: {
    type: 'one_time_price',
    currency: 'USD',
    price: 2000,
    discount: 0,
    purchasing_power_parity: true,
  },
});
```

```python theme={null}
import os
from dodopayments import DodoPayments

client = DodoPayments(
    bearer_token=os.environ.get("DODO_PAYMENTS_API_KEY"),
    environment="test_mode",
)

product = client.products.create(
    name="Starter Plan",
    tax_category="saas",
    price={
        "type": "one_time_price",
        "currency": "USD",
        "price": 2000,
        "discount": 0,
        "purchasing_power_parity": True,
    },
)
```

```go theme={null}
package main

import (
	"context"
	"os"

	"github.com/dodopayments/dodopayments-go"
	"github.com/dodopayments/dodopayments-go/option"
)

func main() {
	client := dodopayments.NewClient(
		option.WithBearerToken(os.Getenv("DODO_PAYMENTS_API_KEY")),
	)

	_, err := client.Products.New(context.TODO(), dodopayments.ProductNewParams{
		Name:        dodopayments.F("Starter Plan"),
		TaxCategory: dodopayments.F(dodopayments.ProductNewParamsTaxCategorySaas),
		Price: dodopayments.F[dodopayments.PriceUnionParam](
			dodopayments.PriceOneTimePriceParam{
				Type:                  dodopayments.F(dodopayments.PriceOneTimePriceTypeOneTimePrice),
				Currency:              dodopayments.F(dodopayments.CurrencyUsd),
				Price:                 dodopayments.F(int64(2000)),
				Discount:              dodopayments.F(int64(0)),
				PurchasingPowerParity: dodopayments.F(true),
			},
		),
	})
	if err != nil {
		panic(err)
	}
}
```

</CodeGroup>

ビジネスで Adaptive Currency がオフの場合、リクエストは `422 ppp_not_enabled_for_business` で失敗します。先に有効にしてください。
</Warning>

## 重要な動作

| 動作 | 詳細 |
| :--- | :--- |
| **Adaptive Currency が必要** | Adaptive Currency がオフの間、PPP は機能しません。 |
| **デフォルトではオフ** | すべての価格は `purchasing_power_parity: false` から開始します。 |
| **ローカライズされた価格が優先** | 一致する [Localized Pricing](/features/localized-pricing) ルールを持つ商品は、PPP による調整を受けません。設定した正確な金額が適用されます。 |
| **換算前に適用** | 割合は基本価格に適用されます。Adaptive Currency が結果を換算します。 |
| **割引前に適用** | [discount code](/features/discount-codes) は値下げ後の価格に適用されるため、2つの値下げが組み合わされます。 |
| **使用量ベースでは固定料金のみ** | PPP は使用量ベース商品の固定料金に適用されますが、従量制の使用量には適用されません。 |
| **Pay What You Want には非対応** | 顧客が金額を選択するため、PPP は適用されません。[Pay What You Want](/features/pay-what-you-want) を参照してください。 |
| **割合の範囲** | 国別の割合は30〜100です。最大値下げ率は70%です。 |
| **専用 webhook なし** | 値下げ後の金額は、他の価格と同様に決済またはサブスクリプションに表示されます。 |

## ベストプラクティス

- **まず1つの商品をオプトインします。** カタログをオプトインする前に、チェックアウト価格を確認してください。
- **割引の重複に注意します。** 割引コードは PPP 価格に重ねて適用されます。国別30%にコードの20%を加えると、リスト価格の24%になります。
- **エンタープライズプランは対象外にします。** 交渉済みのプランに国別調整が必要になることはほとんどありません。
- **重要な場合は独自の値を設定します。** デフォルト値は出発点であり、ルールではありません。
- **サブスクリプションへの影響を確認します。** 値下げ後の価格で登録したサブスクライバーは、その価格で更新されます。
