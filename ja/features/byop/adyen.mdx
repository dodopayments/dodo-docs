<Note>
このガイドは、[Bring Your Own Processor (BYOP)](/features/byop) を通じて**Adyen**を独自のプロセッサとして接続する場合に適用されます。ご不明な点がありましたら、[こちら](mailto:founders@dodopayments.com) までご連絡ください。
</Note>

## 生カードデータアクセスを有効化

DodoがAdyenを介して支払いを処理する前に、Adyenアカウントで**生カードデータアクセス**を有効にする必要があります。AdyenはこれをPCI DSS準拠により制限しています。**Dodo Paymentsがあなたに代わって生カードデータを処理**し、**PCI DSS レベル1に準拠**しているため、Adyenに対して**Dodo Paymentsの準拠証明書（AOC）**を提出し、自分で認証を取得する必要はありません。

<Card title="Dodo Payments PCI DSS Attestation of Compliance (AOC)" icon="file-shield" href="https://pub-2a89184e4c954b599464449d23f506bb.r2.dev/dodo-payments-pci-dss-aoc.pdf">
現在のDodo PaymentsのAOCをダウンロードして、Adyenのサポートに提出し、生カードデータアクセスを有効にしてください。
</Card>

Adyenのサポートに連絡し、上記のAOCを添付して、マーチャントアカウントのための生カードアクセスをリクエストしてください。

## 必要なもの

**設定 → BYOP**でAdyenを接続するには、Adyenのお客様領域から3つの値を集めてください。

| 値 | 出所 |
|-------|---------------------|
| **API key** | Developers → API credentials |
| **Merchant Account** | あなたのAdyenマーチャントアカウント識別子 |
| **HMAC key** | Webhook設定時に生成されます |

<Info>
Adyenは**test** (`ca-test.adyen.com`) と **live** (`ca-live.adyen.com`) の認証情報を分けて管理しています。Dodoで設定しているモードに一致する環境で認証情報を生成してください。
</Info>

## ステップ1：APIキーを生成

<Steps>
<Step title="Open API credentials">
Adyenのお客様領域で、**Developers → API credentials**に進みます。**Manage API credentials** または **Merchant admin** の権限が必要です。
</Step>

<Step title="Select your credential">
**Payments** タブを選び、あなたの認証情報のユーザー名（ 例: `ws_123456@Company.YourCompanyAccount`）を選択します。
</Step>

<Step title="Generate the key">
**Server settings → Authentication**に進み、**API key** タブを開いて、**Generate API key** を選択します。
</Step>

<Step title="Copy it immediately">
キーをコピーして安全に保存してください。ページを離れた後にコピーすることはできません。新しく生成されたキーは即座に有効になり、前のキーは24時間使用可能です。
</Step>
</Steps>

## ステップ2：マーチャントアカウントを見つける

あなたの**マーチャントアカウント**は、Adyenがトランザクションを処理するために使用するアカウント識別子です。お客様領域の上部にあるアカウントセレクタに表示されています（例: `YourCompany_ECOM`）。これをDodoの**Merchant Account** フィールドに貼り付けます。

## ステップ3：WebhookとHMACキーを設定

Dodoは、Adyen接続を保存するときに**Webhook Endpoint** URLを生成します。これをAdyenにWebhookとして追加し、HMACキーを生成します。**Merchant admin** または **Merchant technical integrator** の権限が必要です。

<Steps>
<Step title="Create a webhook">
お客様領域で、**Developers → Webhooks**に進み、**Create new webhook** を選択します。リストから **Standard webhook** タイプの **Add** を選びます。
</Step>

<Step title="Configure the webhook">
- **Description** を入力します。
- **Enabled** を切り替えて、有効にします。
- **Server configuration** の下で、Dodoが生成した**Webhook Endpoint** URLを **URL** フィールドに貼り付けます（HTTPSで公開されている必要があります）。
</Step>

<Step title="Generate the HMAC key">
**Security** の下で、**HMAC Key** セクションに移動して、**Generate** を選択して新しいHMACキーを作成します。コピーして安全に保存してください。後でコピーすることはできません。その後、**Save configuration** を選択します。
</Step>

<Step title="Paste the HMAC key into Dodo">
**Settings → BYOP** に戻り、HMACキーを **Webhook Signing Secret** フィールドに貼り付けて接続を完了します。

<Card title="Set up BYOP" icon="shuffle" href="/features/byop">
完全なBring Your Own Processor設定フローに従ってください。
</Card>
</Step>
</Steps>

<Tip>
保存後、Dodoで**接続を検証**して、Adyenに対するテスト呼び出しを実行し、APIキー、マーチャントアカウント、HMACキーが有効であることを確認してから実稼働します。
</Tip>

## よくある質問

<AccordionGroup>
<Accordion title="What is the HMAC key for?">
Adyenは、受信者が通知の整合性と出所を確認できるように、すべてのWebhookにHMAC署名を付与します。Dodoは、提供されたHMACキーを使用して、AdyenアカウントからのWebhookを検証します。
</Accordion>

<Accordion title="I lost my API key or HMAC key, what now?">
作成後はどちらも取得できません。**Developers → API credentials**で新しいAPIキーを生成するか、Webhook設定で新しいHMACキーを生成し、その値を**Settings → BYOP**で更新してください。
</Accordion>

<Accordion title="Do test and live use the same credentials?">
いいえ。環境に一致した認証情報を生成してください。テスト (`ca-test.adyen.com`) または本番 (`ca-live.adyen.com`) で、そのモードに合わせてDodoで設定します。
</Accordion>
</AccordionGroup>
