## 適応通貨

適応通貨により、顧客は好みの現地通貨で支払うことができ、信頼性とコンバージョン率が向上します。

### 仕組み

1. **有効化**: ビジネス設定から適応通貨を有効にします
2. **選択**: 顧客はチェックアウト時に通貨を直接切り替えることができます
3. **変換**: 価格はリアルタイムの為替レートを使用して動的に変換されます
4. **表示**: 支払い前に最終的な支払額が透明に表示されます

## 自動税計算

税金は顧客の請求住所に基づいて自動的に計算され、GST、VAT、及び販売税の要件に準拠し、手動設定なしで対応します。

### 税計算の仕組み

<Steps>
<Step title="場所の検出">
  税ルールは顧客の国（および該当する場合は地域）に基づいて適用されます。
</Step>

<Step title="動的更新">
  国が変更されると、税額が自動的に更新されます。
  - 住所が更新される
</Step>

<Step title="透明な表示">
  支払い前に最終的な税金内訳が明確に表示されます。
</Step>
</Steps>

<Tip>
税計算は完全に自動化されています。標準的なデジタル商品やSaaS製品に対する手動設定は不要です。
</Tip>

## ビジネスタックスIDサポート

登録されたビジネスの場合、顧客はチェックアウト時にビジネスタックスID（例：VAT/GST番号）を入力できます。

### 税IDが入力された場合の処理

- 税金の適格性がリアルタイムで検証される
- 適用可能な税の免除または逆課税ルールが適用される
- 税額が即時にチェックアウトで更新される

</Info>

## 割引コード

顧客はダッシュボードで作成した割引またはプロモーションコードを直接チェックアウトページで適用できます。

### チェックアウト体験

1. 顧客が割引コードを入力する
2. 割引が即座に検証される
3. 更新された価格と節約が明確に表示される

<Frame>
  <img src="/images/checkout/c4.png" alt="チェックアウトでの割引コード入力" style={{ width: '70%' }}/>
</Frame>

### API統合

割引コードを事前に適用するか、割引入力フィールドを有効にします:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  discount_code: 'WELCOME20', // Pre-apply a code
  feature_flags: {
    allow_discount_code: true // Show discount input field
  },
  return_url: 'https://yoursite.com/return'
});
```

## スマートアドレス収集

チェックアウトは、より迅速な完了のために柔軟な住所入力をサポートします。

### 利用可能なオプション

| オプション | 説明 |
|--------|-------------|
| **Google住所自動入力** | オートコンプリートによる迅速な選択 |
| **手動入力** | 完全な住所のための完全なコントロール |
| **国の選択** | 税金およびコンプライアンスロジックを促進 |

<Tip>
住所の収集は、速度、精度、そしてグローバルなカバレッジをバランスよく保ち、コンバージョンを最大化しつつ、コンプライアンスを確保します。
</Tip>

## カスタムフィールド

顧客からの追加情報を収集するためにカスタムフォームフィールドを定義することができます。これは、会社名、チームのサイズ、紹介元など、ビジネス特有の情報を収集するのに役立ちます。

### 利用可能なフィールドタイプ

| タイプ | 説明 |
|------|-------------|
| `text` | 単一行のテキスト入力 |
| `number` | 数値入力 |
| `email` | 検証付きのメールアドレス |
| `url` | 検証付きのURL |
| `date` | 日付ピッカー |
| `dropdown` | 事前定義されたオプションから選択 |
| `boolean` | はい/いいえトグル |

### 例

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
顧客の応答は自動的に webhook ペイロード (`payment.succeeded`, `subscription.created`) および API 応答を介して `custom_field_responses` 配列に含まれます。チェックアウトセッションごとに最大5つのカスタムフィールドを定義できます。
</Info>

## プライバシーポリシーと利用規約の承認

法的およびコンプライアンスの透明性を確保するために:

- [プライバシーポリシー](https://dodopayments.com/privacy-policy)および[購入者条件](https://dodopayments.com/buyer-terms)へのリンクはチェックアウトで明確に表示される
- 顧客は支払いを完了する前にこれらを明示的に承認する必要があります

<Info>
これは、GDPR準拠を含む世界的な消費者保護およびデータプライバシー要件をい満たすのに役立ちます。
</Info>

## コレクションチェックアウト

製品コレクションは、複数の関連製品（例: スターター、プロ、エンタープライズプラン）を表示し、統一されたチェックアウト体験を提供します。

### 仕組み

1. **すべての製品が表示される**: 顧客はコレクション内のすべてのアクティブ製品を見ることができます
2. **最初の製品が事前選択される**: コレクション内の最初の製品が自動的に選択されます
3. **オプションを比較する**: 顧客は選択する前に価格や特徴を比較できます
4. **単一選択**: 利用可能な製品を選択した後、チェックアウトは標準的な支払いフローに進みます

### コレクションチェックアウトの作成

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
`product_collection_id` を使用する場合は、空の `product_cart` 配列を渡してください。割引コードはセッション作成時に事前に適用することはできません。
</Warning>

## チェックアウトセッションの設定

チェックアウトの動作をチェックアウトセッションAPIを使用して制御します:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_code: 'PROMO10',
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
支払い後、顧客は自動的にあなたの `return_url` にリダイレクトされ、クエリパラメータが自動的に追加されます -- `payment_id` または `subscription_id`、`status`、`email`、および `license_key` （該当する場合）。詳細は [チェックアウトセッションガイド](/developer-resources/checkout-session#request-body) を参照ください。
</Info>

## チェックアウトテーマのカスタマイズ

APIを介してチェックアウトセッションを作成する際に `customization.theme_config` パラメータを使用して、チェックアウトページの外観をブランドに合わせてカスタマイズできます。ライトモードとダークモードの両方の色、フォント、ボーダー半径、ボタンテキストを設定します。

<Frame>
  <img src="/images/checkout/theme-example.png" alt="カスタムテーマのチェックアウトページ"/>
</Frame>

<Info>
このセクションでは、`customization.theme_config`を使用した**サーバーサイドAPI**テーマの設定を説明します。**チェックアウトSDK**（オーバーレイまたはインラインチェックアウト）を使用している場合は、[オーバーレイチェックアウト](/developer-resources/overlay-checkout#theme-customization)または[インラインチェックアウト](/developer-resources/inline-checkout#theme-customization)のテーマカスタマイズセクションを参照してください。これらはキャメルケースプロパティ（例: `bgPrimary` ではなく `bg_primary`）を使用します。
</Info>

### テーマ設定オプション

| プロパティ | 説明 |
|----------|-------------|
| `light` | ライトモード用の色設定 |
| `dark` | ダークモード用の色設定 |
| `font_primary_url` | プライマリフォントのURL |
| `font_secondary_url` | セカンダリフォントのURL |
| `font_size` | フォントサイズ: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `font_weight` | フォントの太さ: `normal`, `medium`, `bold`, `extraBold` |
| `radius` | UI要素のボーダー半径（例: `4px`, `0.5rem`, `8px`） |
| `pay_button_text` | 支払いボタンのカスタムテキスト（例: "購入を完了する", "今すぐ登録"） |

### 色設定（ライト／ダークモード）

それぞれのモード（`light`および`dark`）では、以下の色プロパティをサポートしています。

| プロパティ | 説明 |
|----------|-------------|
| `bg_primary` | 背景のプライマリカラー |
| `bg_secondary` | 背景のセカンダリカラー |
| `text_primary` | テキストのプライマリカラー |
| `text_secondary` | テキストのセカンダリカラー |
| `text_placeholder` | テキストのプレースホルダー色 |
| `text_error` | テキストのエラー色 |
| `text_success` | テキストの成功色 |
| `border_primary` | ボーダーのプライマリカラー |
| `border_secondary` | ボーダーのセカンダリカラー |
| `button_primary` | プライマリボタンの背景色 |
| `button_primary_hover` | プライマリボタンのホバー色 |
| `button_secondary` | セカンダリボタンの背景色 |
| `button_secondary_hover` | セカンダリボタンのホバー色 |
| `button_text_primary` | プライマリボタンのテキスト色 |
| `button_text_secondary` | セカンダリボタンのテキスト色 |
| `input_focus_border` | 入力フォーカスのボーダー色 |

<Info>
すべての色フィールドは標準のCSSカラー形式を受け入れます:
- Hex: `#fff`, `#ffffff`, `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`, `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`, `hsla(120, 100%, 50%, 0.5)`
- 名前付き色: `red`, `blue`, `transparent`
</Info>

### 例

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
すべての色プロパティを指定する必要はありません。指定されていないプロパティはデフォルトのテーマ値が使用されます。
</Tip>
