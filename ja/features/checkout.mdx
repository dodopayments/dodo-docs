## Adaptive Currency

Adaptive Currency を使用すると、顧客は希望する現地通貨で支払えるため、信頼性とコンバージョン率が向上します。

### 仕組み

1. **有効化**: **Settings → Business** から Adaptive Currency を有効にします
2. **選択**: Customers は checkout 上で直接通貨を切り替えられます
3. **PPP の適用**: 商品で [Purchasing Power Parity](/features/purchasing-power-parity) が有効になっている場合、国別の割合によって base price が引き下げられます
4. **換算**: price（または PPP 調整後の price）が live FX rates で customer の通貨に換算されます
5. **丸め処理**: [Charm Pricing](/features/charm-pricing) が有効な場合、換算後の金額は 49.99 のように分かりやすい末尾に丸められます
6. **表示**: 最終的な支払額が payment 前に明確に表示されます

## 自動税計算

顧客の請求先所在地に基づいて税金が自動的に計算されるため、手動設定なしで GST、VAT、売上税の要件に準拠できます。

### 税計算の仕組み

<Steps>
<Step title="Location Detection">
  税ルールは顧客の国（該当する場合は地域）に基づいて適用されます。
</Step>

<Step title="Dynamic Updates">
  次の場合、税額が自動的に更新されます。
  - 国が変更された場合
  - 住所が更新された場合
</Step>

<Step title="Transparent Display">
  支払い前に最終的な税額の内訳が明確に表示されます。
</Step>
</Steps>

<Tip>
税計算は完全に自動化されています。標準的なデジタル商品およびSaaS製品では、手動設定は必要ありません。
</Tip>

## Business Tax ID のサポート

登録済みの事業者の場合、チェックアウトで顧客が Business Tax ID（例: VAT/GST番号）を入力できます。

### Tax ID を入力するとどうなるか

- 税務上の適格性がリアルタイムで検証されます
- 適用可能な免税またはリバースチャージのルールが適用されます
- チェックアウト画面の税額が即座に更新されます

## Discount Codes

顧客は、ダッシュボードで作成した割引コードまたはプロモーションコードをチェックアウトページで直接適用できます。

### チェックアウト体験

1. 顧客が割引コードを入力
2. 割引が即座に検証されます
3. 更新後の価格と割引額が明確に表示されます

商品で [Purchasing Power Parity](/features/purchasing-power-parity) が有効になっている場合、discount は base price ではなく PPP 調整後の price に適用されます。

<Frame>
  <img src="/images/checkout/c4.png" alt="checkout 上の discount code 入力" style={{ maxHeight: '500px', width: '70%' }}/>
</Frame>

### API Integration

1 つ以上の stacked discount codes を事前に適用するか、discount input field を有効にします。

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  discount_codes: ['WELCOME20'], // Pre-apply one or more codes (max 20, applied in order)
  feature_flags: {
    allow_discount_code: true // Shown by default; set to false to hide the field
  },
  return_url: 'https://yoursite.com/return'
});
```

<Info>
`discount_codes` は、順番に積み重ねて適用される最大 20 個の codes の array を受け付けます。単数形の `discount_code` field は deprecated ですが、引き続き動作します。既存の integrations はすぐに変更する必要はありません。stacking と、より豊富な response shape を利用するには、都合のよいタイミングで `discount_codes` に移行してください。
</Info>

## Smart Address Collection

checkout は、より迅速に完了できる柔軟な address 入力に対応しています。

### 利用可能な Options

| Option | Description |
|--------|-------------|
| **Google Address Autofill** | autocomplete によるすばやい選択 |
| **Manual Entry** | 完全な address を入力するための細かな制御 |
| **Country Selection** | tax と compliance のロジックを決定 |
| **Minimal Address** | country のみ（tax に必要な場合は ZIP も）を収集 — [Minimal Address Mode](#minimal-address-mode) を参照 |

<Tip>
Address collection は、compliance を確保しながら conversion を最大化するため、速度、正確性、グローバルな対応範囲のバランスを取ります。
</Tip>

### Minimal Address Mode

conversion を最大化するには、minimal address collection を有効にして checkout の負担を軽減します。`minimal_address` が `true` に設定されている場合、checkout で収集されるのは次の項目のみです。

- **Country** — tax の判定に常に必要
- **ZIP/Postal code** — sales tax、VAT、または GST の計算に必要な地域でのみ収集

その他の address fields（street、city、state）はすべて省略されるため、checkout の完了が大幅に速くなります。

<Frame>
  <img src="/images/changelog/minimal-address.png" alt="checkout 上で country と ZIP/postal code fields のみを表示する Minimal Address Mode" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  minimal_address: true,
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Full address collection が default です。完全な billing details が必要ない digital products や SaaS flows では、`minimal_address` を有効にしてください。
</Info>

<Card title="Minimal Address Reference" icon="address-card" href="/developer-resources/checkout-session#request-body">
  Checkout Sessions API guide で `minimal_address` parameter の完全な reference を確認できます。
</Card>

## Phone Number Collection

checkout に phone number field を表示するか、必須にするかを、checkout session feature flags で制御できます。

| Flag | Default | Behavior |
|------|---------|----------|
| `allow_phone_number_collection` | `true` | checkout form に phone number field を表示 |
| `require_phone_number` | `false` | phone number field を必須にする（form validation により空でない value を要求） |

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_abc', quantity: 1 }],
  feature_flags: {
    allow_phone_number_collection: true,
    require_phone_number: true
  },
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
`require_phone_number: true` には `allow_phone_number_collection: true` が必要です。phone collection が disabled の状態で phone number が required に設定された sessions は、API によって reject されます。
</Warning>

<Tip>
B2B SaaS、regulated industries、または support、fraud review、compliance のために verified contact channel が必要な flow では、`require_phone_number` を使用してください。
</Tip>

## Custom Fields

custom form fields を定義して、checkout 中に customers から追加情報を収集できます。company name、team size、referral source、その他の business-specific information などのデータ収集に便利です。

### 利用可能な Field Types

| Type | Description |
|------|-------------|
| `text` | 1 行の text input |
| `number` | Numeric input |
| `email` | validation 付きの Email address |
| `url` | validation 付きの URL |
| `date` | Date picker |
| `dropdown` | predefined options から選択 |
| `boolean` | Yes/No toggle |

### Example

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Customer responses は webhook payloads（`payment.succeeded`、`subscription.active`）と、`custom_field_responses` array を介した API responses に自動的に含まれます。checkout session ごとに最大 5 つの custom fields を定義できます。
</Info>

## Collection Checkout

Product Collections により、customers が 1 回の checkout で複数の関連 products（Starter、Pro、Enterprise plans など）を表示・選択できる、統一された checkout experience を実現できます。

### 仕組み

1. **すべての products を表示**: Customers に collection 内のすべての active products を表示
2. **最初の product を事前選択**: collection 内の最初の product が自動的に選択されます
3. **Options を比較**: Customers は選択前に pricing と features を比較できます
4. **単一選択**: product を選択すると、checkout は標準の payment flow に進みます

### Collection Checkout の作成

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
`product_collection_id` を使用する場合は、空の `product_cart` array を渡してください。session creation 時に discount codes を事前適用することはできません。
</Warning>

## Checkout Session Configuration

Checkout Sessions API を使用して checkout behavior を制御します。

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_codes: ['PROMO10'],
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  cancel_url: 'https://yoursite.com/pricing', // Optional: where to redirect on cancel
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
payment 後、customers は `return_url` に redirect され、query parameters が自動的に追加されます。これには、`payment_id` または `subscription_id`、`status`、`email`、`license_key`（該当する場合）が含まれます。完全な list については [Checkout Sessions guide](/developer-resources/checkout-session#request-body) を参照してください。
</Info>

## Checkout Theme Customization

API 経由で checkout session を作成する際に `customization.theme_config` parameter を使用して、checkout page の appearance を brand に合わせてカスタマイズできます。light mode と dark mode の両方で、colors、fonts、border radius、button text を設定できます。

<Frame>
  <img src="/images/checkout/theme-example.png" alt="カスタムテーマを適用した checkout page" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Card title="Design & Theme Customization" icon="palette" href="/features/design">
  pre-built themes、typography、colors、live preview を使用して、dashboard から themes を視覚的に設定できます。
</Card>

<Info>
この section では `customization.theme_config` を使用した **server-side API** theme configuration について説明します。**Checkout SDK**（overlay または inline checkout）を使用している場合は、camelCase properties を使用する [Overlay Checkout](/developer-resources/overlay-checkout#theme-customization) の theme customization section を参照してください（たとえば、`bg_primary` の代わりに `bgPrimary` を使用します）。
</Info>

### Theme Configuration Options

| Property | Description |
|----------|-------------|
| `light` | light mode の color configuration |
| `dark` | dark mode の color configuration |
| `font_primary_url` | primary font の URL |
| `font_secondary_url` | secondary font の URL |
| `font_size` | Font size: `xs`、`sm`、`md`、`lg`、`xl`、`2xl` |
| `font_weight` | Font weight: `normal`、`medium`、`bold`、`extraBold` |
| `radius` | UI elements の border radius（例: `4px`、`0.5rem`、`8px`） |
| `pay_button_text` | pay button の custom text（例: "Complete Purchase"、"Subscribe Now"） |

### Color Configuration (Light/Dark Mode)

各 mode（`light` および `dark`）は、次の color properties に対応しています。

| Property | Description |
|----------|-------------|
| `bg_primary` | primary background color |
| `bg_secondary` | secondary background color |
| `text_primary` | primary text color |
| `text_secondary` | secondary text color |
| `text_placeholder` | placeholder text color |
| `text_error` | error text color |
| `text_success` | success text color |
| `border_primary` | primary border color |
| `border_secondary` | secondary border color |
| `button_primary` | primary button background color |
| `button_primary_hover` | primary button hover color |
| `button_secondary` | secondary button background color |
| `button_secondary_hover` | secondary button hover color |
| `button_text_primary` | primary button text color |
| `button_text_secondary` | secondary button text color |
| `input_focus_border` | input focus border color |

<Info>
すべての color fields は標準的な CSS color formats に対応しています。
- Hex: `#fff`、`#ffffff`、`#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`、`rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`、`hsla(120, 100%, 50%, 0.5)`
- Named colors: `red`、`blue`、`transparent`
</Info>

### Example

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
すべての color properties を指定する必要はありません。指定されていない properties には default theme values が使用されます。
</Tip>
