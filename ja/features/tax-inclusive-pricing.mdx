## 税金込み価格設定とは？

税金込み価格設定では、表示される製品価格に適用される税金を直接埋め込むことができます。顧客は、より透明でコンバージョンに優しい体験のために、事前に最終的な金額を1つ表示されます。チェックアウト時に、Dodoは表示された価格に基づいて顧客の所在地から税金を除いた部分と税金の金額を計算し、請求書で明確に分けます。

<Info>
最終的な税金は顧客の所在地や税金のカテゴリによって異なります。チェックアウトおよび請求書には、表示された価格から導出された計算された税金部分が表示されます。
</Info>

## 主な利点

- **顧客への明確さ**: 事前に表示される最終価格
- **地域ごとのコンプライアンス**: 所在地ごとに税金が計算され、分けられます
- **正確な請求書**: 請求書には、価格から導出されたネット金額と税金が表示されます
- **コンバージョンに優しい**: チェックアウト時の驚きを減少させます

## 製品設定

ダッシュボードで製品を作成または編集し、価格設定の設定で税金込み価格設定を有効にします。

#### 価格設定

- **価格** (必須): 顧客に表示される基本価格。
- **税金込み価格設定**: 表示された価格を税金込みとして扱うためにトグルをオンにします。Dodoは、顧客の所在地と税金のカテゴリに基づいて、ネット（税抜き）金額と税金部分をチェックアウト時に計算します。

<Warning>
将来の購入のみが更新された税金込み設定を反映します。既存の購入やアクティブなサブスクリプションは遡及的に変更されません。
</Warning>

<Tip>
「税金込み」といった一貫した製品コピーを使用して、顧客が合計を一目で理解できるようにします。
</Tip>

## 統合例

### 税金込み価格設定の製品を作成

```typescript
const product = await client.products.create({
  name: 'Pro Plan',
  description: 'All features included',
  price: {
    currency: 'USD',
    price: 10000
    tax_inclusive: true
  }
});
```

### 既存の製品を更新して税金込みに切り替え

```typescript
await client.products.update(product.id, {
  price: {
    tax_inclusive: true
  }
});
```

## ベストプラクティス

- **正しい税金カテゴリを選択**して、地域ごとの正確な計算を確保します。
- **合計を明確に伝える**ために、製品コピーに「税金込み」ラベルを使用します。
- **サンドボックスでテスト**して検証します。
