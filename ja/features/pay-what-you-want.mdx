**好きな金額を支払う (PWYW)** は、顧客が支払う金額を決定できるモデルです。これは、商人が定義した最低価格以上での支払いを可能にします。顧客の関与を高め、コミュニティのサポートを促し、デジタル製品に対して柔軟な価格設定を提供します。

## 好きな金額を支払うとは？

PWYWは、顧客があなたが定義したガードレール内で自分の価格を設定する価格モデルです。これは以下のような場合に最適です：

- **デジタル製品とメディア**: テンプレート、電子書籍、コース、プラグイン
- **実験的なローンチ**: 早期アクセス、ベータリリース、期間限定プロモーション
- **バンドルと追加**: 参加を促進するためにPWYW層を追加

## 主な利点

- **顧客主導の価格設定**: 購入者が支払う金額を選択
- **収益の底**: マージンを保護するための最低価格を強制
- **期待の固定**: 選択を導くためのオプションの推奨価格
- **シームレスなチェックアウト**: ホストされたチェックアウトと領収書が自動的に処理される
- **開発者ファースト**: 作成、返金、Webhookのための明確なAPI

<Warning>
PWYW は**Single Payment**（一度限り）の商品のみに対応しています。
</Warning>

## 好きな金額を支払うの作成

一回限りの製品を作成し、Dodo PaymentsダッシュボードでPWYWを有効にします。以下のセクションは作成フォームに直接対応しています。

### 製品の作成

#### 製品の詳細

- **製品名**（必須）: チェックアウトと請求書に表示される名前
- **製品説明**（必須）: 顧客が支払う前に見る明確な価値声明
- **製品画像**（必須）: PNG/JPG/WebP 最大3MB
- **ブランド**: テーマやメールのために特定のブランドに製品を関連付ける
- **税カテゴリ**（必須）: 税ルールを決定するために正しいカテゴリを選択

<Tip>
地域ごとに正しく税金を徴収するには、最も正確な税カテゴリを選択してください。
</Tip>

#### 価格設定

- **価格タイプ**: <b>単一支払い</b>を選択
- **好きな金額を支払う**（トグル）: 購入者が金額を選択できるようにする
- **最低価格**（必須）: 顧客が支払うことができる最低金額
- **推奨価格**（オプション）: 製品ページに表示される推奨金額

<Tip>
後でイベントや領収書を照合できるように、metadata を使用して自システムの識別子（orderId など）を保存してください。
</Tip>

#### 固定金額のリンクを共有する

**Products** から PWYW 商品のチェックアウトリンクを共有する際、**Advanced Settings** を開き、**Payment amount** を設定すると、購入者に金額を選択させず、設定した金額をそのまま請求できます。金額は商品の Minimum Price 以上である必要があり、主要通貨単位（例：$12.50 の場合は `12.5`）で、`paymentAmount` query parameter としてリンクに付加されます。購入者が金額を選択できる動作を維持するには、フィールドを空のままにしてください。

## 一般的なユースケース

- **デジタルアセット**：テーマ、テンプレート、アイコンセット、メディア、プラグイン
- **コンテンツと教育**：電子書籍、コース、支援者向け価格を設定したワークショップ
- **コミュニティと寄付**：募金活動、オープンソースへのスポンサーシップ、クリエイター支援
- **ローンチの実験**：需要を測るためのベータアクセスや期間限定キャンペーン

## 統合例

### チェックアウトセッション（単一支払い、PWYW）
PWYW 商品をカートに追加します。チェックアウトでは購入者が金額を入力し（設定した最低金額が適用されます）、追加のフィールドは必要ありません。

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_pwyw_demo', quantity: 1 }
  ],
  return_url: 'https://yoursite.com/checkout/success'
});
```

## ベストプラクティス

- **妥当な最低金額を設定する**：コストをカバーしつつ、参加しやすい金額にする
- **推奨価格を提示する**：期待値を示して平均注文額の向上につなげる
- **価値を明確に説明する**：購入者に、貢献によって得られるものを伝える
- **キャンペーンを A/B テストする**：オファーに期限を設け、メッセージを試行する
- **分布を監視する**：支払額を追跡し、最低金額と推奨価格を改善する

<Info>
PWYW は、収益の下限を維持しながら、より多くの顧客を呼び込める柔軟な方法です。まずはシンプルに始め、十分にテストし、コンバージョン、貢献額の分布、返金率に基づいて改善を重ねてください。
</Info>
