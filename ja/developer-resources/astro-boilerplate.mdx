## 概要

Astroミニマルボイラープレートは、Dodo PaymentsをAstroアプリケーションに統合するためのすぐに使える出発点を提供します。このテンプレートには、認証、Webhook処理、基本的な支払い設定が含まれており、迅速に支払いを受け入れる手助けをします。

<Info>
このボイラープレートは、TypeScriptを使用したAstroで構成されており、チェックアウトセッションとWebhook検証の例実装が含まれています。
</Info>

## クイックスタート

<Steps>
<Step title="リポジトリをクローンする">
ボイラープレートリポジトリをクローンし、プロジェクトディレクトリに移動します:

```bash
git clone https://github.com/dodopayments/dodo-astro-minimal-boilerplate.git
cd dodo-astro-minimal-boilerplate
```

</Step>

<Step title="API資格情報を取得する">
テストモードでDodo Paymentsダッシュボードから資格情報を取得します:

- **APIキー**: [ダッシュボード](https://app.dodopayments.com)の**Developer → API Keys**に移動します
- **Webhook署名キー**: [ダッシュボード](https://app.dodopayments.com)の**Developer → Webhooks**に移動します

<Tip>
テストモードから始めて、実際の支払いを処理せずに統合を安全にテストしてください。
</Tip>
</Step>

<Step title="環境変数を設定する">
ルートディレクトリに`.env`ファイルを作成します:

```bash
touch .env
```

Dodo Paymentsの資格情報を追加します:

```bash .env
DODO_API_KEY_TEST=your_test_api_key_here
DODO_PAYMENTS_WEBHOOK_KEY=your_webhook_signing_key_here
```

<Warning>
`.env`ファイルをバージョン管理にコミットしないでください。これはすでに`.gitignore`に含まれています。
</Warning>
</Step>

<Step title="Webhookローカルホストを設定する">
ローカルでWebhookをテストする際は、[ngrok](https://ngrok.com)のようなツールを使用してローカルホストを公開します:

```bash
ngrok http 4321
```

Webhook配信のために、`allowed_hosts`リストにngrokのURLを`astro.config.mjs`に追加します:

```javascript astro.config.mjs
export default defineConfig({
  server: {
    host: true,
    allowedHosts: ['your-ngrok-url.ngrok.io']
  }
});
```

<Note>
このステップは、Webhookがローカル開発環境に配信されるために必要です。
</Note>
</Step>

<Step title="依存関係をインストールする">
必要なnpmパッケージをインストールします:

```bash
npm install
```

</Step>

<Step title="開発サーバーを実行する">
Astro開発サーバーを起動します:

```bash
npm run dev
```

アプリケーションは`http://localhost:4321`で利用可能になります。

<Check>
ビルドを開始する準備が整いました！ボイラープレートには、統合を理解するための例ルートとコンポーネントが含まれています。
</Check>
</Step>
</Steps>

## プロジェクト構造

```
dodo-astro-minimal-boilerplate/
├── src/
│   ├── pages/
│   │   ├── api/
│   │   │   └── webhooks.ts     # Webhook handler
│   │   └── index.astro         # Home page with examples
│   └── lib/
│       └── dodo.ts             # Dodo Payments client setup
├── .env.example                # Environment variables template
├── astro.config.mjs            # Astro configuration
└── package.json
```

## 次のステップ

ボイラープレートが動作している状態になったら:

<Steps>
<Step title="製品を作成する">
チェックアウト機能を有効にするために、[Dodo Paymentsダッシュボード](https://app.dodopayments.com)に製品を追加します。
</Step>

<Step title="ローカルでWebhookをテストする">
[ngrok](https://ngrok.com)を使用してローカルWebhookエンドポイントを公開し、`allowed_hosts`を`astro.config.mjs`で更新します:

```bash
ngrok http 4321
```

ngrokのURLをダッシュボードのWebhook設定に追加します。
</Step>

<Step title="統合をカスタマイズする">
アプリケーションのニーズとデザインに合わせて例コードを適応させます。
</Step>

<Step title="本番環境に移行する">
準備が整ったら、Live Mode APIキーに切り替えてアプリケーションをデプロイします。
</Step>
</Steps>
