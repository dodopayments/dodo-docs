Dodo Paymentsリソースを管理し、チェックアウトセッションを作成し、ターミナルから直接ウェブフックをテストします。コマンドラインを好む開発者のために構築されています。

## インストール

<CodeGroup>

```bash npm (Recommended)
npm install -g dodopayments-cli
```

```bash Bun
bun install -g dodopayments-cli
```

</CodeGroup>

### 手動インストール

1. [GitHub Releases](https://github.com/dodopayments/dodopayments-cli/releases)からシステムに合った最新のリリースをダウンロードします
2. バイナリを抽出して、`dodo`に名前を変更します
3. PATH内のディレクトリに移動します:

<CodeGroup>

```bash Linux
sudo mv ./dodo /usr/local/bin/
```

```text Windows
move .\dodo C:\Windows\System32\dodo
```

</CodeGroup>

## 認証

CLIを使用する前に、APIキーで認証します:

```bash
dodo login
```

これは:
1. ブラウザでDodo Payments APIキーのページを開きます
2. APIキーの入力を促します
3. 環境（**テストモード**または**ライブモード**）を選択するよう求めます
4. ローカルに資格情報を保存します `~/.dodopayments/api-key`

<Info>
CLIは、環境ごとに1つのAPIキーの保存をサポートします。テストとライブモードの両方のキーが設定されている場合、現在のセッションで使用する環境を選ぶように促されます。
</Info>

## 使用法

一般的な構文は次のとおりです:

```bash
dodo ‹category› ‹sub-command›
```

引数なしで`dodo`を実行すると、利用可能なすべてのカテゴリが表示されます。サブコマンドなしで`dodo <category>`を実行すると、そのカテゴリの利用可能なサブコマンドが表示されます。

### 商品

製品カタログを管理します。

| コマンド | 説明 |
|---------|-------------|
| `dodo products list` | すべての製品をリスト表示します（ページネーション） |
| `dodo products create` | ダッシュボードを開いて製品を作成します |
| `dodo products info` | 特定の製品の詳細を表示します |

### 支払い

支払いトランザクションを表示します。

| コマンド | 説明 |
|---------|-------------|
| `dodo payments list` | すべての支払いをリスト表示します（ページネーション） |
| `dodo payments info` | 特定の支払いについての情報を取得します |

### 顧客

顧客基盤を管理します。

| コマンド | 説明 |
|---------|-------------|
| `dodo customers list` | すべての顧客をリスト表示します（ページネーション） |
| `dodo customers create` | 新しい顧客プロファイルを作成します |
| `dodo customers update` | 既存の顧客の詳細を更新します |

### 割引

クーポンと割引を管理します。

| コマンド | 説明 |
|---------|-------------|
| `dodo discounts list` | すべての割引をリスト表示します（ページネーション） |
| `dodo discounts create` | 新しい割合ベースの割引を作成します |
| `dodo discounts delete` | IDで割引を削除します |

### ライセンス

ソフトウェアライセンスを管理します。

| コマンド | 説明 |
|---------|-------------|
| `dodo licences list` | すべてのライセンスキーをリスト表示します（ページネーション） |

### アドオン

製品アドオンを管理します。

| コマンド | 説明 |
|---------|-------------|
| `dodo addons list` | すべてのアドオンをリスト表示します（ページネーション） |
| `dodo addons create` | ダッシュボードを開いてアドオンを作成します |
| `dodo addons info` | 特定のアドオンの詳細を表示します |

### 返金

返金情報を表示します。

| コマンド | 説明 |
|---------|-------------|
| `dodo refund list` | すべての返金をリスト表示します（ページネーション） |
| `dodo refund info` | 特定の返金の詳細を表示します |

### チェックアウト

チェックアウトセッションを作成します。

| コマンド | 説明 |
|---------|-------------|
| `dodo checkout new` | 新しいチェックアウトセッションを作成し、チェックアウトURLを取得します |

チェックアウトコマンドは、最小限の住所収集、リターンURL、3Dセキュア強制、割引コード、メタデータなどの高度なオプションをサポートします。

## ウェブフックテスト

CLIには、開発中にウェブフックをテストするための2つの強力なツールが含まれています：ライブテストウェブフックをローカルサーバーに転送する**リスナー**と、任意のエンドポイントにモックウェブフックペイロードを送信する**トリガー**。

### ウェブフックをリッスン

Dodo Paymentsからのウェブフックをリアルタイムであなたのローカル開発サーバーに転送します。

```bash
dodo wh listen
```

<Steps>
<Step title="ローカルエンドポイントURLを入力">
  ウェブフックを受け取るローカルURLを指定します（例：`http://localhost:3000/webhook`）。
</Step>

<Step title="自動設定">
  CLIは、まだ存在しない場合にDodo Paymentsアカウントにウェブフックエンドポイントを自動的に作成し、リアルタイムでイベントを受信するためにWebSocket接続を開きます。
</Step>

<Step title="受信して転送">
  ウェブフックイベントが発生したとき（テスト支払い、サブスクリプションの変更など）、CLIはそれを受信し、イベントタイプをログに記録し、リクエスト全体をヘッダーおよびボディと共にローカルエンドポイントに転送します。エンドポイントからの応答はログに記録され、返されます。
</Step>
</Steps>

<Warning>
ウェブフックリスナーは、**テストモード**のAPIキーでのみ機能します。`dodo wh listen`を使用する前に、テストモードキーでログインしていることを確認してください。
</Warning>

<Tip>
リスナーは、ローカルエンドポイントに転送する際に元のウェブフックヘッダー（`webhook-id`、`webhook-signature`、`webhook-timestamp`）を保持するため、署名検証ロジックをテストできます。
</Tip>

### テストウェブフックをトリガー

リアルなトランザクションを作成せずに、任意のエンドポイントにモックウェブフックペイロードを送信して迅速にテストします。

```bash
dodo wh trigger
```

これにより以下が案内されます:
1. 宛先**エンドポイントURL**を設定します
2. 必要に応じて**ビジネスID**、**商品ID**、および**メタデータ**を設定します
3. インタラクティブメニューから特定の**イベント**を選択してトリガーします
4. モックペイロードを送信し、レスポンスを表示します

各イベントの後、別のイベントをトリガーするか終了することができるため、1セッションで複数のイベントハンドラーをテストしやすくなります。

<Warning>
トリガーツールは、ウェブフック署名なしでモックペイロードを送信します。テスト中は、ウェブフックハンドラー内で`unsafe_unwrap()`の代わりに`unwrap()`を使用してウェブフック署名検証を無効にします。
</Warning>

### サポートされているウェブフックイベント

| カテゴリ | イベント |
|----------|--------|
| **サブスクリプション** | `subscription.active`、`subscription.updated`、`subscription.on_hold`、`subscription.renewed`、`subscription.plan_changed`、`subscription.cancelled`、`subscription.failed`、`subscription.expired` |
| **支払い** | `payment.success`、`payment.failed`、`payment.processing`、`payment.cancelled` |
| **返金** | `refund.success`、`refund.failed` |
| **紛争** | `dispute.opened`、`dispute.expired`、`dispute.accepted`、`dispute.cancelled`、`dispute.challenged`、`dispute.won`、`dispute.lost` |
| **ライセンス** | `licence.created` |

### 環境変数

| 変数 | 説明 |
|----------|-------------|
| `DODO_WH_TEST_SERVER_URL` | `dodo wh listen`で使用されるデフォルトのウェブフックリレーサーバーURLを上書きします |
