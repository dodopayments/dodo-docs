## インストール

<Steps>
<Step title="Install the package">
プロジェクトのルートで次のコマンドを実行します:

```bash
npm install @dodopayments/tanstack
```

</Step>
<Step title="Set up environment variables">
プロジェクトのルートに<code>.env</code>ファイルを作成します:

```env expandable
DODO_PAYMENTS_API_KEY=your-api-key
DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
DODO_PAYMENTS_RETURN_URL=your-return-url
DODO_PAYMENTS_ENVIRONMENT="test_mode" or "live_mode"
```

<Warning>
<code>.env</code>ファイルやシークレットをバージョン管理にコミットしないでください。
</Warning>
</Step>
</Steps>

<Tab title="Checkout Handler">

  </Info>
  <CodeGroup>

    ```typescript Tanstack Route Handler expandable
    // src/routes/api/checkout.ts
    import { Checkout } from "@dodopayments/tanstack";
    import { createServerFileRoute } from "@tanstack/react-start/server";

    export const ServerRoute = createServerFileRoute("/api/checkout")
    .methods({
        GET: async ({ request }) => {
        return Checkout({
            bearerToken: process.env.DODO_PAYMENTS_API_KEY,
            returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
            environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
            type: "static", // optional, defaults to 'static'

        return Checkout({
            bearerToken: process.env.DODO_PAYMENTS_API_KEY,

            environment: process.env.DODO_PAYMENTS_ENVIRONMENT,

        }
    })
  
    ```

## Checkout Route Handler

<Info>
Dodo Paymentsは、決済をWebサイトに統合するための3種類のpayment flowをサポートしており、このadaptorはすべてのpayment flowに対応しています。
</Info>

- **Static Payment Links:** すぐに共有でき、コードなしで迅速に決済を収集できるURLです。
- **Dynamic Payment Links:** APIまたはSDKを使用して、カスタム詳細を含むpayment linkをプログラムで生成します。
- **Checkout Sessions:** 事前設定された商品カートと顧客情報を使用して、安全でカスタマイズ可能なcheckout体験を作成します。

### Response Format
Static checkoutはcheckout URLを含むJSON responseを返します:

```json
{
  "checkout_url": "https://checkout.dodopayments.com/..."
}
```

</Accordion>
<Accordion title="Dynamic Checkout (POST)">
- パラメータをPOST requestのJSON bodyとして送信します。
- one-time paymentとrecurring paymentの両方をサポートします。
- サポートされているPOST body fieldの完全な一覧については、次を参照してください:
  - [One Time Payment ProductのRequest body](https://docs.dodopayments.com/api-reference/payments/post-payments)
  - [Subscription ProductのRequest body](https://docs.dodopayments.com/api-reference/subscriptions/post-subscriptions)

### Response Format
Dynamic checkoutはcheckout URLを含むJSON responseを返します:

```json
{
  "checkout_url": "https://checkout.dodopayments.com/..."
}
```

</Accordion>
<Accordion title="Checkout Sessions (POST)">
Checkout sessionsは、より安全なhosted checkout体験を提供します。one-time purchaseとsubscriptionの両方について、完全にカスタマイズ可能な決済フロー全体を処理します。

詳細とサポートされているfieldの完全な一覧については、[Checkout Sessions Integration Guide](https://docs.dodopayments.com/developer-resources/checkout-session)を参照してください。

### Response Format
Checkout sessionsはcheckout URLを含むJSON responseを返します:

```json
{
  "checkout_url": "https://checkout.dodopayments.com/session/..."
}
```

</Accordion>

## Customer Portal Route Handler

Customer Portal Route Handlerを使用すると、Dodo Payments customer portalをTanstackアプリケーションにシームレスに統合できます。

### Query Parameters
<ParamField query="customer_id" type="string" required>
portal sessionの顧客ID（例: <code>?customer_id=cus_123</code>）。
</ParamField>
<ParamField query="send_email" type="boolean">
<code>true</code>に設定すると、portal linkを記載したメールを顧客に送信します。
</ParamField>

<Warning>
<code>customer_id</code>がない場合は400を返します。
</Warning>

## Webhook Route Handler

- **Method:** POST requestsのみサポートされます。それ以外のmethodには405を返します。
- **Signature Verification:** <code>webhookKey</code>を使用してwebhook signatureを検証します。検証に失敗した場合は401を返します。
- **Payload Validation:** Zodで検証します。無効なpayloadには400を返します。
- **Error Handling:**
  - 401: 無効なsignature
  - 400: 無効なpayload
  - 500: 検証中のinternal error
- **Event Routing:** payload typeに基づいて適切なevent handlerを呼び出します。
