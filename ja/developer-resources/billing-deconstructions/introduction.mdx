## 概要

| アプリ | 主な指標 | 独自のイノベーション | Dodo 機能 |
| :--- | :--- | :--- | :--- |
| OpenAI | トークン（フィアット通貨建て） | 有効期限のないプリペイドフィアットクレジット | クレジットベース請求（フィアットクレジット） |
| Cursor | プレミアムリクエスト | モデル重み付けクレジット減耗（モデルごとに異なるコスト） | クレジットベース請求（カスタムユニット） |
| ElevenLabs | 文字数 | ロールオーバー付き文字数割り当て + 段階的超過料金 | クレジットベース請求（ロールオーバー + 超過） |
| Midjourney | GPU 時間 | クォータ後の「リラックスモード」無制限フォールバック | サブスクリプション + 使用メーター |
| Replicate | 実行秒数 | ハードウェア固有の毎秒純正メーター | 純使用ベース請求 |
| Lovable | メッセージ（クレジット） | 毎日のボーナスドリップ + チーム全体でのクレジット共有プール | クレジットベース請求（カスタムユニット） + サブスクリプション |

各デコンストラクションは実在の企業の請求モデルを分解し、Dodo Paymentsでそのモデルを再現する方法を示します。

構築しているアプリに最も近いものを選んでください:

## インジェスションブループリント

各デコンストラクションには、Dodoの[インジェスションブループリント](/features/usage-based-billing/ingestion-blueprints)との統合が含まれており、イベントトラッキングを自動で処理するプリビルドSDKが備わっています。利用イベントを手動で構築する代わりに、ブループリントを使用して数分で実運用に適したメーターリングを実現できます。
