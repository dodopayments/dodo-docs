## 概要

Agent Skills は、AI コーディングアシスタントが Dodo Payments を扱う際に実行できることを拡張する、再利用可能な機能です。手続きに関する知識とベストプラクティスを提供し、checkout フローの統合から usage-based billing の設定まで、エージェントが特定のタスクをより効果的に遂行できるよう支援します。

<Info>
**skills は AI アシスタント向けのプラグインだと考えてください。** エージェントが推奨パターンとベストプラクティスに従って、Dodo Payments の機能を正しく実装できるようにします。
</Info>

Skills は、次のような MCP-compatible AI エージェントで利用できます。
- **Claude Code** - Anthropic の CLI コーディングアシスタント
- **OpenCode** - オープンソースの AI コーディングエージェント
- **Cursor** - AI-first のコードエディター
- **その他の MCP clients** - skills protocol に対応するあらゆるエージェント

## インストール

AI coding assistantに応じて、希望するインストール方法を選択してください。

<Tabs>
<Tab title="Agent Plugin (recommended)">
Claude Code、Codex CLI、Cursor、またはOpenCodeを使用している場合、[Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents)によって17のスキルと両方のMCP serversを1ステップでインストールできます。agentが関連するタスクを検出すると、スキルは自動的に読み込まれます。

agentごとのインストールコマンドについては、[AI Coding Agents guide](/developer-resources/build-with-ai-coding-agents)を参照してください。
</Tab>

<Tab title="Skills CLI">
任意のMCP-compatible agentで動作するuniversal skills CLIを使用してスキルをインストールします。

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

または、必要に応じて個別のスキルをインストールします。

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
必要なスキルだけをインストールして、agentの焦点を維持し、コンテキストのオーバーヘッドを減らします。
</Tip>
</Tab>

## スキルの使用

インストール後、Dodo Paymentsの機能の実装を依頼すると、AI assistantは関連するスキルを自動的に読み込みます。スキル名を指定する必要はありません。タスクを説明するだけで十分です。

| Example prompt | Skill that loads |
|----------------|------------------|
| Dodo Paymentsをベストプラクティスに従ってNext.jsアプリに統合するのを手伝って | `dodo-best-practices` |
| HonoアプリにDodo Payments checkout route handlerを追加して | `framework-adapters` |
| 決済のテストと本番開始までの手順を説明して | `testing-and-go-live` |
| SaaS product用のcheckout sessionを作成して | `checkout-integration` |
| 無料トライアルと複数の価格帯を含むsubscription flowを実装して | `subscription-integration` |
| React Nativeアプリにアプリ内checkoutを追加して | `mobile-checkout` |
| paymentとsubscriptionのイベント用webhook handlersを設定して | `webhook-integration` |
| AI product用のcredit entitlementsとmetered credit deductionを設定して | `credit-based-billing` |
| AI productのAPI callsを追跡するusage-based billingを追加して | `usage-based-billing` |
| desktop app用のlicense key validationを実装して | `license-keys` |
| add-onsとtiered pricingを含むproduct catalogを作成して | `product-catalog-management` |
| 最初の3 billing cyclesが20% offになるpromo codeを追加して | `discounts-and-promotions` |
| 購買力平価を適用して訪問者の現地通貨で価格を表示して | `localized-pricing` |
| 顧客がpayment methodsを管理できるself-service portalを提供して | `customer-management` |
| partial refundを発行し、disputeが開始されたらアクセス権を取り消して | `refunds-and-disputes` |
| BillingSDK componentsを使用してpricing pageを追加して | `billing-sdk` |
| Dodo PaymentsをBetter Auth setupに接続して | `better-auth-integration` |

## スキルの仕組み

スキルはAI assistantに次の情報を提供します。

1. **手順に関する知識** - 機能を実装するためのステップごとの手順
2. **Code Templates** - 本番環境で使用できるコードパターンとスニペット
3. **Best Practices** - security、error handling、UXに推奨されるアプローチ
4. **Context Awareness** - Dodo Paymentsの各機能がどのように連携するかの理解

AI assistantに機能の実装を依頼すると、関連するスキルを使用して次のことを行います。
- 正しい実装アプローチを理解する
- 正確で動作するコードを生成する
- Dodo Paymentsの規約に従う
- edge casesとerrorsを適切に処理する

<Note>
スキルは[MCP Server](/developer-resources/mcp-server)と[Sentra](/developer-resources/sentra)を補完します。API operationsにはMCP、guided integrationにはSentra、AI assistantの機能強化にはSkillsを使用してください。
</Note>

## 他のツールとの比較

| Tool | Purpose | Best For |
|------|---------|----------|
| **Agent Skills** | AI assistantの知識を強化 | 任意のMCP clientを使用したAI支援開発 |
| **MCP Server** | API operationsを実行 | AI assistantからの直接的なAPI access |
| **Sentra** | Guided integration assistant | IDEでのinteractive billing integration |
