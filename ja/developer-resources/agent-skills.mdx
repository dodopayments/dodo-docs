## 概要

Agent Skills は、AI コーディングアシスタントが Dodo Payments を扱う際に実行できることを拡張する、再利用可能な機能です。手続きに関する知識とベストプラクティスを提供し、checkout フローの統合から usage-based billing の設定まで、エージェントが特定のタスクをより効果的に遂行できるよう支援します。

<Info>
**skills は AI アシスタント向けのプラグインだと考えてください。** エージェントが推奨パターンとベストプラクティスに従って、Dodo Payments の機能を正しく実装できるようにします。
</Info>

Skills は、次のような MCP-compatible AI エージェントで利用できます。
- **Claude Code** - Anthropic の CLI コーディングアシスタント
- **OpenCode** - オープンソースの AI コーディングエージェント
- **Cursor** - AI-first のコードエディター
- **その他の MCP clients** - skills protocol に対応するあらゆるエージェント

## インストール

AI コーディングアシスタントに応じて、希望するインストール方法を選択してください。

<Tabs>
<Tab title="Agent Plugin (recommended)">
Claude Code、Codex CLI、Cursor、または OpenCode を使用している場合は、[Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) により、8 つすべての skills と両方の MCP servers を 1 ステップでインストールできます。エージェントが関連するタスクを検出すると、skills は自動的に読み込まれます。

エージェントごとのインストールコマンドについては、[AI Coding Agents guide](/developer-resources/build-with-ai-coding-agents) を参照してください。
</Tab>

<Tab title="Skills CLI">
あらゆる MCP-compatible agent で動作する universal skills CLI を使用して、skills をインストールします。

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

または、必要に応じて個別の skills をインストールします。

```bash
# Best practices guide
npx skills add dodopayments/skills/dodo-payments/best-practices

# Webhook integration
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Subscription billing
npx skills add dodopayments/skills/dodo-payments/subscription-integration

# Checkout flows
npx skills add dodopayments/skills/dodo-payments/checkout-integration

# Usage-based billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing

# BillingSDK components
npx skills add dodopayments/skills/dodo-payments/billing-sdk

# License key management
npx skills add dodopayments/skills/dodo-payments/license-keys

# Credit-based billing
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
```

<Tip>
必要な skills のみをインストールして、エージェントの焦点を維持し、コンテキストのオーバーヘッドを削減します。
</Tip>
</Tab>

<Tab title="Claude Code">
Dodo Payments skills marketplace を Claude Code に追加します。

```bash
/plugin marketplace add dodopayments/skills
```

次に、個別の plugins をインストールします。

```bash
# Install best practices
/plugin install dodo-best-practices

# Install webhook integration
/plugin install webhook-integration

# Install subscription integration
/plugin install subscription-integration

# Install checkout integration
/plugin install checkout-integration

# Install usage-based billing
/plugin install usage-based-billing

# Install BillingSDK
/plugin install billing-sdk

# Install license keys
/plugin install license-keys

# Install credit-based billing
/plugin install credit-based-billing
```

</Tab>

<Tab title="OpenCode">
OpenCode settings で設定すると、skills は自動的に利用可能になります。Dodo Payments skills repository を設定に追加します。

```json
{
  "skills": {
    "repositories": [
      "dodopayments/skills"
    ]
  }
}
```

</Tab>
</Tabs>

## Skills の使用

インストールすると、AI アシスタントは、Dodo Payments の機能の実装を依頼した際に、これらの skills を活用できます。プロンプトの例を以下に示します。

### ベストプラクティス

```
Help me integrate Dodo Payments into my Next.js app following best practices
```

### Webhooks

```
Set up webhook handlers for payment and subscription events
```

### Subscriptions

```
Implement a subscription flow with free trial and multiple pricing tiers
```

### Checkout

```
Create a checkout session for my SaaS product
```

### Usage-Based Billing

```
Add usage-based billing to track API calls for my AI product
```

### BillingSDK

```
Add a pricing page using BillingSDK components
```

### License Keys

```
Implement license key validation for my desktop app
```

### Credit-Based Billing

```
Set up credit entitlements and metered credit deduction for my AI product
```

## Skills の仕組み

Skills は AI アシスタントに次の情報を提供します。

1. **Procedural Knowledge** - 機能を実装するための手順ごとの指示
2. **Code Templates** - 本番環境で利用できるコードパターンとスニペット
3. **Best Practices** - security、error handling、UX に関する推奨アプローチ
4. **Context Awareness** - 異なる Dodo Payments の機能がどのように連携するかについての理解

AI アシスタントに機能の実装を依頼すると、関連する skill を使用して次のことを行います。
- 正しい実装アプローチを理解する
- 正確で動作するコードを生成する
- Dodo Payments の規約に従う
- エッジケースとエラーを適切に処理する

<Note>
Skills は [MCP Server](/developer-resources/mcp-server) と [Sentra](/developer-resources/sentra) を補完します。API operations には MCP、ガイド付き統合には Sentra、AI アシスタントの機能強化には Skills を使用してください。
</Note>
