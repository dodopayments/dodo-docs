## 概要

Agent Skills は、AI コーディングアシスタントが Dodo Payments を扱う際に実行できることを拡張する、再利用可能な機能です。手続きに関する知識とベストプラクティスを提供し、checkout フローの統合から usage-based billing の設定まで、エージェントが特定のタスクをより効果的に遂行できるよう支援します。

<Info>
**skills は AI アシスタント向けのプラグインだと考えてください。** エージェントが推奨パターンとベストプラクティスに従って、Dodo Payments の機能を正しく実装できるようにします。
</Info>

Skills protocolをサポートするあらゆるAI agentでSkillsを使用できます。以下が含まれます:
- **Claude Code** - AnthropicのCLIコーディングアシスタント
- **Codex CLI** - OpenAIのCLIコーディングagent
- **Cursor** - AIファーストのコードエディター
- **VS Code / GitHub Copilot** - Agent Plugin経由
- **Kiro** - SkillsをPowerとして読み込み
- **OpenCode** - オープンソースのAIコーディングagent
- **その他のクライアント** - Skills protocolをサポートするあらゆるagent

<Note>
**Gemini CLIは例外です。** agent-skill primitiveがないため、Skillsは利用できません — 利用できるのは2つの[MCP servers](/developer-resources/mcp-server)のみです。
</Note>

## インストール

AI coding assistantに応じて、希望するインストール方法を選択してください。

<Tabs>
<Tab title="Agent Plugin (recommended)">
Claude Code、Codex CLI、Cursor、VS Code / GitHub Copilot、Kiro、またはOpenCodeを使用している場合、[Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents)によって17個すべてのSkillsと両方のMCP serversを一度にインストールできます。agentが関連するタスクを検出すると、Skillsは自動的に読み込まれます。

agentごとのインストールコマンドについては、[AI Coding Agents guide](/developer-resources/build-with-ai-coding-agents)を参照してください。
</Tab>

<Tab title="Skills CLI">
あらゆるMCP-compatible agentで動作するuniversal skills CLIを使用してSkillsをインストールします:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

または、必要に応じて個々のSkillsをインストールします:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/dodo-best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>

</Tip>

<Tab title="OpenCode">
OpenCodeは、指定したdirectoriesからSkillsを読み込みます。インストール済みpackagesをスキャンしないため、明示的な`skills.paths` entryが必要です。

Agent Plugin packageを使用する場合:

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

Relative pathsは**project directory**を基準に解決されるため、packageはそのprojectの`node_modules`に存在している必要があります。Absolute pathも使用でき、その場合はlocal-install requirementを回避できます。

<Warning>
存在しないSkills pathは**サイレントに**無視されます — errorもwarningもありません。Skillsが実際に読み込まれたことを確認します:

```bash
opencode run "List every skill available to you by name."
```

17個すべてが表示されるはずです。
</Warning>
</Tab>
</Tabs>

## Skillsの使用

インストール後、Dodo Paymentsのfeatureの実装を依頼すると、AI assistantは関連するSkillを自動的に読み込みます。Skillの名前を指定する必要はありません — タスクを説明するだけで構いません。

| Example prompt | Skill that loads |
|----------------|------------------|
| ベストプラクティスに従って、Dodo PaymentsをNext.js appに統合する方法を教えて | `dodo-best-practices` |
| Hono appにDodo Payments checkout route handlerを追加して | `framework-adapters` |
| 決済のテストと本番稼働までの手順を説明して | `testing-and-go-live` |
| SaaS product用のcheckout sessionを作成して | `checkout-integration` |
| free trialと複数のpricing tiersを備えたsubscription flowを実装して | `subscription-integration` |
| React Native appにアプリ内checkoutを追加して | `mobile-checkout` |
| paymentとsubscription events用のwebhook handlersを設定して | `webhook-integration` |
| AI product用にcredit entitlementsとmetered credit deductionを設定して | `credit-based-billing` |
| AI productのAPI callsを追跡するusage-based billingを追加して | `usage-based-billing` |
| desktop app用のlicense key validationを実装して | `license-keys` |
| add-onsとtiered pricingを備えたproduct catalogを作成して | `product-catalog-management` |
| 最初の3 billing cyclesを20%割引にするpromo codeを追加して | `discounts-and-promotions` |
| purchasing power parityを適用し、訪問者のlocal currencyで価格を表示して | `localized-pricing` |
| Customersがpayment methodsを管理できるself-service portalを提供して | `customer-management` |
| partial refundを発行し、disputeが開始されたらaccessを取り消して | `refunds-and-disputes` |
| BillingSDK componentsを使用したpricing pageを追加して | `billing-sdk` |
| Better Auth setupにDodo Paymentsを組み込んで | `better-auth-integration` |

## Skillsの仕組み

SkillsはAI assistantに以下を提供します:

1. **Procedural Knowledge** - feature実装のstep-by-step instructions
2. **Code Templates** - production-readyなcode patternsとsnippets
3. **Best Practices** - security、error handling、UXに推奨されるアプローチ
4. **Context Awareness** - Dodo Paymentsのさまざまなfeaturesがどのように連携するかの理解

AI assistantにfeatureの実装を依頼すると、関連するSkillを使用して以下を行います:
- 正しいimplementation approachを理解する
- 正確で動作するcodeを生成する
- Dodo Paymentsのconventionsに従う
- edge casesとerrorsを適切に処理する

<Note>
Skillsは[MCP Server](/developer-resources/mcp-server)と[Sentra](/developer-resources/sentra)を補完します。API operationsにはMCP、guided integrationにはSentra、AI assistant capabilitiesの強化にはSkillsを使用してください。
</Note>
