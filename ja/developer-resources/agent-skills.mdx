## 概要

エージェントスキルは、Dodo Paymentsと連携する際にAIコーディングアシスタントができることを強化する再利用可能な機能です。これらは手続き的な知識とベストプラクティスを提供し、エージェントが特定のタスクをより効果的に実行できるように支援します - チェックアウトフローの統合から使用量ベースの請求の設定まで。

<Info>
**スキルをAIアシスタントのプラグインとして考えてください。** これらはエージェントにDodo Paymentsの機能を正しく実装する方法を教え、推奨されるパターンとベストプラクティスに従います。
</Info>

スキルは、次のような任意のMCP互換のAIエージェントと連携します:
- **Claude Code** - AnthropicのCLIコーディングアシスタント
- **OpenCode** - オープンソースのAIコーディングエージェント
- **Cursor** - AIファーストのコードエディタ
- **その他のMCPクライアント** - スキルプロトコルをサポートする任意のエージェント

## インストール

AIコーディングアシスタントに基づいて、好みのインストール方法を選択してください。

<Tabs>
<Tab title="Skills CLI">
MCP互換のエージェントで動作するユニバーサルスキルCLIを使用してスキルをインストールします：

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

または、必要に応じて個別のスキルをインストールします：

```bash
# Best practices guide
npx skills add dodopayments/skills/dodo-best-practices

# Webhook integration
npx skills add dodopayments/skills/webhook-integration

# Subscription billing
npx skills add dodopayments/skills/subscription-integration

# Checkout flows
npx skills add dodopayments/skills/checkout-integration

# Usage-based billing
npx skills add dodopayments/skills/usage-based-billing

# BillingSDK components
npx skills add dodopayments/skills/billing-sdk

# License key management
npx skills add dodopayments/skills/license-keys
```

<Tip>
エージェントを集中させ、コンテキストオーバーヘッドを減らすために、必要なスキルのみをインストールしてください。
</Tip>
</Tab>

<Tab title="Claude Code">
Claude CodeにDodo Paymentsスキルマーケットプレイスを追加します：

```bash
/plugin marketplace add dodopayments/skills
```

次に、個別のプラグインをインストールします：

```bash
# Install best practices
/plugin install dodo-best-practices

# Install webhook integration
/plugin install webhook-integration

# Install subscription integration
/plugin install subscription-integration

# Install checkout integration
/plugin install checkout-integration

# Install usage-based billing
/plugin install usage-based-billing

# Install BillingSDK
/plugin install billing-sdk

# Install license keys
/plugin install license-keys
```

</Tab>

<Tab title="OpenCode">
スキルはOpenCodeの設定で構成されると自動的に利用可能になります。Dodo Paymentsスキルリポジトリを設定に追加します：

```json
{
  "skills": {
    "repositories": [
      "dodopayments/skills"
    ]
  }
}
```

</Tab>
</Tabs>

## スキルの使用

インストール後、AIアシスタントはDodo Paymentsの機能を実装するように求めたときにこれらのスキルを活用できます。以下は例のプロンプトです：

### ベストプラクティス

```
Help me integrate Dodo Payments into my Next.js app following best practices
```

### Webhooks

```
Set up webhook handlers for payment and subscription events
```

### サブスクリプション

```
Implement a subscription flow with free trial and multiple pricing tiers
```

### チェックアウト

```
Create a checkout session for my SaaS product
```

### 使用量ベースの請求

```
Add usage-based billing to track API calls for my AI product
```

### BillingSDK

```
Add a pricing page using BillingSDK components
```

### ライセンスキー

```
Implement license key validation for my desktop app
```

## スキルの仕組み

スキルはAIアシスタントに次のことを提供します：

1. **手続き的知識** - 機能を実装するための手順に基づく指示
2. **コードテンプレート** - 生産準備されたコードパターンとスニペット
3. **ベストプラクティス** - セキュリティ、エラーハンドリング、UXの推奨アプローチ
4. **コンテキスト認識** - 異なるDodo Payments機能が連携して動作する方法の理解

AIアシスタントに機能を実装するように頼むと、関連するスキルを使用して：
- 正しい実装アプローチを理解する
- 正確で動作するコードを生成する
- Dodo Paymentsの慣習に従う
- エッジケースやエラーを適切に処理する

<Note>
スキルは[MCPサーバー](/developer-resources/mcp-server)および[Sentra](/developer-resources/sentra)を補完します。API操作にはMCPを、ガイド付きの統合にはSentraを、AIアシスタントの機能強化にはスキルを使用してください。
</Note>

## 他のツールとの比較

| ツール | 目的 | 最適な用途 |
|------|---------|----------|
| **エージェントスキル** | AIアシスタントの知識を強化する | 任意のMCPクライアントによるAI支援開発 |
| **MCPサーバー** | API操作を実行する | AIアシスタントからの直接的なAPIアクセス |
| **Sentra** | ガイド付き統合アシスタント | IDE内でのインタラクティブな請求統合 |
