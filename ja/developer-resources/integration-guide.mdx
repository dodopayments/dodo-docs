## 前提条件

Dodo Payments APIを統合するには、次のものが必要です。
- Dodo Payments merchant account
- ダッシュボードから取得した API Credentials（API key と webhook secret key）

## ダッシュボードの設定

1. [Dodo Payments Dashboard](https://app.dodopayments.com/) に移動します

2. 商品を作成します（一回限りの支払いまたはサブスクリプション）。サブスクリプション商品は、少なくとも **$1**（または選択した通貨での相当額）で価格設定する必要があります。この最低額を下回る金額はサポートされていません。

4. API key を生成します。
   - Developer > API に移動します
   - [詳細ガイド](/api-reference/introduction#api-key-generation)
   - DODO_PAYMENTS_API_KEY という env に API key をコピーします

5. Webhooks を設定します。
   - Developer > Webhooks に移動します
   - payment notifications 用の webhook URL を作成します
   - env に webhook secret key をコピーします 

## 統合

### Payment Links

ユースケースに合った統合方法を選択します。
- **Checkout Sessions（推奨）**: ほとんどの統合に最適です。サーバー上でセッションを作成し、安全なホスト型 checkout に顧客をリダイレクトします。
- **Overlay Checkout**: サイト上で modal overlay として checkout を開く、ページ内の体験が必要な場合に使用します。
- **Inline Checkout**: checkout をページレイアウトに直接埋め込み、完全に統合されたブランド化 checkout 体験を実現します。
- **Static Payment Links**: コード不要で、すぐに共有できる URL による迅速な支払い回収が可能です。
- **Dynamic Payment Links**: プログラムで作成するリンクです。ただし、Checkout Sessions が推奨されており、より柔軟性があります。

#### 1. Checkout Sessions

Checkout Sessions を使用すると、一回限りの支払いやサブスクリプション向けに、安全なホスト型 checkout 体験を作成できます。サーバー上でセッションを作成し、返された `checkout_url` に顧客をリダイレクトします。

<Info>
Checkout sessions はデフォルトで24時間有効です。<code>confirm=true</code> を渡すと、セッションは15分間有効になり、必須フィールドをすべて指定する必要があります。
</Info>

<Steps>
<Step title="Create a checkout session">
  使用する SDK を選択するか、REST API を呼び出します。

  <Tabs>
  <Tab title="Node.js SDK">

  ```javascript
  import DodoPayments from 'dodopayments';

  const client = new DodoPayments({
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    environment: 'test_mode', // defaults to 'live_mode'
  });

  const session = await client.checkoutSessions.create({
    product_cart: [{ product_id: 'prod_123', quantity: 1 }],
    customer: { email: 'customer@example.com', name: 'John Doe' },
    return_url: 'https://yourapp.com/checkout/success',
  });
  ```

  </Tab>

  <Tab title="Python SDK">

  ```python
  import os
  from dodopayments import DodoPayments

  client = DodoPayments(
      bearer_token=os.environ.get("DODO_PAYMENTS_API_KEY"),
      environment="test_mode",  # defaults to "live_mode"
  )

  session = client.checkout_sessions.create(
      product_cart=[{"product_id": "prod_123", "quantity": 1}],
      customer={"email": "customer@example.com", "name": "John Doe"},
      return_url="https://yourapp.com/checkout/success",
  )
  ```

  </Tab>

  <Tab title="REST API">

  ```javascript
  const response = await fetch('https://test.dodopayments.com/checkouts', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${process.env.DODO_PAYMENTS_API_KEY}`,
    },
    body: JSON.stringify({
      product_cart: [{ product_id: 'prod_123', quantity: 1 }],
      customer: { email: 'customer@example.com', name: 'John Doe' },
      return_url: 'https://yourapp.com/checkout/success',
    }),
  });
  const session = await response.json();
  ```

  </Tab>

</Step>

<Step title="Redirect customer to checkout">
  セッション作成後、ホスト型フローを開始するには `checkout_url` にリダイレクトします。

  ```javascript
  // Example in a browser context
  window.location.href = session.checkout_url;
  ```

<Tip>
支払いの受付を最も迅速かつ確実に開始するには、Checkout Sessions を使用してください。高度なカスタマイズについては、完全な <a href="/developer-resources/checkout-session">Checkout Sessions ガイド</a> と <a href="/api-reference/checkout-sessions/create">API Reference</a> を参照してください。

#### 2. Overlay Checkout

ページ内でシームレスな checkout 体験を実現するには、顧客がWebサイトを離れずに支払いを完了できる [Overlay Checkout](/developer-resources/overlay-checkout) 統合を確認してください。

#### 3. Inline Checkout

ページに直接埋め込んだ完全統合型の checkout 体験には、[Inline Checkout](/developer-resources/inline-checkout) 統合を使用します。これにより、カスタム注文概要を作成し、checkout レイアウトを完全に制御できます。また、Dodo Payments が支払いの回収を安全に処理します。

#### 4. Static Payment Links

Static payment links を使用すると、シンプルな URL を共有してすばやく支払いを受け付けられます。query parameters を渡すことで、顧客情報の事前入力、フォームフィールドの制御、カスタムメタデータの追加など、checkout 体験をカスタマイズできます。

<Steps>
<Step title="Construct your payment link">
  ベース URL から始め、商品 ID を追加します。

  ```text
  https://checkout.dodopayments.com/buy/{productid}
  ```

</Step>
<Step title="Add core parameters">
  必須の query parameters を含めます。
  - <ParamField query="quantity" type="integer" default="1">購入する商品の数。</ParamField>
  - <ParamField query="redirect_url" type="string" required>支払い完了後にリダイレクトする URL。</ParamField>
  <Note>
  リダイレクト URL には、次の例のように、支払いの詳細が query parameters として含まれます。<br/>
  <code>https://example.com/?payment_id=pay_ts2ySpzg07phGeBZqePbH&status=succeeded&email=customer%40example.com</code><br/><br/>
  商品で license keys が有効になっている場合は、`license_key` parameter も追加されます（複数のキーの場合はカンマ区切り）。<br/>
  <code>https://example.com/?payment_id=pay_xxx&status=succeeded&license_key=LK-001&email=customer%40example.com</code>
  </Note>
</Step>
<Step title="Pre-fill customer information (optional)">
  checkout を効率化するため、顧客情報または請求先フィールドを query parameters として追加します。
  <AccordionGroup>
    <Accordion title="Supported Customer Fields">
      - <ParamField query="fullName" type="string">顧客の氏名（firstName または lastName が指定されている場合は無視されます）。</ParamField>
      - <ParamField query="firstName" type="string">顧客の名。</ParamField>
      - <ParamField query="lastName" type="string">顧客の姓。</ParamField>
      - <ParamField query="email" type="string">顧客のメールアドレス。</ParamField>
      - <ParamField query="country" type="string">顧客の国。</ParamField>
      - <ParamField query="addressLine" type="string">住所。</ParamField>
      - <ParamField query="city" type="string">市区町村。</ParamField>
      - <ParamField query="state" type="string">州または県。</ParamField>
      - <ParamField query="zipCode" type="string">郵便番号。</ParamField>
      - <ParamField query="showDiscounts" type="boolean">true または false</ParamField>
    </Accordion>
  </AccordionGroup>
</Step>
<Step title="Control form fields (optional)">
  <Info>
  特定のフィールドを無効にして、顧客が読み取り専用にすることができます。これは、ログイン済みユーザーなど、顧客の詳細をすでに取得している場合に便利です。
  </Info>
  フィールドを無効にするには、その値を指定し、対応する <code>disable...</code> flag を <code>true</code> に設定します。
  <CodeGroup>

  ```text Example
  &email=alice@example.com&disableEmail=true
  ```

  </CodeGroup>
  <Tabs>
    <Tab title="Disable Flags Table">
      | フィールド         | 無効化フラグ         | 必須パラメータ |
      |---------------|---------------------|-------------------|
      | 氏名     | `disableFullName`   | `fullName`        |
      | 名    | `disableFirstName`  | `firstName`       |
      | 姓     | `disableLastName`   | `lastName`        |
      | Email         | `disableEmail`      | `email`           |
      | 国       | `disableCountry`    | `country`         |
      | 住所       | `disableAddressLine`| `addressLine`     |
      | 市区町村          | `disableCity`       | `city`            |
      | 州         | `disableState`      | `state`           |
      | 郵便番号      | `disableZipCode`    | `zipCode`         |
    </Tab>
  </Tabs>
  <Tip>
  フィールドを無効にすると、誤った変更を防ぎ、データの一貫性を確保できます。
  </Tip>
  <Note>
  <code>showDiscounts=false</code> を設定すると、checkout form の割引セクションが無効になり、非表示になります。checkout 中に顧客が coupon または promo codes を入力できないようにする場合に使用します。
  </Note>

</Step>
<Step title="Add advanced controls (optional)">
  - <ParamField query="paymentCurrency" type="string">支払い通貨を指定します。デフォルトでは請求先の国の通貨が使用されます。</ParamField>
  - <ParamField query="showCurrencySelector" type="boolean" default="true">通貨セレクターを表示または非表示にします。</ParamField>
  - <ParamField query="paymentAmount" type="integer">金額（Pay What You Want pricing の場合のみ、セント単位）。</ParamField>
  - <ParamField query="metadata_*" type="string">カスタムメタデータフィールド（例: <code>metadata_orderId=123</code>）。</ParamField>
</Step>
<Step title="Share the link">
  完成した payment link を顧客に送信します。顧客がアクセスすると、すべての query parameters が収集され、session ID とともに保存されます。その後、URL は session parameter のみを含む簡略化された形式になります（例: <code>?session=sess_1a2b3c4d</code>）。保存された情報はページを更新しても保持され、checkout プロセス全体で利用できます。
  <Check>
  顧客の checkout 体験は、指定した parameters に基づいて効率化およびパーソナライズされます。
  </Check>
</Step>
</Steps>

#### 4. Dynamic Payment Links
<Tip>
ほとんどのユースケースでは Checkout Sessions を推奨します。より柔軟かつ細かな制御が可能です。
</Tip>

顧客情報を含む API call または SDK によって作成します。例を示します。

dynamic payment links を作成する API は2つあります。

- One-time Payment Link API [API reference](/api-reference/payments/post-payments)
- Subscription Payment Link API [API reference](/api-reference/subscriptions/post-subscriptions)

以下のガイドでは、一回限りの payment link の作成方法を説明します。

サブスクリプションの統合手順については、[Subscription Integration Guide](/developer-resources/subscription-integration-guide) を参照してください。

<Info>payment link を取得するには `payment_link = true` を渡していることを確認してください </Info>

    package main

import (
  "context"
  "fmt"

  "github.com/dodopayments/dodopayments-go"
  "github.com/dodopayments/dodopayments-go/option"
)

func main() {
  client := dodopayments.NewClient(
    option.WithBearerToken("My Bearer Token"), // defaults to os.LookupEnv("DODO_PAYMENTS_API_KEY")
  )
  payment, err := client.Payments.New(context.TODO(), dodopayments.PaymentNewParams{
    PaymentLink: dodopayments.F(true),
    Billing: dodopayments.F(dodopayments.PaymentNewParamsBilling{
      City: dodopayments.F("city"),
      Country: dodopayments.F(dodopayments.CountryCodeAf),
      State: dodopayments.F("state"),
      Street: dodopayments.F("street"),
      Zipcode: dodopayments.F(int64(0)),
    }),
    Customer: dodopayments.F(dodopayments.PaymentNewParamsCustomer{
      Email: dodopayments.F("email"),
      Name: dodopayments.F("name"),
    }),
    ProductCart: dodopayments.F([]dodopayments.PaymentNewParamsProductCart{dodopayments.PaymentNewParamsProductCart{
      ProductID: dodopayments.F("product_id"),
      Quantity: dodopayments.F(int64(0)),
    }}),
  })
  if err != nil {
    panic(err.Error())
  }
  fmt.Printf("%+v\n", payment.PaymentLink)
}

export async function POST(request: NextRequest) {
  try {
    const body = await request.json();
    const { formData, cartItems } = paymentRequestSchema.parse(body);

    const response = await fetch(`${process.env.NEXT_PUBLIC_DODO_TEST_API}/payments`, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        Authorization: `Bearer ${process.env.DODO_API_KEY}`, // Replace with your API secret key generated from the Dodo Payments Dashboard
      },
      body: JSON.stringify({
        billing: {
          city: formData.city,
          country: formData.country,
          state: formData.state,
          street: formData.addressLine,
          zipcode: parseInt(formData.zipCode),
        },
        customer: {
          email: formData.email,
          name: `${formData.firstName} ${formData.lastName}`,
          phone_number: formData.phoneNumber || undefined,
        },
        payment_link: true,
        product_cart: cartItems.map((id) => ({
          product_id: id,
          quantity: 1,
        })),
        return_url: process.env.NEXT_PUBLIC_RETURN_URL,
      }),
    });

    if (!response.ok) {
      const errorData = await response.json().catch(() => null);
      return NextResponse.json(
        { error: "Payment link creation failed", details: errorData },
        { status: response.status }
      );
    }

    const data = await response.json();
    return NextResponse.json({ paymentLink: data.payment_link });
  } catch (err) {
    console.error("Payment error:", err);
    return NextResponse.json(
      {
        error: err instanceof Error ? err.message : "An unknown error occurred",
      },
      { status: 500 }
    );
  }
}

### Webhooks の実装

支払い通知を受信する API endpoint を設定します。Next.js を使用した例を示します。

```javascript
import { Webhook } from "standardwebhooks";
import { headers } from "next/headers";
import { WebhookPayload } from "@/types/api-types";

const webhook = new Webhook(process.env.DODO_WEBHOOK_KEY!); // Replace with your secret key generated from the Dodo Payments Dashboard

export async function POST(request: Request) {
  const headersList = headers();
  const rawBody = await request.text();

  const webhookHeaders = {
    "webhook-id": headersList.get("webhook-id") || "",
    "webhook-signature": headersList.get("webhook-signature") || "",
    "webhook-timestamp": headersList.get("webhook-timestamp") || "",
  };

  await webhook.verify(rawBody, webhookHeaders);
  const payload = JSON.parse(rawBody) as WebhookPayload;
  
  // Process the payload according to your business logic
}
```

当社の webhook 実装は [Standard Webhooks](https://standardwebhooks.com/) 仕様に準拠しています。webhook type definitions については、[Webhook Event Guide](/developer-resources/webhooks/intents/webhook-events-guide) を参照してください。

Next.js と TypeScript を使用したデモ実装を含むプロジェクトを [GitHub](https://github.com/dodopayments/dodo-checkout-demo) で確認できます。

ライブ実装は [こちら](https://atlas.dodopayments.com/) で確認できます。
