## 概要

Sentra は、Dodo Payments のコアスタック上にインテリジェンスと実行機能を追加します。請求と決済を統合、分析、実行する AI エージェントです。Sentra は、スタック全体（Auth、DB、CRM など）にまたがる SDK、API、アダプターを接続し、成長要因などの収益インサイトを提示するとともに、返金、アップグレード、クレジット付与などの顧客アクションを実行します。

<Info>
Sentra は現在 Beta 版です。機能、API、統合は急速に変更される可能性があります。改善を進める中で、フィードバックやバグ報告をお待ちしています。
</Info>

## セットアップ

インストール後、Sentra に Dodo Payments API key と環境設定を構成する必要があります。

<Steps>
<Step title="Get Your API Key">
1. [Dodo Payments ダッシュボード](https://app.dodopayments.com) にログインします。
2. **Developer** › **API Keys** に移動します。
3. API key をコピーします。
</Step>

<Step title="Configure Sentra">
1. IDE（VS Code、Cursor、または Windsurf）を開きます。
2. Command Palette を開きます（macOS では `Cmd+Shift+P`、Windows/Linux では `Ctrl+Shift+P`）。
3. 「Sentra: Configure」と入力して選択します。
4. プロンプトが表示されたら、Dodo Payments API key を入力します。

<Frame>
  <img
    src="/images/sentra/setup.png"
    alt="API key の入力と環境選択が表示された Sentra 設定画面"
    width="50%"
  style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Select Environment Mode">
環境モードを選択します。
- **Test Mode**: 開発およびテスト用
- **Live Mode**: 本番環境での使用用

<Warning>
本番データで Live mode に切り替える前に、まず Test mode でセットアップを検証してください。
</Warning>
</Step>

<Step title="Set Model Reasoning Effort">
モデルの推論 effort レベルを選択します。
- **Low**: より高速な応答。単純なタスクに適しています
- **Medium**: バランスの取れたパフォーマンス（推奨）
- **High**: より詳細な分析。複雑な統合に適しています
</Step>

<Step title="Complete Setup">
**Let's go!** をクリックしてセットアップを完了し、Sentra の使用を開始します。

<Check>
API keys は IDE の Secret Storage に安全に保存され、コード内に公開されることはありません。
</Check>
</Step>
</Steps>

## Sentra の使用

### モード

Sentra には、インターフェースから利用できる 3 つのインタラクションモードがあります。

- **Ask**: Dodo Payments、請求モデル、API の使用方法、ベストプラクティスについて質問する
- **Build**: ガイド付きアシスタンスを利用して、アプリケーションに請求と UI を統合する
- **Plan**: アーキテクチャに関するガイダンスを利用して、スケーラブルな請求アーキテクチャを設計する

### タスクの例

Sentra で実行できる一般的なタスクは次のとおりです。

- **Pricing Page の統合**: 商品一覧とチェックアウトを備えた完全な Pricing Page をセットアップする
- **Webhook の実装**: 決済イベント用の webhook handlers を構成する
- **Subscription Flow の追加**: upgrade/downgrade 機能を備えたサブスクリプション管理を作成する
- **使用量ベースの請求のセットアップ**: 使用量追跡用の meters と event ingestion を構成する
- **Customer Portal の作成**: 請求管理用の顧客セルフサービスポータルを構築する

### 自動承認設定

ワークフローを効率化するため、自動承認設定を構成できます。

- **None**: すべての変更を手動でレビューして承認する（本番環境に推奨）
- **Low Risk**: 単純でリスクの低い変更を自動承認する
- **All**: すべての変更を自動承認する（慎重に使用してください）

## 対応する請求モデル

Sentra は、Dodo Payments のすべての請求モデルに対応しています。

- **One-time Payments**: 1 回限りの購入取引
- **Subscriptions**: 複数の間隔での継続的な請求
- **Usage-Based Billing**: 消費量に基づく従量課金
- **Outcome-Based Billing**: 結果に応じて支払う料金モデル

## 対象ユーザー

Sentra はエンジニアリングとビジネスの架け橋となり、すべてのチームが摩擦なく収益化機能をリリースできるようにします。

- **Developers**: IDE 内でより迅速に収益化機能をリリースする
- **Founders & PMs**: 深いインフラ作業なしで請求モデルをプロトタイプする
- **RevOps & Finance**: エンジニアを必要とせず、ガードレール付きのアクションを使用する
- **Support & Success**: 必要に応じて承認を得ながら、安全に請求関連のケースを解決する

## トラブルシューティング

<AccordionGroup>
<Accordion title="Extension not appearing after installation">
インストール後に IDE に Sentra が表示されない場合は、次の手順を試してください。

1. **エディターを再起動する**: VS Code、Cursor、または Windsurf を完全に終了して再度開きます
2. **インストールを確認する**: Extensions に移動し、「Sentra」を検索して拡張機能がインストールされていることを確認します
3. **ウィンドウを再読み込みする**: Command Palette（`Cmd+Shift+P` / `Ctrl+Shift+P`）を使用して「Developer: Reload Window」を実行します

<Check>
ほとんどの場合、エディターを再起動すると問題が解決します。
</Check>
</Accordion>

<Accordion title="Invalid API key or authentication errors">
- API key が正しく、有効になっていることを Dodo Payments ダッシュボードで確認します
- API key に対応する正しい環境モード（Test または Live）を使用していることを確認します
- API key に必要な権限があることを確認します
- 問題が解決しない場合は、API key を再生成してみます
</Accordion>

<Accordion title="Configuration not saving">
- 設定画面ですべての必須フィールドへの入力が完了していることを確認します
- IDE に Secret Storage へのアクセス権限があることを確認します
- Command Palette から Sentra の再構成を試します
</Accordion>

<Accordion title="Plan generation fails">
- API key が有効で、必要なリソースへのアクセス権を持っていることを確認します
- インターネット接続を確認します
- 対応している請求モデルを使用していることを確認します
- より具体的な詳細を含めてプロンプトを言い換えてみます
</Accordion>

<Accordion title="Execution errors">
- 承認する前に、生成されたプランを慎重にレビューします
- プロジェクト構造が Sentra の想定と一致していることを確認します
- すべての依存関係がインストールされていることを確認します
- 詳細なエラーメッセージについては、IDE の出力パネルを確認します
</Accordion>
</AccordionGroup>

<Warning>
エディターを再起動しても問題が解決しない場合は、IDE のバージョンと表示されている具体的なエラーメッセージの詳細を添えてサポートにお問い合わせください。
</Warning>
