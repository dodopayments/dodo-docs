Dodo Paymentsは、複数のプログラミング言語用の公式SDKを提供しており、それぞれが言語固有のベストプラクティスと最新の機能を備えて、シームレスな支払い統合を実現しています。

<Tip>
常に最新のSDKバージョンを使用して、最新の機能と改善にアクセスしてください。パッケージマネージャーで定期的に更新を確認し、Dodo Paymentsのすべての機能を利用できるようにしてください。
</Tip>

## クイックスタート

どのSDKでも数分で始めることができます：

<Steps>
<Step title="Install the SDK">
  使用する言語のパッケージマネージャでSDKをインストールします
  
  <Tabs>
  <Tab title="TypeScript/Node.js">

  ```bash
  npm install dodopayments
  ```

  </Tab>
  
  <Tab title="Python">

  ```bash
  pip install dodopayments
  ```

  </Tab>
  
  <Tab title="PHP">

  ```bash
  composer require dodopayments/client
  ```

  </Tab>
  
  <Tab title="Go">

  ```bash
  go get github.com/dodopayments/dodopayments-go
  ```

  </Tab>

  <Tab title="Rust">

  ```bash
  cargo add dodopayments
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Initialize the Client">
  クライアントをAPIキーで構成します
  
  <Tabs>
  <Tab title="TypeScript">

  ```typescript
  import DodoPayments from 'dodopayments';
  const client = new DodoPayments({ bearerToken: 'your_api_key' });
  ```

  </Tab>
  
  <Tab title="Python">

  ```python
  from dodopayments import DodoPayments
  client = DodoPayments(bearer_token="your_api_key")
  ```

  </Tab>
  
  <Tab title="PHP">

  ```php
  use Dodopayments\Client;
  $client = new Client(bearerToken: 'your_api_key');
  ```

  </Tab>
  
  <Tab title="Go">

  ```go
  import "github.com/dodopayments/dodopayments-go"
  client := dodopayments.NewClient(option.WithBearerToken("your_api_key"))
  ```

  </Tab>

  <Tab title="Rust">

  ```rust
  use dodopayments::Client;
  let client = Client::from_env()?; // reads DODO_PAYMENTS_API_KEY
  ```

  </Tab>
  </Tabs>
  
  <Warning>
  常に環境変数を使用してAPIキーを安全に保存します。バージョン管理にコミットしないでください。
  </Warning>
</Step>

<Step title="Make Your First API Call">
  チェックアウトセッションまたは支払いを作成します
  
  <Check>
  これで支払いの処理が準備完了です！詳細なガイドと例を含む個々のSDKページをご覧ください。
  </Check>
</Step>
</Steps>

## 主な特徴

すべての **backend** SDK は、これらの基本機能を共有しています。以下の mobile checkout SDKs は意図的に機能を絞っており、API key を保持せず、API を呼び出すこともありません。

- **型安全性**: コンパイル時の安全性と優れたIDEサポートのための強力な型付け
- **エラーハンドリング**: 詳細なエラーメッセージを持つ包括的な例外処理
- **認証**: 環境変数サポートによるシンプルなAPIキー認証
- **非同期サポート**: 適用可能なモダンなasync/awaitパターン
- **自動ページネーション**: リストレスポンスの自動ページネーション
- **使用量ベースの課金**: 使用イベントの追跡と取り込みをサポート
- **テスト**: 開発とテスト用の完全なサンドボックス環境

## Mobile Checkout SDKs

ネイティブの決済シートを構築する代わりに、Dodo の **hosted checkout page** を開く場合は、ご利用のプラットフォーム向けの mobile checkout SDK を使用してください。4 つすべてが同じ one-call contract を共有しています。`start(...)` は型付きの `CheckoutResult` を返し、いずれも API key を保持しません。また、checkout は `SFSafariViewController` / Custom Tabs ではなく、プラットフォームの実際のブラウザー画面で開かれるため、Apple Pay/Google Pay は open web と同じように動作します。`WebView` ではありません。

## Command-Line Interface

ターミナルベースのワークフローと自動化に使用します。

<Card title="CLI" icon="terminal" href="/developer-resources/sdks/cli">
  Dodo Payments API をサポートする自動生成されたコマンドラインインターフェース
</Card>

**Features:**
- 直感的に使用できる resource ベースのコマンド構造
- 複数の出力形式（JSON、YAML、pretty、interactive）
- bash、zsh、fish 向けの shell completion
- scripting と CI/CD automation に最適

```bash
# Quick example
dodopayments payments list --format json | jq '.items[] | {payment_id, total_amount}'
```
