<Note>
このガイドでは、**カード、Apple Pay、およびGoogle Pay**を使用した**一回限りの支払い**に限定して説明します。
</Note>

## APIエンドポイント

| 環境 | ベースURL | 支払い確認エンドポイント |
| --- | --- | --- |
| **テストモード** | `https://test.dodopayments.com` | `https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm` |
| **ライブモード** | `https://live.dodopayments.com` | `https://api.hs.dodopayments.com/payments/<payment_id>/confirm` |

## ステップバイステップのカード支払いフロー

### ステップ1: シークレットキーの取得

次に示すAPIを使用して、支払いを作成します:

- **支払い**: [支払い作成API](/api-reference/payments/post-payments)

このAPIは、次のステップで必要な**`secret_key`**を返します。

### ステップ2: 支払いを確認する

`payments confirm`エンドポイントを呼び出して、支払いを確認します:

- **テストモード**: `POST https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm`
- **ライブモード**: `POST https://api.hs.dodopayments.com/payments/<payment_id>/confirm`

リクエストボディに以下の詳細を含めてください:

- `client_secret`: ステップ1からのシークレットキー
- `payment_method`: `card`に設定
- `payment_method_data`: カードと請求の詳細
- `browser_info`: ブラウザ固有のデータ（ユーザーエージェント、画面の詳細など）
- `payment_type`: 明示的に`normal`に設定（1回限りの支払いの場合）

必要なヘッダー:

- DodoPaymentsサポートから公開可能キーを取得してください
- `api-key`: あなたの公開可能キー（これはDodo Paymentsチームから取得します）
- `content-type`: `application/json`

**例: リクエストボディ:**

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "card",
  "payment_method_data": {
    "card": {

      "card_exp_year": "<exp_year>",
      "card_holder_name": "<cardholder_name>",
      "card_cvc": "<cvc>",
      "card_network": "<network>"
    },
    "billing": {
      "address": {
        "first_name": "<first_name>",
        "last_name": "<last_name>"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,

    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },

```

### ブラウザ情報の例

ブラウザ情報は通常次のようになります（実際の値は異なる場合があります）:

```json

  "color_depth": 24,
```

### レスポンスの処理

- レスポンスが**`status`**で**`requires_customer_action`**の場合、顧客を**`next_action`**フィールドに提供されたURLにリダイレクトして、さらに認証を行ってください。

<Warning>
生カードデータを扱う際は、PCIコンプライアンスガイドラインを遵守してください。
</Warning>

## Apple Pay統合

Apple Payを使用するには、`payment_method`を`wallet`に設定し、Apple Payデータを`payment_method_data`に含めてください。

### リクエストボディ構造

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "apple_pay": {
        "payment_data": "<decrypted_payment_data>",
        "payment_method": {
          "display_name": "Visa 1234",
          "network": "Visa",
          "type": "debit"
        },
        "transaction_identifier": "UNIQUE_TRANSACTION_ID_FROM_APPLE"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Apple Payフィールド参照

| フィールド | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| `payment_data` | 文字列 | はい | この列挙型は、暗号化されたまたは復号化されたApple Pay支払いデータを表すために使用されます。 |
| `payment_method.display_name` | 文字列 | はい | Apple Payボタンに表示される名前（例: "Visa 1234"） |
| `payment_method.network` | 文字列 | はい | カードネットワーク（例: "Visa", "Mastercard", "Amex"） |
| `payment_method.type` | 文字列 | はい | 支払い方法の種類（例: "デビット", "クレジット"） |
| `payment_method.card_exp_month` | 文字列 | いいえ | カードの有効期限月（例: "12"） |
| `payment_method.card_exp_year` | 文字列 | いいえ | カードの有効期限年（例: "25"） |
| `transaction_identifier` | 文字列 | はい | Apple Payからのユニークトランザクション識別子 |

## Google Pay統合

Google Payを使用するには、`payment_method`を`wallet`に設定し、Google Payデータを`payment_method_data`に含めてください。

### リクエストボディ構造

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "google_pay": {
        "type": "CARD",
        "description": "Visa ending in 1234",
        "info": {
          "card_network": "VISA",
          "card_details": "1234"
        },
        "tokenization_data": {
          "type": "PAYMENT_GATEWAY",
          "token": "<encrypted_payment_token>"
        }
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Google Payフィールド参照

| フィールド | タイプ | 必須 | 説明 |
| --- | --- | --- | --- |
| `type` | 文字列 | はい | 支払い方法の種類（通常は「CARD」） |
| `description` | 文字列 | はい | 支払い方法のユーザー向け説明 |
| `info.card_network` | 文字列 | はい | カードネットワーク（例: "VISA", "MASTERCARD", "AMEX"） |
| `info.card_details` | 文字列 | はい | カードの最後の4桁 |
| `info.assurance_details` | オブジェクト | いいえ | 認証保証の詳細 |
| `tokenization_data.type` | 文字列 | はい | トークン化の種類（例: "PAYMENT_GATEWAY"） |
| `tokenization_data.token` | 文字列 | はい | Google Payからの暗号化された支払いトークン |
