## 概要

<Info>
このガイドでは、公式の Nuxt module を使用して Dodo Payments を Nuxt アプリケーションに統合する方法を説明します。checkout、Customer Portal、webhook API routes の設定方法と、environment variables を安全に管理する方法を学びます。
</Info>

## インストール

<Steps>
<Step title="Install the Nuxt module">
プロジェクトの root で次の command を実行します:

```bash
npm install @dodopayments/nuxt
```

</Step>
<Step title="Register the module in nuxt.config.ts">
<code>modules</code> array に <code>@dodopayments/nuxt</code> を追加し、設定します:

```typescript nuxt.config.ts expandable
export default defineNuxtConfig({
  modules: ["@dodopayments/nuxt"],
  devtools: { enabled: true },
  compatibilityDate: "2025-02-25",
  runtimeConfig: {
    private: {
      bearerToken: process.env.NUXT_PRIVATE_BEARER_TOKEN,
      webhookKey: process.env.NUXT_PRIVATE_WEBHOOK_KEY,
      environment: process.env.NUXT_PRIVATE_ENVIRONMENT,
      returnUrl: process.env.NUXT_PRIVATE_RETURNURL
    },
  }
});
```

</Step>
</Steps>

<Warning>
<code>.env</code> file や secrets を version control に commit しないでください。
</Warning>

## Checkout Route Handler

<Info>
Dodo Payments は、website に payments を統合するための 3 種類の payment flows をサポートしており、この adaptor はすべての payment flows に対応しています。
</Info>

- **Static Payment Links:** すぐに共有できる URL で、コード不要ですばやく payment を収集できます。
- **Dynamic Payment Links:** API または SDKs を使用して、カスタム詳細を含む payment links を programmatically に生成できます。
- **Checkout Sessions:** 事前設定済みの product carts と customer details により、安全でカスタマイズ可能な checkout experiences を作成できます。

## Webhook Route Handler

- **Method:** POST requests のみサポートされます。それ以外の methods には 405 を返します。
- **Signature Verification:** <code>webhookKey</code> を使用して webhook signature を検証します。検証に失敗した場合は 401 を返します。
- **Payload Validation:** Zod で検証します。payload が無効な場合は 400 を返します。
- **Error Handling:**
  - 401: Invalid signature
  - 400: Invalid payload
  - 500: 検証中の Internal error
- **Event Routing:** payload type に基づいて適切な event handler を呼び出します。
