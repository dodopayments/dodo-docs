<Tip> [ISO Alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) 国コードのリストが提供され、**現在サポートしている支払い可能な国**を示します。対応している国の完全なリストは[こちら](/miscellaneous/list-of-countries-we-accept-payments-from)からご覧いただけます。このリストは、カバレッジの拡大に伴い定期的に更新されます。 </Tip>

<Tip>注: 利用可能なオプションには、現在対応している国だけでなく、**すべての国**のISO Alpha-2コードが含まれます。対応状況は対応国の一覧でご確認ください。 </Tip>
