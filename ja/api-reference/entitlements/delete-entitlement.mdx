<Warning>
権利を削除することは、既存の付与を顧客ポータルから隠す**ソフトデリート**です。プラットフォーム側のアクセスを取り消すわけではありません:

- 権利にリンクされた付与はデータベースに残り、現在の`status`を保持します。
- Discordの役割、GitHubのコラボレーターアクセス、Notionアクセス、Telegramのメンバーシップ、ライセンスキー、およびデジタルファイルURLは有効なままです。
- `entitlement_grant.revoked`ウェブフックは発行されず、`revoked_at` / `revocation_reason`は設定されません。

顧客はカスタマーポータルでこれらの付与を確認できなくなりますが、基盤となるプラットフォームでのアクセスは、サブスクリプション/支払いライフサイクルがそれを取り消す（キャンセル、返金）か、または[`DELETE /entitlements/{id}/grants/{grant_id}`](/api-reference/entitlements/revoke-grant)を介して各付与を手動で取り消すまで続きます。

アクセスを完全に切りたい場合は、まず付与を取り消してから、権利を削除してください。
</Warning>
