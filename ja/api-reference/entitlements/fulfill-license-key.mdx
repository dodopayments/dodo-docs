<Info>
この endpoint は、`fulfillment_mode: manual` を伴う License Key entitlement の下で作成された grant に対してのみ使用してください。grant は key が添付されていない `Pending` status である必要があります。完全なフローについては、[手動フルフィルメント](/features/license-keys#manual-fulfillment)および[手動 License Key フルフィルメント統合ガイド](/developer-resources/manual-license-key-fulfillment)を参照してください。
</Info>
