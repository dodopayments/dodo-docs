<Info>
このエンドポイントは、`fulfillment_mode: manual`を持つライセンスキーの権利付与下で作成された付与に対してのみ使用してください。付与は、キーが付いていない状態の`pending`ステータスでなければなりません。完全なフローについては、[手動履行](/features/license-keys#manual-fulfillment)および[手動ライセンスキー履行統合ガイド](/developer-resources/manual-license-key-fulfillment)を参照してください。
</Info>
