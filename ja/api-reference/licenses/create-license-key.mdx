<Info>
このエンドポイントは、すでにお持ちのキーをインポートします — `key`、`customer_id`、`product_id` はすべて必須です。キーの値は生成されません。すでに存在する `key` をインポートすると、`409 Conflict` が返されます。
</Info>

<Info>
API を通じて作成または更新されたライセンスキーでは、顧客へのメール通知は送信されません。ライセンスキーについて顧客に通知する必要がある場合は、アプリケーションで別途処理する必要があります。
</Info>
