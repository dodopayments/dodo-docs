<Warning>
**非推奨のAPI**: ライセンスキーは現在、[Entitlements](/features/entitlements/introduction) システムを通じて管理されています。[License Key entitlement](/api-reference/entitlements/update-entitlement) でアクティベーションの制限や期間を設定し、顧客のキーを無効にするには [Revoke Grant](/api-reference/entitlements/revoke-grant) を使用してください。このエンドポイントは将来のリリースで削除されます。
</Warning>

<Info>
APIを通じてライセンスキーを更新しても、顧客へのメール通知はトリガーされません。
</Info>
