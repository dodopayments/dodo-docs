顧客のアカウントから保存された支払い方法を削除します。これを使用して、古いまたは不要な支払い方法を整理します。

<Warning>
アクティブなサブスクリプションで使用中の支払い方法は削除できません。APIは`409 Conflict`を`Payment method is in use by an active subscription`とともに返します。まず、[支払い方法を更新](/api-reference/subscriptions/update-payment-method)を使用してサブスクリプションを別の支払い方法に移行してから、古い支払い方法を削除してください。
</Warning>

削除が成功すると、`204 No Content`が返されます。

## ユースケース

- **顧客からのリクエスト**: 顧客が保存を希望しなくなった支払い方法を削除
- **有効期限切れのカード**: カード情報の有効期限が切れた支払い方法を整理
- **セキュリティ**: 不正使用の疑いがある支払い方法を直ちに削除
