顧客のアカウントから保存された支払い方法を削除します。これを使用して、古いまたは不要な支払い方法を整理します。

<Warning>
削除された支払い方法がアクティブなサブスクリプションに対して唯一のものである場合、次の請求サイクルでサブスクリプションの更新に失敗する可能性があります。削除する前に、顧客が代替の支払い方法を持っていることを確認してください。
</Warning>

## ユースケース

- **顧客からのリクエスト**: 顧客がファイルに残したくない支払い方法を削除
- **期限切れのカード**: 期限切れのカード詳細を持つ支払い方法をクリーンアップ
- **セキュリティ**: 危険にさらされた支払い方法を即座に削除
