## 概要

Dodo Payments APIは、APIリクエストの成功または失敗を示すために、標準のHTTPステータスコードとカスタムエラーコードを使用します。エラーが発生した場合、APIは適切なHTTPステータスコードとエラーに関する詳細情報を含むJSONレスポンスを返します。

各エラーレスポンスには以下が含まれます：
- エラーの一般的なカテゴリを示すHTTPステータスコード
- エラーの正確な性質を特定する特定のエラーコード
- 何が問題だったのかを説明する人間が読めるエラーメッセージ
- 適用可能な場合、エラーに関する追加の詳細

これらのエラーコードとその意味を理解することは、以下のために重要です：
- 統合の問題をデバッグする
- アプリケーションで適切なエラーハンドリングを実装する
- エンドユーザーに意味のあるフィードバックを提供する
- 堅牢な決済処理システムを維持する

以下のセクションでは、Dodo Payments APIを使用する際に遭遇する可能性のある標準のHTTPステータスコードと特定のエラーコードに関する詳細情報を提供します。

## 標準APIエラーコード

| エラーコード | HTTPステータス | 説明 |
|------------|-------------|-------------|
| **400** | 不正なリクエスト | リクエストが不正または無効なパラメータを含んでいました |
| **401** | 認証失敗 | 認証に失敗したか、APIキーが無効です |
| **403** | 禁止 | APIキーにリクエストされたリソースへのアクセス権がありません |
| **404** | 未検出 | リクエストされたリソースは存在しません |
| **405** | メソッド不許可 | このエンドポイントではHTTPメソッドがサポートされていません |
| **409** | 競合 | リクエストがリソースの現在の状態と競合しています |
| **422** | 処理できないエンティティ | リクエストは正しく形成されましたが、意味的なエラーが含まれています |
| **429** | リクエストが多すぎます | レート制限を超えました |
| **500** | サーバー内部エラー | サーバーで予期しないエラーが発生しました |
| **502** | 不正なゲートウェイ | サーバーが上流サーバーから無効なレスポンスを受け取りました |
| **503** | サービス利用不可 | サービスは一時的に利用できません |
| **504** | ゲートウェイタイムアウト | サーバーが上流のレスポンスを待っている間にタイムアウトしました |

## エラーレスポンスフォーマット

エラーが発生した場合、APIは以下の構造を持つJSONレスポンスを返します：

```json
{
  "code": "UNSUPPORTED_COUNTRY",
  "message": "Country AI currently not supported"
}
```

## エラーコードリファレンス

- `ACTIVATION_LIMIT_LESS_THAN_CURRENT_AMOUNT`
  - **Trigger:** ライセンスキーのアクティベーション: 新しい制限 < 現在のインスタンス数
  - **Message:** 新しいアクティベーション制限は現在のインスタンス数未満にすることはできません。

- `ADDONS_IN_USAGE_BASED_BILLING_NOT_SUPPORTED`
  - **Trigger:** 使用ベースの請求サブスクリプションにアドオンを追加しようとしました
  - **Message:** サブスクリプションにアドオンは使用ベースの請求ではサポートされていません。

- `ADDONS_NOT_ALLOWED_FOR_ON_DEMAND`
  - **Trigger:** オンデマンドサブスクリプションにアドオンを追加しようとしました
  - **Message:** オンデマンドサブスクリプションにはアドオンは許可されていません。

- `BRAND_MISMATCH`
  - **Trigger:** カートアイテムが異なるブランドに属しています
  - **Message:** 製品カート内のすべてのアイテムは同じブランドに属している必要があります。

- `BRAND_NOT_ENABLED`
  - **Trigger:** ブランドが無効または非アクティブです
  - **Message:** 提供されたブランドは有効ではありません。

- `BRAND_SUBMISSION_NOT_ENABLED`
  - **Trigger:** ブランド検証再提出機能が有効ではありません
  - **Message:** ブランド検証の再提出は有効ではありません。

- `CHARGE_NOT_ALLOWED_FOR_SCHEDULED_CANCELLATION`
  - **Trigger:** キャンセル予定のサブスクリプションの料金請求を試みました
  - **Message:** サブスクリプションはキャンセル予定です。

- `CHECKOUT_SESSION_CONSUMED`
  - **Trigger:** チェックアウトセッションが既に支払いを生成しています
  - **Message:** チェックアウトセッションはすでに使用されています。

- `DISCOUNT_CODE_ALREADY_EXISTS`
  - **Trigger:** 重複割引コードの作成
  - **Message:** 割引コードは既に存在します。

- `DISCOUNT_CODE_EXPIRED`
  - **Trigger:** 割引コードが期日 `expires_at` を過ぎました
  - **Message:** 割引コードは期限切れです。

- `DISCOUNT_CODE_USAGE_LIMIT_EXCEEDED`
  - **Trigger:** 使用制限が `usage_limit` に達した後の割引の再利用
  - **Message:** 使用制限は times_used より少なくすることはできません / 割引コードの使用制限に達しました。

- `DISCOUNT_NOT_AVAILABLE_FOR_ON_DEMAND`
  - **Trigger:** コードがオンデマンドサブスクリプションに適用されました
  - **Message:** 割引クーポンはオンデマンドサブスクリプションには利用できません。

- `DISCOUNT_NOT_AVAILABLE_FOR_PRODUCT`
  - **Trigger:** コードが関連しない製品に適用されました
  - **Message:** 割引クーポンはこの製品には利用できません。

- `DUPLICATE_LINE_ITEMS_IN_REQUEST`
  - **Trigger:** 同じ `item_id` が `items[]` に二度現れました
  - **Message:** アイテム配列に重複する item_ids が指定されています。

- `DUPLICATE_METER_IDS_IN_REQUEST`
  - **Trigger:** 同じメーターIDがリクエスト内に複数回現れました
  - **Message:** 重複するメーターIDは許可されていません。

- `EXCHANGE_RATE_NOT_FOUND`
  - **Trigger:** `from → to` 通貨ペアのFXレートなし
  - **Message:** 通貨から通貨への変換に対する為替レートが見つかりません。

- `EXISTING_REFUND_REQUEST_PROCESSING`
  - **Trigger:** 前の返金リクエストがまだ処理中です
  - **Message:** 状態が「保留」の返金リクエストがまだ処理中です。

- `INACTIVE_LICENSE_KEY`
  - **Trigger:** キーステータス ≠ `ACTIVE`
  - **Message:** ライセンスキーはアクティブではありません。

- `INACTIVE_SUBSCRIPTION_PLAN_CHANGE_NOT_SUPPORTED`
  - **Trigger:** 非アクティブサブスクリプションのプラン変更
  - **Message:** 非アクティブサブスクリプションでのプラン変更はサポートされていません。

- `INSUFFICIENT_WALLET_FUNDS`
  - **Trigger:** ウォレット残高 < デビット金額
  - **Message:** ウォレットに十分な資金がありません。

- `INTEGER_CONVERSION_FAILURE`
  - **Trigger:** 整数 ↔ 文字列/小数点変換に失敗したサーバーサイド
  - **Message:** 整数変換エラー

- `INTERNAL_SERVER_ERROR`
  - **Trigger:** キャッチされていない例外; サーバーサイドで詳細をログする必要があります
  - **Message:** *公開メッセージなし (一般的な500)*

- `INVALID_DISCOUNT_CODE`
  - **Trigger:** コードが存在しない / 適用できない
  - **Message:** 無効な割引コード / 割引コードはカート内のいかなる製品にも適用できません。

- `INVALID_PERCENTAGE`
  - **Trigger:** パーセント額 > 100% (または10,000ベーシスポイント)
  - **Message:** 割引コードの金額は100%を超えることはできません。

- `INVALID_QUANTITY`
  - **Trigger:** 使用ベースの価格指定で無効な数量が指定されました
  - **Message:** 使用ベースの価格製品では数量は1のみ許可されています。

- `INVALID_QUERY_PARAMS`
  - **Trigger:** 相互排他的 / 不正なクエリパラメータ
  - **Message:** クエリパラメータは time_frame または (start, end) のいずれかのみを含むべきです。

- `INVALID_REQUEST_BODY`
  - **Trigger:** 不正なJSONまたはスキーマ違反
  - **Message:** リクエストボディが無効です。リクエストヘッダーとオブジェクトを確認してください。

- `INVALID_REQUEST_PARAMETERS`
  - **Trigger:** 意味論が間違っている (例: 過去の日付)
  - **Message:** 次の請求日を過去の時間に変更することはできません。

- `INVALID_SUGGESTED_PRICE`
  - **Trigger:** PWYW価格 < 最低許可価格
  - **Message:** 提案された価格は最低価格より低くすることはできません。Pay What You Want の場合、価格は最低受け入れ金額として考慮されます。

- `INVALID_TAX_ID`
  - **Trigger:** VAT/GST/TINの検証に失敗しました
  - **Message:** 税IDが無効です。

- `LICENSE_KEY_LIMIT_REACHED`
  - **Trigger:** アクティベーション = 制限
  - **Message:** ライセンスキーのアクティベーション制限に達しました。

- `LICENSE_KEY_NOT_FOUND`
  - **Trigger:** インスタンスIDまたはキーIDが無効です
  - **Message:** ライセンスキーのインスタンスが見つからないか、このライセンスキーに属していません。

- `LINE_ITEM_FULLY_REFUNDED`
  - **Trigger:** すでに完全に返金された行アイテムを返金しようとしました
  - **Message:** 行アイテム {id} はすでに完全に返金されているため、これ以上返金できません。

- `LINE_ITEM_NOT_FOUND`
  - **Trigger:** アイテムIDが参照された支払いの一部ではありません
  - **Message:** 行アイテム {id} が支払いに見つかりません。

- `LINE_ITEM_PRORATED`
  - **Trigger:** プロレートされた行の返金または更新を試みました
  - **Message:** 行アイテム {id} はプロレートされているため、返金できません。

- `LINE_ITEM_REFUND_AMOUNT_TOO_HIGH`
  - **Trigger:** 返金金額 > 支払金額 (税金含む)
  - **Message:** 行アイテム {id} で要求された返金金額 (税金を含む) は {amount} で、支払金額 {amount} を超えています。

- `LINE_ITEM_REFUND_AMOUNT_TOO_LOW`
  - **Trigger:** 返金金額が最低しきい値を下回っています
  - **Message:** 行アイテム {id} で要求された返金金額は {amount} で、これは低すぎます。

- `MAXIMUM_KEYS_REACHED`
  - **Trigger:** メタデータ / カスタムフィールドが50ペアを超えました
  - **Message:** 50のキー-バリューペアを超えています。

- `MERCHANT_NOT_LIVE`
  - **Trigger:** 事業はまだテスト/サンドボックスモードです
  - **Message:** マーチャントはライブではありません。

- `METER_IS_DELETED`
  - **Trigger:** 削除されたメーターを使用しようとしました
  - **Message:** メーターはすでに削除されています。

- `MISSING_ADDON_IDS`
  - **Trigger:** `addon_id` リストが空または不明なID
  - **Message:** 1つ以上の製品IDが存在しません: {id}

- `MISSING_METER_IDS`
  - **Trigger:** メーターIDリストが空または無効なIDを含んでいます
  - **Message:** 1つ以上のメーターIDが存在しません: {id}

- `MISSING_PRODUCT_INFORMATION`
  - **Trigger:** 製品は存在しますが、必須情報が欠けています
  - **Message:** 製品 {id} は存在しますが、他の必須情報が欠けているか無効です。

- `NEGATIVE_BALANCE_ADJUSTMENT`
  - **Trigger:** ウォレット残高を負にしようとしました
  - **Message:** ウォレット残高を負にすることはできません。

- `NO_ELIGIBLE_PAYMENT_METHODS`
  - **Trigger:** フィルタリング後、残りがありません
  - **Message:** 適格な支払い方法が見つかりませんでした。

- `NO_EXPIRY_ON_SUBSCRIPTION_LICENSE_KEYS`
  - **Trigger:** サブベースキーの有効期限を設定しようとしました
  - **Message:** サブスクリプションベースのライセンスキーに対して有効期限を設定することはできません。

- `NOT_FOUND`
  - **Trigger:** すべての欠落しているリソースに対する汎用404
  - **Message:** アイテムが見つかりません *（またはより具体的）*

- `ON_DEMAND_PLAN_CHANGE_NOT_SUPPORTED`
  - **Trigger:** オンデマンドでのプラン変更は許可されていません
  - **Message:** オンデマンドサブスクリプションでのプラン変更はサポートされていません。

- `ON_DEMAND_SUBSCRIPTIONS_NOT_ENABLED`
  - **Trigger:** 事業が機能フラグオフです
  - **Message:** この事業ではオンデマンドサブスクリプションが有効ではありません。

- `ON_DEMAND_USAGE_BASED_BILLING_NOT_SUPPORTED`
  - **Trigger:** 使用ベースの請求でのオンデマンドを使用しようとしました
  - **Message:** オンデマンドサブスクリプションは使用ベースの請求ではサポートされていません。

- `PAY_AS_YOU_WANT_AMOUNT_REQUIRED`
  - **Trigger:** PWYW製品の価格が欠落しています
  - **Message:** 「Pay What You Want」製品に対しては金額が必須です。

- `PAYMENT_ALREADY_REFUNDED`
  - **Trigger:** 重複返金
  - **Message:** この支払いはすでに返金されています。

- `PAYMENT_HAS_BEEN_REFUNDED`
  - **Trigger:** 支払いが完全に返金されています
  - **Message:** 支払いIDは完全に返金されています。

- `PAYMENT_NOT_SUCCEEDED`
  - **Trigger:** 支払いに失敗した支払いの返金/処理を試みました
  - **Message:** 提供された支払いは成功していません。

- `PLAN_CHANGE_NOT_ALLOWED_FOR_SCHEDULED_CANCELLATION`
  - **Trigger:** キャンセル予定のサブスクリプションでのプラン変更を試みました
  - **Message:** サブスクリプションはキャンセル予定です。

- `PREVIOUS_PAYMENT_PENDING`
  - **Trigger:** 前の支払いが非端末状態の間に料金を作成しようとしました
  - **Message:** 前の支払いがまだ成功していないため、新しい料金を作成できません。

- `PRODUCT_CART_EMPTY`
  - **Trigger:** 空の製品カートが送信されました
  - **Message:** product_cart は空です。

- `PRODUCT_IS_DELETED`
  - **Trigger:** 製品がソフト削除されています
  - **Message:** *メッセージなし*

- `REFUND_AMOUNT_EXCEEDS_PAID_AMOUNT`
  - **Trigger:** 集合的な返金金額 > 支払金額
  - **Message:** 計算された返金金額が支払金額より大きくなっています。

- `REFUND_WINDOW_EXPIRED`
  - **Trigger:** 許可されている返金ウィンドウの外
  - **Message:** 支払い作成後 {days} 日以内に返金を開始する必要があります。support@dodopayments.com に連絡してください。

- `REQUEST_AMOUNT_BELOW_MINIMUM`
  - **Trigger:** 金額 < 製品の最小
  - **Message:** 金額は製品の指定された最小金額より低くすることはできません。

- `SUBSCRIPTION_EXPIRED`
  - **Trigger:** 請求が `ends_at` を過ぎました
  - **Message:** サブスクリプションが期限切れのため、新しい料金を作成できません。

- `SUBSCRIPTION_INACTIVE`
  - **Trigger:** 状態 ≠ `ACTIVE`
  - **Message:** サブスクリプションはアクティブではありません。

- `SUBSCRIPTION_NOT_ON_DEMAND`
  - **Trigger:** 期待されたオンデマンドですが、固定インターバルでした
  - **Message:** サブスクリプションはすでにオンデマンドではありません。

- `SUBSCRIPTION_PAYMENT_RETRY_LIMIT_EXCEEDED`
  - **Trigger:** サブスクリプションの支払いリトライが最大試行回数を超えました
  - **Message:** このサブスクリプションに対する最大のリトライ制限（10回）を超えました。

- `TOO_MANY_REQUESTS`
  - **Trigger:** 429 レート制限
  - **Message:** *メッセージなし*

- `TOTAL_PAYMENT_AMOUNT_BELOW_MINIMUM_AMOUNT`
  - **Trigger:** 合計カート金額 < ゲートウェイの最小
  - **Message:** 支払いを処理するために {display_str} の最小金額が必要です。

- `UNABLE_TO_EDIT_PRIMARY_BRAND`
  - **Trigger:** 通常のAPI経由でプライマリブランドを更新しようとしました
  - **Message:** このAPIエンドポイント経由でプライマリブランドを更新することはできません。

- `UNAUTHORIZED`
  - **Trigger:** APIキーがないか無効なトークン/スコープ
  - **Message:** このアクションを実行する権限がありません。

- `UNSUPPORTED_ACTION`
  - **Trigger:** リソースタイプに対してサポートされていないアクション
  - **Message:** 使用ベースのサブスクリプションに対してプランの変更はサポートされていません。

- `UNSUPPORTED_BILLING_CURRENCY`
  - **Trigger:** サブスクリプションはUSDに制限されています
  - **Message:** サブスクリプションには非USDの請求通貨はサポートされていません。

- `UNSUPPORTED_COUNTRY`
  - **Trigger:** 地理的にまだサポートされていません
  - **Message:** 国 {country_name} は現在サポートされていません。

- `UNSUPPORTED_CURRENCY`
  - **Trigger:** 製品またはアドオン通貨が無効です
  - **Message:** 通貨は現在サポートされていません / 現在サポートされているのはUSDとINRのみ / アドオン価格にはUSDとINRのみサポートされています / 請求通貨についてはUSDまたはINRのみリクエストできます / 通貨はサポートされていません / インドのカードサブスクリプションに対する予期しない通貨。

- `UNSUPPORTED_DISCOUNT_TYPE`
  - **Trigger:** 定額割引などはまだライブではありません
  - **Message:** 現在サポートされているのはパーセント割引コードのみです。

- `UNSUPPORTED_PAYMENT_CURRENCY`
  - **Trigger:** コネクタの支払い通貨がブロックされています
  - **Message:** この取引に対してINRトランザクションはサポートされていません。

- `UNSUPPORTED_TAX_CATEGORY`
  - **Trigger:** 税カテゴリ文字列が列挙型にありません
  - **Message:** カテゴリ {category} は現在サポートされていません。

- `UNSUCCESSFUL_PAYMENT_ID`
  - **Trigger:** 支払いIDが失敗した支払いを参照しています
  - **Message:** 支払いIDは失敗した状態です。

- `ZERO_AMOUNT_PAYMENT_REFUND_NOT_ALLOWED`
  - **Trigger:** ゼロ金額の支払いを返金しようとしました
  - **Message:** 金額がゼロの支払いを返金することはできません。

## ベストプラクティス

1. アプリケーション内でエラーを常に優雅に処理する
2. 適切なエラーロギングを実装する
3. エンドユーザーに適切なエラーメッセージを使用する
4. 一時的なエラーに対してリトライロジックを実装する
5. 未解決の問題についてはサポートに連絡する

## サポート

エラーコードや統合の問題についての追加のヘルプが必要な場合は、support@dodopayments.comまでサポートチームにご連絡ください。
