## 概要

Dodo Payments API では、HTTP ステータスコードと独自のエラーコードでリクエストの成功・失敗を示します。エラーが発生すると、適切な HTTP ステータスと詳細な JSON レスポンスが返されます。

各エラーレスポンスには以下が含まれます。
- エラーの種類を示す HTTP ステータスコード
- エラー内容を特定する固有のエラーコード
- 何が起きたかを説明するメッセージ
- 必要に応じた追加の詳細

これらのコードを理解すると、以下に役立ちます。
- 連携トラブルのデバッグ
- アプリでの適切なエラーハンドリング
- エンドユーザーへの分かりやすい通知
- 安定した決済システム運用

以下では、HTTP ステータスコードと API 固有のエラーコードをまとめています。

## 標準的な API エラーコード

| Error code | HTTP Status | Description |
|------------|-------------|-------------|
| **400** | Bad Request | リクエスト形式が不正またはパラメータが無効 |
| **401** | Unauthorized | 認証に失敗、または API キーが無効 |
| **403** | Forbidden | API キーにリソースへの権限がない |
| **404** | Not Found | リソースが存在しない |
| **405** | Method Not Allowed | エンドポイントがこの HTTP メソッドを非対応 |
| **409** | Conflict | リソースの現在状態と競合 |
| **422** | Unprocessable Entity | リクエストは正しいが内容に意味的エラー |
| **429** | Too Many Requests | レートリミット超過 |
| **500** | Internal Server Error | サーバー側で予期せぬエラー |
| **502** | Bad Gateway | 上流サーバーから無効な応答 |
| **503** | Service Unavailable | 一時的にサービス利用不可 |
| **504** | Gateway Timeout | 上流応答の待ち時間切れ |

## エラーレスポンス形式

エラー時は次の形式で JSON が返されます。

```json
{
  "code": "UNSUPPORTED_COUNTRY",
  "message": "Country AI currently not supported"
}
```


## エラーコード一覧

- `ACTIVATION_LIMIT_LESS_THAN_CURRENT_AMOUNT`
  - **発生条件:** ライセンスキーの新しい上限が既存のインスタンス数を下回る
  - **メッセージ:** New activation limit cannot be less than current instances count

- `ADDONS_IN_USAGE_BASED_BILLING_NOT_SUPPORTED`
  - **発生条件:** 従量課金サブスクリプションにアドオンを追加
  - **メッセージ:** Addons in Subscriptions are not supported for Usage Based Billing

- `ADDONS_NOT_ALLOWED_FOR_ON_DEMAND`
  - **発生条件:** オンデマンドサブスクリプションにアドオンを追加
  - **メッセージ:** Addons are not allowed for on demand subscriptions

- `BRAND_MISMATCH`
  - **発生条件:** カート内の商品が複数ブランドにまたがる
  - **メッセージ:** All items in the product cart should belong to the same brand

- `BRAND_NOT_ENABLED`
  - **発生条件:** ブランドが無効または非アクティブ
  - **メッセージ:** Brand provided is not enabled

- `BRAND_SUBMISSION_NOT_ENABLED`
  - **発生条件:** ブランド再申請機能が無効
  - **メッセージ:** Brand verificatin resubmission is not enabled

- `CHARGE_NOT_ALLOWED_FOR_SCHEDULED_CANCELLATION`
  - **発生条件:** 解約予定のサブスクリプションに課金
  - **メッセージ:** Subscription scheduled for cancellation

- `CHECKOUT_SESSION_CONSUMED`
  - **発生条件:** チェックアウトセッションが既に支払いに使用済み
  - **メッセージ:** Checkout session has already been consumed

- `DISCOUNT_CODE_ALREADY_EXISTS`
  - **発生条件:** 割引コードの重複作成
  - **メッセージ:** Discount Code already exists

- `DISCOUNT_CODE_EXPIRED`
  - **発生条件:** 割引コードの有効期限切れ
  - **メッセージ:** Discount code expired

- `DISCOUNT_CODE_USAGE_LIMIT_EXCEEDED`
  - **発生条件:** 使用上限を超えて割引コードを利用
  - **メッセージ:** Usage limit cannot be less than times_used / Discount code hit usage limit

- `DISCOUNT_NOT_AVAILABLE_FOR_ON_DEMAND`
  - **発生条件:** オンデマンドサブスクリプションに割引コードを適用
  - **メッセージ:** Discount coupon not available for on demand subscriptions

- `DISCOUNT_NOT_AVAILABLE_FOR_PRODUCT`
  - **発生条件:** 対象外の商品に割引コードを適用
  - **メッセージ:** Discount coupon not available for this product

- `DUPLICATE_LINE_ITEMS_IN_REQUEST`
  - **発生条件:** `items[]` に同じ `item_id` が重複
  - **メッセージ:** Duplicate item_ids specified in items array

- `DUPLICATE_METER_IDS_IN_REQUEST`
  - **発生条件:** リクエストに同じメーター ID が複数回指定
  - **メッセージ:** Duplicate Meter Ids are not allowed

- `EXCHANGE_RATE_NOT_FOUND`
  - **発生条件:** 通貨ペアの為替レートが存在しない
  - **メッセージ:** Exchange rate not found to convert from Currency to Currency

- `EXISTING_REFUND_REQUEST_PROCESSING`
  - **発生条件:** 既存の返金リクエストが処理中
  - **メッセージ:** A refund request with status "Pending" is still being processed

- `INACTIVE_LICENSE_KEY`
  - **発生条件:** キーのステータスが `ACTIVE` ではない
  - **メッセージ:** License key is not active

- `INACTIVE_SUBSCRIPTION_PLAN_CHANGE_NOT_SUPPORTED`
  - **発生条件:** 非アクティブなサブスクリプションでプラン変更
  - **メッセージ:** Changing plans is not supported for inactive subscriptions

- `INSUFFICIENT_WALLET_FUNDS`
  - **発生条件:** ウォレット残高が引き落とし額を下回る
  - **メッセージ:** Insufficient funds in wallet

- `INTEGER_CONVERSION_FAILURE`
  - **発生条件:** サーバー側での整数変換に失敗
  - **メッセージ:** Integer Conversion Failure

- `INTERNAL_SERVER_ERROR`
  - **発生条件:** 未処理の例外などサーバー内部エラー
  - **メッセージ:** *No public message (generic 500)*

- `INVALID_DISCOUNT_CODE`
  - **発生条件:** コード不存在・適用外
  - **メッセージ:** Invalid Discount Code / Discount Code cannot be applied to any product in the cart

- `INVALID_PERCENTAGE`
  - **発生条件:** 割合が 100%（10000bp）超過
  - **メッセージ:** Percentage amount cannot be more than 10000 / Discount code amount cannot be more than 100%

- `INVALID_QUANTITY`
  - **発生条件:** 従量課金で不正な数量
  - **メッセージ:** Only 1 quantity allowed in usage based price products

- `INVALID_QUERY_PARAMS`
  - **発生条件:** クエリパラメータの不整合や誤り
  - **メッセージ:** Query params should only contain either time_frame or (start, end)

- `INVALID_REQUEST_BODY`
  - **発生条件:** JSON 破損・スキーマ不一致
  - **メッセージ:** Your request body is invalid. Please check your request headers and object.

- `INVALID_REQUEST_PARAMETERS`
  - **発生条件:** セマンティックエラー（過去日付など）
  - **メッセージ:** Cannot change next_billing_date to past time

- `INVALID_SUGGESTED_PRICE`
  - **発生条件:** 希望価格が最小許容額を下回る
  - **メッセージ:** Suggested Price cannot be lower than minimum price. In case of pay what you want, price is considered as minimum accepted amount

- `INVALID_TAX_ID`
  - **発生条件:** VAT/GST/TIN 検証に失敗
  - **メッセージ:** Tax Id is invalid

- `LICENSE_KEY_LIMIT_REACHED`
  - **発生条件:** ライセンスキーのアクティベーションが上限到達
  - **メッセージ:** License key activation limit reached

- `LICENSE_KEY_NOT_FOUND`
  - **発生条件:** インスタンス ID / キー ID が不正
  - **メッセージ:** License key instance not found or does not belong to this license key

- `LINE_ITEM_FULLY_REFUNDED`
  - **発生条件:** 既に全額返金済みの明細を再度返金
  - **メッセージ:** Line item {id} has been fully refunded cannot be refunded further.

- `LINE_ITEM_NOT_FOUND`
  - **発生条件:** 対象支払いに明細 ID が存在しない
  - **メッセージ:** Line item {id} not found in payment

- `LINE_ITEM_PRORATED`
  - **発生条件:** 日割り計算された明細を返金/更新
  - **メッセージ:** Line item {id} cannot be refunded because its prorated

- `LINE_ITEM_REFUND_AMOUNT_TOO_HIGH`
  - **発生条件:** 返金額が支払額（税含む）を超過
  - **メッセージ:** Line item {id} requested refund amount including tax is {amount} which is above the paid amount {amount}

- `LINE_ITEM_REFUND_AMOUNT_TOO_LOW`
  - **発生条件:** 返金額が下限を下回る
  - **メッセージ:** Line item {id} requested refund amount is {amount} which is too low

- `MAXIMUM_KEYS_REACHED`
  - **発生条件:** メタデータ/カスタムフィールドが 50 ペア超え
  - **メッセージ:** Exceeds 50 key-value pairs

- `MERCHANT_NOT_LIVE`
  - **発生条件:** ビジネスがテスト/サンドボックス状態
  - **メッセージ:** Merchant is not live

- `METER_IS_DELETED`
  - **発生条件:** 削除済みメーターを使用
  - **メッセージ:** The Meter is already been deleted

- `MISSING_ADDON_IDS`
  - **発生条件:** `addon_id` が空または無効 ID を含む
  - **メッセージ:** One or more product IDs do not exist: {id}

- `MISSING_METER_IDS`
  - **発生条件:** メーター ID が空、または無効 ID を含む
  - **メッセージ:** One or more meter IDs do not exist: {id}

- `MISSING_PRODUCT_INFORMATION`
  - **発生条件:** 商品が存在するが必須情報が欠落
  - **メッセージ:** Product {id} exists but other mandatory information is missing or invalid

- `NEGATIVE_BALANCE_ADJUSTMENT`
  - **発生条件:** ウォレット残高をマイナスにしようとした
  - **メッセージ:** Wallet balance is not allowed to be made negative

- `NO_ELIGIBLE_PAYMENT_METHODS`
  - **発生条件:** フィルタ後に利用可能な支払い方法がない
  - **メッセージ:** No eligible payment methods found

- `NO_EXPIRY_ON_SUBSCRIPTION_LICENSE_KEYS`
  - **発生条件:** サブスクリプション型ライセンスキーに有効期限を設定
  - **メッセージ:** Cannot set expiry date for subscription-based license key

- `NOT_FOUND`
  - **発生条件:** リソースが見つからない一般的な 404
  - **メッセージ:** Item not found *(or more specific)*

- `ON_DEMAND_PLAN_CHANGE_NOT_SUPPORTED`
  - **発生条件:** オンデマンド契約でのプラン変更
  - **メッセージ:** Changing plans is not supported for on demand subscriptions

- `ON_DEMAND_SUBSCRIPTIONS_NOT_ENABLED`
  - **発生条件:** オンデマンドサブスクリプション機能が無効
  - **メッセージ:** On demand subscriptions not enabled for this business

- `ON_DEMAND_USAGE_BASED_BILLING_NOT_SUPPORTED`
  - **発生条件:** オンデマンドと従量課金の併用
  - **メッセージ:** On Demand Subscriptions are not supported for Usage Based Billing

- `PAY_AS_YOU_WANT_AMOUNT_REQUIRED`
  - **発生条件:** PWYW 商品で金額未指定
  - **メッセージ:** Amount is mandatory for pay as you want product

- `PAYMENT_ALREADY_REFUNDED`
  - **発生条件:** 支払いが既に返金済み
  - **メッセージ:** This payment has already been refunded

- `PAYMENT_HAS_BEEN_REFUNDED`
  - **発生条件:** 支払いが全額返金済み
  - **メッセージ:** The Payment ID has been fully refunded.

- `PAYMENT_NOT_SUCCEEDED`
  - **発生条件:** 成功していない支払いを処理/返金
  - **メッセージ:** The provided payment has not succeeded

- `PLAN_CHANGE_NOT_ALLOWED_FOR_SCHEDULED_CANCELLATION`
  - **発生条件:** 解約予定のサブスクリプションでプラン変更
  - **メッセージ:** Subscription scheduled for cancellation

- `PREVIOUS_PAYMENT_PENDING`
  - **発生条件:** 以前の支払いが完了前に新規課金を作成
  - **メッセージ:** Cannot create new charge as previous payment is not successful yet

- `PRODUCT_CART_EMPTY`
  - **発生条件:** product_cart が空のまま送信
  - **メッセージ:** product_cart is empty

- `PRODUCT_IS_DELETED`
  - **発生条件:** ソフト削除された商品を参照
  - **メッセージ:** *No messages*

- `REFUND_AMOUNT_EXCEEDS_PAID_AMOUNT`
  - **発生条件:** 返金総額が支払額を超過
  - **メッセージ:** The calculated refund amount is larger than the paid amount

- `REFUND_WINDOW_EXPIRED`
  - **発生条件:** 返金可能期間を過ぎている
  - **メッセージ:** Refunds cannot be initiated {days} days after payment creation. Contact support@dodopayments.com.

- `REQUEST_AMOUNT_BELOW_MINIMUM`
  - **発生条件:** 金額が商品の最小額未満
  - **メッセージ:** Amount cannot be less than minimum amount specified for the product

- `SUBSCRIPTION_EXPIRED`
  - **発生条件:** `ends_at` を過ぎたサブスクリプション
  - **メッセージ:** Subscription expired cannot create new charges

- `SUBSCRIPTION_INACTIVE`
  - **発生条件:** ステータスが `ACTIVE` ではない
  - **メッセージ:** Subscription is not active

- `SUBSCRIPTION_NOT_ON_DEMAND`
  - **発生条件:** オンデマンドを期待したが固定課金だった
  - **メッセージ:** Subscription is already not on demand

- `SUBSCRIPTION_PAYMENT_RETRY_LIMIT_EXCEEDED`
  - **発生条件:** サブスク支払いの再試行が上限超過
  - **メッセージ:** Maximum retry limit of 10 attempts exceeded for this subscription

- `TOO_MANY_REQUESTS`
  - **発生条件:** 429 レートリミット
  - **メッセージ:** *No messages*

- `TOTAL_PAYMENT_AMOUNT_BELOW_MINIMUM_AMOUNT`
  - **発生条件:** カート合計が決済最小額を下回る
  - **メッセージ:** Minimum amount of {display_str} is required to process payment

- `UNABLE_TO_EDIT_PRIMARY_BRAND`
  - **発生条件:** 通常 API でプライマリブランドを更新
  - **メッセージ:** Primary brand cannot be updated via this API endpoint.

- `UNAUTHORIZED`
  - **発生条件:** API キーなし、トークン/スコープ無効
  - **メッセージ:** You are not authorised to perform this action

- `UNSUPPORTED_ACTION`
  - **発生条件:** リソース種別で非対応の操作
  - **メッセージ:** Changing plans for usage based subscriptions is not supported

- `UNSUPPORTED_BILLING_CURRENCY`
  - **発生条件:** サブスクの請求通貨が USD 以外
  - **メッセージ:** Non USD billing currency is not supported for subscriptions

- `UNSUPPORTED_COUNTRY`
  - **発生条件:** 未対応の国
  - **メッセージ:** Country {country_name} currently not supported

- `UNSUPPORTED_CURRENCY`
  - **発生条件:** 商品/アドオンの通貨が無効
  - **メッセージ:** Currency is not currently supported / Only USD and INR products supported currently / Only USD and INR supported for addon price / Can only request USD or INR for billing_currency / Currency Not Supported / Unexpected currency for Indian card subscripitons

- `UNSUPPORTED_DISCOUNT_TYPE`
  - **発生条件:** 固定額割引など未サポートのタイプ
  - **メッセージ:** Only percentage discount codes are supported for now

- `UNSUPPORTED_PAYMENT_CURRENCY`
  - **発生条件:** コネクタで支払い通貨がブロック
  - **メッセージ:** INR transaction is not supported for this transaction

- `UNSUPPORTED_TAX_CATEGORY`
  - **発生条件:** 税区分がサポート外
  - **メッセージ:** Category {category} currently not supported

- `UNSUCCESSFUL_PAYMENT_ID`
  - **発生条件:** 成功していない支払い ID を参照
  - **メッセージ:** The Payment ID has an unsuccessful status.

- `ZERO_AMOUNT_PAYMENT_REFUND_NOT_ALLOWED`
  - **発生条件:** 金額 0 の支払いを返金しようとした
  - **メッセージ:** Cannot refund a payment with zero currency amount

## ベストプラクティス

1. アプリでエラーを丁寧に処理する  
2. 適切なエラーログを実装する  
3. エンドユーザーには分かりやすいメッセージを返す  
4. 一時的なエラーにはリトライロジックを入れる  
5. 解決しない場合はサポートへ連絡する  

## サポート

エラーコードや連携トラブルに関する追加サポートは、support@dodopayments.com までお問い合わせください。
