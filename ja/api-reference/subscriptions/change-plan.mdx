## 支払い失敗の処理

プラン変更の支払いが失敗した場合に何が起こるかを制御するには、`on_payment_failure` パラメーターを使用します：

| 値 | 動作 |
|-------|----------|
| `prevent_change` | 支払いが成功するまで現在のプランを保持します。プラン変更は保留のままです。 |
| `apply_change` | 支払いの結果にかかわらず、プラン変更を即時に適用します。これがデフォルトです。 |

<Info>
`on_payment_failure` が指定されていない場合、動作はダッシュボードで設定されたビジネスレベルの設定にデフォルトで従います。
</Info>

<Tip>
重要なアップグレードには、`prevent_change` を使用して、プレミアム機能へのアクセスを許可する前に支払いを確保してください。
</Tip>
