<Info>
このエンドポイントを使用して、サブスクリプションのアップグレードやダウングレード時に顧客に正確な料金を示します。これにより透明性が向上し、サポートへの問い合わせを減らすことができます。
</Info>

## ユースケース

- **チェックアウト確認**: 顧客がプラン変更を確認する前に、日割り計算された料金を表示する
- **価格計算機**: アプリケーション内でアップグレード/ダウングレードの計算機を構築する
- **顧客セルフサービス**: 顧客が正確な価格でプランオプションを探ることができるようにする
- **割引検証**: 割引コードがプラン変更の価格にどのように影響するかをプレビューする

<Info>
変更を確定する前に、割引が即時請求と新しいプランの価格にどのように影響するかを見るために、プレビューリクエストに`discount_code`を含めることができます。
</Info>

## レスポンスフィールド

プレビュー応答には次のものが含まれます：

| フィールド | 説明 |
|-------|-------------|
| `immediate_charge` | 行項目とサマリーを含め、即時に作成される料金 |
| `new_plan` | プラン変更後の状態を示す完全なサブスクリプションオブジェクト |

<Tip>
`immediate_charge.summary`は請求される合計金額を含みます。顧客がプラン変更を確認する前に価格を表示するために使用してください。
</Tip>
