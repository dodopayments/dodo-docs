Dodo Payments ダッシュボードが数回のキー入力で利用可能です。Raycast を使用して、ダッシュボードを開かずに、支払い、サブスクリプション、顧客、製品、割引コード、ライセンスキー、返金を迅速に表示できます。

## インストール

<Card title="Raycast Store からインストール →" icon="puzzle-piece" href="https://www.raycast.com/dodopayments/dodo-payments">
  Raycast Store の Dodo Payments 拡張機能ページを開きます。
</Card>

<Info>
macOS 上の Raycast と Dodo Payments API キーが必要です。
</Info>

## セットアップ

<Steps>
<Step title="API キーを取得する">
1. Dodo Payments ダッシュボードにログインします。
2. 設定 › API キーに移動します。
3. API キーをコピーします。
</Step>

<Step title="拡張機能を設定する">
1. Raycast を開きます。
2. 「Dodo Payments」を検索し、任意のコマンドを選択します。
3. プロンプトが表示されたら、API キーフィールドに API キーを入力します。
4. API モードを選択します：
   - テスト：開発およびテスト用に使用します。
   - 本番：本番データ用に使用します。
5. 設定を保存します。
</Step>
</Steps>

<Tip>
テストモードでセットアップを検証し、その後本番に切り替えます。
</Tip>

<Warning>
API キーはパスワードのように扱ってください。共有したり、プレーンテキストで保存したりしないでください。
</Warning>

## 拡張機能の使用

- **検索**：Raycast を開き、「Dodo Payments」と入力し、コマンドを選択します。
- **フィルタ**：ID、メール、名前、またはステータスの一部を入力して結果を絞り込みます。
- **詳細を開く**：リスト項目で Enter を押して、詳細情報を表示します。

## トラブルシューティング

<AccordionGroup>
<Accordion title="認証に失敗したか、401/403 エラーが発生しました">
API キーとモード（テスト vs 本番）がダッシュボードデータと一致していることを確認してください。必要に応じてコマンドを再オープンし、キーを再入力してください。
</Accordion>
<Accordion title="結果が表示されない">
選択したモードにデータがあることを確認してください。テストと本番の間で切り替えてみてください。
</Accordion>
<Accordion title="レート制限またはタイムアウト">
少し待ってから再試行してください。問題が解決しない場合は、ネットワーク接続を確認してください。
</Accordion>
</AccordionGroup>
