## はじめに

[Evendeals](https://www.evendeals.com/integrations/dodo-payments)は、地域に基づく購買力平価の割引クーポンを作成し、Dodo Paymentsアカウントに同期するプラットフォームです。単発商品とサブスクリプション商品の両方に対応しており、指定したスケジュールに従って自動的にローテーションする割引コードを生成します。

<Frame>
  <img src="/images/integrations/evendeals/hero.png" alt="Evendeals Dodo Payments integration overview" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Note>
Dodo Paymentsにはネイティブの [Purchasing Power Parity](/features/purchasing-power-parity)機能があり、バナー、スクリプト、管理が必要なクーポンコードを使わずに、チェックアウト時の国別価格を引き下げられます。Evendealsは、自動的なクーポンのローテーションを伴う割引コード方式を特に必要とするマーチャント向けです。
</Note>

## 仕組み

EvendealsはAPI keyを介してDodo Paymentsアカウントに接続します。接続後、国グループごとにパーセンテージ割引を設定します。EvendealsはDodo Paymentsアカウントに割引コードを自動的に作成し、不正利用を防ぐため、設定したスケジュール（時間間隔、引き換え回数、または表示回数）に従ってローテーションします。

## EvendealsとネイティブPPPの比較

ネイティブのPurchasing Power Parityは、クーポンコードが不要で、共有や不正利用もできないため、国別価格の設定に推奨される方法です。割引コード方式を特に必要とする場合はEvendealsを選択してください。

| | ネイティブPPP | Evendeals |
| :--- | :--- | :--- |
| 仕組み | 国ごとのパーセンテージをチェックアウト時に適用 | コードを通じて一定割合を割引 |
| 設定場所 | Dodo Paymentsに組み込み | Evendealsダッシュボード |
| バナーまたはスクリプトの必要性 | 不要 | 不要 |
| クーポンのローテーション / 自動更新 | 該当なし | 対応 |
| サブスクリプション対応 | 対応 | 対応 |
| 最適な用途 | サイトを変更せずに適正な価格を設定 | 自動ローテーションを伴う割引コード方式 |

## 主な機能

- **クーポンの自動同期** — クーポンがDodo Paymentsで自動的に作成・管理されます
- **パーセンテージ割引** — 国グループごとに一定割合の割引を提供できます
- **サブスクリプション対応** — サブスクリプションの請求サイクル全体に割引が適用されます
- **自動更新ルール** — 不正利用を防ぐため、時間間隔、引き換え回数、または表示回数に基づいてクーポンコードを自動的にローテーションします

<Info>
Evendealsで作成された割引コードは、Dodo Paymentsダッシュボードの **Sales → Discounts** に自動的に表示されます。
</Info>

## 前提条件

この連携を設定する前に、次のものを用意してください。

1. [Dodo Paymentsアカウント](https://app.dodopayments.com)
2. [Evendealsアカウント](https://www.evendeals.com/signin)
3. Dodo Payments API key

## はじめに

<Steps>
  <Step title="Create a Dodo Payments API Key">
    Dodo Paymentsダッシュボードで **Developers → API Keys** に移動し、**Create New API** をクリックします。後で識別できるように、「Evendeals」など、内容がわかる名前を付けてください。
  </Step>

  <Step title="Connect in Evendeals">
    [Evendealsダッシュボード](https://www.evendeals.com/signin)で **Integrations** に移動し、Dodo Paymentsカードを見つけてAPI keyを貼り付けます。
  </Step>

  <Step title="Configure Regional Discounts">
    国グループごとにパーセンテージ割引を設定し、同期を実行します。EvendealsがDodo Paymentsにクーポンを自動的に作成します。

    <Check>
    同期後、Dodo Paymentsダッシュボードで **Sales → Discounts** を開き、生成されたクーポンが表示されることを確認します。各クーポンには、Evendealsだと識別できるプレフィックスが付いています。
    </Check>
  </Step>
</Steps>
