## はじめに

[Dub](https://dub.co)は、短縮リンクの作成、共有、追跡を支援する強力なリンク管理プラットフォームです。Dodo PaymentsとDubを統合すると、顧客が購入を完了した際に販売コンバージョンイベントを自動的に追跡でき、マーケティングキャンペーンや紹介プログラムのROIを測定できます。

Dubでは、顧客が次のいずれかを行ったときに「販売」イベントが記録されます。
- 一回限りの支払いを完了する
- 有料プランに登録する
- 定期サブスクリプションの支払いを行う

<Info>
この統合には、リンクでコンバージョン追跡が有効になっているDubアカウントが必要です。
</Info>

<Tip>
**アフィリエイトプログラム統合**: この統合は、アフィリエイトの紹介とコミッションの追跡に**Dub Partners**ともシームレスに連携します。Dubのコンバージョン追跡を使用して、販売をアフィリエイトリンクに紐付け、パートナーのパフォーマンスを測定できます。アフィリエイトプログラムの設定については、[Affiliates機能ガイド](/features/affiliates)をご覧ください。
</Tip>

## 仕組み

Dubは、ユーザーがDubの短縮リンクをクリックした際にcookieに保存される一意のクリックID（`dub_id`）を通じて訪問者を追跡します。販売をリンクに紐付けるには、次の操作が必要です。

1. チェックアウトセッションの作成時に、cookieから**DubのクリックIDを取得**する
2. 顧客の外部IDとともに、**クリックIDを支払いメタデータに保存**する
3. Track APIを使用して、支払い成功時に**販売データをDubへ送信**する

これにより、Dubは成功した販売と元のリンククリックを照合でき、完全なコンバージョンアトリビューションを実現できます。

## 前提条件

この統合を設定する前に、次のものを準備してください。

1. ワークスペースを含む[Dubアカウント](https://dub.co)
2. リンクのコンバージョン追跡
3. Dub APIキー（DubダッシュボードのSettings → API Keysから取得可能）

## 実装ガイド

### ステップ1: クリックIDと顧客IDをチェックアウトメタデータに追加する

チェックアウトセッションの作成時にcookieからDubのクリックIDを取得し、顧客の外部IDとともに支払いメタデータに含めます。

<CodeGroup>

```typescript Next.js
import { cookies } from 'next/headers';
import DodoPayments from 'dodopayments';

const client = new DodoPayments();

export async function createCheckout(productId: string, customerId: string) {
  // Capture Dub click ID from cookie
  const dubClickId = cookies().get('dub_id')?.value;

  const payment = await client.payments.create({
    billing: {
      city: 'New York',
      country: 'US',
      state: 'NY',
      street: '123 Main St',
      zipcode: '10001',
    },
    customer: {
      email: 'customer@example.com',
      name: 'John Doe',
    },
    product_cart: [{ product_id: productId, quantity: 1 }],
    metadata: {
      dub_click_id: dubClickId,           // Store Dub click ID
      dub_external_id: customerId,        // Store your customer's unique ID
    },
  });

  return payment;
}
```

## 変換コードの例

### 基本的な販売追跡

支払い成功時に販売を追跡します。

```javascript basic_sale.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;

    // Only send to Dub if click ID exists in metadata
    if (payment.metadata && payment.metadata.dub_click_id) {
      webhook.payload = {
        clickId: payment.metadata.dub_click_id,
        externalId: payment.metadata.dub_external_id || payment.customer.customer_id,
        amount: payment.total_amount, // Ensure the amount is in cents
        currency: payment.currency || "USD",
        paymentProcessor: "dodo",
        invoiceId: payment.payment_id,
        metadata: {
          customer_email: payment.customer.email,
          customer_name: payment.customer.name,
          product_id: payment.product_cart ? payment.product_cart.map(product => product.product_id).join(', ') : undefined,
        },
      };
    } else {
      // Cancel dispatch if no click ID (organic traffic)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

### サブスクリプション販売の追跡

初回サブスクリプションと定期支払いの両方を追跡します。

```javascript subscription_sale.js icon="js" expandable
function handler(webhook) {
  const data = webhook.payload.data;

  // Track initial subscription activation
  if (webhook.eventType === "subscription.active") {
    if (data.metadata && data.metadata.dub_click_id) {
      webhook.payload = {
        clickId: data.metadata.dub_click_id,
        externalId: data.metadata.dub_external_id || data.customer.customer_id,
        amount: data.recurring_pre_tax_amount, // Amount in cents
        currency: data.currency || "USD",
        paymentProcessor: "dodo",
        invoiceId: data.subscription_id,
        eventName: "Subscription Started",
        metadata: {
          subscription_id: data.subscription_id,
          product_id: data.product_id,
          billing_interval: data.payment_frequency_interval,
          customer_email: data.customer.email,
        },
      };
    } else {
      // Cancel dispatch if no click ID (organic traffic)
      webhook.cancel = true;
    }
  }

  // Track recurring subscription payments
  if (webhook.eventType === "subscription.renewed") {
    if (data.metadata && data.metadata.dub_click_id) {
      webhook.payload = {
        clickId: data.metadata.dub_click_id,
        externalId: data.metadata.dub_external_id || data.customer.customer_id,
        amount: data.recurring_pre_tax_amount,
        currency: data.currency || "USD",
        paymentProcessor: "dodo",
        invoiceId: `${data.subscription_id}_${Date.now()}`,
        eventName: "Subscription Renewed",
        metadata: {
          subscription_id: data.subscription_id,
          product_id: data.product_id,
          customer_email: data.customer.email,
        },
      };
    } else {
      // Cancel dispatch if no click ID (organic traffic)
      webhook.cancel = true;
    }
  }

  return webhook;
}
```

### 税額を除外した販売の追跡

正確な収益追跡のため、税引前金額のみをDubに送信します。

```javascript sale_without_tax.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;

    if (payment.metadata && payment.metadata.dub_click_id) {
      // Calculate pre-tax amount (total minus tax)
      const preTaxAmount = payment.total_amount - (payment.tax || 0);

      webhook.payload = {
        clickId: payment.metadata.dub_click_id,
        externalId: payment.metadata.dub_external_id || payment.customer.customer_id,
        amount: preTaxAmount, // Pre-tax amount in cents
        currency: payment.currency || "USD",
        paymentProcessor: "dodo",
        invoiceId: payment.payment_id,
        metadata: {
          total_amount: payment.total_amount,
          tax_amount: payment.tax || 0,
          customer_email: payment.customer.email,
        },
      };
    } else {
      // Cancel dispatch if no click ID (organic traffic)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

### カスタムイベント名を使用した販売の追跡

カスタムイベント名を使用して、さまざまな種類の販売を分類します。

```javascript custom_events.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;

    if (payment.metadata && payment.metadata.dub_click_id) {
      // Determine event name based on payment type
      let eventName = "Purchase";
      if (payment.subscription_id) {
        eventName = "Subscription Purchase";
      } else if (payment.metadata && payment.metadata.is_upgrade) {
        eventName = "Plan Upgrade";
      }

      webhook.payload = {
        clickId: payment.metadata.dub_click_id,
        externalId: payment.metadata.dub_external_id || payment.customer.customer_id,
        amount: payment.total_amount,
        currency: payment.currency || "USD",
        paymentProcessor: "dodo",
        invoiceId: payment.payment_id,
        eventName: eventName,
        metadata: {
          product_id: payment.product_cart ? payment.product_cart.map(product => product.product_id).join(', ') : undefined,
          customer_email: payment.customer.email,
        },
      };
    } else {
      // Cancel dispatch if no click ID (organic traffic)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

## 代替方法: クライアント側での実装

webhookを使用せず、サーバーから販売を追跡したい場合は、支払い成功後にDubのTrack APIを直接呼び出せます。

<CodeGroup>

```typescript Next.js (Server Action)
'use server';

import { Dub } from 'dub';

const dub = new Dub();

export async function trackSale(
  paymentId: string,
  clickId: string,
  customerId: string,
  amount: number,
  currency: string
) {
  await dub.track.sale({
    clickId: clickId,
    externalId: customerId,
    amount: amount,
    currency: currency,
    paymentProcessor: 'dodo',
    invoiceId: paymentId,
  });
}
```

```javascript Node.js
const { Dub } = require('dub');

const dub = new Dub();

async function trackSale(payment) {
  if (payment.metadata?.dub_click_id) {
    await dub.track.sale({
      clickId: payment.metadata.dub_click_id,
      externalId: payment.metadata.dub_external_id,
      amount: payment.total_amount,
      currency: payment.currency,
      paymentProcessor: 'dodo',
      invoiceId: payment.payment_id,
    });
  }
}
```

## ベストプラクティス

<Tip>
**クリックIDを早期に取得する**: 正確なアトリビューションを確保するため、ユーザーが離脱して後から戻ってきた場合でも、チェックアウトフローのできるだけ早い段階でDubのクリックIDを保存します。
</Tip>

- **メタデータには必ずクリックIDを含める**: クリックIDがないと、Dubは収益をリンクに紐付けられません
- **外部IDを一貫して使用する**: 顧客単位で正確に分析できるよう、システムで使用しているものと同じ顧客IDを渡します
- **オーガニックトラフィックを適切に処理する**: クリックIDがない場合は`webhook.cancel = true`を設定し、不要なAPI呼び出しを避けます
- **サンプル支払いでテストする**: 本番稼働前に統合が正しく動作することを確認します
- **Dubダッシュボードを監視する**: 適切なアトリビューションで販売が正しく表示されていることを確認します

## 重要な注意事項

<Note>
- **金額形式**: Dubは金額をセント単位で受け取ります（例: $10.00 = 1000）
- **通貨**: ISO 4217通貨コード（USD、EUR、GBPなど）を使用します
- **無料トライアル**: $0の支払いは販売として追跡されません
- **返金**: 正確な収益レポートが必要な場合は、返金を別途追跡することを検討してください
</Note>

## トラブルシューティング

<AccordionGroup>
<Accordion title="Sales not appearing in Dub">
- Dub APIキーが正しく、`conversions.write`スコープを持っていることを確認します
- `dub_click_id`が取得され、支払いメタデータに保存されていることを確認します
- webhookの変換でpayloadが正しく整形されていることを確認します
- webhookが`payment.succeeded`イベントでトリガーされていることを確認します
- Dubリンクでコンバージョン追跡が有効になっていることを確認します
</Accordion>

<Accordion title="Revenue attribution not working">
- チェックアウト前にユーザーがDubの短縮リンクをクリックしていることを確認します
- ドメインで`dub_id` cookieが正しく設定されていることを確認します
- チェックアウト作成時と支払い完了時でクリックIDが一致していることを確認します
- チェックアウトセッションを作成する前にクリックIDを取得していることを確認します
</Accordion>

<Accordion title="Transformation errors">
- JSON構造がDubのTrack Sale API形式と一致することを確認します
- 必須フィールド（`clickId`、`externalId`、`amount`）がすべて存在することを確認します
- 金額がセント単位（小数ではなく整数）であることを確認します
- API endpoint URLが正しいことを確認します: `https://api.dub.co/track/sale`
- サンプルwebhook payloadで変換をテストします
</Accordion>

<Accordion title="Duplicate sales being tracked">
- `payment.succeeded`イベントでのみ追跡し、`payment.processing`では追跡しないようにします
- 各販売には一意の`invoiceId`値を使用します
- サブスクリプションでは、更新時の重複を防ぐためにタイムスタンプまたは請求期間を追加します
</Accordion>
</AccordionGroup>
