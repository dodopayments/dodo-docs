## はじめに

DataFastは、収益を最優先に考えた分析ツールで、どのマーケティングチャネルが支払い顧客を引き寄せるかを発見するのに役立ちます。Dodo PaymentsをDataFastと統合することで、トラフィックソースに収益を帰属させ、高価値の顧客セグメントを特定し、データに基づいた意思決定を行ってビジネスを成長させることができます。

<Info>
この統合には、[DataFast ダッシュボード](https://datafa.st/) から取得できる DataFast API キーが必要です。
</Info>

## 仕組み

DataFastは、クッキーに保存されたユニークな訪問者IDを通じて訪問者を追跡します。マーケティングチャネルに収益を帰属させるには、次の手順が必要です：

1. **チェックアウト セッションを作成する際に、`datafast_visitor_id` クッキーから DataFast の訪問者 ID を取得する**
2. **支払いのメタデータに訪問者 ID を保存する**
3. **支払いが成功したら DataFast の Payment API に支払いデータを送信する**

これにより、DataFastは成功した支払いを元のトラフィックソースと照合し、完全な収益帰属を提供します。

## 始め方

<Steps>
<Step title="Install DataFast Script">
  まず、ウェブサイトに DataFast のトラッキングスクリプトをインストールします。これにより、訪問者を追跡する `datafast_visitor_id` クッキーが生成されます。
  
  プラットフォームごとのインストール手順については、[DataFast ドキュメント](https://datafa.st/docs)をご覧ください。
</Step>

<Step title="Get Your API Key">
  [DataFast ダッシュボード](https://datafa.st/) にログインし、ウェブサイト設定に移動して API キーを取得します。
  
  <Warning>
  API キーは安全に管理し、クライアント側のコードで公開しないでください。
  </Warning>
</Step>

<Step title="Capture Visitor ID in Checkout">
  チェックアウト セッションを作成する際に、クッキーから DataFast の訪問者 ID を取得し、支払いメタデータに追加します。
</Step>

<Step title="Send Payment Data via Webhook">
  支払いが成功したときに DataFast の Payment API に支払いデータを送信するように、Webhook を構成します。
</Step>

<Step title="Done!">
  🎉 これで収益データが DataFast ダッシュボードに表示され、マーケティングチャネルに完全に帰属されます。
</Step>
</Steps>

## 実装ガイド

### ステップ1: チェックアウトメタデータに訪問者IDを追加

チェックアウトセッションを作成する際に、クッキーからDataFastの訪問者IDを取得し、支払いメタデータに含めます。

<Note>
以下の例では `POST /payments` を使用していますが、これは**非推奨**です。既存のインテグレーションでは引き続き動作しますが、新しいインテグレーションでは [Checkout Sessions](/developer-resources/checkout-session)（`POST /checkouts`）を使用してください。`metadata` は同じ方法で渡されます。
</Note>

<CodeGroup>

```typescript Next.js
import { cookies } from 'next/headers';
import { dodopayments } from '@/lib/dodopayments';

export async function createCheckout(productId: string) {
  // Capture DataFast visitor ID from cookie
  const datafastVisitorId = cookies().get('datafast_visitor_id')?.value;

  const payment = await dodopayments.payments.create({
    product_cart: [{ product_id: productId, quantity: 1 }],
    // ... other payment configuration
    metadata: {
      datafast_visitor_id: datafastVisitorId, // Store visitor ID in metadata
    },
  });

  return payment;
}
```

```javascript Express.js
const express = require('express');
const router = express.Router();

router.post('/create-checkout', async (req, res) => {
  // Capture DataFast visitor ID from cookie
  const datafastVisitorId = req.cookies?.datafast_visitor_id;

  const payment = await dodopayments.payments.create({
    product_cart: [{ product_id: req.body.productId, quantity: 1 }],
    // ... other payment configuration
    metadata: {
      datafast_visitor_id: datafastVisitorId, // Store visitor ID in metadata
    },
  });

  res.json({ payment });
});
```

```javascript Other Frameworks

  product_cart: [{ product_id: productId, quantity: 1 }],

  },

```

</CodeGroup>

## 変換コードの例

### 基本的な支払いアトリビューション

```javascript basic_payment.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    // Only send to DataFast if visitor ID exists in metadata
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      webhook.payload = {
        amount: payment.total_amount / 100, // Convert from cents to dollars
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

### 小数点以下のない通貨への対応

JPY など、一部の通貨では小数点以下の桁を使用しません。それに応じて金額の計算を調整してください。

```javascript zero_decimal.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      // Zero decimal currencies: JPY, KRW, CLP, etc.
      const zeroDecimalCurrencies = ['JPY', 'KRW', 'CLP', 'VND', 'UGX', 'MGA'];
      const isZeroDecimal = zeroDecimalCurrencies.includes(payment.currency);
      
      webhook.payload = {
        amount: isZeroDecimal 
          ? payment.total_amount // Use amount as-is for zero decimal currencies
          : payment.total_amount / 100, // Convert from cents for other currencies
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

### サブスクリプションの支払い

定期的なサブスクリプションの支払いでは、各支払いを追跡できます。

```javascript subscription_payment.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    // Check if this is a subscription payment
    const isSubscription = payment.subscription_id !== null;
    
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      webhook.payload = {
        amount: payment.total_amount / 100,
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
        // Optional: Add subscription context
        ...(isSubscription && {
          subscription_id: payment.subscription_id,
        }),
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

## ベストプラクティス

<Tip>
**visitor ID を早期に取得する**：正確なアトリビューションを確保するため、checkout flow のできるだけ早い段階で DataFast visitor ID を保存します。これにより、ユーザーがページを離れて後から戻ってきた場合でも対応できます。
</Tip>

- **metadata には必ず visitor ID を含める**：visitor ID がないと、DataFast は収益をマーケティングチャネルにアトリビュートできません
- **小数点以下のない通貨に対応する**：一部の通貨（JPY、KRW など）では小数点以下の桁を使用しないため、それに応じて金額の計算を調整します
- **サンプル支払いでテストする**：本番稼働する前に、インテグレーションが正しく動作することを確認します
- **DataFast ダッシュボードを監視する**：適切なアトリビューションとともに支払いが正しく表示されていることを確認します
- **webhook retry を使用する**：DataFast の Payment API は idempotent であるため、webhook が失敗した場合も retry は安全です

## トラブルシューティング

<AccordionGroup>
<Accordion title="Payments not appearing in DataFast">
- DataFast API key が正しく、有効であることを確認します
- `datafast_visitor_id` が取得され、支払い metadata に保存されていることを確認します
- webhook transformation で payload が正しくフォーマットされていることを確認します
- webhook が `payment.succeeded` events でトリガーされていることを確認します
- DataFast ダッシュボードでエラーメッセージや API logs を確認します
</Accordion>

<Accordion title="Revenue attribution not working">
- DataFast tracking script がウェブサイトにインストールされ、動作していることを確認します
- `datafast_visitor_id` cookie が正しく設定されていることを確認します
- checkout creation と payment completion の間で visitor ID が一致していることを確認します
- checkout session を作成する前に visitor ID を取得していることを確認します
- 追加のガイダンスについては、DataFast の [Payment API documentation](https://datafa.st/docs/payments-api) を確認してください
</Accordion>

<Accordion title="Transformation errors">
- JSON structure が DataFast の Payment API format と一致していることを確認します
- 必須フィールド（`amount`、`currency`、`transaction_id`、`datafast_visitor_id`）がすべて存在することを確認します
- 金額が正しく変換されていることを確認します（小数点以下のない通貨を除き、ほとんどの通貨では 100 で割ります）
- API endpoint URL が正しいことを確認します：`https://datafa.st/api/v1/payments`
- サンプル webhook payload で transformation をテストします
</Accordion>

<Accordion title="Currency conversion issues">
- 小数点以下のない通貨（JPY、KRW、CLP、VND、UGX、MGA）では、100 で割らずに金額をそのまま送信します
- その他すべての通貨では、cents から基本単位に変換するため、金額を 100 で割ります
- currency code が ISO 4217 format（例：「USD」、「EUR」、「JPY」）と一致していることを再確認します
</Accordion>
</AccordionGroup>
