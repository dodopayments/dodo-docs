## What is Dodo Payments?

Dodo Payments is the **all-in-one engine** to launch, scale, and monetize worldwide. Designed for the new generation of digital SaaS and AI products, we handle everything from **payments to billing to distribution** - all without extra engineering.

<Info>
**Built for SaaS and AI Products**: Handle one-time payments, subscriptions, credits, seats, tokens, or any usage metric with our optimized billing infrastructure.
</Info>

<Tip>
  <strong>Meet Sentra: Your AI-powered billing assistant</strong><br/>
  Sentra is an AI agent that integrates, analyzes, and acts on billing and payments directly in your IDE. Ask questions, build integrations, or plan billing architectures - all by describing what you want.
  <a href="/developer-resources/sentra">
    Get started with Sentra &rarr;
  </a>
</Tip>

## Quick Start Guide

数ステップでDodo Paymentsをすぐに始めましょう。

<AccordionGroup>
{/* LOCKED_PATTERN_5456326d20112c91d694aeee1569fdff */}
  自分で統合を進めたいですか？以下のステップでアカウント作成から製品追加、統合方法の選択まで5分以内で進行します。コードは必要ありませんが、各主要言語に対応したSDKサンプルも用意されています。

  AIコーディングアシスタントに荷物を任せたい場合は、VS Code、Cursor、Windsurf用のAI請求アシスタントである**[Sentra](/developer-resources/sentra)**をインストールしてください。希望する内容を説明すると、Sentraが計画し、骨組みを作り、出荷します。
</Accordion>

{/* LOCKED_PATTERN_cccd916835a5dc3261db269c8e55de19 */}
  Dodo Paymentsはエージェントネイティブなワークフロー向けに構築されています。もしこれを読んでいるのがLLMか、またはそれを設定している開発者であれば、ここから始めましょう。

  **探索**. 完全なドキュメントのインデックスは[`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt)で提供され、ドキュメントの各ページは、そのURLに`.md`を追加することでプレーンマークダウン形式で利用可能です（例: `/api-reference/introduction.md`）。

  **接続**. 2つのMCPサーバーがエージェントにプラットフォームへのライブアクセスを提供します。

  - **[Dodo Knowledge MCP](/developer-resources/mcp-server#dodo-knowledge-mcp)** - Dodoのドキュメント全体を対象にセマンティック検索
  - **[Dodo Payments MCP](/developer-resources/mcp-server)** - API操作の実行（支払いの作成、サブスクリプションの管理、返金の発行）

  完全なクライアント設定については[MCPサーバーガイド](/developer-resources/mcp-server)をご覧ください。

  **拡張**. 公式[Dodo Payments Skills](/developer-resources/agent-skills)をインストールして、チェックアウト、サブスクリプション、使用量ベースの請求、クレジットベースの請求、ウェブフックなどの処理方法をエージェントに教えてください。

  ```bash
  npx skills add dodopayments/skills
  ```

  Claude Code、OpenCode、Cursor、およびMCP対応エージェントと互換性があります。
</Accordion>
</AccordionGroup>

AIコーディングアシスタント（Cursor、Claude Desktop、Windsurf、VS Code）をDodo Paymentsに直接接続するためのMCPサーバーです。

<CardGroup cols={2}>
<Card title="Dodo Knowledge MCP" icon="book-open" href="/developer-resources/mcp-server#dodo-knowledge-mcp">
  Dodo Payments文書全体でのセマンティック検索 - 機能、API、およびベストプラクティスについてすぐに回答を得られます
</Card>

<Card title="Dodo Payments MCP" icon="credit-card" href="/developer-resources/mcp-server">
  API操作を直接実行 - 支払いの作成、サブスクリプションの管理、返金の処理をAIアシスタントを通じて行います
</Card>
</CardGroup>

<Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
お使いのMCP設定に両サーバーを追加 (`~/.cursor/mcp.json`またはClaude Desktop設定):

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

<Info>
Node.js 18+ が必要です。すべてのサポートされたクライアントの詳細な設定手順については[MCPサーバードキュメント](/developer-resources/mcp-server)をご覧ください。
</Info>
</Accordion>
