## What is Dodo Payments?

Dodo Payments is the **all-in-one engine** to launch, scale, and monetize worldwide. Designed for the new generation of digital SaaS and AI products, we handle everything from **payments to billing to distribution** - all without extra engineering.

<Info>
**Built for SaaS and AI Products**: Handle one-time payments, subscriptions, credits, seats, tokens, or any usage metric with our optimized billing infrastructure.
</Info>

<Tip>
  <strong>Meet Sentra: Your AI-powered billing assistant</strong><br/>
  Sentra is an AI agent that integrates, analyzes, and acts on billing and payments directly in your IDE. Ask questions, build integrations, or plan billing architectures - all by describing what you want.
  <a href="/developer-resources/sentra">
    Get started with Sentra &rarr;
  </a>
</Tip>

## Quick Start Guide

数ステップでDodo Paymentsをすぐに始めましょう。

<AccordionGroup>
<Accordion title="For Humans">
  自分で統合を進めたいですか？以下のステップでアカウント作成から製品追加、統合方法の選択まで5分以内で進行します。コードは必要ありませんが、各主要言語に対応したSDKサンプルも用意されています。

  AIコーディングアシスタントに荷物を任せたい場合は、VS Code、Cursor、Windsurf用のAI請求アシスタントである**[Sentra](/developer-resources/sentra)**をインストールしてください。希望する内容を説明すると、Sentraが計画し、骨組みを作り、出荷します。
</Accordion>

<Accordion title="For AI Agents">
  Dodo Paymentsはエージェントネイティブなワークフロー向けに構築されています。もしこれを読んでいるのがLLMか、またはそれを設定している開発者であれば、ここから始めましょう。

  **インストール**。Claude Code、Codex CLI、Cursor、または OpenCode の場合、[Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) は、1 つのステップで MCP サーバーとすべてのスキルを配線します。各エージェントのインストールコマンドについては、[AI Coding Agents ガイド](/developer-resources/build-with-ai-coding-agents) を参照してください。

  **発見**。完全なドキュメントのインデックスは [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt) で提供され、すべてのドキュメントページは、その URL に `.md` を追加することで簡単なマークダウンで利用できます（例：`/api-reference/introduction.md`）。

  **接続**。2 つの MCP サーバーがエージェントにプラットフォームへのライブアクセスを提供します:

  - **[Dodo Knowledge MCP](/developer-resources/mcp-server#dodo-knowledge-mcp)** - Dodo ドキュメント全体のセマンティック検索
  - **[Dodo Payments MCP](/developer-resources/mcp-server)** - API 操作の実行（支払い作成、サブスクリプション管理、払い戻しの発行）

  完全なクライアント構成については、[MCP Server ガイド](/developer-resources/mcp-server) を参照してください。

  **拡張**。公式の [Dodo Payments Skills](/developer-resources/agent-skills) をインストールして、チェックアウト、サブスクリプション、使用量ベースの課金、クレジットベースの課金、ウェブフックなどの処理方法をエージェントに教えましょう。

  ```bash
  npx skills add dodopayments/skills
  ```

  Claude Code、OpenCode、Cursor、および MCP 対応エージェントと連携します。
</Accordion>
</AccordionGroup>

<Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
両方のサーバーを MCP 構成に追加 (`~/.cursor/mcp.json` または Claude Desktop 構成):

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

<Info>
Node.js 18+ が必要です。すべてのサポートされているクライアントの詳細なセットアップ手順については、[MCP サーバー ドキュメンテーション](/developer-resources/mcp-server) を参照してください。
</Info>
</Accordion>
