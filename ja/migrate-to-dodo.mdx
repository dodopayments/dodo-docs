**別の決済プロバイダーからDodo Paymentsに切り替えますか？** 移行ツールを使用すると、**製品、顧客、割引コード、ライセンスキーをデータを失うことなく簡単に移行できます。** プロセスは安全で、ガイド付きで、わずか数分で完了します。

現在、**Lemon Squeezy、Stripe、Polar.sh、Paddle**からの移行をサポートしています。

## 始める

まず、移行ツールをインストールします：

```bash
npm install -g dodo-migrate
```

<Note>
コンピュータに Node.js ≥ 18 をインストールしておく必要があります。
</Note>

## データを移行する

### Lemon Squeezyから来ている場合：

```bash
dodo-migrate lemonsqueezy
```

### Stripeから来ている場合：

```bash
dodo-migrate stripe
```

### Polar.shから来ている場合：

```bash
dodo-migrate polar
```

### Paddleから来ている場合：

```bash
dodo-migrate paddle
```

ツールはすべてのプロセスをステップバイステップで案内します。必要なもの：
- ご利用のプロバイダーのAPIキー（Lemon Squeezy, Stripe, Polar.sh, Paddleなど）
- Dodo PaymentsのAPIキー  
- 最初にテストするか（推奨）、または本番環境で行うか
- 移行先のDodo Paymentsのブランド
- 移行するデータ（製品、顧客、割引、ライセンスキー）

## なぜ当社の移行ツールを使用するのか？

- **データ損失なし** - すべてが安全に転送されます
- **最初にテスト** - 本番環境に移行する前にテストモードで試すことができます
- **ガイド付きプロセス** - 各ステップをガイドします
- **必要に応じて再開** - 何か問題が発生した場合、途中から再開できます

## 高度な使用法

プロンプトなしで移行を実行したい場合は、すべての詳細を事前に提供できます：

### Lemon Squeezyの移行：

```bash
dodo-migrate lemonsqueezy \
  --provider-api-key=lsq_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX
```

### Stripeの移行：

```bash
dodo-migrate stripe \
  --provider-api-key=sk_test_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX \
  --migrate-types=products,coupons
```

### Polar.shの移行：

```bash
dodo-migrate polar \
  --provider-api-key=polar_org_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX \
  --migrate-types=products,discounts,customers,license_keys
```

### Paddleの移行：

## ライセンスキーの移行

ライセンスキーの移行は**Polar.sh**と**Lemon Squeezy**に対応しています。対話型プロンプトでライセンスキーを選択するか、`license_keys`を`--migrate-types`に渡すと、ツールは既存のライセンスキーを適切な顧客および製品の関連付けでDodo Paymentsにインポートします。

{/* LOCKED_PATTERN_4907e9f6f7fbd509120d7a87afc829e9 */}
ライセンスキーの移行には、**製品および顧客**を同じセッションで移行する必要があります。ツールは実行中にプロバイダーIDをDodo IDにマッピングするインメモリのマッピングを構築します。製品や顧客が不足している場合は、ライセンスキーを正しくリンクできません。
{/* LOCKED_PATTERN_176d815432e7554ac558e8631b2bc397 */}

### 移行される内容

- ライセンスキーの文字列
- アクティベーション制限
- 有効期限
- 顧客および製品の関連付け

### 移行されない内容

- **ライセンスキーのアクティベーション** — 顧客は移行後にデバイス上で再アクティベートする必要があります
- **無効または停止されたキー** — アクティブなキーのみが移行されます
- 一致する製品または顧客がないキーは警告とともにスキップされます

{/* LOCKED_PATTERN_317ec56569e36d0c9e56c2648890a76e */}
重複するライセンスキーは丁寧に扱われます。移行を再実行した場合、既にインポートされたキーは検出されてスキップされるため、再試行は安全です。
{/* LOCKED_PATTERN_4dec52ce04aa8849a8a60508baae30ae */}
