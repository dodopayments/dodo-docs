## 新機能 🚀

- **Checkout 2.0**: 完全に再設計されたチェックアウトエクスペリエンスを導入:
    - ユーザー体験を向上させる、洗練されたモダンなインターフェース
    - Session Storage にパラメータをユニークIDと共に保存する新しいQuery Collector System (例: `sess_1a2b3c4d`)
    - チェックアウトフロー全体でのデータの永続的な利用可能性
    - 将来のリリースに備えたさらなる機能強化を計画中！
  
    <Frame><img src="/images/changelog/checkout_2.png" alt="Checkout 2.0" style={{ maxHeight: '500px', width: 'auto' }} /></Frame>

- **設定可能な支払い方法**: 新しい `allowed_payment_method_types` configuration により、加盟店は checkout 中に利用可能な支払いオプションをカスタマイズできます。実装の詳細については、[Allowed Payment Methods](/features/payment-methods#per-checkout-payment-method-configuration) のドキュメントをご覧ください。

- **動的税計算**: 顧客の請求先住所に基づく税率のリアルタイム計算により、静的な支払いリンクの価格をより正確にします。

- **オンデマンドサブスクリプション**: 柔軟なサブスクリプション billing に対応する新しい API endpoints が追加されました（一部の加盟店のみ利用可能）。詳しくは、[On-Demand Subscriptions](/developer-resources/ondemand-subscriptions) ガイドをご覧ください。

- **追加の更新**:
    - パフォーマンスの最適化
    - バグ修正
    - 一般的なシステム改善
