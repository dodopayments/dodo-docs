## 新機能

### 1. **商品コレクション**  
   
   関連商品をまとめて、統一されたチェックアウト体験、プラン選択、カスタマーポータル内でのシームレスなアップグレード/ダウングレードパスを提供します。

   <Frame>
     <img src="/images/product-collection/checkout-page.png" alt="複数のプランオプションを示す商品コレクションのチェックアウトページ" />
   </Frame>

  **主な利点**

   - **コレクションベースのチェックアウト**: コレクション内のすべての商品を1つのチェックアウトビューで表示し、顧客が比較して好みのプランを選択できるようにします
   - **整理された商品管理**: 関連商品（例：スタータープラン、プロプラン、エンタープライズプラン）を単一のコレクションにまとめます
   - **カスタマーポータル統合**: 顧客が同じコレクション内の間で商品をアップグレードまたはダウングレードできるようにします
   - **マーチャントコントロール**: 各コレクション内での商品を有効、無効、有順序できます

   **動作方式**

   コレクションのためのチェックアウトセッションを作成します:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_collection_id: 'pdc_abc123',
     product_cart: [], // Required: pass an empty array for collection checkout
     return_url: 'https://yoursite.com/return'
   });

   // Redirect customer to the checkout
   window.location.href = session.url;
   ```

   <Check>
   結果: 顧客がコレクション内のすべての商品を表示・選択できる統一されたチェックアウト体験。
   </Check>

   <Info>
   コレクションのチェックアウトは、顧客が購入前にプランを並んで比較できるサブスクリプションビジネスに最適です。
   </Info>

   詳細: [商品コレクションガイド](/features/product-collections)

### 2. **GBP通貨のRevolutPay & Billie決済方法**  
   
   RevolutPayおよびBillieによる決済オプションが拡大し、GBP一回限りの支払い取引に対して世界中で利用可能になり、顧客の支払い方法の柔軟性が向上します。

   **新しい決済方法**

   | 決済方法 | 対応国 | 通貨 | サブスクリプションサポート |
   |---------------|---------------------|----------|---------------------|
   | **RevolutPay** | グローバル | GBP | なし（1回限りのみ） |
   | **Billie** | グローバル | GBP | なし（1回限りのみ） |

   - **RevolutPay** – 世界中のRevolutユーザー向けに迅速でシームレスな決済
   - **Billie** – ビジネスが顧客に柔軟な支払い条件を提供可能にするB2B「今すぐ購入、後で支払い」ソリューション

   <Info>
   これらの決済方法はGBP取引に対して自動的に利用可能です。追加の設定は必要ありません。
   </Info>

   詳細: [決済方法](/features/payment-methods)

### 3. **チェックアウトセッションのプレビュー**  
   
   チェックアウトセッションを作成する前にプレビューを行い、正確な価格、税金、割引、合計を計算します。顧客がチェックアウトに進む前に実際の価格を表示します。

   **動作方式**

   ```typescript
   const preview = await client.checkoutSessions.preview({
     product_cart: [
       { product_id: 'prod_123', quantity: 1 }
     ],
     billing_address: {
       country: 'US',
       state: 'CA',
       zipcode: '94102'
     },
     discount_code: 'SAVE20'
   });

   console.log('Subtotal:', preview.subtotal);
   console.log('Tax:', preview.tax);
   console.log('Discount:', preview.discount);
   console.log('Total:', preview.total);
   ```

   **ユースケース**

   - **カスタム価格表示**: チェックアウト前に税金を含む正確な合計を表示
   - **割引検証**: 割引コードを検証し、顧客に節約を示します
   - **マルチ通貨サポート**: 異なる通貨での価格プレビュー
   - **カートの概要**: リアルタイムの価格でカスタムカートUIを構築

### 4. **プラン変更リクエストでのメタデータサポート**  
   
   サブスクリプションプランを変更する際にカスタムメタデータを渡し、プラン変更中の内部システムとのトラッキングと統合を強化します。

   ```javascript
   // Adding metadata when changing a subscription plan
   await client.subscriptions.changePlan('sub_123', {
     product_id: 'prod_premium',
     proration_billing_mode: 'prorated_immediately',
     quantity: 1,
     metadata: {
       upgrade_reason: 'feature_request',
       previous_plan: 'basic',
       sales_rep: 'john@company.com'
     }
   });
   ```

  **ユースケース**

   - **アップグレード/ダウングレード理由の追跡**: 顧客がプランを変更した理由を記録
   - **CRMレコードへのリンク**: プラン変更を営業活動と関連付ける
   - **内部分類**: レポートや分析のためのプラン変更をタグ付け
   - **監査履歴**: プラン変更を開始した人の記録を保持

   <Info>
   メタデータはWebhookイベントに含まれており、カスタムデータでプラン変更を簡単に処理できます。
   </Info>

   詳細: [メタデータガイド](/api-reference/metadata) | [プラン変更API](/api-reference/subscriptions/change-plan)

### 5. **`invoice_url`フィールドに関する決済応答と決済リンク応答**  
   
   決済応答と決済リンク応答には`invoice_url`フィールドが含まれ、各決済に関連する請求書への直接アクセスを提供します。

   ```json
   {
     "payment_id": "pay_2IjeQm4hqU6RA4Z4kwDee",
     "status": "succeeded",
     "invoice_url": "https://dodopayments.com/invoices/inv_2IsUnWGtRKFLxk7xAQeyt",
     "amount": 9900,
     "currency": "USD",
     // ... other fields
   }
   ```

  **ユースケース**

   - **顧客コミュニケーション**: 請求書リンクを顧客に直接送信
   - **会計統合**: 支払いを請求書にリンクする
   - **セルフサービスポータル**: 顧客が請求書に簡単にアクセスできるようにする
   - **記録保持**: 請求書文書への直接参照を保持

### 6. **コード名による割引検証エンドポイント**  
   
   コード名（例: "SAVE20"）によって割引コードを検証し、取得するための新しいAPIエンドポイント。チェックアウト時に適用する前に割引の適格性を確認します。

   ```javascript
   // Validate a discount code before checkout
   const discount = await client.discounts.getByCode('SAVE20');

   console.log('Discount type:', discount.type);
   console.log('Discount value:', discount.amount);
   console.log('Valid until:', discount.expires_at);
   ```

  **利点**

   - **チェックアウト前の検証**: チェックアウトセッションの作成前に割引コードを検証
   - **リアルタイムのフィードバック**: 顧客にコードが有効かどうかを示します
   - **エラーハンドリング**: 無効または期限切れのコードを早期にキャッチ
   - **カスタム割引UI**: インスタントバリデーション付きの割引コード入力フィールドを構築

### 7. **顧客、割引、ライセンスキー向けの強化されたフィルタリング機能**  
   
   顧客、割引、ライセンスキーをリストするための新しいAPIフィルターにより、データをプログラム的に見つけて管理しやすくなります。

   **顧客APIフィルター**

   | フィルター | 説明 |
   |--------|-------------|
   | `email` | 顧客のメールでフィルタリング |
   | `name` | 顧客名でフィルタリング（部分一致、大文字小文字を区別しない） |
   | `created_at_gte` | このタイムスタンプ以降に作成された顧客をフィルタリング |
   | `created_at_lte` | このタイムスタンプ以前に作成された顧客をフィルタリング |

   ```javascript
   // Find customers by name created in the last 30 days
   const customers = await client.customers.list({
     name: 'John',
     created_at_gte: '2026-01-01T00:00:00Z'
   });
   ```

   **割引APIフィルター**

   | フィルター | 説明 |
   |--------|-------------|
   | `code` | 割引コードでフィルタリング（部分一致、大文字小文字を区別しない） |
   | `discount_type` | 割引タイプでフィルタリング（パーセンテージ） |
   | `active` | アクティブステータスでフィルタリング（true = 有効、false = 期限切れ） |
   | `product_id` | 商品制限でフィルタリング（この商品に適用される割引のみ） |

   ```javascript
   // Find active percentage discounts for a specific product
   const discounts = await client.discounts.list({
     active: true,
     discount_type: 'percentage',
     product_id: 'prod_123'
   });
   ```

   **ライセンスキーAPIフィルター**

   | フィルター | 説明 |
   |--------|-------------|
   | `customer_id` | 顧客IDでフィルタリング |
   | `status` | ライセンスキーのステータスでフィルタリング（`active`、`expired`、`disabled`） |
   | `product_id` | 商品IDでフィルタリング |
   | `created_at_gte` | このタイムスタンプ以降に作成されたライセンスキーをフィルタリング |
   | `created_at_lte` | このタイムスタンプ以前に作成されたライセンスキーをフィルタリング |

   ```javascript
   // Find active license keys for a specific product
   const licenseKeys = await client.licenseKeys.list({
     status: 'active',
     product_id: 'prod_123'
   });
   ```
