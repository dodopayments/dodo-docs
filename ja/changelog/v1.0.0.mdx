## 新機能 🚀

- **カスタマーポータル**: `Customer Portal` 機能を導入し、顧客がサブスクリプション、請求書、および支払い方法を管理できるようになりました。Dodo Payments ダッシュボードまたは APIs を介して、顧客向けに静的または動的なカスタマーポータルリンクを作成できます。ダッシュボードでは、`Sales > Customers > Share Invite` に移動します。

- **カスタマーポータルセッション API**: 特定の顧客のためにカスタマーポータルのセッションを作成するための `Customer Portal Session` API を追加しました。このセッションは 24 時間のみ有効であることに注意してください。詳細については、[API リファレンス](/api-reference/customers/create-customer-portal-session) を確認してください。

- **その他**: 小さな改善とバグ修正。
