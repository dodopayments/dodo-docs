## 新機能

### 1. **コミュニケーション設定**

   改良されたコミュニケーション設定で通知の受け取り方をコントロールしてください。メール、プッシュ、アプリ内通知をあなたのワークフローに合わせて設定できます。

   <Frame>
     <img src="/images/communication-preferences/overview.png" alt="コミュニケーション設定の通知設定を示す概要" />
   </Frame>

   **主な機能**

   - **改良されたメールデザイン**: 明確な行動喚起と改善された可読性を持つ新しく現代的なメールテンプレート
   - **プッシュ通知**: 新しい販売、争議、そして支払いなどの重要なイベントに対してモバイルデバイスで即座にアラートを受け取れる
   - **詳細なコントロール**: どのイベントが通知をトリガーするか、そしてどのチャネルを通じて通知が送られるかを選択可能
   - **複数メールサポート**: 複数のメールアドレスを追加して通知を受け取る
   - **顧客のメール設定**: 顧客が受け取るメールを設定可能

   **通知カテゴリ**

   | カテゴリ | 説明 |
   |----------|-------------|
   | **売上と支払い** | 新しい販売、成功した支払い、失敗した支払い |
   | **支払と返金** | 支払い完了、返金リクエスト、返金完了 |
   | **サブスクリプション** | 新しいサブスクリプション、更新、キャンセル、プラン変更 |
   | **争議** | 争議が開かれた、証拠が必要、争議が解決された |

   <Check>
   結果: あなたが望む方法とタイミングで通知が届くことで、ビジネスの最新情報を把握してください。
   </Check>

   詳しくは: [コミュニケーション設定ガイド](/features/communication-preferences)

### 2. **チェックアウトセッションのカスタムフィールド**

   カスタムフィールドを使用してチェックアウト中に顧客から追加情報を収集できます。テキスト入力、ドロップダウン、日付などを追加して、必要なデータを収集してください。

   **サポートされているフィールドタイプ**

   | タイプ | 説明 | 使用例 |
   |------|-------------|----------|
   | `text` | 単一行テキスト入力 | 会社名、注文メモ |
   | `number` | 数値入力 | 数量、年齢 |
   | `email` | 検証付きメール入力 | 請求連絡先メール |
   | `url` | 検証付きURL入力 | ウェブサイト、ソーシャルプロフィール |
   | `date` | 日付ピッカー | 配送日、イベント日 |
   | `dropdown` | 事前定義されたオプションからの選択 | サイズ、色、プランタイプ |
   | `boolean` | はい/いいえの値のためのチェックボックス | 利用規約の受諾、ニュースレターのオプトイン |

   **動作方法**

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     custom_fields: [
       {
         name: 'company_name',
         label: 'Company Name',
         type: 'text',
         required: true
       },
       {
         name: 'team_size',
         label: 'Team Size',
         type: 'dropdown',
         options: ['1-10', '11-50', '51-200', '200+'],
         required: true
       },
       {
         name: 'newsletter',
         label: 'Subscribe to our newsletter',
         type: 'boolean',
         required: false
       }
     ],
     return_url: 'https://yoursite.com/success'
   });
   ```

   **利点**

   - **柔軟なデータ収集**: 完了やパーソナライズのために必要な情報を収集
   - **ビルトインのバリデーション**: メールおよびURLフィールドは自動的に入力形式を検証
   - **必須/任意の制御**: あなたのニーズに基づいてフィールドを必須または任意としてマーク
   - **Webhook配信**: カスタムフィールドの値は、支払いWebhookイベントに含まれる

   <Info>
   カスタムフィールドの値は、支払いとチェックアウトセッションのレスポンス内の `custom_fields` オブジェクトで返されます。
   </Info>

   詳しくは: [チェックアウトセッションのカスタムフィールド](/developer-resources/checkout-session#custom-fields)

### 3. **拡張されたチェックアウト言語サポート**

   チェックアウトページは現在**21言語**をサポートしており、以前は16言語でした。ネイティブ言語でのより良いチェックアウト体験のために、より多くの顧客にアプローチできます。

   **新たに追加された言語**

   | 言語 | コード |
   |----------|------|
   | 韓国語 | `ko` |
   | マレー語 | `ms` |
   | ルーマニア語 | `ro` |
   | ロシア語 | `ru` |
   | タイ語 | `th` |

   **すべてのサポート言語**

   アラビア語、中国語、オランダ語、英語、フランス語、ドイツ語、ヒンディー語、インドネシア語、イタリア語、日本語、韓国語、マレー語、ポルトガル語、ルーマニア語、ロシア語、スペイン語、スウェーデン語、タイ語、トルコ語、ウクライナ語、ベトナム語。

   **特定の言語を強制**

   `force_language` パラメータを使用して自動言語検出をオーバーライドします:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     force_language: 'ko', // Force Korean language
     return_url: 'https://yoursite.com/success'
   });
   ```

   <Tip>
   デフォルトでは、チェックアウトページはブラウザ設定から顧客の好みの言語を自動的に検出します。あなたのウェブサイトの言語と一貫性を確保したい場合は、`force_language`を使用してください。
   </Tip>

   詳しくは: [チェックアウト言語サポート](/features/checkout#supported-languages)
