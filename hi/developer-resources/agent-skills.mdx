## ओवरव्यू

एजेंट कौशल पुन: प्रयोज्य क्षमताएँ हैं जो Dodo Payments के साथ काम करते समय AI कोडिंग सहायकों की कार्यक्षमता को बढ़ाती हैं। ये प्रक्रियात्मक ज्ञान और सर्वोत्तम प्रथाओं को प्रदान करते हैं जो एजेंटों को विशिष्ट कार्यों को अधिक प्रभावी ढंग से पूरा करने में मदद करते हैं - चेकआउट प्रवाह को एकीकृत करने से लेकर उपयोग-आधारित बिलिंग सेट करने तक।

<Info>
**कौशल को अपने AI सहायक के लिए प्लगइन के रूप में सोचें।** ये आपके एजेंट को Dodo Payments सुविधाओं को सही ढंग से लागू करने के लिए सिखाते हैं, हमारे सुझाए गए पैटर्न और सर्वोत्तम प्रथाओं का पालन करते हुए।
</Info>

कौशल किसी भी MCP-संलग्न AI एजेंट के साथ काम करते हैं, जिसमें शामिल हैं:
- **Claude Code** - Anthropic का CLI कोडिंग सहायक
- **OpenCode** - ओपन-सोर्स AI कोडिंग एजेंट
- **Cursor** - AI-प्रथमिक कोड संपादक
- **अन्य MCP क्लाइंट** - कोई भी एजेंट जो कौशल प्रोटोकॉल का समर्थन करता है

## स्थापना

अपने AI कोडिंग सहायक के आधार पर अपनी पसंद की स्थापना विधि चुनें।

<Tabs>
<Tab title="Skills CLI">
किसी भी MCP-संलग्न एजेंट के साथ काम करने वाले सार्वभौमिक कौशल CLI का उपयोग करके कौशल स्थापित करें:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

या आवश्यकतानुसार व्यक्तिगत कौशल स्थापित करें:

```bash
# Best practices guide
npx skills add dodopayments/skills/dodo-best-practices

# Webhook integration
npx skills add dodopayments/skills/webhook-integration

# Subscription billing
npx skills add dodopayments/skills/subscription-integration

# Checkout flows
npx skills add dodopayments/skills/checkout-integration

# Usage-based billing
npx skills add dodopayments/skills/usage-based-billing

# BillingSDK components
npx skills add dodopayments/skills/billing-sdk

# License key management
npx skills add dodopayments/skills/license-keys
```

<Tip>
केवल उन कौशल को स्थापित करें जिनकी आपको आवश्यकता है ताकि आपका एजेंट केंद्रित रहे और संदर्भ ओवरहेड को कम करे।
</Tip>
</Tab>

<Tab title="Claude Code">
Claude Code में Dodo Payments कौशल मार्केटप्लेस जोड़ें:

```bash
/plugin marketplace add dodopayments/skills
```

फिर व्यक्तिगत प्लगइन्स स्थापित करें:

```bash
# Install best practices
/plugin install dodo-best-practices

# Install webhook integration
/plugin install webhook-integration

# Install subscription integration
/plugin install subscription-integration

# Install checkout integration
/plugin install checkout-integration

# Install usage-based billing
/plugin install usage-based-billing

# Install BillingSDK
/plugin install billing-sdk

# Install license keys
/plugin install license-keys
```

</Tab>

<Tab title="OpenCode">
जब आपके OpenCode सेटिंग्स में कॉन्फ़िगर किया गया हो तो कौशल स्वचालित रूप से उपलब्ध होते हैं। अपनी कॉन्फ़िगरेशन में Dodo Payments कौशल रिपॉजिटरी जोड़ें:

```json
{
  "skills": {
    "repositories": [
      "dodopayments/skills"
    ]
  }
}
```

</Tab>
</Tabs>

## कौशल का उपयोग करना

एक बार स्थापित होने के बाद, आपका AI सहायक तब इन कौशलों का उपयोग कर सकता है जब आप उससे Dodo Payments सुविधाओं को लागू करने के लिए कहते हैं। यहां कुछ उदाहरण प्रॉम्प्ट हैं:

### सर्वोत्तम प्रथाएँ

```
Help me integrate Dodo Payments into my Next.js app following best practices
```

### वेबहुक

```
Set up webhook handlers for payment and subscription events
```

### सदस्यताएँ

```
Implement a subscription flow with free trial and multiple pricing tiers
```

### चेकआउट

```
Create a checkout session for my SaaS product
```

### उपयोग-आधारित बिलिंग

```
Add usage-based billing to track API calls for my AI product
```

### BillingSDK

```
Add a pricing page using BillingSDK components
```

### लाइसेंस कुंजी

```
Implement license key validation for my desktop app
```

## कौशल कैसे काम करते हैं

कौशल आपके AI सहायक को प्रदान करते हैं:

1. **प्रक्रियात्मक ज्ञान** - सुविधाओं को लागू करने के लिए चरण-दर-चरण निर्देश
2. **कोड टेम्पलेट्स** - उत्पादन-तैयार कोड पैटर्न और स्निपेट्स
3. **सर्वोत्तम प्रथाएँ** - सुरक्षा, त्रुटि हैंडलिंग, और UX के लिए अनुशंसित दृष्टिकोण
4. **संदर्भ जागरूकता** - यह समझ कि विभिन्न Dodo Payments सुविधाएँ एक साथ कैसे काम करती हैं

जब आप अपने AI सहायक से किसी फीचर को लागू करने के लिए कहते हैं, तो यह संबंधित कौशल का उपयोग करता है:
- सही कार्यान्वयन दृष्टिकोण को समझना
- सटीक, कार्यशील कोड उत्पन्न करना
- Dodo Payments कन्वेंशन का पालन करना
- किनारे के मामले और त्रुटियों को सही तरीके से संभालना

<Note>
कौशल [MCP सर्वर](/developer-resources/mcp-server) और [Sentra](/developer-resources/sentra) का पूरक हैं। API संचालन के लिए MCP का उपयोग करें, मार्गदर्शित एकीकरण के लिए Sentra का उपयोग करें, और AI सहायक की क्षमताओं को बढ़ाने के लिए कौशल का उपयोग करें।
</Note>
