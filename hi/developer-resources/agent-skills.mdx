## अवलोकन

Agent Skills ऐसी reusable capabilities हैं जो Dodo Payments के साथ काम करते समय AI coding assistants की क्षमताओं को बेहतर बनाती हैं। वे procedural knowledge और best practices प्रदान करती हैं, जिससे agents checkout flows को integrate करने से लेकर usage-based billing सेट अप करने तक, विशिष्ट कार्य अधिक प्रभावी ढंग से पूरा कर सकें।

<Info>
**Skills को अपने AI assistant के लिए plugins की तरह समझें।** वे आपके agent को recommended patterns और best practices का पालन करते हुए Dodo Payments features को सही ढंग से implement करना सिखाती हैं।
</Info>

Skills उन सभी AI agent के साथ काम करती हैं जो skills protocol को सपोर्ट करते हैं, जिनमें शामिल हैं:
- **Claude Code** - Anthropic का CLI coding assistant
- **Codex CLI** - OpenAI का CLI coding agent
- **Cursor** - AI-first code editor
- **VS Code / GitHub Copilot** - Agent Plugin के माध्यम से
- **Kiro** - skills को Power के रूप में लोड करता है
- **OpenCode** - open source AI coding agent
- **Other clients** - skills protocol को सपोर्ट करने वाला कोई भी agent

<Note>
**Gemini CLI अपवाद है।** इसमें agent-skill primitive नहीं है, इसलिए skills वहां उपलब्ध नहीं हैं — केवल दो [MCP servers](/developer-resources/mcp-server) उपलब्ध हैं।
</Note>

## Installation

अपने AI coding assistant के आधार पर अपनी पसंदीदा installation method चुनें।

<Tabs>
<Tab title="Agent Plugin (recommended)">
यदि आप Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro या OpenCode का उपयोग कर रहे हैं, तो [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) एक ही चरण में सभी सत्रह skills और दोनों MCP servers install करता है। जब आपका agent किसी relevant task का पता लगाता है, तो skills अपने आप load हो जाती हैं।

प्रत्येक agent के लिए install commands देखने हेतु [AI Coding Agents guide](/developer-resources/build-with-ai-coding-agents) देखें।
</Tab>

<Tab title="Skills CLI">
Universal skills CLI का उपयोग करके skills install करें, जो किसी भी MCP-compatible agent के साथ काम करती है:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

या आवश्यकता के अनुसार individual skills install करें:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/dodo-best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
अपने agent को focused रखने और context overhead कम करने के लिए केवल आवश्यक skills install करें।
</Tip>
</Tab>

<Tab title="OpenCode">
OpenCode उन directories से skills load करता है जिन्हें आप उसे बताते हैं। यह installed packages को **scan नहीं** करता, इसलिए एक explicit `skills.paths` entry आवश्यक है।

Agent Plugin package का उपयोग करना:

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

Relative paths **project directory** के आधार पर resolve होते हैं, इसलिए package उस project के `node_modules` में मौजूद होना चाहिए। Absolute path भी काम करता है और local-install requirement से बचाता है।

<Warning>
जो skills path मौजूद नहीं है, उसे **चुपचाप** अनदेखा कर दिया जाता है — न error, न warning। पुष्टि करें कि skills वास्तव में load हुई हैं:

```bash
opencode run "List every skill available to you by name."
```

आपको सभी सत्रह दिखाई देनी चाहिए।
</Warning>
</Tab>
</Tabs>

## Skills का उपयोग करना

Install करने के बाद, जब आप अपने AI assistant से Dodo Payments feature implement करने के लिए कहते हैं, तो वह relevant skill को अपने आप load कर लेता है। आपको skill का नाम बताने की आवश्यकता नहीं है — बस task का वर्णन करें।

| Example prompt | Skill that loads |
|----------------|------------------|
| मेरे Next.js app में best practices का पालन करते हुए Dodo Payments integrate करने में मेरी मदद करें | `dodo-best-practices` |
| मेरे Hono app में Dodo Payments checkout route handler जोड़ें | `framework-adapters` |
| Payments test करने और live जाने की प्रक्रिया समझाएं | `testing-and-go-live` |
| मेरे SaaS product के लिए checkout session बनाएं | `checkout-integration` |
| Free trial और multiple pricing tiers के साथ subscription flow implement करें | `subscription-integration` |
| मेरे React Native app में in-app checkout जोड़ें | `mobile-checkout` |
| Payment और subscription events के लिए webhook handlers set up करें | `webhook-integration` |
| अपने AI product के लिए credit entitlements और metered credit deduction set up करें | `credit-based-billing` |
| अपने AI product के API calls track करने के लिए usage-based billing जोड़ें | `usage-based-billing` |
| अपने desktop app के लिए license key validation implement करें | `license-keys` |
| Add-ons और tiered pricing के साथ product catalog बनाएं | `product-catalog-management` |
| ऐसा promo code जोड़ें जो पहले तीन billing cycles पर 20% की छूट दे | `discounts-and-promotions` |
| Purchasing power parity के साथ visitor की local currency में prices दिखाएं | `localized-pricing` |
| Customers को उनके payment methods manage करने के लिए self-service portal दें | `customer-management` |
| Partial refund जारी करें और dispute खुलने पर access revoke करें | `refunds-and-disputes` |
| BillingSDK components का उपयोग करके pricing page जोड़ें | `billing-sdk` |
| Dodo Payments को मेरे Better Auth setup में integrate करें | `better-auth-integration` |

## Skills कैसे काम करती हैं

Skills आपके AI assistant को ये सुविधाएं प्रदान करती हैं:

1. **Procedural Knowledge** - Features implement करने के लिए step-by-step instructions
2. **Code Templates** - Production-ready code patterns और snippets
3. **Best Practices** - Security, error handling और UX के लिए recommended approaches
4. **Context Awareness** - अलग-अलग Dodo Payments features एक साथ कैसे काम करती हैं, इसकी समझ

जब आप अपने AI assistant से कोई feature implement करने के लिए कहते हैं, तो वह relevant skill का उपयोग करके:
- सही implementation approach समझता है
- सटीक, working code generate करता है
- Dodo Payments conventions का पालन करता है
- Edge cases और errors को उचित रूप से handle करता है

<Note>
Skills [MCP Server](/developer-resources/mcp-server) और [Sentra](/developer-resources/sentra) की पूरक हैं। API operations के लिए MCP, guided integration के लिए Sentra और enhanced AI assistant capabilities के लिए Skills का उपयोग करें।
</Note>
