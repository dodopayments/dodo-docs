## अवलोकन

Agent Skills ऐसी reusable capabilities हैं जो Dodo Payments के साथ काम करते समय AI coding assistants की क्षमताओं को बेहतर बनाती हैं। वे procedural knowledge और best practices प्रदान करती हैं, जिससे agents checkout flows को integrate करने से लेकर usage-based billing सेट अप करने तक, विशिष्ट कार्य अधिक प्रभावी ढंग से पूरा कर सकें।

<Info>
**Skills को अपने AI assistant के लिए plugins की तरह समझें।** वे आपके agent को recommended patterns और best practices का पालन करते हुए Dodo Payments features को सही ढंग से implement करना सिखाती हैं।
</Info>

Skills किसी भी MCP-compatible AI agent के साथ काम करती हैं, जिनमें शामिल हैं:
- **Claude Code** - Anthropic का CLI coding assistant
- **OpenCode** - Open source AI coding agent
- **Cursor** - AI-first code editor
- **अन्य MCP clients** - skills protocol को support करने वाला कोई भी agent

## Installation

अपने AI coding assistant के आधार पर अपनी पसंदीदा installation method चुनें।

<Tabs>
<Tab title="Agent Plugin (recommended)">
यदि आप Claude Code, Codex CLI, Cursor या OpenCode का उपयोग कर रहे हैं, तो [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) सभी आठ skills और दोनों MCP servers को एक ही चरण में install करता है। जब आपका agent किसी संबंधित task का पता लगाता है, तो skills अपने आप load हो जाती हैं।

प्रति-agent install commands के लिए [AI Coding Agents guide](/developer-resources/build-with-ai-coding-agents) देखें।
</Tab>

<Tab title="Skills CLI">
Universal skills CLI का उपयोग करके skills install करें, जो किसी भी MCP-compatible agent के साथ काम करता है:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

या आवश्यकतानुसार अलग-अलग skills install करें:

```bash
# Best practices guide
npx skills add dodopayments/skills/dodo-payments/best-practices

# Webhook integration
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Subscription billing
npx skills add dodopayments/skills/dodo-payments/subscription-integration

# Checkout flows
npx skills add dodopayments/skills/dodo-payments/checkout-integration

# Usage-based billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing

# BillingSDK components
npx skills add dodopayments/skills/dodo-payments/billing-sdk

# License key management
npx skills add dodopayments/skills/dodo-payments/license-keys

# Credit-based billing
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
```

<Tip>
अपने agent को focused रखने और context overhead कम करने के लिए केवल आवश्यक skills install करें।
</Tip>
</Tab>

<Tab title="Claude Code">
Claude Code में Dodo Payments skills marketplace जोड़ें:

```bash
/plugin marketplace add dodopayments/skills
```

फिर अलग-अलग plugins install करें:

```bash
# Install best practices
/plugin install dodo-best-practices

# Install webhook integration
/plugin install webhook-integration

# Install subscription integration
/plugin install subscription-integration

# Install checkout integration
/plugin install checkout-integration

# Install usage-based billing
/plugin install usage-based-billing

# Install BillingSDK
/plugin install billing-sdk

# Install license keys
/plugin install license-keys

# Install credit-based billing
/plugin install credit-based-billing
```

</Tab>

<Tab title="OpenCode">
OpenCode settings में configure किए जाने पर skills अपने आप उपलब्ध हो जाती हैं। अपनी configuration में Dodo Payments skills repository जोड़ें:

```json
{
  "skills": {
    "repositories": [
      "dodopayments/skills"
    ]
  }
}
```

</Tab>
</Tabs>

## Skills का उपयोग करना

Install हो जाने के बाद, जब आप अपने AI assistant से Dodo Payments features implement करने के लिए कहेंगे, तो वह इन skills का उपयोग कर सकता है। यहां कुछ उदाहरण prompts दिए गए हैं:

### Best Practices

```
Help me integrate Dodo Payments into my Next.js app following best practices
```

### Webhooks

```
Set up webhook handlers for payment and subscription events
```

### Subscriptions

```
Implement a subscription flow with free trial and multiple pricing tiers
```

### Checkout

```
Create a checkout session for my SaaS product
```

### Usage-Based Billing

```
Add usage-based billing to track API calls for my AI product
```

### BillingSDK

```
Add a pricing page using BillingSDK components
```

### License Keys

```
Implement license key validation for my desktop app
```

### Credit-Based Billing

```
Set up credit entitlements and metered credit deduction for my AI product
```

## Skills कैसे काम करती हैं

Skills आपके AI assistant को ये सुविधाएं प्रदान करती हैं:

1. **Procedural Knowledge** - features implement करने के लिए step-by-step instructions
2. **Code Templates** - production-ready code patterns और snippets
3. **Best Practices** - security, error handling और UX के लिए recommended approaches
4. **Context Awareness** - यह समझ कि अलग-अलग Dodo Payments features एक-दूसरे के साथ कैसे काम करती हैं

जब आप अपने AI assistant से किसी feature को implement करने के लिए कहते हैं, तो वह relevant skill का उपयोग करके:
- सही implementation approach समझता है
- सटीक और working code generate करता है
- Dodo Payments conventions का पालन करता है
- edge cases और errors को सही ढंग से handle करता है

<Note>
Skills [MCP Server](/developer-resources/mcp-server) और [Sentra](/developer-resources/sentra) की पूरक हैं। API operations के लिए MCP, guided integration के लिए Sentra और enhanced AI assistant capabilities के लिए Skills का उपयोग करें।
</Note>
