Dodo Payments एक built-in database sync feature प्रदान करता है, जो आपके payment data को आपके अपने database के साथ स्वचालित रूप से synchronize करता है। आप अपने data की local copy बनाए रखने के लिए **payments**, **customers**, **subscriptions**, और **licenses** को analytics, reporting या अन्य systems के साथ integration के लिए sync कर सकते हैं।

<Info>
**Implementation**: [npm package](https://www.npmjs.com/package/dodo-sync) के माध्यम से उपलब्ध | **Source Code**: [GitHub](https://github.com/dodopayments/dodo-sync)
</Info>

## आप क्या-क्या Sync कर सकते हैं?

हमारा database sync feature निम्नलिखित Dodo Payments entities को आपके database के साथ synchronize करने का support करता है:

<CardGroup cols={2}>
  <Card title="Payments" icon="credit-card">
    सभी payment transactions को sync करें, जिनमें one-time payments, refunds और payment status updates शामिल हैं।
  </Card>
  <Card title="Customers" icon="users">
    अपने customer data को sync में रखें, जिसमें customer profiles, contact information और metadata शामिल हैं।
  </Card>
  <Card title="Subscriptions" icon="repeat">
    subscription data को synchronize करें, जिसमें active subscriptions, billing cycles और subscription status changes शामिल हैं।
  </Card>
  <Card title="Licenses" icon="key">
    license information को sync करें, जिसमें license keys, activations और license status updates शामिल हैं।
  </Card>
</CardGroup>

आप इन entities के किसी भी combination को `scopes` parameter में निर्दिष्ट करके sync कर सकते हैं। सभी sync operations incremental होते हैं और बेहतर performance के लिए केवल नए या updated records transfer करते हैं।

## Database Support

हम वर्तमान में **MongoDB**, **PostgreSQL**, **MySQL**, और **ClickHouse** को support करते हैं।

हम निम्नलिखित के लिए support बढ़ाने पर सक्रिय रूप से काम कर रहे हैं:
- **Databases**: Snowflake और अन्य।
- **Pipelines**: ETL pipelines, Realtime sync।

<Tip>
हम लगातार database support का विस्तार कर रहे हैं। यदि आप कोई नया database integration contribute करना चाहते हैं, तो हमारे [GitHub repository](https://github.com/dodopayments/dodo-sync) में Pull Request submit करें।
</Tip>

## शुरुआत करना

आप हमारे database sync feature का उपयोग **CLI** के माध्यम से या अपने **code** में programmatically कर सकते हैं। दोनों methods समान functionality प्रदान करते हैं—वह method चुनें जो आपके workflow के लिए सबसे उपयुक्त हो।

### CLI का उपयोग करना

CLI tool database synchronization को set up और run करने का एक तेज़ तरीका प्रदान करता है। इसे globally install करें, ताकि आप इसे अपने terminal में कहीं से भी उपयोग कर सकें:

<CodeGroup>

```bash npm
npm install -g dodo-sync
```

```bash bun
bun add -g dodo-sync
```

</CodeGroup>

#### CLI चलाना

CLI दो modes support करता है: guided setup के लिए **Interactive Mode**, और direct configuration के लिए **Manual Mode**।

**Interactive Mode**: Interactive setup wizard शुरू करने के लिए बिना arguments के command चलाएँ।

```bash
dodo-sync
```

**Manual Mode**: Wizard को skip करने के लिए arguments सीधे pass करें।

```bash
dodo-sync -i [interval] -d [database] -u [database_uri] --scopes [scopes] --api-key [api_key] --env [environment]
```

**Examples:**

```bash
# MongoDB
dodo-sync -i 600 -d mongodb -u mongodb://mymongodb.url --scopes "licences,payments,customers,subscriptions" --api-key YOUR_API_KEY --env test_mode

# PostgreSQL
dodo-sync -i 600 -d postgres -u postgresql://user:password@localhost:5432/mydb --scopes "licences,payments,customers,subscriptions" --api-key YOUR_API_KEY --env test_mode

# MySQL
dodo-sync -i 600 -d mysql -u mysql://user:password@localhost:3306/mydb --scopes "licences,payments,customers,subscriptions" --api-key YOUR_API_KEY --env test_mode

# ClickHouse
dodo-sync -i 600 -d clickhouse -u http://localhost:8123 --scopes "licences,payments,customers,subscriptions" --api-key YOUR_API_KEY --env test_mode
```

#### CLI Arguments

<ParamField path="--interval" type="number" alias="-i">
Seconds में sync interval। यह निर्धारित करता है कि sync operation कितनी बार run होगा। यदि प्रदान नहीं किया गया, तो sync एक बार run होकर exit हो जाएगा।
</ParamField>

<ParamField path="--database" type="string" alias="-d" required>
उपयोग किया जाने वाला database type। Supported values: `"mongodb"`, `"postgres"`, `"mysql"`, या `"clickhouse"`।
</ParamField>

<ParamField path="--database-uri" type="string" alias="-u" required>
आपके database के लिए Connection URI:
- **MongoDB**: `mongodb://localhost:27017` या `mongodb+srv://user:pass@cluster.mongodb.net/`
- **PostgreSQL**: `postgresql://user:password@localhost:5432/mydb`
- **MySQL**: `mysql://user:password@localhost:3306/mydb`
- **ClickHouse**: `http://localhost:8123`
</ParamField>

<ParamField path="--scopes" type="string" required>
Sync की जाने वाली data entities की comma-separated list। उपलब्ध scopes: `licences`, `payments`, `customers`, `subscriptions`। उदाहरण: `"payments,customers"`।
</ParamField>

<ParamField path="--api-key" type="string" required>
आपकी Dodo Payments API key। Live mode के लिए इसकी शुरुआत `dp_live_` से और test mode के लिए `dp_test_` से होनी चाहिए।
</ParamField>

<ParamField path="--env" type="string" required>
Environment target। यह या तो `"live_mode"` या `"test_mode"` होना चाहिए। यह निर्धारित करता है कि किस Dodo Payments environment से sync करना है।
</ParamField>

<ParamField path="--rate-limit" type="number" alias="--rl">
Requests per second में rate limit। यह नियंत्रित करता है कि sync engine API requests कितनी तेज़ी से करता है, ताकि Dodo Payments API पर अत्यधिक load न पड़े।
</ParamField>

### अपने Code में उपयोग करना

Programmatic control के लिए sync feature को सीधे अपने application में integrate करें। इसे अपने project में dependency के रूप में install करें:

<CodeGroup>

```bash npm
npm install dodo-sync
```

```bash bun
bun add dodo-sync
```

</CodeGroup>

#### Automatic Sync (Interval-based)

जब आप sync को नियमित intervals पर लगातार run करना चाहते हैं, तब automatic sync का उपयोग करें:

```typescript
import { DodoSync } from 'dodo-sync';

const syncDodoPayments = new DodoSync({
  interval: 60, // Sync every 60 seconds
  database: 'mongodb',
  databaseURI: process.env.MONGODB_URI, // e.g., 'mongodb://localhost:27017'
  scopes: ['licences', 'payments', 'customers', 'subscriptions'],
  dodoPaymentsOptions: {
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    environment: 'test_mode' // or 'live_mode'
  }
});

// Initialize connection
await syncDodoPayments.init();

// Start the sync loop
syncDodoPayments.start();
```

<Tip>
Automatic syncing के लिए `.start()` का उपयोग करते समय `interval` option आवश्यक है। Process को stop किए जाने तक sync निर्दिष्ट interval पर लगातार run होगा।
</Tip>

#### Manual Sync

जब आप sync operations को on-demand trigger करना चाहते हैं, तब manual sync का उपयोग करें (जैसे, cron job या API endpoint से):

```typescript
import { DodoSync } from 'dodo-sync';

const syncDodoPayments = new DodoSync({
  database: 'mongodb',
  databaseURI: process.env.MONGODB_URI,
  scopes: ['licences', 'payments', 'customers', 'subscriptions'],
  dodoPaymentsOptions: {
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    environment: 'test_mode'
  }
});

// Initialize connection
await syncDodoPayments.init();

// Trigger a single sync operation
await syncDodoPayments.run();
```

<Tip>
Manual sync का उपयोग करते समय `interval` option आवश्यक नहीं है। Sync operation करने के लिए आप जब भी आवश्यकता हो, `.run()` call कर सकते हैं।
</Tip>

#### Constructor Options

<ParamField body="database" type="string" required>
उपयोग किया जाने वाला database का नाम। Supported values: `"mongodb"`, `"postgres"`, `"mysql"`, या `"clickhouse"`।
</ParamField>

<ParamField body="databaseURI" type="string" required>
आपके database के लिए Connection string:
- **MongoDB**: `mongodb://localhost:27017` या `mongodb+srv://...`
- **PostgreSQL**: `postgresql://user:password@localhost:5432/mydb`
- **MySQL**: `mysql://user:password@localhost:3306/mydb`
- **ClickHouse**: `http://localhost:8123`
</ParamField>

<ParamField body="scopes" type="string[]" required>
Sync की जाने वाली entities का array। उपलब्ध options: `"licences"`, `"payments"`, `"customers"`, `"subscriptions"`। आप इनमें से कोई भी combination शामिल कर सकते हैं।

<ParamField body="dodoPaymentsOptions" type="object" required>

## महत्वपूर्ण जानकारी

<Warning>
**MongoDB**: आपके database server पर `dodopayments_sync` नाम का database स्वचालित रूप से बनाया जाएगा। सभी sync data वहीं store किया जाएगा। यह database name वर्तमान में fixed है और इसे बदला नहीं जा सकता।

**PostgreSQL**: Tables (`Subscriptions`, `Payments`, `Licenses`, `Customers`) आपके connection URI में निर्दिष्ट database में बनाई जाएँगी। Data JSONB के रूप में store किया जाता है।

**MySQL**: Tables (`Subscriptions`, `Payments`, `Licenses`, `Customers`) आपके connection URI में निर्दिष्ट database में बनाई जाएँगी। Data JSON के रूप में store किया जाता है।

**ClickHouse**: Tables (`Subscriptions`, `Payments`, `Licenses`, `Customers`) ReplacingMergeTree engine का उपयोग करके बनाई जाएँगी। Query करते समय deduplicated results सुनिश्चित करने के लिए `FINAL` keyword का उपयोग करें।
</Warning>

<Info>
Sync engine changes को track करता है और केवल नए या updated records को sync करता है, जिससे बड़े datasets के साथ भी subsequent syncs efficient रहते हैं।
</Info>
