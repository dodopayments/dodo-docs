## अवलोकन

Dodo Payments को Expo/React Native अनुप्रयोगों में एकीकृत करने के लिए एक उत्पादन-तैयार boilerplate। इस टेम्पलेट में चेकआउट सत्र निर्माण, भुगतान प्रबंधन, और उचित TypeScript कॉन्फ़िगरेशन शामिल है ताकि आप अपने मोबाइल ऐप में जल्दी से भुगतान स्वीकार करना शुरू कर सकें।

<Info>
यह बूलरप्लेट TypeScript के साथ Expo SDK का उपयोग करता है और चेकआउट सेशन्स तथा भुगतान प्रोसेसिंग के लिए उदाहरण कार्यान्वयन शामिल करता है।
</Info>

## पूर्वापेक्षाएँ

- Node.js 18+
- Expo CLI या EAS CLI
- Dodo Payments खाता (डैशबोर्ड से API कुंजी)
- iOS सिम्युलेटर या Android एमुलेटर (या भौतिक उपकरण)

## त्वरित प्रारंभ

<Steps>
<Step title="Clone the Repository">
बूलरप्लेट रिपॉजिटरी को क्लोन करें और प्रोजेक्ट डायरेक्टरी में जाएं:

```bash
git clone https://github.com/dodopayments/expo-boilerplate.git
cd expo-boilerplate
```

</Step>

<Step title="Get Your API Credentials">
टेस्ट मोड में Dodo Payments डैशबोर्ड से अपनी क्रेडेंशियल प्राप्त करें:

- **API कुंजी**: अपने [डैशबोर्ड](https://app.dodopayments.com) में **डेवलपर → API कुंजी** पर जाएं।

<Tip>
असली भुगतान प्रोसेस किए बिना अपने एकीकरण का सुरक्षित परीक्षण करने के लिए टेस्ट मोड से शुरू करें।
</Tip>
</Step>

<Step title="Configure Environment Variables">
रूट डायरेक्टरी में `.env` फ़ाइल बनाएं:

```bash
touch .env
```

अपनी Dodo Payments क्रेडेंशियल जोड़ें:

```bash .env
EXPO_PUBLIC_DODO_API_KEY=your_test_api_key_here
```

<Warning>
अपनी `.env` फ़ाइल को कभी भी version control में commit न करें। यह पहले से ही `.gitignore` में शामिल है।
</Warning>

<Warning>
`EXPO_PUBLIC_*` variables shipped JavaScript bundle में एम्बेड किए जाते हैं और आपका app डाउनलोड करने वाला कोई भी व्यक्ति इन्हें पढ़ सकता है। Dodo Payments API keys bearer secrets होती हैं, इसलिए development के दौरान इनका उपयोग केवल Test Mode key के साथ करें। Production के लिए, अपने backend पर checkout sessions बनाएँ और app को केवल परिणामी `checkout_url` भेजें — [Mobile Integration](/developer-resources/mobile-integration) देखें।
</Warning>
</Step>

<Step title="Install Dependencies">
आवश्यक npm packages install करें:

```bash
npm install
```

</Step>

<Step title="Start the Development Server">
Expo development server शुरू करें:

```bash
npx expo start
```

अपने device पर Expo Go app से QR code scan करें, या iOS simulator के लिए `i` अथवा Android emulator के लिए `a` दबाएँ।

<Check>
अब आप building शुरू करने के लिए तैयार हैं! boilerplate में integration को समझने में सहायता करने वाली example screens और components शामिल हैं।
</Check>
</Step>
</Steps>

## Project Structure

```
expo-boilerplate/
├── app/
│   ├── (tabs)/
│   │   └── index.tsx          # Home screen with examples
│   └── checkout.tsx           # Checkout screen
├── components/
│   └── PaymentButton.tsx      # Payment button component
├── lib/
│   └── dodo.ts                # Dodo Payments client setup
├── .env.example               # Environment variables template
└── package.json
```

## अगले चरण

boilerplate चलने के बाद:

<Steps>
<Step title="Create Your Products">
checkout functionality enable करने के लिए अपने [Dodo Payments dashboard](https://app.dodopayments.com) में products जोड़ें।
</Step>

<Step title="Customize the Integration">
example code को अपने application की आवश्यकताओं और design के अनुसार ढालें।
</Step>

<Step title="Test on Real Devices">
यह सुनिश्चित करने के लिए कि सब कुछ सही ढंग से काम करता है, physical devices पर payment flow का परीक्षण करें।
</Step>

<Step title="Go Live">
तैयार होने पर, Live Mode API keys पर switch करें और production के लिए अपना app build करें।
</Step>
</Steps>

## Production के लिए Building

<Steps>
<Step title="Install EAS CLI">

```bash
npm install -g eas-cli
```

</Step>

<Step title="Configure EAS">

```bash
eas build:configure
```

</Step>

<Step title="Build Your App">
iOS के लिए:

```bash
eas build --platform ios
```

Android के लिए:

```bash
eas build --platform android
```

</Step>
</Steps>
