## अवलोकन

Next.js 15, React 19, Supabase, Drizzle ORM और Dodo Payments का उपयोग करने वाला production-ready subscription boilerplate। इसमें Google OAuth, subscription checkout, webhook handling, database schema और एक basic dashboard शामिल है।

<Info>
यदि आपको किसी मौजूदा app के लिए केवल route handlers चाहिए, तो dedicated adaptors देखें: <a href="/developer-resources/nextjs-adaptor">Next.js Adaptor</a> और <a href="/developer-resources/express-adaptor">Express Adaptor</a>।
</Info>

## आवश्यकताएँ

- Node.js 18+ (या Bun 1.0+)
- Supabase project (URL, Anon key, Service role key, Database URL)
- Dodo Payments account (API key, Webhook secret)
- Google Cloud OAuth client (Client ID और Secret)

## Quickstart

<Steps>
<Step title="Clone and install">

```bash
git clone https://github.com/dodopayments/dodo-supabase-subscription-starter.git
cd dodo-supabase-subscription-starter
# choose one
bun install
# or
npm install
# or
pnpm install
```

</Step>

<Step title="Create Supabase project">
Supabase project बनाएँ और इन्हें कॉपी करें:
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY
- SUPABASE_SERVICE_ROLE_KEY
- DATABASE_URL (Connection string)
</Step>

<Step title="Configure Google OAuth">
Google Cloud में redirect URI को `https://[your-project-ref].supabase.co/auth/v1/callback` पर सेट करें, फिर अपने Client ID और Secret का उपयोग करके Supabase Auth में Google provider सक्षम करें।
</Step>

<Step title="Configure Dodo Payments">
Dodo dashboard से API key और Webhook secret जनरेट करें। विकास के दौरान environment को `test_mode` पर सेट करें।
</Step>

<Step title="Create .env.local">

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role

# Database
DATABASE_URL=postgresql://postgres:[password]@db.[project-ref].supabase.co:5432/postgres

# Dodo Payments
DODO_PAYMENTS_API_KEY=your-dodo-api-key
DODO_WEBHOOK_SECRET=your-webhook-secret
DODO_PAYMENTS_ENVIRONMENT=test_mode
```

<Warning>
Secrets को कभी commit न करें। Deployment environments में environment variables का उपयोग करें।
</Warning>
</Step>

<Step title="Provision database schema">

```bash
bun run db:push
# or
npm run db:push
# or
pnpm run db:push
```

<Check>
बनाई गई tables: `users`, `subscriptions`, `payments`।
</Check>
</Step>

<Step title="Deploy webhook function">

```bash
# login (one-time)
bunx supabase login
# or
npx supabase login

# deploy the edge function
bun run deploy:webhook --project-ref [your-project-ref]
# or
npm run deploy:webhook -- --project-ref [your-project-ref]
# or
pnpm run deploy:webhook --project-ref [your-project-ref]
```

```bash cURL
curl -X POST \
  'https://[your-project-ref].supabase.co/functions/v1/dodo-webhook' \
  -H 'Content-Type: application/json' \
  -H 'Dodo-Signature: <signature>' \
  -d '{"type":"payment.succeeded","data":{}}'
```

</Step>

<Step title="Add webhook in Dodo Payments">
Endpoint URL को सेट करें:

```text
https://[your-project-ref].supabase.co/functions/v1/dodo-webhook
```

Payment और subscription events चुनें।
</Step>

<Step title="Create products and features">
Dodo dashboard में → Products → Create Product पर जाएँ। वैकल्पिक रूप से metadata जोड़ें:

```json
{
  "features": ["Feature 1", "Feature 2", "Feature 3"]
}
```

Pricing UI इस `features` array को पढ़ता है और इसे dynamically render करता है।
</Step>

<Step title="Run the dev server">

```bash
bun run dev
# or
npm run dev
# or
pnpm run dev
```

http://localhost:3000 खोलें।
</Step>
</Steps>

## इसमें क्या शामिल है

- Supabase के माध्यम से Authentication (Google OAuth configured)
- Dodo Payments के माध्यम से Subscription checkout
- Webhooks के लिए Supabase Edge Function (`dodo-webhook`)
- Drizzle ORM schema और migrations
- Invoices, subscription status और plan features वाला dashboard

<Tip>
End-to-end tests पूरे करने तक `DODO_PAYMENTS_ENVIRONMENT` को `test_mode` के रूप में रखें।
</Tip>

## Verification और troubleshooting

<AccordionGroup>
<Accordion title="Webhook signature invalid (401)">
- सुनिश्चित करें कि `DODO_WEBHOOK_SECRET` का मान Dodo dashboard के मान से मेल खाता है
- पुष्टि करें कि आपने नवीनतम `dodo-webhook` function deploy किया है
- अपने function में header name सही है या नहीं, जाँचें (Dodo-Signature)
</Accordion>
<Accordion title="Database push fails">
- `DATABASE_URL` syntax और Supabase network egress जाँचें
- पहले push से पहले project creation के बाद लगभग 2–3 मिनट प्रतीक्षा करें
</Accordion>
<Accordion title="OAuth redirect mismatch">
- Redirect URI `https://[ref].supabase.co/auth/v1/callback` होना चाहिए
- Google Cloud और Supabase Auth provider में भी यही सुनिश्चित करें
</Accordion>
</AccordionGroup>
