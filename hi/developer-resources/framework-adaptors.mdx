Dodo Payments आधिकारिक framework adaptors प्रदान करता है, जो payment integration को सरल बनाते हैं। प्रत्येक adaptor को आपके framework के conventions के साथ सहज रूप से काम करने के लिए डिज़ाइन किया गया है, जो checkout, customer portal और webhook handling पहले से उपलब्ध कराता है।

<Tip>
Framework adaptors आपको 10 lines से कम code में Dodo Payments integrate करने देते हैं। ये authentication, request parsing और response formatting को स्वचालित रूप से संभालते हैं।
</Tip>

## मुख्य सुविधाएँ

सभी framework adaptors ये built-in capabilities प्रदान करते हैं:

| सुविधा | विवरण |
|---------|-------------|
| **Checkout Handler** | static, dynamic और session-based checkout flows के लिए support |
| **Customer Portal** | subscription और billing management के लिए पहले से निर्मित handler |
| **Webhook Handler** | typed event handlers के साथ सुरक्षित signature verification |
| **Environment Config** | environment variables के माध्यम से आसान setup |
| **Type Safety** | typed payloads के साथ पूर्ण TypeScript support |

## त्वरित शुरुआत

तीन steps में किसी भी framework adaptor के साथ शुरुआत करें:

<Steps>
<Step title="Install the Adaptor">
  framework-specific adaptor install करने के लिए अपने package manager का उपयोग करें:

  <Tabs>
  <Tab title="Next.js">

  ```bash
  npm install @dodopayments/nextjs
  ```

  </Tab>
  
  <Tab title="Nuxt">

  ```bash
  npm install @dodopayments/nuxt
  ```

  </Tab>
  
  <Tab title="Express">

  ```bash
  npm install @dodopayments/express
  ```

  </Tab>
  
  <Tab title="Hono">

  ```bash
  npm install @dodopayments/hono
  ```

  </Tab>

  <Tab title="Astro">

  ```bash
  npm install @dodopayments/astro
  ```

  </Tab>

  <Tab title="SvelteKit">

  ```bash
  npm install @dodopayments/sveltekit
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Configure Environment Variables">
  अपने environment में अपने Dodo Payments credentials जोड़ें:

  ```env
  DODO_PAYMENTS_API_KEY=your-api-key
  DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
  DODO_PAYMENTS_RETURN_URL=https://yourdomain.com/checkout/success
  DODO_PAYMENTS_ENVIRONMENT="test_mode" # or "live_mode"
  ```

  <Warning>
  अपनी `.env` file या secrets को version control में कभी commit न करें।
  </Warning>
</Step>

<Step title="Create Route Handlers">
  अपने checkout, customer portal और webhook routes set up करें:

  <Tabs>
  <Tab title="Next.js">

  ```typescript
  // app/checkout/route.ts
  import { Checkout } from "@dodopayments/nextjs";

  export const GET = Checkout({
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
    environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  });
  ```

  </Tab>
  
  <Tab title="Express">

  ```typescript
  import { checkoutHandler } from '@dodopayments/express';

  app.get('/api/checkout', checkoutHandler({
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
    environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  }));
  ```

  </Tab>
  
  <Tab title="Hono">

  ```typescript
  import { Checkout } from "@dodopayments/hono";

  app.get('/checkout', Checkout({
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
    environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  }));
  ```

  </Tab>
  </Tabs>

  <Check>
  अब आप payments process करने के लिए तैयार हैं! विस्तृत guides और सभी उपलब्ध options के लिए individual adaptor pages पर जाएँ।
  </Check>
</Step>
</Steps>

## Checkout Flow Types

सभी adaptors तीन checkout flow types support करते हैं:

<AccordionGroup>
<Accordion title="Static Checkout (GET)">
सरल और shareable payment links के लिए static checkout का उपयोग करें। product ID को query parameter के रूप में पास करें:

```
/api/checkout?productId=pdt_xxx&quantity=1
```

query parameters के माध्यम से optional customer prefill और customization support करता है।
</Accordion>

<Accordion title="Dynamic Checkout (POST)">
custom details के साथ programmatically payments create करने के लिए dynamic checkout का उपयोग करें:

```json
{
  "product_id": "pdt_xxx",
  "customer": {
    "email": "customer@example.com",
    "name": "John Doe"
  },
  "quantity": 1
}
```

one-time payments और subscriptions, दोनों को support करता है।
</Accordion>

<Accordion title="Checkout Sessions (POST)">
cart support के साथ सबसे flexible checkout experience के लिए checkout sessions का उपयोग करें:

```json
{
  "product_cart": [
    { "product_id": "pdt_xxx", "quantity": 1 },
    { "product_id": "pdt_yyy", "quantity": 2 }
  ],
  "customer": {
    "email": "customer@example.com"
  }
}
```

[Checkout Sessions Guide](/developer-resources/checkout-session) में अधिक जानें।
</Accordion>
</AccordionGroup>

## Webhook Event Handling

सभी adaptors granular event callbacks के साथ type-safe webhook handling प्रदान करते हैं:

```typescript
Webhooks({
  webhookKey: process.env.DODO_PAYMENTS_WEBHOOK_KEY,
  onPayload: async (payload) => {
    // Handle any webhook event
  },
  onPaymentSucceeded: async (payload) => {
    // Handle successful payments
  },
  onSubscriptionActive: async (payload) => {
    // Handle new subscriptions
  },
  // ... 20+ event types supported
});
```

<Info>
सभी webhook handlers Zod schemas का उपयोग करके signatures को स्वचालित रूप से verify और payloads को validate करते हैं। Invalid requests को उचित error codes के साथ reject कर दिया जाता है।
</Info>

## सही Adaptor चुनना

| Framework | Best For | Runtime |
|-----------|----------|---------|
| **Next.js** | App Router के साथ full-stack React apps | Node.js, Edge |
| **Nuxt** | Full-stack Vue.js applications | Node.js |
| **Express** | REST APIs और traditional Node.js apps | Node.js |
| **Fastify** | High-performance APIs | Node.js |
| **Hono** | Edge deployments, Cloudflare Workers | Edge, Node.js |
| **Astro** | Server endpoints वाली content sites | Node.js, Edge |
| **SvelteKit** | Full-stack Svelte applications | Node.js |
| **Remix** | Nested routing वाला full-stack React | Node.js |
| **TanStack Start** | Type-safe full-stack React | Node.js |
| **Better Auth** | पहले से Better Auth का उपयोग करने वाले apps | Various |
| **Convex** | Backend के लिए Convex का उपयोग करने वाले apps | Convex Runtime |
| **Bun** | Native Bun server applications | Bun |
