डोडो पेमेंट्स आधिकारिक फ्रेमवर्क अडॉप्टर्स प्रदान करता है जो भुगतान एकीकरण को सरल बनाते हैं। प्रत्येक अडॉप्टर आपके फ्रेमवर्क की परंपराओं के साथ सहजता से काम करने के लिए डिज़ाइन किया गया है, जो चेकआउट, ग्राहक पोर्टल और वेबहुक हैंडलिंग को बॉक्स से बाहर प्रदान करता है।

<Tip>
फ्रेमवर्क अडॉप्टर्स आपको 10 लाइनों से कम कोड में डोडो पेमेंट्स को एकीकृत करने की अनुमति देते हैं। वे स्वचालित रूप से प्रमाणीकरण, अनुरोध पार्सिंग और प्रतिक्रिया स्वरूपण को संभालते हैं।
</Tip>

## मुख्य विशेषताएँ

सभी फ्रेमवर्क एडेप्टर इन अंतर्निर्मित क्षमताओं को प्रदान करते हैं:

| विशेषता | विवरण |
|---------|-------------|
| **चेकआउट हैंडलर** | स्थिर, गतिशील, और सत्र-आधारित चेकआउट प्रवाह के लिए समर्थन |
| **ग्राहक पोर्टल** | सब्सक्रिप्शन और बिल भुगतान प्रबंधन के लिए पूर्व-निर्मित हैंडलर |
| **वेबहुक हैंडलर** | टाइप किए गए ईवेंट हैंडलरों के साथ सुरक्षित हस्ताक्षर सत्यापन |
| **पर्यावरण कॉन्फिग** | पर्यावरण चर के माध्यम से सरल सेटअप |
| **टाइप सुरक्षा** | टाइप किए गए पेलोड के साथ पूर्ण TypeScript समर्थन |

## त्वरित शुरुआत

किसी भी फ्रेमवर्क एडेप्टर के साथ तीन चरणों में शुरू करें:

<Steps>
<Step title="एडेप्टर स्थापित करें">
  अपने पैकेज प्रबंधक का उपयोग करके फ्रेमवर्क-विशिष्ट एडेप्टर स्थापित करें:

  <Tabs>
  <Tab title="Next.js">

  ```bash
  npm install @dodopayments/nextjs
  ```

  </Tab>
  
  <Tab title="Nuxt">

  ```bash
  npm install @dodopayments/nuxt
  ```

  </Tab>
  
  <Tab title="Express">

  ```bash
  npm install @dodopayments/express
  ```

  </Tab>
  
  <Tab title="Hono">

  ```bash
  npm install @dodopayments/hono
  ```

  </Tab>

  <Tab title="Astro">

  ```bash
  npm install @dodopayments/astro
  ```

  </Tab>

  <Tab title="SvelteKit">

  ```bash
  npm install @dodopayments/sveltekit
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="पर्यावरण चर कॉन्फ़िगर करें">
  अपने Dodo Payments क्रेडेंशियल्स को अपने वातावरण में जोड़ें:

  ```env
  DODO_PAYMENTS_API_KEY=your-api-key
  DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
  DODO_PAYMENTS_RETURN_URL=https://yourdomain.com/checkout/success
  DODO_PAYMENTS_ENVIRONMENT="test_mode" # or "live_mode"
  ```

  <Warning>
  अपने `.env` फ़ाइल या सीक्रेट्स को संस्करण नियंत्रण में कभी भी कमिट न करें।
  </Warning>
</Step>

<Step title="रूट हैंडलर्स बनाएं">
  अपने चेकआउट, ग्राहक पोर्टल, और वेबहुक रूट सेटअप करें:

  <Tabs>
  <Tab title="Next.js">

  ```typescript
  // app/checkout/route.ts
  import { Checkout } from "@dodopayments/nextjs";

  export const GET = Checkout({
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
    environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  });
  ```

  </Tab>
  
  <Tab title="Express">

  ```typescript
  import { checkoutHandler } from '@dodopayments/express';

  app.get('/api/checkout', checkoutHandler({
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
    environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  }));
  ```

  </Tab>
  
  <Tab title="Hono">

  ```typescript
  import { Checkout } from "@dodopayments/hono";

  app.get('/checkout', Checkout({
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
    environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  }));
  ```

  </Tab>
  </Tabs>

  <Check>
  आप अब भुगतान संसाधित करने के लिए तैयार हैं! विस्तृत गाइड और सभी उपलब्ध विकल्पों के लिए व्यक्तिगत एडेप्टर पन्नों पर जाएं।
  </Check>
</Step>
</Steps>

## चेकआउट फ्लो प्रकार

सभी एडेप्टर तीन चेकआउट फ्लो प्रकारों का समर्थन करते हैं:

<AccordionGroup>
<Accordion title="स्टैटिक चेकआउट (GET)">
सरल, साझा किए जाने योग्य भुगतान लिंक के लिए स्टैटिक चेकआउट का उपयोग करें। उत्पाद आईडी को क्वेरी पैरामीटर के रूप में पास करें:

```
/api/checkout?productId=pdt_xxx&quantity=1
```

वैकल्पिक ग्राहक प्रीफिल और क्वेरी पैरामीटर के माध्यम से अनुकूलन का समर्थन करता है।
</Accordion>

<Accordion title="डायनामिक चेकआउट (POST)">
कस्टम विवरण के साथ भुगतान बनाने के लिए डायनामिक चेकआउट का उपयोग करें:

```json
{
  "product_id": "pdt_xxx",
  "customer": {
    "email": "customer@example.com",
    "name": "John Doe"
  },
  "quantity": 1
}
```

एक बार के भुगतानों और सब्सक्रिप्शनों का समर्थन करता है।
</Accordion>

<Accordion title="चेकआउट सत्र (POST)">
कार्ट समर्थन के साथ सबसे लचीले चेकआउट अनुभव के लिए चेकआउट सत्र का उपयोग करें:

```json
{
  "product_cart": [
    { "product_id": "pdt_xxx", "quantity": 1 },
    { "product_id": "pdt_yyy", "quantity": 2 }
  ],
  "customer": {
    "email": "customer@example.com"
  }
}
```

[Checkout Sessions Guide](/developer-resources/checkout-session) में अधिक जानें।
</Accordion>
</AccordionGroup>

## वेबहुक इवेंट हैंडलिंग

सभी एडेप्टर ग्रैन्युलर ईवेंट कॉलबैक के साथ टाइप-सेफ वेबहुक हैंडलिंग प्रदान करते हैं:

```typescript
Webhooks({
  webhookKey: process.env.DODO_PAYMENTS_WEBHOOK_KEY,
  onPayload: async (payload) => {
    // Handle any webhook event
  },
  onPaymentSucceeded: async (payload) => {
    // Handle successful payments
  },
  onSubscriptionActive: async (payload) => {
    // Handle new subscriptions
  },
  // ... 20+ event types supported
});
```

<Info>
सभी वेबहुक हैंडलर स्वचालित रूप से हस्ताक्षर सत्यापित करते हैं और Zod स्कीमाओं का उपयोग करके पेलोड को मान्य करते हैं। अवैध अनुरोधों को उपयुक्त त्रुटि कोड के साथ अस्वीकृत किया जाता है।
</Info>

## सही एडेप्टर का चयन करना

| फ्रेमवर्क | सबसे अच्छा है | रनटाइम |
|-----------|----------|---------|
| **Next.js** | ऐप राउटर के साथ पूर्ण-स्टैक React ऐप | Node.js, Edge |
| **Nuxt** | पूर्ण-स्टैक Vue.js अनुप्रयोग | Node.js |
| **Express** | REST API और पारंपरिक Node.js ऐप | Node.js |
| **Fastify** | उच्च प्रदर्शन APIs | Node.js |
| **Hono** | Edge परिनियोजन, Cloudflare Workers | Edge, Node.js |
| **Astro** | सर्वर एंडपॉइंट के साथ सामग्री साइटें | Node.js, Edge |
| **SvelteKit** | पूर्ण-स्टैक Svelte अनुप्रयोग | Node.js |
| **Remix** | नेस्टेड राउटिंग के साथ पूर्ण-स्टैक React | Node.js |
| **TanStack Start** | टाइप-सेफ पूर्ण-स्टैक React | Node.js |
| **Better Auth** | Better Auth का उपयोग करने वाले ऐप | विभिन्न |
| **Convex** | बैकएंड के लिए Convex का उपयोग करने वाले ऐप | Convex Runtime |
| **Bun** | नेटिव Bun सर्वर अनुप्रयोग | Bun |
