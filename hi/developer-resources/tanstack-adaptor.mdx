## स्थापना

<Steps>
<Step title="Install the package">
अपने प्रोजेक्ट रूट में निम्नलिखित कमांड चलाएँ:

```bash
npm install @dodopayments/tanstack
```

</Step>
<Step title="Set up environment variables">
अपने प्रोजेक्ट रूट में <code>.env</code> फ़ाइल बनाएँ:

```env expandable
DODO_PAYMENTS_API_KEY=your-api-key
DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
DODO_PAYMENTS_RETURN_URL=your-return-url
DODO_PAYMENTS_ENVIRONMENT="test_mode" or "live_mode"
```

<Warning>
अपनी <code>.env</code> फ़ाइल या रहस्य संस्करण नियंत्रण में कभी कमिट न करें।
</Warning>
</Step>
</Steps>

    import { Checkout } from "@dodopayments/tanstack";
    import { createServerFileRoute } from "@tanstack/react-start/server";

    export const ServerRoute = createServerFileRoute("/api/checkout")
    .methods({
        GET: async ({ request }) => {
        return Checkout({

            returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
            environment: process.env.DODO_PAYMENTS_ENVIRONMENT,

        }
    })
  
    ```

## चेकआउट रूट हैंडलर

<Info>
Dodo Payments आपकी वेबसाइट में भुगतान को एकीकृत करने के लिए तीन प्रकार के भुगतान फ्लो का समर्थन करता है, यह एडेप्टर सभी प्रकार के भुगतान फ्लो का समर्थन करता है।
</Info>

- **स्थिर भुगतान लिंक:** त्वरित, बिना कोड के भुगतान संग्रह के लिए तुरंत साझा करने योग्य URL।
- **गतिशील भुगतान लिंक:** API या SDKs का उपयोग करके कस्टम विवरण के साथ प्रोग्रामेटिक रूप से भुगतान लिंक उत्पन्न करें।
- **चेकआउट सत्र:** पूर्व-निर्धारित उत्पाद कार्ट और ग्राहक विवरण के साथ सुरक्षित, अनुकूलन योग्य चेकआउट अनुभव बनाएं।

  - [एक बार के भुगतान उत्पाद के लिए अनुरोध बॉडी](https://docs.dodopayments.com/api-reference/payments/post-payments)

</Warning>

```

```json

  "checkout_url": "https://checkout.dodopayments.com/session/..."
}
```

## Customer Portal Route Handler

Customer Portal Route Handler आपको Dodo Payments customer portal को अपने Tanstack application में सहज रूप से integrate करने की सुविधा देता है।

### Query Parameters
<ParamField query="customer_id" type="string" required>
portal session के लिए customer ID (उदाहरण के लिए, <code>?customer_id=cus_123</code>)।
</ParamField>
<ParamField query="send_email" type="boolean">
यदि इसे <code>true</code> पर सेट किया जाता है, तो customer को portal link वाला email भेजा जाता है।
</ParamField>

<Warning>
यदि <code>customer_id</code> अनुपस्थित है, तो 400 लौटाता है।
</Warning>

## Webhook Route Handler

- **Method:** केवल POST requests समर्थित हैं। अन्य methods 405 लौटाते हैं।
- **Signature Verification:** <code>webhookKey</code> का उपयोग करके webhook signature verify करता है। Verification विफल होने पर 401 लौटाता है।
- **Payload Validation:** Zod से validated होता है। Invalid payloads के लिए 400 लौटाता है।
- **Error Handling:**
  - 401: Invalid signature
  - 400: Invalid payload
  - 500: Verification के दौरान internal error
- **Event Routing:** Payload type के आधार पर उपयुक्त event handler को call करता है।
