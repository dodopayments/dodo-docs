## अवलोकन

Go boilerplate आपके Go backend के साथ Dodo Payments को integrate करने के लिए production-ready शुरुआती आधार प्रदान करता है। इस template में checkout session handling, webhook verification, customer portal integration शामिल हैं और यह Go best practices का पालन करता है, ताकि आप जल्दी से payments स्वीकार करना शुरू कर सकें।

<Info>
यह boilerplate clean architecture patterns (`cmd`, `internal`, `templates`), HTML templates और seamless API integration के लिए `dodopayments-go` SDK के साथ Go 1.21+ का उपयोग करता है।
</Info>

### सुविधाएँ

- **त्वरित Setup** - 5 मिनट से कम समय में शुरुआत करें
- **Payment Integration** - `dodopayments-go` SDK का उपयोग करने वाला pre-configured checkout flow
- **आधुनिक UI** - HTML templates के साथ clean, dark-themed pricing page
- **Webhook Handling** - payment events को सुरक्षित रूप से verify और process करें
- **Customer Portal** - Self-serve subscription management
- **Go Best Practices** - `cmd`, `internal` और `templates` के साथ clean architecture
- **Pre-filled Checkout** - बेहतर UX के लिए customer data पास करने का प्रदर्शन

## आवश्यकताएँ

शुरू करने से पहले सुनिश्चित करें कि आपके पास ये हैं:

- **Go 1.21+**
- **Dodo Payments account** (dashboard से API और Webhook Keys access करने के लिए)

## Quick Start

<Steps>
<Step title="Clone the Repository">

```bash
git clone https://github.com/dodopayments/go-boilerplate.git
cd go-boilerplate
```

</Step>

<Step title="Install Dependencies">

```bash
make install
```

या manually:

```bash
go mod download
```

</Step>

<Step title="Get API Credentials">
[Dodo Payments](https://dodopayments.com/) पर sign up करें और dashboard से अपने credentials प्राप्त करें:

- **API Key:** [Dashboard → Developer → API Keys](https://app.dodopayments.com/developer/api-keys)
- **Webhook Key:** [Dashboard → Developer → Webhooks](https://app.dodopayments.com/developer/webhooks)

<Tip>
Development के दौरान सुनिश्चित करें कि आप **Test Mode** में हैं!
</Tip>
</Step>

<Step title="Configure Environment Variables">
Root directory में एक `.env` file बनाएँ:

```bash
cp .env.example .env
```

अपने Dodo Payments credentials के साथ values update करें:

```bash .env
DODO_PAYMENTS_API_KEY=your_api_key_here
DODO_PAYMENTS_WEBHOOK_KEY=your_webhook_signing_key_here
DODO_PAYMENTS_RETURN_URL=http://localhost:8000
DODO_PAYMENTS_ENVIRONMENT=test_mode
```

<Warning>
अपने `.env` file को version control में कभी commit न करें। यह पहले से ही `.gitignore` में शामिल है।
</Warning>
</Step>

<Step title="Add Your Products">
`internal/lib/products.go` को Dodo Payments से प्राप्त वास्तविक product IDs के साथ update करें:

```go
var Products = []Product{
    {
        ProductID:   "pdt_001", // Replace with your product ID
        Name:        "Basic Plan",
        Description: "Get access to basic features and support",
        Price:       9999, // in cents
        Features: []string{
            "Access to basic features",
            "Email support",
            "1 Team member",
            "Basic analytics",
        },
    },
    // ... add more products
}
```

</Step>

<Step title="Run the Development Server">

```bash
make run
```

या manually:

```bash
go run cmd/server/main.go
```

अपना pricing page देखने के लिए [http://localhost:8000](http://localhost:8000) खोलें!

<Check>
आपको अपने products के purchase के लिए तैयार एक dark-themed pricing page दिखाई देना चाहिए।
</Check>
</Step>
</Steps>

## Project Structure

```text
go-boilerplate/
├── cmd/
│   └── server/             # Application entry point
├── internal/
│   ├── api/                # API handlers (Checkout, Portal, Webhook)
│   ├── core/               # Configuration and system core
│   └── lib/                # Shared logic (Products, Customer utils)
├── templates/              # HTML templates
├── Makefile                # Build and run commands
├── go.mod                  # Go module definition
├── go.sum                  # Dependency checksums
├── .env.example            # Environment template
└── README.md
```

## API Endpoints

Boilerplate में निम्नलिखित pre-configured endpoints शामिल हैं:

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/` | GET | product listing वाला pricing page |
| `/api/checkout` | POST | नया checkout session बनाएँ |
| `/api/webhook` | POST | Dodo Payments webhooks handle करें |
| `/api/customer-portal` | POST | customer portal URL generate करें |

## Customization

### Product Information update करें

`internal/lib/products.go` को edit करके ये modify करें:
- Product IDs (अपने Dodo dashboard से)
- Pricing
- Features
- Descriptions

```go
var Products = []Product{
    {
        ProductID:   "pdt_001", // Replace with your product ID
        Name:        "Basic Plan",
        Description: "Get access to basic features and support",
        Price:       9999,
        Features: []string{
            "Access to basic features",
            "Email support",
            "1 Team member",
            "Basic analytics",
        },
    },
}
```

### Customer Data पहले से भरें

`templates/index.html` में hardcoded customer data को अपने वास्तविक user data से replace करें:

```javascript
const customerData = {
    name: "John Doe",       // Replace with actual logged-in user's name
    email: "john@example.com"  // Replace with actual logged-in user's email
};
```

Production app में आप अपने authentication system से इन values को dynamically inject करेंगे।

## Webhook Events

Boilerplate `internal/api/webhook.go` में webhook events को handle करने का प्रदर्शन करता है। Supported events में शामिल हैं:

| Event | Description |
|-------|-------------|
| `subscription.active` | subscription active होने पर trigger होता है |
| `payment.succeeded` | payment successful होने पर trigger होता है |

Webhook handler के अंदर अपनी business logic जोड़ें ताकि:
- अपने database में user permissions update करें
- confirmation emails भेजें
- digital products का access provision करें
- analytics और metrics track करें

## Webhooks को Locally Test करना

Local development के लिए अपने local server को expose करने हेतु [ngrok](https://ngrok.com/) जैसे tools का उपयोग करें:

```bash
ngrok http 8000
```

अपने [Dodo Payments Dashboard](https://app.dodopayments.com/developer/webhooks) में webhook URL update करें:

```
https://your-ngrok-url.ngrok.io/api/webhook
```

## Deployment

### Production के लिए Build करें

```bash
make build
```

या manually:

```bash
go build -o bin/server cmd/server/main.go
./bin/server
```

### Vercel पर Deploy करें

[

![Deploy with Vercel](https://vercel.com/button)

](https://vercel.com/new/clone?repository-url=https://github.com/dodopayments/go-boilerplate)

### Docker

एक `Dockerfile` बनाएँ:

```dockerfile
FROM golang:1.21-alpine AS builder

WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download

COPY . .
RUN go build -o bin/server cmd/server/main.go

FROM alpine:latest
WORKDIR /app
COPY --from=builder /app/bin/server .
COPY --from=builder /app/templates ./templates

EXPOSE 8000
CMD ["./server"]
```

Build और run करें:

```bash
docker build -t go-dodo .
docker run -p 8000:8000 --env-file .env go-dodo
```

### Production संबंधी विचार

<Warning>
Production पर deploy करने से पहले:
- `DODO_PAYMENTS_ENVIRONMENT` को `live_mode` में switch करें
- Dashboard से production API keys का उपयोग करें
- Webhook URL को अपने production domain पर update करें
- सभी endpoints के लिए HTTPS enable करें
</Warning>

## Troubleshooting

<AccordionGroup>
<Accordion title="Build errors or missing dependencies">
सुनिश्चित करें कि Go modules ठीक से download किए गए हैं:

```bash
go mod tidy
go mod download
```

</Accordion>

<Accordion title="Checkout session creation fails">
**सामान्य कारण:**
- Invalid product ID - verify करें कि यह आपके Dodo dashboard में मौजूद है
- `.env` में गलत API key या environment setting
- Detailed error messages के लिए server logs देखें
</Accordion>

<Accordion title="Webhooks not receiving events">
Local testing के लिए अपने server को expose करने हेतु [ngrok](https://ngrok.com) का उपयोग करें:

```bash
ngrok http 8000
```

अपने [Dodo dashboard](https://app.dodopayments.com/developer/webhooks) में webhook URL को ngrok URL पर update करें। अपने `.env` file को सही webhook verification key के साथ update करना सुनिश्चित करें।
</Accordion>

<Accordion title="Templates not loading">
सुनिश्चित करें कि आप server को project root directory से चला रहे हैं या आपके code में templates path सही तरीके से configured है।
</Accordion>
</AccordionGroup>
