## स्थापना

<Steps>
<Step title="Install the package">
अपने प्रोजेक्ट रूट में निम्न कमांड चलाएं:

```bash
npm install @dodopayments/sveltekit
```

</Step>
<Step title="Set up environment variables">
अपने प्रोजेक्ट रूट में <code>.env</code> फ़ाइल बनाएँ:

```env expandable
DODO_PAYMENTS_API_KEY=your-api-key
DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
DODO_PAYMENTS_ENVIRONMENT="test_mode" or "live_mode"
DODO_PAYMENTS_RETURN_URL=https://yourdomain.com/checkout/success
```

<Warning>
अपनी <code>.env</code> फ़ाइल या गुप्त जानकारियाँ version control में कभी कमिट न करें.
</Warning>
</Step>
</Steps>

<Tabs>
<Tab title="Checkout Handler">
  <Info>
  इस हैंडलर का उपयोग अपने SvelteKit ऐप में Dodo Payments चेकआउट को एकीकृत करने के लिए करें। यह static (GET), dynamic (POST), और session (POST) भुगतान फ्लो का समर्थन करता है।
  </Info>
  <CodeGroup>

    ```typescript SvelteKit Route Handler expandable
    // src/routes/api/checkout/+server.ts
    import { Checkout } from "@dodopayments/sveltekit";
    import { DODO_PAYMENTS_API_KEY, DODO_PAYMENTS_RETURN_URL, DODO_PAYMENTS_ENVIRONMENT } from '$env/static/private';

    const checkoutGetHandler = Checkout({
        bearerToken: DODO_PAYMENTS_API_KEY,
        returnUrl: DODO_PAYMENTS_RETURN_URL,
        environment: DODO_PAYMENTS_ENVIRONMENT,
        type: "static",
    });

    const checkoutPostHandler = Checkout({
        bearerToken: DODO_PAYMENTS_API_KEY,
        returnUrl: DODO_PAYMENTS_RETURN_URL,
        environment: DODO_PAYMENTS_ENVIRONMENT,
        type: "session", // or "dynamic" for dynamic link
    });

    export const GET = checkoutGetHandler.GET;
    export const POST = checkoutPostHandler.POST;
    ```

  </CodeGroup>

## चेकआउट रूट हैंडलर

<Info>
Dodo Payments आपके वेबसाइट में भुगतान एकीकृत करने के लिए तीन प्रकार के भुगतान फ्लो का समर्थन करता है, यह एडाप्टर सभी प्रकार के भुगतान फ्लो का समर्थन करता है.
</Info>

- **स्थिर भुगतान लिंक:** त्वरित, बिना कोड के भुगतान संग्रह के लिए तुरंत साझा करने योग्य URL।
- **गतिशील भुगतान लिंक:** API या SDKs का उपयोग करके कस्टम विवरण के साथ प्रोग्रामेटिक रूप से भुगतान लिंक उत्पन्न करें।
- **चेकआउट सत्र:** पूर्व-निर्धारित उत्पाद कार्ट और ग्राहक विवरण के साथ सुरक्षित, अनुकूलन योग्य चेकआउट अनुभव बनाएं।

<Accordion title="Dynamic Checkout (POST)">

  - [Request body for a One Time Payment Product](https://docs.dodopayments.com/api-reference/payments/post-payments)

अधिक जानकारी और supported fields की पूरी सूची के लिए [Checkout Sessions Integration Guide](https://docs.dodopayments.com/developer-resources/checkout-session) देखें।

### Response Format
Checkout sessions checkout URL के साथ JSON response लौटाते हैं:

```json
{
  "checkout_url": "https://checkout.dodopayments.com/session/..."
}
```

</Accordion>

## Customer Portal Route Handler

Customer Portal Route Handler आपको अपने SvelteKit application में Dodo Payments customer portal को सहज रूप से integrate करने की सुविधा देता है।

### Query Parameters
<ParamField query="customer_id" type="string" required>
portal session के लिए customer ID (उदाहरण के लिए, <code>?customer_id=cus_123</code>)।
</ParamField>
<ParamField query="send_email" type="boolean">
यदि इसे <code>true</code> पर सेट किया जाता है, तो customer को portal link वाला email भेजा जाता है।
</ParamField>

<Warning>
यदि <code>customer_id</code> अनुपस्थित है, तो 400 लौटाता है।
</Warning>

## Webhook Route Handler

- **Method:** केवल POST requests supported हैं। अन्य methods 405 लौटाते हैं।
- **Signature Verification:** <code>webhookKey</code> का उपयोग करके webhook signature verify करता है। Verification विफल होने पर 401 लौटाता है।
- **Payload Validation:** Zod के साथ validate किया जाता है। Invalid payloads के लिए 400 लौटाता है।
- **Error Handling:**
  - 401: Invalid signature
  - 400: Invalid payload
  - 500: Verification के दौरान internal error
- **Event Routing:** Payload type के आधार पर उपयुक्त event handler को call करता है।
