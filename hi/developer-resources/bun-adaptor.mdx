## इंस्टॉलेशन

<Steps>
<Step title="पैकेज स्थापित करें">
अपने प्रोजेक्ट रूट में निम्नलिखित कमांड चलाएँ:

```bash
bun add @dodopayments/bun
```

</Step>
<Step title="पर्यावरण चर सेट करें">
अपने प्रोजेक्ट रूट में एक <code>.env</code> फ़ाइल बनाएँ:

```env expandable
DODO_PAYMENTS_API_KEY=your-api-key
DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
DODO_PAYMENTS_ENVIRONMENT="test_mode" or "live_mode"
DODO_PAYMENTS_RETURN_URL=your-return-url
```

<Warning>
कभी भी अपने <code>.env</code> फ़ाइल या गोपनीयताओं को संस्करण नियंत्रण में सम्मिलित न करें।
</Warning>
</Step>
</Steps>

## रूट हैंडलर उदाहरण

<Info>
सभी उदाहरण मानते हैं कि आप बन के मूल सर्वर का उपयोग कर रहे हैं <code>Bun.serve()</code>।
</Info>

<Tabs>
<Tab title="चेकआउट हैंडलर">
  <Info>
  इस हैंडलर का उपयोग डोडो पेमेंट्स चेकआउट को अपने बन सर्वर में एकीकृत करने के लिए करें। स्थैतिक (GET), गतिशील (POST), और सत्र (POST) भुगतान प्रवाह का समर्थन करता है।
  </Info>
  <CodeGroup>

    ```typescript Bun Server Handler expandable
    import { Checkout } from '@dodopayments/bun';

    const staticCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "static"
    });

    const sessionCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "session"
    });

    const dynamicCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "dynamic"
    });

    Bun.serve({
      port: 3000,
      fetch(request) {
        const url = new URL(request.url);
        
        if (url.pathname === "/api/checkout") {
          if (request.method === "GET") {
            return staticCheckoutHandler(request);
          }
          if (request.method === "POST") {
            return sessionCheckoutHandler(request);
            // or return dynamicCheckoutHandler(request);
          }
        }
        
        return new Response("Not Found", { status: 404 });
      },
    });
    ```

  </CodeGroup>
  <CodeGroup>

  ```curl Static Checkout Curl example expandable
  curl --request GET \
  --url 'https://example.com/api/checkout?productId=pdt_xxx' \
  --header 'User-Agent: insomnia/11.2.0' \
  --cookie mode=test
  ```

  </CodeGroup>
  <CodeGroup>

  ```curl Dynamic Checkout Curl example expandable

	"billing_currency": "USD",
	"discount_code": "IKHZ23M9GQ",

	"trial_period_days": 10
}'
  ```

  </CodeGroup>
  <CodeGroup>

    Bun.serve({
      port: 3000,
      fetch(request) {
        const url = new URL(request.url);
        
        if (url.pathname === "/api/customer-portal" && request.method === "GET") {
          return customerPortalHandler(request);

        return new Response("Not Found", { status: 404 });
      },
    });
    ```

## चेकआउट रूट हैंडलर

<Info>
डोडो पेमेंट्स आपकी वेबसाइट में भुगतान एकीकृत करने के लिए तीन प्रकार के भुगतान प्रवाह का समर्थन करता है, यह एडाप्टर सभी प्रकार के भुगतान प्रवाह का समर्थन करता है।
</Info>

- **स्थैतिक भुगतान लिंक:** त्वरित, नो-कोड भुगतान संग्रह के लिए साझा करने योग्य यूआरएल।
- **गतिशील भुगतान लिंक:** API या SDK का उपयोग करके कस्टम विवरणों के साथ भुगतान लिंक प्रोग्रामेटिक रूप से उत्पन्न करें।
- **चेकआउट सत्र:** पूर्व-कॉन्फ़िगर किए गए उत्पाद कार्ट और ग्राहक विवरणों के साथ सुरक्षित, अनुकूलन योग्य चेकआउट अनुभव बनाएँ।

## ग्राहक पोर्टल रूट हैंडलर

ग्राहक पोर्टल रूट हैंडलर आपको अपने बन सर्वर एप्लिकेशन में डोडो पेमेंट्स ग्राहक पोर्टल को सहजता से एकीकृत करने की अनुमति देता है।

### क्वेरी पैरामीटर
<ParamField query="customer_id" type="string" required>
पोर्टल सत्र के लिए ग्राहक ID (जैसे, <code>?customer_id=cus_123</code>).
</ParamField>
<ParamField query="send_email" type="boolean">
यदि <code>true</code> पर सेट किया गया है, तो ग्राहक को पोर्टल लिंक के साथ एक ईमेल भेजता है।
</ParamField>

<Warning>
यदि <code>customer_id</code> गायब है तो 400 उत्तर देता है।
</Warning>

## वेबहूक रूट हैंडलर

- **पद्धति:** केवल POST अनुरोध स्वीकार किए जाते हैं। अन्य विधियाँ 405 लौटाती हैं।
- **हस्ताक्षर सत्यापन:** <code>webhookKey</code> का उपयोग करके वेबहूक हस्ताक्षर की पुष्टि करता है। सत्यापन विफल होने पर 401 लौटता है।
- **पेलोड वैलिडेशन:** Zod के साथ मान्य। अमान्य पेलोड के लिए 400 लौटाता है।
- **त्रुटि प्रबंधन:**
  - 401: अमान्य हस्ताक्षर
  - 400: अमान्य पेलोड
  - 500: सत्यापन के दौरान आंतरिक त्रुटि
- **इवेंट राउटिंग:** पेलोड प्रकार के आधार पर उचित इवेंट हैंडलर को कॉल करता है।

If the user wants to integrate all three functionalities, provide a complete Bun server example that combines all handlers.

```

typescript
import { Checkout, CustomerPortal, Webhooks } from "@dodopayments/bun";

const staticCheckoutHandler = Checkout({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  type: "static",
});

const sessionCheckoutHandler = Checkout({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  type: "session",
});

const customerPortalHandler = CustomerPortal({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
});

const webhookHandler = Webhooks({
  webhookKey: process.env.DODO_PAYMENTS_WEBHOOK_KEY,
  onPaymentSucceeded: async (payload) => {
    console.log("भुगतान सफल:", payload);
    // यहाँ अपनी व्यावसायिक लॉजिक लिखें
  },
  onSubscriptionActive: async (payload) => {
    console.log("सदस्यता सक्रिय:", payload);
    // यहाँ अपनी व्यावसायिक लॉजिक लिखें
  },
});

Bun.serve({
  port: 3000,
  fetch(request) {
    const url = new URL(request.url);
    
    // चेकआउट रूट
    if (url.pathname === "/api/checkout") {
      if (request.method === "GET") {
        return staticCheckoutHandler(request);
      }
      if (request.method === "POST") {
        return sessionCheckoutHandler(request);
      }
    }
    
    // ग्राहक पोर्टल रूट
    if (url.pathname === "/api/customer-portal" && request.method === "GET") {
      return customerPortalHandler(request);
    }
    
    // वेबहूक रूट
    if (url.pathname === "/api/webhook/dodo-payments" && request.method === "POST") {
      return webhookHandler(request);
    }
    
    return new Response("नहीं मिला", { status: 404 });
  },
});

console.log("सर्वर http://localhost:3000 पर चल रहा है");

अधिक मार्गदर्शन:
• समझाएँ कि हैंडलर बुन मूल हैं और Bun.serve() के साथ आसानी से काम करते हैं
• वेब मानक अनुरोध और प्रतिक्रिया वस्तुओं के उपयोग पर प्रकाश डालें
• उल्लेख करें कि त्रुटि प्रबंधन पूर्वनिर्धारित है और उचित HTTP स्थिति कोड लौटाता है
• अधिक जानकारी के लिए डोडो पेमेंट्स दस्तावेज़ों के लिए लिंक प्रदान करें
```
