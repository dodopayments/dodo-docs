## सदस्यता वेबहुक घटनाएँ

सदस्यता जीवनचक्र परिवर्तनों को ट्रैक करने के लिए निम्नलिखित वेबहुक घटनाएँ उपलब्ध हैं:

| इवेंट | विवरण |
|-------|-------------|
| `subscription.active` | सदस्यता सफलतापूर्वक सक्रिय की गई |
| `subscription.updated` | सदस्यता वस्तु को अपडेट किया गया (किसी भी क्षेत्र में बदलाव इस इवेंट को उत्तेजित करता है) |
| `subscription.on_hold` | सदस्यता को नवीनीकरण में विफलता के कारण होल्ड पर रखा गया |
| `subscription.renewed` | सदस्यता अगले बिलिंग अवधि के लिए नवीनीकरण किया गया |
| `subscription.plan_changed` | सदस्यता योजना को अपग्रेड, डाउनग्रेड या संशोधित किया गया |
| `subscription.cancelled` | सदस्यता समाप्त कर दी गई |
| `subscription.failed` | जनादेश निर्माण के दौरान सदस्यता निर्माण विफल हुआ |
| `subscription.expired` | सदस्यता ने अपनी अवधि के अंत तक पहुँच गई |

### `subscription.updated` का उपयोग वास्तविक-समय समन्वय के लिए

`subscription.updated` वेबहुक तब चलेगा जब कोई भी सदस्यता क्षेत्र बदलता है, जिससे आप अपनी एप्लिकेशन स्थिति को समन्वयित रख सकते हैं बिना पोलिंग किए:

```javascript
app.post('/webhooks/dodo', async (req, res) => {
  const event = req.body;
  
  if (event.type === 'subscription.updated') {
    const subscription = event.data;
    
    // Sync subscription changes to your database
    await syncSubscription(subscription.subscription_id, {
      status: subscription.status,
      next_billing_date: subscription.next_billing_date,
      metadata: subscription.metadata,
      // ... other fields you want to track
    });
    
    console.log(`Subscription ${subscription.subscription_id} updated`);
  }
  
  res.json({ received: true });
});
```

<Tip>
`subscription.updated` की सदस्यता लें ताकि आप किसी भी सदस्यता परिवर्तनों के बारे में वास्तविक-समय की सूचनाएँ प्राप्त कर सकें, API से अपडेट के लिए पोलिंग की आवश्यकता समाप्त हो जाए।
</Tip>
