## Dodo Payments क्या है?

Dodo Payments दुनिया भर में launch, scale और monetize करने का **all-in-one engine** है। digital SaaS और AI products की नई पीढ़ी के लिए बनाया गया यह platform **payments से billing और distribution तक** सब कुछ संभालता है - अतिरिक्त engineering के बिना।

<Info>
**SaaS और AI Products के लिए बनाया गया**: हमारी optimized billing infrastructure से one-time payments, subscriptions, credits, seats, tokens या किसी भी usage metric को संभालें।
</Info>

<Tip>
  <strong>Sentra से मिलें: आपका AI-powered billing assistant</strong><br/>
  Sentra एक AI agent है जो सीधे आपके IDE में billing और payments को integrate, analyze और manage करता है। प्रश्न पूछें, integrations बनाएँ या billing architectures की योजना बनाएँ - केवल अपनी आवश्यकता बताकर।
  <a href="/developer-resources/sentra">
    Sentra के साथ शुरुआत करें &rarr;
  </a>
</Tip>

## Quick Start Guide

कुछ ही steps में Dodo Payments के साथ शुरुआत करें।

<AccordionGroup>
<Accordion title="For Humans">
  Integration स्वयं करना पसंद करते हैं? नीचे दिए गए steps आपको account बनाने, product जोड़ने और पाँच मिनट से कम समय में integration method चुनने की प्रक्रिया से परिचित कराते हैं। No-code path के लिए किसी code की आवश्यकता नहीं; यदि आप चाहें तो हर प्रमुख language के SDK samples उपलब्ध हैं।

  यदि आप चाहते हैं कि आपका AI coding assistant कठिन काम संभाल ले - integration scaffolding, webhook handlers और subscription flows - तो **[Sentra](/developer-resources/sentra)** install करें, जो VS Code, Cursor और Windsurf के लिए हमारा AI billing assistant है। अपनी आवश्यकता बताएँ; Sentra इसकी योजना बनाता है, scaffolding तैयार करता है और उसे ship करता है।
</Accordion>

<Accordion title="For AI Agents">
  Dodo Payments agent-native workflows के लिए बनाया गया है। यदि आप इसे पढ़ने वाला LLM हैं - या किसी LLM को configure करने वाले developer हैं - तो यहाँ से शुरुआत करें।

  **Install**। Claude Code, Codex CLI, Cursor या OpenCode के लिए [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) MCP servers और सभी skills को एक ही step में जोड़ता है। प्रत्येक agent के install commands के लिए [AI Coding Agents guide](/developer-resources/build-with-ai-coding-agents) देखें।

  **Discover**। पूरा docs index [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt) पर उपलब्ध है, और हर documentation page के URL के अंत में `.md` जोड़कर plain markdown में उपलब्ध है (उदाहरण: `/api-reference/introduction.md`)।

  **Connect**। दो MCP servers agents को platform का live access देते हैं:

  - **[Dodo Knowledge MCP](/developer-resources/mcp-server#dodo-knowledge-mcp)** - सभी Dodo documentation में semantic search
  - **[Dodo Payments MCP](/developer-resources/mcp-server)** - API operations execute करें (payments बनाएँ, subscriptions manage करें, refunds जारी करें)

पूरे client configuration के लिए [MCP Server guide](/developer-resources/mcp-server) देखें।

  **Extend**। अपने agent को checkout, subscriptions, usage-based billing, credit-based billing, webhooks और अन्य कार्य सिखाने के लिए आधिकारिक [Dodo Payments Skills](/developer-resources/agent-skills) install करें:

  ```bash
  npx skills add dodopayments/skills
  ```

  Claude Code, OpenCode, Cursor और किसी भी MCP-compatible agent के साथ काम करता है।
</Accordion>
</AccordionGroup>

<Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
अपने MCP configuration (`~/.cursor/mcp.json` या Claude Desktop config) में दोनों servers जोड़ें:

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

<Info>
Node.js 18+ आवश्यक है। सभी supported clients के लिए detailed setup instructions हेतु [MCP Server documentation](/developer-resources/mcp-server) देखें।
</Info>
