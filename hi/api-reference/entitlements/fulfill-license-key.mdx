<Info>
इस endpoint का उपयोग केवल उन grants के लिए करें जो License Key entitlement के अंतर्गत `fulfillment_mode: manual` के साथ बनाए गए हैं। grant की स्थिति `Pending` होनी चाहिए और उससे कोई key जुड़ी नहीं होनी चाहिए। पूरी प्रक्रिया के लिए [मैन्युअल पूर्ति](/features/license-keys#manual-fulfillment) और [मैन्युअल License Key पूर्ति एकीकरण गाइड](/developer-resources/manual-license-key-fulfillment) देखें।
</Info>
