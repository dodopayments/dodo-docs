<Warning>
अनुमति को हटाना **एक सॉफ़्ट-डिलीट है जो मौजूदा अनुदानों को ग्राहक पोर्टल से छिपाता है**। यह प्लेटफ़ॉर्म-साइड एक्सेस को रद्द नहीं करता:

- अनुमति से जुड़े अनुदान डेटाबेस में बने रहते हैं और अपने वर्तमान `status` को बनाए रखते हैं।
- Discord भूमिकाएँ, GitHub सहयोगी एक्सेस, Notion एक्सेस, Telegram सदस्यता, लाइसेंस कुंजी, और डिजिटल फ़ाइल URLs वैध रहते हैं।
- कोई `entitlement_grant.revoked` webhook नहीं प्रसारित होता, और `revoked_at` / `revocation_reason` सेट नहीं होते।

ग्राहक अपने पोर्टल में इन अनुदानों को देखना बंद कर देते हैं, लेकिन उनके पास प्लेटफ़ॉर्म पर एक्सेस तब तक बना रहता है जब तक कि सब्सक्रिप्शन/भुगतान जीवनचक्र इसे रद्द नहीं कर देता (रद्दीकरण, धनवापसी) या आप प्रत्येक अनुदान को मैन्युअल रूप से [`DELETE /entitlements/{id}/grants/{grant_id}`](/api-reference/entitlements/revoke-grant) के माध्यम से रद्द नहीं करते।

यदि आपको पूरी तरह से पहुंच काटने की आवश्यकता है, तो पहले अनुदान रद्द करें, फिर अनुमति हटा दें।
</Warning>
