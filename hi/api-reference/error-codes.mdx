## अवलोकन

Dodo Payments API मानक HTTP स्थिति कोड और कस्टम त्रुटि कोड का उपयोग करता है ताकि API अनुरोधों की सफलता या विफलता को इंगित किया जा सके। जब कोई त्रुटि होती है, तो API एक उपयुक्त HTTP स्थिति कोड और त्रुटि के बारे में विस्तृत जानकारी प्रदान करने वाले JSON प्रतिक्रिया को लौटाता है।

प्रत्येक त्रुटि प्रतिक्रिया में शामिल हैं:
- एक HTTP स्थिति कोड जो त्रुटि की सामान्य श्रेणी को इंगित करता है
- एक विशिष्ट त्रुटि कोड जो त्रुटि की सटीक प्रकृति की पहचान करता है
- एक मानव-पठनीय त्रुटि संदेश जो बताता है कि क्या गलत हुआ
- जब लागू हो, तो त्रुटि के बारे में अतिरिक्त विवरण

इन त्रुटि कोडों और उनके अर्थ को समझना महत्वपूर्ण है:
- एकीकरण मुद्दों को डिबग करने के लिए
- अपने एप्लिकेशन में उचित त्रुटि हैंडलिंग लागू करने के लिए
- अंतिम उपयोगकर्ताओं को अर्थपूर्ण फीडबैक प्रदान करने के लिए
- एक मजबूत भुगतान प्रसंस्करण प्रणाली बनाए रखने के लिए

निम्नलिखित अनुभाग मानक HTTP स्थिति कोड और विशिष्ट त्रुटि कोड के बारे में विस्तृत जानकारी प्रदान करते हैं जो आप Dodo Payments API का उपयोग करते समय सामना कर सकते हैं।

## मानक API त्रुटि कोड

| त्रुटि कोड | HTTP स्थिति | विवरण |
|------------|-------------|-------------|
| **400** | खराब अनुरोध | अनुरोध गलत था या इसमें अमान्य पैरामीटर थे |
| **401** | अनधिकृत | प्रमाणीकरण विफल रहा या API कुंजी अमान्य है |
| **403** | निषिद्ध | API कुंजी को अनुरोधित संसाधन तक पहुँचने की अनुमति नहीं है |
| **404** | नहीं मिला | अनुरोधित संसाधन मौजूद नहीं है |
| **405** | विधि की अनुमति नहीं है | HTTP विधि इस एंडपॉइंट के लिए समर्थित नहीं है |
| **409** | संघर्ष | अनुरोध संसाधन की वर्तमान स्थिति के साथ संघर्ष करता है |
| **422** | असंसाध्य इकाई | अनुरोध अच्छी तरह से निर्मित था लेकिन इसमें अर्थ संबंधी त्रुटियाँ थीं |
| **429** | बहुत अधिक अनुरोध | दर सीमा पार हो गई |
| **500** | आंतरिक सर्वर त्रुटि | हमारे सर्वरों पर एक अप्रत्याशित त्रुटि हुई |
| **502** | खराब गेटवे | सर्वर को एक अपस्ट्रीम सर्वर से अमान्य प्रतिक्रिया मिली |
| **503** | सेवा अनुपलब्ध | सेवा अस्थायी रूप से अनुपलब्ध है |
| **504** | गेटवे टाइमआउट | सर्वर अपस्ट्रीम प्रतिक्रिया की प्रतीक्षा करते समय टाइमआउट हो गया |

## त्रुटि प्रतिक्रिया प्रारूप

जब कोई त्रुटि होती है, तो API निम्नलिखित संरचना के साथ JSON प्रतिक्रिया लौटाता है:

```json
{
  "code": "UNSUPPORTED_COUNTRY",
  "message": "Country AI currently not supported"
}
```

## त्रुटि कोड संदर्भ

- `ACTIVATION_LIMIT_LESS_THAN_CURRENT_AMOUNT`
  - **Trigger:** लाइसेंस कुंजी सक्रियण: नई सीमा < मौजूदा उदाहरणों की संख्या
  - **Message:** नई सक्रियण सीमा मौजूदा उदाहरणों की संख्या से कम नहीं हो सकती है

- `ADDONS_IN_USAGE_BASED_BILLING_NOT_SUPPORTED`
  - **Trigger:** उपयोग-आधारित बिलिंग सब्सक्रिप्शन में addons जोड़ने का प्रयास
  - **Message:** उपयोग आधारित बिलिंग के लिए सब्सक्रिप्शन में addons का समर्थन नहीं है

- `ADDONS_NOT_ALLOWED_FOR_ON_DEMAND`
  - **Trigger:** ऑन-डिमांड सब्सक्रिप्शन में addons जोड़ने का प्रयास
  - **Message:** ऑन डिमांड सब्सक्रिप्शन के लिए addons की अनुमति नहीं है

- `BRAND_MISMATCH`
  - **Trigger:** कार्ट में आइटम विभिन्न ब्रांडों से संबंधित हैं
  - **Message:** उत्पाद कार्ट में सभी आइटम एक ही ब्रांड के होने चाहिए

- `BRAND_NOT_ENABLED`
  - **Trigger:** ब्रांड निष्क्रिय या सक्रिय नहीं है
  - **Message:** प्रदान किया गया ब्रांड सक्षम नहीं है

- `BRAND_SUBMISSION_NOT_ENABLED`
  - **Trigger:** ब्रांड सत्यापन पुनः सबमिशन सुविधा सक्षम नहीं है
  - **Message:** ब्रांड सत्यापन पुनः सबमिशन सक्षम नहीं है

- `CHARGE_NOT_ALLOWED_FOR_SCHEDULED_CANCELLATION`
  - **Trigger:** समाप्ति के लिए शेड्यूल की गई सब्सक्रिप्शन पर शुल्क लगाने का प्रयास
  - **Message:** सब्सक्रिप्शन समाप्ति के लिए शेड्यूल की गई है

- `CHECKOUT_SESSION_CONSUMED`
  - **Trigger:** चेकआउट सत्र ने पहले ही एक भुगतान उत्पन्न कर दिया है
  - **Message:** चेकआउट सत्र का पहले ही उपभोग किया जा चुका है

- `DISCOUNT_CODE_ALREADY_EXISTS`
  - **Trigger:** डुप्लिकेट छूट कोड निर्माण
  - **Message:** छूट कोड पहले से ही मौजूद है

- `DISCOUNT_CODE_EXPIRED`
  - **Trigger:** छूट कोड अपनी `expires_at` तिथि के बाद
  - **Message:** छूट कोड समाप्त हो गया

- `DISCOUNT_CODE_USAGE_LIMIT_EXCEEDED`
  - **Trigger:** `usage_limit` तक पहुंचने के बाद छूट कोड का पुनः उपयोग
  - **Message:** उपयोग सीमा times_used / छूट कोड हिट उपयोग सीमा से कम नहीं हो सकती

- `DISCOUNT_NOT_AVAILABLE_FOR_ON_DEMAND`
  - **Trigger:** ऑन-डिमांड सब्सक्रिप्शन पर कोड लागू किया गया
  - **Message:** ऑन डिमांड सब्सक्रिप्शन के लिए छूट कूपन उपलब्ध नहीं है

- `DISCOUNT_NOT_AVAILABLE_FOR_PRODUCT`
  - **Trigger:** संबंधित उत्पादों पर कोड लागू किया गया
  - **Message:** इस उत्पाद के लिए छूट कूपन उपलब्ध नहीं है

- `DUPLICATE_LINE_ITEMS_IN_REQUEST`
  - **Trigger:** समान `item_id` का दो बार उल्लेख
  - **Message:** आइटम सूची में डुप्लिकेट item_ids निर्दिष्ट हैं

- `DUPLICATE_METER_IDS_IN_REQUEST`
  - **Trigger:** अनुरोध में समान मीटर आईडी एकाधिक बार उपस्थित
  - **Message:** डुप्लिकेट मीटर आईडी की अनुमति नहीं है

- `EXCHANGE_RATE_NOT_FOUND`
  - **Trigger:** `from → to` मुद्रा जोड़ी के लिए कोई FX दर नहीं
  - **Message:** मुद्रा से मुद्रा में परिवर्तित करने के लिए विनिमय दर नहीं मिली

- `EXISTING_REFUND_REQUEST_PROCESSING`
  - **Trigger:** पिछले रिफंड अनुरोध की अभी भी प्रक्रिया हो रही है
  - **Message:** "पेंडिंग" स्थिति के साथ रिफंड अनुरोध की अभी भी प्रक्रिया हो रही है

- `INACTIVE_LICENSE_KEY`
  - **Trigger:** कुंजी स्थिति ≠ `ACTIVE`
  - **Message:** लाइसेंस कुंजी सक्रिय नहीं है

- `INACTIVE_SUBSCRIPTION_PLAN_CHANGE_NOT_SUPPORTED`
  - **Trigger:** निष्क्रिय सब्सक्रिप्शन पर योजना में परिवर्तन
  - **Message:** निष्क्रिय सब्सक्रिप्शन के लिए योजनाओं में परिवर्तन का समर्थन नहीं है

- `INSUFFICIENT_WALLET_FUNDS`
  - **Trigger:** वॉलेट बैलेंस < डेबिट राशि
  - **Message:** वॉलेट में धन अपर्याप्त है

- `INTEGER_CONVERSION_FAILURE`
  - **Trigger:** कोई पूर्णांक ↔ स्ट्रिंग/दशमलव रूपांतरण जो सर्वर-पक्ष पर विफल है
  - **Message:** पूर्णांक रूपांतरण विफल

- `INTERNAL_SERVER_ERROR`
  - **Trigger:** अप्रत्याशित अपवाद; आपको विवरण सर्वर-पक्ष पर लॉग करना चाहिए
  - **Message:** *कोई सार्वजनिक संदेश नहीं (सामान्य 500)*

- `INVALID_DISCOUNT_CODE`
  - **Trigger:** कोड मौजूद नहीं है / लागू नहीं है
  - **Message:** अमान्य छूट कोड / छूट कोड कार्ट में किसी भी उत्पाद पर लागू नहीं किया जा सकता है

- `INVALID_PERCENTAGE`
  - **Trigger:** प्रतिशत राशि > 100% (या 10,000 आधार अंक)
  - **Message:** प्रतिशत राशि 10000 से अधिक नहीं हो सकती / छूट कोड राशि 100% से अधिक नहीं हो सकती

- `INVALID_QUANTITY`
  - **Trigger:** उपयोग-आधारित मूल्य निर्धारण के लिए निर्दिष्ट मात्रा अमान्य है
  - **Message:** उपयोग आधारित मूल्य उत्पादों में केवल 1 मात्रा की अनुमति है

- `INVALID_QUERY_PARAMS`
  - **Trigger:** परस्पर विशेष / गलत फ़ॉर्मेट क्वेरी पैरामीटर
  - **Message:** क्वेरी पैरामीटर्स में केवल या तो time_frame या (आरंभ, समाप्त) ही होना चाहिए

- `INVALID_REQUEST_BODY`
  - **Trigger:** गलत JSON या योजना का उल्लंघन
  - **Message:** आपका अनुरोध शरीर अमान्य है। कृपया अपने अनुरोध हेडर और वस्तु की जांच करें।

- `INVALID_REQUEST_PARAMETERS`
  - **Trigger:** अर्थ उत्तरदायी गलत (जैसे, अतीत में तारीख)
  - **Message:** अगले_billing_date को अतीत में नहीं बदला जा सकता है

- `INVALID_SUGGESTED_PRICE`
  - **Trigger:** PWYW मूल्य < न्यूनतम अनुमत मूल्य
  - **Message:** सुझावित मूल्य न्यूनतम मूल्य से कम नहीं हो सकता। भुगतान करने के लिए आप जो चाहें, उसमें मूल्य को न्यूनतम स्वीकृत राशि माना जाता है

- `INVALID_TAX_ID`
  - **Trigger:** VAT/GST/TIN असत्यापन
  - **Message:** टैक्स आईडी अमान्य है

- `LICENSE_KEY_LIMIT_REACHED`
  - **Trigger:** सक्रियण = सीमा
  - **Message:** लाइसेंस कुंजी सक्रियण सीमा पहुँच गई

- `LICENSE_KEY_NOT_FOUND`
  - **Trigger:** उदाहरण ID या कुंजी ID अमान्य
  - **Message:** लाइसेंस कुंजी उदाहरण नहीं मिला या इस लाइसेंस कुंजी से संबंधित नहीं है

- `LINE_ITEM_FULLY_REFUNDED`
  - **Trigger:** पहले से पूरी तरह से रिफंड की गई पंक्ति आइटम पर रिफंड की कोशिश करना
  - **Message:** पंक्ति आइटम {id} को पूरी तरह से रिफंड किया गया है इसे आगे रिफंड नहीं किया जा सकता।

- `LINE_ITEM_NOT_FOUND`
  - **Trigger:** आइटम ID संदर्भित भुगतान का हिस्सा नहीं है
  - **Message:** पंक्ति आइटम {id} भुगतान में नहीं मिला

- `LINE_ITEM_PRORATED`
  - **Trigger:** प्रोरटेड पंक्ति पर रिफंड या अपडेट का प्रयास किया गया
  - **Message:** पंक्ति आइटम {id} को रिफंड नहीं किया जा सकता क्योंकि यह प्रोरटेड है

- `LINE_ITEM_REFUND_AMOUNT_TOO_HIGH`
  - **Trigger:** रिफंड राशि > भुगतान राशि (कर सहित)
  - **Message:** पंक्ति आइटम {id} के लिए अनुरोधित रिफंड राशि जिसमें कर {amount} शामिल है जो भुगतान राशि {amount} से अधिक है

- `LINE_ITEM_REFUND_AMOUNT_TOO_LOW`
  - **Trigger:** रिफंड राशि न्यूनतम थ्रेशोल्ड से कम है
  - **Message:** पंक्ति आइटम {id} के लिए अनुरोधित रिफंड राशि {amount} है जो बहुत कम है

- `MAXIMUM_KEYS_REACHED`
  - **Trigger:** मेटाडेटा / कस्टम-फील्ड ने 50 जोड़े पार कर लिए हैं
  - **Message:** 50 की-मान जोड़ों से अधिक होता है

- `MERCHANT_NOT_LIVE`
  - **Trigger:** व्यवसाय अभी भी परीक्षण/सैंडबॉक्स मोड में है
  - **Message:** व्यापारी लाइव नहीं है

- `METER_IS_DELETED`
  - **Trigger:** हटा दिए गए मीटर का उपयोग करने का प्रयास
  - **Message:** मीटर पहले ही हटा दिया गया है

- `MISSING_ADDON_IDS`
  - **Trigger:** `addon_id` सूची खाली या अज्ञात IDs
  - **Message:** एक या अधिक उत्पाद IDs मौजूद नहीं हैं: {id}

- `MISSING_METER_IDS`
  - **Trigger:** मीटर ID सूची खाली या अमान्य IDs रखती है
  - **Message:** एक या अधिक मीटर IDs मौजूद नहीं हैं: {id}

- `MISSING_PRODUCT_INFORMATION`
  - **Trigger:** उत्पाद मौजूद है लेकिन अनिवार्य जानकारी गायब है
  - **Message:** उत्पाद {id} मौजूद है लेकिन अन्य अनिवार्य जानकारी गायब या अमान्य है

- `NEGATIVE_BALANCE_ADJUSTMENT`
  - **Trigger:** वॉलेट बैलेंस को ऋणात्मक बनाने का प्रयास
  - **Message:** वॉलेट बैलेंस को ऋणात्मक नहीं बनाया जा सकता

- `NO_ELIGIBLE_PAYMENT_METHODS`
  - **Trigger:** फ़िल्टर लगाने के बाद, कुछ नहीं बचा
  - **Message:** कोई पात्र भुगतान विधियाँ नहीं मिलीं

- `NO_EXPIRY_ON_SUBSCRIPTION_LICENSE_KEYS`
  - **Trigger:** सब्सक्रिप्शन-आधारित कुंजी पर समाप्ति सेट करने का प्रयास
  - **Message:** सब्सक्रिप्शन-आधारित लाइसेंस कुंजी के लिए समाप्ति तिथि सेट नहीं की जा सकती

- `NOT_FOUND`
  - **Trigger:** किसी भी लापता संसाधन के लिए सामान्य 404
  - **Message:** आइटम नहीं मिला *(या अधिक विशिष्ट)*

- `ON_DEMAND_PLAN_CHANGE_NOT_SUPPORTED`
  - **Trigger:** ऑन-डिमांड के लिए योजना स्वैप की अनुमति नहीं है
  - **Message:** ऑन डिमांड सब्सक्रिप्शनों के लिए योजनाओं का परिवर्तन समर्थित नहीं है

- `ON_DEMAND_SUBSCRIPTIONS_NOT_ENABLED`
  - **Trigger:** व्यवसाय में फ़ीचर फ्लैग बंद है
  - **Message:** इस व्यवसाय के लिए ऑन डिमांड सब्सक्रिप्शन सक्षम नहीं हैं

- `ON_DEMAND_USAGE_BASED_BILLING_NOT_SUPPORTED`
