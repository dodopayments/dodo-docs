## अवलोकन

Dodo Payments API विस्तृत लेनदेन विफलता कारण प्रदान करता है ताकि आप समझ सकें कि भुगतान प्रयास असफल क्यों हुआ। ये विफलता कारण विभिन्न भुगतान विधियों और प्रदाताओं के बीच मानकीकृत हैं, जिससे आपके अनुप्रयोग में सुसंगत त्रुटि हैंडलिंग लागू करना आसान हो जाता है।

प्रत्येक लेनदेन विफलता प्रतिक्रिया में शामिल हैं:
- एक विशिष्ट विफलता कारण कोड
- एक मानव-पठनीय त्रुटि संदेश
- उपलब्ध होने पर विफलता के बारे में अतिरिक्त संदर्भ
- क्या त्रुटि उपयोगकर्ता द्वारा सुधार योग्य है या प्रणाली हस्तक्षेप की आवश्यकता है

इन विफलता कारणों को समझना महत्वपूर्ण है:
- अपने ग्राहकों को स्पष्ट फीडबैक प्रदान करना
- उपयुक्त पुनः प्रयास तर्क लागू करना
- विभिन्न विफलता परिदृश्यों को सुचारू रूप से संभालना
- एक विश्वसनीय भुगतान प्रसंस्करण प्रणाली बनाए रखना

## लेनदेन विफलता कारण

निम्नलिखित तालिका सभी संभावित लेनदेन विफलता कारणों, उनके अर्थ और क्या वे उपयोगकर्ता-सुधार योग्य त्रुटियाँ हैं, को सूचीबद्ध करती है।

| असफलता कोड | उपयोगकर्ता त्रुटि | विवरण |
|----------------|------------|-------------|
| `AUTHENTICATION_FAILURE` | हाँ | लेन-देन के दौरान प्रमाणीकरण प्रक्रिया विफल हो गई |
| `AUTHENTICATION_REQUIRED` | हाँ | लेन-देन पूरा करने के लिए अतिरिक्त प्रमाणीकरण आवश्यक है |
| `AUTHENTICATION_TIMEOUT` | हाँ | प्रमाणीकरण प्रक्रिया समय सीमा समाप्त हो गई |
| `CARD_DECLINED` | नहीं | कार्ड को जारी करने वाले बैंक द्वारा अस्वीकार कर दिया गया |
| `CARD_NOT_ACTIVATED` | हाँ | कार्डधारक द्वारा कार्ड सक्रिय नहीं किया गया है |
| `CARD_VELOCITY_EXCEEDED` | हाँ | एक छोटे समय में बहुत अधिक लेन-देन करने का प्रयास किया गया |
| `CUSTOMER_CANCELLED` | हाँ | ग्राहक ने लेन-देन रद्द कर दिया |
| `DO_NOT_HONOR` | नहीं | जारी करने वाला बैंक लेन-देन को अस्वीकार कर दिया |
| `EXPIRED_CARD` | हाँ | कार्ड की अवधि समाप्त हो गई है |
| `FRAUDULENT` | हाँ | लेन-देन को संभावित रूप से धोखाधड़ी के रूप में चिह्नित किया गया |
| `GENERIC_DECLINE` | नहीं | लेन-देन को अनिर्दिष्ट कारणों के लिए अस्वीकार कर दिया गया |
| `INCORRECT_CVC` | हाँ | प्रदान किया गया CVC कोड गलत था |
| `INCORRECT_NUMBER` | हाँ | कार्ड नंबर गलत तरीके से दर्ज किया गया था |
| `INSUFFICIENT_FUNDS` | हाँ | खाते में लेन-देन पूरा करने के लिए पर्याप्त फंड नहीं हैं |
| `INVALID_ACCOUNT` | हाँ | प्रदान की गई खाता जानकारी अमान्य है |
| `INVALID_AMOUNT` | हाँ | लेन-देन राशि अमान्य है |
| `INVALID_CARD_NUMBER` | हाँ | कार्ड नंबर प्रारूप अमान्य है |
| `INVALID_CARD_OWNER` | हाँ | कार्ड मालिक की जानकारी अमान्य है |
| `INVALID_CVC` | हाँ | CVC प्रारूप अमान्य है |
| `INVALID_EXPIRY_YEAR` | हाँ | कार्ड की समाप्ति वर्ष अमान्य है |
| `INVALID_PIN` | हाँ | प्रदान किया गया पिन गलत है |
| `INVALID_REQUEST` | हाँ | लेन-देन अनुरोध में अमान्य डेटा है |
| `INVALID_UPI_ID` | हाँ | प्रदान किया गया UPI ID अमान्य है |
| `LIMIT_EXCEEDED` | हाँ | लेन-देन कार्ड या खाता सीमा को पार करता है |
| `LIVE_MODE_TEST_CARD` | हाँ | लाइव मोड में एक परीक्षण कार्ड का उपयोग किया गया |
| `LOST_CARD` | हाँ | कार्ड को खोया हुआ बताया गया है |
| `MANDATE_INVALID` | हाँ | भुगतान मंडेट अमान्य है |
| `MANDATE_REQUIRED` | हाँ | इस लेन-देन के लिए एक मंडेट आवश्यक है |
| `MANDATE_REQUIRED_SYSTEM` | नहीं | प्रणाली को इस लेन-देन प्रकार के लिए एक मंडेट की आवश्यकता है |
| `NETWORK_ERROR` | नहीं | लेन-देन के दौरान एक नेटवर्क त्रुटि हुई |
| `NETWORK_TIMEOUT` | नहीं | नेटवर्क अनुरोध की समय सीमा समाप्त हो गई |
| `ORDER_CREATION_FAILED` | नहीं | लेन-देन के लिए आदेश बनाने में असफल |
| `PAYMENT_METHOD_PROVIDER_DECLINED` | हाँ | भुगतान विधि प्रदाता ने लेन-देन को अस्वीकार कर दिया |
| `PAYMENT_METHOD_UNSUPPORTED` | हाँ | इस लेन-देन के लिए भुगतान विधि समर्थित नहीं है |
| `PICKUP_CARD` | हाँ | कार्ड को चोरी हुआ बताया गया है और इसे उठाया जाना चाहिए |
| `PROCESSING_ERROR` | नहीं | लेन-देन प्रोसेस करते समय एक त्रुटि हुई |
| `PROVIDER_UNSUPPORTED` | नहीं | भुगतान प्रदाता इस लेन-देन प्रकार का समर्थन नहीं करता |
| `REENTER_TRANSACTION` | हाँ | लेन-देन को फिर से दर्ज करने की आवश्यकता है |
| `REVOCATION_OF_AUTHORIZATION` | हाँ | लेन-देन के लिए अधिकृत किया गया था |
| `STOLEN_CARD` | हाँ | कार्ड को चोरी हुआ बताया गया है |
| `TRANSACTION_NOT_ALLOWED` | हाँ | इस कार्ड या खाते के लिए लेन-देन की अनुमति नहीं है |
| `TRANSACTION_NOT_APPROVED` | हाँ | लेन-देन को मंजूरी नहीं दी गई |
| `TRY_AGAIN_LATER` | नहीं | लेन-देन को बाद में पुनः प्रयास करने की आवश्यकता है |
| `UNKNOWN_ERROR` | नहीं | एक अज्ञात त्रुटि हुई |

<Note>
  **उपयोगकर्ता त्रुटि** यह संकेत करता है कि क्या भुगतान अस्वीकृति को ग्राहक द्वारा हल किया जा सकता है। जब `true`, ग्राहक समस्या को ठीक करने के लिए कार्रवाई कर सकता है (जैसे, सही कार्ड विवरण दर्ज करना)। जब `false`, अस्वीकृति प्रणाली स्तर की समस्याओं या बैंक की प्रतिबंध के कारण है जिसे ग्राहक द्वारा हल नहीं किया जा सकता।
</Note>
