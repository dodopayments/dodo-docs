<Warning>
**अप्रचलित API**: लाइसेंस कुंजियों अब [Entitlements](/features/entitlements/introduction) प्रणाली के माध्यम से प्रबंधित की जाती हैं। जारी लाइसेंस कुंजियों को सूचीबद्ध करने के लिए [List Customer Grants](/api-reference/entitlements/list-customer-grants) का उपयोग करें (फिल्टर करें `integration_type=license_key`); प्रत्येक अनुदान अपने `license_key` विवरण के साथ आता है। यह एंडपॉइंट भविष्य के रिलीज़ में हटा दिया जाएगा।
</Warning>
