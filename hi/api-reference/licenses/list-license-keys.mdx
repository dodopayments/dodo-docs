<Warning>
**अप्रचलित API**: लाइसेंस कुंजियाँ अब [Entitlements](/features/entitlements/introduction) सिस्टम के माध्यम से प्रबंधित की जाती हैं। जारी लाइसेंस कुंजियों की सूची के लिए [List Grants](/api-reference/entitlements/list-grants) का उपयोग करें (`integration_type=license_key` के साथ फिल्टर करें); प्रत्येक ग्रांट उसके `license_key` विवरण के साथ आता है। यह एंडपॉइंट भविष्य के रिलीज में हटा दिया जाएगा।
</Warning>
