<Warning>
**अप्रचलित API**: लाइसेंस कुंजियाँ अब [अधिकार](/features/entitlements/introduction) प्रणाली के माध्यम से प्रबंधित की जाती हैं। [लाइसेंस कुंजी अधिकार](/api-reference/entitlements/update-entitlement) पर सक्रियण सीमाएँ और अवधि कॉन्फ़िगर करें, और ग्राहक की कुंजी को अक्षम करने के लिए [अनुदान रद्द करें](/api-reference/entitlements/revoke-grant) का उपयोग करें। यह एंडपॉइंट भविष्य के किसी रिलीज़ में हटा दिया जाएगा।
</Warning>

<Info>
API के माध्यम से लाइसेंस कुंजी को अपडेट करना ग्राहक को ईमेल सूचनाएं ट्रिगर नहीं करता है।
</Info>
