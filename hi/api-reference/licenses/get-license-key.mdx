<Warning>
**अप्रचलित API**: लाइसेंस कुंजियाँ अब [Entitlements](/features/entitlements/introduction) प्रणाली के माध्यम से प्रबंधित की जाती हैं। किसी कुंजी के अनुदान और उसके `license_key` विवरणों को प्राप्त करने के लिए [List Grants](/api-reference/entitlements/list-grants) का उपयोग करें (`integration_type=license_key` के साथ फ़िल्टर करें)। यह एंडपॉइंट भविष्य के संस्करण में हटा दिया जाएगा।
</Warning>
