<Info>
यह endpoint आपके पास पहले से मौजूद key को इम्पोर्ट करता है — `key`, `customer_id` और `product_id` सभी आवश्यक हैं। यह आपके लिए key value जनरेट नहीं करता। पहले से मौजूद `key` को इम्पोर्ट करने पर `409 Conflict` लौटता है।
</Info>

<Info>
API के माध्यम से बनाई या अपडेट की गई license keys ग्राहकों को email notifications ट्रिगर नहीं करती हैं। यदि आपको ग्राहकों को उनकी license key के बारे में सूचित करना है, तो आपको इसे अपने application में अलग से संभालना होगा।
</Info>
