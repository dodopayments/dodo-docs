## परिचय

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) एक ऐसा platform है जो location-based purchasing power parity discount coupons बनाता है और उन्हें आपके Dodo Payments account में sync करता है। यह one-time और subscription products दोनों को support करता है और आपके द्वारा निर्धारित schedule के अनुसार rotate होने वाले discount codes अपने आप generate करता है।

<Note>
Dodo Payments में native [Purchasing Power Parity](/features/purchasing-power-parity) मौजूद है, जो checkout के समय देश के अनुसार prices कम करता है—इसके लिए किसी banner, script या manage किए जाने वाले coupon codes की आवश्यकता नहीं होती। Evendeals उन merchants के लिए है जो विशेष रूप से automatic coupon rotation के साथ discount-code approach चाहते हैं।
</Note>

## यह कैसे काम करता है

Evendeals API key के माध्यम से आपके Dodo Payments account से connect होता है। Connect होने के बाद, आप प्रत्येक country group के लिए percentage discounts configure करते हैं। इसके बाद Evendeals आपके Dodo Payments account में discount codes अपने आप बनाता है और abuse को रोकने के लिए आपके द्वारा निर्धारित schedule (time interval, redemption count या view count के आधार पर) पर उन्हें rotate करता है।

## Evendeals बनाम Native PPP

देश के अनुसार pricing के लिए Native Purchasing Power Parity recommended तरीका है, क्योंकि इसमें coupon codes की आवश्यकता नहीं होती और इसे share या abuse नहीं किया जा सकता। जब आप विशेष रूप से discount-code approach चाहते हों, तब Evendeals चुनें।

| | Native PPP | Evendeals |
| :--- | :--- | :--- |
| यह कैसे काम करता है | प्रत्येक देश के लिए एक percentage, checkout के समय लागू | एक percentage की छूट, code के माध्यम से लागू |
| इसे कहाँ configure किया जाता है | Dodo Payments में built-in | Evendeals dashboard |
| Banner या script आवश्यक | आवश्यक नहीं | आवश्यक नहीं |
| Coupon rotation / auto-refresh | लागू नहीं | हाँ |
| Subscription support | हाँ | हाँ |
| किसके लिए बेहतर | बिना site changes के सही prices | Automatic rotation के साथ discount-code approach |

## मुख्य सुविधाएँ

- **Auto coupon sync** — Coupons Dodo Payments में अपने आप create और manage किए जाते हैं
- **Percentage discounts** — प्रत्येक country group के लिए percentage-off discounts offer करें
- **Subscription support** — Discounts subscription billing cycles के दौरान लागू होते हैं
- **Auto-refresh rules** — Abuse को रोकने के लिए time interval, redemption count या view count के आधार पर coupon codes को अपने आप rotate करें

<Info>
Evendeals द्वारा बनाए गए discount codes आपके Dodo Payments dashboard में **Sales → Discounts** के अंतर्गत अपने आप दिखाई देंगे।
</Info>

## आवश्यकताएँ

इस integration को set up करने से पहले सुनिश्चित करें कि आपके पास ये मौजूद हों:

1. एक [Dodo Payments account](https://app.dodopayments.com)
2. एक [Evendeals account](https://www.evendeals.com/signin)
3. एक Dodo Payments API key

## शुरुआत करना

<Steps>
  <Step title="Create a Dodo Payments API Key">
    अपने Dodo Payments dashboard में **Developers → API Keys** पर जाएँ और **Create New API** पर click करें। इसे स्पष्ट नाम दें (जैसे, "Evendeals") ताकि आप बाद में इसे पहचान सकें।
  </Step>

  <Step title="Connect in Evendeals">
    अपने [Evendeals dashboard](https://www.evendeals.com/signin) में **Integrations** पर जाएँ, Dodo Payments card खोजें और अपनी API key paste करें।
  </Step>

  <Step title="Configure Regional Discounts">
    प्रत्येक country group के लिए percentage discounts set करें और sync पर click करें। Evendeals Dodo Payments में coupons अपने आप create करता है।

    <Check>
    Sync करने के बाद, अपने Dodo Payments dashboard में **Sales → Discounts** खोलकर पुष्टि करें कि generated coupons दिखाई दे रहे हैं। प्रत्येक coupon में Evendeals का पहचानने योग्य prefix होगा।
    </Check>
  </Step>
</Steps>
