## परिचय

DataFast एक राजस्व-प्रथम एनालिटिक्स उपकरण है जो आपको यह पता लगाने में मदद करता है कि कौन से मार्केटिंग चैनल भुगतान करने वाले ग्राहकों को लाते हैं। DataFast के साथ Dodo Payments को एकीकृत करके, आप अपने ट्रैफ़िक स्रोतों को राजस्व सौंप सकते हैं, उच्च-मूल्य वाले ग्राहक खंडों की पहचान कर सकते हैं, और अपने व्यवसाय को बढ़ाने के लिए डेटा-संचालित निर्णय ले सकते हैं।

<Info>
यह एकीकरण आपके DataFast API Key की आवश्यकता करता है, जिसे आप अपने [DataFast डैशबोर्ड](https://datafa.st/) से प्राप्त कर सकते हैं।
</Info>

## यह कैसे काम करता है

DataFast आगंतुकों को एक अद्वितीय आगंतुक आईडी के माध्यम से ट्रैक करता है जो एक कुकी में संग्रहीत होती है। मार्केटिंग चैनलों को राजस्व सौंपने के लिए, आपको करना होगा:

1. **चेकआउट सत्र बनाते समय `datafast_visitor_id` कुकी से DataFast का विज़िटर ID कैप्चर करें**
2. **विज़िटर ID को अपने भुगतान मेटाडाटा में संग्रहीत करें**
3. **भुगतान सफल होने पर DataFast को उनके Payment API के माध्यम से भुगतान डेटा भेजें**

यह DataFast को सफल भुगतानों को मूल ट्रैफ़िक स्रोत से मिलाने की अनुमति देता है, जिससे आपको पूर्ण राजस्व सौंपने की जानकारी मिलती है।

  अपने प्लेटफ़ॉर्म के लिए इंस्टॉलेशन निर्देशों के लिए [DataFast प्रलेखन](https://datafa.st/docs) देखें।

<Step title="Send Payment Data via Webhook">

</Step>

<Step title="Done!">

</Step>

## कार्यान्वयन गाइड

### चरण 1: चेकआउट मेटाडेटा में आगंतुक आईडी जोड़ें

चेकआउट सत्र बनाते समय, कुकी से DataFast आगंतुक आईडी को कैप्चर करें और इसे अपने भुगतान मेटाडेटा में शामिल करें।

<Note>
नीचे दिए गए उदाहरण `POST /payments` का उपयोग करते हैं, जो **deprecated** है। यह मौजूदा integrations के लिए अभी भी काम करता है, लेकिन नए integrations को [Checkout Sessions](/developer-resources/checkout-session) (`POST /checkouts`) का उपयोग करना चाहिए — `metadata` को भी इसी तरह पास किया जाता है।
</Note>

<CodeGroup>

```typescript Next.js
import { cookies } from 'next/headers';
import { dodopayments } from '@/lib/dodopayments';

export async function createCheckout(productId: string) {
  // Capture DataFast visitor ID from cookie
  const datafastVisitorId = cookies().get('datafast_visitor_id')?.value;

  const payment = await dodopayments.payments.create({
    product_cart: [{ product_id: productId, quantity: 1 }],
    // ... other payment configuration
    metadata: {
      datafast_visitor_id: datafastVisitorId, // Store visitor ID in metadata
    },
  });

  return payment;
}
```

```javascript Express.js
const express = require('express');
const router = express.Router();

router.post('/create-checkout', async (req, res) => {

    product_cart: [{ product_id: req.body.productId, quantity: 1 }],
    // ... other payment configuration
    metadata: {
      datafast_visitor_id: datafastVisitorId, // Store visitor ID in metadata
    },
  });

  res.json({ payment });
});
```

## Transformation Code Examples

### Basic Payment Attribution

```javascript basic_payment.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    // Only send to DataFast if visitor ID exists in metadata
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      webhook.payload = {
        amount: payment.total_amount / 100, // Convert from cents to dollars
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

### Handle Zero Decimal Currencies

कुछ currencies (जैसे JPY) में decimal places का उपयोग नहीं होता। amount calculation को उसी के अनुसार समायोजित करें:

```javascript zero_decimal.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      // Zero decimal currencies: JPY, KRW, CLP, etc.
      const zeroDecimalCurrencies = ['JPY', 'KRW', 'CLP', 'VND', 'UGX', 'MGA'];
      const isZeroDecimal = zeroDecimalCurrencies.includes(payment.currency);
      
      webhook.payload = {
        amount: isZeroDecimal 
          ? payment.total_amount // Use amount as-is for zero decimal currencies
          : payment.total_amount / 100, // Convert from cents for other currencies
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

### Subscription Payments

recurring subscription payments के लिए, आप प्रत्येक payment को track कर सकते हैं:

```javascript subscription_payment.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    // Check if this is a subscription payment
    const isSubscription = payment.subscription_id !== null;
    
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      webhook.payload = {
        amount: payment.total_amount / 100,
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
        // Optional: Add subscription context
        ...(isSubscription && {
          subscription_id: payment.subscription_id,
        }),
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

## Best Practices

<Tip>
**visitor ID को जल्दी capture करें**: सटीक attribution सुनिश्चित करने के लिए checkout flow में DataFast visitor ID को जितनी जल्दी संभव हो store करें, भले ही user वहाँ से चला जाए और बाद में वापस आए।
</Tip>

- **metadata में visitor ID हमेशा शामिल करें**: visitor ID के बिना, DataFast revenue को marketing channels से attribute नहीं कर सकता
- **zero decimal currencies को handle करें**: कुछ currencies (JPY, KRW आदि) में decimal places का उपयोग नहीं होता—अपनी amount calculation को उसी के अनुसार समायोजित करें
- **sample payments के साथ test करें**: live होने से पहले verify करें कि integration सही तरीके से काम कर रहा है
- **अपने DataFast dashboard को monitor करें**: जाँचें कि payments सही attribution के साथ दिखाई दे रहे हैं
- **webhook retries का उपयोग करें**: DataFast का Payment API idempotent है, इसलिए webhook विफल होने पर retries सुरक्षित हैं

## Troubleshooting

<AccordionGroup>
<Accordion title="Payments not appearing in DataFast">
- Verify करें कि आपकी DataFast API key सही और active है
- जाँचें कि `datafast_visitor_id` को capture करके payment metadata में store किया जा रहा है
- सुनिश्चित करें कि webhook transformation payload को सही तरीके से format कर रहा है
- Verify करें कि webhook `payment.succeeded` events पर trigger हो रहा है
- किसी भी error messages या API logs के लिए DataFast dashboard जाँचें
</Accordion>

<Accordion title="Revenue attribution not working">
- Confirm करें कि DataFast tracking script आपकी website पर installed और working है
- Verify करें कि `datafast_visitor_id` cookie सही तरीके से set हो रही है
- जाँचें कि checkout creation और payment completion के बीच visitor IDs match करती हैं
- सुनिश्चित करें कि checkout session बनाने से पहले आप visitor ID capture कर रहे हैं
- अतिरिक्त guidance के लिए DataFast के [Payment API documentation](https://datafa.st/docs/payments-api) की समीक्षा करें
</Accordion>

<Accordion title="Transformation errors">
- Validate करें कि JSON structure DataFast के Payment API format से match करता है
- जाँचें कि सभी required fields (`amount`, `currency`, `transaction_id`, `datafast_visitor_id`) मौजूद हैं
- सुनिश्चित करें कि amount सही तरीके से converted है (अधिकांश currencies के लिए 100 से divide करें, zero decimal currencies को छोड़कर)
- Verify करें कि API endpoint URL सही है: `https://datafa.st/api/v1/payments`
- sample webhook payloads के साथ transformation को test करें
</Accordion>

<Accordion title="Currency conversion issues">
- zero decimal currencies (JPY, KRW, CLP, VND, UGX, MGA) के लिए amount को 100 से divide किए बिना 그대로 भेजें
- अन्य सभी currencies के लिए cents से base unit में convert करने हेतु amount को 100 से divide करें
- दोबारा जाँचें कि currency code ISO 4217 format से match करता है (जैसे, "USD", "EUR", "JPY")
</Accordion>
</AccordionGroup>
