## नई सुविधाएँ 🚀

- **नए यूरोपीय भुगतान तरीके**: हमने चार नए यूरोपीय भुगतान तरीकों के साथ अपने भुगतान विकल्पों का विस्तार किया है:
  - **iDEAL** - नीदरलैंड
  - **Bancontact** - बेल्जियम
  - **Przelewy24 (P24)** - पोलैंड
  - **EPS** - ऑस्ट्रिया

  <Frame>
    <img alt="Supported European Payment Methods" src="/images/transactions/payments/european.png" style={{ maxHeight: '500px', width: 'auto' }} />
  </Frame>

  <Note>
    ये भुगतान तरीके वर्तमान में केवल इनके लिए उपलब्ध हैं:
      * केवल यूरो (EUR) मुद्रा
      * केवल एकमुश्त भुगतान (subscriptions के लिए उपलब्ध नहीं)

    इन भुगतान तरीकों के बारे में विस्तृत जानकारी के लिए हमारा [Payment Methods](/features/payment-methods) documentation देखें।
  </Note>

- **Subscription Billing Address में अपडेट**: अब निम्नलिखित माध्यमों से subscriptions के billing addresses को अपडेट करने की सुविधा जोड़ी गई है:
  * Customer Portal interface
  * Patch subscription API endpoint
