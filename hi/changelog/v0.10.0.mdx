## नई सुविधाएँ
- **Open Sourced Atlas**: Dodo Payments के integration को प्रदर्शित करने के लिए Next.js में लिखा गया एक demo application। [GitHub Repository](https://github.com/dodopayments/dodo-checkout-demo) और documentation [यहाँ](/developer-resources/integration-guide) देखें।
- **Feature-Request Section**: user feedback के आधार पर product roadmap को प्राथमिकता देने के लिए Dodo Payments dashboard में feature-request section जोड़ा गया।
- **Webhook Request Logs API**: webhook request logs को सूचीबद्ध करने और उनका विवरण प्राप्त करने के लिए APIs जोड़ी गईं।
- **Static Payment Links**: checkout process में अधिक flexibility प्रदान करने के लिए static payment links में और query parameters जोड़े गए। अधिक जानकारी के लिए [यहाँ](/developer-resources/integration-guide#4-static-payment-links) क्लिक करें।
- **Subscription List API**: सभी subscriptions प्राप्त करने के लिए एक API जोड़ी गई। विवरण के लिए [API Reference](/api-reference/subscriptions/get-subscriptions-1) देखें।

## छोटे सुधार और बग फिक्स
- उत्पाद और सब्सक्रिप्शन एपीआई प्रतिक्रियाओं को अतिरिक्त पैरामीटर के साथ बेहतर बनाया गया।
- एपीआई अनुरोधों के लिए दर सीमा लागू की गई, जो वर्तमान में प्रति सेकंड 20 अनुरोधों पर सेट है।
- दस्तावेज़ को अधिक उपयोगकर्ता-अनुकूल और नेविगेट करने में आसान बनाने के लिए सुधार किया गया।
- विभिन्न छोटे बग फिक्स और सुधार।
