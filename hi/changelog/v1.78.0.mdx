## नई विशेषताएँ

### 1. **संचार प्राथमिकताएँ**

   हमारी नवीनीकृत संचार प्राथमिकताओं के साथ सूचनाएँ प्राप्त करने का नियंत्रण लें। अपने कार्यप्रवाह के अनुसार ईमेल, पुश, और इन-ऐप नोटिफिकेशनों को कॉन्फ़िगर करें।

   <Frame>
     <img src="/images/communication-preferences/overview.png" alt="Communication Preferences overview showing notification settings" />
   </Frame>

   **मुख्य विशेषताएँ**

   - **नवीनीकृत ईमेल डिज़ाइन**: स्पष्ट कॉल-टू-एक्शन और बेहतर पठनीयता के साथ ताज़ा, आधुनिक ईमेल टेम्पलेट
   - **पुश नोटिफिकेशन्स**: नए बिक्री, विवाद, और भुगतान जैसे महत्वपूर्ण घटनाओं के लिए अपने मोबाइल उपकरण पर तुरंत अलर्ट प्राप्त करें
   - **विवरणात्मक नियंत्रण**: चुनें कि कौन सी घटनाएँ सूचनाओं को ट्रिगर करें और कौन से चैनलों के माध्यम से
   - **बहु-ईमेल समर्थन**: सूचनाएँ प्राप्त करने के लिए कई ईमेल पते जोड़ें
   - **ग्राहक ईमेल प्राथमिकताएँ**: कॉन्फ़िगर करें कि आपके ग्राहक कौन से ईमेल प्राप्त करें

   **नोटिफिकेशन श्रेणियाँ**

   | श्रेणी | विवरण |
   |----------|-------------|
   | **बिक्री और भुगतान** | नए बिक्री, सफल भुगतान, विफल भुगतान |
   | **भुगतान और रिफंड** | भुगतान पूर्णता, रिफंड अनुरोध, रिफंड पूर्णता |
   | **सदस्यताएँ** | नई सदस्यताएँ, नवीनीकरण, रद्दीकरण, योजना परिवर्तन |
   | **विवाद** | विवाद खोला गया, प्रमाण आवश्यक, विवाद हल हुआ |

   <Check>
   परिणाम: सूचनाओं द्वारा अपने व्यवसाय के बारे में जानकारी रखें, जो आपको जिस तरह से और जब चाहिए, बिल्कुल उस तरह से प्रदान की जाती हैं।
   </Check>

   अधिक जानकारी: [संचार प्राथमिकताओं की गाइड](/features/communication-preferences)

### 2. **चेकआउट सत्रों में कस्टम फ़ील्ड**

   चेकआउट के दौरान ग्राहकों से अतिरिक्त जानकारी इकट्ठा करने के लिए कस्टम फ़ील्ड का उपयोग करें। टेक्स्ट इनपुट, ड्रॉपडाउन, तिथियाँ, और अधिक जोड़ें ताकि आपको जरूरी डेटा मिल सके।

   **समर्थित फ़ील्ड प्रकार**

   | प्रकार | विवरण | उपयोग का मामला |
   |------|-------------|----------|
   | `text` | एकल-लाइन टेक्स्ट इनपुट | कंपनी का नाम, आदेश नोट्स |
   | `number` | अंकात्मक इनपुट | मात्रा, आयु |
   | `email` | ईमेल इनपुट के साथ सत्यापन | बिलिंग संपर्क ईमेल |
   | `url` | URL इनपुट के साथ सत्यापन | वेबसाइट, सामाजिक प्रोफाइल |
   | `date` | तिथि चुनने वाला | वितरण तिथि, कार्यक्रम तिथि |
   | `dropdown` | पूर्व निर्धारित विकल्पों में से चयन | आकार, रंग, योजना प्रकार |
   | `boolean` | हाँ/नहीं मानों के लिए चेकबॉक्स | शर्तों की स्वीकृति, न्यूज़लेटर में सम्मिलित होना |

   **यह कैसे काम करता है**

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     custom_fields: [
       {
         name: 'company_name',
         label: 'Company Name',
         type: 'text',
         required: true
       },
       {
         name: 'team_size',
         label: 'Team Size',
         type: 'dropdown',
         options: ['1-10', '11-50', '51-200', '200+'],
         required: true
       },
       {
         name: 'newsletter',
         label: 'Subscribe to our newsletter',
         type: 'boolean',
         required: false
       }
     ],
     return_url: 'https://yoursite.com/success'
   });
   ```

   **लाभ**

   - **लचीला डेटा संग्रह**: किसी भी जानकारी को इकट्ठा करें जो पूरा करने या व्यक्तिगतकरण के लिए आवश्यक है
   - **सत्यापन अंतर्निहित**: ईमेल और URL फ़ील्ड स्वचालित रूप से इनपुट प्रारूप को सत्यापित करता है
   - **अनिवार्य/वैकल्पिक नियंत्रण**: अपने आवश्यकताओं के अनुसार फ़ील्ड को अनिवार्य या वैकल्पिक के रूप में चिह्नित करें
   - **Webhook डिलीवरी**: कस्टम फ़ील्ड मानों को भुगतान webhook घटनाओं में शामिल किया गया है

   <Info>
   कस्टम फ़ील्ड मान भुगतान और चेकआउट सत्र प्रतिक्रियाओं के भीतर `custom_fields` वस्तु में लौटाए जाते हैं।
   </Info>

   अधिक जानकारी: [चेकआउट सत्र कस्टम फ़ील्ड](/developer-resources/checkout-session#custom-fields)

### 3. **चेकआउट भाषा समर्थन का विस्तार**

   चेकआउट पृष्ठ अब **21 भाषाएँ** समर्थन करता है, जो पहले 16 थीं। अपने ग्राहकों को बेहतर चेकआउट अनुभव के लिए उनकी मातृ भाषा में अधिक पहुँचें।

   **नए भाषाएँ जोड़ी गई**

   | भाषा | कोड |
   |----------|------|
   | कोरियाई | `ko` |
   | मलय | `ms` |
   | रोमानियाई | `ro` |
   | रूसी | `ru` |
   | थाई | `th` |

   **सभी समर्थित भाषाएँ**

   अरबी, चीनी, डच, अंग्रेजी, फ्रेंच, जर्मन, हिंदी, इंडोनेशियन, इटालियन, जापानी, कोरियाई, मलय, पुर्तगाली, रोमानियाई, रूसी, स्पेनिश, स्वीडिश, थाई, तुर्की, यूक्रेनी, वियतनामी।

   **विशिष्ट भाषा को बलात लागू करना**

   स्वचालित भाषा पहचान को ओवरराइड करने के लिए `force_language` पैरामीटर का उपयोग करें:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     force_language: 'ko', // Force Korean language
     return_url: 'https://yoursite.com/success'
   });
   ```

   <Tip>
   डिफ़ॉल्ट रूप से, चेकआउट पृष्ठ स्वचालित रूप से ग्राहक की पसंदीदा भाषा को उनके ब्राउज़र सेटिंग्स से पहचानता है। जब आप अपने वेबसाइट की भाषा के साथ निरंतरता सुनिश्चित करना चाहते हैं, तो `force_language` का उपयोग करें।
   </Tip>

   अधिक जानकारी: [चेकआउट भाषा समर्थन](/features/checkout#supported-languages)
