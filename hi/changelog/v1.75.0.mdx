## नई विशेषताएँ

### 1. **उत्पाद संग्रह**  
   
   संबंधित उत्पादों को एक साथ समूहित करें ताकि ग्राहक पोर्टल के भीतर एकीकृत चेकआउट अनुभव, योजना चयन, और सीधी अपग्रेड/डाउनग्रेड पथ मिल सकें।

   <Frame>
     <img src="/images/product-collection/checkout-page.png" alt="उत्पाद संग्रह चेकआउट पृष्ठ जो कई योजनाओं के विकल्प दिखा रहा है" />
   </Frame>

  **मुख्य लाभ**

   - **संग्रह-आधारित चेकआउट**: एक चेकआउट दृश्य में एक संग्रह के सभी उत्पादों को प्रदर्शित करें, जिससे ग्राहकों को उनकी पसंदीदा योजना की तुलना करने और चुनने में मदद मिलती है
   - **व्यवस्थित उत्पाद प्रबंधन**: संबंधित उत्पादों (जैसे, स्टार्टअप, प्रो, एंटरप्राइज) को एकल संग्रह के तहत समूहित करें
   - **ग्राहक पोर्टल एकीकरण**: ग्राहकों को एक ही संग्रह के भीतर उत्पादों के बीच अपग्रेड या डाउनग्रेड करने की सुविधा दें
   - **व्यापारी नियंत्रण**: प्रत्येक संग्रह के भीतर उत्पादों को सक्षम, अक्षम, और पुनः क्रमबद्ध करें

   **यह कैसे काम करता है**

   एक संग्रह के लिए चेकआउट सत्र बनाएँ:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_collection_id: 'pdc_abc123',
     product_cart: [], // Required: pass an empty array for collection checkout
     return_url: 'https://yoursite.com/return'
   });

   // Redirect customer to the checkout
   window.location.href = session.url;
   ```

   <Check>
   परिणाम: एक एकीकृत चेकआउट अनुभव जहां ग्राहक आपके संग्रह में सभी उपलब्ध उत्पादों को देख और चुन सकते हैं।
   </Check>

   <Info>
   संग्रह चेकआउट सब्सक्रिप्शन व्यवसायों के लिए आदर्श है जहां आप चाहते हैं कि ग्राहक खरीदारी से पहले योजनाओं की तुलना करें।
   </Info>

   अधिक जानें: [उत्पाद संग्रह गाइड](/features/product-collections)

### 2. **GBP मुद्रा के लिए RevolutPay & Billie भुगतान विधियाँ**  
   
   RevolutPay और Billie के साथ विस्तारित भुगतान विकल्प अब वैश्विक स्तर पर GBP एकमुश्त भुगतान लेनदेन के लिए उपलब्ध हैं, आपके ग्राहकों को भुगतान करने के लिए अधिक लचीलापन देते हैं।

   **नई भुगतान विधियाँ**

   | भुगतान विधि | समर्थित Länder | मुद्रा | सब्सक्रिप्शन सहायता |
   |---------------|---------------------|----------|---------------------|
   | **RevolutPay** | वैश्विक | GBP | नहीं (केवल एकमुश्त) |
   | **Billie** | वैश्विक | GBP | नहीं (केवल एकमुश्त) |

   - **RevolutPay** – Revolut उपयोगकर्ताओं के लिए तेज और निर्बाध भुगतान
   - **Billie** – B2B खरीदें अब, बाद में भुगतान करें समाधान जो व्यवसायों को अपने ग्राहकों को लचीले भुगतान की शर्तें प्रदान करने में सक्षम बनाता है

   <Info>
   ये भुगतान विधियाँ GBP लेनदेन के लिए स्वचालित रूप से उपलब्ध हैं। किसी अतिरिक्त कॉन्फ़िगरेशन की आवश्यकता नहीं है।
   </Info>

   अधिक जानें: [भुगतान विधियाँ](/features/payment-methods)

### 3. **चेकआउट सत्र पूर्वावलोकन**  
   
   सटीक मूल्य निर्धारण, करों, छूट और कुलों की गणना करने के लिए चेकआउट सत्रों का पूर्वावलोकन करें। ग्राहकों को चेकआउट करने से पहले वास्तविक मूल्य प्रदर्शित करें।

   **यह कैसे काम करता है**

   ```typescript
   const preview = await client.checkoutSessions.preview({
     product_cart: [
       { product_id: 'prod_123', quantity: 1 }
     ],
     billing_address: {
       country: 'US',
       state: 'CA',
       zipcode: '94102'
     },
     discount_code: 'SAVE20'
   });

   console.log('Subtotal:', preview.subtotal);
   console.log('Tax:', preview.tax);
   console.log('Discount:', preview.discount);
   console.log('Total:', preview.total);
   ```

   **उपयोग के मामले**

   - **कस्टम मूल्य निर्धारण प्रदर्शित करें**: चेकआउट से पहले सटीक कुल दिखाएं जिसमें कर शामिल हैं
   - **छूट मान्यता**: छूट कोडों की जांच करें और ग्राहकों को बचत दिखाएं
   - **बहु-मुद्रा समर्थन**: विभिन्न मुद्राओं में मूल्य निर्धारण का पूर्वावलोकन करें
   - **कार्ट सारांश**: वास्तविक समय मूल्य निर्धारण के साथ कस्टम कार्ट UI बनाएं

### 4. **योजना परिवर्तन अनुरोधों में मेटाडेटा समर्थन**  
   
   सब्सक्रिप्शन योजनाओं को बदलते समय कस्टम मेटाडेटा पास करें, जिससे योजना संक्रमण के दौरान आपके आंतरिक प्रणालियों के साथ बेहतर ट्रैकिंग और एकीकरण सक्षम हो सके।

   ```javascript
   // Adding metadata when changing a subscription plan
   await client.subscriptions.changePlan('sub_123', {
     product_id: 'prod_premium',
     proration_billing_mode: 'prorated_immediately',
     quantity: 1,
     metadata: {
       upgrade_reason: 'feature_request',
       previous_plan: 'basic',
       sales_rep: 'john@company.com'
     }
   });
   ```

  **उपयोग के मामले**

   - **अपग्रेड/डाउनग्रेड कारणों का ट्रैकिंग**: स्टोर करें कि ग्राहकों ने योजनाएँ क्यों बदलीं
   - **CRM रिकॉर्ड से लिंक करें**: बिक्री गतिविधियों के साथ योजना परिवर्तनों को जोड़ें
   - **आंतरिक वर्गीकरण**: रिपोर्टिंग और विश्लेषण के लिए योजना परिवर्तनों को टैग करें
   - **ऑडिट ट्रेल्स**: यह रिकॉर्ड रखें कि किसने योजना बदलाव शुरू किया

   <Info>
   मेटाडेटा वेबहुक घटनाओं में शामिल है, जिससे आपकी कस्टम डेटा के साथ योजना परिवर्तनों को प्रोसेस करना आसान हो जाता है।
   </Info>

   अधिक जानें: [मेटाडेटा गाइड](/api-reference/metadata) | [योजना परिवर्तन API](/api-reference/subscriptions/change-plan)

### 5. **भुगतान प्रतिक्रिया और भुगतान लिंक प्रतिक्रिया में `invoice_url` फ़ील्ड**  
   
   भुगतान प्रतिक्रिया और भुगतान लिंक प्रतिक्रिया में अब `invoice_url` फ़ील्ड शामिल है, जो प्रत्येक भुगतान से जुड़े चालान तक सीधे पहुंच प्रदान करता है।

   ```json
   {
     "payment_id": "pay_2IjeQm4hqU6RA4Z4kwDee",
     "status": "succeeded",
     "invoice_url": "https://dodopayments.com/invoices/inv_2IsUnWGtRKFLxk7xAQeyt",
     "amount": 9900,
     "currency": "USD",
     // ... other fields
   }
   ```

  **उपयोग के मामले**

   - **ग्राहक संचार**: चालान लिंक सीधे ग्राहकों को भेजें
   - **लेखांकन एकीकरण**: अपने लेखांकन सॉफ़्टवेयर में चालानों से भुगतानों को लिंक करें
   - **स्व-सर्विस पोर्टल**: ग्राहकों को उनके चालानों तक आसानी से पहुँचने की अनुमति दें
   - **रिकॉर्ड रखना**: चालान दस्तावेज़ों के लिए सीधे संदर्भ बनाए रखना

### 6. **कोड नाम द्वारा छूट मान्यता अंतिम बिंदु**  
   
   नए API अंतिम बिंदु कोड नाम (जैसे, "SAVE20") द्वारा छूट को मान्य करने और पुनर्प्राप्त करने के लिए, आंतरिक छूट ID का उपयोग करने के बजाय। चेकआउट पर लागू करने से पहले छूट पात्रता को सत्यापित करें।

   ```javascript
   // Validate a discount code before checkout
   const discount = await client.discounts.getByCode('SAVE20');

   console.log('Discount type:', discount.type);
   console.log('Discount value:', discount.amount);
   console.log('Valid until:', discount.expires_at);
   ```

  **लाभ**

   - **पूर्व-चेकआउट मान्यता**: चेकआउट सत्र बनाने से पहले छूट कोड की जांच करें
   - **वास्तविक समय फीडबैक**: ग्राहकों को दिखाएं कि उनका कोड मान्य है या नहीं
   - **त्रुटि हैंडलिंग**: अमान्य या समाप्त कोड जल्दी पकड़ें
   - **कस्टम छूट UIs**: त्वरित मान्यता के साथ छूट कोड इनपुट फ़ील्ड बनाएं

### 7. **ग्राहकों, छूट, और लाइसेंस कुंजी के लिए उन्नत फ़िल्टरिंग क्षमताएँ**  
   
   ग्राहकों, छूट, और लाइसेंस कुंजी को सूचीबद्ध करने के लिए नए API फ़िल्टर, जिससे आपकी डेटा को प्रोग्रामेटिक रूप से खोजना और प्रबंधित करना आसान हो जाता है।

   **ग्राहकों API फ़िल्टर**

   | फ़िल्टर | विवरण |
   |--------|-------------|
   | `email` | ग्राहक ईमेल द्वारा फ़िल्टर करें |
   | `name` | ग्राहक नाम द्वारा फ़िल्टर करें (आंशिक मिलान, केस-संवेदी) |
   | `created_at_gte` | इस समय मुहर्त पर या उसके बाद बनाए गए ग्राहकों को फ़िल्टर करें |
   | `created_at_lte` | इस समय मुहर्त पर या उसके पहले बने ग्राहकों को फ़िल्टर करें |

   ```javascript
   // Find customers by name created in the last 30 days
   const customers = await client.customers.list({
     name: 'John',
     created_at_gte: '2026-01-01T00:00:00Z'
   });
   ```

   **छूट API फ़िल्टर**

   | फ़िल्टर | विवरण |
   |--------|-------------|
   | `code` | छूट कोड द्वारा फ़िल्टर करें (आंशिक मिलान, केस-संवेदी) |
   | `discount_type` | छूट प्रकार द्वारा फ़िल्टर करें (प्रतिशत) |
   | `active` | सक्रिय स्थिति द्वारा फ़िल्टर करें (सत्य = समाप्त नहीं, असत्य = समाप्त) |
   | `product_id` | उत्पाद प्रतिबंध द्वारा फ़िल्टर करें (केवल वे छूट जो इस उत्पाद पर लागू होती हैं) |

   ```javascript
   // Find active percentage discounts for a specific product
   const discounts = await client.discounts.list({
     active: true,
     discount_type: 'percentage',
     product_id: 'prod_123'
   });
   ```

   **लाइसेंस कुंजी API फ़िल्टर**

   | फ़िल्टर | विवरण |
   |--------|-------------|
   | `customer_id` | ग्राहक ID द्वारा फ़िल्टर करें |
   | `status` | लाइसेंस कुंजी स्थिति द्वारा फ़िल्टर करें (`active`, `expired`, `disabled`) |
   | `product_id` | उत्पाद ID द्वारा फ़िल्टर करें |
   | `created_at_gte` | इस समय मुहर्त पर या उसके बाद बनाए गए लाइसेंस कुंजी को फ़िल्टर करें |
   | `created_at_lte` | इस समय मुहर्त पर या उसके पहले बनाए गए लाइसेंस कुंजी को फ़िल्टर करें |

   ```javascript
   // Find active license keys for a specific product
   const licenseKeys = await client.licenseKeys.list({
     status: 'active',
     product_id: 'prod_123'
   });
   ```
