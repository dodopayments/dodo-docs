## नई विशेषताएँ 🚀

### API Enhancements
- इनवॉइस API लॉन्च की गई, जो व्यापारियों और ग्राहकों को `payment_id` का उपयोग करके इनवॉइस डाउनलोड करने में सक्षम बनाती है। अधिक जानकारी के लिए [Invoice API](/api-reference/payments/get-invoice) दस्तावेज़ देखें।
- सब्सक्रिप्शन नवीनीकरण सूचनाओं के लिए नया `subscription.renewed` वेबहुक इवेंट लागू किया गया।

### प्लेटफ़ॉर्म अपडेट्स
- Dodo Payments [Wall of Love](https://dodopayments.com/wall-of-love) की शुरुआत की, जिसमें ग्राहक के प्रशंसापत्र प्रदर्शित हैं।
- सफल लेनदेन के लिए सोशल शेयरिंग फ़ंक्शनलिटी जोड़ी गई।
    <img src="/images/changelog/share-transaction.png" alt="Share Transaction Feature" style={{ maxHeight: '500px', width: 'auto' }} />
- गोपनीयता नीति, सेवा शर्तें और धनवापसी नीति दस्तावेज़ों के स्वचालित निर्माण के लिए पॉलिसी जेनरेटर टूल जारी किया। [पॉलिसी जेनरेटर आज़माएँ](https://dodopayments.com/tools/policy-generator)।

### दस्तावेज़ सुधार
- व्यापक गाइड प्रकाशित किए गए:
    - [सब्सक्रिप्शन इंटीग्रेशन गाइड](/developer-resources/subscription-integration-guide)
    - [वेबहुक इवेंट्स गाइड](/developer-resources/webhooks/intents/webhook-events-guide)

## सुधार और बग फिक्स 🔧

### API Updates
- उत्पाद-स्तर के ट्रायल पीरियड को ओवरराइड करने के लिए [Create Subscription API](/api-reference/subscriptions/post-subscriptions) में `trial_period_days` पैरामीटर जोड़ा गया।
- ग्राहक पहचान लॉजिक में सुधार: अब एक ही ईमेल के लिए भुगतान और सब्सक्रिप्शन दोनों में `customer_id` का एक समान उपयोग किया जा रहा है।
- विभिन्न प्रदर्शन अनुकूलन लागू किए गए और छोटे बग तय किए गए।
