## Adaptive Currency

Adaptive Currency ग्राहकों को अपनी पसंदीदा स्थानीय currency में भुगतान करने की सुविधा देता है, जिससे trust और conversion rates बेहतर होते हैं।

### यह कैसे काम करता है

1. **Enable**: **Settings → Business** से Adaptive Currency enable करें
2. **Select**: ग्राहक checkout पर सीधे currencies बदल सकते हैं
3. **Convert**: real-time FX rates का उपयोग करके prices dynamically convert की जाती हैं
4. **Display**: payment से पहले अंतिम payable amount पारदर्शी रूप से दिखाया जाता है

## Automatic Tax Calculation

ग्राहक के billing location के आधार पर taxes automatically calculate किए जाते हैं, जिससे manual setup के बिना GST, VAT और sales tax requirements का compliance सुनिश्चित होता है।

### Tax Calculation कैसे काम करता है

<Steps>
<Step title="Location Detection">
  Tax rules ग्राहक के country (और जहाँ लागू हो, region) के आधार पर लागू किए जाते हैं।
</Step>

<Step title="Dynamic Updates">
  Tax amount automatically update होता है जब:
  - Country बदलता है
  - Address update किया जाता है
</Step>

<Step title="Transparent Display">
  payment से पहले अंतिम tax breakdown स्पष्ट रूप से दिखाया जाता है।
</Step>
</Steps>

<Tip>
Tax calculation पूरी तरह automated है। standard digital goods और SaaS products के लिए किसी manual configuration की आवश्यकता नहीं है।
</Tip>

### API Integration

एक या अधिक stacked discount codes को पहले से apply करें या discount input field enable करें:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  discount_codes: ['WELCOME20'], // Pre-apply one or more codes (max 20, applied in order)
```

## Smart Address Collection

तेज़ completion के लिए checkout flexible address entry को support करता है।

### उपलब्ध Options

| Option | Description |
|--------|-------------|
| **Google Address Autofill** | autocomplete के साथ quick selection |
| **Manual Entry** | complete addresses के लिए full control |
| **Country Selection** | tax और compliance logic को निर्धारित करता है |
| **Minimal Address** | केवल country (और जहाँ tax के लिए आवश्यक हो वहाँ ZIP) collect करें — [Minimal Address Mode](#minimal-address-mode) देखें |

<Tip>
compliance सुनिश्चित करते हुए conversion को अधिकतम करने के लिए address collection speed, accuracy और global coverage में संतुलन बनाता है।
</Tip>

### Minimal Address Mode

अधिकतम conversion के लिए checkout friction कम करने हेतु minimal address collection enable करें। जब `minimal_address` को `true` पर set किया जाता है, तो checkout केवल ये details collect करता है:

- **Country** — tax determination के लिए हमेशा required
- **ZIP/Postal code** — केवल उन regions में जहाँ sales tax, VAT या GST calculation के लिए यह आवश्यक है

अन्य सभी address fields (street, city, state) skip कर दिए जाते हैं, जिससे checkout completion काफी तेज़ हो जाता है।

<Frame>
  <img src="/images/changelog/minimal-address.png" alt="Minimal address mode showing only country and ZIP/postal code fields on checkout" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  minimal_address: true,
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Full address collection default बना रहता है। Digital products और SaaS flows के लिए `minimal_address` enable करें, जहाँ complete billing details required नहीं होती हैं।
</Info>

<Card title="Minimal Address Reference" icon="address-card" href="/developer-resources/checkout-session#request-body">

</Card>

## Phone Number Collection

checkout session feature flags का उपयोग करके नियंत्रित करें कि phone number field checkout पर दिखाई दे या नहीं — और क्या यह required हो।

| Flag | Default | Behavior |
|------|---------|----------|
| `allow_phone_number_collection` | `true` | checkout form पर phone number field दिखाता है |
| `require_phone_number` | `false` | phone number field को required बनाता है (form validation non-empty value लागू करता है) |

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_abc', quantity: 1 }],
  feature_flags: {
    allow_phone_number_collection: true,
    require_phone_number: true
  },
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
`require_phone_number: true` के लिए `allow_phone_number_collection: true` आवश्यक है। जब phone collection disabled हो और phone number required हो, तो API sessions को reject करता है।
</Warning>

<Tip>
B2B SaaS, regulated industries या ऐसे किसी भी flow के लिए `require_phone_number` का उपयोग करें जहाँ support, fraud review या compliance के लिए verified contact channel आवश्यक हो।
</Tip>

## Custom Fields

custom form fields define करके checkout के दौरान ग्राहकों से अतिरिक्त information collect करें। यह company name, team size, referral source या किसी अन्य business-specific information जैसे data एकत्र करने के लिए उपयोगी है।

### उपलब्ध Field Types

| Type | Description |
|------|-------------|
| `text` | Single-line text input |
| `number` | Numeric input |
| `email` | validation के साथ Email address |
| `url` | validation के साथ URL |
| `date` | Date picker |
| `dropdown` | Predefined options में से select करें |
| `boolean` | Yes/No toggle |

### Example

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Customer responses webhook payloads (`payment.succeeded`, `subscription.active`) और API responses में `custom_field_responses` array के माध्यम से automatically शामिल किए जाते हैं। आप प्रत्येक checkout session के लिए अधिकतम 5 custom fields define कर सकते हैं।
</Info>

## Collection Checkout

Product Collections एक unified checkout experience enable करते हैं, जहाँ ग्राहक एक ही checkout में multiple related products (जैसे, Starter, Pro, Enterprise plans) देख और select कर सकते हैं।

### यह कैसे काम करता है

1. **All products displayed**: ग्राहक collection में प्रत्येक active product देखते हैं
2. **First product pre-selected**: collection का पहला product automatically select किया जाता है
3. **Compare options**: चुनने से पहले ग्राहक pricing और features की तुलना कर सकते हैं
4. **Single selection**: product select करने के बाद checkout standard payment flow के साथ आगे बढ़ता है

### Collection Checkout बनाना

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
`product_collection_id` का उपयोग करते समय एक empty `product_cart` array pass करें। Session creation के दौरान discount codes pre-apply नहीं किए जा सकते।
</Warning>

## Checkout Session Configuration

Checkout Sessions API का उपयोग करके checkout behavior नियंत्रित करें:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_codes: ['PROMO10'],
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  cancel_url: 'https://yoursite.com/pricing', // Optional: where to redirect on cancel
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
payment के बाद ग्राहक आपके `return_url` पर redirect किए जाते हैं, जिसमें query parameters automatically append किए जाते हैं -- इनमें `payment_id` या `subscription_id`, `status`, `email` और `license_key` (यदि लागू हो) शामिल हैं। पूरी list के लिए [Checkout Sessions guide](/developer-resources/checkout-session#request-body) देखें।
</Info>

</Info>

### Theme Configuration Options

| Property | Description |
|----------|-------------|
| `light` | light mode के लिए Color configuration |
| `dark` | dark mode के लिए Color configuration |
| `font_primary_url` | primary font के लिए URL |
| `font_secondary_url` | secondary font के लिए URL |
| `font_size` | Font size: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `font_weight` | Font weight: `normal`, `medium`, `bold`, `extraBold` |
| `radius` | UI elements के लिए Border radius (जैसे, `4px`, `0.5rem`, `8px`) |
| `pay_button_text` | pay button के लिए Custom text (जैसे, "Complete Purchase", "Subscribe Now") |

### Color Configuration (Light/Dark Mode)

प्रत्येक mode (`light` और `dark`) निम्नलिखित color properties को support करता है:

| Property | Description |
|----------|-------------|
| `bg_primary` | Background primary color |
| `bg_secondary` | Background secondary color |
| `text_primary` | Text primary color |
| `text_secondary` | Text secondary color |
| `text_placeholder` | Text placeholder color |
| `text_error` | Text error color |
| `text_success` | Text success color |
| `border_primary` | Border primary color |
| `border_secondary` | Border secondary color |
| `button_primary` | Primary button background color |
| `button_primary_hover` | Primary button hover color |
| `button_secondary` | Secondary button background color |
| `button_secondary_hover` | Secondary button hover color |
| `button_text_primary` | Primary button text color |
| `button_text_secondary` | Secondary button text color |
| `input_focus_border` | Input focus border color |

<Info>
सभी color fields standard CSS color formats स्वीकार करते हैं:
- Hex: `#fff`, `#ffffff`, `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`, `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`, `hsla(120, 100%, 50%, 0.5)`
- Named colors: `red`, `blue`, `transparent`
</Info>

### Example

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
```
