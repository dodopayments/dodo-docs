## अनुकूलनशील मुद्रा

अनुकूलनशील मुद्रा ग्राहकों को उनकी पसंदीदा स्थानीय मुद्रा में भुगतान करने की अनुमति देती है, जिससे विश्वास और रूपांतरण दरें बढ़ती हैं।

### यह कैसे काम करता है

1. **सक्षम करें**: अपने व्यवसाय सेटिंग्स से अनुकूलनशील मुद्रा सक्षम करें
2. **चुनें**: ग्राहक चेकआउट पर सीधे मुद्राएँ बदल सकते हैं
3. **परिवर्तित करें**: मूल्य वास्तविक समय के FX दरों का उपयोग करके गतिशील रूप से परिवर्तित होते हैं
4. **प्रदर्शित करें**: अंतिम देय राशि भुगतान से पहले पारदर्शी रूप से दिखाई जाती है

## बहुभाषी चेकआउट

डोडो पेमेंट्स चेकआउट पृष्ठ पर कई भाषाओं का समर्थन करता है, जिससे ग्राहक अपनी पसंदीदा भाषा में भुगतान पूरा कर सकते हैं।

- UI पाठ, लेबल, और सिस्टम संदेश स्थानीयकृत हैं

## स्वचालित कर गणना

कर ग्राहक के बिलिंग स्थान के आधार पर स्वचालित रूप से गणना की जाती है, जिससे जीएसटी, वैट, और बिक्री कर आवश्यकताओं के अनुपालन को बिना किसी मैन्युअल सेटअप के सुनिश्चित किया जा सके।

### कर गणना कैसे काम करती है

<Steps>
<Step title="स्थान पहचान">
  कर नियम ग्राहक के देश (और यदि आवश्यक हो तो क्षेत्र) के आधार पर लागू होते हैं।
</Step>

<Step title="गतिशील अपडेट">
  कर की राशि स्वचालित रूप से अपडेट होती है जब:
  - देश बदला जाता है
  - पता अपडेट किया जाता है
</Step>

<Step title="स्पष्ट प्रदर्शन">
  अंतिम कर विवरण भुगतान से पहले स्पष्ट रूप से दिखाया जाता है।
</Step>
</Steps>

<Tip>
कर गणना पूरी तरह से स्वचालित है। मानक डिजिटल सामान और SaaS उत्पादों के लिए कोई मैन्युअल कॉन्फ़िगरेशन आवश्यक नहीं है।
</Tip>

## व्यापार कर आईडी समर्थन

पंजीकृत व्यवसायों के लिए, चेकआउट ग्राहकों को उनके व्यापार कर आईडी (जैसे, VAT/GST नंबर) दर्ज करने की अनुमति देता है।

### कर आईडी दर्ज करने पर क्या होता है

- कर पात्रता को वास्तविक समय में मान्य किया जाता है
- लागू कर छूट या रिवर्स-चार्ज नियम लागू होते हैं
- चेकआउट पर कर की राशि तुरंत अपडेट होती है

## छूट कोड

ग्राहक सीधे चेकआउट पृष्ठ पर आपके द्वारा डैशबोर्ड में बनाए गए छूट या प्रचार कोड को लागू कर सकते हैं।

### चेकआउट अनुभव

1. ग्राहक छूट कोड दर्ज करता है
2. छूट तुरंत मान्य की जाती है
3. अपडेट की गई कीमत और बचत स्पष्ट रूप से दिखाई जाती है

<Frame>
  <img src="/images/checkout/c4.png" alt="चेकआउट पर छूट कोड प्रविष्टि" style={{ width: '70%' }}/>

### API एकीकरण

छूट कोड को पूर्व-लगाना या छूट इनपुट फ़ील्ड को सक्षम करना:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  discount_code: 'WELCOME20', // Pre-apply a code
  feature_flags: {
    allow_discount_code: true // Show discount input field
  },
  return_url: 'https://yoursite.com/return'
});
```

## स्मार्ट पता संग्रहण

चेकआउट तेज़ पूर्णता के लिए लचीले पता प्रविष्टि का समर्थन करता है।

### उपलब्ध विकल्प

| विकल्प | विवरण |
|--------|-------------|
| **गूगल पता ऑटॉफिल** | ऑटो-पूर्ण के साथ त्वरित चयन |
| **मैनुअल प्रविष्टि** | पूर्ण पतों के लिए पूर्ण नियंत्रण |
| **देश चयन** | कर और अनुपालन तर्क को संचालित करते हैं |

<Tip>
पता संग्रह गति, सटीकता और वैश्विक कवरेज को संतुलित करता है ताकि रूपांतरण को अधिकतम किया जा सके जबकि अनुपालन सुनिश्चित किया जा सके।
</Tip>

## कस्टम फ़ील्ड

चेकआउट के दौरान ग्राहकों से अतिरिक्त जानकारी संकलित करने के लिए कस्टम फ़ॉर्म फ़ील्ड परिभाषित करें। यह कंपनी का नाम, टीम का आकार, संदर्भ स्रोत, या किसी अन्य व्यावसायिक-संबंधित जानकारी इकट्ठा करने के लिए उपयोगी है।

### उपलब्ध फ़ील्ड प्रकार

| प्रकार | विवरण |
|------|-------------|
| `text` | एकल-लाइन टेक्स्ट इनपुट |
| `number` | संख्यात्मक इनपुट |
| `email` | वैधता के साथ ईमेल पता |
| `url` | वैधता के साथ URL |
| `date` | दिनांक Picker |
| `dropdown` | पूर्व-निर्धारित विकल्पों में से चुनें |
| `boolean` | हां/नहीं स्विच |

### उदाहरण

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
ग्राहक की प्रतिक्रियाएँ स्वचालित रूप से वेबहुक लोड में शामिल की जाती हैं (`payment.succeeded`, `subscription.created`) और API प्रतिक्रियाओं के माध्यम से `custom_field_responses` ऐरे। आप प्रति चेकआउट सत्र अधिकतम 5 कस्टम फ़ील्ड परिभाषित कर सकते हैं।
</Info>

<Card title="कस्टम फ़ील्ड गाइड" icon="input-text" href="/developer-resources/checkout-session#15-collecting-custom-fields">
  कस्टम फ़ील्ड कॉन्फ़िगरेशन और उत्तरों को एक्सेस करने के बारे में अधिक जानें।
</Card>

## गोपनीयता नीति और शर्तों की स्वीकृति

कानूनी और अनुपालन पारदर्शिता सुनिश्चित करने के लिए:

- चेकआउट पर [गोपनीयता नीति](https://dodopayments.com/privacy-policy) और [क्रेता शर्तें](https://dodopayments.com/buyer-terms) लिंक स्पष्ट रूप से प्रदर्शित होते हैं
- ग्राहक भुगतान पूरा करने से पहले इनकी स्पष्ट रूप से स्वीकृति देते हैं

<Info>
यह वैश्विक उपभोक्ता सुरक्षा और डेटा गोपनीयता आवश्यकताओं को पूरा करने में सहायक है जिसमें जीडीपीआर अनुपालन भी शामिल है।
</Info>

## संग्रह चेकआउट

उत्पाद संग्रह एक एकीकृत चेकआउट अनुभव सक्षम करते हैं जहां ग्राहक एक ही चेकआउट में कई संबंधित उत्पादों (जैसे, स्टार्टर्स, प्रो, एंटरप्राइज योजनाएँ) को देख और चुन सकते हैं।

### यह कैसे काम करता है

1. **सभी उत्पाद प्रदर्शित किए गए**: ग्राहक संग्रह में हर सक्रिय उत्पाद देखते हैं
2. **पहला उत्पाद पूर्व-चयनित**: संग्रह में पहला उत्पाद स्वचालित रूप से चुना जाता है
3. **विकल्पों की तुलना**: ग्राहक चयन करने से पहले मूल्य निर्धारण और विशेषताओं की तुलना कर सकते हैं
4. **एकल चयन**: एक उत्पाद का चयन करने के बाद, चेकआउट मानक भुगतान प्रवाह के साथ आगे बढ़ता है

### संग्रह चेकआउट बनाना

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
जब `product_collection_id` का उपयोग कर रहे हैं, तो एक खाली `product_cart` ऐरे पास करें। सत्र निर्माण में छूट कोड पूर्व-लागू नहीं किए जा सकते हैं।
</Warning>

## चेकआउट सत्र कॉन्फ़िगरेशन

चेकआउट व्यवहार को नियंत्रित करने के लिए Checkout Sessions API का उपयोग करें:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_code: 'PROMO10',
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
भुगतान के बाद, ग्राहकों को आपके `return_url` पर पुनर्निर्देशित किया जाता है जिसमें स्वचालित रूप से क्वेरी पैरामीटर जोड़े जाते हैं -- जिसमें `payment_id` या `subscription_id`, `status`, `email`, और `license_key` (यदि लागू हो) शामिल हैं। पूरी सूची के लिए [Checkout Sessions guide](/developer-resources/checkout-session#request-body) देखें।
</Info>

## चेकआउट थीम कस्टमाइजेशन

API के माध्यम से चेकआउट सत्र बनाते समय `customization.theme_config` पैरामीटर का उपयोग करके चेकआउट पृष्ठ की उपस्थिति को अपने ब्रांड के साथ मेल खाने के लिए कस्टमाइज़ करें। रंग, फ़ॉन्ट, सीमा त्रिज्या, और बटन पाठ दोनों हल्के और गहरे मोड के लिए कॉन्फ़िगर करें।

<Frame>
  <img src="/images/checkout/theme-example.png" alt="कस्टम थीम वाला चेकआउट पृष्ठ"/>
</Frame>

<Info>
यह अनुभाग **सर्वर-तरफ API** थीम कॉन्फ़िगरेशन को `customization.theme_config` का उपयोग करते हुए कवर करता है। यदि आप **Checkout SDK** (ओवरले या इनलाइन चेकआउट) का उपयोग कर रहे हैं, तो [Overlay Checkout](/developer-resources/overlay-checkout#theme-customization) या [Inline Checkout](/developer-resources/inline-checkout#theme-customization) में थीम कस्टमाइजेशन अनुभागों को देखें जो camelCase गुणों का उपयोग करते हैं (जैसे, `bgPrimary` के बजाय `bg_primary`)।
</Info>

### थीम कॉन्फ़िगरेशन विकल्प

| संपत्ति | विवरण |
|----------|-------------|
| `light` | हल्के मोड के लिए रंग कॉन्फ़िगरेशन |
| `dark` | गहरे मोड के लिए रंग कॉन्फ़िगरेशन |
| `font_primary_url` | प्राथमिक फ़ॉन्ट के लिए URL |
| `font_secondary_url` | द्वितीयक फ़ॉन्ट के लिए URL |
| `font_size` | फ़ॉन्ट आकार: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `font_weight` | फ़ॉन्ट वजन: `normal`, `medium`, `bold`, `extraBold` |
| `radius` | UI तत्वों के लिए सीमा त्रिज्या (जैसे, `4px`, `0.5rem`, `8px`) |
| `pay_button_text` | भुगतान बटन के लिए कस्टम टेक्स्ट (जैसे, "खरीदारी समाप्त करें", "अभी सदस्यता लें") |

### रंग कॉन्फ़िगरेशन (हल्का/गहरा मोड)

प्रत्येक मोड (`light` और `dark`) निम्नलिखित रंग गुणों का समर्थन करता है:

| संपत्ति | विवरण |
|----------|-------------|
| `bg_primary` | बैकग्राउंड प्राथमिक रंग |
| `bg_secondary` | बैकग्राउंड द्वितीयक रंग |
| `text_primary` | टेक्स्ट प्राथमिक रंग |
| `text_secondary` | टेक्स्ट द्वितीयक रंग |
| `text_placeholder` | टेक्स्ट स्थानांकित रंग |
| `text_error` | टेक्स्ट त्रुटि रंग |
| `text_success` | टेक्स्ट सफल रंग |
| `border_primary` | सीमा प्राथमिक रंग |
| `border_secondary` | सीमा द्वितीयक रंग |
| `button_primary` | प्राथमिक बटन बैकग्राउंड रंग |
| `button_primary_hover` | प्राथमिक बटन होवर रंग |
| `button_secondary` | द्वितीयक बटन बैकग्राउंड रंग |
| `button_secondary_hover` | द्वितीयक बटन होवर रंग |
| `button_text_primary` | प्राथमिक बटन टेक्स्ट रंग |
| `button_text_secondary` | द्वितीयक बटन टेक्स्ट रंग |
| `input_focus_border` | इनपुट फोकस सीमा रंग |

<Info>
सभी रंग फ़ील्ड मानक CSS रंग स्वरूपों को स्वीकार करते हैं:
- हेक्स: `#fff`, `#ffffff`, `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`, `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`, `hsla(120, 100%, 50%, 0.5)`
- नामित रंग: `red`, `blue`, `transparent`
</Info>

### उदाहरण

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
आपको सभी रंग गुणों को निर्दिष्ट करने की आवश्यकता नहीं है। कोई भी निर्दिष्ट न की गई गुण डिफ़ॉल्ट थीम मानों का उपयोग करेंगी।
</Tip>
