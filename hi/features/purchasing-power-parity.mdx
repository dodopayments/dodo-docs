[ParityDeals](https://www.paritydeals.com/) और [Evendeals](https://www.evendeals.com/integrations/dodo-payments) प्लेटफॉर्म हैं जो ग्राहक की भौगोलिक स्थिति के आधार पर स्वचालित मूल्य निर्धारण ऑप्टीमाइज़ेशन को सक्षम करते हैं, जिसे आमतौर पर "पर्चेसिंग पावर पैरिटी" (PPP) मूल्य निर्धारण कहा जाता है।

आप सीधे Dodo Payments स्टोरफ्रंट पर डिस्काउंट बैनर्स एम्बेड नहीं कर सकते (कस्टम स्क्रिप्ट समर्थित नहीं हैं), लेकिन आप इन उपकरणों को अपने स्वयं के वेबसाइट या एप्लिकेशन पर प्रभावी ढंग से लागू कर सकते हैं।

स्थान-आधारित, छुट्टियों और समय-आधारित सौदों को अनुकूलन योग्य बैनरों के साथ सेट करें।
कूपन सिंक और रिफ्रेश नियमों को एक बार और सब्सक्रिप्शन उत्पादों के लिए स्वचालित करें।
Dodo Payments डैशबोर्ड में मैन्युअली डिस्काउंट कोड बनाने और प्रबंधित करने का तरीका जानें।
अपने बिक्री, छूट, और API कुंजियों को केंद्रीय डैशबोर्ड में एक्सेस करें।

## संयोजन चुनना

दोनों प्लेटफॉर्म स्वचालित रूप से डिस्काउंट कोड बनाने और प्रबंधित करने के लिए Dodo Payments के साथ सीधे एकीकृत होते हैं। अपनी आवश्यकताओं के अनुसार सबसे उपयुक्त उपकरण चुनने के लिए नीचे दिए गए तुलना का उपयोग करें।

## ParityDeals

जब ParityDeals आपके वेबसाइट में एकीकृत होता है, तो योग्य विज़िटर एक बैनर देखेंगे जिसमें एक स्थान-आधारित छूट कोड शामिल होगा जिसे वे चेकआउट पर उपयोग कर सकते हैं। इन डिस्काउंट कोड्स को स्वचालित रूप से ParityDeals द्वारा बनाया और प्रबंधित किया जाता है और वे आपके **Dodo Payments डैशबोर्ड** में **बिक्री → छूट** के तहत दिखाई देंगे।

<img src="/images/ppp/1.png" alt="ParityDeals डिस्काउंट बैनर उदाहरण" />

### सेटअप

Visit [app.paritydeals.com](https://app.paritydeals.com/) and create an account.
Dodo Payments डैशबोर्ड में, **Developers → API Keys** पर जाएं और एक नया API बनाएं।

साइन इन करने के बाद, सौदे बनाने का विकल्प ढूंढें। ड्रॉपडाउन मेनू से **"Create Deals via Dodo Payments"** चुनें।
Dodo Payments डैशबोर्ड में, **Developers → API Keys** पर नेविगेट करें और **"Create New API"** पर क्लिक करें।

<img src="/images/ppp/2.png" alt="Dodo Payments के माध्यम से सौदे बनाना" />

अपने **Dodo Payments डैशबोर्ड** में लॉग इन करें और **Developers → API Keys** पर नेविगेट करें। **"Create New API"** पर क्लिक करें।

अपने API कुंजी को वर्णनात्मक नाम दें (उदाहरण के लिए, 'ParityDeals') ताकि आप इसे बाद में पहचान सकें।

<img src="/images/ppp/3.png" alt="Dodo Payments में एक नया API कुंजी बनाना" />

आपने तैयार की गई API कुंजी कॉपी करें और इसे ParityDeals इंटरफेस में पेस्ट करें ताकि अपने Dodo Payments खाते के साथ कनेक्शन स्थापित कर सकें।

<img src="/images/ppp/4.png" alt="ParityDeals से API कुंजी कनेक्ट करना" />

एक बार कनेक्ट होने के बाद, ParityDeals आपके Dodo Payments उत्पाद कैटलॉग को फेच करेगा। उन उत्पादों का चयन करें जिन्हें आप अपने सौदों के साथ जोड़ना चाहते हैं।

<img src="/images/ppp/5.png" alt="ParityDeals के लिए उत्पादों का चयन" />

अपना वेबसाइट URL दर्ज करें और वैकल्पिक रूप से विशिष्ट लक्षित पृष्ठ चुनें जहाँ डिस्काउंट बैनर दिखाई देना चाहिए। फिर अपनी पसंद का सौदा प्रकार चुनें:
- स्थान-आधारित सौदे
- छुट्टियों के सौदे
- समय-आधारित फ्लैश सौदे

<img src="/images/ppp/6.png" alt="सौदा सेटिंग्स को कॉन्फ़िगर करना" />

उन देशों का चयन करें जहाँ आप स्थानीयकृत छूट प्रदान करना चाहते हैं और प्रत्येक के लिए छूट प्रतिशत को परिभाषित करें। ParityDeals अनुशंसित डिफॉल्ट्स प्रदान करता है जिन्हें आप आवश्यकतानुसार समायोजित कर सकते हैं।

<img src="/images/ppp/7.png" alt="देश-आधारित छूट नियम सेट करना" />

अपने डिस्काउंट बैनर को डिजाइन करें, पाठ अनुकूलित करें, रंग और लेआउट का चयन करें, और बैनर स्थान (पृष्ठ के ऊपरी या निचले हिस्से) को चुनें। यह बैनर आपके कॉन्फ़िगर किए गए नियमों के आधार पर योग्य विज़िटर्स को प्रदर्शित होगा।

<img src="/images/ppp/8.png" alt="डिस्काउंट बैनर को अनुकूलित करना" />

अपने सौदे को सहेजने के बाद, ParityDeals एक स्क्रिप्ट उत्पन्न करेगा। इस स्क्रिप्ट को अपनी वेबसाइट कोड में जोड़ें (आमतौर पर `<head>` सेक्शन में)। यह स्क्रिप्ट स्वचालित रूप से विज़िटर के स्थानों का पता लगाती है और उचित डिस्काउंट बैनर प्रदर्शित करती है।

<img src="/images/ppp/9.png" alt="ParityDeals एकीकरण स्क्रिप्ट" />

### अतिरिक्त विशेषताएँ

ParityDeals के साथ, आप साल भर [स्वचालित समय-आधारित छूट](https://www.paritydeals.com/features/time-based-discounts/) और [छुट्टियों के प्रमोशन](https://www.paritydeals.com/features/holiday-based-discounts/) की पेशकश भी कर सकते हैं। अधिक विवरण के लिए, [ParityDeals डॉक्यूमेंटेशन](https://www.paritydeals.com/docs/) देखें।

## Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) एक अन्य प्लेटफ़ॉर्म है जो Dodo Payments के साथ एकीकृत होता है ताकि स्थान-आधारित पर्चेसिंग पावर पैरिटी मूल्य निर्धारण की पेशकश कर सके। यह एक बार और सब्सक्रिप्शन दोनों उत्पादों का समर्थन करता है।

<img src="/images/ppp/evendeals-hero.png" alt="Evendeals Dodo Payments एकीकरण अवलोकन" />

### प्रमुख विशेषताएँ

- **ऑटो कूपन सिंक** — कूपन Dodo Payments में स्वचालित रूप से बनाए और प्रबंधित किए जाते हैं
- **प्रतिशत छूट** — प्रत्येक देश समूह के लिए प्रतिशत-ऑफ छूट की पेशकश करें
- **सब्सक्रिप्शन समर्थन** — छूट सब्सक्रिप्शन बिलिंग साइकल्स पर लागू होती है
- **ऑटो-रिफ्रेश नियम** — कूपन कोडों को समय अंतराल, पुनर्चक्रण संख्या, या दृश्य संख्या द्वारा स्वयं बदलें ताकि दुर्व्यवहार रोका जा सके

Evendeals द्वारा बनाए गए डिस्काउंट कोड स्वचालित रूप से आपके Dodo Payments डैशबोर्ड में बिक्री → छूट के तहत दिखाई देंगे।

<img src="/images/ppp/evendeals-features.png" alt="Evendeals के लिए Dodo Payments एकीकरण के लिए प्रमुख विशेषताएँ" />

### सेटअप

Dodo Payments डैशबोर्ड में, **Developers → API Keys** पर जाएं और एक नया कुंजी उत्पन्न करें।
इसके बाद, अपने [Evendeals डैशबोर्ड](https://www.evendeals.com/signin) में, **Integrations** पर नेविगेट करें, Dodo Payments कार्ड ढूंढें और अपनी API कुंजी पेस्ट करें।

अपने [Evendeals डैशबोर्ड](https://www.evendeals.com/signin) में, **Integrations** पर नेविगेट करें, Dodo Payments कार्ड ढूंढें और अपनी API कुंजी पेस्ट करें।

प्रत्येक देश समूह के लिए प्रतिशत छूट सेट करें और Sync पर हिट करें। Evendeals Dodo Payments में स्वचालित रूप से कूपन बनाता है।

सिंक के बाद, अपने Dodo Payments डैशबोर्ड में **बिक्री → छूट** खोलें ताकि यह सुनिश्चित किया जा सके कि उत्पन्न कूपन दिखाई दे रहे हैं। प्रत्येक कूपन का एक पहचाने जाने योग्य Evendeals प्रीफ़िक्स होगा।

<img src="/images/ppp/evendeals-setup.png" alt="Dodo Payments के लिए Evendeals सेटअप गाइड" />

दोनों ParityDeals और Evendeals निर्बाध रूप से Dodo Payments के साथ काम करते हैं ताकि आप अपनी वैश्विक मूल्य निर्धारण रणनीति को ऑप्टिमाइज़ कर सकें। अधिक विवरण के लिए, [ParityDeals डाक्यूमेंटेशन](https://www.paritydeals.com/docs/) या [Evendeals Dodo Payments संयोजन पृष्ठ](https://www.evendeals.com/integrations/dodo-payments) पर जाएं।
