<Info>
Purchasing Power Parity (PPP) ग्राहक से आपके सूची मूल्य का एक हिस्सा लेता है, जो उस देश पर आधारित होता है जहाँ से वह खरीदारी करता है। \$20 का उत्पाद बिना discount code और दूसरी price list के **भारत में \$6.00** में बेचा जा सकता है।
</Info>

## Purchasing Power Parity क्या है?

हर जगह एक ही कीमत समान रूप से सस्ती नहीं होती। संयुक्त राज्य अमेरिका में \$20 की खरीदारी छोटी है, जबकि फिलीपींस में बड़ी। PPP pricing इस अंतर को संतुलित करती है।

Dodo Payments हर देश के लिए एक प्रतिशत रखता है। यह प्रतिशत **आपके सूची मूल्य का वह हिस्सा है जिसका भुगतान ग्राहक करता है**। भारत का मान 30 है, इसलिए भारत में ग्राहक कीमत का 30% भुगतान करता है। संयुक्त राज्य अमेरिका का मान 100 है, इसलिए वहाँ कुछ नहीं बदलता।

आप हर उस product price के लिए PPP चालू करते हैं जिस पर आप इसे लागू करना चाहते हैं। जिन products को आप इसमें शामिल नहीं करते, उनकी सामान्य कीमत हर जगह बनी रहती है।

<Note>
PPP के लिए [Adaptive Currency](/features/adaptive-currency) आवश्यक है। पहले Adaptive Currency चालू करें।
</Note>

## मुख्य लाभ

- **कीमत-संवेदनशील बाज़ारों तक पहुँचें**: अपनी मूल कीमत कम किए बिना स्थानीय कीमत पर बेचें।
- **कोई banner और script नहीं**: checkout पर कीमत सही होती है। आपकी website में कुछ नहीं जोड़ा जाता।
- **discount codes प्रबंधित करने की आवश्यकता नहीं**: कुछ बनाने, बदलने या रद्द करने की जरूरत नहीं।
- **प्रति-product नियंत्रण**: starter plan को शामिल करें और enterprise plan को अलग रखें।
- **हर जगह काम करता है**: one-time, subscription और usage-based products।

## Purchasing Power Parity सक्षम करें

<Steps>
<Step title="Enable Adaptive Currency">
**Settings → Business** पर जाएँ। **Business Settings** में **Adaptive Currency** चालू करें। इसके बिना PPP कुछ नहीं करता।

  <img src="/images/ppp/adaptive-currency-toggle.png" alt="Business Settings में Adaptive Currency और Purchasing Power Parity" style={{ maxHeight: '360px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Review your country percentages">
**Purchasing Power Parity** के अंतर्गत **Edit** पर क्लिक करके **Country Prices** खोलें। किसी भी देश का प्रतिशत बदलें, फिर **Save Changes** पर क्लिक करें।

हर देश द्वारा भुगतान की जाने वाली राशि देखने के लिए **Example product price** सेट करें। टाइप करते ही **Your Price** कॉलम अपडेट होता है। नाम या code से देश खोजने के लिए search box का उपयोग करें।

<Frame>
  <img src="/images/ppp/country-percentages.png" alt="Country Prices dialog जिसमें प्रत्येक देश के लिए प्रतिशत और परिणामी कीमत है" style={{ maxHeight: '620px', width: 'auto' }} />
</Frame>

<Note>
ये प्रतिशत पूरे business पर लागू होते हैं। Purchasing Power Parity चालू वाला हर product इनका उपयोग करता है।
</Note>
</Step>

<Step title="Turn PPP on for a product">
Product खोलें। **Pricing** section में **Purchasing Power Parity** चुनें, फिर product save करें।

जिन products को आप नहीं चुनते, उनकी सामान्य कीमत हर जगह बनी रहती है।

<Frame>
  <img src="/images/ppp/product-toggle.png" alt="Product Pricing section में Purchasing Power Parity चुना गया है" style={{ maxHeight: '440px', width: 'auto' }} />
</Frame>

<Warning>
Adaptive Currency बंद होने पर आप इसे नहीं चुन सकते। पहले Adaptive Currency चालू करें।
</Warning>
</Step>

<Step title="Confirm at checkout">
<Check>
ऐसे billing country के साथ test checkout खोलें जिसका प्रतिशत 100 से कम हो। पुष्टि करें कि कम कीमत दिखाई दे रही है।
</Check>
</Step>
</Steps>

## कीमत की गणना कैसे की जाती है

देश का प्रतिशत आपके सूची मूल्य से गुणा होता है:

```
price paid = list price × country percentage ÷ 100
```

भारत के ऐसे ग्राहक के लिए \$20.00 का product, जिसका प्रतिशत 30 है:

```
2000 × 30 ÷ 100 = 600   →   $6.00
```

Dodo Payments मुद्रा रूपांतरण से पहले base price पर प्रतिशत लागू करता है। इसके बाद [Adaptive Currency](/features/adaptive-currency) परिणाम को ग्राहक की मुद्रा में बदलता है।

<Info>
Dodo Payments checkout पर ग्राहक के **billing country** से देश की जानकारी लेता है।
</Info>

### देश के प्रतिशत

हर देश का प्रतिशत **30 और 100** के बीच होता है:

- **100** का अर्थ है कि ग्राहक आपकी पूरी कीमत का भुगतान करता है। इसमें कोई कमी नहीं होती।
- **30** वह सबसे कम मान है जिसे आप सेट कर सकते हैं। इसलिए अधिकतम कमी 70% है।

डिफ़ॉल्ट मान World Bank के price level index data से लिए जाते हैं। Dodo Payments हर मान को निकटतम 5 तक round करता है, न्यूनतम 30 रखता है और अधिकतम 100 तक सीमित करता है। हर supported country का एक मान होता है। आप इनमें से किसी को भी बदल सकते हैं।

दायरा दिखाने के लिए यहाँ कुछ डिफ़ॉल्ट मान दिए गए हैं:

| देश | प्रतिशत | \$20 का product इस कीमत पर बिकता है |
| :--- | :---: | :--- |
| United States | 100 | \$20.00 |
| United Kingdom | 85 | \$17.00 |
| Germany | 75 | \$15.00 |
| Japan | 60 | \$12.00 |
| Brazil | 45 | \$9.00 |
| South Africa | 40 | \$8.00 |
| Philippines | 35 | \$7.00 |
| India | 30 | \$6.00 |

<Note>
पूरी सूची में 217 देश शामिल हैं। हर मान देखने के लिए अपने dashboard में country table खोलें।
</Note>

## API के माध्यम से सक्षम करें

PPP प्रति product चालू किया जाता है, जिसमें `purchasing_power_parity` field का उपयोग होता है। डिफ़ॉल्ट मान `false` है।

<Info>
देशों के प्रतिशत केवल dashboard में प्रबंधित किए जाते हैं। वे public API का हिस्सा नहीं हैं।
</Info>

<CodeGroup>

```typescript theme={null}
import DodoPayments from 'dodopayments';

const client = new DodoPayments({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: 'test_mode',
});

const product = await client.products.create({
  name: 'Starter Plan',
  tax_category: 'saas',
  price: {
    type: 'one_time_price',
    currency: 'USD',
    price: 2000,
    discount: 0,
    purchasing_power_parity: true,
  },
});
```

```python theme={null}
import os
from dodopayments import DodoPayments

client = DodoPayments(
    bearer_token=os.environ.get("DODO_PAYMENTS_API_KEY"),
    environment="test_mode",
)

product = client.products.create(
    name="Starter Plan",
    tax_category="saas",
    price={
        "type": "one_time_price",
        "currency": "USD",
        "price": 2000,
        "discount": 0,
        "purchasing_power_parity": True,
    },
)
```

```go theme={null}
package main

import (
	"context"
	"os"

	"github.com/dodopayments/dodopayments-go"
	"github.com/dodopayments/dodopayments-go/option"
)

func main() {
	client := dodopayments.NewClient(
		option.WithBearerToken(os.Getenv("DODO_PAYMENTS_API_KEY")),
	)

	_, err := client.Products.New(context.TODO(), dodopayments.ProductNewParams{
		Name:        dodopayments.F("Starter Plan"),
		TaxCategory: dodopayments.F(dodopayments.ProductNewParamsTaxCategorySaas),
		Price: dodopayments.F[dodopayments.PriceUnionParam](
			dodopayments.PriceOneTimePriceParam{
				Type:                  dodopayments.F(dodopayments.PriceOneTimePriceTypeOneTimePrice),
				Currency:              dodopayments.F(dodopayments.CurrencyUsd),
				Price:                 dodopayments.F(int64(2000)),
				Discount:              dodopayments.F(int64(0)),
				PurchasingPowerParity: dodopayments.F(true),
			},
		),
	})
	if err != nil {
		panic(err)
	}
}
```

</CodeGroup>

<Warning>
यदि आपके business के लिए Adaptive Currency बंद है, तो request `422 ppp_not_enabled_for_business` के साथ विफल हो जाती है। पहले इसे चालू करें।
</Warning>

## महत्वपूर्ण व्यवहार

| व्यवहार | विवरण |
| :--- | :--- |
| **Adaptive Currency आवश्यक है** | Adaptive Currency बंद होने पर PPP कुछ नहीं करता। |
| **डिफ़ॉल्ट रूप से बंद** | हर price `purchasing_power_parity: false` से शुरू होती है। |
| **Localized prices को प्राथमिकता मिलती है** | Matching [Localized Pricing](/features/localized-pricing) rule वाले product को PPP से कभी adjust नहीं किया जाता। आपके द्वारा सेट की गई सटीक राशि लागू होती है। |
| **रूपांतरण से पहले लागू** | प्रतिशत आपके base price पर लागू होता है। Adaptive Currency परिणाम को convert करता है। |
| **discounts से पहले** | [discount code](/features/discount-codes) कम की गई कीमत पर लागू होता है, इसलिए दोनों reductions एक साथ जुड़ती हैं। |
| **usage-based के लिए केवल fixed fees** | PPP usage-based product की fixed fee पर लागू होता है, metered usage पर कभी नहीं। |
| **Pay What You Want के लिए नहीं** | ग्राहक राशि चुनता है, इसलिए PPP लागू नहीं होता। [Pay What You Want](/features/pay-what-you-want) देखें। |
| **प्रतिशत की सीमा** | देश का प्रतिशत 30 और 100 के बीच होता है। अधिकतम कमी 70% है। |
| **इसका अपना कोई webhook नहीं** | कम की गई राशि payment या subscription पर किसी भी अन्य price की तरह दिखाई देती है। |

## सर्वोत्तम अभ्यास

- **पहले एक product को शामिल करें।** अपने catalogue को शामिल करने से पहले checkout price की पुष्टि करें।
- **discount stack पर नज़र रखें।** discount code PPP price के ऊपर लागू होता है। 30% country और 20% code मिलकर आपके सूची मूल्य का 24% छोड़ते हैं।
- **enterprise plans को अलग रखें।** Negotiated plan को शायद ही कभी देश के अनुसार adjustment की आवश्यकता होती है।
- **जहाँ आवश्यक हो, अपने मान सेट करें।** डिफ़ॉल्ट संख्याएँ शुरुआत के लिए हैं, कोई नियम नहीं।
- **subscriptions पर प्रभाव जाँचें।** कम कीमत पर sign up करने वाला subscriber उसी कीमत पर renew होता है।
