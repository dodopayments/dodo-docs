## Customer Wallets क्या हैं?

Customer wallets monetary balance accounts होते हैं, जिनमें आपके users के लिए वास्तविक funds रखे जाते हैं। उनका account बनाते ही हर customer को एक wallet अपने-आप मिल जाता है। आप इन wallets का उपयोग निम्नलिखित के लिए कर सकते हैं:

- भविष्य के subscription payments के लिए **prepaid funds स्टोर करें**
- card refunds के बजाय wallet balance के रूप में **refunds संभालें**
- welcome bonuses या loyalty rewards जैसे **promotional balances जारी करें**
- billing के दौरान **wallet funds को invoices में अपने-आप लागू करें**
- विस्तृत ledger history के साथ **monetary transactions ट्रैक करें**

<Info>
जब आप customer का account बनाते हैं, तो हर customer को अपने-आप एक wallet मिलता है। Wallets USD और INR currencies को support करते हैं और प्रत्येक के लिए अलग monetary balances रखते हैं।
</Info>

<Warning>
**Customer Wallets ≠ Credit-Based Billing**

Customer Wallets में **वास्तविक monetary balances** (USD, INR) रखे जाते हैं, जिन्हें invoices और subscription payments में लागू किया जा सकता है।

यदि आप virtual usage units (API calls, tokens, compute hours) को ट्रैक करना चाहते हैं, तो इसके बजाय [Credit-Based Billing](/features/credit-based-billing) देखें।
</Warning>

## यह कैसे काम करता है

Customer wallets में funds रखे जाते हैं, जिन्हें customers अपनी purchases पर लागू कर सकते हैं। जब किसी customer के पास invoice या recurring subscription charge होता है, तो पहले उसका wallet balance जाँचा जाता है। उपलब्ध funds को primary payment method से charge करने से पहले invoice पर अपने-आप लागू कर दिया जाता है।

### Automatic Setup

जब आप नया customer बनाते हैं, तो Dodo Payments अपने-आप zero balance वाला wallet बनाता है। यह हमारे API के माध्यम से तुरंत funds प्राप्त करने के लिए तैयार होता है।

### Multi-Currency Support

प्रत्येक wallet अलग-अलग currencies में balances रख सकता है:

<ResponseField name="USD Balance" type="integer">
US Dollars में balance (cents में स्टोर किया जाता है)
</ResponseField>

<ResponseField name="INR Balance" type="integer">
Indian Rupees में balance (paise में स्टोर किया जाता है)
</ResponseField>

<Info>
वर्तमान में केवल **USD** और **INR** balances उपलब्ध हैं। जल्द ही और currencies उपलब्ध होंगी।
</Info>

## Wallets के साथ काम करना

### Customer Balances जाँचें

देखें कि customer के पास सभी currencies में कितने funds हैं। Purchase process करने से पहले उपलब्ध balance सत्यापित करने या अपने application UI में balance दिखाने के लिए यह उपयोगी है।

### Funds जोड़ें या घटाएँ

Customer wallets में funds जोड़ें (जैसे welcome bonuses या refund balances) या funds घटाएँ (जैसे subscription charges)। स्पष्ट audit trail बनाए रखने के लिए आप प्रत्येक transaction का reason दे सकते हैं।

<Note>
The `entry_type` field uses `'credit'` to add funds to the wallet and `'debit'` to subtract funds from the wallet.
</Note>

## वास्तविक उदाहरण

### Wallet में Refund

जब कोई customer refund का अनुरोध करता है, तो traditional card refund करने के बजाय आप राशि को उसके wallet balance में जोड़ सकते हैं। इससे funds आपके ecosystem में भविष्य की purchases के लिए बने रहते हैं।

```javascript
async function refundToWallet(customerId, refundAmount, originalPaymentId) {
  await client.customers.wallets.ledgerEntries.create(customerId, {
    amount: refundAmount, // Amount in cents
    currency: 'USD',
    entry_type: 'credit',
    reason: `Refund for payment ${originalPaymentId}`,
    idempotency_key: `refund_${originalPaymentId}`
  });
}
```

### Welcome Bonus / Promotional Balance

नई purchase को प्रोत्साहित करने के लिए नए customers को monetary welcome bonus दें।

```javascript
async function addWelcomeBonus(customerId) {
  await client.customers.wallets.ledgerEntries.create(customerId, {
    amount: 1000, // $10.00 promotional balance
    currency: 'USD',
    entry_type: 'credit',
    reason: 'Welcome bonus - $10 promotional balance',
    idempotency_key: `welcome_${customerId}`
  });
}
```

### Wallet से Subscription Payment

Subscription charge या manual purchase को cover करने के लिए wallet से funds घटाएँ।

```javascript
async function deductForPurchase(customerId, purchaseAmount, purchaseId) {
  try {
    await client.customers.wallets.ledgerEntries.create(customerId, {
      amount: purchaseAmount,
      currency: 'USD',
      entry_type: 'debit',
      reason: `Subscription charge - monthly billing`,
      idempotency_key: `charge_${purchaseId}`
    });
  } catch (error) {
    if (error.status === 400) {
      console.log('Insufficient wallet balance');
    }
  }
}
```

## Best Practices

### Duplicate Transactions रोकें

यह सुनिश्चित करने के लिए idempotency keys का उपयोग करें कि आप गलती से एक ही event के लिए funds दो बार न जोड़ें या घटाएँ।

```javascript
async function addFundsSafely(customerId, amount, reason) {
  const idempotencyKey = `${reason}_${customerId}_${Date.now()}`;
  
  try {
    const result = await client.customers.wallets.ledgerEntries.create(customerId, {
      amount: amount,
      currency: 'USD',
      entry_type: 'credit',
      reason: reason,
      idempotency_key: idempotencyKey
    });
    
    return { success: true, wallet: result };
  } catch (error) {
    if (error.status === 409) {
      // Transaction already processed
      return { success: true, wallet: null, duplicate: true };
    }
    
    throw error;
  }
}
```

### Charging से पहले Balances जाँचें

Wallet से बड़ी transactions process करने का प्रयास करने से पहले सत्यापित करें कि customers के पास पर्याप्त funds हैं।

```javascript
async function checkBalanceBeforeOperation(customerId, requiredAmount) {
  const wallets = await client.customers.wallets.list(customerId);
  const usdWallet = wallets.items.find(w => w.currency === 'USD');
  
  if (!usdWallet || usdWallet.balance < requiredAmount) {
    throw new Error('Insufficient funds for this operation');
  }
  
  return usdWallet.balance;
}
```
