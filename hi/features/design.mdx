<Info>
Design पेज, हर customer-facing surface की ब्रांडिंग के लिए आपका केंद्रीय केंद्र है: checkout, storefront और Customer Portal। बदलाव तीनों पर तुरंत लागू होते हैं और save करने से पहले real time में preview किए जाते हैं। Test mode और live mode में अलग-अलग designs होते हैं — [Copy Design From Test to Live Mode](#copy-design-from-test-to-live-mode) देखें।
</Info>

## मुख्य विशेषताएं

1. **एकीकृत Design Hub** - एक ही पेज से checkout, storefront और Customer Portal का स्वरूप configure करें।
2. **पहले से निर्मित Themes** - एक चुनी हुई theme से शुरुआत करें और उसे अपनी आवश्यकता के अनुसार customize करें।
3. **Light & Dark Mode** - प्रत्येक mode के लिए अलग color palettes निर्धारित करें।
4. **Live Preview** - save करने से पहले देखें कि आपके बदलाव checkout, Customer Portal और storefront पर कैसे दिखाई देते हैं।
5. **प्रति-Section Overrides** - अन्य sections को प्रभावित किए बिना अलग-अलग sections (checkout, storefront, Customer Portal) को fine-tune करें।
6. **Programmatic Control** - API या Checkout SDK के ज़रिए checkout के समय themes को override करें।
7. **Test Design को Live में Copy करें** - Test mode में बेहतर बनाया गया design एक चरण में live mode में ले जाएँ।

## शुरुआत करना

अपने मर्चेंट डैशबोर्ड में **Settings → Design** पर नेविगेट करें। डिज़ाइन पेज में चार टैब होते हैं:

| Tab | Purpose |
|-----|---------|
| **General** | व्यवसाय का नाम, लोगो, थीम चयन, और वैश्विक उन्नत सेटिंग्स |
| **Checkout** | चेकआउट पेज के लिए विशेष रूप से थीम सेटिंग्स को ओवरराइड करें |
| **Storefront** | स्टोरफ्रंट लेआउट कॉन्फ़िगर करें और थीम सेटिंग्स ओवरराइड करें |
| **Customer Portal** | ग्राहक पोर्टल के लिए थीम सेटिंग्स ओवरराइड करें |

## सामान्य सेटिंग्स

**General** टैब आपकी मौलिक ब्रांड पहचान और वैश्विक थीम को नियंत्रित करता है।

  <img src="/images/design/general-advanced-settings.jpg" alt="जनरल टैब में टाइपोग्राफी, रंग, और बॉर्डर कॉन्फ़िगरेशन के साथ उन्नत सेटिंग्स हैं" style={{ maxHeight: '500px', width: 'auto' }} />

### मूल कॉन्फ़िगरेशन

| Setting | Description |
|---------|-------------|
| **Business Name** | वह नाम जो चेकआउट, स्टोरफ्रंट, और ग्राहक पोर्टल पर प्रदर्शित होता है |
| **Business Logo** | आपका ब्रांड लोगो जो सभी ग्राहक-सामना करने वाले पृष्ठों में दिखता है |
| **Theme** | प्रारंभिक बिंदु के रूप में एक पूर्व-निर्मित थीम चुनें |

### उन्नत सेटिंग्स

**Advanced Settings** को विस्तारित करें ताकि आपको सूक्ष्म नियंत्रण मिलें:

<Frame>
  <img src="/images/design/general-color-settings.jpg" alt="उन्नत सेटिंग्स खुली हुई हैं, जिसमें लाइट और डार्क मोड के लिए पूर्ण रंग विन्यास है" style={{ maxHeight: '500px', width: 'auto' }} />

#### टाइपोग्राफी

| Setting | Options | Description |
|---------|---------|-------------|
| **Primary Font** | Any Google Font | हेडिंग और बॉडी टेक्स्ट के लिए मुख्य फ़ॉन्ट |
| **Secondary Font** | Any Google Font | लेबल और द्वितीयक टेक्स्ट के लिए सहायक फ़ॉन्ट |
| **Font Size** | `xs`, `sm`, `md`, `lg`, `xl`, `2xl` | वैश्विक आधार फ़ॉन्ट आकार |
| **Font Weight** | `normal`, `medium`, `bold`, `extraBold` | डिफ़ॉल्ट फ़ॉन्ट वजन |

#### रंग कॉन्फ़िगरेशन

**Light Mode** और **Dark Mode** के लिए अलग रंग पैलेट परिभाषित करें। प्रत्येक मोड निम्न गुणों का समर्थन करता है:

| Property | Description |
|----------|-------------|
| **Background Primary** | मुख्य पृष्ठभूमि रंग |
| **Background Secondary** | द्वितीयक पृष्ठभूमि (टैब, कार्ड) |
| **Text Primary** | मुख्य टेक्स्ट रंग |
| **Text Secondary** | म्यूट किए गए टेक्स्ट का रंग |
| **Button Primary** | मुख्य बटन की पृष्ठभूमि |
| **Button Primary Text** | मुख्य बटन पर टेक्स्ट का रंग |
| **Button Secondary** | द्वितीयक बटन की पृष्ठभूमि |
| **Button Secondary Text** | द्वितीयक बटन पर टेक्स्ट का रंग |
| **Border Primary** | मुख्य बॉर्डर रंग |
| **Border Secondary** | ऐक्सेंट बॉर्डर रंग |

#### बॉर्डर

| Setting | Description |
|---------|-------------|
| **Border Radius** | इनपुट, बटन, टैब और कार्ड की गोलाई को नियंत्रित करता है (जैसे, `0` तीखे कोनों के लिए, `8px` गोल कोनों के लिए, `16px` पिल-आकार के लिए) |

## प्रति-सेक्शन ओवरराइड

प्रत्येक सेक्शन टैब (Checkout, Storefront, Customer Portal) में एक **Override Theme** टॉगल होता है। सक्षम करने पर, आप उस सेक्शन की उपस्थिति को वैश्विक थीम से स्वतंत्र रूप से अनुकूलित कर सकते हैं।

### चेकआउट टैब

<Frame>
  <img src="/images/design/checkout-tab.jpg" alt="चेकआउट टैब जिसमें उत्पाद विवरण और भुगतान फॉर्म के साथ पूरा चेकआउट प्रीव्यू दिखाया गया है" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

विशेष रूप से चेकआउट अनुभव के लिए टाइपोग्राफी, रंग और बॉर्डर सेटिंग्स को ओवरराइड करें। लाइव पूर्वावलोकन में दिखाई देता है:
- उत्पाद जानकारी और मूल्य निर्धारण
- एक्सप्रेस चेकआउट विकल्प (Apple Pay, Google Pay)
- भुगतान विधि चयन और कार्ड फॉर्म
- डिस्काउंट कोड इनपुट और मूल्य ब्रेकडाउन

| **Override Theme** | केवल स्टोरफ्रंट के लिए टाइपोग्राफी, रंग और बॉर्डर अनुकूलित करने के लिए सक्षम करें |

## Test Mode से Live Mode में Design Copy करें

Test mode और live mode में अलग-अलग design configurations होती हैं, इसलिए testing के दौरान बनाई गई theme अपने-आप real customers को दिखाई नहीं देती। इसे हाथ से दोबारा बनाने के बजाय, अपने design को एक चरण में test mode से live mode में copy करें।

Copy में **सभी design surfaces** — general settings, checkout, Customer Portal और storefront overrides — साथ ही आपकी storefront branding भी शामिल होती है।

<Warning>
Copy करने से मौजूदा live mode design overwrite हो जाता है। Copy करने के बाद अपने live checkout और storefront की समीक्षा करें, ताकि यह सुनिश्चित हो सके कि सब कुछ आपकी अपेक्षा के अनुसार दिखाई दे रहा है।
</Warning>
