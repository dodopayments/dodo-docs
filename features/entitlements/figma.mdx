<Info>
The Figma entitlement gives paying customers viewer access to a Figma file. Once you connect Figma to Dodo Payments, access is granted on purchase and revoked when the customer's subscription ends.
</Info>

## What gets delivered

- The customer's Figma account is granted access to the configured file.
- The customer receives a link to the file in their delivery email and customer portal.
- On cancellation, refund, or manual revoke, access is removed.

Common uses include paid design templates, UI kits, icon libraries, and component systems.

## Connect Figma

<Steps>
<Step title="Open Entitlements">
In your Dodo Payments dashboard, go to **Entitlements** and click **+**.
</Step>

<Step title="Pick Figma">
Choose **Figma Access** as the integration. If Figma is not yet connected, complete the OAuth flow with the Figma account that owns the files you want to share.
</Step>

<Step title="Pick a file">
Select the **Figma file** to grant access to. Only files visible to the connected Figma account appear.

<Frame>
<img src="/images/entitlements/create.png" alt="Figma entitlement form with file picker" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Save the entitlement">
Save and attach to any product.
</Step>
</Steps>

## Customer flow

1. The customer completes checkout.
2. Dodo Payments creates a `pending` grant and asks Figma to share the file with the customer's account.
3. The grant transitions to `delivered` once Figma confirms access has been shared, and the customer receives an email with the file link.
4. On cancellation, refund, or manual revoke, access is removed.

## Required configuration

| Field | Required | Description |
|---|---|---|
| `figma_file_id` | Yes | The Figma file ID. The dashboard picker fills this in. |

## Create via API

<CodeGroup>
```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'UI Kit Pro',
  integration_type: 'figma',
  integration_config: {
    figma_file_id: 'abc123XYZ',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="UI Kit Pro",
    integration_type="figma",
    integration_config={"figma_file_id": "abc123XYZ"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("UI Kit Pro"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFigma),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFigmaConfigParam{
      FigmaFileID: dodopayments.F("abc123XYZ"),
    },
  ),
})
```
</CodeGroup>

## Webhooks

See [`entitlement_grant.*` webhook events](/developer-resources/webhooks/intents/entitlement-grant). Figma grants arrive `pending` and transition to `delivered` once Figma confirms the file has been shared.

## Troubleshooting

<AccordionGroup>
<Accordion title="File picker is empty">
The connected Figma account must have access to the file. Reconnect Figma from **Entitlements → Integrations → Figma** with an account that owns or is a member of the file's team.
</Accordion>

<Accordion title="Customer says they can't open the file">
Confirm the customer signed up to Figma with the same email address used for the purchase, or have them add the purchase email to their Figma account before opening the link.
</Accordion>
</AccordionGroup>
