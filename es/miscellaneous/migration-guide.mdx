## Proceso de Migración de Tokens de Tarjeta

### 1. Solicitar Exportación de Tokens al Procesador Actual

- Inicia contacto con el equipo de soporte de tu procesador de pagos actual a través de sus canales de soporte oficiales
- Presenta una solicitud formal para una exportación completa de todos los tokens de tarjeta de tus clientes
- Prepárate para proporcionar verificación de tu identidad y autorización para acceder a estos datos sensibles
- Es probable que tu procesador de pagos requiera que completes varios pasos de verificación de cumplimiento
- Pueden ser necesarias aprobaciones de seguridad adicionales de sus equipos de riesgo y cumplimiento
- El proceso podría tardar de 5 a 10 días hábiles dependiendo de las políticas de tu procesador

### 2. Compartir de Forma Segura la Exportación con Dodo Payments

- Al recibir el archivo de exportación de tokens encriptado de tu procesador actual, no lo desencriptes
- Tienes dos opciones seguras para compartir los datos con nuestro equipo:
  1. Usa nuestro portal de carga segura dedicado en [secure upload link]
  2. Transfiere a través de nuestro servidor SFTP (las credenciales se proporcionarán a solicitud)
- Limita estrictamente el acceso al archivo a personal autorizado con la debida autorización de seguridad
- Documenta a todas las personas que manejen el archivo para mantener una cadena de custodia clara
- Sigue todos los requisitos de PCI DSS para el manejo de datos de pago sensibles
- Elimina cualquier copia local del archivo inmediatamente después de la transferencia exitosa

### 3. Dodo Payments Procesa la Migración

- Nuestro equipo especializado en migraciones se encargará del proceso de importación de tokens
- Seguimos un procedimiento detallado para:
  - Verificar la integridad y encriptación del archivo
  - Mapear el antiguo formato de token a nuestra estructura de token segura
  - Importar tokens en nuestro Card Vault compatible con PCI utilizando encriptación de grado militar
  - Realizar múltiples verificaciones de validación para asegurar la precisión de los datos
- Recibirás actualizaciones de estado detalladas a lo largo del proceso
- Al finalizar, enviaremos un informe de migración completo
- El tiempo de procesamiento típico es de 2 a 3 días hábiles para migraciones estándar

### 4. Validar y Comenzar a Usar los Nuevos Tokens

- Proporcionaremos documentación detallada sobre el nuevo formato de token
- Recibirás un mapeo completo de los antiguos tokens a los nuevos tokens de Dodo Payments
- Se provisionará un entorno de sandbox dedicado para pruebas
- Recomendamos:
  - Probar todos los tipos de transacciones con los tokens migrados
  - Verificar el procesamiento exitoso de cargos recurrentes
  - Confirmar el almacenamiento y recuperación adecuados de tokens
  - Ejecutar sistemas paralelos temporalmente para asegurar una transición fluida
- Nuestro equipo técnico estará disponible para soporte durante las pruebas
