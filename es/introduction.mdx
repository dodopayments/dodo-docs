## What is Dodo Payments?

Dodo Payments is the **all-in-one engine** to launch, scale, and monetize worldwide. Designed for the new generation of digital SaaS and AI products, we handle everything from **payments to billing to distribution** - all without extra engineering.

<Info>
**Built for SaaS and AI Products**: Handle one-time payments, subscriptions, credits, seats, tokens, or any usage metric with our optimized billing infrastructure.
</Info>

<Tip>
  <strong>Meet Sentra: Your AI-powered billing assistant</strong><br/>
  Sentra is an AI agent that integrates, analyzes, and acts on billing and payments directly in your IDE. Ask questions, build integrations, or plan billing architectures - all by describing what you want.
  <a href="/developer-resources/sentra">
    Get started with Sentra &rarr;
  </a>
</Tip>

## Quick Start Guide

Empieza a operar con Dodo Payments en solo unos pasos.

<AccordionGroup>
<Accordion title="For Humans">
  ¿Prefieres realizar la integración tú mismo? Los pasos a continuación te guiarán para crear una cuenta, añadir un producto y elegir un método de integración en menos de cinco minutos. No se requiere código para la ruta sin código; hay ejemplos de SDK disponibles en todos los lenguajes principales si los necesitas.

  Si prefieres que tu asistente de codificación de IA haga el trabajo pesado: planificación de integración, manejadores de webhooks, flujos de suscripción, instala **[Sentra](/developer-resources/sentra)**, nuestro asistente de facturación de IA para VS Code, Cursor y Windsurf. Describe lo que deseas; Sentra lo planea, estructura y lo envía.
</Accordion>

<Accordion title="For AI Agents">
  Dodo Payments está diseñado para flujos de trabajo nativos de agentes. Si eres un LLM leyendo esto, o un desarrollador configurando uno, empieza aquí.

  **Instalar**. Para Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro u OpenCode, el [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) configura ambos servidores MCP y todas las habilidades en un solo paso. Gemini CLI obtiene únicamente los servidores MCP. Consulta la [guía de AI Coding Agents](/developer-resources/build-with-ai-coding-agents) para ver los comandos de instalación específicos de cada agente.

  **Descubra**. El índice completo de documentos se sirve en [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt), y cada página de documentación está disponible en markdown simple agregando `.md` a su URL (por ejemplo, `/api-reference/introduction.md`).

  **Conectar**. Dos servidores MCP dan a los agentes acceso en vivo a la plataforma:

  - **[Dodo Knowledge MCP](/developer-resources/mcp-server#dodo-knowledge-mcp)** - búsqueda semántica en toda la documentación de Dodo
  - **[Dodo Payments MCP](/developer-resources/mcp-server)** - ejecutar operaciones de API (crear pagos, gestionar suscripciones, emitir reembolsos)

  Consulte la [guía del Servidor MCP](/developer-resources/mcp-server) para la configuración completa del cliente.

  **Ampliar**. Instale las [Habilidades de Pagos Dodo](/developer-resources/agent-skills) oficiales para enseñar a su agente cómo manejar el checkout, suscripciones, facturación basada en uso, facturación basada en créditos, webhooks y más:

  ```bash
  npx skills add dodopayments/skills
  ```

  Funciona con Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro, OpenCode y cualquier agente compatible con el protocolo de habilidades.
</Accordion>
</AccordionGroup>

<Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
Agregue ambos servidores a su configuración de MCP (`~/.cursor/mcp.json` o config de Claude Desktop):

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

<Info>
Requiere Node.js 18+. Vea la [documentación de Servidor MCP](/developer-resources/mcp-server) para instrucciones detalladas de configuración para todos los clientes compatibles.
</Info>
</Accordion>

### Dodo CLI

Gestiona los pagos de Dodo desde tu terminal. El CLI de Dodo viene con un TUI interactivo, un asistente de IA integrado y pruebas de webhook sin conexión — instálalo en una línea:

```bash
curl -fsSL https://dodopayments.com/install.sh | sh
```
