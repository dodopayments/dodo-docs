## Introducción

El plugin de WooCommerce de Dodo Payments proporciona una integración sin problemas con tu tienda, permitiéndote aceptar pagos a través de múltiples métodos, incluyendo UPI, tarjetas, banca en línea y billeteras digitales. Esta guía completa te guiará a través del proceso de instalación y configuración.

## Guía de Instalación Paso a Paso

1. Descarga el último zip del plugin de pago de WooCommerce.

3. Navega a **Plugins → Añadir nuevo plugin**

5. Haz clic en **Examinar…** y selecciona el archivo zip que descargaste

## Guía de Configuración

### Configuración de Claves API y Webhooks

1. Navega a **WooCommerce → Ajustes → Pagos** o haz clic en el botón **Pagos** en la barra lateral izquierda debajo del elemento del menú de WooCommerce
    
    <Frame>
        <img src="/images/woocommerce/6.webp" alt="Plugin Dodo Payments para WooCommerce" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
    <Frame>
        <img src="/images/woocommerce/7.webp" alt="Plugin Dodo Payments para WooCommerce" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
2. Habilita el proveedor de pago **Dodo Payments** si aún no lo está, luego haz clic en **Administrar** para configurar el plugin
3. Verás varias opciones de configuración, cada una con texto explicativo útil. Comienza configurando tu clave de API de Producción
    
    <Frame>
        <img src="/images/woocommerce/8.webp" alt="Plugin Dodo Payments para WooCommerce" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
4. Inicia sesión en tu panel de control de Dodo Payments en **Modo Producción**, luego navega a **Dodo Payments (Modo Producción) > Desarrollador > Claves API** o visita [este enlace directo](https://app.dodopayments.com/developer/api-keys) y haz clic en **Agregar clave API**
    
    <Frame>
        <img src="/images/woocommerce/9.webp" alt="Plugin Dodo Payments para WooCommerce" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
5. Dale a tu clave API un nombre descriptivo y haz clic en **Crear**
    
    <Frame>
        <img src="/images/woocommerce/10.webp" alt="Plugin Dodo Payments para WooCommerce" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
6. Copia la clave API generada y pégala en el campo de **Clave de API de Producción** en la configuración del plugin de WooCommerce
    
    <Frame>
        <img src="/images/woocommerce/11.webp" alt="Plugin Dodo Payments para WooCommerce" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
    <Frame>
        <img src="/images/woocommerce/12.webp" alt="Plugin Dodo Payments para WooCommerce" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
7. A continuación, configura la clave de firma de webhook para habilitar la sincronización del estado de pagos entre Dodo Payments y WooCommerce
8. Desplázate hasta el final de la página de configuración del plugin y copia la URL de webhook que se muestra allí
    
    <Frame>
        <img src="/images/woocommerce/13.webp" alt="Plugin Dodo Payments para WooCommerce" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
9. Regresa a tu panel de Dodo Payments y navega a **Dodo Payments (Modo Producción) > Desarrollador > Webhooks** y haz clic en **Agregar Webhook**
    
    <Frame>
        <img src="/images/woocommerce/14.webp" alt="Plugin Dodo Payments para WooCommerce" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
10. Pega la URL que copiaste en el paso 8 en el diálogo y haz clic en **Agregar Webhook**
    
    <Frame>
        <img src="/images/woocommerce/15.webp" alt="Plugin Dodo Payments para WooCommerce" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
11. Después de crear el webhook, haz clic en el icono de ojo junto a la **Clave de Firma** redactada para revelarla y copiarla
    
    <Frame>
        <img src="/images/woocommerce/16.webp" alt="Plugin Dodo Payments para WooCommerce" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
12. Pega la clave de firma en el campo de **Clave de Firma de Webhook de Producción** en la configuración de tu plugin y guarda los cambios
    
    <Frame>
        <img src="/images/woocommerce/17.webp" alt="Plugin Dodo Payments para WooCommerce" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
13. Revisa los ajustes restantes como **Categoría de Impuesto Global** y **Todas las Precios Incluyen Impuestos**, ya que estas opciones determinan cómo se sincronizan los productos de WooCommerce a Dodo Payments. Ten en cuenta que la **Clave de API de Prueba** y la **Clave de Firma de Webhook de Prueba** solo son necesarias si planeas usar el Modo de Prueba
    
    <Frame>
        <img src="/images/woocommerce/18.webp" alt="Plugin Dodo Payments para WooCommerce" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>

## Características Clave

- **Experiencia de Pago Sin Problemas**: Redirige a los clientes a una página de pago segura y optimizada
- **Múltiples Métodos de Pago**: Soporte para varias opciones de pago locales e internacionales
- **Actualizaciones de Estado en Tiempo Real**: Sincronización instantánea del estado del pedido a través de webhooks
- **Registros de Transacciones Detallados**: Historial de pagos completo en tu panel de WooCommerce
- **Soporte Multimoneda**: Acepta pagos en múltiples monedas

## Solución de Problemas

### Problemas Comunes

1. **Fallos en el Procesamiento de Pagos**
   - Verifica que las claves API estén configuradas correctamente
   - Asegúrate de que la URL del webhook esté configurada correctamente
   - Verifica que tu certificado SSL sea válido

2. **Problemas de Sincronización de Webhooks**
   - Confirma que la clave de firma del webhook coincida
   - Revisa los registros del servidor en busca de posibles errores
   - Verifica que tu servidor pueda recibir solicitudes de webhook entrantes

## Mejores Prácticas de Mantenimiento

1. Actualiza regularmente el plugin para parches de seguridad y nuevas características
2. Prueba todos los flujos de pago en modo sandbox antes de procesar transacciones en vivo
3. Mantén WordPress y WooCommerce actualizados a las últimas versiones
4. Implementa copias de seguridad regulares del sitio
5. Monitorea los registros de transacciones en busca de cualquier actividad inusual
6. Almacena las claves API de forma segura y nunca las compartas públicamente
