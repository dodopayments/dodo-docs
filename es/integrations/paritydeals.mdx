## Introducción

[ParityDeals](https://www.paritydeals.com/) es una plataforma que muestra banners de descuentos basados en la ubicación a los visitantes elegibles de tu sitio web y genera automáticamente los códigos de descuento correspondientes en Dodo Payments. Cuando un visitante ve el banner, obtiene un código que puede usar al finalizar la compra. Esos códigos aparecen en tu panel de Dodo Payments, en **Sales → Discounts**.

<Note>
Dodo Payments ofrece [Purchasing Power Parity](/features/purchasing-power-parity) de forma nativa, lo que reduce los precios por país al finalizar la compra sin necesidad de un banner ni de un script. ParityDeals está pensado para merchants que quieren mostrar un banner de descuento visible en su propio sitio o ejecutar ofertas de temporada y basadas en el tiempo.
</Note>

## Cómo funciona

ParityDeals detecta la ubicación de un visitante, le muestra un banner de descuento personalizable en tu sitio web y genera un código de descuento que puede aplicar al finalizar la compra. El código se crea automáticamente en tu cuenta de Dodo Payments y funciona con los productos que configures.

1. Un visitante llega a tu sitio web y ParityDeals detecta su ubicación.
2. Si el visitante reúne los requisitos para recibir un descuento, aparece un banner con un código basado en la ubicación.
3. El visitante usa ese código al finalizar la compra y Dodo Payments aplica el descuento.
4. El código aparece en tu panel, en **Sales → Discounts**.

## ParityDeals frente a PPP nativo

Purchasing Power Parity nativo es la forma recomendada de establecer precios por país. Elige ParityDeals cuando necesites específicamente un banner de descuento en tu propio sitio o campañas de temporada y basadas en el tiempo.

| | PPP nativo | ParityDeals |
| :--- | :--- | :--- |
| Cómo funciona | Un porcentaje por país, aplicado al finalizar la compra | Un porcentaje de descuento, aplicado mediante un código |
| Dónde se configura | Integrado en Dodo Payments | Panel de ParityDeals |
| Banner o script en tu sitio | No es necesario | Es necesario |
| Ofertas de temporada y basadas en el tiempo | No | Sí |
| Ideal para | Precios correctos sin cambios en el sitio | Banners promocionales y ofertas de temporada |

<Info>
No puedes insertar el banner de ParityDeals en un checkout o storefront alojado por Dodo Payments, ya que allí no se admiten scripts personalizados. El banner debe colocarse en tu propio sitio web o aplicación.
</Info>

## Requisitos previos

Antes de configurar esta integración, asegúrate de tener:

1. Una [cuenta de Dodo Payments](https://app.dodopayments.com)
2. Una [cuenta de ParityDeals](https://app.paritydeals.com/)
3. Una clave de API de Dodo Payments

## Primeros pasos

<Steps>
  <Step title="Sign up on ParityDeals">
    Visita [app.paritydeals.com](https://app.paritydeals.com/) y crea una cuenta.
  </Step>

  <Step title="Create Deals">
    Después de iniciar sesión, busca la opción para crear ofertas. En el menú desplegable, selecciona **"Create Deals via Dodo Payments"**.

    <Frame>
      <img src="/images/integrations/paritydeals/create-deals.png" alt="Creación de ofertas mediante Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Inicia sesión en tu **panel de Dodo Payments** y ve a **Developers → API Keys**. Haz clic en **"Create New API"**.

    <Tip>
      Asigna a tu clave de API un nombre descriptivo (por ejemplo, 'ParityDeals') para poder identificarla más adelante.
    </Tip>

    <Frame>
      <img src="/images/integrations/paritydeals/api-key.png" alt="Creación de una nueva clave de API en Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Copia la clave de API que creaste y pégala en la interfaz de ParityDeals para establecer la conexión con tu cuenta de Dodo Payments.

    <Frame>
      <img src="/images/integrations/paritydeals/connect-api-key.png" alt="Conexión de una clave de API con ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Una vez conectada, ParityDeals obtendrá tu catálogo de productos de Dodo Payments. Selecciona los productos que quieras asociar con tus ofertas.

    <Frame>
      <img src="/images/integrations/paritydeals/select-products.png" alt="Selección de productos para ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Introduce la URL de tu sitio web y, opcionalmente, selecciona páginas específicas donde debe aparecer el banner de descuento. Después, elige el tipo de oferta que prefieras:
    - Ofertas basadas en la ubicación
    - Ofertas de temporada
    - Ofertas flash basadas en el tiempo

    <Frame>
      <img src="/images/integrations/paritydeals/deal-settings.png" alt="Configuración de los ajustes de la oferta" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Selecciona los países a los que quieres ofrecer descuentos localizados y define el porcentaje de descuento para cada uno. ParityDeals proporciona valores predeterminados recomendados que puedes ajustar según sea necesario.

    <Frame>
      <img src="/images/integrations/paritydeals/country-rules.png" alt="Configuración de reglas de descuento por país" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Diseña tu banner de descuento personalizando el texto, seleccionando los colores y el diseño, y eligiendo la posición del banner (parte superior o inferior de la página). Este banner se mostrará a los visitantes elegibles según las reglas que hayas configurado.

    <Frame>
      <img src="/images/integrations/paritydeals/customize-banner.png" alt="Personalización del banner de descuento" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Después de guardar tu oferta, ParityDeals generará un script. Añade este script al código de tu sitio web (normalmente, en la sección `<head>`). Este script detecta automáticamente las ubicaciones de los visitantes y muestra el banner de descuento correspondiente.

    <Frame>
      <img src="/images/integrations/paritydeals/script.png" alt="Script de integración de ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>
