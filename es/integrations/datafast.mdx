## Introducción

DataFast es una herramienta de análisis centrada en los ingresos que te ayuda a descubrir qué canales de marketing generan clientes de pago. Al integrar Dodo Payments con DataFast, puedes atribuir ingresos a tus fuentes de tráfico, identificar segmentos de clientes de alto valor y tomar decisiones basadas en datos para hacer crecer tu negocio.

<Info>
Esta integración requiere su clave API de DataFast, que puede obtener en su [panel de DataFast](https://datafa.st/).
</Info>

## Cómo Funciona

DataFast rastrea a los visitantes a través de un ID de visitante único almacenado en una cookie. Para atribuir ingresos a los canales de marketing, necesitas:

1. **Capture el ID de visitante de DataFast** de la cookie `datafast_visitor_id` al crear sesiones de pago
2. **Almacene el ID de visitante** en los metadatos de pago
3. **Envíe los datos de pago a DataFast** cuando los pagos se completen con éxito utilizando su API de pagos

Esto permite que DataFast asocie los pagos exitosos con la fuente de tráfico original, dándote una atribución de ingresos completa.

<Steps>

  Primero, instale el script de seguimiento de DataFast en su sitio web. Esto crea la cookie `datafast_visitor_id` que rastrea a sus visitantes.

</Step>

<Step title="Get Your API Key">
  Inicie sesión en su [panel de DataFast](https://datafa.st/) y vaya a la configuración de su sitio web para obtener su clave API.
  
  <Warning>
  Mantenga su clave API segura y nunca la exponga en código del lado del cliente.
  </Warning>
</Step>

<Step title="Capture Visitor ID in Checkout">
  Al crear una sesión de pago, capture el ID de visitante de DataFast de la cookie y agrégelo a los metadatos de su pago.
</Step>

<Step title="Send Payment Data via Webhook">
  Configure un webhook para enviar los datos de pago a la API de Pagos de DataFast cuando los pagos tengan éxito.
</Step>

<Step title="Done!">
  🎉 Los datos de ingresos ahora aparecerán en su panel de DataFast con atribución completa a los canales de marketing.
</Step>
</Steps>

## Guía de Implementación

### Paso 1: Agregar ID de Visitante a los Metadatos del Pago

Al crear una sesión de pago, captura el ID de visitante de DataFast de la cookie e inclúyelo en tus metadatos de pago.

<Note>
Los ejemplos a continuación utilizan `POST /payments`, que está **obsoleto**. Sigue funcionando para las integraciones existentes, pero las integraciones nuevas deben usar [Checkout Sessions](/developer-resources/checkout-session) (`POST /checkouts`); `metadata` se pasa de la misma manera.
</Note>

<CodeGroup>

```typescript Next.js
import { cookies } from 'next/headers';
import { dodopayments } from '@/lib/dodopayments';

export async function createCheckout(productId: string) {
  // Capture DataFast visitor ID from cookie
  const datafastVisitorId = cookies().get('datafast_visitor_id')?.value;

  const payment = await dodopayments.payments.create({
    product_cart: [{ product_id: productId, quantity: 1 }],
    // ... other payment configuration
    metadata: {
      datafast_visitor_id: datafastVisitorId, // Store visitor ID in metadata
    },
  });

  return payment;
}
```

```javascript Express.js
const express = require('express');
const router = express.Router();

router.post('/create-checkout', async (req, res) => {
  // Capture DataFast visitor ID from cookie
  const datafastVisitorId = req.cookies?.datafast_visitor_id;

  const payment = await dodopayments.payments.create({
    product_cart: [{ product_id: req.body.productId, quantity: 1 }],
    // ... other payment configuration
    metadata: {
      datafast_visitor_id: datafastVisitorId, // Store visitor ID in metadata
    },
  });

  res.json({ payment });
});
```

## Ejemplos de código de transformación

### Atribución de pagos básica

```javascript basic_payment.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    // Only send to DataFast if visitor ID exists in metadata
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      webhook.payload = {
        amount: payment.total_amount / 100, // Convert from cents to dollars
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

### Gestionar monedas sin decimales

Algunas monedas (como JPY) no utilizan posiciones decimales. Ajusta el cálculo del importe según corresponda:

```javascript zero_decimal.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      // Zero decimal currencies: JPY, KRW, CLP, etc.
      const zeroDecimalCurrencies = ['JPY', 'KRW', 'CLP', 'VND', 'UGX', 'MGA'];
      const isZeroDecimal = zeroDecimalCurrencies.includes(payment.currency);
      
      webhook.payload = {
        amount: isZeroDecimal 
          ? payment.total_amount // Use amount as-is for zero decimal currencies
          : payment.total_amount / 100, // Convert from cents for other currencies
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

### Pagos de suscripciones

Para los pagos de suscripciones recurrentes, puedes realizar un seguimiento de cada pago:

```javascript subscription_payment.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    // Check if this is a subscription payment
    const isSubscription = payment.subscription_id !== null;
    
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      webhook.payload = {
        amount: payment.total_amount / 100,
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
        // Optional: Add subscription context
        ...(isSubscription && {
          subscription_id: payment.subscription_id,
        }),
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

## Prácticas recomendadas

<Tip>
**Captura el ID del visitante con antelación**: Almacena el ID del visitante de DataFast lo antes posible en tu flujo de checkout para garantizar una atribución precisa, incluso si el usuario abandona el sitio y vuelve más tarde.
</Tip>

- **Incluye siempre el ID del visitante en los metadatos**: Sin el ID del visitante, DataFast no puede atribuir los ingresos a los canales de marketing
- **Gestiona las monedas sin decimales**: Algunas monedas (JPY, KRW, etc.) no utilizan posiciones decimales; ajusta el cálculo del importe según corresponda
- **Prueba con pagos de ejemplo**: Verifica que la integración funcione correctamente antes de pasar a producción
- **Supervisa tu panel de DataFast**: Comprueba que los pagos aparezcan correctamente con la atribución adecuada
- **Utiliza reintentos de webhook**: La Payment API de DataFast es idempotente, por lo que los reintentos son seguros si falla un webhook

## Solución de problemas

<AccordionGroup>
<Accordion title="Payments not appearing in DataFast">
- Verifica que tu API key de DataFast sea correcta y esté activa
- Comprueba que `datafast_visitor_id` se esté capturando y almacenando en los metadatos del pago
- Asegúrate de que la transformación del webhook dé el formato correcto al payload
- Verifica que el webhook se active en los eventos `payment.succeeded`
- Comprueba si hay mensajes de error o registros de API en el panel de DataFast
</Accordion>

<Accordion title="Revenue attribution not working">
- Confirma que el script de seguimiento de DataFast esté instalado y funcione en tu sitio web
- Verifica que la cookie `datafast_visitor_id` se establezca correctamente
- Comprueba que los ID de visitante coincidan entre la creación del checkout y la finalización del pago
- Asegúrate de capturar el ID del visitante antes de crear la sesión de checkout
- Consulta la [documentación de la Payment API](https://datafa.st/docs/payments-api) de DataFast para obtener más información
</Accordion>

<Accordion title="Transformation errors">
- Valida que la estructura JSON coincida con el formato de la Payment API de DataFast
- Comprueba que todos los campos obligatorios (`amount`, `currency`, `transaction_id`, `datafast_visitor_id`) estén presentes
- Asegúrate de que el importe se convierta correctamente (divídelo entre 100 para la mayoría de las monedas, excepto las monedas sin decimales)
- Verifica que la URL del endpoint de la API sea correcta: `https://datafa.st/api/v1/payments`
- Prueba la transformación con payloads de webhook de ejemplo
</Accordion>

<Accordion title="Currency conversion issues">
- Para las monedas sin decimales (JPY, KRW, CLP, VND, UGX, MGA), envía el importe tal cual, sin dividirlo entre 100
- Para todas las demás monedas, divide el importe entre 100 para convertirlo de centavos a la unidad base
- Comprueba que el código de moneda coincida con el formato ISO 4217 (por ejemplo, "USD", "EUR", "JPY")
</Accordion>
</AccordionGroup>
