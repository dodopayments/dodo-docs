## Nuevas Características

### 1. **Soporte para Análisis de Terceros**

Realiza un seguimiento del comportamiento del cliente a través de la Tienda, el Pago y el Portal del Cliente con Google Analytics 4, Google Tag Manager y Meta Pixel. Agrega tus IDs de seguimiento en **Configuraciones → Análisis** para comenzar a recopilar eventos de comercio electrónico.

**Plataformas Soportadas**

| Plataforma | Formato de ID |
|----------|-----------|
| Google Analytics 4 | `G-XXXXXXXXXX` |
| Google Tag Manager | `GTM-XXXXXXX` |
| Meta Pixel | Numérico (10-20 dígitos) |

**Eventos Seguidos**

Eventos como `purchase`, `add_payment_info`, `view_item`, y `view_item_list` se envían automáticamente a tus plataformas de análisis a medida que los clientes navegan y completan compras.

<Check>
Soportado en Tienda, Pago hospedado, Pago en overlay/in-line, y Portal del Cliente.
</Check>

Más información: [Análisis de Terceros](/features/analytics)

### 2. **Personalización del Tema de Pago**

Personaliza la apariencia del pago a través del parámetro `customization.theme_config` al crear sesiones de pago. Configura colores, fuentes, radio de borde y texto de botón para modos claros y oscuros.

**Opciones de Configuración**

| Propiedad | Descripción |
|----------|-------------|
| `light` / `dark` | Esquemas de color para cada modo |
| `font_primary_url` | URL de fuente personalizada |
| `font_size` | `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `radius` | Radio de borde (e.g., `8px`) |
| `pay_button_text` | Texto de botón personalizado |

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  customization: {
    theme_config: {
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      light: { button_primary: '#0066ff', text_primary: '#1a1a1a' },
      dark: { button_primary: '#3385ff', text_primary: '#ffffff' }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

Más información: [Personalización del Tema de Pago](/features/checkout#checkout-theme-customization)

### 3. **Prevenir Cambio de Plan en Caso de Fallo de Pago**

Nuevo parámetro `on_payment_failure` para cambios de plan de suscripción que controla el comportamiento cuando un pago falla.

| Modo | Comportamiento |
|------|----------|
| `prevent_change` | Mantener suscripción en el plan actual hasta que el pago tenga éxito |
| `apply_change` | Aplicar cambio de plan inmediatamente sin importar el resultado del pago (predeterminado) |

```typescript
await client.subscriptions.changePlan('sub_123', {
  product_id: 'prod_pro',
  proration_billing_mode: 'prorated_immediately',
  on_payment_failure: 'prevent_change'
});
```

<Tip>
Usa `prevent_change` para actualizaciones críticas donde desees asegurar el pago antes de otorgar acceso a funciones premium.
</Tip>

Más información: [Manejo de Fallos de Pago](/developer-resources/subscription-upgrade-downgrade#handling-payment-failures)

## Actualizaciones de API

### API de Libro Mayor de Balance

Nuevo punto de acceso `GET /balances/ledger` para recuperar las entradas del libro mayor de tu cuenta con filtrado y paginación.

| Parámetro | Descripción |
|-----------|-------------|
| `created_at_gte` / `created_at_lte` | Filtrar por rango de fechas |
| `event_type` | Filtrar por `payment`, `refund`, `dispute`, `payout`, etc. |
| `currency` | Filtrar por código de moneda |
| `reference_object_id` | Filtrar por ID específico de pago/reembolso/disputa |

Más información: [API de Libro Mayor de Balance](/api-reference/balance-ledger/list-ledger-entries)

### Respuesta de Pago: `refund_status`

Se añadió el campo `refund_status` a la respuesta `GET /payments/{paymentId}` para verificar rápidamente si un pago ha sido reembolsado sin consultar el punto de acceso de reembolsos por separado.
