## Nuevas Funciones 🚀

1. **Carrito Mixto: Productos de Pago Único y Suscripciones en un Solo Carrito**  
   Ahora, el proceso de pago admite la combinación de productos de pago único y productos de suscripción en un solo carrito, desbloqueando potentes nuevos casos de facturación.
   
   <Frame>
   <img src="/images/changelog/mixed-checkout.png" alt="Pago mixto con productos de pago único y suscripción" style={{ maxHeight: '500px', width: 'auto' }} />
   </Frame>
   
   ### Lo Que Permite Esto
   
   - **Tarifas de configuración + suscripciones**: Cobra una tarifa de configuración única junto a una suscripción recurrente en un solo pago
   - **Paquetes con componentes recurrentes**: Vende un producto (de pago único) empaquetado con acceso a servicios continuos (suscripción)
   - **Combos de curso + membresía**: Ofrece la compra de un curso con una suscripción opcional a una comunidad
   - **Acceso de por vida + suscripciones adicionales**: Combina el acceso de por vida a un producto con funciones premium opcionales recurrentes
   
   ### Cómo Funciona
   
   Simplemente añade tanto productos de pago único como de suscripción a tu sesión de pago:
   

   ```javascript
   const session = await client.checkoutSessions.create({
     product_cart: [
       // One-time setup fee
       { product_id: 'prod_setup_fee', quantity: 1 },
       // Monthly subscription
       { product_id: 'prod_monthly_plan', quantity: 1 }
     ],
     customer: {
       email: 'customer@example.com',
       name: 'Jane Doe'
     },
     return_url: 'https://yourapp.com/success'
   });
   ```

   
   <Check>
   Resultado: un único flujo de pago que procesa el cargo único e inicia la suscripción, reduciendo la fricción y aumentando las tasas de conversión.
   </Check>
   
   <Info>
   Al mezclar tipos de productos, el pago único se cobra de inmediato mientras que la suscripción sigue su ciclo de facturación configurado (incluido cualquier período de prueba que hayas establecido).
   </Info>
   
   Más información: [Checkout Sessions](/developer-resources/checkout-session)

2. **Portal Unificado de Clientes**  
   
   Un nuevo portal centralizado para clientes en [customer.dodopayments.com](https://customer.dodopayments.com) donde los clientes pueden ver y gestionar todas sus compras y suscripciones de diferentes empresas en Dodo Payments.
   
   <Frame>
   <img src="/images/changelog/unified-customer-portal.png" alt="Portal Unificado de Clientes" style={{ maxHeight: '500px', width: 'auto' }} />
   </Frame>
   
   ### Funcionalidades del Portal
   
   - **Visibilidad entre empresas**: Ver todas las compras y suscripciones de cualquier empresa que utilice Dodo Payments en un solo lugar
   - **Gestión centralizada de suscripciones**: Gestionar suscripciones de diferentes comerciantes desde un único panel
   - **Historial de facturación unificado**: Acceder a facturas y al historial de pagos de todas tus compras
   - **Experiencia de inicio de sesión único**: Inicia sesión una vez con tu correo electrónico para acceder a compras de todos los comerciantes de Dodo Payments
   
   ### Cómo Funciona
   
   Los clientes simplemente visitan [customer.dodopayments.com](https://customer.dodopayments.com) e ingresan su dirección de correo electrónico. Recibirán un enlace seguro de inicio de sesión que otorga acceso a todas sus compras dentro del ecosistema de Dodo Payments.
   
   <Tip>
   El Portal Unificado de Clientes complementa los portales de clientes específicos de cada negocio. Los clientes aún pueden acceder a portales de comerciantes individuales para una experiencia de marca, o usar el portal unificado para una vista consolidada.
   </Tip>
   
   <Note>
   El portal unificado utiliza la misma autenticación basada en correo electrónico que los portales específicos de negocio, garantizando una experiencia consistente y segura.
   </Note>

3. **ID de factura en la respuesta de pago**  
   La respuesta de Pago ahora incluye un campo `invoice_id`, facilitando reconciliar pagos con facturas e integrarse con sistemas de contabilidad.
   

   ```json
   {
     "payment_id": "pay_2IjeQm4hqU6RA4Z4kwDee",
     "status": "succeeded",
     "invoice_id": "inv_2IsUnWGtRKFLxk7xAQeyt",
     "total_amount": 9900,
     "currency": "USD",
     // ... other fields
   }
   ```

   
   ### Casos de uso
   
   - **Integración contable**: Vincula directamente los pagos con las facturas en tu software de contabilidad
   - **Atención al cliente**: Encuentra rápidamente la factura asociada a un pago al gestionar solicitudes de soporte
   - **Reconciliación**: Simplifica la conciliación financiera emparejando pagos con facturas de forma programática
   - **Cumplimiento**: Mantén registros precisos vinculando los pagos con sus facturas fiscales correspondientes
   
   <Info>
   El campo `invoice_id` utiliza identificadores de factura específicos de India cuando están disponibles, asegurando el cumplimiento con los requisitos locales de facturación.
   </Info>
   
   Más información: [Get Payment Detail API](/api-reference/payments/get-payments-1)
