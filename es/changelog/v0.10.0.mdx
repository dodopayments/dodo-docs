## Nuevas funciones
- **Atlas de código abierto**: Una aplicación de demostración escrita en Next.js para mostrar la integración de Dodo Payments. Explora el [repositorio de GitHub](https://github.com/dodopayments/dodo-checkout-demo) y la documentación [aquí](/developer-resources/integration-guide).
- **Sección de solicitudes de funciones**: Se introdujo una sección de solicitudes de funciones en el dashboard de Dodo Payments para priorizar la hoja de ruta del producto según los comentarios de los usuarios.
- **API de registros de solicitudes de webhook**: Se añadieron APIs para enumerar y consultar en detalle los registros de solicitudes de webhook.
- **Enlaces de pago estáticos**: Se añadieron más parámetros de consulta a los enlaces de pago estáticos para ofrecer mayor flexibilidad en el proceso de checkout. Para obtener más información, haz clic [aquí](/developer-resources/integration-guide#4-static-payment-links).
- **API de lista de suscripciones**: Se añadió una API para obtener todas las suscripciones. Consulta la [referencia de la API](/api-reference/subscriptions/get-subscriptions-1) para obtener más información.

## Mejoras Menores y Correcciones de Errores
- Se mejoraron las respuestas de la API de Producto y Suscripción con parámetros adicionales.
- Se implementó limitación de tasa para las solicitudes de API, actualmente establecida en 20 solicitudes por segundo.
- Se mejoró la documentación para que sea más amigable y fácil de navegar.
- Varias correcciones de errores menores y mejoras.
