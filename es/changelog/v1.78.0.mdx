## Nuevas Funciones

### 1. **Preferencias de Comunicación**

   Toma el control de cómo recibes notificaciones con nuestras renovadas Preferencias de Comunicación. Configura notificaciones por correo electrónico, push y en la aplicación para que se ajusten a tu flujo de trabajo.

   <Frame>
     <img src="/images/communication-preferences/overview.png" alt="Resumen de Preferencias de Comunicación mostrando configuraciones de notificación" />
   </Frame>

   **Características Clave**

   - **Diseños de correo electrónico renovados**: Plantillas de correo electrónico frescas y modernas con llamadas a la acción claras y mejor legibilidad
   - **Notificaciones push**: Recibe alertas instantáneas en tu dispositivo móvil para eventos críticos como nuevas ventas, disputas y pagos
   - **Controles granulares**: Elige exactamente qué eventos activan notificaciones y a través de qué canales
   - **Soporte para múltiples correos electrónicos**: Agrega múltiples direcciones de correo electrónico para recibir notificaciones
   - **Preferencias de correo electrónico del cliente**: Configura qué correos electrónicos reciben tus clientes

   **Categorías de Notificación**

   | Categoría | Descripción |
   |----------|-------------|
   | **Ventas y Pagos** | Nuevas ventas, pagos exitosos, pagos fallidos |
   | **Pagos y Reembolsos** | Completaciones de pagos, solicitudes de reembolso, completaciones de reembolso |
   | **Suscripciones** | Nuevas suscripciones, renovaciones, cancelaciones, cambios de plan |
   | **Disputas** | Disputa abierta, evidencia requerida, disputa resuelta |

   <Check>
   Resultado: Mantente informado sobre tu negocio con notificaciones entregadas exactamente como y cuando las desees.
   </Check>

   Aprende más: [Guía de Preferencias de Comunicación](/features/communication-preferences)

### 2. **Campos Personalizados en Sesiones de Checkout**

   Recoge información adicional de los clientes durante el checkout con campos personalizados. Agrega entradas de texto, listas desplegables, fechas y más para recopilar los datos que necesitas.

   **Tipos de Campos Soportados**

   | Tipo | Descripción | Caso de Uso |
   |------|-------------|----------|
   | `text` | Entrada de texto de una sola línea | Nombre de la empresa, notas de pedido |
   | `number` | Entrada numérica | Cantidad, edad |
   | `email` | Entrada de correo electrónico con validación | Correo electrónico del contacto de facturación |
   | `url` | Entrada de URL con validación | Sitio web, perfil social |
   | `date` | Selector de fecha | Fecha de entrega, fecha del evento |
   | `dropdown` | Selección de opciones predefinidas | Tamaño, color, tipo de plan |
   | `boolean` | Casilla de verificación para valores sí/no | Aceptación de términos, suscripción a boletín |

   **Cómo Funciona**

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     custom_fields: [
       {
         name: 'company_name',
         label: 'Company Name',
         type: 'text',
         required: true
       },
       {
         name: 'team_size',
         label: 'Team Size',
         type: 'dropdown',
         options: ['1-10', '11-50', '51-200', '200+'],
         required: true
       },
       {
         name: 'newsletter',
         label: 'Subscribe to our newsletter',
         type: 'boolean',
         required: false
       }
     ],
     return_url: 'https://yoursite.com/success'
   });
   ```

   **Beneficios**

   - **Recopilación de datos flexible**: Recoge cualquier información necesaria para el cumplimiento o personalización
   - **Validación incorporada**: Campos de correo electrónico y URL validan automáticamente el formato de entrada
   - **Control de requerido/opcional**: Marca campos como requeridos u opcionales según tus necesidades
   - **Entrega de Webhook**: Los valores de los campos personalizados se incluyen en los eventos de webhook de pago

   <Info>
   Los valores de los campos personalizados se devuelven en el objeto `custom_fields` dentro de las respuestas de pago y sesiones de checkout.
   </Info>

   Aprende más: [Campos Personalizados en Sesiones de Checkout](/developer-resources/checkout-session#custom-fields)

### 3. **Soporte Ampliado de Idiomas en el Checkout**

   La página de checkout ahora soporta **21 idiomas**, un aumento respecto a 16. Alcance más clientes en su idioma nativo para una mejor experiencia de checkout.

   **Nuevos Idiomas Añadidos**

   | Idioma | Código |
   |----------|------|
   | Coreano | `ko` |
   | Malayo | `ms` |
   | Rumano | `ro` |
   | Ruso | `ru` |
   | Tailandés | `th` |

   **Todos los Idiomas Soportados**

   Árabe, Chino, Neerlandés, Inglés, Francés, Alemán, Hindi, Indonesio, Italiano, Japonés, Coreano, Malayo, Portugués, Rumano, Ruso, Español, Sueco, Tailandés, Turco, Ucraniano, Vietnamita.

   **Forzar un Idioma Específico**

   Usa el parámetro `force_language` para anular la detección automática del idioma:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     force_language: 'ko', // Force Korean language
     return_url: 'https://yoursite.com/success'
   });
   ```

   <Tip>
   Por defecto, la página de checkout detecta automáticamente el idioma preferido del cliente según la configuración de su navegador. Usa `force_language` cuando quieras asegurar la consistencia con el idioma de tu sitio web.
   </Tip>

   Aprende más: [Soporte de Idiomas en el Checkout](/features/checkout#supported-languages)
