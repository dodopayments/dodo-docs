## Overview

Agent Skills are reusable capabilities that enhance what AI coding assistants can do when working with Dodo Payments. They provide procedural knowledge and best practices that help agents accomplish specific tasks more effectively - from integrating checkout flows to setting up usage-based billing.

<Info>
**Think of skills as plugins for your AI assistant.** They teach your agent how to implement Dodo Payments features correctly, following our recommended patterns and best practices.
</Info>

Las skills funcionan con cualquier agente de IA compatible con el protocolo de skills, incluidos:
- **Claude Code** - asistente de programación CLI de Anthropic
- **Codex CLI** - agente de programación CLI de OpenAI
- **Cursor** - editor de código centrado en la IA
- **VS Code / GitHub Copilot** - mediante el Agent Plugin
- **Kiro** - carga las skills como una Power
- **OpenCode** - agente de programación de IA de código abierto
- **Otros clientes** - cualquier agente compatible con el protocolo de skills

<Note>
**Gemini CLI es la excepción.** No tiene una primitiva de agent-skill, por lo que las skills no están disponibles allí; solo lo están los dos [servidores MCP](/developer-resources/mcp-server).
</Note>

## Instalación

Elige tu método de instalación preferido según tu asistente de programación con IA.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Si usas Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro u OpenCode, el [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) instala las diecisiete skills y los dos servidores MCP en un solo paso. Las skills se cargan automáticamente cuando tu agente detecta una tarea relevante.

Consulta la [guía de AI Coding Agents](/developer-resources/build-with-ai-coding-agents) para ver los comandos de instalación de cada agente.
</Tab>

<Tab title="Skills CLI">
Instala las skills mediante la CLI universal de skills, compatible con cualquier agente compatible con MCP:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

También puedes instalar skills individuales según sea necesario:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/dodo-best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
Instala solo las skills que necesites para mantener tu agente centrado y reducir la sobrecarga de contexto.
</Tip>

<Tab title="OpenCode">
OpenCode carga las skills desde los directorios que le indiques. **No** analiza los paquetes instalados, por lo que se requiere una entrada explícita de `skills.paths`.

Mediante el paquete Agent Plugin:

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

Las rutas relativas se resuelven en relación con el **directorio del proyecto**, por lo que el paquete debe estar presente en su `node_modules`. También funciona una ruta absoluta y evita el requisito de instalación local.

<Warning>
Una ruta de skills que no existe se ignora **silenciosamente**: no se muestra ningún error ni advertencia. Confirma que las skills se hayan cargado correctamente:

```bash
opencode run "List every skill available to you by name."
```

Deberías ver las diecisiete.
</Warning>
</Tab>
</Tabs>

## Uso de las skills

Una vez instaladas, tu asistente de IA carga automáticamente la skill relevante cuando le pides que implemente una funcionalidad de Dodo Payments. No necesitas indicar el nombre de la skill; solo describe la tarea.

| Ejemplo de prompt | Skill que se carga |
|----------------|------------------|
| Ayúdame a integrar Dodo Payments en mi aplicación de Next.js siguiendo las prácticas recomendadas | `dodo-best-practices` |
| Añade un route handler de checkout de Dodo Payments a mi aplicación de Hono | `framework-adapters` |
| Explícame cómo probar los pagos y pasar a producción | `testing-and-go-live` |
| Crea una sesión de checkout para mi producto SaaS | `checkout-integration` |
| Implementa un flujo de suscripción con una prueba gratuita y varios niveles de precios | `subscription-integration` |
| Añade un checkout dentro de la aplicación a mi aplicación de React Native | `mobile-checkout` |
| Configura handlers de webhook para eventos de pago y suscripción | `webhook-integration` |
| Configura derechos de crédito y deducción de créditos basada en medidores para mi producto de IA | `credit-based-billing` |
| Añade facturación basada en el uso para realizar un seguimiento de las llamadas a la API de mi producto de IA | `usage-based-billing` |
| Implementa la validación de license keys para mi aplicación de escritorio | `license-keys` |
| Crea un catálogo de productos con complementos y precios escalonados | `product-catalog-management` |
| Añade un código promocional con un 20 % de descuento en los tres primeros ciclos de facturación | `discounts-and-promotions` |
| Muestra los precios en la moneda local del visitante con paridad de poder adquisitivo | `localized-pricing` |
| Ofrece a los clientes un portal de autoservicio para gestionar sus métodos de pago | `customer-management` |
| Emite un reembolso parcial y revoca el acceso cuando se abre una disputa | `refunds-and-disputes` |
| Añade una página de precios usando componentes de BillingSDK | `billing-sdk` |
| Integra Dodo Payments en mi configuración de Better Auth | `better-auth-integration` |

## Cómo funcionan las skills

Las skills proporcionan a tu asistente de IA:

1. **Conocimientos procedimentales** - Instrucciones paso a paso para implementar funcionalidades
2. **Plantillas de código** - Patrones y fragmentos de código listos para producción
3. **Prácticas recomendadas** - Enfoques recomendados para la seguridad, la gestión de errores y la UX
4. **Consciencia del contexto** - Comprensión de cómo funcionan conjuntamente las distintas funcionalidades de Dodo Payments

Cuando pides a tu asistente de IA que implemente una funcionalidad, utiliza la skill relevante para:
- Comprender el enfoque de implementación correcto
- Generar código preciso y funcional
- Seguir las convenciones de Dodo Payments
- Gestionar correctamente los casos límite y los errores

<Note>
Las skills complementan el [MCP Server](/developer-resources/mcp-server) y [Sentra](/developer-resources/sentra). Usa MCP para las operaciones de API, Sentra para una integración guiada y las skills para mejorar las capacidades del asistente de IA.
</Note>
