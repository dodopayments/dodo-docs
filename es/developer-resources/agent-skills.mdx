## Overview

Agent Skills are reusable capabilities that enhance what AI coding assistants can do when working with Dodo Payments. They provide procedural knowledge and best practices that help agents accomplish specific tasks more effectively - from integrating checkout flows to setting up usage-based billing.

<Info>
**Think of skills as plugins for your AI assistant.** They teach your agent how to implement Dodo Payments features correctly, following our recommended patterns and best practices.
</Info>

Skills work with any MCP-compatible AI agent, including:
- **Claude Code** - Anthropic's CLI coding assistant
- **OpenCode** - Open source AI coding agent
- **Cursor** - AI-first code editor
- **Other MCP clients** - Any agent supporting the skills protocol

## Installation

Choose your preferred installation method based on your AI coding assistant.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Si estás utilizando Claude Code, Codex CLI, Cursor o OpenCode, el [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) instala las ocho habilidades más ambos servidores MCP en un paso. Las habilidades se cargan automáticamente cuando tu agente detecta una tarea relevante.

Consulta la [guía de Agentes de Codificación AI](/developer-resources/build-with-ai-coding-agents) para los comandos de instalación por agente.
</Tab>

<Tab title="Skills CLI">
Instala habilidades utilizando el CLI de habilidades universales que funciona con cualquier agente compatible con MCP:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

O instala habilidades individuales según sea necesario:

```bash
# Best practices guide
npx skills add dodopayments/skills/dodo-payments/best-practices

# Webhook integration
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Subscription billing
npx skills add dodopayments/skills/dodo-payments/subscription-integration

# Checkout flows
npx skills add dodopayments/skills/dodo-payments/checkout-integration

# Usage-based billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing

# BillingSDK components
npx skills add dodopayments/skills/dodo-payments/billing-sdk

# License key management
npx skills add dodopayments/skills/dodo-payments/license-keys

# Credit-based billing
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
```

<Tip>
Instala solo las habilidades que necesites para mantener tu agente enfocado y reducir la sobrecarga de contexto.
</Tip>
</Tab>

<Tab title="Claude Code">
Agrega el mercado de habilidades de Dodo Payments a Claude Code:

```bash
/plugin marketplace add dodopayments/skills
```

Luego instala complementos individuales:

```bash
# Install best practices
/plugin install dodo-best-practices

# Install webhook integration
/plugin install webhook-integration

# Install subscription integration
/plugin install subscription-integration

# Install checkout integration
/plugin install checkout-integration

# Install usage-based billing
/plugin install usage-based-billing

# Install BillingSDK
/plugin install billing-sdk

# Install license keys
/plugin install license-keys

# Install credit-based billing
/plugin install credit-based-billing
```

</Tab>

<Tab title="OpenCode">
Las habilidades están disponibles automáticamente cuando están configuradas en tu configuración de OpenCode. Agrega el repositorio de habilidades de Dodo Payments a tu configuración:

```json
{
  "skills": {
    "repositories": [
      "dodopayments/skills"
    ]
  }
}
```

</Tab>
</Tabs>

## Uso de Habilidades

Una vez instaladas, tu asistente de IA puede aprovechar estas habilidades cuando le pidas que implemente características de Dodo Payments. Aquí tienes algunos ejemplos de solicitudes:

### Mejores Prácticas

```
Help me integrate Dodo Payments into my Next.js app following best practices
```

### Webhooks

```
Set up webhook handlers for payment and subscription events
```

### Suscripciones

```
Implement a subscription flow with free trial and multiple pricing tiers
```

### Pago

```
Create a checkout session for my SaaS product
```

### Facturación Basada en Uso

```
Add usage-based billing to track API calls for my AI product
```

### BillingSDK

```
Add a pricing page using BillingSDK components
```

### Claves de Licencia

```
Implement license key validation for my desktop app
```

### Facturación Basada en Crédito

```
Set up credit entitlements and metered credit deduction for my AI product
```

## Cómo Funcionan las Habilidades

Las habilidades proporcionan a tu asistente de IA con:

1. **Conocimiento Procedural** - Instrucciones paso a paso para implementar características
2. **Plantillas de Código** - Patrones y fragmentos de código listos para producción
3. **Mejores Prácticas** - Enfoques recomendados para seguridad, manejo de errores y UX
4. **Conciencia de Contexto** - Comprensión de cómo funcionan juntas las diferentes características de Dodo Payments

Cuando le pides a tu asistente de IA que implemente una característica, utiliza la habilidad relevante para:
- Entender el enfoque correcto de implementación
- Generar un código preciso y funcional
- Seguir las convenciones de Dodo Payments
- Manejar adecuadamente los casos límite y errores

<Note>
Las habilidades complementan al [Servidor MCP](/developer-resources/mcp-server) y a [Sentra](/developer-resources/sentra). Usa MCP para operaciones API, Sentra para integración guiada, y Habilidades para capacidades mejoradas del asistente de IA.
</Note>
