En este tutorial, crearás una **aplicación de chat con IA** con facturación automática basada en el uso. Crearemos todo desde cero: el medidor de facturación, la configuración del producto y el código de la aplicación que permite mantener conversaciones y realiza un seguimiento del uso de tokens en tiempo real.

<Note>
Este tutorial proporciona una aplicación completa y funcional, con backend y frontend. La aplicación de chat utiliza la IA Gemini de Google y realiza un seguimiento automático del uso de tokens sin necesidad de ningún recuento manual.
</Note>

Al finalizar este tutorial, tendrás una aplicación de chat funcional que:
- Permite mantener conversaciones con IA usando Google Gemini (AI SDK)
- Realiza un seguimiento automático del uso de tokens (sin código manual)
- Cobra a los clientes según el consumo real de tokens
- Incluye una atractiva interfaz de chat

## Lo que vamos a crear

Comencemos por comprender nuestro servicio de chat con IA:

- **Servicio**: chat con tecnología de IA usando Google Gemini (AI SDK)
- **Modelo de precios**: pago por token ($0.01 por cada 1,000 tokens)
- **Nivel gratuito**: 10,000 tokens gratuitos por cliente al mes
- **Funciones**: historial de conversaciones y seguimiento automático de tokens

<Info>
Antes de comenzar, asegúrate de tener:
- Una cuenta de Dodo Payments
- Una clave de API de Google AI ([Obtén una en aistudio](https://aistudio.google.com/api-keys))
- Node.js v16+ instalado
</Info>

## Paso 1: Crea tu medidor de uso

Comenzaremos creando un medidor en tu panel de control de Dodo Payments que realizará un seguimiento del uso de tokens de IA.

<Tip>
**Lo que vamos a crear**: un medidor llamado "AI Token Usage Meter" que suma todos los tokens consumidos en las conversaciones de chat.
</Tip>

<Steps>
<Step title="Open the Meters section">
1. Inicia sesión en tu panel de control de Dodo Payments
2. Haz clic en Products en la barra lateral izquierda
3. Haz clic en **Meters**
4. Haz clic en el botón **Create Meter**

<Frame>
  <img src="/images/cookbooks/ai-chat-app/create-meter.png" alt="Crear medidor" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Deberías ver un formulario en el que configuraremos el seguimiento de tokens.
</Step>

<Step title="Fill in the basic meter information">
Ahora introduciremos los detalles específicos de nuestro servicio de chat con IA:

**Nombre del medidor** → `AI Token Usage Meter`

**Descripción** → `Tracks token consumption from AI chat conversations using AI SDK`

**Nombre del evento** → `ai_chat_usage`

<Warning>
El nombre del evento `ai_chat_usage` debe coincidir exactamente con lo que enviaremos más adelante desde el código de nuestra aplicación. ¡Los nombres de los eventos distinguen entre mayúsculas y minúsculas!
</Warning>
</Step>

<Step title="Configure how we count tokens">
Configura la agregación (cómo cuenta el medidor nuestros eventos):

**Tipo de agregación**: selecciona **Sum** en el menú desplegable

**Agregado sobre**: escribe → `totalTokens`

**Unidad de medición**: escribe → `tokens`

<Info>
Usamos "Sum" porque queremos sumar todos los tokens consumidos en varios mensajes de chat. El SDK envía automáticamente `totalTokens` en cada evento.
</Info>
</Step>

<Step title="Create your meter">
1. Comprueba que todos los ajustes coincidan con los valores anteriores
2. Haz clic en **Create Meter**

<Frame>
  <img src="/images/cookbooks/ai-chat-app/meter-configuration.png" alt="Configuración del medidor" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Check>
**¡Medidor creado!** Tu "AI Token Usage Meter" ya está listo para comenzar a contar tokens. A continuación, lo conectaremos a un producto de facturación.
</Check>
</Step>
</Steps>

## Paso 3: Crea tu producto de facturación

Ahora debemos crear un producto que defina nuestros precios ($0.01 por cada 1,000 tokens con 10,000 tokens gratuitos). Esto conecta nuestro medidor con la facturación real.

<Tip>
**Lo que vamos a crear**: un producto llamado "AI Chat Service" que cobra según el consumo de tokens y ofrece un generoso nivel gratuito.
</Tip>

<Steps>
<Step title="Navigate to Products">
1. En el panel de control de Dodo Payments, haz clic en **Products** en la barra lateral izquierda
2. Haz clic en **Create Product**
3. Selecciona **Usage-Based** como tipo de producto

Esto indica a Dodo Payments que la facturación se basará en el uso del medidor, no en una suscripción fija.
</Step>

<Step title="Enter product details">
Completa los datos obligatorios:

**Nombre del producto**: → `AI Chat Service`

**Descripción**: → `AI-powered chat service with automatic token-based billing`

**Imagen del producto**: sube una imagen relevante

<Info>
Estos datos aparecerán en las facturas de los clientes, así que deben ser claros y profesionales.
</Info>
</Step>

<Step title="Connect your meter">
Antes de conectar el medidor, asegúrate de haber seleccionado **Usage Based Billing** como tipo de precio del producto.

Además, establece el **Fixed Price** en `0` para asegurarte de que los clientes solo paguen según su uso, sin ninguna tarifa base.

Ahora, vincula el medidor que acabas de crear:

1. Desplázate hasta la sección **Associated Meter**
2. Haz clic en **Add Meters**
3. En el menú desplegable, selecciona **"AI Token Usage Meter"** (el que creaste anteriormente)
4. Confirma que aparezca en la configuración de tu producto

<Check>
Tu medidor ya está conectado correctamente a este producto.
</Check>
</Step>

<Step title="Set your pricing">
Aquí definimos nuestro modelo de negocio:

**Precio por unidad**: introduce → `0.00001` (esto equivale a $0.01 por cada 1,000 tokens o $0.00001 por token)

**Umbral gratuito**: introduce → `10000` (los clientes reciben 10,000 tokens gratuitos al mes)

<Frame>
  <img src="/images/cookbooks/ai-chat-app/product-pricing.png" alt="Precios del producto" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Tip>
**Cómo funciona la facturación**: si un cliente utiliza 25,000 tokens en un mes, se le cobrará por 15,000 tokens (25,000 - 10,000 gratuitos) = 15,000 × $0.00001 = $0.15
</Tip>
</Step>

<Step title="Save your product">
1. Revisa todos los ajustes:
   - Nombre: AI Chat Service
   - Medidor: AI Token Usage Meter
   - Precio: $0.01 por cada 1,000 tokens
   - Nivel gratuito: 10,000 tokens
2. Haz clic en **Save Changes**

<Check>
**¡Producto creado!** Tu facturación ya está configurada. A los clientes se les cobrará automáticamente según el uso de tokens.
</Check>
</Step>
</Steps>

<CodeGroup>

```typescript src/server.ts expandable
import express, { Request, Response } from 'express';
import { generateText } from 'ai';
import { google } from '@ai-sdk/google';
import { createLLMTracker } from '@dodopayments/ingestion-blueprints';
import 'dotenv/config';

const app = express();
app.use(express.json());
app.use(express.static('public'));

// Replace with your test customer ID
const CUSTOMER_ID = 'cus_123';

// Create tracker once with your meter event name
const llmTracker = createLLMTracker({
  apiKey: process.env.DODO_PAYMENTS_API_KEY!,
  environment: process.env.DODO_ENVIRONMENT as 'test_mode' | 'live_mode',
  eventName: 'ai_chat_usage', // Must match your meter configuration
});

// Chat endpoint with conversation support
app.post('/chat', async (req: Request, res: Response) => {
  try {
    const { messages } = req.body;

    if (!messages || !Array.isArray(messages)) {
      return res.status(400).json({ 
        error: 'Missing required field: messages (array)' 
      });
    }

    // Wrap AI SDK with automatic token tracking
    const trackedClient = llmTracker.wrap({
      client: { generateText },
      customerId: CUSTOMER_ID
    });

    // Generate AI response - tokens are automatically tracked!
    const response = await trackedClient.generateText({
      model: google('gemini-2.5-flash'),
      messages: messages
    });

    res.json({
      message: response.text,
      usage: {
        totalTokens: response.usage.totalTokens
      }
    });

  } catch (error: any) {
    console.error('Chat error:', error);
    res.status(500).json({ 
      error: 'Failed to process chat',
      details: error.message 
    });
  }
});

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
  console.log(`🚀 Server running at http://localhost:${PORT}`);
  console.log(`📊 Tracking event: ai_chat_usage`);
  console.log(`👤 Customer ID: ${CUSTOMER_ID}`);
  console.log(`🔧 Environment: ${process.env.DODO_ENVIRONMENT}`);
});
```

    <script>
      let conversationHistory = [];

      const messageInput = document.getElementById("messageInput");
      let resizeTimeout;
      messageInput.addEventListener("input", function () {
        clearTimeout(resizeTimeout);
        resizeTimeout = setTimeout(() => {
          this.style.height = "auto";
          this.style.height = Math.min(this.scrollHeight, 120) + "px";
        }, 10);
      });

      // Send message on Enter (Shift+Enter for new line)
      messageInput.addEventListener("keydown", function (e) {
        if (e.key === "Enter" && !e.shiftKey) {
          e.preventDefault();
          sendMessage();
        }
      });

      async function sendMessage() {
        const input = document.getElementById("messageInput");
        const message = input.value.trim();

        if (!message) return;

        // Hide empty state
        document.getElementById("emptyState").style.display = "none";

        // Hide error
        document.getElementById("errorMessage").classList.remove("show");

        // Add user message to UI
        addMessage("user", message);

        // Add to conversation history
        conversationHistory.push({
          role: "user",
          content: message,
        });

        // Clear input
        input.value = "";
        input.style.height = "auto";

        // Show typing indicator
        showTypingIndicator();

        // Disable send button
        const sendBtn = document.getElementById("sendBtn");
        sendBtn.disabled = true;

        try {
          const response = await fetch("/chat", {
            method: "POST",
            headers: {
              "Content-Type": "application/json",
            },
            body: JSON.stringify({
              messages: conversationHistory,
            }),
          });

          const data = await response.json();

          if (!response.ok) {
            throw new Error(data.error || "Failed to get response");
          }

          // Hide typing indicator
          hideTypingIndicator();

          // Add assistant response to UI
          addMessage("assistant", data.message, data.usage);

          // Add to conversation history
          conversationHistory.push({
            role: "assistant",
            content: data.message,
          });
        } catch (error) {
          hideTypingIndicator();
          showError(error.message);
          // Remove the last user message from history since it failed
          conversationHistory.pop();
        } finally {
          sendBtn.disabled = false;
        }
      }

      function addMessage(role, content, usage = null) {
        const messagesDiv = document.getElementById("chatMessages");

        const messageDiv = document.createElement("div");
        messageDiv.className = `message ${role}`;

        const avatar = role === "user" ? "👤" : "🤖";

        let metaHTML = "";
        if (usage) {
          metaHTML = `
                    <div class="message-meta">
                        <span class="token-badge">📊 ${usage.totalTokens} tokens</span>
                    </div>
                `;
        }

        messageDiv.innerHTML = `
                <div class="message-avatar">${avatar}</div>
                <div class="message-content">
                    <div class="message-bubble">${escapeHtml(content)}</div>
                    ${metaHTML}
                </div>
            `;

        messagesDiv.appendChild(messageDiv);
        requestAnimationFrame(() => {
          messagesDiv.scrollTop = messagesDiv.scrollHeight;
        });
      }

      function showTypingIndicator() {
        const messagesDiv = document.getElementById("chatMessages");

        const typingDiv = document.createElement("div");
        typingDiv.className = "message assistant";
        typingDiv.id = "typingIndicator";
        typingDiv.innerHTML = `
                <div class="message-avatar">🤖</div>
                <div class="typing-indicator show">
                    <div class="typing-dots">
                        <span></span>
                        <span></span>
                        <span></span>
                    </div>
                </div>
            `;

        messagesDiv.appendChild(typingDiv);
        requestAnimationFrame(() => {
          messagesDiv.scrollTop = messagesDiv.scrollHeight;
        });
      }

      function hideTypingIndicator() {
        const typingIndicator = document.getElementById("typingIndicator");
        if (typingIndicator) {
          typingIndicator.remove();
        }
      }

      function showError(message) {
        const errorDiv = document.getElementById("errorMessage");
        errorDiv.textContent = "❌ " + message;
        errorDiv.classList.add("show");
      }

      function escapeHtml(text) {
        const div = document.createElement("div");
        div.textContent = text;
        return div.innerHTML.replace(/\n/g, "<br>");
      }
    </script>
  </body>
</html>

## Solución de problemas

Problemas habituales y sus soluciones:

<AccordionGroup>
<Accordion title="Events not appearing in dashboard">
**Posibles causas:**
- El nombre del evento no coincide exactamente con la configuración del medidor
- El ID de cliente no existe en tu cuenta
- La clave de API no es válida o ha caducado
- Problemas de conectividad de red

**Soluciones:**
1. Comprueba que el nombre del evento coincida exactamente con la configuración del medidor (distingue entre mayúsculas y minúsculas: `ai_chat_usage`)
2. Comprueba que el ID de cliente exista en el panel de control de Dodo Payments
3. Prueba la clave de API con una llamada de API sencilla
4. Comprueba los registros del servidor para ver los mensajes de error
</Accordion>

<Accordion title="Token counts showing zero">
**Posibles causas:**
- El modelo no devuelve información de uso
- La versión del SDK es incorrecta

**Soluciones:**
1. Comprueba si el modelo devuelve información de uso:

```typescript
const response = await generateText({...});
console.log('Usage:', response.usage);
```

2. Actualiza a la versión más reciente de Blueprints SDK: `npm install @dodopayments/ingestion-blueprints@latest`
</Accordion>

<Accordion title="API key invalid error">
**Posibles causas:**
- La clave de API no corresponde al entorno
- Hay espacios o comillas adicionales en el archivo `.env`

**Soluciones:**
- Asegúrate de que la clave de prueba comience por `test_` y la clave activa por `live_`
- Elimina las comillas que rodeen las claves en el archivo `.env`
- Genera una clave nueva si es necesario
</Accordion>
</AccordionGroup>
