Administra tus recursos de Dodo Payments, crea sesiones de pago y prueba webhooks directamente desde la terminal. Diseñado para desarrolladores que prefieren la línea de comandos.

## Instalación

<CodeGroup>

```bash npm (Recommended)
npm install -g dodopayments-cli
```

```bash Bun
bun install -g dodopayments-cli
```

</CodeGroup>

### Instalación Manual

1. Descarga la última versión desde [GitHub Releases](https://github.com/dodopayments/dodopayments-cli/releases) para tu sistema
2. Extrae y renombra el binario a `dodo`
3. Mueve a un directorio en tu PATH:

<CodeGroup>

```bash Linux
sudo mv ./dodo /usr/local/bin/
```

```text Windows
move .\dodo C:\Windows\System32\dodo
```

</CodeGroup>

## Autenticación

Antes de usar la CLI, autentícate con tu clave API:

```bash
dodo login
```

Esto hará:
1. Abrir tu navegador en la página de Claves API de Dodo Payments
2. Pedirte que ingreses tu clave API
3. Preguntarte qué entorno seleccionar (**Modo de Prueba** o **Modo en Vivo**)
4. Almacenar tus credenciales localmente en `~/.dodopayments/api-key`

<Info>
La CLI admite el almacenamiento de una clave API por entorno. Si ambas claves de modo de prueba y en vivo están configuradas, se te pedirá elegir qué entorno utilizar para la sesión actual.
</Info>

## Uso

La sintaxis general es:

```bash
dodo ‹category› ‹sub-command›
```

Ejecutar `dodo` sin argumentos muestra todas las categorías disponibles. Ejecutar `dodo <category>` sin subcomando muestra los subcomandos disponibles para esa categoría.

### Productos

Administra tu catálogo de productos.

| Comando | Descripción |
|---------|-------------|
| `dodo products list` | Lista todos los productos (paginados) |
| `dodo products create` | Abre el tablero para crear un producto |
| `dodo products info` | Ver detalles de un producto específico |

### Pagos

Ver transacciones de pago.

| Comando | Descripción |
|---------|-------------|
| `dodo payments list` | Lista todos los pagos (paginados) |
| `dodo payments info` | Obtener información sobre un pago específico |

### Clientes

Administra tu base de clientes.

| Comando | Descripción |
|---------|-------------|
| `dodo customers list` | Lista todos los clientes (paginados) |
| `dodo customers create` | Crea un nuevo perfil de cliente |
| `dodo customers update` | Actualiza los detalles de un cliente existente |

### Descuentos

Administra cupones y descuentos.

| Comando | Descripción |
|---------|-------------|
| `dodo discounts list` | Lista todos los descuentos (paginados) |
| `dodo discounts create` | Crea un nuevo descuento basado en porcentaje |
| `dodo discounts delete` | Elimina un descuento por ID |

### Licencias

Administra licencias de software.

| Comando | Descripción |
|---------|-------------|
| `dodo licences list` | Lista todas las claves de licencia (paginadas) |

### Añadidos

Administra añadidos de productos.

| Comando | Descripción |
|---------|-------------|
| `dodo addons list` | Lista todos los añadidos (paginados) |
| `dodo addons create` | Abre el tablero para crear un añadido |
| `dodo addons info` | Ver detalles de un añadido específico |

### Reembolsos

Ver información sobre reembolsos.

| Comando | Descripción |
|---------|-------------|
| `dodo refund list` | Lista todos los reembolsos (paginados) |
| `dodo refund info` | Ver detalles de un reembolso específico |

### Pago

Crea sesiones de pago.

| Comando | Descripción |
|---------|-------------|
| `dodo checkout new` | Crea una nueva sesión de pago y obtén la URL de pago |

El comando de pago admite opciones avanzadas, incluida la recopilación mínima de direcciones, URL de retorno, aplicación de 3D Secure, códigos de descuento y metadatos.

## Pruebas de Webhook

La CLI incluye dos herramientas poderosas para probar webhooks durante el desarrollo: un **listener** que reenvía webhooks de prueba en vivo a tu servidor local, y un **trigger** que envía cargas útiles de webhook simuladas a cualquier endpoint.

### Escuchar Webhooks

Reenvía webhooks de Dodo Payments directamente a tu servidor de desarrollo local en tiempo real.

```bash
dodo wh listen
```

<Steps>
<Step title="Ingresa tu URL de endpoint local">
  Proporciona la URL local donde deseas recibir webhooks (por ejemplo, `http://localhost:3000/webhook`).
</Step>

<Step title="Configuración automática">
  La CLI crea automáticamente un endpoint de webhook en tu cuenta de Dodo Payments si no existe uno ya, y luego abre una conexión WebSocket para recibir eventos en tiempo real.
</Step>

<Step title="Recibir y reenviar">
  Cuando se activa un evento de webhook (de un pago de prueba, cambio de suscripción, etc.), la CLI lo recibe, registra el tipo de evento y reenvía la solicitud completa con encabezados y cuerpo a tu endpoint local. La respuesta de tu endpoint se registra y se envía de vuelta.
</Step>
</Steps>

<Warning>
El listener de webhook solo funciona con una clave API de **modo de prueba**. Asegúrate de que estás conectado con una clave de modo de prueba antes de usar `dodo wh listen`.
</Warning>

<Tip>
El listener preserva los encabezados de webhook originales (`webhook-id`, `webhook-signature`, `webhook-timestamp`) al reenviarlos a tu endpoint local, por lo que puedes probar tu lógica de verificación de firma.
</Tip>

### Activar Webhooks de Prueba

Envía cargas útiles de webhook simuladas a cualquier endpoint para pruebas rápidas sin necesidad de crear transacciones reales.

```bash
dodo wh trigger
```

Esto te guía a través de:
1. Establecer una **URL de endpoint** de destino
2. Opcionalmente, configurar **ID de Negocio**, **ID de Producto** y **Metadatos**
3. Seleccionar un **evento** específico para activar desde un menú interactivo
4. Enviar la carga útil simulada y ver la respuesta

Después de cada evento, puedes seleccionar otro evento para activar o salir, lo que facilita probar múltiples controladores de eventos en una sesión.

<Warning>
La herramienta de activación envía cargas útiles simuladas sin firmas de webhook. Desactiva la verificación de firmas de webhook durante las pruebas utilizando `unsafe_unwrap()` en lugar de `unwrap()` en tu controlador de webhook.
</Warning>

### Eventos de Webhook Soportados

| Categoría | Eventos |
|----------|--------|
| **Suscripción** | `subscription.active`, `subscription.updated`, `subscription.on_hold`, `subscription.renewed`, `subscription.plan_changed`, `subscription.cancelled`, `subscription.failed`, `subscription.expired` |
| **Pago** | `payment.success`, `payment.failed`, `payment.processing`, `payment.cancelled` |
| **Reembolso** | `refund.success`, `refund.failed` |
| **Disputa** | `dispute.opened`, `dispute.expired`, `dispute.accepted`, `dispute.cancelled`, `dispute.challenged`, `dispute.won`, `dispute.lost` |
| **Licencia** | `licence.created` |

### Variables de Entorno

| Variable | Descripción |
|----------|-------------|
| `DODO_WH_TEST_SERVER_URL` | Sobrescribir la URL del servidor de retransmisión de webhook predeterminada utilizada por `dodo wh listen` |
