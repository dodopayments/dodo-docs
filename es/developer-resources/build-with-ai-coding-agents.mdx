El Dodo Agent Plugin conecta dos servidores MCP y diecisiete skills de integración con tu agente de programación basado en IA en una sola instalación. Funciona con **Claude Code**, **Codex CLI**, **Cursor** y **OpenCode**; además, los servidores MCP y la CLI de skills funcionan con cualquier cliente compatible con MCP.

<Info>
**Tres primitivas, un solo plugin.** El Agent Plugin incluye todo lo que necesitas:
- **Servidor MCP de API** — acceso en tiempo real a pagos, suscripciones, clientes, productos, reembolsos, licencias y uso. Se autentica mediante OAuth en el navegador (no requiere claves locales).
- **Servidor MCP de conocimiento** — búsqueda semántica en toda la documentación de Dodo Payments. No requiere credenciales.
- **Diecisiete skills de agente** — hojas de referencia que tu agente carga cuando las necesita para checkout, suscripciones, webhooks, facturación basada en uso y en créditos, claves de licencia, catálogo de productos, descuentos, precios localizados, checkout móvil, reembolsos y disputas, gestión de clientes, adaptadores de frameworks, BillingSDK, Better Auth, pruebas y puesta en producción, y prácticas recomendadas.
</Info>

## Instalar el plugin

Elige tu agente de programación a continuación. La instalación añade automáticamente ambos servidores MCP y las diecisiete skills.

<AccordionGroup>
<Accordion title="Claude Code" defaultOpen>
Instalar desde el marketplace:

```bash
claude plugins marketplace add dodopayments/dodo-agent-plugin
claude plugins install dodopayments@dodopayments
```

El servidor API MCP utiliza OAuth del navegador por defecto — no se requieren claves al momento de la instalación. La primera vez que su agente llame a una herramienta Dodo, se le pedirá que inicie sesión.

<Card title="Dodo Agent Plugin on GitHub" icon="github" href="https://github.com/dodopayments/dodo-agent-plugin">
  Código fuente, opciones de configuración e instrucciones de desarrollo local
</Card>
</Accordion>

<Accordion title="Codex CLI">
Codex instala plugins en dos pasos: registra el marketplace desde tu terminal y luego instala el plugin desde dentro de la TUI de Codex.

<Steps>
<Step title="Register the marketplace">

```bash
codex plugin marketplace add dodopayments/dodo-agent-plugin
```

</Step>

<Step title="Install from the Codex TUI">
Abre Codex y ejecuta el comando `/plugins`:

```bash
codex
```

Luego escribe `/plugins`, cambia al marketplace **Dodo Payments**, selecciona el plugin **dodopayments** y elige **Instalar plugin**.
</Step>
</Steps>

Ambos servidores MCP y las diecisiete skills se registran automáticamente una vez instalado el plugin.

<Note>
Codex CLI no tiene un subcomando `codex plugin install` — la instalación de plugins siempre ocurre a través del flujo `/plugins` dentro de la TUI. Consulta los [documentos oficiales de plugins de Codex](https://developers.openai.com/codex/plugins).
</Note>

Si previamente agregaste el marketplace y el plugin no aparece bajo `/plugins`, actualízalo:

```bash
codex plugin marketplace upgrade dodopayments
```

</Accordion>

<Accordion title="Cursor">
Instalación manual — clona el repositorio en el directorio de plugins locales de Cursor:

```bash
git clone https://github.com/dodopayments/dodo-agent-plugin.git ~/.cursor/plugins/local/dodo-agent-plugin
```

Reinicia Cursor. El plugin carga habilidades desde `.claude/skills/` (a través de la capa de compatibilidad de Cursor con Claude Code) y servidores MCP desde `.mcp.json`.

<Info>
El soporte del marketplace de Cursor está en camino. Por ahora, utiliza la instalación manual anterior.
</Info>
</Accordion>

<Accordion title="OpenCode">
OpenCode se distribuye a través de npm. Agrega el plugin a tu `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"]
}
```

Reinicia OpenCode. Ambos servidores MCP (`dodopayments-api`, `dodo-knowledge`) se registran automáticamente mediante el hook de configuración del plugin, y las diecisiete skills se detectan automáticamente desde el paquete instalado. No se requiere ningún bloque `mcp` manual.
</Accordion>
</AccordionGroup>

<Info>
¿Usando un agente diferente? Las guías [MCP Server](/developer-resources/mcp-server) y [Agent Skills](/developer-resources/agent-skills) cubren Cursor, Claude Desktop, VS Code, Windsurf, Cline, Zed, y cualquier cliente compatible con MCP.
</Info>

## Lo que obtienes

Una vez instalado el plugin, tu agente tiene acceso a dos servidores MCP y diecisiete skills.

### Servidores MCP

| Servidor | Propósito | Autenticación |
|--------|---------|------|
| `dodopayments-api` | Acceso API en vivo — pagos, suscripciones, clientes, productos, reembolsos, licencias, uso | OAuth (navegador) |
| `dodo-knowledge` | Búsqueda semántica en toda la documentación de Dodo Payments | Ninguna |

Ambos servidores están conectados a través de `mcp-remote` para que funcionen en cualquier cliente compatible con MCP.

### Habilidades del agente

| Skill | Descripción |
|-------|-------------|
| `best-practices` | Configuración del SDK, entornos, claves de API y la arquitectura canónica de checkout a webhook |
| `framework-adapters` | Controladores de ruta oficiales de `@dodopayments/*` para Next.js, Express, Hono, Astro, Remix, SvelteKit, Nuxt, Fastify, TanStack, Bun y Convex |
| `testing-and-go-live` | Modo de prueba, métodos de pago de prueba, pruebas de webhooks y checklist de lanzamiento a producción |
| `checkout-integration` | Checkout Sessions, enlaces de pago y checkout superpuesto o integrado |
| `subscription-integration` | Ciclo de vida de las suscripciones, pruebas gratuitas, cambios de plan, prorrateo y cargos bajo demanda |
| `mobile-checkout` | Checkout dentro de la aplicación para React Native, Flutter, iOS y Android |
| `webhook-integration` | Recepción y verificación de webhooks mediante la especificación Standard Webhooks |
| `credit-based-billing` | Entitlements de crédito, saldos, libro mayor, rollover, excedentes y deducciones basadas en medidores |
| `usage-based-billing` | Medidores, ingesta de eventos, agregación y precios por unidad |
| `license-keys` | Activación y validación de claves de licencia y gestión de instancias |
| `product-catalog-management` | Productos, precios, complementos, colecciones, imágenes y distribución de productos digitales |
| `discounts-and-promotions` | Códigos de descuento, reglas de elegibilidad, combinación de descuentos y límites por ciclo de suscripción |
| `localized-pricing` | Precios localizados, Adaptive Currency y paridad del poder adquisitivo |
| `customer-management` | Clientes, portal de autoservicio, métodos de pago guardados y wallets |
| `refunds-and-disputes` | Emisión de reembolsos, gestión de disputas y contracargos, y conciliación del acceso |
| `billing-sdk` | Componentes de BillingSDK React para tablas de precios e interfaz de facturación |
| `better-auth-integration` | El plugin `@dodopayments/better-auth` para sincronización de clientes, checkout y acceso al portal |

Las habilidades se cargan automáticamente — tu agente elige la correcta cuando detecta una tarea relevante. Consulta la [documentación de Habilidades del Agente](/developer-resources/agent-skills) para ver la lista completa y la instalación individual.

### Prueba este prompt primero

Una vez que el plugin esté activo, prueba:

```
Set up Dodo Payments webhook handlers in my Next.js app for payment.succeeded and subscription.active events.
```

Tu agente cargará la habilidad `webhook-integration`, utilizará el MCP `dodo-knowledge` para obtener las últimas formas de carga útil y escribirá un controlador con verificación de firma siguiendo la especificación de Webhooks Estándar.

## Seguridad y mejores prácticas

<Warning>
**Nunca comprometas claves API de producción.** Usa [modo de prueba](/miscellaneous/test-mode-vs-live-mode) durante el desarrollo. El Plugin de Agente utiliza OAuth de navegador por defecto — solo cambia a claves API locales si tu flujo de trabajo lo requiere.
</Warning>

- **Usa primero el modo de prueba.** Prueba tu integración con claves `dodo_test_...` antes de ir en vivo. Consulta [Modo de Prueba vs Modo en Vivo](/miscellaneous/test-mode-vs-live-mode).
- **OAuth es el modo predeterminado.** El Plugin de Agente se autentica a través de OAuth de navegador (sin secretos locales). Solo usa el modo de claves API si lo necesitas — consulta la sección Configurar abajo.
- **Revisa el código generado por el agente.** Siempre verifica que los manejadores de webhooks incluyan la verificación de firma siguiendo la [Especificación de Webhooks Estándar](https://standardwebhooks.com/).

## Configura con una clave API

Por defecto, el Plugin de Agente utiliza el servidor MCP remoto con OAuth de navegador — no se necesitan credenciales locales. Si tu flujo de trabajo requiere una clave API local (por ejemplo, entornos CI, servidores sin cabeza), puedes cambiar a modo stdio.

<AccordionGroup>
<Accordion title="Local API key mode — Claude Code">
Abre `/plugins` en Claude Code, selecciona **Dodo Payments**, y elige **Configurar opciones**. Completa:

- `dodo_api_key` — tu clave `dodo_test_...` o `dodo_live_...`
- `dodo_webhook_key` — tu secreto de firma de webhook
- `dodo_environment` — `test_mode` o `live_mode`

Luego edita `.mcp.json` para apuntar `dodopayments-api` al servidor stdio local:

```json
{
  "mcpServers": {
    "dodopayments-api": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "dodopayments-mcp@latest"],
      "env": {
        "DODO_PAYMENTS_API_KEY": "${user_config.dodo_api_key}",
        "DODO_PAYMENTS_WEBHOOK_KEY": "${user_config.dodo_webhook_key}",
        "DODO_PAYMENTS_ENVIRONMENT": "${user_config.dodo_environment}"
      }
    }
  }
}
```

Ejecuta `/reload-plugins` para aplicar cambios a tu sesión actual.
</Accordion>

<Accordion title="Local API key mode — OpenCode">
Declara `dodopayments-api` tú mismo en `opencode.json` — tu entrada tiene prioridad sobre el servidor remoto predeterminado del plugin:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "mcp": {
    "dodopayments-api": {
      "type": "local",
      "command": ["npx", "-y", "dodopayments-mcp@latest"],
      "environment": {
        "DODO_PAYMENTS_API_KEY": "dodo_test_...",
        "DODO_PAYMENTS_WEBHOOK_KEY": "whsec_...",
        "DODO_PAYMENTS_ENVIRONMENT": "test_mode"
      },
      "enabled": true
    }
  }
}
```

Reinicia OpenCode para aplicar.
</Accordion>
</AccordionGroup>
