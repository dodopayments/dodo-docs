El Plugin Dodo Agent conecta dos servidores MCP y ocho habilidades de integración en su agente de codificación AI en una sola instalación. Funciona con **Claude Code**, **Codex CLI**, **Cursor** y **OpenCode** — y los servidores MCP y habilidades CLI funcionan con cualquier cliente compatible con MCP.

<Info>
**Tres elementos básicos, un plugin.** El Plugin de Agente agrupa todo lo que necesita:
- **Servidor API MCP** — acceso en vivo a pagos, suscripciones, clientes, productos, reembolsos, licencias y uso. Se autentica a través de OAuth del navegador (no se requieren claves locales).
- **Servidor de Conocimiento MCP** — búsqueda semántica en toda la documentación de Dodo Payments. No se necesitan credenciales.
- **Ocho habilidades de agente** — hojas de referencia que su agente carga a demanda para pagos, suscripciones, webhooks, facturación basada en uso, facturación basada en crédito, claves de licencia, BillingSDK y mejores prácticas.
</Info>

## Instalar el plugin

Elija su agente de codificación a continuación. La instalación agrega ambos servidores MCP y las ocho habilidades automáticamente.

<AccordionGroup>
<Accordion title="Claude Code" defaultOpen>
Instalar desde el marketplace:

```bash
claude plugins marketplace add dodopayments/dodo-agent-plugin
claude plugins install dodopayments@dodopayments
```

El servidor API MCP utiliza OAuth del navegador por defecto — no se requieren claves al momento de la instalación. La primera vez que su agente llame a una herramienta Dodo, se le pedirá que inicie sesión.

<Card title="Dodo Agent Plugin on GitHub" icon="github" href="https://github.com/dodopayments/dodo-agent-plugin">
  Código fuente, opciones de configuración e instrucciones de desarrollo local
</Card>
</Accordion>

<Accordion title="Codex CLI">
Codex lee `.claude-plugin/marketplace.json` de forma nativa, por lo que el mismo repositorio del plugin funciona:

```bash
codex plugin marketplace add dodopayments/dodo-agent-plugin
codex plugin install dodopayments@dodopayments
```

Ambos servidores MCP y todas las ocho habilidades se registran automáticamente.
</Accordion>

<Accordion title="Cursor">
Instalación manual — clone el repositorio en el directorio de plugins locales de Cursor:

```bash
git clone https://github.com/dodopayments/dodo-agent-plugin.git ~/.cursor/plugins/local/dodo-agent-plugin
```

Reinicie Cursor. El plugin carga habilidades desde `.claude/skills/` (a través de la capa de compatibilidad de Claude Code de Cursor) y servidores MCP desde `.mcp.json`.

<Info>
El soporte del marketplace para Cursor está en camino. Por ahora, use la instalación manual anterior.
</Info>
</Accordion>

<Accordion title="OpenCode">
OpenCode se distribuye a través de npm. Agregue el plugin a su `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"]
}
```

Reinicie OpenCode. Ambos servidores MCP (`dodopayments-api`, `dodo-knowledge`) se registran automáticamente a través del hook de configuración del plugin, y las ocho habilidades se descubren automáticamente desde el paquete instalado. No se requiere bloque `mcp` manual.
</Accordion>
</AccordionGroup>

## Qué obtiene

Una vez instalado el plugin, su agente tiene acceso a dos servidores MCP y ocho habilidades.

### Servidores MCP

| Servidor | Propósito | Auth |
|--------|---------|------|
| `dodopayments-api` | Acceso API en vivo — pagos, suscripciones, clientes, productos, reembolsos, licencias, uso | OAuth (navegador) |
| `dodo-knowledge` | Búsqueda semántica en toda la documentación de Dodo Payments | Ninguno |

Ambos servidores están conectados a través de `mcp-remote` para que funcionen en cualquier cliente compatible con MCP.

### Habilidades del agente

| Habilidad | Descripción |
|-------|-------------|
| `best-practices` | Guía completa para integrar Dodo Payments con mejores prácticas |
| `checkout-integration` | Creación de sesiones de pago y flujos de pago |
| `subscription-integration` | Implementación de flujos de facturación de suscripción |
| `webhook-integration` | Configuración y manejo de webhooks para eventos de pago |
| `usage-based-billing` | Implementación de facturación medida con eventos y medidores |
| `credit-based-billing` | Créditos, saldos y deducción de crédito medida |
| `license-keys` | Gestión de claves de licencia para productos digitales |
| `billing-sdk` | Uso de componentes React de BillingSDK |

Las habilidades se cargan automáticamente — su agente elige la correcta cuando detecta una tarea relevante. Consulte la [documentación de Habilidades del Agente](/developer-resources/agent-skills) para ver la lista completa y la instalación individual.

### Pruebe este mensaje primero

Una vez que el plugin esté activo, intente:

```
Set up Dodo Payments webhook handlers in my Next.js app for payment.succeeded and subscription.active events.
```

Su agente cargará la habilidad `webhook-integration`, usará el MCP `dodo-knowledge` para extraer las formas de payload más recientes y escribirá un manejador con verificación de firma siguiendo la especificación Webhooks estándar.

Con el plugin instalado, su agente de codificación puede:

- **Crear sesiones de pago y enlaces de pago** — [Pagos únicos](/features/one-time-payment-products) y [suscripciones](/features/subscription)
- **Implementar facturación de suscripción y basada en uso de extremo a extremo** — [Suscripciones](/features/subscription), [Facturación basada en uso](/features/usage-based-billing), [Facturación basada en crédito](/features/credit-based-billing)

## Seguridad y mejores prácticas

<Warning>
**Nunca comprometa las claves de API de producción.** Use [modo de prueba](/miscellaneous/test-mode-vs-live-mode) durante el desarrollo. El Plugin de Agente utiliza OAuth del navegador por defecto — solo cambie a claves API locales si su flujo de trabajo lo requiere.
</Warning>

- **Utilice el modo de prueba primero.** Pruebe su integración con claves `dodo_test_...` antes de lanzarla. Consulte [Modo de Prueba vs Modo en Vivo](/miscellaneous/test-mode-vs-live-mode).
- **OAuth es el predeterminado.** El Plugin de Agente se autentica a través de OAuth del navegador (sin secretos locales). Solo use el modo de clave API si lo necesita — consulte la sección de Configuración a continuación.
- **Revise el código generado por el agente.** Siempre verifique que los manejadores de webhooks incluyan verificación de firma siguiendo la [especificación de Webhooks estándar](https://standardwebhooks.com/).

## Configurar con una clave API

Por defecto, el Plugin de Agente utiliza el servidor remoto MCP con OAuth del navegador — no se necesitan credenciales locales. Si su flujo de trabajo requiere una clave API local (por ejemplo, entornos CI, servidores sin cabeza), puede cambiar al modo stdio.

<AccordionGroup>
<Accordion title="Local API key mode — Claude Code">
Abra `/plugins` en Claude Code, seleccione **Dodo Payments** y elija **Configurar opciones**. Complete:

- `dodo_api_key` — su clave `dodo_test_...` o `dodo_live_...`
- `dodo_webhook_key` — su secreto de firma de webhook
- `dodo_environment` — `test_mode` o `live_mode`

Luego edite `.mcp.json` para apuntar `dodopayments-api` al servidor local stdio:

```json
{
  "mcpServers": {
    "dodopayments-api": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "dodopayments-mcp@latest"],
      "env": {
        "DODO_PAYMENTS_API_KEY": "${user_config.dodo_api_key}",
        "DODO_PAYMENTS_WEBHOOK_KEY": "${user_config.dodo_webhook_key}",
        "DODO_PAYMENTS_ENVIRONMENT": "${user_config.dodo_environment}"
      }
    }
  }
}
```

Ejecute `/reload-plugins` para aplicar cambios a su sesión actual.
</Accordion>

<Accordion title="Local API key mode — OpenCode">
Declare `dodopayments-api` usted mismo en `opencode.json` — su entrada prevalece sobre el servidor remoto predeterminado del plugin:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "mcp": {
    "dodopayments-api": {
      "type": "local",
      "command": ["npx", "-y", "dodopayments-mcp@latest"],
      "environment": {
        "DODO_PAYMENTS_API_KEY": "dodo_test_...",
        "DODO_PAYMENTS_WEBHOOK_KEY": "whsec_...",
        "DODO_PAYMENTS_ENVIRONMENT": "test_mode"
      },
      "enabled": true
    }
  }
}
```

Reinicie OpenCode para aplicar.
</Accordion>
</AccordionGroup>
