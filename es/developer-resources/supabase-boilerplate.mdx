## Descripción general

Un boilerplate listo para producción para suscripciones que utiliza Next.js 15, React 19, Supabase, Drizzle ORM y Dodo Payments. Incluye Google OAuth, checkout de suscripciones, gestión de webhooks, esquema de base de datos y un dashboard básico.

<Info>
Si solo necesitas route handlers para una aplicación existente, consulta los adaptadores específicos: <a href="/developer-resources/nextjs-adaptor">adaptador de Next.js</a> y <a href="/developer-resources/express-adaptor">adaptador de Express</a>.
</Info>

## Requisitos previos

- Node.js 18+ (o Bun 1.0+)
- Proyecto de Supabase (URL, clave Anon, clave de rol de servicio, URL de la base de datos)
- Cuenta de Dodo Payments (API key, secreto de Webhook)
- Cliente OAuth de Google Cloud (Client ID y Secret)

## Inicio rápido

<Steps>
<Step title="Clone and install">

```bash
git clone https://github.com/dodopayments/dodo-supabase-subscription-starter.git
cd dodo-supabase-subscription-starter
# choose one
bun install
# or
npm install
# or
pnpm install
```

</Step>

<Step title="Create Supabase project">
Crea un proyecto de Supabase y copia:
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY
- SUPABASE_SERVICE_ROLE_KEY
- DATABASE_URL (cadena de conexión)
</Step>

<Step title="Configure Google OAuth">
Establece la URI de redirección en: `https://[your-project-ref].supabase.co/auth/v1/callback` en Google Cloud y, a continuación, habilita el proveedor de Google en Supabase Auth mediante tu Client ID y Secret.
</Step>

<Step title="Configure Dodo Payments">
Genera una API key y un secreto de Webhook desde el dashboard de Dodo. Establece el entorno en `test_mode` durante el desarrollo.
</Step>

<Step title="Create .env.local">

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role

# Database
DATABASE_URL=postgresql://postgres:[password]@db.[project-ref].supabase.co:5432/postgres

# Dodo Payments
DODO_PAYMENTS_API_KEY=your-dodo-api-key
DODO_WEBHOOK_SECRET=your-webhook-secret
DODO_PAYMENTS_ENVIRONMENT=test_mode
```

<Warning>
Nunca incluyas secretos en el commit. Usa variables de entorno en los entornos de implementación.
</Warning>
</Step>

<Step title="Provision database schema">

```bash
bun run db:push
# or
npm run db:push
# or
pnpm run db:push
```

<Check>
Tablas creadas: `users`, `subscriptions`, `payments`.
</Check>
</Step>

<Step title="Deploy webhook function">

```bash
# login (one-time)
bunx supabase login
# or
npx supabase login

# deploy the edge function
bun run deploy:webhook --project-ref [your-project-ref]
# or
npm run deploy:webhook -- --project-ref [your-project-ref]
# or
pnpm run deploy:webhook --project-ref [your-project-ref]
```

```bash cURL
curl -X POST \
  'https://[your-project-ref].supabase.co/functions/v1/dodo-webhook' \
  -H 'Content-Type: application/json' \
  -H 'Dodo-Signature: <signature>' \
  -d '{"type":"payment.succeeded","data":{}}'
```

</Step>

<Step title="Add webhook in Dodo Payments">
Establece la URL del endpoint en:

```text
https://[your-project-ref].supabase.co/functions/v1/dodo-webhook
```

Selecciona los eventos de pagos y suscripciones.
</Step>

<Step title="Create products and features">
En el dashboard de Dodo → Products → Create Product. Opcionalmente, añade metadatos:

```json
{
  "features": ["Feature 1", "Feature 2", "Feature 3"]
}
```

La UI de precios lee este array `features` y lo renderiza dinámicamente.
</Step>

<Step title="Run the dev server">

```bash
bun run dev
# or
npm run dev
# or
pnpm run dev
```

Abre http://localhost:3000.
</Step>
</Steps>

## Qué incluye

- Autenticación mediante Supabase (Google OAuth configurado)
- Checkout de suscripciones mediante Dodo Payments
- Supabase Edge Function para webhooks (`dodo-webhook`)
- Esquema y migraciones de Drizzle ORM
- Dashboard con facturas, estado de la suscripción y funciones del plan

<Tip>
Mantén `DODO_PAYMENTS_ENVIRONMENT` como `test_mode` hasta completar las pruebas de extremo a extremo.
</Tip>

## Verificación y solución de problemas

<AccordionGroup>
<Accordion title="Webhook signature invalid (401)">
- Asegúrate de que `DODO_WEBHOOK_SECRET` coincida con el valor del dashboard de Dodo
- Confirma que implementaste la función `dodo-webhook` más reciente
- Verifica que el nombre del encabezado sea correcto en tu función (Dodo-Signature)
</Accordion>
<Accordion title="Database push fails">
- Comprueba la sintaxis de `DATABASE_URL` y la salida de red de Supabase
- Espera aproximadamente 2–3 minutos después de crear el proyecto antes del primer push
</Accordion>
<Accordion title="OAuth redirect mismatch">
- La URI de redirección debe ser `https://[ref].supabase.co/auth/v1/callback`
- Asegúrate de que sea la misma en Google Cloud y en el proveedor de Supabase Auth
</Accordion>
</AccordionGroup>
