## Descripción General

La plantilla mínima de Astro proporciona un punto de partida listo para usar para integrar Dodo Payments con tu aplicación Astro. Esta plantilla incluye autenticación, manejo de webhooks y configuración básica de pagos para ayudarte a comenzar a aceptar pagos rápidamente.

<Info>
Esta plantilla utiliza Astro con TypeScript e incluye implementaciones de ejemplo para sesiones de pago y verificación de webhooks.
</Info>

## Inicio Rápido

<Steps>
<Step title="Clona el Repositorio">
Clona el repositorio de la plantilla y navega al directorio del proyecto:

```bash
git clone https://github.com/dodopayments/dodo-astro-minimal-boilerplate.git
cd dodo-astro-minimal-boilerplate
```

</Step>

<Step title="Obtén tus Credenciales de API">
Obtén tus credenciales desde el panel de Dodo Payments en Modo de Prueba:

- **API Key**: Navega a **Desarrollador → Claves API** en tu [panel](https://app.dodopayments.com)
- **Webhook Signing Key**: Navega a **Desarrollador → Webhooks** en tu [panel](https://app.dodopayments.com)

<Tip>
Comienza con el Modo de Prueba para probar tu integración de forma segura sin procesar pagos reales.
</Tip>
</Step>

<Step title="Configura las Variables de Entorno">
Crea un `.env` archivo en el directorio raíz:

```bash
touch .env
```

Agrega tus credenciales de Dodo Payments:

```bash .env
DODO_API_KEY_TEST=your_test_api_key_here
DODO_PAYMENTS_WEBHOOK_KEY=your_webhook_signing_key_here
```

<Warning>
Nunca cometas tu `.env` archivo en el control de versiones. Ya está incluido en `.gitignore`.
</Warning>
</Step>

<Step title="Configura el Webhook Localhost">
Al probar webhooks localmente, expón tu localhost utilizando herramientas como [ngrok](https://ngrok.com):

```bash
ngrok http 4321
```

Agrega la URL de ngrok a la `allowed_hosts` lista en `astro.config.mjs` para la entrega de webhooks:

```javascript astro.config.mjs
export default defineConfig({
  server: {
    host: true,
    allowedHosts: ['your-ngrok-url.ngrok.io']
  }
});
```

<Note>
Este paso es necesario para que los webhooks se entreguen a tu entorno de desarrollo local.
</Note>
</Step>

<Step title="Instala Dependencias">
Instala los paquetes npm requeridos:

```bash
npm install
```

</Step>

<Step title="Ejecuta el Servidor de Desarrollo">
Inicia el servidor de desarrollo de Astro:

```bash
npm run dev
```

Tu aplicación estará disponible en `http://localhost:4321`.

<Check>
¡Estás listo para comenzar a construir! La plantilla incluye rutas y componentes de ejemplo para ayudarte a entender la integración.
</Check>
</Step>
</Steps>

## Estructura del Proyecto

```
dodo-astro-minimal-boilerplate/
├── src/
│   ├── pages/
│   │   ├── api/
│   │   │   └── webhooks.ts     # Webhook handler
│   │   └── index.astro         # Home page with examples
│   └── lib/
│       └── dodo.ts             # Dodo Payments client setup
├── .env.example                # Environment variables template
├── astro.config.mjs            # Astro configuration
└── package.json
```

## Próximos Pasos

Una vez que tengas la plantilla en funcionamiento:

<Steps>
<Step title="Crea tus Productos">
Agrega productos en tu [panel de Dodo Payments](https://app.dodopayments.com) para habilitar la funcionalidad de checkout.
</Step>

<Step title="Prueba Webhooks Localmente">
Usa [ngrok](https://ngrok.com) para exponer tu endpoint de webhook local y actualiza el `allowed_hosts` en `astro.config.mjs`:

```bash
ngrok http 4321
```

Agrega la URL de ngrok a la configuración de tu webhook en el panel.
</Step>

<Step title="Personaliza la Integración">
Adapta el código de ejemplo para que se ajuste a las necesidades y diseño de tu aplicación.
</Step>

<Step title="Pasa a Producción">
Cuando estés listo, cambia a las claves API de Modo en Vivo y despliega tu aplicación.
</Step>
</Steps>
