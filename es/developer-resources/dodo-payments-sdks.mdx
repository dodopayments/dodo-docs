Dodo Payments proporciona SDKs oficiales para múltiples lenguajes de programación, cada uno diseñado con las mejores prácticas específicas del lenguaje y características modernas para una integración de pagos sin problemas.

<Tip>
Utiliza siempre la versión más reciente del SDK para acceder a las funciones e mejoras más recientes. Revisa tu gestor de paquetes periódicamente para asegurarte de tener acceso a todas las capacidades de Dodo Payments.
</Tip>

## Inicio Rápido

Comienza con cualquier SDK en minutos:

 <Steps>
<Step title="Install the SDK">
  Usa el gestor de paquetes de tu lenguaje para instalar el SDK
  
  <Tabs>
  <Tab title="TypeScript/Node.js">

  ```bash
  npm install dodopayments
  ```

  </Tab>
  
  <Tab title="Python">

  ```bash
  pip install dodopayments
  ```

  </Tab>
  
  <Tab title="PHP">

  ```bash
  composer require dodopayments/client
  ```

  </Tab>
  
  <Tab title="Go">

  ```bash
  go get github.com/dodopayments/dodopayments-go
  ```

  </Tab>

  <Tab title="Rust">

  ```bash
  cargo add dodopayments
  ```

  </Tab>
  </Tabs>
</Step>

 <Step title="Initialize the Client">
  Configura el cliente con tu clave API
  
  <Tabs>
  <Tab title="TypeScript">

  ```typescript
  import DodoPayments from 'dodopayments';
  const client = new DodoPayments({ bearerToken: 'your_api_key' });
  ```

  </Tab>
  
  <Tab title="Python">

  ```python
  from dodopayments import DodoPayments
  client = DodoPayments(bearer_token="your_api_key")
  ```

  </Tab>
  
  <Tab title="PHP">

  ```php
  use Dodopayments\Client;
  $client = new Client(bearerToken: 'your_api_key');
  ```

  </Tab>
  
  <Tab title="Go">

  ```go
  import "github.com/dodopayments/dodopayments-go"
  client := dodopayments.NewClient(option.WithBearerToken("your_api_key"))
  ```

  </Tab>

  <Tab title="Rust">

  ```rust
  use dodopayments::Client;
  let client = Client::from_env()?; // reads DODO_PAYMENTS_API_KEY
  ```

  </Tab>
  </Tabs>
  
  <Warning>
  Siempre almacena tus claves API de forma segura utilizando variables de entorno. Nunca las comprometas al control de versiones.
  </Warning>
</Step>

 <Step title="Make Your First API Call">
  Crea una sesión de pago o pago
  
  <Check>
  ¡Ahora estás listo para procesar pagos! Visita las páginas individuales de los SDK para guías y ejemplos detallados.
  </Check>
</Step>
</Steps>

## Características Clave

Todos los SDKs de **backend** comparten estas capacidades principales. Los SDKs de Mobile Checkout
a continuación son deliberadamente más limitados: no contienen ninguna API key ni llaman a la API:

- **Seguridad de Tipos**: Fuerte tipado para seguridad en tiempo de compilación y mejor soporte de IDE
- **Manejo de Errores**: Gestión exhaustiva de excepciones con mensajes de error detallados
- **Autenticación**: Autenticación simple con clave API y soporte para variables de entorno
- **Soporte Asíncrono**: Patrones modernos de async/await donde sea aplicable
- **Auto-Paginación**: Paginación automática para respuestas de listas
- **Facturación Basada en Uso**: Soporte incorporado para seguir e ingerir eventos de uso
- **Pruebas**: Soporte completo de entorno de sandbox para desarrollo y pruebas

## SDKs de Mobile Checkout

Si prefieres abrir la **página de checkout alojada** de Dodo en lugar de crear una
hoja de pago nativa, usa el SDK de Mobile Checkout para tu plataforma. Los cuatro comparten
el mismo contrato de una sola llamada: `start(...)` devuelve un `CheckoutResult` tipado,
ninguno contiene una API key, y Apple Pay/Google Pay funcionan de la misma manera que
en la web abierta, ya que el checkout se abre en la superficie del navegador real de la plataforma
(`SFSafariViewController` / Custom Tabs), no en un `WebView`:

## Interfaz de línea de comandos

Para flujos de trabajo y automatización basados en terminal:

<Card title="CLI" icon="terminal" href="/developer-resources/sdks/cli">
  Interfaz de línea de comandos autogenerada compatible con los 78 endpoints de la API
</Card>

**Características:**
- Estructura de comandos basada en recursos para un uso intuitivo
- Múltiples formatos de salida (JSON, YAML, legible, interactivo)
- Autocompletado de shell para bash, zsh y fish
- Ideal para scripting y automatización de CI/CD

```bash
# Quick example
dodopayments payments list --format json | jq '.data[] | {id, amount}'
```
