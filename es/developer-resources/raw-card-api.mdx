<Note>
Esta guía cubre exclusivamente **pagos únicos** que involucran **tarjetas, Apple Pay y Google Pay**.
</Note>

## Puntos Finales de API

| Entorno | URL Base | Punto Final de Confirmación de Pago |
| --- | --- | --- |
| **Modo de Prueba** | `https://test.dodopayments.com` | `https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm` |
| **Modo en Vivo** | `https://live.dodopayments.com` | `https://api.hs.dodopayments.com/payments/<payment_id>/confirm` |

## Flujo de Pago con Tarjeta Paso a Paso

### Paso 1: Obtén la Clave Secreta

Comienza creando un pago utilizando la siguiente API:

- **Pagos**: [Crear API de Pago](/api-reference/payments/post-payments)

Esta API devuelve un **`secret_key`**, necesario para los pasos siguientes.

### Paso 2: Confirma el Pago

Confirma el pago llamando al punto final `payments confirm`:

- **Modo de Prueba**: `POST https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm`
- **Modo en Vivo**: `POST https://api.hs.dodopayments.com/payments/<payment_id>/confirm`

Incluye los siguientes detalles en el cuerpo de la solicitud:

- `client_secret`: Clave secreta del Paso 1
- `payment_method`: Establecida en `card`
- `payment_method_data`: Detalles de tarjeta y facturación
- `browser_info`: Datos específicos del navegador (agente de usuario, detalles de la pantalla, etc.)
- `payment_type`: Establecido explícitamente en `normal` (para pagos únicos)

Headers requeridos:

- Obtén tu clave publicable del soporte de DodoPayments
- `api-key`: Tu clave publicable (Obtén esto del equipo de Dodo Payments)
- `content-type`: `application/json`

**Ejemplo de Cuerpo de Solicitud:**

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "card",
  "payment_method_data": {
    "card": {
      "card_number": "<card_number>",
      "card_exp_month": "<exp_month>",
      "card_exp_year": "<exp_year>",
      "card_holder_name": "<cardholder_name>",
      "card_cvc": "<cvc>",
      "card_network": "<network>"
    },
    "billing": {
      "address": {
        "first_name": "<first_name>",
        "last_name": "<last_name>"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Manejo de la Respuesta

- Si la respuesta **`status`** es **`requires_customer_action`**, redirige al cliente a la URL proporcionada en el campo **`next_action`** para una autenticación posterior.

<Warning>
Asegúrate de cumplir con las directrices de cumplimiento de PCI al manejar datos de tarjetas en crudo.
</Warning>

## Integración de Apple Pay

Para usar Apple Pay, establece `payment_method` en `wallet` e incluye los datos de Apple Pay en `payment_method_data`.

### Estructura del Cuerpo de Solicitud

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "apple_pay": {
        "payment_data": "<decrypted_payment_data>",
        "payment_method": {
          "display_name": "Visa 1234",
          "network": "Visa",
          "type": "debit"
        },
        "transaction_identifier": "UNIQUE_TRANSACTION_ID_FROM_APPLE"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Referencia de Campos de Apple Pay

| Campo | Tipo | Requerido | Descripción |
| --- | --- | --- | --- |
| `payment_data` | string | Sí | Este enum se utiliza para representar los datos de pago de Apple Pay, que pueden estar cifrados o descifrados. |
| `payment_method.display_name` | string | Sí | Nombre que se muestra en el botón de Apple Pay (por ejemplo, "Visa 1234") |
| `payment_method.network` | string | Sí | Red de tarjeta (por ejemplo, "Visa", "Mastercard", "Amex") |
| `payment_method.type` | string | Sí | Tipo de método de pago (por ejemplo, "débito", "crédito") |
| `payment_method.card_exp_month` | string | No | Mes de expiración de la tarjeta (por ejemplo, "12") |
| `payment_method.card_exp_year` | string | No | Año de expiración de la tarjeta (por ejemplo, "25") |
| `transaction_identifier` | string | Sí | Identificador único de transacción de Apple Pay |

## Integración de Google Pay

Para usar Google Pay, establece `payment_method` en `wallet` e incluye los datos de Google Pay en `payment_method_data`.

### Estructura del Cuerpo de Solicitud

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "google_pay": {
        "type": "CARD",
        "description": "Visa ending in 1234",
        "info": {
          "card_network": "VISA",
          "card_details": "1234"
        },
        "tokenization_data": {
          "type": "PAYMENT_GATEWAY",
          "token": "<encrypted_payment_token>"
        }
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Referencia de Campos de Google Pay

| Campo | Tipo | Requerido | Descripción |
| --- | --- | --- | --- |
| `type` | string | Sí | Tipo de método de pago (típicamente "CARD") |
| `description` | string | Sí | Descripción visible para el usuario del método de pago |
| `info.card_network` | string | Sí | Red de tarjeta (por ejemplo, "VISA", "MASTERCARD", "AMEX") |
| `info.card_details` | string | Sí | Últimos 4 dígitos de la tarjeta |
| `info.assurance_details` | object | No | Detalles de aseguramiento de autenticación |
| `tokenization_data.type` | string | Sí | Tipo de tokenización (por ejemplo, "PAYMENT_GATEWAY") |
| `tokenization_data.token` | string | Sí | Token de pago encriptado de Google Pay |
