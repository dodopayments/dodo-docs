## **Validación del ID Fiscal para Transacciones B2B**

- Si se proporciona un **ID Fiscal válido** durante el proceso de pago, la factura incluirá:
    - El **ID Fiscal del cliente**.
- Las deducciones fiscales se determinarán según las regulaciones aplicables para el país del cliente.
- La factura incluirá los **detalles fiscales de Dodo Payments**, junto con el impuesto aplicado a la transacción.

## Recopilación de un Nombre Comercial para Facturas B2B

Para compras B2B, puedes hacer que el **nombre legal de la empresa** del cliente aparezca en la factura en lugar del nombre personal del comprador. Esto se recopila junto con el ID Fiscal a través del campo `customer_business_name`.

Cuando el cliente selecciona **Comprar como empresa** al finalizar la compra, se le solicita tanto un **Nombre de Empresa** como un **Número de ID Fiscal**.

El ID de impuesto se valida en tiempo real mientras el cliente escribe. Para los estados miembros de la UE, Gran Bretaña y Australia, el proceso de pago realiza tanto la validación de formato/suma de control **como** una consulta en el registro en vivo (VIES, HMRC y ABR respectivamente) y completa automáticamente el nombre comercial legal registrado cuando se encuentra una coincidencia. Para todos los demás países, solo se realiza la validación de formato/suma de control.

El nombre de la empresa aparece en la factura solo cuando se cumplen **las tres** condiciones:

1. La transacción es B2B (`b2b = true`)
2. Se presenta un `tax_id`
3. Se suministra un `customer_business_name` no vacío

Si no se cumple alguna condición, se utiliza el nombre personal del cliente.

### Configuración en el proceso de pago

Pasar `customer_business_name` directamente, y/o habilitar `allow_customer_editing_business_name` para permitir que el cliente lo ingrese o lo edite en la página de pago junto a su ID Fiscal:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_abc', quantity: 1 }],
  customer: { email: 'buyer@acme.com' },
  tax_id: 'GB123456789',
  customer_business_name: 'Acme Corp Ltd',
  feature_flags: {
    allow_tax_id: true,
    allow_customer_editing_business_name: true // optional: let the customer edit it
  },
  return_url: 'https://yoursite.com/return'
});
```

| Superficie | Campo | Notas |
|---------|-------|-------|
| Checkout Sessions | `customer_business_name`, `feature_flags.allow_customer_editing_business_name` | Máx. 250 caracteres; el indicador tiene el valor predeterminado `false` |
| Payments | `customer_business_name` | Máx. 250 caracteres |
| Subscriptions | `customer_business_name` | Establecer o borrar mediante `PATCH /subscriptions/{subscription_id}` |

<Warning>
`customer_business_name` no se puede configurar sin un `tax_id` — la solicitud es rechazada. Borrar el `tax_id` también borra el nombre de la empresa, ya que ambos están vinculados en la factura. Los espacios en blanco circundantes se recortan, y los valores que solo contienen espacios se tratan como un borrado explícito.
</Warning>

## **Tratamiento Fiscal para Transacciones B2C**

- Las transacciones en las que **no se proporcione** un ID Fiscal válido se tratarán como **transacciones B2C**, y se deducirá el impuesto según las regulaciones fiscales aplicables en el país del cliente.
- La factura incluirá **los detalles fiscales de Dodo Payments**, junto con el impuesto aplicado a la transacción.

## Mecanismo de Inversión del Sujeto Pasivo

Generalmente, el proveedor de bienes o servicios es responsable de pagar el IVA/Impuesto sobre Servicios/GST. Sin embargo, en casos específicos como importaciones y otros suministros notificados, la responsabilidad recae en el destinatario (cliente) bajo el mecanismo de inversión del sujeto pasivo. La Inversión del Sujeto Pasivo significa que la responsabilidad de pagar el impuesto recae en el destinatario del suministro de bienes o servicios en lugar del proveedor de dichos bienes o servicios con respecto a las categorías de suministro notificadas.

## **Aplicabilidad de la Inversión del Sujeto Pasivo**

- En ciertos casos, donde lo permite la ley, el impuesto **no se deducirá** en el pago y la transacción estará sujeta **al mecanismo de inversión del sujeto pasivo**.
- La factura indicará claramente cuándo se aplica una inversión del sujeto pasivo, según los requisitos regulatorios.
