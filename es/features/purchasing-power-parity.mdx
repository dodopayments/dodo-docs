[ParityDeals](https://www.paritydeals.com/) y [Evendeals](https://www.evendeals.com/integrations/dodo-payments) son plataformas que permiten la optimización automática de precios basada en la ubicación geográfica del cliente, comúnmente conocida como precios de "paridad de poder adquisitivo" (PPP).

<Info>
Si bien no puedes incrustar directamente banners de descuento en una tienda de Dodo Payments (ya que no se admiten scripts personalizados), aún puedes implementar estas herramientas de manera efectiva en tu propio sitio web o aplicación.
</Info>

## Elegir una Integración

Ambas plataformas se integran directamente con Dodo Payments para crear y gestionar automáticamente códigos de descuento. Utiliza la comparación a continuación para elegir la herramienta que mejor se adapte a tus necesidades.

| Característica | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| Precios PPP / Basados en ubicación | Sí | Sí |
| Ofertas por festivos / Tiempo | Sí | No |
| Soporte de suscripciones | Sí | Sí |
| Actualización automática de cupones | — | Sí |
| Personalización de banners | Sí | No |
| Precios | [Ver Precios](https://www.paritydeals.com/pricing/) | [Ver Precios](https://www.evendeals.com/pricing) |

## ParityDeals

Cuando ParityDeals se integra en tu sitio web, los visitantes elegibles verán un banner que incluye un código de descuento basado en la ubicación que pueden usar en la compra. Estos códigos de descuento se crean y gestionan automáticamente por ParityDeals y aparecerán en tu **Panel de Dodo Payments** bajo **Ventas → Descuentos**.

### Configuración

<Steps>
  <Step title="Sign up on ParityDeals">
    Visita [app.paritydeals.com](https://app.paritydeals.com/) y crea una cuenta.
  </Step>

  <Step title="Create Deals">
    Después de iniciar sesión, busca la opción para crear ofertas. En el menú desplegable, selecciona **"Create Deals via Dodo Payments"**.

    <Frame>
      <img src="/images/ppp/2.png" alt="Creación de ofertas vía Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Inicia sesión en tu **panel de Dodo Payments** y navega a **Desarrolladores → Claves API**. Haz clic en **"Create New API"**.

    <Tip>
      Nombra tu clave API de manera descriptiva (por ejemplo, 'ParityDeals') para que puedas identificarla más tarde.
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="Creación de una nueva clave API en Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Copia la clave API que creaste y pégala en la interfaz de ParityDeals para establecer la conexión con tu cuenta de Dodo Payments.

    <Frame>
      <img src="/images/ppp/4.png" alt="Conectando la clave API a ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Una vez conectado, ParityDeals recuperará el catálogo de productos de Dodo Payments. Selecciona los productos que deseas asociar con tus ofertas.

    <Frame>
      <img src="/images/ppp/5.png" alt="Selección de productos para ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Ingresa la URL de tu sitio web y selecciona opcionalmente páginas específicas donde debería aparecer el banner de descuento. Luego elige tu tipo de oferta preferido:
    - Ofertas basadas en ubicación
    - Ofertas por festivos
    - Ofertas flash basadas en tiempo

    <Frame>
      <img src="/images/ppp/6.png" alt="Configuración de parámetros de la oferta" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Selecciona los países a los que deseas ofrecer descuentos localizados y define el porcentaje de descuento para cada uno. ParityDeals proporciona valores predeterminados recomendados que puedes ajustar según sea necesario.

    <Frame>
      <img src="/images/ppp/7.png" alt="Configuración de reglas de descuento por país" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Diseña tu banner de descuento personalizando el texto, seleccionando colores y diseño, y eligiendo la posición del banner (parte superior o inferior de la página). Este banner se mostrará a los visitantes elegibles según tus reglas configuradas.

    <Frame>
      <img src="/images/ppp/8.png" alt="Personalización del banner de descuento" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Después de guardar tu oferta, ParityDeals generará un script. Agrega este script al código de tu sitio web (típicamente en la sección `<head>`). Este script detecta automáticamente las ubicaciones de los visitantes y muestra el banner de descuento apropiado.

    <Frame>
      <img src="/images/ppp/9.png" alt="Script de integración de ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

## Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) es otra plataforma que se integra con Dodo Payments para ofrecer precios de paridad de poder adquisitivo basados en la ubicación. Soporta tanto productos únicos como de suscripción.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Visión general de la integración de Evendeals en Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

### Características Clave

- **Sincronización automática de cupones** — Los cupones se crean y gestionan automáticamente en Dodo Payments
- **Descuentos por porcentaje** — Ofrece descuentos por porcentaje por grupo de países
- **Soporte de suscripción** — Los descuentos se aplican a lo largo de los ciclos de facturación de suscripción
- **Reglas de actualización automática** — Rota los códigos de cupones automáticamente por intervalo de tiempo, cantidad de redenciones o cantidad de vistas para prevenir abusos

<Info>
Los códigos de descuento creados por Evendeals aparecerán automáticamente en tu panel de Dodo Payments bajo Ventas → Descuentos.
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="Características clave de Evendeals para la integración en Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

### Configuración

<Steps>
  <Step title="Create a Dodo Payments API key">
    En tu panel de Dodo Payments, dirígete a **Desarrolladores → Claves API** y genera una nueva clave.
  </Step>

  <Step title="Connect in Evendeals">
    En tu [panel de Evendeals](https://www.evendeals.com/signin), navega a **Integrations**, encuentra la tarjeta de Dodo Payments y pega tu clave API.
  </Step>

  <Step title="Configure regional discounts">
    Establece descuentos por porcentaje para cada grupo de países y presiona sincronizar. Evendeals crea cupones en Dodo Payments automáticamente.

    <Check>
    Después de sincronizar, abre **Ventas → Descuentos** en tu panel de Dodo Payments para confirmar que los cupones generados aparecen. Cada cupón tendrá un prefijo reconocible de Evendeals.
    </Check>
  </Step>
</Steps>
