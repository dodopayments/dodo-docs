El precio de la paridad de poder adquisitivo (PPP) ajusta lo que cobras para igualar el poder de compra de la ubicación de cada cliente. Hay dos formas de hacerlo en Dodo Payments.

<Info>
**Recomendado:** Usa [Precios Localizados](/features/localized-pricing) de forma nativa para establecer un precio local fijo por país, por ejemplo ₹999 en India para un producto con un base de $20. Tú controlas el número exacto, se aplica en productos de pago único, de suscripción y basados en uso, y no hay necesidad de instalar ningún banner o script.
</Info>

  <Card title="Localized Pricing" icon="earth-americas" href="/features/localized-pricing">

## Dos formas de ejecutar PPP

| | Precios Localizados (nativo) | Códigos de descuento basados en ubicación |
| :--- | :--- | :--- |
| Cómo funciona | Estableces un precio local fijo por país/moneda | Un porcentaje de descuento sobre tu precio base, aplicado a través de un código |
| Herramientas | Integrado en Dodo Payments | [ParityDeals](https://www.paritydeals.com/) / [Evendeals](https://www.evendeals.com/integrations/dodo-payments) |
| Banner / script en tu sitio web | No requerido | Requerido para mostrar el código |
| Precio que ve el cliente | La cantidad exacta que estableces | Precio base menos el descuento |
| Ideal para | Precios limpios, ajustados al mercado que controlas completamente | Banners promocionales y ofertas basadas en tiempo o festividades |

Para configuración nativa, consulta [Precios Localizados](/features/localized-pricing). El resto de esta página cubre el enfoque de códigos de descuento basados en ubicación con ParityDeals y Evendeals.

## Códigos de descuento basados en ubicación

[ParityDeals](https://www.paritydeals.com/) y [Evendeals](https://www.evendeals.com/integrations/dodo-payments) son plataformas que permiten la optimización automática de precios basada en la ubicación geográfica del cliente generando códigos de descuento.

<Info>
Aunque no puedes integrar directamente banners de descuento en una tienda de Dodo Payments (ya que no se admiten scripts personalizados), aún puedes implementar estas herramientas efectivamente en tu propio sitio web o aplicación.
</Info>

### Elegir una Integración

Ambas plataformas se integran directamente con Dodo Payments para crear y gestionar códigos de descuento automáticamente. Usa la compararación a continuación para elegir la herramienta que mejor se adapte a tus necesidades.

| Función | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| PPP / Precio basado en ubicación | Sí | Sí |
| Ofertas basadas en festividades/tiempo | Sí | No |
| Soporte de suscripción | Sí | Sí |
| Actualización automática de cupones | — | Sí |
| Personalización de banner | Sí | No |
| Precios | [Ver Precios](https://www.paritydeals.com/pricing/) | [Ver Precios](https://www.evendeals.com/pricing) |

### ParityDeals

Cuando ParityDeals se integra en tu sitio web, los visitantes elegibles verán un banner que incluye un código de descuento basado en ubicación que pueden utilizar al realizar el pago. Estos códigos de descuento son automáticamente creados y gestionados por ParityDeals y aparecerán en tu **Panel de Control de Dodo Payments** bajo **Ventas → Descuentos**.

#### Configuración

<Steps>
  <Step title="Sign up on ParityDeals">
    Visita [app.paritydeals.com](https://app.paritydeals.com/) y crea una cuenta.
  </Step>

  <Step title="Create Deals">
    Después de iniciar sesión, localiza la opción para crear ofertas. En el menú desplegable, selecciona **"Crear Ofertas a través de Dodo Payments"**.

    <Frame>
      <img src="/images/ppp/2.png" alt="Creando ofertas a través de Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Inicia sesión en tu **panel de control de Dodo Payments** y navega a **Desarrolladores → Claves API**. Haz clic en **"Crear Nueva API"**.

    <Tip>
      Nombra tu clave API de manera descriptiva (por ejemplo, 'ParityDeals') para poder identificarla después.
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="Creando una nueva clave API en Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Copia la clave API que creaste y pégala en la interfaz de ParityDeals para establecer la conexión con tu cuenta de Dodo Payments.

    <Frame>
      <img src="/images/ppp/4.png" alt="Conectando clave API a ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Una vez conectado, ParityDeals obtendrá tu catálogo de productos de Dodo Payments. Selecciona los productos que deseas asociar con tus ofertas.

    <Frame>
      <img src="/images/ppp/5.png" alt="Seleccionando productos para ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Ingresa la URL de tu sitio web y opcionalmente selecciona páginas específicas de destino donde debería aparecer el banner de descuento. Luego elige tu tipo de oferta preferido:
    - Ofertas basadas en ubicación
    - Ofertas por festividades
    - Ofertas relámpago basadas en tiempo

    <Frame>
      <img src="/images/ppp/6.png" alt="Configurando ajustes de ofertas" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Selecciona los países a los que deseas ofrecer descuentos localizados y define el porcentaje de descuento para cada uno. ParityDeals proporciona valores predeterminados recomendados que puedes ajustar según sea necesario.

    <Frame>
      <img src="/images/ppp/7.png" alt="Estableciendo reglas de descuentos por país" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Diseña tu banner de descuento personalizando el texto, seleccionando colores y diseño, y eligiendo la posición del banner (arriba o abajo de la página). Este banner se mostrará a los visitantes elegibles según tus reglas configuradas.

    <Frame>
      <img src="/images/ppp/8.png" alt="Personalizando el banner de descuento" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Después de guardar tu oferta, ParityDeals generará un script. Agrega este script al código de tu sitio web (típicamente en la sección `<head>`). Este script detecta automáticamente las ubicaciones de los visitantes y muestra el banner de descuento apropiado.

    <Frame>
      <img src="/images/ppp/9.png" alt="Script de integración de ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

#### Funciones adicionales

Con ParityDeals, también puedes ofrecer [descuentos automáticos basados en tiempo](https://www.paritydeals.com/features/time-based-discounts/) y [promociones basadas en festividades](https://www.paritydeals.com/features/holiday-based-discounts/) a lo largo del año. Para obtener más información detallada, consulta la [Documentación de ParityDeals](https://www.paritydeals.com/docs/).

### Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) es otra plataforma que se integra con Dodo Payments para ofrecer precios de paridad de poder adquisitivo basados en ubicación. Soporta tanto productos de pago único como de suscripción.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Visión general de la integración de Evendeals con Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### Funciones clave

- **Sincronización automática de cupones** — Los cupones se crean y gestionan automáticamente en Dodo Payments
- **Descuentos porcentuales** — Ofrece descuentos porcentuales por grupo de países
- **Soporte de suscripción** — Los descuentos se aplican en todos los ciclos de facturación de suscripción
- **Reglas de actualización automática** — Rota los códigos de cupones automáticamente por intervalo de tiempo, conteo de redenciones o conteo de vistas para evitar abusos

<Info>
Los códigos de descuento creados por Evendeals aparecerán automáticamente en tu panel de control de Dodo Payments bajo Ventas → Descuentos.
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="Características clave de Evendeals para la integración con Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### Configuración

<Steps>
  <Step title="Create a Dodo Payments API key">
    En tu panel de control de Dodo Payments, ve a **Desarrolladores → Claves API** y genera una nueva clave.
  </Step>

  <Step title="Connect in Evendeals">
    En tu [panel de control de Evendeals](https://www.evendeals.com/signin), navega a **Integraciones**, encuentra la tarjeta de Dodo Payments y pega tu clave API.
  </Step>

  <Step title="Configure regional discounts">
    Establece descuentos en porcentaje para cada grupo de países y haz clic en sincronizar. Evendeals crea los cupones automáticamente en Dodo Payments.

    <Check>
    Después de sincronizar, abre **Ventas → Descuentos** en tu panel de control de Dodo Payments para confirmar que los cupones generados aparecen. Cada cupón tendrá un prefijo reconocible de Evendeals.
    </Check>
  </Step>
</Steps>
