<Info>
La paridad del poder adquisitivo (PPP) cobra al cliente una proporción de tu precio de lista según el país desde el que compra. Un producto de \$20 puede venderse por **\$6.00 en India** sin un código de descuento y sin una segunda lista de precios.
</Info>

## ¿Qué es la paridad del poder adquisitivo?

El mismo precio no resulta igual de asequible en todas partes. \$20 es una compra pequeña en Estados Unidos y una grande en Filipinas. Los precios PPP corrigen esa diferencia.

Dodo Payments mantiene un porcentaje para cada país. El porcentaje es la **proporción de tu precio de lista que paga el cliente**. India tiene 30, por lo que un cliente en India paga el 30 % del precio. Estados Unidos tiene 100, así que el precio no cambia.

Activas PPP para cada precio de producto al que quieras aplicarlo. Los productos que no actives mantienen su precio normal en todas partes.

<Note>
PPP necesita [Adaptive Currency](/features/adaptive-currency). Activa primero Adaptive Currency.
</Note>

## Ventajas principales

- **Llega a mercados sensibles al precio**: vende a un precio local sin reducir tu precio habitual.
- **Sin banners ni scripts**: el precio es correcto en el checkout. No se añade nada a tu sitio web.
- **Sin códigos de descuento que gestionar**: no tienes que crear, rotar ni revocar nada.
- **Control por producto**: activa un plan inicial y deja intacto un plan empresarial.
- **Funciona en todas partes**: productos únicos, de suscripción y basados en el uso.

## Activa la paridad del poder adquisitivo

<Steps>
<Step title="Enable Adaptive Currency">
Ve a **Configuración → Empresa**. En **Configuración empresarial**, activa **Adaptive Currency**. PPP no funciona sin esta opción.

<Frame>
  <img src="/images/ppp/adaptive-currency-toggle.png" alt="Adaptive Currency y paridad del poder adquisitivo en Configuración empresarial" style={{ maxHeight: '360px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Review your country percentages">
En **Paridad del poder adquisitivo**, haz clic en **Editar** para abrir **Precios por país**. Cambia el porcentaje de cualquier país y haz clic en **Guardar cambios**.

Establece el **precio de producto de ejemplo** para ver cuánto paga cada país. La columna **Tu precio** se actualiza mientras escribes. Usa el cuadro de búsqueda para encontrar un país por nombre o código.

<Frame>
  <img src="/images/ppp/country-percentages.png" alt="Diálogo Precios por país con un porcentaje y el precio resultante para cada país" style={{ maxHeight: '620px', width: 'auto' }} />
</Frame>

<Note>
Estos porcentajes se aplican a toda la empresa. Todos los productos que tengan activada la paridad del poder adquisitivo los utilizan.
</Note>
</Step>

<Step title="Turn PPP on for a product">
Abre el producto. En la sección **Precios**, marca **Paridad del poder adquisitivo** y guarda el producto.

Los productos que no marques mantienen su precio normal en todas partes.

<Frame>
  <img src="/images/ppp/product-toggle.png" alt="Paridad del poder adquisitivo marcada en la sección Precios del producto" style={{ maxHeight: '440px', width: 'auto' }} />
</Frame>

<Warning>
No puedes marcar esta opción mientras Adaptive Currency esté desactivado. Activa primero Adaptive Currency.
</Warning>
</Step>

<Step title="Confirm at checkout">
<Check>
Abre un checkout de prueba con un país de facturación que tenga un porcentaje inferior a 100. Confirma que aparezca el precio reducido.
</Check>
</Step>
</Steps>

## Cómo se calcula el precio

El porcentaje del país multiplica tu precio de lista:

```
price paid = list price × country percentage ÷ 100
```

Un producto de \$20.00 para un cliente en India con un porcentaje de 30:

```
2000 × 30 ÷ 100 = 600   →   $6.00
```

Dodo Payments aplica el porcentaje al precio base antes de la conversión de moneda. Después, [Adaptive Currency](/features/adaptive-currency) convierte el resultado a la moneda del cliente.

<Info>
Dodo Payments obtiene el país del **país de facturación** del cliente durante el checkout.
</Info>

### Porcentajes por país

Cada país tiene un porcentaje entre **30 y 100**:

- **100** significa que el cliente paga el precio completo. No hay reducción.
- **30** es el valor mínimo que puedes establecer. Por lo tanto, la reducción máxima es del 70 %.

Los valores predeterminados proceden de los datos del índice de nivel de precios del Banco Mundial. Dodo Payments redondea cada valor al múltiplo de 5 más cercano, aplica un mínimo de 30 y establece un máximo de 100. Todos los países compatibles tienen un valor. Puedes cambiar cualquiera de ellos.

Estos son algunos de los valores predeterminados para mostrar el rango:

| País | Porcentaje | Un producto de \$20 se vende por |
| :--- | :---: | :--- |
| Estados Unidos | 100 | \$20.00 |
| Reino Unido | 85 | \$17.00 |
| Alemania | 75 | \$15.00 |
| Japón | 60 | \$12.00 |
| Brasil | 45 | \$9.00 |
| Sudáfrica | 40 | \$8.00 |
| Filipinas | 35 | \$7.00 |
| India | 30 | \$6.00 |

<Note>
La lista completa incluye 217 países. Abre la tabla de países en tu dashboard para ver todos los valores.
</Note>

## Activa la función mediante la API

PPP se activa por producto mediante el campo `purchasing_power_parity`. El valor predeterminado es `false`.

<Info>
Los porcentajes por país se gestionan únicamente en el dashboard. No forman parte de la API pública.
</Info>

<CodeGroup>

```typescript theme={null}
import DodoPayments from 'dodopayments';

const client = new DodoPayments({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: 'test_mode',
});

const product = await client.products.create({
  name: 'Starter Plan',
  tax_category: 'saas',
  price: {
    type: 'one_time_price',
    currency: 'USD',
    price: 2000,
    discount: 0,
    purchasing_power_parity: true,
  },
});
```

```python theme={null}
import os
from dodopayments import DodoPayments

client = DodoPayments(
    bearer_token=os.environ.get("DODO_PAYMENTS_API_KEY"),
    environment="test_mode",
)

product = client.products.create(
    name="Starter Plan",
    tax_category="saas",
    price={
        "type": "one_time_price",
        "currency": "USD",
        "price": 2000,
        "discount": 0,
        "purchasing_power_parity": True,
    },
)
```

```go theme={null}
package main

import (
	"context"
	"os"

	"github.com/dodopayments/dodopayments-go"
	"github.com/dodopayments/dodopayments-go/option"
)

func main() {
	client := dodopayments.NewClient(
		option.WithBearerToken(os.Getenv("DODO_PAYMENTS_API_KEY")),
	)

	_, err := client.Products.New(context.TODO(), dodopayments.ProductNewParams{
		Name:        dodopayments.F("Starter Plan"),
		TaxCategory: dodopayments.F(dodopayments.ProductNewParamsTaxCategorySaas),
		Price: dodopayments.F[dodopayments.PriceUnionParam](
			dodopayments.PriceOneTimePriceParam{
				Type:                  dodopayments.F(dodopayments.PriceOneTimePriceTypeOneTimePrice),
				Currency:              dodopayments.F(dodopayments.CurrencyUsd),
				Price:                 dodopayments.F(int64(2000)),
				Discount:              dodopayments.F(int64(0)),
				PurchasingPowerParity: dodopayments.F(true),
			},
		),
	})
	if err != nil {
		panic(err)
	}
}
```

## Comportamientos importantes

| Comportamiento | Detalle |
| :--- | :--- |
| **Necesita Adaptive Currency** | PPP no funciona mientras Adaptive Currency esté desactivado. |
| **Desactivado de forma predeterminada** | Todos los precios empiezan en `purchasing_power_parity: false`. |
| **Los precios localizados tienen prioridad** | Un producto con una regla de [precios localizados](/features/localized-pricing) coincidente nunca se ajusta mediante PPP. Se aplica exactamente el importe que establezcas. |
| **Se aplica antes de la conversión** | El porcentaje se aplica a tu precio base. Adaptive Currency convierte el resultado. |
| **Antes de los descuentos** | Un [código de descuento](/features/discount-codes) se aplica al precio reducido, por lo que ambas reducciones se combinan. |
| **Comisiones fijas solo para productos basados en el uso** | PPP se aplica a la comisión fija de un producto basado en el uso, nunca al uso medido. |
| **No disponible para Pay What You Want** | El cliente elige el importe, por lo que PPP no se aplica. Consulta [Pay What You Want](/features/pay-what-you-want). |
| **Rango de porcentajes** | El porcentaje de un país está entre 30 y 100. La reducción máxima es del 70 %. |
| **No tiene su propio webhook** | El importe reducido aparece en el pago o la suscripción como cualquier otro precio. |

## Buenas prácticas

- **Activa primero un producto.** Confirma el precio del checkout antes de activarlo para todo tu catálogo.
- **Vigila la acumulación de descuentos.** Un código de descuento se aplica sobre el precio PPP. Un país con 30 % más un código del 20 % deja el 24 % de tu precio de lista.
- **Deja fuera los planes empresariales.** Un plan negociado rara vez necesita un ajuste por país.
- **Establece tus propios valores cuando sea importante.** Los números predeterminados son un punto de partida, no una regla.
- **Comprueba el efecto en las suscripciones.** Un suscriptor que se registra con el precio reducido renueva con ese precio.
