<Info>
El derecho de Framer desbloquea un enlace de remix de plantilla de Framer para clientes que pagan. Subes la plantilla a Dodo Payments, adjuntas el derecho a un producto, y los clientes reciben un enlace de remix que les permite clonar la plantilla en su propia cuenta de Framer.
</Info>

## Lo que se entrega

- Un enlace de remix único para la plantilla de Framer que subiste.
- El cliente hace clic en el enlace para hacer remix de la plantilla en su propio espacio de trabajo de Framer.
- En caso de cancelación o reembolso, el enlace de remix se invalida.

Los usos comunes incluyen plantillas de páginas de destino de Framer de pago, kits de portafolios y bibliotecas de componentes.

## Conectar Framer

Framer se conecta implícitamente la primera vez que creas un derecho de plantilla. No hay un paso separado de OAuth.

<Steps>
<Step title="Open Entitlements">
En tu panel de Dodo Payments, ve a **Entitlements** y haz clic en **+**.
</Step>

<Step title="Pick Framer">
Elige **Framer Template** como la integración.
</Step>

<Step title="Grab the remix link from Framer">
Abre tu proyecto de Framer. Desde el menú superior izquierdo, ve a **File → Copy Remix Link**. Esto produce una URL pública de remix que permite a cualquiera clonar el proyecto en su propia cuenta de Framer — el enlace que Dodo Payments compartirá con los clientes que pagan.

</Frame>
</Step>

<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">

</Step>

<Step title="Add the template and create the entitlement">
De vuelta en el panel de Dodo Payments, elige la plantilla del menú desplegable **Template**. La primera vez que haces esto para una nueva plantilla, pega el enlace de remix que copiaste para registrarlo. Dale al derecho un **nombre** y haz clic en **Create Entitlement**.

Dodo Payments registra la plantilla y devuelve un `framer_template_id` que puedes referenciar programáticamente.
</Step>

## Flujo del cliente

1. El cliente completa el pago.
2. Dodo Payments crea un `pending` y emite un enlace de remix único vinculado a ese cliente.
3. El derecho se transiciona a `delivered` una vez que el enlace de remix se proporciona y el enlace se incluye en el correo electrónico y portal del cliente.
4. El cliente hace clic en el enlace, inicia sesión en Framer y hace remix de la plantilla.
5. En caso de revocación, el enlace de remix se invalida. Las copias ya remixadas en la cuenta de Framer del cliente permanecen, ya que Framer no ofrece forma de revocarlas.

## Configuración requerida

| Campo | Requerido | Descripción |
|---|---|---|
| `framer_template_id` | Sí | El ID de la plantilla devuelto cuando subes la plantilla. |

## Crear vía API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Portfolio Kit',
  integration_type: 'framer',
  integration_config: {
    framer_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Portfolio Kit",
    integration_type="framer",
    integration_config={"framer_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Portfolio Kit"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFramer),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFramerConfigParam{
      FramerTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

Consulta [eventos de Inline Code Webhook](/developer-resources/webhooks/intents/entitlement-grant). Los derechos de Framer llegan `pending` y se transicionan a `delivered` una vez que se proporciona el enlace de remix.

## Solución de problemas

<AccordionGroup>
<Accordion title="Customer's remix link doesn't work">
El enlace de remix es de un solo uso y está vinculado al cliente. Si lo limpiaron antes de hacer remix, revoca el derecho y vuelve a emitirlo.
</Accordion>

<Accordion title="Refunded customer still has a remixed copy">
Esto es esperado. Framer trata un remix como el proyecto propio del cliente una vez clonado; Dodo Payments invalida el enlace original pero no puede eliminar copias en la cuenta del cliente.
</Accordion>
</AccordionGroup>
