<Info>
El entitlement de Framer desbloquea un enlace de remix de una plantilla de Framer para clientes que hayan realizado un pago. Subes la plantilla a Dodo Payments, vinculas el entitlement a un producto y los clientes reciben un enlace de remix que les permite clonar la plantilla en su propia cuenta de Framer.
</Info>

## Qué se entrega

- Un enlace de remix único a la plantilla de Framer que subiste.
- El cliente hace clic en el enlace para crear un remix de la plantilla en su propio espacio de trabajo de Framer.
- Al cancelar o emitir un reembolso, el enlace de remix se invalida.

Algunos usos habituales incluyen plantillas de páginas de destino de Framer de pago, kits de portafolio y bibliotecas de componentes.

## Conectar Framer

Framer se conecta implícitamente la primera vez que creas un entitlement de plantilla. No hay ningún paso de OAuth independiente.

<Steps>
<Step title="Open Entitlements">
En tu panel de Dodo Payments, ve a **Entitlements** y haz clic en **+**.
</Step>

<Step title="Pick Framer">
Elige **Framer Template** como integración.
</Step>

<Step title="Grab the remix link from Framer">
Abre tu proyecto de Framer. En el menú superior izquierdo, ve a **File → Copy Remix Link**. Esto genera una URL de remix pública que permite a cualquiera clonar el proyecto en su propia cuenta de Framer; el enlace que Dodo Payments compartirá con los clientes que hayan realizado un pago.

<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">
<img src="/images/entitlements/framer/copy-remix-link.png" alt="Menú File de Framer con la opción Copy Remix Link resaltada" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Add the template and create the entitlement">
De vuelta en el panel de Dodo Payments, selecciona la plantilla en el menú desplegable **Template**. La primera vez que hagas esto con una plantilla nueva, pega el enlace de remix que copiaste para registrarla. Asigna un **name** al entitlement y haz clic en **Create Entitlement**.

<Frame>
<img src="/images/entitlements/framer/create.png" alt="Formulario de entitlement de plantilla de Framer con selector de plantilla y campo de nombre" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Dodo Payments registra la plantilla y devuelve un `framer_template_id` al que puedes hacer referencia mediante programación.
</Step>
</Steps>

## Flujo del cliente

1. El cliente completa el checkout.
2. Dodo Payments crea un `pending` grant y emite un enlace de remix único vinculado a ese cliente.
3. El grant pasa a `delivered` una vez aprovisionado el enlace de remix, y el enlace se incluye en el correo electrónico y el portal del cliente.
4. El cliente hace clic en el enlace, inicia sesión en Framer y crea un remix de la plantilla.
5. Al revocarlo, el enlace de remix se invalida. Las copias que ya se hayan convertido en remix en la cuenta de Framer del cliente permanecen, ya que Framer no ofrece una forma de revocarlas.

## Configuración requerida

| Campo | Obligatorio | Descripción |
|---|---|---|
| `framer_template_id` | Sí | El ID de la plantilla que se devuelve al subirla. |

## Crear mediante API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Portfolio Kit',
  integration_type: 'framer',
  integration_config: {
    framer_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Portfolio Kit",
    integration_type="framer",
    integration_config={"framer_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Portfolio Kit"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFramer),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFramerConfigParam{
      FramerTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

Consulta los [eventos de webhook de `entitlement_grant.*`](/developer-resources/webhooks/intents/entitlement-grant). Los grants de Framer llegan como `pending` y pasan a `delivered` una vez aprovisionado el enlace de remix.

## Solución de problemas

<AccordionGroup>
<Accordion title="Customer's remix link doesn't work">
El enlace de remix es de un solo uso y está vinculado al cliente. Si el cliente borró el enlace antes de crear el remix, revoca el grant y vuelve a emitirlo.
</Accordion>

<Accordion title="Refunded customer still has a remixed copy">
Esto es lo esperado. Framer trata un remix como el proyecto propio del cliente una vez clonado; Dodo Payments invalida el enlace original, pero no puede eliminar las copias de la cuenta del cliente.
</Accordion>
</AccordionGroup>
