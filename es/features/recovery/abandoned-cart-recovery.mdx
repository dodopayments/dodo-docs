<Info>
La Recuperación de Carritos Abandonados (ACR) detecta los pagos incompletos o fallidos y envía secuencias de correos electrónicos automatizados para que los clientes regresen. Combina con incentivos de descuento opcionales para maximizar las tasas de recuperación.
</Info>

## ¿Qué es la Recuperación de Carritos Abandonados?

ACR identifica automáticamente a los clientes que empezaron pero no completaron un pago — ya sea porque el pago falló o abandonaron antes de pagar — y envía una secuencia de correos de recuperación para traerlos de vuelta.

- **Pagos fallidos**: El cliente intentó pagar pero fue rechazado o hubo un error
- **Pagos incompletos**: El cliente visitó la página de pago pero nunca intentó pagar

## Cómo funciona ACR

<Steps>
<Step title="Detection">
Escaneamos pagos que tienen más de 60 minutos y no han sido exitosos. Esto incluye pagos fallidos y pagos donde el cliente nunca intentó pagar.
</Step>

<Step title="Classification">
Cada pago abandonado se clasifica por razón:
- **Pago fallido**: El cliente intentó pagar pero falló
- **Pago incompleto**: El cliente visitó el pago pero nunca intentó pagar
</Step>

<Step title="Email Sequence">
Basado en la clasificación, el sistema envía hasta 3 correos de recuperación en intervalos configurados. Cada correo contiene un enlace de recuperación único.
</Step>

<Step title="Recovery">
Cuando el cliente hace clic en el enlace de recuperación, es llevado a una página de recuperación que muestra su carrito original. Puede completar el pago con una nueva sesión de compra.
</Step>
</Steps>

## Ciclo de Vida del Estado

Cada pago abandonado progresa a través de estos estados:

| Estado | Descripción |
|--------|-------------|
| `abandoned` | Pago detectado como abandonado, aún no se han enviado correos |
| `recovering` | Se ha enviado al menos un correo de recuperación |
| `recovered` | Cliente completó el pago a través del enlace de recuperación |
| `exhausted` | Se han enviado todos los correos sin recuperación, o un pago más reciente lo superó |
| `opted_out` | Cliente se dio de baja de los correos de recuperación |

### Configuraciones Globales

| Configuración | Descripción | Predeterminado |
|---------|-------------|---------|
| **Habilitado** | Interruptor principal para ACR | Desactivado |
| **Descuento Habilitado** | Generación automática de un código de descuento para correos de recuperación | Desactivado |
| **Porcentaje de Descuento** | Porcentaje de descuento que se aplicará al pago para este cliente | 0 |
| **Días de Validez del Descuento** | Cuántos días permanece válido el código de descuento generado automáticamente | 5 |

### Secuencias de Correo

ACR soporta dos secuencias de correos — **Pago Fallido** y **Pago Incompleto** — cada una con hasta 3 correos configurables.

<Frame caption="ACR email sequence configuration">
<img src="/images/recovery/acr-email-config.png" alt="Editor de secuencia de correos mostrando asunto, cuerpo, momento, e interruptor de habilitación para cada correo en la secuencia" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

| Configuración | Descripción |
|---------|-------------|
| **Habilitado** | Activar o desactivar correos individuales sin eliminarlos |
| **Retraso** | Cuánto tiempo después de detectar el abandono se envía este correo |
| **Asunto** | Línea de asunto del correo electrónico con marcadores de posición variables |
| **Cuerpo** | Cuerpo del correo HTML con marcadores de posición variables |
| **Responder a** | Dirección de correo electrónico para respuestas de clientes |

**Tiempo de correo predeterminado:**

| Correo # | Retraso Predeterminado |
|---------|---------------|
| 1 | 1 hora |
| 2 | 24 horas |
| 3 | 72 horas |

## Descuentos de Recuperación

Cuando el descuento está habilitado, ACR genera automáticamente un código de descuento único de un solo uso para cada pago abandonado. El descuento:

- Está restringido a los productos del pago original
- Tiene un periodo de expiración configurable
- Está limitado a una sola redención
- Está oculto de la lista de descuentos de tu panel (uso interno únicamente)

<Tip>
Comienza con un descuento modesto (5-10%) para probar el impacto de conversión antes de incrementarlo. Incluso un pequeño incentivo puede mejorar significativamente las tasas de recuperación.
</Tip>

## Experiencia de Recuperación del Cliente

Cuando un cliente hace clic en el enlace de recuperación en un correo, vuelve a su sesión de pago original. La página muestra el producto que dejó atrás, junto con un código de descuento si se ha configurado.

## Casos de Borde

| Escenario | Comportamiento |
|----------|----------|
| Cliente completa la compra antes del próximo correo | La recuperación se detecta en el momento del envío; el pago se marca como recuperado si es elegible |
| Cliente comienza un nuevo pago | El antiguo pago abandonado se marca como `exhausted` |
| Cliente hace clic en "Pagar" después de haber recuperado | La página de recuperación muestra una confirmación de que el pago ya se completó |
| Cliente se da de baja | Pago abandonado se marca como `opted_out`; no se envían más correos |

## Mejores Prácticas

- **Comienza con los predeterminados**: El tiempo y los asuntos de correo predeterminados están optimizados para patrones comunes de recuperación. Personaliza después de tener datos de referencia.
- **Personaliza los correos**: Usa variables de plantilla para hacer que los correos se sientan personales y relevantes para el cliente.
- **Monitorea las analíticas**: Realiza un seguimiento de las tasas de recuperación por correo para identificar qué mensajes impulsan más conversiones. Desactiva los correos con bajo rendimiento.
- **Usa descuentos estratégicamente**: Comienza con poco (5-10%) para proteger los márgenes mientras pruebas el impacto de conversión.
- **Mantén los correos breves**: Los correos de recuperación deben ser breves y orientados a la acción. Un llamado a la acción claro ofrece mejores resultados que explicaciones largas.

<Info>
ACR está diseñado para funcionar automáticamente una vez habilitado. Comienza con la configuración predeterminada, monitorea tus analíticas y ajusta según los datos de rendimiento.
</Info>
