<Info>
Use este endpoint solo para concesiones creadas bajo una concesión de Clave de Licencia con `fulfillment_mode: manual`. La concesión debe estar en el estado `pending` sin ninguna clave adjunta. Vea [Cumplimiento Manual](/features/license-keys#manual-fulfillment) y la [Guía de Integración de Cumplimiento Manual de Clave de Licencia](/developer-resources/manual-license-key-fulfillment) para el flujo completo.
</Info>
