<Info>
Usa este endpoint únicamente para grants creados bajo un entitlement de License Key con `fulfillment_mode: manual`. El grant debe estar en estado `Pending` sin ninguna key asociada. Consulta [Cumplimiento manual](/features/license-keys#manual-fulfillment) y la [Guía de integración para el cumplimiento manual de License Key](/developer-resources/manual-license-key-fulfillment) para conocer el flujo completo.
</Info>
