title: Revocar Concesión
description: Revocar manualmente una concesión. El acceso a la plataforma del
  cliente se elimina (para integraciones OAuth/bot) y las claves de licencia se
  desactivan. Las revocaciones manuales usan revocation_reason "manual" y no se
  conceden automáticamente al renovar la suscripción.
keywords:

  - Referencia API
  - REST API
  - revocar concesión
