## Gestión de Claves API y Autenticación

<Steps>
<Step title="Acceder a las Claves API">
Navega a **Desarrollador → Claves API** en tu panel para gestionar tus claves.
</Step>

<Step title="Generar una Nueva Clave">
Selecciona **Agregar Clave API**, proporciona un nombre descriptivo y configura el acceso de escritura:

- **Habilitar acceso de escritura** (marcado): Permisos de lectura y escritura completos para todas las operaciones de la API
- **Habilitar acceso de escritura** (desmarcado): Acceso solo de lectura - solo se puede obtener datos (pagos, suscripciones, clientes, productos). No se pueden crear ni modificar recursos.

<Tip>
Desmarca "Habilitar acceso de escritura" para integraciones de panel, herramientas de análisis y cualquier sistema que solo necesite ver datos sin realizar cambios.
</Tip>
</Step>

<Step title="Almacena Tu Clave de Forma Segura">
Copia la clave generada de inmediato y asegúrate de que se almacene de forma segura.
</Step>

<Step title="Autentica Tus Solicitudes API">
Utiliza tus claves API para autenticar todas las solicitudes. Aplica el siguiente formato de autorización:

```bash 
Authorization: Bearer YOUR_API_KEY
```

<Warning>
Nunca expongas tus claves API secretas en código del lado del cliente o en repositorios públicos.
</Warning>
</Step>
</Steps>

## Límites de Tasa

Nuestra API utiliza un sistema de limitación de tasa de doble ventana con protección contra ráfagas. Los límites se aplican según su método de autenticación y nivel empresarial.

### Límites predeterminados (Nivel 0)

| Ventana | Límite |
|--------|-------|
| Por segundo (Ráfaga) | 40 solicitudes |
| Por minuto (Sostenido) | 240 solicitudes |

### Niveles de negocio

Se encuentran disponibles límites de tasa más altos para empresas con mayores necesidades de API:

| Nivel | Ráfaga (por segundo) | Sostenido (por minuto) |
|------|-------------------|------------------------|
| Nivel 0 (Predeterminado) | 40 | 240 |
| Nivel 1 | 100 | 1,000 |
| Nivel 2 | 500 | 5,000 |

<Tip>
Contacte al soporte para actualizar su negocio a un nivel de límite de tasa más alto.
</Tip>

### Solicitudes no autenticadas

Las solicitudes sin encabezados de autenticación válidos tienen un límite de tasa por dirección IP:

| Ventana | Límite |
|--------|-------|
| Por segundo (Ráfaga) | 20 solicitudes |
| Por minuto (Sostenido) | 100 solicitudes |

### Encabezados de límite de tasa

Monitoree su uso con estos encabezados de respuesta:

- `X-RateLimit-Limit` - Máximo de solicitudes permitidas
- `X-RateLimit-Remaining` - Solicitudes restantes en la ventana actual
- `X-RateLimit-Reset` - Tiempo cuando se restablece el límite de tasa

<Note>
Cuando supere los límites de tasa, la API devuelve una respuesta `429 Too Many Requests`. Implemente retroceso exponencial en su lógica de reintentos.
</Note>
