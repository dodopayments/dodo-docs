## Administración y autenticación de API keys

<Steps>
<Step title="Access API Keys">
Ve a **Developer → API Keys** en tu dashboard para administrar tus claves.
</Step>

<Step title="Generate a New Key">
Selecciona **Add API Key**, proporciona un nombre descriptivo y configura el acceso de escritura:

- **Enable write access** (seleccionado): permisos completos de lectura y escritura para todas las operaciones de la API
- **Enable write access** (no seleccionado): acceso de solo lectura; solo permite obtener datos (pagos, suscripciones, clientes y productos). No permite crear ni modificar recursos.

<Tip>
Desmarca "Enable write access" para integraciones con el dashboard, herramientas de análisis y cualquier sistema que solo necesite consultar datos sin realizar cambios.
</Tip>
</Step>

<Step title="Store Your Key Securely">
Copia inmediatamente la clave generada y asegúrate de almacenarla de forma segura.
</Step>

<Step title="Authenticate Your API Requests">
Usa tus API keys para autenticar todas las solicitudes. Aplica el siguiente formato de autorización:

```bash 
Authorization: Bearer YOUR_API_KEY
```

<Warning>
Nunca expongas tus API keys secretas en código del lado del cliente ni en repositorios públicos.
</Warning>
</Step>
</Steps>

## Límites de solicitudes

Nuestra API utiliza un sistema de limitación de solicitudes de doble ventana con protección contra picos. Los límites se aplican según tu método de autenticación y el nivel de tu empresa.

### Límites predeterminados (nivel 0)

| Ventana | Límite |
|--------|-------|
| Por segundo (picos) | 40 solicitudes |
| Por minuto (sostenido) | 240 solicitudes |

### Niveles empresariales

Hay límites de solicitudes más altos disponibles para empresas con mayores necesidades de API:

| Nivel | Picos (por segundo) | Sostenido (por minuto) |
|------|-------------------|------------------------|
| Nivel 0 (predeterminado) | 40 | 240 |
| Nivel 1 | 100 | 1.000 |
| Nivel 2 | 500 | 5.000 |

<Tip>
Contacta con soporte para actualizar tu empresa a un nivel superior de límite de solicitudes.
</Tip>

### Solicitudes no autenticadas

Las solicitudes sin encabezados de autenticación válidos tienen un límite basado en la dirección IP:

| Ventana | Límite |
|--------|-------|
| Por segundo (picos) | 20 solicitudes |
| Por minuto (sostenido) | 100 solicitudes |

### Encabezados de límite de solicitudes

Supervisa tu uso con estos encabezados de respuesta:

- `X-RateLimit-Limit` - Máximo de solicitudes permitidas
- `X-RateLimit-Remaining` - Solicitudes restantes en la ventana actual
- `X-RateLimit-Reset` - Momento en que se restablece el límite de solicitudes

<Note>
Cuando superes los límites de solicitudes, la API devuelve una respuesta `429 Too Many Requests`. Implementa un retroceso exponencial en tu lógica de reintento.
</Note>
