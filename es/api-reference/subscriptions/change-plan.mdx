## Manejo de fallas de pago

Utiliza el parámetro `on_payment_failure` para controlar lo que ocurre cuando el pago del cambio de plan falla:

| Valor | Comportamiento |
|-------|----------------|
| `prevent_change` | Mantener la suscripción en el plan actual hasta que el pago tenga éxito. El cambio de plan permanece pendiente. |
| `apply_change` | Aplicar el cambio de plan de inmediato independientemente del resultado del pago. Esta es la opción predeterminada. |

<Info>
Si `on_payment_failure` no se especifica, el comportamiento predeterminado es la configuración a nivel de negocio que hayas configurado en el panel.
</Info>

## Códigos de Descuento

Puedes aplicar un código de descuento al cambiar de plan pasando el parámetro `discount_code`.

| Escenario | Comportamiento |
|----------|----------------|
| `discount_code` proporcionado | Valida y aplica el descuento al nuevo plan. |
| `discount_code` no proporcionado, descuento existente con `preserve_on_plan_change=true` | El descuento existente se conserva si es aplicable al nuevo producto. |
| `discount_code` no proporcionado, ningún descuento conservable | No se aplica descuento. |

<Tip>
Usa códigos de descuento durante los cambios de plan para ofrecer precios promocionales en actualizaciones, o pasa un código al migrar clientes a un nuevo nivel de plan.
</Tip>

<Tip>
Usa `prevent_change` para actualizaciones críticas donde quieres asegurar el pago antes de conceder acceso a características premium.
</Tip>
