## Manejo de Fallos en el Pago

Utilice el parámetro `on_payment_failure` para controlar qué sucede cuando falla el pago del cambio de plan:

| Valor | Comportamiento |
|-------|---------------|
| `prevent_change` | Mantener la suscripción en el plan actual hasta que el pago tenga éxito. El cambio de plan queda pendiente. |
| `apply_change` | Aplicar el cambio de plan de inmediato, independientemente del resultado del pago. Este es el comportamiento por defecto. |

<Info>
Si no se especifica `on_payment_failure`, el comportamiento predeterminado se ajusta a la configuración a nivel de negocio configurada en el panel de control.
</Info>

<Tip>
Utilice `prevent_change` para actualizaciones críticas donde desee asegurar el pago antes de conceder acceso a funciones premium.
</Tip>
