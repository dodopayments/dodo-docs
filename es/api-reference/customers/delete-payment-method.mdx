Elimina un método de pago guardado de la cuenta de un cliente. Usa esto para limpiar métodos de pago obsoletos o no deseados.

<Warning>
Si el método de pago eliminado es el único registrado para una suscripción activa, la suscripción puede no renovarse en el siguiente ciclo de facturación. Asegúrate de que el cliente tenga un método de pago alternativo antes de eliminarlo.
</Warning>

## Casos de Uso

- **Solicitud del cliente**: Eliminar un método de pago que el cliente ya no desea tener registrado
- **Tarjetas vencidas**: Limpiar métodos de pago con detalles de tarjetas vencidas
- **Seguridad**: Eliminar inmediatamente los métodos de pago comprometidos
