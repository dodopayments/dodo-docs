Elimina un método de pago guardado de la cuenta de un cliente. Usa esto para limpiar métodos de pago obsoletos o no deseados.

<Warning>
No puedes eliminar un método de pago que está en uso por una suscripción activa. La API devuelve `409 Conflict` con `Payment method is in use by an active subscription`. Primero, mueve la suscripción a otro método de pago mediante [Actualizar método de pago](/api-reference/subscriptions/update-payment-method) y, después, elimina el anterior.
</Warning>

Una eliminación correcta devuelve `204 No Content`.

## Casos de uso

- **Solicitud del cliente**: Elimina un método de pago que el cliente ya no quiere conservar
- **Tarjetas caducadas**: Limpia los métodos de pago con datos de tarjetas caducados
- **Seguridad**: Elimina inmediatamente los métodos de pago comprometidos
