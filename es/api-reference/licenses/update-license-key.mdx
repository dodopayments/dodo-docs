<Warning>
**API Obsoleto**: Las claves de licencia ahora se gestionan a través del sistema de [Derechos](/features/entitlements/introduction). Configure los límites de activación y duraciones en el [Derecho de clave de licencia](/api-reference/entitlements/update-entitlement), y utilice [Revocar concesión](/api-reference/entitlements/revoke-grant) para deshabilitar la clave de un cliente. Este endpoint se eliminará en una futura versión.
</Warning>

<Info>
Actualizar una clave de licencia a través del API no desencadena notificaciones por correo electrónico al cliente.
</Info>
