  cadena de la clave, el cliente y el producto son obligatorios.
keywords:
  - Dodo Payments
  - Referencia de API
  - REST API
  - crear clave de licencia
  - importar clave de licencia
openapi: post /license_keys
---

<Info>
Este endpoint importa una clave que ya tienes — `key`, `customer_id` y `product_id` son obligatorios. No genera un valor de clave por ti. Importar un `key` que ya existe devuelve `409 Conflict`.
</Info>

<Info>
Las claves de licencia creadas o actualizadas mediante la API no activan notificaciones por correo electrónico para los clientes. Si necesitas notificar a los clientes sobre su clave de licencia, debes gestionarlo por separado en tu aplicación.
</Info>
