<Warning>
**API Obsoleto**: Las claves de licencia ahora se administran a través del sistema de [Derechos](/features/entitlements/introduction). Utiliza [Lista de Concesiones](/api-reference/entitlements/list-grants) para listar las claves de licencia emitidas (filtrar con `integration_type=license_key`); cada concesión lleva sus detalles de `license_key`. Este endpoint se eliminará en una versión futura.
</Warning>
