<Warning>
**API obsoleta**: Las claves de licencia ahora se gestionan a través del sistema de [Derechos](/features/entitlements/introduction). Utiliza [List Customer Grants](/api-reference/entitlements/list-customer-grants) para listar las claves de licencia emitidas (filtrando con `integration_type=license_key`); cada concesión lleva sus detalles `license_key`. Este endpoint se eliminará en una versión futura.
</Warning>
