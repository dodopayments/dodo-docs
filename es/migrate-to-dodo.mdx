**¿Cambiando de otro proveedor de pagos a Dodo Payments?** Nuestra herramienta de migración facilita mover tus **productos, clientes, códigos de descuento y claves de licencia sin perder ningún dato.** El proceso es seguro, guiado, y puede hacerse en solo unos minutos.

Actualmente, soportamos migraciones desde **Lemon Squeezy, Stripe, Polar.sh y Paddle**.

## Comenzar

Primero, instala la herramienta de migración:

```bash
npm install -g dodo-migrate
```

<Note>
Necesitarás tener Node.js ≥ 18 instalado en tu computadora.
</Note>

## Migra Tus Datos

### Si vienes de Lemon Squeezy:

```bash
dodo-migrate lemonsqueezy
```

### Si vienes de Stripe:

```bash
dodo-migrate stripe
```

### Si vienes de Polar.sh:

```bash
dodo-migrate polar
```

### Si vienes de Paddle:

```bash
dodo-migrate paddle
```

La herramienta te guiará paso a paso en todo. Necesitarás:
- La clave API de tu proveedor (Lemon Squeezy, Stripe, Polar.sh, Paddle, etc.)
- Tu clave API de Dodo Payments
- Si deseas probar primero (recomendado) o entrar en vivo
- A qué marca de Dodo Payments deseas migrar
- Qué datos migrar (productos, clientes, descuentos, claves de licencia)

## ¿Por Qué Usar Nuestra Herramienta de Migración?

- **Sin pérdida de datos** - Todo se transfiere de forma segura
- **Prueba primero** - Pruébalo en modo de prueba antes de ir en vivo
- **Proceso guiado** - Te guiamos a través de cada paso
- **Reanudar si es necesario** - Si algo sale mal, puedes continuar desde donde lo dejaste

## Uso Avanzado

Si prefieres ejecutar la migración sin indicaciones, puedes proporcionar todos los detalles de antemano:

### Migración de Lemon Squeezy:

```bash
dodo-migrate lemonsqueezy \
  --provider-api-key=lsq_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX
```

### Migración de Stripe:

```bash
dodo-migrate stripe \
  --provider-api-key=sk_test_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX \
  --migrate-types=products,coupons
```

### Migración de Polar.sh:

```bash
dodo-migrate polar \
  --provider-api-key=polar_org_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX \
  --migrate-types=products,discounts,customers,license_keys
```

## Migración de Clave de Licencia

La migración de claves de licencia es compatible con **Polar.sh** y **Lemon Squeezy**. Cuando seleccionas claves de licencia en el aviso interactivo (o pasas `license_keys` en `--migrate-types`), la herramienta importará tus claves de licencia existentes a Dodo Payments con las asociaciones correctas de clientes y productos.

{/* LOCKED_PATTERN_4907e9f6f7fbd509120d7a87afc829e9 */}
La migración de claves de licencia requiere que se migren **productos y clientes** en la misma sesión. La herramienta construye un mapa en memoria de IDs de proveedor a IDs de Dodo durante la ejecución — si faltan productos o clientes, las claves de licencia no pueden enlazarse correctamente.
{/* LOCKED_PATTERN_176d815432e7554ac558e8631b2bc397 */}

### Qué se migra

- Cadenas de claves de licencia
- Límites de activación
- Fechas de expiración
- Asociaciones de clientes y productos

### Qué no se migra

- **Activaciones de claves de licencia** — los clientes necesitarán reactivar en sus dispositivos después de la migración
- **Claves revocadas o deshabilitadas** — solo se migran las claves activas
- Claves sin un producto o cliente correspondiente se omiten con una advertencia

{/* LOCKED_PATTERN_317ec56569e36d0c9e56c2648890a76e */}
Las claves de licencia duplicadas se manejan de manera adecuada. Si vuelves a ejecutar la migración, las claves ya importadas se detectarán y omitirán, haciendo el proceso seguro para reintentar.
{/* LOCKED_PATTERN_4dec52ce04aa8849a8a60508baae30ae */}
