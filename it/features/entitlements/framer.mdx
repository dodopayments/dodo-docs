<Info>
Il diritto di Framer sblocca un link remix del modello Framer per i clienti paganti. Carichi il modello su Dodo Payments, alleghi il diritto a un prodotto e i clienti ricevono un link remix che consente loro di clonare il modello nel proprio account Framer.
</Info>

## Cosa viene consegnato

- Un link remix unico al modello Framer che hai caricato.
- Il cliente clicca sul link per remixare il modello nel proprio workspace di Framer.
- In caso di cancellazione o rimborso, il link remix viene invalidato.

Gli usi comuni includono modelli a pagamento di landing-page Framer, kit di portfolio e librerie di componenti.

## Connetti Framer

Framer è connesso implicitamente la prima volta che crei un diritto di modello. Non c'è un passaggio OAuth separato.

<Steps>
<Step title="Open Entitlements">
Nel tuo pannello di controllo di Dodo Payments, vai a **Diritti** e clicca su **+**.
</Step>

<Step title="Pick Framer">
Scegli **Framer Template** come integrazione.
</Step>

<Step title="Grab the remix link from Framer">
Apri il tuo progetto Framer. Dal menu in alto a sinistra, vai su **File → Copia Link Remix**. Questo produce un URL di remix pubblico che consente a chiunque di clonare il progetto nel proprio account Framer — il link che Dodo Payments condividerà con i clienti paganti.
</Step>

<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">
<img src="/images/entitlements/framer/copy-remix-link.png" alt="Menu File di Framer con l'opzione Copia Link Remix evidenziata" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Add the template and create the entitlement">
Tornando al pannello di controllo di Dodo Payments, seleziona il modello dal menu a tendina **Template**. La prima volta che lo fai per un nuovo modello, incolla il link remix copiato per registrarlo. Dai al diritto un **nome** e clicca su **Crea Diritto**.
<Frame>
<img src="/images/entitlements/framer/create.png" alt="Modulo di diritto del modello Framer con selezione del modello e campo nome" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Dodo Payments registra il modello e restituisce un `framer_template_id` che puoi riferire programmaticamente.
</Step>

## Flusso del cliente

1. Il cliente completa il checkout.
2. Dodo Payments crea un `pending` grant e rilascia un link remix unico collegato a quel cliente.
3. Il grant passa a `delivered` una volta che il link remix è stato fornito e il link è incluso nell'email e nel portale del cliente.
4. Il cliente clicca sul link, accede a Framer e remix il modello.
5. In caso di revoca, il link remix viene invalidato. Le copie già remixate nell'account Framer del cliente rimangono, poiché Framer non espone un modo per revocarle.

## Configurazione richiesta

| Campo | Richiesto | Descrizione |
|---|---|---|
| `framer_template_id` | Sì | L'ID del modello restituito quando carichi il modello. |

## Creare tramite API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Portfolio Kit',
  integration_type: 'framer',
  integration_config: {
    framer_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Portfolio Kit",
    integration_type="framer",
    integration_config={"framer_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Portfolio Kit"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFramer),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFramerConfigParam{
      FramerTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Risoluzione dei problemi

<AccordionGroup>
<Accordion title="Customer's remix link doesn't work">
Il link remix è monouso e legato al cliente. Se lo hanno cancellato prima del remix, revoca il grant e riemettilo.
</Accordion>

<Accordion title="Refunded customer still has a remixed copy">
Questo è previsto. Framer tratta un remix come progetto del cliente una volta clonato; Dodo Payments invalida il link originale ma non può eliminare le copie nell'account del cliente.
</Accordion>
</AccordionGroup>

<Accordion title="Refunded customer still has a remixed copy">
This is expected. Framer treats a remix as the customer's own project once it's cloned; Dodo Payments invalidates the original link but cannot delete copies in the customer's account.
</Accordion>
</AccordionGroup>
