<Info>
L'entitlement Framer sblocca un link remix di un template Framer per i clienti paganti. Carichi il template su Dodo Payments, colleghi l'entitlement a un prodotto e i clienti ricevono un link remix che consente loro di clonare il template nel proprio account Framer.
</Info>

## Cosa viene fornito

- Un link remix univoco al template Framer che hai caricato.
- Il cliente fa clic sul link per eseguire il remix del template nel proprio workspace Framer.
- In caso di annullamento o rimborso, il link remix viene invalidato.

Gli utilizzi comuni includono template per landing page Framer a pagamento, kit per portfolio e librerie di componenti.

## Collega Framer

Framer viene collegato implicitamente la prima volta che crei un entitlement per un template. Non è necessario alcun passaggio OAuth separato.

<Steps>
<Step title="Open Entitlements">
Nel tuo dashboard Dodo Payments, vai su **Entitlements** e fai clic su **+**.
</Step>

<Step title="Pick Framer">
Scegli **Framer Template** come integrazione.
</Step>

<Step title="Grab the remix link from Framer">
Apri il tuo progetto Framer. Dal menu in alto a sinistra, vai su **File → Copy Remix Link**. Viene così generato un URL remix pubblico che consente a chiunque di clonare il progetto nel proprio account Framer: il link Dodo Payments condividerà con i clienti paganti.

<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">
<img src="/images/entitlements/framer/copy-remix-link.png" alt="Menu File di Framer con l'opzione Copy Remix Link evidenziata" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Add the template and create the entitlement">
Tornato nel dashboard Dodo Payments, seleziona il template dal menu a discesa **Template**. La prima volta che esegui questa operazione per un nuovo template, incolla il link remix che hai copiato per registrarlo. Assegna un **nome** all'entitlement e fai clic su **Create Entitlement**.

<Frame>
<img src="/images/entitlements/framer/create.png" alt="Modulo di entitlement per template Framer con selettore del template e campo del nome" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Dodo Payments registra il template e restituisce un `framer_template_id` che puoi utilizzare a livello programmatico.
</Step>
</Steps>

## Flusso del cliente

1. Il cliente completa il checkout.
2. Dodo Payments crea un grant `Pending` e genera un link di remix univoco associato a quel cliente.
3. Il grant passa a `Delivered` una volta effettuato il provisioning del link di remix, che viene incluso nell'email e nel portale del cliente.
4. Il cliente fa clic sul link, accede a Framer e crea un remix del template.
5. In caso di revoca, il link di remix viene invalidato. Le copie già sottoposte a remix nell'account Framer del cliente rimangono disponibili, poiché Framer non offre un modo per revocarle.

## Configurazione richiesta

| Campo | Obbligatorio | Descrizione |
|---|---|---|
| `framer_template_id` | Sì | L'ID del template restituito quando carichi il template. |

## Crea tramite API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Portfolio Kit',
  integration_type: 'framer',
  integration_config: {
    framer_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Portfolio Kit",
    integration_type="framer",
    integration_config={"framer_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Portfolio Kit"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFramer),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFramerConfigParam{
      FramerTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhook

Consulta gli [eventi webhook `entitlement_grant.*`](/developer-resources/webhooks/intents/entitlement-grant). I grant di Framer arrivano nello stato `Pending` e passano a `Delivered` una volta effettuato il provisioning del link di remix.

## Risoluzione dei problemi

<AccordionGroup>
<Accordion title="Customer's remix link doesn't work">
Il link remix è monouso e associato al cliente. Se il cliente ha cancellato il link prima di eseguire il remix, revoca il grant e rilascialo.
</Accordion>

<Accordion title="Refunded customer still has a remixed copy">
È un comportamento previsto. Framer considera il remix come un progetto del cliente una volta clonato; Dodo Payments invalida il link originale, ma non può eliminare le copie dall'account del cliente.
</Accordion>
</AccordionGroup>
