<Info>
L'accesso a Telegram offre ai clienti paganti l'accesso a una chat o canale privato. Il bot Telegram di Dodo Payments genera un link di invito unico per ciascun cliente e li rimuove in caso di cancellazione.
</Info>

## Cosa viene fornito

- Il grant viene creato in `pending` mentre il bot prepara l'invito, e poi passa a `delivered` una volta pronto il link.
- Il cliente riceve un link di invito unico per Telegram nella sua email di consegna e nel portale clienti.
- Tocca il link e il bot lo aggiunge alla chat configurata.
- In caso di cancellazione, rimborso o revoca manuale, il bot lo rimuove dalla chat.

Usi comuni includono canali alfa privati, gruppi di segnali a pagamento e vantaggi per livelli di comunità.

## Collegare Telegram

<Steps>
<Step title="Open Entitlements">
Nel tuo dashboard di Dodo Payments, vai su **Accessi** e clicca **+**, quindi scegli **Accesso Telegram** come integrazione. Il dashboard richiede il tuo user ID Telegram in modo che il bot possa verificare la proprietà delle chat che gestisce.

<Frame caption="New Entitlement → Telegram Access. The dashboard needs your Telegram user ID before it lists chats.">
<img src="/images/entitlements/telegram/connect-prompt.png" alt="Nuovo modulo di accesso Telegram con richiesta di user ID Telegram e pulsante Connect Telegram" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Tip>
I prossimi due passaggi sono attività di configurazione su Telegram e possono essere completati in qualsiasi ordine — ottieni il tuo user ID e aggiungi il bot alla tua chat come amministratore. Una volta fatto, torna al dashboard per l'ultimo passaggio.
</Tip>
</Step>

<Step title="Get your Telegram user ID">
Su Telegram, invia un messaggio a **`/start`**:


- **`@dodo_payments_bot`** se stai usando **Modalità Live**
- **`@DodoPaymentsTestBot`** se stai usando **Modalità Test**

Il bot risponde con il tuo user ID numerico di Telegram. Copialo — lo inserirai nel dashboard nell'ultimo passaggio.
</Step>

<Step title="Add the bot to your chat as an admin">
Nella chat o canale Telegram che vuoi proteggere, apri l'elenco dei membri e **aggiungi lo stesso bot come amministratore** (`@dodo_payments_bot` per live, `@DodoPaymentsTestBot` per test) con questi due permessi abilitati:

- **Ban Users** — necessario per rimuovere i membri in caso di revoca
- **Add Users** — necessario per invitare i clienti paganti

Disattiva tutti gli altri permessi di amministrazione.

<Frame caption="Telegram → Promote to admin. Only Ban Users and Add Users need to be enabled.">
<img src="/images/entitlements/telegram/promote-bot-admin.png" alt="Schermata di promozione a amministratore in Telegram che mostra Ban Users e Add Users abilitati per il bot di Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Connect Telegram and pick the chat">
Torna al dashboard, inserisci lo user ID dal passaggio 2 in **Telegram User ID** e clicca **Connect Telegram**. L'elenco delle chat ora mostra ogni gruppo e canale dove il bot è un amministratore — scegli quello che vuoi proteggere, dai un nome al grant e clicca **Create Entitlement**.
</Step>
</Steps>

## Flusso del cliente

1. Il cliente completa il checkout.
2. Dodo Payments crea un grant `pending` e chiede al bot di generare un link di invito unico alla chat configurata.
3. Una volta pronto il link, il grant passa a `delivered` e il link è incluso nell'email di consegna e nel portale clienti.
4. Il cliente tocca il link ed è aggiunto alla chat.
5. In caso di revoca, il bot rimuove il cliente dalla chat.

<Tip>
Il link di invito è monouso e scade dopo che il cliente si unisce. Se perde il link prima di unirsi, rigeneralo inviando nuovamente l'email di consegna o revocando e ricreando il grant dal dashboard.
</Tip>

## Configurazione richiesta

| Campo | Richiesto | Descrizione |
|---|---|---|
| `chat_id` | Sì | L'ID della chat Telegram (numerico, spesso negativo per gruppi/canali). Il selettore del dashboard lo compila per te. |

## Creare via API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Premium Signals Group',
  integration_type: 'telegram',
  integration_config: {
    chat_id: '-1001234567890',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Premium Signals Group",
    integration_type="telegram",
    integration_config={"chat_id": "-1001234567890"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Premium Signals Group"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeTelegram),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigTelegramConfigParam{
      ChatID: dodopayments.F("-1001234567890"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

Vedi [eventi webhook `entitlement_grant.*`](/developer-resources/webhooks/intents/entitlement-grant). I grant di Telegram arrivano `pending` e passano a `delivered` una volta che il bot ha emesso il link di invito.

## Risoluzione dei problemi

<AccordionGroup>
<Accordion title="Chat doesn't appear in the picker">
Il bot di Dodo Payments deve essere aggiunto alla chat **come amministratore** con **Add Users** abilitato. Il selettore legge lo stato live, quindi la chat appare non appena il bot è un amministratore.
</Accordion>

<Accordion title="Customer says the invite link doesn't work">
I link unici di Telegram scadono dopo il primo utilizzo. Se il cliente lo ha toccato su un dispositivo scollegato o ha perso il link, revoca il grant e riesegui il procedura.
</Accordion>

<Accordion title="Customer cancelled but is still in the chat">
Il bot ha bisogno del permesso di amministratore **Ban Users** per rimuovere i membri. Apri le impostazioni della chat e conferma che sia **Ban Users** che **Add Users** siano attivati sul bot di Dodo Payments.
</Accordion>
</AccordionGroup>
