<Info>
L'entitlement di Notion duplica un modello che hai preparato nello spazio di lavoro del cliente pagante. Il cliente autorizza tramite OAuth, sceglie lo spazio di lavoro in cui vuole copiare il modello, e Dodo Payments gestisce la duplicazione.
</Info>

## Cosa viene consegnato

- Al cliente viene richiesto di collegare il proprio workspace Notion tramite OAuth.
- Una volta autorizzato, Dodo Payments duplica il template configurato nel workspace scelto dal cliente.
- In caso di annullamento, il template duplicato rimane nel workspace del cliente (Notion non supporta l'eliminazione remota). La concessione viene contrassegnata come `Revoked` per la conservazione dei dati.

Gli usi comuni includono modelli Notion a pagamento, sistemi di produttività e modelli OS/CRM.

## Flusso del cliente

1. Il cliente completa il checkout.
2. Dodo Payments crea una concessione con stato `Pending` e un `oauth_url` Notion che consente al cliente di collegare il proprio workspace.
3. Il cliente autorizza tramite il link nell'email o nel customer portal e sceglie il workspace in cui desidera duplicare il template.
4. Dodo Payments duplica il template. La concessione passa a `Delivered`.
5. In caso di revoca, la concessione viene contrassegnata come `Revoked`; la copia duplicata rimane nel workspace del cliente.

<Note>
Notion considera intenzionalmente una pagina duplicata come contenuto del destinatario. Dodo Payments non può eliminare la copia in caso di revoca.
</Note>

## Configurazione necessaria

| Campo | Richiesto | Descrizione |
|---|---|---|
| `notion_template_id` | Sì | L'ID del modello. Il selezionatore del dashboard lo compila. |

## Creazione tramite API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Study Notes',
  integration_type: 'notion',
  integration_config: {
    notion_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Study Notes",
    integration_type="notion",
    integration_config={"notion_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Study Notes"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeNotion),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigNotionConfigParam{
      NotionTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhook

Consulta [eventi webhook `entitlement_grant.*`](/developer-resources/webhooks/intents/entitlement-grant):

- `entitlement_grant.created` include il Notion `oauth_url`.
- `entitlement_grant.delivered` si attiva una volta duplicato il modello.
- `entitlement_grant.revoked` si attiva alla cancellazione; la copia del cliente rimane intatta.

## Risoluzione dei problemi

<AccordionGroup>
<Accordion title="Customer didn't get the template">
La concessione rimane `Pending` finché il cliente non completa l'OAuth di Notion. Invia nuovamente l'email di consegna; il link OAuth scade dopo una settimana, dopodiché puoi revocare e ricreare la concessione.
</Accordion>

<Accordion title="Template picker is empty">
Riconnetti Notion da **Entitlements → Integrations → Notion** con lo spazio di lavoro che possiede i modelli sorgente.
</Accordion>

<Accordion title="Customer wants the template removed after refund">
Notion non consente la cancellazione remota delle pagine duplicate. Il cliente deve eliminare la copia dal proprio spazio di lavoro.
</Accordion>
</AccordionGroup>
