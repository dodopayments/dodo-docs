[ParityDeals](https://www.paritydeals.com/) e [Evendeals](https://www.evendeals.com/integrations/dodo-payments) sono piattaforme che consentono l'ottimizzazione automatica dei prezzi in base alla posizione geografica del cliente, comunemente nota come prezzo "Parità del Potere d'Acquisto" (PPP).

<Info>
Anche se non puoi incorporare direttamente banner di sconto su una vetrina Dodo Payments (poiché non sono supportati script personalizzati), puoi comunque implementare efficacemente questi strumenti sul tuo sito web o applicazione.
</Info>

## Scegliere un'Integrazione

Entrambe le piattaforme si integrano direttamente con Dodo Payments per creare e gestire automaticamente i codici sconto. Usa il confronto seguente per scegliere lo strumento più adatto alle tue esigenze.

| Caratteristica | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| Prezzi PPP / basati sulla posizione | Sì | Sì |
| Offerte per vacanze / basate sul tempo | Sì | No |
| Supporto per abbonamenti | Sì | Sì |
| Aggiornamento automatico dei coupon | — | Sì |
| Personalizzazione del banner | Sì | No |
| Prezzi | [Vedi Prezzi](https://www.paritydeals.com/pricing/) | [Vedi Prezzi](https://www.evendeals.com/pricing) |

## ParityDeals

Quando ParityDeals è integrato nel tuo sito web, i visitatori idonei vedranno un banner che include un codice sconto basato sulla posizione che possono utilizzare al checkout. Questi codici sconto sono creati e gestiti automaticamente da ParityDeals e appariranno nel tuo **Dodo Payments Dashboard** sotto **Vendite → Sconti**.

### Configurazione

<Steps>
  <Step title="Sign up on ParityDeals">
    Visita [app.paritydeals.com](https://app.paritydeals.com/) e crea un account.
  </Step>

  <Step title="Create Deals">
    Dopo aver effettuato l'accesso, individuare l'opzione per creare offerte. Dal menu a tendina, seleziona **"Crea Offerte tramite Dodo Payments"**.

    <Frame>
      <img src="/images/ppp/2.png" alt="Creazione di offerte tramite Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Accedi al tuo **Dodo Payments dashboard** e naviga su **Sviluppatori → Chiavi API**. Clicca **"Crea Nuova API"**.

    <Tip>
      Dai un nome descrittivo alla tua chiave API (es., 'ParityDeals') in modo da poterla identificare in seguito.
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="Creazione di una nuova chiave API in Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Copia la chiave API che hai creato e incollala nell'interfaccia di ParityDeals per stabilire la connessione con il tuo account Dodo Payments.

    <Frame>
      <img src="/images/ppp/4.png" alt="Collegamento della chiave API a ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Una volta connesso, ParityDeals recupererà il tuo catalogo prodotti Dodo Payments. Seleziona i prodotti che desideri associare alle tue offerte.

    <Frame>
      <img src="/images/ppp/5.png" alt="Selezione di prodotti per ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Inserisci l'URL del tuo sito web e seleziona facoltativamente le pagine specifiche di destinazione dove il banner di sconto dovrebbe apparire. Poi scegli il tuo tipo di offerta preferito:
    - Offerte basate sulla posizione
    - Offerte per vacanze
    - Offerte flash basate su orario

    <Frame>
      <img src="/images/ppp/6.png" alt="Configurazione delle impostazioni dell'offerta" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Seleziona i paesi a cui vuoi offrire sconti localizzati e definisci la percentuale di sconto per ciascuno. ParityDeals fornisce impostazioni predefinite consigliate che puoi modificare secondo necessità.

    <Frame>
      <img src="/images/ppp/7.png" alt="Impostazione delle regole di sconto basate sul paese" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Progetta il tuo banner sconto personalizzando il testo, selezionando colori e layout e scegliendo la posizione del banner (parte superiore o inferiore della pagina). Questo banner sarà mostrato ai visitatori idonei in base alle regole configurate.

    <Frame>
      <img src="/images/ppp/8.png" alt="Personalizzazione del banner sconto" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Dopo aver salvato la tua offerta, ParityDeals genererà uno script. Aggiungi questo script al codice del tuo sito web (tipicamente nella sezione `<head>`). Questo script rileva automaticamente le posizioni dei visitatori e mostra il banner sconto appropriato.

    <Frame>
      <img src="/images/ppp/9.png" alt="Script di integrazione ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

### Funzionalità Aggiuntive

## Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) è un'altra piattaforma che si integra con Dodo Payments per offrire prezzi di parità del potere d'acquisto basati sulla posizione. Supporta sia prodotti una tantum che in abbonamento.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Panoramica dell'integrazione di Evendeals Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

### Caratteristiche Principali

- **Sincronizzazione automatica dei coupon** — I coupon sono creati e gestiti in Dodo Payments automaticamente
- **Sconti in percentuale** — Offri sconti in percentuale per gruppo di paesi
- **Supporto per abbonamenti** — Gli sconti si applicano su cicli di fatturazione in abbonamento
- **Regole di auto-aggiornamento** — Ruota i codici coupon automaticamente in base all'intervallo di tempo, al numero di riscatti o al numero di visualizzazioni per prevenire abusi

<Info>
I codici sconto creati da Evendeals appariranno automaticamente nel tuo dashboard Dodo Payments sotto Vendite → Sconti.
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="Caratteristiche principali di Evendeals per l'integrazione con Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

### Configurazione

<Steps>
  <Step title="Create a Dodo Payments API key">
    Nel tuo dashboard Dodo Payments, vai su **Sviluppatori → Chiavi API** e genera una nuova chiave.
  </Step>

  <Step title="Connect in Evendeals">
    Nel tuo [dashboard Evendeals](https://www.evendeals.com/signin), naviga su **Integrazioni**, trova la scheda Dodo Payments e incolla la tua chiave API.
  </Step>

  <Step title="Configure regional discounts">
    Imposta sconti percentuali per ciascun gruppo di paesi e premi il pulsante di sincronizzazione. Evendeals crea automaticamente i coupon in Dodo Payments.

    <Check>
    Dopo la sincronizzazione, apri **Vendite → Sconti** nel tuo dashboard Dodo Payments per confermare che i coupon generati appariscano. Ogni coupon avrà un prefisso riconoscibile di Evendeals.
    </Check>
  </Step>
</Steps>
