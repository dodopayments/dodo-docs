## Valuta Adattiva

La Valuta Adattiva consente ai clienti di pagare nella loro valuta locale preferita, migliorando la fiducia e i tassi di conversione.

### Come Funziona

1. **Abilita**: Abilita la Valuta Adattiva dalle Impostazioni Aziendali
2. **Seleziona**: I clienti possono cambiare valuta direttamente al checkout
3. **Converti**: I prezzi vengono convertiti dinamicamente utilizzando tassi di cambio in tempo reale
4. **Visualizza**: L'importo finale da pagare viene mostrato in modo trasparente prima del pagamento

## Calcolo Automatico delle Tasse

Le tasse sono automaticamente calcolate in base alla posizione di fatturazione del cliente, garantendo la conformità ai requisiti di GST, IVA e tassa sulle vendite senza configurazione manuale.

### Come Funziona il Calcolo delle Tasse

<Steps>
<Step title="Rilevamento della Posizione">
  Le regole fiscali vengono applicate in base al paese del cliente (e alla regione ove applicabile).
</Step>

<Step title="Aggiornamenti Dinamici">
  L'importo delle tasse viene aggiornato automaticamente quando:
  - Il paese cambia
  - L'indirizzo viene aggiornato
</Step>

<Step title="Visualizzazione Trasparente">
  La suddivisione finale delle tasse è chiaramente mostrata prima del pagamento.
</Step>
</Steps>

<Tip>
Il calcolo delle tasse è completamente automatizzato. Non è necessaria alcuna configurazione manuale per beni digitali standard e prodotti SaaS.
</Tip>

## Supporto per il Codice Fiscale Aziendale

Per le aziende registrate, il checkout consente ai clienti di inserire il proprio Codice Fiscale Aziendale (ad es. numero IVA/GST).

### Cosa Succede Quando Viene Inserito un Codice Fiscale

- L’idoneità fiscale viene convalidata in tempo reale
- Le esenzioni fiscali applicabili o le regole di inversione dell'onere sono applicate
- L'importo delle tasse viene aggiornato istantaneamente al checkout

## Codici Sconto

I clienti possono applicare codici sconto o promozionali che hai creato nel pannello direttamente nella pagina di checkout.

### Esperienza di Checkout

1. Il cliente inserisce il codice sconto
2. Lo sconto viene convalidato istantaneamente
3. Il prezzo aggiornato e i risparmi sono mostrati chiaramente

<Frame>
  <img src="/images/checkout/c4.png" alt="Inserimento codice sconto al checkout" style={{ width: '70%' }}/>
</Frame>

### Integrazione API

Pre-applica un codice sconto o abilita il campo di input dello sconto:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  discount_code: 'WELCOME20', // Pre-apply a code
  feature_flags: {
    allow_discount_code: true // Show discount input field
  },
  return_url: 'https://yoursite.com/return'
});
```

## Campi Personalizzati

Raccogli informazioni aggiuntive dai clienti durante il checkout definendo campi di modulo personalizzati. Questo è utile per raccogliere dati come nome dell'azienda, dimensioni del team, fonte di riferimento o qualsiasi altra informazione specifica per l'azienda.

### Tipi di Campo Disponibili

| Tipo | Descrizione |
|------|-------------|
| `text` | Input di testo a riga singola |
| `number` | Input numerico |
| `email` | Indirizzo email con validazione |
| `url` | URL con validazione |
| `date` | Selettore di data |
| `dropdown` | Seleziona da opzioni predefinite |
| `boolean` | Toggle Sì/No |

### Esempio

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Le risposte dei clienti sono automaticamente incluse nei payload webhook (`payment.succeeded`, `subscription.created`) e nelle risposte API tramite l'array `custom_field_responses`. Puoi definire fino a 5 campi personalizzati per sessione di checkout.
</Info>

## Checkout per Collezioni

Le Collezioni di Prodotti consentono un'esperienza di checkout unificata dove i clienti possono visualizzare e selezionare più prodotti correlati (ad es. piani Starter, Pro, Enterprise) in un unico checkout.

### Come Funziona

1. **Tutti i prodotti visualizzati**: I clienti vedono ogni prodotto attivo nella collezione
2. **Primo prodotto pre-selezionato**: Il primo prodotto nella collezione è automaticamente selezionato
3. **Confronta le opzioni**: I clienti possono confrontare prezzi e caratteristiche prima di scegliere
4. **Selezione singola**: Dopo aver selezionato un prodotto, il checkout procede con il flusso di pagamento standard

### Creare un Checkout per Collezioni

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
Quando si utilizza `product_collection_id`, passare un array `product_cart` vuoto. I codici sconto non possono essere pre-applicati alla creazione della sessione.
</Warning>

## Configurazione della Sessione di Checkout

Controlla il comportamento del checkout utilizzando l'API delle Sessioni di Checkout:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_code: 'PROMO10',
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
Dopo il pagamento, i clienti vengono reindirizzati al tuo `return_url` con i parametri di query aggiunti automaticamente -- inclusi `payment_id` o `subscription_id`, `status`, `email`, e `license_key` (se applicabile). Consulta la [guida alle sessioni di checkout](/developer-resources/checkout-session#request-body) per l'elenco completo.
</Info>

## Personalizzazione del Tema del Checkout

Personalizza l'aspetto della pagina di checkout per abbinarlo al tuo marchio utilizzando il parametro `customization.theme_config` durante la creazione di una sessione di checkout tramite l'API. Configura colori, caratteri, raggio dei bordi e testo del pulsante per le modalità chiara e scura.

<Frame>
  <img src="/images/checkout/theme-example.png" alt="Pagina di checkout a tema personalizzato"/>
</Frame>

<Info>
Questa sezione tratta della configurazione del tema **server-side API** utilizzando `customization.theme_config`. Se stai utilizzando il **Checkout SDK** (overlay o checkout inline), consulta le sezioni di personalizzazione del tema in [Overlay Checkout](/developer-resources/overlay-checkout#theme-customization) o [Inline Checkout](/developer-resources/inline-checkout#theme-customization) che utilizzano proprietà in camelCase (ad es., `bgPrimary` invece di `bg_primary`).
</Info>

### Opzioni di Configurazione del Tema

| Proprietà | Descrizione |
|-----------|-------------|
| `light` | Configurazione del colore per la modalità chiara |
| `dark` | Configurazione del colore per la modalità scura |
| `font_primary_url` | URL per il carattere primario |
| `font_secondary_url` | URL per il carattere secondario |
| `font_size` | Dimensione del carattere: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `font_weight` | Peso del carattere: `normal`, `medium`, `bold`, `extraBold` |
| `radius` | Raggio dei bordi per gli elementi UI (ad es., `4px`, `0.5rem`, `8px`) |
| `pay_button_text` | Testo personalizzato per il pulsante di pagamento (ad es., "Completa Acquisto", "Iscriviti Ora") |

### Configurazione Colore (Modalità Chiara/Scura)

Ogni modalità (`light` e `dark`) supporta le seguenti proprietà di colore:

| Proprietà | Descrizione |
|----------|-------------|
| `bg_primary` | Colore di sfondo primario |
| `bg_secondary` | Colore di sfondo secondario |
| `text_primary` | Colore primario del testo |
| `text_secondary` | Colore secondario del testo |
| `text_placeholder` | Colore del segnaposto del testo |
| `text_error` | Colore di errore del testo |
| `text_success` | Colore di successo del testo |
| `border_primary` | Colore primario del bordo |
| `border_secondary` | Colore secondario del bordo |
| `button_primary` | Colore di sfondo del pulsante primario |
| `button_primary_hover` | Colore di hover del pulsante primario |
| `button_secondary` | Colore di sfondo del pulsante secondario |
| `button_secondary_hover` | Colore di hover del pulsante secondario |
| `button_text_primary` | Colore del testo del pulsante primario |
| `button_text_secondary` | Colore del testo del pulsante secondario |
| `input_focus_border` | Colore del bordo di messa a fuoco dell'input |

<Info>
Tutti i campi di colore accettano formati standard di colore CSS:
- Hex: `#fff`, `#ffffff`, `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`, `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`, `hsla(120, 100%, 50%, 0.5)`
- Colori nominati: `red`, `blue`, `transparent`
</Info>

### Esempio

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
Non è necessario specificare tutte le proprietà di colore. Qualsiasi proprietà non specificata utilizzerà i valori predefiniti del tema.
</Tip>
