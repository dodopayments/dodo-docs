## Adaptive Currency

Adaptive Currency consente ai clienti di pagare nella valuta locale preferita, migliorando la fiducia e i tassi di conversione.

### Come funziona

1. **Abilita**: abilita Adaptive Currency da **Settings → Business**
2. **Seleziona**: i clienti possono cambiare valuta direttamente durante il checkout
3. **Applica PPP**: se sul prodotto è abilitata la [Purchasing Power Parity](/features/purchasing-power-parity), la percentuale del paese riduce il prezzo base
4. **Converti**: il prezzo (o il prezzo modificato dal PPP) viene convertito nella valuta del cliente ai tassi FX correnti
5. **Arrotonda**: se [Charm Pricing](/features/charm-pricing) è abilitato, l'importo convertito viene arrotondato a una cifra finale ordinata, come 49.99
6. **Visualizza**: l'importo finale da pagare viene mostrato in modo trasparente prima del pagamento

## Calcolo automatico delle imposte

Le imposte vengono calcolate automaticamente in base alla località di fatturazione del cliente, garantendo la conformità ai requisiti GST, VAT e alle imposte sulle vendite senza configurazione manuale.

### Come funziona il calcolo delle imposte

<Steps>
<Step title="Location Detection">
  Le regole fiscali vengono applicate in base al paese del cliente (e alla regione, ove applicabile).
</Step>

<Step title="Dynamic Updates">
  L'importo delle imposte si aggiorna automaticamente quando:
  - Cambia il paese
  - L'indirizzo viene aggiornato
</Step>

<Step title="Transparent Display">
  Il riepilogo finale delle imposte viene mostrato chiaramente prima del pagamento.
</Step>
</Steps>

<Tip>
Il calcolo delle imposte è completamente automatizzato. Non è necessaria alcuna configurazione manuale per i prodotti digitali e i prodotti SaaS standard.
</Tip>

## Supporto per il Business Tax ID

Per le aziende registrate, il checkout consente ai clienti di inserire il proprio Business Tax ID (ad es. numero VAT/GST).

### Cosa succede quando viene inserito un Tax ID

- L'idoneità fiscale viene convalidata in tempo reale
- Vengono applicate le esenzioni fiscali o le regole di reverse charge pertinenti
- L'importo delle imposte si aggiorna istantaneamente nel checkout

## Codici sconto

I clienti possono applicare direttamente nella pagina di checkout i codici sconto o promozionali che hai creato nella dashboard.

### Esperienza di checkout

1. Il cliente inserisce il codice sconto
2. Lo sconto viene convalidato istantaneamente
3. Il prezzo aggiornato e il risparmio vengono mostrati chiaramente

Quando la [Purchasing Power Parity](/features/purchasing-power-parity) è abilitata su un prodotto, lo sconto viene applicato al prezzo modificato dal PPP, non al prezzo base.

<Frame>
  <img src="/images/checkout/c4.png" alt="Inserimento del codice sconto durante il checkout" style={{ maxHeight: '500px', width: '70%' }}/>
</Frame>

### Integrazione API

Preapplica uno o più codici sconto cumulativi oppure abilita il campo di inserimento dello sconto:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  discount_codes: ['WELCOME20'], // Pre-apply one or more codes (max 20, applied in order)
  feature_flags: {
    allow_discount_code: true // Shown by default; set to false to hide the field
  },
  return_url: 'https://yoursite.com/return'
});
```

<Info>
`discount_codes` accetta un array contenente fino a 20 codici, applicati cumulativamente nell'ordine indicato. Il campo singolare `discount_code` è deprecato, ma continua a funzionare: le integrazioni esistenti non devono essere modificate immediatamente. Esegui la migrazione a `discount_codes` quando preferisci, per utilizzare il supporto ai codici cumulativi e una struttura della risposta più completa.
</Info>

## Raccolta intelligente degli indirizzi

Il checkout supporta l'inserimento flessibile degli indirizzi per velocizzare il completamento.

### Opzioni disponibili

| Opzione | Descrizione |
|--------|-------------|
| **Compilazione automatica dell'indirizzo con Google** | Selezione rapida con completamento automatico |
| **Inserimento manuale** | Controllo completo per indirizzi completi |
| **Selezione del paese** | Determina la logica fiscale e di compliance |
| **Indirizzo minimo** | Raccoglie solo il paese (e il CAP dove richiesto ai fini fiscali) — consulta la [Modalità indirizzo minimo](#minimal-address-mode) |

<Tip>
La raccolta degli indirizzi bilancia velocità, accuratezza e copertura globale per massimizzare la conversione e garantire al contempo la compliance.
</Tip>

### Modalità indirizzo minimo

Per massimizzare la conversione, abilita la raccolta dell'indirizzo minimo per ridurre gli ostacoli durante il checkout. Quando `minimal_address` è impostato su `true`, il checkout raccoglie solo:

- **Paese** — sempre richiesto per determinare le imposte
- **CAP/Codice postale** — solo nelle aree in cui è necessario per il calcolo di imposte sulle vendite, VAT o GST

Tutti gli altri campi dell'indirizzo (via, città, stato) vengono omessi, velocizzando notevolmente il completamento del checkout.

<Frame>
  <img src="/images/changelog/minimal-address.png" alt="Modalità indirizzo minimo che mostra solo i campi del paese e del CAP/codice postale durante il checkout" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  minimal_address: true,
  return_url: 'https://yoursite.com/return'
});
```

<Info>
La raccolta dell'indirizzo completo rimane l'impostazione predefinita. Abilita `minimal_address` per prodotti digitali e flussi SaaS in cui non sono richiesti dati di fatturazione completi.
</Info>

<Card title="Minimal Address Reference" icon="address-card" href="/developer-resources/checkout-session#request-body">
  Consulta il riferimento completo del parametro `minimal_address` nella guida dell'API Checkout Sessions.
</Card>

## Raccolta del numero di telefono

Controlla se il campo del numero di telefono viene visualizzato durante il checkout e se è obbligatorio utilizzando i feature flag della checkout session.

| Flag | Predefinito | Comportamento |
|------|---------|----------|
| `allow_phone_number_collection` | `true` | Mostra il campo del numero di telefono nel modulo di checkout |
| `require_phone_number` | `false` | Rende obbligatorio il campo del numero di telefono (la convalida del modulo impone un valore non vuoto) |

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_abc', quantity: 1 }],
  feature_flags: {
    allow_phone_number_collection: true,
    require_phone_number: true
  },
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
`require_phone_number: true` richiede `allow_phone_number_collection: true`. L'API rifiuta le sessioni in cui la raccolta del numero di telefono è disabilitata mentre il numero di telefono è obbligatorio.
</Warning>

<Tip>
Utilizza `require_phone_number` per SaaS B2B, settori regolamentati o qualsiasi flusso in cui sia necessario un canale di contatto verificato per l'assistenza, la revisione delle frodi o la compliance.
</Tip>

## Campi personalizzati

Raccogli informazioni aggiuntive dai clienti durante il checkout definendo campi modulo personalizzati. È utile per raccogliere dati come il nome dell'azienda, le dimensioni del team, la fonte di riferimento o qualsiasi altra informazione specifica dell'attività.

### Tipi di campo disponibili

| Tipo | Descrizione |
|------|-------------|
| `text` | Campo di testo a riga singola |
| `number` | Campo numerico |
| `email` | Indirizzo email con convalida |
| `url` | URL con convalida |
| `date` | Selettore di data |
| `dropdown` | Selezione da opzioni predefinite |
| `boolean` | Interruttore Sì/No |

### Esempio

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Le risposte dei clienti vengono incluse automaticamente nei payload webhook (`payment.succeeded`, `subscription.active`) e nelle risposte API tramite l'array `custom_field_responses`. Puoi definire fino a 5 campi personalizzati per checkout session.
</Info>

## Checkout delle raccolte

Le Product Collections consentono un'esperienza di checkout unificata in cui i clienti possono visualizzare e selezionare più prodotti correlati (ad esempio, i piani Starter, Pro ed Enterprise) in un singolo checkout.

### Come funziona

1. **Tutti i prodotti visualizzati**: i clienti vedono ogni prodotto attivo nella raccolta
2. **Primo prodotto preselezionato**: il primo prodotto della raccolta viene selezionato automaticamente
3. **Confronto delle opzioni**: i clienti possono confrontare prezzi e funzionalità prima di scegliere
4. **Selezione singola**: dopo aver selezionato un prodotto, il checkout prosegue con il normale flusso di pagamento

### Creazione di un checkout di raccolta

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
Quando utilizzi `product_collection_id`, passa un array `product_cart` vuoto. I codici sconto non possono essere preapplicati durante la creazione della sessione.
</Warning>

## Configurazione della Checkout Session

Controlla il comportamento del checkout utilizzando l'API Checkout Sessions:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_codes: ['PROMO10'],
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  cancel_url: 'https://yoursite.com/pricing', // Optional: where to redirect on cancel
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
Dopo il pagamento, i clienti vengono reindirizzati al tuo `return_url` con i parametri di query aggiunti automaticamente -- inclusi `payment_id` o `subscription_id`, `status`, `email` e `license_key` (se applicabile). Consulta la [guida Checkout Sessions](/developer-resources/checkout-session#request-body) per l'elenco completo.
</Info>

Personalizza l'aspetto della pagina di checkout per adattarlo al tuo brand utilizzando il parametro `customization.theme_config` durante la creazione di una checkout session tramite API. Configura colori, font, raggio dei bordi e testo del pulsante per le modalità chiara e scura.

  <img src="/images/checkout/theme-example.png" alt="Pagina di checkout con tema personalizzato" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Card title="Design & Theme Customization" icon="palette" href="/features/design">
  Configura visivamente i temi dalla dashboard con temi predefiniti, tipografia, colori e anteprima in tempo reale.

<Info>
Questa sezione illustra la configurazione del tema tramite **server-side API** utilizzando `customization.theme_config`. Se utilizzi il **Checkout SDK** (checkout overlay o inline), consulta la sezione sulla personalizzazione del tema in [Overlay Checkout](/developer-resources/overlay-checkout#theme-customization), che utilizza proprietà camelCase (ad esempio, `bgPrimary` invece di `bg_primary`).
</Info>

### Opzioni di configurazione del tema

| Proprietà | Descrizione |
|----------|-------------|
| `light` | Configurazione dei colori per la modalità chiara |
| `dark` | Configurazione dei colori per la modalità scura |
| `font_primary_url` | URL del font principale |
| `font_secondary_url` | URL del font secondario |
| `font_size` | Dimensione del font: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `font_weight` | Peso del font: `normal`, `medium`, `bold`, `extraBold` |
| `radius` | Raggio dei bordi per gli elementi dell'interfaccia (ad esempio, `4px`, `0.5rem`, `8px`) |
| `pay_button_text` | Testo personalizzato per il pulsante di pagamento (ad esempio, "Complete Purchase", "Subscribe Now") |

### Configurazione dei colori (modalità chiara/scura)

Ogni modalità (`light` e `dark`) supporta le seguenti proprietà dei colori:

| Proprietà | Descrizione |
|----------|-------------|
| `bg_primary` | Colore primario dello sfondo |
| `bg_secondary` | Colore secondario dello sfondo |
| `text_primary` | Colore primario del testo |
| `text_secondary` | Colore secondario del testo |
| `text_placeholder` | Colore del testo segnaposto |
| `text_error` | Colore del testo di errore |
| `text_success` | Colore del testo di esito positivo |
| `border_primary` | Colore primario del bordo |
| `border_secondary` | Colore secondario del bordo |
| `button_primary` | Colore di sfondo del pulsante primario |
| `button_primary_hover` | Colore al passaggio del mouse sul pulsante primario |
| `button_secondary` | Colore di sfondo del pulsante secondario |
| `button_secondary_hover` | Colore al passaggio del mouse sul pulsante secondario |
| `button_text_primary` | Colore del testo del pulsante primario |
| `button_text_secondary` | Colore del testo del pulsante secondario |
| `input_focus_border` | Colore del bordo quando l'input è attivo |

<Info>
Tutti i campi dei colori accettano i formati di colore CSS standard:
- Hex: `#fff`, `#ffffff`, `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`, `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`, `hsla(120, 100%, 50%, 0.5)`
- Colori denominati: `red`, `blue`, `transparent`
</Info>

### Esempio

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
Non è necessario specificare tutte le proprietà dei colori. Le proprietà non specificate utilizzeranno i valori del tema predefinito.
</Tip>
