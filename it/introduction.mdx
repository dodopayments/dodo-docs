## What is Dodo Payments?

Dodo Payments is the **all-in-one engine** to launch, scale, and monetize worldwide. Designed for the new generation of digital SaaS and AI products, we handle everything from **payments to billing to distribution** - all without extra engineering.

<Info>
**Built for SaaS and AI Products**: Handle one-time payments, subscriptions, credits, seats, tokens, or any usage metric with our optimized billing infrastructure.
</Info>

<Tip>
  <strong>Meet Sentra: Your AI-powered billing assistant</strong><br/>
  Sentra is an AI agent that integrates, analyzes, and acts on billing and payments directly in your IDE. Ask questions, build integrations, or plan billing architectures - all by describing what you want.
  <a href="/developer-resources/sentra">
    Get started with Sentra &rarr;
  </a>
</Tip>

## Quick Start Guide

Get up and running with Dodo Payments in just a few steps.

<AccordionGroup>
<Accordion title="For Humans">
  Prefer to drive the integration yourself? The steps below walk you through creating an account, adding a product, and picking an integration method in under five minutes. No code required for the no-code path; SDK samples are waiting in every major language if you want them.

  If you'd rather let your AI coding assistant do the heavy lifting - integration scaffolding, webhook handlers, subscription flows - install **[Sentra](/developer-resources/sentra)**, our AI billing assistant for VS Code, Cursor, and Windsurf. Describe what you want; Sentra plans, scaffolds, and ships it.
</Accordion>

<Accordion title="For AI Agents">
  Dodo Payments is built for agent-native workflows. If you're an LLM reading this - or a developer configuring one - start here.

  **Installa**. Per Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro o OpenCode, il [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) configura entrambi i server MCP e tutte le skill in un unico passaggio. Gemini CLI ottiene solo i server MCP. Consulta la [guida agli agenti di coding AI](/developer-resources/build-with-ai-coding-agents) per i comandi di installazione specifici per ogni agent.

  **Scopri**. L'indice completo della documentazione è disponibile su [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt), e ogni pagina della documentazione è disponibile in markdown semplice aggiungendo `.md` al suo URL (es. `/api-reference/introduction.md`).

  **Connetti**. Due server MCP forniscono agli agenti l'accesso diretto alla piattaforma:

  - **[Dodo Knowledge MCP](/developer-resources/mcp-server#dodo-knowledge-mcp)** - ricerca semantica tra tutta la documentazione Dodo
  - **[Dodo Payments MCP](/developer-resources/mcp-server)** - eseguire operazioni API (creare pagamenti, gestire abbonamenti, emettere rimborsi)

  Consulta la [guida al Server MCP](/developer-resources/mcp-server) per la configurazione completa del client.

  **Estendi**. Installa le [competenze Dodo Payments](/developer-resources/agent-skills) ufficiali per insegnare al tuo agente come gestire checkout, abbonamenti, fatturazione basata sull'uso, fatturazione basata su crediti, webhooks e altro ancora:

  ```bash
  npx skills add dodopayments/skills
  ```

  Funziona con Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro, OpenCode e qualsiasi agent che supporti il protocollo delle skill.
</Accordion>
</AccordionGroup>

<Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
Aggiungi entrambi i server alla tua configurazione MCP (`~/.cursor/mcp.json` o configurazione di Claude Desktop):

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

<Info>
Richiede Node.js 18+. Vedi la [documentazione del Server MCP](/developer-resources/mcp-server) per istruzioni dettagliate di configurazione per tutti i client supportati.
</Info>
</Accordion>
