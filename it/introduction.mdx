## What is Dodo Payments?

Dodo Payments is the **all-in-one engine** to launch, scale, and monetize worldwide. Designed for the new generation of digital SaaS and AI products, we handle everything from **payments to billing to distribution** - all without extra engineering.

<Info>
**Built for SaaS and AI Products**: Handle one-time payments, subscriptions, credits, seats, tokens, or any usage metric with our optimized billing infrastructure.
</Info>

### Server MCP per Assistenti AI

Connetti il tuo assistente di codifica AI (Cursor, Claude Desktop, Windsurf, VS Code) direttamente a Dodo Payments con i nostri server MCP.

Ricerca semantica nella documentazione di Dodo Payments - ottieni risposte immediate su caratteristiche, API e migliori pratiche

Esegui direttamente le operazioni API - crea pagamenti, gestisci abbonamenti, ed effettua rimborsi tramite il tuo assistente AI
</CardGroup>

Aggiungi entrambi i server alla tua configurazione MCP (`~/.cursor/mcp.json` o configurazione Claude Desktop):

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

Richiede Node.js 18+. Consulta la [documentazione del Server MCP](/developer-resources/mcp-server) per istruzioni dettagliate sulla configurazione per tutti i client supportati.
