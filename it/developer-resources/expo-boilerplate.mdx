## Panoramica

Un boilerplate pronto per la produzione per integrare Dodo Payments nelle applicazioni Expo/React Native. Questo template include la creazione di sessioni di checkout, gestione dei pagamenti e una corretta configurazione di TypeScript per aiutarti a iniziare ad accettare pagamenti nella tua app mobile rapidamente.

<Info>
Questo boilerplate utilizza Expo SDK con TypeScript e include implementazioni di esempio per sessioni di checkout e gestione dei pagamenti.
</Info>

## Requisiti

- Node.js 18+
- Expo CLI o EAS CLI
- Account Dodo Payments (chiave API dal dashboard)
- Simulatore iOS o Emulatore Android (o dispositivo fisico)

## Avvio Veloce

<Steps>
<Step title="Clone the Repository">
Clona il repository del boilerplate e entra nella directory del progetto:

```bash
git clone https://github.com/dodopayments/expo-boilerplate.git
cd expo-boilerplate
```

</Step>

<Step title="Get Your API Credentials">
Ottieni le tue credenziali dalla dashboard di Dodo Payments in Modalità Test:

- **Chiave API**: Naviga su **Sviluppatore → Chiavi API** nel tuo [dashboard](https://app.dodopayments.com)

<Tip>
Inizia con la Modalità Test per testare l’integrazione in modo sicuro senza processare pagamenti reali.
</Tip>
</Step>

<Step title="Configure Environment Variables">
Crea un file `.env` nella directory principale:

```bash
touch .env
```

Aggiungi le tue credenziali Dodo Payments:

```bash .env
EXPO_PUBLIC_DODO_API_KEY=your_test_api_key_here
```

<Warning>
Non eseguire mai il commit del tuo file `.env` nel controllo versione. È già incluso in `.gitignore`.
</Warning>

<Warning>
Le variabili `EXPO_PUBLIC_*` sono incorporate nel bundle JavaScript distribuito e possono essere lette da chiunque scarichi la tua app. Le chiavi API di Dodo Payments sono bearer secret, quindi durante lo sviluppo usale solo con una chiave Test Mode. In produzione, crea sessioni di checkout sul tuo backend e passa all'app solo il valore `checkout_url` risultante — consulta [Mobile Integration](/developer-resources/mobile-integration).
</Warning>
</Step>

<Step title="Install Dependencies">
Installa i pacchetti npm richiesti:

```bash
npm install
```

</Step>

<Step title="Start the Development Server">
Avvia il server di sviluppo Expo:

```bash
npx expo start
```

Scansiona il codice QR con l'app Expo Go sul tuo dispositivo oppure premi `i` per il simulatore iOS o `a` per l'emulatore Android.

<Check>
Ora puoi iniziare a sviluppare! Il boilerplate include schermate e componenti di esempio che ti aiutano a comprendere l'integrazione.
</Check>
</Step>
</Steps>

## Struttura del progetto

```
expo-boilerplate/
├── app/
│   ├── (tabs)/
│   │   └── index.tsx          # Home screen with examples
│   └── checkout.tsx           # Checkout screen
├── components/
│   └── PaymentButton.tsx      # Payment button component
├── lib/
│   └── dodo.ts                # Dodo Payments client setup
├── .env.example               # Environment variables template
└── package.json
```

## Passaggi successivi

Dopo aver avviato il boilerplate:

<Steps>
<Step title="Create Your Products">
Aggiungi i prodotti nella tua [dashboard di Dodo Payments](https://app.dodopayments.com) per abilitare la funzionalità di checkout.
</Step>

<Step title="Customize the Integration">
Adatta il codice di esempio alle esigenze e al design della tua applicazione.
</Step>

<Step title="Test on Real Devices">
Testa il flusso di pagamento su dispositivi fisici per assicurarti che tutto funzioni correttamente.
</Step>

<Step title="Go Live">
Quando sei pronto, passa alle chiavi API Live Mode e crea la build della tua app per la produzione.
</Step>
</Steps>

## Build per la produzione

<Steps>
<Step title="Install EAS CLI">

```bash
npm install -g eas-cli
```

</Step>

<Step title="Configure EAS">

```bash
eas build:configure
```

</Step>

<Step title="Build Your App">
Per iOS:

```bash
eas build --platform ios
```

Per Android:

```bash
eas build --platform android
```

</Step>
</Steps>
