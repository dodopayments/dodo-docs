<Note>
Questa guida copre esclusivamente i **pagamenti una tantum** che coinvolgono **carte, Apple Pay e Google Pay**.
</Note>

## API Endpoints

| Ambiente | Base URL | Endpoint di Conferma Pagamento |
| --- | --- | --- |
| **Modalità di Test** | `https://test.dodopayments.com` | `https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm` |
| **Modalità Live** | `https://live.dodopayments.com` | `https://api.hs.dodopayments.com/payments/<payment_id>/confirm` |

## Flusso di Pagamento con Carta Step-by-Step

### Passo 1: Ottenere la Chiave Segreta

Inizia creando un pagamento utilizzando la seguente API:

- **Pagamenti**: [Crea API di Pagamento](/api-reference/payments/post-payments)

Questa API restituisce un **`secret_key`**, necessario per i passaggi successivi.

### Passo 2: Confermare il Pagamento

Conferma il pagamento chiamando l'endpoint `payments confirm`:

- **Modalità di Test**: `POST https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm`
- **Modalità Live**: `POST https://api.hs.dodopayments.com/payments/<payment_id>/confirm`

Includi i seguenti dettagli nel corpo della richiesta:

- `client_secret`: Chiave segreta del Passo 1
- `payment_method`: Imposta a `card`
- `payment_method_data`: Dettagli della carta e fatturazione
- `browser_info`: Dati specifici del browser (user agent, dettagli dello schermo, ecc.)
- `payment_type`: Imposta esplicitamente a `normal` (per pagamenti una tantum)

Intestazioni richieste:

- Ottieni la tua chiave pubblicabile dal supporto DodoPayments
- `api-key`: La tua chiave pubblicabile (Ottieni questo dal team di Dodo Payments)
- `content-type`: `application/json`

**Esempio di Corpo della Richiesta:**

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "card",
  "payment_method_data": {
    "card": {
      "card_number": "<card_number>",
      "card_exp_month": "<exp_month>",
      "card_exp_year": "<exp_year>",
      "card_holder_name": "<cardholder_name>",
      "card_cvc": "<cvc>",
      "card_network": "<network>"
    },
    "billing": {
      "address": {
        "first_name": "<first_name>",
        "last_name": "<last_name>"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"

```

### Gestire la Risposta

- Se la risposta **`status`** è **`requires_customer_action`**, reindirizza il cliente all'URL fornito nel campo **`next_action`** per ulteriori autenticazioni.

<Warning>
Assicurati di rispettare le linee guida di conformità PCI quando gestisci i dati raw delle carte.
</Warning>

## Integrazione di Apple Pay

Per utilizzare Apple Pay, imposta `payment_method` su `wallet` e includi i dati di Apple Pay in `payment_method_data`.

### Struttura del Corpo della Richiesta

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "apple_pay": {
        "payment_data": "<decrypted_payment_data>",
        "payment_method": {
          "display_name": "Visa 1234",
          "network": "Visa",
          "type": "debit"
        },
        "transaction_identifier": "UNIQUE_TRANSACTION_ID_FROM_APPLE"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Riferimento ai Campi di Apple Pay

| Campo | Tipo | Richiesto | Descrizione |
| --- | --- | --- | --- |
| `payment_data` | string | Sì | Questo enum viene utilizzato per rappresentare i dati di pagamento di Apple Pay, che possono essere crittografati o decrittografati. |
| `payment_method.display_name` | string | Sì | Nome visualizzato sul pulsante Apple Pay (es. "Visa 1234") |
| `payment_method.network` | string | Sì | Rete della carta (es. "Visa", "Mastercard", "Amex") |
| `payment_method.type` | string | Sì | Tipo di metodo di pagamento (es. "debito", "credito") |
| `payment_method.card_exp_month` | string | No | Mese di scadenza della carta (es. "12") |
| `payment_method.card_exp_year` | string | No | Anno di scadenza della carta (es. "25") |
| `transaction_identifier` | string | Sì | Identificatore di transazione unico da Apple Pay |

## Integrazione di Google Pay

Per utilizzare Google Pay, imposta `payment_method` su `wallet` e includi i dati di Google Pay in `payment_method_data`.

### Struttura del Corpo della Richiesta

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "google_pay": {
        "type": "CARD",
        "description": "Visa ending in 1234",
        "info": {
          "card_network": "VISA",
          "card_details": "1234"
        },
        "tokenization_data": {
          "type": "PAYMENT_GATEWAY",
          "token": "<encrypted_payment_token>"
        }
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Riferimento ai Campi di Google Pay

| Campo | Tipo | Richiesto | Descrizione |
| --- | --- | --- | --- |
| `type` | string | Sì | Tipo di metodo di pagamento (tipicamente "CARD") |
| `description` | string | Sì | Descrizione visibile dell metodo di pagamento |
| `info.card_network` | string | Sì | Rete della carta (es. "VISA", "MASTERCARD", "AMEX") |
| `info.card_details` | string | Sì | Ultime 4 cifre della carta |
| `info.assurance_details` | object | No | Dettagli di garanzia di autenticazione |
| `tokenization_data.type` | string | Sì | Tipo di tokenizzazione (es. "PAYMENT_GATEWAY") |
| `tokenization_data.token` | string | Sì | Token di pagamento crittografato da Google Pay |
