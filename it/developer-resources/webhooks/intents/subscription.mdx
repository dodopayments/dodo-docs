## Eventi Webhook di Abbonamento

I seguenti eventi webhook sono disponibili per il monitoraggio delle modifiche al ciclo di vita dell'abbonamento:

| Evento | Descrizione |
|-------|-------------|
| `subscription.active` | La subscription è stata attivata correttamente |
| `subscription.updated` | L'oggetto subscription è stato aggiornato (qualsiasi modifica a un campo attiva questo evento) |
| `subscription.on_hold` | La subscription è stata sospesa a causa di un rinnovo non riuscito |
| `subscription.paused` | La subscription è stata messa in pausa |
| `subscription.unpaused` | La subscription è ripresa dopo essere stata messa in pausa |
| `subscription.renewed` | La subscription è stata rinnovata per il periodo di fatturazione successivo |
| `subscription.plan_changed` | Il piano della subscription è stato aggiornato, declassato o modificato |
| `subscription.update_payment_method` | Il metodo di pagamento della subscription è stato aggiornato |
| `subscription.cancelled` | La subscription è stata annullata |
| `subscription.failed` | La creazione della subscription non è riuscita durante la creazione del mandato |
| `subscription.expired` | La subscription ha raggiunto la fine del suo periodo |

### Utilizzo di `subscription.updated` per la sincronizzazione in tempo reale

Il webhook `subscription.updated` viene attivato ogni volta che cambia un campo dell'abbonamento, consentendoti di mantenere lo stato dell'applicazione sincronizzato senza effettuare polling:

```javascript
app.post('/webhooks/dodo', async (req, res) => {
  const event = req.body;
  
  if (event.type === 'subscription.updated') {
    const subscription = event.data;
    
    // Sync subscription changes to your database
    await syncSubscription(subscription.subscription_id, {
      status: subscription.status,
      next_billing_date: subscription.next_billing_date,
      metadata: subscription.metadata,
      // ... other fields you want to track
    });
    
    console.log(`Subscription ${subscription.subscription_id} updated`);
  }
  
  res.json({ received: true });
});
```

<Tip>
Iscriviti a `subscription.updated` per ricevere notifiche in tempo reale su qualsiasi modifica dell'abbonamento, eliminando la necessità di interrogare periodicamente l'API per gli aggiornamenti.
</Tip>
