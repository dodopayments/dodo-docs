Gestisci le tue risorse Dodo Payments, crea sessioni di checkout e testa i webhook direttamente dal terminale. Creata per gli sviluppatori che preferiscono la riga di comando.

## Installazione

<CodeGroup>

```bash npm (Recommended)
npm install -g dodopayments-cli
```

```bash Bun
bun install -g dodopayments-cli
```

</CodeGroup>

### Installazione Manuale

1. Scarica l'ultima versione da [GitHub Releases](https://github.com/dodopayments/dodopayments-cli/releases) per il tuo sistema
2. Estrai e rinomina il binario in `dodo`
3. Sposta in una directory nel tuo PATH:

<CodeGroup>

```bash Linux
sudo mv ./dodo /usr/local/bin/
```

```text Windows
move .\dodo C:\Windows\System32\dodo
```

</CodeGroup>

## Autenticazione

Prima di utilizzare la CLI, autenticati con la tua chiave API:

```bash
dodo login
```

Questo farà:
1. Aprire il tuo browser sulla pagina delle chiavi API di Dodo Payments
2. Chiederti di inserire la tua chiave API
3. Chiederti di selezionare l'ambiente (**Modalità Test** o **Modalità Live**)
4. Memorizzare localmente le tue credenziali in `~/.dodopayments/api-key`

<Info>
La CLI supporta la memorizzazione di una chiave API per ambiente. Se sono configurate sia le chiavi in modalità test che live, ti verrà chiesto di scegliere quale ambiente utilizzare per la sessione corrente.
</Info>

## Utilizzo

La sintassi generale è:

```bash
dodo ‹category› ‹sub-command›
```

Eseguire `dodo` senza argomenti mostra tutte le categorie disponibili. Eseguire `dodo <category>` senza sotto-comando mostra i sotto-comandi disponibili per quella categoria.

### Prodotti

Gestisci il tuo catalogo prodotti.

| Comando | Descrizione |
|---------|-------------|
| `dodo products list` | Elenca tutti i prodotti (paginati) |
| `dodo products create` | Apri il dashboard per creare un prodotto |
| `dodo products info` | Visualizza i dettagli di un prodotto specifico |

### Pagamenti

Visualizza le transazioni di pagamento.

| Comando | Descrizione |
|---------|-------------|
| `dodo payments list` | Elenca tutti i pagamenti (paginati) |
| `dodo payments info` | Ottieni informazioni su un pagamento specifico |

### Clienti

Gestisci la tua base clienti.

| Comando | Descrizione |
|---------|-------------|
| `dodo customers list` | Elenca tutti i clienti (paginati) |
| `dodo customers create` | Crea un nuovo profilo cliente |
| `dodo customers update` | Aggiorna i dettagli di un cliente esistente |

### Sconti

Gestisci coupon e sconti.

| Comando | Descrizione |
|---------|-------------|
| `dodo discounts list` | Elenca tutti gli sconti (paginati) |
| `dodo discounts create` | Crea un nuovo sconto basato su percentuale |
| `dodo discounts delete` | Rimuovi uno sconto per ID |

### Licenze

Gestisci le licenze software.

| Comando | Descrizione |
|---------|-------------|
| `dodo licences list` | Elenca tutte le chiavi di licenza (paginati) |

### Addons

Gestisci gli addon dei prodotti.

| Comando | Descrizione |
|---------|-------------|
| `dodo addons list` | Elenca tutti gli addon (paginati) |
| `dodo addons create` | Apri il dashboard per creare un addon |
| `dodo addons info` | Visualizza i dettagli di un addon specifico |

### Rimborsi

Visualizza informazioni sui rimborsi.

| Comando | Descrizione |
|---------|-------------|
| `dodo refund list` | Elenca tutti i rimborsi (paginati) |
| `dodo refund info` | Visualizza i dettagli di un rimborso specifico |

### Checkout

Crea sessioni di checkout.

| Comando | Descrizione |
|---------|-------------|
| `dodo checkout new` | Crea una nuova sessione di checkout e ottieni l'URL di checkout |

Il comando di checkout supporta opzioni avanzate tra cui raccolta minima di indirizzi, URL di ritorno, enforcement di 3D Secure, codici sconto e metadati.

## Test dei Webhook

La CLI include due potenti strumenti per testare i webhook durante lo sviluppo: un **listener** che inoltra i webhook di test dal vivo al tuo server locale e un **trigger** che invia payload di webhook mock a qualsiasi endpoint.

### Ascolta i Webhook

Inoltra i webhook di Dodo Payments direttamente al tuo server di sviluppo locale in tempo reale.

```bash
dodo wh listen
```

<Steps>
<Step title="Inserisci l'URL del tuo endpoint locale">
  Fornisci l'URL locale dove desideri ricevere i webhook (es. `http://localhost:3000/webhook`).
</Step>

<Step title="Impostazione automatica">
  La CLI crea automaticamente un endpoint webhook sul tuo account Dodo Payments se uno non esiste già, quindi apre una connessione WebSocket per ricevere eventi in tempo reale.
</Step>

<Step title="Ricevi e inoltra">
  Quando si attiva un evento webhook (da un pagamento di test, modifica dell'abbonamento, ecc.), la CLI lo riceve, registra il tipo di evento e inoltra la richiesta completa con intestazioni e corpo al tuo endpoint locale. La risposta dal tuo endpoint è registrata e inviata indietro.
</Step>
</Steps>

<Warning>
Il listener dei webhook funziona solo con una chiave API in **modalità test**. Assicurati di essere connesso con una chiave in modalità test prima di utilizzare `dodo wh listen`.
</Warning>

<Tip>
Il listener preserva le intestazioni originali del webhook (`webhook-id`, `webhook-signature`, `webhook-timestamp`) quando le inoltra al tuo endpoint locale, in modo da poter testare la tua logica di verifica della firma.
</Tip>

### Innesca Test dei Webhook

Invia payload di webhook mock a qualsiasi endpoint per test rapidi senza la necessità di creare transazioni reali.

```bash
dodo wh trigger
```

Questo ti guida attraverso:
1. Impostare un **endpoint URL** di destinazione
2. Opzionalmente configurare **ID Azienda**, **ID Prodotto** e **Metadati**
3. Selezionare un **evento** specifico da attivare da un menu interattivo
4. Inviare il payload mock e visualizzare la risposta

Dopo ogni evento, puoi selezionare un altro evento da attivare o uscire, rendendo facile testare più gestori di eventi in una sola sessione.

<Warning>
Lo strumento di attivazione invia payload mock senza firme dei webhook. Disabilita la verifica delle firme dei webhook durante il test utilizzando `unsafe_unwrap()` invece di `unwrap()` nel tuo gestore dei webhook.
</Warning>

### Eventi Webhook Supportati

| Categoria | Eventi |
|----------|--------|
| **Abbonamento** | `subscription.active`, `subscription.updated`, `subscription.on_hold`, `subscription.renewed`, `subscription.plan_changed`, `subscription.cancelled`, `subscription.failed`, `subscription.expired` |
| **Pagamento** | `payment.success`, `payment.failed`, `payment.processing`, `payment.cancelled` |
| **Rimborso** | `refund.success`, `refund.failed` |
| **Controversia** | `dispute.opened`, `dispute.expired`, `dispute.accepted`, `dispute.cancelled`, `dispute.challenged`, `dispute.won`, `dispute.lost` |
| **Licenza** | `licence.created` |

### Variabili di Ambiente

| Variabile | Descrizione |
|----------|-------------|
| `DODO_WH_TEST_SERVER_URL` | Sovrascrivi l'URL predefinito del server di relay webhook utilizzato da `dodo wh listen` |
