## Panoramica

Un boilerplate pronto per la produzione per gli abbonamenti che utilizza Next.js 15, React 19, Supabase, Drizzle ORM e Dodo Payments. Include Google OAuth, il checkout degli abbonamenti, la gestione dei webhook, lo schema del database e una dashboard di base.

<Info>
Se ti servono solo i route handler per un'app esistente, consulta gli adaptor dedicati: <a href="/developer-resources/nextjs-adaptor">Adaptor Next.js</a> e <a href="/developer-resources/express-adaptor">Adaptor Express</a>.
</Info>

## Prerequisiti

- Node.js 18+ (o Bun 1.0+)
- Progetto Supabase (URL, chiave Anon, chiave del ruolo Service, URL del database)
- Account Dodo Payments (chiave API, segreto del Webhook)
- Client OAuth Google Cloud (ID client e segreto)

## Avvio rapido

<Steps>
<Step title="Clone and install">

```bash
git clone https://github.com/dodopayments/dodo-supabase-subscription-starter.git
cd dodo-supabase-subscription-starter
# choose one
bun install
# or
npm install
# or
pnpm install
```

</Step>

<Step title="Create Supabase project">
Crea un progetto Supabase e copia:
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY
- SUPABASE_SERVICE_ROLE_KEY
- DATABASE_URL (stringa di connessione)
</Step>

<Step title="Configure Google OAuth">
Imposta l'URI di reindirizzamento su: `https://[your-project-ref].supabase.co/auth/v1/callback` in Google Cloud, quindi abilita il provider Google in Supabase Auth utilizzando il tuo ID client e il tuo segreto.
</Step>

<Step title="Configure Dodo Payments">
Genera una chiave API e un segreto del Webhook dalla dashboard di Dodo. Imposta l'ambiente su `test_mode` durante lo sviluppo.
</Step>

<Step title="Create .env.local">

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role

# Database
DATABASE_URL=postgresql://postgres:[password]@db.[project-ref].supabase.co:5432/postgres

# Dodo Payments
DODO_PAYMENTS_API_KEY=your-dodo-api-key
DODO_WEBHOOK_SECRET=your-webhook-secret
DODO_PAYMENTS_ENVIRONMENT=test_mode
```

<Warning>
Non eseguire mai il commit dei segreti. Usa le variabili d'ambiente negli ambienti di deployment.
</Warning>
</Step>

<Step title="Provision database schema">

```bash
bun run db:push
# or
npm run db:push
# or
pnpm run db:push
```

<Check>
Tabelle create: `users`, `subscriptions`, `payments`.
</Check>
</Step>

<Step title="Deploy webhook function">

```bash
# login (one-time)
bunx supabase login
# or
npx supabase login

# deploy the edge function
bun run deploy:webhook --project-ref [your-project-ref]
# or
npm run deploy:webhook -- --project-ref [your-project-ref]
# or
pnpm run deploy:webhook --project-ref [your-project-ref]
```

```bash cURL
curl -X POST \
  'https://[your-project-ref].supabase.co/functions/v1/dodo-webhook' \
  -H 'Content-Type: application/json' \
  -H 'Dodo-Signature: <signature>' \
  -d '{"type":"payment.succeeded","data":{}}'
```

</Step>

<Step title="Add webhook in Dodo Payments">
Imposta l'URL dell'endpoint su:

```text
https://[your-project-ref].supabase.co/functions/v1/dodo-webhook
```

Seleziona gli eventi di pagamento e di abbonamento.
</Step>

<Step title="Create products and features">
Nella dashboard di Dodo → Products → Create Product. Facoltativamente, aggiungi i metadati:

```json
{
  "features": ["Feature 1", "Feature 2", "Feature 3"]
}
```

L'interfaccia dei prezzi legge questo array `features` e lo visualizza dinamicamente.
</Step>

<Step title="Run the dev server">

```bash
bun run dev
# or
npm run dev
# or
pnpm run dev
```

Apri http://localhost:3000.
</Step>
</Steps>

## Cosa è incluso

- Autenticazione tramite Supabase (Google OAuth configurato)
- Checkout degli abbonamenti tramite Dodo Payments
- Supabase Edge Function per i webhook (`dodo-webhook`)
- Schema e migrazioni di Drizzle ORM
- Dashboard con fatture, stato dell'abbonamento e funzionalità del piano

<Tip>
Mantieni `DODO_PAYMENTS_ENVIRONMENT` come `test_mode` finché non completi i test end-to-end.
</Tip>

## Verifica e risoluzione dei problemi

<AccordionGroup>
<Accordion title="Webhook signature invalid (401)">
- Assicurati che `DODO_WEBHOOK_SECRET` corrisponda al valore nella dashboard di Dodo
- Conferma di aver distribuito la funzione `dodo-webhook` più recente
- Verifica che il nome dell'header sia corretto nella tua funzione (Dodo-Signature)
</Accordion>
<Accordion title="Database push fails">
- Controlla la sintassi di `DATABASE_URL` e l'uscita di rete di Supabase
- Attendi circa 2–3 minuti dopo la creazione del progetto prima del primo push
</Accordion>
<Accordion title="OAuth redirect mismatch">
- L'URI di reindirizzamento deve essere `https://[ref].supabase.co/auth/v1/callback`
- Assicurati che sia lo stesso in Google Cloud e nel provider Supabase Auth
</Accordion>
</AccordionGroup>
