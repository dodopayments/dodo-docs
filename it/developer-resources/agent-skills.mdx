## Overview

Agent Skills are reusable capabilities that enhance what AI coding assistants can do when working with Dodo Payments. They provide procedural knowledge and best practices that help agents accomplish specific tasks more effectively - from integrating checkout flows to setting up usage-based billing.

<Info>
**Think of skills as plugins for your AI assistant.** They teach your agent how to implement Dodo Payments features correctly, following our recommended patterns and best practices.
</Info>

Skills funzionano con qualsiasi agente AI che supporti il skills protocol, tra cui:
- **Claude Code** - assistente di programmazione CLI di Anthropic
- **Codex CLI** - agente di programmazione CLI di OpenAI
- **Cursor** - editor di codice basato innanzitutto sull'AI
- **VS Code / GitHub Copilot** - tramite il Agent Plugin
- **Kiro** - carica le skills come Power
- **OpenCode** - agente di programmazione AI open source
- **Altri client** - qualsiasi agente che supporti il skills protocol

<Note>
**Gemini CLI è l'eccezione.** Non dispone di una primitiva agent-skill, quindi le skills non sono disponibili; sono disponibili solo i due [MCP servers](/developer-resources/mcp-server).
</Note>

## Installazione

Scegli il metodo di installazione che preferisci in base al tuo assistente di programmazione AI.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Se utilizzi Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro o OpenCode, il [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) installa tutte le diciassette skills e i due MCP servers in un unico passaggio. Le skills vengono caricate automaticamente quando il tuo agente rileva un'attività pertinente.

Consulta la [guida agli AI Coding Agents](/developer-resources/build-with-ai-coding-agents) per i comandi di installazione specifici per ogni agente.
</Tab>

<Tab title="Skills CLI">
Installa le skills utilizzando il skills CLI universale, compatibile con qualsiasi agente compatibile con MCP:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Oppure installa singole skills secondo necessità:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/dodo-best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
Installa solo le skills necessarie per mantenere il tuo agente concentrato e ridurre il sovraccarico di contesto.
</Tip>
</Tab>

<Tab title="OpenCode">
OpenCode carica le skills dalle directory che gli indichi. **Non** esegue la scansione dei pacchetti installati, quindi è necessaria una voce `skills.paths` esplicita.

Utilizzando il pacchetto Agent Plugin:

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

I percorsi relativi vengono risolti rispetto alla **directory del progetto**, quindi il pacchetto deve essere presente nella `node_modules` di quel progetto. Funziona anche un percorso assoluto, che evita il requisito dell'installazione locale.

<Warning>
Un percorso delle skills che non esiste viene ignorato **silenziosamente**: nessun errore e nessun avviso. Conferma che le skills siano state effettivamente caricate:

```bash
opencode run "List every skill available to you by name."
```

Dovresti visualizzarle tutte e diciassette.
</Warning>
</Tab>
</Tabs>

## Utilizzo delle skills

Una volta installate, il tuo assistente AI carica automaticamente la skill pertinente quando gli chiedi di implementare una funzionalità di Dodo Payments. Non è necessario specificare il nome della skill: descrivi semplicemente l'attività.

| Prompt di esempio | Skill caricata |
|----------------|------------------|
| Aiutami a integrare Dodo Payments nella mia app Next.js seguendo le best practice | `dodo-best-practices` |
| Aggiungi un gestore di route checkout di Dodo Payments alla mia app Hono | `framework-adapters` |
| Guidami nei test dei pagamenti e nella messa in produzione | `testing-and-go-live` |
| Crea una checkout session per il mio prodotto SaaS | `checkout-integration` |
| Implementa un flusso di abbonamento con un periodo di prova gratuito e più livelli di prezzo | `subscription-integration` |
| Aggiungi il checkout in-app alla mia app React Native | `mobile-checkout` |
| Configura i gestori webhook per gli eventi di pagamento e abbonamento | `webhook-integration` |
| Configura gli entitlement dei crediti e la deduzione dei crediti basata su meter per il mio prodotto AI | `credit-based-billing` |
| Aggiungi la fatturazione basata sull'utilizzo per monitorare le chiamate API del mio prodotto AI | `usage-based-billing` |
| Implementa la validazione delle license key per la mia app desktop | `license-keys` |
| Crea un catalogo prodotti con add-on e prezzi a livelli | `product-catalog-management` |
| Aggiungi un codice promozionale che offre il 20% di sconto sui primi tre cicli di fatturazione | `discounts-and-promotions` |
| Mostra i prezzi nella valuta locale del visitatore con la parità del potere d'acquisto | `localized-pricing` |
| Fornisci ai clienti un portale self-service per gestire i loro metodi di pagamento | `customer-management` |
| Emetti un rimborso parziale e revoca l'accesso quando viene aperta una contestazione | `refunds-and-disputes` |
| Aggiungi una pagina dei prezzi utilizzando i componenti BillingSDK | `billing-sdk` |
| Integra Dodo Payments nella mia configurazione Better Auth | `better-auth-integration` |

## Come funzionano le skills

Le skills forniscono al tuo assistente AI:

1. **Conoscenze procedurali** - Istruzioni passo passo per implementare le funzionalità
2. **Template di codice** - Pattern e snippet di codice pronti per la produzione
3. **Best practice** - Approcci consigliati per sicurezza, gestione degli errori e UX
4. **Consapevolezza del contesto** - Comprensione di come le diverse funzionalità di Dodo Payments interagiscono tra loro

Quando chiedi al tuo assistente AI di implementare una funzionalità, utilizza la skill pertinente per:
- Comprendere l'approccio corretto all'implementazione
- Generare codice accurato e funzionante
- Seguire le convenzioni di Dodo Payments
- Gestire correttamente casi limite ed errori

<Note>
Le skills completano il [MCP Server](/developer-resources/mcp-server) e [Sentra](/developer-resources/sentra). Usa MCP per le operazioni API, Sentra per l'integrazione guidata e le skills per potenziare le funzionalità dell'assistente AI.
</Note>
