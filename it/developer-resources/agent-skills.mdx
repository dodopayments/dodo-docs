## Overview

Agent Skills are reusable capabilities that enhance what AI coding assistants can do when working with Dodo Payments. They provide procedural knowledge and best practices that help agents accomplish specific tasks more effectively - from integrating checkout flows to setting up usage-based billing.

<Info>
**Think of skills as plugins for your AI assistant.** They teach your agent how to implement Dodo Payments features correctly, following our recommended patterns and best practices.
</Info>

Skills work with any MCP-compatible AI agent, including:
- **Claude Code** - Anthropic's CLI coding assistant
- **OpenCode** - Open source AI coding agent
- **Cursor** - AI-first code editor
- **Other MCP clients** - Any agent supporting the skills protocol

## Installazione

Scegli il metodo di installazione che preferisci in base al tuo assistente di programmazione AI.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Se utilizzi Claude Code, Codex CLI, Cursor o OpenCode, il [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) installa tutti e diciassette gli skill e entrambi i server MCP in un unico passaggio. Gli skill vengono caricati automaticamente quando il tuo agent rileva un'attività pertinente.

Consulta la [guida agli AI Coding Agents](/developer-resources/build-with-ai-coding-agents) per i comandi di installazione specifici per ogni agent.
</Tab>

<Tab title="Skills CLI">
Installa gli skill usando il skills CLI universale, compatibile con qualsiasi agent compatibile con MCP:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Oppure installa singoli skill secondo necessità:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
Installa solo gli skill di cui hai bisogno per mantenere concentrato il tuo agent e ridurre il sovraccarico di contesto.
</Tip>
</Tab>

<Tab title="OpenCode">
Gli skill sono automaticamente disponibili quando vengono configurati nelle impostazioni di OpenCode. Aggiungi il repository degli skill di Dodo Payments alla configurazione:

## Utilizzare gli skill

Una volta installati, il tuo assistente di programmazione AI carica automaticamente lo skill pertinente quando gli chiedi di implementare una funzionalità di Dodo Payments. Non è necessario indicare il nome dello skill: descrivi semplicemente l'attività.

| Prompt di esempio | Skill caricato |
|----------------|------------------|
| Aiutami a integrare Dodo Payments nella mia app Next.js seguendo le best practice | `dodo-best-practices` |
| Aggiungi un route handler di checkout di Dodo Payments alla mia app Hono | `framework-adapters` |
| Guidami nei test dei pagamenti e nella messa in produzione | `testing-and-go-live` |
| Crea una checkout session per il mio prodotto SaaS | `checkout-integration` |
| Implementa un flusso di abbonamento con un periodo di prova gratuito e più livelli di prezzo | `subscription-integration` |
| Aggiungi il checkout in-app alla mia app React Native | `mobile-checkout` |
| Configura i webhook handler per gli eventi di pagamento e abbonamento | `webhook-integration` |
| Configura gli entitlement di crediti e la detrazione dei crediti misurata per il mio prodotto AI | `credit-based-billing` |
| Aggiungi la fatturazione basata sull'utilizzo per monitorare le chiamate API del mio prodotto AI | `usage-based-billing` |
| Implementa la convalida delle chiavi di licenza per la mia app desktop | `license-keys` |
| Crea un catalogo prodotti con componenti aggiuntivi e prezzi a livelli | `product-catalog-management` |
| Aggiungi un codice promozionale con uno sconto del 20% sui primi tre cicli di fatturazione | `discounts-and-promotions` |
| Mostra i prezzi nella valuta locale del visitatore con la parità del potere d'acquisto | `localized-pricing` |
| Fornisci ai clienti un portale self-service per gestire i metodi di pagamento | `customer-management` |
| Emetti un rimborso parziale e revoca l'accesso quando viene aperta una contestazione | `refunds-and-disputes` |
| Aggiungi una pagina dei prezzi usando i componenti BillingSDK | `billing-sdk` |
| Integra Dodo Payments nella mia configurazione Better Auth | `better-auth-integration` |

## Come funzionano gli skill

Gli skill forniscono al tuo assistente di programmazione AI:

1. **Conoscenze procedurali** - Istruzioni dettagliate per implementare le funzionalità
2. **Template di codice** - Pattern e snippet di codice pronti per la produzione
3. **Best practice** - Approcci consigliati per sicurezza, gestione degli errori e UX
4. **Consapevolezza del contesto** - Comprensione di come le diverse funzionalità di Dodo Payments collaborano tra loro

Quando chiedi al tuo assistente di programmazione AI di implementare una funzionalità, utilizza lo skill pertinente per:
- Comprendere l'approccio corretto all'implementazione
- Generare codice accurato e funzionante
- Seguire le convenzioni di Dodo Payments
- Gestire correttamente casi limite ed errori

<Note>
Gli skill completano il [MCP Server](/developer-resources/mcp-server) e [Sentra](/developer-resources/sentra). Usa MCP per le operazioni API, Sentra per l'integrazione guidata e gli skill per potenziare le capacità dell'assistente di programmazione AI.
</Note>
