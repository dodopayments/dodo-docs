## Panoramica

Le Competenze dell'Agente sono capacità riutilizzabili che migliorano ciò che gli assistenti di codifica AI possono fare quando lavorano con Dodo Payments. Forniscono conoscenze procedurali e migliori pratiche che aiutano gli agenti a portare a termine compiti specifici in modo più efficace - dall'integrazione dei flussi di checkout all'impostazione della fatturazione basata sull'uso.

<Info>
**Pensa alle competenze come a plugin per il tuo assistente AI.** Insegnano al tuo agente come implementare correttamente le funzionalità di Dodo Payments, seguendo i nostri schemi e le migliori pratiche raccomandate.
</Info>

Le competenze funzionano con qualsiasi agente AI compatibile con MCP, inclusi:
- **Claude Code** - L'assistente di codifica CLI di Anthropic
- **OpenCode** - Agente di codifica AI open source
- **Cursor** - Editor di codice AI-first
- **Altri client MCP** - Qualsiasi agente che supporta il protocollo delle competenze

## Installazione

Scegli il tuo metodo di installazione preferito in base al tuo assistente di codifica AI.

<Tabs>
<Tab title="Skills CLI">
Installa le competenze utilizzando la CLI universale delle competenze che funziona con qualsiasi agente compatibile con MCP:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Oppure installa competenze individuali secondo necessità:

```bash
# Best practices guide
npx skills add dodopayments/skills/dodo-best-practices

# Webhook integration
npx skills add dodopayments/skills/webhook-integration

# Subscription billing
npx skills add dodopayments/skills/subscription-integration

# Checkout flows
npx skills add dodopayments/skills/checkout-integration

# Usage-based billing
npx skills add dodopayments/skills/usage-based-billing

# BillingSDK components
npx skills add dodopayments/skills/billing-sdk

# License key management
npx skills add dodopayments/skills/license-keys
```

<Tip>
Installa solo le competenze di cui hai bisogno per mantenere il tuo agente concentrato e ridurre il sovraccarico di contesto.
</Tip>
</Tab>

<Tab title="Claude Code">
Aggiungi il marketplace delle competenze di Dodo Payments a Claude Code:

```bash
/plugin marketplace add dodopayments/skills
```

Poi installa plugin individuali:

```bash
# Install best practices
/plugin install dodo-best-practices

# Install webhook integration
/plugin install webhook-integration

# Install subscription integration
/plugin install subscription-integration

# Install checkout integration
/plugin install checkout-integration

# Install usage-based billing
/plugin install usage-based-billing

# Install BillingSDK
/plugin install billing-sdk

# Install license keys
/plugin install license-keys
```

</Tab>

<Tab title="OpenCode">
Le competenze sono automaticamente disponibili quando configurate nelle impostazioni di OpenCode. Aggiungi il repository delle competenze di Dodo Payments alla tua configurazione:

```json
{
  "skills": {
    "repositories": [
      "dodopayments/skills"
    ]
  }
}
```

</Tab>
</Tabs>

## Utilizzo delle Competenze

Una volta installato, il tuo assistente AI può sfruttare queste competenze quando gli chiedi di implementare le funzionalità di Dodo Payments. Ecco alcuni esempi di richieste:

### Migliori Pratiche

```
Help me integrate Dodo Payments into my Next.js app following best practices
```

### Webhooks

```
Set up webhook handlers for payment and subscription events
```

### Abbonamenti

```
Implement a subscription flow with free trial and multiple pricing tiers
```

### Checkout

```
Create a checkout session for my SaaS product
```

### Fatturazione Basata sull'Uso

```
Add usage-based billing to track API calls for my AI product
```

### BillingSDK

```
Add a pricing page using BillingSDK components
```

### Chiavi di Licenza

```
Implement license key validation for my desktop app
```

## Come Funzionano le Competenze

Le competenze forniscono al tuo assistente AI:

1. **Conoscenza Procedurale** - Istruzioni passo-passo per l'implementazione delle funzionalità
2. **Modelli di Codice** - Modelli di codice pronti per la produzione e frammenti
3. **Migliori Pratiche** - Approcci raccomandati per sicurezza, gestione degli errori e UX
4. **Consapevolezza del Contesto** - Comprensione di come diverse funzionalità di Dodo Payments lavorano insieme

Quando chiedi al tuo assistente AI di implementare una funzionalità, utilizza la competenza pertinente per:
- Comprendere l'approccio corretto di implementazione
- Generare codice accurato e funzionante
- Seguire le convenzioni di Dodo Payments
- Gestire correttamente i casi limite e gli errori

<Note>
Le competenze completano il [MCP Server](/developer-resources/mcp-server) e [Sentra](/developer-resources/sentra). Usa MCP per operazioni API, Sentra per integrazione guidata e Competenze per capacità avanzate dell'assistente AI.
</Note>
