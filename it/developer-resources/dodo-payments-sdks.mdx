Dodo Payments fornisce SDK ufficiali per diversi linguaggi di programmazione, ciascuno progettato secondo le best practice specifiche del linguaggio e con funzionalità moderne per un'integrazione fluida dei pagamenti.

<Tip>
Utilizza sempre la versione più recente dell'SDK per accedere alle nuove funzionalità e ai miglioramenti. Controlla regolarmente gli aggiornamenti nel tuo gestore di pacchetti per assicurarti di avere accesso a tutte le funzionalità di Dodo Payments.
</Tip>

## Avvio rapido

Inizia a utilizzare qualsiasi SDK in pochi minuti:

<Steps>
<Step title="Install the SDK">
  Usa il gestore di pacchetti del tuo linguaggio per installare l'SDK
  
  <Tabs>
  <Tab title="TypeScript/Node.js">

  ```bash
  npm install dodopayments
  ```

  </Tab>
  
  <Tab title="Python">

  ```bash
  pip install dodopayments
  ```

  </Tab>
  
  <Tab title="PHP">

  ```bash
  composer require dodopayments/client
  ```

  </Tab>
  
  <Tab title="Go">

  ```bash
  go get github.com/dodopayments/dodopayments-go
  ```

  </Tab>

  <Tab title="Rust">

  ```bash
  cargo add dodopayments
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Initialize the Client">
  Configura il client con la tua chiave API
  
  <Tabs>
  <Tab title="TypeScript">

  ```typescript
  import DodoPayments from 'dodopayments';
  const client = new DodoPayments({ bearerToken: 'your_api_key' });
  ```

  </Tab>
  
  <Tab title="Python">

  ```python
  from dodopayments import DodoPayments
  client = DodoPayments(bearer_token="your_api_key")
  ```

  </Tab>
  
  <Tab title="PHP">

  ```php
  use Dodopayments\Client;
  $client = new Client(bearerToken: 'your_api_key');
  ```

  </Tab>
  
  <Tab title="Go">

  ```go
  import "github.com/dodopayments/dodopayments-go"
  client := dodopayments.NewClient(option.WithBearerToken("your_api_key"))
  ```

  </Tab>

  <Tab title="Rust">

  ```rust
  use dodopayments::Client;
  let client = Client::from_env()?; // reads DODO_PAYMENTS_API_KEY
  ```

  </Tab>
  </Tabs>
  
  <Warning>
  Archivia sempre le tue chiavi API in modo sicuro utilizzando variabili d'ambiente. Non inserirle mai nel sistema di controllo versione.
  </Warning>
</Step>

<Step title="Make Your First API Call">
  Crea una sessione di checkout o un pagamento
  
  <Check>
  Ora puoi elaborare i pagamenti. Visita le singole pagine degli SDK per guide ed esempi dettagliati.
  </Check>
</Step>
</Steps>

## Funzionalità principali

Tutti gli SDK **backend** condividono queste funzionalità principali. Gli SDK per il checkout mobile
qui sotto sono deliberatamente più limitati: non contengono alcuna API key e non chiamano mai l'API:

- **Type Safety**: tipizzazione forte per la sicurezza a compile-time e un migliore supporto dell'IDE
- **Gestione degli errori**: gestione completa delle eccezioni con messaggi di errore dettagliati
- **Autenticazione**: autenticazione semplice tramite chiave API con supporto per le variabili d'ambiente
- **Supporto asincrono**: moderni pattern async/await quando applicabili
- **Impaginazione automatica**: impaginazione automatica per le risposte delle liste
- **Fatturazione basata sull'utilizzo**: supporto integrato per il monitoraggio e l'acquisizione degli eventi di utilizzo
- **Testing**: supporto completo per un ambiente sandbox durante lo sviluppo e i test

## SDK per il checkout mobile

Se preferisci aprire la **pagina di checkout ospitata** di Dodo invece di creare un
payment sheet nativo, usa l'SDK per il checkout mobile della tua piattaforma. Tutti e quattro condividono
lo stesso contratto con una sola chiamata: `start(...)` restituisce un `CheckoutResult` tipizzato,
nessuno contiene una API key e Apple Pay/Google Pay funzionano allo stesso modo in cui
funzionano sul web aperto, poiché il checkout si apre nella vera superficie browser della piattaforma
(`SFSafariViewController` / Custom Tabs), non in un `WebView`:

## Command-Line Interface

Per flussi di lavoro e automazioni basati sul terminale:

<Card title="CLI" icon="terminal" href="/developer-resources/sdks/cli">
  Interfaccia a riga di comando generata automaticamente con supporto per tutti i 78 endpoint API
</Card>

**Funzionalità:**
- Struttura dei comandi basata sulle risorse per un utilizzo intuitivo
- Più formati di output (JSON, YAML, pretty, interattivo)
- Completamento della shell per bash, zsh e fish
- Ideale per lo scripting e l'automazione CI/CD

```bash
# Quick example
dodopayments payments list --format json | jq '.data[] | {id, amount}'
```
