<Info>
Usa questo endpoint solo per concessioni create sotto un diritto di Chiave di Licenza con `fulfillment_mode: manual`. La concessione deve essere in stato `pending` senza alcuna chiave allegata. Vedi [Manual Fulfillment](/features/license-keys#manual-fulfillment) e la [Guida all’Integrazione per il Compimento Manuale della Chiave di Licenza](/developer-resources/manual-license-key-fulfillment) per il flusso completo.
</Info>
