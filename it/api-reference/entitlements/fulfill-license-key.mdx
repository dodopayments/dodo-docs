<Info>
Utilizza questo endpoint solo per le concessioni create nell’ambito di un’entitlement License Key con `fulfillment_mode: manual`. La concessione deve avere lo stato `Pending` e non deve avere alcuna chiave associata. Consulta il [completamento manuale](/features/license-keys#manual-fulfillment) e la [Guida all’integrazione per il completamento manuale delle License Key](/developer-resources/manual-license-key-fulfillment) per il flusso completo.
</Info>
