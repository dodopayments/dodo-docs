title: Revoca Concessione
description: Revoca manuale di una concessione. L'accesso alla piattaforma del
  cliente viene rimosso (per integrazioni OAuth/bot) e le chiavi di licenza sono
  disabilitate. Le revoche manuali utilizzano revocation_reason "manual" e non
  vengono ri-concesse automaticamente al rinnovo dell'abbonamento.
