<Warning>
Eliminare un diritto è una **eliminazione soft che nasconde le concessioni esistenti dal portale clienti**. Non revoca l'accesso lato piattaforma:

- Le concessioni legate al diritto rimangono nel database e mantengono il loro stato attuale `status`.
- I ruoli di Discord, l'accesso a collaboratori GitHub, l'accesso a Notion, l'appartenenza a Telegram, le chiavi di licenza e gli URL dei file digitali rimangono validi.
- Nessun `entitlement_grant.revoked` webhook viene emesso, e `revoked_at` / `revocation_reason` non sono impostati.

I clienti smettono di vedere queste concessioni in `GET /customer-portal/entitlements`, ma il loro accesso sulla piattaforma sottostante continua fino a quando il ciclo di vita dell'abbonamento/pagamento lo revoca (cancellazione, rimborso) o revochi manualmente ogni concessione tramite [`DELETE /entitlements/{id}/grants/{grant_id}`](/api-reference/entitlements/revoke-grant).

Se hai bisogno di interrompere completamente l'accesso, revoca prima le concessioni, quindi elimina il diritto.
</Warning>
