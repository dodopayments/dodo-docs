<Warning>
**API deprecato**: Le chiavi di licenza sono ora gestite tramite il sistema di [Entitlements](/features/entitlements/introduction). Utilizza [List Grants](/api-reference/entitlements/list-grants) (filtro con `integration_type=license_key`) per recuperare la concessione di una chiave e i suoi dettagli `license_key`. Questo endpoint verrà rimosso in un rilascio futuro.
</Warning>
