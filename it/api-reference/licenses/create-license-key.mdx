<Info>
Questo endpoint importa una chiave che già possiedi — `key`, `customer_id` e `product_id` sono tutti obbligatori. Non genera un valore per la chiave. L'importazione di una `key` già esistente restituisce `409 Conflict`.
</Info>

<Info>
Le chiavi di licenza create o aggiornate tramite l'API non attivano notifiche email per i clienti. Se devi informare i clienti della loro chiave di licenza, devi gestire questa operazione separatamente nella tua applicazione.
</Info>
