<Warning>
**API deprecata**: Le chiavi di licenza sono ora gestite tramite il sistema di [Entitlements](/features/entitlements/introduction). Configura i limiti e le durate di attivazione sull'[Entitlement della Chiave di Licenza](/api-reference/entitlements/update-entitlement), e utilizza [Revoke Grant](/api-reference/entitlements/revoke-grant) per disabilitare la chiave di un cliente. Questo endpoint verrà rimosso in un rilascio futuro.
</Warning>

<Info>
L'aggiornamento di una chiave di licenza tramite l'API non attiva notifiche email al cliente.
</Info>
