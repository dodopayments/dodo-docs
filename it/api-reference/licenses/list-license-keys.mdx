**API deprecata**: Le chiavi di licenza ora sono gestite tramite il sistema di [Entitlements](/features/entitlements/introduction). Usa [List Customer Grants](/api-reference/entitlements/list-customer-grants) per elencare le chiavi di licenza emesse (filtra con `integration_type=license_key`); ogni concessione porta i suoi dettagli `license_key`. Questo endpoint verrà rimosso in un prossimo rilascio.
</Warning>
