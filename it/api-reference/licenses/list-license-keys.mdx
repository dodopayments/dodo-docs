<Warning>
**API deprecato**: Le chiavi di licenza sono ora gestite tramite il sistema [Entitlements](/features/entitlements/introduction). Utilizza [List Grants](/api-reference/entitlements/list-grants) per elencare le chiavi di licenza emesse (filtra con `integration_type=license_key`); ogni grant trasporta i suoi dettagli `license_key`. Questo endpoint sarà rimosso in un futuro rilascio.
</Warning>
