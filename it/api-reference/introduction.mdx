## Gestione delle Chiavi API e Autenticazione

<Steps>
<Step title="Accedi alle Chiavi API">
Naviga su **Sviluppatore → Chiavi API** nel tuo dashboard per gestire le tue chiavi.
</Step>

<Step title="Genera una Nuova Chiave">
Seleziona **Aggiungi Chiave API**, fornisci un nome descrittivo e configura l'accesso in scrittura:

- **Abilita accesso in scrittura** (selezionato): Permessi completi di lettura e scrittura per tutte le operazioni API
- **Abilita accesso in scrittura** (non selezionato): Accesso in sola lettura - può solo recuperare dati (pagamenti, abbonamenti, clienti, prodotti). Non può creare o modificare risorse.

<Tip>
Deseleziona "Abilita accesso in scrittura" per integrazioni del dashboard, strumenti di analisi e qualsiasi sistema che ha solo bisogno di visualizzare i dati senza apportare modifiche.
</Tip>
</Step>

<Step title="Conserva la Tua Chiave in Sicurezza">
Copia immediatamente la chiave generata e assicurati che sia conservata in modo sicuro.
</Step>

<Step title="Autenticare le Tue Richieste API">
Utilizza le tue chiavi API per autenticare tutte le richieste. Applica il seguente formato di autorizzazione:

```bash 
Authorization: Bearer YOUR_API_KEY
```

<Warning>
Non esporre mai le tue chiavi API segrete nel codice lato client o in repository pubblici.
</Warning>
</Step>
</Steps>

## Limiti di Richiesta

La nostra API utilizza un sistema di limitazione del rateo a doppia finestra con protezione dagli spike. I limiti sono applicati in base al tuo metodo di autenticazione e al livello aziendale.

### Limiti Predefiniti (Livello 0)

| Finestra | Limite |
|--------|-------|
| Per Secondo (Burst) | 40 richieste |
| Per Minuto (Sostenuta) | 240 richieste |

### Livelli Aziendali

Limiti di rateo superiori sono disponibili per le aziende con maggiori esigenze API:

| Livello | Burst (per secondo) | Sostenuta (per minuto) |
|------|-------------------|------------------------|
| Livello 0 (Predefinito) | 40 | 240 |
| Livello 1 | 100 | 1,000 |
| Livello 2 | 500 | 5,000 |

<Tip>
Contatta il supporto per aggiornare la tua azienda a un livello di limite di rateo superiore.
</Tip>

### Richieste Non Autenticate

Le richieste senza intestazioni di autenticazione valide sono limitate per indirizzo IP:

| Finestra | Limite |
|--------|-------|
| Per Secondo (Burst) | 20 richieste |
| Per Minuto (Sostenuta) | 100 richieste |

### Intestazioni di Limite di Rateo

Monitora il tuo utilizzo con queste intestazioni di risposta:

- `X-RateLimit-Limit` - Richieste massime consentite
- `X-RateLimit-Remaining` - Richieste rimanenti nella finestra attuale
- `X-RateLimit-Reset` - Tempo in cui il limite di rateo si resetta

<Note>
Quando superi i limiti di rateo, l'API restituisce una risposta `429 Too Many Requests`. Implementa un backoff esponenziale nella tua logica di ripetizione.
</Note>
