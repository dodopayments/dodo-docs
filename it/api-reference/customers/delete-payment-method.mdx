Rimuovi un metodo di pagamento salvato dall'account di un cliente. Usa questa procedura per pulire i metodi di pagamento obsoleti o indesiderati.

<Warning>
Se il metodo di pagamento eliminato è l'unico registrato per un abbonamento attivo, l'abbonamento potrebbe non rinnovarsi al prossimo ciclo di fatturazione. Assicurati che il cliente abbia un metodo di pagamento alternativo prima di eliminare.
</Warning>

## Casi d'Uso

- **Richiesta del cliente**: Rimuovi un metodo di pagamento che il cliente non desidera più avere registrato
- **Carte scadute**: Pulisci i metodi di pagamento con dettagli di carte scadute
- **Sicurezza**: Rimuovi immediatamente i metodi di pagamento compromessi
