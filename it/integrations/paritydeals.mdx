## Introduzione

[ParityDeals](https://www.paritydeals.com/) è una piattaforma che mostra banner di sconto basati sulla posizione ai visitatori idonei sul tuo sito web e genera automaticamente i codici sconto corrispondenti in Dodo Payments. Quando un visitatore vede il banner, riceve un codice da utilizzare al checkout. Questi codici vengono visualizzati nella dashboard di Dodo Payments in **Sales → Discounts**.

<Note>
Dodo Payments offre [Purchasing Power Parity](/features/purchasing-power-parity) nativa, che riduce i prezzi in base al Paese durante il checkout senza banner né script. ParityDeals è pensato per i merchant che desiderano un banner di sconto visibile sul proprio sito o che vogliono organizzare promozioni stagionali e a tempo.
</Note>

## Come funziona

ParityDeals rileva la posizione del visitatore, mostra un banner di sconto personalizzabile sul tuo sito web e genera un codice sconto che può essere applicato al checkout. Il codice viene creato automaticamente nel tuo account Dodo Payments e funziona sui prodotti configurati.

1. Un visitatore accede al tuo sito web e ParityDeals rileva la sua posizione.
2. Se il visitatore è idoneo a ricevere uno sconto, viene visualizzato un banner con un codice basato sulla posizione.
3. Il visitatore utilizza il codice al checkout e Dodo Payments applica lo sconto.
4. Il codice viene visualizzato nella dashboard in **Sales → Discounts**.

## ParityDeals e PPP nativa a confronto

La Purchasing Power Parity nativa è il metodo consigliato per definire i prezzi in base al Paese. Scegli ParityDeals se hai specificamente bisogno di un banner di sconto sul tuo sito o di campagne stagionali e a tempo.

| | PPP nativa | ParityDeals |
| :--- | :--- | :--- |
| Come funziona | Una percentuale per Paese, applicata al checkout | Una percentuale di sconto, applicata tramite un codice |
| Dove viene configurata | Integrata in Dodo Payments | Dashboard di ParityDeals |
| Banner o script sul tuo sito | Non richiesto | Richiesto |
| Promozioni stagionali e a tempo | No | Sì |
| Ideale per | Prezzi corretti, senza modifiche al sito | Banner promozionali e offerte stagionali |

<Info>
Non puoi incorporare il banner di ParityDeals in un checkout o storefront ospitato da Dodo Payments, poiché gli script personalizzati non sono supportati. Il banner deve essere inserito nel tuo sito web o nella tua app.
</Info>

## Prerequisiti

Prima di configurare questa integrazione, assicurati di avere:

1. Un [account Dodo Payments](https://app.dodopayments.com)
2. Un [account ParityDeals](https://app.paritydeals.com/)
3. Una chiave API di Dodo Payments

## Per iniziare

<Steps>
  <Step title="Sign up on ParityDeals">
    Visita [app.paritydeals.com](https://app.paritydeals.com/) e crea un account.
  </Step>

  <Step title="Create Deals">
    Dopo aver effettuato l'accesso, individua l'opzione per creare le offerte. Dal menu a discesa, seleziona **"Create Deals via Dodo Payments"**.

    <Frame>
      <img src="/images/integrations/paritydeals/create-deals.png" alt="Creazione di offerte tramite Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Accedi alla **dashboard di Dodo Payments** e vai su **Developers → API Keys**. Fai clic su **"Create New API"**.

    <Tip>
      Assegna alla chiave API un nome descrittivo, ad esempio 'ParityDeals', così potrai identificarla in seguito.
    </Tip>

    <Frame>
      <img src="/images/integrations/paritydeals/api-key.png" alt="Creazione di una nuova chiave API in Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Copia la chiave API che hai creato e incollala nell'interfaccia di ParityDeals per stabilire la connessione con il tuo account Dodo Payments.

    <Frame>
      <img src="/images/integrations/paritydeals/connect-api-key.png" alt="Connessione della chiave API a ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Una volta stabilita la connessione, ParityDeals recupererà il catalogo dei prodotti di Dodo Payments. Seleziona i prodotti che vuoi associare alle tue offerte.

    <Frame>
      <img src="/images/integrations/paritydeals/select-products.png" alt="Selezione dei prodotti per ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Inserisci l'URL del tuo sito web e, facoltativamente, seleziona pagine specifiche in cui deve apparire il banner di sconto. Scegli quindi il tipo di offerta che preferisci:
    - Offerte basate sulla posizione
    - Offerte stagionali
    - Offerte flash a tempo

    <Frame>
      <img src="/images/integrations/paritydeals/deal-settings.png" alt="Configurazione delle impostazioni dell'offerta" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Seleziona i Paesi ai quali vuoi offrire sconti localizzati e definisci la percentuale di sconto per ciascuno. ParityDeals fornisce valori predefiniti consigliati che puoi modificare secondo necessità.

    <Frame>
      <img src="/images/integrations/paritydeals/country-rules.png" alt="Impostazione delle regole di sconto basate sul Paese" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Progetta il banner di sconto personalizzando il testo, selezionando colori e layout e scegliendo la posizione del banner (in alto o in fondo alla pagina). Il banner verrà mostrato ai visitatori idonei in base alle regole configurate.

    <Frame>
      <img src="/images/integrations/paritydeals/customize-banner.png" alt="Personalizzazione del banner di sconto" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Dopo aver salvato l'offerta, ParityDeals genererà uno script. Aggiungi questo script al codice del tuo sito web (in genere nella sezione `<head>`). Questo script rileva automaticamente le posizioni dei visitatori e mostra il banner di sconto appropriato.

    <Frame>
      <img src="/images/integrations/paritydeals/script.png" alt="Script di integrazione di ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>
