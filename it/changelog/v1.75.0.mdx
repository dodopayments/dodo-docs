## Nuove Funzionalità

### 1. **Collezioni di Prodotti**  
   
   Raggruppa prodotti correlati per esperienze di checkout unificate, selezione del piano e percorsi di upgrade/downgrade fluidi all'interno del Portale Clienti.

   <Frame>
     <img src="/images/product-collection/checkout-page.png" alt="Pagina di checkout della Collezione di Prodotti che mostra più opzioni di piano" />
   </Frame>

  **Vantaggi Chiave**

   - **Checkout basato su collezioni**: Mostra tutti i prodotti da una collezione in una sola vista di checkout, consentendo ai clienti di confrontare e scegliere il piano preferito
   - **Gestione dei prodotti organizzata**: Raggruppa prodotti correlati (es. Starter, Pro, Enterprise) sotto una singola collezione
   - **Integrazione con il Portale Clienti**: Consenti ai clienti di eseguire upgrade o downgrade tra i prodotti all'interno della stessa collezione
   - **Controllo per il Merchant**: Abilita, disabilita e riordina i prodotti all'interno di ciascuna collezione

   **Come Funziona**

   Crea una sessione di checkout per una collezione:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_collection_id: 'pdc_abc123',
     product_cart: [], // Required: pass an empty array for collection checkout
     return_url: 'https://yoursite.com/return'
   });

   // Redirect customer to the checkout
   window.location.href = session.url;
   ```

   <Check>
   Risultato: Un'esperienza di checkout unificata in cui i clienti possono visualizzare e selezionare tutti i prodotti disponibili nella tua collezione.
   </Check>

   <Info>
   Il checkout della collezione è ideale per le aziende di abbonamento in cui vuoi che i clienti possano confrontare i piani fianco a fianco prima dell'acquisto.
   </Info>

   Scopri di più: [Guida alle Collezioni di Prodotti](/features/product-collections)

### 2. **Metodi di Pagamento RevolutPay & Billie per Valuta GBP**  
   
   Opzioni di pagamento ampliate con RevolutPay e Billie ora disponibili a livello globale per transazioni di pagamento una tantum in GBP, offrendo ai tuoi clienti maggiore flessibilità nel modo in cui pagano.

   **Nuovi Metodi di Pagamento**

   | Metodo di Pagamento | Paesi Supportati | Valuta | Supporto Abbonamenti |
   |---------------------|------------------|--------|---------------------|
   | **RevolutPay** | Globale | GBP | No (solo una tantum) |
   | **Billie** | Globale | GBP | No (solo una tantum) |

   - **RevolutPay** – Pagamenti rapidi e senza intoppi per gli utenti di Revolut a livello globale
   - **Billie** – Soluzione B2B Compra Ora Paga Dopo che consente alle aziende di offrire termini di pagamento flessibili ai loro clienti

   <Info>
   Questi metodi di pagamento sono automaticamente disponibili per le transazioni in GBP. Non è necessaria alcuna configurazione aggiuntiva.
   </Info>

   Scopri di più: [Metodi di Pagamento](/features/payment-methods)

### 3. **Anteprima della Sessione di Checkout**  
   
   Anteprima delle sessioni di checkout prima di crearle per calcolare prezzi, tasse, sconti e totali accurati. Mostra i prezzi reali ai clienti prima di procedere al checkout.

   **Come Funziona**

   ```typescript
   const preview = await client.checkoutSessions.preview({
     product_cart: [
       { product_id: 'prod_123', quantity: 1 }
     ],
     billing_address: {
       country: 'US',
       state: 'CA',
       zipcode: '94102'
     },
     discount_code: 'SAVE20'
   });

   console.log('Subtotal:', preview.subtotal);
   console.log('Tax:', preview.tax);
   console.log('Discount:', preview.discount);
   console.log('Total:', preview.total);
   ```

   **Casi d'Uso**

   - **Visualizzazione dei prezzi personalizzati**: Mostra totali accurati comprensivi di tassa prima del checkout
   - **Validazione degli sconti**: Verifica i codici sconto e mostra i risparmi ai clienti
   - **Supporto multi-valuta**: Anteprima dei prezzi in diverse valute
   - **Riepiloghi del carrello**: Crea interfacce carrello personalizzate con prezzi in tempo reale

### 4. **Supporto Metadati nelle Richieste di Cambio Piano**  
   
   Passa metadati personalizzati quando cambi i piani di abbonamento, consentendo un miglior monitoraggio e integrazione con i tuoi sistemi interni durante le transizioni di piano.

   ```javascript
   // Adding metadata when changing a subscription plan
   await client.subscriptions.changePlan('sub_123', {
     product_id: 'prod_premium',
     proration_billing_mode: 'prorated_immediately',
     quantity: 1,
     metadata: {
       upgrade_reason: 'feature_request',
       previous_plan: 'basic',
       sales_rep: 'john@company.com'
     }
   });
   ```

  **Casi d'Uso**

   - **Monitora le ragioni di upgrade/downgrade**: Conserva motivi per cui i clienti hanno cambiato piano
   - **Collegati ai record CRM**: Associa i cambi di piano con le attività di vendita
   - **Categorizzazione interna**: Etichetta i cambi di piano per reporting e analisi
   - **Audit trails**: Mantieni registri di chi ha avviato i cambi di piano

   <Info>
   I metadati sono inclusi negli eventi webhook, rendendo facile elaborare i cambi di piano con i tuoi dati personalizzati.
   </Info>

   Scopri di più: [Guida ai Metadati](/api-reference/metadata) | [API Cambio Piano](/api-reference/subscriptions/change-plan)

### 5. **Campo `invoice_url` nella Risposta di Pagamento e nella Risposta al Link di Pagamento**  
   
   La Risposta di Pagamento e la Risposta al Link di Pagamento ora includono un campo `invoice_url`, fornendo accesso diretto alla fattura associata a ciascun pagamento.

   ```json
   {
     "payment_id": "pay_2IjeQm4hqU6RA4Z4kwDee",
     "status": "succeeded",
     "invoice_url": "https://dodopayments.com/invoices/inv_2IsUnWGtRKFLxk7xAQeyt",
     "amount": 9900,
     "currency": "USD",
     // ... other fields
   }
   ```

  **Casi d'Uso**

   - **Comunicazione con i clienti**: Invia link della fattura direttamente ai clienti
   - **Integrazione contabile**: Collega i pagamenti alle fatture nel tuo software contabile
   - **Portali self-service**: Permetti ai clienti di accedere facilmente alle loro fatture
   - **Archiviazione**: Mantieni riferimenti diretti ai documenti di fattura

### 6. **Endpoint di Validazione Sconto per Nome Codice**  
   
   Nuovo endpoint API per convalidare e recuperare codici sconto tramite il loro nome codice (es. "SAVE20") invece di usare l'ID sconto interno. Verifica l'idoneità agli sconti prima di applicarli al checkout.

   ```javascript
   // Validate a discount code before checkout
   const discount = await client.discounts.getByCode('SAVE20');

   console.log('Discount type:', discount.type);
   console.log('Discount value:', discount.amount);
   console.log('Valid until:', discount.expires_at);
   ```

  **Vantaggi**

   - **Validazione pre-checkout**: Verifica i codici sconto prima di creare sessioni di checkout
   - **Feedback in tempo reale**: Mostra ai clienti se il loro codice è valido
   - **Gestione degli errori**: Cattura codici non validi o scaduti precocemente
   - **Interfacce di sconto personalizzate**: Crea campi di input per codice sconto con validazione istantanea

### 7. **Capacità di Filtraggio Avanzato per Clienti, Sconti e Chiavi di Licenza**  
   
   Nuovi filtri API per elencare Clienti, Sconti e Chiavi di Licenza, rendendo più facile trovare e gestire i tuoi dati in modo programmatico.

   **Filtri API Clienti**

   | Filtro | Descrizione |
   |--------|-------------|
   | `email` | Filtra per email cliente |
   | `name` | Filtra per nome cliente (corrispondenza parziale, non sensibile al maiuscolo/minuscolo) |
   | `created_at_gte` | Filtra clienti creati a partire da questo timestamp |
   | `created_at_lte` | Filtra clienti creati fino a questo timestamp |

   ```javascript
   // Find customers by name created in the last 30 days
   const customers = await client.customers.list({
     name: 'John',
     created_at_gte: '2026-01-01T00:00:00Z'
   });
   ```

   **Filtri API Sconti**

   | Filtro | Descrizione |
   |--------|-------------|
   | `code` | Filtra per codice sconto (corrispondenza parziale, non sensibile al maiuscolo/minuscolo) |
   | `discount_type` | Filtra per tipo di sconto (percentuale) |
   | `active` | Filtra per stato attivo (true = non scaduto, false = scaduto) |
   | `product_id` | Filtra per restrizione del prodotto (solo sconti che si applicano a questo prodotto) |

   ```javascript
   // Find active percentage discounts for a specific product
   const discounts = await client.discounts.list({
     active: true,
     discount_type: 'percentage',
     product_id: 'prod_123'
   });
   ```

   **Filtri API Chiavi di Licenza**

   | Filtro | Descrizione |
   |--------|-------------|
   | `customer_id` | Filtra per ID cliente |
   | `status` | Filtra per stato della chiave di licenza (`active`, `expired`, `disabled`) |
   | `product_id` | Filtra per ID prodotto |
   | `created_at_gte` | Filtra chiavi di licenza create a partire da questo timestamp |
   | `created_at_lte` | Filtra chiavi di licenza create fino a questo timestamp |

   ```javascript
   // Find active license keys for a specific product
   const licenseKeys = await client.licenseKeys.list({
     status: 'active',
     product_id: 'prod_123'
   });
   ```
