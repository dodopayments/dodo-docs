## Nuove Funzionalità

### 1. **Preferenze di Comunicazione**

   Prendi il controllo su come ricevi le notifiche con le nostre rinnovate Preferenze di Comunicazione. Configura notifiche via email, push e in-app per adattarle al tuo flusso di lavoro.

   <Frame>
     <img src="/images/communication-preferences/overview.png" alt="Panoramica delle Preferenze di Comunicazione che mostra le impostazioni delle notifiche" />
   </Frame>

   **Funzionalità Chiave**

   - **Design email rinnovati**: Modelli di email freschi e moderni con chiari inviti all'azione e miglior leggibilità
   - **Notifiche push**: Ricevi avvisi istantanei sul tuo dispositivo mobile per eventi critici come nuove vendite, controversie e pagamenti
   - **Controlli granulari**: Scegli esattamente quali eventi attivano le notifiche e attraverso quali canali
   - **Supporto per più email**: Aggiungi più indirizzi email per ricevere notifiche
   - **Preferenze email dei clienti**: Configura quali email ricevono i tuoi clienti

   **Categorie di Notificazione**

   | Categoria | Descrizione |
   |----------|-------------|
   | **Vendite & Pagamenti** | Nuove vendite, pagamenti riusciti, pagamenti non riusciti |
   | **Payout e Rimborsi** | Completamenti dei payout, richieste di rimborso, completamenti dei rimborsi |
   | **Abbonamenti** | Nuovi abbonamenti, rinnovi, cancellazioni, modifiche al piano |
   | **Controversie** | Controversia aperta, evidenza richiesta, controversia risolta |

   <Check>
   Risultato: Rimani informato sulla tua attività con notifiche consegnate esattamente come e quando le vuoi.
   </Check>

   Scopri di più: [Guida alle Preferenze di Comunicazione](/features/communication-preferences)

### 2. **Campi Personalizzati nelle Sessioni di Checkout**

   Raccogli ulteriori informazioni dai clienti durante il checkout con campi personalizzati. Aggiungi input di testo, menu a discesa, date e altro per raccogliere i dati di cui hai bisogno.

   **Tipi di Campo Supportati**

   | Tipo | Descrizione | Caso d'uso |
   |------|-------------|----------|
   | `text` | Input di testo su una sola riga | Nome dell'azienda, note dell'ordine |
   | `number` | Input numerico | Quantità, età |
   | `email` | Input email con validazione | Email per contatto di fatturazione |
   | `url` | Input URL con validazione | Sito web, profilo social |
   | `date` | Selettore di data | Data di consegna, data dell'evento |
   | `dropdown` | Selezione da opzioni predefinite | Taglia, colore, tipo di piano |
   | `boolean` | Checkbox per valori sì/no | Accettazione delle condizioni, iscrizione alla newsletter |

   **Come Funziona**

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     custom_fields: [
       {
         name: 'company_name',
         label: 'Company Name',
         type: 'text',
         required: true
       },
       {
         name: 'team_size',
         label: 'Team Size',
         type: 'dropdown',
         options: ['1-10', '11-50', '51-200', '200+'],
         required: true
       },
       {
         name: 'newsletter',
         label: 'Subscribe to our newsletter',
         type: 'boolean',
         required: false
       }
     ],
     return_url: 'https://yoursite.com/success'
   });
   ```

   **Benefici**

   - **Raccolta dati flessibile**: Raccogli qualsiasi informazione necessaria per l'evasione o la personalizzazione
   - **Validazione integrata**: I campi email e URL convalidano automaticamente il formato di input
   - **Controllo obbligatorio/opzionale**: Segna i campi come obbligatori o opzionali in base alle tue esigenze
   - **Consegna via webhook**: I valori dei campi personalizzati sono inclusi negli eventi webhook di pagamento

   <Info>
   I valori dei campi personalizzati sono restituiti nell'oggetto `custom_fields` all'interno delle risposte di pagamento e sessione di checkout.
   </Info>

   Scopri di più: [Campi Personalizzati della Sessione di Checkout](/developer-resources/checkout-session#custom-fields)

### 3. **Supporto Linguistico Ampliato per il Checkout**

   La pagina di checkout ora supporta **21 lingue**, rispetto alle 16 precedenti. Raggiungi più clienti nella loro lingua nativa per un'esperienza di checkout migliore.

   **Nuove Lingue Aggiunte**

   | Lingua | Codice |
   |----------|------|
   | Coreano | `ko` |
   | Malese | `ms` |
   | Rumeno | `ro` |
   | Russo | `ru` |
   | Thai | `th` |

   **Tutte le Lingue Supportate**

Arabo, Cinese, Olandese, Inglese, Francese, Tedesco, Hindi, Indonesiano, Italiano, Giapponese, Coreano, Malese, Portoghese, Rumeno, Russo, Spagnolo, Svedese, Thai, Turco, Ucraino, Vietnamita.

   **Forzare una Lingua Specifica**

Utilizza il parametro `force_language` per sovrascrivere la rilevazione automatica della lingua:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     force_language: 'ko', // Force Korean language
     return_url: 'https://yoursite.com/success'
   });
   ```

   <Tip>
   Per impostazione predefinita, la pagina di checkout rileva automaticamente la lingua preferita del cliente dalle impostazioni del browser. Usa `force_language` quando vuoi garantire coerenza con la lingua del tuo sito web.
   </Tip>

   Scopri di più: [Supporto Linguistico per il Checkout](/features/checkout#supported-languages)
