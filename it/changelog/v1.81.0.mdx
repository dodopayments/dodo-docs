## Nuove Funzionalità

### 1. **Supporto per Analisi di Terze Parti**

Monitora il comportamento dei clienti su Storefront, Checkout e Customer Portal con Google Analytics 4, Google Tag Manager e Meta Pixel. Aggiungi i tuoi ID di tracciamento in **Impostazioni → Analisi** per iniziare a raccogliere eventi e-commerce.

**Piattaforme Supportate**

| Piattaforma | Formato ID |
|----------|-----------|
| Google Analytics 4 | `G-XXXXXXXXXX` |
| Google Tag Manager | `GTM-XXXXXXX` |
| Meta Pixel | Numerico (10-20 cifre) |

**Eventi Tracciati**

Eventi come `purchase`, `add_payment_info`, `view_item` e `view_item_list` vengono automaticamente inviati alle tue piattaforme di analisi mentre i clienti navigano e completano gli acquisti.

<Check>
Supportato su Storefront, Checkout ospitato, Checkout in overlay/in-line e Customer Portal.
</Check>

Scopri di più: [Analisi di Terze Parti](/features/analytics)

### 2. **Personalizzazione del Tema di Checkout**

Personalizza l'aspetto del checkout tramite il parametro `customization.theme_config` quando crei sessioni di checkout. Configura colori, font, raggio del bordo e testo del pulsante per le modalità chiara e scura.

**Opzioni di Configurazione**

| Proprietà | Descrizione |
|----------|-------------|
| `light` / `dark` | Schemi di colori per ciascuna modalità |
| `font_primary_url` | URL font personalizzato |
| `font_size` | `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `radius` | Raggio del bordo (ad es., `8px`) |
| `pay_button_text` | Testo del pulsante personalizzato |

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  customization: {
    theme_config: {
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      light: { button_primary: '#0066ff', text_primary: '#1a1a1a' },
      dark: { button_primary: '#3385ff', text_primary: '#ffffff' }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

Scopri di più: [Personalizzazione del Tema di Checkout](/features/checkout#checkout-theme-customization)

### 3. **Impedire la Modifica del Piano in Caso di Pagamento Fallito**

Nuovo parametro `on_payment_failure` per il cambiamento dei piani di abbonamento che controlla il comportamento quando il pagamento fallisce.

| Modalità | Comportamento |
|------|----------|
| `prevent_change` | Mantieni l'abbonamento sul piano attuale fino a quando il pagamento non ha successo |
| `apply_change` | Applica la modifica del piano immediatamente indipendentemente dall'esito del pagamento (predefinito) |

```typescript
await client.subscriptions.changePlan('sub_123', {
  product_id: 'prod_pro',
  proration_billing_mode: 'prorated_immediately',
  on_payment_failure: 'prevent_change'
});
```

<Tip>
Utilizza `prevent_change` per aggiornamenti critici in cui vuoi assicurarti il pagamento prima di concedere l'accesso a funzionalità premium.
</Tip>

Scopri di più: [Gestione dei Fallimenti di Pagamento](/developer-resources/subscription-upgrade-downgrade#handling-payment-failures)

## Aggiornamenti dell'API

### API del Bilancio del Libro Contabile

Nuovo endpoint `GET /balances/ledger` per recuperare le voci del libro contabile del tuo account con filtraggio e paginazione.

| Parametro | Descrizione |
|-----------|-------------|
| `created_at_gte` / `created_at_lte` | Filtra per intervallo di date |
| `event_type` | Filtra per `payment`, `refund`, `dispute`, `payout`, ecc. |
| `currency` | Filtra per codice valuta |
| `reference_object_id` | Filtra per ID pagamento/rimborso/disputa specifico |

Scopri di più: [API del Bilancio del Libro Contabile](/api-reference/balance-ledger/list-ledger-entries)

### Risposta di Pagamento: `refund_status`

Aggiunto il campo `refund_status` alla risposta `GET /payments/{paymentId}` per controllare rapidamente se un pagamento è stato rimborsato senza interrogare separatamente l'endpoint dei rimborsi.
