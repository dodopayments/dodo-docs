## Nuove funzionalità
- **Atlas open source**: un'applicazione demo scritta in Next.js per mostrare l'integrazione di Dodo Payments. Esplora il [repository GitHub](https://github.com/dodopayments/dodo-checkout-demo) e la documentazione [qui](/developer-resources/integration-guide).
- **Sezione per le richieste di funzionalità**: è stata introdotta una sezione per le richieste di funzionalità nella dashboard di Dodo Payments, per definire le priorità della roadmap del prodotto in base al feedback degli utenti.
- **API dei log delle richieste webhook**: sono state aggiunte API per elencare e visualizzare i dettagli dei log delle richieste webhook.
- **Link di pagamento statici**: sono stati aggiunti ulteriori parametri di query ai link di pagamento statici per offrire maggiore flessibilità nel processo di checkout. Per maggiori dettagli, fai clic [qui](/developer-resources/integration-guide#4-static-payment-links).
- **API per l'elenco delle sottoscrizioni**: è stata aggiunta un'API per recuperare tutte le sottoscrizioni. Consulta il [riferimento API](/api-reference/subscriptions/get-subscriptions-1) per maggiori dettagli.

## Miglioramenti Minori e Correzioni di Bug
- Migliorate le risposte delle API di Prodotto e Abbonamento con parametri aggiuntivi.
- Implementato il rate limiting per le richieste API, attualmente impostato a 20 richieste al secondo.
- Migliorata la documentazione per renderla più user-friendly e facile da navigare.
- Varie correzioni di bug minori e miglioramenti.
