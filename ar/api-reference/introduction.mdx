## إدارة API Key والمصادقة

<Steps>
<Step title="Access API Keys">
انتقل إلى **Developer → API Keys** في لوحة التحكم لإدارة مفاتيحك.
</Step>

<Step title="Generate a New Key">
حدّد **Add API Key**، وأدخل اسمًا وصفيًا، واضبط صلاحية الكتابة:

- **Enable write access** (محددة): أذونات كاملة للقراءة والكتابة لجميع عمليات API
- **Enable write access** (غير محددة): صلاحية للقراءة فقط - يمكنها جلب البيانات فقط (المدفوعات والاشتراكات والعملاء والمنتجات). لا يمكنها إنشاء الموارد أو تعديلها.

<Tip>
ألغِ تحديد "Enable write access" لتكاملات لوحة التحكم وأدوات التحليلات وأي نظام يحتاج إلى عرض البيانات فقط دون إجراء تغييرات.
</Tip>
</Step>

<Step title="Store Your Key Securely">
انسخ المفتاح الذي تم إنشاؤه فورًا واحرص على تخزينه بأمان.
</Step>

<Step title="Authenticate Your API Requests">
استخدم مفاتيح API للمصادقة على جميع الطلبات. طبّق تنسيق التفويض التالي:

```bash 
Authorization: Bearer YOUR_API_KEY
```

<Warning>
لا تكشف أبدًا عن مفاتيح API السرية في التعليمات البرمجية من جهة العميل أو في المستودعات العامة.
</Warning>
</Step>
</Steps>

## حدود المعدل

تستخدم API لدينا نظامًا مزدوج النوافذ للحد من المعدل مع حماية من الاندفاعات. تُطبّق الحدود استنادًا إلى طريقة المصادقة ودرجة نشاطك التجاري.

### الحدود الافتراضية (Tier 0)

| النافذة | الحد |
|--------|-------|
| لكل ثانية (Burst) | 40 طلبًا |
| لكل دقيقة (Sustained) | 240 طلبًا |

### درجات النشاط التجاري

تتوفر حدود معدل أعلى للأنشطة التجارية ذات احتياجات API المتزايدة:

| الدرجة | Burst (لكل ثانية) | Sustained (لكل دقيقة) |
|------|-------------------|------------------------|
| Tier 0 (افتراضية) | 40 | 240 |
| Tier 1 | 100 | 1,000 |
| Tier 2 | 500 | 5,000 |

<Tip>
تواصل مع الدعم لترقية نشاطك التجاري إلى درجة أعلى من حدود المعدل.
</Tip>

### الطلبات غير المصادق عليها

تُحدَّد الطلبات التي لا تحتوي على ترويسات مصادقة صالحة استنادًا إلى عنوان IP:

| النافذة | الحد |
|--------|-------|
| لكل ثانية (Burst) | 20 طلبًا |
| لكل دقيقة (Sustained) | 100 طلب |

### ترويسات حدود المعدل

راقب استخدامك من خلال ترويسات الاستجابة التالية:

- `X-RateLimit-Limit` - الحد الأقصى للطلبات المسموح بها
- `X-RateLimit-Remaining` - الطلبات المتبقية في النافذة الحالية
- `X-RateLimit-Reset` - وقت إعادة ضبط حد المعدل

<Note>
عند تجاوز حدود المعدل، تُرجع API استجابة `429 Too Many Requests`. طبّق التراجع الأُسّي في منطق إعادة المحاولة لديك.
</Note>
