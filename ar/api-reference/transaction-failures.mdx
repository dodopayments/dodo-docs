## نظرة عامة

توفر واجهة برمجة تطبيقات مدفوعات دودي أسباب فشل المعاملات بالتفصيل لمساعدتك على فهم سبب عدم نجاح محاولة الدفع. هذه الأسباب موحدة عبر طرق الدفع ومقدمي الخدمات المختلفة، مما يسهل تنفيذ معالجة الأخطاء بشكل متسق في تطبيقك.

يتضمن كل رد فشل معاملة:
- رمز سبب الفشل المحدد
- رسالة خطأ قابلة للقراءة البشرية
- سياق إضافي حول الفشل عند توفره
- ما إذا كان الخطأ يمكن تصحيحه من قبل المستخدم أو يتطلب تدخل النظام

فهم هذه الأسباب أمر بالغ الأهمية لـ:
- تقديم ملاحظات واضحة لعملائك
- تنفيذ منطق إعادة المحاولة المناسب
- التعامل مع سيناريوهات الفشل المختلفة بشكل سلس
- الحفاظ على نظام معالجة مدفوعات موثوق

## أسباب فشل المعاملات

تسرد الجدول التالي جميع أسباب فشل المعاملات المحتملة، ومعانيها، وما إذا كانت أخطاء يمكن تصحيحها من قبل المستخدم.

| رمز الخطأ | خطأ المستخدم | الوصف |
|----------------|------------|-------------|
| `AUTHENTICATION_FAILURE` | نعم | فشلت عملية المصادقة خلال الصفقة |
| `AUTHENTICATION_REQUIRED` | نعم | هناك حاجة لمصادقة إضافية لإتمام الصفقة |
| `AUTHENTICATION_TIMEOUT` | نعم | انتهت مهلة عملية المصادقة |
| `CARD_DECLINED` | لا | تم رفض البطاقة من قبل البنك المصدر |
| `CARD_NOT_ACTIVATED` | نعم | لم يتم تنشيط البطاقة من قبل حامل البطاقة |
| `CARD_VELOCITY_EXCEEDED` | نعم | تم محاولة إجراء الكثير من المعاملات في فترة قصيرة |
| `CUSTOMER_CANCELLED` | نعم | قام العميل بإلغاء الصفقة |
| `DO_NOT_HONOR` | لا | رفض البنك المصدر الصفقة |
| `EXPIRED_CARD` | نعم | انتهت صلاحية البطاقة |
| `FRAUDULENT` | نعم | تم تمييز الصفقة على أنها محتملة الاحتيال |
| `GENERIC_DECLINE` | لا | تم رفض الصفقة لسبب غير محدد |
| `INCORRECT_CVC` | نعم | كان رمز CVC المقدم غير صحيح |
| `INCORRECT_NUMBER` | نعم | تم إدخال رقم البطاقة بشكل غير صحيح |
| `INSUFFICIENT_FUNDS` | نعم | لا توجد أموال كافية في الحساب لإتمام الصفقة |
| `INVALID_ACCOUNT` | نعم | تفاصيل الحساب المقدمة غير صالحة |
| `INVALID_AMOUNT` | نعم | مبلغ الصفقة غير صالح |
| `INVALID_CARD_NUMBER` | نعم | تنسيق رقم البطاقة غير صالح |
| `INVALID_CARD_OWNER` | نعم | معلومات صاحب البطاقة غير صالحة |
| `INVALID_CVC` | نعم | تنسيق CVC غير صالح |
| `INVALID_EXPIRY_YEAR` | نعم | سنة انتهاء صلاحية البطاقة غير صالحة |
| `INVALID_PIN` | نعم | الرقم السري المقدم غير صحيح |
| `INVALID_REQUEST` | نعم | تحتوي طلب المعاملة على بيانات غير صالحة |
| `INVALID_UPI_ID` | نعم | معرف UPI المقدم غير صالح |
| `LIMIT_EXCEEDED` | نعم | تتجاوز الصفقة الحد المسموح به للبطاقة أو الحساب |
| `LIVE_MODE_TEST_CARD` | نعم | تم استخدام بطاقة اختبار في وضع مباشر |
| `LOST_CARD` | نعم | تم الإبلاغ عن البطاقة كضائعة |
| `MANDATE_INVALID` | نعم | التفويض غير صالح |
| `MANDATE_REQUIRED` | نعم | يتطلب الأمر تفويضًا لهذه الصفقة |
| `MANDATE_REQUIRED_SYSTEM` | لا | يتطلب النظام تفويضًا لهذا النوع من الصفقة |
| `NETWORK_ERROR` | لا | حدث خطأ في الشبكة خلال الصفقة |
| `NETWORK_TIMEOUT` | لا | انتهت مهلة طلب الشبكة |
| `ORDER_CREATION_FAILED` | لا | فشل في إنشاء الطلب للصفقة |
| `PAYMENT_METHOD_PROVIDER_DECLINED` | نعم | رفض مزود طريقة الدفع الصفقة |
| `PAYMENT_METHOD_UNSUPPORTED` | نعم | طريقة الدفع غير مدعومة لهذه الصفقة |
| `PICKUP_CARD` | نعم | تم الإبلاغ عن البطاقة كمسروقة ويجب استرجاعها |
| `PROCESSING_ERROR` | لا | حدث خطأ أثناء معالجة الصفقة |
| `PROVIDER_UNSUPPORTED` | لا | مزود الدفع لا يدعم هذا النوع من الصفقة |
| `REENTER_TRANSACTION` | نعم | تحتاج الصفقة إلى إعادة إدخال |
| `REVOCATION_OF_AUTHORIZATION` | نعم | تم سحب التفويض للصفقة |
| `STOLEN_CARD` | نعم | تم الإبلاغ عن البطاقة كمسروقة |
| `TRANSACTION_NOT_ALLOWED` | نعم | الصفقة غير مسموحة لهذه البطاقة أو الحساب |
| `TRANSACTION_NOT_APPROVED` | نعم | لم يتم الموافقة على الصفقة |
| `TRY_AGAIN_LATER` | لا | يجب إعادة تجربة الصفقة لاحقًا |
| `UNKNOWN_ERROR` | لا | حدث خطأ غير معروف |

<Note>
  **خطأ المستخدم** يشير إلى ما إذا كان يمكن حل رفض الدفع بواسطة العميل. عندما يكون `true`، يمكن للعميل اتخاذ إجراء لإصلاح المشكلة (على سبيل المثال، إدخال تفاصيل البطاقة الصحيحة). عندما يكون `false`، يكون الرفض بسبب مشاكل على مستوى النظام أو قيود البنك التي لا يمكن للعميل حلها.
</Note>
