## نظرة عامة

تستخدم واجهة برمجة تطبيقات مدفوعات دودي رموز الحالة القياسية HTTP ورموز الخطأ المخصصة للإشارة إلى نجاح أو فشل طلبات API. عند حدوث خطأ، تعيد واجهة برمجة التطبيقات رمز حالة HTTP مناسب واستجابة JSON تحتوي على معلومات مفصلة حول الخطأ.

تتضمن كل استجابة خطأ:
- رمز حالة HTTP يشير إلى الفئة العامة للخطأ
- رمز خطأ محدد يحدد الطبيعة الدقيقة للخطأ
- رسالة خطأ قابلة للقراءة البشرية تشرح ما حدث
- تفاصيل إضافية حول الخطأ عند الاقتضاء

فهم هذه الرموز ومعانيها أمر بالغ الأهمية لـ:
- تصحيح مشكلات التكامل
- تنفيذ معالجة الأخطاء بشكل صحيح في تطبيقك
- تقديم ملاحظات ذات مغزى للمستخدمين النهائيين
- الحفاظ على نظام معالجة مدفوعات قوي

هذه هي أخطاء **API والمنطق التجاري**. لأسباب **رفض البطاقة** التي تُرجع عند فشل الدفع (مثل `INSUFFICIENT_FUNDS` أو `CARD_DECLINED`)، راجع مرجع [إخفاقات المعاملات](/api-reference/transaction-failures) بدلاً من ذلك.

## رموز خطأ API القياسية

| HTTP Status | الاسم | الوصف |
|-------------|------|-------------|
| **400** | طلب سيئ | كان الطلب مشكلاً بشكل غير صحيح أو يحتوي على معلمات غير صالحة |
| **401** | غير مصرح | فشل التحقق من الهوية أو مفتاح API غير صالح |
| **403** | محظور | لا يمتلك مفتاح API إذن للوصول إلى المورد المطلوب |
| **404** | غير موجود | المورد المطلوب غير موجود |
| **405** | طريقة غير مسموح بها | طريقة HTTP غير مدعومة لهذه النقطة النهاية |
| **409** | تعارض | الطلب يتعارض مع الحالة الحالية للمورد |
| **422** | كيان غير قابل للمعالجة | الطلب كان مشكلاً بشكل جيد ولكن يحتوي على أخطاء دلالية |
| **429** | طلبات كثيرة جداً | تم تجاوز حد المعدل |
| **500** | خطأ في الخادم الداخلي | حدث خطأ غير متوقع في الخوادم الخاصة بنا |
| **502** | بوابة سيئة | تلقى الخادم استجابة غير صالحة من خادم علوي |
| **503** | الخدمة غير متاحة | الخدمة غير متاحة مؤقتاً |
| **504** | انتهاء مهلة البوابة | انتهت مهلة الخادم أثناء انتظار استجابة من الخادم العلوي |

## تنسيق استجابة الخطأ

عند حدوث خطأ، تعيد واجهة برمجة التطبيقات استجابة JSON بالهيكل التالي:

```json
{
  "code": "UNSUPPORTED_COUNTRY",
  "message": "Country AI currently not supported"
}
```

## مرجع رموز الخطأ

الرموز الخطأ أدناه مجمعة حسب منطقة API التي تتعلق بها. تعرض كل إدخال الحالة التي تحفزها والرسالة التي يعيدها API.

### التحقق من الهوية والحساب

- `UNAUTHORIZED`
  - **محفز:** لا يوجد مفتاح API أو رمز غير صالح / نطاق
  - **رسالة:** ليس لديك إذن لأداء هذا الإجراء

- `MERCHANT_NOT_LIVE`
  - **محفز:** لا يزال العمل في وضع الاختبار / البيئة التجريبية
  - **رسالة:** التاجر ليس على الهواء مباشرة

### المدفوعات وتسجيل الخروج

- `CHECKOUT_SESSION_CONSUMED`
  - **محفز:** جلسة الخروج قد أنشأت بالفعل دفعة
  - **رسالة:** تم استخدام جلسة الخروج بالفعل

- `NO_ELIGIBLE_PAYMENT_METHODS`
  - **محفز:** بعد التصفية، لم يتبقَ شيء
  - **رسالة:** لم يتم العثور على طرق دفع مؤهلة

- `PAYMENT_NOT_SUCCEEDED`
  - **محفز:** محاولة استرداد / معالجة دفعة غير ناجحة
  - **رسالة:** لم تنجح الدفعة المقدمة

- `PREVIOUS_PAYMENT_PENDING`
  - **محفز:** محاولة إنشاء رسوم بينما السابقة في حالة غير نهائية
  - **رسالة:** لا يمكن إنشاء رسوم جديدة لأن الدفع السابق لم يكتمل بنجاح بعد

- `UNSUCCESSFUL_PAYMENT_ID`
  - **محفز:** معرف الدفع يشير إلى دفعة غير ناجحة
  - **رسالة:** معرف الدفع لديه حالة غير ناجحة.

### موصلات وجلب معالجك الخاص (BYOP)

هذه الأخطاء تتعلق بالموصلات المملوكة للتاجر (جلب معالجك الخاص).

- `BYOP_CONNECTOR_DISABLED`
  - **محفز:** تحديث وسيلة الدفع في اشتراك موجه عبر موصل BYOP معطل
  - **رسالة:** الاشتراك يتم توجيهه عبر موصل التاجر الخاص (BYOP) الذي تم تعطيله حاليًا

- `BYOP_CUSTOM_INVOICE_ADDRESS_MISSING`
  - **محفز:** دفعة بتوجيه من التاجر (BYOP) تفتقد إلى عنوان فاتورة مخصص مطلوب
  - **رسالة:** يتطلب عنوان الفاتورة المخصص BYOP عندما يتم توجيه دفعة عبر موصل التاجر

- `CONNECTOR_LABEL_ALREADY_EXISTS`
  - **محفز:** إنشاء موصل بعلامة موجودة بالفعل
  - **رسالة:** يوجد بالفعل موصل بعلامة كهذه. يرجى اختيار علامة مختلفة.

### الاستردادات

- `EXISTING_REFUND_REQUEST_PROCESSING`
  - **Trigger:** طلب استرداد سابق لا يزال قيد المعالجة
  - **Message:** طلب استرداد بحالة "قيد الانتظار" ما زال قيد المعالجة

- `LINE_ITEM_FULLY_REFUNDED`
  - **محفز:** محاولة استرداد بند خط تم استرداده بالكامل بالفعل
  - **رسالة:** تم استرداد بند الخط {id} بالكامل لا يمكن استرداده أكثر.

- `LINE_ITEM_NOT_FOUND`
  - **محفز:** معرف العنصر لا يعد جزءاً من الدفع المشار إليه
  - **رسالة:** لم يتم العثور على بند الخط {id} في الدفع

- `LINE_ITEM_PRORATED`
  - **محفز:** محاولة استرداد أو تحديث لخط محجوب
  - **رسالة:** لا يمكن استرداد بند الخط {id} لأنه محجوب

- `LINE_ITEM_REFUND_AMOUNT_TOO_HIGH`
  - **محفز:** مبلغ الاسترداد > مبلغ المدفوع (بما في ذلك الضرائب)
  - **رسالة:** مبلغ الاسترداد المطلوب لبند الخط {id} بما في ذلك الضريبة هو {amount} وهو أعلى من المبلغ المدفوع {amount}

- `LINE_ITEM_REFUND_AMOUNT_TOO_LOW`
  - **محفز:** مبلغ الاسترداد أقل من الحد الأدنى
  - **رسالة:** مبلغ الاسترداد المطلوب لبند الخط {id} هو {amount} وهو منخفض جداً

- `NOTHING_TO_REFUND`
  - **محفز:** لا يتبقى أي مبلغ يمكن استرداده؛ جميع البنود الإيجابية تم استردادها بالكامل
  - **رسالة:** لا يتبقى أي مبلغ يمكن استرداده. تم استرداد جميع البنود الإيجابية بالكامل.

- `PARTIAL_REFUND_NOT_ALLOWED`
  - **محفز:** محاولة استرداد جزئي لطريقة دفع تدعم الاستردادات الكاملة فقط
  - **رسالة:** لا يُسمح بالاستردادات الجزئية لهذه وسيلة الدفع

- `PAYMENT_ALREADY_REFUNDED`
  - **محفز:** استرداد مكرر
  - **رسالة:** تم استرداد هذا الدفع بالفعل

- `PAYMENT_HAS_BEEN_REFUNDED`
  - **محفز:** تم استرداد الدفعة بالكامل
  - **رسالة:** تم استرداد معرف الدفع بالكامل.

- `REFUND_AMOUNT_EXCEEDS_PAID_AMOUNT`
  - **محفز:** مبلغ الاسترداد الإجمالي > المبلغ المدفوع
  - **رسالة:** مبلغ الاسترداد المحسوب أكبر من المبلغ المدفوع

- `REFUND_WINDOW_EXPIRED`
  - **محفز:** خارج نافذة الاسترداد المسموح بها
  - **رسالة:** لا يمكن تقديم الاستردادات بعد {days} يومًا من إنشاء الدفع. اتصل بـ support@dodopayments.com.

- `ZERO_AMOUNT_PAYMENT_REFUND_NOT_ALLOWED`
  - **محفز:** محاولة استرداد دفعة بلا مبلغ
  - **رسالة:** لا يمكن استرداد دفعة بمبلغ عملة صفر

### الاشتراكات والإضافات

- `ADDONS_IN_USAGE_BASED_BILLING_NOT_SUPPORTED`
  - **محفز:** محاولة إضافة إضافات لخطط الفوترة على أساس الاستخدام
  - **رسالة:** لا تدعم الاشتراكات الإضافات عند الفوترة على أساس الاستخدام

- `ADDONS_NOT_ALLOWED_FOR_ON_DEMAND`
  - **محفز:** محاولة إضافة إضافات للاشتراكات عند الطلب
  - **رسالة:** لا يُسمح بالإضافات للاشتراكات عند الطلب

- `CANCEL_SCHEDULED_PLAN_CHANGE_FOR_CUSTOMER_PORTAL_DISABLED`
  - **محفز:** محاولة بوابة العميل إلغاء تغيير الخطة المجدولة بينما العمل قد عطل هذا الإجراء
  - **رسالة:** إلغاء تغيير الخطة المجدولة معطل لبوابة العميل.

- `CHARGE_NOT_ALLOWED_FOR_SCHEDULED_CANCELLATION`
  - **محفز:** محاولة تحصيل رسوم الاشتراك المقرر إلغاؤه
  - **رسالة:** الاشتراك مقرر للإلغاء

- `CUSTOMER_HAS_EXISTING_SUBSCRIPTION`
  - **محفز:** إنشاء اشتراك لعميل لديه بالفعل واحد، عندما لا يسمح بأكثر من اشتراك لكل عميل
  - **رسالة:** العميل {id} لديه بالفعل اشتراك. للسماح بأكثر من اشتراك لكل عميل، غير إعدادات العمل

- `DO_NOT_BILL_NOT_ALLOWED_IN_CUSTOMER_PORTAL`
  - **محفز:** استخدام `do_not_bill` وضع التناسخ في تغيير خطة بوابة العميل
  - **رسالة:** لا يُسمح باستخدام وضع التناسخ do_not_bill في بوابة العميل

- `DUPLICATE_ADDON_IDS_IN_REQUEST`
  - **محفز:** الظهور المتكرر لنفس `addon_id` أكثر من مرة في الطلب
  - **رسالة:** لا يُسمح بتكرار معرفات الإضافات

- `INACTIVE_SUBSCRIPTION_PLAN_CHANGE_NOT_SUPPORTED`
  - **محفز:** تغيير الخطة على اشتراك غير نشط
  - **رسالة:** لا يدعم تغيير الخطط للاشتراكات غير النشطة

- `INVALID_PRORATION_MODE_WITH_NEXT_BILLING_DATE`
  - **محفز:** استخدام وضع تناسخ غير `full_immediately` مع `effective_at: next_billing_date`
  - **رسالة:** يُسمح فقط بوضع التناسخ full_immediately مع effective_at: next_billing_date

- `MISSING_ADDON_IDS`
  - **محفز:** قائمة `addon_id` فارغة أو تحتوي على معرّفات غير معروفة
  - **رسالة:** لا يوجد واحد أو أكثر من معرفات المنتج: {id}

- `ON_DEMAND_PLAN_CHANGE_NOT_SUPPORTED`
  - **محفز:** لا يُسمح بتبديل الخطة عند الطلب
  - **رسالة:** لا يدعم تغيير الخطط للاشتراكات عند الطلب

- `ON_DEMAND_USAGE_BASED_BILLING_NOT_SUPPORTED`
  - **محفز:** محاولة استخدام عند الطلب مع الفوترة على أساس الاستخدام
  - **رسالة:** لا يدعم الاشتراكات عند الطلب للفوترة على أساس الاستخدام

- `ONE_TIME_PRODUCTS_NOT_ALLOWED_FOR_ON_DEMAND`
  - **محفز:** إضافة منتج بوقت واحد إلى اشتراك عند الطلب
  - **رسالة:** لا يُسمح بالمنتجات ذات المرة الواحدة للاشتراكات عند الطلب

- `PENDING_PLAN_CHANGE_EXISTS`
  - **محفز:** طلب تغيير خطة جديد بينما لا يزال السابق في انتظار الدفع
  - **رسالة:** يوجد بالفعل تغيير خطة معلق لهذا الاشتراك. يرجى الانتظار حتى يكتمل الدفع الحالي.

- `PLAN_CHANGE_FOR_CUSTOMER_PORTAL_DISABLED`
  - **محفز:** تغيير الخطة من خلال بوابة العميل بينما الأعمال قد عطلتها
  - **رسالة:** تم تعطيل تغيير خطة الاشتراك لبوابة العميل.

- `PLAN_CHANGE_NOT_ALLOWED_FOR_SCHEDULED_CANCELLATION`
  - **محفز:** محاولة تغيير الخطة على اشتراك مقرر للإلغاء
  - **رسالة:** الاشتراك مقرر للإلغاء

- `SCHEDULE_PLAN_CHANGE_FOR_CUSTOMER_PORTAL_DISABLED`
  - **محفز:** جدولة تغيير خطة من خلال بوابة العميل بينما العمل قد عطلها
  - **رسالة:** تم تعطيل جدولة تغييرات الخطط لهذا العمل.

- `SCHEDULED_PLAN_CHANGE_EXISTS`
  - **محفز:** إنشاء تغيير خطة مقرر عند وجود آخر بالفعل
  - **رسالة:** يوجد بالفعل تغيير خطة مقرر لهذا الاشتراك. يرجى إلغاء التغيير المجدول الحالي قبل إنشاء واحد جديد.

- `SCHEDULED_PLAN_CHANGE_NOT_FOUND`
  - **محفز:** الإشارة إلى أو إلغاء تغيير خطة مقرر غير موجود
  - **رسالة:** لم يتم العثور على تغيير خطة مقرر لهذا الاشتراك.

- `SUBSCRIPTION_EXPIRED`
  - **محفز:** الفوترة بعد `ends_at`
  - **رسالة:** انتهى الاشتراك لا يمكن إنشاء رسوم جديدة

- `SUBSCRIPTION_INACTIVE`
  - **محفز:** الحالة ≠ `ACTIVE`
  - **رسالة:** الاشتراك غير نشط

- `SUBSCRIPTION_NOT_ON_DEMAND`
  - **محفز:** تم الحصول على عقدة عند الطلب ولكن كانت بمدة محددة
  - **رسالة:** الاشتراك ليس عند الطلب بالفعل

- `SUBSCRIPTION_PAYMENT_RETRY_LIMIT_EXCEEDED`
  - **محفز:** تجاوزت محاولات إعادة محاولة دفع الاشتراك الحد الأقصى
  - **رسالة:** تجاوز حد المحاولة الأقصى 10 محاولات لهذا الاشتراك

### المنتجات، السلة والعلامات التجارية

- `BRAND_MISMATCH`
  - **محفز:** عناصر السلة تنتمي إلى علامات تجارية مختلفة
  - **رسالة:** يجب أن تنتمي جميع العناصر في سلة المنت جات إلى نفس العلامة التجارية

- `BRAND_NOT_ENABLED`
  - **محفز:** العلامة التجارية معطلة أو غير نشطة
  - **رسالة:** العلامة التجارية المقدمة غير ممكّنة

- `BRAND_SUBMISSION_NOT_ENABLED`
  - **محفز:** ميزة إعادة تقديم تحقق العلامة التجارية غير ممكّنة
  - **رسالة:** إعادة تقديم تحقق العلامة التجارية غير ممكّنة

- `FILE_IN_USE`
  - **محفز:** حذف ملف منتج رقمي لا يزال يُشار إليه بواسطة منح الامتيازات النشطة (تمرير `?force=true` لتجاوز)
  - **رسالة:** الملف الرقمي يشير إليه منح نشط

- `INVALID_SUGGESTED_PRICE`
  - **محفز:** السعر المقترح تحت الحد الأدنى المسموح به
  - **رسالة:** لا يمكن أن يكون السعر المقترح أقل من السعر الأدنى. في حالة الدفع ما تريد، يُعتبر السعر هو الحد الأدنى المقبول

- `LOCALIZED_PRICE_ALREADY_EXISTS`
  - **محفز:** يوجد سعر محلي بالفعل لهذا المنتج والبلد / العملة
  - **رسالة:** يوجد سعر محلي لهذا المنتج والبلد / العملة بالفعل

- `LOCALIZED_PRICE_DUPLICATES_BASE`
  - **محفز:** السعر المحلي يكرر عملة / بلد المنتج الأساسية
  - **رسالة:** السعر المحلي يكرر عملة / بلد المنتج الأساسية

- `LOCALIZED_PRICE_SHAPE_MISMATCH`
  - **محفز:** شكل السعر المحلي لا يتطابق مع `pricing_mode` المنتج
  - **رسالة:** شكل السعر المحلي لا يتطابق مع الوضع التسعيري للمنتج

- `MISSING_PRODUCT_INFORMATION`
  - **محفز:** المنتج موجود لكن المعلومات الضرورية مفقودة
  - **رسالة:** المنتج {id} موجود لكن المعلومات الضرورية الأخرى مفقودة أو غير صالحة

- `PAY_AS_YOU_WANT_AMOUNT_REQUIRED`
  - **محفز:** السعر مفقود لمنتج الدفع حسب ما تريد
  - **رسالة:** المبلغ إلزامي لمنتج الدفع كما تريد

- `PRODUCT_CART_EMTPY`
  - **محفز:** إرسال سلة منتجات فارغة
  - **رسالة:** سلة المنتج فارغة (رمز الخطأ يتم تهجئته عمداً كـ `EMTPY` لتطابق القيمة الدقيقة التي يعيدها API)

- `PRODUCT_COLLECTION_IS_DELETED`
  - **محفز:** العمل على مجموعة منتجات تم حذفها
  - **رسالة:** *لا توجد رسالة*

- `PRODUCT_COLLECTION_MUST_HAVE_PRODUCTS`
  - **محفز:** إزالة آخر منتج (أو آخر مجموعة تحتوي منتجات) من مجموعة
  - **رسالة:** لا يمكن حذف آخر منتج في مجموعة. أرشيف المجموعة بدلاً من ذلك.

- `PRODUCT_IS_DELETED`
  - **محفز:** حذف منتج بشكل لطيف
  - **رسالة:** *لا توجد رسالة*

- `PRODUCT_PRICING_MODE_REQUIRED`
  - **محفز:** إضافة أسعار محلية قبل إعداد `pricing_mode` للمنتج
  - **رسالة:** يجب ضبط وضع التسعير المنتج قبل إضافة الأسعار المحلية

- `SLUG_ALREADY_TAKEN`
  - **محفز:** شريط المنتج المطلوب / عنوان URL القصير مستخدم بالفعل
  - **رسالة:** شريط العنوان مأخوذ بالفعل

- `UNABLE_TO_EDIT_PRIMARY_BRAND`
  - **محفز:** محاولة تحديث العلامة التجارية الرئيسية عبر API العادي
  - **رسالة:** لا يمكن تحديث العلامة التجارية الرئيسية عبر نقطة النهاية API هذه.

### الخصومات

- `DISCOUNT_ALREADY_USED_ON_SUBSCRIPTION`
  - **محفز:** إعادة تطبيق خصم تم استخدامه بالفعل في هذا الاشتراك
  - **رسالة:** تم استخدام هذا الخصم بالفعل في هذا الاشتراك

- `DISCOUNT_CODE_ALREADY_EXISTS`
  - **محفز:** إنشاء رمز خصم مكرر
  - **رسالة:** رمز الخصم موجود بالفعل

- `DISCOUNT_CODE_EXPIRED`
  - **محفز:** رمز الخصم تجاوز `expires_at` التاريخ
  - **رسالة:** رمز الخصم منتهي

- `DISCOUNT_CODE_USAGE_LIMIT_EXCEEDED`
  - **محفز:** استخدام الخصم بعد `usage_limit` تم الوصول إليه
  - **رسالة:** لا يمكن أن يكون حد الاستخدام أقل من times_used / تم الوصول إلى حد استخدام رمز الخصم

- `DISCOUNT_NOT_APPLICABLE_TO_NEW_PRODUCT`
  - **محفز:** تغيير الخطة إلى منتج لا ينطبق عليه الخصم الحالي
  - **رسالة:** الخصم غير قابل للتطبيق على منتج الخطة الجديدة

- `DISCOUNT_NOT_AVAILABLE_FOR_ON_DEMAND`
  - **محفز:** رمز مطبق على اشتراك عند الطلب
  - **رسالة:** القسائم الخصم غير متاحة للاشتراكات عند الطلب

- `DISCOUNT_NOT_AVAILABLE_FOR_PRODUCT`
  - **محفز:** رمز مطبق على منتجات غير ذات صلة
  - **رسالة:** القسائم الخصم غير متاحة لهذا المنتج

- `INVALID_DISCOUNT_CODE`
  - **محفز:** الرمز غير موجود / غير قابل للتطبيق
  - **رسالة:** رمز الخصم غير صالح / لا يمكن تطبيق رمز الخصم على أي منتج في السلة

- `INVALID_PERCENTAGE`
  - **محفز:** مبلغ النسبة المئوية > 100% (أو 10,000 نقطة أساس)
  - **رسالة:** لا يمكن أن تكون النسبة المئوية أكثر من 10000 / لا يمكن أن يكون مبلغ رمز الخصم أكثر من 100٪

- `UNSUPPORTED_DISCOUNT_TYPE`
  - **محفز:** الخصومات ذات المبلغ الثابت، إلخ، لم تكن حية بعد
  - **رسالة:** لا يدعم حالياً سوى رموز الخصم النسبي

### مفاتيح الترخيص

- `ACTIVATION_LIMIT_LESS_THAN_CURRENT_AMOUNT`
  - **محفز:** تفعيل مفاتيح الترخيص: الحد الجديد < عدد الحالات الحالي
  - **رسالة:** لا يمكن أن يكون الحد الجديد للتفعيل أقل من العدد الحالي للحالات

- `INACTIVE_LICENSE_KEY`
  - **محفز:** حالة المفتاح ≠ `ACTIVE`
  - **رسالة:** مفتاح الترخيص غير نشط

- `LICENSE_KEY_LIMIT_REACHED`
  - **محفز:** التفعيلات = الحد
  - **رسالة:** تم الوصول إلى حد تفعيل مفتاح الترخيص

- `LICENSE_KEY_NOT_FOUND`
  - **محفز:** معرف الحالة أو معرف المفتاح غير صالح
  - **رسالة:** لم يتم العثور على حالة مفتاح الترخيص أو لا تنتمي لمفتاح الترخيص هذا

- `NO_EXPIRY_ON_SUBSCRIPTION_LICENSE_KEYS`
  - **محفز:** محاولة تعيين انتهاء الصلاحية على مفتاح يستند إلى الاشتراك
  - **رسالة:** لا يمكن تعيين تاريخ انتهاء لمفتاح ترخيص يستند إلى الاشتراك

### الفوترة المستندة إلى الاستخدام والمقاييس

- `DUPLICATE_METER_IDS_IN_REQUEST`
  - **محفز:** يظهر نفس معرف المقياس عدة مرات في الطلب
  - **رسالة:** لا يُسمح بمعرفات المقياس المكررة

- `INVALID_QUANTITY`
  - **محفز:** كمية غير صالحة محددة للأسعار المستندة إلى الاستخدام
  - **رسالة:** يُسمح بكمية واحدة فقط في المنتجات ذات السعر المستند إلى الاستخدام

- `METER_IS_DELETED`
  - **محفز:** محاولة استخدام مقياس محذوف
  - **رسالة:** تم حذف المقياس بالفعل

- `MISSING_METER_IDS`
  - **محفز:** قائمة معرف المقياس فارغة أو تحتوي على معرفات غير صالحة
  - **رسالة:** لا يوجد واحد أو أكثر من معرفات المقياس: {id}

### الفوترة المستندة إلى الائتمان

- `CREDIT_ENTITLEMENT_IS_DELETED`
  - **محفز:** العمل على منحة ائتمان تم حذفها
  - **رسالة:** تم حذف منحة الائتمان بالفعل

- `CREDIT_ENTITLEMENT_NAME_ALREADY_EXISTS`
  - **محفز:** إنشاء منحة ائتمان مع اسم موجود بالفعل
  - **رسالة:** يوجد بالفعل منحة ائتمان بهذا الاسم

- `OVERAGE_LIMIT_EXCEEDED`
  - **محفز:** استخدام أو خصم ائتمان سيتجاوز الحد الأقصى المحدد
  - **رسالة:** تم تجاوز الحد الأقصى

### المحفظة

- `INSUFFICIENT_WALLET_FUNDS`
  - **محفز:** رصيد المحفظة < مبلغ الخصم
  - **رسالة:** ليس لديك أموال كافية بالمحفظة

- `NEGATIVE_BALANCE_ADJUSTMENT`
  - **محفز:** محاولة جعل رصيد المحفظة سالبًا
  - **رسالة:** لا يُسمح بجعل رصيد المحفظة سالبًا

### العملة، الضرائب والمنطقة

- `EXCHANGE_RATE_NOT_FOUND`
  - **محفز:** لا يوجد سعر تحويل لـ `from → to` زوج العملات
  - **رسالة:** لم يتم العثور على سعر التحويل للتحويل من عملة إلى عملة

- `INVALID_TAX_ID`
  - **محفز:** فشل التحقق من صلاحية VAT/GST/TIN
  - **رسالة:** معرف الضريبة غير صالح

- `REQUEST_AMOUNT_BELOW_MINIMUM`
  - **محفز:** المبلغ < الحد الأدنى للمنتج
  - **رسالة:** لا يمكن أن يكون المبلغ أقل من الحد الأدنى المحدد للمنتج

- `TOTAL_PAYMENT_AMOUNT_BELOW_MINIMUM_AMOUNT`
  - **محفز:** إجمالي عربات التسوق المجمعة < الحد الأدنى للبوابة
  - **رسالة:** يتطلب معالجة الدفع مبلغًا أدنى قدره {display_str}

- `UNSUPPORTED_BILLING_CURRENCY`
  - **Trigger:** عملة الفوترة المطلوبة غير مدعومة لهذا الاشتراك
  - **Message:** عملة الفوترة غير USD غير مدعومة للاشتراكات

- `UNSUPPORTED_COUNTRY`
  - **محفز:** الجغرافيا لم تُدعم بعد
  - **رسالة:** البلد {country_name} غير مدعوم حاليًا

- `UNSUPPORTED_CURRENCY`
  - **Trigger:** عملة المنتج أو الإضافة ليست عملة يمكن لـ Dodo Payments تحصيل المدفوعات بها. يمكن تعيين الأسعار الأساسية بأي عملة قابلة للتحصيل، لذا يعني هذا عادةً أن رمز العملة غير صالح أو غير مدعوم بعد.
  - **Message:** العملة غير مدعومة حاليًا / المنتجات المدعومة حاليًا هي USD وINR فقط / العملات المدعومة حاليًا لأسعار الإضافات هي USD وINR فقط / لا يمكن طلب سوى USD أو INR لـ billing_currency / العملة غير مدعومة / عملة غير متوقعة لاشتراكات البطاقات الهندية

- `UNSUPPORTED_TAX_CATEGORY`
  - **محفز:** سلسلة فئة الضرائب غير موجودة في العداد
  - **رسالة:** الفئة {category} غير مدعومة حاليًا

### التحقق من الصحة والطلبات

- `DUPLICATE_LINE_ITEMS_IN_REQUEST`
  - **محفز:** نفس `item_id` ظهر مرتين في `items[]`
  - **رسالة:** تم تحديد معرفات العناصر المكررة في مصفوفة العناصر

- `INVALID_QUERY_PARAMS`
  - **محفز:** معلمات الاستعلام المتنافية / المشوهة
  - **رسالة:** يجب أن تحتوي معلمات الاستعلام على time_frame أو (start, end) فقط

- `INVALID_REQUEST_BODY`
  - **محفز:** JSON مشوه أو انتهاك مخطط
  - **رسالة:** جسم طلبك غير صالح. يرجى التحقق من ترويسة الطلب والكائن.

- `INVALID_REQUEST_PARAMETERS`
  - **محفز:** دلالات خاطئة (على سبيل المثال، التاريخ في الماضي)
  - **رسالة:** لا يمكن تغيير next_billing_date إلى وقت مضى

- `MAXIMUM_KEYS_REACHED`
  - **محفز:** الأفMetadata / الحقول المخصصة تجاوزت 50 زوجًا
  - **رسالة:** تتجاوز 50 زوجًا من القيم الرئيسية

### عام والنظام

- `INTEGER_CONVERSION_FAILURE`
  - **محفز:** أي تحويل عدد صحيح ↔ سلسلة/عشري يفشل على جهة الخادم
  - **رسالة:** فشل تحويل العدد الصحيح

- `INTERNAL_SERVER_ERROR`
  - **محفز:** استثناءات غير محصورة؛ يجب تسجيل التفاصيل على جهة الخادم
  - **رسالة:** *لا توجد رسالة عامة (500 عام)*

- `NOT_FOUND`
  - **محفز:** 404 عام لأي مورد مفقود
  - **رسالة:** لم يتم العثور على العنصر *(أو أكثر تحديدًا)*

- `TOO_MANY_REQUESTS`
  - **محفز:** حد معدل 429
  - **رسالة:** *لا توجد رسائل*

- `UNSUPPORTED_ACTION`
  - **محفز:** إجراء غير مدعوم لنوع المورد
  - **رسالة:** لا يُسمح بتغيير الخطط للاشتراكات المستندة إلى الاستخدام
