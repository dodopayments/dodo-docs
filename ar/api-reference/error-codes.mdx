## نظرة عامة

تستخدم واجهة برمجة تطبيقات مدفوعات دودي رموز الحالة القياسية HTTP ورموز الخطأ المخصصة للإشارة إلى نجاح أو فشل طلبات API. عند حدوث خطأ، تعيد واجهة برمجة التطبيقات رمز حالة HTTP مناسب واستجابة JSON تحتوي على معلومات مفصلة حول الخطأ.

تتضمن كل استجابة خطأ:
- رمز حالة HTTP يشير إلى الفئة العامة للخطأ
- رمز خطأ محدد يحدد الطبيعة الدقيقة للخطأ
- رسالة خطأ قابلة للقراءة البشرية تشرح ما حدث
- تفاصيل إضافية حول الخطأ عند الاقتضاء

فهم هذه الرموز ومعانيها أمر بالغ الأهمية لـ:
- تصحيح مشكلات التكامل
- تنفيذ معالجة الأخطاء بشكل صحيح في تطبيقك
- تقديم ملاحظات ذات مغزى للمستخدمين النهائيين
- الحفاظ على نظام معالجة مدفوعات قوي

تقدم الأقسام التالية معلومات مفصلة حول رموز الحالة القياسية HTTP ورموز الخطأ المحددة التي قد تواجهها عند استخدام واجهة برمجة تطبيقات مدفوعات دودي.

## رموز خطأ API القياسية

| رمز الخطأ | حالة HTTP | الوصف |
|------------|-------------|-------------|
| **400** | طلب غير صحيح | كان الطلب مشوهاً أو يحتوي على معلمات غير صالحة |
| **401** | غير مصرح | فشلت المصادقة أو مفتاح API غير صالح |
| **403** | محظور | مفتاح API ليس لديه إذن للوصول إلى المورد المطلوب |
| **404** | غير موجود | المورد المطلوب غير موجود |
| **405** | طريقة غير مسموح بها | طريقة HTTP غير مدعومة لهذه النقطة النهائية |
| **409** | تعارض | يتعارض الطلب مع الحالة الحالية للمورد |
| **422** | كيان غير قابل للمعالجة | كان الطلب مشكلاً بشكل جيد ولكنه يحتوي على أخطاء دلالية |
| **429** | عدد كبير جداً من الطلبات | تم تجاوز حد المعدل |
| **500** | خطأ في الخادم الداخلي | حدث خطأ غير متوقع على خوادمنا |
| **502** | بوابة غير صالحة | تلقت الخادم استجابة غير صالحة من خادم متقدم |
| **503** | الخدمة غير متاحة | الخدمة غير متاحة مؤقتاً |
| **504** | انتهاء مهلة البوابة | انتهت مهلة الخادم أثناء الانتظار لاستجابة متقدمة |

## تنسيق استجابة الخطأ

عند حدوث خطأ، تعيد واجهة برمجة التطبيقات استجابة JSON بالهيكل التالي:

```json
{
  "code": "UNSUPPORTED_COUNTRY",
  "message": "Country AI currently not supported"
}
```

## مرجع رموز الخطأ

- `ACTIVATION_LIMIT_LESS_THAN_CURRENT_AMOUNT`
  - **Trigger:** تفعيل مفتاح الترخيص: الحد الجديد < عدد الأمثلة الحالي
  - **Message:** يجب ألا يقل الحد الأقصى للتفعيل الجديد عن عدد الأمثلة الحالي

- `ADDONS_IN_USAGE_BASED_BILLING_NOT_SUPPORTED`
  - **Trigger:** محاولة إضافة إضافات للاشتراكات المعتمدة على الاستخدام
  - **Message:** الإضافات في الاشتراكات غير مدعومة للاشتراكات المعتمدة على الاستخدام

- `ADDONS_NOT_ALLOWED_FOR_ON_DEMAND`
  - **Trigger:** محاولة إضافة إضافات للاشتراكات عند الطلب
  - **Message:** الإضافات غير مسموح بها للاشتراكات عند الطلب

- `BRAND_MISMATCH`
  - **Trigger:** تخصيص العناصر في العربة تنتمي إلى علامات تجارية مختلفة
  - **Message:** يجب أن تنتمي جميع العناصر في عربة المنتجات لنفس العلامة التجارية

- `BRAND_NOT_ENABLED`
  - **Trigger:** العلامة التجارية معطلة أو غير نشطة
  - **Message:** العلامة التجارية المقدمة غير مفعلة

- `BRAND_SUBMISSION_NOT_ENABLED`
  - **Trigger:** ميزة إعادة تقديم تحقق العلامة التجارية غير مفعلة
  - **Message:** إعادة تقديم التحقق من العلامة التجارية غير مفعلة

- `CHARGE_NOT_ALLOWED_FOR_SCHEDULED_CANCELLATION`
  - **Trigger:** محاولة فرض رسوم على اشتراك مقرر إلغائه
  - **Message:** الاشتراك مقرر إلغائه

- `CHECKOUT_SESSION_CONSUMED`
  - **Trigger:** تم إنشاء جلسة الخروج سابقًا
  - **Message:** تم استهلاك جلسة الخروج بالفعل

- `DISCOUNT_CODE_ALREADY_EXISTS`
  - **Trigger:** إنشاء رمز خصم مكرر
  - **Message:** رمز الخصم موجود بالفعل

- `DISCOUNT_CODE_EXPIRED`
  - **Trigger:** رمز الخصم بعد تاريخ انتهاء الصلاحية `expires_at`
  - **Message:** رمز الخصمExpired

- `DISCOUNT_CODE_USAGE_LIMIT_EXCEEDED`
  - **Trigger:** إعادة استخدام الخصم بعد وصول الحد الأقصى `usage_limit`
  - **Message:** لا يمكن أن يكون الحد الأقصى للاستخدام أقل من times_used / لقد وصل حد استخدام رمز الخصم

- `DISCOUNT_NOT_AVAILABLE_FOR_ON_DEMAND`
  - **Trigger:** تم تطبيق الرمز على اشتراك عند الطلب
  - **Message:** قسيمة الخصم غير متاحة للاشتراكات عند الطلب

- `DISCOUNT_NOT_AVAILABLE_FOR_PRODUCT`
  - **Trigger:** تم تطبيق الرمز على منتج غير مرتبط
  - **Message:** قسيمة الخصم غير متاحة لهذا المنتج

- `DUPLICATE_LINE_ITEMS_IN_REQUEST`
  - **Trigger:** نفس `item_id` يظهر مرتين في `items[]`
  - **Message:** تم تحديد معرفات عناصر مكررة في مصفوفة العناصر

- `DUPLICATE_METER_IDS_IN_REQUEST`
  - **Trigger:** يظهر نفس معرف العداد عدة مرات في الطلب
  - **Message:** لا يُسمح بمعرفات العداد المكررة

- `EXCHANGE_RATE_NOT_FOUND`
  - **Trigger:** لا توجد سعر صرف لزوج العملات `from → to`
  - **Message:** لم يتم العثور على سعر الصرف للتحويل من العملة إلى العملة

- `EXISTING_REFUND_REQUEST_PROCESSING`
  - **Trigger:** لا تزال طلبات الاسترداد السابقة قيد المعالجة
  - **Message:** طلب الاسترداد بحالة "قيد الانتظار" لا يزال قيد المعالجة

- `INACTIVE_LICENSE_KEY`
  - **Trigger:** حالة المفتاح ≠ `ACTIVE`
  - **Message:** مفتاح الترخيص غير نشط

- `INACTIVE_SUBSCRIPTION_PLAN_CHANGE_NOT_SUPPORTED`
  - **Trigger:** تغيير الخطة على اشتراك غير نشط
  - **Message:** لا يسمح بتغيير الخطط للاشتراكات غير النشطة

- `INSUFFICIENT_WALLET_FUNDS`
  - **Trigger:** رصيد المحفظة < مبلغ الخصم
  - **Message:** لا توجد أموال كافية في المحفظة

- `INTEGER_CONVERSION_FAILURE`
  - **Trigger:** أي تحويل صحيح ↔ سلسلة / عدد عشري يفشل في الخادم
  - **Message:** فشل تحويل كامل

- `INTERNAL_SERVER_ERROR`
  - **Trigger:** استثناءات غير متوقعة؛ يجب عليك تسجيل التفاصيل في الخادم
  - **Message:** *لا توجد رسالة عامة (خطأ 500 عام)*

- `INVALID_DISCOUNT_CODE`
  - **Trigger:** الرمز غير موجود / غير قابل للتطبيق
  - **Message:** رمز الخصم غير صالح / لا يمكن تطبيق رمز الخصم على أي منتج في عربة التسوق

- `INVALID_PERCENTAGE`
  - **Trigger:** مبلغ النسبة > 100% (أو 10,000 نقطة أساس)
  - **Message:** لا يمكن أن يكون مبلغ النسبة أكثر من 10000 / لا يمكن أن يكون مبلغ رمز الخصم أكثر من 100%

- `INVALID_QUANTITY`
  - **Trigger:** كمية غير صالحة محددة للتسعير القائم على الاستخدام
  - **Message:** يُسمح بكمية واحدة فقط في المنتجات التي تعتمد على الأسعار المبنية على الاستخدام

- `INVALID_QUERY_PARAMS`
  - **Trigger:** متغيرات الاستعلام المتعارضة / المعيار غير صالح
  - **Message:** يجب أن تحتوي متغيرات الاستعلام على إما time_frame أو (start, end) فقط

- `INVALID_REQUEST_BODY`
  - **Trigger:** JSON غير صالح أو انتهاك المعيار
  - **Message:** نص الطلب الخاص بك غير صالح. يرجى التحقق من رؤوس الطلب وكائن الطلب.

- `INVALID_REQUEST_PARAMETERS`
  - **Trigger:** معاني خاطئة (على سبيل المثال، تاريخ في الماضي)
  - **Message:** لا يمكن تغيير next_billing_date إلى وقت ماضي

- `INVALID_SUGGESTED_PRICE`
  - **Trigger:** السعر المقدم < الحد الأدنى المسموح به
  - **Message:** لا يمكن أن يكون السعر المقترح أقل من السعر الأدنى. في حالة الدفع كما تريد، يعتبر السعر هو الحد الأدنى المقبول

- `INVALID_TAX_ID`
  - **Trigger:** فشل تحقق VAT/GST/TIN
  - **Message:** الرقم الضريبي غير صالح

- `LICENSE_KEY_LIMIT_REACHED`
  - **Trigger:** التفعيل = الحد
  - **Message:** تم الوصول إلى حد تفعيل مفتاح الترخيص

- `LICENSE_KEY_NOT_FOUND`
  - **Trigger:** معرف الحالة ID أو المفتاح غير صحيح
  - **Message:** لم يتم العثور على حالة مفتاح الترخيص أو لا تنتمي إلى هذا المفتاح

- `LINE_ITEM_FULLY_REFUNDED`
  - **Trigger:** محاولة لاسترداد عنصر مسترد بالكامل
  - **Message:** العنصر {id} تم استرداده بالكامل ولا يمكن استرداده مرة أخرى.

- `LINE_ITEM_NOT_FOUND`
  - **Trigger:** معرف العنصر ليس جزءًا من الدفع المرجعي
  - **Message:** العنصر {id} غير موجود في الدفع

- `LINE_ITEM_PRORATED`
  - **Trigger:** محاولة لاسترداد أو تحديث على سطر مقسم
  - **Message:** لا يمكن استرداد العنصر {id} لأنه مقسم

- `LINE_ITEM_REFUND_AMOUNT_TOO_HIGH`
  - **Trigger:** مبلغ الاسترداد > المبلغ المدفوع (شامل الضريبة)
  - **Message:** مبلغ الاسترداد المطلوب للعنصر {id} بما في ذلك الضريبة هو {amount} والذي يتجاوز المبلغ المدفوع {amount}

- `LINE_ITEM_REFUND_AMOUNT_TOO_LOW`
  - **Trigger:** مبلغ الاسترداد أقل من الحد الأدنى
  - **Message:** مبلغ الاسترداد المطلوب للعنصر {id} هو {amount} وهو منخفض جدًا

- `MAXIMUM_KEYS_REACHED`
  - **Trigger:** تجاوز بيانات التعريف / الحقول المخصصة 50 زوجًا
  - **Message:** يتجاوز 50 زوجًا من القيم المفتاحية

- `MERCHANT_NOT_LIVE`
  - **Trigger:** لا يزال العمل في وضع الاختبار / صندوق الرمل
  - **Message:** التاجر غير نشط

- `METER_IS_DELETED`
  - **Trigger:** محاولة لاستخدام عداد محذوف
  - **Message:** تم حذف العداد بالفعل

- `MISSING_ADDON_IDS`
  - **Trigger:** `addon_id` القائمة فارغة أو معرفات غير معروفة
  - **Message:** لا توجد أو أكثر من معرفات المنتجات: {id}

- `MISSING_METER_IDS`
  - **Trigger:** قائمة معرفات العداد فارغة أو تحتوي على معرفات غير صالحة
  - **Message:** لا توجد أو أكثر من معرفات العداد: {id}

- `MISSING_PRODUCT_INFORMATION`
  - **Trigger:** المنتج موجود ولكن المعلومات الإلزامية مفقودة
  - **Message:** المنتج {id} موجود ولكن المعلومات الإلزامية الأخرى مفقودة أو غير صالحة

- `NEGATIVE_BALANCE_ADJUSTMENT`
  - **Trigger:** محاولة لجعل رصيد المحفظة سالب
  - **Message:** لا يُسمح بجعل رصيد المحفظة سالبًا

- `NO_ELIGIBLE_PAYMENT_METHODS`
  - **Trigger:** بعد التصفية، لا شيء متبقي
  - **Message:** لم يتم العثور على طرق الدفع المؤهلة

- `NO_EXPIRY_ON_SUBSCRIPTION_LICENSE_KEYS`
  - **Trigger:** محاولة لتعيين تاريخ انتهاء الصلاحية على مفتاح قائم على الاشتراك
  - **Message:** لا يمكن تعيين تاريخ انتهاء لصلاحية مفتاح الترخيص القائم على الاشتراك

- `NOT_FOUND`
  - **Trigger:** 404 العامة لأي مصدر مفقود
  - **Message:** العنصر غير موجود *(أو أكثر تحديداً)*

- `ON_DEMAND_PLAN_CHANGE_NOT_SUPPORTED`
  - **Trigger:** لا يسمح بتغيير الخطط للاشتراكات عند الطلب
  - **Message:** تغيير الخطط غير مدعوم للاشتراكات عند الطلب

- `ON_DEMAND_SUBSCRIPTIONS_NOT_ENABLED`
  - **Trigger:** تم إيقاف ميزة العمل
  - **Message:** لا يتم تمكين الاشتراكات عند الطلب لهذا العمل

- `ON_DEMAND_USAGE_BASED_BILLING_NOT_SUPPORTED`
  - **Trigger:** محاولة لاستخدام عند الطلب مع بنية التسعير المعتمدة على الاستخدام
  - **Message:** الاشتراكات عند الطلب غير مدعومة للاشتراكات المعتمدة على الاستخدام

- `PAY_AS_YOU_WANT_AMOUNT_REQUIRED`
  - **Trigger:** السعر مفقود لمنتج PWYW
  - **Message:** المبلغ إلزامي لمنتج الدفع كما تريد

- `PAYMENT_ALREADY_REFUNDED`
  - **Trigger:** استرداد مكرر
  - **Message:** تم استرداد هذا الدفع بالفعل

- `PAYMENT_HAS_BEEN_REFUNDED`
  - **Trigger:** تم استرداد الدفع بالكامل
  - **Message:** تم استرداد معرف الدفع بالكامل.

- `PAYMENT_NOT_SUCCEEDED`
  - **Trigger:** محاولة لاسترداد / معالجة دفع غير ناجح
  - **Message:** الدفع المقدم لم ينجح

- `PLAN_CHANGE_NOT_ALLOWED_FOR_SCHEDULED_CANCELLATION`
  - **Trigger:** تم محاولة تغيير الخطة على اشتراك مقرر إلغائه
  - **Message:** الاشتراك مقرر إلغائه

- `PREVIOUS_PAYMENT_PENDING`
  - **Trigger:** محاولة لإنشاء رسوم بينما السابقة في حالة غير نهائية
  - **Message:** لا يمكن إنشاء رسوم جديدة حيث لم تنجح الدفعة السابقة بعد

- `PRODUCT_CART_EMPTY`
  - **Trigger:** تم تقديم عربة منتجات فارغة
  - **Message:** product_cart فارغ

- `PRODUCT_IS_DELETED`
  - **Trigger:** المنتج محذوف برفق
  - **Message:** *لا توجد رسائل*

- `REFUND_AMOUNT_EXCEEDS_PAID_AMOUNT`
  - **Trigger:** مبلغ الاسترداد الإجمالي > المبلغ المدفوع
  - **Message:** مبلغ الاسترداد المحسوب أكبر من المبلغ المدفوع

- `REFUND_WINDOW_EXPIRED`
  - **Trigger:** خارج نافذة الاسترداد المسموح بها
  - **Message:** لا يمكن تنفيذ الطلبات الاستردادية {days} يومًا بعد إنشاء الدفع. اتصل support@dodopayments.com.

- `REQUEST_AMOUNT_BELOW_MINIMUM`
  - **Trigger:** مبلغ < الحد الأدنى للمنتج
  - **Message:** لا يمكن أن يكون المبلغ أقل من الحد الأدنى المحدد للمنتج

- `SUBSCRIPTION_EXPIRED`
  - **Trigger:** الفواتير في الماضي `ends_at`
  - **Message:** انتهت صلاحيته الاشتراك ولا يمكن إنشاء رسوم جديدة

- `SUBSCRIPTION_INACTIVE`
  - **Trigger:** الحالة ≠ `ACTIVE`
  - **Message:** الاشتراك غير نشط

- `SUBSCRIPTION_NOT_ON_DEMAND`
  - **Trigger:** متوقع عند الطلب ولكن حصل على فترة ثابتة
  - **Message:** الاشتراك ليس عند الطلب بالفعل

- `SUBSCRIPTION_PAYMENT_RETRY_LIMIT_EXCEEDED`
  - **Trigger:** تجاوز محاولات إعادة دفع الاشتراك الحد الأقصى
  - **Message:** تم تجاوز الحد الأقصى لعدد المحاولات البالغ 10 محاولات لهذا الاشتراك

- `TOO_MANY_REQUESTS`
  - **Trigger:** 429 معدل الحد
  - **Message:** *لا توجد رسائل*

- `TOTAL_PAYMENT_AMOUNT_BELOW_MINIMUM_AMOUNT`
  - **Trigger:** يكون المجموع الإجمالي للعربة < الحد الأدنى للبوابة
  - **Message:** يتطلب الحد الأدنى من {display_str} لمعالجة الدفع

- `UNABLE_TO_EDIT_PRIMARY_BRAND`
  - **Trigger:** محاولة لتحديث العلامة التجارية الأساسية عبر واجهة برمجة التطبيقات العادية
  - **Message:** لا يمكن تحديث العلامة التجارية الأساسية عبر نقطة نهاية واجهة برمجة التطبيقات هذه.

- `UNAUTHORIZED`
  - **Trigger:** لا يوجد مفتاح واجهة برمجة التطبيقات أو رمز غير صالح / نطاق
  - **Message:** غير مصرح لك بأداء هذا الإجراء

- `UNSUPPORTED_ACTION`
  - **Trigger:** إجراء غير مدعوم لنوع المورد
  - **Message:** لا يُسمح بتغيير الخطط للاشتراكات المعتمدة على الاستخدام

- `UNSUPPORTED_BILLING_CURRENCY`
  - **Trigger:** الاشتراكات مقيدة بالدولار الأمريكي
  - **Message:** لا يتم دعم العملة الخاصة بالفواتير غير الدولار الأمريكي للاشتراكات

- `UNSUPPORTED_COUNTRY`
  - **Trigger:** حقل غير مدعوم بعد
  - **Message:** البلاد {country_name} غير مدعومة حاليًا

- `UNSUPPORTED_CURRENCY`
  - **Trigger:** currency غير صالح للمنتج أو الإضافات
  - **Message:** العملة غير مدعومة حاليًا / المدعومة حاليًا للمنتجات هي فقط الدولار الأمريكي والروبية الهندية / المدعومة حاليًا للخصومات هي فقط الدولار الأمريكي والروبية الهندية / يمكن طلب العملة الدولار الأمريكي أو الروبية الهندية فقط للفواتير / العملة غير مدعومة / العملة غير متوقعة للاشتراكات بالبطاقات الهندية

- `UNSUPPORTED_DISCOUNT_TYPE`
  - **Trigger:** خصومات المبالغ الثابتة، إلخ، غير مفعلة بعد
  - **Message:** فقط رموز الخصم النسبية مدعومة حاليًا

- `UNSUPPORTED_PAYMENT_CURRENCY`
  - **Trigger:** العملة المدفوعة محظورة للموصل
  - **Message:** معاملات الروبية الهندية غير مدعومة لهذه المعاملة

- `UNSUPPORTED_TAX_CATEGORY`
  - **Trigger:** سلسلة فئة الضريبة ليست في التعداد
  - **Message:** الفئة {category} غير مدعومة حاليًا

- `UNSUCCESSFUL_PAYMENT_ID`
  - **Trigger:** يشار لمعرف الدفع إلى دفع غير ناجح
  - **Message:** معرف الدفع له حالة غير ناجحة.

- `ZERO_AMOUNT_PAYMENT_REFUND_NOT_ALLOWED`
  - **Trigger:** محاولة لاسترداد الدفع بمبلغ صفري
  - **Message:** لا يمكن استرداد دفع بمبلغ صفري

## أفضل الممارسات

1. تعامل دائماً مع الأخطاء بشكل لطيف في تطبيقك
2. نفذ تسجيل الأخطاء بشكل صحيح
3. استخدم رسائل خطأ مناسبة للمستخدمين النهائيين
4. نفذ منطق إعادة المحاولة للأخطاء العابرة
5. اتصل بالدعم لحل المشكلات غير المحلولة
