<Warning>
**واجهة برمجة تطبيقات مهملة**: يتم الآن إدارة مفاتيح الترخيص من خلال نظام [Entitlements](/features/entitlements/introduction). قم بتكوين حدود ومدة التنشيط على [استحقاق مفتاح الترخيص](/api-reference/entitlements/update-entitlement)، واستخدم [إلغاء المَنْح](/api-reference/entitlements/revoke-grant) لتعطيل مفتاح العميل. سيتم إزالة هذه النقطة الطرفية في إصدار مستقبلي.
</Warning>

<Info>
تحديث مفتاح الترخيص من خلال واجهة برمجة التطبيقات لا يؤدي إلى إرسال إشعارات بريد إلكتروني إلى العميل.
</Info>
