<Info>
تستورد نقطة النهاية هذه مفتاحًا لديك بالفعل — `key` و`customer_id` و`product_id` كلها مطلوبة. ولا تنشئ قيمة مفتاح لك. ويؤدي استيراد `key` موجود بالفعل إلى إرجاع `409 Conflict`.
</Info>

<Info>
لا تؤدي مفاتيح الترخيص التي يتم إنشاؤها أو تحديثها من خلال API إلى إرسال إشعارات بريد إلكتروني إلى العملاء. إذا كنت بحاجة إلى إخطار العملاء بشأن مفتاح الترخيص الخاص بهم، فيجب عليك معالجة ذلك بشكل منفصل في تطبيقك.
</Info>
