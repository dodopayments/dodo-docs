<Info>
استخدم نقطة النهاية هذه فقط للمنح المُنشأة بموجب استحقاق License Key مع `fulfillment_mode: manual`. يجب أن يكون المنح في حالة `Pending` من دون إرفاق أي مفتاح. راجع [التنفيذ اليدوي](/features/license-keys#manual-fulfillment) و[دليل تكامل التنفيذ اليدوي لمفتاح الترخيص](/developer-resources/manual-license-key-fulfillment) للاطلاع على التدفق الكامل.
</Info>
