إزالة طريقة دفع محفوظة من حساب العميل. استخدم هذا لتنظيف طرق الدفع القديمة أو غير المرغوب فيها.

<Warning>
لا يمكنك حذف طريقة دفع قيد الاستخدام من قِبل اشتراك نشط. تُرجع API القيمة `409 Conflict` مع `Payment method is in use by an active subscription`. انقل الاشتراك إلى طريقة دفع أخرى أولًا باستخدام [تحديث طريقة الدفع](/api-reference/subscriptions/update-payment-method)، ثم احذف الطريقة القديمة.
</Warning>

يُرجع الحذف الناجح `204 No Content`.

## حالات الاستخدام

- **طلب العميل**: إزالة طريقة دفع لم يعد العميل يريد الاحتفاظ بها
- **البطاقات منتهية الصلاحية**: تنظيف طرق الدفع التي تحتوي على تفاصيل بطاقات منتهية الصلاحية
- **الأمان**: إزالة طرق الدفع المخترقة فورًا
