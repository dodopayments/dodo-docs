## مقدمة

[ParityDeals](https://www.paritydeals.com/) منصة تعرض لافتات خصم مستندة إلى الموقع للزوار المؤهلين على موقعك الإلكتروني، وتنشئ تلقائيًا رموز الخصم المطابقة في Dodo Payments. عندما يرى الزائر اللافتة، يحصل على رمز يمكنه استخدامه عند إتمام الدفع. تظهر هذه الرموز في لوحة تحكم Dodo Payments ضمن **المبيعات ← الخصومات**.

<Note>
توفّر Dodo Payments ميزة [تعادل القوة الشرائية](/features/purchasing-power-parity) الأصلية، التي تخفّض الأسعار حسب البلد عند إتمام الدفع من دون لافتة أو script. تناسب ParityDeals التجار الذين يرغبون في عرض لافتة خصم واضحة على موقعهم، أو الذين يريدون تشغيل عروض موسمية وعروض محددة بوقت.
</Note>

## آلية العمل

تكتشف ParityDeals موقع الزائر، وتعرض له لافتة خصم قابلة للتخصيص على موقعك الإلكتروني، وتنشئ رمز خصم يمكنه تطبيقه عند إتمام الدفع. يُنشأ الرمز تلقائيًا في حسابك على Dodo Payments، ويعمل على المنتجات التي تضبطها.

1. يزور أحد الأشخاص موقعك الإلكتروني، وتكتشف ParityDeals موقعه.
2. إذا كان الزائر مؤهلًا للحصول على خصم، تظهر لافتة تتضمن رمزًا مستندًا إلى الموقع.
3. يستخدم الزائر الرمز عند إتمام الدفع، وتطبّق Dodo Payments الخصم.
4. يظهر الرمز في لوحة التحكم ضمن **المبيعات ← الخصومات**.

## ParityDeals مقابل PPP الأصلي

يُعد تعادل القوة الشرائية الأصلي الطريقة الموصى بها لتسعير المنتجات حسب البلد. اختر ParityDeals عندما تحتاج تحديدًا إلى لافتة خصم على موقعك، أو إلى حملات موسمية وعروض محددة بوقت.

| | PPP الأصلي | ParityDeals |
| :--- | :--- | :--- |
| آلية العمل | نسبة مئوية لكل بلد، تُطبّق عند إتمام الدفع | نسبة مئوية من الخصم، تُطبّق من خلال رمز |
| مكان الضبط | مدمج في Dodo Payments | لوحة تحكم ParityDeals |
| لافتة أو script على موقعك | غير مطلوب | مطلوب |
| العروض الموسمية والمحددة بوقت | لا | نعم |
| الأنسب لـ | أسعار صحيحة من دون إجراء تغييرات على الموقع | اللافتات الترويجية والعروض الموسمية |

<Info>
لا يمكنك تضمين لافتة ParityDeals في صفحة إتمام الدفع أو المتجر المستضافَين على Dodo Payments، لأن custom scripts غير مدعومة هناك. يجب وضع اللافتة على موقعك الإلكتروني أو تطبيقك.
</Info>

## المتطلبات الأساسية

قبل إعداد هذا التكامل، تأكد من توفر ما يلي:

1. [حساب Dodo Payments](https://app.dodopayments.com)
2. [حساب ParityDeals](https://app.paritydeals.com/)
3. Dodo Payments API key

## البدء

<Steps>
  <Step title="Sign up on ParityDeals">
    انتقل إلى [app.paritydeals.com](https://app.paritydeals.com/) وأنشئ حسابًا.
  </Step>

  <Step title="Create Deals">
    بعد تسجيل الدخول، ابحث عن خيار إنشاء العروض. من القائمة المنسدلة، اختر **"Create Deals via Dodo Payments"**.

    <Frame>
      <img src="/images/integrations/paritydeals/create-deals.png" alt="إنشاء العروض من خلال Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    سجّل الدخول إلى **لوحة تحكم Dodo Payments** وانتقل إلى **Developers ← API Keys**. انقر على **"Create New API"**.

    <Tip>
      سمِّ API key اسمًا وصفيًا (مثل 'ParityDeals') حتى تتمكن من التعرف عليه لاحقًا.
    </Tip>

    <Frame>
      <img src="/images/integrations/paritydeals/api-key.png" alt="إنشاء API key جديد في Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    انسخ API key الذي أنشأته والصقه في واجهة ParityDeals لإنشاء الاتصال بحسابك على Dodo Payments.

    <Frame>
      <img src="/images/integrations/paritydeals/connect-api-key.png" alt="توصيل API key بـ ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    بعد الاتصال، ستجلب ParityDeals كتالوج منتجاتك من Dodo Payments. حدّد المنتجات التي تريد ربطها بعروضك.

    <Frame>
      <img src="/images/integrations/paritydeals/select-products.png" alt="اختيار المنتجات لـ ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    أدخل عنوان URL لموقعك الإلكتروني، ويمكنك اختياريًا تحديد صفحات مستهدفة بعينها حيث يجب أن تظهر لافتة الخصم. ثم اختر نوع العرض المفضل لديك:
    - العروض المستندة إلى الموقع
    - العروض الموسمية
    - العروض الخاطفة المحددة بوقت

    <Frame>
      <img src="/images/integrations/paritydeals/deal-settings.png" alt="ضبط إعدادات العرض" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    حدّد البلدان التي تريد تقديم خصومات محلية إليها، وعرّف نسبة الخصم لكل بلد. توفّر ParityDeals إعدادات افتراضية موصى بها يمكنك تعديلها حسب الحاجة.

    <Frame>
      <img src="/images/integrations/paritydeals/country-rules.png" alt="ضبط قواعد الخصم حسب البلد" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    صمّم لافتة الخصم من خلال تخصيص النص، واختيار الألوان والتخطيط، وتحديد موضع اللافتة (في أعلى الصفحة أو أسفلها). ستُعرض هذه اللافتة للزوار المؤهلين استنادًا إلى القواعد التي ضبطتها.

    <Frame>
      <img src="/images/integrations/paritydeals/customize-banner.png" alt="تخصيص لافتة الخصم" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    بعد حفظ العرض، ستنشئ ParityDeals script. أضف هذا script إلى شفرة موقعك الإلكتروني (عادةً في قسم `<head>`). يكتشف هذا script مواقع الزوار تلقائيًا ويعرض لافتة الخصم المناسبة.

    <Frame>
      <img src="/images/integrations/paritydeals/script.png" alt="script تكامل ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>
