## المقدمة

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) هي منصة تنشئ قسائم خصم Purchasing Power Parity المستندة إلى الموقع وتزامنها مع حسابك في Dodo Payments. وهي تدعم منتجات الدفع لمرة واحدة ومنتجات الاشتراكات، وتنشئ رموز خصم تلقائيًا وتدوّرها وفق جدول زمني تحدده.

  <img src="/images/integrations/evendeals/hero.png" alt="نظرة عامة على تكامل Evendeals مع Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />

<Note>
يقدّم Dodo Payments ميزة Purchasing Power Parity الأصلية [Purchasing Power Parity](/features/purchasing-power-parity)، التي تخفّض الأسعار حسب الدولة عند الدفع من دون لافتة أو script أو رموز قسائم يجب إدارتها. أما Evendeals فهي مخصصة للتجّار الذين يريدون تحديدًا أسلوب رموز الخصم مع التدوير التلقائي للقسائم.
</Note>

## آلية العمل

تتصل Evendeals بحسابك في Dodo Payments عبر API key. بعد الاتصال، يمكنك ضبط نسب الخصم لكل مجموعة من الدول. ثم تنشئ Evendeals رموز خصم في حسابك على Dodo Payments تلقائيًا وتدوّرها وفق جدول زمني تحدده (حسب الفاصل الزمني أو عدد مرات الاسترداد أو عدد مرات العرض) لمنع إساءة الاستخدام.

## Evendeals مقارنةً بـ Native PPP

تُعد Purchasing Power Parity الأصلية الطريقة الموصى بها للتسعير حسب الدولة، لأنها لا تحتاج إلى رموز قسائم ولا يمكن مشاركتها أو إساءة استخدامها. اختر Evendeals عندما تريد تحديدًا استخدام أسلوب رموز الخصم.

| | Native PPP | Evendeals |
| :--- | :--- | :--- |
| آلية العمل | نسبة مئوية لكل دولة، تُطبّق عند الدفع | نسبة مئوية مخفّضة، تُطبّق عبر رمز |
| مكان الإعداد | مضمّنة في Dodo Payments | لوحة تحكم Evendeals |
| الحاجة إلى لافتة أو script | غير مطلوبة | غير مطلوبة |
| تدوير القسائم / التحديث التلقائي | غير منطبق | نعم |
| دعم الاشتراكات | نعم | نعم |
| الأنسب لـ | أسعار صحيحة من دون تغييرات على الموقع | أسلوب رموز الخصم مع التدوير التلقائي |

## الميزات الرئيسية

- **المزامنة التلقائية للقسائم** — يتم إنشاء القسائم وإدارتها في Dodo Payments تلقائيًا
- **الخصومات النسبية** — قدّم خصومات مئوية لكل مجموعة من الدول
- **دعم الاشتراكات** — تُطبّق الخصومات عبر دورات فوترة الاشتراك
- **قواعد التحديث التلقائي** — دوّر رموز القسائم تلقائيًا حسب الفاصل الزمني أو عدد مرات الاسترداد أو عدد مرات العرض لمنع إساءة الاستخدام

<Info>
ستظهر رموز الخصم التي تنشئها Evendeals تلقائيًا في لوحة تحكم Dodo Payments ضمن **Sales → Discounts**.
</Info>

## المتطلبات الأساسية

قبل إعداد هذا التكامل، تأكد من توفر ما يلي:

1. [حساب Dodo Payments](https://app.dodopayments.com)
2. [حساب Evendeals](https://www.evendeals.com/signin)
3. Dodo Payments API key

## البدء

<Steps>
  <Step title="Create a Dodo Payments API Key">
    في لوحة تحكم Dodo Payments، انتقل إلى **Developers → API Keys** وانقر على **Create New API**. سمّه تسمية واضحة (مثل "Evendeals") حتى تتمكن من التعرّف عليه لاحقًا.
  </Step>

  <Step title="Connect in Evendeals">
    في [لوحة تحكم Evendeals](https://www.evendeals.com/signin)، انتقل إلى **Integrations**، وابحث عن بطاقة Dodo Payments، ثم الصق API key الخاص بك.
  </Step>

  <Step title="Configure Regional Discounts">
    اضبط نسب الخصم لكل مجموعة من الدول وانقر على المزامنة. ستنشئ Evendeals القسائم في Dodo Payments تلقائيًا.

    <Check>
    بعد المزامنة، افتح **Sales → Discounts** في لوحة تحكم Dodo Payments للتأكد من ظهور القسائم التي تم إنشاؤها. سيحمل كلٌّ منها بادئة Evendeals واضحة.
    </Check>
  </Step>
</Steps>
