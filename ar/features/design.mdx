<Info>
صفحة التصميم هي مركزك الرئيسي لإضفاء هوية علامتك التجارية على كل واجهة موجّهة للعملاء: checkout وstorefront وCustomer Portal. تُطبَّق التغييرات فورًا على الواجهات الثلاث جميعها، وتتم معاينتها في الوقت الفعلي قبل الحفظ. يحتفظ Test mode وlive mode بتصميمات منفصلة — راجع [نسخ التصميم من Test mode إلى live mode](#copy-design-from-test-to-live-mode).
</Info>

## أبرز النقاط

1. **مركز تصميم موحّد** - اضبط مظهر checkout وstorefront وCustomer Portal من صفحة واحدة.
2. **سمات جاهزة مسبقًا** - ابدأ بسمة منتقاة وخصّصها وفقًا لاحتياجاتك.
3. **الوضع الفاتح والداكن** - حدّد لوحات ألوان منفصلة لكل وضع.
4. **معاينة مباشرة** - اطّلع على شكل تغييراتك في checkout وCustomer Portal وstorefront قبل الحفظ.
5. **تجاوزات لكل قسم** - اضبط الأقسام الفردية بدقة (checkout وstorefront وCustomer Portal) من دون التأثير في الأقسام الأخرى.
6. **تحكم برمجي** - تجاوز السمات في checkout عبر API أو Checkout SDK.
7. **نسخ تصميم Test mode إلى live mode** - انقل تصميمًا أتقنته في Test mode إلى live mode بخطوة واحدة.

## للبدء

انتقل إلى **الإعدادات → التصميم** في لوحة التحكم الخاصة بالتاجر. تحتوي صفحة التصميم على أربعة علامات تبويب:

| التبويب | الغرض |
|-----|---------|
| **عام** | اسم العمل، الشعار، اختيار الثيم، والإعدادات المتقدمة العامة |
| **الدفع** | تجاوز إعدادات الثيم تحديدًا لصفحة الدفع |
| **المتجر** | تجاوز إعدادات الثيم وضبط تخطيط المتجر |
| **بوابة العملاء** | تجاوز إعدادات الثيم لبوابة العملاء |

## الإعدادات العامة

يتحكم تبويب **عام** في هوية علامتك التجارية الأساسية والثيم العام.

  <img src="/images/design/general-advanced-settings.jpg" alt="علامة التبويب العامة تعرض الإعدادات المتقدمة مع تكوين الطباعة، الألوان، والحدود" style={{ maxHeight: '500px', width: 'auto' }} />

### التهيئة الأساسية

| الإعداد | الوصف |
|---------|-------------|
| **اسم العمل** | الاسم المعروض في صفحة الدفع، المتجر، وبوابة العملاء |
| **شعار العمل** | شعار علامتك التجارية المعروض عبر جميع الصفحات التي يراها العميل |
| **الثيم** | اختر ثيمًا جاهزًا كنقطة بداية |

### الإعدادات المتقدمة

افتح **الإعدادات المتقدمة** للوصول إلى عناصر التحكم الدقيقة:

<Frame>
  <img src="/images/design/general-color-settings.jpg" alt="الإعدادات المتقدمة الموسعة التي تعرض التكوين الكامل للألوان للوضعين الفاتح والداكن" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### الطباعة

| الإعداد | الخيارات | الوصف |
|---------|---------|-------------|
| **الخط الأساسي** | أي خط من Google Font | الخط الرئيسي للعناوين والنصوص |
| **الخط الثانوي** | أي خط من Google Font | خط تمييزي للعناوين الفرعية والنصوص الثانوية |
| **حجم الخط** | `xs`، `sm`، `md`، `lg`، `xl`، `2xl` | حجم الخط الأساسي العام |
| **وزن الخط** | `normal`، `medium`، `bold`، `extraBold` | وزن الخط الافتراضي |

#### تكوين الألوان

حدد لوحات ألوان منفصلة لـ **الوضع الفاتح** و**الوضع الداكن**. يدعم كل وضع الخصائص التالية:

| الخاصية | الوصف |
|----------|-------------|
| **الخلفية الأساسية** | لون الخلفية الرئيسي |
| **الخلفية الثانوية** | الخلفية الثانوية (التبويبات، البطاقات) |
| **النص الأساسي** | لون النص الرئيسي |
| **النص الثانوي** | لون النص الخافت |
| **زر أساسي** | خلفية الزر الأساسي |
| **نص الزر الأساسي** | لون النص في الأزرار الأساسية |
| **زر ثانوي** | خلفية الزر الثانوي |
| **نص الزر الثانوي** | لون النص في الأزرار الثانوية |
| **الحد الأساسي** | لون الحد الرئيسي |
| **الحد الثانوي** | لون الحد التمييزي |

#### الحدود

| الإعداد | الوصف |
|---------|-------------|
| **نصف قطر الحدود** | يتحكم في إنحناء الحقول، الأزرار، التبويبات، والبطاقات (مثلاً `0` للحواف الحادة، `8px` للحواف المستديرة، `16px` للشكل الكبسولي) |

## تجاوزات لكل قسم

يتضمن كل تبويب قسم (الدفع، المتجر، بوابة العملاء) مفتاح تبديل **تجاوز الثيم**. عند التفعيل، يمكنك تخصيص مظهر ذلك القسم بشكل مستقل عن الثيم العام.

### تبويب الدفع

<Frame>
  <img src="/images/design/checkout-tab.jpg" alt="علامة تبويب الدفع تعرض معاينة كاملة لعملية الدفع مع تفاصيل المنتج ونموذج الدفع" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

تجاوز الطباعة، الألوان، وإعدادات الحدود خصيصًا لتجربة الدفع. تعرض المعاينة الحية:
- معلومات المنتج والأسعار
- خيارات الدفع السريعة (Apple Pay، Google Pay)
- اختيار وسيلة الدفع ونموذج البطاقة
- إدخال كود الخصم وتفصيل الأسعار

### تبويب المتجر

<Frame>
  <img src="/images/design/storefront-tab.jpg" alt="علامة تبويب الواجهة الأمامية تعرض عنوان URL الخاص بالمتجر، عناصر التحكم في العلامة التجارية، ومعاينة الواجهة الأمامية" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

اضبط إعدادات خاصة بالمتجر:

| الإعداد | الوصف |
|---------|-------------|
| **عنوان المتجر** | عنوان متجرك (مثلاً `store.dodopayments.com/your-store`) |
| **اسم المتجر** | فعّل وعيّن الاسم المعروض في المتجر |
| **شعار المتجر** | فعّل ورفع شعار لرأس المتجر |
| **لافتة المتجر** | فعّل ورفع صورة لافتة |
| **وصف المنتج** | فعّل لعرض أو إخفاء أوصاف المنتجات على البطاقات |
| **تجاوز الثيم** | فعّل لتخصيص الطباعة، الألوان، والحدود للمتجر فقط |

### تبويب بوابة العملاء

<Frame>
  <img src="/images/design/customer-portal-tab.jpg" alt="علامة تبويب بوابة العملاء تعرض إدارة الاشتراك، تاريخ الفواتير، ومعاينة طرق الدفع" style={{ maxHeight: '500px', width: 'auto' }} />

تجاوز الثيم لبوابة العملاء، التي تشمل:

- طرق الدفع
- المحفظة والرصيد

## نسخ التصميم من Test mode إلى live mode

يحتفظ Test mode وlive mode بإعدادات تصميم منفصلة، لذلك لا يظهر تلقائيًا للعملاء الحقيقيين أي تصميم تنشئه أثناء الاختبار. وبدلًا من إعادة إنشائه يدويًا، انسخ تصميمك من Test mode إلى live mode بخطوة واحدة.

تتضمن عملية النسخ **جميع أسطح التصميم** — الإعدادات العامة، وcheckout، وCustomer Portal، وتجاوزات storefront — إلى جانب هوية علامتك التجارية في storefront.

<Warning>
تؤدي عملية النسخ إلى استبدال تصميم live mode الحالي. راجع checkout وstorefront في live mode بعد النسخ للتأكد من أن كل شيء يظهر بالشكل المتوقع.
</Warning>
