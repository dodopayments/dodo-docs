## العملة التكيفية

تسمح العملة التكيفية للعملاء بالدفع بعملتهم المحلية المفضلة، مما يعزز الثقة ومعدلات التحويل.

### كيف تعمل

1. **تفعيل**: قم بتفعيل العملة التكيفية من إعدادات عملك
2. **اختيار**: يمكن للعملاء تبديل العملات مباشرة عند الدفع
3. **تحويل**: يتم تحويل الأسعار ديناميكيًا باستخدام أسعار الصرف الفورية
4. **عرض**: يتم عرض المبلغ النهائي المستحق بشفافية قبل الدفع

تدعم مدفوعات دودي لغات متعددة في صفحة الدفع، مما يسمح للعملاء بإكمال المدفوعات بلغة يشعرون بالراحة بها.

- محدد اللغة متاح مباشرة عند الدفع

## حساب الضرائب التلقائي

يتم حساب الضرائب تلقائيًا بناءً على موقع الفوترة الخاص بالعميل، مما يضمن الامتثال لمتطلبات ضريبة السلع والخدمات (GST) والضريبة على القيمة المضافة (VAT) ومتطلبات ضريبة المبيعات بدون إعداد يدوي.

### كيف يعمل حساب الضرائب

<Steps>
<Step title="اكتشاف الموقع">
  يتم تطبيق قواعد الضرائب بناءً على بلد العميل (والمنطقة عند الاقتضاء).
</Step>

<Step title="التحديثات الديناميكية">
  يتحدث مبلغ الضريبة تلقائيًا عندما:
  - يتغير البلد
  - يتم تحديث العنوان
</Step>

<Step title="عرض شفاف">
  يتم عرض تفاصيل الضريبة النهائية بوضوح قبل الدفع.
</Step>
</Steps>

<Tip>
حساب الضريبة مؤتمت بالكامل. لا حاجة لتكوين يدوي للسلع الرقمية القياسية ومنتجات SaaS.
</Tip>

## دعم رقم ضريبة الأعمال

بالنسبة للشركات المسجلة، يسمح الخروج للعملاء بإدخال رقم ضريبة الأعمال الخاص بهم (على سبيل المثال، رقم الضريبة على القيمة المضافة/ضريبة السلع والخدمات).

### ماذا يحدث عند إدخال رقم ضريبة

- يتم التحقق من أهلية الضريبة في الوقت الحقيقي
- يتم تطبيق الإعفاءات الضريبية أو قواعد التحويل المعمول بها
- يتحدث مبلغ الضريبة على الفور عند الدفع

  <img src="/images/checkout/c3.png" alt="إدخال رقم ضريبة الأعمال في الدفع" style={{ width: '70%' }}/>

<Info>
هذا المفهوم مفيد بشكل خاص لخدمات SaaS وB2B حيث قد يكون العملاء التجاريون مؤهلين للإعفاءات الضريبية.
</Info>

## رموز الخصم

يمكن للعملاء تطبيق رموز الخصم أو الترويج التي قمت بإنشائها في لوحة التحكم مباشرة على صفحة الدفع.

### تجربة الدفع

1. يدخل العميل رمز الخصم
2. يتم التحقق من الخصم على الفور
3. يتم عرض السعر المحدث والتوفير بوضوح

<Frame>
  <img src="/images/checkout/c4.png" alt="إدخال رمز الخصم في الدفع" style={{ width: '70%' }}/>
</Frame>

### تكامل API

يمكنك تطبيق رمز خصم مسبقًا أو تمكين حقل إدخال الخصم:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  discount_code: 'WELCOME20', // Pre-apply a code
  feature_flags: {
    allow_discount_code: true // Show discount input field
  },
  return_url: 'https://yoursite.com/return'
});
```

## جمع العناوين الذكي

تدعم صفحة الدفع إدخال عناوين مرنة لإنجاز أسرع.

### الخيارات المتاحة

| الخيار | الوصف |
|--------|-------------|
| **ملء عنوان جوجل التلقائي** | اختيار سريع مع الإكمال التلقائي |
| **إدخال يدوي** | السيطرة الكاملة لعناوين كاملة |
| **اختيار البلد** | يقود المنطق الضريبي والامتثال |

<Tip>
توازن جمع العناوين بين السرعة والدقة والتغطية العالمية لتعظيم التحويل مع ضمان الامتثال.
</Tip>

## الحقول المخصصة

اجمع معلومات إضافية من العملاء أثناء الدفع من خلال تعريف حقول النماذج المخصصة. يكون هذا مفيدًا لجمع بيانات مثل اسم الشركة، حجم الفريق، مصدر الإحالة، أو أي معلومات خاصة بالأعمال الأخرى.

### أنواع الحقول المتاحة

| النوع | الوصف |
|------|-------------|
| `text` | إدخال نص بخط واحد |
| `number` | إدخال رقمي |
| `email` | عنوان بريد إلكتروني مع التحقق |
| `url` | عنوان URL مع التحقق |
| `date` | اختيار تاريخ |
| `dropdown` | اختيار من خيارات محددة مسبقًا |
| `boolean` | تبديل نعم/لا |

### مثال

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
تتضمن ردود العملاء تلقائيًا في حزم الويب (`payment.succeeded`، `subscription.created`) وفي ردود API عبر مصفوفة `custom_field_responses`. يمكنك تعريف ما يصل إلى 5 حقول مخصصة لكل جلسة دفع.
</Info>

  لمعرفة المزيد حول تكوين الحقول المخصصة والوصول إلى الردود.

## سياسة الخصوصية وقبول الشروط

لضمان الشفافية القانونية والامتثال:

- روابط [سياسة الخصوصية](https://dodopayments.com/privacy-policy) و[شروط المشتري](https://dodopayments.com/buyer-terms) تعرض بوضوح على صفحة الدفع
- يعترف العملاء صراحةً بهذه قبل إتمام الدفع

<Info>
يساعد هذا في تلبية متطلبات حماية المستهلك العالمية ومتطلبات خصوصية البيانات بما في ذلك الامتثال لـ GDPR.
</Info>

## الدفع من خلال المجموعات

تمكن مجموعات المنتجات تجربة دفع موحدة حيث يمكن للعملاء عرض واختيار من عدة منتجات ذات صلة (مثل خطط ستيتر، برو، مؤسسات) في عملية دفع واحدة.

### كيف تعمل

1. **عرض جميع المنتجات**: يرى العملاء كل منتج نشط في المجموعة
2. **تم اختيار أول منتج مسبقًا**: يتم اختيار أول منتج في المجموعة تلقائيًا
3. **مقارنة الخيارات**: يمكن للعملاء مقارنة الأسعار والميزات قبل الاختيار
4. **اختيار فردي**: بعد اختيار منتج، تستمر عملية الدفع بمجرى الدفع القياسي

### إنشاء دفع من خلال مجموعة

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
عند استخدام `product_collection_id`، مرر مصفوفة فارغة `product_cart`. لا يمكن تطبيق رموز الخصم مسبقًا عند إنشاء الجلسة.
</Warning>

## تكوين جلسة الدفع

تحكم في سلوك الدفع باستخدام Checkout Sessions API:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_code: 'PROMO10',
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
بعد الدفع، يتم توجيه العملاء إلى `return_url` مع إضافة معلمات الاستعلام تلقائيًا -- بما في ذلك `payment_id` أو `subscription_id` و`status` و`email` و`license_key` (إذا كان مناسبًا). راجع [دليل جلسات الدفع](/developer-resources/checkout-session#request-body) للحصول على القائمة الكاملة.
</Info>

## تخصيص موضوع الدفع

قم بتخصيص مظهر صفحة الدفع ليتناسب مع علامتك التجارية باستخدام معلمة `customization.theme_config` عند إنشاء جلسة دفع عبر API. قم بتكوين الألوان والخطوط ونصف قطر الزوايا ونص الزر لوحدات الضوء والظلام.

<Frame>
  <img src="/images/checkout/theme-example.png" alt="صفحة دفع بتصميم مخصص"/>
</Frame>

<Info>
يتناول هذا القسم تكوين الموضوع من خلال API من جانب الخادم باستخدام `customization.theme_config`. إذا كنت تستخدم **Checkout SDK** (الدفع المنبثق أو الدفع المباشر)، انظر أقسام تخصيص الموضوع في [Overlay Checkout](/developer-resources/overlay-checkout#theme-customization) أو [Inline Checkout](/developer-resources/inline-checkout#theme-customization) والتي تستخدم خصائص camelCase (مثل `bgPrimary` بدلاً من `bg_primary`).
</Info>

### خيارات تكوين الموضوع

| الخاصية | الوصف |
|----------|-------------|
| `light` | تكوين اللون لوضع الضوء |
| `dark` | تكوين اللون لوضع الظلام |
| `font_primary_url` | عنوان URL للخط الرئيسي |
| `font_secondary_url` | عنوان URL للخط الثانوي |
| `font_size` | حجم الخط: `xs`، `sm`، `md`، `lg`، `xl`، `2xl` |
| `font_weight` | وزن الخط: `normal`، `medium`، `bold`، `extraBold` |
| `radius` | نصف قطر الزاوية لعناصر واجهة المستخدم (مثل `4px`، `0.5rem`، `8px`) |
| `pay_button_text` | نص مخصص لزر الدفع (مثل "إتمام الشراء"، "اشترك الآن") |

### تكوين الألوان (الوضع الضوئي/الداكن)

يدعم كل وضع (`light` و `dark`) خصائص اللون التالية:

| الخاصية | الوصف |
|----------|-------------|
| `bg_primary` | لون الخلفية الرئيسي |
| `bg_secondary` | لون الخلفية الثانوي |
| `text_primary` | لون النص الرئيسي |
| `text_secondary` | لون النص الثانوي |
| `text_placeholder` | لون نص العنصر النائب |
| `text_error` | لون نص الخطأ |
| `text_success` | لون نص النجاح |
| `border_primary` | لون الحدود الرئيسي |
| `border_secondary` | لون الحدود الثانوي |
| `button_primary` | لون خلفية الزر الرئيسي |
| `button_primary_hover` | لون تمرير الزر الرئيسي |
| `button_secondary` | لون خلفية الزر الثانوي |
| `button_secondary_hover` | لون تمرير الزر الثانوي |
| `button_text_primary` | لون نص الزر الرئيسي |
| `button_text_secondary` | لون نص الزر الثانوي |
| `input_focus_border` | لون الحدود عند التركيز |

<Info>
تقبل جميع حقول الألوان تنسيقات لون CSS القياسية:
- Hex: `#fff`، `#ffffff`، `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`، `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`، `hsla(120, 100%, 50%, 0.5)`
- الألوان المسماة: `red`، `blue`، `transparent`
</Info>

### مثال

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
لا تحتاج إلى تحديد جميع خصائص الألوان. ستستخدم أي خصائص غير محددة القيم الافتراضية للموضوع.
</Tip>
