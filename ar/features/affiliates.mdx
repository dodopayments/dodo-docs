## المقدمة

يوضح لك هذا الدليل كيفية تتبّع إحالات المسوقين بالعمولة، والتعامل مع أحداث العمولات، وزيادة إيراداتك من خلال شراكات موثوقة في مجال التسويق بالعمولة عبر Dodo Payments. نوفر تكاملات مع منصات التسويق بالعمولة الرائدة، بما في ذلك **Affonso** و**Dub Partners** و**Rekomi**، لمساعدتك على إدارة برامج التسويق بالعمولة وتتبعها بسلاسة.

## خيارات التكامل

يتكامل Dodo Payments مع منصات إدارة التسويق بالعمولة الرائدة:

- **[Affonso](https://affonso.io)**: منصة شاملة لإدارة التسويق بالعمولة، توفر تتبّعًا آليًا للعمولات، وتقارير في الوقت الفعلي، ولوحات تحكم مخصصة للمسوقين بالعمولة.
- **[Dub Partners](https://dub.co)**: استخدم إدارة الروابط وتتبع التحويلات من Dub لتشغيل برنامج التسويق بالعمولة لديك، مع تحليلات تفصيلية لإسناد التحويلات.
- **[Rekomi](https://rekomi.com)**: منصة لتتبّع التسويق بالعمولة وإدارته، توفر اتصالًا بـ Dodo Payments من خلال لصق واحد، كما تتولى دفعات المسوقين بالعمولة ونماذج الضرائب نيابةً عنك.

اختر المنصة التي تناسب احتياجاتك، أو استخدم كلاهما لحالات استخدام مختلفة.

## تكامل أفونسو

لقد تعاوننا مع أفونسو، منصة رائدة لإدارة الشركاء لتفعيل مبيعاتك. اتبع الخطوات أدناه لربط حساب مدفوعات دودي الخاص بك مع أفونسو وبدء تتبع المبيعات المدفوعة من الشركاء.

<Steps>
  <Step title="Connect with Dodo Payments">
    للبدء، اربط حساب Dodo Payments الخاص بك عن طريق إضافة مفتاح واجهة برمجة التطبيقات.

    ### كيفية الحصول على مفتاح API الخاص بك من مدفوعات دودي

    - قم بتسجيل الدخول إلى **لوحة معلومات مدفوعات دودي**
    - انتقل إلى قسم **المطور** في القائمة اليسرى
    - انقر على **مفاتيح API**
    - اختر **إضافة مفتاح API**
    - أعطه اسمًا (مثل "تكامل أفونسو")
    - انقر على **إنشاء** و **انسخ** مفتاح API الخاص بك

    ### أضف مفتاح API الخاص بك إلى أفونسو

    - افتح **لوحة معلومات أفونسو عبر** [affonso.io](https://affonso.io/)
    - انتقل إلى **تفاصيل البرنامج > الاتصال**
    - انقر على بطاقة **تكامل مدفوعات دودي**
    - ألصق مفتاح API الخاص بك من مدفوعات دودي
    - انقر على **الاتصال**

    <Callout type="info">
      سيتم تشفير مفتاح واجهة برمجة التطبيقات الخاص بك بأمان بواسطة Affonso.
    </Callout>
  </Step>

  <Step title="Add Webhook to Dodo Payments">
    بمجرد الاتصال، ستحصل على عنوان ويب هوك فريد من Affonso. يمكّنك هذا من تتبع المدفوعات وإطلاق عمولات الشركاء.

    ### إضافة عنوان URL لـ Webhook في مدفوعات دودي

    - في لوحة معلومات مدفوعات دودي الخاصة بك، انتقل إلى **المطور → Webhooks**
    - انقر على **إضافة Webhook**
    - ألصق **عنوان URL لـ Webhook أفونسو** (من إعدادات برنامجك)
    - احفظ الـ Webhook

    ### إضافة سر Webhook في أفونسو

    - بعد حفظ الـ Webhook في مدفوعات دودي، **انسخ مفتاح التوقيع** المقدم
    - ألصقه مرة أخرى في أفونسو تحت **إعدادات Webhook مدفوعات دودي**

    <Callout type="info">
      هذا يتيح لـAffonso التحقق بأمان من الفعاليات الواردة من Dodo Payments.
    </Callout>
  </Step>

  <Step title="Add the Tracking Script">
    ضع بكسل Affonso على موقعك لبدء تتبع زيارات الشركاء والتحويلات.

    ```html
    <!-- Place in <head> tag -->
    <script async defer
    src="https://affonso.io/js/pixel.min.js"
    data-affonso="YOUR_PUBLIC_PROGRAM_ID"
    data-cookie_duration="YOUR_COOKIE_DURATION">
    </script>
    ```

    هذا البرنامج النصي:
    - يتتبع زيارات الشركاء
    - ينشئ ملف تعريف ارتباط بمعرّف الإحالة (`affonso_referral`)
    - يتيح تتبع التسجيلات والمدفوعات

    <Callout type="info">
      ضع هذا على جميع النطاقات التي يزور فيها المستخدمون أو يتم التحويل فيها (مثل موقع التسويق، التطبيق).
    </Callout>
  </Step>

  <Step title="Track User Signups">
    للحصول على رؤية لقمع المبيعات وتحسين أداء الشركاء، تتبع تسجيلات المستخدمين كعملاء محتملين.

    ```js
    // After successful registration
    window.Affonso.signup(userEmail);
    ```

    هذا سيسجل إحالة جديدة كـ **عميل محتمل** إذا جاء المستخدم عبر رابط الشريك
    - سيتم عرضها في لوحة المعلومات الخاصة بك وإحصائيات الشريك

    <Callout type="info">
      أفضل ممارسة: قم بإطلاق هذا بعد التسجيل الناجح أو التفعيل المزدوج (DOI).
    </Callout>
  </Step>

  <Step title="Pass Referral Data to Dodo Payments">
    لاحتساب العمولات بشكل صحيح، مرّر معرّف الإحالة من Affonso إلى Dodo Payments خلال الدفع.

    ### تكامل المدفوعات

    ```js
    import DodoPayments from 'dodopayments';

    const referralId = window.affonso_referral;

    const client = new DodoPayments({
      bearerToken: process.env['DODO_PAYMENTS_API_KEY'],
    });

    async function main() {
      const payment = await client.payments.create({
        payment_link: true,
        billing: { city: 'city', country: 'AF', state: 'state', street: 'street', zipcode: '00000' },
        customer: { email: 'email@email.com', name: 'name' },
        product_cart: [{ product_id: 'product_id', quantity: 0 }],
        metadata: {
          affonso_referral: referralId,
        },
      });

      console.log(payment.payment_id);
    }

    main();
    ```

    ### تكامل الاشتراك

    ```js
    import DodoPayments from 'dodopayments';

    const referralId = window.affonso_referral;

    const client = new DodoPayments({
      bearerToken: process.env['DODO_PAYMENTS_API_KEY'],
    });

    async function main() {
      const subscription = await client.subscriptions.create({
        billing: { city: 'city', country: 'IN', state: 'state', street: 'street', zipcode: '89789' },
        customer: { customer_id: 'customer_id' },
        product_id: 'product_id',
        payment_link: true,
        return_url: 'https://example.com/success',
        quantity: 1,
        metadata: {
          affonso_referral: referralId,
        },
      });

      console.log(subscription.subscription_id);
    }

    main();
    ```

    ### روابط الدفع

    ```js
    // Original Dodo Payments Link
    const originalLink = 'https://checkout.dodopayments.com/buy/<YOUR_PRODUCT_ID>';

    // Append referral ID as reference_id
    const linkWithReferral = `${originalLink}?metadata_affonso_referral=${window.affonso_referral}`;
    ```

    <Callout type="info">
      لمزيد من التفاصيل، راجع [وثائق واجهة برمجة تطبيقات Dodo Payments](https://docs.dodopayments.com/api-reference/introduction)
    </Callout>
  </Step>

  <Step title="Testing Your Integration">
    قبل الإطلاق للجمهور، اختبر إعدادك باستخدام روابط شركاء فعلية ومعاملات تجريبية.

    **قائمة التحقق من الاختبار:**
    - ✅ أنشئ شريكاً وولّد رابط تتبع
    - ✅ زر موقعك عبر رابط الشريك
    - ✅ تأكد من تحميل سكربت Affonso وتعيين ملف تعريف الارتباط `affonso_referral`
    - ✅ أكمل تسجيلاً (اختياري)
    - ✅ أكمل دفعة عبر Dodo Payments
    - ✅ أكد التتبع والانتساب في لوحة تحكم Affonso الخاصة بك
  </Step>
</Steps>

## تكامل دب بارتنرز

يمكنك أيضًا استخدام [دب بارتنرز](https://dub.co) لتتبع إحالات الشركاء والتحويلات. تتيح لك ميزة تتبع التحويلات من دب تخصيص المبيعات إلى روابط الشركاء الخاصة بك، مما يوفر تحليلات تفصيلية حول أي الشركاء يحققون أكبر إيرادات.

<Info>
للحصول على تعليمات إعداد مفصلة، اطلع على [دليل تكامل Dub](/integrations/dub) الذي يشرح كيفية تتبع أحداث تحويل المبيعات ونسب الإيرادات إلى روابط شركائك.
</Info>

### إعداد سريع مع دب بارتنرز

1. **فعّل تتبع التحويلات** في لوحة تحكم Dub الخاصة بالروابط التابعة
2. **التقط معرف نقرة Dub** (ملف تعريف الارتباط `dub_id`) عند إنشاء جلسات الدفع
3. **خزن معرف النقر** في البيانات الوصفية للدفعة إلى جانب معلومات العميل
4. **قم بتكوين تكامل ويب هوك** لإرسال بيانات المبيعات إلى Dub عند نجاح الدفعات

يتتبع التكامل تلقائيًا:
- المدفوعات لمرة واحدة
- تفعيل الاشتراكات
- المدفوعات المتكررة للاشتراكات

## تكامل Rekomi

يمكنك أيضًا استخدام [Rekomi](https://rekomi.com) لإدارة برنامج التسويق بالعمولة لديك من البداية إلى النهاية. تتتبّع Rekomi النقرات والتحويلات، وتحسب العمولات على مبلغ البيع قبل الضريبة، وتدفع لمسوقيك بالعمولة نيابةً عنك في أكثر من 150 دولة، بما في ذلك نماذج الضرائب.

<Info>
للحصول على تعليمات الإعداد التفصيلية، راجع [دليل تكامل Rekomi](/integrations/rekomi). يتطلب الاتصال لصق API key واحدًا فقط: تنشئ Rekomi نقطة نهاية webhook في حساب Dodo Payments لديك بنفسها، لذا لا حاجة إلى إعداد webhook يدويًا.
</Info>

### إعداد سريع باستخدام Rekomi

1. **أنشئ API key مع تفعيل صلاحية الكتابة** في لوحة تحكم Dodo Payments لديك ضمن **Developer → API Keys**
2. **الصق المفتاح في Rekomi**، حيث تتحقق من صحته وتنشئ نقطة نهاية webhook تلقائيًا
3. **ثبّت نص تتبّع Rekomi** على موقعك لالتقاط نقرات المسوقين بالعمولة
4. **مرّر الإحالة** إلى صفحة الدفع باعتبارها `rekomi_ref` metadata (أو باعتبارها `metadata_rekomi_ref` payment-link parameter)

يتتبّع التكامل تلقائيًا ما يلي:
- الدفعات لمرة واحدة
- عمليات تفعيل الاشتراكات وتجديدها
- عمليات رد الأموال والنزاعات، مع استرداد تلقائي للعمولات
