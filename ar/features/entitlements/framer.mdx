<Info>
الامتياز في Framer يفتح رابط إعادة تصميم قالب Framer للعملاء الذين دفعوا. تقوم بتحميل القالب إلى Dodo Payments، إرفاق الامتياز إلى منتج، ويحصل العملاء على رابط إعادة التصميم الذي يتيح لهم استنساخ القالب إلى حسابهم الخاص في Framer.
</Info>

## ما يتم تسليمه

- رابط إعادة تصميم فريد لقالب Framer الذي قمت بتحميله.
- يقوم العميل بالنقر على الرابط لإعادة تصميم القالب في مساحة العمل الخاصة بهم على Framer.
- عند الإلغاء أو الاسترداد، يصبح رابط إعادة التصميم غير صالح.

تشمل الاستخدامات الشائعة قوالب صفحة الهبوط المدفوعة على Framer، مجموعات البورتفوليو، ومكتبات المكونات.

## توصيل Framer

يتم توصيل Framer ضمنيًا في المرة الأولى التي تقوم فيها بإنشاء امتياز للقالب. لا توجد خطوة OAuth منفصلة.

<Steps>
<Step title="Open Entitlements">
في لوحة معلومات Dodo Payments الخاصة بك، اذهب إلى **Entitlements** وانقر على **+**.
</Step>

<Step title="Pick Framer">
اختر **Framer Template** كتكامل.
</Step>

<Step title="Grab the remix link from Framer">
افتح مشروعك في Framer. من القائمة العلوية اليسرى، اذهب إلى **File → Copy Remix Link**. ينتج عن ذلك عنوان URL عام لإعادة التصميم يتيح لأي شخص استنساخ المشروع في حساب Framer الخاص به — الرابط الذي ستشاركه Dodo Payments مع العملاء الذين دفعوا.


<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">
<img src="/images/entitlements/framer/copy-remix-link.png" alt="Framer File menu with Copy Remix Link option highlighted" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Add the template and create the entitlement">
عد إلى لوحة معلومات Dodo Payments، اختر القالب من القائمة المنسدلة **Template**. في المرة الأولى التي تقوم فيها بهذا لقالب جديد، قم بلصق رابط إعادة التصميم الذي نسخته لتسجيله. أعط الامتياز **اسم** واضغط على **Create Entitlement**.


<Frame>
<img src="/images/entitlements/framer/create.png" alt="Framer template entitlement form with template picker and name field" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

يسجل Dodo Payments القالب ويعيد `framer_template_id` يمكنك الرجوع إليه برمجيًا.
</Step>
</Steps>

## تدفق العملاء

1. يكمل العميل عملية الشراء.
2. يخلق Dodo Payments `pending` منح ويصدر رابط إعادة تصميم فريد مرتبط بهذا العميل.
3. يتحول المنح إلى `delivered` بمجرد توفير رابط إعادة التصميم ويُدرج الرابط في بريد العميل الإلكتروني والبوابة.
4. ينقر العميل على الرابط، يسجل الدخول إلى Framer، ويعيد تصميم القالب.
5. عند الإلغاء، يصبح رابط إعادة التصميم غير صالح. تبقى النسخ التي تم تعديلها بالفعل في حساب Framer الخاص بالعميل، لأن Framer لا يتيح طريقة لإلغائها.

## الإعدادات المطلوبة

| الحقل | مطلوب | الوصف |
|---|---|---|
| `framer_template_id` | نعم | معرف القالب الذي تم إرجاعه عندما تقوم بتحميل القالب. |

## الإنشاء عبر API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Portfolio Kit',
  integration_type: 'framer',
  integration_config: {
    framer_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Portfolio Kit",
    integration_type="framer",
    integration_config={"framer_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Portfolio Kit"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFramer),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFramerConfigParam{
      FramerTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

اطلع على [`entitlement_grant.*` أحداث ويبهوك](/developer-resources/webhooks/intents/entitlement-grant). تصل منح Framer كـ `pending` وتنتقل إلى `delivered` بمجرد توفير رابط إعادة التصميم.

## استكشاف الأخطاء وإصلاحها

<AccordionGroup>
<Accordion title="Customer's remix link doesn't work">
رابط إعادة التصميم هو للاستخدام الواحد ومرتبط بالعميل. إذا قاموا بمسح الرابط قبل إعادة التصميم، قم بإلغاء المنح وإعادة الإصدار.
</Accordion>

<Accordion title="Refunded customer still has a remixed copy">
هذا متوقع. يعتبر Framer إعادة التصميم كمشروع خاص بالعميل بمجرد استنساخه؛ يلغي Dodo Payments الرابط الأصلي ولكنه لا يمكنه حذف النسخ في حساب العميل.
</Accordion>
</AccordionGroup>
