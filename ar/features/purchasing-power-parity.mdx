تقوم تسعير تعادل القوة الشرائية (PPP) بتعديل ما تتقاضاه ليتناسب مع القدرة الشرائية لموقع كل عميل. هناك طريقتان للقيام بذلك على Dodo Payments.

<Info>
**موصى به:** استخدم [التسعير المحلي](/features/localized-pricing) الأصلي لضبط سعر محلي ثابت لكل بلد، على سبيل المثال ₹999 في الهند لمنتج بقيمة $20 أساسي. تتحكم في الرقم بالضبط، يتضمن المنتجات ذات الدفعة الواحدة، الاشتراك، والمنتجات المستندة إلى الاستخدام، ولا يتطلب تثبيت لافتة أو سكربت.
</Info>

## طريقتان لتشغيل PPP

| | التسعير المحلي (الأصلي) | رموز الخصم المستندة إلى الموقع |
| :--- | :--- | :--- |
| كيفية العمل | تحدد سعر محلي ثابت لكل بلد/عملة | نسبة مئوية من الخصم على السعر الأساسي عبر رمز |
| الأدوات | مدمجة في Dodo Payments | [ParityDeals](https://www.paritydeals.com/) / [Evendeals](https://www.evendeals.com/integrations/dodo-payments) |
| لافتة / سكربت على موقعك | غير مطلوب | مطلوب لعرض الرمز |
| السعر الذي يراه العميل | المبلغ الدقيق الذي تحدده | السعر الأساسي ناقص الخصم |
| الأفضل لـ | أسعار نظيفة مضبوطة للسوق تتحكم فيها بالكامل | لافتات ترويجية وصفقات موسمية/عطلات |

للإعداد الأصلي، انظر [التسعير المحلي](/features/localized-pricing). بقية هذه الصفحة تغطي نهج رموز الخصم المستندة إلى الموقع مع ParityDeals وEvendeals.

## رموز الخصم المستندة إلى الموقع

[ParityDeals](https://www.paritydeals.com/) و [Evendeals](https://www.evendeals.com/integrations/dodo-payments) هي منصات تُمكن تسعير التحسين التلقائي بناءً على الموقع الجغرافي للعميل عبر إنشاء رموز الخصم.

<Info>
على الرغم من أنك لا تستطيع تضمين لافتات الخصم مباشرة على واجهة متجر Dodo Payments (حيث لا تدعم السكربتات المخصصة)، يمكنك تنفيذ هذه الأدوات بفعالية على موقعك أو تطبيقك الخاص.
</Info>

### اختيار التكامل

كلا المنصتين تتكامل مباشرة مع Dodo Payments لإنشاء وإدارة رموز الخصم تلقائيًا. استخدم المقارنة أدناه لاختيار الأداة التي تناسب احتياجاتك.

| الميزة | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| تسعير PPP / المستند إلى الموقع | نعم | نعم |
| صفقات موسمية / مستندة إلى الزمن | نعم | لا |
| دعم الاشتراكات | نعم | نعم |
| تحديث تلقائي للكوبون | — | نعم |
| تخصيص اللافتة | نعم | لا |
| التسعير | [عرض التسعير](https://www.paritydeals.com/pricing/) | [عرض التسعير](https://www.evendeals.com/pricing) |

### ParityDeals

عندما يتم دمج ParityDeals في موقعك، سيرى الزوار المؤهلون لافتة تشمل رمز خصم مستند إلى الموقع يمكنهم استخدامه عند الدفع. يتم إنشاء وإدارة هذه الرموز تلقائيًا بواسطة ParityDeals وستظهر في **لوحة إدارة Dodo Payments** تحت **المبيعات → الخصومات**.

#### الإعداد

<Steps>
  <Step title="Sign up on ParityDeals">
    قم بزيارة [app.paritydeals.com](https://app.paritydeals.com/) وأنشئ حسابًا.
  </Step>

  <Step title="Create Deals">
    بعد تسجيل الدخول، حدد خيار إنشاء الصفقات. من القائمة المنسدلة، اختر **"إنشاء الصفقات عبر Dodo Payments"**.

    <Frame>
      <img src="/images/ppp/2.png" alt="إنشاء الصفقات عبر Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    قم بتسجيل الدخول إلى **لوحة إدارة Dodo Payments** وانتقل إلى **المطورون → مفاتيح API**. انقر **"إنشاء واجهة API جديدة"**.

    <Tip>
      اسم واجهة API بطريقة وصفية (على سبيل المثال، 'ParityDeals') بحيث يمكنك التعرف عليها لاحقًا.
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="إنشاء مفتاح API جديد في Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    انسخ مفتاح API الذي أنشأته والصقه في واجهة ParityDeals لإقامة الاتصال مع حساب Dodo Payments الخاص بك.

    <Frame>
      <img src="/images/ppp/4.png" alt="اتصال مفتاح API بـ ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    بمجرد الاتصال، سيقوم ParityDeals بجلب كتالوج منتجات Dodo Payments الخاص بك. حدد المنتجات التي تريد ربطها بصفقاتك.

    <Frame>
      <img src="/images/ppp/5.png" alt="اختيار المنتجات من أجل ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    أدخل عنوان URL الخاص بموقعك واختر اختياريًا صفحات مستهدفة محددة ينبغي أن تظهر فيها لافتة الخصم. ثم اختر نوع الصفقة المفضل لديك:
    - صفقات مستندة إلى الموقع
    - صفقات العطلات
    - صفقات فلاش مستندة إلى الوقت

    <Frame>
      <img src="/images/ppp/6.png" alt="تهيئة إعدادات الصفقة" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    حدد البلدان التي ترغب في تقديم خصومات محلية لها وحدد نسبة الخصم لكل منها. يوفر ParityDeals الافتراضيات الموصى بها التي يمكنك تعديلها حسب الحاجة.

    <Frame>
      <img src="/images/ppp/7.png" alt="تنظيم قواعد الخصم المستندة إلى البلد" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    قم بتصميم لافتة خصمك عن طريق تخصيص النص، واختيار الألوان والتخطيط، واختيار موقع اللافتة (أعلى أو أسفل الصفحة). سيتم عرض هذه اللافتة للزوار المؤهلين بناءً على القواعد التي قمت بتكوينها.

    <Frame>
      <img src="/images/ppp/8.png" alt="تخصيص لافتة الخصم" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    بعد حفظ صفقك، سيولد ParityDeals سكربت. أضف هذا السكربت إلى كود موقعك (عادةً في القسم `<head>`). يكتشف هذا السكربت تلقائيًا مواقع الزوار ويعرض لافتة الخصم المناسبة.

    <Frame>
      <img src="/images/ppp/9.png" alt="سكربت تكامل ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

#### الميزات الإضافية

مع ParityDeals، يمكنك أيضًا تقديم [خصومات تلقائية مستندة إلى الوقت](https://www.paritydeals.com/features/time-based-discounts/) و [عروض ترويجية موسمية](https://www.paritydeals.com/features/holiday-based-discounts/) على مدار السنة. للحصول على معلومات أكثر تفصيلاً، راجع [مستندات ParityDeals](https://www.paritydeals.com/docs/).

### Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) هو منصة أخرى تتكامل مع Dodo Payments لتقديم تسعير تعادل القوة الشرائية المستند إلى الموقع. يدعم كلاً من المنتجات ذات الدفعة الواحدة والاشتراكات.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="نظرة عامة على تكامل Evendeals مع Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### الميزات الرئيسية

- **المزامنة التلقائية للكوبون** — يتم إنشاء وإدارة الكوبونات في Dodo Payments تلقائيًا
- **خصومات النسبة المئوية** — تقديم خصومات بنسبة معينة لكل مجموعة دول
- **دعم الاشتراكات** — تنطبق الخصومات على دورات الفوترة الاشتراكية
- **قواعد التحديث التلقائي** — تدوير رموز الكوبون تلقائيًا بفاصل زمني، عدد الاستردادات، أو عدد المشاهدات لمنع الإساءة

<Info>
رموز الخصم التي ينشئها Evendeals ستظهر تلقائيًا في لوحة إدارة Dodo Payments الخاصة بك تحت المبيعات → الخصومات.
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="الميزات الرئيسية لـ Evendeals لتكامل Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### الإعداد

<Steps>
  <Step title="Create a Dodo Payments API key">
    في لوحة إدارة Dodo Payments الخاصة بك، انتقل إلى **المطورون → مفاتيح API** وقم بإنشاء مفتاح جديد.
  </Step>

  <Step title="Connect in Evendeals">
    في [لوحة Evendeals الخاصة بك](https://www.evendeals.com/signin)، انتقل إلى **التكاملات**، ابحث عن بطاقة Dodo Payments، والصق مفتاح API الخاص بك.
  </Step>

  <Step title="Configure regional discounts">
    حدد خصومات النسبة المئوية لكل مجموعة دول واضغط على المزامنة. يقوم Evendeals بإنشاء الكوبونات في Dodo Payments تلقائيًا.

    <Check>
    بعد المزامنة، افتح **المبيعات → الخصومات** في لوحة إدارة Dodo Payments لتأكيد ظهور الكوبونات التي تم إنشاؤها. كل كوبون سيكون له بادئة Evendeals واضحة.
    </Check>
  </Step>
</Steps>

<Frame>
  <img src="/images/ppp/evendeals-setup.png" alt="دليل إعداد Evendeals لـ Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

يعمل كلاً من ParityDeals وEvendeals بسلاسة مع Dodo Payments لمساعدتك على تحسين استراتيجية التسعير العالمية الخاصة بك. لمزيد من التفاصيل، قم بزيارة [مستندات ParityDeals](https://www.paritydeals.com/docs/) أو صفحة [تكامل Evendeals مع Dodo Payments](https://www.evendeals.com/integrations/dodo-payments).
