<Info>
يفرض تعادل القوة الشرائية (PPP) على العميل دفع نسبة من سعرك المدرج، استنادًا إلى البلد الذي يشتري منه. يمكن بيع منتج بسعر \$20 مقابل **\$6.00 في الهند** من دون رمز خصم ومن دون قائمة أسعار ثانية.
</Info>

## ما هو تعادل القوة الشرائية؟

السعر نفسه لا يكون ميسور التكلفة بالقدر نفسه في كل مكان. يُعد مبلغ \$20 شراءً بسيطًا في الولايات المتحدة وشراءً كبيرًا في الفلبين. يعمل تسعير PPP على تصحيح هذا الفرق.

يحتفظ Dodo Payments بنسبة مئوية واحدة لكل بلد. والنسبة المئوية هي **الحصة من سعرك المدرج التي يدفعها العميل**. النسبة في الهند هي 30، لذلك يدفع العميل في الهند 30% من السعر. أما الولايات المتحدة فنسبتها 100، ولذلك لا يتغير شيء هناك.

فعّل PPP لكل سعر منتج تريد تطبيقه عليه. أما المنتجات التي لا تفعّلها لها، فتحافظ على سعرها العادي في كل مكان.

<Note>
يتطلب PPP استخدام [Adaptive Currency](/features/adaptive-currency). فعّل Adaptive Currency أولًا.
</Note>

## المزايا الرئيسية

- **الوصول إلى الأسواق الحساسة للأسعار**: بِع بسعر محلي من دون خفض سعرك الأساسي.
- **لا حاجة إلى شريط إعلاني أو نص برمجي**: يكون السعر صحيحًا عند الدفع. ولا يُضاف أي شيء إلى موقعك.
- **لا حاجة إلى إدارة رموز الخصم**: لا شيء لإنشائه أو تغييره أو إلغائه.
- **تحكم لكل منتج**: فعّلها لخطة بداية واترك خطة المؤسسات كما هي.
- **تعمل في كل الحالات**: المنتجات ذات الدفع لمرة واحدة، والاشتراكات، والمنتجات القائمة على الاستخدام.

## تفعيل تعادل القوة الشرائية

<Steps>
<Step title="Enable Adaptive Currency">
انتقل إلى **Settings → Business**. في **Business Settings**، فعّل **Adaptive Currency**. لا يعمل PPP من دونها.

<Frame>
  <img src="/images/ppp/adaptive-currency-toggle.png" alt="Adaptive Currency and Purchasing Power Parity in Business Settings" style={{ maxHeight: '360px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Review your country percentages">
ضمن **Purchasing Power Parity**، انقر على **Edit** لفتح **Country Prices**. غيّر النسبة المئوية لأي بلد، ثم انقر على **Save Changes**.

حدّد **Example product price** لمعرفة ما يدفعه كل بلد. يتم تحديث عمود **Your Price** أثناء الكتابة. استخدم مربع البحث للعثور على بلد بالاسم أو الرمز.

<Frame>
  <img src="/images/ppp/country-percentages.png" alt="Country Prices dialog with a percentage and resulting price for each country" style={{ maxHeight: '620px', width: 'auto' }} />
</Frame>

<Note>
هذه النسب المئوية على مستوى النشاط التجاري بأكمله. ويستخدمها كل منتج مفعّل فيه Purchasing Power Parity.
</Note>
</Step>

<Step title="Turn PPP on for a product">
افتح المنتج. في قسم **Pricing**، حدّد **Purchasing Power Parity**، ثم احفظ المنتج.

تحافظ المنتجات التي لا تحدّد لها هذا الخيار على سعرها العادي في كل مكان.

<Frame>
  <img src="/images/ppp/product-toggle.png" alt="Purchasing Power Parity ticked in the product Pricing section" style={{ maxHeight: '440px', width: 'auto' }} />
</Frame>

<Warning>
لا يمكنك تحديد هذا الخيار أثناء إيقاف Adaptive Currency. فعّل Adaptive Currency أولًا.
</Warning>
</Step>

<Step title="Confirm at checkout">
<Check>
افتح صفحة دفع تجريبية باستخدام بلد فوترة تقل نسبته عن 100. وتأكد من ظهور السعر المخفّض.
</Check>
</Step>
</Steps>

## كيفية احتساب السعر

تضرب النسبة المئوية للبلد سعرك المدرج:

```
price paid = list price × country percentage ÷ 100
```

منتج بسعر \$20.00 لعميل في الهند بنسبة 30:

```
2000 × 30 ÷ 100 = 600   →   $6.00
```

يطبّق Dodo Payments النسبة المئوية على السعر الأساسي قبل تحويل العملة. ثم تحوّل [Adaptive Currency](/features/adaptive-currency) الناتج إلى عملة العميل.

<Info>
يقرأ Dodo Payments البلد من **بلد الفوترة** الخاص بالعميل عند الدفع.
</Info>

### النسب المئوية للبلدان

لكل بلد نسبة مئوية واحدة تتراوح بين **30 و100**:

- **100** تعني أن العميل يدفع سعرك الكامل. ولا يوجد أي تخفيض.
- **30** هي أدنى قيمة يمكنك تعيينها. ولذلك يبلغ أكبر تخفيض 70%.

تأتي القيم الافتراضية من بيانات مؤشر مستوى الأسعار الصادرة عن البنك الدولي. يقرّب Dodo Payments كل قيمة إلى أقرب 5، ويطبّق حدًا أدنى قدره 30، ويضع حدًا أقصى قدره 100. ولكل بلد مدعوم قيمة محددة. ويمكنك تغيير أي منها.

فيما يلي بعض القيم الافتراضية لتوضيح النطاق:

| البلد | النسبة المئوية | يُباع منتج بسعر \$20 مقابل |
| :--- | :---: | :--- |
| الولايات المتحدة | 100 | \$20.00 |
| المملكة المتحدة | 85 | \$17.00 |
| ألمانيا | 75 | \$15.00 |
| اليابان | 60 | \$12.00 |
| البرازيل | 45 | \$9.00 |
| جنوب أفريقيا | 40 | \$8.00 |
| الفلبين | 35 | \$7.00 |
| الهند | 30 | \$6.00 |

<Note>
تغطي القائمة الكاملة 217 بلدًا. افتح جدول البلدان في لوحة التحكم للاطلاع على كل قيمة.
</Note>

## التفعيل عبر API

يتم تفعيل PPP لكل منتج باستخدام الحقل `purchasing_power_parity`. والقيمة الافتراضية هي `false`.

<Info>
تُدار النسب المئوية للبلدان من لوحة التحكم فقط. وهي ليست جزءًا من API العام.
</Info>

<CodeGroup>

```typescript theme={null}
import DodoPayments from 'dodopayments';

const client = new DodoPayments({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: 'test_mode',
});

const product = await client.products.create({
  name: 'Starter Plan',
  tax_category: 'saas',
  price: {
    type: 'one_time_price',
    currency: 'USD',
    price: 2000,
    discount: 0,
    purchasing_power_parity: true,
  },
});
```

```python theme={null}
import os
from dodopayments import DodoPayments

client = DodoPayments(
    bearer_token=os.environ.get("DODO_PAYMENTS_API_KEY"),
    environment="test_mode",
)

product = client.products.create(
    name="Starter Plan",
    tax_category="saas",
    price={
        "type": "one_time_price",
        "currency": "USD",
        "price": 2000,
        "discount": 0,
        "purchasing_power_parity": True,
    },
)
```

```go theme={null}
package main

import (
	"context"
	"os"

	"github.com/dodopayments/dodopayments-go"
	"github.com/dodopayments/dodopayments-go/option"
)

func main() {
	client := dodopayments.NewClient(
		option.WithBearerToken(os.Getenv("DODO_PAYMENTS_API_KEY")),
	)

	_, err := client.Products.New(context.TODO(), dodopayments.ProductNewParams{
		Name:        dodopayments.F("Starter Plan"),
		TaxCategory: dodopayments.F(dodopayments.ProductNewParamsTaxCategorySaas),
		Price: dodopayments.F[dodopayments.PriceUnionParam](
			dodopayments.PriceOneTimePriceParam{
				Type:                  dodopayments.F(dodopayments.PriceOneTimePriceTypeOneTimePrice),
				Currency:              dodopayments.F(dodopayments.CurrencyUsd),
				Price:                 dodopayments.F(int64(2000)),
				Discount:              dodopayments.F(int64(0)),
				PurchasingPowerParity: dodopayments.F(true),
			},
		),
	})
	if err != nil {
		panic(err)
	}
}
```

</CodeGroup>

<Warning>
يفشل الطلب باستخدام `422 ppp_not_enabled_for_business` إذا كانت Adaptive Currency متوقفة لنشاطك التجاري. فعّلها أولًا.
</Warning>

## السلوكيات المهمة

| السلوك | التفاصيل |
| :--- | :--- |
| **يتطلب Adaptive Currency** | لا يعمل PPP أثناء إيقاف Adaptive Currency. |
| **متوقف افتراضيًا** | يبدأ كل سعر بالقيمة `purchasing_power_parity: false`. |
| **الأسعار المحلية لها الأولوية** | لا يتم تعديل المنتج الذي يطابق قاعدة [Localized Pricing](/features/localized-pricing) بواسطة PPP مطلقًا. ويُطبّق المبلغ المحدد بالضبط. |
| **يُطبّق قبل التحويل** | تُطبّق النسبة المئوية على سعرك الأساسي. ثم تحوّل Adaptive Currency الناتج. |
| **قبل الخصومات** | يُطبّق [رمز الخصم](/features/discount-codes) على السعر المخفّض، ولذلك يجتمع التخفيضان. |
| **الرسوم الثابتة للمنتجات القائمة على الاستخدام فقط** | يطبّق PPP على الرسم الثابت للمنتج القائم على الاستخدام، ولا يطبّقه على الاستخدام المقاس مطلقًا. |
| **لا ينطبق على Pay What You Want** | يختار العميل المبلغ، ولذلك لا ينطبق PPP. راجع [Pay What You Want](/features/pay-what-you-want). |
| **نطاق النسبة المئوية** | تتراوح النسبة المئوية للبلد بين 30 و100. ويبلغ أكبر تخفيض 70%. |
| **لا يوجد webhook خاص به** | يظهر المبلغ المخفّض في عملية الدفع أو الاشتراك مثل أي سعر آخر. |

## أفضل الممارسات

- **فعّل المنتج الأول فقط.** أكّد سعر الدفع قبل تفعيلها في كتالوجك.
- **راقب تراكم الخصومات.** يُطبّق رمز الخصم فوق سعر PPP. إن كانت نسبة البلد 30% ورمز الخصم 20%، فسيبقى 24% من سعرك المدرج.
- **استبعد خطط المؤسسات.** نادرًا ما تحتاج الخطة المتفاوض عليها إلى تعديل حسب البلد.
- **حدّد قيمك الخاصة حيثما يهم الأمر.** الأرقام الافتراضية نقطة بداية وليست قاعدة.
- **تحقّق من التأثير على الاشتراكات.** يجدّد المشترك الذي يسجّل بالسعر المخفّض بالسعر نفسه.
