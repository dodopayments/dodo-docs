## ما هي محافظ العملاء؟

محافظ العملاء هي حسابات أرصدة نقدية تحتفظ بأموال حقيقية لمستخدميك. يحصل كل عميل على محفظة تلقائيًا عند إنشاء حسابه. يمكنك استخدام هذه المحافظ من أجل:

- **تخزين الأموال المدفوعة مسبقًا** لدفعات الاشتراك المستقبلية
- **معالجة المبالغ المستردة** كرصيد في المحفظة بدلًا من ردّ الأموال إلى البطاقة
- **إصدار أرصدة ترويجية** مثل مكافآت الترحيب أو مكافآت الولاء
- **تطبيق أموال المحفظة على الفواتير** تلقائيًا أثناء الفوترة
- **تتبّع المعاملات النقدية** باستخدام سجل دفتر أستاذ مفصل

<Info>
يحصل كل عميل تلقائيًا على محفظة عند إنشاء حسابه. تدعم المحافظ عملات USD وEUR وGBP، مع أرصدة مالية منفصلة لكل عملة.
</Info>

<Warning>
**محافظ العملاء ≠ الفوترة القائمة على الائتمان**

تحتفظ محافظ العملاء **بأرصدة مالية حقيقية** (USD وEUR وGBP) يمكن تطبيقها على الفواتير ودفعات الاشتراكات.

إذا كنت تريد تتبّع وحدات الاستخدام الافتراضية (مثل استدعاءات API والرموز وساعات الحوسبة)، فراجع [الفوترة القائمة على الائتمان](/features/credit-based-billing) بدلًا من ذلك.
</Warning>

## آلية العمل

تحتفظ محافظ العملاء بالأموال التي يمكن للعملاء استخدامها في مشترياتهم. عندما تكون لدى العميل فاتورة أو رسوم اشتراك متكررة، يتم التحقق من رصيد محفظته أولًا. وتُطبَّق أي أموال متاحة تلقائيًا على الفاتورة قبل الخصم من طريقة الدفع الأساسية.

### الإعداد التلقائي

عند إنشاء عميل جديد، يقوم Dodo Payments تلقائيًا بإنشاء محفظة برصيد صفري. وتصبح المحفظة جاهزة لتلقي الأموال فورًا من خلال API الخاص بنا.

### دعم العملات المتعددة

يمكن لكل محفظة الاحتفاظ بأرصدة بعملات مختلفة:

<ResponseField name="USD Balance" type="integer">
الرصيد بالدولار الأمريكي (مخزّن بالسنتات)
</ResponseField>

<ResponseField name="EUR Balance" type="integer">
الرصيد باليورو (مخزّن بالسنتات)
</ResponseField>

<ResponseField name="GBP Balance" type="integer">
الرصيد بالجنيه الإسترليني (مخزّن بالبنسات)
</ResponseField>

<Info>
حاليًا، تتوفر أرصدة **USD** و**EUR** و**GBP** فقط. تم إيقاف المحفظة الأصلية بالروبية الهندية (INR) — راجع [هيكل المدفوعات](/features/payouts/payout-structure). تظل INR مدعومة كعملة معاملات لاشتراكات UPI وRuPay والبطاقات الهندية.
</Info>

## أمثلة من العالم الحقيقي

### ردّ الأموال إلى المحفظة

عندما يطلب العميل استردادًا، يمكنك إضافة المبلغ إلى رصيد محفظته بدلًا من تنفيذ عملية رد أموال تقليدية إلى البطاقة. يحافظ ذلك على الأموال ضمن منظومتك لإجراء عمليات شراء مستقبلية.

```javascript
async function refundToWallet(customerId, refundAmount, originalPaymentId) {
  await client.customers.wallets.ledgerEntries.create(customerId, {
    amount: refundAmount, // Amount in cents
    currency: 'USD',
    entry_type: 'credit',
    reason: `Refund for payment ${originalPaymentId}`,
    idempotency_key: `refund_${originalPaymentId}`
  });
}
```

### مكافأة ترحيبية / رصيد ترويجي

قدّم للعملاء الجدد مكافأة مالية ترحيبية لتشجيعهم على إجراء أول عملية شراء.

```javascript
async function addWelcomeBonus(customerId) {
  await client.customers.wallets.ledgerEntries.create(customerId, {
    amount: 1000, // $10.00 promotional balance
    currency: 'USD',
    entry_type: 'credit',
    reason: 'Welcome bonus - $10 promotional balance',
    idempotency_key: `welcome_${customerId}`
  });
}
```

### دفع الاشتراك من المحفظة

اخصم الأموال من المحفظة لتغطية رسوم اشتراك أو عملية شراء يدوية.

```javascript
async function deductForPurchase(customerId, purchaseAmount, purchaseId) {
  try {
    await client.customers.wallets.ledgerEntries.create(customerId, {
      amount: purchaseAmount,
      currency: 'USD',
      entry_type: 'debit',
      reason: `Subscription charge - monthly billing`,
      idempotency_key: `charge_${purchaseId}`
    });
  } catch (error) {
    if (error.status === 400) {
      console.log('Insufficient wallet balance');
    }
  }
}
```

اسمح للعملاء بتمويل حساباتهم مقدمًا والسحب من هذا الرصيد بمرور الوقت.

## أفضل الممارسات

### منع المعاملات المكررة

استخدم مفاتيح idempotency لضمان عدم إضافة الأموال أو خصمها مرتين عن طريق الخطأ للحدث نفسه.

```javascript
async function addFundsSafely(customerId, amount, reason) {
  const idempotencyKey = `${reason}_${customerId}_${Date.now()}`;
  
  try {
    const result = await client.customers.wallets.ledgerEntries.create(customerId, {
      amount: amount,
      currency: 'USD',
      entry_type: 'credit',
      reason: reason,
      idempotency_key: idempotencyKey
    });
    
    // Replaying the same idempotency_key returns the original entry rather than
    // creating a duplicate, so no special duplicate handling is required.
    return { success: true, wallet: result };
  } catch (error) {
    if (error.status === 400) {
      // e.g. insufficient balance on a debit
      return { success: false, reason: 'insufficient_balance' };
    }

    throw error;
  }
}
```

### التحقق من الأرصدة قبل الخصم

تحقّق من امتلاك العملاء أموالًا كافية قبل محاولة معالجة معاملات كبيرة من المحفظة.

```javascript
async function checkBalanceBeforeOperation(customerId, requiredAmount) {
  const wallets = await client.customers.wallets.list(customerId);
  const usdWallet = wallets.items.find(w => w.currency === 'USD');
  
  if (!usdWallet || usdWallet.balance < requiredAmount) {
    throw new Error('Insufficient funds for this operation');
  }
  
  return usdWallet.balance;
}
```

## ما التالي؟

<Warning>
هذه الميزات مخططة للإصدارات المستقبلية:
</Warning>

- **انتهاء صلاحية الرصيد**: حدّد مدة تنتهي بعدها صلاحية الأموال
- **تحليلات أفضل**: تقارير مفصلة عن الإنفاق واتجاهات الرصيد
- **المزيد من Webhooks**: إشعارات في الوقت الفعلي بشأن تغيّرات الرصيد وتنبيهات انخفاض الرصيد

<Tip>
ابدأ بعمليات التمويل والخصم الأساسية، ثم ادمج المزيد من تدفقات الفوترة الآلية المعقدة مع نمو أعمالك.
</Tip>
