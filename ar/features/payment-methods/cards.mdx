تعتبر مدفوعات البطاقة أساس المدفوعات عبر الإنترنت، مقبولة عالميًا وموثوقة من قبل العملاء في جميع أنحاء العالم. تدعم مدفوعات دودي جميع الشبكات الرئيسية للبطاقات مع حماية مدمجة ضد الاحتيال والامتثال لمعايير PCI.

## الشبكات المدعومة للبطاقات

### الشبكات العالمية

| الشبكة | التغطية |
| :------ | :------- |
| **فيزا** | رائد عالمي، 4 مليارات بطاقة حول العالم |
| **ماستركارد** | انتشار عالمي، ميزات أمان قوية |
| **أمريكان إكسبريس** | حاملي بطاقات مميزين، إنفاق أعلى |
| **Discover** | تركز على الولايات المتحدة، تنمو عالميًا |
| **JCB** | الرائد في اليابان، يتوسع عبر آسيا |
| **UnionPay** | مهيمنة في الصين، 8 مليارات بطاقة |
| **Diners Club** | للمسافرين الدوليين المميزين |

### الشبكات الإقليمية

| الشبكة | المنطقة |
| :------ | :----- |
| **Interac** | شبكة الخصم في كندا |
| **Cartes Bancaires** | الشبكة الوطنية في فرنسا |
| **Korean Local Cards** | الشبكات المحلية الكورية |
| **Rupay** | الشبكة الوطنية في الهند |

## التكوين

استخدم هذه القيم في `allowed_payment_method_types`:

| النوع | الوصف |
| :--- | :---------- |
| `credit` | جميع بطاقات الائتمان |
| `debit` | جميع بطاقات الخصم |

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

<Tip>
قم بتضمين كل من `credit` و `debit` ما لم يكن لديك سبب محدد لاستبعاد أحدهما. يفضل العديد من العملاء بطاقات الخصم وعادة ما تكون الرسوم أقل.
</Tip>

## مصادقة 3D Secure

تضيف 3D Secure (3DS) طبقة مصادقة تقلل من الاحتيال والمطالبات باسترداد الأموال من خلال التحقق من هوية حامل البطاقة.

### متى يتم تفعيل 3DS

يتم تفعيل 3DS تلقائيًا عند:
- يتطلبها شبكة البطاقة
- يتطلبها اللوائح الإقليمية (مثل PSD2 في أوروبا)
- يُعلام أن المعاملة ذات مخاطر عالية

### فرض 3DS

يمكنك فرض 3DS على جميع المعاملات:

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  force_3ds: true,
  return_url: 'https://example.com/success'
});
```

<Note>
تمكين 3DS لجميع المعاملات يقلل من الاحتيال ولكن قد يقلل قليلاً من التحويل حيث يتخلى بعض العملاء خلال عملية المصادقة.
</Note>

### تفعيل البطاقات المحفوظة

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  show_saved_payment_methods: true,
  customer: { customer_id: 'cus_existing_123' },
  return_url: 'https://example.com/success'
});
```

### عمليات الشراء بنقرة واحدة

```javascript
// Get customer's saved payment methods
const methods = await client.customers.getPaymentMethods('cus_123');

// Use saved card for instant checkout
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  customer: { customer_id: 'cus_123' },
  payment_method_id: methods[0].payment_method_id,
  confirm: true,
  return_url: 'https://example.com/success'
});
```

## الأمان والامتثال

| الميزة | الوصف |
| :------ | :---------- |
| **مستوى PCI DSS 1** | أعلى مستوى من الشهادات |
| **التوكنة** | يتم توكنة أرقام البطاقة على الفور |
| **تقييم الاحتيال** | تقييم خطر في الوقت الفعلي |
| **AVS** | خدمة التحقق من العنوان |
| **التحقق من CVV** | التحقق من رمز الأمان |
| **3D Secure** | مصادقة حامل البطاقة |

## استكشاف الأخطاء وإصلاحها

<AccordionGroup>
<Accordion title="تم رفض البطاقة">
**الأسباب:** نقص في الأموال، انتهاء صلاحية البطاقة، CVV غير صحيح، حماية البنك من الاحتيال.

**الحل:** اطلب من العميل التحقق من التفاصيل أو تجربة بطاقة مختلفة.
</Accordion>

<Accordion title="فشل مصادقة 3DS">
**الأسباب:** تخلى العميل، النظام المصرفي غير متاح، نفاد الوقت.

**الحل:** حاول مجددًا أو اطلب من العميل الاتصال ببنكه.
</Accordion>

<Accordion title="البطاقة غير مدعومة">
**الأسباب:** البطاقة الإقليمية غير مدعومة، قيود على البطاقة المدفوعة مسبقًا.

**الحل:** ينبغي على العميل تجربة بطاقة مختلفة من شبكة رئيسية.
</Accordion>
</AccordionGroup>
