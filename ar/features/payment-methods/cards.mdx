تُعد مدفوعات البطاقات أساس المدفوعات عبر الإنترنت، فهي مقبولة عالميًا وموثوقة من العملاء في جميع أنحاء العالم. يدعم Dodo Payments جميع شبكات البطاقات الرئيسية مع حماية مضمّنة من الاحتيال والامتثال لمعيار PCI.

## شبكات البطاقات المدعومة

### الشبكات العالمية

| الشبكة | التغطية |
| :------ | :------- |
| **Visa** | رائدة عالميًا، وأكثر من 4 مليارات بطاقة حول العالم |
| **Mastercard** | انتشار عالمي وميزات أمان قوية |
| **American Express** | حاملو البطاقات المتميزة وإنفاق أعلى |
| **Discover** | تركز على الولايات المتحدة وتنتشر عالميًا |
| **JCB** | رائدة في اليابان وتتوسع في أنحاء آسيا |
| **UnionPay** | مهيمنة في الصين، وأكثر من 8 مليارات بطاقة |
| **Diners Club** | للمسافرين الدوليين المتميزين |

### الشبكات الإقليمية

| الشبكة | المنطقة |
| :------ | :----- |
| **Interac** | شبكة بطاقات الخصم في كندا |
| **Cartes Bancaires** | الشبكة الوطنية في فرنسا |
| **Korean Local Cards** | الشبكات المحلية الكورية |
| **Rupay** | الشبكة الوطنية في الهند |

## الإعداد

استخدم هذه القيم في `allowed_payment_method_types`:

| النوع | الوصف |
| :--- | :---------- |
| `credit` | جميع بطاقات الائتمان |
| `debit` | جميع بطاقات الخصم |

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  allowed_payment_method_types: ['credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

<Tip>
ضمّن كلاً من `credit` و`debit` ما لم يكن لديك سبب محدد لاستبعاد أحدهما. يفضّل العديد من العملاء بطاقات الخصم، وغالبًا ما تفرض رسومًا أقل.
</Tip>

## مصادقة 3D Secure

تضيف 3D Secure (3DS) طبقة مصادقة تقلل الاحتيال وعمليات رد المدفوعات من خلال التحقق من هوية حامل البطاقة.

### متى يتم تشغيل 3DS

يتم تشغيل 3DS تلقائيًا عندما:
- تطلبها شبكة البطاقات
- تتطلبها اللوائح الإقليمية (مثل PSD2 في أوروبا)
- تُصنّف المعاملة على أنها عالية المخاطر

### فرض 3DS

يمكنك طلب 3DS في جميع المعاملات:

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  force_3ds: true,
  return_url: 'https://example.com/success'
});
```

<Note>
يؤدي تفعيل 3DS لجميع المعاملات إلى تقليل الاحتيال، لكنه قد يخفض معدل التحويل قليلًا، إذ قد يتخلى بعض العملاء عن عملية الشراء أثناء المصادقة.
</Note>

### التعامل مع حالات فشل المصادقة

عندما تحتاج دفعة ما إلى مصادقة 3DS، تمر الدفعة بحالات وسيطة قبل نجاحها أو فشلها:

| الحالة | المعنى | الإجراء |
|--------|---------|------------|
| `requires_customer_action` | يجب على العميل إكمال تحدي 3DS | اجعل العميل يكمل المصادقة أثناء إتمام الدفع |
| `requires_payment_method` | لم يقدّم العميل طريقة دفع مطلقًا (لم يُدخل التفاصيل أو تخلى عن الطلب) — عادةً ما تكون حالة انسحاب وليست رفضًا | أعد إشراك العميل لإكمال إتمام الدفع؛ راجع [استرداد السلات المتروكة](/features/recovery/abandoned-cart-recovery) |

إذا لم تكتمل المصادقة، تفشل الدفعة باستخدام أحد رموز الرفض التالية:

- `AUTHENTICATION_FAILURE` — تعذرت مصادقة العميل.
- `AUTHENTICATION_REQUIRED` — المصادقة مطلوبة، لكنها لم تُنفّذ.
- `AUTHENTICATION_TIMEOUT` — لم يستجب العميل في الوقت المحدد.

راجع مرجع [فشل المعاملات](/api-reference/transaction-failures) للاطلاع على الإجراء الموصى به لكل حالة.

#### عند إتمام الدفع مقابل التجديد

- **عند إتمام الدفع (العميل حاضر):** يكون العميل حاضرًا، لذلك يظهر تحدي 3DS أثناء إتمام الدفع. إذا فشل، اطلب منه إعادة المحاولة أو استخدام بطاقة أخرى.
- **عند تجديد الاشتراك (العميل غير حاضر):** لا يكون العميل حاضرًا، لذلك لا يمكن عرض تحدي 3DS في الوقت الفعلي. إذا تطلب التجديد مصادقة، ينتقل الاشتراك إلى `on_hold`. استعده من خلال مطالبة العميل بالعودة وتحديث طريقة الدفع — راجع [التعامل مع فشل المدفوعات](/developer-resources/handle-payment-failures) و[إدارة تحصيل الاشتراكات المتأخرة](/features/recovery/subscription-dunning).

## طرق الدفع المحفوظة

يمكن للعملاء حفظ بطاقاتهم لإتمام عمليات الدفع المستقبلية بسرعة أكبر.

<CardGroup cols={3}>
<Card title="Tokenized" icon="lock">
لا يتم تخزين أرقام البطاقات الأصلية مطلقًا.
</Card>
<Card title="PCI Compliant" icon="shield-check">
يتولى Dodo جميع جوانب الامتثال.
</Card>
<Card title="Customer-Scoped" icon="user">
بطاقات مرتبطة بعملاء محددين.
</Card>
</CardGroup>

### تفعيل البطاقات المحفوظة

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  show_saved_payment_methods: true,
  customer: { customer_id: 'cus_existing_123' },
  return_url: 'https://example.com/success'
});
```

### عمليات الشراء بنقرة واحدة

```javascript
// Get customer's saved payment methods
const methods = await client.customers.retrievePaymentMethods('cus_123');

// Use saved card for instant checkout
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  customer: { customer_id: 'cus_123' },
  payment_method_id: methods.items[0].payment_method_id,
  confirm: true,
  return_url: 'https://example.com/success'
});
```

## استكشاف الأخطاء وإصلاحها

<AccordionGroup>
<Accordion title="Card declined">
**الأسباب:** رصيد غير كافٍ، انتهاء صلاحية البطاقة، CVV غير صحيح، حماية البنك من الاحتيال.

**الحل:** اطلب من العميل التحقق من التفاصيل أو تجربة بطاقة أخرى. ابحث عن رمز الرفض المحدد `Error Code` والإجراء الموصى به في مرجع [فشل المعاملات](/api-reference/transaction-failures)، وراجع [التعامل مع فشل المدفوعات](/developer-resources/handle-payment-failures) للتعامل البرمجي.
</Accordion>

<Accordion title="3DS authentication failed">
**الأسباب:** تخلى العميل عن العملية، نظام البنك غير متاح، انتهاء المهلة.

**الحل:** أعد المحاولة أو اطلب من العميل التواصل مع بنكه. راجع [التعامل مع حالات فشل المصادقة](#handling-authentication-failures) للاطلاع على حالات الدفع ورموز الرفض المعنية.
</Accordion>

<Accordion title="Card not supported">
**الأسباب:** البطاقة الإقليمية غير مدعومة، قيود على البطاقات مسبقة الدفع.

**الحل:** ينبغي للعميل تجربة بطاقة أخرى من شبكة رئيسية.
</Accordion>
</AccordionGroup>
