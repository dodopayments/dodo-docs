تتيح لك الفوترة حسب الاستخدام فرض رسوم على العملاء مقابل ما يستخدمونه فعلياً—مثل استدعاءات API، والتخزين، ورموز الذكاء الاصطناعي، أو أي مقياس تحدده. يدفع العملاء مقابل الاستهلاك، وليس رسوماً ثابتة.

<Info>
**مناسبة تماماً لـ**: واجهات API، وخدمات الذكاء الاصطناعي، ومنصات البنية التحتية، وأي منتج تتناسب قيمته مع الاستخدام.
</Info>

## آلية العمل

<Steps>
<Step title="Send Usage Events">
يرسل تطبيقك الأحداث عند حدوث الإجراءات القابلة للفوترة.

```javascript
{
  "event_id": "evt_123",
  "customer_id": "cus_abc",
  "event_name": "api.call",
  "metadata": { "endpoint": "/v1/users" }
}
```

</Step>

<Step title="Meters Aggregate Usage">
تجمع Meters الأحداث في كميات قابلة للفوترة باستخدام عمليات التجميع Count أو Sum أو Max أو Last.
</Step>

<Step title="Automatic Billing">
حدّد السعر لكل وحدة والحدود المجانية. تتم فوترة العملاء تلقائياً في كل دورة.
</Step>
</Steps>

## المفاهيم الأساسية

### الأحداث

تمثل الأحداث إجراءات الاستخدام في تطبيقك. ويتضمن كل حدث:
- **اسم الحدث**: نوع الاستخدام (مثل `api.call`)
- **معرّف العميل**: الجهة التي استخدمته
- **البيانات الوصفية**: خصائص إضافية للتجميع

### Meters

تجمع Meters الأحداث في كميات قابلة للفوترة:
- **Count**: إجمالي الأحداث (استدعاءات API)
- **Sum**: جمع القيم (إجمالي وحدات البايت)
- **Max**: أعلى قيمة (عدد المستخدمين الأقصى)
- **Last**: أحدث قيمة

### المنتجات ذات تسعير الاستخدام

حدّد السعر لكل وحدة والحدود المجانية الاختيارية:

<Frame>

**مثال**: 2,500 استدعاء - 1,000 مجاناً = 1,500 × $0.02 = $30.00

### الخصم القائم على الرصيد

بدلاً من فرض رسوم بالدولار لكل وحدة، يمكنك ضبط Meters للخصم من [رصيد العميل](/features/credit-based-billing). يتم تحديث الأرصدة في كل دورة فوترة، وتُطبّق قبل أي رسوم تجاوز.

## البدء السريع

<Steps>
<Step title="Create a Meter">
في لوحة التحكم لديك: **Meters** ← **إنشاء Meter**

1. حدّد اسم الحدث (مثل `api.call`)
2. اختر عملية التجميع (Count أو Sum أو Max أو Last)
3. أضف الفلاتر الاختيارية
</Step>

<Step title="Add to Product">
اربط Meter بمنتج يتضمن تسعيراً:

<Frame>
<img src="/images/usage-based/UBB-5.png" alt="إضافة Meter إلى منتج" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

1. اختر **الفوترة حسب الاستخدام**
2. اختر Meter الخاص بك
3. حدّد السعر لكل وحدة والحد المجاني
</Step>

<Step title="Send Events">

```javascript
await fetch('https://test.dodopayments.com/events/ingest', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.DODO_PAYMENTS_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    events: [{
      event_id: "unique_event_id",
      customer_id: "cus_abc123",
      event_name: "api.call",
      metadata: { endpoint: "/v1/users" }
    }]
  })
});
```

</Step>

<Step title="Monitor Usage">
<Frame>
<img src="/images/guides/usage-based-billing/meter-quantities-chart.png" alt="لوحة معلومات Meter" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

تحقق من لوحة معلومات Meter للاطلاع على الأحداث وتجميع الاستخدام. تتم فوترة العملاء تلقائياً في كل دورة.
</Step>
</Steps>

## حالات الاستخدام

<CardGroup cols={2}>
<Card title="APIs & Infrastructure" icon="cloud">
تتبّع استدعاءات API وساعات الحوسبة وعرض النطاق الترددي والتخزين. مثال: $0.001 لكل استدعاء بعد 10,000 استدعاء مجاني.
</Card>

<Card title="AI Usage Tracking" icon="brain">
تتبّع الرموز وعمليات الإنشاء ووقت المعالجة. مثال: \$0.04 لكل صورة قياسية، و\$0.08 لكل صورة عالية الدقة.
</Card>

<Card title="Data & Analytics" icon="chart-line">

</Card>

<Card title="Communication" icon="message">
احسب عدد الرسائل والدقائق والبيانات المنقولة. مثال: $0.01 لكل رسالة SMS مُرسلة.
</Card>
</CardGroup>
