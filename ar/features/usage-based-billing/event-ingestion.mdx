تُعد الأحداث أساس الفوترة القائمة على الاستخدام. أرسل الأحداث عند وقوع الإجراءات القابلة للفوترة، وتعمل العدادات على تجميعها وتحويلها إلى رسوم.

<Card title="API Reference - Events Ingestion" icon="code" href="/api-reference/usage-events/ingest-events">
توثيق كامل لـ API مع أمثلة ورموز استجابة.
</Card>

## بنية الحدث

<Accordion title="Required Fields">
<ParamField body="event_id" type="string" required>
معرّف فريد. استخدم UUIDs أو ادمج معرّف العميل + الطابع الزمني + الإجراء.
</ParamField>

<ParamField body="customer_id" type="string" required>
Dodo Payments معرّف العميل. يجب أن يكون عميلاً موجوداً وصالحاً.
</ParamField>

<ParamField body="event_name" type="string" required>
نوع الحدث الذي يطابق اسم حدث العداد (حساس لحالة الأحرف). أمثلة: `api.call`، `image.generated`
</ParamField>
</Accordion>

<Accordion title="Optional Fields">

<ParamField body="timestamp" type="string">
طابع زمني بتنسيق ISO 8601 (بالتوقيت العالمي المنسق UTC). يتم تعيينه افتراضيًا إلى وقت الخادم الحالي إذا لم يتم تضمينه. قم بتضمينه لضمان دقة الفوترة مع الأحداث المؤجلة/المجمعة. يتم رفض الطوابع الزمنية الأقدم من ساعة واحدة أو التي تتجاوز 5 دقائق في المستقبل.
</ParamField>

<ParamField body="metadata" type="object">
خصائص إضافية للتجميع والتصفية:
- القيم الرقمية: `bytes`، `tokens`، `duration_ms`
- عوامل التصفية: `endpoint`، `method`، `quality`

```javascript
metadata: {
  endpoint: "/v1/orders",
  method: "POST",
  tokens: 1024
}
```

</ParamField>
</Accordion>

## إرسال الأحداث

<CodeGroup>

```javascript Single Event
await fetch('https://test.dodopayments.com/events/ingest', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.DODO_PAYMENTS_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    events: [{
      event_id: "api_call_1234",
      customer_id: "cus_abc123",
      event_name: "api.call",
      metadata: { endpoint: "/v1/orders" }
    }]
  })
});
```

```javascript Batch Events
await fetch('https://test.dodopayments.com/events/ingest', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.DODO_PAYMENTS_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    events: [
      { event_id: "call_1", customer_id: "cus_abc", event_name: "api.call" },
      { event_id: "call_2", customer_id: "cus_abc", event_name: "api.call" },
      { event_id: "call_3", customer_id: "cus_abc", event_name: "api.call" }
    ]
  })
});
```

```python Python
import requests

requests.post(
    'https://test.dodopayments.com/events/ingest',
    headers={'Authorization': f'Bearer {api_key}', 'Content-Type': 'application/json'},
    json={'events': [{'event_id': 'call_1', 'customer_id': 'cus_abc', 'event_name': 'api.call'}]}
)
```

```curl cURL
curl -X POST 'https://test.dodopayments.com/events/ingest' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"events": [{"event_id": "call_1", "customer_id": "cus_abc", "event_name": "api.call"}]}'
```

</CodeGroup>

<Tip>
أرسل ما يصل إلى 1,000 حدث في كل طلب لتحسين الأداء. تفرض API حداً أقصى ثابتاً يبلغ 1,000 حدث لكل استدعاء.
</Tip>

## أفضل الممارسات

<AccordionGroup>
<Accordion title="Use Unique Event IDs">
استخدم معرّفات حتمية لمنع التكرارات: `${customerId}_${action}_${timestamp}`
</Accordion>

<Accordion title="Implement Retries">
أعد المحاولة عند حدوث أخطاء 5xx باستخدام التراجع الأسي. لا تُعد المحاولة عند حدوث أخطاء 4xx.
</Accordion>

<Accordion title="Include Timestamps">
احذفه من الأحداث الفورية. أدرجه في الأحداث المتأخرة/المجمعة لضمان الدقة.
</Accordion>

<Accordion title="Monitor Delivery">
تتبع معدلات النجاح وضع الأحداث الفاشلة في قائمة انتظار لإعادة المحاولة.
</Accordion>
</AccordionGroup>

## استكشاف الأخطاء وإصلاحها

<AccordionGroup>
<Accordion title="Events not appearing">
- يجب أن يطابق اسم الحدث العداد تماماً (حساس لحالة الأحرف)
- يجب أن يكون معرّف العميل موجوداً
- تحقق من أن عوامل تصفية العداد لا تستبعد الأحداث
- تحقق من أن الطوابع الزمنية حديثة
</Accordion>

<Accordion title="Authentication errors (401)">
تحقق من صحة API key واستخدم التنسيق: `Bearer YOUR_API_KEY`
</Accordion>

<Accordion title="Validation errors (400)">
تأكد من وجود جميع الحقول المطلوبة: `event_id`، `customer_id`، `event_name`
</Accordion>

<Accordion title="Metadata not aggregating">
- يجب أن تتطابق مفاتيح Metadata تماماً مع قيمة "Over Property" في العداد
- استخدم أرقاماً، وليس سلاسل نصية: `tokens: 150` وليس `tokens: "150"`
</Accordion>
</AccordionGroup>
