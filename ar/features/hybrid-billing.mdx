## ما الفوترة الهجينة؟

تجمع الفوترة الهجينة بين أبعاد تسعير متعددة ضمن عرض منتج واحد. وبدلاً من الاختيار بين الاشتراكات ذات السعر الثابت أو التسعير القائم على الاستخدام، يمكنك استخدام النموذجين معًا.

### لماذا تستخدم الفوترة الهجينة؟

| الهدف التجاري | الحل الهجين |
|--------------|-----------------|
| إيرادات يمكن التنبؤ بها + إمكانية النمو | اشتراك أساسي + تجاوز الاستخدام |
| تسعير الفرق القابل للتوسع | لكل مقعد + إضافات الميزات |
| استقطاب العملاء ثم التوسع لاحقًا | رسوم أساسية منخفضة + رسوم الاستهلاك |
| مرونة المؤسسات | إنفاق ملتزم به + رسوم عند الطلب |
| تسعير عادل للاستخدام المتغير | حصة مشمولة + الدفع حسب الاستخدام |

### الأنماط الهجينة الشائعة

| النموذج | الوصف | المثال | الدعم الأصلي |
|-------|-------------|---------|----------------|
| **1. الاشتراك + الاستخدام** | رسوم أساسية + رسوم الاستهلاك | \$49/شهريًا + \$0.01/استدعاء API بعد 10 آلاف مجانًا | ✅ كامل |
| **2. الاشتراك + المقاعد** | رسوم المنصة + رسوم لكل مستخدم | \$99/شهريًا + \$15/مقعد | ✅ كامل |
| **3. الاشتراك + إضافات الميزات** | الخطة الأساسية + ترقيات اختيارية | \$29/شهريًا + \$19/شهريًا للتحليلات + \$9/شهريًا للوصول إلى API | ✅ كامل |
| **4. المقاعد + الاستخدام** | رسوم لكل مستخدم + تجاوز الاستهلاك | \$10/مستخدم/شهريًا + \$0.05/GB بعد 5GB/مستخدم | ⚠️ حل بديل |
| **5. الاشتراك + المقاعد + الاستخدام** | المنصة + المستخدمون + الاستهلاك (هجين ثلاثي) | \$199/شهريًا + \$20/مقعد + تجاوز الاستخدام | ⚠️ حل بديل |
| **6. الأساس المتدرج + تجاوز الاستخدام** | مستويات مختلفة بحصص مختلفة | المبتدئة (5 آلاف استدعاء) مقابل الاحترافية (50 ألف استدعاء) + التجاوز | ✅ كامل |
| **7. الاشتراك + الرسوم عند الطلب** | رسوم متكررة + رسوم يدوية متغيرة | مبلغ احتفاظ قدره \$99/شهريًا + فوترة العمل بالساعة | ✅ كامل |

## النموذج الهجين 1: الاشتراك + الاستخدام

هذا هو النموذج الهجين الأكثر شيوعًا. يدفع العملاء رسوم اشتراك أساسية، بالإضافة إلى رسوم الاستهلاك الذي يتجاوز الحصص المشمولة.

### آلية العمل

**الخطة الاحترافية: $49/شهريًا**

- **المشمول**: 10,000 استدعاء API/شهريًا
- **التجاوز**: $0.005 لكل استدعاء بعد 10,000

**حساب نموذجي** (يستخدم العميل 25,000 استدعاء هذا الشهر):
- الاشتراك الأساسي: $49.00
- التجاوز: (25,000 - 10,000) × $0.005 = $75.00
- **الإجمالي: $124.00**

### حالات الاستخدام

- **منصات API**: وصول أساسي + رسوم لكل طلب
- **خدمات AI/ML**: اشتراك + استخدام الرموز/التوليد
- **خدمات التخزين**: خطة أساسية + تجاوز لكل GB
- **منصات الاتصالات**: رسوم أساسية + رسوم لكل رسالة/دقيقة

### التنفيذ

<Steps>
<Step title="Create Usage Meter">
أنشئ مقياسًا لتتبع بُعد الاستخدام القابل للفوترة.

```bash
Dashboard: Meters → Create Meter
Event Name: "api.call"
Aggregation: Count
This tracks API calls per customer
```

</Step>

<Step title="Create Subscription Product with Usage Pricing">
أنشئ منتج اشتراك وأرفق به مقياس الاستخدام مع التسعير.

```bash

Name: "Pro Plan"
Base Price: $49/month

Then attach usage pricing:
- Meter: api.call
- Price per unit: $0.005
- Free threshold: 10,000 (included in subscription)
```

<Info>
يُرفق مقياس الاستخدام مباشرةً بمنتج الاشتراك. تُحسب رسوم الاستخدام وتُضاف إلى فاتورة الاشتراك تلقائيًا.
</Info>
</Step>

<Step title="Create Checkout Session">
أنشئ جلسة دفع باستخدام منتج الاشتراك الخاص بك.


</Step>

### تنويعات التسعير

<Tabs>
<Tab title="Included Allowance">
تغطي العتبة المجانية الاستخدام المشمول في الاشتراك الأساسي.

**الخطة الاحترافية: $49/شهريًا**
- تشمل: 10,000 استدعاء API
- التجاوز: $0.005/استدعاء بعد 10,000
- يستخدم العميل 8,000 ← يدفع $49 (من دون تجاوز)
</Tab>

<Tab title="Zero Base + Pure Usage">

**الدفع حسب الاستخدام: أساس $0/شهريًا**
- تشمل: 0 من استدعاءات API
- الاستخدام: $0.01/استدعاء منذ أول استدعاء
- يستخدم العميل 5,000 ← يدفع $50
</Tab>

<Tab title="Tiered Allowances">
تتضمن المستويات المختلفة حصصًا مختلفة.

- **المبتدئة**: $19/شهريًا (تشمل 1,000 استدعاء)
- **الاحترافية**: $49/شهريًا (تشمل 10,000 استدعاء)
- **المؤسسات**: $199/شهريًا (تشمل 100,000 استدعاء)
- جميع المستويات: تجاوز بقيمة $0.005/استدعاء
</Tab>
</Tabs>

## النموذج الهجين 2: الاشتراك + المقاعد

رسوم المنصة بالإضافة إلى رسوم لكل مستخدم. مثالي لأدوات التعاون الجماعي وSaaS الموجهة إلى الشركات.

### آلية العمل

**خطة الفريق: $99/شهريًا + $15/مقعد**

- **رسوم المنصة الأساسية**: $99/شهريًا (تشمل 3 مقاعد)
- **المقاعد الإضافية**: $15/مقعد/شهريًا

**حساب نموذجي** (فريق مكوّن من 12 مستخدمًا):
- رسوم المنصة: $99.00
- المقاعد الإضافية: (12 - 3) × $15 = $135.00
- **الإجمالي: $234.00/شهريًا**

### حالات الاستخدام

- **أدوات التعاون**: رسوم مساحة العمل + رسوم لكل عضو
- **أنظمة CRM**: ترخيص المنصة + رسوم لكل مندوب مبيعات
- **إدارة المشاريع**: خطة الفريق + رسوم لكل مساهم
- **أدوات المطورين**: رسوم المؤسسة + رسوم لكل مطور

### التنفيذ

<Steps>
<Step title="Create Seat Add-on">
أنشئ إضافة للمقاعد الإضافية.

```bash

Name: "Additional Seat"
Price: $15/month
Description: "Add another team member"
```

</Step>

<Step title="Create Base Subscription">
أنشئ منتج الاشتراك مع رسوم المنصة وأرفق الإضافة به.

```bash

Name: "Team Plan"
Price: $99/month
Description: "Includes 3 team members"

Then in Add-ons section:
- Attach: "Additional Seat" add-on
```

</Step>

<Step title="Create Checkout with Seats">
حدّد عدد المقاعد أثناء الدفع.

```typescript

    product_id: 'pdt_team_plan',

  }],

```

</Step>

<Step title="Adjust Seats as Needed">
أضف المقاعد أو أزلها من الاشتراكات الحالية.

```typescript
  }]

```

</Step>
</Steps>

### تنويعات التسعير

<Tabs>
<Tab title="Included Seats">
تتضمن الخطة الأساسية بعض المقاعد، وتُفرض رسوم على المقاعد الإضافية.

**خطة الفريق: $99/شهريًا**
- تشمل: 5 مقاعد
- المقاعد الإضافية: $15/مقعد/شهريًا
- 20 مستخدمًا = \$99 + (15 × \$15) = \$324/شهريًا
</Tab>

<Tab title="Pure Per-Seat">
لا توجد رسوم للمنصة، وتُفرض رسوم على كل مستخدم فقط.

**لكل مستخدم: $25/مستخدم/شهريًا**
- لا توجد رسوم للمنصة
- 5 مستخدمين = $125/شهريًا
- 50 مستخدمًا = $1,250/شهريًا

التنفيذ: اضبط سعر الاشتراك الأساسي على $0، واستخدم إضافة المقاعد فقط.
</Tab>

<Tab title="Tiered Per-Seat">
ينخفض سعر المقعد عند المستويات الأعلى.

- **المبتدئة**: $20/مقعد (من 1 إلى 10 مقاعد)
- **النمو**: $15/مقعد (من 11 إلى 50 مقعدًا)
- **المؤسسات**: $10/مقعد (51 مقعدًا فأكثر)

التنفيذ: أنشئ منتجات اشتراك منفصلة لكل مستوى مع أسعار مختلفة للإضافات.
</Tab>
</Tabs>

## النموذج الهجين 3: الاشتراك + إضافات الميزات

اشتراك أساسي مع ترقيات ميزات اختيارية يمكن للعملاء إضافتها.

### آلية العمل

**الخطة الأساسية: $29/شهريًا**

**الإضافات الاختيارية:**
- التحليلات المتقدمة: +$19/شهريًا
- الوصول إلى API: +$9/شهريًا
- الدعم ذي الأولوية: +$29/شهريًا
- العلامة البيضاء: +$49/شهريًا

**حساب نموذجي** (يختار العميل الخطة الأساسية + التحليلات + الوصول إلى API):
- الخطة الأساسية: $29.00
- التحليلات: $19.00
- الوصول إلى API: $9.00
- **الإجمالي: $57.00/شهريًا**

### حالات الاستخدام

- **منصات SaaS**: الميزات الأساسية + الوحدات المميزة
- **أدوات التسويق**: الأداة الأساسية + عمليات التكامل
- **منتجات التحليلات**: لوحة المعلومات + التقارير المتقدمة
- **برامج الأمان**: الحماية الأساسية + الميزات المتقدمة

## النموذج الهجين 4: المقاعد + الاستخدام

رسوم لكل مستخدم مدمجة مع رسوم قائمة على الاستهلاك. يحصل كل مستخدم على حصة.

<Warning>
**القيد**: لا يدعم Dodo Payments حاليًا إرفاق مقاييس الاستخدام والإضافات بمنتج الاشتراك نفسه. يتطلب هذا النموذج استخدام حل بديل يعتمد على منطق على مستوى التطبيق.
</Warning>

### كيف يعمل

**تحليلات الفريق: 20 دولارًا أمريكيًا/مستخدم/شهر**

**يتضمن كل مستخدم:**
- معالجة بيانات بسعة 5 GB شهريًا
- الاستخدام الزائد: 2 دولار أمريكي/GB بعد الحصة المسموح بها

**مثال على الحساب** (فريق مكوّن من 10 مستخدمين يستخدم 80 GB إجمالًا):
- رسوم المقاعد: 10 × 20 دولارًا أمريكيًا = 200.00 دولار أمريكي
- البيانات المضمنة: 10 × 5 GB = 50 GB
- الاستخدام الزائد: (80 - 50) × 2 دولار أمريكي = 60.00 دولارًا أمريكيًا
- **الإجمالي: 260.00 دولارًا أمريكيًا/شهر**

### حالات الاستخدام

- **منصات التحليلات**: لكل محلل + معالجة البيانات
- **أدوات التصميم**: لكل مصمم + التخزين/عمليات التصدير
- **بيئات التطوير**: لكل مطور + ساعات الحوسبة
- **أدوات التواصل**: لكل مستخدم + حجم الرسائل/المكالمات

### خيارات التنفيذ

نظرًا إلى أنه لا يمكنك إرفاق عدادات الاستخدام والإضافات معًا بالاشتراك نفسه، اختر أحد الأساليب التالية:

```typescript
async function checkUsageOverage(customerId: string) {
  const seatCount = await getSeatCount(customerId);
  const includedGB = seatCount * 5; // 5 GB per user

  const currentUsage = await getUsageFromDodo(customerId);
  const overage = Math.max(0, currentUsage - includedGB);

  return { included: includedGB, used: currentUsage, overage };
}
```

```typescript
    const overageCharge = overageGB * 200; // $2/GB in cents
    await client.subscriptions.charge(subscriptionId, {
      product_price: overageCharge,
```

### إمكانية التنبؤ بالتكلفة

ساعد العملاء على تقدير تكاليفهم:

```typescript
// Provide a cost calculator
function estimateMonthlyCost({
  plan,
  seats,
  expectedUsage,
  addons
}: EstimateParams): number {
  let total = plan.basePrice;

  // Add seat costs
  const extraSeats = Math.max(0, seats - plan.includedSeats);
  total += extraSeats * plan.seatPrice;

  // Add usage overage
  const overage = Math.max(0, expectedUsage - plan.includedUsage);
  total += overage * plan.overageRate;

  // Add feature add-ons
  total += addons.reduce((sum, addon) => sum + addon.price, 0);

  return total;
}
```

## استكشاف أخطاء الفوترة الهجينة وإصلاحها

<AccordionGroup>
<Accordion title="Usage not being tracked correctly">
**الأعراض**: يظهر الاستخدام بقيمة 0 أو بقيم غير صحيحة.

**الحلول**:
1. تحقّق من أن استيعاب الأحداث يعمل (تحقّق من استجابات API)
2. تأكد من أن `customer_id` يطابق عميل الاشتراك
3. تحقّق من أن `event_name` يطابق إعداد العداد
4. تحقّق من أن للأحداث طوابع زمنية صحيحة (وليست مؤرخة في المستقبل)
</Accordion>

<Accordion title="Proration confusion with multiple components">
**الأعراض**: تم تحصيل مبالغ غير متوقعة من العميل عند تغيير الخطط.

**الحلول**:
1. استخدم API ‏`previewChangePlan` لعرض الرسوم الدقيقة قبل التأكيد
2. وضّح أن التقسيط النسبي ينطبق على الاشتراك والإضافات
3. فكّر في استخدام `difference_immediately` لتبسيط فوترة الترقية
</Accordion>

<Accordion title="Free threshold not applying correctly">
**الأعراض**: تم تحصيل رسوم من العميل مقابل استخدام يجب أن يكون مجانيًا.

**الحلول**:
1. تحقّق من إعداد الحد المجاني على المنتج القائم على الاستخدام
2. تحقّق من تطابق وحدة الحد مع تجميع الأحداث (الاستدعاءات مقابل الطلبات)
3. تأكد من إرفاق عداد الاستخدام بمنتج الاشتراك بشكل صحيح
</Accordion>

<Accordion title="Add-ons not appearing in checkout">
