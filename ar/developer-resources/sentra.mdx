## نظرة عامة

تضيف Sentra الذكاء والتنفيذ إلى أعلى حزم Dodo Payments الأساسية. وهي وكيل ذكاء اصطناعي يدمج الفوترة والمدفوعات ويحللها ويتخذ إجراءات بشأنها. تربط Sentra بين SDKs وواجهات API والمحوّلات عبر حزمة تقنياتك (المصادقة وقاعدة البيانات وCRM وغير ذلك)، وتعرض رؤى حول الإيرادات مثل محركات النمو، وتنفّذ إجراءات العملاء مثل ردّ الأموال والترقيات والأرصدة.

<Info>
Sentra متاحة حاليًا في إصدار تجريبي Beta. قد تتغير الميزات وواجهات API وعمليات التكامل بسرعة. نرحب بملاحظاتكم وتقارير الأخطاء أثناء تطويرنا للمنتج!
</Info>

## الإعداد

بعد التثبيت، عليك تهيئة Sentra باستخدام مفتاح API وإعدادات البيئة الخاصة بـ Dodo Payments.

<Steps>
<Step title="Get Your API Key">
1. سجّل الدخول إلى [لوحة معلومات Dodo Payments](https://app.dodopayments.com).
2. انتقل إلى **Developer** › **API Keys**.
3. انسخ مفتاح API الخاص بك.
</Step>

<Step title="Configure Sentra">
1. افتح بيئة التطوير المتكاملة لديك (VS Code أو Cursor أو Windsurf).
2. افتح Command Palette (`Cmd+Shift+P` على macOS / `Ctrl+Shift+P` على Windows/Linux).
3. اكتب "Sentra: Configure" وحدده.
4. أدخل مفتاح API الخاص بـ Dodo Payments عند مطالبتك بذلك.

<Frame>
  <img
    src="/images/sentra/setup.png"
    alt="شاشة إعداد Sentra مع إدخال مفتاح API واختيار البيئة"
    width="50%"
  style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Select Environment Mode">
اختر وضع البيئة:
- **Test Mode**: للتطوير والاختبار
- **Live Mode**: للاستخدام في الإنتاج

<Warning>
ابدأ بـ Test mode للتحقق من إعدادك قبل التبديل إلى Live mode لبيانات الإنتاج.
</Warning>
</Step>

<Step title="Set Model Reasoning Effort">
حدد مستوى جهد الاستدلال المفضل للنموذج:
- **Low**: استجابات أسرع، مناسبة للمهام البسيطة
- **Medium**: أداء متوازن (موصى به)
- **High**: تحليل أكثر شمولًا، مناسب لعمليات التكامل المعقدة
</Step>

<Step title="Complete Setup">
انقر على **Let's go!** لإكمال الإعداد والبدء باستخدام Sentra.

<Check>
تُخزّن مفاتيح API الخاصة بك بأمان في Secret Storage لبيئة التطوير المتكاملة، ولا تُكشف مطلقًا في التعليمات البرمجية الخاصة بك.
</Check>
</Step>
</Steps>

## استخدام Sentra

### الأوضاع

تقدم Sentra ثلاثة أوضاع للتفاعل يمكن الوصول إليها من الواجهة:

- **Ask**: اطرح أسئلة حول Dodo Payments ونماذج الفوترة واستخدام API وأفضل الممارسات
- **Build**: ادمج الفوترة وواجهة المستخدم في تطبيقك بمساعدة إرشادية
- **Plan**: صمّم بنى فوترة قابلة للتوسع مع إرشادات معمارية

### أمثلة على المهام

إليك بعض المهام الشائعة التي يمكنك إنجازها باستخدام Sentra:

- **دمج صفحة التسعير**: إعداد صفحة تسعير كاملة مع قوائم المنتجات وإتمام الدفع
- **تنفيذ Webhook**: تهيئة معالجات Webhook لأحداث الدفع
- **إضافة تدفق الاشتراك**: إنشاء إدارة للاشتراكات مع إمكانات الترقية والتخفيض
- **إعداد الفوترة القائمة على الاستخدام**: تهيئة العدادات واستقبال الأحداث لتتبع الاستخدام
- **إنشاء Customer Portal**: إنشاء بوابة خدمة ذاتية للعملاء لإدارة الفوترة

### إعدادات الموافقة التلقائية

يمكنك تهيئة إعدادات الموافقة التلقائية لتبسيط سير عملك:

- **None**: مراجعة جميع التغييرات والموافقة عليها يدويًا (موصى به للإنتاج)
- **Low Risk**: الموافقة التلقائية على التغييرات البسيطة منخفضة المخاطر
- **All**: الموافقة التلقائية على جميع التغييرات (استخدمه بحذر)

## نماذج الفوترة المدعومة

تدعم Sentra جميع نماذج الفوترة لدى Dodo Payments:

- **المدفوعات لمرة واحدة**: معاملات شراء فردية
- **الاشتراكات**: فوترة متكررة بفواصل زمنية متعددة
- **الفوترة القائمة على الاستخدام**: فوترة محسوبة وفق الاستهلاك
- **الفوترة القائمة على النتائج**: نماذج تسعير تدفع فيها مقابل كل نتيجة

## لمن صُممت؟

تربط Sentra بين الهندسة والأعمال، بحيث يتمكن كل فريق من إطلاق تحقيق الدخل دون عوائق:

- **المطوّرون**: أطلقوا تحقيق الدخل بشكل أسرع داخل بيئة التطوير المتكاملة
- **المؤسسون ومديرو المنتجات**: أنشئوا نماذج أولية للفوترة دون أعمال بنية تحتية عميقة
- **فرق عمليات الإيرادات والمالية**: استخدموا إجراءات محكومة دون الحاجة إلى المهندسين
- **فرق الدعم ونجاح العملاء**: عالجوا حالات الفوترة بأمان، مع الحصول على الموافقات عند الحاجة

## استكشاف الأخطاء وإصلاحها

<AccordionGroup>
<Accordion title="Extension not appearing after installation">
إذا لم تظهر Sentra في بيئة التطوير المتكاملة لديك بعد التثبيت، فجرّب ما يلي:

1. **أعد تشغيل المحرر**: أغلق VS Code أو Cursor أو Windsurf وافتحه مجددًا بالكامل
2. **تحقق من التثبيت**: تأكد من تثبيت الإضافة بالانتقال إلى Extensions والبحث عن "Sentra"
3. **أعد تحميل النافذة**: استخدم Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`) وشغّل "Developer: Reload Window"

<Check>
تحل إعادة تشغيل المحرر المشكلة في معظم الحالات.
</Check>
</Accordion>

<Accordion title="Invalid API key or authentication errors">
- تحقّق من صحة مفتاح API الخاص بك وتفعيله في لوحة معلومات Dodo Payments
- تأكد من استخدام وضع البيئة الصحيح (Test مقابل Live) المتوافق مع مفتاح API الخاص بك
- تحقّق من امتلاك مفتاح API الأذونات اللازمة
- حاول إنشاء مفتاح API جديد إذا استمرت المشكلة
</Accordion>

<Accordion title="Configuration not saving">
- تأكد من إكمال جميع الحقول المطلوبة في شاشة الإعداد
- تحقّق من امتلاك بيئة التطوير المتكاملة الإذن للوصول إلى Secret Storage
- حاول إعادة تهيئة Sentra من خلال Command Palette
</Accordion>

<Accordion title="Plan generation fails">
- تحقّق من صلاحية مفتاح API وإمكانية وصوله إلى الموارد المطلوبة
- تحقّق من اتصالك بالإنترنت
- تأكد من استخدام نموذج فوترة مدعوم
- حاول إعادة صياغة مطالبتك بمزيد من التفاصيل المحددة
</Accordion>

<Accordion title="Execution errors">
- راجع الخطة التي تم إنشاؤها بعناية قبل الموافقة
- تحقّق من توافق بنية مشروعك مع توقعات Sentra
- تأكد من تثبيت جميع التبعيات
- تحقّق من لوحة الإخراج في بيئة التطوير المتكاملة للاطلاع على رسائل الخطأ التفصيلية
</Accordion>
</AccordionGroup>

<Warning>
إذا استمرت المشكلات بعد إعادة تشغيل المحرر، فاتصل بالدعم مع تقديم تفاصيل حول إصدار بيئة التطوير المتكاملة لديك ورسائل الخطأ المحددة التي تظهر لك.
</Warning>
