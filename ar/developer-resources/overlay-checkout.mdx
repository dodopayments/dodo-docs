## نظرة عامة

يوفر Checkout SDK الخاص بـ Dodo Payments طريقة سلسة لدمج نافذة الدفع overlay الخاصة بنا في تطبيق الويب لديك. وقد بُني باستخدام TypeScript ومعايير الويب الحديثة، ويوفر حلاً موثوقًا لمعالجة المدفوعات، مع معالجة الأحداث في الوقت الفعلي وإمكانية تخصيص السمات.

## بدء سريع

ابدأ باستخدام Checkout SDK الخاص بـ Dodo Payments من خلال بضعة أسطر من التعليمات البرمجية فقط:

```typescript
import { DodoPayments } from "dodopayments-checkout";

// Initialize the SDK
DodoPayments.Initialize({
  mode: "test", // 'test' or 'live'
  displayType: "overlay", // Optional: defaults to 'overlay' for overlay checkout
  onEvent: (event) => {
    console.log("Checkout event:", event);
  },
});

// Open checkout
DodoPayments.Checkout.open({
  checkoutUrl: "https://checkout.dodopayments.com/session/cks_123"
});
```

<Tip>
احصل على عنوان URL للدفع من [create checkout session API](/api-reference/checkout-sessions/create).
</Tip>

<Step title="Create a Checkout Button Component">

أنشئ مكوّنًا يفتح نافذة الدفع overlay:

```typescript
// components/CheckoutButton.tsx
"use client";

import { Button } from "@/components/ui/button";
import { DodoPayments } from "dodopayments-checkout";
import { useEffect, useState } from "react";

export function CheckoutButton() {
  const [isLoading, setIsLoading] = useState(false);

  useEffect(() => {
    // Initialize the SDK
    DodoPayments.Initialize({
      mode: "test",
      displayType: "overlay",
      onEvent: (event) => {
        switch (event.event_type) {
          case "checkout.opened":
            setIsLoading(false);
            break;
          case "checkout.error":
            setIsLoading(false);
            console.error("Checkout error:", event.data?.message);
            break;
        }
      },
    });
  }, []);

  const handleCheckout = async () => {
    try {
      setIsLoading(true);
      await DodoPayments.Checkout.open({
        checkoutUrl: "https://checkout.dodopayments.com/session/cks_123"
      });
    } catch (error) {
      console.error("Failed to open checkout:", error);
      setIsLoading(false);
    }
  };

  return (
    <Button 
      onClick={handleCheckout}
      disabled={isLoading}
    >
      {isLoading ? "Loading..." : "Checkout Now"}
    </Button>
  );
}
```

## مرجع API

### الإعدادات

#### خيارات التهيئة

```typescript
interface InitializeOptions {
  mode: "test" | "live";
  displayType?: "overlay" | "inline";
  onEvent: (event: CheckoutEvent) => void;
}
```

| الخيار | النوع | مطلوب | الوصف |
|--------|------|----------|-------------|
| `mode` | `"test" \| "live"` | نعم | وضع البيئة: `'test'` للتطوير، و`'live'` للإنتاج |
| `displayType` | `"overlay" \| "inline"` | لا | نوع العرض: `'overlay'` للدفع عبر نافذة modal (افتراضيًا)، و`'inline'` للدفع المضمّن |
| `onEvent` | `function` | نعم | دالة callback لمعالجة أحداث الدفع |

#### خيارات الدفع

```typescript
interface CheckoutOptions {
  checkoutUrl: string;
  options?: {
    showTimer?: boolean;
    showSecurityBadge?: boolean;
  };
}
```

| الخيار | النوع | مطلوب | الوصف |
|--------|------|----------|-------------|
| `checkoutUrl` | `string` | نعم | عنوان URL لجلسة الدفع من [create checkout session API](/api-reference/checkout-sessions/create) |
| `options.showTimer` | `boolean` | لا | إظهار مؤقت الدفع أو إخفاؤه. القيمة الافتراضية هي `true`. عند تعطيله، ستتلقى حدث `checkout.link_expired` عند انتهاء الجلسة. |
| `options.showSecurityBadge` | `boolean` | لا | إظهار شارة الأمان أو إخفاؤها. القيمة الافتراضية هي `true`. |

### Methods

#### فتح عملية الدفع

يفتح نافذة الدفع overlay باستخدام عنوان URL المحدد لجلسة الدفع.

```typescript
DodoPayments.Checkout.open({
  checkoutUrl: "https://checkout.dodopayments.com/session/cks_123"
});
```

يمكنك أيضًا تمرير خيارات إضافية لتخصيص سلوك الدفع:

```typescript
DodoPayments.Checkout.open({
  checkoutUrl: "https://checkout.dodopayments.com/session/cks_123",
  options: {
    showTimer: false,
    showSecurityBadge: false,
  },
});
```

#### إغلاق عملية الدفع

يغلق نافذة الدفع overlay برمجيًا.

```typescript
DodoPayments.Checkout.close();
```

#### التحقق من الحالة

يعيد ما إذا كانت نافذة الدفع overlay مفتوحة حاليًا.

```typescript
const isOpen = DodoPayments.Checkout.isOpen();
// Returns: boolean
```

### الأحداث

يوفر SDK أحداثًا في الوقت الفعلي يمكنك الاستماع إليها من خلال callback `onEvent`:

```typescript
DodoPayments.Initialize({
  onEvent: (event: CheckoutEvent) => {
    switch (event.event_type) {
      case "checkout.opened":
        // Checkout overlay has been opened
        break;
      case "checkout.form_ready":
        // Checkout form is ready for user input
        break;
      case "checkout.payment_page_opened":
        // Payment page has been displayed
        break;
      case "checkout.customer_details_submitted":
        // Customer and billing details submitted
        break;
      case "checkout.closed":
        // Checkout has been closed
        break;
      case "checkout.redirect":
        // Checkout will perform a redirect
        break;
      case "checkout.error":
        // An error occurred
        console.error("Error:", event.data?.message);
        break;
      case "checkout.link_expired":
        // Checkout session has expired (only when showTimer is false)
        break;
    }
  }
});
```

| نوع الحدث | الوصف |
|------------|-------------|
| `checkout.opened` | تم فتح نافذة الدفع overlay |
| `checkout.form_ready` | نموذج الدفع جاهز لاستقبال إدخال المستخدم. مفيد لإخفاء حالات التحميل. |
| `checkout.payment_page_opened` | تم عرض صفحة الدفع |
| `checkout.customer_details_submitted` | تم إرسال بيانات العميل والفوترة |
| `checkout.closed` | تم إغلاق نافذة الدفع overlay |
| `checkout.redirect` | سينفّذ الدفع عملية إعادة توجيه |
| `checkout.error` | حدث خطأ أثناء الدفع |
| `checkout.link_expired` | يُطلَق عند انتهاء جلسة الدفع. لا يتم تلقيه إلا عند ضبط `showTimer` على `false`. |

### تخصيص السمة

يمكنك تخصيص مظهر الدفع من خلال تمرير كائن `themeConfig` في المعامل `options` عند فتح الدفع. يدعم إعداد السمة الوضعين الفاتح والداكن، ما يتيح لك تخصيص الألوان والحدود والنصوص والأزرار ونصف قطر الحدود.

<Warning>
خيار `themeConfig` من جهة العميل **مهمل** وسيُزال في الإصدار الرئيسي التالي من Checkout SDK (v2.0.0). يؤدي تمريره إلى تسجيل تحذير بشأن الإهمال في وحدة تحكم المتصفح. بدلاً من ذلك، اضبط السمة عند إنشاء جلسة الدفع عبر API باستخدام المعامل `customization.theme_config` — راجع [تخصيص سمة الدفع](/features/checkout#checkout-theme-customization) — أو بصريًا من خلال [صفحة التصميم](/features/design) في لوحة التحكم. تنطبق السمات المُهيّأة على مستوى الجلسة على الدفع overlay والدفع المضمّن والدفع المستضاف على حد سواء.
</Warning>

<Info>
يغطّي هذا القسم إعداد السمة **من جهة العميل** باستخدام Checkout SDK، وهو إعداد **مهمل**. النهج الموصى به هو إعداد السمات **من جهة الخادم** عند إنشاء جلسة دفع عبر API باستخدام المعامل `theme_config`. راجع [تخصيص سمة الدفع](/features/checkout#checkout-theme-customization) للإعداد على مستوى API، أو استخدم [صفحة التصميم](/features/design) في لوحة التحكم لإعداد السمات بصريًا مع معاينة مباشرة.
</Info>

## معالجة الأخطاء

يوفر SDK معلومات تفصيلية عن الأخطاء من خلال نظام الأحداث. طبّق دائمًا معالجة مناسبة للأخطاء في callback `onEvent`:

```typescript
DodoPayments.Initialize({
  mode: "test",
  displayType: "overlay",
  onEvent: (event: CheckoutEvent) => {
    if (event.event_type === "checkout.error") {
      console.error("Checkout error:", event.data?.message);
      // Handle error appropriately
      // You may want to show a user-friendly error message
      // or retry the checkout process
    }
    if (event.event_type === "checkout.link_expired") {
      // Handle expired checkout session
      console.warn("Checkout session has expired");
    }
  }
});
```

<Warning>
عالج دائمًا حدث `checkout.error` لتوفير تجربة مستخدم جيدة عند حدوث الأخطاء.
</Warning>

## أفضل الممارسات

1. **التهيئة مرة واحدة**: هيّئ SDK مرة واحدة عند تحميل التطبيق، وليس عند كل محاولة دفع
2. **معالجة الأخطاء**: طبّق دائمًا معالجة مناسبة للأخطاء في callback الأحداث
3. **وضع الاختبار**: استخدم وضع `test` أثناء التطوير، وانتقل إلى `live` فقط عند الاستعداد للإنتاج
4. **معالجة الأحداث**: عالج جميع الأحداث ذات الصلة لتوفير تجربة مستخدم متكاملة
5. **عناوين URL صالحة**: استخدم دائمًا عناوين URL صالحة للدفع من create checkout session API
6. **TypeScript**: استخدم TypeScript لتحسين أمان الأنواع وتجربة المطور
7. **حالات التحميل**: اعرض حالات التحميل أثناء فتح الدفع لتحسين تجربة المستخدم
8. **إدارة المؤقت**: عطّل المؤقت (`showTimer: false`) إذا كنت تريد معالجة انتهاء الجلسة يدويًا

**الحلول:**
- تحقّق من حدوث تهيئة SDK قبل فتح الدفع
- تحقّق من وجود أخطاء في وحدة التحكم
- تأكّد من أن عنوان URL للدفع صالح ومن create checkout session API
- تحقّق من اتصال الشبكة

</Accordion>

<Accordion title="Events not firing">

**الأسباب المحتملة:**
- لم تتم تهيئة معالج الأحداث بشكل صحيح
- أخطاء JavaScript تمنع انتشار الأحداث
- لم تتم تهيئة SDK بشكل صحيح

**الحلول:**
- أكّد تهيئة معالج الأحداث بشكل صحيح في `Initialize()`
- تحقّق من وحدة تحكم المتصفح بحثًا عن أخطاء JavaScript
- تحقّق من اكتمال تهيئة SDK بنجاح
- اختبر أولًا باستخدام معالج أحداث بسيط

</Accordion>

<Accordion title="Styling issues">

**الأسباب المحتملة:**
- تعارض CSS مع أنماط تطبيقك
- لم يتم تطبيق إعدادات السمة بشكل صحيح
- مشكلات في التصميم المتجاوب

**الحلول:**
- تحقّق من تعارضات CSS في أدوات مطوري المتصفح
- تحقّق من صحة إعدادات السمة
- اختبر على أحجام شاشات مختلفة
- تأكّد من عدم وجود تعارضات في z-index مع النافذة overlay

</Accordion>
</AccordionGroup>

## الدفع Overlay مقابل الدفع Inline

اختر نوع الدفع المناسب لحالة الاستخدام لديك:

| الميزة | الدفع Overlay | الدفع Inline |
|---------|-----------------|-----------------|
| مستوى الدمج | نافذة modal فوق الصفحة | مضمّن بالكامل في الصفحة |
| التحكم في التخطيط | محدود | تحكم كامل |
| العلامة التجارية | منفصلة عن الصفحة | سلسة |
| جهد التنفيذ | أقل | أعلى |
| الأنسب لـ | الدمج السريع والصفحات الحالية | صفحات دفع مخصصة وتدفقات عالية التحويل |

<Tip>
استخدم **الدفع overlay** للدمج الأسرع مع إجراء تغييرات بسيطة على صفحاتك الحالية. استخدم **الدفع inline** عندما تريد أقصى قدر من التحكم في تجربة الدفع وعلامة تجارية سلسة.
</Tip>
