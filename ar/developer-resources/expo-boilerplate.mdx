## نظرة عامة

نموذج جاهز للإنتاج لتكامل مدفوعات دودي في تطبيقات إكسبو/React Native. يتضمن هذا القالب إنشاء جلسات الدفع، معالجة المدفوعات، وتكوين TypeScript المناسب لمساعدتك في البدء بقبول المدفوعات في تطبيقك المحمول بسرعة.

<Info>
يستخدم هذا الهيكل SDK لـ Expo مع TypeScript ويتضمن تنفيذاً نموذجياً لجلسات الدفع ومعالجة المدفوعات.
</Info>

## المتطلبات الأساسية

- Node.js 18+
- Expo CLI أو EAS CLI
- حساب مدفوعات دودي (مفتاح API من لوحة التحكم)
- محاكي iOS أو محاكي Android (أو جهاز فعلي)

## البدء السريع

<Steps>
<Step title="Clone the Repository">
استنسخ مستودع الهيكل وانتقل إلى دليل المشروع:

```bash
git clone https://github.com/dodopayments/expo-boilerplate.git
cd expo-boilerplate
```

</Step>

<Step title="Get Your API Credentials">
احصل على بيانات الاعتماد من لوحة تحكم Dodo Payments في وضع الاختبار:

- **مفتاح API**: انتقل إلى **المطور → مفاتيح API** في [لوحة التحكم](https://app.dodopayments.com)

<Tip>
ابدأ بوضع الاختبار لاختبار التكامل بأمان دون معالجة مدفوعات حقيقية.
</Tip>
</Step>

<Step title="Configure Environment Variables">
أنشئ ملف `.env` في الدليل الجذري:

```bash
touch .env
```

أضف بيانات اعتماد مدفوعات دودي الخاصة بك:

```bash .env
EXPO_PUBLIC_DODO_API_KEY=your_test_api_key_here
```

<Warning>
لا تلتزم أبدًا بملف `.env` بنظام التحكم في الإصدارات. فهو مضمن بالفعل في `.gitignore`.
</Warning>

<Warning>
يتم تضمين متغيرات `EXPO_PUBLIC_*` في حزمة JavaScript المشحونة، ويمكن لأي شخص ينزّل تطبيقك قراءتها. مفاتيح Dodo Payments API هي أسرار bearer، لذا استخدم هذا فقط مع مفتاح Test Mode أثناء التطوير. في بيئة الإنتاج، أنشئ جلسات checkout على خادمك الخلفي ومرّر إلى التطبيق فقط `checkout_url` الناتج — راجع [Mobile Integration](/developer-resources/mobile-integration).
</Warning>
</Step>

<Step title="Install Dependencies">
ثبّت حزم npm المطلوبة:

```bash
npm install
```

</Step>

<Step title="Start the Development Server">
شغّل خادم تطوير Expo:

```bash
npx expo start
```

امسح رمز QR باستخدام تطبيق Expo Go على جهازك، أو اضغط `i` لمحاكي iOS أو `a` لمحاكي Android.

<Check>
أنت جاهز لبدء البناء! يتضمن القالب الأساسي شاشات ومكوّنات نموذجية لمساعدتك على فهم عملية التكامل.
</Check>
</Step>
</Steps>

## بنية المشروع

```
expo-boilerplate/
├── app/
│   ├── (tabs)/
│   │   └── index.tsx          # Home screen with examples
│   └── checkout.tsx           # Checkout screen
├── components/
│   └── PaymentButton.tsx      # Payment button component
├── lib/
│   └── dodo.ts                # Dodo Payments client setup
├── .env.example               # Environment variables template
└── package.json
```

## الخطوات التالية

بعد تشغيل القالب الأساسي:

<Steps>
<Step title="Create Your Products">
أضف المنتجات في [لوحة تحكم Dodo Payments](https://app.dodopayments.com) لتمكين وظائف checkout.
</Step>

<Step title="Customize the Integration">
عدّل الشيفرة النموذجية لتتوافق مع احتياجات تطبيقك وتصميمه.
</Step>

<Step title="Test on Real Devices">
اختبر تدفق الدفع على أجهزة فعلية للتأكد من أن كل شيء يعمل بشكل صحيح.
</Step>

<Step title="Go Live">
عندما تصبح جاهزًا، بدّل إلى مفاتيح Live Mode API وأنشئ تطبيقك للإنتاج.
</Step>
</Steps>

## البناء للإنتاج

<Steps>
<Step title="Install EAS CLI">

```bash
npm install -g eas-cli
```

</Step>

<Step title="Configure EAS">

```bash
eas build:configure
```

</Step>

<Step title="Build Your App">
لنظام iOS:

```bash
eas build --platform ios
```

لنظام Android:

```bash
eas build --platform android
```

</Step>
</Steps>
