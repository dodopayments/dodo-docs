يوفر C# SDK وصولًا سهلًا إلى REST API الخاص بـ Dodo Payments من التطبيقات المكتوبة بلغة C#. ويتضمن API قائمًا على async Task مع كتابة قوية، وإعادة محاولات تلقائية، ومعالجة شاملة للأخطاء.

## التثبيت

ثبّت الحزمة من [NuGet](https://www.nuget.org/packages/DodoPayments.Client):

```bash
dotnet add package DodoPayments.Client
```

<Info>
يتطلب SDK الإصدار .NET 8.0 أو إصدارًا أحدث. وهو يعمل مع ASP.NET Core وتطبيقات Console وأنواع مشاريع .NET الأخرى.
</Info>

## البدء السريع

هيّئ العميل وأنشئ جلسة checkout:

```csharp
using System;
using DodoPayments.Client;
using DodoPayments.Client.Models.CheckoutSessions;

// Configured using the DODO_PAYMENTS_API_KEY and DODO_PAYMENTS_BASE_URL environment variables
DodoPaymentsClient client = new();

CheckoutSessionCreateParams parameters = new()
{
    ProductCart =
    [
        new()
        {
            ProductID = "product_id",
            Quantity = 1,
        },
    ],
};

var checkoutSessionResponse = await client.CheckoutSessions.Create(parameters);

Console.WriteLine(checkoutSessionResponse.SessionId);
```

<Warning>
احرص دائمًا على تخزين مفاتيح API بأمان باستخدام متغيرات البيئة أو user secrets أو Azure Key Vault. لا تضعها مطلقًا بشكل مباشر في الكود المصدري أو ترفعها إلى version control.
</Warning>

## الإعداد

### متغيرات البيئة

```bash .env
DODO_PAYMENTS_API_KEY=your_api_key_here
```

```csharp
// Automatically reads from environment variables
DodoPaymentsClient client = new();
```

| الخاصية      | متغير البيئة        | مطلوب | القيمة الافتراضية                     |
| ------------- | --------------------------- | -------- | --------------------------------- |
| `BearerToken` | `DODO_PAYMENTS_API_KEY`     | true     | -                                 |
| `WebhookKey`  | `DODO_PAYMENTS_WEBHOOK_KEY` | false    | -                                 |
| `BaseUrl`     | `DODO_PAYMENTS_BASE_URL`    | true     | `"https://live.dodopayments.com"` |

### الإعداد اليدوي

```csharp
DodoPaymentsClient client = new() { BearerToken = "My Bearer Token" };
```

### البيئات

بدّل بين الوضع المباشر ووضع الاختبار:

```csharp
using DodoPayments.Client.Core;

DodoPaymentsClient client = new() { BaseUrl = EnvironmentUrl.TestMode };
```

### إعادة المحاولات

يعيد SDK المحاولة تلقائيًا مرتين افتراضيًا مع exponential backoff. وتتم إعادة المحاولة عند حدوث أخطاء الاتصال ورموز الحالة 408 و409 و429 و5xx.

```csharp
// Custom retry count
DodoPaymentsClient client = new() { MaxRetries = 3 };
```

### مهلات الانتظار

تنتهي مهلة الطلبات بعد دقيقة واحدة افتراضيًا.

```csharp
DodoPaymentsClient client = new() { Timeout = TimeSpan.FromSeconds(30) };
```

### التجاوزات الخاصة بكل طلب

عدّل الإعداد مؤقتًا لطلب واحد باستخدام `WithOptions`:

```csharp
var response = await client
    .WithOptions(options => options with
    {
        Timeout = TimeSpan.FromSeconds(10),
        MaxRetries = 5,
    })
    .CheckoutSessions.Create(parameters);
```

## العمليات الشائعة

### إنشاء جلسة checkout

```csharp
var parameters = new CheckoutSessionCreateParams
{
    ProductCart =
    [
        new()
        {
            ProductID = "pdt_123",
            Quantity = 1
        }
    ],
    ReturnUrl = "https://yourdomain.com/return"
};

var session = await client.CheckoutSessions.Create(parameters);
Console.WriteLine($"Checkout URL: {session.CheckoutUrl}");
```

### إدارة العملاء

```csharp
// Create a customer
var customer = await client.Customers.Create(new CustomerCreateParams
{
    Email = "customer@example.com",
    Name = "John Doe"
});

// Retrieve customer
var retrieved = await client.Customers.Retrieve(new CustomerRetrieveParams { CustomerID = "cus_123" });
Console.WriteLine($"Customer: {retrieved.Name} ({retrieved.Email})");
```

### معالجة الاشتراكات

<Warning>
`POST /subscriptions` (طريقة `subscriptions.create` في SDK) **مهملة**. لا تزال تعمل مع عمليات التكامل الحالية، ولكن ينبغي لعمليات التكامل الجديدة إنشاء الاشتراكات من خلال [Checkout Session](/developer-resources/checkout-session).
</Warning>

```csharp
using DodoPayments.Client.Models.Payments;
using DodoPayments.Client.Models.Subscriptions;

// Create a subscription
var subscription = await client.Subscriptions.Create(new SubscriptionCreateParams
{
    Billing = new BillingAddress
    {
        Country = "US",
        City = "San Francisco",
        State = "CA",
        Street = "1 Market St",
        Zipcode = "94105",
    },
    Customer = new AttachExistingCustomer { CustomerID = "cus_123" },
    ProductID = "pdt_456",
    Quantity = 1,
});

// Charge an on-demand subscription
// ProductPrice is in the lowest currency denomination (e.g., 2500 = $25.00 USD)
var charge = await client.Subscriptions.Charge(new SubscriptionChargeParams
{
    SubscriptionID = subscription.SubscriptionId,
    ProductPrice = 2500,
});
```

<Info>
يتطلب `Billing` رمز `Country` المكوّن من حرفين وفق معيار ISO كحد أدنى. استخدم `AttachExistingCustomer` لإرفاق عميل حالي، أو `NewCustomer` لإنشاء عميل. تكون قيمة `ProductPrice` بأدنى فئة للعملة.
</Info>

## معالجة الأخطاء

يطرح SDK استثناءات محددة استنادًا إلى رمز حالة HTTP. ترث جميع أخطاء 4xx من `DodoPayments4xxException`.

| الحالة | الاستثناء                                   |
| ------ | ------------------------------------------- |
| 400    | `DodoPaymentsBadRequestException`           |
| 401    | `DodoPaymentsUnauthorizedException`         |
| 403    | `DodoPaymentsForbiddenException`            |
| 404    | `DodoPaymentsNotFoundException`             |
| 422    | `DodoPaymentsUnprocessableEntityException`  |
| 429    | `DodoPaymentsRateLimitException`            |
| 5xx    | `DodoPayments5xxException`                  |
| أخرى | `DodoPaymentsUnexpectedStatusCodeException` |

أنواع الاستثناءات الأخرى:
- `DodoPaymentsIOException`: أخطاء الشبكة المتعلقة بالإدخال والإخراج
- `DodoPaymentsInvalidDataException`: تعذّر تفسير البيانات المحللة
- `DodoPaymentsException`: الفئة الأساسية لجميع الاستثناءات

## ترقيم الصفحات

### ترقيم الصفحات التلقائي

كرّر على جميع النتائج عبر جميع الصفحات باستخدام طريقة `Paginate`، التي تُرجع `IAsyncEnumerable`:

```csharp
var page = await client.Payments.List(parameters);
await foreach (var item in page.Paginate())
{
    Console.WriteLine(item);
}
```

### ترقيم الصفحات اليدوي

```csharp
var page = await client.Payments.List();
while (true)
{
    foreach (var item in page.Items)
    {
        Console.WriteLine(item);
    }
    if (!page.HasNext())
    {
        break;
    }
    page = await page.Next();
}
```

## التكامل مع ASP.NET Core

سجّل العميل في حاوية DI لديك:

```csharp Program.cs
using DodoPayments.Client;

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddSingleton<DodoPaymentsClient>(sp =>
{
    var configuration = sp.GetRequiredService<IConfiguration>();
    return new DodoPaymentsClient
    {
        BearerToken = configuration["DodoPayments:ApiKey"]
    };
});

var app = builder.Build();
app.Run();
```

```json appsettings.json
{
  "DodoPayments": {
    "ApiKey": "your_api_key_here"
  }
}
```

<Tip>
لأغراض التطوير، استخدم [أسرار المستخدم](https://learn.microsoft.com/en-us/aspnet/core/security/app-secrets) بدلًا من تخزين المفاتيح في `appsettings.json`:

```bash
dotnet user-secrets init
dotnet user-secrets set "DodoPayments:ApiKey" "your_api_key_here"
```

</Tip>
