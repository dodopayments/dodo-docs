## التثبيت

<Steps>
<Step title="Install the package">
شغّل الأمر التالي في جذر مشروعك:

```bash
bun add @dodopayments/bun
```

</Step>
<Step title="Set up environment variables">
أنشئ ملف <code>.env</code> في جذر مشروعك:

```env expandable
DODO_PAYMENTS_API_KEY=your-api-key
DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
DODO_PAYMENTS_ENVIRONMENT="test_mode" or "live_mode"
DODO_PAYMENTS_RETURN_URL=your-return-url
```

<Warning>
لا تُضمّن ملف <code>.env</code> أو الأسرار في نظام التحكم بالإصدارات.
</Warning>
</Step>
</Steps>

<Tabs>
<Tab title="Checkout Handler">
  <Info>
  استخدم هذا المعالج لدمج checkout الخاص بـ Dodo Payments في خادم Bun الخاص بك. يدعم تدفقات الدفع الثابتة (GET) والديناميكية (POST) والجلسات (POST).
  </Info>
  <CodeGroup>

    ```typescript Bun Server Handler expandable
    import { Checkout } from '@dodopayments/bun';

    const staticCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "static"
    });

    const sessionCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "session"
    });

    const dynamicCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "dynamic"
    });

    Bun.serve({
      port: 3000,
      fetch(request) {
        const url = new URL(request.url);
        
        if (url.pathname === "/api/checkout") {
          if (request.method === "GET") {
            return staticCheckoutHandler(request);
          }
          if (request.method === "POST") {
            return sessionCheckoutHandler(request);
            // or return dynamicCheckoutHandler(request);
          }
        }
        
        return new Response("Not Found", { status: 404 });
      },
    });
    ```

## Checkout Route Handler

<Info>
يدعم Dodo Payments ثلاثة أنواع من تدفقات الدفع لدمج المدفوعات في موقعك، ويدعم هذا adaptor جميع أنواع تدفقات الدفع.
</Info>

- **روابط الدفع الثابتة:** عناوين URL قابلة للمشاركة فورًا لتحصيل المدفوعات بسرعة ومن دون كتابة تعليمات برمجية.
- **روابط الدفع الديناميكية:** إنشاء روابط دفع برمجيًا مع تفاصيل مخصصة باستخدام API أو SDKs.
- **جلسات Checkout:** إنشاء تجارب checkout آمنة وقابلة للتخصيص مع سلال منتجات وتفاصيل عملاء مُعدّة مسبقًا.

## Webhook Route Handler

- **Method:** لا يتم دعم سوى طلبات POST. وتعيد الطرق الأخرى 405.
- **Signature Verification:** يتحقق من توقيع webhook باستخدام <code>webhookKey</code>. ويعيد 401 عند فشل التحقق.
- **Payload Validation:** يتم التحقق منه باستخدام Zod. ويعيد 400 للـ payload غير الصالح.
- **Error Handling:**
  - 401: توقيع غير صالح
  - 400: payload غير صالح
  - 500: خطأ داخلي أثناء التحقق
- **Event Routing:** يستدعي معالج الحدث المناسب استنادًا إلى نوع payload.
