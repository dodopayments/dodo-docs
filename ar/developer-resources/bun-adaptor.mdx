## التثبيت

<Steps>
<Step title="تثبيت الحزمة">
قم بتشغيل الأمر التالي في جذر مشروعك:

```bash
bun add @dodopayments/bun
```

</Step>
<Step title="إعداد المتغيرات البيئية">
قم بإنشاء ملف <code>.env</code> في جذر مشروعك:

```env expandable
DODO_PAYMENTS_API_KEY=your-api-key
DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
DODO_PAYMENTS_ENVIRONMENT="test_mode" or "live_mode"
DODO_PAYMENTS_RETURN_URL=your-return-url
```

<Warning>
لا تقم بالتزام ملف <code>.env</code> أو الأسرار في التحكم في النسخ.
</Warning>
</Step>
</Steps>

## أمثلة على معالج المسار

<Info>
تُفيد جميع الأمثلة في أنك تستخدم خادم بون الأصلي مع <code>Bun.serve()</code>.
</Info>

<Tabs>
<Tab title="معالج الدفع">
  <Info>
  استخدام هذا المعالج لدمج إجراءات دفع دودي في خادم بون الخاص بك. يدعم تدفقات الدفع الثابتة (GET)، الديناميكية (POST)، والجلسات (POST).
  </Info>
  <CodeGroup>

    ```typescript Bun Server Handler expandable
    import { Checkout } from '@dodopayments/bun';

    const staticCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "static"
    });

    const sessionCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "session"
    });

    const dynamicCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "dynamic"
    });

    Bun.serve({
      port: 3000,
      fetch(request) {
        const url = new URL(request.url);
        
        if (url.pathname === "/api/checkout") {
          if (request.method === "GET") {
            return staticCheckoutHandler(request);
          }
          if (request.method === "POST") {
            return sessionCheckoutHandler(request);
            // or return dynamicCheckoutHandler(request);
          }
        }
        
        return new Response("Not Found", { status: 404 });
      },
    });
    ```

  </CodeGroup>

## معالج مسار الدفع

<Info>
يدعم دودي طرق دفع ثلاث للتكامل مع المدفوعات في موقعك الإلكتروني، يدعم هذا المحول جميع أنواع طرق الدفع.
</Info>

- **روابط الدفع الثابتة:** URLs قابلة للمشاركة الفورية لجمع المدفوعات بسرعة وبدون كود.
- **روابط الدفع الديناميكية:** إنشاء روابط دفع برمجياً مع تفاصيل مخصصة باستخدام API أو SDKs.
- **جلسات الدفع:** إنشاء تجارب دفع آمنة وقابلة للتخصيص مع عربات منتجات محددة مسبقاً وتفاصيل العملاء.

## معالج مسار بوابة العملاء

يسمح لك معالج مسار بوابة العملاء بدمج بوابة عملاء دودي بسلاسة في تطبيق خادم بون الخاص بك.

### معلمات الاستعلام
<ParamField query="customer_id" type="string" required>
معرف العميل لجلسة البوابة (مثل <code>?customer_id=cus_123</code>).
</ParamField>
<ParamField query="send_email" type="boolean">
إذا تم تعيينها إلى <code>true</code>، يتم إرسال بريد إلكتروني للعميل مع رابط البوابة.
</ParamField>

<Warning>
سيعود 400 إذا كانت <code>customer_id</code> مفقودة.
</Warning>

## معالج مسار الواصلة

- **الطريقة:** تدعم فقط طلبات POST. تعود الطرق الأخرى 405.
- **التحقق من التوقيع:** يتحقق من توقيع الواصلة باستخدام <code>webhookKey</code>. تعود 401 إذا فشل التحقق.
- **التحقق من الحمولة:** يتم التحقق منها باستخدام Zod. تعود 400 للحمولات غير الصحيحة.
- **معالجة الأخطاء:**
  - 401: توقيع غير صحيح
  - 400: حمولة غير صحيحة
  - 500: خطأ داخلي أثناء التحقق
- **توجيه الأحداث:** يستدعي المعالج المناسب للأحداث بناءً على نوع الحمولة.

import { Checkout, CustomerPortal, Webhooks } from "@dodopayments/bun";

const staticCheckoutHandler = Checkout({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  type: "static",
});

const sessionCheckoutHandler = Checkout({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  type: "session",
});

const customerPortalHandler = CustomerPortal({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
});

const webhookHandler = Webhooks({
  webhookKey: process.env.DODO_PAYMENTS_WEBHOOK_KEY,
  onPaymentSucceeded: async (payload) => {
    console.log("نجح الدفع:", payload);
    // منطق الأعمال هنا
  },
  onSubscriptionActive: async (payload) => {
    console.log("تم تفعيل الاشتراك:", payload);
    // منطق الأعمال هنا
  },
});

Bun.serve({
  port: 3000,
  fetch(request) {
    const url = new URL(request.url);
    
    // مسارات الدفع
    if (url.pathname === "/api/checkout") {
      if (request.method === "GET") {
        return staticCheckoutHandler(request);
      }
      if (request.method === "POST") {
        return sessionCheckoutHandler(request);
      }
    }
    
    // مسار بوابة العملاء
    if (url.pathname === "/api/customer-portal" && request.method === "GET") {
      return customerPortalHandler(request);
    }
    
    // مسار الواصلة
    if (url.pathname === "/api/webhook/dodo-payments" && request.method === "POST") {
      return webhookHandler(request);
    }
    
    return new Response("غير موجودة", { status: 404 });
  },
});

console.log("الخادم يعمل على http://localhost:3000");
