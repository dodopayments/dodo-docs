Dodo Payments توفر حزم SDK رسمية للعديد من لغات البرمجة، وقد صُممت كل منها وفق أفضل الممارسات الخاصة باللغة والميزات الحديثة لتوفير تكامل سلس مع المدفوعات.

<Tip>
استخدم دائمًا أحدث إصدار من SDK للوصول إلى أحدث الميزات والتحسينات. تحقق بانتظام من وجود تحديثات في مدير الحزم لديك لضمان الوصول إلى جميع إمكانات Dodo Payments.
</Tip>

## البدء السريع

ابدأ باستخدام أي SDK خلال دقائق:

<Steps>
<Step title="Install the SDK">
  استخدم مدير الحزم الخاص بلغتك لتثبيت SDK
  
  <Tabs>
  <Tab title="TypeScript/Node.js">

  ```bash
  npm install dodopayments
  ```

  </Tab>
  
  <Tab title="Python">

  ```bash
  pip install dodopayments
  ```

  </Tab>
  
  <Tab title="PHP">

  ```bash
  composer require dodopayments/client
  ```

  </Tab>
  
  <Tab title="Go">

  ```bash
  go get github.com/dodopayments/dodopayments-go
  ```

  </Tab>

  <Tab title="Rust">

  ```bash
  cargo add dodopayments
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Initialize the Client">
  اضبط إعدادات العميل باستخدام مفتاح API الخاص بك
  
  <Tabs>
  <Tab title="TypeScript">

  ```typescript
  import DodoPayments from 'dodopayments';
  const client = new DodoPayments({ bearerToken: 'your_api_key' });
  ```

  </Tab>
  
  <Tab title="Python">

  ```python
  from dodopayments import DodoPayments
  client = DodoPayments(bearer_token="your_api_key")
  ```

  </Tab>
  
  <Tab title="PHP">

  ```php
  use Dodopayments\Client;
  $client = new Client(bearerToken: 'your_api_key');
  ```

  </Tab>
  
  <Tab title="Go">

  ```go
  import "github.com/dodopayments/dodopayments-go"
  client := dodopayments.NewClient(option.WithBearerToken("your_api_key"))
  ```

  </Tab>

  <Tab title="Rust">

  ```rust
  use dodopayments::Client;
  let client = Client::from_env()?; // reads DODO_PAYMENTS_API_KEY
  ```

  </Tab>
  </Tabs>
  
  <Warning>
  خزّن مفاتيح API دائمًا بأمان باستخدام متغيرات البيئة. لا تضعها أبدًا في نظام التحكم بالإصدارات.
  </Warning>
</Step>

<Step title="Make Your First API Call">
  أنشئ جلسة Checkout أو عملية دفع
  
  <Check>
  أصبحت الآن مستعدًا لمعالجة المدفوعات! انتقل إلى صفحات SDK الفردية للاطلاع على الأدلة والأمثلة التفصيلية.
  </Check>
</Step>
</Steps>

## الميزات الأساسية

تشترك جميع SDKs الخاصة بـ **backend** في هذه الإمكانات الأساسية. أما Mobile Checkout SDKs
أدناه فهي أضيق نطاقًا عمدًا — لا تحتوي على مفتاح API ولا تستدعي API مطلقًا:

- **سلامة الأنواع**: كتابة صارمة لضمان السلامة وقت الترجمة وتحسين دعم IDE
- **معالجة الأخطاء**: معالجة شاملة للاستثناءات مع رسائل خطأ مفصلة
- **المصادقة**: مصادقة بسيطة باستخدام مفتاح API مع دعم متغيرات البيئة
- **دعم العمليات غير المتزامنة**: أنماط async/await الحديثة عند الاقتضاء
- **الترقيم التلقائي للصفحات**: ترقيم تلقائي للصفحات في استجابات القوائم
- **الفوترة القائمة على الاستخدام**: دعم مدمج لتتبع أحداث الاستخدام واستيعابها
- **الاختبار**: دعم كامل لبيئة الاختبار للتطوير والاختبار

## Mobile Checkout SDKs

إذا كنت تفضّل فتح **hosted checkout page** الخاصة بـ Dodo بدلًا من بناء
واجهة دفع أصلية، فاستخدم Mobile Checkout SDK لمنصتك. تشترك SDKs الأربعة جميعًا
في نفس العقد ذي الاستدعاء الواحد: يعيد `start(...)` قيمة `CheckoutResult` مكتوبة النوع،
ولا يحتوي أيٌّ منها على مفتاح API، ويعمل Apple Pay/Google Pay بالطريقة نفسها التييعملان بها على الويب المفتوح، لأن checkout يُفتح في واجهة المتصفح الحقيقية للمنصة
(`SFSafariViewController` / Custom Tabs)، وليس في `WebView`:

<CardGroup cols={2}>
<Card title="Android" icon="android" href="/developer-resources/sdks/android">
  Kotlin SDK يفتح Chrome Custom Tab. يتطلب `minSdk` 23
</Card>

<Card title="iOS" icon="apple" href="/developer-resources/sdks/ios">
  Swift SDK يفتح `SFSafariViewController`. يتطلب iOS 16+
</Card>

<Card title="React Native" icon="react" href="/developer-resources/sdks/react-native">
  Turbo Module يعمل فوق كلا النواتين الأصليتين. يتطلب React Native 0.76+
</Card>

<Card title="Flutter" icon="layer-group" href="/developer-resources/sdks/flutter">
  قناة Pigeon تعمل فوق كلا النواتين الأصليتين. تتطلب Flutter 3.44+
</Card>
</CardGroup>

<Card title="Mobile Integration Guide" icon="mobile" href="/developer-resources/mobile-integration">
  تدفق الدفع عبر الأجهزة المحمولة من البداية إلى النهاية، بدءًا من جلسة checkout في backend ووصولًا إلى إعداد مخطط callback
</Card>

## واجهة سطر الأوامر

لسير العمل والأتمتة المعتمدة على الطرفية:

<Card title="CLI" icon="terminal" href="/developer-resources/sdks/cli">
  واجهة سطر أوامر مُنشأة تلقائيًا مع دعم لـ Dodo Payments API
</Card>

**الميزات:**
- بنية أوامر قائمة على الموارد لاستخدام بديهي
- تنسيقات إخراج متعددة (JSON وYAML ومنسّق وتفاعلي)
- إكمال الأوامر في shell لـ bash وzsh وfish
- مثالية للبرمجة النصية وأتمتة CI/CD

```bash
# Quick example
dodopayments payments list --format json | jq '.items[] | {payment_id, total_amount}'
```
