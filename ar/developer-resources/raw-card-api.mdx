</Note>

## نقاط النهاية الخاصة بواجهة برمجة التطبيقات

| البيئة | عنوان URL الأساسي | نقطة نهاية تأكيد الدفع |
| --- | --- | --- |
| **وضع الاختبار** | `https://test.dodopayments.com` | `https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm` |
| **الوضع المباشر** | `https://live.dodopayments.com` | `https://api.hs.dodopayments.com/payments/<payment_id>/confirm` |

## سير دفع البطاقة خطوة بخطوة

### الخطوة 1: الحصول على السر الخاص بالعميل

ابدأ بإنشاء دفعة باستخدام واجهة برمجة التطبيقات التالية:

- **المدفوعات**: [واجهة برمجة تطبيقات إنشاء الدفع](/api-reference/payments/post-payments)

تُرجع هذه الـ API **`client_secret`**، والمطلوب للخطوات التالية.

<Warning>
`POST /payments` مهجور. يظل متاحًا لتكاملات raw-card لأنه نقطة النهاية الوحيدة التي تُرجع `client_secret`، ولكن بالنسبة إلى جميع تدفقات الدفع الأخرى لمرة واحدة، استخدم [Checkout Sessions](/api-reference/checkout-sessions/create).
</Warning>

### الخطوة 2: تأكيد الدفع

أكّد الدفع باستدعاء نقطة النهاية `payments confirm`:

- **وضع الاختبار**: `POST https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm`
- **الوضع المباشر**: `POST https://api.hs.dodopayments.com/payments/<payment_id>/confirm`

أدرج التفاصيل التالية في نص الطلب:

- `client_secret`: `client_secret` من الخطوة 1
- `payment_method`: اضبطه على `card`
- `payment_method_data`: تفاصيل البطاقة والفوترة
- `browser_info`: بيانات خاصة بالمتصفح (وكيل المستخدم، وتفاصيل الشاشة، وغير ذلك)
- `payment_type`: اضبطه صراحةً على `normal` (للدفعات لمرة واحدة)

الترويسات المطلوبة:

- احصل على مفتاحك القابل للنشر من دعم DodoPayments
- `api-key`: مفتاحك القابل للنشر (احصل عليه من فريق Dodo Payments)
- `content-type`: `application/json`

**نص الطلب النموذجي:**

```json
{
  "client_secret": "<client_secret>",
  "payment_method": "card",
  "payment_method_data": {

      "card_cvc": "<cvc>",
      "card_network": "<network>"
    },
    "billing": {
      "address": {
        "first_name": "<first_name>",
        "last_name": "<last_name>"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
```

تبدو معلومات المتصفح عادةً بهذا الشكل (ستختلف القيم الفعلية):

ينبغي للتجار جمع هذه التفاصيل مباشرةً من متصفح العميل أثناء الدفع.

### معالجة الاستجابة

- إذا كانت الاستجابة **`status`** هي **`requires_customer_action`**، فأعد توجيه العميل إلى عنوان URL المتوفر في الحقل **`next_action`** لإجراء مصادقة إضافية.

<Warning>
تأكد من الالتزام بإرشادات الامتثال لمعيار PCI عند التعامل مع بيانات البطاقة الخام.
</Warning>

## تكامل Apple Pay

لاستخدام Apple Pay، اضبط `payment_method` على `wallet`، وأدرج بيانات Apple Pay في `payment_method_data`.

### بنية نص الطلب

```json
{
  "client_secret": "<client_secret>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "apple_pay": {
        "payment_data": "<decrypted_payment_data>",
        "payment_method": {
          "display_name": "Visa 1234",
          "network": "Visa",
          "type": "debit"
        },
        "transaction_identifier": "UNIQUE_TRANSACTION_ID_FROM_APPLE"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### مرجع حقول Apple Pay

| الحقل | النوع | مطلوب | الوصف |
| --- | --- | --- | --- |
| `payment_data` | string | نعم | يُستخدم هذا التعداد لتمثيل بيانات دفع Apple Pay، والتي يمكن أن تكون مشفّرة أو غير مشفّرة. |
| `payment_method.display_name` | string | نعم | اسم العرض الظاهر على زر Apple Pay (مثل "Visa 1234") |
| `payment_method.network` | string | نعم | شبكة البطاقة (مثل "Visa" أو "Mastercard" أو "Amex") |
| `payment_method.type` | string | نعم | نوع طريقة الدفع (مثل "debit" أو "credit") |
| `payment_method.card_exp_month` | string | لا | شهر انتهاء صلاحية البطاقة (مثل "12") |
| `payment_method.card_exp_year` | string | لا | سنة انتهاء صلاحية البطاقة (مثل "25") |
| `transaction_identifier` | string | نعم | معرّف المعاملة الفريد من Apple Pay |

## تكامل Google Pay

لاستخدام Google Pay، اضبط `payment_method` على `wallet`، وأدرج بيانات Google Pay في `payment_method_data`.

### بنية نص الطلب

```json
{
  "client_secret": "<client_secret>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "google_pay": {
        "type": "CARD",
        "description": "Visa ending in 1234",
        "info": {
          "card_network": "VISA",
          "card_details": "1234"
        },
        "tokenization_data": {
          "type": "PAYMENT_GATEWAY",
          "token": "<encrypted_payment_token>"
        }
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### مرجع حقول Google Pay

| الحقل | النوع | مطلوب | الوصف |
| --- | --- | --- | --- |
| `type` | string | نعم | نوع طريقة الدفع (عادةً "CARD") |
| `description` | string | نعم | وصف طريقة الدفع الظاهر للمستخدم |
| `info.card_network` | string | نعم | شبكة البطاقة (مثل "VISA" أو "MASTERCARD" أو "AMEX") |
| `info.card_details` | string | نعم | آخر 4 أرقام من البطاقة |
| `info.assurance_details` | object | لا | تفاصيل ضمان المصادقة |
| `tokenization_data.type` | string | نعم | نوع إنشاء الرموز (مثل "PAYMENT_GATEWAY") |
| `tokenization_data.token` | string | نعم | رمز الدفع المشفّر من Google Pay |
