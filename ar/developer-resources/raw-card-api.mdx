هذا الدليل يغطي فقط **المدفوعات لمرة واحدة** التي تتضمن **البطاقات، Apple Pay و Google Pay**.
</Note>

## نقاط النهاية لواجهة برمجة التطبيقات

| البيئة | عنوان URL الأساسي | نقطة نهاية تأكيد الدفع |
| --- | --- | --- |
| **وضع الاختبار** | `https://test.dodopayments.com` | `https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm` |
| **الوضع المباشر** | `https://live.dodopayments.com` | `https://api.hs.dodopayments.com/payments/<payment_id>/confirm` |

## تدفق دفع البطاقة خطوة بخطوة

### الخطوة 1: الحصول على المفتاح السري

ابدأ بإنشاء دفع باستخدام واجهة برمجة التطبيقات التالية:

- **المدفوعات**: [إنشاء واجهة برمجة المدفوعات](/api-reference/payments/post-payments)

تُرجع هذه واجهة برمجة التطبيقات **`secret_key`**، المطلوبة للخطوات التالية.

### الخطوة 2: تأكيد الدفع

أكد الدفع من خلال استدعاء نقطة النهاية `payments confirm`:

- **وضع الاختبار**: `POST https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm`
- **الوضع المباشر**: `POST https://api.hs.dodopayments.com/payments/<payment_id>/confirm`

تضمن التفاصيل التالية في جسم الطلب:

- `client_secret`: المفتاح السري من الخطوة 1
- `payment_method`: تعيين على `card`
- `payment_method_data`: تفاصيل البطاقة والفواتير
- `browser_info`: بيانات خاصة بالمتصفح (وكلاء المستخدم، تفاصيل الشاشة، إلخ.)
- `payment_type`: تعيين بشكل صريح إلى `normal` (للمدفوعات لمرة واحدة)

الرؤوس المطلوبة:

- احصل على مفتاح النشر الخاص بك من دعم DodoPayments
- `api-key`: مفتاح النشر الخاص بك (احصل عليه من فريق Dodo Payments)
- `content-type`: `application/json`

**مثال على جسم الطلب:**

```json

  "payment_method_data": {

    },

        "first_name": "<first_name>",

      }
    }

  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",

    "color_depth": "<color_depth>",
```

### التعامل مع الاستجابة

- إذا كانت الاستجابة **`status`** هي **`requires_customer_action`**، قم بإعادة توجيه العميل إلى عنوان URL المقدم في حقل **`next_action`** لمزيد من المصادقة.

<Warning>
تأكد من الالتزام وإرشادات الامتثال PCI عند التعامل مع بيانات البطاقة الخام.
</Warning>

## تكامل Apple Pay

لاستخدام Apple Pay، قم بتعيين `payment_method` إلى `wallet` وتضمين بيانات Apple Pay في `payment_method_data`.

### هيكل جسم الطلب

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "apple_pay": {
        "payment_data": "<decrypted_payment_data>",
        "payment_method": {
          "display_name": "Visa 1234",
          "network": "Visa",
          "type": "debit"
        },
        "transaction_identifier": "UNIQUE_TRANSACTION_ID_FROM_APPLE"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### مرجع حقول Apple Pay

| الحقل | النوع | مطلوب | الوصف |
| --- | --- | --- | --- |
| `payment_data` | سلسلة | نعم | تُستخدم هذه القيمة التعداد لتمثيل بيانات الدفع من Apple Pay، والتي يمكن أن تكون مشفرة أو مفكوكة التشفير. |
| `payment_method.display_name` | سلسلة | نعم | اسم العرض المعروض على زر Apple Pay (مثل، "Visa 1234") |
| `payment_method.network` | سلسلة | نعم | شبكة البطاقة (مثل، "Visa"، "Mastercard"، "Amex") |
| `payment_method.type` | سلسلة | نعم | نوع وسيلة الدفع (مثل، "مدين"، "ائتماني") |
| `payment_method.card_exp_month` | سلسلة | لا | شهر انتهاء صلاحية البطاقة (مثل، "12") |
| `payment_method.card_exp_year` | سلسلة | لا | سنة انتهاء صلاحية البطاقة (مثل، "25") |
| `transaction_identifier` | سلسلة | نعم | معرف المعاملة الفريد من Apple Pay |

## تكامل Google Pay

لاستخدام Google Pay، قم بتعيين `payment_method` إلى `wallet` وتضمين بيانات Google Pay في `payment_method_data`.

### هيكل جسم الطلب

```json
{
  "client_secret": "<secret_key>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "google_pay": {
        "type": "CARD",
        "description": "Visa ending in 1234",
        "info": {
          "card_network": "VISA",
          "card_details": "1234"
        },
        "tokenization_data": {
          "type": "PAYMENT_GATEWAY",
          "token": "<encrypted_payment_token>"
        }
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### مرجع حقول Google Pay

| الحقل | النوع | مطلوب | الوصف |
| --- | --- | --- | --- |
| `type` | سلسلة | نعم | نوع وسيلة الدفع (عادةً "بطاقة") |
| `description` | سلسلة | نعم | الوصف الموجه للعميل لوسيلة الدفع |
| `info.card_network` | سلسلة | نعم | شبكة البطاقة (مثل، "VISA"، "MASTERCARD"، "AMEX") |
| `info.card_details` | سلسلة | نعم | آخر 4 أرقام من البطاقة |
| `info.assurance_details` | كائن | لا | تفاصيل ضمان المصادقة |
| `tokenization_data.type` | سلسلة | نعم | نوع التشفير (مثل، "PAYMENT_GATEWAY") |
| `tokenization_data.token` | سلسلة | نعم | رمز الدفع المشفر من Google Pay |
