## نظرة عامة

مهارات الوكلاء هي إمكانات قابلة لإعادة الاستخدام تعزّز ما يمكن لمساعدي البرمجة بالذكاء الاصطناعي القيام به عند العمل مع Dodo Payments. وهي توفر المعرفة الإجرائية وأفضل الممارسات التي تساعد الوكلاء على إنجاز مهام محددة بكفاءة أكبر، بدءًا من دمج تدفقات الدفع ووصولًا إلى إعداد الفوترة القائمة على الاستخدام.

<Info>
**فكّر في المهارات على أنها إضافات لمساعدك بالذكاء الاصطناعي.** فهي تعلّم وكيلك كيفية تنفيذ ميزات Dodo Payments بشكل صحيح، مع اتباع الأنماط وأفضل الممارسات التي نوصي بها.
</Info>

تعمل المهارات مع أي وكيل ذكاء اصطناعي متوافق مع MCP، بما في ذلك:
- **Claude Code** - مساعد البرمجة عبر CLI من Anthropic
- **OpenCode** - وكيل برمجة بالذكاء الاصطناعي مفتوح المصدر
- **Cursor** - محرر أكواد يضع الذكاء الاصطناعي في المقام الأول
- **عملاء MCP آخرون** - أي وكيل يدعم بروتوكول المهارات

## التثبيت

اختر طريقة التثبيت المفضلة لديك بناءً على مساعد البرمجة بالذكاء الاصطناعي الذي تستخدمه.

<Tabs>
<Tab title="Agent Plugin (recommended)">
إذا كنت تستخدم Claude Code أو Codex CLI أو Cursor أو OpenCode، فإن [إضافة Dodo Agent](/developer-resources/build-with-ai-coding-agents) تثبّت المهارات الثماني وجميع خادمي MCP في خطوة واحدة. تُحمّل المهارات تلقائيًا عندما يكتشف وكيلك مهمة ذات صلة.

راجع [دليل وكلاء البرمجة بالذكاء الاصطناعي](/developer-resources/build-with-ai-coding-agents) للاطلاع على أوامر التثبيت الخاصة بكل وكيل.
</Tab>

<Tab title="Skills CLI">
ثبّت المهارات باستخدام CLI العام للمهارات، الذي يعمل مع أي وكيل متوافق مع MCP:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

أو ثبّت المهارات الفردية حسب الحاجة:

```bash
# Best practices guide
npx skills add dodopayments/skills/dodo-payments/best-practices

# Webhook integration
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Subscription billing
npx skills add dodopayments/skills/dodo-payments/subscription-integration

# Checkout flows
npx skills add dodopayments/skills/dodo-payments/checkout-integration

# Usage-based billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing

# BillingSDK components
npx skills add dodopayments/skills/dodo-payments/billing-sdk

# License key management
npx skills add dodopayments/skills/dodo-payments/license-keys

# Credit-based billing
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
```

<Tip>
ثبّت المهارات التي تحتاج إليها فقط للحفاظ على تركيز وكيلك وتقليل العبء على السياق.
</Tip>
</Tab>

<Tab title="Claude Code">
أضف سوق مهارات Dodo Payments إلى Claude Code:

```bash
/plugin marketplace add dodopayments/skills
```

ثم ثبّت الإضافات الفردية:

```bash
# Install best practices
/plugin install dodo-best-practices

# Install webhook integration
/plugin install webhook-integration

# Install subscription integration
/plugin install subscription-integration

# Install checkout integration
/plugin install checkout-integration

# Install usage-based billing
/plugin install usage-based-billing

# Install BillingSDK
/plugin install billing-sdk

# Install license keys
/plugin install license-keys

# Install credit-based billing
/plugin install credit-based-billing
```

</Tab>

<Tab title="OpenCode">
تتوفر المهارات تلقائيًا عند تهيئتها في إعدادات OpenCode. أضف مستودع مهارات Dodo Payments إلى إعداداتك:

```json
{
  "skills": {
    "repositories": [
      "dodopayments/skills"
    ]
  }
}
```

</Tab>
</Tabs>

## استخدام المهارات

بعد التثبيت، يمكن لمساعدك بالذكاء الاصطناعي الاستفادة من هذه المهارات عندما تطلب منه تنفيذ ميزات Dodo Payments. إليك بعض الأمثلة على المطالبات:

### أفضل الممارسات

```
Help me integrate Dodo Payments into my Next.js app following best practices
```

### Webhooks

```
Set up webhook handlers for payment and subscription events
```

### الاشتراكات

```
Implement a subscription flow with free trial and multiple pricing tiers
```

### الدفع

```
Create a checkout session for my SaaS product
```

### الفوترة القائمة على الاستخدام

```
Add usage-based billing to track API calls for my AI product
```

### BillingSDK

```
Add a pricing page using BillingSDK components
```

### مفاتيح الترخيص

```
Implement license key validation for my desktop app
```

### الفوترة القائمة على الأرصدة

```
Set up credit entitlements and metered credit deduction for my AI product
```

## كيفية عمل المهارات

توفر المهارات لمساعدك بالذكاء الاصطناعي ما يلي:

1. **المعرفة الإجرائية** - تعليمات خطوة بخطوة لتنفيذ الميزات
2. **قوالب الأكواد** - أنماط ومقتطفات أكواد جاهزة للاستخدام في بيئة الإنتاج
3. **أفضل الممارسات** - أساليب موصى بها للأمان ومعالجة الأخطاء وتجربة المستخدم
4. **الوعي بالسياق** - فهم كيفية عمل ميزات Dodo Payments المختلفة معًا

عندما تطلب من مساعدك بالذكاء الاصطناعي تنفيذ ميزة، فإنه يستخدم المهارة ذات الصلة من أجل:
- فهم أسلوب التنفيذ الصحيح
- إنشاء أكواد دقيقة وقابلة للتشغيل
- اتباع اصطلاحات Dodo Payments
- التعامل مع الحالات الطرفية والأخطاء بشكل صحيح

<Note>
تكمّل المهارات [خادم MCP](/developer-resources/mcp-server) و[Sentra](/developer-resources/sentra). استخدم MCP لعمليات API، وSentra لدمج موجّه، والمهارات لتعزيز إمكانات مساعد الذكاء الاصطناعي.
</Note>
