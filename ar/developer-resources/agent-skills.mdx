## نظرة عامة

مهارات الوكلاء هي إمكانات قابلة لإعادة الاستخدام تعزّز ما يمكن لمساعدي البرمجة بالذكاء الاصطناعي القيام به عند العمل مع Dodo Payments. وهي توفر المعرفة الإجرائية وأفضل الممارسات التي تساعد الوكلاء على إنجاز مهام محددة بكفاءة أكبر، بدءًا من دمج تدفقات الدفع ووصولًا إلى إعداد الفوترة القائمة على الاستخدام.

<Info>
**فكّر في المهارات على أنها إضافات لمساعدك بالذكاء الاصطناعي.** فهي تعلّم وكيلك كيفية تنفيذ ميزات Dodo Payments بشكل صحيح، مع اتباع الأنماط وأفضل الممارسات التي نوصي بها.
</Info>

تعمل Skills مع أي AI agent يدعم بروتوكول skills، بما في ذلك:
- **Claude Code** - مساعد برمجة CLI من Anthropic
- **Codex CLI** - وكيل برمجة CLI من OpenAI
- **Cursor** - محرر أكواد يضع الذكاء الاصطناعي في المقام الأول
- **VS Code / GitHub Copilot** - عبر Agent Plugin
- **Kiro** - يحمّل Skills باعتبارها Power
- **OpenCode** - وكيل برمجة AI مفتوح المصدر
- **عملاء آخرون** - أي وكيل يدعم بروتوكول skills

<Note>
**Gemini CLI هو الاستثناء.** لا يحتوي على بدائية agent-skill، لذلك لا تتوفر Skills فيه — يتوفر خادما [MCP](/developer-resources/mcp-server) فقط.
</Note>

## التثبيت

اختر طريقة التثبيت المفضلة لديك بناءً على مساعد البرمجة AI الذي تستخدمه.

<Tabs>
<Tab title="Agent Plugin (recommended)">
إذا كنت تستخدم Claude Code أو Codex CLI أو Cursor أو VS Code / GitHub Copilot أو Kiro أو OpenCode، فإن [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) يثبّت المهارات السبع عشرة بالإضافة إلى خادمي MCP في خطوة واحدة. تُحمّل Skills تلقائيًا عندما يكتشف وكيلك مهمة ذات صلة.

راجع [دليل AI Coding Agents](/developer-resources/build-with-ai-coding-agents) للاطلاع على أوامر التثبيت الخاصة بكل وكيل.
</Tab>

<Tab title="Skills CLI">
ثبّت Skills باستخدام skills CLI الشامل الذي يعمل مع أي وكيل متوافق مع MCP:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

أو ثبّت Skills فردية حسب الحاجة:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/dodo-best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
ثبّت Skills التي تحتاج إليها فقط للحفاظ على تركيز وكيلك وتقليل الحمل على السياق.
</Tip>
</Tab>

<Tab title="Claude Code">
أضف سوق Dodo Payments Skills إلى Claude Code:

```bash
/plugin marketplace add dodopayments/skills
```

ثم ثبّت الإضافات الفردية:

```bash expandable
# Getting started
/plugin install dodo-best-practices
/plugin install framework-adapters
/plugin install testing-and-go-live

# Accepting payments
/plugin install checkout-integration
/plugin install subscription-integration
/plugin install mobile-checkout
/plugin install webhook-integration

# Billing models
/plugin install credit-based-billing
/plugin install usage-based-billing
/plugin install license-keys

# Catalog and pricing
/plugin install product-catalog-management
/plugin install discounts-and-promotions
/plugin install localized-pricing

# Customers and operations
/plugin install customer-management
/plugin install refunds-and-disputes

# UI and integrations
```

</Tab>

<Tab title="OpenCode">
يحمّل OpenCode Skills من الأدلة التي تحددها له. ولا يفحص الحزم المثبتة، لذلك يلزم إدخال صريح لـ `skills.paths`.

باستخدام حزمة Agent Plugin:

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

تُحل المسارات النسبية بالنسبة إلى **دليل المشروع**، لذلك يجب أن تكون الحزمة موجودة في `node_modules` الخاص بذلك المشروع. ويعمل المسار المطلق أيضًا، كما يتجنب الحاجة إلى التثبيت المحلي.

<Warning>
يتم تجاهل مسار Skills غير الموجود **بصمت** — دون خطأ أو تحذير. تأكد من تحميل Skills فعليًا:

```bash
opencode run "List every skill available to you by name."
```

من المفترض أن ترى السبعة عشر جميعًا.
</Warning>
</Tab>
</Tabs>

## استخدام Skills

بعد التثبيت، يحمّل مساعدك AI الـ Skill المناسب تلقائيًا عندما تطلب منه تنفيذ ميزة في Dodo Payments. لا تحتاج إلى تسمية Skill — ما عليك سوى وصف المهمة.

| مثال على الطلب | Skill التي يتم تحميلها |
|----------------|------------------|
| ساعدني على دمج Dodo Payments في تطبيقي Next.js وفقًا لأفضل الممارسات | `dodo-best-practices` |
| أضف معالج مسار checkout في Dodo Payments إلى تطبيقي Hono | `framework-adapters` |
| أرشدني خلال اختبار المدفوعات وإطلاقها في الإنتاج | `testing-and-go-live` |
| أنشئ جلسة checkout لمنتج SaaS الخاص بي | `checkout-integration` |
| نفّذ تدفق اشتراك مع فترة تجريبية مجانية وطبقات تسعير متعددة | `subscription-integration` |
| أضف checkout داخل التطبيق إلى تطبيقي React Native | `mobile-checkout` |
| أعد إعداد معالجات webhook لأحداث الدفع والاشتراك | `webhook-integration` |
| أعد إعداد استحقاقات الأرصدة وخصم الأرصدة المستند إلى العداد لمنتج AI الخاص بي | `credit-based-billing` |
| أضف فوترة مستندة إلى الاستخدام لتتبع استدعاءات API لمنتج AI الخاص بي | `usage-based-billing` |
| نفّذ التحقق من مفاتيح الترخيص لتطبيقي المكتبي | `license-keys` |
| أنشئ كتالوج منتجات مع إضافات وتسعير متدرج | `product-catalog-management` |
| أضف رمزًا ترويجيًا يمنح خصمًا بنسبة 20% على دورات الفوترة الثلاث الأولى | `discounts-and-promotions` |
| اعرض الأسعار بعملة الزائر المحلية مع تعادل القوة الشرائية | `localized-pricing` |
| امنح العملاء بوابة خدمة ذاتية لإدارة طرق الدفع الخاصة بهم | `customer-management` |
| أصدر استردادًا جزئيًا وألغِ الوصول عند فتح نزاع | `refunds-and-disputes` |
| أضف صفحة أسعار باستخدام مكونات BillingSDK | `billing-sdk` |
| اربط Dodo Payments بإعداد Better Auth الخاص بي | `better-auth-integration` |

## آلية عمل Skills

توفر Skills لمساعدك AI ما يلي:

1. **المعرفة الإجرائية** - تعليمات خطوة بخطوة لتنفيذ الميزات
2. **قوالب الأكواد** - أنماط أكواد ومقاطع جاهزة للإنتاج
3. **أفضل الممارسات** - أساليب موصى بها للأمان ومعالجة الأخطاء وتجربة المستخدم
4. **الوعي بالسياق** - فهم كيفية عمل ميزات Dodo Payments المختلفة معًا

عندما تطلب من مساعدك AI تنفيذ ميزة، فإنه يستخدم Skill المناسبة من أجل:
- فهم أسلوب التنفيذ الصحيح
- إنشاء أكواد دقيقة وعملية
- اتباع اصطلاحات Dodo Payments
- التعامل مع الحالات الطرفية والأخطاء بشكل صحيح

<Note>
تكمّل Skills كلًا من [MCP Server](/developer-resources/mcp-server) و[Sentra](/developer-resources/sentra). استخدم MCP لعمليات API، وSentra للتكامل الموجّه، وSkills لتحسين إمكانات مساعد AI.
</Note>
