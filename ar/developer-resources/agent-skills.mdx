## نظرة عامة

مهارات الوكيل هي قدرات قابلة لإعادة الاستخدام تعزز ما يمكن أن تفعله مساعدات البرمجة المعتمدة على الذكاء الاصطناعي عند العمل مع Dodo Payments. إنها توفر المعرفة الإجرائية وأفضل الممارسات التي تساعد الوكلاء في إنجاز مهام معينة بشكل أكثر كفاءة - من دمج تدفقات الدفع إلى إعداد الفوترة القائم على الاستخدام.

<Info>
**فكر في المهارات كإضافات لمساعد الذكاء الاصطناعي الخاص بك.** إنها تعلم وكيلك كيفية تنفيذ ميزات Dodo Payments بشكل صحيح، وفقًا لنماذجنا الموصى بها وأفضل الممارسات.
</Info>

تعمل المهارات مع أي وكيل متوافق مع MCP، بما في ذلك:
- **Claude Code** - مساعد البرمجة من Anthropic
- **OpenCode** - وكيل البرمجة مفتوح المصدر
- **Cursor** - محرر الشفرة المعتمد على الذكاء الاصطناعي
- **عملاء MCP الآخرين** - أي وكيل يدعم بروتوكول المهارات

## التثبيت

اختر طريقة التثبيت المفضلة لديك بناءً على مساعد البرمجة الذكي الخاص بك.

<Tabs>
<Tab title="Skills CLI">
قم بتثبيت المهارات باستخدام CLI المهارات العالمية التي تعمل مع أي وكيل متوافق مع MCP:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

أو قم بتثبيت مهارات فردية حسب الحاجة:

```bash
# Best practices guide
npx skills add dodopayments/skills/dodo-best-practices

# Webhook integration
npx skills add dodopayments/skills/webhook-integration

# Subscription billing
npx skills add dodopayments/skills/subscription-integration

# Checkout flows
npx skills add dodopayments/skills/checkout-integration

# Usage-based billing
npx skills add dodopayments/skills/usage-based-billing

# BillingSDK components
npx skills add dodopayments/skills/billing-sdk

# License key management
npx skills add dodopayments/skills/license-keys
```

<Tip>
قم بتثبيت المهارات التي تحتاجها فقط للحفاظ على تركيز وكيلك وتقليل عبء السياق.
</Tip>
</Tab>

<Tab title="Claude Code">
أضف سوق مهارات Dodo Payments إلى Claude Code:

```bash
/plugin marketplace add dodopayments/skills
```

ثم قم بتثبيت الإضافات الفردية:

```bash
# Install best practices
/plugin install dodo-best-practices

# Install webhook integration
/plugin install webhook-integration

# Install subscription integration
/plugin install subscription-integration

# Install checkout integration
/plugin install checkout-integration

# Install usage-based billing
/plugin install usage-based-billing

# Install BillingSDK
/plugin install billing-sdk

# Install license keys
/plugin install license-keys
```

</Tab>

<Tab title="OpenCode">
تتوفر المهارات تلقائيًا عند إعدادها في إعدادات OpenCode الخاصة بك. أضف مستودع مهارات Dodo Payments إلى تكوينك:

```json
{
  "skills": {
    "repositories": [
      "dodopayments/skills"
    ]
  }
}
```

</Tab>
</Tabs>

## استخدام المهارات

بمجرد التثبيت، يمكن لمساعد الذكاء الاصطناعي الخاص بك الاستفادة من هذه المهارات عندما تطلب منه تنفيذ ميزات Dodo Payments. إليك بعض الأمثلة عن الأوامر:

### أفضل الممارسات

```
Help me integrate Dodo Payments into my Next.js app following best practices
```

### webhooks

```
Set up webhook handlers for payment and subscription events
```

### الاشتراكات

```
Implement a subscription flow with free trial and multiple pricing tiers
```

### الدفع عند الشراء

```
Create a checkout session for my SaaS product
```

### الفوترة المستندة إلى الاستخدام

```
Add usage-based billing to track API calls for my AI product
```

### BillingSDK

```
Add a pricing page using BillingSDK components
```

### مفاتيح الترخيص

```
Implement license key validation for my desktop app
```

## كيفية عمل المهارات

توفر المهارات لمساعد الذكاء الاصطناعي الخاص بك:

1. **المعرفة الإجرائية** - تعليمات خطوة بخطوة لتنفيذ الميزات
2. **قوالب الشيفرة** - أنماط ومقتطفات الشيفرة الجاهزة للإنتاج
3. **أفضل الممارسات** - الأساليب الموصى بها للأمان، معالجة الأخطاء، وتجربة المستخدم
4. **الوعي بالسياق** - فهم كيفية عمل ميزات Dodo Payments المختلفة معًا

عندما تطلب من مساعد الذكاء الاصطناعي الخاص بك تنفيذ ميزة، فإنه يستخدم المهارة ذات الصلة لـ:
- فهم النهج الصحيح للتنفيذ
- توليد شيفرة دقيقة وعاملة
- اتباع تقاليد Dodo Payments
- التعامل بشكل صحيح مع الحالات الحدية والأخطاء

<Note>
تُكمل المهارات [خادم MCP](/developer-resources/mcp-server) و[Sentra](/developer-resources/sentra). استخدم MCP لعمليات API، وSentra للتكامل الموجه، والمهارات لزيادة قدرات مساعد الذكاء الاصطناعي.
</Note>
