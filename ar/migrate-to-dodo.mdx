**التبديل من مزود دفع آخر إلى Dodo Payments؟** تسهل أداة الترحيل الخاصة بنا نقل **منتجاتك، عملائك، رموز الخصم، ومفاتيح الترخيص دون فقدان أي بيانات.** العملية آمنة وموُجهة ويمكن إتمامها في بضع دقائق فقط.

نحن ندعم حاليًا عمليات الترحيل من **Lemon Squeezy وStripe وPolar.sh وPaddle**.

## ابدأ الآن

أولاً، قم بتثبيت أداة الترحيل:

```bash
npm install -g dodo-migrate
```

<Note>
ستحتاج إلى تثبيت Node.js إصدار 18 أو أحدث على جهاز الكمبيوتر الخاص بك.
</Note>

## ترحيل بياناتك

### إذا كنت قادمًا من Lemon Squeezy:

```bash
dodo-migrate lemonsqueezy
```

### إذا كنت قادمًا من Stripe:

```bash
dodo-migrate stripe
```

### إذا كنت قادمًا من Polar.sh:

```bash
dodo-migrate polar
```

### إذا كنت قادمًا من Paddle:

```bash
dodo-migrate paddle
```

ستقوم الأداة بإرشادك في كل خطوة بخطوة. ستحتاج إلى:
- مفتاح API الخاص بمزودك (مثل Lemon Squeezy، Stripe، Polar.sh، Paddle، إلخ.)
- مفتاح API الخاص بـ Dodo Payments  
- ما إذا كنت تريد الاختبار أولاً (موصى به) أو بدء العمل
- إلى أي علامة تجارية من Dodo Payments ترغب في الترحيل
- أي البيانات ينبغي ترحيلها (المنتجات، العملاء، الخصومات، مفاتيح الترخيص)

## لماذا تستخدم أداة الترحيل لدينا؟

- **لا فقدان للبيانات** - يتم نقل كل شيء بأمان
- **اختبر أولاً** - جربه في وضع الاختبار قبل الانتقال مباشرة
- **عملية موجهة** - نحن نوجهك خلال كل خطوة
- **استئناف إذا لزم الأمر** - إذا حدث خطأ ما، يمكنك استئناف من حيث توقفت

## الاستخدام المتقدم

إذا كنت تفضل تشغيل الترحيل دون مطالبات، يمكنك تقديم جميع التفاصيل مسبقًا:

### ترحيل Lemon Squeezy:

```bash
dodo-migrate lemonsqueezy \
  --provider-api-key=lsq_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX
```

### ترحيل Stripe:

```bash
dodo-migrate stripe \
  --provider-api-key=sk_test_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX \
  --migrate-types=products,coupons
```

### ترحيل Polar.sh:

```bash
dodo-migrate polar \
  --provider-api-key=polar_org_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX \
  --migrate-types=products,discounts,customers,license_keys
```

### ترحيل Paddle:

```bash
dodo-migrate paddle \
  --provider-api-key=paddle_XXXXXXXXXXXXXXXX \
  --dodo-api-key=dp_XXXXXXXXXXXXXXXX \
  --mode=test_mode \
  --dodo-brand-id=brand_XXXXXX
```

## ترحيل مفتاح الترخيص

يتم دعم ترحيل مفتاح الترخيص لـ **Polar.sh** و **Lemon Squeezy**. عند اختيار مفاتيح الترخيص في المطالبة التفاعلية (أو تمرير `license_keys` في `--migrate-types`)، ستقوم الأداة باستيراد مفاتيح الترخيص الحالية الخاصة بك إلى Dodo Payments مع الارتباطات الصحيحة للعملاء والمنتجات.

<Warning>
يتطلب ترحيل مفتاح الترخيص ترحيل **المنتجات والعملاء** في نفس الجلسة. تبني الأداة خريطة في الذاكرة لأرقام المعرفات من المزود إلى معرفات Dodo أثناء التشغيل — إذا كانت المنتجات أو العملاء مفقودين، فلا يمكن ربط مفاتيح الترخيص بشكل صحيح.
</Warning>

### ما الذي يتم ترحيله

- سلاسل مفاتيح الترخيص
- حدود التفعيل
- تواريخ الانتهاء
- ارتباطات العملاء والمنتجات

### ما الذي لا يتم ترحيله

- **التفعيل لمفاتيح الترخيص** — سيحتاج العملاء إلى إعادة التفعيل على أجهزتهم بعد الترحيل
- **المفاتيح الملقية أو المعطلة** — يتم ترحيل المفاتيح النشطة فقط
- يتم تخطي المفاتيح التي لا تتطابق مع منتج أو عميل بموجب تحذير

<Tip>
تتم معالجة مفاتيح الترخيص المكررة بعناية. إذا قمت بإعادة تشغيل الترحيل، يتم الكشف عن المفاتيح التي تم استيرادها بالفعل وتخطيها، مما يجعل العملية آمنة لإعادة المحاولة.
</Tip>
