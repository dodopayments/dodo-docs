## ميزات جديدة 🚀

1. **الدفع بعربة مختلطة: منتجات دفع لمرة واحدة واشتراكات في عربة واحدة**  
   يدعم الدفع الآن الجمع بين منتجات الدفع لمرة واحدة ومنتجات الاشتراك في عربة واحدة، مما يفتح حالات استخدام قوية جديدة للفوترة.
   
   <Frame>
   <img src="/images/changelog/mixed-checkout.png" alt="Mixed checkout with one-time and subscription products" style={{ maxHeight: '500px', width: 'auto' }} />
   </Frame>
   
   ### ما يمكن أن يحققه هذا
   
   - **رسوم الإعداد + الاشتراكات**: تحصيل رسوم إعداد لمرة واحدة جنبًا إلى جنب مع اشتراك متكرر في عملية دفع واحدة
   - **حزم مع مكونات متكررة**: بيع منتج (لمرة واحدة) مع حزمة تتضمن الوصول إلى خدمة مستمرة (اشتراك)
   - **البرامج + العضويات المشتركة**: تقديم شراء دورة تدريبية مع اشتراك اختياري لعضوية مجتمع
   - **الوصول مدى الحياة + الاشتراكات الإضافية**: دمج الوصول مدى الحياة للمنتج مع ميزات متميزة متكررة اختيارية
   
   ### كيفية عملها
   
   ببساطة أضف كلا من منتجات الدفع لمرة واحدة والاشتراك إلى جلسة الدفع الخاصة بك:
   

   ```javascript
   const session = await client.checkoutSessions.create({
     product_cart: [
       // One-time setup fee
       { product_id: 'prod_setup_fee', quantity: 1 },
       // Monthly subscription
       { product_id: 'prod_monthly_plan', quantity: 1 }
     ],
     customer: {
       email: 'customer@example.com',
       name: 'Jane Doe'
     },
     return_url: 'https://yourapp.com/success'
   });
   ```

   
   <Check>
   النتيجة: تدفق دفع واحد يُعالج الدفع لمرة واحدة ويبدأ الاشتراك — مما يقلل الاحتكاك ويزيد معدلات التحويل.
   </Check>
   
   <Info>
   عند خلط أنواع المنتجات، يتم تحصيل الدفع لمرة واحدة فوراً بينما يتبع الاشتراك دورة الفوترة التي تم تكوينها (بما في ذلك أي فترة تجريبية قمت بتعيينها).
   </Info>
   
   Learn more: [Checkout Sessions](/developer-resources/checkout-session)

2. **بوابة العملاء الموحدة**  
   
   بوابة العملاء المركزية الجديدة على [customer.dodopayments.com](https://customer.dodopayments.com) حيث يمكن للعملاء مشاهدة وإدارة جميع مشترياتهم واشتراكاتهم عبر شركات مختلفة على Dodo Payments.
   
   <Frame>
   <img src="/images/changelog/unified-customer-portal.png" alt="Unified Customer Portal" style={{ maxHeight: '500px', width: 'auto' }} />
   </Frame>
   
   ### ميزات البوابة
   
   - **رؤية عبر الأعمال**: مشاهدة جميع المشتريات والاشتراكات من أي شركة تستخدم Dodo Payments في مكان واحد
   - **إدارة اشتراكات مركزية**: إدارة الاشتراكات عبر تجار مختلفين من لوحة تحكم واحدة
   - **توحيد سجل الفواتير**: الاطلاع على الفواتير وسجل الدفع من جميع مشترياتك
   - **تجربة الدخول الموحد**: تسجيل الدخول مرة واحدة باستخدام بريدك الإلكتروني للوصول إلى المشتريات من جميع تجار Dodo Payments
   
   ### كيفية عملها
   
   يقوم العملاء ببساطة بزيارة [customer.dodopayments.com](https://customer.dodopayments.com) وإدخال عنوان بريدهم الإلكتروني. سيحصلون على رابط تسجيل دخول آمن يمنحهم الوصول إلى جميع مشترياتهم عبر نظام Dodo Payments.
   
   <Tip>
   تكمل بوابة العملاء الموحدة بوابات العملاء المحددة للأعمال. لا يزال بإمكان العملاء الوصول إلى بوابات التجار الفردية لتجربة ذات علامة تجارية، أو استخدام البوابة الموحدة لعرض موحد.
   </Tip>
   
   <Note>
   تستخدم البوابة الموحدة نفس المصادقة القائمة على البريد الإلكتروني كبوابات العملاء المحددة للأعمال، لضمان تجربة متسقة وآمنة.
   </Note>

3. **معرف الفاتورة في استجابة الدفع**  
   تتضمن استجابة الدفع الآن حقل `invoice_id`، مما يسهل مطابقة المدفوعات مع الفواتير والتكامل مع أنظمة المحاسبة.
   

   ```json
   {
     "payment_id": "pay_2IjeQm4hqU6RA4Z4kwDee",
     "status": "succeeded",
     "invoice_id": "inv_2IsUnWGtRKFLxk7xAQeyt",
     "total_amount": 9900,
     "currency": "USD",
     // ... other fields
   }
   ```

   
   ### حالات الاستخدام
   
   - **التكامل المحاسبي**: ربط المدفوعات بالفواتير مباشرة في برنامج المحاسبة الخاص بك
   - **دعم العملاء**: العثور بسرعة على الفاتورة المرتبطة بمدفوع عند معالجة طلبات الدعم
   - **التسوية**: تبسيط التسوية المالية من خلال مطابقة المدفوعات بالفواتير برمجياً
   - **الامتثال**: الحفاظ على سجلات دقيقة تربط المدفوعات بالفواتير الضريبية المقابلة لها
   
   <Info>
   يستخدم الحقل `invoice_id` معرفات فواتير خاصة بالهند عند توفرها، مما يضمن الالتزام بمتطلبات الفوترة المحلية.
   </Info>
   
   Learn more: [Get Payment Detail API](/api-reference/payments/get-payments-1)
