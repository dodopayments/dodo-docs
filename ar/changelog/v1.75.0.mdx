## ميزات جديدة

### 1. **مجموعات المنتجات**  
   
   تجمع المنتجات ذات الصلة معًا لتجارب دفع موحدة، واختيار الخطط، ومسارات ترقية/تخفيض سلسة داخل بوابة العملاء.

   <Frame>
     <img src="/images/product-collection/checkout-page.png" alt="صفحة الخروج لمجموعة المنتجات تُظهر خيارات متعددة للخطط" />
   </Frame>

  **الفوائد الرئيسية**

   - **خروج مبني على المجموعات**: عرض جميع المنتجات من مجموعة واحدة في عرض خروج واحد، مما يتيح للعملاء المقارنة واختيار خطتهم المفضلة
   - **إدارة منتجات منظمة**: تجميع المنتجات ذات الصلة (مثل: Starter، Pro، Enterprise) تحت مجموعة واحدة
   - **تكامل بوابة العملاء**: تمكين العملاء من الترقية أو التخفيض بين المنتجات داخل نفس المجموعة
   - **تحكم التجار**: تمكين، وتعطيل، وإعادة ترتيب المنتجات داخل كل مجموعة

   **كيف يعمل**

   إنشاء جلسة خروج لمجموعة:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_collection_id: 'pdc_abc123',
     product_cart: [], // Required: pass an empty array for collection checkout
     return_url: 'https://yoursite.com/return'
   });

   // Redirect customer to the checkout
   window.location.href = session.url;
   ```

   <Check>
   النتيجة: تجربة خروج موحدة حيث يمكن للعملاء عرض واختيار من جميع المنتجات المتاحة في مجموعتك.
   </Check>

   <Info>
   خروج المجموعة مثالي للأعمال الاشتراكية حيث ترغب في أن يتمكن العملاء من مقارنة الخطط جنبًا إلى جنب قبل الشراء.
   </Info>

   تعرف على المزيد: [دليل مجموعات المنتجات](/features/product-collections)

### 2. **طرق الدفع RevolutPay و Billie للعملة GBP**  
   
   خيارات الدفع الموسعة مع RevolutPay و Billie متاحة الآن عالميًا للمعاملات لمرة واحدة بالجنيه الإسترليني، مما يمنح عملائك مزيدًا من المرونة في كيفية الدفع.

   **طرق الدفع الجديدة**

   | طريقة الدفع   | الدول المدعومة | العملة | دعم الاشتراك |
   |----------------|------------------|--------|-----------------|
   | **RevolutPay**  | عالمي        | GBP    | لا (لمرة واحدة فقط) |
   | **Billie**      | عالمي        | GBP    | لا (لمرة واحدة فقط) |

   - **RevolutPay** – مدفوعات سريعة وسلسة لمستخدمي Revolut عالميًا
   - **Billie** – حل شراء الآن وادفع لاحقًا للأعمال يمكّن الشركات من تقديم شروط دفع مرنة لعملائها

   <Info>
   هذه طرق الدفع متاحة تلقائيًا للمعاملات بالجنيه الإسترليني. لا تتطلب أي تكوين إضافي.
   </Info>

   تعرف على المزيد: [طرق الدفع](/features/payment-methods)

### 3. **معاينة جلسة الخروج**  
   
   معاينة جلسات الخروج قبل إنشائها لحساب الأسعار الدقيقة، والضرائب، والخصومات، والمجموعات. عرض الأسعار الفعلية للعملاء قبل الانتقال إلى عملية الدفع.

   **كيف يعمل**

   ```typescript
   const preview = await client.checkoutSessions.preview({
     product_cart: [
       { product_id: 'prod_123', quantity: 1 }
     ],
     billing_address: {
       country: 'US',
       state: 'CA',
       zipcode: '94102'
     },
     discount_code: 'SAVE20'
   });

   console.log('Subtotal:', preview.subtotal);
   console.log('Tax:', preview.tax);
   console.log('Discount:', preview.discount);
   console.log('Total:', preview.total);
   ```

   **حالات الاستخدام**

   - **عرض الأسعار المخصصة**: عرض المجموعات الصحيحة بما في ذلك الضرائب قبل الخروج
   - **التحقق من الخصومات**: التحقق من رموز الخصم وعرض توفيرات للعملاء
   - **دعم العملات المتعددة**: معاينة الأسعار بالعملات المختلفة
   - **ملخصات السلة**: بناء واجهات سلة مخصصة مع تسعير في الوقت الفعلي

### 4. **دعم البيانات الوصفية في طلبات تغيير الخطط**  
   
   تمرير البيانات الوصفية المخصصة عند تغيير خطط الاشتراك، مما يمكّن من تتبع أفضل ودمج مع أنظمتك الداخلية أثناء انتقالات الخطط.

   ```javascript
   // Adding metadata when changing a subscription plan
   await client.subscriptions.changePlan('sub_123', {
     product_id: 'prod_premium',
     proration_billing_mode: 'prorated_immediately',
     quantity: 1,
     metadata: {
       upgrade_reason: 'feature_request',
       previous_plan: 'basic',
       sales_rep: 'john@company.com'
     }
   });
   ```

  **حالات الاستخدام**

   - **تتبع أسباب الترقية/التخفيض**: تخزين لماذا غير العملاء الخطط
   - **ربط بسجلات CRM**: ربط تغييرات الخطط بالأنشطة البيعية
   - **تصنيف داخلي**: وضع علامة على تغييرات الخطط للتقارير والتحليلات
   - **سجلات التدقيق**: الاحتفاظ بسجلات بمن بدأ تغييرات الخطط

   <Info>
   البيانات الوصفية مضمنة في أحداث الويب هوك، مما يجعل من السهل معالجة تغييرات الخطط مع بياناتك المخصصة.
   </Info>

   تعرف على المزيد: [دليل البيانات الوصفية](/api-reference/metadata) | [API تغيير الخطة](/api-reference/subscriptions/change-plan)

### 5. **حقل `invoice_url` في استجابة الدفع واستجابة رابط الدفع**  
   
   تتضمن استجابة الدفع واستجابة رابط الدفع الآن حقل `invoice_url`، مما يوفر وصولًا مباشرًا إلى الفاتورة المرتبطة بكل عملية دفع.

   ```json
   {
     "payment_id": "pay_2IjeQm4hqU6RA4Z4kwDee",
     "status": "succeeded",
     "invoice_url": "https://dodopayments.com/invoices/inv_2IsUnWGtRKFLxk7xAQeyt",
     "amount": 9900,
     "currency": "USD",
     // ... other fields
   }
   ```

  **حالات الاستخدام**

   - **التواصل مع العملاء**: إرسال روابط الفواتير مباشرة إلى العملاء
   - **تكامل المحاسبة**: ربط المدفوعات بالفواتير في برنامج المحاسبة الخاص بك
   - **بوابات الخدمة الذاتية**: السماح للعملاء بالوصول بسهولة إلى فواتيرهم
   - **حفظ السجلات**: الحفاظ على مراجع مباشرة لوثائق الفواتير

     عرض مخطط استجابة الدفع.

### 6. **نقطة نهاية تحقق الخصم بواسطة اسم الرمز**  
   
   نقطة نهاية API جديدة للتحقق واسترجاع رموز الخصم بواسطة اسم الرمز (مثل: "SAVE20") بدلاً من استخدام معرف الخصم الداخلي. تحقق من أهلية الخصم قبل تطبيقه عند الخروج.

   ```javascript
   // Validate a discount code before checkout
   const discount = await client.discounts.getByCode('SAVE20');

   console.log('Discount type:', discount.type);
   console.log('Discount value:', discount.amount);
   console.log('Valid until:', discount.expires_at);
   ```

  **المزايا**

   - **التحقق قبل الخروج**: التحقق من رموز الخصم قبل إنشاء جلسات الدفع
   - **ردود الفعل في الوقت الفعلي**: إظهار للعملاء إذا كان رمزهم صالحًا
   - **معالجة الأخطاء**: الكشف عن الرموز غير الصالحة أو المنتهية مبكرًا
   - **واجهات المستخدم الخاصة بالخصم**: بناء حقول إدخال رمز الخصم مع التحقق الفوري

### 7. **تحسينات في قدرات التصفية للعملاء، الخصومات، ومفاتيح الترخيص**  
   
   فلاتر جديدة لواجهة برمجة التطبيقات لتعداد العملاء، الخصومات، ومفاتيح الترخيص، مما يجعل من الأسهل العثور على بياناتك وإدارتها برمجيًا.

   **فلاتر API العملاء**

   | الفلتر | الوصف |
   |--------|-------------|
   | `email` | تصفية بواسطة بريد العميل |
   | `name` | تصفية بواسطة اسم العميل (مطابقة جزئية، غير حساسة لحالة الأحرف) |
   | `created_at_gte` | تصفية العملاء المنشئين في أو بعد هذا الطابع الزمني |
   | `created_at_lte` | تصفية العملاء المنشئين في أو قبل هذا الطابع الزمني |

   ```javascript
   // Find customers by name created in the last 30 days
   const customers = await client.customers.list({
     name: 'John',
     created_at_gte: '2026-01-01T00:00:00Z'
   });
   ```

   **فلاتر API الخصومات**

   | الفلتر | الوصف |
   |--------|-------------|
   | `code` | تصفية بواسطة رمز الخصم (مطابقة جزئية، غير حساسة لحالة الأحرف) |
   | `discount_type` | تصفية بواسطة نوع الخصم (نسبة مئوية) |
   | `active` | تصفية بواسطة الحالة النشطة (true = غير منتهية، false = منتهية) |
   | `product_id` | تصفية بواسطة قيود المنتج (فقط الخصومات التي تنطبق على هذا المنتج) |

   ```javascript
   // Find active percentage discounts for a specific product
   const discounts = await client.discounts.list({
     active: true,
     discount_type: 'percentage',
     product_id: 'prod_123'
   });
   ```

   **فلاتر API مفاتيح الترخيص**

   | الفلتر | الوصف |
   |--------|-------------|
   | `customer_id` | تصفية بواسطة معرف العميل |
   | `status` | تصفية بواسطة حالة مفتاح الترخيص (`active`، `expired`، `disabled`) |
   | `product_id` | تصفية بواسطة معرف المنتج |
   | `created_at_gte` | تصفية مفاتيح الترخيص المنشأة في أو بعد هذا الطابع الزمني |
   | `created_at_lte` | تصفية مفاتيح الترخيص المنشأة في أو قبل هذا الطابع الزمني |

   ```javascript
   // Find active license keys for a specific product
   const licenseKeys = await client.licenseKeys.list({
     status: 'active',
     product_id: 'prod_123'
   });
   ```
