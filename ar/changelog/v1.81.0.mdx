## ميزات جديدة

### 1. **دعم تحليلات الطرف الثالث**

تتبع سلوك العملاء عبر واجهة المتجر، الخروج، وبوابة العملاء باستخدام Google Analytics 4 و Google Tag Manager و Meta Pixel. أضف معرفات التتبع الخاصة بك في **الإعدادات → التحليلات** لبدء جمع أحداث التجارة الإلكترونية.

**المنصات المدعومة**

| المنصة | تنسيق المعرف |
|----------|-----------|
| Google Analytics 4 | `G-XXXXXXXXXX` |
| Google Tag Manager | `GTM-XXXXXXX` |
| Meta Pixel | رقمي (10-20 رقم) |

**الأحداث المتعقبة**

تُرسل أحداث مثل `purchase`، `add_payment_info`، `view_item`، و `view_item_list` تلقائيًا إلى منصات التحليلات الخاصة بك أثناء تجول العملاء وإتمام عمليات الشراء.

<Check>
مدعوم في واجهة المتجر، الخروج المستضاف، الخروج المنبثق / المتداخل، وبوابة العملاء.
</Check>

تعرف على المزيد: [تحليلات الطرف الثالث](/features/analytics)

### 2. **تخصيص مظهر الخروج**

خصص مظهر الخروج عبر معامل `customization.theme_config` عند إنشاء جلسات الخروج. قم بتكوين الألوان، الخطوط، نصف قطر الحدود، ونص الزر لأنماط الضوء والظلام.

**خيارات التكوين**

| الخاصية | الوصف |
|----------|-------------|
| `light` / `dark` | مخططات الألوان لكل وضع |
| `font_primary_url` | عنوان URL للخطوط المخصصة |
| `font_size` | `xs`، `sm`، `md`، `lg`، `xl`، `2xl` |
| `radius` | نصف قطر الحدود (مثل `8px`) |
| `pay_button_text` | نص الزر المخصص |

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  customization: {
    theme_config: {
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      light: { button_primary: '#0066ff', text_primary: '#1a1a1a' },
      dark: { button_primary: '#3385ff', text_primary: '#ffffff' }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

تعرف على المزيد: [تخصيص مظهر الخروج](/features/checkout#checkout-theme-customization)

### 3. **منع تغيير الخطة عند فشل الدفع**

معامل `on_payment_failure` الجديد لتغييرات خطة الاشتراك يتحكم في السلوك عند فشل الدفع.

| الوضع | السلوك |
|------|----------|
| `prevent_change` | الاحتفاظ بالاشتراك في الخطة الحالية حتى ينجح الدفع |
| `apply_change` | تطبيق تغيير الخطة على الفور بغض النظر عن نتيجة الدفع (افتراضي) |

```typescript
await client.subscriptions.changePlan('sub_123', {
  product_id: 'prod_pro',
  proration_billing_mode: 'prorated_immediately',
  on_payment_failure: 'prevent_change'
});
```

<Tip>
استخدم `prevent_change` للترقيات الحيوية حيث تريد ضمان الدفع قبل منح الوصول إلى الميزات المميزة.
</Tip>

تعرف على المزيد: [التعامل مع فشل الدفع](/developer-resources/subscription-upgrade-downgrade#handling-payment-failures)

## تحديثات واجهة برمجة التطبيقات

### واجهة برمجة تطبيقات دفتر الأستاذ المالي

نقطة النهاية `GET /balances/ledger` الجديدة لاسترجاع إدخالات دفتر الأستاذ الخاص بحسابك مع التصفية والترقيم.

| المعامل | الوصف |
|-----------|-------------|
| `created_at_gte` / `created_at_lte` | تصفية حسب نطاق التاريخ |
| `event_type` | تصفية حسب `payment`، `refund`، `dispute`، `payout`، إلخ. |
| `currency` | تصفية حسب رمز العملة |
| `reference_object_id` | تصفية حسب معرف الدفع/الاسترداد/النزاع المحدد |

تعرف على المزيد: [واجهة برمجة تطبيقات دفتر الأستاذ المالي](/api-reference/balance-ledger/list-ledger-entries)

### استجابة الدفع: `refund_status`

تمت إضافة حقل `refund_status` إلى استجابة `GET /payments/{paymentId}` للتحقق بسرعة مما إذا كان قد تم استرداد الدفع دون الاستعلام عن نقطة النهاية الخاصة بالاستردادات بشكل منفصل.
