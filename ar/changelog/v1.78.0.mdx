## ميزات جديدة

### 1. **تفضيلات الاتصال**

   تَحَكَّم في كيفية استلامك للإشعارات من خلال تفضيلات الاتصال المحدثة لدينا. قم بتكوين إشعارات البريد الإلكتروني، ودفع، وفي التطبيق لتتناسب مع سير العمل الخاص بك.

   <Frame>
     <img src="/images/communication-preferences/overview.png" alt="نظرة عامة على تفضيلات الاتصال تظهر إعدادات الإشعارات" />
   </Frame>

   **الميزات الرئيسية**

   - **تصاميم بريد إلكتروني متجددة**: قوالب بريد إلكتروني جديدة وعصرية مع دعوات واضحة للإجراء وتحسين قابلية القراءة
   - **إشعارات الدفع**: احصل على تنبيهات فورية على جهازك المحمول لأحداث حرجة مثل المبيعات الجديدة، والنزاعات، والمدفوعات
   - **ضوابط دقيقة**: اختر بالضبط أي الأحداث تؤدي إلى إشعارات ومن خلال أي قنوات
   - **دعم للبريد الإلكتروني المتعدد**: أضف عناوين بريد إلكتروني متعددة لاستلام إشعارات
   - **تفضيلات بريدية للعملاء**: قم بتكوين أي رسائل بريد إلكتروني يتلقاها عملاؤك

   **فئات الإشعارات**

   | الفئة | الوصف |
   |----------|-------------|
   | **المبيعات والمدفوعات** | مبيعات جديدة، مدفوعات ناجحة، مدفوعات فاشلة |
   | **المدفوعات والاستردادات** | إكمال المدفوعات، طلبات الاسترداد، إكمال الاسترداد |
   | **الاشتراكات** | اشتراكات جديدة، تجديدات، إلغاءات، تغييرات في الخطط |
   | **النزاعات** | فتح نزاع، دليل مطلوب، حل النزاع |

   <Check>
   النتيجة: ابقَ على اطلاع بشأن عملك مع الإشعارات التي تُسلم بالضبط كما تريد ومتى تريد.
   </Check>

   لمعرفة المزيد: [دليل تفضيلات الاتصال](/features/communication-preferences)

### 2. **حقول مخصصة في جلسات الخروج**

   جمع معلومات إضافية من العملاء أثناء الخروج مع الحقول المخصصة. أضف مدخلات نصية، قوائم منسدلة، تواريخ، والمزيد لجمع البيانات التي تحتاجها.

   **أنواع الحقول المدعومة**

   | النوع | الوصف | حالة الاستخدام |
   |------|-------------|----------|
   | `text` | مدخل نصي ذو سطر واحد | اسم الشركة، ملاحظات الطلب |
   | `number` | إدخال رقمي | الكمية، العمر |
   | `email` | إدخال بريد إلكتروني مع التحقق | بريد الاتصال للدفع |
   | `url` | إدخال URL مع التحقق | الموقع الإلكتروني، الملف الشخصي الاجتماعي |
   | `date` | محدد تاريخ | تاريخ التوصيل، تاريخ الحدث |
   | `dropdown` | اختيار من خيارات محددة مسبقًا | الحجم، اللون، نوع الخطة |
   | `boolean` | خانة اختيار لقيم نعم/لا | قبول الشروط، الاشتراك في النشرة الإخبارية |

   **كيفية عمله**

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     custom_fields: [
       {
         name: 'company_name',
         label: 'Company Name',
         type: 'text',
         required: true
       },
       {
         name: 'team_size',
         label: 'Team Size',
         type: 'dropdown',
         options: ['1-10', '11-50', '51-200', '200+'],
         required: true
       },
       {
         name: 'newsletter',
         label: 'Subscribe to our newsletter',
         type: 'boolean',
         required: false
       }
     ],
     return_url: 'https://yoursite.com/success'
   });
   ```

   **الفوائد**

   - **جمع بيانات مرنة**: جمع أي معلومات ضرورية للتنفيذ أو التخصيص
   - **التحقق المدمج**: حقول البريد الإلكتروني و URL تتحقق تلقائيًا من تنسيق الإدخال
   - **تحكم مطلوب/اختياري**: تحديد الحقول كولادة أو اختيارية بناءً على احتياجاتك
   - **توصيل Webhook**: يتم تضمين قيم الحقول المخصصة في أحداث Webhook المدفوعات

   <Info>
   تُعاد قيم الحقول المخصصة في كائن `custom_fields` ضمن الاستجابات الخاصة بجلسات الدفع والخروج.
   </Info>

   لمعرفة المزيد: [حقول مخصصة لجلسة الخروج](/developer-resources/checkout-session#custom-fields)

### 3. **دعم موسع للغة الخروج**

   تدعم صفحة الخروج الآن **21 لغة**، مرتفعة من 16. الوصول إلى مزيد من العملاء بلغتهم الأم لتحسين تجربة الخروج.

   **اللغات الجديدة المضافة**

   | اللغة | الرمز |
   |----------|------|
   | الكورية | `ko` |
   | المالاوية | `ms` |
   | الرومانية | `ro` |
   | الروسية | `ru` |
   | التايلاندية | `th` |

   **جميع اللغات المدعومة**

اللغة العربية، الصينية، الهولندية، الإنجليزية، الفرنسية، الألمانية، الهندية، الإندونيسية، الإيطالية، اليابانية، الكورية، المالاوية، البرتغالية، الرومانية، الروسية، الإسبانية، السويدية، التايلاندية، التركية، الأوكرانية، الفيتنامية.

   **فرض لغة محددة**

   استخدم وسيط `force_language` لتجاوز الكشف التلقائي عن اللغة:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     force_language: 'ko', // Force Korean language
     return_url: 'https://yoursite.com/success'
   });
   ```

   <Tip>
   بشكل افتراضي، تقوم صفحة الخروج بالكشف تلقائيًا عن اللغة المفضلة للعميل من إعدادات متصفحهم. استخدم `force_language` عندما تريد ضمان التناسق مع لغة موقعك.
   </Tip>

   لمعرفة المزيد: [دعم اللغة في الخروج](/features/checkout#supported-languages)
