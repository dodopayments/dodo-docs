## ميزات جديدة 🚀

- **أول دفعة للاشتراك**: الميزة الأكثر طلبًا هنا! الآن، ستكون هناك معاملة واحدة للدفع الأول، تجمع بين التفويض ومبلغ الاشتراك الفعلي.

- **طريقة دفع UPI QR**: إضافة UPI QR كوسيلة دفع للسوق الهندي، مما يتيح للعملاء الدفع باستخدام رموز UPI QR.
    
    <img src="/images/changelog/upi-qr.png" alt="ميزة UPI QR" style={{ maxHeight: '500px', width: 'auto' }} />

- **رقم التعريف الضريبي عند الخروج**: يمكن للعملاء الآن إضافة رقم التعريف الضريبي الخاص بهم في صفحة الخروج لأغراض الفوترة والضرائب.

- **إعادة هيكلة لوحة التحكم**: تم إعادة هيكلة لوحة تحكم Dodo Payments بالكامل لتكون أكثر سهولة في الاستخدام وودية للمستخدم.

- **أدلة التوجيه الذاتي**: يمكن للمستخدمين الجدد الآن البدء في استخدام Dodo Payments باستخدام أدلة التوجيه الذاتي.

- **دعم متعدد اللغات**: تمت إضافة دعم لأكثر من 14 لغة في صفحة الدفع، مما يتيح للعملاء الدفع باللغة المفضلة لديهم. تشمل اللغات المدعومة:
    - English (en)
    - العربية (ar) // Arabic
    - Català (ca) // Catalan
    - 中文 (cn) // Chinese
    - Deutsch (de) // German
    - Español (es) // Spanish
    - Français (fr) // French
    - עברית (he) // Hebrew
    - Italiano (it) // Italian
    - 日本語 (ja) // Japanese
    - Nederlands (nl) // Dutch
    - Polski (pl) // Polish
    - Português (pt) // Portuguese
    - Svenska (sv) // Swedish

- **تجديد تصميم PDF الفاتورة**: تم منح PDF الفواتير تصميمًا جديدًا، أوضح وأكثر فعالية.

- **الأداة المساعدة المركزية**: إضافة أداة مساعدة مركزية لتبسيط وتحسين الدعم.

## تحسينات وإصلاحات الأخطاء 🔧

- **تحديد معدل الاستخدام**: تمت إضافة تحديد معدل الاستخدام في واجهة برمجة التطبيقات للفواتير لمنع الإساءة وضمان استقرار النظام.

- **البيانات الوصفية في روابط الدفع الثابتة**: تمت إضافة دعم البيانات الوصفية في روابط الدفع الثابتة. لمزيد من التفاصيل، يُرجى الرجوع إلى [التوثيق](/developer-resources/integration-guide#4-static-payment-links).

- **تحسينات وإصلاحات طفيفة**: تحسينات وإصلاحات طفيفة متنوعة لتحسين الأداء العام وتجربة المستخدم.
