## What is Dodo Payments?

Dodo Payments is the **all-in-one engine** to launch, scale, and monetize worldwide. Designed for the new generation of digital SaaS and AI products, we handle everything from **payments to billing to distribution** - all without extra engineering.

<Info>
**Built for SaaS and AI Products**: Handle one-time payments, subscriptions, credits, seats, tokens, or any usage metric with our optimized billing infrastructure.
</Info>

<Tip>
  <strong>Meet Sentra: Your AI-powered billing assistant</strong><br/>
  Sentra is an AI agent that integrates, analyzes, and acts on billing and payments directly in your IDE. Ask questions, build integrations, or plan billing architectures - all by describing what you want.
  <a href="/developer-resources/sentra">
    Get started with Sentra &rarr;
  </a>
</Tip>

## Quick Start Guide

Get up and running with Dodo Payments in just a few steps:

<Steps>
<Step title="Create Your Account">
  Sign up at [app.dodopayments.com](https://app.dodopayments.com/signup) using your email.

  <Check>
  You'll receive a confirmation email to verify your account.
  </Check>
</Step>

<Step title="Add Your First Product">
  Choose your billing model and add your product to start accepting payments.

**التثبيت**. بالنسبة لـ Claude Code أو Codex CLI أو Cursor أو OpenCode، يقوم [البرنامج المساعد لـ Dodo Agent](/developer-resources/build-with-ai-coding-agents) بتوصيل خوادم MCP وجميع المهارات في خطوة واحدة. راجع [دليل وكلاء التشفير AI](/developer-resources/build-with-ai-coding-agents) للحصول على أوامر تثبيت الوكيل لكل منها.

**اكتشف**. يتم تقديم فهرس المستندات الكامل في [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt)، وكل صفحة من صفحات الوثائق متاحة بتنسيق Markdown العادي عن طريق إلحاق `.md` بعنوان URL الخاص بها (على سبيل المثال، `/api-reference/introduction.md`).

**تواصل**. يقدم خادمان MCP وصولاً مباشراً للوكلاء إلى المنصة:

- **[Dodo Knowledge MCP](/developer-resources/mcp-server#dodo-knowledge-mcp)** - البحث الدلالي في جميع وثائق Dodo
- **[Dodo Payments MCP](/developer-resources/mcp-server)** - تنفيذ عمليات API (إنشاء المدفوعات، إدارة الاشتراكات، إصدار المبالغ المستردة)

راجع [دليل خادم MCP](/developer-resources/mcp-server) للحصول على التكوين الكامل للعميل.

**تمديد**. قم بتثبيت [مهارات مدفوعات Dodo](/developer-resources/agent-skills) الرسمية لتعليم وكيلك كيفية التعامل مع الخروج، الاشتراكات، الفوترة بناءً على الاستخدام، الفوترة المستندة إلى الائتمانات، ربط الشبكات، والمزيد:

  ```bash
  npx skills add dodopayments/skills
  ```

يعمل مع Claude Code وOpenCode وCursor وأي وكيل متوافق مع MCP.
</Accordion>
</AccordionGroup>

<Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
أضف كلا الخادمين إلى تكوين MCP الخاص بك (`~/.cursor/mcp.json` أو تكوين Claude Desktop):

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

<Info>
يتطلب Node.js 18+. راجع [وثائق خادم MCP](/developer-resources/mcp-server) للحصول على تعليمات الإعداد التفصيلية لجميع العملاء المدعومين.
</Info>
