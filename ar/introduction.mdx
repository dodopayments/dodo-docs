## ما هو Dodo Payments؟

Dodo Payments هو **المحرك المتكامل** لإطلاق منتجاتك وتوسيع نطاقها وتحقيق الدخل منها عالميًا. صُمم للجيل الجديد من منتجات SaaS والذكاء الاصطناعي الرقمية، ونتولى كل شيء بدءًا من **المدفوعات وصولًا إلى الفوترة والتوزيع**، من دون الحاجة إلى هندسة إضافية.

<Info>
**مصمم لمنتجات SaaS والذكاء الاصطناعي**: تعامل مع المدفوعات لمرة واحدة، والاشتراكات، والأرصدة، والمقاعد، والرموز، أو أي مقياس للاستخدام باستخدام بنيتنا التحتية المحسّنة للفوترة.
</Info>

<Tip>
  <strong>تعرّف على Sentra: مساعد الفوترة المدعوم بالذكاء الاصطناعي</strong><br/>
  Sentra هو وكيل ذكاء اصطناعي يتكامل مع الفوترة والمدفوعات، ويحللها ويتعامل معها مباشرةً داخل بيئة التطوير المتكاملة IDE. اطرح الأسئلة، وأنشئ عمليات التكامل، أو خطط بنى الفوترة، كل ذلك بمجرد وصف ما تريده.
  <a href="/developer-resources/sentra">
    ابدأ استخدام Sentra &rarr;
  </a>
</Tip>

## دليل البدء السريع

ابدأ العمل باستخدام Dodo Payments في بضع خطوات فقط.

<AccordionGroup>
<Accordion title="For Humans">
  هل تفضّل تنفيذ التكامل بنفسك؟ ترشدك الخطوات أدناه إلى إنشاء حساب، وإضافة منتج، واختيار طريقة التكامل في أقل من خمس دقائق. لا تحتاج إلى كتابة تعليمات برمجية لمسار عدم استخدام البرمجة؛ كما تتوفر أمثلة SDK بكل اللغات الرئيسية إذا رغبت في استخدامها.

  إذا كنت تفضّل أن يتولى مساعد البرمجة بالذكاء الاصطناعي العمل الشاق، مثل إعداد التكامل، ومعالجات webhook، وتدفقات الاشتراك، فثبّت **[Sentra](/developer-resources/sentra)**، مساعد الفوترة بالذكاء الاصطناعي الخاص بنا لـ VS Code وCursor وWindsurf. صف ما تريده؛ وسيخطط Sentra له ويُنشئ أساسه وينفذه.
</Accordion>

<Accordion title="For AI Agents">
  صُمم Dodo Payments لسير العمل الأصلي للوكلاء. إذا كنت نموذج LLM يقرأ هذا، أو مطورًا يهيئ أحدها، فابدأ من هنا.

  **التثبيت**. بالنسبة إلى Claude Code وCodex CLI وCursor وVS Code / GitHub Copilot وKiro أو OpenCode، يربط [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) كلاً من خادمي MCP وجميع skills في خطوة واحدة. يحصل Gemini CLI على خادمي MCP فقط. راجع [دليل AI Coding Agents](/developer-resources/build-with-ai-coding-agents) للاطلاع على أوامر التثبيت الخاصة بكل agent.

  **الاستكشاف**. يتوفر فهرس المستندات الكامل على [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt)، كما تتوفر كل صفحة توثيق بتنسيق markdown عادي عبر إضافة `.md` إلى عنوان URL الخاص بها (مثلًا `/api-reference/introduction.md`).

  **الاتصال**. يتيح خادما MCP الوصول المباشر إلى المنصة للوكلاء:

  - **[خادم MCP المعرفي لـ Dodo](/developer-resources/mcp-server#dodo-knowledge-mcp)** - بحث دلالي في جميع مستندات Dodo
  - **[MCP الخاص بـ Dodo Payments](/developer-resources/mcp-server)** - تنفيذ عمليات API، مثل إنشاء المدفوعات وإدارة الاشتراكات وإصدار المبالغ المستردة

  راجع [دليل خادم MCP](/developer-resources/mcp-server) للاطلاع على إعداد العميل الكامل.

  **التوسعة**. ثبّت [مهارات Dodo Payments الرسمية](/developer-resources/agent-skills) لتعليم وكيلك كيفية التعامل مع إتمام الدفع، والاشتراكات، والفوترة القائمة على الاستخدام، والفوترة القائمة على الأرصدة، وwebhooks، وغير ذلك:

  ```bash
  npx skills add dodopayments/skills
  ```

  يعمل مع Claude Code وCodex CLI وCursor وVS Code / GitHub Copilot وKiro وOpenCode وأي agent يدعم skills protocol.
</Accordion>
</AccordionGroup>

<Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
أضف الخادمين إلى إعداد MCP الخاص بك (`~/.cursor/mcp.json` أو إعداد Claude Desktop):

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

<Info>
يتطلب Node.js 18 أو إصدارًا أحدث. راجع [وثائق خادم MCP](/developer-resources/mcp-server) للاطلاع على تعليمات الإعداد التفصيلية لجميع العملاء المدعومين.
</Info>
