## Processus de Migration des Tokens de Carte

### 1. Demander l'Exportation des Tokens à l'Actuel Processeur

- Initiez le contact avec l'équipe de support de votre processeur de paiement actuel via leurs canaux de support officiels
- Soumettez une demande formelle pour une exportation complète de tous vos tokens de carte client
- Soyez prêt à fournir une vérification de votre identité et une autorisation d'accès à ces données sensibles
- Votre processeur de paiement exigera probablement que vous complétiez plusieurs étapes de vérification de conformité
- Des approbations de sécurité supplémentaires peuvent être nécessaires de la part de leurs équipes de risque et de conformité
- Le processus pourrait prendre 5 à 10 jours ouvrables selon les politiques de votre processeur

### 2. Partager l'Export de Manière Sécurisée avec Dodo Payments

- Dès réception du fichier d'exportation de tokens chiffré de votre processeur actuel, ne le déchiffrez pas
- Vous avez deux options sécurisées pour partager les données avec notre équipe :
  1. Utilisez notre portail de téléchargement sécurisé dédié à [lien de téléchargement sécurisé]
  2. Transférez via notre serveur SFTP (les identifiants seront fournis sur demande)
- Limitez strictement l'accès au fichier au personnel autorisé avec la sécurité appropriée
- Documentez toutes les personnes qui manipulent le fichier pour maintenir une chaîne de custody claire
- Suivez toutes les exigences PCI DSS pour le traitement des données de paiement sensibles
- Supprimez immédiatement toutes les copies locales du fichier après un transfert réussi

### 3. Dodo Payments Traite la Migration

- Notre équipe de migration spécialisée s'occupera du processus d'importation des tokens
- Nous suivons une procédure détaillée pour :
  - Vérifier l'intégrité et le chiffrement du fichier
  - Mapper l'ancien format de token à notre structure de token sécurisée
  - Importer les tokens dans notre coffre-fort de cartes conforme PCI en utilisant un chiffrement de niveau militaire
  - Effectuer plusieurs vérifications de validation pour garantir l'exactitude des données
- Vous recevrez des mises à jour détaillées sur l'état tout au long du processus
- Une fois terminé, nous enverrons un rapport de migration complet
- Le temps de traitement typique est de 2 à 3 jours ouvrables pour les migrations standard

### 4. Valider et Commencer à Utiliser les Nouveaux Tokens

- Nous fournirons une documentation détaillée sur le nouveau format de token
- Vous recevrez un mappage complet des anciens tokens aux nouveaux tokens Dodo Payments
- Un environnement sandbox dédié sera provisionné pour les tests
- Nous recommandons :
  - De tester tous les types de transactions avec les tokens migrés
  - De vérifier le traitement réussi des charges récurrentes
  - De confirmer le stockage et la récupération appropriés des tokens
  - De faire fonctionner des systèmes parallèles temporairement pour assurer une transition fluide
- Notre équipe technique sera disponible pour le support tout au long des tests

### 5. Chiffrement PGP pour un Transfert de Données Sécurisé
