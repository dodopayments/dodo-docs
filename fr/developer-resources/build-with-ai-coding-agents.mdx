Le Plugin Agent Dodo connecte deux serveurs MCP et huit compétences d'intégration à votre agent de codage IA en une seule installation. Il fonctionne avec **Claude Code**, **Codex CLI**, **Cursor**, et **OpenCode** — et les serveurs et compétences MCP CLI fonctionnent avec tout client compatible MCP.

<Info>
**Trois primitives, un plugin.** Le Plugin Agent regroupe tout ce dont vous avez besoin :
- **Serveur API MCP** — accès en direct aux paiements, abonnements, clients, produits, remboursements, licences, et utilisation. Authentification via OAuth du navigateur (pas de clés locales requises).
- **Serveur de Connaissances MCP** — recherche sémantique à travers toute la documentation Dodo Payments. Aucune référence requise.
- **Huit compétences d'agent** — fiches pratiques que votre agent charge à la demande pour checkout, abonnements, webhooks, facturation basée sur l'utilisation, facturation basée sur le crédit, clés de licence, BillingSDK, et meilleures pratiques.
</Info>

## Installer le plugin

Choisissez votre agent de codage ci-dessous. L'installation ajoute automatiquement les deux serveurs MCP et toutes les huit compétences.

<AccordionGroup>
<Accordion title="Claude Code" defaultOpen>
Installez depuis le marché :

```bash
claude plugins marketplace add dodopayments/dodo-agent-plugin
claude plugins install dodopayments@dodopayments
```

Le serveur API MCP utilise OAuth du navigateur par défaut — pas de clés requises lors de l'installation. La première fois que votre agent appelle un outil Dodo, vous serez invité à vous connecter.

<Accordion title="OpenCode">
OpenCode distribue via npm. Ajoutez le plugin à votre `opencode.json` :

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"]
}
```

Redémarrez OpenCode. Les deux serveurs MCP (`dodopayments-api`, `dodo-knowledge`) sont enregistrés automatiquement via le hook de configuration du plugin, et les huit compétences sont découvertes automatiquement à partir du package installé. Aucun bloc `mcp` manuel requis.

## Ce que vous obtenez

Une fois le plugin installé, votre agent a accès à deux serveurs MCP et huit compétences.

### Serveurs MCP

| Serveur | Objectif | Auth |
|--------|---------|------|
| `dodopayments-api` | Accès API en direct — paiements, abonnements, clients, produits, remboursements, licences, utilisation | OAuth (navigateur) |
| `dodo-knowledge` | Recherche sémantique dans toute la documentation Dodo Payments | Aucun |

Les deux serveurs sont connectés via `mcp-remote` afin qu'ils fonctionnent dans tout client compatible MCP.

### Compétences d'agent

| Compétence | Description |
|-------|-------------|
| `best-practices` | Guide complet pour intégrer Dodo Payments avec les meilleures pratiques |
| `checkout-integration` | Création de sessions de paiement et flux de paiement |
| `subscription-integration` | Mise en œuvre de flux de facturation d'abonnement |
| `webhook-integration` | Configuration et gestion des webhooks pour les événements de paiement |
| `usage-based-billing` | Mise en œuvre de la facturation mesurée avec événements et compteurs |
| `credit-based-billing` | Droits de crédit, soldes et déduction de crédit mesurée |
| `license-keys` | Gestion des clés de licence pour produits numériques |
| `billing-sdk` | Utilisation des composants React BillingSDK |

Les compétences se chargent automatiquement — votre agent choisit la bonne lorsqu'il détecte une tâche pertinente. Voir la [documentation des compétences d'agent](/developer-resources/agent-skills) pour la liste complète et l'installation individuelle.

### Essayez ce prompt en premier

Une fois le plugin actif, essayez :

```
Set up Dodo Payments webhook handlers in my Next.js app for payment.succeeded and subscription.active events.
```

Votre agent chargera la compétence `webhook-integration`, utilisera le MCP `dodo-knowledge` pour récupérer les dernières formes de charge utile, et écrira un gestionnaire avec vérification de signature suivant la spécification des Standard Webhooks.

## Documentation conçue pour les agents

Chaque page de documentation Dodo Payments est disponible dans un format optimisé pour la consommation par IA :

- **Index complet des documents** : [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt) — fournit l'index complet de la documentation pour l'ingestion contextuelle.
- **Markdown brut** : Ajoutez `.md` à n'importe quelle URL de documentation pour obtenir la version markdown brute (par exemple, `/api-reference/introduction.md`).
- **Dépôt source** : [`github.com/dodopayments/dodo-docs`](https://github.com/dodopayments/dodo-docs) — clonez pour indexation hors ligne.

## Ce que votre agent peut faire

Avec le plugin installé, votre agent de codage peut :

- **Créer des sessions de paiement et des liens de paiement** — [Paiements uniques](/features/one-time-payment-products) et [abonnements](/features/subscription)
- **Mettre en place une facturation par abonnement et basée sur l'utilisation de bout en bout** — [Abonnements](/features/subscription), [Facturation basée sur l'utilisation](/features/usage-based-billing), [Facturation basée sur le crédit](/features/credit-based-billing)
- **Générer des gestionnaires conformes aux Standard Webhooks** avec vérification de signature — [Webhooks](/developer-resources/webhooks)
- **Intégrer les composants React de BillingSDK** pour les tableaux de tarification et la gestion des abonnements — [BillingSDK](/developer-resources/billingsdk)
- **Rédiger des flux de clés de licence** pour les produits numériques — [Clés de licence](/features/license-keys)
- **Implémenter une facturation basée sur le crédit** avec droits, soldes, report et dépassement — [Crédits](/features/credit-based-billing)

## Sécurité et meilleures pratiques

<Warning>
**Ne vous engagez jamais avec des clés API de production.** Utilisez le [mode test](/miscellaneous/test-mode-vs-live-mode) pendant le développement. Le plugin d'agent utilise par défaut OAuth du navigateur — ne passez à des clés API locales que si votre flux de travail l'exige.
</Warning>

- **Utilisez d'abord le mode test.** Testez votre intégration avec les clés `dodo_test_...` avant de passer en production. Voir [Mode test vs Mode live](/miscellaneous/test-mode-vs-live-mode).
- **OAuth est par défaut.** Le plugin d'agent s'authentifie via OAuth du navigateur (aucun secret local). Utilisez le mode clé API uniquement si nécessaire — voir la section Configuration ci-dessous.
- **Relisez le code généré par l'agent.** Vérifiez toujours que les gestionnaires de webhooks incluent la vérification de signature suivant la [spécification des Standard Webhooks](https://standardwebhooks.com/).

## Configurer avec une clé API

Par défaut, le plugin d'agent utilise le serveur MCP distant avec OAuth du navigateur — pas besoin d'identifiants locaux. Si votre flux de travail nécessite une clé API locale (par exemple, environnements CI, serveurs sans interface), vous pouvez passer au mode stdio.

<AccordionGroup>
<Accordion title="Local API key mode — Claude Code">
Ouvrez `/plugins` dans Claude Code, sélectionnez **Dodo Payments** et choisissez **Configurer les options**. Remplissez :

- `dodo_api_key` — votre clé `dodo_test_...` ou `dodo_live_...`
- `dodo_webhook_key` — votre secret de signature de webhook
- `dodo_environment` — `test_mode` ou `live_mode`

Puis éditez `.mcp.json` pour pointer `dodopayments-api` vers le serveur stdio local :

```json
{
  "mcpServers": {
    "dodopayments-api": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "dodopayments-mcp@latest"],
      "env": {
        "DODO_PAYMENTS_API_KEY": "${user_config.dodo_api_key}",
        "DODO_PAYMENTS_WEBHOOK_KEY": "${user_config.dodo_webhook_key}",
        "DODO_PAYMENTS_ENVIRONMENT": "${user_config.dodo_environment}"
      }
    }
  }
}
```

Exécutez `/reload-plugins` pour appliquer les changements à votre session actuelle.
</Accordion>

<Accordion title="Local API key mode — OpenCode">
Déclarez `dodopayments-api` vous-même dans `opencode.json` — votre entrée prévaut sur le serveur distant par défaut du plugin :

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "mcp": {
    "dodopayments-api": {
      "type": "local",
      "command": ["npx", "-y", "dodopayments-mcp@latest"],
      "environment": {
        "DODO_PAYMENTS_API_KEY": "dodo_test_...",
        "DODO_PAYMENTS_WEBHOOK_KEY": "whsec_...",
        "DODO_PAYMENTS_ENVIRONMENT": "test_mode"
      },
      "enabled": true
    }
  }
}
```

Redémarrez OpenCode pour appliquer.
</Accordion>
</AccordionGroup>
