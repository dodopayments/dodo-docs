## Overview

Agent Skills are reusable capabilities that enhance what AI coding assistants can do when working with Dodo Payments. They provide procedural knowledge and best practices that help agents accomplish specific tasks more effectively - from integrating checkout flows to setting up usage-based billing.

<Info>
**Think of skills as plugins for your AI assistant.** They teach your agent how to implement Dodo Payments features correctly, following our recommended patterns and best practices.
</Info>

Les skills fonctionnent avec tout agent IA prenant en charge le protocole skills, notamment :
- **Claude Code** - assistant de programmation CLI d'Anthropic
- **Codex CLI** - agent de programmation CLI d'OpenAI
- **Cursor** - éditeur de code conçu autour de l'IA
- **VS Code / GitHub Copilot** - via le plugin Agent
- **Kiro** - charge les skills en tant que Power
- **OpenCode** - agent de programmation IA open source
- **Autres clients** - tout agent prenant en charge le protocole skills

<Note>
**Gemini CLI est l'exception.** Il ne dispose d'aucun primitive agent-skill, les skills n'y sont donc pas disponibles — seuls les deux [serveurs MCP](/developer-resources/mcp-server) le sont.
</Note>

## Installation

Choisissez votre méthode d'installation préférée en fonction de votre assistant de programmation IA.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Si vous utilisez Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro ou OpenCode, le [plugin Agent Dodo](/developer-resources/build-with-ai-coding-agents) installe les dix-sept skills ainsi que les deux serveurs MCP en une seule étape. Les skills se chargent automatiquement lorsque votre agent détecte une tâche pertinente.

Consultez le [guide des agents de programmation IA](/developer-resources/build-with-ai-coding-agents) pour connaître les commandes d'installation propres à chaque agent.
</Tab>

<Tab title="Skills CLI">
Installez les skills à l'aide de la skills CLI universelle, compatible avec tout agent compatible MCP :

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Vous pouvez également installer des skills individuels selon vos besoins :

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/dodo-best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
Installez uniquement les skills dont vous avez besoin afin de garder votre agent concentré et de réduire la surcharge de contexte.
</Tip>
</Tab>

<Tab title="OpenCode">
OpenCode charge les skills depuis les répertoires que vous lui indiquez. Il n'analyse **pas** les packages installés ; une entrée explicite `skills.paths` est donc requise.

Utilisation du package Agent Plugin :

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

Les chemins relatifs sont résolus par rapport au **répertoire du projet** ; le package doit donc être présent dans le `node_modules` de ce projet. Un chemin absolu fonctionne également et évite d'avoir à effectuer une installation locale.

<Warning>
Un chemin de skills qui n'existe pas est ignoré **silencieusement** — aucune erreur ni aucun avertissement. Vérifiez que les skills ont bien été chargés :

```bash
opencode run "List every skill available to you by name."
```

Vous devriez tous les voir apparaître, au nombre de dix-sept.
</Warning>
</Tab>
</Tabs>

## Utiliser les skills

Une fois installés, vos assistant IA charge automatiquement le skill pertinent lorsque vous lui demandez d'implémenter une fonctionnalité Dodo Payments. Vous n'avez pas besoin de nommer le skill : décrivez simplement la tâche.

| Exemple de prompt | Skill chargé |
|----------------|------------------|
| Aidez-moi à intégrer Dodo Payments dans mon application Next.js en suivant les bonnes pratiques | `dodo-best-practices` |
| Ajoutez un gestionnaire de routes checkout Dodo Payments à mon application Hono | `framework-adapters` |
| Guidez-moi dans les tests des paiements et la mise en production | `testing-and-go-live` |
| Créez une session checkout pour mon produit SaaS | `checkout-integration` |
| Implémentez un parcours d'abonnement avec un essai gratuit et plusieurs niveaux de tarification | `subscription-integration` |
| Ajoutez un checkout intégré à l'application React Native | `mobile-checkout` |
| Configurez des gestionnaires de webhooks pour les événements de paiement et d'abonnement | `webhook-integration` |
| Configurez les droits de crédit et la déduction de crédits basée sur un meter pour mon produit IA | `credit-based-billing` |
| Ajoutez une facturation basée sur l'utilisation pour suivre les appels API de mon produit IA | `usage-based-billing` |
| Implémentez la validation des clés de licence pour mon application de bureau | `license-keys` |
| Créez un catalogue de produits avec des add-ons et une tarification par niveaux | `product-catalog-management` |
| Ajoutez un code promotionnel offrant 20 % de réduction sur les trois premiers cycles de facturation | `discounts-and-promotions` |
| Affichez les prix dans la devise locale du visiteur avec la parité de pouvoir d'achat | `localized-pricing` |
| Donnez aux clients un portail en libre-service pour gérer leurs moyens de paiement | `customer-management` |
| Émettez un remboursement partiel et révoquez l'accès lorsqu'un litige est ouvert | `refunds-and-disputes` |
| Ajoutez une page de tarification à l'aide des composants BillingSDK | `billing-sdk` |
| Intégrez Dodo Payments à ma configuration Better Auth | `better-auth-integration` |

## Fonctionnement des skills

Les skills fournissent à votre assistant IA :

1. **Connaissances procédurales** - Instructions étape par étape pour implémenter des fonctionnalités
2. **Modèles de code** - Patterns et snippets de code prêts pour la production
3. **Bonnes pratiques** - Approches recommandées pour la sécurité, la gestion des erreurs et l'UX
4. **Compréhension du contexte** - Compréhension de la manière dont les différentes fonctionnalités de Dodo Payments fonctionnent ensemble

Lorsque vous demandez à votre assistant IA d'implémenter une fonctionnalité, il utilise le skill pertinent pour :
- Comprendre la bonne approche d'implémentation
- Générer un code précis et fonctionnel
- Respecter les conventions de Dodo Payments
- Gérer correctement les cas particuliers et les erreurs

<Note>
Les skills complètent le [serveur MCP](/developer-resources/mcp-server) et [Sentra](/developer-resources/sentra). Utilisez MCP pour les opérations API, Sentra pour une intégration guidée et les skills pour améliorer les capacités de votre assistant IA.
</Note>
