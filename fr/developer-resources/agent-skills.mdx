## Overview

Agent Skills are reusable capabilities that enhance what AI coding assistants can do when working with Dodo Payments. They provide procedural knowledge and best practices that help agents accomplish specific tasks more effectively - from integrating checkout flows to setting up usage-based billing.

<Info>
**Think of skills as plugins for your AI assistant.** They teach your agent how to implement Dodo Payments features correctly, following our recommended patterns and best practices.
</Info>

Skills work with any MCP-compatible AI agent, including:
- **Claude Code** - Anthropic's CLI coding assistant
- **OpenCode** - Open source AI coding agent
- **Cursor** - AI-first code editor
- **Other MCP clients** - Any agent supporting the skills protocol

## Installation

Choisissez votre méthode d’installation préférée en fonction de votre assistant de programmation IA.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Si vous utilisez Claude Code, Codex CLI, Cursor ou OpenCode, le [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) installe les dix-sept skills ainsi que les deux serveurs MCP en une seule étape. Les skills se chargent automatiquement lorsque votre agent détecte une tâche pertinente.

Consultez le [guide des assistants de programmation IA](/developer-resources/build-with-ai-coding-agents) pour connaître les commandes d’installation propres à chaque agent.
</Tab>

<Tab title="Skills CLI">
Installez les skills à l’aide de la CLI universelle de skills, compatible avec tout agent compatible avec MCP :

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Vous pouvez également installer des skills individuels selon vos besoins :

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
Installez uniquement les skills dont vous avez besoin afin de garder votre agent concentré et de réduire la surcharge de contexte.
</Tip>
</Tab>

<Tab title="Claude Code">
Ajoutez la marketplace de skills Dodo Payments à Claude Code :

```bash

```

Installez ensuite les plugins individuels :

```bash expandable

# Accepting payments

# Billing models

# Catalog and pricing

# Customers and operations
/plugin install customer-management
```

</Tab>

<Tab title="OpenCode">
Les skills sont automatiquement disponibles lorsqu’ils sont configurés dans vos paramètres OpenCode. Ajoutez le dépôt de skills Dodo Payments à votre configuration :

```json
{
  "skills": {
    "repositories": [
      "dodopayments/skills"
    ]
  }
}
```

</Tab>

## Utiliser les skills

Une fois installés, vos assistants de programmation IA chargent automatiquement le skill pertinent lorsque vous leur demandez d’implémenter une fonctionnalité Dodo Payments. Vous n’avez pas besoin de nommer le skill : il vous suffit de décrire la tâche.

| Exemple de prompt | Skill chargé |
|----------------|------------------|
| Aidez-moi à intégrer Dodo Payments dans mon application Next.js en suivant les bonnes pratiques | `dodo-best-practices` |
| Ajoutez un gestionnaire de route checkout Dodo Payments à mon application Hono | `framework-adapters` |
| Guidez-moi pour tester les paiements et passer en production | `testing-and-go-live` |
| Créez une Checkout Session pour mon produit SaaS | `checkout-integration` |
| Implémentez un parcours d’abonnement avec une période d’essai gratuite et plusieurs niveaux de tarification | `subscription-integration` |
| Ajoutez un checkout intégré à l’application React Native | `mobile-checkout` |
| Configurez des gestionnaires de webhooks pour les événements de paiement et d’abonnement | `webhook-integration` |
| Configurez les droits en crédits et la déduction de crédits basée sur un meter pour mon produit IA | `credit-based-billing` |
| Ajoutez une facturation à l’usage pour suivre les appels API de mon produit IA | `usage-based-billing` |
| Implémentez la validation des clés de licence pour mon application de bureau | `license-keys` |
| Créez un catalogue de produits avec des modules complémentaires et une tarification par niveaux | `product-catalog-management` |
| Ajoutez un code promotionnel offrant 20 % de réduction sur les trois premiers cycles de facturation | `discounts-and-promotions` |
| Affichez les prix dans la devise locale du visiteur avec la parité de pouvoir d’achat | `localized-pricing` |
| Offrez aux clients un portail en libre-service pour gérer leurs moyens de paiement | `customer-management` |
| Émettez un remboursement partiel et révoquez l’accès lorsqu’un litige est ouvert | `refunds-and-disputes` |
| Ajoutez une page de tarification à l’aide des composants BillingSDK | `billing-sdk` |
| Intégrez Dodo Payments à ma configuration Better Auth | `better-auth-integration` |

## Fonctionnement des skills

Les skills fournissent à votre assistant de programmation IA :

1. **Connaissances procédurales** - Instructions étape par étape pour implémenter des fonctionnalités
2. **Modèles de code** - Patterns et snippets de code prêts pour la production
3. **Bonnes pratiques** - Approches recommandées pour la sécurité, la gestion des erreurs et l’UX
4. **Compréhension du contexte** - Compréhension de la manière dont les différentes fonctionnalités de Dodo Payments fonctionnent ensemble

Lorsque vous demandez à votre assistant de programmation IA d’implémenter une fonctionnalité, il utilise le skill pertinent pour :
- Comprendre la bonne approche d’implémentation
- Générer un code précis et fonctionnel
- Respecter les conventions de Dodo Payments
- Gérer correctement les cas particuliers et les erreurs

<Note>
Les skills complètent le [MCP Server](/developer-resources/mcp-server) et [Sentra](/developer-resources/sentra). Utilisez MCP pour les opérations API, Sentra pour une intégration guidée et les skills pour améliorer les capacités de votre assistant de programmation IA.
</Note>
