Gérez vos ressources Dodo Payments, créez des sessions de paiement et testez les webhooks directement depuis le terminal. Conçu pour les développeurs qui préfèrent la ligne de commande.

## Installation

<CodeGroup>

```bash npm (Recommended)
npm install -g dodopayments-cli
```

```bash Bun
bun install -g dodopayments-cli
```

</CodeGroup>

### Installation Manuelle

1. Téléchargez la dernière version depuis [GitHub Releases](https://github.com/dodopayments/dodopayments-cli/releases) pour votre système
2. Extrayez et renommez le binaire en `dodo`
3. Déplacez-le vers un répertoire dans votre PATH :

<CodeGroup>

```bash Linux
sudo mv ./dodo /usr/local/bin/
```

```text Windows
move .\dodo C:\Windows\System32\dodo
```

</CodeGroup>

## Authentification

Avant d'utiliser le CLI, authentifiez-vous avec votre clé API :

```bash
dodo login
```

Cela permettra de :
1. Ouvrir votre navigateur sur la page des clés API de Dodo Payments
2. Vous demander d'entrer votre clé API
3. Vous demander de choisir l'environnement (**Mode Test** ou **Mode Actif**)
4. Stocker vos identifiants localement dans `~/.dodopayments/api-key`

<Info>
Le CLI prend en charge le stockage d'une clé API par environnement. Si les clés de test et de production sont configurées, vous serez invité à choisir quel environnement utiliser pour la session actuelle.
</Info>

## Utilisation

La syntaxe générale est :

```bash
dodo ‹category› ‹sub-command›
```

Exécuter `dodo` sans arguments affiche toutes les catégories disponibles. Exécuter `dodo <category>` sans sous-commande montre les sous-commandes disponibles pour cette catégorie.

### Produits

Gérez votre catalogue de produits.

| Commande | Description |
|---------|-------------|
| `dodo products list` | Lister tous les produits (paginé) |
| `dodo products create` | Ouvrir le tableau de bord pour créer un produit |
| `dodo products info` | Voir les détails d'un produit spécifique |

### Paiements

Voir les transactions de paiement.

| Commande | Description |
|---------|-------------|
| `dodo payments list` | Lister tous les paiements (paginé) |
| `dodo payments info` | Obtenir des informations sur un paiement spécifique |

### Clients

Gérez votre base de clients.

| Commande | Description |
|---------|-------------|
| `dodo customers list` | Lister tous les clients (paginé) |
| `dodo customers create` | Créer un nouveau profil client |
| `dodo customers update` | Mettre à jour les détails d'un client existant |

### Remises

Gérez les coupons et remises.

| Commande | Description |
|---------|-------------|
| `dodo discounts list` | Lister toutes les remises (paginé) |
| `dodo discounts create` | Créer une nouvelle remise basée sur un pourcentage |
| `dodo discounts delete` | Supprimer une remise par ID |

### Licences

Gérez les licences de logiciels.

| Commande | Description |
|---------|-------------|
| `dodo licences list` | Lister toutes les clés de licence (paginé) |

### Addons

Gérez les addons de produits.

| Commande | Description |
|---------|-------------|
| `dodo addons list` | Lister tous les addons (paginé) |
| `dodo addons create` | Ouvrir le tableau de bord pour créer un addon |
| `dodo addons info` | Voir les détails d'un addon spécifique |

### Remboursements

Voir les informations de remboursement.

| Commande | Description |
|---------|-------------|
| `dodo refund list` | Lister tous les remboursements (paginé) |
| `dodo refund info` | Voir les détails d'un remboursement spécifique |

### Paiement

Créez des sessions de paiement.

| Commande | Description |
|---------|-------------|
| `dodo checkout new` | Créer une nouvelle session de paiement et obtenir l'URL de paiement |

La commande de paiement prend en charge des options avancées, y compris la collecte d'adresses minimales, l'URL de retour, l'application de 3D Secure, les codes de réduction et les métadonnées.

## Test de Webhook

Le CLI comprend deux outils puissants pour tester les webhooks pendant le développement : un **écouteur** qui redirige les webhooks de test en direct vers votre serveur local et un **déclencheur** qui envoie des charges utiles de webhook fictives à n'importe quel point de terminaison.

### Écouter les Webhooks

Transférez les webhooks de Dodo Payments directement vers votre serveur de développement local en temps réel.

```bash
dodo wh listen
```

<Steps>
<Step title="Entrez votre URL de point de terminaison local">
  Fournissez l'URL locale où vous souhaitez recevoir les webhooks (par exemple, `http://localhost:3000/webhook`).
</Step>

<Step title="Configuration automatique">
  Le CLI crée automatiquement un point de terminaison de webhook sur votre compte Dodo Payments s'il n'existe pas déjà, puis ouvre une connexion WebSocket pour recevoir des événements en temps réel.
</Step>

<Step title="Recevoir et transférer">
  Lorsqu'un événement de webhook se déclenche (à partir d'un paiement de test, d'un changement d'abonnement, etc.), le CLI le reçoit, enregistre le type d'événement et transfère l'intégralité de la requête avec les en-têtes et le corps vers votre point de terminaison local. La réponse de votre point de terminaison est enregistrée et renvoyée.
</Step>
</Steps>

<Warning>
L'écouteur de webhook ne fonctionne qu'avec une clé API en **mode test**. Assurez-vous d'être connecté avec une clé en mode test avant d'utiliser `dodo wh listen`.
</Warning>

<Tip>
L'écouteur préserve les en-têtes d'origine du webhook (`webhook-id`, `webhook-signature`, `webhook-timestamp`) lors de la redirection vers votre point de terminaison local, afin que vous puissiez tester votre logique de vérification de signature.
</Tip>

### Déclencher des Webhooks de Test

Envoyez des charges utiles de webhook fictives à n'importe quel point de terminaison pour des tests rapides sans avoir besoin de créer de vraies transactions.

```bash
dodo wh trigger
```

Cela vous guide à travers :
1. Définir une **URL de point de terminaison** de destination
2. Configurer facultativement **l'ID de l'entreprise**, **l'ID du produit** et **les métadonnées**
3. Sélectionner un **événement** spécifique à déclencher depuis un menu interactif
4. Envoyer la charge utile fictive et voir la réponse

Après chaque événement, vous pouvez sélectionner un autre événement à déclencher ou sortir - facilitant ainsi le test de plusieurs gestionnaires d'événements dans une seule session.

<Warning>
L'outil de déclenchement envoie des charges utiles fictives sans signatures de webhook. Désactivez la vérification de signature de webhook pendant les tests en utilisant `unsafe_unwrap()` au lieu de `unwrap()` dans votre gestionnaire de webhook.
</Warning>

### Événements de Webhook Pris en Charge

| Catégorie | Événements |
|----------|--------|
| **Abonnement** | `subscription.active`, `subscription.updated`, `subscription.on_hold`, `subscription.renewed`, `subscription.plan_changed`, `subscription.cancelled`, `subscription.failed`, `subscription.expired` |
| **Paiement** | `payment.success`, `payment.failed`, `payment.processing`, `payment.cancelled` |
| **Remboursement** | `refund.success`, `refund.failed` |
| **Litige** | `dispute.opened`, `dispute.expired`, `dispute.accepted`, `dispute.cancelled`, `dispute.challenged`, `dispute.won`, `dispute.lost` |
| **Licence** | `licence.created` |

### Variables d'Environnement

| Variable | Description |
|----------|-------------|
| `DODO_WH_TEST_SERVER_URL` | Remplacer l'URL du serveur de relais de webhook par défaut utilisé par `dodo wh listen` |
