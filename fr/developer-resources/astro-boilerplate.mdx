## Aperçu

Le boilerplate minimal Astro fournit un point de départ prêt à l'emploi pour intégrer Dodo Payments avec votre application Astro. Ce modèle inclut l'authentification, la gestion des webhooks et la configuration de paiement de base pour vous aider à commencer à accepter des paiements rapidement.

<Info>
Ce boilerplate utilise Astro avec TypeScript et inclut des implémentations d'exemple pour les sessions de paiement et la vérification des webhooks.
</Info>

## Démarrage Rapide

<Steps>
<Step title="Cloner le Référentiel">
Clonez le référentiel du boilerplate et naviguez jusqu'au répertoire du projet :

```bash
git clone https://github.com/dodopayments/dodo-astro-minimal-boilerplate.git
cd dodo-astro-minimal-boilerplate
```

</Step>

<Step title="Obtenez Vos Identifiants API">
Obtenez vos identifiants depuis le tableau de bord Dodo Payments en mode Test :

- **Clé API** : Allez dans **Développeur → Clés API** dans votre [tableau de bord](https://app.dodopayments.com)
- **Clé de Signature Webhook** : Allez dans **Développeur → Webhooks** dans votre [tableau de bord](https://app.dodopayments.com)

<Tip>
Commencez avec le mode Test pour tester votre intégration en toute sécurité sans traiter de paiements réels.
</Tip>
</Step>

<Step title="Configurer les Variables d'Environnement">
Créez un `.env` fichier dans le répertoire racine :

```bash
touch .env
```

Ajoutez vos identifiants Dodo Payments :

```bash .env
DODO_API_KEY_TEST=your_test_api_key_here
DODO_PAYMENTS_WEBHOOK_KEY=your_webhook_signing_key_here
```

<Warning>
Ne jamais commettre votre `.env` fichier dans le contrôle de version. Il est déjà inclus dans `.gitignore`.
</Warning>
</Step>

<Step title="Configurer le Webhook Localhost">
Lors de tests de webhooks localement, exposez votre localhost en utilisant des outils comme [ngrok](https://ngrok.com) :

```bash
ngrok http 4321
```

Ajoutez l'URL ngrok à la `allowed_hosts` liste dans `astro.config.mjs` pour la livraison des webhooks :

```javascript astro.config.mjs
export default defineConfig({
  server: {
    host: true,
    allowedHosts: ['your-ngrok-url.ngrok.io']
  }
});
```

<Note>
Cette étape est nécessaire pour que les webhooks soient livrés à votre environnement de développement local.
</Note>
</Step>

<Step title="Installer les Dépendances">
Installez les packages npm requis :

```bash
npm install
```

</Step>

<Step title="Lancer le Serveur de Développement">
Démarrez le serveur de développement Astro :

```bash
npm run dev
```

Votre application sera disponible à `http://localhost:4321`.

<Check>
Vous êtes prêt à commencer à construire ! Le boilerplate inclut des routes et des composants d'exemple pour vous aider à comprendre l'intégration.
</Check>
</Step>
</Steps>

## Structure du Projet

```
dodo-astro-minimal-boilerplate/
├── src/
│   ├── pages/
│   │   ├── api/
│   │   │   └── webhooks.ts     # Webhook handler
│   │   └── index.astro         # Home page with examples
│   └── lib/
│       └── dodo.ts             # Dodo Payments client setup
├── .env.example                # Environment variables template
├── astro.config.mjs            # Astro configuration
└── package.json
```

## Prochaines Étapes

Une fois que vous avez le boilerplate en cours d'exécution :

<Steps>
<Step title="Créez Vos Produits">
Ajoutez des produits dans votre [tableau de bord Dodo Payments](https://app.dodopayments.com) pour activer la fonctionnalité de paiement.
</Step>

<Step title="Tester les Webhooks Localement">
Utilisez [ngrok](https://ngrok.com) pour exposer votre point de terminaison webhook local et mettez à jour le `allowed_hosts` dans `astro.config.mjs` :

```bash
ngrok http 4321
```

Ajoutez l'URL ngrok à vos paramètres de webhook dans le tableau de bord.
</Step>

<Step title="Personnalisez l'Intégration">
Adaptez le code d'exemple pour correspondre aux besoins et au design de votre application.
</Step>

<Step title="Mettez en Production">
Lorsque vous êtes prêt, passez aux clés API en mode Live et déployez votre application.
</Step>
</Steps>
