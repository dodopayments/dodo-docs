Dodo Payments fournit des SDK officiels pour plusieurs langages de programmation. Chacun est conçu selon les bonnes pratiques propres à son langage et avec des fonctionnalités modernes, pour une intégration fluide des paiements.

<Tip>
Utilisez toujours la dernière version du SDK pour bénéficier des fonctionnalités et améliorations les plus récentes. Consultez régulièrement votre gestionnaire de paquets pour vérifier les mises à jour et vous assurer d’avoir accès à toutes les capacités de Dodo Payments.
</Tip>

## Démarrage rapide

Commencez à utiliser n’importe quel SDK en quelques minutes :

<Steps>
<Step title="Install the SDK">
  Utilisez le gestionnaire de paquets de votre langage pour installer le SDK
  
  <Tabs>
  <Tab title="TypeScript/Node.js">

  ```bash
  npm install dodopayments
  ```

  </Tab>
  
  <Tab title="Python">

  ```bash
  pip install dodopayments
  ```

  </Tab>
  
  <Tab title="PHP">

  ```bash
  composer require dodopayments/client
  ```

  </Tab>
  
  <Tab title="Go">

  ```bash
  go get github.com/dodopayments/dodopayments-go
  ```

  </Tab>

  <Tab title="Rust">

  ```bash
  cargo add dodopayments
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Initialize the Client">
  Configurez le client avec votre clé API
  
  <Tabs>
  <Tab title="TypeScript">

  ```typescript
  import DodoPayments from 'dodopayments';
  const client = new DodoPayments({ bearerToken: 'your_api_key' });
  ```

  </Tab>
  
  <Tab title="Python">

  ```python
  from dodopayments import DodoPayments
  client = DodoPayments(bearer_token="your_api_key")
  ```

  </Tab>
  
  <Tab title="PHP">

  ```php
  use Dodopayments\Client;
  $client = new Client(bearerToken: 'your_api_key');
  ```

  </Tab>
  
  <Tab title="Go">

  ```go
  import "github.com/dodopayments/dodopayments-go"
  client := dodopayments.NewClient(option.WithBearerToken("your_api_key"))
  ```

  </Tab>

  <Tab title="Rust">

  ```rust
  use dodopayments::Client;
  let client = Client::from_env()?; // reads DODO_PAYMENTS_API_KEY
  ```

  </Tab>
  </Tabs>
  
  <Warning>
  Stockez toujours vos clés API de manière sécurisée à l’aide de variables d’environnement. Ne les envoyez jamais dans le contrôle de version.
  </Warning>
</Step>

<Step title="Make Your First API Call">
  Créez une session de checkout ou un paiement
  
  <Check>
  Vous êtes maintenant prêt à traiter les paiements ! Consultez les pages consacrées à chaque SDK pour découvrir des guides et exemples détaillés.
  </Check>
</Step>
</Steps>

## Fonctionnalités clés

Tous les SDK partagent ces fonctionnalités essentielles :

- **Type Safety** : typage fort pour garantir la sécurité à la compilation et améliorer la prise en charge par les IDE
- **Gestion des erreurs** : gestion complète des exceptions avec des messages d’erreur détaillés
- **Authentification** : authentification simple par clé API avec prise en charge des variables d’environnement
- **Prise en charge de l’async** : modèles async/await modernes lorsque cela est applicable
- **Pagination automatique** : pagination automatique des réponses de type liste
- **Facturation basée sur l’utilisation** : prise en charge intégrée du suivi et de l’ingestion des événements d’utilisation
- **Tests** : prise en charge complète de l’environnement sandbox pour le développement et les tests

## SDK React Native

Pour les applications mobiles, nous fournissons un SDK React Native dédié :

<Card title="React Native SDK" icon="mobile" href="/developer-resources/react-native-integration">
  Créez des expériences de paiement sécurisées pour les applications iOS et Android grâce à des composants d’interface natifs et à une collecte simplifiée des données de paiement
</Card>

**Fonctionnalités :**
- Composants d’interface natifs pour Android et iOS
- Sécurité simplifiée pour la collecte des données de paiement sensibles
- Prise en charge de plusieurs moyens de paiement
- Intégration fluide avec les applications React Native

<Info>
Apple Pay, Google Pay, Cash App et UPI ne sont actuellement pas pris en charge par le SDK React Native. La prise en charge de ces moyens de paiement est prévue dans de prochaines versions.
</Info>
