Dodo Payments fournit des SDK officiels pour plusieurs langages de programmation. Chacun est conçu selon les bonnes pratiques propres à son langage et avec des fonctionnalités modernes, pour une intégration fluide des paiements.

<Tip>
Utilisez toujours la dernière version du SDK pour bénéficier des fonctionnalités et améliorations les plus récentes. Consultez régulièrement votre gestionnaire de paquets pour vérifier les mises à jour et vous assurer d’avoir accès à toutes les capacités de Dodo Payments.
</Tip>

## Démarrage rapide

Commencez à utiliser n’importe quel SDK en quelques minutes :

<Steps>
<Step title="Install the SDK">
  Utilisez le gestionnaire de paquets de votre langage pour installer le SDK
  
  <Tabs>
  <Tab title="TypeScript/Node.js">

  ```bash
  npm install dodopayments
  ```

  </Tab>
  
  <Tab title="Python">

  ```bash
  pip install dodopayments
  ```

  </Tab>
  
  <Tab title="PHP">

  ```bash
  composer require dodopayments/client
  ```

  </Tab>
  
  <Tab title="Go">

  ```bash
  go get github.com/dodopayments/dodopayments-go
  ```

  </Tab>

  <Tab title="Rust">

  ```bash
  cargo add dodopayments
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Initialize the Client">
  Configurez le client avec votre clé API
  
  <Tabs>
  <Tab title="TypeScript">

  ```typescript
  import DodoPayments from 'dodopayments';
  const client = new DodoPayments({ bearerToken: 'your_api_key' });
  ```

  </Tab>
  
  <Tab title="Python">

  ```python
  from dodopayments import DodoPayments
  client = DodoPayments(bearer_token="your_api_key")
  ```

  </Tab>
  
  <Tab title="PHP">

  ```php
  use Dodopayments\Client;
  $client = new Client(bearerToken: 'your_api_key');
  ```

  </Tab>
  
  <Tab title="Go">

  ```go
  import "github.com/dodopayments/dodopayments-go"
  client := dodopayments.NewClient(option.WithBearerToken("your_api_key"))
  ```

  </Tab>

  <Tab title="Rust">

  ```rust
  use dodopayments::Client;
  let client = Client::from_env()?; // reads DODO_PAYMENTS_API_KEY
  ```

  </Tab>
  </Tabs>
  
  <Warning>
  Stockez toujours vos clés API de manière sécurisée à l’aide de variables d’environnement. Ne les envoyez jamais dans le contrôle de version.
  </Warning>
</Step>

<Step title="Make Your First API Call">
  Créez une session de checkout ou un paiement
  
  <Check>
  Vous êtes maintenant prêt à traiter les paiements ! Consultez les pages consacrées à chaque SDK pour découvrir des guides et exemples détaillés.
  </Check>
</Step>
</Steps>

## Fonctionnalités clés

Tous les SDK **backend** partagent ces fonctionnalités principales. Les SDK de paiement mobile
ci-dessous sont volontairement plus limités — ils ne contiennent aucune clé API et n’appellent jamais l’API :

- **Sécurité des types** : typage fort pour garantir la sécurité à la compilation et améliorer la prise en charge par les IDE
- **Gestion des erreurs** : gestion complète des exceptions avec des messages d’erreur détaillés
- **Authentification** : authentification simple par clé API avec prise en charge des variables d’environnement
- **Prise en charge de l’asynchrone** : modèles modernes async/await lorsque cela est pertinent
- **Pagination automatique** : pagination automatique pour les réponses de type liste
- **Facturation basée sur l’utilisation** : prise en charge intégrée du suivi et de l’ingestion des événements d’utilisation
- **Tests** : prise en charge complète du mode de test pour le développement et les tests

## SDK de paiement mobile

Si vous préférez ouvrir la **page de paiement hébergée** de Dodo plutôt que de créer
une feuille de paiement native, utilisez le SDK de paiement mobile adapté à votre plateforme. Les quatre SDK partagent
le même contrat en un seul appel : `start(...)` renvoie un `CheckoutResult` typé,
aucun ne contient de clé API, et Apple Pay/Google Pay fonctionnent de la même manière que
sur le web ouvert, puisque le paiement s’ouvre dans la véritable interface de navigateur de la plateforme
(`SFSafariViewController` / Custom Tabs), et non dans un `WebView` :

## Interface de ligne de commande

Pour les workflows et l’automatisation basés sur un terminal :

<Card title="CLI" icon="terminal" href="/developer-resources/sdks/cli">
  Interface en ligne de commande générée automatiquement avec prise en charge de l’API Dodo Payments
</Card>

**Fonctionnalités :**
- Structure de commandes basée sur les ressources pour une utilisation intuitive
- Plusieurs formats de sortie (JSON, YAML, lisible, interactif)
- Complétion shell pour bash, zsh et fish
- Idéale pour les scripts et l’automatisation CI/CD

```bash
# Quick example
dodopayments payments list --format json | jq '.items[] | {payment_id, total_amount}'
```
