## Événements Webhook de Souscription

Les événements webhook suivants sont disponibles pour suivre les changements du cycle de vie des souscriptions :

| Événement | Description |
|-------|-------------|
| `subscription.active` | La souscription est activée avec succès |
| `subscription.updated` | L'objet de souscription a été mis à jour (tout changement de champ déclenche cet événement) |
| `subscription.on_hold` | La souscription est mise en attente en raison d'un échec de renouvellement |
| `subscription.renewed` | La souscription est renouvelée pour la prochaine période de facturation |
| `subscription.plan_changed` | Le plan de souscription a été mis à niveau, rétrogradé ou modifié |
| `subscription.cancelled` | La souscription est annulée |
| `subscription.failed` | La création de la souscription a échoué lors de la création du mandat |
| `subscription.expired` | La souscription a atteint la fin de sa période |

### Utilisation de `subscription.updated` pour la Synchronisation en Temps Réel

Le webhook `subscription.updated` se déclenche chaque fois qu'un champ de souscription change, vous permettant de garder l'état de votre application synchronisé sans interroger :

```javascript
app.post('/webhooks/dodo', async (req, res) => {
  const event = req.body;
  
  if (event.type === 'subscription.updated') {
    const subscription = event.data;
    
    // Sync subscription changes to your database
    await syncSubscription(subscription.subscription_id, {
      status: subscription.status,
      next_billing_date: subscription.next_billing_date,
      metadata: subscription.metadata,
      // ... other fields you want to track
    });
    
    console.log(`Subscription ${subscription.subscription_id} updated`);
  }
  
  res.json({ received: true });
});
```

<Tip>
Abonnez-vous à `subscription.updated` pour recevoir des notifications en temps réel sur tout changement de souscription, éliminant ainsi le besoin d'interroger l'API pour des mises à jour.
</Tip>
