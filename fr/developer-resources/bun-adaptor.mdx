## Installation

<Steps>
<Step title="Installez le package">
Exécutez la commande suivante dans la racine de votre projet :

```bash
bun add @dodopayments/bun
```

</Step>
<Step title="Configurez les variables d'environnement">
Créez un <code>.env</code> dans la racine de votre projet :

```env expandable
DODO_PAYMENTS_API_KEY=your-api-key
DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
DODO_PAYMENTS_ENVIRONMENT="test_mode" or "live_mode"
DODO_PAYMENTS_RETURN_URL=your-return-url
```

<Warning>
Ne jamais engager votre fichier <code>.env</code> ou vos secrets dans le contrôle de version.
</Warning>
</Step>
</Steps>

## Exemples de gestionnaire de route

<Info>
Tous les exemples supposent que vous utilisez le serveur natif de Bun avec <code>Bun.serve()</code>.
</Info>

<Tabs>
<Tab title="Gestionnaire de paiement">
  <Info>
  Utilisez ce gestionnaire pour intégrer le processus de paiement Dodo dans votre serveur Bun. Prend en charge les flux de paiement statiques (GET), dynamiques (POST) et de session (POST).
  </Info>
  <CodeGroup>

    ```typescript Bun Server Handler expandable
    import { Checkout } from '@dodopayments/bun';

    const staticCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "static"
    });

    const sessionCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "session"
    });

    const dynamicCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "dynamic"
    });

    Bun.serve({
      port: 3000,
      fetch(request) {
        const url = new URL(request.url);
        
        if (url.pathname === "/api/checkout") {
          if (request.method === "GET") {
            return staticCheckoutHandler(request);
          }
          if (request.method === "POST") {
            return sessionCheckoutHandler(request);
            // or return dynamicCheckoutHandler(request);
          }
        }
        
        return new Response("Not Found", { status: 404 });
      },
    });
    ```

  </CodeGroup>

## Gestionnaire de route de paiement

<Info>
Dodo Payments prend en charge trois types de flux de paiement pour intégrer les paiements sur votre site Web, cet adaptateur prend en charge tous les types de flux de paiement.
</Info>

- **Liens de paiement statiques :** URLs partageables instantanément pour une collecte de paiement rapide, sans code.
- **Liens de paiement dynamiques :** Générer de manière programmatique des liens de paiement avec des détails personnalisés en utilisant l'API ou SDKs.
- **Sessions de paiement :** Créez des expériences de paiement sécurisées et personnalisables avec des paniers de produits préconfigurés et des détails clients.

Le paiement statique retourne une réponse JSON avec l'URL de paiement :

```json

}
```

</Accordion>
<Accordion title="Checkout Dynamique (POST)">
- Envoyez des paramètres sous forme de corps JSON dans une requête POST.
- Prend en charge à la fois les paiements uniques et récurrents.
- Pour une liste complète des champs de corps POST pris en charge, reportez-vous à :
  - [Corps de requête pour un produit de paiement unique](https://docs.dodopayments.com/api-reference/payments/post-payments)
  - [Corps de requête pour un produit d'abonnement](https://docs.dodopayments.com/api-reference/subscriptions/post-subscriptions)

### Format de réponse
Le paiement dynamique retourne une réponse JSON avec l'URL de paiement :

```json
{
  "checkout_url": "https://checkout.dodopayments.com/..."
}
```

</Accordion>
<Accordion title="Sessions de paiement (POST)">
Les sessions de paiement offrent une expérience de paiement hébergée plus sécurisée qui gère le flux de paiement complet pour les achats uniques et les abonnements avec un contrôle de personnalisation complet.

Reportez-vous au [Guide d'intégration des sessions de paiement](https://docs.dodopayments.com/developer-resources/checkout-session) pour plus de détails et une liste complète des champs pris en charge.

Les sessions de paiement retournent une réponse JSON avec l'URL de paiement :

```json

}
```

</Accordion>

## Gestionnaire de route du portail client

Le gestionnaire de route du portail client vous permet d'intégrer facilement le portail client Dodo Payments dans votre application serveur Bun.

### Paramètres de requête
<ParamField query="customer_id" type="string" required>
L'ID client pour la session du portail (par exemple, <code>?customer_id=cus_123</code>).
</ParamField>
<ParamField query="send_email" type="boolean">
S'il est défini sur <code>true</code>, envoie un email au client avec le lien du portail.
</ParamField>

<Warning>
Retourne 400 si <code>customer_id</code> est manquant.
</Warning>

## Gestionnaire de route Webhook

- **Méthode :** Uniquement les requêtes POST sont prises en charge. D'autres méthodes retournent 405.
- **Vérification de signature :** Vérifie la signature du webhook en utilisant <code>webhookKey</code>. Retourne 401 si la vérification échoue.
- **Validation de payload :** Validé avec Zod. Retourne 400 pour les payloads invalides.
- **Gestion des erreurs :**
  - 401 : Signature invalide
  - 400 : Payload invalide
  - 500 : Erreur interne lors de la vérification
- **Routage d'événements :** Appelle le gestionnaire d'événements approprié selon le type de payload.

import { Checkout, CustomerPortal, Webhooks } from "@dodopayments/bun";

const staticCheckoutHandler = Checkout({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  type: "static",
});

const sessionCheckoutHandler = Checkout({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  type: "session",
});

const customerPortalHandler = CustomerPortal({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
});

const webhookHandler = Webhooks({
  webhookKey: process.env.DODO_PAYMENTS_WEBHOOK_KEY,
  onPaymentSucceeded: async (payload) => {
    console.log("Paiement réussi:", payload);
    // Votre logique métier ici
  },
  onSubscriptionActive: async (payload) => {
    console.log("Abonnement activé:", payload);
    // Votre logique métier ici
  },
});

Bun.serve({
  port: 3000,
  fetch(request) {
