## Nouvelles Fonctionnalités

### 1. **Préférences de Communication**

   Prenez le contrôle de la façon dont vous recevez les notifications avec nos Préférences de Communication repensées. Configurez les notifications par e-mail, push et dans l'application pour correspondre à votre flux de travail.

   <Frame>
     <img src="/images/communication-preferences/overview.png" alt="Aperçu des Préférences de Communication montrant les paramètres de notification" />
   </Frame>

   **Fonctionnalités Clés**

   - **Designs d'e-mail repensés** : Modèles d'e-mails frais et modernes avec des appels à l'action clairs et une lisibilité améliorée
   - **Notifications push** : Recevez des alertes instantanées sur votre appareil mobile pour des événements critiques comme de nouvelles ventes, des litiges et des paiements
   - **Contrôles granulaires** : Choisissez exactement quels événements déclenchent des notifications et par quels canaux
   - **Support d'e-mail multiple** : Ajoutez plusieurs adresses e-mail pour recevoir des notifications
   - **Préférences des e-mails clients** : Configurez quels e-mails vos clients reçoivent

   **Catégories de Notifications**

   | Catégorie | Description |
   |----------|-------------|
   | **Ventes & Paiements** | Nouvelles ventes, paiements réussis, paiements échoués |
   | **Payouts & Remboursements** | Achèvement des paiements, demandes de remboursement, achevements de remboursement |
   | **Abonnements** | Nouveaux abonnements, renouvellements, annulations, changements de plan |
   | **Litiges** | Litige ouvert, preuve requise, litige résolu |

   <Check>
   Résultat : Restez informé de votre entreprise avec des notifications livrées exactement comme et quand vous le souhaitez.
   </Check>

   En savoir plus : [Guide des Préférences de Communication](/features/communication-preferences)

### 2. **Champs Personnalisés dans les Sessions de Paiement**

   Collectez des informations supplémentaires auprès des clients lors du paiement avec des champs personnalisés. Ajoutez des champs de texte, des listes déroulantes, des dates, et plus encore pour rassembler les données dont vous avez besoin.

   **Types de Champs Supportés**

   | Type | Description | Cas d'utilisation |
   |------|-------------|----------|
   | `text` | Champ de texte sur une seule ligne | Nom de l'entreprise, notes de commande |
   | `number` | Entrée numérique | Quantité, âge |
   | `email` | Entrée d'e-mail avec validation | E-mail de contact de facturation |
   | `url` | Entrée d'URL avec validation | Site web, profil social |
   | `date` | Sélecteur de date | Date de livraison, date d'événement |
   | `dropdown` | Sélection parmi des options prédéfinies | Taille, couleur, type de plan |
   | `boolean` | Case à cocher pour les valeurs oui/non | Acceptation des conditions, inscription à la newsletter |

   **Comment Cela Fonctionne**

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     custom_fields: [
       {
         name: 'company_name',
         label: 'Company Name',
         type: 'text',
         required: true
       },
       {
         name: 'team_size',
         label: 'Team Size',
         type: 'dropdown',
         options: ['1-10', '11-50', '51-200', '200+'],
         required: true
       },
       {
         name: 'newsletter',
         label: 'Subscribe to our newsletter',
         type: 'boolean',
         required: false
       }
     ],
     return_url: 'https://yoursite.com/success'
   });
   ```

   **Avantages**

   - **Collecte de données flexible** : Rassemblez toutes les informations nécessaires pour l'exécution ou la personnalisation
   - **Validation intégrée** : Les champs d'e-mail et d'URL valident automatiquement le format d'entrée
   - **Contrôle requis/facultatif** : Marquez les champs comme requis ou facultatifs selon vos besoins
   - **Livraison de Webhook** : Les valeurs des champs personnalisés sont incluses dans les événements de webhook de paiement

   <Info>
   Les valeurs des champs personnalisés sont renvoyées dans l'objet `custom_fields` dans les réponses de paiement et de session de paiement.
   </Info>

   En savoir plus : [Champs Personnalisés de Session de Paiement](/developer-resources/checkout-session#custom-fields)

### 3. **Support Élargi des Langues lors du Paiement**

   La page de paiement supporte désormais **21 langues**, contre 16 auparavant. Atteignez plus de clients dans leur langue maternelle pour une meilleure expérience de paiement.

   **Nouvelles Langues Ajoutées**

   | Langue | Code |
   |----------|------|
   | Coréen | `ko` |
   | Malais | `ms` |
   | Roumain | `ro` |
   | Russe | `ru` |
   | Thaï | `th` |

   **Toutes les Langues Supportées**

   Arabe, Chinois, Néerlandais, Anglais, Français, Allemand, Hindi, Indonésien, Italien, Japonais, Coréen, Malais, Portugais, Roumain, Russe, Espagnol, Suédois, Thaï, Turc, Ukrainien, Vietnamien.

   **Forcer une Langue Spécifique**

   Utilisez le paramètre `force_language` pour remplacer la détection automatique de la langue :

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     force_language: 'ko', // Force Korean language
     return_url: 'https://yoursite.com/success'
   });
   ```

   <Tip>
   Par défaut, la page de paiement détecte automatiquement la langue préférée de l'utilisateur à partir des paramètres de son navigateur. Utilisez `force_language` lorsque vous souhaitez garantir la cohérence avec la langue de votre site web.
   </Tip>

   En savoir plus : [Support de Langue lors du Paiement](/features/checkout#supported-languages)
