## Nouvelles Fonctionnalités
- **SDKs Officiels** : Introduction des SDKs officiels de Dodo Payments pour **Node.js**, **Python** et **Go**. Consultez la page des [SDKs](/developer-resources/dodo-payments-sdks) pour plus d'informations.
- **Champ de Métadonnées** : Ajout d'un champ `Metadata` pour les paiements et abonnements afin de stocker des informations supplémentaires. Consultez la page des [Métadonnées](/api-reference/metadata) pour plus de détails.
- **API Clients** : Expansion des API clients pour inclure les points de terminaison suivants. Vous pouvez désormais transmettre `customer_id` dans les paiements et abonnements pour prévenir la duplication des clients :
    - **Créer un Client** : [/api-reference/customers/create-customer](/api-reference/customers/create-customer)
    - **Modifier un Client** : [/api-reference/customers/patch-customer](/api-reference/customers/patch-customer)
