## Nouvelles fonctionnalités 🚀

- **Checkout 2.0** : Présentation d'une expérience de paiement entièrement repensée avec :
    - Une interface moderne et simplifiée pour améliorer l'expérience utilisateur
    - Nouveau système de collecte de requêtes qui stocke les paramètres dans le stockage de session avec des ID uniques (par exemple, `sess_1a2b3c4d`)
    - Disponibilité persistante des données tout au long du processus de paiement
    - Davantage d'améliorations prévues pour les futures versions !
  
    <Frame><img src="/images/changelog/checkout_2.png" alt="Checkout 2.0" style={{ maxHeight: '500px', width: 'auto' }} /></Frame>

- **Méthodes de paiement configurables** : La nouvelle configuration `allowed_payment_method_types` permet aux marchands de personnaliser les options de paiement disponibles lors du paiement. Consultez la documentation [Méthodes de paiement autorisées](/features/payment-methods#per-checkout-payment-method-configuration) pour découvrir les détails de mise en œuvre.

- **Calcul dynamique des taxes** : Calcul en temps réel des taux de taxe en fonction des adresses de facturation des clients pour des prix plus précis sur les liens de paiement statiques.

- **Abonnements à la demande** : De nouveaux endpoints API permettent une facturation flexible des abonnements (disponibles pour certains marchands). Pour en savoir plus, consultez le guide [Abonnements à la demande](/developer-resources/ondemand-subscriptions).

- **Mises à jour supplémentaires** :
    - Optimisations de performance
    - Corrections de bogues
    - Améliorations générales du système
