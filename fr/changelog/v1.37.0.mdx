## Nouvelles fonctionnalités 🚀

### Tableau de bord Analytics amélioré

Nous avons enrichi le tableau de bord Analytics avec des informations complètes sur les revenus et la rétention afin de vous aider à mieux comprendre les performances de votre entreprise.

#### Analyse de la ventilation des revenus

Suivez vos métriques de revenus récurrents grâce à une ventilation détaillée :

- **ARR projeté** : projections de revenus récurrents annuels avec analyse des tendances
- **Ventilation du MRR et taux de croissance** : analyse des revenus récurrents mensuels avec des métriques de croissance d'un mois sur l'autre  
- **Graphique du nouveau MRR** : représentation visuelle des revenus générés par l'acquisition de nouveaux clients
- **Graphique du MRR d'expansion** : suivi de la croissance des revenus provenant des mises à niveau et extensions des clients existants
- **Graphique du MRR de churn** : suivi des revenus perdus en raison des annulations et déclassements des clients
- **Graphique du MRR net nouveau** : impact net sur les revenus combinant le nouveau MRR, le MRR d'expansion et le MRR de churn

#### Analyse de la rétention

Surveillez la rétention des clients et les tendances du churn :

- **Taux de churn des clients** : pourcentage de clients qui annulent leurs abonnements
- **Taux de churn des revenus** : pourcentage des revenus perdus en raison des annulations et déclassements
- **Tendances du taux de churn** : suivi historique des tendances du churn des clients et des revenus au fil du temps
- **Matrice de rétention des utilisateurs** : analyse par cohortes présentant les taux de rétention des clients sur différentes périodes

### Reports 2.0

Nous avons entièrement repensé la section des rapports avec des fonctionnalités de reporting plus complètes et détaillées. Accédez à la nouvelle suite de rapports via **Business > Reports**.

Les rapports disponibles incluent :

- **Rapport des paiements** : relevé détaillé de tous les paiements traités, avec suivi du statut des transactions
- **Rapport des remboursements** : journal complet de toutes les activités de remboursement, avec des informations détaillées sur les remboursements
- **Rapport des payouts** : récapitulatif des payouts versés sur votre compte
- **Rapport des ventes par produit** : informations sur les performances commerciales, avec des métriques de revenus et de croissance de l'entreprise
- **Rapport des échecs de paiement** : récapitulatif des tentatives de paiement échouées, avec les raisons de l'échec
- **Rapport des clients** : récapitulatif des paiements organisé par client
- **Rapport des litiges** : récapitulatif des litiges de paiement avec leur statut de résolution
- **Rapport récapitulatif du compte** : vue d'ensemble et récapitulatif complets du compte

### Dodo Payments Remote MCP Server

Vous pouvez désormais utiliser le Remote MCP Server hébergé à l'adresse [https://mcp.dodopayments.com](https://mcp.dodopayments.com) pour une intégration MCP instantanée, sans configuration locale requise.

<Note>
C'est le moyen le plus rapide de commencer à utiliser l'intégration MCP de Dodo Payments. Aucune installation ni maintenance de serveur n'est nécessaire.
</Note>

<Steps>
<Step title="Open the Remote MCP Server">
    Accédez à <a href="https://mcp.dodopayments.com" target="_blank">https://mcp.dodopayments.com</a> dans votre navigateur.
</Step>
<Step title="Copy the MCP JSON configuration">
    Sur le site, copiez la configuration JSON MCP fournie pour votre client.
</Step>
<Step title="Configure your AI application">
    Collez la configuration dans les paramètres MCP de votre application (par exemple, Cursor ou Claude).
    <Tip>
    Pour Cursor, votre configuration devrait ressembler à ceci :
    </Tip>

    ```json
    {
      "mcpServers": {
        "dodopayments_api": {
          "command": "npx",
          "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
        }
      }
    }
    ```

</Step>
<Step title="Complete authentication and environment setup">
    Après avoir ajouté la configuration JSON, une fenêtre contextuelle vous invitera à :
    - Saisir votre clé API Dodo Payments
    - Sélectionner l'environnement (test ou live)
    - Sélectionner votre client MCP sous Configuration Options
</Step>
<Step title="Login and Approve">
    - Cliquer sur le bouton Login and Approve
</Step>
<Step title="Verify successful connection">
    Une fois la configuration terminée, un écran de confirmation s'affichera.
    <Check>
    Vous êtes maintenant prêt à utiliser le serveur MCP de Dodo Payments !
    </Check>
</Step>
</Steps>
