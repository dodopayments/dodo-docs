## Nouvelles Fonctionnalités
- **E-mails Automatisés** : Ajout d'e-mails automatisés pour les paiements, les abonnements, les remboursements et les litiges afin de tenir les commerçants et les clients informés.
- **Journal des Événements Webhook** : Ajout d'un journal des événements webhook sur le tableau de bord Dodo Payments pour suivre les événements webhook et résoudre les problèmes. Accédez aux journaux en naviguant vers `Settings > Webhooks > Webhook Logs`.
- **Guide de Génération de Clés de Licence** : Ajout d'un nouveau guide pour mettre en œuvre la génération de clés de licence pour les produits numériques. Consultez le [guide](/features/license-keys) pour plus d'informations.
