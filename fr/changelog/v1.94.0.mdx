## Nouvelles Fonctionnalités

### 1. **Récupération de Panier Abandonné**

Détectez automatiquement les paiements incomplets ou échoués et envoyez des séquences d'emails ciblées pour ramener les clients. ACR surveille les paiements non réussis après 60 minutes et les classe comme **paiement échoué** ou **paiement incomplet**, puis envoie jusqu'à 3 emails de récupération configurables par séquence.

<Frame>
<img src="/images/recovery/recovery-analytics.png" alt="Tableau de bord des analyses de récupération montrant les comptes de paiements abandonnés, les taux de récupération et les revenus récupérés" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Capacités clés :
- **Deux séquences d'emails** — Paiement Echoué et Paiement Incomplet, chacune avec jusqu'à 3 emails
- **Réductions de récupération** — Générer automatiquement des codes de réduction à usage unique pour inciter à la récupération
- **Page de récupération client** — Des liens de récupération uniques mènent les clients à une page dédiée pour terminer leur achat
- **Analyses de récupération** — Suivez les comptes de paiements abandonnés, les taux de récupération, les revenus récupérés et les décompositions par email/produit

<Tip>
Commencez avec le timing d'email par défaut (1 heure, 24 heures, 72 heures) et itérez en fonction des données de vos analyses de récupération.
</Tip>

En savoir plus : [Récupération de Panier Abandonné](/features/recovery/abandoned-cart-recovery)

### 2. **Relance d'Abonnement**

Envoyez automatiquement des séquences d'emails pour récupérer les abonnements interrompus ou annulés. La relance est déclenchée lorsqu'un abonnement passe en ** attente ** (échec de paiement) ou est ** annulé ** par le client depuis le portail client.

Capacités clés :
- **Deux séquences d'emails** — En Attente et Annulé, chacune avec jusqu'à 4 emails
- **Facturation automatique** — Lorsqu'un client met à jour son mode de paiement, les sommes dues sont automatiquement facturées
- **Timing configurable** — Intervalles par défaut à 1, 3, 5, et 7 jours, entièrement personnalisables par email

En savoir plus : [Relance d'Abonnement](/features/recovery/subscription-dunning)

### 3. **Métadonnées de Réduction**

Vous pouvez désormais attacher des **métadonnées** (paires clé-valeur) aux réductions lors de leur création ou mise à jour via l'API. Utilisez les métadonnées pour marquer les réductions par campagne, source ou référence interne pour le suivi et la réconciliation.

```typescript
const discount = await client.discounts.create({
  type: 'percentage',
  amount: 1500, // 15%
  code: 'SUMMER2025',
  metadata: {
    campaign: 'summer_promo',
    source: 'email_blast'
  }
});
```

En savoir plus : [Codes de Réduction](/features/discount-codes) | [Guide des Métadonnées](/api-reference/metadata)

### 4. **Webhooks de Récupération**

Nouveaux événements de webhook pour suivre le cycle de vie de la récupération :

| Événement | Description |
|-------|-------------|
| `abandoned_checkout.detected` | Un paiement abandonné a été détecté |
| `abandoned_checkout.recovered` | Le client a complété le paiement via un lien de récupération |
| `dunning.started` | Une tentative de relance a été commencée pour un abonnement |
| `dunning.recovered` | Le client a mis à jour son mode de paiement et le paiement a réussi |

En savoir plus : [Webhooks de Récupération](/developer-resources/webhooks/intents/recovery)

### 5. **Paiements Pix pour le Brésil**

Acceptez **Pix** — le système de paiement instantané du Brésil créé par la Banque Centrale du Brésil — dans votre processus de paiement Dodo Payments. Pix est désormais le moyen de paiement le plus utilisé au Brésil, surpassant à la fois les cartes de crédit et le boleto, et se confirme en quelques secondes 24/7/365.

**Couverture**

| Détail | Valeur |
|--------|-------|
| Devise de facturation | BRL |
| Pays pris en charge | Brésil |
| Abonnements | Non supportés (paiements uniques uniquement) |
| Montant minimum | $0.50 |
| Règlement | Instantané |

**Configuration**

Passez `pix` dans `allowed_payment_method_types` et définissez la devise de facturation sur `BRL` :

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['pix', 'credit', 'debit'],
  billing_currency: 'BRL',
  return_url: 'https://example.com/success'
});
```

Le client se voit présenter un code QR Pix et une clé à copier-coller lors du paiement. Il ouvre son application bancaire, scanne ou colle, et le paiement est confirmé instantanément.

<Tip> Les codes QR Pix expirent après une période définie — concevez votre flux de paiement pour permettre aux clients de régénérer le code si nécessaire. Incluez toujours des options de carte pour les clients qui préfèrent payer par carte. </Tip>

En savoir plus : [Paiements Pix](/features/payment-methods/pix)

### 6. **WeChat Pay pour les clients chinois**

Acceptez **WeChat Pay** — utilisé par plus d'un milliard de personnes à travers la Chine — directement dans votre processus de paiement Dodo Payments. Les clients scannent un code QR avec leur application WeChat et confirment le paiement en quelques secondes, le tout sans quitter l'écosystème WeChat.

**Couverture**

| Détail | Valeur |
|--------|-------|
| Devises de facturation | USD, CNY |
| Abonnements | Non supportés (paiements uniques uniquement) |
| Montant minimum | $0.50 / ¥1.00 |
| Règlement | USD |

**Configuration**

Passez `wechat_pay` dans `allowed_payment_method_types` lorsque vous créez une session de paiement :

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['wechat_pay', 'credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

WeChat Pay prend en charge à la fois le **USD** (pour les commerçants internationaux ciblant les clients chinois) et le **CNY** (pour les transactions domestiques chinoises). Le règlement vers les commerçants se fait en USD, quelle que soit la devise de facturation.

<Tip> Affichez le processus de paiement sur un ordinateur de bureau ou une tablette afin que les clients puissent scanner le code QR avec leur téléphone — c'est le flux le plus familier pour les utilisateurs de WeChat Pay. </Tip>

En savoir plus : [WeChat Pay](/features/payment-methods/wechat)
