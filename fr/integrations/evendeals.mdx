## Introduction

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) est une plateforme qui crée et synchronise des coupons de réduction basés sur la parité de pouvoir d’achat et la localisation dans votre compte Dodo Payments. Elle prend en charge les produits à paiement unique et les abonnements, en générant automatiquement des codes de réduction qui changent selon la fréquence que vous définissez.

<Note>
Dodo Payments propose nativement la [Purchasing Power Parity](/features/purchasing-power-parity), qui réduit les prix selon le pays lors du checkout, sans bannière, sans script et sans codes de réduction à gérer. Evendeals s’adresse aux marchands qui souhaitent spécifiquement utiliser l’approche par codes de réduction avec une rotation automatique des coupons.
</Note>

## Fonctionnement

Evendeals se connecte à votre compte Dodo Payments via une clé API. Une fois la connexion établie, vous configurez des réductions en pourcentage pour chaque groupe de pays. Evendeals crée ensuite automatiquement les codes de réduction dans votre compte Dodo Payments et les fait tourner selon la fréquence définie (par intervalle de temps, nombre d’utilisations ou nombre de vues) afin de prévenir les abus.

## Evendeals vs PPP native

La Purchasing Power Parity native est la méthode recommandée pour définir les prix par pays, car elle ne nécessite aucun code de réduction et ne peut pas être partagée ou utilisée de manière abusive. Choisissez Evendeals si vous souhaitez spécifiquement utiliser l’approche par codes de réduction.

| | PPP native | Evendeals |
| :--- | :--- | :--- |
| Fonctionnement | Un pourcentage par pays, appliqué lors du checkout | Un pourcentage de réduction, appliqué via un code |
| Où la configurer | Intégrée à Dodo Payments | Tableau de bord Evendeals |
| Bannière ou script requis | Non requis | Non requis |
| Rotation / actualisation automatique des coupons | Non applicable | Oui |
| Prise en charge des abonnements | Oui | Oui |
| Idéal pour | Des prix corrects sans modifier le site | L’approche par codes de réduction avec rotation automatique |

## Fonctionnalités principales

- **Synchronisation automatique des coupons** — Les coupons sont automatiquement créés et gérés dans Dodo Payments
- **Réductions en pourcentage** — Proposez des réductions en pourcentage pour chaque groupe de pays
- **Prise en charge des abonnements** — Les réductions s’appliquent à chaque cycle de facturation de l’abonnement
- **Règles d’actualisation automatique** — Faites automatiquement tourner les codes de réduction selon un intervalle de temps, un nombre d’utilisations ou un nombre de vues afin de prévenir les abus

<Info>
Les codes de réduction créés par Evendeals apparaîtront automatiquement dans votre tableau de bord Dodo Payments, sous **Sales → Discounts**.
</Info>

## Prérequis

Avant de configurer cette intégration, assurez-vous de disposer des éléments suivants :

1. Un [compte Dodo Payments](https://app.dodopayments.com)
2. Un [compte Evendeals](https://www.evendeals.com/signin)
3. Une clé API Dodo Payments

## Pour commencer

<Steps>
  <Step title="Create a Dodo Payments API Key">
    Dans votre tableau de bord Dodo Payments, accédez à **Developers → API Keys** et cliquez sur **Create New API**. Donnez-lui un nom descriptif (par exemple, "Evendeals") afin de pouvoir l’identifier ultérieurement.
  </Step>

  <Step title="Connect in Evendeals">
    Dans votre [tableau de bord Evendeals](https://www.evendeals.com/signin), accédez à **Integrations**, recherchez la carte Dodo Payments et collez votre clé API.
  </Step>

  <Step title="Configure Regional Discounts">
    Définissez les réductions en pourcentage pour chaque groupe de pays, puis lancez la synchronisation. Evendeals crée automatiquement les coupons dans Dodo Payments.

    <Check>
    Après la synchronisation, ouvrez **Sales → Discounts** dans votre tableau de bord Dodo Payments pour confirmer que les coupons générés apparaissent. Chaque coupon possède un préfixe Evendeals identifiable.
    </Check>
  </Step>
</Steps>
