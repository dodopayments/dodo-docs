## Introduction

[ParityDeals](https://www.paritydeals.com/) est une plateforme qui affiche des bannières de remise basées sur la localisation aux visiteurs éligibles de votre site web et génère automatiquement les codes de remise correspondants dans Dodo Payments. Lorsqu'un visiteur voit la bannière, il obtient un code qu'il peut utiliser lors du checkout. Ces codes apparaissent dans votre tableau de bord Dodo Payments, sous **Sales → Discounts**.

<Note>
Dodo Payments propose nativement la [Purchasing Power Parity](/features/purchasing-power-parity), qui réduit les prix par pays au checkout, sans bannière ni script. ParityDeals s'adresse aux marchands qui souhaitent afficher une bannière de remise visible sur leur propre site, ou organiser des offres saisonnières et limitées dans le temps.
</Note>

## Fonctionnement

ParityDeals détecte la localisation d'un visiteur, lui affiche une bannière de remise personnalisable sur votre site web et génère un code de remise qu'il peut appliquer lors du checkout. Le code est automatiquement créé dans votre compte Dodo Payments et fonctionne sur les produits que vous configurez.

1. Un visiteur arrive sur votre site web et ParityDeals détecte sa localisation.
2. Si le visiteur peut bénéficier d'une remise, une bannière apparaît avec un code basé sur sa localisation.
3. Le visiteur utilise ce code lors du checkout et Dodo Payments applique la remise.
4. Le code apparaît dans votre tableau de bord, sous **Sales → Discounts**.

## ParityDeals et PPP native

La Purchasing Power Parity native est la méthode recommandée pour définir les prix par pays. Choisissez ParityDeals si vous avez spécifiquement besoin d'une bannière de remise sur votre propre site, ou pour des campagnes saisonnières et limitées dans le temps.

| | PPP native | ParityDeals |
| :--- | :--- | :--- |
| Fonctionnement | Un pourcentage par pays, appliqué lors du checkout | Un pourcentage de remise, appliqué au moyen d'un code |
| Lieu de configuration | Intégrée à Dodo Payments | Tableau de bord ParityDeals |
| Bannière ou script sur votre site | Non requis | Requis |
| Offres saisonnières et limitées dans le temps | Non | Oui |
| Idéal pour | Des prix adaptés, sans modification du site | Des bannières promotionnelles et des offres saisonnières |

<Info>
Vous ne pouvez pas intégrer la bannière ParityDeals à un checkout ou une storefront hébergé par Dodo Payments, car les scripts personnalisés n'y sont pas pris en charge. La bannière doit être placée sur votre propre site web ou votre application.
</Info>

## Prérequis

Avant de configurer cette intégration, assurez-vous de disposer des éléments suivants :

1. Un [compte Dodo Payments](https://app.dodopayments.com)
2. Un [compte ParityDeals](https://app.paritydeals.com/)
3. Une clé API Dodo Payments

## Premiers pas

<Steps>
  <Step title="Sign up on ParityDeals">
    Accédez à [app.paritydeals.com](https://app.paritydeals.com/) et créez un compte.
  </Step>

  <Step title="Create Deals">
    Après vous être connecté, recherchez l'option permettant de créer des offres. Dans le menu déroulant, sélectionnez **"Create Deals via Dodo Payments"**.

    <Frame>
      <img src="/images/integrations/paritydeals/create-deals.png" alt="Création d'offres via Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Connectez-vous à votre **tableau de bord Dodo Payments** et accédez à **Developers → API Keys**. Cliquez sur **"Create New API"**.

    <Tip>
      Donnez à votre clé API un nom descriptif (par exemple, 'ParityDeals') afin de pouvoir l'identifier ultérieurement.
    </Tip>

    <Frame>
      <img src="/images/integrations/paritydeals/api-key.png" alt="Création d'une nouvelle clé API dans Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Copiez la clé API que vous avez créée et collez-la dans l'interface ParityDeals afin d'établir la connexion avec votre compte Dodo Payments.

    <Frame>
      <img src="/images/integrations/paritydeals/connect-api-key.png" alt="Connexion d'une clé API à ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Une fois la connexion établie, ParityDeals récupère le catalogue de produits Dodo Payments. Sélectionnez les produits que vous souhaitez associer à vos offres.

    <Frame>
      <img src="/images/integrations/paritydeals/select-products.png" alt="Sélection de produits pour ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Saisissez l'URL de votre site web et, si vous le souhaitez, sélectionnez les pages cibles spécifiques où la bannière de remise doit apparaître. Choisissez ensuite le type d'offre souhaité :
    - Offres basées sur la localisation
    - Offres saisonnières
    - Offres flash limitées dans le temps

    <Frame>
      <img src="/images/integrations/paritydeals/deal-settings.png" alt="Configuration des paramètres d'une offre" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Sélectionnez les pays auxquels vous souhaitez proposer des remises localisées et définissez le pourcentage de remise pour chacun d'eux. ParityDeals fournit des valeurs recommandées que vous pouvez ajuster si nécessaire.

    <Frame>
      <img src="/images/integrations/paritydeals/country-rules.png" alt="Définition de règles de remise par pays" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Concevez votre bannière de remise en personnalisant le texte, en sélectionnant les couleurs et la mise en page, et en choisissant la position de la bannière (en haut ou en bas de la page). Cette bannière sera affichée aux visiteurs éligibles selon les règles que vous avez configurées.

    <Frame>
      <img src="/images/integrations/paritydeals/customize-banner.png" alt="Personnalisation de la bannière de remise" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Après avoir enregistré votre offre, ParityDeals génère un script. Ajoutez ce script au code de votre site web (généralement dans la section `<head>`). Ce script détecte automatiquement la localisation des visiteurs et affiche la bannière de remise appropriée.

    <Frame>
      <img src="/images/integrations/paritydeals/script.png" alt="Script d'intégration ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

## Fonctionnalités supplémentaires

Avec ParityDeals, vous pouvez également proposer des [remises automatiques limitées dans le temps](https://www.paritydeals.com/features/time-based-discounts/) et des [promotions saisonnières](https://www.paritydeals.com/features/holiday-based-discounts/) tout au long de l'année. Pour plus d'informations, consultez la [documentation ParityDeals](https://www.paritydeals.com/docs/).
