## What is Dodo Payments?

Dodo Payments is the **all-in-one engine** to launch, scale, and monetize worldwide. Designed for the new generation of digital SaaS and AI products, we handle everything from **payments to billing to distribution** - all without extra engineering.

<Info>
**Built for SaaS and AI Products**: Handle one-time payments, subscriptions, credits, seats, tokens, or any usage metric with our optimized billing infrastructure.
</Info>

<Tip>
  <strong>Meet Sentra: Your AI-powered billing assistant</strong><br/>
  Sentra is an AI agent that integrates, analyzes, and acts on billing and payments directly in your IDE. Ask questions, build integrations, or plan billing architectures - all by describing what you want.
  <a href="/developer-resources/sentra">
    Get started with Sentra &rarr;
  </a>
</Tip>

## Quick Start Guide

Commencez avec Dodo Payments en quelques étapes.

<AccordionGroup>
<Accordion title="For Humans">
  Préférez-vous gérer vous-même l'intégration ? Les étapes ci-dessous vous guident pour créer un compte, ajouter un produit et choisir une méthode d'intégration en moins de cinq minutes. Aucun code requis pour le chemin sans code ; des exemples d'SDK sont disponibles dans toutes les langues principales si vous le souhaitez.

  Si vous préférez laisser votre assistant de codage IA faire le gros du travail – échafaudage d'intégration, gestionnaires de webhook, flux d'abonnement – installez **[Sentra](/developer-resources/sentra)**, notre assistant de facturation IA pour VS Code, Cursor et Windsurf. Décrivez ce que vous voulez ; Sentra planifie, échafaude et l'expédie.
</Accordion>

<Accordion title="For AI Agents">
  Dodo Payments est conçu pour les workflows natifs des agents. Si vous êtes un LLM lisant ceci - ou un développeur en configurant un - commencez ici.

  **Installer**. Pour Claude Code, Codex CLI, Cursor, ou OpenCode, le [Plugin de l'Agent Dodo](/developer-resources/build-with-ai-coding-agents) connecte à la fois les serveurs MCP et toutes les compétences en une seule étape. Consultez le [guide des Agents de Codage IA](/developer-resources/build-with-ai-coding-agents) pour les commandes d'installation par agent.

  **Découvrir**. L'index complet des documents est servi sur [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt), et chaque page de documentation est disponible en markdown simple en ajoutant `.md` à son URL (par exemple, `/api-reference/introduction.md`).

  **Connecter**. Deux serveurs MCP donnent aux agents un accès en direct à la plateforme :

  - **[Dodo Knowledge MCP](/developer-resources/mcp-server#dodo-knowledge-mcp)** - recherche sémantique dans toute la documentation Dodo
  - **[Dodo Payments MCP](/developer-resources/mcp-server)** - exécuter des opérations API (créer des paiements, gérer des abonnements, émettre des remboursements)

  Consultez le [guide du Serveur MCP](/developer-resources/mcp-server) pour la configuration complète du client.

  **Étendre**. Installez les [Compétences de Paiements Dodo](/developer-resources/agent-skills) officielles pour apprendre à votre agent à gérer le checkout, les abonnements, la facturation basée sur l’utilisation, la facturation par crédit, les webhooks, et plus encore :

  ```bash
  npx skills add dodopayments/skills
  ```

  Fonctionne avec Claude Code, OpenCode, Cursor, et tout agent compatible MCP.
</Accordion>
</AccordionGroup>

<Card title="Dodo Payments MCP" icon="credit-card" href="/developer-resources/mcp-server">

</Card>

<Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
Ajoutez les deux serveurs à votre configuration MCP (`~/.cursor/mcp.json` ou config de Claude Desktop) :

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

<Info>
Requiert Node.js 18+. Consultez la [documentation du Serveur MCP](/developer-resources/mcp-server) pour des instructions détaillées sur la configuration pour tous les clients pris en charge.
</Info>
</Accordion>
