<Info>
La Récupération de Panier Abandonné (ACR) détecte les paiements non finalisés ou échoués et envoie automatiquement des séquences d'e-mails pour ramener les clients. Combinez avec des incitations de réduction optionnelles pour maximiser les taux de récupération.
</Info>

## Qu'est-ce que la Récupération de Panier Abandonné ?

L'ACR identifie automatiquement les clients qui ont commencé mais n'ont pas terminé leur paiement — que ce soit parce que le paiement a échoué ou qu'ils sont partis avant de payer — et envoie une séquence d'e-mails de récupération pour les ramener.

- **Paiements échoués** : Le client a tenté le paiement mais il a été refusé ou a échoué
- **Paiements incomplets** : Le client a visité la caisse mais n'a jamais tenté le paiement

## Comment fonctionne l'ACR

<Steps>
<Step title="Detection">
Nous recherchons les paiements datant de plus de 60 minutes et n'ayant pas réussi. Cela inclut les paiements échoués et les caisses où le client n'a jamais tenté le paiement.
</Step>

<Step title="Classification">
Chaque caisse abandonnée est classifiée par raison :
- **Paiement échoué** : Le client a tenté le paiement mais il a échoué
- **Caisse incomplète** : Le client a visité la caisse mais n'a jamais tenté le paiement
</Step>

<Step title="Email Sequence">
En fonction de la classification, le système envoie jusqu'à 3 e-mails de récupération à des intervalles configurés. Chaque e-mail contient un lien de récupération unique.
</Step>

<Step title="Recovery">
Lorsque le client clique sur le lien de récupération, il est dirigé vers une page de récupération affichant son panier original. Il peut compléter le paiement avec une nouvelle session de paiement.
</Step>
</Steps>

## Cycle de vie du statut

Chaque caisse abandonnée progresse à travers ces étapes :

| Statut | Description |
|--------|-------------|
| `abandoned` | Caisse détectée comme abandonnée, aucun e-mail encore envoyé |
| `recovering` | Au moins un e-mail de récupération a été envoyé |
| `recovered` | Le client a complété le paiement via le lien de récupération |
| `exhausted` | Tous les e-mails ont été envoyés sans récupération, ou une caisse plus récente a remplacé celle-ci |
| `opted_out` | Le client s'est désabonné des e-mails de récupération |

### Paramètres globaux

| Paramètre | Description | Valeur par défaut |
|-----------|-------------|------------------|
| **Activé** | Bouton principal pour l'ACR | Désactivé |
| **Remise activée** | Auto-générer un code de réduction pour les e-mails de récupération | Désactivé |
| **Pourcentage de remise** | Pourcentage de remise qui sera appliqué à la caisse pour ce client | 0 |
| **Jours de validité de la remise** | Nombre de jours pendant lesquels le code de réduction auto-généré reste valide | 5 |

### Séquences d'e-mails

L'ACR prend en charge deux séquences d'e-mails — **Paiement échoué** et **Caisse incomplète** — chacune avec jusqu'à 3 e-mails configurables.

<Frame caption="ACR email sequence configuration">
<img src="/images/recovery/acr-email-config.png" alt="Éditeur de séquences d'e-mails montrant le sujet, le corps, le timing et le bouton d'activation pour chaque e-mail de la séquence" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

| Paramètre | Description |
|-----------|-------------|
| **Activé** | Activer ou désactiver individuellement les e-mails sans les supprimer |
| **Délai** | Temps après la détection de l'abandon pour envoyer cet e-mail |
| **Sujet** | Ligne de sujet de l'e-mail avec des variables de substitution |
| **Corps** | Corps de l'e-mail en HTML avec des variables de substitution |
| **Répondre à** | Adresse e-mail pour les réponses des clients |

**Timing par défaut des e-mails :**

| E-mail # | Délai par défaut |
|---------|-------------------|
| 1 | 1 heure |
| 2 | 24 heures |
| 3 | 72 heures |

## Remises de récupération

Lorsque la remise est activée, l'ACR génère automatiquement un code de réduction unique à usage unique pour chaque caisse abandonnée. La réduction :

- Est limitée au(x) produit(s) de la caisse originale
- A une période d'expiration configurable
- Est limitée à une seule utilisation
- Est cachée de la liste de réduction de votre tableau de bord (usage interne uniquement)

<Tip>
Commencez par une remise modeste (5-10%) pour tester l'impact de conversion avant d'augmenter. Même une petite incitation peut améliorer significativement les taux de récupération.
</Tip>

## Expérience de Récupération pour les Clients

Lorsqu'un client clique sur le lien de récupération dans un e-mail, il est redirigé vers sa session de caisse originale. La page affiche le produit qu'il a laissé derrière, ainsi qu'un code de réduction si un a été configuré.

## Cas Limites

| Scénario | Comportement |
|----------|--------------|
| Le client finalise l'achat avant le prochain e-mail | La récupération est détectée au moment de l'envoi; la caisse est marquée comme récupérée si éligible |
| Le client commence une nouvelle caisse | L'ancienne caisse abandonnée est marquée comme `exhausted` |
| Le client clique sur "Payer" après avoir déjà récupéré | La page de récupération montre une confirmation que le paiement a déjà été effectué |
| Le client se désabonne | La caisse abandonnée est marquée comme `opted_out`; plus aucun e-mail n'est envoyé |

## Meilleures Pratiques

- **Commencez avec les paramètres par défaut** : Le timing et les sujets des e-mails par défaut sont optimisés pour les modèles de récupération courants. Personnalisez après avoir obtenu des données de référence.
- **Personnaliser les e-mails** : Utilisez des variables de modèle pour rendre les e-mails personnels et pertinents pour le client.
- **Surveillez les analyses** : Suivez les taux de récupération par e-mail pour identifier quels messages génèrent le plus de conversions. Désactivez les e-mails qui ne performent pas.
- **Utilisez les remises stratégiquement** : Commencez petit (5-10 %) pour protéger les marges tout en testant l'impact des conversions.
- **Gardez les e-mails concis** : Les e-mails de récupération doivent être courts et orientés vers l'action. Un appel à l'action clair donne de meilleurs résultats qu'une explication longue.

<Info>
L'ACR est conçu pour fonctionner automatiquement une fois activé. Commencez avec les paramètres par défaut, surveillez vos analyses et itérez en fonction des données de performance.
</Info>
