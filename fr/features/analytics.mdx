Suivez les parcours clients depuis votre vitrine jusqu'à la finalisation de l'achat. Dodo Payments s'intègre avec Google Analytics 4, Google Tag Manager et Meta Pixel pour fournir une analytics complète sur toutes vos pages hébergées.

<Info>
Le suivi analytique est automatiquement activé sur votre Vitrine, vos pages de Paiement et votre Portail Client une fois que vous avez ajouté vos ID de suivi dans le tableau de bord.
</Info>

<Warning>
Les bloqueurs de publicités dans les navigateurs des clients peuvent empêcher le suivi analytique de fonctionner pour certains visiteurs de votre boutique.
</Warning>

## Prise en Main

<Steps>
<Step title="Ouvrir les Paramètres de l'Entreprise">
  Dans votre tableau de bord Dodo Payments, accédez à **Paramètres** et faites défiler jusqu'à la section **Analytique**.
</Step>

<Step title="Activer Votre Plateforme de Suivi">
  Activez la plateforme analytique que vous souhaitez utiliser et saisissez votre ID de suivi :
  - **Google Analytics** : Saisissez votre ID de Mesure (format : `G-XXXXXXXXXX`)
  - **Google Tag Manager** : Saisissez votre ID de Conteneur (format : `GTM-XXXXXXX`)
  - **Meta Pixel** : Saisissez votre ID de Pixel (numérique, 10-20 chiffres)
</Step>

<Step title="Enregistrer Vos Paramètres">
  Cliquez sur **Enregistrer** pour appliquer votre configuration de suivi.
</Step>

<Step title="Vérifier le Suivi">
  Visitez votre vitrine ou créez un paiement de test pour vérifier que les événements sont suivis dans votre tableau de bord d'analytique.
</Step>
</Steps>

## Google Analytics 4

[Google Analytics 4](https://marketingplatform.google.com/about/analytics/) fournit une analytics web complète avec des capacités de suivi du commerce électronique. Avec l'intégration Dodo Payments, vous pouvez suivre le parcours complet du client, de la navigation sur votre boutique à la finalisation d'un achat.

### Ajouter Votre ID de Mesure Google Analytics

1. Dans Google Analytics, allez dans **Admin** → **Flux de Données** → sélectionnez votre flux web
2. Copiez l'**ID de Mesure** (commence par `G-`)
3. Dans le tableau de bord Dodo Payments, allez dans **Paramètres** → **Analytique**
4. Activez **Google Analytics** et collez votre ID de Mesure
5. Cliquez sur **Enregistrer**

<Tip>
Si vous n'avez pas encore de propriété Google Analytics, suivez le [guide de configuration de Google](https://support.google.com/analytics/answer/9304153) pour en créer une.
</Tip>

### Événements Suivis dans Google Analytics

Nous suivons les événements suivants sur votre vitrine hébergée et vos pages de paiement. Les données d'événement, y compris les informations sur les produits, les totaux de transactions et la devise, sont envoyées avec chaque événement.

#### Événements de Vitrine

| Événement | Description |
|-------|-------------|
| `view_item_list` | Se produit lorsque la page de vitrine se charge avec des produits |
| `select_item` | Se produit lorsqu'un client clique sur un produit pour commencer le paiement |

#### Événements de Paiement

| Événement | Description |
|-------|-------------|
| `view_item` | Se produit lorsque la page de paiement se charge |
| `view_cart` | Se produit lorsque le paiement se charge et qu'une variante est sélectionnée |
| `apply_discount`* | Se produit lorsqu'un code de réduction valide est appliqué avec succès |
| `remove_discount`* | Se produit lorsqu'un code de réduction est supprimé |
| `add_payment_info` | Se produit lorsque le client soumet le formulaire de paiement |
| `purchase` | Se produit lorsque le paiement est réussi |

<Note>
`apply_discount` et `remove_discount` sont des événements personnalisés non inclus dans les [événements de commerce électronique standard de Google Analytics](https://support.google.com/analytics/answer/9267735).
</Note>

### Utiliser GA4 avec le Paiement Overlay/Inline

Pour suivre les événements Google Analytics dans le paiement overlay ou inline intégré sur votre propre site web, vous devez installer le code de suivi Google Analytics sur votre site où le paiement est intégré.

Une fois installé, tous les événements de suivi énumérés ci-dessus seront envoyés automatiquement à votre compte Google Analytics - aucune configuration supplémentaire n'est nécessaire.

## Google Tag Manager

[Google Tag Manager](https://marketingplatform.google.com/about/tag-manager/) vous permet de gérer des balises marketing et analytiques sans modifier le code. Les balises déployées via GTM se déclencheront sur toutes les pages hébergées par Dodo Payments.

### Ajouter Votre ID de Conteneur GTM

1. Dans Google Tag Manager, copiez votre **ID de Conteneur** (commence par `GTM-`)
2. Dans le tableau de bord Dodo Payments, allez dans **Paramètres** → **Analytique**
3. Activez **Google Tag Manager** et collez votre ID de Conteneur
4. Cliquez sur **Enregistrer**

<Info>
Lorsque vous utilisez GTM, vous pouvez configurer un suivi supplémentaire (comme les conversions Google Ads) directement dans votre conteneur GTM. L'intégration Dodo Payments injecte à la fois le script GTM et la solution de repli noscript pour une compatibilité maximale.
</Info>

### Utiliser GTM avec le Paiement Overlay/Inline

Pour le paiement overlay ou inline intégré sur votre site web, installez GTM sur votre propre site. Le paiement héritera de votre configuration GTM et déclenchera des événements dans le cadre intégré.

## Meta Pixel

[Meta Pixel](https://www.facebook.com/business/tools/meta-pixel/) suit les actions des clients sur votre boutique pour mesurer l'efficacité de vos campagnes publicitaires sur Facebook et Instagram. Suivez les conversions de l'interaction avec l'annonce à la finalisation de l'achat.

### Ajouter Votre ID de Pixel Meta

1. Dans [Meta Events Manager](https://www.facebook.com/events_manager2/), créez ou sélectionnez votre Pixel
2. Copiez le **ID de Pixel** (numérique, généralement 15-16 chiffres)
3. Dans le tableau de bord Dodo Payments, allez dans **Paramètres** → **Analytique**
4. Activez **Meta Pixel** et collez votre ID de Pixel
5. Cliquez sur **Enregistrer**

<Tip>
Suivez le [guide de configuration de Pixel](https://www.facebook.com/business/help/952192354843755) de Meta si vous n'avez pas encore créé de Pixel.
</Tip>

### Événements Suivis avec Meta Pixel

Nous suivons les événements suivants qui apparaissent dans votre [Meta Events Manager](https://www.facebook.com/events_manager2/). Les données d'événements, y compris les IDs de contenu, les valeurs et la devise, sont envoyées avec chaque événement.

<Note>
Les événements peuvent ne pas apparaître immédiatement dans le Meta Events Manager - il peut y avoir un délai de plusieurs minutes.
</Note>

#### Événements de Vitrine

| Événement | Description |
|-------|-------------|
| `PageView` | Se produit lorsque la page de vitrine se charge |
| `ViewContent` | Se produit lorsque la vitrine se charge avec des produits |
| `InitiateCheckout` | Se produit lorsqu'un client clique sur un produit pour commencer le paiement |

#### Événements de Paiement

| Événement | Description |
|-------|-------------|
| `PageView` | Se produit lorsque la page de paiement se charge |
| `AddToCart` | Se produit lorsque le paiement se charge et qu'une variante est sélectionnée |
| `ApplyDiscount`* | Se produit lorsqu'un code de réduction valide est appliqué avec succès |
| `RemoveDiscount`* | Se produit lorsqu'un code de réduction est supprimé |
| `AddPaymentInfo` | Se produit lorsque le client soumet le formulaire de paiement |
| `Purchase` | Se produit lorsque le paiement est réussi |

<Note>
`ApplyDiscount` et `RemoveDiscount` sont des événements personnalisés non inclus dans les [événements standard de Meta](https://developers.facebook.com/docs/meta-pixel/reference#standard-events).
</Note>

## Référence Complète des Événements

Ce tableau montre tous les événements suivis à la fois dans Google Analytics 4 et Meta Pixel :

| Déclencheur | Événement GA4 | Événement Meta Pixel | Emplacement |
|---------|-----------|------------------|----------|
| Page de vitrine chargée | `view_item_list` | `ViewContent` | Vitrine |
| Client clique sur un produit | `select_item` | `InitiateCheckout` | Vitrine |
| Page de paiement chargée | `view_item` | `AddToCart` | Paiement |
| Panier vu/variant sélectionné | `view_cart` | - | Paiement |
| Code de réduction appliqué | `apply_discount` | `ApplyDiscount` | Paiement |
| Code de réduction supprimé | `remove_discount` | `RemoveDiscount` | Paiement |
| Formulaire de paiement soumis | `add_payment_info` | `AddPaymentInfo` | Paiement |
| Paiement réussi | `purchase` | `Purchase` | Paiement |

## Couverture des Plates-formes

Le suivi analytique est disponible sur différentes surfaces de Dodo Payments :

| Surface | Google Analytics 4 | Google Tag Manager | Meta Pixel |
|---------|-------------------|-------------------|------------|
| Vitrine | Oui | Oui | Oui |
| Paiement (Hébergé) | Oui | Oui | Oui |
| Paiement (Overlay/Inline)* | Oui | Oui | Oui |
| Portail Client | Oui | Oui | Non |

<Info>
*Pour le paiement overlay et inline, installez le code de suivi sur votre propre site pour une attribution complète. Les événements provenant du paiement intégré seront suivis automatiquement.
</Info>

## Données d'Événement Incluses

Chaque événement de suivi comprend des données de commerce électronique pertinentes pour vous aider à analyser le comportement des clients :

### Données Produit
- ID de produit
- Nom du produit
- Prix
- Devise
- Quantité

### Données de Transaction (Événements d'Achat)
- ID de Transaction/Paiement
- Montant total
- Montant de la taxe
- Devise
- Remise appliquée

### Données Client
- ID client (pour les clients de retour)
- Email (haché pour la confidentialité lorsque cela est applicable)

## Meilleures Pratiques

<AccordionGroup>
<Accordion title="Testez votre intégration">
Après avoir ajouté vos ID de suivi, visitez votre vitrine et complétez un paiement de test pour vérifier que les événements apparaissent dans vos tableaux de bord d'analytique. Utilisez les rapports en temps réel de Google Analytics ou la fonctionnalité Test Events du Meta Events Manager.
</Accordion>

<Accordion title="Utilisez des paramètres UTM">
Ajoutez des paramètres UTM à vos liens marketing pour suivre quelles campagnes génèrent des conversions. Dodo Payments préserve les paramètres UTM tout au long du flux de paiement.
</Accordion>

<Accordion title="Mettez en Place des Objectifs de Conversion">
Dans Google Analytics, créez des événements de conversion pour `purchase` pour suivre votre taux de conversion. Dans Meta Ads Manager, utilisez l'événement `Purchase` comme votre objectif d'optimisation pour les campagnes.
</Accordion>

<Accordion title="Activez le Commerce Électronique Amélioré">
Si vous utilisez Google Tag Manager, envisagez de configurer des rapports de Commerce Électronique Amélioré pour une analyse détaillée de l'entonnoir et des métriques de performance des produits.
</Accordion>
</AccordionGroup>

## Dépannage

<AccordionGroup>
<Accordion title="Événements n'apparaissant pas dans Google Analytics">
- Vérifiez que votre ID de Mesure est correct (format : `G-XXXXXXXXXX`)
- Consultez les rapports en temps réel de Google Analytics - les événements apparaissent d'abord là
- Assurez-vous que le toggle est activé dans vos paramètres Dodo Payments
- Attendez quelques minutes car il peut y avoir des retards de traitement
- Testez dans une fenêtre incognito pour écarter les bloqueurs de publicités
</Accordion>

<Accordion title="Événements n'apparaissant pas dans Meta Events Manager">
- Vérifiez que votre ID de Pixel est correct (numérique, 10-20 chiffres)
- Utilisez l'extension de navigateur Meta Pixel Helper pour déboguer
- Vérifiez l'onglet Test Events dans le Events Manager
- Les événements peuvent mettre plusieurs minutes à apparaître
- Assurez-vous que les bloqueurs de publicités sont désactivés lors du test
</Accordion>

<Accordion title="Les balises GTM ne se déclenchent pas">
- Confirmez que votre ID de Conteneur est correct (format : `GTM-XXXXXXX`)
- Utilisez le mode Prévisualisation de GTM pour déboguer le déclenchement des balises
- Vérifiez que les déclencheurs sont configurés correctement dans votre conteneur GTM
- Vérifiez que le conteneur est publié (pas seulement en brouillon)
</Accordion>

<Accordion title="Le paiement overlay/inline ne suit pas">
- Installez d'abord le code de suivi sur votre propre site
- Assurez-vous que le suivi se charge avant l'ouverture de l'overlay de paiement
- Vérifiez la console du navigateur pour des erreurs JavaScript
- Vérifiez que le suivi inter-domaines est configuré si vous utilisez GA4
</Accordion>

<Accordion title="Les événements d'achat affichent des montants incorrects">
- Les montants sont envoyés dans la plus petite unité monétaire (cents)
- Vérifiez que votre outil d'analytique est configuré pour afficher la bonne devise
- Vérifiez si la taxe est incluse/exclue comme prévu
</Accordion>
</AccordionGroup>
