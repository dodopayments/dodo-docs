<Info>
Le droit d'utilisation Notion duplique un modèle que vous avez préparé dans l'espace de travail Notion du client payant. Le client s'autorise via OAuth, choisit l'espace de travail dans lequel il souhaite copier le modèle, et Dodo Payments gère la duplication.
</Info>

## Ce qui est livré

- Le client est invité à connecter son espace de travail Notion via OAuth.
- Une fois l'autorisation accordée, Dodo Payments duplique le modèle configuré dans l'espace de travail qu'il a choisi.
- En cas d'annulation, le modèle dupliqué reste dans l'espace de travail du client (Notion ne prend pas en charge la suppression à distance). L'autorisation est marquée `Revoked` à des fins d'archivage.

Les utilisations courantes incluent les modèles Notion payants, les systèmes de productivité et les modèles OS/CRM.

</Step>

## Flux client

1. Le client finalise le paiement.
2. Dodo Payments crée une autorisation avec le statut `Pending` et un `oauth_url` Notion permettant au client de connecter son espace de travail.
3. Le client autorise l'accès via le lien contenu dans son e-mail ou dans le Customer Portal, puis sélectionne l'espace de travail dans lequel il souhaite que le modèle soit dupliqué.
4. Dodo Payments duplique le modèle. L'autorisation passe au statut `Delivered`.
5. En cas de révocation, l'autorisation est marquée `Revoked` ; la copie dupliquée reste dans l'espace de travail du client.

<Note>
Notion considère intentionnellement une page dupliquée comme le contenu propre du destinataire. Dodo Payments ne peut pas supprimer la copie en cas de révocation.
</Note>

## Configuration requise

| Champ | Requis | Description |
|---|---|---|
| `notion_template_id` | Oui | L'ID du modèle. Le sélecteur de tableau de bord remplit cela. |

## Créer via API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Study Notes',
  integration_type: 'notion',
  integration_config: {
    notion_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Study Notes",
    integration_type="notion",
    integration_config={"notion_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Study Notes"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeNotion),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigNotionConfigParam{
      NotionTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

Voir [les événements de webhook `entitlement_grant.*`](/developer-resources/webhooks/intents/entitlement-grant) :

- `entitlement_grant.created` inclut le Notion `oauth_url`.
- `entitlement_grant.delivered` se déclenche une fois le modèle dupliqué.
- `entitlement_grant.revoked` se déclenche en cas d'annulation ; la copie du client reste inchangée.

## Dépannage

<AccordionGroup>
<Accordion title="Customer didn't get the template">
L'autorisation reste à l'état `Pending` jusqu'à ce que le client termine le processus OAuth de Notion. Renvoyez l'e-mail de livraison ; le lien OAuth expire au bout d'une semaine, après quoi vous pouvez révoquer et recréer l'autorisation.
</Accordion>

<Accordion title="Template picker is empty">
Reconnectez Notion depuis **Droits d'utilisation → Intégrations → Notion** avec l'espace de travail qui possède les modèles sources.
</Accordion>

<Accordion title="Customer wants the template removed after refund">
Notion n'autorise pas la suppression à distance des pages dupliquées. Le client doit supprimer la copie de son propre espace de travail.
</Accordion>
</AccordionGroup>
