<Info>
La parité de pouvoir d’achat (PPP) fait payer au client une part de votre prix catalogue, en fonction du pays depuis lequel il achète. Un produit à \$20 peut être vendu **\$6.00 en Inde**, sans code de réduction et sans deuxième liste de prix.
</Info>

## Qu’est-ce que la parité de pouvoir d’achat ?

Le même prix n’est pas abordable de la même manière partout. \$20 représentent une petite dépense aux États-Unis et une dépense importante aux Philippines. La tarification PPP corrige cette différence.

Dodo Payments conserve un pourcentage pour chaque pays. Ce pourcentage correspond à la **part de votre prix catalogue payée par le client**. L’Inde est à 30 : un client en Inde paie donc 30 % du prix. Les États-Unis sont à 100 : rien ne change dans ce pays.

Vous activez la PPP pour chaque prix de produit auquel vous souhaitez l’appliquer. Les produits que vous n’activez pas conservent leur prix normal partout.

<Note>
La PPP nécessite [Adaptive Currency](/features/adaptive-currency). Activez d’abord Adaptive Currency.
</Note>

## Principaux avantages

- **Atteignez les marchés sensibles au prix** : vendez à un prix local sans réduire votre prix national.
- **Aucune bannière ni aucun script** : le prix est correct au checkout. Rien n’est ajouté à votre site web.
- **Aucun code de réduction à gérer** : rien à créer, renouveler ou révoquer.
- **Contrôle par produit** : activez un forfait de démarrage et laissez un forfait entreprise inchangé.
- **Fonctionne partout** : produits à paiement unique, abonnements et produits facturés à l’usage.

## Activer la parité de pouvoir d’achat

<Steps>
<Step title="Enable Adaptive Currency">
Accédez à **Settings → Business**. Dans **Business Settings**, activez **Adaptive Currency**. La PPP ne fonctionne pas sans cette option.

<Frame>
  <img src="/images/ppp/adaptive-currency-toggle.png" alt="Adaptive Currency et parité de pouvoir d’achat dans les paramètres Business" style={{ maxHeight: '360px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Review your country percentages">
Sous **Purchasing Power Parity**, cliquez sur **Edit** pour ouvrir **Country Prices**. Modifiez le pourcentage d’un pays, puis cliquez sur **Save Changes**.

Définissez **Example product price** pour voir ce que paie chaque pays. La colonne **Your Price** se met à jour au fur et à mesure de votre saisie. Utilisez la zone de recherche pour trouver un pays par son nom ou son code.

<Frame>
  <img src="/images/ppp/country-percentages.png" alt="Boîte de dialogue Country Prices avec un pourcentage et le prix obtenu pour chaque pays" style={{ maxHeight: '620px', width: 'auto' }} />
</Frame>

<Note>
Ces pourcentages s’appliquent à l’ensemble de l’entreprise. Tous les produits pour lesquels la parité de pouvoir d’achat est activée les utilisent.
</Note>
</Step>

<Step title="Turn PPP on for a product">
Ouvrez le produit. Dans la section **Pricing**, cochez **Purchasing Power Parity**, puis enregistrez le produit.

Les produits que vous ne cochez pas conservent leur prix normal partout.

<Frame>
  <img src="/images/ppp/product-toggle.png" alt="Parité de pouvoir d’achat cochée dans la section Pricing du produit" style={{ maxHeight: '440px', width: 'auto' }} />
</Frame>

<Warning>
Vous ne pouvez pas cocher cette option si Adaptive Currency est désactivée. Activez d’abord Adaptive Currency.
</Warning>
</Step>

<Step title="Confirm at checkout">
<Check>
Ouvrez un checkout de test avec un pays de facturation dont le pourcentage est inférieur à 100. Vérifiez que le prix réduit s’affiche.
</Check>
</Step>
</Steps>

## Comment le prix est calculé

Le pourcentage du pays multiplie votre prix catalogue :

```
price paid = list price × country percentage ÷ 100
```

Un produit à \$20.00, pour un client en Inde avec un pourcentage de 30 :

```
2000 × 30 ÷ 100 = 600   →   $6.00
```

Dodo Payments applique le pourcentage au prix de base, avant la conversion de devise. [Adaptive Currency](/features/adaptive-currency) convertit ensuite le résultat dans la devise du client.

<Info>
Dodo Payments détermine le pays à partir du **pays de facturation** du client au checkout.
</Info>

### Pourcentages par pays

Chaque pays possède un pourcentage compris entre **30 et 100** :

- **100** signifie que le client paie le prix total. Il n’y a aucune réduction.
- **30** est la valeur minimale que vous pouvez définir. La réduction maximale est donc de 70 %.

Les valeurs par défaut proviennent des données de l’indice du niveau des prix de la Banque mondiale. Dodo Payments arrondit chaque valeur au multiple de 5 le plus proche, applique un plancher de 30 et la plafonne à 100. Chaque pays pris en charge possède une valeur. Vous pouvez toutes les modifier.

Voici quelques valeurs par défaut pour illustrer l’étendue :

| Pays | Pourcentage | Prix de vente d’un produit à \$20 |
| :--- | :---: | :--- |
| États-Unis | 100 | \$20.00 |
| Royaume-Uni | 85 | \$17.00 |
| Allemagne | 75 | \$15.00 |
| Japon | 60 | \$12.00 |
| Brésil | 45 | \$9.00 |
| Afrique du Sud | 40 | \$8.00 |
| Philippines | 35 | \$7.00 |
| Inde | 30 | \$6.00 |

<Note>
La liste complète couvre 217 pays. Ouvrez le tableau des pays dans votre dashboard pour voir chaque valeur.
</Note>

## Activer via l’API

La PPP est activée par produit, avec le champ `purchasing_power_parity`. La valeur par défaut est `false`.

<Info>
Les pourcentages par pays se gèrent uniquement dans le dashboard. Ils ne font pas partie de l’API publique.
</Info>

<CodeGroup>

```typescript theme={null}
import DodoPayments from 'dodopayments';

const client = new DodoPayments({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: 'test_mode',
});

const product = await client.products.create({
  name: 'Starter Plan',
  tax_category: 'saas',
  price: {
    type: 'one_time_price',
    currency: 'USD',
    price: 2000,
    discount: 0,
    purchasing_power_parity: true,
  },
});
```

```python theme={null}
import os
from dodopayments import DodoPayments

client = DodoPayments(
    bearer_token=os.environ.get("DODO_PAYMENTS_API_KEY"),
    environment="test_mode",
)

product = client.products.create(
    name="Starter Plan",
    tax_category="saas",
    price={
        "type": "one_time_price",
        "currency": "USD",
        "price": 2000,
        "discount": 0,
        "purchasing_power_parity": True,
    },
)
```

```go theme={null}
package main

import (
	"context"
	"os"

	"github.com/dodopayments/dodopayments-go"
	"github.com/dodopayments/dodopayments-go/option"
)

func main() {
	client := dodopayments.NewClient(
		option.WithBearerToken(os.Getenv("DODO_PAYMENTS_API_KEY")),
	)

	_, err := client.Products.New(context.TODO(), dodopayments.ProductNewParams{
		Name:        dodopayments.F("Starter Plan"),
		TaxCategory: dodopayments.F(dodopayments.ProductNewParamsTaxCategorySaas),
		Price: dodopayments.F[dodopayments.PriceUnionParam](
			dodopayments.PriceOneTimePriceParam{
				Type:                  dodopayments.F(dodopayments.PriceOneTimePriceTypeOneTimePrice),
				Currency:              dodopayments.F(dodopayments.CurrencyUsd),
				Price:                 dodopayments.F(int64(2000)),
				Discount:              dodopayments.F(int64(0)),
				PurchasingPowerParity: dodopayments.F(true),
			},
		),
	})
	if err != nil {
		panic(err)
	}
}
```

</CodeGroup>

<Warning>
La requête échoue avec `422 ppp_not_enabled_for_business` si Adaptive Currency est désactivée pour votre entreprise. Activez-la d’abord.
</Warning>

## Comportements importants

| Comportement | Détail |
| :--- | :--- |
| **Nécessite Adaptive Currency** | La PPP ne fonctionne pas si Adaptive Currency est désactivée. |
| **Désactivée par défaut** | Chaque prix commence à `purchasing_power_parity: false`. |
| **Les prix localisés sont prioritaires** | Un produit associé à une règle de [tarification localisée](/features/localized-pricing) correspondante n’est jamais ajusté par la PPP. Le montant exact que vous avez défini s’applique. |
| **Appliquée avant la conversion** | Le pourcentage s’applique à votre prix de base. Adaptive Currency convertit le résultat. |
| **Avant les réductions** | Un [code de réduction](/features/discount-codes) s’applique au prix réduit : les deux réductions se cumulent. |
| **Frais fixes uniquement pour les produits facturés à l’usage** | La PPP s’applique aux frais fixes d’un produit facturé à l’usage, jamais à l’utilisation mesurée. |
| **Ne s’applique pas à Pay What You Want** | Le client choisit le montant, la PPP ne s’applique donc pas. Consultez [Pay What You Want](/features/pay-what-you-want). |
| **Plage de pourcentage** | Le pourcentage d’un pays est compris entre 30 et 100. La réduction maximale est de 70 %. |
| **Aucun webhook dédié** | Le montant réduit apparaît sur le paiement ou l’abonnement comme n’importe quel autre prix. |

## Bonnes pratiques

- **Activez d’abord un seul produit.** Vérifiez le prix au checkout avant d’activer la PPP pour votre catalogue.
- **Surveillez le cumul des réductions.** Un code de réduction s’applique en plus du prix PPP. Un pourcentage de pays de 30 et un code de 20 % laissent 24 % de votre prix catalogue.
- **Laissez les forfaits entreprise de côté.** Un forfait négocié nécessite rarement un ajustement par pays.
- **Définissez vos propres valeurs lorsque c’est important.** Les chiffres par défaut sont un point de départ, pas une règle.
- **Vérifiez l’effet sur les abonnements.** Un abonné qui s’inscrit au prix réduit renouvelle son abonnement à ce prix.
