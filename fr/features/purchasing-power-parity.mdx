La tarification parité de pouvoir d'achat (PPP) ajuste ce que vous facturez pour correspondre au pouvoir d'achat de l'emplacement de chaque client. Il y a deux façons de le faire sur Dodo Payments.

<Info>
**Recommandé :** Utilisez la [tarification localisée](/features/localized-pricing) native pour définir un prix local fixe par pays, par exemple ₹999 en Inde pour un produit avec une base de \$20. Vous contrôlez le montant exact, il s'applique aux produits ponctuels, par abonnement et basés sur l'usage, et il n'y a pas de bannière ou de script à installer.
</Info>

## Deux façons d'exécuter la PPP

| | Tarification localisée (native) | Codes de réduction basés sur la localisation |
| :--- | :--- | :--- |
| Comment ça fonctionne | Vous définissez un prix local fixe par pays/devise | Un pourcentage de réduction sur votre prix de base, appliqué via un code |
| Outils | Intégré dans Dodo Payments | [ParityDeals](https://www.paritydeals.com/) / [Evendeals](https://www.evendeals.com/integrations/dodo-payments) |
| Bannière / script sur votre site | Non requis | Requis pour afficher le code |
| Prix que voit le client | Le montant exact que vous définissez | Prix de base moins la réduction |
| Idéal pour | Prix propres et ajustés au marché que vous contrôlez entièrement | Bannières promotionnelles et offres basées sur le temps/jours fériés |

Pour la configuration native, voir [tarification localisée](/features/localized-pricing). Le reste de cette page couvre l'approche des codes de réduction basés sur la localisation avec ParityDeals et Evendeals.

## Codes de réduction basés sur la localisation

[ParityDeals](https://www.paritydeals.com/) et [Evendeals](https://www.evendeals.com/integrations/dodo-payments) sont des plateformes qui permettent l'optimisation automatique des prix en fonction de la localisation géographique d'un client en générant des codes de réduction.

<Info>
Bien que vous ne puissiez pas intégrer directement des bannières de réduction sur une vitrine Dodo Payments (car les scripts personnalisés ne sont pas pris en charge), vous pouvez quand même implémenter ces outils efficacement sur votre propre site ou application.
</Info>

### Choisir une intégration

Les deux plateformes s'intègrent directement à Dodo Payments pour créer et gérer automatiquement les codes de réduction. Utilisez la comparaison ci-dessous pour choisir l'outil qui correspond le mieux à vos besoins.

| Fonctionnalité | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| Tarification PPP / basée sur la localisation | Oui | Oui |
| Offres basées sur les jours fériés / le temps | Oui | Non |
| Support des abonnements | Oui | Oui |
| Rafraîchissement automatique des coupons | — | Oui |
| Personnalisation des bannières | Oui | Non |
| Tarification | [Voir la tarification](https://www.paritydeals.com/pricing/) | [Voir la tarification](https://www.evendeals.com/pricing) |

### ParityDeals

Lorsque ParityDeals est intégré à votre site, les visiteurs éligibles verront une bannière incluant un code de réduction basé sur la localisation qu'ils pourront utiliser au moment du paiement. Ces codes de réduction sont automatiquement créés et gérés par ParityDeals et apparaîtront dans votre **Tableau de bord Dodo Payments** sous **Ventes → Réductions**.

#### Configuration

<Steps>
  <Step title="Sign up on ParityDeals">
    Visitez [app.paritydeals.com](https://app.paritydeals.com/) et créez un compte.
  </Step>

  <Step title="Create Deals">
    Après vous être connecté, localisez l'option pour créer des offres. Dans le menu déroulant, sélectionnez **"Créer des offres via Dodo Payments"**.

    <Frame>
      <img src="/images/ppp/2.png" alt="Créer des offres via Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Connectez-vous à votre **tableau de bord Dodo Payments** et accédez à **Développeurs → Clés API**. Cliquez sur **"Créer une nouvelle API"**.

    <Tip>
      Nommez votre clé API de façon descriptive (par exemple, 'ParityDeals') pour pouvoir l'identifier plus tard.
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="Créer une nouvelle clé API dans Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Copiez la clé API que vous avez créée et collez-la dans l'interface ParityDeals pour établir la connexion avec votre compte Dodo Payments.

    <Frame>
      <img src="/images/ppp/4.png" alt="Connexion de la clé API à ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Une fois connecté, ParityDeals récupère votre catalogue de produits Dodo Payments. Sélectionnez les produits que vous souhaitez associer à vos offres.

    <Frame>
      <img src="/images/ppp/5.png" alt="Sélection de produits pour ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Entrez l'URL de votre site et, éventuellement, sélectionnez des pages cibles spécifiques où la bannière de réduction doit apparaître. Choisissez ensuite votre type d'offre préféré :
    - Offres basées sur la localisation
    - Offres pour les jours fériés
    - Offres flash basées sur le temps

    <Frame>
      <img src="/images/ppp/6.png" alt="Configuration des paramètres de l'offre" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Sélectionnez les pays auxquels vous souhaitez offrir des réductions localisées et définissez le pourcentage de réduction pour chacun. ParityDeals fournit des paramètres par défaut recommandés que vous pouvez ajuster selon vos besoins.

    <Frame>
      <img src="/images/ppp/7.png" alt="Définir les règles de réduction par pays" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Concevez votre bannière de réduction en personnalisant le texte, en sélectionnant les couleurs et la mise en page, et en choisissant la position de la bannière (en haut ou en bas de la page). Cette bannière sera affichée aux visiteurs éligibles selon vos règles configurées.

    <Frame>
      <img src="/images/ppp/8.png" alt="Personnalisation de la bannière de réduction" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Après avoir enregistré votre offre, ParityDeals générera un script. Ajoutez ce script au code de votre site (généralement dans la section `<head>`). Ce script détecte automatiquement les emplacements des visiteurs et affiche la bannière de réduction appropriée.

    <Frame>
      <img src="/images/ppp/9.png" alt="Script d'intégration ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

#### Fonctionnalités supplémentaires

Avec ParityDeals, vous pouvez également offrir des [réductions automatiques basées sur le temps](https://www.paritydeals.com/features/time-based-discounts/) et des [promotions basées sur les jours fériés](https://www.paritydeals.com/features/holiday-based-discounts/) tout au long de l'année. Pour des informations plus détaillées, consultez la [documentation ParityDeals](https://www.paritydeals.com/docs/).

### Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) est une autre plateforme qui s'intègre à Dodo Payments pour offrir une tarification parité de pouvoir d'achat basée sur la localisation. Elle prend en charge les produits à la fois ponctuels et sur abonnement.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Vue d'ensemble de l'intégration Evendeals avec Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### Fonctionnalités clés

- **Synchronisation automatique des coupons** — Les coupons sont créés et gérés automatiquement dans Dodo Payments
- **Réductions en pourcentage** — Offrez des réductions en pourcentage par groupe de pays
- **Support des abonnements** — Les réductions s'appliquent aux cycles de facturation des abonnements
- **Règles de rafraîchissement automatique** — Faites tourner automatiquement les codes de coupons par intervalle de temps, nombre de validations ou nombre d'affichages pour éviter les abus

<Info>
Les codes de réduction créés par Evendeals apparaîtront automatiquement dans votre tableau de bord Dodo Payments sous Ventes → Réductions.
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="Fonctionnalités clés d'Evendeals pour l'intégration Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### Configuration

<Steps>
  <Step title="Create a Dodo Payments API key">
    Dans votre tableau de bord Dodo Payments, allez à **Développeurs → Clés API** et générez une nouvelle clé.
  </Step>

  <Step title="Connect in Evendeals">
    Dans votre [tableau de bord Evendeals](https://www.evendeals.com/signin), accédez à **Intégrations**, trouvez la carte Dodo Payments, et collez votre clé API.
  </Step>

  <Step title="Configure regional discounts">
    Définissez des réductions en pourcentage pour chaque groupe de pays et cliquez sur synchroniser. Evendeals crée automatiquement des coupons dans Dodo Payments.

    <Check>
    Après synchronisation, ouvrez **Ventes → Réductions** dans votre tableau de bord Dodo Payments pour confirmer que les coupons générés apparaissent. Chaque coupon aura un préfixe Evendeals reconnaissable.
    </Check>
  </Step>
</Steps>
