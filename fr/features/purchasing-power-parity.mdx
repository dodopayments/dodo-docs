[ParityDeals](https://www.paritydeals.com/) et [Evendeals](https://www.evendeals.com/integrations/dodo-payments) sont des plateformes qui permettent une optimisation automatique des prix basée sur la localisation géographique d'un client, communément appelée tarification "parité de pouvoir d'achat" (PPP).

<Info>
Bien que vous ne puissiez pas directement intégrer de bannières de réduction sur une vitrine Dodo Payments (car les scripts personnalisés ne sont pas pris en charge), vous pouvez toujours mettre en œuvre efficacement ces outils sur votre propre site web ou application.
</Info>

## Choisir une Intégration

Les deux plateformes s'intègrent directement avec Dodo Payments pour créer et gérer automatiquement des codes de réduction. Utilisez la comparaison ci-dessous pour choisir l'outil qui convient le mieux à vos besoins.

| Fonctionnalité | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| Tarification PPP / Basée sur la localisation | Oui | Oui |
| Offres basées sur les fêtes / le temps | Oui | Non |
| Support d'abonnement | Oui | Oui |
| Rafraîchissement automatique des coupons | — | Oui |
| Personnalisation des bannières | Oui | Non |
| Tarification | [Voir Tarification](https://www.paritydeals.com/pricing/) | [Voir Tarification](https://www.evendeals.com/pricing) |

## ParityDeals

Lorsque ParityDeals est intégré à votre site web, les visiteurs éligibles verront une bannière incluant un code de réduction basé sur la localisation qu'ils peuvent utiliser lors de l'achat. Ces codes de réduction sont automatiquement créés et gérés par ParityDeals et apparaîtront dans votre **Tableau de Bord Dodo Payments** sous **Ventes → Réductions**.

### Configuration

<Steps>
  <Step title="Sign up on ParityDeals">
    Rendez-vous sur [app.paritydeals.com](https://app.paritydeals.com/) et créez un compte.
  </Step>

  <Step title="Create Deals">
    Après vous être connecté, trouvez l'option pour créer des offres. Dans le menu déroulant, sélectionnez **"Créer des Offres via Dodo Payments"**.

    <Frame>
      <img src="/images/ppp/2.png" alt="Créer des offres via Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Connectez-vous à votre **tableau de bord Dodo Payments** et naviguez vers **Développeurs → Clés API**. Cliquez sur **"Créer une Nouvelle API"**.

    <Tip>
      Nommez votre clé API de manière descriptive (par ex., 'ParityDeals') pour pouvoir l'identifier plus tard.
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="Créer une nouvelle clé API dans Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Copiez la clé API que vous avez créée et collez-la dans l'interface ParityDeals pour établir la connexion avec votre compte Dodo Payments.

    <Frame>
      <img src="/images/ppp/4.png" alt="Connexion de la clé API à ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    Une fois connecté, ParityDeals récupérera votre catalogue de produits Dodo Payments. Sélectionnez les produits que vous souhaitez associer à vos offres.

    <Frame>
      <img src="/images/ppp/5.png" alt="Sélection de produits pour ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Entrez l'URL de votre site web et sélectionnez éventuellement des pages cibles spécifiques où la bannière de réduction devrait apparaître. Puis choisissez le type d'offre préféré :
    - Offres basées sur la localisation
    - Offres de fêtes
    - Offres flash basées sur le temps

    <Frame>
      <img src="/images/ppp/6.png" alt="Configurer les paramètres de l'offre" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Sélectionnez les pays auxquels vous souhaitez offrir des réductions localisées et définissez le pourcentage de réduction pour chacun. ParityDeals fournit des paramètres par défaut recommandés que vous pouvez ajuster selon vos besoins.

    <Frame>
      <img src="/images/ppp/7.png" alt="Définir des règles de réduction basées sur le pays" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Concevez votre bannière de réduction en personnalisant le texte, en sélectionnant les couleurs et la mise en page, et en choisissant la position de la bannière (en haut ou en bas de la page). Cette bannière sera affichée aux visiteurs éligibles suivant les règles que vous avez configurées.

    <Frame>
      <img src="/images/ppp/8.png" alt="Personnalisation de la bannière de réduction" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Après avoir enregistré votre offre, ParityDeals générera un script. Ajoutez ce script au code de votre site web (typiquement dans la section `<head>`). Ce script détecte automatiquement les localisations des visiteurs et affiche la bannière de réduction appropriée.

    <Frame>
      <img src="/images/ppp/9.png" alt="Script d'intégration ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

### Fonctionnalités Supplémentaires

Avec ParityDeals, vous pouvez également offrir des [réductions automatiques basées sur le temps](https://www.paritydeals.com/features/time-based-discounts/) et des [promotions basées sur les fêtes](https://www.paritydeals.com/features/holiday-based-discounts/) tout au long de l'année. Pour plus d'informations, consultez la [Documentation ParityDeals](https://www.paritydeals.com/docs/).

## Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) est une autre plateforme qui s'intègre avec Dodo Payments pour offrir une tarification basée sur la parité de pouvoir d'achat en fonction de la localisation. Elle supporte à la fois les produits uniques et par abonnement.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Aperçu de l'intégration Evendeals Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

### Caractéristiques Clés

- **Synchronisation automatique des coupons** — Les coupons sont créés et gérés automatiquement dans Dodo Payments
- **Réductions en pourcentage** — Offrez des réductions en pourcentage par groupe de pays
- **Support des abonnements** — Les réductions s'appliquent à travers les cycles de facturation des abonnements
- **Règles de rafraîchissement automatique** — Faites tourner les codes de coupon automatiquement par intervalle de temps, nombre de rédemptions ou nombre de vues pour éviter les abus

<Info>
Les codes de réduction créés par Evendeals apparaîtront automatiquement dans votre tableau de bord Dodo Payments sous Ventes → Réductions.
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="Caractéristiques clés d'Evendeals pour l'intégration Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

### Configuration

<Steps>
  <Step title="Create a Dodo Payments API key">
    Dans votre tableau de bord Dodo Payments, allez à **Développeurs → Clés API** et générez une nouvelle clé.
  </Step>

  <Step title="Connect in Evendeals">
    Dans votre [tableau de bord Evendeals](https://www.evendeals.com/signin), naviguez vers **Intégrations**, trouvez la carte Dodo Payments et collez votre clé API.
  </Step>

  <Step title="Configure regional discounts">
    Définissez des réductions en pourcentage pour chaque groupe de pays et appuyez sur synchroniser. Evendeals crée automatiquement des coupons dans Dodo Payments.

    <Check>
    Après la synchronisation, ouvrez **Ventes → Réductions** dans votre tableau de bord Dodo Payments pour confirmer l'apparition des coupons générés. Chaque coupon aura un préfixe Evendeals reconnaissable.
    </Check>
  </Step>
</Steps>
