## Qu'est-ce que les modules complémentaires ?

Les modules complémentaires sont des produits supplémentaires que les clients peuvent acheter en plus de leur abonnement principal. Ils sont parfaits pour :

- **Facturation par siège** : Membres d'équipe supplémentaires, licences utilisateur ou utilisateurs simultanés
- **Mises à niveau de fonctionnalités** : Fonctionnalités premium, analyses avancées ou support prioritaire
- **Extensions d'utilisation** : Stockage supplémentaire, appels API ou allocations de bande passante
- **Modules complémentaires de service** : Services professionnels, formation ou heures de consultation

## Avantages clés

- **Modèles de tarification flexibles** : Proposez des plans de base avec des modules complémentaires optionnels pour créer des structures de tarification sophistiquées. Vous pouvez répondre à divers segments de clients avec des mises à niveau qui évoluent au fur et à mesure que les besoins de vos clients changent.
- **Optimisation des revenus** : Augmentez votre revenu moyen par utilisateur (ARPU) en présentant des modules complémentaires pertinents. Cela permet des opportunités de vente incitative naturelles à mesure que les clients ajoutent des fonctionnalités au fil du temps.
- **Gestion simplifiée** : Gérez tous les composants de tarification depuis un seul tableau de bord. Les modules complémentaires sont automatiquement inclus dans les sessions de paiement et la gestion des abonnements.
- **Choix du client** : Permettez aux clients de personnaliser leurs abonnements en sélectionnant uniquement les modules complémentaires dont ils ont besoin, ce qui améliore la satisfaction et réduit le taux de désabonnement.

## Création de modules complémentaires

Les modules complémentaires sont créés en tant que produits séparés dans votre tableau de bord Dodo Payments, puis attachés à vos produits d'abonnement principaux. Cette séparation vous permet de :

- Réutiliser les modules complémentaires sur plusieurs produits d'abonnement
- Gérer les prix de manière indépendante
- Suivre la performance des modules complémentaires séparément
- Mettre à jour les modules complémentaires sans affecter les abonnements de base

### Configuration des modules complémentaires

Lors de la création de modules complémentaires, vous pouvez configurer :

- **Tarification** : Définir un prix unique ou récurrent pour le module complémentaire
- **Cycle de facturation** : Correspondre à votre facturation d'abonnement ou utiliser des cycles différents
- **Limites de quantité** : Définir des quantités minimales et maximales par client
- **Disponibilité** : Contrôler quels produits d'abonnement peuvent utiliser le module complémentaire
- **Paramètres fiscaux** : Configurer les catégories fiscales appropriées

## Exemples d'intégration

### Sessions de paiement avec des modules complémentaires
Lors de la création de sessions de paiement, vous pouvez inclure des modules complémentaires avec des quantités personnalisées :

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    {
      product_id: 'your_subscription_id',
      quantity: 1,
      addons: [
        {
          addon_id: 'your_addon_id',
          quantity: 3 // 3 additional seats
        }
      ]
    }
  ],
  // ... other checkout options
});
```

### Changements de plan avec des modules complémentaires
Modifiez les abonnements existants pour ajouter, supprimer ou mettre à jour des modules complémentaires :

```typescript
// Add add-ons to existing subscription
await client.subscriptions.changePlan('sub_123', {
  product_id: 'prod_new',
  quantity: 1,
  proration_billing_mode: 'difference_immediately',
  addons: [
    { addon_id: 'addon_123', quantity: 2 }
  ]
});

// Remove all existing add-ons
await client.subscriptions.changePlan('sub_123', {
  product_id: 'prod_new',
  quantity: 1,
  proration_billing_mode: 'difference_immediately',
  addons: [] // Empty array removes all existing add-ons
});
```

### Tarification dynamique
Calculez les coûts totaux de manière dynamique en fonction des sélections de modules complémentaires :

```typescript
function calculateTotalCost(basePrice: number, addons: AddonSelection[]) {
  const addonTotal = addons.reduce((sum, addon) => 
    sum + (addon.price * addon.quantity), 0
  );
  return basePrice + addonTotal;
}
```

## Meilleures pratiques

- **Commencez simplement** : Lancez-vous avec 2-3 modules complémentaires de base et élargissez les options en fonction des retours et de l'utilisation des clients.
- **Maintenez la clarté des prix** : Communiquez clairement les prix et la valeur des modules complémentaires, afin que les clients comprennent ce qu'ils obtiennent pour le coût supplémentaire.
- **Testez minutieusement** : Validez les combinaisons de modules complémentaires pour vous assurer que les calculs de prix restent précis et que les flux de paiement fonctionnent sans problème.

### Considérations de conception

- **Proposition de valeur claire** : Chaque module complémentaire doit avoir un avantage clair que les clients peuvent facilement comprendre
- **Regroupement logique** : Regroupez les modules complémentaires liés ensemble dans votre flux de paiement
- **Quantités flexibles** : Permettez aux clients d'ajuster les quantités de modules complémentaires selon leurs besoins
- **Tarification transparente** : Affichez clairement les coûts totaux tout au long du processus de paiement

<Info>
Les modules complémentaires sont un moyen puissant de créer des modèles de tarification flexibles et évolutifs qui grandissent avec vos clients. Commencez par des cas d'utilisation simples et élargissez à mesure que vous apprenez ce qui fonctionne le mieux pour votre entreprise et vos clients.
