## Quels sont les add-ons ?

Les add-ons sont des produits complémentaires que les clients peuvent acheter en plus de leur abonnement principal. Ils sont parfaits pour :

- **Facturation par siège** : Membres d'équipe supplémentaires, licences utilisateur ou utilisateurs simultanés
- **Mises à niveau de fonctionnalités** : Fonctionnalités premium, analyses avancées ou support prioritaire
- **Extensions d'utilisation** : Stockage supplémentaire, appels API ou allocations de bande passante
- **Add-ons de services** : Services professionnels, formations ou heures de conseil

## Avantages clés

- **Modèles de tarification flexibles** : Proposez des formules de base avec des add-ons facultatifs pour créer des structures de tarification sophistiquées. Vous pouvez répondre à des segments de clientèle divers avec des mises à niveau qui évoluent en fonction des besoins de vos clients.
- **Optimisation des revenus** : Augmentez votre revenu moyen par utilisateur (ARPU) en présentant des add-ons pertinents. Cela permet de créer des opportunités d'upsell naturelles au fur et à mesure que les clients ajoutent des fonctionnalités.
- **Gestion simplifiée** : Gérez tous les éléments de tarification depuis un seul tableau de bord. Les add-ons sont automatiquement inclus dans les sessions de paiement et la gestion des abonnements.
- **Choix du client** : Permettez aux clients de personnaliser leurs abonnements en sélectionnant uniquement les add-ons dont ils ont besoin, ce qui augmente la satisfaction et réduit le churn.

## Création d'add-ons

Les add-ons sont créés comme des produits distincts dans votre tableau de bord Dodo Payments, puis rattachés à vos principaux produits d'abonnement. Cette séparation vous permet de :

- Réutiliser les add-ons sur plusieurs produits d'abonnement
- Gérer les tarifs indépendamment
- Suivre les performances des add-ons séparément
- Mettre à jour les add-ons sans affecter les abonnements de base

### Configuration des add-ons

Lors de la création d'add-ons, vous pouvez configurer :

- **Tarification** : Définissez le montant de l’add-on (`price`) dans la plus petite unité monétaire. L’add-on est facturé selon le cycle de l’abonnement parent
- **Devise** : Définissez le prix de base dans n’importe quelle devise que Dodo Payments peut facturer. Le sélecteur de devises avec recherche place **USD, GBP, EUR et INR** en tête de liste ; les clients dont la devise de base est différente sont facturés via [Adaptive Currency](/features/adaptive-currency)
- **Quantité** : Les clients choisissent une quantité lorsque l’add-on est associé à un abonnement
- **Disponibilité** : Contrôlez quels produits d’abonnement peuvent utiliser l’add-on
- **Paramètres fiscaux** : Configurez l’élément `tax_category` approprié

## Exemples d'intégration

### Sessions de paiement avec add-ons
Lors de la création de sessions de paiement, vous pouvez inclure des add-ons avec des quantités personnalisées :

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    {
      product_id: 'your_subscription_id',
      quantity: 1,
      addons: [
        {
          addon_id: 'your_addon_id',
          quantity: 3 // 3 additional seats
        }
      ]
    }
  ],
  // ... other checkout options
});
```

<Tip>
Pour permettre aux clients d'ajouter ou de retirer eux-mêmes des compléments sur la page de paiement, définissez le drapeau de fonctionnalité [`allow_editing_addons`](/developer-resources/checkout-session#optional-fields) sur `true` lors de la création de la session. Par défaut, il est sur `false` et ne s'applique qu'aux produits par abonnement.

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'your_subscription_id', quantity: 1 }],
  feature_flags: {
    allow_editing_addons: true // customers can edit add-ons at checkout
  },
});
```

</Tip>

### Modifications de plan avec compléments
Modifiez les abonnements existants pour ajouter, retirer ou mettre à jour des compléments :

```typescript
// Add add-ons to existing subscription
await client.subscriptions.changePlan('sub_123', {
  product_id: 'prod_new',
  quantity: 1,
  proration_billing_mode: 'difference_immediately',
  addons: [
    { addon_id: 'addon_123', quantity: 2 }
  ]
});

// Remove all existing add-ons
await client.subscriptions.changePlan('sub_123', {
  product_id: 'prod_new',
  quantity: 1,
  proration_billing_mode: 'difference_immediately',
  addons: [] // Empty array removes all existing add-ons
});
```

### Tarification dynamique
Calculez les coûts totaux dynamiquement en fonction des sélections de compléments :

```typescript
function calculateTotalCost(basePrice: number, addons: AddonSelection[]) {
  const addonTotal = addons.reduce((sum, addon) => 
    sum + (addon.price * addon.quantity), 0
  );
  return basePrice + addonTotal;
}
```

## Meilleures pratiques

- **Commencez simplement** : Lancez avec 2-3 compléments principaux et élargissez les options en fonction des retours clients et de l'utilisation.
- **Conservez la clarté des prix** : Communiquez clairement le prix et la valeur des compléments, afin que les clients comprennent ce qu'ils obtiennent pour le coût supplémentaire.
- **Testez minutieusement** : Validez les combinaisons de compléments pour garantir que les calculs de prix restent précis et que les flux de paiement fonctionnent sans accroc.

### Considérations de design

- **Proposition de valeur claire** : Chaque complément doit avoir un avantage clair que les clients peuvent facilement comprendre
- **Regroupement logique** : Regroupez les compléments liés ensemble dans votre flux de paiement
- **Quantités flexibles** : Permettez aux clients d'ajuster les quantités de compléments selon leurs besoins
- **Transparence des prix** : Affichez clairement les coûts totaux tout au long du processus de paiement

<Info>
Les compléments sont un moyen puissant de créer des modèles de tarification flexibles et évolutifs qui évoluent avec vos clients. Commencez avec des cas d'utilisation simples et développez-vous au fur et à mesure que vous apprenez ce qui fonctionne le mieux pour votre entreprise et vos clients.
</Info>
