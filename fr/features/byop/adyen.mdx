<Note>
Ce guide s'applique lorsque vous connectez **Adyen** en tant que votre propre processeur via [Apportez Votre Propre Processeur (BYOP)](/features/byop). [Contactez-nous](mailto:founders@dodopayments.com) si vous avez besoin d'aide.
</Note>

## Activer l'accès aux données brutes de carte

Avant que Dodo puisse acheminer les paiements via Adyen, votre compte Adyen doit avoir l'**accès aux données brutes de carte** activé. Adyen exige la conformité PCI DSS pour cela. Puisque **Dodo Payments gère les données brutes de carte pour vous** et est **conforme PCI DSS de niveau 1**, vous fournissez à Adyen l'**Attestation de Conformité (AOC) de Dodo Payments** — vous n'avez pas besoin de votre propre certification.

<Card title="Dodo Payments PCI DSS Attestation of Compliance (AOC)" icon="file-shield" href="https://pub-2a89184e4c954b599464449d23f506bb.r2.dev/dodo-payments-pci-dss-aoc.pdf">
Téléchargez l'AOC actuelle de Dodo Payments et soumettez-la à l'assistance d'Adyen pour activer l'accès aux données brutes de carte.
</Card>

Contactez le support d'Adyen pour demander l'accès aux données de carte pour votre compte marchand, en joignant l'AOC mentionnée ci-dessus.

## Ce dont vous aurez besoin

Pour connecter Adyen dans **Paramètres → BYOP**, rassemblez trois valeurs de votre espace client Adyen :

| Valeur | Source |
|-------|---------------------|
| **clé API** | Développeurs → Identifiants API |
| **Compte marchand** | Identifiant de votre compte marchand Adyen |
| **Clé HMAC** | Générée lors de la configuration du webhook |

<Info>
Adyen garde séparées les identifiants **test** (`ca-test.adyen.com`) et **live** (`ca-live.adyen.com`). Générez les identifiants dans l'environnement correspondant au mode que vous configurez dans Dodo.
</Info>

## Étape 1 : Générer une clé API

<Steps>
<Step title="Open API credentials">
Dans l'espace client Adyen, allez à **Développeurs → Identifiants API**. Vous avez besoin du rôle **Gérer les identifiants API** ou **Admin marchand**.
</Step>

<Step title="Select your credential">
Choisissez l'onglet **Paiements** et sélectionnez votre nom d'utilisateur de credential (il ressemble à `ws_123456@Company.YourCompanyAccount`).
</Step>

<Step title="Generate the key">
Allez dans **Paramètres serveur → Authentification**, ouvrez l'onglet **Clé API**, et sélectionnez **Générer une clé API**.
</Step>

<Step title="Copy it immediately">
Copiez et stockez la clé en toute sécurité ; vous ne pourrez pas la copier à nouveau après avoir quitté la page. Une clé nouvellement générée est activée immédiatement, et l'ancienne clé continue de fonctionner pendant 24 heures.
</Step>
</Steps>

## Étape 2 : Trouver votre compte marchand

Votre **compte marchand** est l'identifiant du compte qu'Adyen utilise pour traiter vos transactions. Il est affiché dans le sélecteur de compte en haut de l'espace client (par exemple, `YourCompany_ECOM`). Vous le collerez dans le champ **Compte marchand** dans Dodo.

## Étape 3 : Configurer le webhook et la clé HMAC

Dodo génère une URL **Endpoint du Webhook** lorsque vous enregistrez la connexion Adyen. Ajoutez-la comme un webhook dans Adyen et générez une clé HMAC. Vous avez besoin du rôle **Admin marchand** ou **Intégrateur technique marchand**.

<Steps>
<Step title="Create a webhook">
Dans l'espace client, allez à **Développeurs → Webhooks** et sélectionnez **Créer un nouveau webhook**. Dans la liste, sélectionnez **Ajouter** pour le type de webhook **Standard**.
</Step>

<Step title="Configure the webhook">
- Saisissez une **Description**.
- Activez **Activé** pour l'activer.
- Sous **Configuration du serveur**, collez l'URL **Endpoint du Webhook** que Dodo a générée dans le champ **URL** (elle doit être en HTTPS et accessible au public).
</Step>

<Step title="Generate the HMAC key">
Sous **Sécurité**, dans la section **Clé HMAC**, sélectionnez **Générer** pour créer une nouvelle clé HMAC. Copiez-la et stockez-la en toute sécurité ; vous ne pourrez plus la copier plus tard. Ensuite, sélectionnez **Enregistrer la configuration**.
</Step>

<Step title="Paste the HMAC key into Dodo">
Retournez dans **Paramètres → BYOP**, collez la clé HMAC dans le champ **Secret de signature du Webhook** pour terminer la connexion.

<Card title="Set up BYOP" icon="shuffle" href="/features/byop">
Suivez le flux complet de configuration Apportez Votre Propre Processeur.
</Card>
</Step>
</Steps>

<Tip>
Après avoir enregistré, utilisez **Vérifier la connexion** dans Dodo pour effectuer un appel test contre Adyen et vérifier que votre clé API, compte marchand et clé HMAC sont valides avant de passer en production.
</Tip>

## Questions fréquentes

<AccordionGroup>
<Accordion title="What is the HMAC key for?">
Adyen signe chaque webhook avec une signature HMAC pour que le récepteur puisse vérifier l'intégrité et l'origine de la notification. Dodo utilise la clé HMAC que vous fournissez pour valider les webhooks de votre compte Adyen.
</Accordion>

<Accordion title="I lost my API key or HMAC key, what now?">
Aucune ne peut être récupérée après création. Générez une nouvelle clé API sous **Développeurs → Identifiants API**, ou une nouvelle clé HMAC dans les paramètres du webhook, puis mettez à jour la valeur dans **Paramètres → BYOP**.
</Accordion>

<Accordion title="Do test and live use the same credentials?">
Non. Générez des identifiants dans l'environnement correspondant, test (`ca-test.adyen.com`) ou live (`ca-live.adyen.com`), et configurez-les dans le mode correspondant dans Dodo.
</Accordion>
</AccordionGroup>
