<Info>
La devise adaptative vous permet d'afficher des prix localisés et d'accepter des paiements dans les devises locales des clients. Cela réduit la friction lors du paiement et renforce la confiance.
</Info>

## Qu'est-ce que la Monnaie Adaptative ?

Adaptive Currency affiche les prix des produits dans la devise locale du client au lieu de les afficher uniquement dans votre devise de base. Lorsqu'elle est activée, le paiement utilise par défaut la devise locale détectée pour les pays pris en charge, avec la possibilité de revenir à votre devise de base.

Votre devise de base correspond à la devise dans laquelle vous avez fixé le prix du produit ou du module complémentaire — il peut s'agir de n'importe quelle devise que Dodo Payments peut facturer, et pas uniquement de l'USD. Adaptive Currency convertit ce prix de base selon les taux de change en temps réel. Pour définir plutôt votre propre prix fixe par devise ou par pays, consultez la [tarification localisée](/features/localized-pricing).

## Principaux avantages

- **Expérience de paiement localisée** : Les prix s'affichent par défaut dans la devise locale.
- **Plus de méthodes de paiement** : Déverrouille les méthodes de paiement disponibles pour la devise locale.
- **Remboursements dans la même devise** : Remboursez le client dans la devise avec laquelle il a payé.

## Activer la devise adaptative

<Steps>
<Step title="Open Settings">
Connectez-vous à votre tableau de bord marchand et allez dans Paramètres → Entreprise.
</Step>

<Step title="Toggle Adaptive Pricing">
Activez le basculement des prix adaptatifs. Vous pouvez le désactiver à tout moment.

<Warning>
Les modifications s'appliquent uniquement aux transactions futures.
</Warning>
</Step>

<Step title="Confirm and Save">
Enregistrez vos paramètres.

<Check>
Vérifiez qu'un test de paiement affiche les prix dans votre devise locale lorsqu'elle est prise en charge.
</Check>
</Step>
</Steps>

## Expérience client

1. **Détection** : Le système détecte le pays du client à partir de l'adresse de facturation.
2. **Sélection de la devise** : Si le pays est pris en charge, les prix s'affichent par défaut dans la devise locale. Les clients peuvent revenir à votre devise de base.
3. **Moyens de paiement** : Les moyens de paiement locaux s'affichent lorsque cela est applicable.
4. **Paiement** : Le paiement est effectué dans la devise sélectionnée.

## Conversion et frais

Adaptive Currency facture le client dans sa devise locale en utilisant les derniers taux de change.

- **Vous payez** : 0 % (par défaut) ou 2 à 4 % (lorsque les frais inclus sont activés)
- **Vos clients paient** : 2 à 4 % selon la valeur de la commande (par défaut) ou 0 % (lorsque les frais inclus sont activés)

Frais par palier appliqués au paiement :

- 4 % pour les commandes de moins de 500 $
- 3 % pour 500 à 1 500 $
- 2 % pour plus de 1 500 $

### Choisissez qui assume les frais

Par défaut, les frais de devise adaptative sont ajoutés au prix affiché et supportés par le client. Avec le paramètre **Frais inclus**, vous pouvez absorber les frais vous-même : le client voit le même prix en devise locale que toujours, et les frais sont déduits de votre règlement.

<Steps>
<Step title="Enable Adaptive Pricing">
Accédez à **Paramètres → Entreprise** et activez le basculement des prix adaptatifs si vous ne l'avez pas déjà fait.
</Step>

<Step title="Toggle Fees Inclusive">
Une fois les prix adaptatifs activés, activez le sous-basculement **Frais inclus** dans la même section.
</Step>
</Steps>

| Mode | Le client voit | Le marchand reçoit |
|------|---------------|-------------------|
| Exclusif (par défaut) | Prix local + frais de 2 à 4 % en plus | Prix de base complet |
| Inclusif | Prix local (inchangé) | Prix de base moins le frais de 2 à 4 % |

Vous pouvez également remplacer la valeur par défaut du marchand pour chaque requête en transmettant `adaptive_currency_fees_inclusive` (booléen) lors d’un paiement ponctuel, d’un abonnement à la demande (`on_demand.adaptive_currency_fees_inclusive`), d’un prélèvement d’abonnement ou d’un changement de plan. Ce paramètre n’est pas accepté dans les sessions de paiement :

```typescript
const payment = await client.payments.create({
  product_cart: [{ product_id: 'pdt_abc', quantity: 1 }],
  customer: { customer_id: 'cus_123' },
  billing: { country: 'US' },
  adaptive_currency_fees_inclusive: true, // override the business setting for this payment
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Les transactions INR → INR sont toujours traitées comme inclusives, quelles que soient les configurations d'entreprise ou les substitutions par demande.
</Info>

<Info>
Lorsqu'une règle de [Tarification localisée](/features/localized-pricing) correspond, la transaction est toujours traitée comme inclusive, indépendamment de votre paramètre **Frais inclus** ou de toute substitution par requête. Le client paie exactement le montant localisé que vous avez défini, et les frais de conversion sont déduits de votre règlement.
</Info>

## Remboursements et ajustements

Dodo Payments émet les remboursements dans la devise avec laquelle le client a effectué son paiement initial, en utilisant le dernier taux de change. Le montant dans votre devise de base reste fixe sur votre tableau de bord, vos factures et dans le remboursement. Cela signifie que le client peut recevoir un montant supérieur ou inférieur au montant initial dans la devise locale, selon les variations du taux de change.

<Info>
Les frais de devise adaptative, qui sont généralement les frais de change, ne sont pas remboursés.
</Info>

**Exemple de remboursement**

1. Vous vendez un produit pour 100 USD avec la devise adaptative activée.
2. Un client canadien voit 137 CAD à un taux de change de 1,37 CAD pour 1 USD et réalise l'achat.
3. Nous traitons le paiement, convertissant 137 CAD en 100 USD pour votre règlement.
4. Plus tard, le taux de change passe à 1,40 CAD pour 1 USD et vous émettez un remboursement intégral.
5. Nous déduisons 100 USD et remboursons 140 CAD au client.

## Factures et fiscalité

- Les factures n'affichent que le montant en devise de règlement.
- Les taxes et les frais de plateforme sont calculés sur le montant en devise de règlement.
- Exemple : une vente de 10 $ convertie en 36 AED est toujours affichée comme 10 $ sur le tableau de bord et les factures.

<Info>
Tous les montants sont arrondis selon la logique d'arrondi interne de Dodo Payments.
</Info>

## Exemples d'intégration

**Sessions de paiement avec devise de facturation**

Passez `billing_currency` pour définir explicitement la devise de facturation pour la session.

<Info>
Lorsque les prix adaptatifs sont désactivés, `billing_currency` est ignoré.
</Info>

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    {
      product_id: 'prod_one_time_or_subscription',
      quantity: 1
    }
  ],
  billing_currency: 'AED',
  return_url: 'https://example.com/return'
});
```
