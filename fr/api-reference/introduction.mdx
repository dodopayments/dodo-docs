## Gestion des clés API et authentification

<Steps>
<Step title="Access API Keys">
Accédez à **Developer → API Keys** dans votre dashboard pour gérer vos clés.
</Step>

<Step title="Generate a New Key">
Sélectionnez **Add API Key**, saisissez un nom descriptif et configurez l’accès en écriture :

- **Enable write access** (coché) : autorisations complètes de lecture et d’écriture pour toutes les opérations API
- **Enable write access** (non coché) : accès en lecture seule : permet uniquement de récupérer des données (paiements, abonnements, clients, produits). Impossible de créer ou de modifier des ressources.

<Tip>
Désactivez « Enable write access » pour les intégrations avec le dashboard, les outils d’analytique et tout système qui doit uniquement consulter les données sans les modifier.
</Tip>
</Step>

<Step title="Store Your Key Securely">
Copiez immédiatement la clé générée et veillez à la stocker de manière sécurisée.
</Step>

<Step title="Authenticate Your API Requests">
Utilisez vos clés API pour authentifier toutes les requêtes. Appliquez le format d’autorisation suivant :

```bash 
Authorization: Bearer YOUR_API_KEY
```

<Warning>
N’exposez jamais vos clés API secrètes dans du code côté client ou des dépôts publics.
</Warning>
</Step>
</Steps>

## Limites de débit

Notre API utilise un système de limitation du débit à deux fenêtres avec protection contre les rafales. Les limites sont appliquées en fonction de votre méthode d’authentification et de votre niveau d’activité.

### Limites par défaut (niveau 0)

| Fenêtre | Limite |
|--------|-------|
| Par seconde (rafale) | 40 requêtes |
| Par minute (soutenue) | 240 requêtes |

### Niveaux d’activité

Des limites de débit plus élevées sont disponibles pour les entreprises ayant des besoins accrus en API :

| Niveau | Rafale (par seconde) | Soutenue (par minute) |
|------|-------------------|------------------------|
| Niveau 0 (par défaut) | 40 | 240 |
| Niveau 1 | 100 | 1 000 |
| Niveau 2 | 500 | 5 000 |

<Tip>
Contactez le support pour faire passer votre entreprise à un niveau de limite de débit supérieur.
</Tip>

### Requêtes non authentifiées

Les requêtes sans en-têtes d’authentification valides sont limitées en fonction de l’adresse IP :

| Fenêtre | Limite |
|--------|-------|
| Par seconde (rafale) | 20 requêtes |
| Par minute (soutenue) | 100 requêtes |

### En-têtes de limite de débit

Surveillez votre utilisation avec ces en-têtes de réponse :

- `X-RateLimit-Limit` - Nombre maximal de requêtes autorisées
- `X-RateLimit-Remaining` - Nombre de requêtes restantes dans la fenêtre actuelle
- `X-RateLimit-Reset` - Heure de réinitialisation de la limite de débit

<Note>
Lorsque vous dépassez les limites de débit, l’API renvoie une réponse `429 Too Many Requests`. Implémentez un backoff exponentiel dans votre logique de nouvelle tentative.
</Note>
