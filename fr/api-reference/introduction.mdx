## Gestion des clés API et authentification

<Steps>
<Step title="Accéder aux clés API">
Naviguez vers **Développeur → Clés API** dans votre tableau de bord pour gérer vos clés.
</Step>

<Step title="Générer une nouvelle clé">
Sélectionnez **Ajouter une clé API**, fournissez un nom descriptif et configurez l'accès en écriture :

- **Activer l'accès en écriture** (coché) : Pleins droits de lecture et d'écriture pour toutes les opérations API
- **Activer l'accès en écriture** (décoché) : Accès en lecture seule - peut uniquement récupérer des données (paiements, abonnements, clients, produits). Ne peut pas créer ou modifier des ressources.

<Tip>
Décochez "Activer l'accès en écriture" pour les intégrations de tableau de bord, les outils d'analyse et tout système qui a seulement besoin de visualiser des données sans apporter de modifications.
</Tip>
</Step>

<Step title="Stockez votre clé en toute sécurité">
Copiez la clé générée immédiatement et assurez-vous qu'elle est stockée en toute sécurité.
</Step>

<Step title="Authentifiez vos requêtes API">
Utilisez vos clés API pour authentifier toutes les requêtes. Appliquez le format d'autorisation suivant :

```bash 
Authorization: Bearer YOUR_API_KEY
```

<Warning>
Ne jamais exposer vos clés API secrètes dans le code côté client ou dans des dépôts publics.
</Warning>
</Step>
</Steps>

## Limites de taux

Notre API utilise un système de limitation de débit à double fenêtre avec protection contre les pics. Les limites sont appliquées en fonction de votre méthode d'authentification et de votre niveau commercial.

### Limites par défaut (Niveau 0)

| Fenêtre | Limite |
|--------|-------|
| Par seconde (Pic) | 40 requêtes |
| Par minute (Soutenue) | 240 requêtes |

### Niveaux d'entreprise

Des limites de débit plus élevées sont disponibles pour les entreprises ayant des besoins API accrus :

| Niveau | Pic (par seconde) | Soutenue (par minute) |
|------|-------------------|------------------------|
| Niveau 0 (Par défaut) | 40 | 240 |
| Niveau 1 | 100 | 1,000 |
| Niveau 2 | 500 | 5,000 |

<Tip>
Contactez le support pour mettre à niveau votre entreprise vers un niveau de limite de débit plus élevé.
</Tip>

### Requêtes non authentifiées

Les requêtes sans en-têtes d'authentification valides sont limitées par adresse IP :

| Fenêtre | Limite |
|--------|-------|
| Par seconde (Pic) | 20 requêtes |
| Par minute (Soutenue) | 100 requêtes |

### En-têtes de limite de débit

Surveillez votre utilisation avec ces en-têtes de réponse :

- `X-RateLimit-Limit` - Nombre maximum de requêtes autorisées
- `X-RateLimit-Remaining` - Requêtes restantes dans la fenêtre actuelle
- `X-RateLimit-Reset` - Moment où la limite de débit se réinitialise

<Note>
Lorsque vous dépassez les limites de débit, l'API retourne une réponse `429 Too Many Requests`. Implémentez un retour exponentiel dans votre logique de réessai.
</Note>
