---
title: Accorder la Licence Clé
description: Remplir manuellement une attribution de clé de licence en attente
  en fournissant la valeur de la clé. Insère la clé, la livre au client par
  email, et passe l'attribution à livrée.
keywords:
  - Dodo Payments
  - Référence API
  - API REST
  - accorder clé de licence
  - fulfillment manuel
openapi: post /grants/{grant_id}/license-key
---

<Info>
Utilisez cet endpoint uniquement pour les grants créés sous un entitlement License Key avec `fulfillment_mode: manual`. Le grant doit avoir le statut `Pending` et aucune clé ne doit lui être associée. Consultez [Manual Fulfillment](/features/license-keys#manual-fulfillment) et le [Manual License Key Fulfillment Integration Guide](/developer-resources/manual-license-key-fulfillment) pour connaître le flux complet.
</Info>
