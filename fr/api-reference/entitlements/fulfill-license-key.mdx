---
title: Accorder la Licence Clé
description: Remplir manuellement une attribution de clé de licence en attente
  en fournissant la valeur de la clé. Insère la clé, la livre au client par
  email, et passe l'attribution à livrée.
keywords:
  - Dodo Payments
  - Référence API
  - API REST
  - accorder clé de licence
  - fulfillment manuel
openapi: post /grants/{grant_id}/license-key
---

<Info>
Utilisez ce point de terminaison uniquement pour les attributions créées sous un droit de Clé de Licence avec `fulfillment_mode: manual`. L'attribution doit être en statut `pending` sans clé attachée. Voir [Fulfillment Manuel](/features/license-keys#manual-fulfillment) et le [Guide d'Intégration de Fulfillment Manuel de Clé de Licence](/developer-resources/manual-license-key-fulfillment) pour le déroulement complet.
</Info>
