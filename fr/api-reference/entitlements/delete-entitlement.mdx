<Warning>
Supprimer un droit est un **effacement en douceur qui masque les autorisations existantes dans le portail client**. Cela ne révoque pas l'accès côté plateforme :

- Les autorisations liées au droit restent dans la base de données et conservent leur état actuel `status`.
- Les rôles Discord, l'accès collaborateur à GitHub, l'accès à Notion, l'adhésion à Telegram, les clés de licence et les URL de fichiers numériques restent valides.
- Aucun webhook `entitlement_grant.revoked` n'est émis, et `revoked_at` / `revocation_reason` ne sont pas définis.

Les clients cessent de voir ces autorisations dans leur portail client, mais leur accès sur la plateforme sous-jacente se poursuit jusqu'à ce que le cycle de vie de l'abonnement/paiement le révoque (annulation, remboursement) ou que vous révoquiez chaque autorisation manuellement via [`DELETE /entitlements/{id}/grants/{grant_id}`](/api-reference/entitlements/revoke-grant).

Si vous devez complètement couper l'accès, révoquez d'abord les autorisations, puis supprimez le droit.
</Warning>
