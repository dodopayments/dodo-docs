## Gestion des échecs de paiement

Utilisez le paramètre `on_payment_failure` pour contrôler ce qui se passe lorsque le paiement du changement de plan échoue :

| Valeur | Comportement |
|-------|----------|
| `prevent_change` | Maintenir l'abonnement sur le plan actuel jusqu'à ce que le paiement réussisse. Le changement de plan reste en attente. |
| `apply_change` | Appliquer le changement de plan immédiatement, peu importe le résultat du paiement. C'est le paramètre par défaut. |

<Info>
Si `on_payment_failure` n'est pas spécifié, le comportement par défaut utilise votre paramètre de niveau entreprise configuré dans le tableau de bord.
</Info>

<Tip>
Utilisez `prevent_change` pour des mises à niveau critiques où vous souhaitez garantir le paiement avant d'accorder l'accès aux fonctionnalités premium.
</Tip>
