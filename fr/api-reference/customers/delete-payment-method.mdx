Supprimer une méthode de paiement enregistrée du compte d'un client. Utilisez ceci pour supprimer les méthodes de paiement obsolètes ou indésirables.

<Warning>
Vous ne pouvez pas supprimer un moyen de paiement utilisé par un abonnement actif. L’API renvoie `409 Conflict` avec `Payment method is in use by an active subscription`. Transférez d’abord l’abonnement vers un autre moyen de paiement à l’aide de [Mettre à jour le moyen de paiement](/api-reference/subscriptions/update-payment-method), puis supprimez l’ancien.
</Warning>

Une suppression réussie renvoie `204 No Content`.

## Cas d’utilisation

- **Demande du client** : Supprimer un moyen de paiement que le client ne souhaite plus conserver
- **Cartes expirées** : Nettoyer les moyens de paiement dont les informations de carte ont expiré
- **Sécurité** : Supprimer immédiatement les moyens de paiement compromis
