Supprimer une méthode de paiement enregistrée du compte d'un client. Utilisez ceci pour supprimer les méthodes de paiement obsolètes ou indésirables.

<Warning>
Si la méthode de paiement supprimée est la seule enregistrée pour un abonnement actif, celui-ci peut ne pas se renouveler lors du prochain cycle de facturation. Assurez-vous que le client dispose d'une méthode de paiement alternative avant de supprimer.
</Warning>

## Cas d'utilisation

- **Demande du client** : Retirer une méthode de paiement que le client ne souhaite plus conserver
- **Cartes expirées** : Nettoyer les méthodes de paiement avec des détails de carte expirés
- **Sécurité** : Supprimer immédiatement les méthodes de paiement compromises
