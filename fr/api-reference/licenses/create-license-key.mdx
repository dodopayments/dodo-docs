<Info>
Cet endpoint importe une clé que vous possédez déjà — `key`, `customer_id` et `product_id` sont tous obligatoires. Il ne génère pas de valeur de clé pour vous. L’importation d’une `key` qui existe déjà renvoie `409 Conflict`.
</Info>

<Info>
Les clés de licence créées ou mises à jour via l’API ne déclenchent pas de notifications par e-mail aux clients. Si vous devez informer les clients au sujet de leur clé de licence, vous devez gérer cela séparément dans votre application.
</Info>
