<Warning>
**API obsolète** : Les clés de licence sont désormais gérées via le système [Entitlements](/features/entitlements/introduction). Utilisez [List Grants](/api-reference/entitlements/list-grants) (filtrez avec `integration_type=license_key`) pour récupérer la subvention d'une clé et ses détails `license_key`. Ce point de terminaison sera supprimé dans une prochaine version.
</Warning>
