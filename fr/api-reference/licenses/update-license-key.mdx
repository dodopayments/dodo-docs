<Warning>
**API obsolète** : Les clés de licence sont maintenant gérées via le système [Entitlements](/features/entitlements/introduction). Configurez les limites et durées d'activation sur le [droit de clé de licence](/api-reference/entitlements/update-entitlement), et utilisez [Révoquer la concession](/api-reference/entitlements/revoke-grant) pour désactiver la clé d'un client. Ce point de terminaison sera supprimé dans une future version.
</Warning>

<Info>
La mise à jour d'une clé de licence via l'API ne déclenche pas de notifications par email au client.
</Info>
