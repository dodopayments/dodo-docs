<Warning>
**API obsolète**: Les clés de licence sont désormais gérées via le système des [Droits](/features/entitlements/introduction). Utilisez [Lister les Concessions Client](/api-reference/entitlements/list-customer-grants) pour lister les clés de licence émises (filtrer avec `integration_type=license_key`); chaque concession contient ses détails `license_key`. Ce point de terminaison sera supprimé dans une version future.
</Warning>
