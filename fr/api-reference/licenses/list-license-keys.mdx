<Warning>
**API déconseillée** : Les clés de licence sont désormais gérées via le système [Entitlements](/features/entitlements/introduction). Utilisez [List Grants](/api-reference/entitlements/list-grants) pour lister les clés de licence émises (filtrez avec `integration_type=license_key`); chaque octroi contient ses détails `license_key`. Ce point de terminaison sera supprimé dans une future version.
</Warning>
