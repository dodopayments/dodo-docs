## Så fastställs ditt behöriga land

Behörigheten baseras på **landet som utfärdade den statligt utfärdade identitetshandling som du verifierar dig med**, inte på var ditt företag är registrerat eller var du betalar skatt.

| Kontotyp | Vems identitetshandling avgör behörigheten |
| --- | --- |
| **Privatperson** | Din egen statligt utfärdade ID-handling |
| **Registrerad juridisk person** | Den statligt utfärdade ID-handlingen för varje styrelseledamot och verklig huvudman, utöver registreringslandet |

<Warning>
Att registrera ett företag i ett land som stöds gör inte automatiskt ett konto behörigt. Om en styrelseledamot eller verklig huvudman endast kan verifiera sig med en ID-handling som utfärdats i ett land som inte finns med nedan, kan kontot inte onboardas.
</Warning>

Skatterättslig hemvist, uppehållstillstånd och ett lokalt bankkonto är alla användbara, men inget av dem ersätter en statligt utfärdad ID-handling från ett land på listan.

<Info>
Osäker på hur detta gäller dig? Kontakta [support@dodopayments.com](mailto:support@dodopayments.com) innan du påbörjar din integration, så att du inte bygger utifrån ett resultat som inte kan godkännas.
</Info>

<Note>
Denna policy gäller för alla landsbeteckningar som görs den 23 mars 2026 eller senare. Merchants som tar emot tjänster i länder som stöddes före detta datum påverkas inte, såvida det berörda landet inte omfattas av aktiva sanktioner eller regulatoriska begränsningar. I sådana fall förbehåller sig Dodo Payments rätten att upphöra med supporten.
</Note>

<Note>
Denna lista uppdateras regelbundet för att återspegla FATF-, OFAC-, FN- och EU-direktiv om AML/CFT. Alla merchants ansvarar för att säkerställa fortlöpande efterlevnad.

Utbetalningar stöds endast i de länder och regioner som anges ovan. Om ditt land inte finns med är utbetalningar för närvarande inte tillgängliga från den platsen.

Denna lista kan ändras över tid i linje med regulatoriska krav och efterlevnadskrav, och vi kan inte erbjuda utbetalningar utanför de regioner som stöds.

Merchant-konton stöds endast där KYC-dokumentation utfärdas i de länder som anges ovan.
</Note>
