Spåra kundresor från din butik genom kassan till slutförandet av köpet. Dodo Payments integreras med Google Analytics 4, Google Tag Manager och Meta Pixel för att ge omfattande analyser över alla dina värdförda sidor.

<Info>
Analysspårning aktiveras automatiskt på din butiksfront, kassasidor och kundportal så snart du lägger till dina spårnings-ID:i instrumentpanelen.
</Info>

<Warning>
Annonsblockerare i kundernas webbläsare kan förhindra att analysspårning fungerar för vissa besökare på din butik.
</Warning>

## Komma igång

<Steps>
<Step title="Öppna företagsinställningar">
  I din Dodo Payments-instrumentpanel, navigera till **Inställningar** och scrolla ner till **Analys**-sektionen.
</Step>

<Step title="Aktivera din spårningsplattform">
  Aktivera den analysplattform du vill använda och ange ditt spårnings-ID:
  - **Google Analytics**: Ange ditt mät-ID (format: `G-XXXXXXXXXX`)
  - **Google Tag Manager**: Ange ditt container-ID (format: `GTM-XXXXXXX`)
  - **Meta Pixel**: Ange ditt pixel-ID (numeriskt, 10-20 siffror)
</Step>

<Step title="Spara dina inställningar">
  Klicka på **Spara** för att tillämpa din spårningskonfiguration.
</Step>

<Step title="Verifiera spårning">
  Besök din butik eller skapa en testkassa för att verifiera att händelser spåras i din analysinstrumentpanel.
</Step>
</Steps>

## Google Analytics 4

[Google Analytics 4](https://marketingplatform.google.com/about/analytics/) erbjuder omfattande webbanalys med e-handelsräkningsfunktioner. Med Dodo Payments integration kan du spåra hela kundresan från att bläddra i din butik till att slutföra ett köp.

### Lägg till ditt Google Analytics mät-ID

1. I Google Analytics, gå till **Admin** → **Data Streams** → välj din webbström
2. Kopiera **mät-ID** (börjar med `G-`)
3. I Dodo Payments-instrumentpanelen, gå till **Inställningar** → **Analys**
4. Aktivera **Google Analytics** och klistra in ditt mät-ID
5. Klicka på **Spara**

<Tip>
Om du inte har ett Google Analytics-konto ännu, följ [Google's setup guide](https://support.google.com/analytics/answer/9304153) för att skapa ett.
</Tip>

### Händelser som spåras i Google Analytics

Vi spårar följande händelser i din värdförda butik och kassasidor. Händelsedata inklusive produktinformation, transaktionstotaler och valuta skickas med varje händelse.

#### Butikshändelser

| Händelse | Beskrivning |
|-------|-------------|
| `view_item_list` | Utlöses när butikssidan laddas med produkter |
| `select_item` | Utlöses när en kund klickar på en produkt för att påbörja kassan |

#### Kassahändelser

| Händelse | Beskrivning |
|-------|-------------|
| `view_item` | Utlöses när kassasidan laddas |
| `view_cart` | Utlöses när kassan laddas och en variant väljs |
| `apply_discount`* | Utlöses när en giltig rabattkod har tillämpats med framgång |
| `remove_discount`* | Utlöses när en rabattkod tas bort |
| `add_payment_info` | Utlöses när kunden skickar betalningsformuläret |
| `purchase` | Utlöses när betalningen lyckas |

<Note>
`apply_discount` och `remove_discount` är anpassade händelser som inte ingår i [standard Google Analytics e-handels-händelser](https://support.google.com/analytics/answer/9267735).
</Note>

### Använda GA4 med Overlay/Inline Checkout

För att spåra Google Analytics-händelser i overlay eller inline-kassan som är inbäddad på din egen webbplats, behöver du installera Google Analytics spårningskod på din webbplats där kassan är inbäddad.

När den är installerad kommer alla spårningshändelser som listas ovan att skickas till ditt Google Analytics-konto automatiskt - ingen ytterligare konfiguration behövs.

## Google Tag Manager

[Google Tag Manager](https://marketingplatform.google.com/about/tag-manager/) låter dig hantera marknadsförings- och analysetiketter utan att ändra koden. Taggar som distribueras via GTM kommer att utlösas på alla Dodo Payments-värdförda sidor.

### Lägg till ditt GTM Container ID

1. I Google Tag Manager, kopiera ditt **Container ID** (börjar med `GTM-`)
2. I Dodo Payments-instrumentpanelen, gå till **Inställningar** → **Analys**
3. Aktivera **Google Tag Manager** och klistra in ditt Container ID
4. Klicka på **Spara**

<Info>
När du använder GTM kan du konfigurera ytterligare spårning (som Google Ads-konversioner) direkt i din GTM-container. Dodo Payments-integrationen injicerar både GTM-scriptet och noscript-fallback för maximal kompatibilitet.
</Info>

### Använda GTM med Overlay/Inline Checkout

För overlay eller inline-kassan som är inbäddad på din webbplats, installera GTM på din egen webbplats. Kassan kommer att ärva din GTM-konfiguration och utlösa händelser inom den inbäddade ramen.

## Meta Pixel

[Meta Pixel](https://www.facebook.com/business/tools/meta-pixel/) spårar kundaktioner på din butik för att mäta effektiviteten av dina Facebook- och Instagram-annonskampanjer. Spåra konverteringar från annonsklick till slutförande av köp.

### Lägg till ditt Meta Pixel ID

1. I [Meta Events Manager](https://www.facebook.com/events_manager2/), skapa eller välj din pixel
2. Kopiera **Pixel ID** (numeriskt, vanligtvis 15-16 siffror)
3. I Dodo Payments-instrumentpanelen, gå till **Inställningar** → **Analys**
4. Aktivera **Meta Pixel** och klistra in ditt Pixel ID
5. Klicka på **Spara**

<Tip>
Följ Metas [Pixel setup guide](https://www.facebook.com/business/help/952192354843755) om du inte har skapat en Pixel ännu.
</Tip>

### Händelser som spåras med Meta Pixel

Vi spårar följande händelser som visas i din [Meta Events Manager](https://www.facebook.com/events_manager2/). Händelsedata inklusive innehålls-ID, värden och valuta skickas med varje händelse.

<Note>
Händelser kanske inte visas omedelbart i Meta Events Manager - det kan finnas en fördröjning på flera minuter.
</Note>

#### Butikshändelser

| Händelse | Beskrivning |
|-------|-------------|
| `PageView` | Utlöses när butikssidan laddas |
| `ViewContent` | Utlöses när butikssidan laddas med produkter |
| `InitiateCheckout` | Utlöses när en kund klickar på en produkt för att påbörja kassan |

#### Kassahändelser

| Händelse | Beskrivning |
|-------|-------------|
| `PageView` | Utlöses när kassasidan laddas |
| `AddToCart` | Utlöses när kassan laddas och när en variant väljs |
| `ApplyDiscount`* | Utlöses när en giltig rabattkod har tillämpats med framgång |
| `RemoveDiscount`* | Utlöses när en rabattkod tas bort |
| `AddPaymentInfo` | Utlöses när kunden skickar betalningsformuläret |
| `Purchase` | Utlöses när betalningen lyckas |

<Note>
`ApplyDiscount` och `RemoveDiscount` är anpassade händelser som inte ingår i [Metas standardhändelser](https://developers.facebook.com/docs/meta-pixel/reference#standard-events).
</Note>

## Fullständig händelsereferens

Denna tabell visar alla händelser som spåras i både Google Analytics 4 och Meta Pixel:

| Utlösare | GA4-händelse | Meta Pixel-händelse | Plats |
|---------|-----------|------------------|----------|
| Butikssidan laddas | `view_item_list` | `ViewContent` | Butik |
| Kund klickar på produkt | `select_item` | `InitiateCheckout` | Butik |
| Kassasidan laddas | `view_item` | `AddToCart` | Kassan |
| Kundvagn visas/variant vald | `view_cart` | - | Kassan |
| Rabattkod tillämpad | `apply_discount` | `ApplyDiscount` | Kassan |
| Rabattkod borttagen | `remove_discount` | `RemoveDiscount` | Kassan |
| Betalningsformulär skickat | `add_payment_info` | `AddPaymentInfo` | Kassan |
| Betalning lyckad | `purchase` | `Purchase` | Kassan |

## Plattformstäckning

Analysspårning finns tillgänglig på olika Dodo Payments-ytor:

| Yta | Google Analytics 4 | Google Tag Manager | Meta Pixel |
|---------|-------------------|-------------------|------------|
| Butik | Ja | Ja | Ja |
| Kassan (Hostad) | Ja | Ja | Ja |
| Kassan (Overlay/Inline)* | Ja | Ja | Ja |
| Kundportal | Ja | Ja | Nej |

<Info>
*För overlay och inline-kassan, installera spårningskoden på din egen webbplats för fullständig attribuering. Händelser från den inbäddade kassan kommer att spåras automatiskt.
</Info>

## Händelsedata som ingår

Varje spårningshändelse innehåller relevant e-handelsdata för att hjälpa dig analysera kundbeteende:

### Produktdata
- Produkt-ID
- Produktnamn
- Pris
- Valuta
- Kvantitet

### Transaktionsdata (Köphändelser)
- Transaktions-/Betalnings-ID
- Totalt belopp
- Skattebelopp
- Valuta
- Rabatt tillämpad

### Kunddata
- Kund-ID (för återkommande kunder)
- E-post (hashad för integritet där det är tillämpligt)

## Bästa praxis

<AccordionGroup>
<Accordion title="Testa din integration">
Efter att ha lagt till dina spårnings-ID, besök din butik och slutför en testkassa för att verifiera att händelser visas i dina analysinstrumentpaneler. Använd Google Analytics Realtime-rapporter eller Meta Events Managers Test Events-funktion.
</Accordion>

<Accordion title="Använd UTM-parametrar">
Lägg till UTM-parametrar till dina marknadsföringslänkar för att spåra vilka kampanjer som driver konverteringar. Dodo Payments bevarar UTM-parametrar genom hela kassaflödet.
</Accordion>

<Accordion title="Ställ in konverteringsmål">
I Google Analytics, skapa konverteringshändelser för `purchase` för att spåra din konverteringsgrad. I Meta Ads Manager, använd `Purchase`-händelsen som ditt optimeringsmål för kampanjer.
</Accordion>

<Accordion title="Aktivera förbättrad e-handel">
Om du använder Google Tag Manager, överväg att ställa in rapporter för förbättrad e-handel för detaljerad funnelanalys och produktprestandamått.
</Accordion>
</AccordionGroup>

## Felsökning

<AccordionGroup>
<Accordion title="Händelser visas inte i Google Analytics">
- Verifiera att ditt mät-ID är korrekt (format: `G-XXXXXXXXXX`)
- Kontrollera Google Analytics Realtime-rapporter - händelser visas där först
- Säkerställ att växeln är aktiverad i dina Dodo Payments-inställningar
- Vänta några minuter då det kan finnas behandlingsfördröjningar
- Testa i en inkognitoflik för att utesluta annonsblockerare
</Accordion>

<Accordion title="Händelser visas inte i Meta Events Manager">
- Verifiera att ditt Pixel ID är korrekt (numeriskt, 10-20 siffror)
- Använd Meta Pixel Helper-webbläsartillägget för att felsöka
- Kontrollera Test Events-fliken i Events Manager
- Händelser kan ta flera minuter att visas
- Se till att annonsblockerare är inaktiverade under testning
</Accordion>

<Accordion title="GTM-taggar utlöses inte">
- Bekräfta att ditt Container ID är korrekt (format: `GTM-XXXXXXX`)
- Använd GTM Förhandsgranskningsläge för att felsöka taggutlösning
- Kontrollera att utlösare är korrekt konfigurerade i din GTM-container
- Verifiera att containern har publicerats (inte bara i utkast)
</Accordion>

<Accordion title="Overlay/Inline-kassan spåras inte">
- Installera spårningskoden på din egen webbplats först
- Se till att spårningen laddas innan kassa-overlayen öppnas
- Kontrollera webbläsarkonsolen för eventuella JavaScript-fel
- Verifiera att spårning mellan domäner är konfigurerad om du använder GA4
</Accordion>

<Accordion title="Köphändelser visar fel belopp">
- Belopp skickas i den minsta valutakomponenten (cent)
- Verifiera att ditt analysverktyg är konfigurerat för att visa rätt valuta
- Kontrollera om skatt är inklusive/exklusive som förväntat
</Accordion>
</AccordionGroup>
