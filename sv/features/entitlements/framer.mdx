<Info>
Framer-entitlement låser upp en remixlänk till en Framer-mall för betalande kunder. Du laddar upp mallen till Dodo Payments, kopplar rätten till en produkt, och kunderna får en remixlänk som låter dem klona mallen till sitt eget Framer-konto.
</Info>

## Vad som levereras

- En unik remixlänk till Framer-mallen du laddade upp.
- Kunden klickar på länken för att remixa mallen till sin egen Framer-arbetsyta.
- Vid avbokning eller återbetalning blir remix-länken ogiltig.

Vanliga användningsområden inkluderar betalade Framer-mallar för landningssidor, portföljkit och komponentbibliotek.

## Anslut Framer

Framer ansluts implicit första gången du skapar en mallrättighet. Det finns inget separat OAuth-steg.

<Steps>
<Step title="Open Entitlements">
I din Dodo Payments-panel, gå till **Entitlements** och klicka på **+**.
</Step>

<Step title="Pick Framer">
Välj **Framer Template** som integration.
</Step>

<Step title="Grab the remix link from Framer">
Öppna ditt Framer-projekt. Från menyn uppe till vänster, gå till **File → Copy Remix Link**. Detta ger en offentlig remix-URL som låter vem som helst klona projektet till sitt eget Framer-konto — länken som Dodo Payments kommer dela med betalande kunder.
<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">

<img src="/images/entitlements/framer/copy-remix-link.png" alt="Framer File menu with Copy Remix Link option highlighted" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Add the template and create the entitlement">
Tillbaka i Dodo Payments-panelen, välj mallen från **Template**-rullgardinsmenyn. Första gången du gör detta för en ny mall, klistra in remixlänken du kopierade för att registrera den. Ge rättigheten ett **namn** och klicka på **Create Entitlement**.
<Frame>

<img src="/images/entitlements/framer/create.png" alt="Framer template entitlement form with template picker and name field" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Dodo Payments registrerar mallen och returnerar en `framer_template_id` som du kan referera programmatiskt.
</Step>
</Steps>

## Kundflöde

1. Kunden slutför checkout.
2. Dodo Payments skapar ett `Pending`-beviljande och utfärdar en unik remixlänk kopplad till kunden.
3. Beviljandet övergår till `Delivered` när remixlänken har tillhandahållits, och länken inkluderas i kundens e-post och portal.
4. Kunden klickar på länken, loggar in på Framer och remixar mallen.
5. Vid återkallande ogiltigförklaras remixlänken. Kopior som redan har remixats i kundens Framer-konto finns kvar, eftersom Framer inte erbjuder något sätt att återkalla dem.

## Krävd konfiguration

| Fält | Krävd | Beskrivning |
|---|---|---|
| `framer_template_id` | Ja | Mall-ID som returneras när du laddar upp mallen. |

## Skapa via API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Portfolio Kit',
  integration_type: 'framer',
  integration_config: {
    framer_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Portfolio Kit",
    integration_type="framer",
    integration_config={"framer_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Portfolio Kit"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFramer),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFramerConfigParam{
      FramerTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

Se [`entitlement_grant.*` webhook-händelser](/developer-resources/webhooks/intents/entitlement-grant). Framer-beviljanden anländer som `Pending` och övergår till `Delivered` när remixlänken har tillhandahållits.

## Felsökning

<AccordionGroup>
<Accordion title="Customer's remix link doesn't work">
Remix-länken är för engångsbruk och kopplad till kunden. Om de rensade länken innan remixning, återkalla bidraget och återutfärda.
</Accordion>

<Accordion title="Refunded customer still has a remixed copy">
Detta är förväntat. Framer behandlar en remix som kundens eget projekt när det väl är klonat; Dodo Payments gör original-länken ogiltig men kan inte ta bort kopior i kundens konto.
</Accordion>
</AccordionGroup>
