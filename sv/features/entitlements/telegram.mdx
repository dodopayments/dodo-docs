<Info>
Telegramrättigheten ger betalande kunder tillgång till en privat chatt eller kanal. Dodo Payments Telegram-botten genererar en engångsinbjudningslänk för varje kund och tar bort dem vid avbokning.
</Info>

## Vad som levereras

- Beviljandet skapas i `pending` medan botten förbereder inbjudan, sedan övergår den till `delivered` när länken är klar.
- Kunden får en engångsinbjudningslänk för Telegram i sitt leveransmail och kundportal.
- De trycker på länken och boten lägger till dem i den konfigurerade chatten.
- Vid avbokning, återbetalning eller manuell återkallelse tar boten bort dem från chatten.

Vanliga användningsområden inkluderar privata alpha-kanaler, betalda signalgrupper och community-förmåner.

## Anslut Telegram

<Steps>
<Step title="Open Entitlements">
I din Dodo Payments-instrumentpanel går du till **Rättigheter** och klickar på **+**, välj sedan **Telegram Access** som integration. Instrumentpanelen ber om ditt Telegram-användar-ID så att boten kan verifiera ägarskap av de chattar den hanterar.

<Frame caption="New Entitlement → Telegram Access. The dashboard needs your Telegram user ID before it lists chats.">
<img src="/images/entitlements/telegram/connect-prompt.png" alt="New Entitlement Telegram Access form prompting for Telegram user ID and Connect Telegram button" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Tip>
De två nästa stegen är inställningsuppgifter i Telegram och kan utföras i vilken ordning som helst — få ditt användar-ID och lägg till boten i din chatt som admin. När båda är klara, återgå till instrumentpanelen för det sista steget.
</Tip>
</Step>

<Step title="Get your Telegram user ID">
På Telegram, meddelande **`/start`** till:

- **`@dodo_payments_bot`** om du använder **Live Mode**
- **`@DodoPaymentsTestBot`** om du använder **Test Mode**

Boten svarar med ditt numeriska Telegram-användar-ID. Kopiera det — du kommer att klistra in det i instrumentpanelen i sista steget.
</Step>

<Step title="Add the bot to your chat as an admin">
I Telegram-gruppen eller kanalen du vill låsa, öppna medlemslistan och **lägg till samma bot som admin** (`@dodo_payments_bot` för live, `@DodoPaymentsTestBot` för test) med dessa två behörigheter aktiverade:

- **Banna användare** — behövs för att ta bort medlemmar vid återkallelse
- **Lägg till användare** — behövs för att bjuda in betalande kunder

Lämna alla andra admin-behörigheter avslagna.

<Frame caption="Telegram → Promote to admin. Only Ban Users and Add Users need to be enabled.">
<img src="/images/entitlements/telegram/promote-bot-admin.png" alt="Telegram Promote to admin screen showing Ban Users and Add Users enabled for the Dodo Payments bot" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Connect Telegram and pick the chat">
Tillbaka i instrumentpanelen, klistra in användar-ID:t från steg 2 i **Telegram User ID** och klicka på **Anslut Telegram**. Chattväljaren listar nu varje grupp och kanal där boten är en administratör — välj den du vill låsa, ge rättigheten ett namn och klicka på **Skapa Rättighet**.
</Step>
</Steps>

## Kundflöde

1. Kunden slutför kassan.
2. Dodo Payments skapar en `pending` beviljning och ber boten att generera en engångsinbjudningslänk till den konfigurerade chatten.
3. När länken är klar går beviljningen till `delivered` och länken inkluderas i leveransmailet och kundportalen.
4. Kunden trycker på länken och läggs till i chatten.
5. Vid återkallelse tar boten bort kunden från chatten.

<Tip>
Inbjudningslänken är för engångsbruk och upphör att gälla efter att kunden gått med. Om de förlorar länken innan de går med, återskapa den genom att skicka om leveransmailet eller återkalla och återskapa beviljandet från instrumentpanelen.
</Tip>

## Krävd konfiguration

| Fält | Krävd | Beskrivning |
|---|---|---|
| `chat_id` | Ja | Telegram-chattens ID (numerisk, ofta negativ för grupper/kanaler). Instrumentpanelens väljare fyller i detta åt dig. |

## Skapa via API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Premium Signals Group',
  integration_type: 'telegram',
  integration_config: {
    chat_id: '-1001234567890',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Premium Signals Group",
    integration_type="telegram",
    integration_config={"chat_id": "-1001234567890"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Premium Signals Group"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeTelegram),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigTelegramConfigParam{
      ChatID: dodopayments.F("-1001234567890"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

Se [`entitlement_grant.*` webhook-händelser](/developer-resources/webhooks/intents/entitlement-grant). Telegram-beviljningar anländer `pending` och övergår till `delivered` när boten har utfärdat inbjudningslänken.

## Felsökning

<AccordionGroup>
<Accordion title="Chat doesn't appear in the picker">
Dodo Payments-boten måste läggas till i chatten **som administratör** med **Lägg till användare** aktiverat. Väljaren läser det nuvarande tillståndet, så chatten visas så snart boten är administratör.
</Accordion>

<Accordion title="Customer says the invite link doesn't work">
Telegram engångslänkar upphör att gälla efter första användning. Om kunden tryckte på den på en utloggad enhet eller förlorat länken, återkalla beviljandet och utfärda på nytt.
</Accordion>

<Accordion title="Customer cancelled but is still in the chat">
Boten behöver adminbehörigheten **Banna användare** för att ta bort medlemmar. Öppna chattens inställningar och bekräfta att både **Banna användare** och **Lägg till användare** är markerade på Dodo Payments-boten.
</Accordion>
</AccordionGroup>
