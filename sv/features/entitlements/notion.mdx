<Info>
Notion-entitlement duplicerar en mall du har förberett i den betalande kundens Notion-arbetsyta. Kunden godkänner genom OAuth, väljer arbetsytan de vill kopiera mallen till, och Dodo Payments hanterar dupliceringen.
</Info>

## Vad som levereras

- Kunden uppmanas att ansluta sin Notion-arbetsyta via OAuth.
- När godkänd duplicerar Dodo Payments den konfigurerade mallen i den valda arbetsytan.
- Vid annullering kvarstår den duplicerade mallen i kundens arbetsyta (Notion stöder inte fjärrborttagning). Beviljandet markeras `revoked` för registerhållning.

Vanliga användningsområden inkluderar betalda Notion-mallar, produktivitetssystem och OS/CRM-mallar.

## Kundflöde

1. Kunden slutför kassan.
2. Dodo Payments skapar ett beviljande i `pending` status med en Notion `oauth_url` för kunden att ansluta sin arbetsyta.
3. Kunden auktoriserar via länken i deras e-post eller kundportal och väljer den arbetsyta de vill duplicera mallen till.
4. Dodo Payments duplicerar mallen. Beviljandet går till `delivered`.
5. Vid återkallelse markeras beviljandet `revoked`; den duplicerade kopian finns kvar i kundens arbetsyta.

<Note>
Notion behandlar avsiktligt en duplicerad sida som mottagarens eget innehåll. Dodo Payments kan inte ta bort kopian vid återkallelse.
</Note>

## Nödvändig konfiguration

| Fält | Obligatorisk | Beskrivning |
|---|---|---|
| `notion_template_id` | Ja | Mall-ID. Instrumentpanelväljaren fyller i detta. |

## Skapa via API

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Study Notes',
  integration_type: 'notion',
  integration_config: {
    notion_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Study Notes",
    integration_type="notion",
    integration_config={"notion_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Study Notes"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeNotion),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigNotionConfigParam{
      NotionTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

Se [`entitlement_grant.*` webhook-händelser](/developer-resources/webhooks/intents/entitlement-grant):

- `entitlement_grant.created` inkluderar Notion `oauth_url`.
- `entitlement_grant.delivered` utlöses när mallen dupliceras.
- `entitlement_grant.revoked` utlöses vid annullering; kundens kopia lämnas orörd.

## Felsökning

<AccordionGroup>
<Accordion title="Customer didn't get the template">
Beviljandet kvarstår som `pending` tills kunden slutför Notion OAuth. Skicka om leverans-e-posten; OAuth-länken går ut efter en vecka, varefter du kan återkalla och återskapa beviljandet.
</Accordion>

<Accordion title="Template picker is empty">
Anslut Notion igen från **Entitlements → Integrations → Notion** med arbetsytan som äger källmallarna.
</Accordion>

<Accordion title="Customer wants the template removed after refund">
Notion tillåter inte fjärrborttagning av duplicerade sidor. Kunden måste ta bort kopian från sin egen arbetsyta.
</Accordion>
</AccordionGroup>
