## Adaptiv Valuta

Adaptiv Valuta gör det möjligt för kunder att betala i sin föredragna lokala valuta, vilket förbättrar förtroendet och konverteringsgraden.

### Hur Det Fungerar

1. **Aktivera**: Aktivera Adaptiv Valuta från dina Företagsinställningar
2. **Välj**: Kunder kan byta valuta direkt vid kassan
3. **Konvertera**: Priser konverteras dynamiskt med hjälp av realtids FX-kurser
4. **Visa**: Slutbeloppet visas transparent innan betalning

## Automatisk skatteberäkning

Skatter beräknas automatiskt baserat på kundens faktureringsplats, vilket säkerställer efterlevnad av GST, VAT och försäljningsskattekrav utan manuell inställning.

### Hur skatteberäkningen fungerar

<Steps>
<Step title="Platsdetektering">
  Skatteregler tillämpas baserat på kundens land (och region där tillämpligt).
</Step>

<Step title="Dynamiska uppdateringar">
  Skattebeloppet uppdateras automatiskt när:
  - Landet ändras
  - Adressen uppdateras
</Step>

<Step title="Transparent visning">
  Den slutgiltiga skatteuppdelningen visas tydligt före betalning.
</Step>
</Steps>

<Tip>
Skatteberäkningen är helt automatiserad. Ingen manuell konfiguration krävs för standard digitala varor och SaaS-produkter.
</Tip>

## Stöd för företags-ID

För registrerade företag tillåter kassan kunder att ange sitt Företags-ID (t.ex. VAT/GST-nummer).

### Vad händer när ett skattee-ID anges

- Skatteberättigande valideras i realtid
- Gällande skattebefrielser eller omvänd betalningsregler tillämpas
- Skattebeloppet uppdateras omedelbart i kassan

## Rabattkoder

### Kassaupplevelse

1. Kunden anger rabattkoden
2. Rabatten valideras omedelbart
3. Uppdaterat pris och besparingar visas tydligt

### API-integration

Förhandsanvänd en rabattkod eller aktivera inmatningsfältet för rabatt:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  discount_code: 'WELCOME20', // Pre-apply a code
  feature_flags: {
    allow_discount_code: true // Show discount input field
  },
  return_url: 'https://yoursite.com/return'
});
```

## Smart adressinsamling

### Tillgängliga alternativ

| Alternativ | Beskrivning |
|--------|-------------|
| **Google Address Autofill** | Snabbt val med automatisk ifyllning |

## Anpassade fält

Samla in ytterligare information från kunder under kassan genom att definiera anpassade formulärfält. Detta är användbart för att samla in data som företagsnamn, teamstorlek, referenskälla eller annan affärsspecifik information.

### Tillgängliga fälttyper

| Typ | Beskrivning |
|------|-------------|
| `text` | Enkel rad textinmatning |
| `number` | Numerisk inmatning |
| `email` | E-postadress med validering |
| `url` | URL med validering |
| `date` | Datumväljare |
| `dropdown` | Välj bland fördefinierade alternativ |
| `boolean` | Ja/Nej-omkopplare |

### Exempel

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Kundernas svar ingår automatiskt i webhook-payloads (`payment.succeeded`, `subscription.created`) och API-svar via `custom_field_responses`-arrayen. Du kan definiera upp till 5 anpassade fält per kassasession.
</Info>

## Kollektion av kassa

Produktkollektioner möjliggör en enhetlig kassaupplevelse där kunder kan se och välja bland flera relaterade produkter (t.ex. Starter, Pro, Enterprise-planer) i en och samma kassa.

### Hur det fungerar

1. **Alla produkter visas**: Kunder ser varje aktiv produkt i kollektionen
2. **Första produkten förvaltad**: Den första produkten i kollektionen väljs automatiskt
3. **Jämföra alternativ**: Kunder kan jämföra priser och funktioner innan de väljer
4. **Enkel val**: Efter att ha valt en produkt fortsätter kassan med standardbetalningsflödet

### Skapa en kollektionkassa

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
Vid användning av `product_collection_id`, skicka en tom `product_cart`-array. Rabattkoder kan inte förhandsanvändas vid skapandet av sessionen.
</Warning>

## Konfiguration av kassasession

Kontrollera kassans beteende genom att använda Checkout Sessions API:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_code: 'PROMO10',
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
Efter betalningen blir kunder omdirigerade till din `return_url` med frågeparametrar som automatiskt bifogas -- inklusive `payment_id` eller `subscription_id`, `status`, `email`, och `license_key` (om tillämpligt). Se [Checkout Sessions-guide](/developer-resources/checkout-session#request-body) för hela listan.
</Info>

## Anpassning av temat för kassan

Anpassa utseendet på kassasidan för att matcha ditt varumärke genom att använda parametern `customization.theme_config` när du skapar en kassasession via API:et. Konfigurera färger, typsnitt, hörnradie och knapptext för både ljus och mörk läge.

<Frame>
  <img src="/images/checkout/theme-example.png" alt="Anpassad tematisk kassa"/>
</Frame>

<Info>
Detta avsnitt täcker **server-side API** tematisk konfiguration med `customization.theme_config`. Om du använder **Checkout SDK** (overlay eller inline checkout), se temaanpassningssektionerna i [Overlay Checkout](/developer-resources/overlay-checkout#theme-customization) eller [Inline Checkout](/developer-resources/inline-checkout#theme-customization) som använder camelCase-egenskaper (t.ex. `bgPrimary` istället för `bg_primary`).
</Info>

### Alternativ för temakonfiguration

| Egenskap | Beskrivning |
|----------|-------------|
| `light` | Färgkonfiguration för ljusläge |
| `dark` | Färgkonfiguration för mörkt läge |
| `font_primary_url` | URL för det primära typsnittet |
| `font_secondary_url` | URL för det sekundära typsnittet |
| `font_size` | Typsnittsstorlek: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `font_weight` | Typsnittsvikt: `normal`, `medium`, `bold`, `extraBold` |
| `radius` | Hörnradie för UI-element (t.ex. `4px`, `0.5rem`, `8px`) |
| `pay_button_text` | Anpassad text för betalningsknappen (t.ex. "Avsluta köp", "Prenumerera nu") |

### Färgkonfiguration (Ljus/Mörkt läge)

Varje läge (`light` och `dark`) stöder följande färgegenskaper:

| Egenskap | Beskrivning |
|----------|-------------|
| `bg_primary` | Bakgrunds primära färg |
| `bg_secondary` | Bakgrunds sekundära färg |
| `text_primary` | Text primära färg |
| `text_secondary` | Text sekundära färg |
| `text_placeholder` | Textplatshållarfärg |
| `text_error` | Textfel färg |
| `text_success` | Text framgångsfärg |
| `border_primary` | Border primära färg |
| `border_secondary` | Border sekundära färg |
| `button_primary` | Primär knapputsbackgrundsfärg |
| `button_primary_hover` | Primär knapphoverfärg |
| `button_secondary` | Sekundär knapputsbackgrundsfärg |
| `button_secondary_hover` | Sekundär knapphoverfärg |
| `button_text_primary` | Primär knapptextfärg |
| `button_text_secondary` | Sekundär knapptextfärg |
| `input_focus_border` | Inmatning fokuserad kantfärg |

<Info>
Alla färgfält accepterar standard CSS-färformat:
- Hex: `#fff`, `#ffffff`, `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`, `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`, `hsla(120, 100%, 50%, 0.5)`
- Namngivna färger: `red`, `blue`, `transparent`
</Info>

### Exempel

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
Du behöver inte ange alla färgegenskaper. Alla outtagna egenskaper kommer att använda standardtemavärdena.
</Tip>
