## Adaptive Currency

Adaptive Currency gör det möjligt för kunder att betala i sin lokala valuta, vilket ökar förtroendet och konverteringsgraden.

### Så fungerar det

1. **Aktivera**: Aktivera Adaptive Currency från **Settings → Business**
2. **Välj**: Kunder kan byta valuta direkt i kassan
3. **Konvertera**: Priser konverteras dynamiskt med aktuella FX-kurser
4. **Visa**: Det slutliga betalningsbeloppet visas tydligt före betalning

## Automatisk skatteberäkning

Skatter beräknas automatiskt baserat på kundens faktureringsadress, vilket säkerställer efterlevnad av GST-, VAT- och sales tax-krav utan manuell konfiguration.

### Så fungerar skatteberäkningen

<Steps>
<Step title="Location Detection">
  Skatteregler tillämpas baserat på kundens land (och region där det är tillämpligt).
</Step>

<Step title="Dynamic Updates">
  Skattebeloppet uppdateras automatiskt när:
  - Landet ändras
  - Adressen uppdateras
</Step>

<Step title="Transparent Display">
  Den slutliga skattespecifikationen visas tydligt före betalning.
</Step>
</Steps>

<Tip>
Skatteberäkningen är helt automatiserad. Ingen manuell konfiguration krävs för standardiserade digitala varor och SaaS-produkter.
</Tip>

## Stöd för Business Tax ID

För registrerade företag kan kunder ange sitt Business Tax ID (till exempel VAT/GST-nummer) i kassan.

### Vad händer när ett Tax ID anges

- Skatteberättigande valideras i realtid
- Tillämpliga skattebefrielser eller regler för omvänd skattskyldighet tillämpas
- Skattebeloppet uppdateras omedelbart i kassan

Kunder kan använda rabatt- eller kampanjkoder som du har skapat i instrumentpanelen direkt på kassasidan.

### Kassaupplevelse

1. Kunden anger rabattkoden
2. Rabatten valideras omedelbart
3. Det uppdaterade priset och besparingen visas tydligt

  <img src="/images/checkout/c4.png" alt="Angivande av rabattkod i kassan" style={{ maxHeight: '500px', width: '70%' }}/>

### API-integration

Förbered en eller flera staplade rabattkoder eller aktivera rabattkodsfältet:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  discount_codes: ['WELCOME20'], // Pre-apply one or more codes (max 20, applied in order)
  feature_flags: {
    allow_discount_code: true // Show discount input field
  },
  return_url: 'https://yoursite.com/return'
});
```

<Info>
`discount_codes` accepterar en array med upp till 20 koder som staplas i ordning. Det enskilda fältet `discount_code` är föråldrat men fungerar fortfarande — befintliga integrationer behöver inte ändras omedelbart. Migrera till `discount_codes` när det passar för att använda stapling och den mer omfattande svarsstrukturen.
</Info>

## Smart adressinsamling

Kassan stöder flexibel adressinmatning för snabbare slutförande.

### Tillgängliga alternativ

| Alternativ | Beskrivning |
|--------|-------------|
| **Google Address Autofill** | Snabbt val med autokomplettering |
| **Manuell inmatning** | Full kontroll över kompletta adresser |
| **Val av land** | Styr skatte- och efterlevnadslogik |
| **Minimal adress** | Samla endast in land (och ZIP där det krävs för skatt) — se [läget Minimal adress](#minimal-address-mode) |

<Tip>
Adressinsamlingen balanserar snabbhet, noggrannhet och global täckning för att maximera konverteringen och samtidigt säkerställa efterlevnad.
</Tip>

### Läget Minimal adress

Aktivera minimal adressinsamling för maximal konvertering och mindre friktion i kassan. När `minimal_address` har värdet `true` samlar kassan endast in:

- **Land** — krävs alltid för skatteberäkning
- **ZIP/postnummer** — endast i regioner där det behövs för beräkning av sales tax, VAT eller GST

Alla övriga adressfält (gata, ort, delstat) hoppas över, vilket avsevärt snabbar upp slutförandet av kassan.

<Frame>
  <img src="/images/changelog/minimal-address.png" alt="Läget Minimal adress som endast visar fält för land och ZIP/postnummer i kassan" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  minimal_address: true,
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Fullständig adressinsamling är fortfarande standard. Aktivera `minimal_address` för digitala produkter och SaaS-flöden där fullständiga faktureringsuppgifter inte krävs.
</Info>

<Card title="Minimal Address Reference" icon="address-card" href="/developer-resources/checkout-session#request-body">
  Se den fullständiga referensen för parametern `minimal_address` i guiden för Checkout Sessions API.
</Card>

## Insamling av telefonnummer

Styr om telefonnummerfältet visas i kassan — och om det är obligatoriskt — med feature flags för checkout-sessionen.

| Flagga | Standard | Beteende |
|------|---------|----------|
| `allow_phone_number_collection` | `true` | Visar telefonnummerfältet i kassaformuläret |
| `require_phone_number` | `false` | Gör telefonnummerfältet obligatoriskt (formulärvalideringen kräver ett icke-tomt värde) |

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_abc', quantity: 1 }],
  feature_flags: {
    allow_phone_number_collection: true,
    require_phone_number: true
  },
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
`require_phone_number: true` kräver `allow_phone_number_collection: true`. API:et avvisar sessioner där telefoninsamling är inaktiverad samtidigt som telefonnummer är obligatoriskt.
</Warning>

<Tip>
Använd `require_phone_number` för B2B SaaS, reglerade branscher eller andra flöden där du behöver en verifierad kontaktkanal för support, bedrägerigranskning eller efterlevnad.
</Tip>

## Anpassade fält

Samla in ytterligare information från kunder under kassan genom att definiera anpassade formulärfält. Detta är användbart för att samla in uppgifter som företagsnamn, teamstorlek, hänvisningskälla eller annan företagsspecifik information.

### Tillgängliga fälttyper

| Typ | Beskrivning |
|------|-------------|
| `text` | Textinmatning på en rad |
| `number` | Numerisk inmatning |
| `email` | E-postadress med validering |
| `url` | URL med validering |
| `date` | Datumväljare |
| `dropdown` | Välj bland fördefinierade alternativ |
| `boolean` | Ja/nej-växlare |

### Exempel

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
Kundsvar inkluderas automatiskt i webhook-nyttolaster (`payment.succeeded`, `subscription.active`) och API-svar via arrayen `custom_field_responses`. Du kan definiera upp till 5 anpassade fält per checkout-session.
</Info>

## Kassa för produktkollektioner

Produktkollektioner möjliggör en enhetlig kassaupplevelse där kunder kan visa och välja bland flera relaterade produkter (till exempel Starter-, Pro- och Enterprise-planer) i en enda kassa.

### Så fungerar det

1. **Alla produkter visas**: Kunder ser alla aktiva produkter i kollektionen
2. **Den första produkten är förvald**: Den första produkten i kollektionen väljs automatiskt
3. **Jämför alternativ**: Kunder kan jämföra priser och funktioner innan de väljer
4. **Ett enda val**: När en produkt har valts fortsätter kassan med det vanliga betalningsflödet

### Skapa en kassa för en kollektion

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
När du använder `product_collection_id` ska du skicka en tom array för `product_cart`. Rabattkoder kan inte tillämpas i förväg när sessionen skapas.
</Warning>

## Konfiguration av checkout-session

Styr kassans beteende med Checkout Sessions API:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_codes: ['PROMO10'],
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  cancel_url: 'https://yoursite.com/pricing', // Optional: where to redirect on cancel
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
Efter betalningen omdirigeras kunder till din `return_url`, där query-parametrar läggs till automatiskt -- inklusive `payment_id` eller `subscription_id`, `status`, `email` och `license_key` (om tillämpligt). Se [Checkout Sessions guide](/developer-resources/checkout-session#request-body) för hela listan.
</Info>

Anpassa kassasidans utseende så att det matchar ditt varumärke genom att använda parametern `customization.theme_config` när du skapar en checkout-session via API:et. Konfigurera färger, teckensnitt, hörnradie och knapptext för både ljust och mörkt läge.

<Frame>
  <img src="/images/checkout/theme-example.png" alt="Kassasida med anpassat tema" style={{ maxHeight: '500px', width: 'auto' }} />

<Card title="Design & Theme Customization" icon="palette" href="/features/design">
  Konfigurera teman visuellt från instrumentpanelen med förbyggda teman, typografi, färger och liveförhandsvisning.
</Card>

<Info>
Det här avsnittet beskriver konfiguration av **server-side API**-teman med `customization.theme_config`. Om du använder **Checkout SDK** (overlay- eller inline-kassa) kan du läsa avsnittet om temaanpassning i [Overlay Checkout](/developer-resources/overlay-checkout#theme-customization), som använder camelCase-egenskaper (till exempel `bgPrimary` i stället för `bg_primary`).
</Info>

### Alternativ för temakonfiguration

| Egenskap | Beskrivning |
|----------|-------------|
| `light` | Färgkonfiguration för ljust läge |
| `dark` | Färgkonfiguration för mörkt läge |
| `font_primary_url` | URL för det primära teckensnittet |
| `font_secondary_url` | URL för det sekundära teckensnittet |
| `font_size` | Teckenstorlek: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `font_weight` | Teckengrovlek: `normal`, `medium`, `bold`, `extraBold` |
| `radius` | Hörnradie för UI-element (till exempel `4px`, `0.5rem`, `8px`) |
| `pay_button_text` | Anpassad text för betalningsknappen (till exempel "Complete Purchase", "Subscribe Now") |

### Färgkonfiguration (ljust/mörkt läge)

Varje läge (`light` och `dark`) stöder följande färgegenskaper:

| Egenskap | Beskrivning |
|----------|-------------|
| `bg_primary` | Primär bakgrundsfärg |
| `bg_secondary` | Sekundär bakgrundsfärg |
| `text_primary` | Primär textfärg |
| `text_secondary` | Sekundär textfärg |
| `text_placeholder` | Färg för platshållartext |
| `text_error` | Textfärg för fel |
| `text_success` | Textfärg för lyckat resultat |
| `border_primary` | Primär kantlinjefärg |
| `border_secondary` | Sekundär kantlinjefärg |
| `button_primary` | Bakgrundsfärg för primär knapp |
| `button_primary_hover` | Hover-färg för primär knapp |
| `button_secondary` | Bakgrundsfärg för sekundär knapp |
| `button_secondary_hover` | Hover-färg för sekundär knapp |
| `button_text_primary` | Textfärg för primär knapp |
| `button_text_secondary` | Textfärg för sekundär knapp |
| `input_focus_border` | Kantlinjefärg vid indatafokus |

<Info>
Alla färgfält accepterar standardiserade CSS-färgformat:
- Hex: `#fff`, `#ffffff`, `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`, `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`, `hsla(120, 100%, 50%, 0.5)`
- Namngivna färger: `red`, `blue`, `transparent`
</Info>

### Exempel

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
      font_weight: 'medium',
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      
      // Light mode colors
      light: {
        bg_primary: '#ffffff',
        bg_secondary: '#f5f5f5',
        text_primary: '#1a1a1a',
        text_secondary: '#666666',
        button_primary: '#0066ff',
        button_primary_hover: '#0052cc',
        button_text_primary: '#ffffff',
        border_primary: '#e0e0e0'
      },
      
      // Dark mode colors
      dark: {
        bg_primary: '#1a1a1a',
        bg_secondary: '#2d2d2d',
        text_primary: '#ffffff',
        text_secondary: '#a0a0a0',
        button_primary: '#3385ff',
        button_primary_hover: '#4d99ff',
        button_text_primary: '#ffffff',
        border_primary: '#404040'
      }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

<Tip>
Du behöver inte ange alla färgegenskaper. Egenskaper som inte anges använder standardvärdena för temat.
</Tip>
