<Info>
Köpkraftsparitet (PPP) tar betalt av en kund som en andel av ditt listpris, baserat på landet de köper från. En produkt för \$20 kan säljas för **\$6.00 i Indien** utan en rabattkod och utan en andra prislista.
</Info>

## Vad är köpkraftsparitet?

Samma pris är inte lika överkomligt överallt. \$20 är ett litet köp i USA och ett stort köp i Filippinerna. PPP-prissättning korrigerar för den skillnaden.

Dodo Payments sparar en procentsats för varje land. Procentsatsen är **den andel av ditt listpris som kunden betalar**. Indien är 30, så en kund i Indien betalar 30 % av priset. USA är 100, så ingenting ändras där.

Du aktiverar PPP för varje produktpris som du vill ska omfattas. Produkter som du inte aktiverar behåller sitt normala pris överallt.

<Note>
PPP kräver [Adaptive Currency](/features/adaptive-currency). Aktivera Adaptive Currency först.
</Note>

## Viktiga fördelar

- **Nå priskänsliga marknader**: Sälj till ett lokalt pris utan att sänka ditt hemmamarknadspris.
- **Ingen banner och inget skript**: Priset är korrekt i kassan. Ingenting läggs till på din webbplats.
- **Inga rabattkoder att hantera**: Inget att skapa, byta ut eller återkalla.
- **Kontroll per produkt**: Aktivera en instegsplan och låt en företagsplan vara orörd.
- **Fungerar överallt**: Engångsprodukter, prenumerationer och användningsbaserade produkter.

## Aktivera köpkraftsparitet

<Steps>
<Step title="Enable Adaptive Currency">
Gå till **Settings → Business**. Aktivera **Adaptive Currency** i **Business Settings**. PPP fungerar inte utan den.

<Frame>
  <img src="/images/ppp/adaptive-currency-toggle.png" alt="Adaptive Currency and Purchasing Power Parity in Business Settings" style={{ maxHeight: '360px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Review your country percentages">
Under **Purchasing Power Parity** klickar du på **Edit** för att öppna **Country Prices**. Ändra procentsatsen för valfritt land och klicka sedan på **Save Changes**.

Ange **Example product price** för att se vad varje land betalar. Kolumnen **Your Price** uppdateras medan du skriver. Använd sökrutan för att hitta ett land med namn eller kod.

<Frame>
  <img src="/images/ppp/country-percentages.png" alt="Country Prices dialog with a percentage and resulting price for each country" style={{ maxHeight: '620px', width: 'auto' }} />
</Frame>

<Note>
Dessa procentsatser gäller för hela företaget. Alla produkter där Purchasing Power Parity är aktiverat använder dem.
</Note>
</Step>

<Step title="Turn PPP on for a product">
Öppna produkten. I avsnittet **Pricing** markerar du **Purchasing Power Parity** och sparar sedan produkten.

Produkter som du inte markerar behåller sitt normala pris överallt.

<Frame>
  <img src="/images/ppp/product-toggle.png" alt="Purchasing Power Parity ticked in the product Pricing section" style={{ maxHeight: '440px', width: 'auto' }} />
</Frame>

<Warning>
Du kan inte markera detta när Adaptive Currency är avstängt. Aktivera Adaptive Currency först.
</Warning>
</Step>

<Step title="Confirm at checkout">
<Check>
Öppna en testkassa med ett faktureringsland som har en procentsats under 100. Bekräfta att det reducerade priset visas.
</Check>
</Step>
</Steps>

## Så beräknas priset

Procentsatsen för landet multipliceras med ditt listpris:

```
price paid = list price × country percentage ÷ 100
```

En produkt för \$20.00, för en kund i Indien med 30:

```
2000 × 30 ÷ 100 = 600   →   $6.00
```

Dodo Payments tillämpar procentsatsen på baspriset före valutaomvandlingen. [Adaptive Currency](/features/adaptive-currency) omvandlar sedan resultatet till kundens valuta.

<Info>
Dodo Payments läser landet från kundens **billing country** i kassan.
</Info>

### Procentsatser per land

Varje land har en procentsats mellan **30 och 100**:

- **100** innebär att kunden betalar hela ditt pris. Ingen reducering görs.
- **30** är det lägsta värdet du kan ange. Den största reduceringen är därför 70 %.

Standardvärdena kommer från data om prisnivåindex från Världsbanken. Dodo Payments avrundar varje värde till närmaste 5-tal, tillämpar ett golv på 30 och begränsar det till 100. Alla länder som stöds har ett värde. Du kan ändra vilket som helst av dem.

Här är några av standardvärdena för att visa intervallet:

| Land | Procentsats | En produkt för \$20 säljs för |
| :--- | :---: | :--- |
| USA | 100 | \$20.00 |
| Storbritannien | 85 | \$17.00 |
| Tyskland | 75 | \$15.00 |
| Japan | 60 | \$12.00 |
| Brasilien | 45 | \$9.00 |
| Sydafrika | 40 | \$8.00 |
| Filippinerna | 35 | \$7.00 |
| Indien | 30 | \$6.00 |

<Note>
Den fullständiga listan omfattar 217 länder. Öppna landstabellen i din dashboard för att se alla värden.
</Note>

## Aktivera via API

PPP aktiveras per produkt med fältet `purchasing_power_parity`. Standardvärdet är `false`.

<Info>
Procentsatser per land hanteras endast i dashboarden. De ingår inte i det publika API:et.
</Info>

<CodeGroup>

```typescript theme={null}
import DodoPayments from 'dodopayments';

const client = new DodoPayments({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: 'test_mode',
});

const product = await client.products.create({
  name: 'Starter Plan',
  tax_category: 'saas',
  price: {
    type: 'one_time_price',
    currency: 'USD',
    price: 2000,
    discount: 0,
    purchasing_power_parity: true,
  },
});
```

```python theme={null}
import os
from dodopayments import DodoPayments

client = DodoPayments(
    bearer_token=os.environ.get("DODO_PAYMENTS_API_KEY"),
    environment="test_mode",
)

product = client.products.create(
    name="Starter Plan",
    tax_category="saas",
    price={
        "type": "one_time_price",
        "currency": "USD",
        "price": 2000,
        "discount": 0,
        "purchasing_power_parity": True,
    },
)
```

```go theme={null}
package main

import (
	"context"
	"os"

	"github.com/dodopayments/dodopayments-go"
	"github.com/dodopayments/dodopayments-go/option"
)

func main() {
	client := dodopayments.NewClient(
		option.WithBearerToken(os.Getenv("DODO_PAYMENTS_API_KEY")),
	)

	_, err := client.Products.New(context.TODO(), dodopayments.ProductNewParams{
		Name:        dodopayments.F("Starter Plan"),
		TaxCategory: dodopayments.F(dodopayments.ProductNewParamsTaxCategorySaas),
		Price: dodopayments.F[dodopayments.PriceUnionParam](
			dodopayments.PriceOneTimePriceParam{
				Type:                  dodopayments.F(dodopayments.PriceOneTimePriceTypeOneTimePrice),
				Currency:              dodopayments.F(dodopayments.CurrencyUsd),
				Price:                 dodopayments.F(int64(2000)),
				Discount:              dodopayments.F(int64(0)),
				PurchasingPowerParity: dodopayments.F(true),
			},
		),
	})
	if err != nil {
		panic(err)
	}
}
```

</CodeGroup>

</Warning>

## Viktiga beteenden

| Beteende | Detalj |
| :--- | :--- |
| **Kräver Adaptive Currency** | PPP gör ingenting när Adaptive Currency är avstängt. |
| **Avstängt som standard** | Alla priser börjar på `purchasing_power_parity: false`. |
| **Lokala priser har företräde** | En produkt med en matchande regel för [Localized Pricing](/features/localized-pricing) justeras aldrig av PPP. Det exakta beloppet du anger tillämpas. |
| **Tillämpas före omvandling** | Procentsatsen tillämpas på ditt baspris. Adaptive Currency omvandlar resultatet. |
| **Före rabatter** | En [discount code](/features/discount-codes) tillämpas på det reducerade priset, så de två reduceringarna kombineras. |
| **Fasta avgifter endast för användningsbaserade produkter** | PPP tillämpas på den fasta avgiften för en användningsbaserad produkt, aldrig på mätt användning. |
| **Inte för Pay What You Want** | Kunden väljer beloppet, så PPP tillämpas inte. Se [Pay What You Want](/features/pay-what-you-want). |
| **Procentsatsintervall** | En procentsats för ett land ligger mellan 30 och 100. Den största reduceringen är 70 %. |
| **Ingen egen webhook** | Det reducerade beloppet visas på betalningen eller prenumerationen som vilket annat pris som helst. |

## Bästa praxis

- **Aktivera en produkt först.** Bekräfta priset i kassan innan du aktiverar det för din katalog.
- **Håll koll på rabattstaplingen.** En rabattkod tillämpas ovanpå PPP-priset. Ett land med 30 % plus en kod på 20 % lämnar 24 % av ditt listpris.
- **Lämna företagsplaner utanför.** En förhandlad plan behöver sällan en landsspecifik justering.
- **Ange egna värden där det är viktigt.** Standardvärdena är en utgångspunkt, inte en regel.
- **Kontrollera effekten på prenumerationer.** En prenumerant som registrerar sig till det reducerade priset förnyar prenumerationen till det priset.
