[ParityDeals](https://www.paritydeals.com/) och [Evendeals](https://www.evendeals.com/integrations/dodo-payments) är plattformar som möjliggör automatisk prisoptimering baserat på en kunds geografiska plats, vanligtvis känd som "köpkraftsparitet" (PPP) prissättning.

<Info>
Även om du inte kan bädda in rabattbanderoller direkt på en Dodo Payments-butik (eftersom anpassade skript inte stöds), kan du fortfarande implementera dessa verktyg effektivt på din egen webbplats eller applikation.
</Info>

## Välja en integration

Båda plattformarna integreras direkt med Dodo Payments för att automatiskt skapa och hantera rabattkoder. Använd jämförelsen nedan för att välja det verktyg som bäst passar dina behov.

| Funktion | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| PPP / Platsbaserad prissättning | Ja | Ja |
| Helg / Tidsbaserade erbjudanden | Ja | Nej |
| Prenumerationsstöd | Ja | Ja |
| Automatiskt kuponguppdatering | — | Ja |
| Anpassning av banderoller | Ja | Nej |
| Prissättning | [Se prissättning](https://www.paritydeals.com/pricing/) | [Se prissättning](https://www.evendeals.com/pricing) |

## ParityDeals

När ParityDeals är integrerat på din webbplats, kommer kvalificerade besökare att se en banderoll som inkluderar en platsbaserad rabattkod de kan använda vid kassan. Dessa rabattkoder skapas och hanteras automatiskt av ParityDeals och visas i din **Dodo Payments Dashboard** under **Försäljning → Rabatter**.

### Installation

<Steps>
  <Step title="Sign up on ParityDeals">
    Besök [app.paritydeals.com](https://app.paritydeals.com/) och skapa ett konto.
  </Step>

  <Step title="Create Deals">
    Efter inloggning, hitta alternativet för att skapa erbjudanden. Välj i rullgardinsmenyn **"Skapa erbjudanden via Dodo Payments"**.

    <Frame>
      <img src="/images/ppp/2.png" alt="Skapa erbjudanden via Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Logga in på din **Dodo Payments-dashboard** och navigera till **Utvecklare → API-nycklar**. Klicka på **"Skapa nytt API"**.

    <Tip>
      Namnge din API-nyckel beskrivande (t.ex. 'ParityDeals') så att du kan identifiera den senare.
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="Skapa en ny API-nyckel i Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Kopiera den API-nyckel du skapade och klistra in den i ParityDeals-gränssnittet för att upprätta anslutningen till ditt Dodo Payments-konto.

    <Frame>
      <img src="/images/ppp/4.png" alt="Ansluta API-nyckel till ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    När anslutningen är etablerad, kommer ParityDeals att hämta din Dodo Payments-produktkatalog. Välj de produkter du vill koppla till dina erbjudanden.

    <Frame>
      <img src="/images/ppp/5.png" alt="Välja produkter för ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Ange din webbplats URL och välj eventuellt specifika målsidor där rabattbanderollen ska visas. Välj sedan önskad typ av erbjudande:
    - Platsbaserade erbjudanden
    - Helgerbjudanden
    - Tidsbaserade snaberbjudanden

    <Frame>
      <img src="/images/ppp/6.png" alt="Konfigurera inställningar för erbjudanden" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Välj de länder du vill erbjuda lokala rabatter till och definiera rabattprocenten för varje. ParityDeals ger rekommenderade standardvärden som du kan justera efter behov.

    <Frame>
      <img src="/images/ppp/7.png" alt="Ställa in landsbaserade rabatter" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Designa din rabattbanderoll genom att anpassa texten, välja färger och layout samt välja banderollens position (överst eller längst ner på sidan). Denna banderoll visas för kvalificerade besökare baserat på dina konfigurerade regler.

    <Frame>
      <img src="/images/ppp/8.png" alt="Anpassa rabattbannern" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Efter att ha sparat ditt erbjudande, kommer ParityDeals att generera ett skript. Lägg till detta skript i din webbplatskod (vanligtvis i `<head>`-sektionen). Skriptet identifierar automatiskt besökarnas platser och visar den lämpliga rabattbanderollen.

    <Frame>
      <img src="/images/ppp/9.png" alt="ParityDeals integrationsskript" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

## Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) är en annan plattform som integreras med Dodo Payments för att erbjuda platsbaserad köpkraftsprisparitet. Den stöder både engångs- och prenumerationsprodukter.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Översikt av Evendeals Dodo Payments-integration" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

### Huvudfunktioner

- **Automatisk kupongsynkronisering** — Kuponger skapas och hanteras automatiskt i Dodo Payments
- **Procentuella rabatter** — Erbjud procentuella rabatter per landgrupp
- **Prenumerationsstöd** — Rabatter gäller över prenumerationsfaktureringscykler
- **Regler för automatisk uppdatering** — Roterar kupongkoder automatiskt genom tidsintervall, inlösenantal eller visningsantal för att förhindra missbruk

<Info>
Rabattkoder skapade av Evendeals kommer automatiskt att visas i din Dodo Payments-dashboard under Försäljning → Rabatter.
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="Viktiga funktioner för Evendeals Dodo Payments-integration" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

### Installation

<Steps>
  <Step title="Create a Dodo Payments API key">
    I din Dodo Payments-dashboard, gå till **Utvecklare → API-nycklar** och generera en ny nyckel.
  </Step>

  <Step title="Connect in Evendeals">
    I din [Evendeals-dashboard](https://www.evendeals.com/signin), navigera till **Integrationer**, hitta Dodo Payments-kortet och klistra in din API-nyckel.
  </Step>

  <Step title="Configure regional discounts">
    Ange procentuella rabatter för varje landgrupp och synkronisera. Evendeals skapar kuponger i Dodo Payments automatiskt.

    <Check>
    Efter synkronisering, öppna **Försäljning → Rabatter** i din Dodo Payments-dashboard för att bekräfta att de genererade kupongerna visas. Varje kupong kommer att ha ett igenkännligt Evendeals-prefix.
    </Check>
  </Step>
</Steps>
