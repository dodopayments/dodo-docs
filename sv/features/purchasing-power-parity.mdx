Köpkraftsparitet (PPP) prissättning justerar vad du tar betalt för att matcha köpkraften hos varje kunds plats. Det finns två sätt att göra det på Dodo Payments.

<Info>
**Rekommenderas:** Använd inbyggd [Localized Pricing](/features/localized-pricing) för att sätta ett fast lokalt pris per land, till exempel ₹999 i Indien för en produkt med ett baspris på $20. Du kontrollerar det exakta numret, det gäller engångs-, abonnemangs- och användningsbaserade produkter, och det finns ingen banner eller skript att installera.
</Info>

## Två sätt att köra PPP

| | Localized Pricing (inbyggd) | Platsbaserade rabattkoder |
| :--- | :--- | :--- |
| Hur det fungerar | Du sätter ett fast lokalt pris per land/valuta | En procentuell rabatt på ditt baspris, tillämpad via en kod |
| Verktyg | Inbyggt i Dodo Payments | [ParityDeals](https://www.paritydeals.com/) / [Evendeals](https://www.evendeals.com/integrations/dodo-payments) |
| Banner / skript på din sida | Inte behövs | Krävts för att visa koden |
| Pris kunden ser | Exakt det belopp du satt | Baspris minus rabatten |
| Bäst för | Rena, marknadsanpassade priser du helt kontrollerar | Kampanjbanners och tids- / helgdagbaserade erbjudanden |

För inbyggd installation, se [Localized Pricing](/features/localized-pricing). Resten av denna sida täcker platsbaserade rabattkod-metoden med ParityDeals och Evendeals.

## Platsbaserade rabattkoder

[ParityDeals](https://www.paritydeals.com/) och [Evendeals](https://www.evendeals.com/integrations/dodo-payments) är plattformar som möjliggör automatisk prissättning baserad på en kunds geografiska plats genom att generera rabattkoder.

<Info>
Även om du inte kan bädda in rabattbanners direkt på en Dodo Payments butikssida (eftersom anpassade skript inte stöds), kan du fortfarande implementera dessa verktyg effektivt på din egen webbplats eller applikation.
</Info>

### Välja en integration

Båda plattformarna integreras direkt med Dodo Payments för att skapa och hantera rabattkoder automatiskt. Använd jämförelsen nedan för att välja det verktyg som passar bäst för dina behov.

| Funktion | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| PPP / Platsbaserad prissättning | Ja | Ja |
| Helgdag / Tidsbaserade erbjudanden | Ja | Nej |
| Abonnemangsstöd | Ja | Ja |
| Automatisk kupongförnyelse | — | Ja |
| Banner-anpassning | Ja | Nej |
| Prissättning | [Visa prissättning](https://www.paritydeals.com/pricing/) | [Visa prissättning](https://www.evendeals.com/pricing) |

### ParityDeals

När ParityDeals är integrerat på din webbplats, kommer berättigade besökare att se en banner som inkluderar en platsbaserad rabattkod som de kan använda vid kassan. Dessa rabattkoder skapas och hanteras automatiskt av ParityDeals och kommer att visas i din **Dodo Payments Dashboard** under **Försäljning → Rabatter**.

#### Setup

<Steps>
  <Step title="Sign up on ParityDeals">
    Besök [app.paritydeals.com](https://app.paritydeals.com/) och skapa ett konto.
  </Step>

  <Step title="Create Deals">
    Efter inloggning, hitta alternativet för att skapa erbjudanden. Från rullgardinsmenyn, välj **"Skapa erbjudanden via Dodo Payments"**.

    <Frame>
      <img src="/images/ppp/2.png" alt="Skapa erbjudanden via Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Logga in på din **Dodo Payments dashboard** och navigera till **Utvecklare → API Nycklar**. Klicka på **"Skapa ny API"**.

    <Tip>
      Namnge din API-nyckel beskrivande (t.ex., 'ParityDeals') så att du kan identifiera den senare.
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="Skapa en ny API-nyckel i Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Kopiera den API-nyckel du skapade och klistra in den i ParityDeals-gränssnittet för att upprätta anslutningen med ditt Dodo Payments-konto.

    <Frame>
      <img src="/images/ppp/4.png" alt="Ansluta API-nyckel till ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    När det är anslutet, kommer ParityDeals att hämta din Dodo Payments produktkatalog. Välj de produkter du vill associera med dina erbjudanden.

    <Frame>
      <img src="/images/ppp/5.png" alt="Välja produkter för ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Ange din webbplats URL och välj eventuellt specifika målsidor där rabattbannern ska visas. Välj sedan din föredragna erbjudande typ:
    - Platsbaserade erbjudanden
    - Helgbaserade erbjudanden
    - Tidsbaserade blixt erbjudanden

    <Frame>
      <img src="/images/ppp/6.png" alt="Konfigurera erbjudandeinställningar" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Välj de länder du vill erbjuda lokaliserade rabatter till och definiera rabattprocenten för varje. ParityDeals tillhandahåller rekommenderade standardvärden som du kan justera efter behov.

    <Frame>
      <img src="/images/ppp/7.png" alt="Ställa in landbaserade rabatteregler" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Designa din rabattbanner genom att anpassa texten, välja färger och layout och välja bannerposition (överst eller nederst på sidan). Denna banner kommer att visas för berättigade besökare baserat på dina konfigurerade regler.

    <Frame>
      <img src="/images/ppp/8.png" alt="Anpassa rabattbannern" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    Efter att ha sparat ditt erbjudande, kommer ParityDeals att generera ett skript. Lägg till detta skript i din webbplatskod (vanligtvis i `<head>` sektionen). Detta skript upptäcker automatiskt besökarens platser och visar lämplig rabattbanner.

    <Frame>
      <img src="/images/ppp/9.png" alt="ParityDeals integrationsskript" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

#### Ytterligare funktioner

Med ParityDeals kan du också erbjuda [automatiska tidsbaserade rabatter](https://www.paritydeals.com/features/time-based-discounts/) och [helgbaserade kampanjer](https://www.paritydeals.com/features/holiday-based-discounts/) året runt. För mer detaljerad information, se [ParityDeals Dokumentation](https://www.paritydeals.com/docs/).

### Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) är en annan plattform som integreras med Dodo Payments för att erbjuda platsbaserad köpkraftsprisrättvisa. Det stöder både engångs- och abonnemangsprodukter.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Översikt av Evendeals Dodo Payments integration" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### Nyckelfunktioner

- **Automatisk kupongsynk** — Kuponger skapas och hanteras i Dodo Payments automatiskt
- **Procentuella rabatter** — Erbjud procentuella avdrag per landgrupp
- **Abonnemangsstöd** — Rabatter gäller över abonnemangets faktureringscykler
- **Automatisk uppdateringsregler** — Roterar kupongkoder automatiskt efter tidsintervall, inlösenantal eller visningsantal för att förhindra missbruk

<Info>
Rabattkoder skapade av Evendeals kommer automatiskt visas i din Dodo Payments instrumentpanel under Försäljning → Rabatter.
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="Nyckelfunktioner för Evendeals Dodo Payments integration" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### Setup

<Steps>
  <Step title="Create a Dodo Payments API key">
    I din Dodo Payments instrumentpanel, gå till **Utvecklare → API Nycklar** och generera en ny nyckel.
  </Step>

  <Step title="Connect in Evendeals">
    I din [Evendeals instrumentpanel](https://www.evendeals.com/signin), navigera till **Integrationer**, hitta Dodo Payments kortet och klistra in din API-nyckel.
  </Step>

  <Step title="Configure regional discounts">
    Ställ in procentuella rabatter för varje landgrupp och tryck på synk. Evendeals skapar kuponger i Dodo Payments automatiskt.

    <Check>
    Efter synkronisering, öppna **Försäljning → Rabatter** i din Dodo Payments instrumentpanel för att bekräfta att de genererade kupongerna visas. Varje kupong kommer ha ett igenkännbart EvenDeals prefix.
    </Check>
  </Step>
</Steps>
