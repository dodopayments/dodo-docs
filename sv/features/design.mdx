<Info>
Design-sidan är din centrala hubb för att profilera alla kundinriktade ytor: checkout, storefront och Customer Portal. Ändringar tillämpas direkt på alla tre och förhandsvisas i realtid innan du sparar. Testläge och live-läge har separata designer — se [Kopiera design från testläge till live-läge](#copy-design-from-test-to-live-mode).
</Info>

## Viktiga höjdpunkter

1. **Enhetlig designhubb** - Konfigurera utseendet för checkout, storefront och Customer Portal från en enda sida.
2. **Förbyggda teman** - Börja med ett utvalt tema och anpassa det efter behov.
3. **Ljust och mörkt läge** - Definiera separata färgpaletter för varje läge.
4. **Förhandsvisning i realtid** - Se hur dina ändringar ser ut i checkout, Customer Portal och storefront innan du sparar.
5. **Åsidosättningar per sektion** - Finjustera enskilda sektioner (checkout, storefront, Customer Portal) utan att påverka de andra.
6. **Programmatisk kontroll** - Åsidosätt teman vid checkout-tillfället via API eller Checkout SDK.
7. **Kopiera testdesign till live** - Flytta en design som du har färdigställt i testläge till live-läge i ett steg.

## Kom igång

Navigera till **Inställningar → Design** i din Handelsinstrumentpanel. Design-sidan har fyra flikar:

| Flik | Syfte |
|-----|---------|
| **Allmänt** | Företagsnamn, logotyp, tema urval och globala avancerade inställningar |
| **Kassa** | Överstyr temainställningarna specifikt för kassasidan |
| **Butik** | Överstyr temainställningarna och konfigurera butikens layout |
| **Kundportal** | Överstyr temainställningarna för kundportalen |

## Allmänna inställningar

Fliken **Allmänt** styr din grundläggande varumärkesidentitet och globala tema.

<Frame>
  <img src="/images/design/general-advanced-settings.jpg" alt="Allmän flik som visar avancerade inställningar med typografi, färger och kantkonfiguration" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

### Grundkonfiguration

| Inställning | Beskrivning |
|---------|-------------|
| **Företagsnamn** | Namnet som visas i kassan, butiken och kundportalen |
| **Företagslogotyp** | Din varumärkeslogotyp som visas på alla kundvända sidor |
| **Tema** | Välj ett förbyggt tema som utgångspunkt |

### Avancerade inställningar

Expandera **Avancerade inställningar** för att komma åt detaljerade kontroller:

<Frame>
  <img src="/images/design/general-color-settings.jpg" alt="Avancerade inställningar expanderade som visar fullständig färgkonfiguration för ljusa och mörka lägen" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### Typografi

| Inställning | Alternativ | Beskrivning |
|---------|---------|-------------|
| **Primärt typsnitt** | Valfritt Google Font | Huvudtypsnitt för rubriker och brödtext |
| **Sekundärt typsnitt** | Valfritt Google Font | Accenttypsnitt för etiketter och sekundär text |
| **Teckenstorlek** | `xs`, `sm`, `md`, `lg`, `xl`, `2xl` | Global grundläggande teckenstorlek |
| **Teckenvikt** | `normal`, `medium`, `bold`, `extraBold` | Standard teckenvikt |

#### Färgkonfiguration

Definiera separata färgpaletter för **ljust läge** och **mörkt läge**. Varje läge stöder följande egenskaper:

| Egenskap | Beskrivning |
|----------|-------------|
| **Primär bakgrund** | Huvudsaklig bakgrundsfärg |
| **Sekundär bakgrund** | Sekundär bakgrund (flikar, kort) |
| **Primär text** | Huvudtextfärg |
| **Sekundär text** | Neddämpad textfärg |
| **Primär knapp** | Bakgrund för primära knappar |
| **Text på primär knapp** | Textfärg på primära knappar |
| **Sekundär knapp** | Bakgrund för sekundära knappar |
| **Text på sekundär knapp** | Textfärg på sekundära knappar |
| **Primär kant** | Huvudsaklig kantfärg |
| **Sekundär kant** | Accentfärg för kanter |

#### Kant

| Inställning | Beskrivning |
|---------|-------------|
| **Kantens radie** | Styr rundheten på inmatningar, knappar, flikar och kort (t.ex. `0` för skarpa hörn, `8px` för rundade, `16px` för kapsel-formade) |

## Sektion-överstyrningar

Varje sektionsflik (Kassa, Butik, Kundportal) har en **Överstyr tema**-växling. När den är aktiverad kan du anpassa den sektionens utseende oberoende av det globala temat.

### Kassaflik

<Frame>
  <img src="/images/design/checkout-tab.jpg" alt="Kassaflik som visar fullständig kassaförhandsvisning med produktinformation och betalningsformulär" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Överstyr typografi, färger och kantinställningar specifikt för kassaupplevelsen. Liveförhandsvisningen visar:
- Produktinformation och prissättning
- Expresskassa alternativ (Apple Pay, Google Pay)
- Val av betalningsmetod och kortformulär
- Rabattkodsfält och prisuppdelning

### Butiksflik

<Frame>
  <img src="/images/design/storefront-tab.jpg" alt="Butiksflik som visar butiks-URL, varumärkeskontroller och butiksförhandsvisning" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Konfigurera butiksspecifika inställningar:

| Inställning | Beskrivning |
|---------|-------------|
| **Butikens URL** | Din butikadress (t.ex. `store.dodopayments.com/your-store`) |
| **Butiksnamn** | Aktivera och ange namnet som visas i din butik |
| **Butikslogotyp** | Aktivera och ladda upp en logotyp för butikshuvudet |
| **Butiksbanner** | Aktivera och ladda upp en bannerbild |
| **Produktbeskrivning** | Aktivera för att visa eller dölja produktbeskrivningar på kort |
| **Överstyr tema** | Aktivera för att anpassa typografi, färger och kanter enbart för butiken |

### Kundportalflik

<Frame>
  <img src="/images/design/customer-portal-tab.jpg" alt="Kundportalsflik som visar prenumerationshantering, faktureringshistorik och betalningsmetodförhandsvisning" style={{ maxHeight: '500px', width: 'auto' }} />

Överstyr temat för kundportalen, som inkluderar:

## Kopiera design från testläge till live-läge

Testläge och live-läge har separata designkonfigurationer, så ett tema som du skapar under testning visas inte automatiskt för riktiga kunder. I stället för att återskapa det manuellt kan du kopiera din design från testläge till live-läge i ett steg.

Kopieringen omfattar **alla designytor** — allmänna inställningar, checkout, Customer Portal och åsidosättningar för storefront — samt din storefront-profilering.

<Warning>
Kopieringen skriver över den befintliga designen i live-läge. Granska din checkout och storefront i live-läge efter kopieringen för att bekräfta att allt ser ut som förväntat.
</Warning>
