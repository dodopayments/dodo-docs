<Info>
Inte varje misslyckad betalning innebär förlorade intäkter. Dodo Payments inkluderar tre återhämtningsverktyg som automatiskt vinner tillbaka misslyckade prenumerationsförnyelser och övergivna kassor – de flesta utan integrationsarbete.
</Info>

## Återhämtningsverktyg

<CardGroup cols={3}>
<Card title="Subscription Payment Retries" icon="arrow-rotate-right" href="/features/recovery/payment-retries">
Försök tyst med misslyckade prenumerationsförnyelser på ett smart återkommande schema.
</Card>

<Card title="Subscription Dunning" icon="repeat" href="/features/recovery/subscription-dunning">
E-posta kunder för att uppdatera sin betalningsmetod när en förnyelse misslyckas eller de avbryter.

</Card>

## Vilket verktyg återhämtar vad

Välj det verktyg som passar felscenariot:

| Scenario | Återhämtningsverktyg | Hur det återhämtar |
|----------|----------------|-----------------|
| Prenumeration **förnyelse** misslyckas på **mjuk avvisning** (otillräckliga medel, nätverksfel) | [Betalningsförsök](/features/recovery/payment-retries) | Laddar automatiskt om det befintliga kortet på ett återkommande schema |
| Prenumeration **förnyelse** misslyckas på **hård avvisning** (utgånget/ogiltigt kort) | [Prenumerationsdunning](/features/recovery/subscription-dunning) | E-postar kunden för att uppdatera deras betalningsmetod |
| Kund **avbryter** en prenumeration | [Prenumerationsdunning](/features/recovery/subscription-dunning) | E-postar kunden för att köpa igen |
| **Engångsköp** misslyckas eller överges | [Återställning av övergivna vagnar](/features/recovery/abandoned-cart-recovery) | E-postar kunden för att slutföra köpet |

## Hur de samarbetar

För prenumerationer kompletterar **betalningsförsök** och **dunning** varandra: försök återvinner tyst temporära mjuka avvisningar, medan dunning återvinner kunder vars betalningsmetod verkligen behöver uppdateras. Att aktivera båda ger dig den bredaste återhämtningstäckningen. För att förstå de underliggande felkoderna och när ett nytt försök är värt, se [Hantera betalningsfel](/developer-resources/handle-payment-failures).

## Analys

Spåra återhämtningsprestanda från **Återhämtnings**-fliken i **Analys**-sektionen på din instrumentpanel — inklusive med nytt försök, dunning och övergivna vagnar-mått. Se [Analys & Rapportering](/features/analytics-and-reporting) för fullständig översikt.
