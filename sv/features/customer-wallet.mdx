## Vad är kundplånböcker?

Kundplånböcker är konton för penningbelopp som innehåller riktiga medel för dina användare. Varje kund får automatiskt en när du skapar deras konto. Du kan använda dessa plånböcker för att:

- **Lagra förbetalda medel** för framtida prenumerationsbetalningar
- **Hantera återbetalningar** som plånbokssaldo i stället för kortåterbetalningar
- **Utfärda kampanjsaldon** som välkomstbonusar eller lojalitetsbelöningar
- **Tillämpa plånboksmedel på fakturor** automatiskt under faktureringen
- **Följa penningtransaktioner** med en detaljerad reskontrahistorik

<Info>
Varje kund får automatiskt en plånbok när du skapar deras konto. Plånböcker stöder valutorna USD, EUR och GBP, med separata monetära saldon för varje valuta.
</Info>

<Warning>
**Kundplånböcker ≠ kreditbaserad fakturering**

Kundplånböcker innehåller **verkliga monetära saldon** (USD, EUR, GBP) som kan användas för fakturor och prenumerationsbetalningar.

Om du vill följa virtuella användningsenheter (API-anrop, tokens, beräkningstimmar) kan du läsa mer om [kreditbaserad fakturering](/features/credit-based-billing) i stället.
</Warning>

## Så fungerar det

Kundplånböcker innehåller medel som kunder kan använda för sina köp. När en kund har en faktura eller en återkommande prenumerationsdebitering kontrolleras plånbokssaldot först. Alla tillgängliga medel tillämpas automatiskt på fakturan innan kundens primära betalningsmetod debiteras.

### Automatisk konfiguration

När du skapar en ny kund skapar Dodo Payments automatiskt en plånbok med nollsaldo. Den är redo att ta emot medel direkt via vårt API.

### Stöd för flera valutor

Varje plånbok kan innehålla saldon i olika valutor:

<ResponseField name="USD Balance" type="integer">
Saldo i amerikanska dollar (lagras i cent)
</ResponseField>

<ResponseField name="EUR Balance" type="integer">
Saldo i euro (lagras i cent)
</ResponseField>

<ResponseField name="GBP Balance" type="integer">
Saldo i brittiska pund (lagras i pence)
</ResponseField>

<Info>
För närvarande är endast saldon i **USD**, **EUR** och **GBP** tillgängliga. Den inhemska INR-plånboken har avvecklats – se [Utbetalningsstruktur](/features/payouts/payout-structure). INR stöds fortfarande som transaktionsvaluta för UPI-, RuPay- och indiska kortprenumerationer.
</Info>

## Exempel från verkligheten

### Återbetalning till plånboken

När en kund begär en återbetalning kan du lägga till beloppet i plånbokssaldot i stället för att genomföra en traditionell kortåterbetalning. På så sätt stannar pengarna i ditt ekosystem för framtida köp.

```javascript
async function refundToWallet(customerId, refundAmount, originalPaymentId) {
  await client.customers.wallets.ledgerEntries.create(customerId, {
    amount: refundAmount, // Amount in cents
    currency: 'USD',
    entry_type: 'credit',
    reason: `Refund for payment ${originalPaymentId}`,
    idempotency_key: `refund_${originalPaymentId}`
  });
}
```

### Välkomstbonus / kampanjsaldo

Ge nya kunder en monetär välkomstbonus för att uppmuntra deras första köp.

```javascript
async function addWelcomeBonus(customerId) {
  await client.customers.wallets.ledgerEntries.create(customerId, {
    amount: 1000, // $10.00 promotional balance
    currency: 'USD',
    entry_type: 'credit',
    reason: 'Welcome bonus - $10 promotional balance',
    idempotency_key: `welcome_${customerId}`
  });
}
```

### Prenumerationsbetalning från plånboken

Dra av pengar från en plånbok för att täcka en prenumerationsavgift eller ett manuellt köp.

```javascript
async function deductForPurchase(customerId, purchaseAmount, purchaseId) {
  try {
    await client.customers.wallets.ledgerEntries.create(customerId, {
      amount: purchaseAmount,
      currency: 'USD',
      entry_type: 'debit',
      reason: `Subscription charge - monthly billing`,
      idempotency_key: `charge_${purchaseId}`
    });
  } catch (error) {
    if (error.status === 400) {
      console.log('Insufficient wallet balance');
    }
  }
}
```

## Bästa praxis

### Förhindra dubbla transaktioner

Använd idempotency keys för att säkerställa att du inte råkar lägga till eller dra av pengar två gånger för samma händelse.

```javascript
async function addFundsSafely(customerId, amount, reason) {
  const idempotencyKey = `${reason}_${customerId}_${Date.now()}`;
  
  try {
    const result = await client.customers.wallets.ledgerEntries.create(customerId, {
      amount: amount,
      currency: 'USD',
      entry_type: 'credit',
      reason: reason,
      idempotency_key: idempotencyKey
    });
    
    // Replaying the same idempotency_key returns the original entry rather than
    // creating a duplicate, so no special duplicate handling is required.
    return { success: true, wallet: result };
  } catch (error) {
    if (error.status === 400) {
      // e.g. insufficient balance on a debit
      return { success: false, reason: 'insufficient_balance' };
    }

    throw error;
  }
}
```

### Kontrollera saldon före debitering

Verifiera att kunderna har tillräckligt med pengar innan du försöker behandla stora transaktioner från plånboken.

```javascript
async function checkBalanceBeforeOperation(customerId, requiredAmount) {
  const wallets = await client.customers.wallets.list(customerId);
  const usdWallet = wallets.items.find(w => w.currency === 'USD');
  
  if (!usdWallet || usdWallet.balance < requiredAmount) {
    throw new Error('Insufficient funds for this operation');
  }
  
  return usdWallet.balance;
}
```
