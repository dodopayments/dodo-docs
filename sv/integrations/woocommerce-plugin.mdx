## Introduktion

Dodo Payments WooCommerce-plugin ger en sömlös integration med din butik, vilket gör att du kan ta emot betalningar genom flera metoder inklusive UPI, kort, nätbank och digitala plånböcker. Denna omfattande guide kommer att vägleda dig genom installations- och konfigurationsprocessen.

## Steg-för-steg installationsguide

1. Ladda ner den senaste zip-filen av WooCommerce betalningsplugin.

    <Card title="Download Plugin" icon="download" href="https://github.com/dodopayments/dodo-woocommerce/releases">
    Skaffa den senaste versionen av vår WooCommerce-plugin
    </Card>

    Alternativt kan du installera direkt från WordPress plugin-katalogen:
    
    <Card title="WordPress Plugin Directory" icon="wordpress" href="https://wordpress.org/plugins/dodo-payments-for-woocommerce/">
    Installera Dodo Payments för WooCommerce från WordPress.org
    </Card>

2. Logga in på din WordPress-webbplats som administratör (vi antar att du redan har WooCommerce inställt)
3. Gå till **Plugins → Lägg till nytt plugin**

        <img src="/images/woocommerce/1.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
4. Klicka på knappen **Ladda upp plugin** och en filvalsdialog kommer att visas

    <Frame>
        <img src="/images/woocommerce/2.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />

    <Frame>

5. Klicka på **Bläddra...** och välj zip-filen du laddade ner
6. Klicka på knappen **Installera nu** för att börja installationsprocessen

    <Frame>

## Konfigurationsguide

### Ställa in API-nycklar och webhooks

1. Navigera till **WooCommerce → Inställningar → Betalningar** eller klicka på knappen **Betalningar** i vänstra sidofältet under WooCommerce-menyalternativet
    
    <Frame>
        <img src="/images/woocommerce/6.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
    <Frame>
        <img src="/images/woocommerce/7.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
2. Aktivera betalningsleverantören **Dodo Payments** om den inte redan är aktiverad, klicka sedan på **Hantera** för att konfigurera pluginet
3. Du kommer att se olika konfigurationsalternativ, var och en med förklarande text. Börja med att ställa in din Live API Key
    
    <Frame>
        <img src="/images/woocommerce/8.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
4. Logga in på din Dodo Payments-instrumentpanel i **Live Mode**, navigera sedan till **Dodo Payments (Live Mode) > Developer > API Keys** eller besök [denna direkta länk](https://app.dodopayments.com/developer/api-keys) och klicka på **Lägg till API-nyckel**
    
    <Frame>
        <img src="/images/woocommerce/9.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
5. Ge din API-nyckel ett beskrivande namn och klicka på **Skapa**
    
    <Frame>
        <img src="/images/woocommerce/10.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
6. Kopiera den genererade API-nyckeln och klistra in den i fältet **Live API Key** i dina WooCommerce-plugin-inställningar
    
    <Frame>
        <img src="/images/woocommerce/11.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
    <Frame>
        <img src="/images/woocommerce/12.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
7. Nästa steg, sätt upp Webhook Signing Key för att möjliggöra betalningsstatussynkronisering mellan Dodo Payments och WooCommerce
8. Scrolla till botten av pluginets inställningssida och kopiera webhook-URL:en som visas där
    
    <Frame>
        <img src="/images/woocommerce/13.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
9. Gå tillbaka till din Dodo Payments-instrumentpanel och navigera till **Dodo Payments (Live Mode) > Developer > Webhooks** och klicka på **Lägg till Webhook**
    
    <Frame>
        <img src="/images/woocommerce/14.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
10. Klistra in URL:en du kopierade i steg 8 i dialogrutan och klicka på **Lägg till Webhook**
    
    <Frame>
        <img src="/images/woocommerce/15.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
11. Efter att du skapat webhook, klicka på ögonikonen bredvid den dolda **Signing Key** för att avslöja och kopiera den
    
    <Frame>
        <img src="/images/woocommerce/16.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
12. Klistra in underskriftsnyckeln i fältet **Live Webhook Signing Key** i dina plugin-inställningar och spara ändringarna
    
    <Frame>
        <img src="/images/woocommerce/17.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
    
13. Granska de återstående inställningarna som **Global Tax Category** och **All Prices are Tax Inclusive**, eftersom dessa alternativ bestämmer hur produkter synkas från WooCommerce till Dodo Payments. Observera att **Test API Key** och **Test Webhook Signing Key** endast behövs om du planerar att använda Test Mode
    
    <Frame>
        <img src="/images/woocommerce/18.webp" alt="Dodo Payments for WooCommerce Plugin" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>

## Nyckelfunktioner

- **Sömlös kassaupplevelse**: Omdirigera kunder till en säker, optimerad kassasida
- **Flera betalningsmetoder**: Stöd för olika lokala och internationella betalningsalternativ
- **Uppdateringar i realtid**: Omedelbar synkronisering av orderstatus via webhooks
- **Detaljerade transaktionsregister**: Omfattande betalningshistorik i din WooCommerce-instrumentpanel
- **Stöd för flera valutor**: Acceptera betalningar i flera valutor

## Felsökning

### Vanliga problem

1. **Betalningsbehandlingsfel**
   - Verifiera att API-nycklar är korrekt konfigurerade
   - Se till att webhook-URL:en är korrekt inställd
   - Kontrollera att ditt SSL-certifikat är giltigt

2. **Webhook-synkroniseringsproblem**
   - Bekräfta att webhook-signeringstangenten matchar
   - Granska serverloggar för potentiella fel
   - Verifiera att din server kan ta emot inkommande webhook-förfrågningar

## Underhålls bästa praxis

1. Uppdatera regelbundet pluginet för säkerhetsuppdateringar och nya funktioner
2. Testa alla betalningsflöden i Test Mode innan du behandlar skarpa transaktioner
3. Håll WordPress och WooCommerce uppdaterade till de senaste versionerna
4. Genomför regelbundna säkerhetskopieringar av webbplatsen
5. Övervaka transaktionsloggar efter ovanlig aktivitet
6. Förvara API-nycklar säkert och dela dem aldrig offentligt
