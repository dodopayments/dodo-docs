## Introduktion

[ParityDeals](https://www.paritydeals.com/) är en plattform som visar platsbaserade rabattbanners för berättigade besökare på din webbplats och automatiskt genererar matchande rabattkoder i Dodo Payments. När en besökare ser bannern får de en kod som de kan använda i kassan. Dessa koder visas i din Dodo Payments-dashboard under **Sales → Discounts**.

<Note>
Dodo Payments har inbyggd [Purchasing Power Parity](/features/purchasing-power-parity), som sänker priserna per land i kassan utan banner eller script. ParityDeals är till för merchants som vill visa en synlig rabattbanner på sin egen webbplats eller köra kampanjer under högtider och tidsbegränsade erbjudanden.
</Note>

## Så fungerar det

ParityDeals identifierar en besökares plats, visar en anpassningsbar rabattbanner på din webbplats och genererar en rabattkod som kan användas i kassan. Koden skapas automatiskt i ditt Dodo Payments-konto och fungerar på de produkter du konfigurerar.

1. En besökare kommer till din webbplats och ParityDeals identifierar deras plats.
2. Om besökaren är berättigad till rabatt visas en banner med en platsbaserad kod.
3. Besökaren använder koden i kassan och Dodo Payments tillämpar rabatten.
4. Koden visas i din dashboard under **Sales → Discounts**.

## ParityDeals jämfört med inbyggd PPP

Inbyggd Purchasing Power Parity är det rekommenderade sättet att prissätta per land. Välj ParityDeals när du specifikt behöver en rabattbanner på din egen webbplats eller vill köra kampanjer under högtider och tidsbegränsade kampanjer.

| | Inbyggd PPP | ParityDeals |
| :--- | :--- | :--- |
| Så fungerar det | En procentsats per land som tillämpas i kassan | En procentuell rabatt som tillämpas via en kod |
| Var det konfigureras | Inbyggt i Dodo Payments | ParityDeals-dashboarden |
| Banner eller script på din webbplats | Krävs inte | Krävs |
| Erbjudanden under högtider och tidsbegränsade erbjudanden | Nej | Ja |
| Bäst för | Korrekta priser utan ändringar på webbplatsen | Kampanjbanners och säsongsbaserade erbjudanden |

<Info>
Du kan inte bädda in ParityDeals-bannern i en checkout eller storefront som hostas av Dodo Payments, eftersom anpassade script inte stöds där. Bannern ska placeras på din egen webbplats eller i din app.
</Info>

## Förutsättningar

Innan du konfigurerar denna integration bör du se till att du har:

1. Ett [Dodo Payments-konto](https://app.dodopayments.com)
2. Ett [ParityDeals-konto](https://app.paritydeals.com/)
3. En Dodo Payments API key

## Kom igång

<Steps>
  <Step title="Sign up on ParityDeals">
    Besök [app.paritydeals.com](https://app.paritydeals.com/) och skapa ett konto.
  </Step>

  <Step title="Create Deals">
    När du har loggat in letar du upp alternativet för att skapa erbjudanden. Välj **"Create Deals via Dodo Payments"** i dropdown-menyn.

    <Frame>
      <img src="/images/integrations/paritydeals/create-deals.png" alt="Skapa erbjudanden via Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    Logga in på din **Dodo Payments-dashboard** och gå till **Developers → API Keys**. Klicka på **"Create New API"**.

    <Tip>
      Ge din API key ett beskrivande namn (t.ex. 'ParityDeals') så att du kan identifiera den senare.
    </Tip>

    <Frame>
      <img src="/images/integrations/paritydeals/api-key.png" alt="Skapa en ny API key i Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    Kopiera API key som du skapade och klistra in den i ParityDeals-gränssnittet för att upprätta anslutningen till ditt Dodo Payments-konto.

    <Frame>
      <img src="/images/integrations/paritydeals/connect-api-key.png" alt="Ansluta API key till ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    När anslutningen är klar hämtar ParityDeals din produktkatalog från Dodo Payments. Välj de produkter som du vill koppla till dina erbjudanden.

    <Frame>
      <img src="/images/integrations/paritydeals/select-products.png" alt="Välja produkter för ParityDeals" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    Ange webbplatsens URL och välj valfritt specifika målsidor där rabattbannern ska visas. Välj sedan önskad typ av erbjudande:
    - Platsbaserade erbjudanden
    - Erbjudanden under högtider
    - Tidsbegränsade flash-erbjudanden

    <Frame>
      <img src="/images/integrations/paritydeals/deal-settings.png" alt="Konfigurera inställningar för erbjudandet" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    Välj de länder som du vill erbjuda lokalanpassade rabatter till och ange rabattprocenten för varje land. ParityDeals tillhandahåller rekommenderade standardvärden som du kan justera efter behov.

    <Frame>
      <img src="/images/integrations/paritydeals/country-rules.png" alt="Ange landbaserade rabattregler" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    Utforma din rabattbanner genom att anpassa texten, välja färger och layout samt välja bannerns placering (längst upp eller längst ned på sidan). Bannern visas för berättigade besökare baserat på de regler du har konfigurerat.

    <Frame>
      <img src="/images/integrations/paritydeals/customize-banner.png" alt="Anpassa rabattbannern" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    När du har sparat erbjudandet genererar ParityDeals ett script. Lägg till detta script i webbplatsens kod (vanligtvis i avsnittet `<head>`). Detta script identifierar automatiskt besökarnas platser och visar rätt rabattbanner.

    <Frame>
      <img src="/images/integrations/paritydeals/script.png" alt="ParityDeals-integrationsscript" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>
