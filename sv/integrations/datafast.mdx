## Introduktion

DataFast är ett intäktsfokuserat analysverktyg som hjälper dig att upptäcka vilka marknadsföringskanaler som driver betalande kunder. Genom att integrera Dodo Payments med DataFast kan du attributera intäkter till dina trafik källor, identifiera högvärdiga kundsegment och fatta datadrivna beslut för att växa ditt företag.

<Info>
Den här integrationen kräver din DataFast API-nyckel, som du kan skaffa från din [DataFast-instrumentpanel](https://datafa.st/).
</Info>

## Hur Det Fungerar

DataFast spårar besökare genom ett unikt besökar-ID som lagras i en cookie. För att attributera intäkter till marknadsföringskanaler behöver du:

1. **Fånga DataFast:s besökar-ID** från `datafast_visitor_id`-kakan när du skapar checkout-sessioner
2. **Lagra besökar-ID:t** i din betalningsmetadata
3. **Skicka betalningsdata till DataFast** när betalningar lyckas via deras Payment API

Detta gör att DataFast kan matcha lyckade betalningar med den ursprungliga trafik källan, vilket ger dig fullständig intäktsattribution.

## Implementeringsguide

### Steg 1: Lägg till Besökar-ID i Kassa Metadata

När du skapar en kassa session, fånga DataFast besökar-ID från cookien och inkludera det i din betalningsmetadata.

<Note>
Exemplen nedan använder `POST /payments`, som är **föråldrad**. Den fungerar fortfarande för befintliga integrationer, men nya integrationer bör använda [Checkout Sessions](/developer-resources/checkout-session) (`POST /checkouts`) — `metadata` skickas på samma sätt.
</Note>

<CodeGroup>

```typescript Next.js
import { cookies } from 'next/headers';
import { dodopayments } from '@/lib/dodopayments';

export async function createCheckout(productId: string) {
  // Capture DataFast visitor ID from cookie
  const datafastVisitorId = cookies().get('datafast_visitor_id')?.value;

  const payment = await dodopayments.payments.create({
    product_cart: [{ product_id: productId, quantity: 1 }],
    // ... other payment configuration
    metadata: {
      datafast_visitor_id: datafastVisitorId, // Store visitor ID in metadata
    },
  });

  return payment;
}
```

```javascript Express.js
const express = require('express');
const router = express.Router();

router.post('/create-checkout', async (req, res) => {
  // Capture DataFast visitor ID from cookie
  const datafastVisitorId = req.cookies?.datafast_visitor_id;

  const payment = await dodopayments.payments.create({
    product_cart: [{ product_id: req.body.productId, quantity: 1 }],
    // ... other payment configuration
    metadata: {
      datafast_visitor_id: datafastVisitorId, // Store visitor ID in metadata
    },
  });

  res.json({ payment });
});
```

## Exempel på transformationskod

### Grundläggande betalningsattribuering

```javascript basic_payment.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    // Only send to DataFast if visitor ID exists in metadata
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      webhook.payload = {
        amount: payment.total_amount / 100, // Convert from cents to dollars
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

### Hantera valutor utan decimaler

Vissa valutor (till exempel JPY) använder inte decimaler. Justera beloppsberäkningen därefter:

```javascript zero_decimal.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      // Zero decimal currencies: JPY, KRW, CLP, etc.
      const zeroDecimalCurrencies = ['JPY', 'KRW', 'CLP', 'VND', 'UGX', 'MGA'];
      const isZeroDecimal = zeroDecimalCurrencies.includes(payment.currency);
      
      webhook.payload = {
        amount: isZeroDecimal 
          ? payment.total_amount // Use amount as-is for zero decimal currencies
          : payment.total_amount / 100, // Convert from cents for other currencies
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

### Prenumerationsbetalningar

För återkommande prenumerationsbetalningar kan du spåra varje betalning:

```javascript subscription_payment.js icon="js" expandable
function handler(webhook) {
  if (webhook.eventType === "payment.succeeded") {
    const payment = webhook.payload.data;
    
    // Check if this is a subscription payment
    const isSubscription = payment.subscription_id !== null;
    
    if (payment.metadata && payment.metadata.datafast_visitor_id) {
      webhook.payload = {
        amount: payment.total_amount / 100,
        currency: payment.currency,
        transaction_id: payment.payment_id,
        datafast_visitor_id: payment.metadata.datafast_visitor_id,
        // Optional: Add subscription context
        ...(isSubscription && {
          subscription_id: payment.subscription_id,
        }),
      };
    } else {
      // Cancel dispatch if no visitor ID (prevents unnecessary API calls)
      webhook.cancel = true;
    }
  }
  return webhook;
}
```

## Bästa praxis

<Tip>
**Fånga besökar-ID:t tidigt**: Spara DataFast-besökar-ID:t så tidigt som möjligt i ditt checkout-flöde för att säkerställa korrekt attribuering, även om användaren lämnar sidan och återkommer senare.
</Tip>

- **Inkludera alltid besökar-ID:t i metadata**: Utan besökar-ID:t kan DataFast inte attribuera intäkter till marknadsföringskanaler
- **Hantera valutor utan decimaler**: Vissa valutor (JPY, KRW med flera) använder inte decimaler—justera beloppsberäkningen därefter
- **Testa med exempelbetalningar**: Kontrollera att integrationen fungerar korrekt innan den tas i produktion
- **Övervaka din DataFast-dashboard**: Kontrollera att betalningar visas korrekt med rätt attribuering
- **Använd webhook-omförsök**: DataFast's Payment API är idempotent, så omförsök är säkra om en webhook misslyckas

## Felsökning

<AccordionGroup>
<Accordion title="Payments not appearing in DataFast">
- Kontrollera att din DataFast API key är korrekt och aktiv
- Kontrollera att `datafast_visitor_id` fångas upp och lagras i betalningsmetadata
- Säkerställ att webhook-transformationen formaterar nyttolasten korrekt
- Kontrollera att webhooken utlöses vid händelser av typen `payment.succeeded`
- Kontrollera DataFast-dashboarden efter eventuella felmeddelanden eller API-loggar
</Accordion>

<Accordion title="Revenue attribution not working">
- Bekräfta att DataFast-spårningsskriptet är installerat och fungerar på din webbplats
- Kontrollera att cookien `datafast_visitor_id` ställs in korrekt
- Kontrollera att besökar-ID:n överensstämmer mellan skapandet av checkouten och slutförandet av betalningen
- Säkerställ att du fångar upp besökar-ID:t innan du skapar checkout-sessionen
- Läs DataFast's [dokumentation för Payment API](https://datafa.st/docs/payments-api) för ytterligare vägledning
</Accordion>

<Accordion title="Transformation errors">
- Validera att JSON-strukturen överensstämmer med DataFast's Payment API-format
- Kontrollera att alla obligatoriska fält (`amount`, `currency`, `transaction_id`, `datafast_visitor_id`) finns med
- Säkerställ att beloppet konverteras korrekt (dividera med 100 för de flesta valutor, utom valutor utan decimaler)
- Kontrollera att URL:en till API-endpointen är korrekt: `https://datafa.st/api/v1/payments`
- Testa transformationen med exempel på webhook-nyttolaster
</Accordion>

<Accordion title="Currency conversion issues">
- För valutor utan decimaler (JPY, KRW, CLP, VND, UGX, MGA) skickar du beloppet som det är utan att dividera med 100
- För alla andra valutor dividerar du beloppet med 100 för att konvertera från cent till basenheten
- Kontrollera en extra gång att valutakoden följer ISO 4217-formatet (till exempel "USD", "EUR", "JPY")
</Accordion>
</AccordionGroup>
