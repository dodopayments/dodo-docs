## Introduktion

[Evendeals](https://www.evendeals.com/integrations/dodo-payments) är en plattform som skapar och synkroniserar platsbaserade rabattkuponger baserade på purchasing power parity till ditt Dodo Payments-konto. Den har stöd för både engångsprodukter och prenumerationsprodukter och genererar automatiskt rabattkoder som roteras enligt ett schema du definierar.

  <img src="/images/integrations/evendeals/hero.png" alt="Översikt över Evendeals-integrationen med Dodo Payments" style={{ maxHeight: '500px', width: 'auto' }} />

<Note>
Dodo Payments har inbyggt stöd för [Purchasing Power Parity](/features/purchasing-power-parity), vilket sänker priserna per land i kassan utan någon banner, något script eller några kupongkoder att hantera. Evendeals är till för handlare som specifikt vill använda rabattkodslösningen med automatisk kupongrotation.
</Note>

## Så fungerar det

Evendeals ansluter till ditt Dodo Payments-konto via en API key. När anslutningen är klar konfigurerar du procentuella rabatter för varje landgrupp. Evendeals skapar sedan automatiskt rabattkoder i ditt Dodo Payments-konto och roterar dem enligt ett schema du anger (baserat på tidsintervall, antal inlösningar eller antal visningar) för att förhindra missbruk.

## Evendeals jämfört med inbyggd PPP

Inbyggd Purchasing Power Parity är det rekommenderade sättet att prissätta per land, eftersom det inte kräver några kupongkoder och inte kan delas eller missbrukas. Välj Evendeals när du specifikt vill använda rabattkodslösningen.

| | Inbyggd PPP | Evendeals |
| :--- | :--- | :--- |
| Så fungerar det | En procentsats per land som tillämpas i kassan | En procentuell rabatt som tillämpas genom en kod |
| Var det konfigureras | Inbyggt i Dodo Payments | Evendeals kontrollpanel |
| Banner eller script krävs | Krävs inte | Krävs inte |
| Kupongrotation / automatisk uppdatering | Inte tillämpligt | Ja |
| Stöd för prenumerationer | Ja | Ja |
| Bäst för | Korrekt prissättning utan ändringar på webbplatsen | Rabattkodslösning med automatisk rotation |

## Viktiga funktioner

- **Automatisk kupongsynkronisering** — Kuponger skapas och hanteras automatiskt i Dodo Payments
- **Procentuella rabatter** — Erbjud procentuella rabatter per landgrupp
- **Stöd för prenumerationer** — Rabatter tillämpas under alla prenumerationsperioder
- **Regler för automatisk uppdatering** — Rotera kupongkoder automatiskt baserat på tidsintervall, antal inlösningar eller antal visningar för att förhindra missbruk

<Info>
Rabattkoder som skapas av Evendeals visas automatiskt i din Dodo Payments-kontrollpanel under **Sales → Discounts**.
</Info>

## Förutsättningar

Innan du konfigurerar denna integration ska du se till att du har:

1. Ett [Dodo Payments-konto](https://app.dodopayments.com)
2. Ett [Evendeals-konto](https://www.evendeals.com/signin)
3. En API key för Dodo Payments

## Kom igång

<Steps>
  <Step title="Create a Dodo Payments API Key">
    Gå till **Developers → API Keys** i din Dodo Payments-kontrollpanel och klicka på **Create New API**. Ge den ett beskrivande namn (t.ex. "Evendeals") så att du kan identifiera den senare.
  </Step>

  <Step title="Connect in Evendeals">
    Gå till din [Evendeals-kontrollpanel](https://www.evendeals.com/signin), navigera till **Integrations**, leta reda på Dodo Payments-kortet och klistra in din API key.
  </Step>

  <Step title="Configure Regional Discounts">
    Ange procentuella rabatter för varje landgrupp och klicka på synkronisera. Evendeals skapar kuponger i Dodo Payments automatiskt.

    <Check>
    Efter synkroniseringen öppnar du **Sales → Discounts** i din Dodo Payments-kontrollpanel för att bekräfta att de genererade kupongerna visas. Varje kupong har ett identifierbart Evendeals-prefix.
    </Check>
  </Step>
</Steps>
