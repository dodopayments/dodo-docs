## Nya Funktioner

### 1. **Kommunikationspreferenser**

   Ta kontroll över hur du får notiser med våra förbättrade Kommunikationspreferenser. Konfigurera email, push- och in-app-notiser för att passa din arbetsflöde.

   <Frame>
     <img src="/images/communication-preferences/overview.png" alt="Översikt över Kommunikationspreferenser som visar notisinställningar" />
   </Frame>

   **Huvudfunktioner**

   - **Förbättrade e-postdesigner**: Fräscha, moderna e-postmallar med tydliga uppmaningar och förbättrad läsbarhet
   - **Push-notiser**: Få omedelbara meddelanden på din mobila enhet för kritiska händelser som nya försäljningar, tvister och utbetalningar
   - **Granulära kontroller**: Välj exakt vilka händelser som utlöser notiser och genom vilka kanaler
   - **Flermail-support**: Lägg till flera e-postadresser för att ta emot notiser
   - **Kundens e-postpreferenser**: Konfigurera vilka e-postmeddelanden dina kunder får

   **Notiskategorier**

   | Kategori | Beskrivning |
   |----------|-------------|
   | **Försäljning & Betalningar** | Nya försäljningar, lyckade betalningar, misslyckade betalningar |
   | **Utbetalningar & Återbetalningar** | Utbetalningsslutföranden, återbetalningsförfrågningar, återbetalningsslutföranden |
   | **Prenumerationer** | Nya prenumerationer, förnyelser, avbokningar, planändringar |
   | **Tvister** | Tvist öppnad, bevis krävs, tvist löst |

   <Check>
   Resultat: Håll dig informerad om ditt företag med notiser som levereras exakt så som och när du vill ha dem.
   </Check>

   Lär dig mer: [Guide till Kommunikationspreferenser](/features/communication-preferences)

### 2. **Anpassade Fält i Kassa-sessioner**

   Samla in ytterligare information från kunder under kassan med anpassade fält. Lägg till textinmatningar, rullgardinsmenyer, datum och mer för att samla den data du behöver.

   **Stödda Fälttyper**

   | Typ | Beskrivning | Användningsfall |
   |------|-------------|----------|
   | `text` | En-rads textinmatning | Företagsnamn, beställningsanteckningar |
   | `number` | Numerisk inmatning | Kvantitet, ålder |
   | `email` | E-postinmatning med validering | Faktureringskontaktens e-post |
   | `url` | URL-inmatning med validering | Webbplats, social profil |
   | `date` | Datumväljare | Leveransdatum, evenemangdatum |
   | `dropdown` | Val från fördefinierade alternativ | Storlek, färg, plan typ |
   | `boolean` | Kryssruta för ja/nej-värden | Accepterande av villkor, nyhetsbrevval |

   **Hur Det Fungerar**

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     custom_fields: [
       {
         name: 'company_name',
         label: 'Company Name',
         type: 'text',
         required: true
       },
       {
         name: 'team_size',
         label: 'Team Size',
         type: 'dropdown',
         options: ['1-10', '11-50', '51-200', '200+'],
         required: true
       },
       {
         name: 'newsletter',
         label: 'Subscribe to our newsletter',
         type: 'boolean',
         required: false
       }
     ],
     return_url: 'https://yoursite.com/success'
   });
   ```

   **Fördelar**

   - **Flexibel datainsamling**: Samla in all information som behövs för uppfyllelse eller personalisering
   - **Inbyggd validering**: E-post och URL-fält validerar automatiskt inmatningsformat
   - **Krav/valfritt kontroll**: Markera fält som obligatoriska eller valfria beroende på dina behov
   - **Webhook-leverans**: Värden för anpassade fält ingår i betalnings-webhook-händelser

   <Info>
   Värden för anpassade fält returneras i `custom_fields`-objektet inom betalnings- och kassa-sessionrespons.

   Lär dig mer: [Anpassade Fält i Kassa-sessioner](/developer-resources/checkout-session#custom-fields)

### 3. **Utökat Stöd för Kassaspråk**

   Kassasidan stöder nu **21 språk**, upp från 16. Nå fler kunder på deras modersmål för en bättre kassaupplevelse.

   **Nya Språk Tillagda**

   | Språk | Kod |
   |----------|------|
   | Koreanska | `ko` |
   | Malajiska | `ms` |
   | Rumänska | `ro` |
   | Ryska | `ru` |
   | Thailändska | `th` |

   **Alla Stödda Språk**

   Arabiska, Kinesiska, Holländska, Engelska, Franska, Tyska, Hindi, Indonesiska, Italienska, Japanesiska, Koreanska, Malajiska, Portugisiska, Rumänska, Ryska, Spanska, Svenska, Thailändska, Turkiska, Ukrainska, Vietnamesiska.

   **Tvinga ett Specifikt Språk**

   Använd parametern `force_language` för att åsidosätta automatisk språkdeteckning:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     force_language: 'ko', // Force Korean language
     return_url: 'https://yoursite.com/success'
   });
   ```

   <Tip>
   Som standard detekterar kassasidan automatiskt kundens föredragna språk utifrån deras webbläsarinställningar. Använd `force_language` när du vill säkerställa konsekvens med din webbplats språk.
   </Tip>

   Lär dig mer: [Stöd för Kassaspråk](/features/checkout#supported-languages)
