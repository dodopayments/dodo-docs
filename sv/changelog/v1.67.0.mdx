## Nya funktioner 🚀

1. **Blandad Varukorg Kassa: Engångs- och Prenumerationsprodukter i en Varukorg**  
   Kassan stöder nu att kombinera både engångsbetalningsprodukter och prenumerationsprodukter i en enda varukorg, vilket öppnar upp nya kraftfulla faktureringsanvändningsfall.
   
   <Frame>
   <img src="/images/changelog/mixed-checkout.png" alt="Blandad kassa med engångs- och prenumerationsprodukter" style={{ maxHeight: '500px', width: 'auto' }} />
   </Frame>
   
   ### Vad Detta Möjliggör
   
   - **Setupavgifter + prenumerationer**: Debitering av en engångs-setup-avgift tillsammans med en återkommande prenumeration i en enda kassa
   - **Paket med återkommande komponenter**: Sälj en produkt (engångs) tillsammans med pågående tillgång till tjänster (prenumeration)
   - **Kurs + medlemskapspaket**: Erbjudande om köp av en kurs med valfri gemenskapsmedlemskapsprenumeration
   - **Livstid + tilläggsprenumerationer**: Kombinera livstidstillgång till produkt med valfria återkommande premiumfunktioner
   
   ### Hur Det Fungerar
   
   Lägg helt enkelt till både engångs- och prenumerationsprodukter till din kassasession:
   

   ```javascript
   const session = await client.checkoutSessions.create({
     product_cart: [
       // One-time setup fee
       { product_id: 'prod_setup_fee', quantity: 1 },
       // Monthly subscription
       { product_id: 'prod_monthly_plan', quantity: 1 }
     ],
     customer: {
       email: 'customer@example.com',
       name: 'Jane Doe'
     },
     return_url: 'https://yourapp.com/success'
   });
   ```

   
   <Check>
   Resultat: Ett enda kassaflöde som hanterar engångsbetalningen och initierar prenumerationen — vilket minskar friktion och ökar konverteringsgraden.
   </Check>
   
   <Info>
   När du blandar produkttyper debiteras engångsbetalningen omedelbart medan prenumerationen följer sin konfigurerade faktureringscykel (inklusive eventuell testperiod du har angett).
   </Info>
   
   Läs mer: [Checkout Sessions](/developer-resources/checkout-session)

2. **Enhetlig Kundportal**  
   
   En ny centraliserad kundportal på [customer.dodopayments.com](https://customer.dodopayments.com) där kunder kan se och hantera alla sina köp och prenumerationer över olika företag på Dodo Payments.
   
   <Frame>
   <img src="/images/changelog/unified-customer-portal.png" alt="Enhetlig Kundportal" style={{ maxHeight: '500px', width: 'auto' }} />
   </Frame>
   
   ### Portalens Funktioner
   
   - **Synlighet över företag**: Se alla köp och prenumerationer från alla företag som använder Dodo Payments på ett ställe
   - **Centraliserad prenumerationshantering**: Hantera prenumerationer över olika handlare från en enda instrumentpanel
   - **Enhetlig faktureringshistorik**: Få tillgång till fakturor och betalningshistorik från alla dina köp
   - **Single sign-on upplevelse**: Logga in en gång med din e-post för att få tillgång till köp från alla Dodo Payments-handlare
   
   ### Hur Det Fungerar
   
   Kunder besöker helt enkelt [customer.dodopayments.com](https://customer.dodopayments.com) och anger sin e-postadress. De får en säker inloggningslänk som ger tillgång till alla sina köp över Dodo Payments ekosystem.
   
   <Tip>
   Den Enhetliga Kundportalen kompletterar företagspecifika kundportaler. Kunder kan fortfarande få tillgång till individuella handlarportal för en varumärkesanpassad upplevelse, eller använda den enhetliga portalen för en sammanställd översikt.
   </Tip>
   
   <Note>
   Den enhetliga portalen använder samma e-postbaserade autentisering som företagspecifika portaler, vilket säkerställer en konsekvent och säker upplevelse.
   </Note>

3. **Invoice ID in Payment Response**  
   Betalningssvaret innehåller nu ett `invoice_id`-fält, vilket gör det enklare att stämma av betalningar med fakturor och integrera med ekonomisystem.
   

   ```json
   {
     "payment_id": "pay_2IjeQm4hqU6RA4Z4kwDee",
     "status": "succeeded",
     "invoice_id": "inv_2IsUnWGtRKFLxk7xAQeyt",
     "total_amount": 9900,
     "currency": "USD",
     // ... other fields
   }
   ```

   
   ### Användningsfall
   
   - **Redovisningsintegration**: Koppla betalningar direkt till fakturor i ditt redovisningsprogram
   - **Kundsupport**: Hitta snabbt fakturan som är kopplad till en betalning när du hanterar supportärenden
   - **Avstämning**: Förenkla den ekonomiska avstämningen genom att matcha betalningar mot fakturor programmässigt
   - **Efterlevnad**: Behåll korrekta register som länkar betalningar till deras motsvarande skattefakturor
   
   <Info>
   `invoice_id`-fältet använder Indien-specifika faktura-ID:n när sådana finns tillgängliga, vilket säkerställer efterlevnad av lokala faktureringskrav.
   </Info>
   
   Läs mer: [Get Payment Detail API](/api-reference/payments/get-payments-1)
