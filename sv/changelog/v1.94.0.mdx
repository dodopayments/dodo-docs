## Nya Funktioner

### 1. **Återhämtning av övergivna kundvagnar**

Upptäck automatiskt ofullständiga eller misslyckade köp och skicka riktade e-postsekvenser för att få kunderna tillbaka. ACR övervakar betalningar som inte har lyckats efter 60 minuter och klassificerar dem som antingen **betalning misslyckades** eller **utcheckning ofullständig**, och skickar sedan upp till 3 konfigurerbara återhämtningsmail per sekvens.

<Frame>
<img src="/images/recovery/recovery-analytics.png" alt="Återhämtningsanalysinstrumentbräda som visar antal övergivna utcheckningar, återhämtningsgrader och återhämtad inkomst" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Huvudfunktioner:
- **Två e-postsekvenser** — Payment Failed och Checkout Incomplete, vardera med upp till 3 mail
- **Återhämtningsrabatter** — Möjlighet att automatiskt generera engångsrabattkoder för att uppmuntra återhämtning
- **Kundåterhämtningssida** — Unika återhämtningslänkar tar kunder till en dedikerad sida för att slutföra sitt köp
- **Återhämtningsanalys** — Spåra övergivna utcheckningsantal, återhämtningsgrader, återhämtad inkomst och per-mail/per-produkt-analyser

<Tip>
Börja med standardinställningarna för e-posttider (1 timme, 24 timmar, 72 timmar) och iterera baserat på dina återhämtningsanalyser.
</Tip>

Läs mer: [Återhämtning av övergivna kundvagnar](/features/recovery/abandoned-cart-recovery)

### 2. **Prenumerationshantering**

Skicka automatiskt e-postsekvenser för att återhämta förlorade eller annullerade prenumerationer. Hantering aktiveras när en prenumeration hamnar **on hold** (betalningsmisslyckande) eller **avbeställs** av kunden från kundportalen.

Huvudfunktioner:
- **Två e-postsekvenser** — On Hold och Cancelled, vardera med upp till 4 mail
- **Automatisk debitering** — När en kund uppdaterar sin betalningsmetod debiteras utestående skulder automatiskt
- **Konfigurerbar timing** — Standardintervaller vid 1, 3, 5 och 7 dagar, helt anpassningsbara per mail

Läs mer: [Prenumerationshantering](/features/recovery/subscription-dunning)

### 3. **Rabattmetadata**

Du kan nu bifoga **metadata** (nyckel-värde-par) till rabatter när du skapar eller uppdaterar dem via API:et. Använd metadata för att tagga rabatter efter kampanj, källa eller intern referens för spårning och avstämning.

```typescript
const discount = await client.discounts.create({
  type: 'percentage',
  amount: 1500, // 15%
  code: 'SUMMER2025',
  metadata: {
    campaign: 'summer_promo',
    source: 'email_blast'
  }
});
```

Läs mer: [Rabattkoder](/features/discount-codes) | [Metadataguide](/api-reference/metadata)

### 4. **Återhämtningswebhooks**

Nya webhook-händelser för att spåra återhämtningslivscykeln:

| Händelse | Beskrivning |
|-------|-------------|
| `abandoned_checkout.detected` | En övergiven utcheckning har upptäckts |
| `abandoned_checkout.recovered` | Kund slutförde betalning genom en återhämtningslänk |
| `dunning.started` | Ett hanteringsförsök har startats för en prenumeration |
| `dunning.recovered` | Kund uppdaterade betalningsmetod och betalningen lyckades |

Läs mer: [Återhämtningswebhooks](/developer-resources/webhooks/intents/recovery)

### 5. **Pix-betalningar för Brasilien**

Acceptera **Pix** — Brasiliens omedelbara betalningssystem skapat av Brasiliens centralbank — i din Dodo Payments-kassa. Pix är nu den mest använda betalningsmetoden i Brasilien, och överträffar både kreditkort och boleto, och bekräftas på sekunder 24/7/365.

**Täckning**

| Detalj | Värde |
|--------|-------|
| Faktureringsvaluta | BRL |
| Stödda länder | Brasilien |
| Prenumerationer | Stöds inte (endast engångsbetalningar) |
| Minsta belopp | $0,50 |
| Avräkning | Omedelbar |

**Konfiguration**

Passera `pix` i `allowed_payment_method_types` och ställ in faktureringsvalutan till `BRL`:

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['pix', 'credit', 'debit'],
  billing_currency: 'BRL',
  return_url: 'https://example.com/success'
});
```

Kunden visas en Pix QR-kod och en kopiera/klistra in-nyckel vid kassan. De öppnar sin bankapp, skannar eller klistrar in, och betalningen bekräftas omedelbart.

<Tip>
Pix QR-koder utgår efter ett visst fönster — designa ditt kassaflöde för att låta kunder återskapa koden om det behövs. Inkludera alltid kortalternativ för kunder som föredrar att betala med kort.
</Tip>

Lär dig mer: [Pix Payments](/features/payment-methods/pix)

### 6. **WeChat Pay för kinesiska kunder**

Acceptera **WeChat Pay** — som används av över en miljard människor över hela Kina — direkt i din Dodo Payments-kassa. Kunderna skannar en QR-kod med sin WeChat-app och bekräftar betalningen på sekunder, allt utan att lämna WeChat-ekosystemet.

**Täckning**

| Detalj | Värde |
|--------|-------|
| Faktureringsvalutor | USD, CNY |
| Prenumerationer | Stöds inte (endast engångsbetalningar) |
| Minsta belopp | $0,50 / ¥1,00 |
| Avräkning | USD |

**Konfiguration**

Passera `wechat_pay` i `allowed_payment_method_types` när du skapar en kassasession:

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  allowed_payment_method_types: ['wechat_pay', 'credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

WeChat Pay stöder både **USD** (för gränsöverskridande handlare som riktar sig till kinesiska kunder) och **CNY** (för inrikes kinesiska transaktioner). Avräkning till handlare sker i USD oavsett faktureringsvaluta.

<Tip>
Visa kassan på en stationär dator eller surfplatta så att kunderna kan skanna QR-koden med sin telefon — detta är det mest bekanta flödet för WeChat Pay-användare.
</Tip>

Lär dig mer: [WeChat Pay](/features/payment-methods/wechat)
