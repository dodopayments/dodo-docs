## Nya funktioner

### 1. **Stöd för tredjepartsanalys**

Spåra kundbeteende över Storefront, Checkout och Kundportal med Google Analytics 4, Google Tag Manager och Meta Pixel. Lägg till dina spårnings-ID:n i **Inställningar → Analys** för att börja samla in e-handelsevenemang.

**Stödda plattformar**

| Plattform | ID-format |
|----------|-----------|
| Google Analytics 4 | `G-XXXXXXXXXX` |
| Google Tag Manager | `GTM-XXXXXXX` |
| Meta Pixel | Numerisk (10-20 siffror) |

**Spårade händelser**

Händelser som `purchase`, `add_payment_info`, `view_item` och `view_item_list` skickas automatiskt till dina analysplattformar när kunder bläddrar och slutför köp.

<Check>
Stöds på Storefront, värdad Checkout, överlägg/inline Checkout och Kundportal.
</Check>

Läs mer: [Tredjepartsanalys](/features/analytics)

### 2. **Anpassning av kassan tema**

Anpassa kassans utseende via `customization.theme_config`-parametern när du skapar kassasessioner. Konfigurera färger, typsnitt, hörnradie och knapptext för både ljusa och mörka lägen.

**Konfigurationsalternativ**

| Egenskap | Beskrivning |
|----------|-------------|
| `light` / `dark` | Färgteman för varje läge |
| `font_primary_url` | Anpassad typsnitts-URL |
| `font_size` | `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `radius` | Hörnradie (t.ex., `8px`) |
| `pay_button_text` | Anpassad knapptext |

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  customization: {
    theme_config: {
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      light: { button_primary: '#0066ff', text_primary: '#1a1a1a' },
      dark: { button_primary: '#3385ff', text_primary: '#ffffff' }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

Läs mer: [Anpassning av kassan tema](/features/checkout#checkout-theme-customization)

### 3. **Förhindra planändring vid betalningsfel**

Ny `on_payment_failure`-parameter för abonnemangsplanändringar kontrollerar beteendet när betalningen misslyckas.

| Läget | Beteende |
|------|----------|
| `prevent_change` | Behåll prenumerationen på nuvarande plan tills betalningen lyckas |
| `apply_change` | Tillämpa planändring omedelbart oavsett utfallet av betalningen (standard) |

```typescript
await client.subscriptions.changePlan('sub_123', {
  product_id: 'prod_pro',
  proration_billing_mode: 'prorated_immediately',
  on_payment_failure: 'prevent_change'
});
```

<Tip>
Använd `prevent_change` för kritiska uppgraderingar där du vill säkerställa betalning innan du ger tillgång till premiumfunktioner.
</Tip>

Läs mer: [Hantering av betalningsfel](/developer-resources/subscription-upgrade-downgrade#handling-payment-failures)

## API-uppdateringar

### Balansbok API

Ny `GET /balances/ledger`-slutpunkt för att hämta ditt kontos bokföringspost med filtrering och paginering.

| Parameter | Beskrivning |
|-----------|-------------|
| `created_at_gte` / `created_at_lte` | Filtrera efter datumintervall |
| `event_type` | Filtrera efter `payment`, `refund`, `dispute`, `payout`, m.fl. |
| `currency` | Filtrera efter valutakod |
| `reference_object_id` | Filtrera efter specifik betalnings-/återbetalnings-/tvist-ID |

Läs mer: [Balansbok API](/api-reference/balance-ledger/list-ledger-entries)

### Betalningssvar: `refund_status`

Tillagd `refund_status`-fält till `GET /payments/{paymentId}`-svaret för att snabbt kontrollera om en betalning har blivit återbetald utan att fråga återbetalningsslutpunkten separat.
