## Nya Funktioner 🚀

- **Checkout 2.0**: Introducerar en helt omdesignad kassaupplevelse med:
    - Strömlinjeformat, modernt gränssnitt för förbättrad användarupplevelse
    - Nytt Query Collector System som lagrar parametrar i session storage med unika ID:n (t.ex. `sess_1a2b3c4d`)
    - Persistent tillgänglighet av data genom hela kassaflödet
    - Fler förbättringar planerade för framtida releaser!
  
    <Frame><img src="/images/changelog/checkout_2.png" alt="Checkout 2.0" style={{ maxHeight: '500px', width: 'auto' }} /></Frame>

- **Konfigurerbara betalningsmetoder**: Den nya konfigurationen `allowed_payment_method_types` gör det möjligt för handlare att anpassa de tillgängliga betalningsalternativen i kassan. Se dokumentationen om [Tillåtna betalningsmetoder](/features/payment-methods#configuring-payment-methods) för information om implementeringen.

- **Dynamisk Skatteberäkning**: Realtidsberäkning av skattesatser baserat på kundens faktureringsadresser för mer exakt prissättning på de statiska betalningslänkarna.

- **Prenumerationer på Begäran**: Nya API-endpoints för flexibel prenumerationsfakturering (tillgänglig för utvalda handlare). Lär dig mer i guiden [Prenumerationer på Begäran](/features/subscription#enabling-on-demand-subscriptions).

- **Ytterligare Uppdateringar**:
    - Prestandaoptimeringar
    - Buggfixar
    - Allmänna systemförbättringar
