## Nya funktioner 🚀

### Förbättrad analysdashboard

Vi har utökat analysdashboarden med omfattande intäkts- och retentioninsikter för att hjälpa dig att bättre förstå din affärsprestanda.

#### Intäktsanalys

Följ dina återkommande intäktsmått med detaljerade uppdelningar:

- **Prognoserad ARR**: Årlig återkommande intäktsprognos med trendanalys
- **MRR-uppdelning och tillväxttakt**: Månatlig återkommande intäktsanalys med månad-för-månad tillväxtmått  
- **Ny MRR-diagram**: Visuell representation av intäktsförvärv från nya kunder
- **Expansion MRR-diagram**: Spåra intäktsökning från uppgraderingar och expansioner av befintliga kunder
- **Churn MRR-diagram**: Övervaka intäkter som förloras från kundavbokningar och nedgraderingar
- **Netto ny MRR-diagram**: Nettointäktspåverkan som kombinerar ny, expansion och churn MRR

  <img src="/images/analytics/revenue-breakdown.png" alt="Revenue Breakdown dashboard showing projected ARR, MRR breakdown, and growth rates" />
</Frame>

#### Retentionsanalys

Övervaka kundretention och churnmönster:

- **Kundchurntakt**: Procentandel av kunder som avbokar sina prenumerationer
- **Intäktschurntakt**: Procentandel av intäkter som förloras från avbokningar och nedgraderingar
- **Churntakttrender**: Historisk spårning av både kund- och intäktschurnmönster över tid
- **Användarretentionsmatris**: Kohortanalys som visar kundretentionsgrader över olika tidsperioder

</Frame>

### Rapporter 2.0

Vi har helt omarbetat rapportavsnittet med mer omfattande och detaljerade rapporteringsmöjligheter. Navigera till **Affär > Rapporter** för att få tillgång till den nya rapporteringssviten.

Tillgängliga rapporter inkluderar:

- **Betalningsrapport**: Detaljerad redovisning av alla bearbetade betalningar med spårning av transaktionsstatus
- **Återbetalningsrapport**: Omfattande logg över alla återbetalningsaktiviteter med detaljerad återbetalningsinformation
- **Utbetalningsrapport**: Sammanfattning av utbetalningar som gjorts till ditt konto
- **Produktvis försäljningsrapport**: Försäljningsprestandainsikter med intäkts- och affärstillväxtmått
- **Betalningsfelrapport**: Sammanfattning av misslyckade betalningsförsök med felorsaker
- **Kundrapport**: Betalningssammanfattning organiserad efter kund
- **Tvistrapport**: Sammanfattning av betalningstvister med lösningsstatus
- **Kontosammanfattningsrapport**: Fullständig översikt och sammanfattning av kontot

### Dodo Payments Remote MCP-server

Du kan nu använda den hostade Remote MCP-servern på [https://mcp.dodopayments.com](https://mcp.dodopayments.com) för omedelbar MCP-integration—ingen lokal installation krävs.

<Note>
Detta är det snabbaste sättet att komma igång med Dodo Payments MCP-integration. Ingen serverinstallation eller underhåll krävs.
</Note>

<Steps>
<Step title="Open the Remote MCP Server">
    Besök <a href="https://mcp.dodopayments.com" target="_blank">https://mcp.dodopayments.com</a> i din webbläsare.
</Step>
<Step title="Copy the MCP JSON configuration">
    På webbplatsen kopierar du MCP JSON-konfigurationen som tillhandahålls för din klient.
</Step>
<Step title="Configure your AI application">
    Klistra in konfigurationen i din applikations MCP-inställningar (till exempel Cursor eller Claude).
    <Tip>
    För Cursor bör din konfiguration se ut så här:
    </Tip>

    ```json
    {
      "mcpServers": {
        "dodopayments_api": {
          "command": "npx",
          "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
        }
      }
    }
    ```

</Step>
<Step title="Complete authentication and environment setup">
    Efter att du har lagt till JSON-konfigurationen visas ett popup-fönster där du uppmanas att:
    - Ange din Dodo Payments API-nyckel
    - Välj miljö (test eller live)
    - Välj din MCP-klient under Configuration Options
</Step>
<Step title="Login and Approve">
    - Klicka på knappen Login and Approve
</Step>
<Step title="Verify successful connection">
    När installationen är klar ser du en lyckad skärm.
    <Check>
    Du är nu redo att använda Dodo Payments MCP-server!
    </Check>
</Step>
</Steps>
