## What is Dodo Payments?

Dodo Payments is the **all-in-one engine** to launch, scale, and monetize worldwide. Designed for the new generation of digital SaaS and AI products, we handle everything from **payments to billing to distribution** - all without extra engineering.

<Info>
**Built for SaaS and AI Products**: Handle one-time payments, subscriptions, credits, seats, tokens, or any usage metric with our optimized billing infrastructure.
</Info>

<Tip>
  <strong>Meet Sentra: Your AI-powered billing assistant</strong><br/>
  Sentra is an AI agent that integrates, analyzes, and acts on billing and payments directly in your IDE. Ask questions, build integrations, or plan billing architectures - all by describing what you want.
  <a href="/developer-resources/sentra">
    Get started with Sentra &rarr;
  </a>
</Tip>

## Quick Start Guide

Get up and running with Dodo Payments in just a few steps:

<Steps>
<Step title="Create Your Account">
  Sign up at [app.dodopayments.com](https://app.dodopayments.com/signup) using your email.

  <Check>
  You'll receive a confirmation email to verify your account.
  </Check>
</Step>

<Step title="Add Your First Product">
  Choose your billing model and add your product to start accepting payments.

  **Installera**. För Claude Code, Codex CLI, Cursor eller OpenCode, [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) kopplar både MCP-servrar och alla färdigheter i ett steg. Se [AI Coding Agents guide](/developer-resources/build-with-ai-coding-agents) för installationskommandon per agent.

  **Upptäck**. Den fullständiga dokumentationsindexen finns på [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt), och varje dokumentationssida är tillgänglig i vanlig markdown genom att lägga till `.md` till dess URL (t.ex. `/api-reference/introduction.md`).

  **Anslut**. Två MCP-servrar ger agenterna liveåtkomst till plattformen:

  - **[Dodo Knowledge MCP](/developer-resources/mcp-server#dodo-knowledge-mcp)** - semantisk sökning över all Dodo-dokumentation
  - **[Dodo Payments MCP](/developer-resources/mcp-server)** - utföra API-operationer (skapa betalningar, hantera prenumerationer, utfärda återbetalningar)

  Se [MCP Server guide](/developer-resources/mcp-server) för fullständig klientkonfiguration.

  **Utöka**. Installera officiella [Dodo Payments Skills](/developer-resources/agent-skills) för att lära din agent hantera checkout, prenumerationer, användningsbaserad fakturering, kreditbaserad fakturering, webhooks och mer:

  ```bash
  npx skills add dodopayments/skills
  ```

  Fungerar med Claude Code, OpenCode, Cursor och alla MCP-kompatibla agenter.
</Accordion>
</AccordionGroup>

<Steps>
<Step title="Create Your Account">
  Registrera dig på [app.dodopayments.com](https://app.dodopayments.com/signup) med din e-post.

Anslut din AI-kodningsassistent (Claude Code, Codex CLI, Cursor, OpenCode, Windsurf, VS Code) direkt till Dodo Payments — installera Agent Plugin för en en-kommando-uppsättning, eller anslut MCP-servrarna manuellt.

<CardGroup cols={3}>
{/* LOCKED_PATTERN_ea48f026bc205cccc188764a49c78889 */}
  En installation samlar både MCP-servrar och alla färdigheter för Claude Code, Codex CLI, Cursor och OpenCode
</Card>

<Card title="Dodo Knowledge MCP" icon="book-open" href="/developer-resources/mcp-server#dodo-knowledge-mcp">
  Semantisk sökning i Dodo Payments-dokumentation - få snabba svar om funktioner, APIs och bästa praxis
</Card>

<Card title="Dodo Payments MCP" icon="credit-card" href="/developer-resources/mcp-server">
  Utför API-operationer direkt - skapa betalningar, hantera prenumerationer och hantera återbetalningar genom din AI-assistent
</Card>
</CardGroup>

<Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
Lägg till båda servrarna i din MCP-konfiguration (`~/.cursor/mcp.json` eller Claude Desktop-konfiguration):

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

<Info>
Kräver Node.js 18+. Se [MCP Server-dokumentation](/developer-resources/mcp-server) för detaljerade installationsinstruktioner för alla stödda klienter.
</Info>
</Accordion>
