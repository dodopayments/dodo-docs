<Note>
This guide exclusively covers **one-time payments** involving **cards, Apple Pay and Google Pay**.
</Note>

## API Endpoints

| Environment | Base URL | Confirm Payment Endpoint |
| --- | --- | --- |
| **Test Mode** | `https://test.dodopayments.com` | `https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm` |
| **Live Mode** | `https://live.dodopayments.com` | `https://api.hs.dodopayments.com/payments/<payment_id>/confirm` |

## Step-by-Step Card Payment Flow

### Steg 1: Skaffa klienthemligheten

Begin by creating a payment using the following API:

- **Payments**: [Create Payment API](/api-reference/payments/post-payments)

Detta API returnerar en **`client_secret`**, som krävs för efterföljande steg.

<Warning>
`POST /payments` är föråldrad. Den är fortfarande tillgänglig för raw-card-integreringar eftersom det är den enda endpointen som returnerar en `client_secret`, men för alla andra engångsbetalningsflöden använder du [Checkout Sessions](/api-reference/checkout-sessions/create).
</Warning>

### Steg 2: Bekräfta betalningen

Bekräfta betalningen genom att anropa endpointen `payments confirm`:

- **Testläge**: `POST https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm`
- **Produktionsläge**: `POST https://api.hs.dodopayments.com/payments/<payment_id>/confirm`

Inkludera följande uppgifter i request body:

- `client_secret`: `client_secret` från steg 1
- `payment_method`: Ange `card`
- `payment_method_data`: Kort- och faktureringsuppgifter
- `browser_info`: Webbläsarspecifika data (user agent, skärmuppgifter osv.)
- `payment_type`: Ange uttryckligen `normal` (för engångsbetalningar)

Obligatoriska headers:

- Hämta din publishable key från Dodo Payments support
- `api-key`: Din publishable key (hämta den från Dodo Payments-teamet)
- `content-type`: `application/json`

**Exempel på request body:**

```json
{
  "client_secret": "<client_secret>",
  "payment_method": "card",
  "payment_method_data": {
    "card": {
      "card_number": "<card_number>",
      "card_exp_month": "<exp_month>",
      "card_exp_year": "<exp_year>",
      "card_holder_name": "<cardholder_name>",
      "card_cvc": "<cvc>",
      "card_network": "<network>"
    },
    "billing": {
      "address": {
        "first_name": "<first_name>",
        "last_name": "<last_name>"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Hantera svaret

- Om svaret **`status`** är **`requires_customer_action`**, omdirigerar du kunden till URL:en som anges i fältet **`next_action`** för ytterligare autentisering.

<Warning>
Säkerställ att PCI-compliance-riktlinjer följs vid hantering av raw card-data.
</Warning>

## Apple Pay-integrering

Om du vill använda Apple Pay anger du `payment_method` till `wallet` och inkluderar Apple Pay-data i `payment_method_data`.

### Struktur för request body

```json
{
  "client_secret": "<client_secret>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "apple_pay": {
        "payment_data": "<decrypted_payment_data>",
        "payment_method": {
          "display_name": "Visa 1234",
          "network": "Visa",
          "type": "debit"
        },
        "transaction_identifier": "UNIQUE_TRANSACTION_ID_FROM_APPLE"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Referens för Apple Pay-fält

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `payment_data` | string | Ja | Denna enum används för att representera Apple Pay-betalningsdata, som kan vara antingen krypterad eller dekrypterad. |
| `payment_method.display_name` | string | Ja | Visningsnamn som visas på Apple Pay-knappen (t.ex. "Visa 1234") |
| `payment_method.network` | string | Ja | Kortnätverk (t.ex. "Visa", "Mastercard", "Amex") |
| `payment_method.type` | string | Ja | Typ av betalningsmetod (t.ex. "debit", "credit") |
| `payment_method.card_exp_month` | string | Nej | Kortets utgångsmånad (t.ex. "12") |
| `payment_method.card_exp_year` | string | Nej | Kortets utgångsår (t.ex. "25") |
| `transaction_identifier` | string | Ja | Unik transaktionsidentifierare från Apple Pay |

## Google Pay-integrering

Om du vill använda Google Pay anger du `payment_method` till `wallet` och inkluderar Google Pay-data i `payment_method_data`.

### Struktur för request body

```json
{
  "client_secret": "<client_secret>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "google_pay": {
        "type": "CARD",
        "description": "Visa ending in 1234",
        "info": {
          "card_network": "VISA",
          "card_details": "1234"
        },
        "tokenization_data": {
          "type": "PAYMENT_GATEWAY",
          "token": "<encrypted_payment_token>"
        }
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Referens för Google Pay-fält

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | string | Ja | Typ av betalningsmetod (vanligtvis "CARD") |
| `description` | string | Ja | Användarvänlig beskrivning av betalningsmetoden |
| `info.card_network` | string | Ja | Kortnätverk (t.ex. "VISA", "MASTERCARD", "AMEX") |
| `info.card_details` | string | Ja | Kortets fyra sista siffror |
| `info.assurance_details` | object | Nej | Detaljer om autentiseringssäkerhet |
| `tokenization_data.type` | string | Ja | Tokeniseringstyp (t.ex. "PAYMENT_GATEWAY") |
| `tokenization_data.token` | string | Ja | Krypterad betalningstoken från Google Pay |
