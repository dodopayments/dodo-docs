## Installation

<Steps>
<Step title="Install the package">
Kör följande kommando i projektets rotkatalog:

```bash
npm install @dodopayments/astro
```

</Step>
<Step title="Set up environment variables">
Skapa en <code>.env</code>-fil i projektets rotkatalog:

```env expandable
DODO_PAYMENTS_API_KEY=your-api-key
DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
DODO_PAYMENTS_ENVIRONMENT="test_mode" or "live_mode"
DODO_PAYMENTS_RETURN_URL=https://yourdomain.com/checkout/success
```

<Warning>
Lägg aldrig till din <code>.env</code>-fil eller hemligheter i versionshanteringen.
</Warning>
</Step>
</Steps>

    ```typescript Astro Route Handler expandable
    // src/pages/api/checkout.ts
    import { Checkout } from "@dodopayments/astro";
    export const prerender = false;

    export const GET = Checkout({
        bearerToken: import.meta.env.DODO_PAYMENTS_API_KEY,
        returnUrl: import.meta.env.DODO_PAYMENTS_RETURN_URL,
        environment: import.meta.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "static", // optional, defaults to 'static'

    export const POST = Checkout({
        bearerToken: import.meta.env.DODO_PAYMENTS_API_KEY,
        returnUrl: import.meta.env.DODO_PAYMENTS_RETURN_URL,
        environment: import.meta.env.DODO_PAYMENTS_ENVIRONMENT,
    ```

## Checkout Route Handler

<Info>
Dodo Payments stöder tre typer av betalningsflöden för att integrera betalningar på din webbplats. Denna adaptor stöder alla typer av betalningsflöden.
</Info>

- **Statiska Payment Links:** Omedelbart delbara URL:er för snabb betalningsinsamling utan kod.
- **Dynamiska Payment Links:** Generera programmatiskt betalningslänkar med anpassade uppgifter med hjälp av API:et eller SDK:er.
- **Checkout Sessions:** Skapa säkra och anpassningsbara checkout-upplevelser med förkonfigurerade produktvarukorgar och kunduppgifter.

## Customer Portal Route Handler

Customer Portal Route Handler gör det möjligt att sömlöst integrera Dodo Payments Customer Portal i din Astro-applikation.

### Query Parameters
<ParamField query="customer_id" type="string" required>
Kund-ID:t för portalsessionen (t.ex. <code>?customer_id=cus_123</code>).
</ParamField>
<ParamField query="send_email" type="boolean">
Om värdet är <code>true</code> skickas ett e-postmeddelande till kunden med portallänken.
</ParamField>

<Warning>
Returnerar 400 om <code>customer_id</code> saknas.
</Warning>

## Webhook Route Handler

- **Method:** Endast POST-begäranden stöds. Övriga metoder returnerar 405.
- **Signature Verification:** Verifierar webhook-signaturen med <code>webhookKey</code>. Returnerar 401 om verifieringen misslyckas.
- **Payload Validation:** Valideras med Zod. Returnerar 400 för ogiltiga payloads.
- **Error Handling:**
  - 401: Ogiltig signatur
  - 400: Ogiltig payload
  - 500: Internt fel under verifieringen
- **Event Routing:** Anropar rätt event handler baserat på payload-typen.
