Dodo Payments tillhandahåller officiella SDK:er för flera programmeringsspråk, där varje SDK är utformad enligt språkspecifika best practices och moderna funktioner för sömlös betalningsintegration.

<Tip>
Använd alltid den senaste SDK-versionen för att få tillgång till de nyaste funktionerna och förbättringarna. Kontrollera regelbundet om det finns uppdateringar i din package manager för att säkerställa att du har tillgång till alla funktioner i Dodo Payments.
</Tip>

## Snabbstart

Kom igång med valfri SDK på några minuter:

<Steps>
<Step title="Install the SDK">
  Använd ditt språks package manager för att installera SDK:n
  
  <Tabs>
  <Tab title="TypeScript/Node.js">

  ```bash
  npm install dodopayments
  ```

  </Tab>
  
  <Tab title="Python">

  ```bash
  pip install dodopayments
  ```

  </Tab>
  
  <Tab title="PHP">

  ```bash
  composer require dodopayments/client
  ```

  </Tab>
  
  <Tab title="Go">

  ```bash
  go get github.com/dodopayments/dodopayments-go
  ```

  </Tab>

  <Tab title="Rust">

  ```bash
  cargo add dodopayments
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Initialize the Client">
  Konfigurera klienten med din API-nyckel
  
  <Tabs>
  <Tab title="TypeScript">

  ```typescript
  import DodoPayments from 'dodopayments';
  const client = new DodoPayments({ bearerToken: 'your_api_key' });
  ```

  </Tab>
  
  <Tab title="Python">

  ```python
  from dodopayments import DodoPayments
  client = DodoPayments(bearer_token="your_api_key")
  ```

  </Tab>
  
  <Tab title="PHP">

  ```php
  use Dodopayments\Client;
  $client = new Client(bearerToken: 'your_api_key');
  ```

  </Tab>
  
  <Tab title="Go">

  ```go
  import "github.com/dodopayments/dodopayments-go"
  client := dodopayments.NewClient(option.WithBearerToken("your_api_key"))
  ```

  </Tab>

  <Tab title="Rust">

  ```rust
  use dodopayments::Client;
  let client = Client::from_env()?; // reads DODO_PAYMENTS_API_KEY
  ```

  </Tab>
  </Tabs>
  
  <Warning>
  Lagra alltid dina API-nycklar säkert med hjälp av environment variables. Lägg dem aldrig i versionshantering.
  </Warning>
</Step>

<Step title="Make Your First API Call">
  Skapa en checkout-session eller betalning
  
  <Check>
  Nu är du redo att behandla betalningar! Besök de enskilda SDK-sidorna för detaljerade guider och exempel.
  </Check>
</Step>
</Steps>

## Viktiga funktioner

Alla SDK:er delar dessa centrala funktioner:

- **Typsäkerhet**: Stark typning för typsäkerhet vid kompilering och bättre IDE-stöd
- **Felhantering**: Omfattande undantagshantering med detaljerade felmeddelanden
- **Autentisering**: Enkel API-nyckelautentisering med stöd för environment variables
- **Async-stöd**: Moderna async/await-mönster där det är tillämpligt
- **Automatisk paginering**: Automatisk paginering för list-svar
- **Användningsbaserad fakturering**: Inbyggt stöd för att spåra och ta emot användningshändelser
- **Testning**: Fullt stöd för sandbox-miljö för utveckling och testning

## React Native SDK

För mobilapplikationer tillhandahåller vi en dedikerad React Native SDK:

<Card title="React Native SDK" icon="mobile" href="/developer-resources/react-native-integration">
  Bygg säkra betalningsupplevelser för iOS- och Android-appar med native UI-komponenter och förenklad insamling av betalningsdata
</Card>

**Funktioner:**
- Native UI-komponenter för Android och iOS
- Förenklad säkerhet vid insamling av känsliga betalningsuppgifter
- Stöd för flera betalningsmetoder
- Sömlös integration med React Native-appar

<Info>
Apple Pay, Google Pay, Cash App och UPI stöds för närvarande inte i React Native SDK. Stöd för dessa betalningsmetoder planeras i framtida versioner.
</Info>

<Card title="CLI" icon="terminal" href="/developer-resources/sdks/cli">

