## Översikt

<Info>
Den här guiden förklarar hur du integrerar Dodo Payments i din Nuxt-applikation med den officiella Nuxt-modulen. Du får lära dig hur du konfigurerar checkout-, kundportal- och webhook-API-routes samt hur du hanterar miljövariabler på ett säkert sätt.
</Info>

## Installation

<Steps>
<Step title="Install the Nuxt module">
Kör följande kommando i projektets rotkatalog:

```bash
npm install @dodopayments/nuxt
```

</Step>
<Step title="Register the module in nuxt.config.ts">
Lägg till <code>@dodopayments/nuxt</code> i din <code>modules</code>-array och konfigurera den:

```typescript nuxt.config.ts expandable
export default defineNuxtConfig({
  modules: ["@dodopayments/nuxt"],
  devtools: { enabled: true },
  compatibilityDate: "2025-02-25",
  runtimeConfig: {
    private: {
      bearerToken: process.env.NUXT_PRIVATE_BEARER_TOKEN,
      webhookKey: process.env.NUXT_PRIVATE_WEBHOOK_KEY,
      environment: process.env.NUXT_PRIVATE_ENVIRONMENT,
      returnUrl: process.env.NUXT_PRIVATE_RETURNURL
    },
  }
});
```

</Step>
</Steps>

<Warning>
Lägg aldrig till din <code>.env</code>-fil eller hemligheter i versionshanteringen.
</Warning>

## Exempel på API Route Handler

<Info>
Alla Dodo Payments-integreringar i Nuxt hanteras via server routes i katalogen <code>server/routes/api/</code>.
</Info>

<Info>

## Checkout Route Handler

<Info>
Dodo Payments stöder tre typer av betalningsflöden för integrering av betalningar på din webbplats; denna adaptor stöder alla typer av betalningsflöden.
</Info>

- **Statiska betalningslänkar:** Omedelbart delbara URL:er för snabb betalningsinsamling utan kod.
- **Dynamiska betalningslänkar:** Generera betalningslänkar programmatiskt med anpassade uppgifter via API eller SDK:er.
- **Checkout-sessioner:** Skapa säkra och anpassningsbara checkout-upplevelser med förkonfigurerade produktvarukorgar och kunduppgifter.

## Webhook Route Handler

- **Metod:** Endast POST-begäranden stöds. Övriga metoder returnerar 405.
- **Signaturverifiering:** Verifierar webhook-signaturen med <code>webhookKey</code>. Returnerar 401 om verifieringen misslyckas.
- **Payload-validering:** Valideras med Zod. Returnerar 400 för ogiltiga payloads.
- **Felhantering:**
  - 401: Ogiltig signatur
  - 400: Ogiltig payload
  - 500: Internt fel under verifiering
- **Event-routing:** Anropar lämplig event handler baserat på payload-typen.
