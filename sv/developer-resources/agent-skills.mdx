## Översikt

Agent Skills är återanvändbara funktioner som utökar vad AI-kodningsassistenter kan göra när de arbetar med Dodo Payments. De tillhandahåller processkunskap och bästa praxis som hjälper agenter att utföra specifika uppgifter mer effektivt – från att integrera checkout-flöden till att konfigurera usage-based billing.

<Info>
**Se skills som plugins för din AI-assistent.** De lär din agent att implementera funktioner i Dodo Payments korrekt enligt våra rekommenderade mönster och bästa praxis.
</Info>

Skills fungerar med alla MCP-kompatibla AI-agenter, inklusive:
- **Claude Code** – Anthropics CLI-baserade kodningsassistent
- **OpenCode** – AI-kodningsagent med öppen källkod
- **Cursor** – kodredigerare med AI i fokus
- **Andra MCP-klienter** – alla agenter som stöder skills-protokollet

## Installation

Välj önskad installationsmetod utifrån din AI-kodningsassistent.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Om du använder Claude Code, Codex CLI, Cursor eller OpenCode installerar [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) alla åtta skills samt båda MCP-servrarna i ett steg. Skills laddas automatiskt när din agent identifierar en relevant uppgift.

Se guiden [AI Coding Agents](/developer-resources/build-with-ai-coding-agents) för installationskommandon för varje agent.
</Tab>

<Tab title="Skills CLI">
Installera skills med det universella CLI-verktyget för skills, som fungerar med alla MCP-kompatibla agenter:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Eller installera enskilda skills efter behov:

```bash
# Best practices guide
npx skills add dodopayments/skills/dodo-payments/best-practices

# Webhook integration
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Subscription billing
npx skills add dodopayments/skills/dodo-payments/subscription-integration

# Checkout flows
npx skills add dodopayments/skills/dodo-payments/checkout-integration

# Usage-based billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing

# BillingSDK components
npx skills add dodopayments/skills/dodo-payments/billing-sdk

# License key management
npx skills add dodopayments/skills/dodo-payments/license-keys

# Credit-based billing
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
```

<Tip>
Installera endast de skills du behöver för att hålla din agent fokuserad och minska kontextbelastningen.
</Tip>
</Tab>

<Tab title="Claude Code">
Lägg till Dodo Payments-skills marketplace i Claude Code:

```bash
/plugin marketplace add dodopayments/skills
```

Installera sedan enskilda plugins:

```bash
# Install best practices
/plugin install dodo-best-practices

# Install webhook integration
/plugin install webhook-integration

# Install subscription integration
/plugin install subscription-integration

# Install checkout integration
/plugin install checkout-integration

# Install usage-based billing
/plugin install usage-based-billing

# Install BillingSDK
/plugin install billing-sdk

# Install license keys
/plugin install license-keys

# Install credit-based billing
/plugin install credit-based-billing
```

</Tab>

<Tab title="OpenCode">
Skills blir automatiskt tillgängliga när de har konfigurerats i dina OpenCode-inställningar. Lägg till Dodo Payments-skills repository i din konfiguration:

```json
{
  "skills": {
    "repositories": [
      "dodopayments/skills"
    ]
  }
}
```

</Tab>
</Tabs>

## Använda skills

När de har installerats kan din AI-assistent använda dessa skills när du ber den implementera funktioner i Dodo Payments. Här är några exempel på prompts:

### Bästa praxis

```
Help me integrate Dodo Payments into my Next.js app following best practices
```

### Webhooks

```
Set up webhook handlers for payment and subscription events
```

### Prenumerationer

```
Implement a subscription flow with free trial and multiple pricing tiers
```

### Checkout

```
Create a checkout session for my SaaS product
```

### Usage-Based Billing

```
Add usage-based billing to track API calls for my AI product
```

### BillingSDK

```
Add a pricing page using BillingSDK components
```

### Licensnycklar

```
Implement license key validation for my desktop app
```

### Credit-Based Billing

```
Set up credit entitlements and metered credit deduction for my AI product
```

## Så fungerar skills

Skills förser din AI-assistent med:

1. **Processkunskap** – steg-för-steg-instruktioner för att implementera funktioner
2. **Kodmallar** – produktionsklara kodmönster och kodavsnitt
3. **Bästa praxis** – rekommenderade metoder för säkerhet, felhantering och UX
4. **Kontextmedvetenhet** – förståelse för hur olika funktioner i Dodo Payments fungerar tillsammans

När du ber din AI-assistent att implementera en funktion använder den relevant skill för att:
- Förstå rätt implementeringsmetod
- Generera korrekt, fungerande kod
- Följa konventionerna i Dodo Payments
- Hantera specialfall och fel korrekt

<Note>
Skills kompletterar [MCP Server](/developer-resources/mcp-server) och [Sentra](/developer-resources/sentra). Använd MCP för API-operationer, Sentra för guidad integrering och Skills för förbättrade AI-assistentfunktioner.
</Note>
