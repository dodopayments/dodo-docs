## Översikt

Agent Färdigheter är återanvändbara kapaciteter som förbättrar vad AI-kodning assistenter kan göra när de arbetar med Dodo Payments. De tillhandahåller proceduriell kunskap och bästa praxis som hjälper agenter att utföra specifika uppgifter mer effektivt - från att integrera kassan till att ställa in användningsbaserad fakturering.

<Info>
**Tänk på färdigheter som plugins för din AI-assistent.** De lär din agent hur man implementerar Dodo Payments-funktioner korrekt, följer våra rekommenderade mönster och bästa praxis.
</Info>

Färdigheter fungerar med alla MCP-kompatibla AI-agenter, inklusive:
- **Claude Code** - Anthropics CLI kodningsassistent
- **OpenCode** - Öppen källkod AI kodningsagent
- **Cursor** - AI-först kodredigerare
- **Andra MCP-klienter** - Alla agenter som stöder färdighetsprotokollet

## Installation

Välj din föredragna installationsmetod baserat på din AI-kodning assistent.

<Tabs>
<Tab title="Skills CLI">
Installera färdigheter med den universella färdighet CLI som fungerar med vilken MCP-kompatibel agent som helst:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Eller installera individuella färdigheter efter behov:

```bash
# Best practices guide
npx skills add dodopayments/skills/dodo-best-practices

# Webhook integration
npx skills add dodopayments/skills/webhook-integration

# Subscription billing
npx skills add dodopayments/skills/subscription-integration

# Checkout flows
npx skills add dodopayments/skills/checkout-integration

# Usage-based billing
npx skills add dodopayments/skills/usage-based-billing

# BillingSDK components
npx skills add dodopayments/skills/billing-sdk

# License key management
npx skills add dodopayments/skills/license-keys
```

<Tip>
Installera endast de färdigheter du behöver för att hålla din agent fokuserad och minska kontextöverhänget.
</Tip>
</Tab>

<Tab title="Claude Code">
Lägg till Dodo Payments färdighetsmarknadsplatsen till Claude Code:

```bash
/plugin marketplace add dodopayments/skills
```

Installera sedan individuella plugins:

```bash
# Install best practices
/plugin install dodo-best-practices

# Install webhook integration
/plugin install webhook-integration

# Install subscription integration
/plugin install subscription-integration

# Install checkout integration
/plugin install checkout-integration

# Install usage-based billing
/plugin install usage-based-billing

# Install BillingSDK
/plugin install billing-sdk

# Install license keys
/plugin install license-keys
```

</Tab>

<Tab title="OpenCode">
Färdigheter är automatiskt tillgängliga när de konfigureras i dina OpenCode-inställningar. Lägg till Dodo Payments färdighetsrepository till din konfiguration:

```json
{
  "skills": {
    "repositories": [
      "dodopayments/skills"
    ]
  }
}
```

</Tab>
</Tabs>

## Använda Färdigheter

När de är installerade kan din AI-assistent utnyttja dessa färdigheter när du ber den att implementera Dodo Payments-funktioner. Här är några exempel på kommandon:

### Bästa Praxis

```
Help me integrate Dodo Payments into my Next.js app following best practices
```

### Webhooks

```
Set up webhook handlers for payment and subscription events
```

### Abonnemang

```
Implement a subscription flow with free trial and multiple pricing tiers
```

### Kassa

```
Create a checkout session for my SaaS product
```

### Användningsbaserad Fakturering

```
Add usage-based billing to track API calls for my AI product
```

### BillingSDK

```
Add a pricing page using BillingSDK components
```

### Licensnycklar

```
Implement license key validation for my desktop app
```

## Hur Färdigheter Fungerar

Färdigheter ger din AI-assistent:

1. **Proceduriell Kunskap** - Steg-för-steg-instruktioner för att implementera funktioner
2. **Kodmallar** - Produktionsklara kodmönster och snippets
3. **Bästa Praxis** - Rekommenderade tillvägagångssätt för säkerhet, felhantering och användarupplevelse
4. **Kontext Medvetenhet** - Förståelse för hur olika Dodo Payments-funktioner fungerar tillsammans

När du ber din AI-assistent att implementera en funktion använder den den relevanta färdigheten för att:
- Förstå rätt implementeringsmetod
- Generera korrekt, fungerande kod
- Följa Dodo Payments konventioner
- Hantera kantfall och fel på rätt sätt

<Note>
Färdigheter kompletterar [MCP Server](/developer-resources/mcp-server) och [Sentra](/developer-resources/sentra). Använd MCP för API-operationer, Sentra för guidning i integration och Färdigheter för förbättrade AI-assistent kapabiliteter.
</Note>
