## Översikt

Agent Skills är återanvändbara funktioner som utökar vad AI-kodningsassistenter kan göra när de arbetar med Dodo Payments. De tillhandahåller processkunskap och bästa praxis som hjälper agenter att utföra specifika uppgifter mer effektivt – från att integrera checkout-flöden till att konfigurera usage-based billing.

<Info>
**Se skills som plugins för din AI-assistent.** De lär din agent att implementera funktioner i Dodo Payments korrekt enligt våra rekommenderade mönster och bästa praxis.
</Info>

Skills fungerar med alla AI-agenter som stöder skills-protokollet, inklusive:
- **Claude Code** – Anthropics CLI-kodningsassistent
- **Codex CLI** – OpenAIs CLI-kodningsagent
- **Cursor** – AI-fokuserad kodredigerare
- **VS Code / GitHub Copilot** – via Agent Plugin
- **Kiro** – läser in skills som en Power
- **OpenCode** – AI-kodningsagent med öppen källkod
- **Andra klienter** – alla agenter som stöder skills-protokollet

<Note>
**Gemini CLI är undantaget.** Det saknar en agent-skill-primitiv, så skills är inte tillgängliga där – endast de två [MCP-servrarna](/developer-resources/mcp-server) är tillgängliga.
</Note>

## Installation

Välj önskad installationsmetod utifrån din AI-kodningsassistent.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Om du använder Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro eller OpenCode installerar [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents) alla sjutton skills samt båda MCP-servrarna i ett steg. Skills läses automatiskt in när din agent identifierar en relevant uppgift.

Se guiden [AI Coding Agents](/developer-resources/build-with-ai-coding-agents) för installationskommandon för varje agent.
</Tab>

<Tab title="Skills CLI">
Installera skills med den universella skills CLI som fungerar med alla MCP-kompatibla agenter:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

Eller installera enskilda skills efter behov:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/dodo-best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
Installera endast de skills du behöver för att hålla agenten fokuserad och minska kontextöverhead.
</Tip>
</Tab>

<Tab title="OpenCode">
OpenCode läser in skills från kataloger som du anger. Det söker **inte** igenom installerade paket, så en explicit `skills.paths`-post krävs.

Använda Agent Plugin-paketet:

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

Relativa sökvägar löses i förhållande till **projektkatalogen**, så paketet måste finnas i projektets `node_modules`. En absolut sökväg fungerar också och eliminerar kravet på lokal installation.

<Warning>
En skills-sökväg som inte finns ignoreras **tyst** – inget fel och ingen varning. Bekräfta att skills faktiskt lästes in:

```bash
opencode run "List every skill available to you by name."
```

Du bör se alla sjutton.
</Warning>
</Tab>
</Tabs>

## Använda skills

När de har installerats läser din AI-assistent automatiskt in relevant skill när du ber den implementera en Dodo Payments-funktion. Du behöver inte ange skillens namn – beskriv bara uppgiften.

| Exempel på prompt | Skill som läses in |
|----------------|------------------|
| Hjälp mig integrera Dodo Payments i min Next.js-app enligt bästa praxis | `dodo-best-practices` |
| Lägg till en Dodo Payments checkout route handler i min Hono-app | `framework-adapters` |
| Gå igenom hur jag testar betalningar och går live | `testing-and-go-live` |
| Skapa en checkout session för min SaaS-produkt | `checkout-integration` |
| Implementera ett prenumerationsflöde med en kostnadsfri provperiod och flera prisnivåer | `subscription-integration` |
| Lägg till checkout i appen i min React Native-app | `mobile-checkout` |
| Konfigurera webhook handlers för betalnings- och prenumerationshändelser | `webhook-integration` |
| Konfigurera kreditentitlements och mätarbaserade kreditavdrag för min AI-produkt | `credit-based-billing` |
| Lägg till usage-based billing för att spåra API-anrop för min AI-produkt | `usage-based-billing` |
| Implementera validering av licensnycklar för min desktop-app | `license-keys` |
| Skapa en produktkatalog med tillägg och nivåbaserad prissättning | `product-catalog-management` |
| Lägg till en kampanjkod som ger 20 % rabatt under de tre första faktureringscyklerna | `discounts-and-promotions` |
| Visa priser i besökarens lokala valuta med köpkraftsparitet | `localized-pricing` |
| Ge kunderna en självbetjäningsportal för att hantera sina betalningsmetoder | `customer-management` |
| Utfärda en partiell återbetalning och återkalla åtkomsten när en tvist öppnas | `refunds-and-disputes` |
| Lägg till en prissida med BillingSDK-komponenter | `billing-sdk` |
| Integrera Dodo Payments i min Better Auth-konfiguration | `better-auth-integration` |

## Så fungerar skills

Skills förser din AI-assistent med:

1. **Procedurkunskap** – stegvisa instruktioner för att implementera funktioner
2. **Kodmallar** – produktionsklara kodmönster och kodavsnitt
3. **Bästa praxis** – rekommenderade metoder för säkerhet, felhantering och UX
4. **Kontextmedvetenhet** – förståelse för hur olika Dodo Payments-funktioner fungerar tillsammans

När du ber din AI-assistent att implementera en funktion använder den relevant skill för att:
- Förstå rätt implementeringsmetod
- Generera korrekt, fungerande kod
- Följa Dodo Payments-konventioner
- Hantera specialfall och fel på rätt sätt

<Note>
Skills kompletterar [MCP Server](/developer-resources/mcp-server) och [Sentra](/developer-resources/sentra). Använd MCP för API-operationer, Sentra för vägledd integration och Skills för förbättrade AI-assistentfunktioner.
</Note>
