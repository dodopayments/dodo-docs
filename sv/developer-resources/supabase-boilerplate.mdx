## Översikt

En produktionsklar boilerplate för prenumerationer med Next.js 15, React 19, Supabase, Drizzle ORM och Dodo Payments. Den levereras med Google OAuth, checkout för prenumerationer, webhook-hantering, databasschema och en grundläggande dashboard.

<Info>
Om du endast behöver route handlers för en befintlig app kan du se de dedikerade adaptrarna: <a href="/developer-resources/nextjs-adaptor">Next.js Adaptor</a> och <a href="/developer-resources/express-adaptor">Express Adaptor</a>.
</Info>

## Förutsättningar

- Node.js 18+ (eller Bun 1.0+)
- Supabase-projekt (URL, Anon key, Service role key, Database URL)
- Dodo Payments-konto (API key, Webhook secret)
- Google Cloud OAuth-klient (Client ID och Secret)

## Snabbstart

<Steps>
<Step title="Clone and install">

```bash
git clone https://github.com/dodopayments/dodo-supabase-subscription-starter.git
cd dodo-supabase-subscription-starter
# choose one
bun install
# or
npm install
# or
pnpm install
```

</Step>

<Step title="Create Supabase project">
Skapa ett Supabase-projekt och kopiera:
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY
- SUPABASE_SERVICE_ROLE_KEY
- DATABASE_URL (Connection string)
</Step>

<Step title="Configure Google OAuth">
Ange redirect-URI:n till: `https://[your-project-ref].supabase.co/auth/v1/callback` i Google Cloud och aktivera sedan Google-provider i Supabase Auth med ditt Client ID och Secret.
</Step>

<Step title="Configure Dodo Payments">
Generera en API key och Webhook secret från dashboarden för Dodo. Ange miljön till `test_mode` under utveckling.
</Step>

<Step title="Create .env.local">

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role

# Database
DATABASE_URL=postgresql://postgres:[password]@db.[project-ref].supabase.co:5432/postgres

# Dodo Payments
DODO_PAYMENTS_API_KEY=your-dodo-api-key
DODO_WEBHOOK_SECRET=your-webhook-secret
DODO_PAYMENTS_ENVIRONMENT=test_mode
```

<Warning>
Commita aldrig hemligheter. Använd miljövariabler i distributionsmiljöer.
</Warning>
</Step>

<Step title="Provision database schema">

```bash
bun run db:push
# or
npm run db:push
# or
pnpm run db:push
```

<Check>
Skapade tabeller: `users`, `subscriptions`, `payments`.
</Check>
</Step>

<Step title="Deploy webhook function">

```bash
# login (one-time)
bunx supabase login
# or
npx supabase login

# deploy the edge function
bun run deploy:webhook --project-ref [your-project-ref]
# or
npm run deploy:webhook -- --project-ref [your-project-ref]
# or
pnpm run deploy:webhook --project-ref [your-project-ref]
```

```bash cURL
curl -X POST \
  'https://[your-project-ref].supabase.co/functions/v1/dodo-webhook' \
  -H 'Content-Type: application/json' \
  -H 'Dodo-Signature: <signature>' \
  -d '{"type":"payment.succeeded","data":{}}'
```

</Step>

<Step title="Add webhook in Dodo Payments">
Ange endpoint-URL till:

```text
https://[your-project-ref].supabase.co/functions/v1/dodo-webhook
```

Välj betalnings- och prenumerationshändelser.
</Step>

<Step title="Create products and features">
I dashboarden för Dodo → Products → Create Product. Lägg eventuellt till metadata:

```json
{
  "features": ["Feature 1", "Feature 2", "Feature 3"]
}
```

Prisgränssnittet läser denna `features`-array och återger den dynamiskt.
</Step>

<Step title="Run the dev server">

```bash
bun run dev
# or
npm run dev
# or
pnpm run dev
```

Öppna http://localhost:3000.
</Step>
</Steps>

## Detta ingår

- Autentisering via Supabase (Google OAuth konfigurerat)
- Checkout för prenumerationer via Dodo Payments
- Supabase Edge Function för webhooks (`dodo-webhook`)
- Drizzle ORM-schema och migreringar
- Dashboard med fakturor, prenumerationsstatus och planfunktioner

<Tip>
Behåll `DODO_PAYMENTS_ENVIRONMENT` som `test_mode` tills du har slutfört tester från början till slut.
</Tip>

## Verifiering och felsökning

<AccordionGroup>
<Accordion title="Webhook signature invalid (401)">
- Kontrollera att `DODO_WEBHOOK_SECRET` matchar värdet från dashboarden för Dodo
- Bekräfta att du distribuerade den senaste funktionen `dodo-webhook`
- Kontrollera att headernamnet är korrekt i din funktion (Dodo-Signature)
</Accordion>
<Accordion title="Database push fails">
- Kontrollera `DATABASE_URL`-syntaxen och Supabase-nätverkets utgående trafik
- Vänta cirka 2–3 minuter efter att projektet skapats innan den första pushen
</Accordion>
<Accordion title="OAuth redirect mismatch">
- Redirect-URI:n måste vara `https://[ref].supabase.co/auth/v1/callback`
- Kontrollera att samma URI används i Google Cloud och Supabase Auth-provider
</Accordion>
</AccordionGroup>
