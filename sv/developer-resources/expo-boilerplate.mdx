## Översikt

En produktionsklar boilerplate för att integrera Dodo Payments i Expo/React Native-applikationer. Denna mall inkluderar skapande av checkout-sessioner, betalningshantering och korrekt TypeScript-konfiguration för att hjälpa dig att snabbt börja ta emot betalningar i din mobilapp.

<Info>
Detta boilerplate använder Expo SDK med TypeScript och inkluderar exempelimplementationer för kassasessioner och betalningshantering.
</Info>

## Förutsättningar

- Node.js 18+
- Expo CLI eller EAS CLI
- Dodo Payments-konto (API-nyckel från instrumentpanelen)
- iOS Simulator eller Android Emulator (eller fysisk enhet)

## Snabbstart

<Steps>
<Step title="Clone the Repository">
Klona boilerplate-förvaret och gå till projektkatalogen:

```bash
git clone https://github.com/dodopayments/expo-boilerplate.git
cd expo-boilerplate
```

</Step>

<Step title="Get Your API Credentials">
Hämta dina uppgifter från Dodo Payments-instrumentpanelen i Testläge:

- **API-nyckel**: Navigera till **Utvecklare → API-nycklar** i din [instrumentpanel](https://app.dodopayments.com)

<Tip>
Börja i Testläge för att säkert testa din integration utan att hantera riktiga betalningar.
</Tip>
</Step>

<Step title="Configure Environment Variables">
Skapa en `.env`-fil i rotkatalogen:

```bash
touch .env
```

Lägg till dina Dodo Payments-referenser:

```bash .env
EXPO_PUBLIC_DODO_API_KEY=your_test_api_key_here
```

<Warning>
Checka aldrig in din `.env`-fil i versionshanteringen. Den ingår redan i `.gitignore`.
</Warning>

<Warning>
`EXPO_PUBLIC_*`-variabler bäddas in i det levererade JavaScript-paketet och kan läsas av alla som laddar ner din app. Dodo Payments API-nycklar är bearer-hemligheter, så använd detta endast med en Test Mode-nyckel under utvecklingen. För produktion skapar du checkout-sessioner på din backend och skickar endast den resulterande `checkout_url` till appen – se [Mobile Integration](/developer-resources/mobile-integration).
</Warning>
</Step>

<Step title="Install Dependencies">
Installera de obligatoriska npm-paketen:

```bash
npm install
```

</Step>

<Step title="Start the Development Server">
Starta Expo-utvecklingsservern:

```bash
npx expo start
```

Skanna QR-koden med Expo Go-appen på din enhet, eller tryck på `i` för iOS-simulatorn eller `a` för Android-emulatorn.

<Check>
Du är redo att börja bygga! Boilerplate-koden innehåller exempel på skärmar och komponenter som hjälper dig att förstå integrationen.
</Check>
</Step>
</Steps>

## Projektstruktur

```
expo-boilerplate/
├── app/
│   ├── (tabs)/
│   │   └── index.tsx          # Home screen with examples
│   └── checkout.tsx           # Checkout screen
├── components/
│   └── PaymentButton.tsx      # Payment button component
├── lib/
│   └── dodo.ts                # Dodo Payments client setup
├── .env.example               # Environment variables template
└── package.json
```

## Nästa steg

När du har fått boilerplate-koden att köra:

<Steps>
<Step title="Create Your Products">
Lägg till produkter i din [Dodo Payments-dashboard](https://app.dodopayments.com) för att aktivera checkout-funktionaliteten.
</Step>

<Step title="Customize the Integration">
Anpassa exempelkoden efter din apps behov och design.
</Step>

<Step title="Test on Real Devices">
Testa betalningsflödet på fysiska enheter för att säkerställa att allt fungerar korrekt.
</Step>

<Step title="Go Live">
När du är redo byter du till Live Mode API-nycklar och bygger din app för produktion.
</Step>
</Steps>

## Bygga för produktion

<Steps>
<Step title="Install EAS CLI">

```bash
npm install -g eas-cli
```

</Step>

<Step title="Configure EAS">

```bash
eas build:configure
```

</Step>

<Step title="Build Your App">
För iOS:

```bash
eas build --platform ios
```

För Android:

```bash
eas build --platform android
```

</Step>
</Steps>
