Dodo Agent Plugin kopplar två MCP-servrar och åtta integrationsfärdigheter till din AI-kodningsagent i en enda installation. Den fungerar med **Claude Code**, **Codex CLI**, **Cursor** och **OpenCode** — och MCP-servrar och färdigheter CLI fungerar med alla MCP-kompatibla klienter.

  
**Tre primitiv, en plugin.** Agent Plugin samlar allt du behöver:
- **API MCP-server** — liveåtkomst till betalningar, prenumerationer, kunder, produkter, återbetalningar, licenser och användning. Autentiserar via webbläsarens OAuth (inga lokala nycklar krävs).
- **Kunskap MCP-server** — semantisk sökning i all Dodo Payments-dokumentation. Inga referenser behövs.
- **Åtta agentfärdigheter** — fusklappar som din agent laddar vid behov för kassa, prenumerationer, webhooks, användningsbaserad fakturering, kreditbaserad fakturering, licensnycklar, BillingSDK och bästa praxis.

## Installera plugin

Välj din kodningsagent nedan. Installationen lägger till både MCP-servrar och alla åtta färdigheter automatiskt.

Installera från marknadsplatsen:

```bash
claude plugins marketplace add dodopayments/dodo-agent-plugin
claude plugins install dodopayments@dodopayments
```

API MCP-servern använder webbläsarens OAuth som standard — inga nycklar krävs vid installationen. Första gången din agent anropar ett Dodo-verktyg, kommer du att uppmanas att logga in.

## Vad du får

När pluginen är installerad har din agent tillgång till två MCP-servrar och åtta färdigheter.

### MCP-servrar

| Server | Syfte | Auth |
|--------|-------|------|
| `dodopayments-api` | Live API-åtkomst — betalningar, abonnemang, kunder, produkter, återbetalningar, licenser, användning | OAuth (webbläsare) |
| `dodo-knowledge` | Semantisk sökning över all Dodo Payments dokumentation | Ingen |

Båda servrar är anslutna genom `mcp-remote` så de körs i alla MCP-kompatibla klienter.

### Agentfärdigheter

| Färdighet | Beskrivning |
|-----------|-------------|
| `best-practices` | Omfattande guide för att integrera Dodo Payments med bästa praxis |
| `checkout-integration` | Skapande av kassasessioner och betalningsflöden |
| `subscription-integration` | Implementering av abonnemangsbetalningsflöden |
| `webhook-integration` | Installera och hantera webhooks för betalningshändelser |
| `usage-based-billing` | Implementering av mätt fakturering med händelser och mätare |
| `credit-based-billing` | Krediträttigheter, saldon och mätt krediteringsavdrag |
| `license-keys` | Hantering av licensnycklar för digitala produkter |
| `billing-sdk` | Användning av BillingSDK React-komponenter |

Färdigheter laddas automatiskt — din agent väljer rätt när den upptäcker en relevant uppgift. Se [Agent Skills documentation](/developer-resources/agent-skills) för hela listan och individuell installation.

### Prova detta prompt först

När pluginen är aktiv, prova:

```
Set up Dodo Payments webhook handlers in my Next.js app for payment.succeeded and subscription.active events.
```

Din agent kommer att ladda `webhook-integration` färdigheten, använda `dodo-knowledge` MCP för att dra de senaste payload-formerna, och skriva en handler med signaturverifiering enligt Standard Webhooks spec.

## Dokument byggd för agenter

Varje Dodo Payments dokumentationssida finns tillgänglig i ett format optimerat för AI-konsumtion:

- **Fullständigt dokumentindex**: [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt) — tjänar hela dokumentationsindexet för kontextuell inhämtning.
- **Plains markdown**: Lägg till `.md` till valfri dokumentURL för att få den råa markdown-versionen (t.ex., `/api-reference/introduction.md`).
- **Källkodslager**: [`github.com/dodopayments/dodo-docs`](https://github.com/dodopayments/dodo-docs) — klona för offline-indexering.

- **Implementera kreditbaserad fakturering** med rättigheter, saldon, utdelningar och överskott — [Credits](/features/credit-based-billing)

## Säkerhet och bästa praxis

{/* LOCKED_PATTERN_4907e9f6f7fbd509120d7a87afc829e9 */}
**Ändra aldrig produktions-API-nycklar.** Använd [testläge](/miscellaneous/test-mode-vs-live-mode) under utveckling. Agent Plugin använder webbläsarens OAuth som standard — växla bara till lokala API-nycklar om ditt arbetsflöde kräver det.
{/* LOCKED_PATTERN_176d815432e7554ac558e8631b2bc397 */}

- **Använd testläge först.** Sandlåde din integration med `dodo_test_...` nycklar innan du går live. Se [Test Mode vs Live Mode](/miscellaneous/test-mode-vs-live-mode).
- **OAuth är standard.** Agent Plugin autentiseras via webbläsarens OAuth (inga lokala hemligheter). Använd endast API-nyckelläge om du behöver det — se konfigurationsavsnittet nedan.
- **Granska agent-genererad kod.** Kontrollera alltid att webhook-handlare inkluderar signaturverifiering enligt [Standard Webhooks spec](https://standardwebhooks.com/).

## Konfigurera med en API-nyckel

Som standard använder Agent Plugin den fjärrbundna MCP-servern med webbläsarens OAuth — inga lokala autentiseringsuppgifter behövs. Om ditt arbetsflöde kräver en lokal API-nyckel (t.ex., CI-miljöer, headless-servrar), kan du växla till stdio-läge.

{/* LOCKED_PATTERN_3a00efd457b01f610250031fcbf16962 */}
{/* LOCKED_PATTERN_f22e427153b199e505630b6831e2b3fb */}
Öppna `/plugins` i Claude Code, välj **Dodo Payments**, och välj **Konfigurationsalternativ**. Fyll i:

- `dodo_api_key` — din `dodo_test_...` eller `dodo_live_...` nyckel
- `dodo_webhook_key` — din webhook signeringshemlighet
- `dodo_environment` — `test_mode` eller `live_mode`

Redigera sedan `.mcp.json` för att peka `dodopayments-api` mot den lokala stdio-servern:

```json
{
  "mcpServers": {
    "dodopayments-api": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "dodopayments-mcp@latest"],
      "env": {
        "DODO_PAYMENTS_API_KEY": "${user_config.dodo_api_key}",
        "DODO_PAYMENTS_WEBHOOK_KEY": "${user_config.dodo_webhook_key}",
        "DODO_PAYMENTS_ENVIRONMENT": "${user_config.dodo_environment}"
      }
    }
  }
}
```

Kör `/reload-plugins` för att tillämpa ändringar på din aktuella session.
{/* LOCKED_PATTERN_aae63d8bf6b6da4ac6fb501e13691e4d */}

{/* LOCKED_PATTERN_b7dd62d9b26c1f6d29d920e3d296523a */}
Deklarera `dodopayments-api` själv i `opencode.json` — din post vinner över pluginens standard fjärrserver:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "mcp": {
    "dodopayments-api": {
      "type": "local",
      "command": ["npx", "-y", "dodopayments-mcp@latest"],
      "environment": {
        "DODO_PAYMENTS_API_KEY": "dodo_test_...",
        "DODO_PAYMENTS_WEBHOOK_KEY": "whsec_...",
        "DODO_PAYMENTS_ENVIRONMENT": "test_mode"
      },
      "enabled": true
    }
  }
}
```

Starta om OpenCode för att tillämpa.
