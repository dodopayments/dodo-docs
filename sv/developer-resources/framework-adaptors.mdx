Dodo Payments tillhandahåller officiella ramverksadaptrar som förenklar betalningsintegration. Varje adapter är utformad för att fungera sömlöst med ditt ramverks konventioner och erbjuder kassa, kundportal och webhook-hantering direkt ur lådan.

<Tip>
Ramverksadaptrar låter dig integrera Dodo Payments på mindre än 10 rader kod. De hanterar autentisering, begärningsparsing och svarformatering automatiskt.
</Tip>

## Kärnfunktioner

Alla ramverksadaptrar erbjuder dessa inbyggda egenskaper:

| Egenskap | Beskrivning |
|---------|-------------|
| **Checkout Hanterare** | Stöd för statiska, dynamiska och sessionbaserade checkout-flöden |
| **Kundportal** | Förbygga hanterare för prenumerations- och fakturahantering |
| **Webhook Hanterare** | Säker signaturverifiering med typade eventhanterare |
| **Miljökonfiguration** | Enkel installation via miljövariabler |
| **Typssäkerhet** | Full TypeScript-support med typade payloads |

Kom igång med vilken ramverksadapter som helst i tre steg:

<Steps>
<Step title="Installera Adaptorn">
  Använd din pakethanterare för att installera den ramverkspecifika adaptern:

  <Tabs>
  <Tab title="Next.js">

  ```bash
  npm install @dodopayments/nextjs
  ```

  </Tab>
  
  <Tab title="Nuxt">

  ```bash
  npm install @dodopayments/nuxt
  ```

  </Tab>
  
  <Tab title="Express">

  ```bash
  npm install @dodopayments/express
  ```

  </Tab>
  
  <Tab title="Hono">

  ```bash
  npm install @dodopayments/hono
  ```

  </Tab>

  <Tab title="Astro">

  ```bash
  npm install @dodopayments/astro
  ```

  </Tab>
  
  <Tab title="SvelteKit">

  ```bash
  npm install @dodopayments/sveltekit
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Konfigurera miljövariabler">
  Lägg till dina Dodo Payments-uppgifter i din miljö:

<Step title="Konfigurera Miljövariabler">
  Lägg till dina Dodo Payments referenser i din miljö:

  ```env
  DODO_PAYMENTS_API_KEY=your-api-key
  DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
  DODO_PAYMENTS_RETURN_URL=https://yourdomain.com/checkout/success
  DODO_PAYMENTS_ENVIRONMENT="test_mode" # or "live_mode"
  ```

  <Warning>
  Kom ihåg att aldrig begå din `.env` fil eller hemligheter till versionskontroll.
  </Warning>
</Step>

<Step title="Skapa Rutt-hanterare">
  Ställ in dina checkout-, kundportal- och webhook-rutter:

  <Tabs>
  <Tab title="Next.js">

  ```typescript
  // app/checkout/route.ts
  import { Checkout } from "@dodopayments/nextjs";

  export const GET = Checkout({
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
    environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  });
  ```

  </Tab>
  
  <Tab title="Express">

  ```typescript
  import { checkoutHandler } from '@dodopayments/express';

  app.get('/api/checkout', checkoutHandler({
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
    environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  }));
  ```

  </Tab>
  
  <Tab title="Hono">

  ```typescript
  import { Checkout } from "@dodopayments/hono";

  app.get('/checkout', Checkout({
    bearerToken: process.env.DODO_PAYMENTS_API_KEY,
    returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
    environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  }));
  ```

  </Tab>
  </Tabs>

  <Check>
  Du är nu redo att behandla betalningar! Besök de individuella adaptrarna för detaljerade guider och alla tillgängliga alternativ.
  </Check>
</Step>
</Steps>

## Checkout Flödestyper

Alla adaptrar stöder tre checkout flödestyper:

<AccordionGroup>
<Accordion title="Statisk Checkout (GET)">
Använd statisk checkout för enkla, delbara betalningslänkar. Skicka produkt-ID som en frågeparameter:

```
/api/checkout?productId=pdt_xxx&quantity=1
```

Stödjer valfri kund förifyllning och anpassning via frågeparametrar.
</Accordion>

<Accordion title="Dynamisk Checkout (POST)">
Använd dynamisk checkout för att programmässigt skapa betalningar med anpassade detaljer:

```json
{
  "product_id": "pdt_xxx",
  "customer": {
    "email": "customer@example.com",
    "name": "John Doe"
  },
  "quantity": 1
}
```

Stödjer både engångsbetalningar och prenumerationer.
</Accordion>

<Accordion title="Checkout-sessioner (POST)">
Använd checkout-sessioner för den mest flexibla checkout-upplevelsen med kundvagnsstöd:

```json
{
  "product_cart": [
    { "product_id": "pdt_xxx", "quantity": 1 },
    { "product_id": "pdt_yyy", "quantity": 2 }
  ],
  "customer": {
    "email": "customer@example.com"
  }
}
```

Läs mer i [Checkout-session guide](/developer-resources/checkout-session).
</Accordion>
</AccordionGroup>

## Webhook Händelsehantering

Alla adaptrar erbjuder typ-säker webhook hantering med detaljerade event callbacks:

```typescript
Webhooks({
  webhookKey: process.env.DODO_PAYMENTS_WEBHOOK_KEY,
  onPayload: async (payload) => {
    // Handle any webhook event
  },
  onPaymentSucceeded: async (payload) => {
    // Handle successful payments
  },
  onSubscriptionActive: async (payload) => {
    // Handle new subscriptions
  },
  // ... 20+ event types supported
});
```

<Info>
Alla webhook-hanterare verifierar automatiskt signaturer och validerar payloads med Zod-scheman. Ogiltiga förfrågningar avvisas med lämpliga felkoder.
</Info>
