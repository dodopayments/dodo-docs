## Snabbstart

Kom igång med automatisk LLM-tokenspårning på bara 2 minuter:

<Steps>
<Step title="Install the SDK">
Installera Dodo Payments Ingestion Blueprints:

```bash
npm install @dodopayments/ingestion-blueprints
```

</Step>

<Step title="Get Your API Keys">
Du behöver två API-nycklar:

- **Dodo Payments API Key**: Hämta den från [Dodo Payments Dashboard](https://app.dodopayments.com/developer/api-keys)
- **LLM Provider API Key**: Från AI SDK, OpenAI, Anthropic, Groq osv.

<Tip>
Lagra dina API-nycklar säkert i miljövariabler. Checka aldrig in dem i versionshanteringen.
</Tip>
</Step>

<Step title="Create a Meter in Dodo Payments">
Innan du spårar användning skapar du en mätare i din Dodo Payments-instrumentpanel:

1. **Logga in** på [Dodo Payments Dashboard](https://app.dodopayments.com/)
2. **Gå till** Products → Meters
3. **Klicka på** "Create Meter"
4. **Konfigurera mätaren**:
   - **Meter Name**: Välj ett beskrivande namn (t.ex. "LLM Token Usage")
   - **Event Name**: Ange en unik händelseidentifierare (t.ex. `llm.chat_completion`)
   - **Aggregation Type**: Välj `sum` för att summera tokenantal
   - **Over Property**: Välj vad som ska spåras:
     - `inputTokens` – Spåra indata-/prompttokens
     - `outputTokens` – Spåra utdata-/slutförandetokens (inklusive resonemangstokens när det är tillämpligt)
     - `totalTokens` – Spåra kombinerade indata- och utdatatokens

<Info>
**Event Name** som du anger här måste exakt matcha det du skickar till SDK:t (skiftlägeskänsligt).
</Info>

Detaljerade instruktioner finns i [Guiden för användningsbaserad fakturering](/developer-resources/usage-based-billing-guide).
</Step>

## Konfiguration

### Tracker-konfiguration

Skapa en tracker en gång när applikationen startar, med följande obligatoriska parametrar:

<ParamField path="apiKey" type="string" required>
Din Dodo Payments API-nyckel. Hämta den från sidan [API Keys](https://app.dodopayments.com/developer/api-keys).

```javascript
apiKey: process.env.DODO_PAYMENTS_API_KEY
```

</ParamField>

<ParamField path="environment" type="string" required>
Miljöläget för trackern.

- `test_mode` – Använd för utveckling och testning
- `live_mode` – Använd i produktion

```javascript
environment: 'test_mode' // or 'live_mode'
```

<Warning>
Använd alltid `test_mode` under utveckling för att undvika att påverka produktionsmått.
</Warning>
</ParamField>

<ParamField path="eventName" type="string" required>
Händelsenamnet som utlöser din mätare. Måste exakt matcha det du konfigurerade i din Dodo Payments-mätare (skiftlägeskänsligt).

```javascript
eventName: 'llm.chat_completion'
```

<Info>
Detta händelsenamn kopplar din spårade användning till rätt mätare för faktureringsberäkningar.
</Info>
</ParamField>

### Wrapper-konfiguration

När du wrapper din LLM-klient anger du följande parametrar:

<ParamField path="client" type="object" required>
Din LLM-klientinstans (OpenAI, Anthropic, Groq osv.).

```javascript
client: openai
```

</ParamField>

<ParamField path="customerId" type="string" required>
Den unika kundidentifieraren för fakturering. Den bör matcha ditt kund-ID i Dodo Payments.

```javascript
customerId: 'customer_123'
```

<Tip>
Använd applikationens användar-ID eller kund-ID för att säkerställa korrekt fakturering per kund.
</Tip>
</ParamField>

<ParamField path="metadata" type="object">
Valfria ytterligare data som kopplas till spårningshändelsen. Användbart för filtrering och analys.

```javascript
metadata: {
  feature: 'chat',
  userTier: 'premium',
  sessionId: 'session_123',
  modelVersion: 'gpt-4'
}
```

</ParamField>

### Komplett konfigurationsexempel

<CodeGroup>

```javascript Full Configuration
import { createLLMTracker } from "@dodopayments/ingestion-blueprints";
import { generateText } from "ai";
import { google } from "@ai-sdk/google";
import "dotenv/config";

async function aiSdkExample() {
  console.log("🤖 AI SDK Simple Usage Example\n");

  try {
    // 1. Create tracker
    const llmTracker = createLLMTracker({
      apiKey: process.env.DODO_PAYMENTS_API_KEY!,
      environment: "test_mode",
      eventName: "your_meter_event_name",
    });

    // 2. Wrap the ai-sdk methods
    const client = llmTracker.wrap({
      client: { generateText },
      customerId: "customer_123",
      metadata: {
        provider: "ai-sdk",
      },
    });

    // 3. Use the wrapped function
    const response = await client.generateText({
      model: google("gemini-2.5-flash"),
      prompt: "Hello, I am a cool guy! Tell me a fun fact.",
      maxOutputTokens: 500,
    });

    console.log(response);
    console.log(response.usage);
    console.log("✅ Automatically tracked for customer\n");
  } catch (error) {
    console.error(error);
  }
}

aiSdkExample().catch(console.error);
```

</CodeGroup>

<Info>
**Automatisk spårning:** SDK:t spårar automatiskt tokenanvändningen i bakgrunden utan att ändra svaret. Din kod förblir ren och identisk med kod som använder de ursprungliga leverantörs-SDK:erna.
</Info>

### Express.js API-integration

Komplett exempel på hur LLM-spårning integreras i ett Express.js-API:

<CodeGroup>

```javascript Express.js Server
import express from 'express';
import { createLLMTracker } from '@dodopayments/ingestion-blueprints';
import OpenAI from 'openai';

const app = express();
app.use(express.json());

// Initialize OpenAI client
const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

// Create tracker once at startup
const tracker = createLLMTracker({
  apiKey: process.env.DODO_PAYMENTS_API_KEY,
  environment: process.env.NODE_ENV === 'production' ? 'live_mode' : 'test_mode',
  eventName: 'api.chat_completion'
});

// Chat endpoint with automatic tracking
app.post('/api/chat', async (req, res) => {
  try {
    const { message, userId } = req.body;
    
    // Validate input
    if (!message || !userId) {
      return res.status(400).json({ error: 'Missing message or userId' });
    }
    
    // Wrap client for this specific user
    const trackedClient = tracker.wrap({
      client: openai,
      customerId: userId,
      metadata: { 
        endpoint: '/api/chat',
        timestamp: new Date().toISOString()
      }
    });
    
    // Make LLM request - automatically tracked
    const response = await trackedClient.chat.completions.create({
      model: 'gpt-4',
      messages: [{ role: 'user', content: message }],
      temperature: 0.7
    });
    
    const completion = response.choices[0].message.content;
    
    res.json({ 
      message: completion,
      usage: response.usage
    });
  } catch (error) {
    console.error('Chat error:', error);
    res.status(500).json({ error: 'Internal server error' });
  }
});

app.listen(3000, () => {
  console.log('Server running on port 3000');
});
```

</CodeGroup>


### Händelsefält

<ParamField path="event_id" type="string">
Unik identifierare för den specifika händelsen. Genereras automatiskt av SDK:t.

Format: `llm_[timestamp]_[random]`
</ParamField>

<ParamField path="customer_id" type="string">
Det kund-ID du angav när du wrapper klienten. Används för fakturering.
</ParamField>

<ParamField path="event_name" type="string">
Händelsenamnet som utlöser din mätare. Matchar din tracker-konfiguration.
</ParamField>

<ParamField path="timestamp" type="string">
ISO 8601-tidsstämpel för när händelsen inträffade.
</ParamField>

<ParamField path="metadata" type="object">
Tokenanvändning och ytterligare spårningsdata:

- `inputTokens` – Antalet använda indata-/prompttokens
- `outputTokens` – Antalet använda utdata-/slutförandetokens (inklusive resonemangstokens när det är tillämpligt)
- `totalTokens` – Totalt antal tokens (indata + utdata)
- `model` – Den LLM-modell som användes (t.ex. "gpt-4")
- `provider` – LLM-leverantören (om den ingår i wrapper-metadata)
- Alla anpassade metadata som du angav när du wrapper klienten

<Note>
**Resonemangstokens:** För modeller med resonemangsfunktioner inkluderar `outputTokens` automatiskt både slutförandetokens och resonemangstokens.
</Note>
</ParamField>

<Info>
Din Dodo Payments-mätare använder fälten `metadata` (särskilt `inputTokens`, `outputTokens` eller `totalTokens`) för att beräkna användning och fakturering.
</Info>
