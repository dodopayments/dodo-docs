## Installation

<Steps>
<Step title="Installera paketet">
Kör följande kommando i din projektrot:

```bash
bun add @dodopayments/bun
```

</Step>
<Step title="Ställ in miljövariabler">
Skapa en <code>.env</code>-fil i din projektrot:

```env expandable
DODO_PAYMENTS_API_KEY=your-api-key
DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
DODO_PAYMENTS_ENVIRONMENT="test_mode" or "live_mode"
DODO_PAYMENTS_RETURN_URL=your-return-url
```

<Warning>
Kom aldrig att åta dig din <code>.env</code>-fil eller hemligheter till versionskontroll.
</Warning>
</Step>
</Steps>

## Exempel på Route Handlers

<Info>
Alla exempel förutsätter att du använder Buns inbyggda server med <code>Bun.serve()</code>.
</Info>

<Tabs>
<Tab title="Checkout Handler">
  <Info>
  Använd den här hanteraren för att integrera Dodo Payments checkout i din Bun-server. Stöder statiska (GET), dynamiska (POST) och sessions (POST) betalningsflöden.
  </Info>
  <CodeGroup>

    ```typescript Bun Server Handler expandable
    import { Checkout } from '@dodopayments/bun';

    const staticCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "static"
    });

    const sessionCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "session"
    });

    const dynamicCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "dynamic"
    });

    Bun.serve({
      port: 3000,
      fetch(request) {
        const url = new URL(request.url);
        
        if (url.pathname === "/api/checkout") {
          if (request.method === "GET") {
            return staticCheckoutHandler(request);
          }
          if (request.method === "POST") {
            return sessionCheckoutHandler(request);
            // or return dynamicCheckoutHandler(request);
          }
        }
        
        return new Response("Not Found", { status: 404 });
      },
    });
    ```

  </CodeGroup>
  <CodeGroup>

## Checkout Route Handler

<Info>
Dodo Payments stöder tre typer av betalningsflöden för att integrera betalningar på din webbplats, denna adaptor stöder alla typer av betalningsflöden.
</Info>

- **Statiska betalningslänkar:** Omedelbart delbara URL:er för snabb, kodfri betalningsinsamling.
- **Dynamiska betalningslänkar:** Programmässigt generera betalningslänkar med anpassade uppgifter med hjälp av API:et eller SDK:erna.
- **Checkout-sessioner:** Skapa säkra, anpassningsbara checkout-upplevelser med förkonfigurerade produktkorgar och kunduppgifter.

## Customer Portal Route Handler

Customer Portal Route Handler gör det möjligt för dig att sömlöst integrera Dodo Payments kundportal i din Bun-serverapplikation.

### Frågeparametrar
<ParamField query="customer_id" type="string" required>
Kund-ID för portal-sessionen (t.ex. <code>?customer_id=cus_123</code>).
</ParamField>
<ParamField query="send_email" type="boolean">
Om inställt på <code>true</code>, skickas ett e-postmeddelande till kunden med portalens länk.
</ParamField>

<Warning>
Returnerar 400 om <code>customer_id</code> saknas.
</Warning>

## Webhook Route Handler

- **Metod:** Endast POST-begärningar stöds. Andra metoder returnerar 405.
- **Signaturverifiering:** Verifierar webhook-signaturen med <code>webhookKey</code>. Returnerar 401 om verifieringen misslyckas.
- **Payloadvalidering:** Valideras med Zod. Returnerar 400 för ogiltiga payloads.
- **Felhantering:**
  - 401: Ogiltig signatur
  - 400: Ogiltig payload
  - 500: Internt fel under verifiering
- **Händelse-routing:** Anropar den lämpliga händelsehanteraren baserat på payload-typen.

typescript
import { Checkout, CustomerPortal, Webhooks } from "@dodopayments/bun";

const staticCheckoutHandler = Checkout({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  type: "static",
});

const sessionCheckoutHandler = Checkout({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
  type: "session",
});

const customerPortalHandler = CustomerPortal({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
});

const webhookHandler = Webhooks({
  webhookKey: process.env.DODO_PAYMENTS_WEBHOOK_KEY,
  onPaymentSucceeded: async (payload) => {
    console.log("Betalning genomförd:", payload);
    // Din affärslogik här
  },
  onSubscriptionActive: async (payload) => {
    console.log("Prenumeration aktiverad:", payload);
    // Din affärslogik här
  },
});

Bun.serve({
  port: 3000,
  fetch(request) {
    const url = new URL(request.url);
    
    // Checkout-rutter
    if (url.pathname === "/api/checkout") {
      if (request.method === "GET") {
        return staticCheckoutHandler(request);
      }
      if (request.method === "POST") {
        return sessionCheckoutHandler(request);
      }
    }
    
    // Kundportalroute
    if (url.pathname === "/api/customer-portal" && request.method === "GET") {
      return customerPortalHandler(request);
    }
    
    // Webhookroute
    if (url.pathname === "/api/webhook/dodo-payments" && request.method === "POST") {
      return webhookHandler(request);
    }
    
    return new Response("Inte hittad", { status: 404 });
  },
});

console.log("Server körs på http://localhost:3000");
