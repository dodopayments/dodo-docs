## Installation

<Steps>
<Step title="Install the package">
Kör följande kommando i projektets rotkatalog:

```bash
bun add @dodopayments/bun
```

</Step>
<Step title="Set up environment variables">
Skapa en <code>.env</code>-fil i projektets rotkatalog:

```env expandable
DODO_PAYMENTS_API_KEY=your-api-key
DODO_PAYMENTS_WEBHOOK_KEY=your-webhook-secret
DODO_PAYMENTS_ENVIRONMENT="test_mode" or "live_mode"
DODO_PAYMENTS_RETURN_URL=your-return-url
```

<Warning>
Lägg aldrig in din <code>.env</code>-fil eller hemligheter i versionshanteringen.
</Warning>
</Step>
</Steps>

## Exempel på route handlers

<Info>
Alla exempel förutsätter att du använder Buns inbyggda server med <code>Bun.serve()</code>.
</Info>

<Tabs>
<Tab title="Checkout Handler">
  <Info>
  Använd denna handler för att integrera Dodo Payments checkout i din Bun-server. Stöder statiska (GET), dynamiska (POST) och sessionsbaserade (POST) betalningsflöden.
  </Info>
  <CodeGroup>

    ```typescript Bun Server Handler expandable
    import { Checkout } from '@dodopayments/bun';

    const staticCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "static"
    });

    const sessionCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "session"
    });

    const dynamicCheckoutHandler = Checkout({
        bearerToken: process.env.DODO_PAYMENTS_API_KEY,
        returnUrl: process.env.DODO_PAYMENTS_RETURN_URL,
        environment: process.env.DODO_PAYMENTS_ENVIRONMENT,
        type: "dynamic"
    });

    Bun.serve({
      port: 3000,
      fetch(request) {
        const url = new URL(request.url);
        
        if (url.pathname === "/api/checkout") {
          if (request.method === "GET") {
            return staticCheckoutHandler(request);
          }
          if (request.method === "POST") {
            return sessionCheckoutHandler(request);
            // or return dynamicCheckoutHandler(request);
          }
        }
        
        return new Response("Not Found", { status: 404 });
      },
    });
    ```

  </CodeGroup>
  <CodeGroup>

## Checkout route handler

<Info>
Dodo Payments stöder tre typer av betalningsflöden för att integrera betalningar på din webbplats. Denna adaptor stöder alla typer av betalningsflöden.
</Info>

- **Statiska betalningslänkar:** Omedelbart delbara URL:er för snabb betalningsinsamling utan kod.
- **Dynamiska betalningslänkar:** Skapa betalningslänkar programmatiskt med anpassade uppgifter via API eller SDK:er.
- **Checkout-sessioner:** Skapa säkra, anpassningsbara checkout-upplevelser med förkonfigurerade produktvarukorgar och kunduppgifter.

## Customer Portal route handler

Customer Portal route handler gör det möjligt att sömlöst integrera Dodo Payments kundportal i din Bun-serverapplikation.

### Frågeparametrar
<ParamField query="customer_id" type="string" required>
Kund-ID:t för portalsessionen (t.ex. <code>?customer_id=cus_123</code>).
</ParamField>
<ParamField query="send_email" type="boolean">
Om värdet är <code>true</code> skickas ett e-postmeddelande till kunden med portallänken.
</ParamField>

<Warning>
Returnerar 400 om <code>customer_id</code> saknas.
</Warning>

## Webhook route handler

- **Metod:** Endast POST-begäranden stöds. Andra metoder returnerar 405.
- **Signaturverifiering:** Verifierar webhook-signaturen med <code>webhookKey</code>. Returnerar 401 om verifieringen misslyckas.
- **Validering av payload:** Valideras med Zod. Returnerar 400 för ogiltiga payloads.
- **Felhantering:**
  - 401: Ogiltig signatur
  - 400: Ogiltig payload
  - 500: Internt fel under verifieringen
- **Event routing:** Anropar rätt event handler baserat på payload-typen.
