Hantera dina Dodo Payments-resurser, skapa checkout-sessioner och testa webhooks direkt från terminalen. Byggt för utvecklare som föredrar kommandoraden.

## Installation

<CodeGroup>

```bash npm (Recommended)
npm install -g dodopayments-cli
```

```bash Bun
bun install -g dodopayments-cli
```

</CodeGroup>

### Manuell installation

1. Ladda ner den senaste versionen från [GitHub Releases](https://github.com/dodopayments/dodopayments-cli/releases) för ditt system
2. Extrahera och döp om den binära filen till `dodo`
3. Flytta till en katalog i din PATH:

<CodeGroup>

```bash Linux
sudo mv ./dodo /usr/local/bin/
```

```text Windows
move .\dodo C:\Windows\System32\dodo
```

</CodeGroup>

## Autentisering

Innan du använder CLI, autentisera med din API-nyckel:

```bash
dodo login
```

Detta kommer att:
1. Öppna din webbläsare till sidan för Dodo Payments API-nycklar
2. Be dig att ange din API-nyckel
3. Be dig att välja miljö (**Testläge** eller **Live-läge**)
4. Lagra dina autentiseringsuppgifter lokalt till `~/.dodopayments/api-key`

<Info>
CLI:n stöder lagring av en API-nyckel per miljö. Om både test- och livemiljönycklar är konfigurerade, kommer du att bli ombedd att välja vilken miljö som ska användas för den aktuella sessionen.
</Info>

## Användning

Den allmänna syntaxen är:

```bash
dodo ‹category› ‹sub-command›
```

Att köra `dodo` utan argument visar alla tillgängliga kategorier. Att köra `dodo <category>` utan underkommando visar de tillgängliga underkommandona för den kategorin.

### Produkter

Hantera din produktkatalog.

| Kommando | Beskrivning |
|---------|-------------|
| `dodo products list` | Lista alla produkter (pagineerade) |
| `dodo products create` | Öppna instrumentpanelen för att skapa en produkt |
| `dodo products info` | Visa detaljer för en specifik produkt |

### Betalningar

Visa betalningstransaktioner.

| Kommando | Beskrivning |
|---------|-------------|
| `dodo payments list` | Lista alla betalningar (pagineerade) |
| `dodo payments info` | Få information om en specifik betalning |

### Kunder

Hantera din kundbas.

| Kommando | Beskrivning |
|---------|-------------|
| `dodo customers list` | Lista alla kunder (pagineerade) |
| `dodo customers create` | Skapa en ny kundprofil |
| `dodo customers update` | Uppdatera en existerande kunds uppgifter |

### Rabatter

Hantera kuponger och rabatter.

| Kommando | Beskrivning |
|---------|-------------|
| `dodo discounts list` | Lista alla rabatter (pagineerade) |
| `dodo discounts create` | Skapa en ny procentbaserad rabatt |
| `dodo discounts delete` | Ta bort en rabatt med ID |

### Licenser

Hantera programvarulicenser.

| Kommando | Beskrivning |
|---------|-------------|
| `dodo licences list` | Lista alla licensnycklar (pagineerade) |

### Tillägg

Hantera produkt-tillägg.

| Kommando | Beskrivning |
|---------|-------------|
| `dodo addons list` | Lista alla tillägg (pagineerade) |
| `dodo addons create` | Öppna instrumentpanelen för att skapa ett tillägg |
| `dodo addons info` | Visa detaljer för ett specifikt tillägg |

### Återbetalningar

Visa information om återbetalningar.

| Kommando | Beskrivning |
|---------|-------------|
| `dodo refund list` | Lista alla återbetalningar (pagineerade) |
| `dodo refund info` | Visa detaljer för en specifik återbetalning |

### Checkout

Skapa checkout-sessioner.

| Kommando | Beskrivning |
|---------|-------------|
| `dodo checkout new` | Skapa en ny checkout-session och få checkout-URL:en |

Checkout-kommandot stöder avancerade alternativ inklusive minimal insamling av adresser, åter-URL, 3D Secure-kontroll, rabattkoder och metadata.

## Webbhook-testning

CLI:n inkluderar två kraftfulla verktyg för att testa webhooks under utveckling: en **lyssnare** som vidarebefordrar live test-webhooks till din lokala server, och en **trigger** som skickar mock webhook-payloads till valfri endpoint.

### Lyssna på Webhooks

Vidarebefordra webhooks från Dodo Payments direkt till din lokala utvecklingsserver i realtid.

```bash
dodo wh listen
```

<Steps>
<Step title="Ange din lokala slutpunkt URL">
  Ange den lokala URL där du vill ta emot webhooks (t.ex., `http://localhost:3000/webhook`).
</Step>

<Step title="Automatisk installation">
  CLI:n skapar automatiskt en webhook-slutpunkt på ditt Dodo Payments-konto om en sådan inte redan finns, och öppnar sedan en WebSocket-anslutning för att ta emot händelser i realtid.
</Step>

<Step title="Ta emot och vidarebefordra">
  När en webhook-händelse inträffar (från en testbetalning, abonnemangsändring osv.), tar CLI:n emot den, loggar händelsetypen och vidarebefordrar hela begäran med rubriker och kropp till din lokala slutpunkt. Svaret från din slutpunkt loggas och skickas tillbaka.
</Step>
</Steps>

<Warning>
Webhook-lyssnaren fungerar endast med en **testläge** API-nyckel. Se till att du är inloggad med en testläge-nyckel innan du använder `dodo wh listen`.
</Warning>

<Tip>
Lyssnaren bevarar de ursprungliga webhook-rubrikerna (`webhook-id`, `webhook-signature`, `webhook-timestamp`) när de vidarebefordras till din lokala slutpunkt, så att du kan testa din signaturverifieringslogik.
</Tip>

### Utlös test-webhooks

Skicka mock webhook-payloads till valfri slutpunkt för snabb testning utan att behöva skapa riktiga transaktioner.

```bash
dodo wh trigger
```

Detta vägleder dig genom:
1. Ställa in en destinations **slutpunkt URL**
2. Eventuellt konfigurera **Företags-ID**, **Produkt-ID** och **Metadata**
3. Välja en specifik **händelse** att utlösa från en interaktiv meny
4. Skicka mock-payloaden och visa svaret

Efter varje händelse kan du välja en annan händelse att utlösa eller avsluta – vilket gör det enkelt att testa flera händelsehanterare i en session.

<Warning>
Trigger-verktyget skickar mock-payloads utan webhook-signaturer. Inaktivera webhook-signaturverifiering under testning genom att använda `unsafe_unwrap()` istället för `unwrap()` i din webhook-hanterare.
</Warning>

### Stödda Webhook-händelser

| Kategori | Händelser |
|----------|--------|
| **Abonnemang** | `subscription.active`, `subscription.updated`, `subscription.on_hold`, `subscription.renewed`, `subscription.plan_changed`, `subscription.cancelled`, `subscription.failed`, `subscription.expired` |
| **Betalning** | `payment.success`, `payment.failed`, `payment.processing`, `payment.cancelled` |
| **Återbetalning** | `refund.success`, `refund.failed` |
| **Tvist** | `dispute.opened`, `dispute.expired`, `dispute.accepted`, `dispute.cancelled`, `dispute.challenged`, `dispute.won`, `dispute.lost` |
| **Licens** | `licence.created` |

### Miljövariabler

| Variabel | Beskrivning |
|----------|-------------|
| `DODO_WH_TEST_SERVER_URL` | Överskrid den standard webhook relay-server URL som används av `dodo wh listen` |
