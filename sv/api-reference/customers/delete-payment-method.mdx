Ta bort en sparad betalningsmetod från en kunds konto. Använd detta för att rensa bort föråldrade eller oönskade betalningsmetoder.

<Warning>
Om den borttagna betalningsmetoden är den enda som finns registrerad för ett aktivt abonnemang kan abonnemanget misslyckas med att förnyas vid nästa faktureringscykel. Se till att kunden har en alternativ betalningsmetod innan du raderar.
</Warning>

## Användningsfall

- **Kundförfrågan**: Ta bort en betalningsmetod som kunden inte längre vill ha registrerad
- **Utgångna kort**: Rensa bort betalningsmetoder med kortuppgifter som gått ut
- **Säkerhet**: Ta bort komprometterade betalningsmetoder omedelbart
