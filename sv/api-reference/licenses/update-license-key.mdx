<Warning>
**Avvecklat API**: Licensnycklar hanteras nu via [Entitlements](/features/entitlements/introduction) systemet. Konfigurera aktiverings­begränsningar och varaktighet på [License Key entitlement](/api-reference/entitlements/update-entitlement), och använd [Revoke Grant](/api-reference/entitlements/revoke-grant) för att inaktivera en kunds nyckel. Denna endpoint kommer att tas bort i en framtida utgåva.
</Warning>

<Info>
Att uppdatera en licensnyckel via API:et triggar inte e-postmeddelanden till kunden.
</Info>
