<Info>
Den här endpointen importerar en nyckel som du redan har — `key`, `customer_id` och `product_id` krävs alla. Den genererar inte något nyckelvärde åt dig. Om du importerar en `key` som redan finns returneras `409 Conflict`.
</Info>

<Info>
Licensnycklar som skapas eller uppdateras via API:et utlöser inga e-postaviseringar till kunder. Om du behöver meddela kunder om deras licensnyckel måste du hantera det separat i din applikation.
</Info>
