**Föråldrad API**: Licensnycklar hanteras nu genom [Entitlements](/features/entitlements/introduction) systemet. Använd [List Customer Grants](/api-reference/entitlements/list-customer-grants) för att lista utfärdade licensnycklar (filtrera med `integration_type=license_key`); varje grant bär sina `license_key` detaljer. Denna endpoint kommer att tas bort i en framtida version.
</Warning>
