## API-nyckelhantering och autentisering

<Steps>
<Step title="Åtkomst till API-nycklar">
Navigera till **Utvecklare → API-nycklar** i din instrumentpanel för att hantera dina nycklar.
</Step>

<Step title="Generera en ny nyckel">
Välj **Lägg till API-nyckel**, ange ett beskrivande namn och konfigurera skrivåtkomst:

- **Aktivera skrivåtkomst** (markerad): Full läs- och skrivbehörighet för alla API-operationer
- **Aktivera skrivåtkomst** (avmarkerad): Endast läsbehörighet - kan endast hämta data (betalningar, prenumerationer, kunder, produkter). Kan inte skapa eller ändra resurser.

<Tip>
Avmarkera "Aktivera skrivåtkomst" för instrumentpanelintegrationer, analysverktyg och alla system som endast behöver visa data utan att göra ändringar.
</Tip>
</Step>

<Step title="Spara din nyckel säkert">
Kopiera den genererade nyckeln omedelbart och se till att den lagras säkert.
</Step>

<Step title="Autentisera dina API-förfrågningar">
Använd dina API-nycklar för att autentisera alla förfrågningar. Tillämpa följande auktoriseringsformat:

```bash 
Authorization: Bearer YOUR_API_KEY
```

<Warning>
Exponera aldrig dina hemliga API-nycklar i klientkod eller offentliga arkiv.
</Warning>
</Step>
</Steps>

## Hastighetsbegränsningar

Vår API använder ett dual-fönster hastighetsbegränsningssystem med burst-skydd. Begränsningar tillämpas utifrån din autentiseringsmetod och affärsnivå.

### Standardbegränsningar (Nivå 0)

| Fönster | Begränsning |
|--------|-------|
| Per sekund (Burst) | 40 begärningar |
| Per minut (Sustained) | 240 begärningar |

### Affärsnivåer

Högre hastighetsbegränsningar finns tillgängliga för företag med ökade API-behov:

| Nivå | Burst (per sekund) | Sustained (per minut) |
|------|-------------------|------------------------|
| Nivå 0 (Standard) | 40 | 240 |
| Nivå 1 | 100 | 1,000 |
| Nivå 2 | 500 | 5,000 |

<Tip>
Kontakta supporten för att uppgradera ditt företag till en högre begränsningsnivå.
</Tip>

### Icke-autentiserade begärningar

Begärningar utan giltiga autentiseringshuvuden begränsas efter IP-adress:

| Fönster | Begränsning |
|--------|-------|
| Per sekund (Burst) | 20 begärningar |
| Per minut (Sustained) | 100 begärningar |

### Hastighetsbegränsningshuvuden

Övervaka din användning med dessa svars-huvuden:

- `X-RateLimit-Limit` - Maximala begärningar tillåtna
- `X-RateLimit-Remaining` - Återstående begärningar i nuvarande fönster
- `X-RateLimit-Reset` - Tidpunkt när hastighetsbegränsningen återställs

<Note>
När du överskrider hastighetsbegränsningar returnerar API:t ett `429 Too Many Requests` svar. Implementera exponentiell återhämtning i din omprövningslogik.
</Note>
