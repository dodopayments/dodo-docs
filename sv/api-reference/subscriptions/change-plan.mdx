## Hantering av betalningsfel

Använd parametern `on_payment_failure` för att styra vad som händer när betalningen för planändringen misslyckas:

| Värde | Beteende |
|-------|----------|
| `prevent_change` | Behåll prenumerationen på nuvarande plan tills betalningen lyckas. Planändringen förblir under behandling. |
| `apply_change` | Tillämpa planändringen omedelbart oavsett betalningsresultatet. Detta är standardinställningen. |

<Info>
Om `on_payment_failure` inte anges, defaultar beteendet till din affärsnivåinställning konfigurerad i instrumentpanelen.
</Info>

<Tip>
Använd `prevent_change` för kritiska uppgraderingar där du vill säkerställa betalning innan du ger tillgång till premiumfunktioner.
</Tip>
