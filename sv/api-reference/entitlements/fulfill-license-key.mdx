<Info>
Använd endast denna endpoint för grants som skapats under en License Key-entitlement med `fulfillment_mode: manual`. Grantet måste ha statusen `Pending` utan någon kopplad nyckel. Se [Manuell uppfyllelse](/features/license-keys#manual-fulfillment) och [Integrationsguide för manuell uppfyllelse av License Key](/developer-resources/manual-license-key-fulfillment) för hela flödet.
</Info>
