## 소개

[ParityDeals](https://www.paritydeals.com/)는 웹사이트의 적격 방문자에게 위치 기반 할인 배너를 표시하고 Dodo Payments에서 일치하는 할인 코드를 자동으로 생성하는 플랫폼입니다. 방문자가 배너를 보면 결제 시 사용할 수 있는 코드를 받게 됩니다. 이러한 코드는 Dodo Payments 대시보드의 **Sales → Discounts**에서 확인할 수 있습니다.

<Note>
Dodo Payments에는 국가별로 결제 시 가격을 낮춰 주는 네이티브 [Purchasing Power Parity](/features/purchasing-power-parity)가 있으며, 배너나 스크립트가 필요하지 않습니다. ParityDeals는 자체 사이트에 눈에 띄는 할인 배너를 표시하거나 연말연시 및 기간 한정 할인을 운영하려는 판매자를 위한 도구입니다.
</Note>

## 작동 방식

ParityDeals는 방문자의 위치를 감지하고 웹사이트에 맞춤 설정 가능한 할인 배너를 표시한 다음, 결제 시 적용할 수 있는 할인 코드를 생성합니다. 코드는 Dodo Payments 계정에서 자동으로 생성되며, 구성한 제품에 사용할 수 있습니다.

1. 방문자가 웹사이트에 접속하면 ParityDeals가 방문자의 위치를 감지합니다.
2. 방문자가 할인 대상인 경우 위치 기반 코드가 포함된 배너가 표시됩니다.
3. 방문자는 결제 시 해당 코드를 사용하고, Dodo Payments가 할인을 적용합니다.
4. 코드는 대시보드의 **Sales → Discounts**에서 확인할 수 있습니다.

## ParityDeals와 네이티브 PPP 비교

네이티브 Purchasing Power Parity는 국가별 가격을 설정할 때 권장되는 방식입니다. 자체 사이트에 할인 배너가 필요하거나 연말연시 및 기간 한정 캠페인을 운영하려는 경우 ParityDeals를 선택하세요.

| | 네이티브 PPP | ParityDeals |
| :--- | :--- | :--- |
| 작동 방식 | 국가별 백분율을 결제 시 적용 | 할인율을 코드로 적용 |
| 구성 위치 | Dodo Payments에 기본 제공 | ParityDeals 대시보드 |
| 사이트에 배너 또는 스크립트 표시 | 필요하지 않음 | 필요함 |
| 연말연시 및 기간 한정 할인 | 아니요 | 예 |
| 적합한 용도 | 사이트를 변경하지 않고 올바른 가격 제공 | 프로모션 배너 및 시즌 할인 |

<Info>
Dodo Payments 호스팅 결제 페이지나 스토어프론트에는 ParityDeals 배너를 삽입할 수 없습니다. 해당 환경에서는 custom scripts가 지원되지 않기 때문입니다. 배너는 자체 웹사이트나 앱에 추가해야 합니다.
</Info>

## 사전 요구 사항

이 통합을 설정하기 전에 다음 항목을 준비하세요:

1. [Dodo Payments 계정](https://app.dodopayments.com)
2. [ParityDeals 계정](https://app.paritydeals.com/)
3. Dodo Payments API key

## 시작하기

<Steps>
  <Step title="Sign up on ParityDeals">
    [app.paritydeals.com](https://app.paritydeals.com/)에 방문하여 계정을 생성하세요.
  </Step>

  <Step title="Create Deals">
    로그인한 후 딜을 생성하는 옵션을 찾으세요. 드롭다운 메뉴에서 **"Create Deals via Dodo Payments"**를 선택하세요.

    <Frame>
      <img src="/images/integrations/paritydeals/create-deals.png" alt="Dodo Payments를 통한 딜 생성" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    **Dodo Payments dashboard**에 로그인하고 **Developers → API Keys**로 이동하세요. **"Create New API"**를 클릭하세요.

    <Tip>
      나중에 식별할 수 있도록 API key에 설명적인 이름(예: 'ParityDeals')을 지정하세요.
    </Tip>

    <Frame>
      <img src="/images/integrations/paritydeals/api-key.png" alt="Dodo Payments에서 새 API key 생성" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    생성한 API key를 복사하여 ParityDeals 인터페이스에 붙여넣고 Dodo Payments 계정과 연결하세요.

    <Frame>
      <img src="/images/integrations/paritydeals/connect-api-key.png" alt="ParityDeals에 API key 연결" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    연결되면 ParityDeals가 Dodo Payments 제품 카탈로그를 가져옵니다. 딜에 연결할 제품을 선택하세요.

    <Frame>
      <img src="/images/integrations/paritydeals/select-products.png" alt="ParityDeals용 제품 선택" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    웹사이트 URL을 입력하고 할인 배너를 표시할 특정 대상 페이지를 선택할 수도 있습니다. 그런 다음 원하는 딜 유형을 선택하세요:
    - 위치 기반 딜
    - 연말연시 딜
    - 기간 한정 플래시 딜

    <Frame>
      <img src="/images/integrations/paritydeals/deal-settings.png" alt="딜 설정 구성" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    지역화된 할인을 제공할 국가를 선택하고 각 국가의 할인율을 지정하세요. ParityDeals는 필요에 따라 조정할 수 있는 권장 기본값을 제공합니다.

    <Frame>
      <img src="/images/integrations/paritydeals/country-rules.png" alt="국가 기반 할인 규칙 설정" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    텍스트를 사용자 지정하고 색상과 레이아웃을 선택하며 배너 위치(페이지 상단 또는 하단)를 지정하여 할인 배너를 디자인하세요. 이 배너는 구성한 규칙에 따라 적격 방문자에게 표시됩니다.

    <Frame>
      <img src="/images/integrations/paritydeals/customize-banner.png" alt="할인 배너 사용자 지정" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    딜을 저장하면 ParityDeals가 스크립트를 생성합니다. 이 스크립트를 웹사이트 코드에 추가하세요(일반적으로 `<head>` 섹션에 추가). 이 스크립트는 방문자의 위치를 자동으로 감지하고 적절한 할인 배너를 표시합니다.

    <Frame>
      <img src="/images/integrations/paritydeals/script.png" alt="ParityDeals 통합 스크립트" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

## 추가 기능

ParityDeals를 사용하면 연중 [자동 기간 기반 할인](https://www.paritydeals.com/features/time-based-discounts/)과 [연말연시 기반 프로모션](https://www.paritydeals.com/features/holiday-based-discounts/)도 제공할 수 있습니다. 자세한 내용은 [ParityDeals Documentation](https://www.paritydeals.com/docs/)을 참조하세요.
