## 소개

[Rekomi](https://rekomi.com)는 Dodo Payments와 기본 통합을 제공하는 제휴 추적 및 관리 플랫폼입니다. 누군가 제휴 링크를 공유하면 Rekomi가 클릭을 기록하고, 해당 방문자가 구매하면 Dodo Payments에서 판매 정보가 전달되며 올바른 제휴 파트너에게 자동으로 실적이 귀속됩니다. Rekomi는 커미션을 계산하고 150개 이상의 국가에서 세금 양식을 포함해 제휴 파트너에게 직접 대금을 지급합니다.

연결 방법은 한 번 붙여넣는 것으로 끝납니다. 쓰기 액세스가 활성화된 Dodo Payments API 키를 Rekomi에 제공하면 Rekomi가 키를 검증하고, Dodo Payments 계정에 webhook endpoint를 직접 생성한 다음, signing secret을 직접 가져옵니다. 작성해야 할 webhook 양식도 없고 Dodo Payments에 다시 붙여넣을 내용도 없습니다.

<Info>
추천받은 고객이 일회성 결제를 완료하거나, 유료 구독을 시작하거나, 갱신 요금을 결제하면 해당 "판매"가 제휴 파트너에게 귀속됩니다. 환불 및 dispute가 발생하면 커미션이 자동으로 회수됩니다.
</Info>

## 작동 방식

Dodo Payments는 자체 도메인에서 checkout을 호스팅하므로 제휴 추천 정보는 checkout metadata로 판매에 전달됩니다:

1. 방문자가 제휴 링크를 클릭해 사이트에 도착하면 Rekomi 스크립트가 브라우저에 추천 정보를 저장합니다.
2. 방문자가 checkout으로 이동하면 해당 추천 정보를 `rekomi_ref` metadata로 결제에 추가합니다.
3. Dodo Payments가 결제를 처리하고 서명된 `payment.succeeded` webhook을 Rekomi가 생성한 endpoint로 전달합니다.
4. Rekomi가 추천 정보를 제휴 파트너와 연결하고, 세전 판매 금액을 기준으로 커미션을 계산한 뒤 기록합니다.

구독 갱신도 동일한 방식으로 전달되므로 반복 커미션을 위해 추가 작업이 필요하지 않습니다. 환불 및 dispute도 동일한 endpoint를 통해 처리됩니다.

## 사전 요구 사항

이 통합을 설정하기 전에 다음을 준비하세요:

1. 라이브 모드의 [Dodo Payments 계정](https://app.dodopayments.com)
2. [Rekomi 계정](https://app.rekomi.com/sign-up)
3. **쓰기 액세스**가 활성화된 Dodo Payments API 키(읽기 전용 키로는 webhook을 생성할 수 없음)

## 시작하기

<Steps>
<Step title="Create an API Key with Write Access">
  Dodo Payments 대시보드에서 **Developer → API Keys**로 이동해 **Enable write access**가 선택된 키를 생성하세요(이름은 "Rekomi"로 지정). 자세한 안내는 [API 키 가이드](/api-reference/introduction#api-key-management-and-authentication)를 참조하세요.

  <Warning>
  키에서 쓰기 액세스를 활성화하세요. 읽기 전용 키는 검증을 통과하지만 webhook endpoint를 생성할 수 없으므로 연결이 중간에 실패합니다.
  </Warning>
</Step>

<Step title="Paste the Key into Rekomi">
  Rekomi에서 **Setup → Connect payment processor**를 열고 Dodo Payments를 선택한 다음 키를 붙여넣으세요. Rekomi가 키를 실시간으로 검증하고 계정에 webhook endpoint를 생성한 뒤 signing secret을 직접 가져옵니다.

  <Frame>
    <img src="/images/integrations/rekomi/connect.png" alt="단일 API 키 입력란과 연결 버튼이 있는 Rekomi의 Dodo Payments 설정 페이지" style={{ maxHeight: '500px', width: 'auto' }} />
  </Frame>

  <Info>
  연결 후 키는 webhook endpoint를 관리하고 주기적인 상태 확인을 실행하는 데만 사용됩니다. 판매 정보는 서명된 webhook을 통해 전달되며 API를 통해 전달되지 않습니다.
  </Info>
</Step>

<Step title="Install the Rekomi Script">
  제휴 클릭이 기록되도록 마케팅 사이트에 Rekomi 추적 스크립트를 추가하세요. 프로그램 ID가 입력된 스니펫은 Rekomi의 **Setup → Install**에서 확인할 수 있습니다.

  ```html
  <script
    async
    src="https://api.rekomi.com/api/v1/r/loader.js"
    data-program-id="YOUR_PROGRAM_ID"
  ></script>
  ```

</Step>

<Step title="Pass the Referral into Checkout">
  캡처된 추천 정보를 각 결제의 `rekomi_ref` metadata로 추가하세요. 아래 구현 예제를 참조하세요.
</Step>

<Step title="Done!">
  이제 판매, 갱신, 환불 및 dispute에 따라 제휴 커미션이 자동으로 귀속되거나 회수되며, Rekomi가 제휴 파트너에 대한 지급을 처리합니다.
</Step>
</Steps>

## 구현 가이드

### API를 통한 Checkout Sessions

프런트엔드에서 `window.Rekomi.getReferral()`를 사용해 추천 정보를 읽고, checkout 요청과 함께 백엔드로 전송한 다음 `metadata`에 설정하세요:

```typescript Node.js
import DodoPayments from 'dodopayments';

const client = new DodoPayments();

export async function createCheckout(productId: string, rekomiRef?: string) {
  const session = await client.checkoutSessions.create({
    product_cart: [{ product_id: productId, quantity: 1 }],
    customer: {
      email: 'customer@example.com',
      name: 'John Doe',
    },
    return_url: 'https://yoursite.com/success',
    metadata: {
      ...(rekomiRef ? { rekomi_ref: rekomiRef } : {}),
    },
  });

  return session.checkout_url;
}
```

동일한 `metadata.rekomi_ref` 필드는 구독 제품에서도 사용할 수 있으므로 최초 청구와 모든 갱신에 동일한 제휴 파트너가 귀속됩니다.

### Payments API

<Note>
아래 예제에서는 **deprecated** 상태인 `POST /payments`를 사용합니다. 기존 통합에서는 계속 작동하지만, 새 통합에서는 [Checkout Sessions](/developer-resources/checkout-session)(`POST /checkouts`)를 사용해야 합니다. `metadata`는 동일한 방식으로 전달됩니다.
</Note>

```typescript Node.js
import DodoPayments from 'dodopayments';

const client = new DodoPayments();

export async function createPayment(productId: string, rekomiRef?: string) {
  const payment = await client.payments.create({
    billing: {
      city: 'New York',
      country: 'US',
      state: 'NY',
      street: '123 Main St',
      zipcode: '10001',
    },
    customer: {
      email: 'customer@example.com',
      name: 'John Doe',
    },
    product_cart: [{ product_id: productId, quantity: 1 }],
    payment_link: true,
    metadata: {
      ...(rekomiRef ? { rekomi_ref: rekomiRef } : {}),
    },
  });

  return payment;
}
```

### 정적 Payment Links

flat metadata query parameter를 사용해 링크를 꾸미세요(대괄호 형식은 사용하지 않음):

```javascript
const ref = window.Rekomi?.getReferral?.();
let url = 'https://checkout.dodopayments.com/buy/YOUR_PRODUCT_ID';
if (ref) url += `?metadata_rekomi_ref=${encodeURIComponent(ref)}`;
// use url as the href on your Buy button
```

Dodo Payments는 `metadata_*` query parameters를 결제의 metadata로 병합하며, Rekomi는 여기에서 해당 값을 읽습니다.

## 추적되는 항목

| 이벤트                | 처리 방식                                                            |
| -------------------- | ----------------------------------------------------------------------- |
| 일회성 결제     | 세전 판매 금액을 기준으로 커미션 귀속                          |
| 구독 갱신 | 반복 커미션이 적용되며, 각 청구는 개별 payment event로 전달됨     |
| 환불               | 커미션이 자동으로 회수되며, 기존에 귀속된 금액을 초과하지 않음      |
| Dispute              | dispute가 시작되는 즉시 커미션 회수                     |

<Tip>
커미션은 세전 판매 금액을 기준으로 계산됩니다. Dodo Payments는 Merchant of Record로서 세금을 징수하므로 제휴 파트너는 구매자의 국가에서 추가된 세금이 아니라 판매 자체를 기준으로 수익을 얻습니다.
</Tip>

## 중요 참고 사항

- Rekomi는 필요한 이벤트만 정확히 지정해 webhook endpoint를 등록합니다. Dodo Payments 대시보드에서 해당 endpoint의 이벤트 목록을 수정하지 마세요. 이벤트가 제거되면 Rekomi의 상태 확인에서 연결 오류가 표시됩니다.
- trial이 종료될 때까지 결제가 발생하지 않으므로 trial 중에는 커미션이 생성되지 않으며, 최초의 실제 청구가 발생한 후에만 커미션이 생성됩니다.
- Rekomi에서 연결을 해제하면 Dodo Payments 계정에서 webhook endpoint가 다시 삭제됩니다.
