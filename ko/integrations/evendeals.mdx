## 소개

[Evendeals](https://www.evendeals.com/integrations/dodo-payments)는 위치 기반 Purchasing Power Parity 할인 쿠폰을 Dodo Payments 계정에 생성하고 동기화하는 플랫폼입니다. 일회성 제품과 구독 제품을 모두 지원하며, 정의한 일정에 따라 순환되는 할인 코드를 자동으로 생성합니다.

  <img src="/images/integrations/evendeals/hero.png" alt="Evendeals Dodo Payments 통합 개요" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

<Note>
Dodo Payments에는 국가별로 결제 시 가격을 낮춰 주는 네이티브 [Purchasing Power Parity](/features/purchasing-power-parity)가 내장되어 있으며, 배너나 스크립트 또는 관리해야 할 쿠폰 코드가 필요하지 않습니다. Evendeals는 자동 쿠폰 순환과 함께 할인 코드 방식을 특별히 원하는 판매자를 위한 도구입니다.
</Note>

## 작동 방식

Evendeals는 API key를 통해 Dodo Payments 계정에 연결됩니다. 연결되면 각 국가 그룹에 대한 percentage discounts를 구성합니다. 그런 다음 Evendeals가 Dodo Payments 계정에 discount codes를 자동으로 생성하고, 악용을 방지하기 위해 설정한 일정(시간 간격, redemption count 또는 view count 기준)에 따라 이를 순환합니다.

## Evendeals와 네이티브 PPP 비교

네이티브 Purchasing Power Parity는 쿠폰 코드가 필요하지 않고 공유되거나 악용될 수 없으므로 국가별 가격을 설정하는 데 권장되는 방식입니다. 할인 코드 방식을 특별히 원하는 경우 Evendeals를 선택하세요.

| | 네이티브 PPP | Evendeals |
| :--- | :--- | :--- |
| 작동 방식 | 국가별 percentage를 결제 시 적용 | 코드를 통해 percentage off를 적용 |
| 구성 위치 | Dodo Payments에 기본 제공 | Evendeals dashboard |
| 배너 또는 스크립트 필요 여부 | 필요하지 않음 | 필요하지 않음 |
| 쿠폰 순환 / 자동 새로고침 | 해당 없음 | 지원 |
| 구독 지원 | 지원 | 지원 |
| 적합한 대상 | 사이트 변경 없이 올바른 가격을 적용하려는 경우 | 자동 순환을 지원하는 할인 코드 방식 |

## 주요 기능

- **자동 쿠폰 동기화** — 쿠폰이 Dodo Payments에서 자동으로 생성되고 관리됩니다
- **Percentage discounts** — 국가 그룹별로 percentage-off 할인을 제공합니다
- **구독 지원** — 구독 billing cycles 전체에 할인이 적용됩니다
- **자동 새로고침 규칙** — 악용을 방지하기 위해 시간 간격, redemption count 또는 view count 기준으로 쿠폰 코드를 자동 순환합니다

<Info>
Evendeals에서 생성된 discount codes는 Dodo Payments dashboard의 **Sales → Discounts**에 자동으로 표시됩니다.
</Info>

## 사전 요구 사항

이 통합을 설정하기 전에 다음 항목을 준비하세요:

1. [Dodo Payments account](https://app.dodopayments.com)
2. [Evendeals account](https://www.evendeals.com/signin)
3. Dodo Payments API key

## 시작하기

<Steps>
  <Step title="Create a Dodo Payments API Key">
    Dodo Payments dashboard에서 **Developers → API Keys**로 이동한 후 **Create New API**를 클릭합니다. 나중에 쉽게 식별할 수 있도록 설명적인 이름(예: "Evendeals")을 지정하세요.
  </Step>

  <Step title="Connect in Evendeals">
    [Evendeals dashboard](https://www.evendeals.com/signin)에서 **Integrations**로 이동하고 Dodo Payments 카드를 찾은 다음 API key를 붙여넣습니다.
  </Step>

  <Step title="Configure Regional Discounts">
    각 국가 그룹에 대한 percentage discounts를 설정하고 sync를 클릭합니다. Evendeals가 Dodo Payments에 쿠폰을 자동으로 생성합니다.

    <Check>
    동기화가 완료되면 Dodo Payments dashboard에서 **Sales → Discounts**를 열어 생성된 쿠폰이 표시되는지 확인합니다. 각 쿠폰에는 식별하기 쉬운 Evendeals 접두사가 포함됩니다.
    </Check>
  </Step>
</Steps>
