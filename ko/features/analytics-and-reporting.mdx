## Home

**Home**은 사이드바의 랜딩 페이지로, **Today**와 **Your overview** 두 부분으로 구성됩니다.

### Today

<Frame caption="Today: your day's pulse, hour by hour">
  <img src="/images/analytics/home-today.png" alt="Home Today view with an hourly volume chart, cash position, and next payout tiles" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

시간대별 일일 현황을 확인합니다.

- **주요 차트:** **Net volume**과 **Gross volume** 사이를 전환합니다(기본값은 Net volume). 전날 같은 시간대의 선과 함께 시간별로 표시됩니다.
- **Cash Position:** 현재 지갑 잔액과 다음 지급일입니다.

<Note>
두 카드 모두 정보 툴팁(ⓘ)과 "Updated Xs ago" 타임스탬프를 표시하므로 데이터가 얼마나 최신인지 항상 확인할 수 있습니다.
</Note>

### Your Overview

<Frame caption="Your overview: a fully customizable set of metric cards">
  <img src="/images/analytics/home-overview.png" alt="Home Your overview view with customizable cards for revenue by country, payouts received, top customers by spend, and refunds" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

완전히 사용자 지정할 수 있습니다. **Customize**를 사용하여 카드를 선택하고, 순서를 변경하거나 삭제하세요.

- **기본 카드:** Net volume, Gross volume, Payments, Top customers by spend, New customers, Revenue by country 및 Refunds가 제공됩니다. 여기에 일회성/사용량 기반 판매자는 **Average order value**, 구독 판매자는 **MRR** 및 **Net New MRR**이 추가됩니다.
- **컨트롤:**
  - **Period:** Daily/Weekly 또는 사용자 지정 범위입니다.
  - **Compare:** Previous period 또는 previous month입니다(기본적으로 활성화).
  - **Product:** 단일 제품 또는 그룹입니다.

### 필터링 및 사용자 지정

각 탭에는 자체 필터 바가 있습니다.

- **Time Period:** 미리 설정된 범위 또는 사용자 지정 날짜 범위와 **Daily/Weekly** 그룹화입니다.
- **Compare:** Previous period 또는 previous month입니다(기본적으로 활성화).
- **Product:** Revenue, Subscriptions 및 Retention 탭에서 사용할 수 있습니다. Product는 다중 선택이 가능하며 기본값은 **All**입니다.

<Tip>
필터를 사용하여 특정 제품, 기간 또는 결제 수단으로 범위를 좁혀 필요한 인사이트를 확인하세요.
</Tip>

### Revenue 탭

<Frame caption="Revenue tab: gross/net volume, payouts, and refunds">
  <img src="/images/analytics/revenue-tab.png" alt="Revenue tab showing gross volume, net volume, payouts received, and refunds cards with trend charts" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

수익, 지급 및 분쟁 활동을 추적하여 수익 추세를 파악하고 성과가 가장 높은 시장을 확인하세요. **Gross/Net** 드롭다운을 사용하면 주요 수치, 차트 및 국가 순위를 gross 값과 net 값 사이에서 전환할 수 있습니다.

| Metric | Description |
|--------|-------------|
| **Gross volume** | 수수료, 환불 또는 분쟁 금액을 차감하기 전, 해당 기간의 모든 성공한 결제에서 청구된 총액입니다. |
| **Net volume** | Net volume = gross volume − fees − refunds − lost disputes입니다. |
| **Payouts received** | Payout = eligible sales − taxes − fees − refunds − chargebacks입니다. |
| **Refund rate** | Refund rate = refunded amount ÷ gross volume입니다. |
| **Disputes** | 주요 수치는 결과와 관계없는 chargeback rate입니다. 수신된 모든 chargeback이 집계되므로 이후 승소하거나 철회된 chargeback도 비율을 낮추지 않습니다(카드 네트워크가 위험을 평가하는 방식). Won / lost / pending은 참고를 위해 건수로 표시되며 두 기간을 비교합니다. Chargeback rate = chargebacks received ÷ payments입니다. |
| **Payments count** | Successful 상태인 결제의 수입니다. 진행 중, 실패 또는 시작되지 않은 시도는 제외됩니다. |
| **Average order value** | AOV = revenue ÷ number of orders이며, 일회성 및 사용량 기반 제품을 포함합니다. |
| **Revenue by product** | 각 제품에 귀속된 gross revenue를 높은 순서로 정렬합니다. |
| **Revenue by country** | 고객의 청구 국가를 기준으로 각 국가에 귀속된 수익입니다. |
| **Revenue by geography** | 국가별 수익을 지도로 표시하며, 색이 진할수록 수익이 높습니다. |

### Customers 탭

<Frame caption="Customers tab: active and new customers, ARPU, and top customers">
  <img src="/images/analytics/customers-tab.png" alt="Customers tab showing active customers, new customers, ARPU, and top customers by spend" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

고객 확보, 리텐션 및 지출 패턴을 분석하여 고객 전략을 최적화하세요.

| Metric | Description |
|--------|-------------|
| **Active customers** | 해당 기간 중 언제든 결제했거나 활성 구독을 보유했던 고객입니다. |
| **New customers** | 해당 기간에 판매자와 처음으로 성공적인 결제를 진행한 고객입니다. |
| **ARPU** | ARPU = revenue ÷ active customers입니다. |
| **Top customers** | 해당 기간의 수익을 기준으로 고객을 높은 순서로 정렬합니다. |
| **New vs. returning** | New = 해당 기간에 처음 구매한 고객입니다. Returning = 이전 기간에 판매자로부터 구매한 고객입니다. |
| **Modeled LTV** | 고객이 이탈하기 전까지 발생할 것으로 예상되는 수익입니다. |

### Subscriptions 탭

반복 수익을 모니터링하고 Monthly Recurring Revenue (MRR)가 시간에 따라 어떻게 변하는지 파악하세요.

| Metric | Description |
|--------|-------------|
| **MRR** | 한 달에 발생할 것으로 예상되는 반복 수익으로, 모든 플랜을 월 단위로 환산합니다(연간 플랜은 1/12로 계산). 일회성 결제는 제외됩니다. |
| **Projected ARR** | Projected ARR = current MRR × 12입니다. |
| **Net New MRR** | Net New MRR = New + Expansion − Contraction − Churned입니다. |
| **Active subscriptions** | 현재 결제가 진행 중인 구독으로, 아직 trial 중인 구독도 포함합니다. |
| **New MRR** | 해당 기간에 새로 시작된 구독으로 추가된 MRR입니다. |
| **Expansion MRR** | 기존 고객이 상위 플랜으로 업그레이드하거나 add-on을 구매하여 증가한 MRR입니다. |
| **Contraction MRR** | 기존 고객이 더 저렴한 플랜으로 변경했지만 구독을 유지하여 감소한 MRR입니다. |
| **Churned MRR** | 해당 기간에 고객이 구독을 취소하여 감소한 MRR입니다. |

<Note>
MRR은 **concurrent subscriptions**(고객별 합산)을 반영하며 각 구독의 결제 완료 기간에 따라 비례 배분됩니다.
</Note>

### Retention 탭

<Frame caption="Retention tab: churn rates, retention matrix, and NRR/GRR">
  <img src="/images/analytics/retention-tab.png" alt="Retention tab showing the user retention cohort matrix, customer churn rate, revenue churn rate, and net revenue retention" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

고객 리텐션 및 이탈 패턴을 모니터링하세요.

| Metric | Description |
|--------|-------------|
| **User retention matrix** | 고객을 가입 월(cohort)별로 그룹화한 다음, 이후 각 월에도 활성 상태인 코호트의 비율을 표시합니다. Retention (month k) = month k에 활성 상태인 코호트 고객 ÷ 코호트 규모입니다. |
| **Customer churn rate** | 해당 기간에 취소한 시작 구독자의 비율이며, 이탈 고객 수를 옆에 표시합니다. Customer churn rate = 이탈한 구독자 ÷ 기간 시작 시점의 구독자입니다. |
| **Revenue churn rate** | Revenue churn rate = churned MRR ÷ starting MRR입니다. 여기서 starting MRR은 기간 시작 시점(이전 기간이 종료된 시점)의 기존 고객에게서 발생하는 반복 수익입니다. |
| **Net Revenue Retention (NRR)** | 업그레이드를 포함하므로 100%를 초과할 수 있습니다. NRR = (starting MRR + Expansion − Contraction − Churned) ÷ starting MRR입니다. |
| **Gross Revenue Retention (GRR)** | 업그레이드를 제외하므로 최대 100%입니다. GRR = (starting MRR − Contraction − Churned) ÷ starting MRR입니다. |
| **Trial conversion** | Trial conversion = 전환된 trial ÷ 해당 기간에 종료된 trial입니다. trial을 제공하는 경우에만 표시됩니다. |

### Success Rate 탭

<Frame caption="Success Rate tab: payment and refund success rates with failure analysis">
  <img src="/images/analytics/success-rate-tab.png" alt="Success Rate tab showing payment success rate, payments breakdown, payment failure reasons, and success by payment method" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

결제 및 환불 성공률을 모니터링하여 거래 문제를 신속하게 파악하고 해결하세요.

| Metric | Description |
|--------|-------------|
| **Payment success rate** | processor/network 실패만 성공률에 반영됩니다. 고객이 수정할 수 있는 실패(잘못되었거나 만료된 카드)는 분모에서 제외됩니다. Payment success rate = succeeded ÷ (attempts − customer-fixable failures)입니다. |
| **Payments breakdown** | 시도를 total, success, failed (network), failed (customer) 및 not initiated로 나눕니다. |
| **Payment failure reason** | 실패 사유별 결제 실패 내역입니다. |
| **By payment method** | 각 수단(card, wallet, UPI, BNPL)별로 success rate = succeeded ÷ attempts, volume = succeeded amount입니다. |
| **Checkouts count** | 고객이 시작한 checkout session의 수로, 완료 여부와 관계없이 집계됩니다. |
| **Refund success rate** | 시작된 환불 중 성공적으로 처리된 환불의 비율입니다. |

<Card title="Transaction Failure Reference" icon="circle-exclamation" href="/api-reference/transaction-failures">
가능한 모든 거래 실패 코드와 해당 사유를 확인하세요.
</Card>

<Warning>
성공률이 하락하거나 실패가 급증한 경우 실패 사유를 검토하고 신속하게 대응하여 수익 손실을 최소화하세요.
</Warning>

### Recovery 탭

<Frame caption="Recovery tab: retries, dunning, and abandoned cart recovery">
  <img src="/images/analytics/recovery-tab.png" alt="Recovery tab showing recovery overview, recovery by flow, payment retries, and dunning metrics" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

자동화된 재시도, dunning 이메일 및 abandoned cart recovery를 통해 Dodo Payments가 판매자를 대신하여 얼마나 많은 수익을 복구하는지 추적하세요.

| Metric | Description |
|--------|-------------|
| **Recovery overview** | 해당 기간에 복구된 수익과 전체 recovery rate입니다. Recovery rate = recovered ÷ recoverable failed amount이며, hard decline(폐쇄된 계정)은 recoverable에서 제외됩니다. |
| **Recovery by flow** | 복구된 수익을 retries, dunning 및 abandoned cart별로 나눠 표시합니다. |
| **Payment retries** | 재시도, 성공한 재시도, 재시도 성공률 및 저장된 구독입니다. |
| **Dunning** | dunning 항목, 전송된 이메일, 복구된 수익, recovery rate 및 평균 복구 시간입니다. |
| **Abandoned cart** | abandoned checkout, 복구된 수익, recovery rate 및 평균 복구 시간입니다. |

<Card title="Recovery Features" icon="life-ring" href="/features/recovery/overview">
결제 재시도, dunning 및 abandoned cart recovery를 구성하는 방법을 자세히 알아보세요.
</Card>

</Card>

### Overview 탭

Overview 탭은 제품의 재무 성과를 한눈에 보여주는 요약 정보를 제공합니다.

- **Total Revenue**: 이 제품에서 누적 발생한 수익입니다.
- **Number of Successful Payments**: 성공한 거래의 총 건수입니다.
- **Revenue Trend Chart**: 시간에 따른 수익을 보여주는 30일 선형 차트입니다. **Show Daily** 버튼을 사용하여 누적 보기와 일일 보기 사이를 전환할 수 있습니다.

차트 아래의 **Transactions** 테이블에는 이 제품의 모든 결제가 표시됩니다.

| Column | Description |
|--------|-------------|
| Payment ID | 거래의 고유 식별자 |
| Status | `Successful` 또는 `Failed` |
| Amount | 통화가 포함된 거래 금액 |
| Date (UTC) | 거래 타임스탬프 |
| Payment Method | 사용된 Card, UPI 또는 기타 수단 |
| Refund | 환불을 시작하는 옵션 |

### MRR 탭

제품의 Monthly Recurring Revenue를 상세하게 분석합니다.

<Frame caption="MRR stacked bar chart showing monthly revenue composition">
  <img src="/images/product-analytics/mrr.png" alt="MRR tab with stacked bar chart showing new, expansion, and churned MRR by month" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

**MRR chart**는 누적 막대 차트를 사용하여 월별 반복 수익 구성을 시각화합니다.

차트 아래의 지표 카드에서 상세한 인사이트를 확인할 수 있습니다.

<Frame caption="Detailed MRR breakdown with New, Expansion, Churned, and Net New MRR">
  <img src="/images/product-analytics/mrr-breakdown.png" alt="MRR breakdown showing New MRR, Expansion MRR, Churned MRR, and Net New MRR with trend charts" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

| Metric | Description |
|--------|-------------|
| **New MRR** | 이번 달에 확보한 신규 구독에서 발생한 수익과 전월 대비 변동입니다. |
| **Expansion MRR** | 기존 구독자가 플랜을 업그레이드하거나 플랜에 항목을 추가하여 발생한 추가 수익입니다. |
| **Contraction MRR** | 기존 구독자가 완전히 취소하지 않고 다운그레이드하여 손실된 수익입니다. |
| **Churned MRR** | 취소된 구독으로 손실된 수익입니다. |
| **Net New MRR** | 순 결과입니다: New MRR + Expansion MRR − Contraction MRR − Churned MRR |

각 카드에는 추세 미니 차트와 전월 대비 변동률 표시가 포함됩니다.

## Reports

각 report의 해당 페이지에는 **Build Report** 버튼이 있습니다. 필요한 report에 액세스하고 다운로드하려면 관련 섹션으로 이동하세요.

각 report는 해당되는 경우 payment method, status, product type, failure type, dispute status 또는 currency별로 필터링하고 CSV로 다운로드할 수 있습니다.

| Report Type | Description | Where to find it |
|-------------|-------------|------------------|
| **Payment Report** | billing address, card details, USD-equivalent amounts, settlement details, fees 및 failure codes를 포함한 처리된 모든 결제의 상세 기록입니다. | **Transactions → Payments** |
| **Refund Report** | 상세한 환불 정보가 포함된 모든 환불 활동의 종합 로그입니다. | **Transactions → Refunds** |
| **Disputes Report** | 해결 상태 및 증거 세부 정보가 포함된 결제 분쟁 요약입니다. | **Transactions → Disputes** |
| **Customer Report** | 고객별로 정리된 결제, 환불 및 분쟁 요약입니다. | **Sales → Customers** |
| **Payout Report** | 계정으로 지급된 금액의 요약과 ledger event별 수수료 내역입니다. | **Payouts** |
| **Account Summary Report** | event type, amount 및 references가 포함된 잔액 ledger 항목의 상세 내역입니다. | **Payouts → Balances** |

## Reports 다운로드

<Steps>
<Step title="Navigate to the relevant page">
위 표를 사용하여 필요한 report의 페이지로 이동합니다.
</Step>
<Step title="Select a time period">
<strong>Build Report</strong>를 클릭하고 미리 설정된 범위(Today, Last 7 days, Last 30 days, This month 등)를 선택하거나 캘린더에서 사용자 지정 날짜 범위를 선택합니다.
</Step>
<Step title="Download">
<strong>Download Report</strong>를 클릭합니다. report가 CSV로 내보내지고 기기에 저장됩니다.
</Step>
</Steps>

<Note>
수수료 데이터는 독립적인 report로 제공되지 않습니다. **Payouts → Balances**의 **Account Summary Report**에서 필터 옵션으로 수수료(payment fees, refund fees 및 payout fees) 내역을 확인할 수 있습니다.
</Note>
