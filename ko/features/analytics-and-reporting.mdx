## Home

**Home**은 사이드바의 랜딩 페이지로, **Today**와 **Your overview** 두 부분으로 구성됩니다.

### Today

<Frame caption="Today: your day's pulse, hour by hour">
  <img src="/images/analytics/home-today.png" alt="Home Today view with an hourly volume chart, cash position, and next payout tiles" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

시간대별 일일 현황을 확인합니다.

- **주요 차트:** **Net volume**과 **Gross volume** 사이를 전환합니다(기본값은 Net volume). 전날 같은 시간대의 선과 함께 시간별로 표시됩니다.
- **Cash Position:** 현재 지갑 잔액과 다음 지급일입니다.

<Note>
두 카드 모두 정보 툴팁(ⓘ)과 "Updated Xs ago" 타임스탬프를 표시하므로 데이터가 얼마나 최신인지 항상 확인할 수 있습니다.
</Note>

### Your Overview

<Frame caption="Your overview: a fully customizable set of metric cards">
  <img src="/images/analytics/home-overview.png" alt="Home Your overview view with customizable cards for revenue by country, payouts received, top customers by spend, and refunds" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

완전히 사용자 지정할 수 있습니다. **Customize**를 사용하여 카드를 선택하고, 순서를 변경하거나 삭제하세요.

- **기본 카드:** Net volume, Gross volume, Payments, Top customers by spend, New customers, Revenue by country 및 Refunds가 제공됩니다. 여기에 일회성/사용량 기반 판매자는 **Average order value**, 구독 판매자는 **MRR** 및 **Net New MRR**이 추가됩니다.
- **컨트롤:**
  - **Period:** Daily/Weekly 또는 사용자 지정 범위입니다.
  - **Compare:** Previous period 또는 previous month입니다(기본적으로 활성화).
  - **Product:** 단일 제품 또는 그룹입니다.

### 필터링 및 사용자 지정

각 탭에는 자체 필터 바가 있습니다.

- **Time Period:** 미리 설정된 범위 또는 사용자 지정 날짜 범위와 **Daily/Weekly** 그룹화입니다.
- **Compare:** Previous period 또는 previous month입니다(기본적으로 활성화).
- **Product:** Revenue, Subscriptions 및 Retention 탭에서 사용할 수 있습니다. Product는 다중 선택이 가능하며 기본값은 **All**입니다.

날짜 범위와 비교 선택 항목은 비즈니스별로 기억되므로, 비즈니스를 전환하거나 나중에 다시 돌아와도 각 비즈니스에서 마지막으로 사용한 기간이 유지됩니다.

<Tip>
필터를 사용하여 특정 제품, 기간 또는 결제 수단으로 범위를 좁혀 맞춤 인사이트를 확인하세요.
</Tip>

### Revenue 탭

<Frame caption="Revenue tab: gross/net volume, payouts, and refunds">
  <img src="/images/analytics/revenue-tab.png" alt="총 거래량, 순 거래량, 수령한 지급금 및 환불 카드와 추세 차트를 보여주는 Revenue 탭" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

수익, 지급금 및 분쟁 활동을 추적하여 수익 추세를 파악하고 실적이 가장 우수한 시장을 확인하세요. **Gross/Net** 드롭다운을 사용하여 주요 수치, 차트 및 국가 순위를 총액과 순액 간에 전환할 수 있습니다.

| Metric | Description |
|--------|-------------|
| **Gross volume** | 해당 기간 동안 성공한 모든 결제에서 수수료, 환불 또는 분쟁 금액을 차감하기 전의 총 청구 금액입니다. |
| **Net volume** | 순 거래량 = 총 거래량 − 수수료 − 환불 − 패소한 분쟁입니다. |
| **Payouts received** | 지급금 = 적격 판매액 − 세금 − 수수료 − 환불 − 차지백입니다. |
| **Refund rate** | 환불률 = 환불 금액 ÷ 총 거래량입니다. |
| **Disputes** | 주요 수치는 결과를 고려하지 않은 차지백 비율입니다. 수신된 모든 차지백이 집계되므로, 이후 승소하거나 철회된 차지백도 비율을 낮추지 않습니다(카드 네트워크가 위험을 평가하는 방식입니다). 맥락을 위해 승소 / 패소 / 대기 중인 분쟁은 건수로 표시되며 두 기간 간 비교됩니다. 차지백 비율 = 수신된 차지백 ÷ 결제입니다. |
| **Payments count** | Successful 상태인 결제 건수입니다. 진행 중, 실패 및 시작되지 않은 시도는 제외됩니다. |
| **Average order value** | AOV = 수익 ÷ 주문 수이며, 일회성 제품과 사용량 기반 제품을 모두 포함합니다. |
| **Revenue by product** | 각 제품에 귀속된 총수익으로, 높은 순서부터 정렬됩니다. |
| **Revenue by country** | 고객의 청구 국가를 기준으로 각 국가에 귀속된 수익입니다. 상위 150개 국가는 개별적으로 표시되며 나머지는 하나의 "others" 행으로 그룹화됩니다. |
| **Revenue by geography** | 국가별 수익을 지도로 표시하며, 색상이 진할수록 수익이 높습니다. |

### Customers 탭

<Frame caption="Customers tab: active and new customers, ARPU, and top customers">
  <img src="/images/analytics/customers-tab.png" alt="활성 고객, 신규 고객, ARPU 및 지출 기준 상위 고객을 보여주는 Customers 탭" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

고객 확보, 유지 및 지출 패턴을 분석하여 고객 전략을 최적화하세요.

| Metric | Description |
|--------|-------------|
| **Active customers** | 해당 기간 중 언제든 결제했거나 활성 구독을 보유한 고객입니다. |
| **New customers** | 귀사에서 처음으로 성공적인 결제를 한 시점이 해당 기간에 속하는 고객입니다. |
| **ARPU** | ARPU = 수익 ÷ 활성 고객 수입니다. |
| **Top customers** | 해당 기간의 수익을 기준으로 고객을 정렬하며, 수익이 높은 고객부터 표시합니다. |
| **New vs. returning** | 신규 = 해당 기간에 처음 구매한 고객입니다. 재방문 = 이전 기간에 귀사에서 구매한 고객입니다. |
| **Modeled LTV** | 고객이 이탈하기 전까지 발생할 것으로 추정되는 수익입니다. |

### Subscriptions 탭

반복 수익을 모니터링하고 Monthly Recurring Revenue (MRR)가 시간에 따라 어떻게 변하는지 파악하세요.

| Metric | Description |
|--------|-------------|
| **MRR** | 한 달 동안 예상되는 반복 수익으로, 모든 플랜을 월 단위로 환산합니다(연간 플랜은 1/12로 계산). 일회성 결제는 제외됩니다. |
| **Projected ARR** | 예상 ARR = 현재 MRR × 12입니다. |
| **Net New MRR** | 순 신규 MRR = 신규 + 확장 − 축소 − 이탈입니다. |
| **Active subscriptions** | 현재 청구 중인 구독으로, 아직 체험 기간인 구독도 포함합니다. |
| **New MRR** | 해당 기간에 새로 시작된 구독으로 추가된 MRR입니다. |
| **Expansion MRR** | 기존 고객의 플랜 업그레이드 또는 추가 기능 구매로 발생한 추가 MRR입니다. |
| **Contraction MRR** | 기존 고객이 더 저렴한 플랜으로 변경했지만 구독을 유지할 때 감소한 MRR입니다. |
| **Churned MRR** | 해당 기간에 고객이 구독을 취소하여 감소한 MRR입니다. |

<Note>
MRR은 **동시 구독**(고객별 합산)을 반영하며 각 구독의 결제 완료 기간에 따라 일할 계산됩니다.
</Note>

### Retention 탭

<Frame caption="Retention tab: churn rates, retention matrix, and NRR/GRR">
  <img src="/images/analytics/retention-tab.png" alt="사용자 유지 코호트 매트릭스, 고객 이탈률, 수익 이탈률 및 순수익 유지율을 보여주는 Retention 탭" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

고객 유지 및 이탈 패턴을 모니터링하세요.

| Metric | Description |
|--------|-------------|
| **User retention matrix** | 고객을 가입 월(코호트)별로 그룹화한 다음, 이후 각 월에도 계속 활성 상태인 해당 코호트의 비율을 표시합니다. 유지율(월 k) = 월 k에 활성 상태인 코호트 고객 ÷ 코호트 규모입니다. |
| **Customer churn rate** | 해당 기간에 취소한 시작 구독자의 비율이며, 이탈 고객 수가 옆에 표시됩니다. 고객 이탈률 = 이탈한 구독자 ÷ 기간 시작 시점의 구독자입니다. |
| **Revenue churn rate** | 수익 이탈률 = 이탈한 MRR ÷ 시작 MRR입니다. 시작 MRR은 기간 시작 시점(이전 기간이 종료된 시점)의 기존 고객 반복 수익입니다. |
| **Net Revenue Retention (NRR)** | 업그레이드를 포함하므로 100%를 초과할 수 있습니다. NRR = (시작 MRR + 확장 − 축소 − 이탈) ÷ 시작 MRR입니다. |
| **Gross Revenue Retention (GRR)** | 업그레이드를 제외하므로 최대 100%입니다. GRR = (시작 MRR − 축소 − 이탈) ÷ 시작 MRR입니다. |
| **Trial conversion** | 체험 전환율 = 전환된 체험 수 ÷ 해당 기간에 종료된 체험 수입니다. 체험을 제공하는 경우에만 표시됩니다. |

### Success Rate 탭

<Frame caption="Success Rate tab: payment and refund success rates with failure analysis">
  <img src="/images/analytics/success-rate-tab.png" alt="결제 성공률, 결제 분석, 결제 실패 사유 및 결제 수단별 성공률을 보여주는 Success Rate 탭" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

결제 및 환불 성공률을 모니터링하여 거래 문제를 신속하게 식별하고 해결하세요.

| Metric | Description |
|--------|-------------|
| **Payment success rate** | 프로세서/네트워크 실패만 성공률에 반영되며, 고객이 해결할 수 있는 실패(잘못되었거나 만료된 카드)는 분모에서 제외됩니다. 결제 성공률 = 성공 건수 ÷ (시도 건수 − 고객 해결 가능 실패 건수)입니다. |
| **Payments breakdown** | 시도를 전체, 성공, 실패(네트워크), 실패(고객) 및 시작되지 않음으로 나눕니다. |
| **Payment failure reason** | 사유별 결제 실패 분석입니다. |
| **By payment method** | 수단별(카드, wallet, UPI, BNPL): 성공률 = 성공 건수 ÷ 시도 건수, 거래량 = 성공 금액입니다. |
| **Checkouts count** | 고객이 시작한 checkout 세션 수로, 완료 여부와 관계없이 집계됩니다. |
| **Refund success rate** | 시작된 환불 중 성공적으로 처리된 환불의 비율입니다. |

가능한 모든 거래 실패 코드와 해당 사유를 확인하세요.
</Card>

<Warning>
성공률이 하락하거나 실패가 급증한 경우 실패 사유를 검토하고 신속하게 대응하여 수익 손실을 최소화하세요.
</Warning>

<Frame caption="Recovery tab: retries, dunning, and abandoned cart recovery">

자동 재시도, 연체 관리 이메일 및 abandoned cart recovery를 통해 Dodo Payments가 대신 복구한 수익을 추적하세요.

| Metric | Description |
|--------|-------------|
| **Recovery overview** | 해당 기간에 복구된 수익과 전체 복구율입니다. 복구율 = 복구 금액 ÷ 복구 가능한 실패 금액이며, 강제 거절(폐쇄된 계정)은 복구 가능 금액에서 제외됩니다. |

| **Payment retries** | 재시도 횟수, 성공한 재시도, 재시도 성공률 및 유지된 구독입니다. |
| **Dunning** | 연체 관리 항목, 발송된 이메일, 복구 수익, 복구율 및 평균 복구 소요 시간입니다. |
| **Abandoned cart** | abandoned checkout 수, 복구 수익, 복구율 및 평균 복구 소요 시간입니다. |

## 제품 수준 분석

비즈니스 전체 지표 외에도 **각 개별 제품**에 대한 자세한 분석을 확인할 수 있습니다. **Products > [Select a Product]**로 이동하여 해당 제품 전용 분석 대시보드에 액세스하세요.

### Overview 탭

Overview 탭에서는 제품의 재무 성과를 한눈에 확인할 수 있습니다.

- **Total Revenue**: 이 제품에서 누적 생성된 수익입니다.
- **Number of Successful Payments**: 성공한 거래의 총 건수입니다.
- **Revenue Trend Chart**: 시간에 따른 수익을 보여주는 30일 선형 차트입니다. **Show Daily** 버튼을 사용하여 누적 보기와 일별 보기 간에 전환할 수 있습니다.

차트 아래의 **Transactions** 표에는 이 제품의 모든 결제가 나열됩니다:

| Column | Description |
|--------|-------------|
| Payment ID | 거래의 고유 식별자 |
| Status | `Successful` 또는 `Failed` |
| Amount | 통화가 포함된 거래 금액 |
| Date (UTC) | 거래의 타임스탬프 |
| Payment Method | 사용된 카드, UPI 또는 기타 수단 |
| Refund | 환불을 시작하는 옵션 |

</Frame>

**Filter by status** 버튼을 사용하여 성공하거나 실패한 거래만 표시하도록 목록을 좁힐 수 있습니다.

### Customers 탭

이 제품을 구매하는 고객과 고객의 지출 금액을 확인하세요.

<Frame caption="Top customers of the month with podium ranking and customer table">
  <img src="/images/product-analytics/customers.png" alt="수익 기준 상위 3명의 고객과 상세 분석 표를 보여주는 Customers 탭" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

- **Top Customers of the Month**: 시각적인 시상대에 총 지출액 기준 **상위 3명의 고객**이 표시되며, 수익 금액, 이름 및 이메일을 확인할 수 있습니다.
- **Customer Table**: 고객 ID와 이 제품에서 발생한 총수익을 포함한 모든 고객의 상세 분석입니다.

### Retention 탭

이 제품이 구독자를 얼마나 효과적으로 유지하는지 파악하세요.

<Frame caption="Customer and revenue churn rates with trend analysis">
  <img src="/images/product-analytics/retention.png" alt="고객 이탈률, 수익 이탈률 및 이탈률 추세 차트를 보여주는 Retention 탭" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

- **Customer Churn Rate**: 구독을 취소한 구독자의 비율입니다.
- **Revenue Churn Rate**: 취소 및 다운그레이드로 손실된 수익의 비율입니다.
- **Churn Rate Trend**: 시간에 따른 두 지표를 추적하는 이중 선형 차트로, 추세를 파악하고 시정 조치를 취하는 데 도움이 됩니다.

### Subscribers 탭

이 제품과 연결된 모든 구독의 전체 목록입니다.

<Frame caption="Subscribers table showing all subscriptions with statuses and billing details">
  <img src="/images/product-analytics/subscribers.png" alt="구독 ID, 고객 이메일, 상태, 시작일 및 다음 청구 정보가 포함된 Subscribers 탭" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

| Column | Description |
|--------|-------------|
| Subscription ID | 구독의 고유 식별자 |
| Customer Email | 구독자의 이메일 주소 |
| Status | `Active`, `Failed`, `On hold` 또는 `Pending` |
| Product Name | 이 구독이 속한 제품 |
| Start Date | 구독이 시작된 시점 |
| Next Billing Date | 예정된 갱신일 |
| Next Billing Amount | 다음 갱신 시 결제될 금액(세금 제외) |

### MRR 탭

제품의 Monthly Recurring Revenue를 자세히 분석합니다.

<Frame caption="MRR stacked bar chart showing monthly revenue composition">
  <img src="/images/product-analytics/mrr.png" alt="월별 신규, 확장 및 이탈 MRR을 누적 막대 차트로 보여주는 MRR 탭" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

**MRR 차트**는 월별 반복 수익 구성을 누적 막대 차트로 시각화합니다.

차트 아래의 지표 카드에서 자세한 인사이트를 확인할 수 있습니다:

<Frame caption="Detailed MRR breakdown with New, Expansion, Churned, and Net New MRR">
  <img src="/images/product-analytics/mrr-breakdown.png" alt="New MRR, Expansion MRR, Churned MRR 및 Net New MRR과 추세 차트를 보여주는 MRR 분석" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

| Metric | Description |
|--------|-------------|
| **New MRR** | 이번 달에 확보한 신규 구독에서 발생한 수익과 전월 대비 변동입니다. |
| **Expansion MRR** | 기존 구독자가 플랜을 업그레이드하거나 플랜에 항목을 추가하여 발생한 추가 수익입니다. |
| **Contraction MRR** | 기존 구독자가 완전히 취소하지 않고 다운그레이드하여 손실된 수익입니다. |
| **Churned MRR** | 취소된 구독으로 손실된 수익입니다. |
| **Net New MRR** | 순 결과: New MRR + Expansion MRR − Contraction MRR − Churned MRR입니다. |

각 카드에는 추세 미니 차트와 전월 대비 변동률 지표가 포함됩니다.

## 페이지 하이라이트 타일

이제 대시보드의 많은 목록 페이지 상단에 **하이라이트 타일**이 표시되어 전체 Analytics 대시보드를 열지 않고도 주요 요약 지표를 한눈에 확인할 수 있습니다. 타일에는 해당 페이지의 활성 필터가 적용됩니다.

| Page | Highlight Tiles |
|------|-----------------|
| **Products** | 모든 제품, 활성 제품, 보관된 제품 |
| **Add-ons** | 모든 Add-On, 활성 Add-On, 제품에 연결됨 |
| **Collections** | 모든 컬렉션, 활성 컬렉션, 보관된 컬렉션 |
| **Subscriptions** | 활성 구독, 보류 중, 취소됨 |
| **Payments** | 성공한 결제, 결제 거래량, 실패한 결제 |
| **Refunds** | 성공한 환불, 환불 거래량, 실패한 환불 |
| **Disputes** | 생성된 분쟁, 승소, 수락, 패소 |

<Note>
"활성" Products, Add-ons, Collections 및 meters는 하나 이상의 성공한 결제에 참여한 항목을 의미합니다.
</Note>

## Reports

각 보고서의 해당 페이지에는 **Build Report** 버튼이 있습니다. 관련 섹션으로 이동하여 필요한 보고서에 액세스하고 다운로드하세요.

각 보고서는 해당하는 경우 결제 수단, 상태, 제품 유형, 실패 유형, 분쟁 상태 또는 통화별로 필터링한 후 CSV로 다운로드할 수 있습니다.

| Report Type | Description | Where to find it |
|-------------|-------------|------------------|
| **Payment Report** | 청구 주소, 카드 세부 정보, USD 환산 금액, 정산 세부 정보, 수수료 및 실패 코드를 포함한 모든 처리된 결제의 상세 기록입니다. | **Transactions → Payments** |
| **Refund Report** | 자세한 환불 정보가 포함된 모든 환불 활동의 종합 기록입니다. | **Transactions → Refunds** |
| **Disputes Report** | 해결 상태 및 증거 세부 정보가 포함된 결제 분쟁 요약입니다. | **Transactions → Disputes** |
| **Customer Report** | 고객별로 정리한 결제, 환불 및 분쟁 요약입니다. | **Sales → Customers** |
| **Payout Report** | 계정으로 지급된 금액의 요약과 원장 이벤트별 수수료 분석입니다. | **Payouts** |
| **Account Summary Report** | 이벤트 유형, 금액 및 참조 정보가 포함된 상세 잔액 원장 항목입니다. | **Payouts → Balances** |

## 보고서 다운로드

<Steps>
<Step title="Navigate to the relevant page">
위 표를 사용하여 필요한 보고서의 페이지로 이동합니다.
</Step>
<Step title="Select a time period">
<strong>Build Report</strong>를 클릭한 다음 사전 설정된 기간(Today, Last 7 days, Last 30 days, This month 등)을 선택하거나 캘린더에서 사용자 지정 날짜 범위를 선택합니다.
</Step>
<Step title="Download">
<strong>Download Report</strong>를 클릭합니다. 보고서가 CSV로 내보내져 기기에 저장됩니다.
</Step>
</Steps>

<Note>
수수료 데이터는 독립적인 보고서로 제공되지 않습니다. 수수료(결제 수수료, 환불 수수료 및 지급 수수료) 분석은 **Payouts → Balances**의 **Account Summary Report**에서 필터 옵션으로 이용할 수 있습니다.
</Note>
