## How It Works

Payment methods are automatically presented to customers based on:

- **Customer Location** — Regional methods like iDEAL (Netherlands) or UPI (India) only appear for customers in those regions
- **Transaction Currency** — Payment methods are filtered by supported currencies
- **Device Type** — Apple Pay only appears on compatible Apple devices and browsers
- **Transaction Type** — Some methods don't support subscriptions or have minimum amounts

<Info>
**Automatic Activation:** All payment methods are pre-configured and managed by Dodo Payments. No additional setup needed — they become available once your account is verified and live mode is enabled.
</Info>

## 비즈니스 수준의 결제 수단 비활성화

대시보드에서 비즈니스 수준으로 특정 결제 수단을 비활성화할 수 있습니다. 이 설정은 제품 또는 세션별로 구성하지 않아도 비즈니스의 모든 checkout session에 적용됩니다.

<Steps>
<Step title="Navigate to Settings">
Dodo Payments dashboard에서 **Settings > Payment Methods**로 이동합니다.
</Step>

<Step title="Disable Payment Methods">
고객에게 제공하지 않을 결제 수단을 끕니다.
</Step>
</Steps>

<Tip>
이 기능을 사용하여 해당 지역에서 사기율이 높은 결제 수단을 비활성화하거나, 비즈니스가 운영상 지원하는 수단만 제공하도록 제한할 수 있습니다.
</Tip>

<Info>
비즈니스 수준 설정은 전역 필터로 작동합니다. `allowed_payment_method_types`를 통한 checkout별 제한은 비즈니스 수준에서 활성화된 수단 중 사용 가능한 수단을 추가로 좁힙니다.
</Info>

## Checkout별 결제 수단 구성

비즈니스 수준 설정 외에도 `allowed_payment_method_types`를 사용하여 개별 checkout session에 표시할 결제 수단을 제한할 수 있습니다:

<Tabs>
<Tab title="JavaScript">

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  allowed_payment_method_types: [
    'credit',
    'debit', 
    'apple_pay',
    'google_pay'
  ],
  return_url: 'https://example.com/success'
});
```

</Tab>

<Tab title="Python">

```python
session = client.checkout_sessions.create(
    product_cart=[{"product_id": "pdt_123", "quantity": 1}],
    allowed_payment_method_types=[
        "credit",
        "debit",
        "apple_pay", 
        "google_pay"
    ],
    return_url="https://example.com/success"
)
```

</Tab>

<Tab title="cURL">

```bash
curl -X POST https://test.dodopayments.com/checkouts \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "product_cart": [{"product_id": "pdt_123", "quantity": 1}],
    "allowed_payment_method_types": ["credit", "debit", "apple_pay", "google_pay"],
    "return_url": "https://example.com/success"
  }'
```

</Tab>
</Tabs>

## 모범 사례

<AccordionGroup>
<Accordion title="Match methods to your market">
대상 시장에 맞는 지역 결제 수단을 포함하세요. iDEAL은 네덜란드 온라인 결제의 약 60%를 차지하며, 인도에서는 UPI가 지배적입니다. 이러한 수단을 제외하면 전환율이 크게 저하됩니다.
</Accordion>

<Accordion title="Always provide card fallbacks">
특정 수단을 대상으로 하더라도 `credit` 및 `debit`를 fallback으로 포함하세요. 모든 고객이 모든 결제 수단을 이용할 수 있는 것은 아닙니다.
</Accordion>

<Accordion title="Consider transaction minimums">
BNPL 수단에는 provider별 최소 금액이 있습니다. Klarna와 Afterpay는 $50.01을 요구합니다. 이 범위를 벗어나는 제품에는 포함하지 마세요. 해당 수단은 표시되지 않으며, 이는 정상입니다.
</Accordion>

<Accordion title="Test across regions and devices">
출시 전에 test mode를 사용하여 다양한 고객 위치, 통화 및 device type에서 결제 수단을 사용할 수 있는지 확인하세요.
</Accordion>
</AccordionGroup>

## 문제 해결

<AccordionGroup>
<Accordion title="Payment method not appearing">
**다음 요소를 확인하세요:**
1. `allowed_payment_method_types`에 수단이 포함되어 있나요?
2. 고객 위치가 해당 수단의 지원 지역과 일치하나요?
3. 거래 통화가 해당 수단에서 지원되나요?
    4. 거래 금액이 해당 수단의 지원 범위 내에 있나요(예: Klarna/Afterpay 최소 $50.01)?
5. 구독의 경우 해당 수단이 recurring payment를 지원하나요?

**해결 방법:** 모든 사용 가능한 수단을 확인할 수 있도록 `allowed_payment_method_types`를 일시적으로 제거한 후 문제를 좁혀 보세요.
</Accordion>

<Accordion title="Unexpected methods appearing">
**가능한 원인:**
- `allowed_payment_method_types`가 올바르게 전달되지 않음
- Parameter 형식이 잘못됨(문자열 배열이어야 함)

**해결 방법:** API request payload를 기록하고 parameter 구조를 확인하세요.
</Accordion>

<Accordion title="Regional method not available">
**확인할 항목:**
- 고객 billing address가 해당 수단의 지역과 일치하는지
- 통화가 올바르게 설정되었는지(예: iDEAL의 경우 EUR)
- 고객이 해외 고객인 경우 Adaptive Currency가 활성화되어 있는지

**해결 방법:** API request에서 billing address country code와 currency를 확인하세요.
</Accordion>

<Accordion title="Indian payment method issues">
UPI 및 Rupay 구독에는 48시간 처리 지연과 RBI mandate 한도를 비롯한 고유한 요구 사항이 있습니다.

**참조:** 자세한 안내는 <a href="/features/payment-methods/india">India Payment Methods</a>를 확인하세요.
</Accordion>
</AccordionGroup>
