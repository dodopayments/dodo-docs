<Info>
Adaptive Currency를 사용하면 현지화된 가격을 표시하고 고객의 로컬 통화로 결제를 수락할 수 있습니다. 이로 인해 결제 시 마찰이 줄어들고 신뢰가 쌓입니다.
</Info>

## 적응형 통화란 무엇인가요?

Adaptive Currency는 제품 가격을 기본 통화로만 표시하지 않고 고객의 현지 통화로 표시합니다. 활성화하면 지원되는 국가에서 결제 페이지가 감지된 현지 통화로 기본 설정되며, 기본 통화로 다시 전환할 수도 있습니다.

기본 통화는 제품 또는 추가 기능의 가격을 설정할 때 사용한 통화입니다. USD뿐만 아니라 Dodo Payments에서 청구할 수 있는 모든 통화를 사용할 수 있습니다. Adaptive Currency는 실시간 환율로 해당 기본 가격을 변환합니다. 대신 통화 또는 국가별로 직접 고정 가격을 설정하려면 [현지화된 가격](/features/localized-pricing)을 참조하세요.

## 주요 혜택

- **현지화된 결제 경험**: 가격이 기본적으로 현지 통화로 표시됩니다.
- **다양한 결제 방법**: 현지 통화와 관련된 결제 방법을 활성화합니다.
- **동일 통화 환불**: 고객이 결제한 통화로 환불합니다.

## Adaptive Currency 활성화

<Steps>
<Step title="Open Settings">
상인 대시보드에 로그인하고 설정 → 비즈니스로 이동합니다.
</Step>

<Step title="Toggle Adaptive Pricing">
Adaptive Pricing 토글을 활성화합니다. 언제든지 비활성화할 수 있습니다.

<Warning>
변경 사항은 향후 거래에만 적용됩니다.
</Warning>
</Step>

<Step title="Confirm and Save">
설정을 저장합니다.

<Check>
테스트 결제가 지원되는 경우 가격이 현지 통화로 표시되는지 확인하십시오.
</Check>
</Step>
</Steps>

## 고객 경험

1. **감지**: 시스템이 청구지 주소를 기준으로 고객의 국가를 감지합니다.
2. **통화 선택**: 해당 국가가 지원되는 경우 가격이 기본적으로 현지 통화로 표시됩니다. 고객은 기본 통화로 다시 전환할 수 있습니다.
3. **결제 수단**: 해당하는 경우 현지 결제 수단이 표시됩니다.
4. **결제**: 선택한 통화로 결제가 완료됩니다.

## 전환 및 수수료

Adaptive Currency는 최신 환율을 사용하여 고객의 현지 통화로 결제합니다.

- **귀하가 지불**: 0% (기본값) 또는 2–4% (수수료 포함 활성화 시)
- **고객이 지불**: 주문 가치에 따라 2–4% (기본값) 또는 0% (수수료 포함 활성화 시)

체크아웃 시 적용되는 계층형 수수료:

- $500 이하 주문의 경우 4%
- $500에서 $1,500까지의 경우 3%
- $1,500 이상 주문의 경우 2%

### 수수료 부담 주체 선택

기본적으로 Adaptive Currency 수수료는 표시된 가격에 추가되어 고객이 부담합니다. **수수료 포함** 설정을 통해 귀하가 수수료를 부담할 수 있습니다: 고객은 항상 동일한 현지 통화 가격을 보며, 수수료는 정산 금액에서 차감됩니다.

<Steps>
<Step title="Enable Adaptive Pricing">
이미 설정하지 않았다면 **설정 → 비즈니스**로 이동하여 Adaptive Pricing 토글을 활성화하십시오.
</Step>

<Step title="Toggle Fees Inclusive">
Adaptive Pricing이 켜지면 동일 섹션에서 **수수료 포함** 하위 토글을 활성화하십시오.
</Step>
</Steps>

| 모드 | 고객이 보는 가격 | 상인 정산 금액 |
|------|---------------|------------------|
| 독점 (기본) | 현지 가격 + 2–4% 수수료 추가 | 전체 기본 가격 |
| 포함 | 현지 가격 (변경 없음) | 기본 가격에서 2–4% 수수료를 뺀 금액 |

상인 기본 설정을 요청별로 재정의하려면 체크아웃 세션, 결제, 주문형 구독에 `adaptive_currency_fees_inclusive` (boolean)을 전달하십시오:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_abc', quantity: 1 }],
  adaptive_currency_fees_inclusive: true, // override the business setting for this session
  return_url: 'https://yoursite.com/return'
});
```

<Info>
INR → INR 거래는 비즈니스 설정이나 요청별 재정의와 상관없이 항상 포함된 것으로 처리됩니다.
</Info>

<Info>
[Localized Pricing](/features/localized-pricing) 규칙이 일치하면, 상관없이 거래는 항상 포함된 것으로 처리됩니다. 고객은 설정한 현지화된 금액을 정확히 지불하며, 전환 수수료는 정산에서 차감됩니다.
</Info>

## 환불 및 조정

Dodo Payments는 고객이 처음 결제한 통화로 최신 환율을 적용하여 환불을 처리합니다. 기본 통화로 표시된 금액은 대시보드, 인보이스 및 환불 내역에서 고정된 상태로 유지됩니다. 따라서 환율 변동에 따라 고객이 최초의 현지 통화 금액보다 많거나 적은 금액을 받을 수 있습니다.

<Info>
Adaptive Currency 수수료, 일반적으로 FX 수수료는 환불되지 않습니다.
</Info>

**환불 예시**

1. 상품을 100 USD에 Adaptive Currency 활성화 상태로 판매합니다.
2. 캐나다 고객이 1 USD당 1.37 CAD의 환율로 137 CAD를 보고 구매를 완료합니다.
3. 우리는 결제를 처리하고, 137 CAD를 100 USD로 변환하여 정산합니다.
4. 이후 환율이 1 USD당 1.40 CAD로 변경되고 전체 환불을 발행합니다.
5. 우리는 100 USD를 차감하고 고객에게 140 CAD를 환불합니다.

## 청구서 및 세금

- 청구서는 정산 통화 금액만 표시합니다.
- 세금 및 플랫폼 수수료는 정산 통화 금액에 기반하여 계산됩니다.
- 예: \$10 판매가 36 AED로 변환되더라도 대시보드 및 청구서에서는 여전히 $10로 반영됩니다.

<Info>
모든 금액은 Dodo Payments의 내부 반올림 논리에 따라 반올림됩니다.
</Info>

## 통합 예제

**청구 통화가 설정된 체크아웃 세션**

SESSION의 청구 통화를 명시적으로 설정하려면 `billing_currency`을 전달하십시오.

<Info>
Adaptive Pricing이 비활성화된 경우 `billing_currency`이 무시됩니다.
</Info>

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    {
      product_id: 'prod_one_time_or_subscription',
      quantity: 1
    }
  ],
  billing_currency: 'AED',
  return_url: 'https://example.com/return'
});
```
