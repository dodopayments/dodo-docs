카드 결제는 온라인 결제의 기반으로, 전 세계에서 사용되며 고객들의 신뢰를 받고 있습니다. Dodo Payments은(는) 기본 제공되는 fraud protection 및 PCI compliance와 함께 모든 주요 카드 네트워크를 지원합니다.

## 지원되는 카드 네트워크

### 글로벌 네트워크

| 네트워크 | 지원 범위 |
| :------ | :------- |
| **Visa** | 전 세계 선도 네트워크, 전 세계 40억 장 이상의 카드 |
| **Mastercard** | 전 세계적인 도달 범위, 강력한 보안 기능 |
| **American Express** | 프리미엄 카드 보유자, 높은 지출 규모 |
| **Discover** | 미국 중심, 전 세계로 확장 중 |
| **JCB** | 일본 선도 네트워크, 아시아 전역으로 확장 중 |
| **UnionPay** | 중국에서 지배적인 네트워크, 80억 장 이상의 카드 |
| **Diners Club** | 프리미엄 국제 여행객 |

## 구성

`allowed_payment_method_types`에서 다음 값을 사용하세요:

| 유형 | 설명 |
| :--- | :---------- |
| `credit` | 모든 신용카드 |
| `debit` | 모든 직불카드 |

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  allowed_payment_method_types: ['credit', 'debit'],
  return_url: 'https://example.com/success'
});
```

<Tip>
특별한 이유로 하나를 제외해야 하는 경우가 아니라면 `credit` 및 `debit`를 모두 포함하세요. 많은 고객이 직불카드를 선호하며, 수수료가 더 낮은 경우가 많습니다.
</Tip>

## 3D Secure 인증

3D Secure(3DS)는 카드 소유자의 신원을 확인하여 fraud 및 chargeback을 줄이는 인증 계층을 추가합니다.

### 3DS가 트리거되는 경우

다음과 같은 경우 3DS가 자동으로 트리거됩니다:
- 카드 네트워크에서 요구하는 경우
- 지역 규정에서 요구하는 경우(예: 유럽의 PSD2)
- 거래가 고위험으로 표시된 경우

### 3DS 강제 적용

모든 거래에 3DS를 요구할 수 있습니다:

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  force_3ds: true,
  return_url: 'https://example.com/success'
});
```

<Note>
모든 거래에 3DS를 사용하면 fraud가 줄어들지만, 일부 고객이 인증 중에 이탈할 수 있어 conversion이 약간 감소할 수 있습니다.
</Note>

### 인증 실패 처리

결제에 3DS 인증이 필요한 경우, 결제가 성공하거나 실패하기 전에 중간 상태를 거칩니다:

| 상태 | 의미 | 조치 |
|--------|---------|------------|
| `requires_customer_action` | 고객이 3DS challenge를 완료해야 함 | checkout 중에 고객이 인증을 완료하도록 안내 |
| `requires_payment_method` | 고객이 결제 수단을 제공하지 않음(세부 정보를 입력하지 않았거나 prompt를 중단함) — 일반적으로 decline이 아닌 이탈 | 고객이 checkout을 완료하도록 다시 참여 유도; [Abandoned Cart Recovery](/features/recovery/abandoned-cart-recovery) 참고 |

인증이 완료되지 않으면 다음 decline code 중 하나와 함께 결제가 실패합니다:

- `AUTHENTICATION_FAILURE` — 고객을 인증할 수 없습니다.
- `AUTHENTICATION_REQUIRED` — 인증이 필요하지만 수행되지 않았습니다.
- `AUTHENTICATION_TIMEOUT` — 고객이 제한 시간 내에 응답하지 않았습니다.

각 항목에 권장되는 조치는 [Transaction Failures](/api-reference/transaction-failures) reference를 참고하세요.

#### Checkout 시점과 갱신 시점

- **checkout 시점(고객이 있는 경우):** 고객이 있으므로 checkout 중에 3DS challenge가 표시됩니다. 실패하면 다시 시도하거나 다른 카드를 사용하도록 안내하세요.
- **subscription renewal 시점(고객이 없는 경우):** 고객이 없으므로 실시간으로 3DS challenge를 표시할 수 없습니다. 갱신에 인증이 필요한 경우 subscription은 `on_hold`(으)로 이동합니다. 고객에게 돌아와 결제 수단을 업데이트하도록 안내하여 복구하세요 — [Handle Payment Failures](/developer-resources/handle-payment-failures) 및 [Subscription Dunning](/features/recovery/subscription-dunning)을 참고하세요.

고객은 향후 checkout을 더 빠르게 진행할 수 있도록 카드를 저장할 수 있습니다.

### 저장된 카드 활성화

```javascript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  show_saved_payment_methods: true,
  customer: { customer_id: 'cus_existing_123' },
  return_url: 'https://example.com/success'
});
```

### One-Click 구매

```javascript
// Get customer's saved payment methods
const methods = await client.customers.retrievePaymentMethods('cus_123');

// Use saved card for instant checkout
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_123', quantity: 1 }],
  customer: { customer_id: 'cus_123' },
  payment_method_id: methods.items[0].payment_method_id,
  confirm: true,
  return_url: 'https://example.com/success'
});
```

## 문제 해결

<AccordionGroup>
<Accordion title="Card declined">
**원인:** 잔액 부족, 카드 만료, 잘못된 CVV, 은행의 fraud protection.

**해결 방법:** 고객에게 세부 정보를 확인하거나 다른 카드를 사용하도록 요청하세요. [Transaction Failures](/api-reference/transaction-failures) reference에서 특정 decline `Error Code` 및 권장 조치를 확인하고, programmatic 처리는 [Handle Payment Failures](/developer-resources/handle-payment-failures)를 참고하세요.
</Accordion>

<Accordion title="3DS authentication failed">
**원인:** 고객 이탈, 은행 시스템 사용 불가, timeout.

**해결 방법:** 다시 시도하거나 고객에게 은행에 문의하도록 요청하세요. 관련 결제 상태 및 decline code는 [Handling Authentication Failures](#handling-authentication-failures)을 참고하세요.
</Accordion>

<Accordion title="Card not supported">
**원인:** 지역 카드 미지원, prepaid 제한.

**해결 방법:** 고객에게 주요 네트워크의 다른 카드를 사용하도록 안내하세요.
</Accordion>
</AccordionGroup>
