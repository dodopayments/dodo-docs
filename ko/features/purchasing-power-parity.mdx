[ParityDeals](https://www.paritydeals.com/) 및 [Evendeals](https://www.evendeals.com/integrations/dodo-payments)은 고객의 지리적 위치를 기반으로 자동으로 가격을 최적화하는 플랫폼으로, 일반적으로 "구매력 평가 절하"(PPP) 가격으로 알려져 있습니다.

<Info>
Dodo Payments 상점에서 직접 할인 배너를 삽입할 수는 없지만 (사용자 정의 스크립트가 지원되지 않기 때문), 여전히 자신의 웹사이트나 애플리케이션에서 이러한 도구들을 효과적으로 구현할 수 있습니다.
</Info>

  </Card>

## 통합 선택하기

두 플랫폼 모두 Dodo Payments와 직접 통합되어 할인 코드를 자동으로 생성하고 관리합니다. 아래의 비교를 사용하여 귀하의 요구에 가장 적합한 도구를 선택하십시오.

| 기능 | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| PPP / 위치 기반 가격 | 예 | 예 |
| 휴일 / 시간 기반 거래 | 예 | 아니요 |
| 구독 지원 | 예 | 예 |
| 자동 쿠폰 갱신 | — | 예 |
| 배너 커스터마이징 | 예 | 아니요 |
| 가격 | [가격 보기](https://www.paritydeals.com/pricing/) | [가격 보기](https://www.evendeals.com/pricing) |

## ParityDeals

ParityDeals가 웹사이트에 통합될 경우, 적격 방문자는 체크아웃 시 사용할 수 있는 위치 기반 할인 코드를 포함한 배너를 보게 됩니다. 이러한 할인 코드는 ParityDeals에 의해 자동으로 생성 및 관리되며, **Dodo Payments 대시보드**에 있는 **Sales → Discounts**에 나타납니다.

### 설정

<Steps>
  <Step title="Sign up on ParityDeals">
    [app.paritydeals.com](https://app.paritydeals.com/)을 방문하여 계정을 생성하세요.
  </Step>

  <Step title="Create Deals">
    로그인 후 거래 생성 옵션을 찾습니다. 드롭다운 메뉴에서 **"Dodo Payments를 통한 거래 생성"**을 선택하세요.

    <Frame>
      <img src="/images/ppp/2.png" alt="Dodo Payments를 통한 거래 생성" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    **Dodo Payments 대시보드**에 로그인하여 **Developers → API Keys**로 이동합니다. **"Create New API"**를 클릭하세요.

    <Tip>
      나중에 식별할 수 있도록 API 키의 이름을 설명적으로 지정하세요 (예: 'ParityDeals').
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="Dodo Payments에서 새로운 API 키 생성" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    생성한 API 키를 복사하여 ParityDeals 인터페이스에 붙여넣어 Dodo Payments 계정과의 연결을 설정하세요.

    <Frame>
      <img src="/images/ppp/4.png" alt="API 키를 ParityDeals에 연결" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    연결되면 ParityDeals가 Dodo Payments 제품 카탈로그를 가져오게 됩니다. 거래에 연결할 제품을 선택하세요.

    <Frame>
      <img src="/images/ppp/5.png" alt="ParityDeals에 대한 제품 선택" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    웹사이트 URL을 입력하고, 옵션에 따라 특정 타겟 페이지를 선택하여 할인 배너를 표시할 수 있습니다. 그런 다음 선호하는 거래 유형을 선택하세요:
    - 위치 기반 거래
    - 휴일 거래
    - 시간 기반 플래시 거래

    <Frame>
      <img src="/images/ppp/6.png" alt="거래 설정 구성" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    현지 할인을 제공할 국가를 선택하고 각 국가에 대한 할인 비율을 정의하세요. ParityDeals는 필요한 경우 조정할 수 있는 권장 기본 설정을 제공합니다.

    <Frame>
      <img src="/images/ppp/7.png" alt="국가 기반 할인 규칙 설정" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    텍스트 커스터마이징, 색상 및 레이아웃 선택, 배너 위치 (페이지 상단 또는 하단) 선택을 통해 할인 배너를 디자인하세요. 이 배너는 구성된 규칙에 따라 적격 방문자에게 표시됩니다.

    <Frame>
      <img src="/images/ppp/8.png" alt="할인 배너 맞춤 설정" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    거래를 저장한 후 ParityDeals는 스크립트를 생성합니다. 이 스크립트를 웹사이트 코드에 추가합니다 (일반적으로 `<head>` 섹션). 이 스크립트는 자동으로 방문자 위치를 감지하여 적절한 할인 배너를 표시합니다.

    <Frame>
      <img src="/images/ppp/9.png" alt="ParityDeals 통합 스크립트" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

### 추가 기능

ParityDeals를 통해 연중 [자동 시간 기반 할인](https://www.paritydeals.com/features/time-based-discounts/) 및 [휴일 기반 프로모션](https://www.paritydeals.com/features/holiday-based-discounts/)을 제공할 수 있습니다. 더 자세한 정보는 [ParityDeals Documentation](https://www.paritydeals.com/docs/)를 참조하세요.

## Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments)는 또 다른 플랫폼으로, Dodo Payments와 통합되어 위치 기반 구매력 평가 절하 가격을 제공합니다. 일회성 및 구독 제품 모두를 지원합니다.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Evendeals Dodo Payments 통합 개요" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

### 주요 기능

- **자동 쿠폰 동기화** — 쿠폰은 Dodo Payments에 자동으로 생성 및 관리됩니다
- **비율 할인** — 국가 그룹별로 비율 할인 제공
- **구독 지원** — 구독 청구 주기에 따라 할인이 적용됩니다
- **자동 갱신 규칙** — 남용 방지를 위해 시간 간격, 사용 횟수, 조회수에 따라 쿠폰 코드를 자동으로 회전시킵니다

<Info>
Evendeals에 의해 생성된 할인 코드는 Dodo Payments 대시보드의 Sales → Discounts에 자동으로 나타납니다.
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="Dodo Payments 통합을 위한 Evendeals 주요 기능" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

### 설정

<Steps>
  <Step title="Create a Dodo Payments API key">
    Dodo Payments 대시보드에서 **Developers → API Keys**로 이동하여 새 키를 생성합니다.
  </Step>

  <Step title="Connect in Evendeals">
    [Evendeals 대시보드](https://www.evendeals.com/signin)로 이동하여 **Integrations**를 선택하고, Dodo Payments 카드를 찾아 API 키를 붙여넣으세요.
  </Step>

  <Step title="Configure regional discounts">
    각 국가 그룹에 대한 비율 할인을 설정하고 동기화를 클릭하세요. Evendeals는 Dodo Payments에 자동으로 쿠폰을 생성합니다.

    <Check>
    동기화 후, Dodo Payments 대시보드의 **Sales → Discounts**를 열어 생성된 쿠폰이 나타나는지 확인하세요. 각 쿠폰에는 인식 가능한 Evendeals 접두사가 있습니다.
    </Check>
  </Step>
</Steps>

<Frame>
  <img src="/images/ppp/evendeals-setup.png" alt="Dodo Payments에 대한 Evendeals 설정 가이드" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

ParityDeals 및 Evendeals는 모두 Dodo Payments와 원활하게 작동하여 글로벌 가격 전략을 최적화하는 데 도움을 줍니다. 더 많은 세부 정보는 [ParityDeals Documentation](https://www.paritydeals.com/docs/) 또는 [Evendeals Dodo Payments integration page](https://www.evendeals.com/integrations/dodo-payments)를 방문하세요.
