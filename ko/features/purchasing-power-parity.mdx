구매력 평가(PPP) 가격 책정은 각 고객의 위치에 따라 구매력을 맞추기 위해 청구 금액을 조정합니다. Dodo Payments에서는 두 가지 방법으로 이를 수행할 수 있습니다.

<Info>
**추천 방법:** 네이티브 [Localized Pricing](/features/localized-pricing)을 사용하여 국가별 고정 현지 가격을 설정하세요. 예를 들어 ₹999은 인도에서 $20 기본 가격의 상품을 의미합니다. 이 방법은 일회성, 구독 및 사용 기반 상품에 모두 적용되며, 설치해야 할 배너나 스크립트가 없습니다.
</Info>

## PPP 실행의 두 가지 방법

| | 지역화된 가격 책정(네이티브) | 위치 기반 할인 코드 |
| :--- | :--- | :--- |
| 작동 방식 | 국가/통화별 고정 현지 가격을 설정합니다 | 기본 가격 대비 할인률이 코드로 적용됩니다 |
| 도구 | Dodo Payments에 내장 | [ParityDeals](https://www.paritydeals.com/) / [Evendeals](https://www.evendeals.com/integrations/dodo-payments) |
| 사이트의 배너/스크립트 | 필요하지 않음 | 코드를 표시하려면 필요함 |
| 고객이 보는 가격 | 설정한 정확한 금액 | 기본 가격에서 할인된 금액 |
| 최적의 대상 | 완전히 제어 가능하고 시장에 맞춘 가격 | 프로모션 배너 및 기간/휴가 기반의 거래 |

네이티브 설정은 [Localized Pricing](/features/localized-pricing)을 참조하세요. 이 페이지의 나머지 부분은 ParityDeals 및 Evendeals을 통한 위치 기반 할인 코드 접근 방식을 다룹니다.

## 위치 기반 할인 코드

[ParityDeals](https://www.paritydeals.com/) 및 [Evendeals](https://www.evendeals.com/integrations/dodo-payments)은 고객의 지리적 위치에 기반한 자동 가격 최적화를 할인 코드를 통해 가능하게 하는 플랫폼입니다.

<Info>
커스텀 스크립트를 지원하지 않아 Dodo Payments 스토어프론트에 직접 할인 배너를 임베드할 수는 없지만, 여전히 이러한 도구를 자체 웹사이트나 애플리케이션에 효과적으로 구현할 수 있습니다.
</Info>

### 통합 선택

두 플랫폼 모두 Dodo Payments와 직접 통합되어 할인 코드를 자동으로 생성하고 관리합니다. 아래 비교를 사용하여 귀하의 요구에 가장 적합한 도구를 선택하세요.

| 기능 | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| PPP / 위치 기반 가격 | 예 | 예 |
| 휴일/시간 기반 거래 | 예 | 아니요 |
| 구독 지원 | 예 | 예 |
| 자동 쿠폰 갱신 | — | 예 |
| 배너 사용자 정의 | 예 | 아니요 |
| 가격 책정 | [가격 보기](https://www.paritydeals.com/pricing/) | [가격 보기](https://www.evendeals.com/pricing) |

### ParityDeals

ParityDeals가 웹사이트에 통합되면 자격이 있는 방문자는 결제 시 사용할 수 있는 위치 기반 할인 코드가 포함된 배너를 보게 됩니다. 이 할인 코드는 ParityDeals에서 자동으로 생성 및 관리되며 **Dodo Payments 대시보드**의 **Sales → Discounts**에서 확인할 수 있습니다.

<Frame>
  <img src="/images/ppp/1.png" alt="ParityDeals 할인 배너 예시" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### 설정

<Steps>
  <Step title="Sign up on ParityDeals">
    [app.paritydeals.com](https://app.paritydeals.com/)을 방문하여 계정을 생성하세요.
  </Step>

  <Step title="Create Deals">
    로그인한 후, 거래를 생성할 옵션을 찾습니다. 드롭다운 메뉴에서 **"Dodo Payments로 거래 생성"**을 선택합니다.

    <Frame>
      <img src="/images/ppp/2.png" alt="Dodo Payments로 거래 생성" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Generate a Dodo Payments API Key">
    **Dodo Payments 대시보드**에 로그인하고 **개발자 → API 키**로 이동합니다. **"새 API 생성"**을 클릭하세요.

    <Tip>
      나중에 식별할 수 있도록 API 키 이름을 설명적으로 지정하세요 (예: 'ParityDeals').
    </Tip>

    <Frame>
      <img src="/images/ppp/3.png" alt="Dodo Payments에서 새 API 키 생성" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Connect Your API Key to ParityDeals">
    생성한 API 키를 복사하여 ParityDeals 인터페이스에 붙여 넣어 Dodo Payments 계정과 연결합니다.

    <Frame>
      <img src="/images/ppp/4.png" alt="API 키를 ParityDeals에 연결" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Select Products">
    연결된 후 ParityDeals가 Dodo Payments 제품 카탈로그를 가져옵니다. 거래와 연결할 제품을 선택하세요.

    <Frame>
      <img src="/images/ppp/5.png" alt="ParityDeals용 제품 선택" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Configure Deal Settings">
    웹사이트 URL을 입력하고 옵션에 따라 특정 대상 페이지를 선택한 다음, 선호하는 거래 유형을 선택하세요:
    - 위치 기반 거래
    - 휴일 거래
    - 시간 기반 플래시 거래

    <Frame>
      <img src="/images/ppp/6.png" alt="거래 설정 구성" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Set Country-Based Rules">
    지역별로 제공할 할인 대상을 선택하고 각 나라별 할인율을 정의하세요. ParityDeals는 조정 가능한 권장 값을 제공합니다.

    <Frame>
      <img src="/images/ppp/7.png" alt="국가 기반 할인 규칙 설정" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Customize the Banner">
    텍스트를 커스터마이즈하고 색상, 레이아웃 및 배너 위치(페이지 상단 또는 하단)를 선택하여 할인 배너를 디자인하세요. 이 배너는 구성된 규칙에 따라 적합한 방문자에게 표시됩니다.

    <Frame>
      <img src="/images/ppp/8.png" alt="할인 배너 커스터마이징" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>

  <Step title="Add the ParityDeals Script to Your Website">
    거래를 저장한 후 ParityDeals는 스크립트를 생성합니다. 웹사이트 코드에 이 스크립트를 추가하세요 (일반적으로 `<head>` 섹션에). 이 스크립트는 방문자 위치를 자동으로 감지하고 적절한 할인 배너를 표시합니다.

    <Frame>
      <img src="/images/ppp/9.png" alt="ParityDeals 통합 스크립트" style={{ maxHeight: '500px', width: 'auto' }} />
    </Frame>
  </Step>
</Steps>

#### 추가 기능

ParityDeals로 연중 [자동 시간 기반 할인](https://www.paritydeals.com/features/time-based-discounts/) 및 [휴일 기반 프로모션](https://www.paritydeals.com/features/holiday-based-discounts/)을 제공할 수 있습니다. 자세한 정보는 [ParityDeals Documentation](https://www.paritydeals.com/docs/)을 참조하세요.

### Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments)는 또 다른 플랫폼으로 Dodo Payments와 통합하여 위치 기반 구매력 평가 가격 책정을 제공합니다. 일회성 및 구독 상품을 지원합니다.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Evendeals Dodo Payments 통합 개요" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### 주요 기능

- **자동 쿠폰 동기화** — 쿠폰은 Dodo Payments에서 자동으로 생성 및 관리됩니다
- **퍼센트 할인** — 국가 그룹별로 퍼센트 오프 할인 제공
- **구독 지원** — 할인이 구독 청구 주기 전체에 적용됨
- **자동 갱신 규칙** — 시간 간격, 사용 횟수 또는 보기 횟수에 따라 쿠폰 코드를 자동으로 회전시켜 악용 방지

<Info>
Evendeals에 의해 생성된 할인 코드가 Dodo Payments 대시보드의 Sales → Discounts에 자동으로 나타납니다.
</Info>

<Frame>
  <img src="/images/ppp/evendeals-features.png" alt="Dodo Payments 통합을 위한 Evendeals 주요 기능" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

#### 설정

<Steps>
  <Step title="Create a Dodo Payments API key">
    Dodo Payments 대시보드에서 **개발자 → API 키**로 이동하여 새 키를 생성하세요.
  </Step>

  <Step title="Connect in Evendeals">
    [Evendeals 대시보드](https://www.evendeals.com/signin)에서 **통합**으로 이동하여 Dodo Payments 카드를 찾아 API 키를 붙여넣습니다.
  </Step>

  <Step title="Configure regional discounts">
    각 국가 그룹에 퍼센트 할인을 설정하고 동기화하세요. Evendeals가 Dodo Payments에 쿠폰을 자동으로 생성합니다.

    <Check>
    동기화 후 Dodo Payments 대시보드의 **Sales → Discounts**를 열어 생성된 쿠폰이 나타나는지 확인하세요. 각 쿠폰에는 인식 가능한 Evendeals 접두사가 있습니다.
    </Check>
  </Step>
</Steps>

<Frame>
  <img src="/images/ppp/evendeals-setup.png" alt="Dodo Payments를 위한 Evendeals 설정 가이드" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

ParityDeals와 Evendeals는 모두 Dodo Payments와 매끄럽게 작동하여 글로벌 가격 전략을 최적화하는 데 도움을 줍니다. 자세한 정보는 [ParityDeals Documentation](https://www.paritydeals.com/docs/) 또는 [Evendeals Dodo Payments 통합 페이지](https://www.evendeals.com/integrations/dodo-payments)를 방문하세요.
