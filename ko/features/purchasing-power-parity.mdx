<Info>
구매력 평가(PPP)는 고객이 구매하는 국가를 기준으로 목록 가격의 일정 비율을 고객에게 청구합니다. \$20인 제품을 할인 코드나 두 번째 가격 목록 없이 **India에서 \$6.00**에 판매할 수 있습니다.
</Info>

## 구매력 평가(PPP)란 무엇인가요?

같은 가격이라도 모든 지역에서 동일하게 부담 가능한 것은 아닙니다. \$20은 United States에서는 소액 구매지만 Philippines에서는 큰 금액입니다. PPP pricing은 이러한 차이를 반영합니다.

Dodo Payments는 국가별로 하나의 비율을 유지합니다. 이 비율은 **고객이 지불하는 목록 가격의 비중**입니다. India는 30이므로 India의 고객은 가격의 30%를 지불합니다. United States는 100이므로 가격이 변경되지 않습니다.

적용하려는 각 제품 가격에 PPP를 활성화합니다. 선택하지 않은 제품은 모든 지역에서 정상 가격을 유지합니다.

<Note>
PPP에는 [Adaptive Currency](/features/adaptive-currency)가 필요합니다. 먼저 Adaptive Currency를 활성화하세요.
</Note>

## 주요 이점

- **가격에 민감한 시장에 도달**: 기본 국가의 가격을 낮추지 않고 현지 가격으로 판매할 수 있습니다.
- **배너와 스크립트 불필요**: checkout에서 가격이 올바르게 적용됩니다. 웹사이트에 아무것도 추가하지 않아도 됩니다.
- **관리할 할인 코드 불필요**: 생성, 교체 또는 취소할 코드가 없습니다.
- **제품별 제어**: starter plan에는 적용하고 enterprise plan에는 적용하지 않을 수 있습니다.
- **모든 제품 유형에서 작동**: 일회성, subscription 및 usage-based 제품에 적용됩니다.

## 구매력 평가 활성화

<Steps>
<Step title="Enable Adaptive Currency">
**Settings → Business**로 이동합니다. **Business Settings**에서 **Adaptive Currency**를 활성화합니다. Adaptive Currency 없이는 PPP가 작동하지 않습니다.

<Frame>
  <img src="/images/ppp/adaptive-currency-toggle.png" alt="Business Settings의 Adaptive Currency 및 Purchasing Power Parity" style={{ maxHeight: '360px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Review your country percentages">
**Purchasing Power Parity**에서 **Edit**을 클릭하여 **Country Prices**를 엽니다. 국가별 비율을 변경한 다음 **Save Changes**를 클릭합니다.

각 국가에서 지불하는 금액을 확인하려면 **Example product price**를 설정합니다. 입력하는 동안 **Your Price** 열이 업데이트됩니다. 검색 상자를 사용하여 이름이나 코드로 국가를 찾을 수 있습니다.

<Frame>
  <img src="/images/ppp/country-percentages.png" alt="각 국가의 비율과 그 결과 가격이 표시된 Country Prices 대화 상자" style={{ maxHeight: '620px', width: 'auto' }} />
</Frame>

<Note>
이 비율은 business 전체에 적용됩니다. Purchasing Power Parity가 활성화된 모든 제품은 이 비율을 사용합니다.
</Note>
</Step>

<Step title="Turn PPP on for a product">
제품을 엽니다. **Pricing** 섹션에서 **Purchasing Power Parity**를 선택한 다음 제품을 저장합니다.

선택하지 않은 제품은 모든 지역에서 정상 가격을 유지합니다.

<Frame>
  <img src="/images/ppp/product-toggle.png" alt="제품 Pricing 섹션에서 선택된 Purchasing Power Parity" style={{ maxHeight: '440px', width: 'auto' }} />
</Frame>

<Warning>
Adaptive Currency가 비활성화된 상태에서는 이를 선택할 수 없습니다. 먼저 Adaptive Currency를 활성화하세요.
</Warning>
</Step>

<Step title="Confirm at checkout">
<Check>
비율이 100 미만인 국가를 billing country로 지정하여 테스트 checkout을 엽니다. 가격이 인하되어 표시되는지 확인합니다.
</Check>
</Step>
</Steps>

## 가격 계산 방식

국가별 비율은 목록 가격에 곱해집니다:

```
price paid = list price × country percentage ÷ 100
```

India의 고객에게 비율 30을 적용한 \$20.00 제품의 경우:

```
2000 × 30 ÷ 100 = 600   →   $6.00
```

Dodo Payments는 currency conversion 전에 base price에 비율을 적용합니다. 그런 다음 [Adaptive Currency](/features/adaptive-currency)가 결과를 고객의 currency로 변환합니다.

<Info>
Dodo Payments는 checkout에서 고객의 **billing country**를 기준으로 국가를 확인합니다.
</Info>

### 국가별 비율

각 국가에는 **30에서 100 사이**의 비율이 하나씩 지정됩니다:

- **100**은 고객이 전체 가격을 지불한다는 의미입니다. 가격 인하는 없습니다.
- **30**은 설정할 수 있는 가장 낮은 값입니다. 따라서 최대 인하율은 70%입니다.

기본값은 World Bank의 price level index 데이터를 기반으로 합니다. Dodo Payments는 각 값을 가장 가까운 5의 배수로 반올림하고, 최솟값을 30으로 설정하며, 최댓값을 100으로 제한합니다. 지원되는 모든 국가에 값이 지정되어 있으며, 원하는 값으로 변경할 수 있습니다.

범위를 보여주기 위해 기본값 중 일부를 소개합니다:

| Country | Percentage | A \$20 product sells for |
| :--- | :---: | :--- |
| United States | 100 | \$20.00 |
| United Kingdom | 85 | \$17.00 |
| Germany | 75 | \$15.00 |
| Japan | 60 | \$12.00 |
| Brazil | 45 | \$9.00 |
| South Africa | 40 | \$8.00 |
| Philippines | 35 | \$7.00 |
| India | 30 | \$6.00 |

<Note>
전체 목록에는 217개 국가가 포함됩니다. dashboard에서 국가 표를 열어 모든 값을 확인하세요.
</Note>

## API를 통해 활성화

PPP는 제품별로 `purchasing_power_parity` 필드를 사용하여 활성화합니다. 기본값은 `false`입니다.

<Info>
국가별 비율은 dashboard에서만 관리합니다. public API의 일부가 아닙니다.
</Info>

<CodeGroup>

```typescript theme={null}
import DodoPayments from 'dodopayments';

const client = new DodoPayments({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: 'test_mode',
});

const product = await client.products.create({
  name: 'Starter Plan',
  tax_category: 'saas',
  price: {
    type: 'one_time_price',
    currency: 'USD',
    price: 2000,
    discount: 0,
    purchasing_power_parity: true,
  },
});
```

```python theme={null}
import os
from dodopayments import DodoPayments

client = DodoPayments(
    bearer_token=os.environ.get("DODO_PAYMENTS_API_KEY"),
    environment="test_mode",
)

product = client.products.create(
    name="Starter Plan",
    tax_category="saas",
    price={
        "type": "one_time_price",
        "currency": "USD",
        "price": 2000,
        "discount": 0,
        "purchasing_power_parity": True,
    },
)
```

```go theme={null}
package main

import (
	"context"
	"os"

	"github.com/dodopayments/dodopayments-go"
	"github.com/dodopayments/dodopayments-go/option"
)

func main() {
	client := dodopayments.NewClient(
		option.WithBearerToken(os.Getenv("DODO_PAYMENTS_API_KEY")),
	)

	_, err := client.Products.New(context.TODO(), dodopayments.ProductNewParams{
		Name:        dodopayments.F("Starter Plan"),
		TaxCategory: dodopayments.F(dodopayments.ProductNewParamsTaxCategorySaas),
		Price: dodopayments.F[dodopayments.PriceUnionParam](
			dodopayments.PriceOneTimePriceParam{
				Type:                  dodopayments.F(dodopayments.PriceOneTimePriceTypeOneTimePrice),
				Currency:              dodopayments.F(dodopayments.CurrencyUsd),
				Price:                 dodopayments.F(int64(2000)),
				Discount:              dodopayments.F(int64(0)),
				PurchasingPowerParity: dodopayments.F(true),
			},
		),
	})
	if err != nil {
		panic(err)
	}
}
```

</CodeGroup>

<Warning>
business에서 Adaptive Currency가 비활성화된 경우 요청은 `422 ppp_not_enabled_for_business`와 함께 실패합니다. 먼저 활성화하세요.
</Warning>

## 주요 동작

| Behavior | Detail |
| :--- | :--- |
| **Adaptive Currency 필요** | Adaptive Currency가 비활성화된 동안 PPP는 작동하지 않습니다. |
| **기본적으로 비활성화** | 모든 가격은 `purchasing_power_parity: false`에서 시작합니다. |
| **Localized prices 우선** | 일치하는 [Localized Pricing](/features/localized-pricing) 규칙이 있는 제품에는 PPP가 적용되지 않습니다. 설정한 정확한 금액이 적용됩니다. |
| **conversion 전에 적용** | 비율은 base price에 적용됩니다. Adaptive Currency가 결과를 변환합니다. |
| **discount 전에 적용** | [discount code](/features/discount-codes)는 인하된 가격에 적용되므로 두 인하가 함께 적용됩니다. |
| **usage-based 제품에는 fixed fee에만 적용** | PPP는 usage-based 제품의 fixed fee에 적용되며, metered usage에는 적용되지 않습니다. |
| **Pay What You Want에는 적용되지 않음** | 고객이 금액을 선택하므로 PPP가 적용되지 않습니다. [Pay What You Want](/features/pay-what-you-want)를 참조하세요. |
| **비율 범위** | 국가별 비율은 30에서 100 사이입니다. 최대 인하율은 70%입니다. |
| **전용 webhook 없음** | 인하된 금액은 다른 가격과 마찬가지로 payment 또는 subscription에 표시됩니다. |

## 모범 사례

- **먼저 한 제품에만 적용하세요.** 전체 catalogue에 적용하기 전에 checkout 가격을 확인하세요.
- **할인 중첩에 유의하세요.** discount code는 PPP 가격에 추가로 적용됩니다. 국가 비율 30과 20% 코드를 함께 적용하면 목록 가격의 24%가 됩니다.
- **enterprise plan은 제외하세요.** 협의된 plan에는 국가별 조정이 거의 필요하지 않습니다.
- **중요한 경우에는 직접 값을 설정하세요.** 기본값은 시작점일 뿐 규칙이 아닙니다.
- **subscription에 미치는 영향을 확인하세요.** 인하된 가격으로 가입한 subscriber는 해당 가격으로 갱신됩니다.
