[ParityDeals](https://www.paritydeals.com/) 및 [Evendeals](https://www.evendeals.com/integrations/dodo-payments)은 고객의 지리적 위치를 기반으로 자동으로 가격을 최적화하는 플랫폼으로, 일반적으로 "구매력 평가 절하"(PPP) 가격으로 알려져 있습니다.

<Info>
Dodo Payments 상점에서 직접 할인 배너를 삽입할 수는 없지만 (사용자 정의 스크립트가 지원되지 않기 때문), 여전히 자신의 웹사이트나 애플리케이션에서 이러한 도구들을 효과적으로 구현할 수 있습니다.
</Info>

## 통합 선택하기

두 플랫폼 모두 Dodo Payments와 직접 통합되어 할인 코드를 자동으로 생성하고 관리합니다. 아래의 비교를 사용하여 귀하의 요구에 가장 적합한 도구를 선택하십시오.

| 기능 | ParityDeals | Evendeals |
| :--- | :---: | :---: |
| PPP / 위치 기반 가격 | 예 | 예 |
| 휴일 / 시간 기반 거래 | 예 | 아니요 |
| 구독 지원 | 예 | 예 |
| 자동 쿠폰 갱신 | — | 예 |
| 배너 커스터마이징 | 예 | 아니요 |
| 가격 | [가격 보기](https://www.paritydeals.com/pricing/) | [가격 보기](https://www.evendeals.com/pricing) |

## ParityDeals

ParityDeals가 웹사이트에 통합될 경우, 적격 방문자는 체크아웃 시 사용할 수 있는 위치 기반 할인 코드를 포함한 배너를 보게 됩니다. 이러한 할인 코드는 ParityDeals에 의해 자동으로 생성 및 관리되며, **Dodo Payments 대시보드**에 있는 **Sales → Discounts**에 나타납니다.

### 추가 기능

ParityDeals를 통해 연중 [자동 시간 기반 할인](https://www.paritydeals.com/features/time-based-discounts/) 및 [휴일 기반 프로모션](https://www.paritydeals.com/features/holiday-based-discounts/)을 제공할 수 있습니다. 더 자세한 정보는 [ParityDeals Documentation](https://www.paritydeals.com/docs/)를 참조하세요.

## Evendeals

[Evendeals](https://www.evendeals.com/integrations/dodo-payments)는 또 다른 플랫폼으로, Dodo Payments와 통합되어 위치 기반 구매력 평가 절하 가격을 제공합니다. 일회성 및 구독 제품 모두를 지원합니다.

<Frame>
  <img src="/images/ppp/evendeals-hero.png" alt="Evendeals Dodo Payments 통합 개요" />
</Frame>

### 주요 기능

- **자동 쿠폰 동기화** — 쿠폰은 Dodo Payments에 자동으로 생성 및 관리됩니다
- **비율 할인** — 국가 그룹별로 비율 할인 제공
- **구독 지원** — 구독 청구 주기에 따라 할인이 적용됩니다
- **자동 갱신 규칙** — 남용 방지를 위해 시간 간격, 사용 횟수, 조회수에 따라 쿠폰 코드를 자동으로 회전시킵니다

<Info>
Evendeals에 의해 생성된 할인 코드는 Dodo Payments 대시보드의 Sales → Discounts에 자동으로 나타납니다.
</Info>
