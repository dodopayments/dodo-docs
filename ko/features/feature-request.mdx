저희는 [피드백 포털](https://feedback.dodopayments.com/)을 통해 기능 요청을 관리하고 공개 로드맵을 유지합니다. 이 플랫폼에서는 아이디어를 제출하고, 보고 싶은 기능에 투표하고, 향후 개선 사항의 개발 상태를 추적할 수 있습니다.

<Card title="Visit Our Public Roadmap" icon="external-link" href="https://feedback.dodopayments.com/">
모든 기능 요청을 보고, 아이디어에 투표하고, 피드백 포털에서 제품 로드맵을 추적하세요.
</Card>

## **새로운 기능 요청하기**

Dodo Payments의 경험을 향상시킬 수 있는 기능 아이디어가 있다면, 피드백 포털에서 직접 기능 요청을 제출할 수 있습니다.

<img src="/images/feature-request/Feature.png" alt="기능 요청" style={{ maxHeight: '500px', width: 'auto' }} />

- **기능 요청 방법**:
    1. 저희 [피드백 포털](https://feedback.dodopayments.com/)에 방문하세요.
    2. **"아이디어 게시"** 또는 **"기능 요청 제출"**을 클릭하세요.
    3. 다음 세부 정보를 제공합니다:
        - **기능 이름**: 기능 아이디어에 대한 간결한 제목.
        - **기능 설명**: 기능의 중요성과 비즈니스에 어떻게 도움이 되는지에 대한 간단한 설명.
    4. 요청을 제출합니다.
- **효과적인 요청을 위한 팁**:
    - 명확하고 간결하게 작성하세요.
    - 기능의 비즈니스 영향을 강조하세요.
    - 가능한 경우 예를 제공하세요.
    - 가치를 보여주는 사용 사례를 포함하세요.

## **기존 기능 요청에 투표하기**

가장 많은 가맹점에 혜택을 주는 기능을 우선시합니다. 피드백 포털에서 기존 기능 요청을 탐색하고 가치 있는 요청에 투표하세요.

- **투표하는 방법**:
    1. 저희 [피드백 포털](https://feedback.dodopayments.com/)에 방문하세요.
    2. 제출된 요청 목록을 탐색하세요.
    3. 지원하는 기능 옆의 **upvote** 버튼(👍)을 클릭하세요.
- **투표의 장점**:
    - 관심 있는 기능의 개발 우선순위에 영향을 미칩니다.
    - 팀이 광범위한 수요가 있는 기능을 식별하는 데 도움이 됩니다.
    - 투표한 기능이 출시되면 알림을 받게 됩니다.

## **제품 로드맵 보기**

공개 로드맵을 통해 기능 개발 상태에 대해 정보를 유지하세요.

- **로드맵 기능**:
    - **계획됨**: 승인되고 개발이 예정된 기능.
    - **진행 중**: 팀에서 현재 작업 중인 기능.
    - **완료됨**: 성공적으로 구현되어 라이브된 기능.
- **액세스 방법**:
    - 저희 [피드백 포털](https://feedback.dodopayments.com/)에 방문하세요.
    - **로드맵** 섹션으로 이동하여 상태별로 기능을 확인하세요.
    - 기능 카테고리와 현재 상태를 탐색하세요.
    - 상태, 카테고리별로 필터링하거나 특정 기능을 검색하세요.

<Tip>
새로운 기능에 대한 업데이트를 받고 중요 아이디어에 투표하려면 저희 [피드백 포털](https://feedback.dodopayments.com/)을 북마크하세요.
</Tip>
