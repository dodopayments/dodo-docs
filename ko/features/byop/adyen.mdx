## Raw 카드 데이터 접근 활성화

Dodo가 Adyen을 통해 결제를 라우팅하기 전에, Adyen 계정에 **raw 카드 데이터 접근**이 활성화되어 있어야 합니다. 이는 PCI DSS 규정을 준수해야만 가능합니다. **Dodo Payments가 귀하를 대신하여 raw 카드 데이터를 처리**하며 **PCI DSS 레벨 1을 준수**하므로, **Dodo Payments의 Compliance Attestation (AOC)**를 Adyen에 제공하면 됩니다 — 귀하의 자체 인증은 필요하지 않습니다.

<Card title="Dodo Payments PCI DSS Attestation of Compliance (AOC)" icon="file-shield" href="https://pub-2a89184e4c954b599464449d23f506bb.r2.dev/dodo-payments-pci-dss-aoc.pdf">
Dodo Payments의 현재 AOC를 다운로드하여 raw 카드 데이터 접근을 활성화하기 위해 Adyen 지원팀에 제출하십시오.
</Card>

가맹점 계정에 대해 raw 카드 접근을 요청하려면 Adyen 지원팀에 문의하고, 위의 AOC를 첨부하세요.

## 필요 사항

**설정 → BYOP**에서 Adyen을 연결하기 위해 Adyen 고객 영역에서 다음 세 가지 값을 수집하십시오:

| 값 | 출처 |
|-------|---------------------|
| **API key** | Developers → API credentials |
| **Merchant Account** | 귀하의 Adyen 가맹점 계정 식별자 |
| **HMAC key** | webhook을 설정할 때 생성됨 |

<Info>
Adyen은 **테스트** (`ca-test.adyen.com`) 자격 증명과 **라이브** (`ca-live.adyen.com`) 자격 증명을 별도로 유지합니다. Dodo에서 설정 중인 모드에 맞는 환경에서 자격 증명을 생성하십시오.
</Info>

## 1단계: API 키 생성

<Steps>
<Step title="Open API credentials">
Adyen 고객 영역에서 **Developers → API credentials**로 이동하십시오. **API 자격 증명 관리** 또는 **가맹점 관리자** 역할이 필요합니다.
</Step>

<Step title="Select your credential">
**Payments** 탭을 선택하고 자격 증명 사용자 이름(예: `ws_123456@Company.YourCompanyAccount`)을 선택하세요.
</Step>

<Step title="Generate the key">
**서버 설정 → 인증**으로 이동하여 **API 키** 탭을 열고 **API 키 생성**을 선택하십시오.
</Step>

<Step title="Copy it immediately">
키를 복사하고 안전하게 저장하십시오. 페이지를 나간 후에는 다시 복사할 수 없습니다. 새로 생성된 키는 즉시 활성화되며, 이전 키는 24시간 동안 계속 작동합니다.
</Step>
</Steps>

## 2단계: 가맹점 계정 찾기

귀하의 **가맹점 계정**은 Adyen이 거래 처리를 위해 사용하는 계정 식별자입니다. 고객 영역 상단의 계정 선택기에 표시됩니다(예: `YourCompany_ECOM`). 이를 Dodo의 **가맹점 계정** 필드에 붙여넣으십시오.

## 3단계: webhook 및 HMAC 키 설정

Dodo는 Adyen 연결을 저장할 때 **Webhook Endpoint** URL을 생성합니다. 이를 Adyen에 webhook으로 추가하고 HMAC 키를 생성하세요. **가맹점 관리자** 또는 **가맹점 기술 통합자** 역할이 필요합니다.

<Steps>
<Step title="Create a webhook">
고객 영역에서 **Developers → Webhooks**로 이동하고 **새 webhook 생성**을 선택합니다. 목록에서 **기본 webhook** 유형에 대해 **추가**를 선택하세요.
</Step>

<Step title="Configure the webhook">
- **설명**을 입력합니다.
- **활성화**를 켜서 활성화하십시오.
- **서버 구성**에서 Dodo가 생성한 **Webhook Endpoint** URL을 **URL** 필드에 붙여넣습니다(이는 HTTPS여야 하며 공개적으로 접근 가능해야 합니다).
</Step>

<Step title="Generate the HMAC key">
**보안**에서, **HMAC 키** 섹션 아래에서 **생성**을 선택하여 새 HMAC 키를 만듭니다. 복사하여 안전하게 저장하십시오. 이후에는 복사할 수 없습니다. 그런 다음 **구성 저장**을 선택하십시오.
</Step>

<Step title="Paste the HMAC key into Dodo">
**설정 → BYOP**으로 돌아가서, HMAC 키를 **Webhook 서명 시크릿** 필드에 붙여넣어 연결을 완료하십시오.

<Card title="Set up BYOP" icon="shuffle" href="/features/byop">
전체 Bring Your Own Processor 설정 흐름을 따르십시오.
</Card>
</Step>
</Steps>

<Tip>
저장한 후, Dodo에서 **연결 확인**을 사용하여 Adyen에 대한 테스트 호출을 실행하고 API 키, 가맹점 계정 및 HMAC 키가 유효한지 확인하십시오. 라이브로 전환하기 전에 확인하십시오.
</Tip>

## 자주 묻는 질문

<AccordionGroup>
<Accordion title="What is the HMAC key for?">
Adyen은 각 webhook에 대해 HMAC 서명을 사용하여 수신자가 알림의 무결성과 출처를 확인할 수 있도록 합니다. Dodo는 귀하가 제공한 HMAC 키를 사용하여 Adyen 계정에서 보낸 webhook을 검증합니다.
</Accordion>

<Accordion title="I lost my API key or HMAC key, what now?">
생성 후에는 어느 것도 검색할 수 없습니다. **Developers → API credentials**에서 새 API 키를 생성하거나 webhook 설정에서 새 HMAC 키를 생성한 다음 **설정 → BYOP**에서 값을 업데이트하십시오.
</Accordion>

<Accordion title="Do test and live use the same credentials?">
아니요. 일치하는 환경에서 자격 증명을 생성하고, 테스트(`ca-test.adyen.com`) 또는 라이브(`ca-live.adyen.com`) 모드에서 Dodo에 해당 모드를 구성하십시오.
</Accordion>
</AccordionGroup>
