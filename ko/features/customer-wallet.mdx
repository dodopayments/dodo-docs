## 고객 지갑이란?

고객 지갑은 사용자를 위한 실제 자금을 보관하는 금전 잔액 계정입니다. 고객 계정을 생성하면 모든 고객에게 지갑이 자동으로 생성됩니다. 다음과 같은 용도로 지갑을 사용할 수 있습니다:

- 향후 구독 결제를 위한 **선불 자금 보관**
- 카드 환불 대신 지갑 잔액으로 **환불 처리**
- 가입 보너스나 로열티 보상과 같은 **프로모션 잔액 지급**
- 청구 중 **지갑 자금을 청구서에 자동 적용**
- 상세 원장 내역으로 **금전 거래 추적**

<Info>
고객 계정을 생성하면 모든 고객에게 지갑이 자동으로 생성됩니다. 지갑은 USD와 INR 통화를 지원하며, 각 통화별로 별도의 금전 잔액을 보관합니다.
</Info>

<Warning>
**고객 지갑 ≠ Credit-Based Billing**

고객 지갑은 청구서와 구독 결제에 적용할 수 있는 **실제 금전 잔액**(USD, INR)을 보관합니다.

가상 사용 단위(API 호출, 토큰, 컴퓨팅 시간)를 추적하려는 경우에는 대신 [Credit-Based Billing](/features/credit-based-billing)을 참조하세요.
</Warning>

## 작동 방식

고객 지갑에는 고객이 구매에 사용할 수 있는 자금이 보관됩니다. 고객에게 청구서나 반복 구독 요금이 발생하면 먼저 지갑 잔액을 확인합니다. 사용 가능한 자금이 있으면 기본 결제 수단으로 청구하기 전에 해당 자금이 청구서에 자동으로 적용됩니다.

### 자동 설정

새 고객을 생성하면 Dodo Payments 자동으로 잔액이 0인 지갑을 생성합니다. 지갑은 API를 통해 즉시 자금을 받을 수 있는 상태가 됩니다.

### 다중 통화 지원

각 지갑은 여러 통화의 잔액을 보관할 수 있습니다:

<ResponseField name="USD Balance" type="integer">
미국 달러 잔액(센트 단위로 저장)
</ResponseField>

<ResponseField name="INR Balance" type="integer">
인도 루피 잔액(파이세 단위로 저장)
</ResponseField>

<Info>
현재 **USD** 및 **INR** 잔액만 사용할 수 있습니다. 더 많은 통화가 곧 추가될 예정입니다.
</Info>

모든 통화에 걸쳐 고객이 보유한 자금의 양을 확인합니다. 구매를 처리하기 전에 사용 가능한 잔액을 확인하거나 애플리케이션 UI에 잔액을 표시할 때 유용합니다.

고객 지갑에 자금을 충전하거나(가입 보너스 또는 환불 잔액 등) 자금을 차감합니다(구독 요금 등). 각 거래에 사유를 입력하여 명확한 감사 추적 기록을 유지할 수 있습니다.

The `entry_type` field uses `'credit'` to add funds to the wallet and `'debit'` to subtract funds from the wallet.

## 실제 사용 사례

### 지갑으로 환불

고객이 환불을 요청하면 기존의 카드 환불을 진행하는 대신 환불 금액을 지갑 잔액에 추가할 수 있습니다. 이렇게 하면 향후 구매를 위해 자금을 생태계 내에 유지할 수 있습니다.

```javascript
async function refundToWallet(customerId, refundAmount, originalPaymentId) {
  await client.customers.wallets.ledgerEntries.create(customerId, {
    amount: refundAmount, // Amount in cents
    currency: 'USD',
    entry_type: 'credit',
    reason: `Refund for payment ${originalPaymentId}`,
    idempotency_key: `refund_${originalPaymentId}`
  });
}
```

### 가입 보너스 / 프로모션 잔액

신규 고객에게 금전으로 된 가입 보너스를 제공하여 첫 구매를 유도합니다.

```javascript
async function addWelcomeBonus(customerId) {
  await client.customers.wallets.ledgerEntries.create(customerId, {
    amount: 1000, // $10.00 promotional balance
    currency: 'USD',
    entry_type: 'credit',
    reason: 'Welcome bonus - $10 promotional balance',
    idempotency_key: `welcome_${customerId}`
  });
}
```

### 지갑 잔액으로 구독 결제

지갑에서 자금을 차감하여 구독 요금 또는 수동 구매 비용을 충당합니다.

```javascript
async function deductForPurchase(customerId, purchaseAmount, purchaseId) {
  try {
    await client.customers.wallets.ledgerEntries.create(customerId, {
      amount: purchaseAmount,
      currency: 'USD',
      entry_type: 'debit',
      reason: `Subscription charge - monthly billing`,
      idempotency_key: `charge_${purchaseId}`
    });
  } catch (error) {
    if (error.status === 400) {
      console.log('Insufficient wallet balance');
    }
  }
}
```

### 선불 청구 시스템

고객이 계정에 미리 자금을 충전하고 시간이 지남에 따라 해당 잔액을 차감해 사용할 수 있도록 합니다.

<Steps>
<Step title="Add Initial Funds">
고객이 입금하면 고객 지갑에 자금을 추가합니다.

```javascript
await client.customers.wallets.ledgerEntries.create(customerId, {
  amount: 5000, // $50.00 deposit
  currency: 'USD',
  entry_type: 'credit',
  reason: 'Account funding - prepaid deposit',
  idempotency_key: `deposit_${paymentId}`
});
```

</Step>

<Step title="Apply Balance to Purchases">
고객이 서비스를 사용하거나 구독을 갱신할 때 잔액에서 차감합니다.

```javascript
await client.customers.wallets.ledgerEntries.create(customerId, {
  amount: 1500, // $15.00 charge
  currency: 'USD', 
  entry_type: 'debit',
  reason: 'Service purchase - monthly subscription',
  idempotency_key: `purchase_${purchaseId}`
});
```

</Step>

<Step title="Monitor Balances">
고객의 잔액이 부족해지고 있는지 확인하여 충전을 유도합니다.

```javascript
const wallets = await client.customers.wallets.list(customerId);
const usdWallet = wallets.items.find(w => w.currency === 'USD');
const balance = usdWallet.balance;

if (balance < 1000) { // Less than $10.00
  // Send low balance notification
  await sendLowBalanceNotification(customerId, balance);
}
```

</Step>
</Steps>

## 권장 사항

### 중복 거래 방지

멱등성 키를 사용하여 동일한 이벤트에 대해 실수로 자금을 두 번 추가하거나 차감하지 않도록 합니다.

```javascript
async function addFundsSafely(customerId, amount, reason) {
  const idempotencyKey = `${reason}_${customerId}_${Date.now()}`;
  
  try {
    const result = await client.customers.wallets.ledgerEntries.create(customerId, {
      amount: amount,
      currency: 'USD',
      entry_type: 'credit',
      reason: reason,
      idempotency_key: idempotencyKey
    });
    
    return { success: true, wallet: result };
  } catch (error) {
    if (error.status === 409) {
      // Transaction already processed
      return { success: true, wallet: null, duplicate: true };
    }
    
    throw error;
  }
}
```

### 청구 전 잔액 확인

지갑에서 대규모 거래를 처리하기 전에 고객에게 충분한 자금이 있는지 확인합니다.

```javascript
async function checkBalanceBeforeOperation(customerId, requiredAmount) {
  const wallets = await client.customers.wallets.list(customerId);
  const usdWallet = wallets.items.find(w => w.currency === 'USD');
  
  if (!usdWallet || usdWallet.balance < requiredAmount) {
    throw new Error('Insufficient funds for this operation');
  }
  
  return usdWallet.balance;
}
```
