## **B2B 거래를 위한 세금 ID 검증**

- 체크아웃 중 **유효한 세금 ID**가 제공되면, 송장에는 다음이 포함됩니다:
    - **고객의 세금 ID**.
- 세금 공제는 고객의 국가에 대한 적용 가능한 규정에 따라 결정됩니다.
- 송장에는 **Dodo Payments의 세금 세부정보**와 거래에 적용된 세금이 포함됩니다.

## **B2C 거래에 대한 세금 처리**

- 유효한 세금 ID가 **제공되지 않은** 거래는 **B2C 거래**로 간주되며, 고객의 국가에 적용되는 세금 규정에 따라 세금이 공제됩니다.
- 송장에는 **Dodo Payments의 세금 세부정보**와 거래에 적용된 세금이 포함됩니다.

## 역전가산세 메커니즘

고객이 입력할 때 세금 ID가 실시간으로 검증됩니다. EU 회원국, 영국, 호주의 경우, 결제 시 형식/체크섬 유효성 검사 **및** 실시간 등록부 조회(VIES, HMRC 및 ABR 각각)를 수행하고 일치하는 경우 등록된 법적 사업 이름을 자동으로 채웁니다. 다른 모든 국가의 경우 형식/체크섬 유효성 검사만 수행됩니다.

다음 **세 가지** 조건이 모두 충족될 때만 송장에 사업 명이 표시됩니다:

1. 거래가 B2B입니다 (`b2b = true`)
2. `tax_id`가 존재합니다
3. 비어 있지 않은 `customer_business_name`를 제공합니다

어떤 조건이라도 충족되지 않으면 고객의 개인 이름이 대신 사용됩니다.

### 결제 시 설정하기

`customer_business_name`를 직접 전달하고/또는 `allow_customer_editing_business_name`를 활성화하여 고객이 결제 페이지에서 세금 ID 옆에 입력하거나 편집할 수 있도록 합니다:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'pdt_abc', quantity: 1 }],
  customer: { email: 'buyer@acme.com' },
  tax_id: 'GB123456789',
  customer_business_name: 'Acme Corp Ltd',
  feature_flags: {
    allow_tax_id: true,
    allow_customer_editing_business_name: true // optional: let the customer edit it
  },
  return_url: 'https://yoursite.com/return'
});
```

| 표면 | 필드 | 비고 |
|---------|-------|-------|
| 결제 세션 | `customer_business_name`, `feature_flags.allow_customer_editing_business_name` | 최대 250자; 플래그 기본값은 `false` |
| 결제 | `customer_business_name` | 최대 250자 |
| 구독 | `customer_business_name` | `PATCH /subscriptions/{subscription_id}`을 통해 설정하거나 삭제합니다 |

<Warning>
`customer_business_name`는 `tax_id` 없이는 설정될 수 없으며, 요청이 거부됩니다. `tax_id`를 지우면 비즈니스 이름도 지워지며, 두 항목은 송장에서 결합되어 있습니다. 주변 공백이 잘리고, 공백만 있는 값은 명시적으로 지운 것으로 처리됩니다.
</Warning>

## **B2C 거래에 대한 세금 처리**

- 유효한 세금 ID가 **제공되지 않은** 거래는 **B2C 거래**로 처리되며, 고객의 국가에 적용되는 세금 규정에 따라 세금이 공제됩니다.
- 송장에는 **Dodo Payments의 세금 세부 정보**와 거래에 적용된 세금이 포함됩니다.

## 역차별 과세 기작

일반적으로 상품 또는 서비스의 공급자는 VAT/서비스세/GST를 지불할 책임이 있습니다. 그러나 수입 및 기타 고지된 공급과 같은 특정 경우에는 고객(수령자)이 역차별 과세 기작에 따라 책임을 집니다. 역차별 과세란 지불 책임이 해당 상품 또는 서비스의 공급자가 아닌 공급받는 수령자에게 있는 것을 의미합니다.

## **역차별 과세 적용성**

- 법률에 의해 적용되는 특정 경우, 세금은 결제 시 공제되지 않으며 거래는 **역차별 과세 기작**의 적용을 받습니다.
- 송장에는 규제 요구사항에 따라 역차별 과세가 적용될 경우 이를 명확하게 표시합니다.
