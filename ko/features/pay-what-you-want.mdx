**원하는 만큼 지불하기(PWYW)**를 사용하면 고객이 판매자가 정한 최소 금액 이상에서 지불할 금액을 직접 결정할 수 있습니다. 고객 참여를 높이고 커뮤니티 지원을 장려하며 디지털 제품에 유연한 가격 책정을 제공할 수 있습니다.

## 원하는 만큼 지불하기란 무엇인가요?

PWYW는 고객이 판매자가 정의한 제한 범위 내에서 가격을 직접 설정하는 가격 모델입니다. 다음과 같은 경우에 적합합니다.

- **디지털 제품 및 미디어**: 템플릿, 전자책, 강좌, 플러그인
- **실험적 출시**: 얼리 액세스, 베타 릴리스, 기간 한정 프로모션
- **번들 및 추가 상품**: 참여를 높이기 위해 PWYW 등급 추가

## 주요 이점

- **고객 주도 가격 책정**: 구매자가 지불할 금액을 선택
- **수익 하한선**: 마진을 보호하기 위해 최소 금액 적용
- **기준점이 있는 기대치**: 선택 사항인 권장 가격으로 선택을 안내
- **원활한 결제**: 호스팅된 결제와 영수증 처리를 자동으로 지원
- **개발자 우선**: 생성, 환불, 웹훅을 위한 명확한 API 제공

<Warning>
PWYW는 **Single Payment**(일회성) 제품에서만 사용할 수 있습니다.
</Warning>

## 원하는 만큼 지불하기 생성

일회성 제품을 생성하고 Dodo Payments 대시보드에서 PWYW를 활성화하세요. 아래 섹션은 생성 양식에 직접 대응합니다.

### 제품 생성

#### 제품 세부 정보

- **제품 이름**(필수): 결제 및 청구서에 표시되는 이름
- **제품 설명**(필수): 고객이 결제 전에 확인할 수 있는 명확한 가치 설명
- **제품 이미지**(필수): 최대 3MB의 PNG/JPG/WebP
- **브랜드**: 테마와 이메일에 사용할 특정 브랜드에 제품 연결
- **세금 카테고리**(필수): 세금 규칙을 결정할 올바른 카테고리 선택

<Tip>
지역별로 정확하게 세금을 징수할 수 있도록 가장 정확한 세금 카테고리를 선택하세요.
</Tip>

#### 가격 책정

- **가격 유형**: <b>Single Payment</b> 선택
- **원하는 만큼 지불하기**(토글): 구매자가 금액을 선택할 수 있도록 활성화
- **최소 가격**(필수): 고객이 지불할 수 있는 가장 낮은 금액
- **권장 가격**(선택 사항): 제품 페이지에 표시되는 추천 금액

<Tip>
메타데이터를 사용하여 시스템의 식별자(예: orderId)를 저장하면 나중에 이벤트와 영수증을 대조할 수 있습니다.
</Tip>

#### 고정 금액으로 링크 공유하기

**Products**에서 PWYW 제품의 checkout 링크를 공유할 때 **Advanced Settings**를 열고 **Payment amount**를 설정하면 구매자가 금액을 선택하는 대신 정확히 해당 금액을 청구할 수 있습니다. 금액은 제품의 Minimum Price 이상이어야 하며, 주요 통화 단위로 링크에 `paymentAmount` query parameter로 전달됩니다(예: $12.50의 경우 `12.5`). 구매자가 금액을 선택하도록 하려면 필드를 비워 두세요.

## 일반적인 사용 사례

- **디지털 자산**: 테마, 템플릿, 아이콘 세트, 미디어 또는 플러그인
- **콘텐츠 및 교육**: 후원자 가격이 적용된 전자책, 강좌, 워크숍
- **커뮤니티 및 기부**: 모금 행사, 오픈 소스 후원, 크리에이터 지원
- **출시 실험**: 수요를 파악하기 위한 베타 액세스 및 기간이 정해진 캠페인

## 통합 예시

### Checkout Sessions (단일 결제, PWYW)
장바구니에 PWYW 제품을 추가합니다. Checkout에서 구매자가 금액을 입력하며(설정한 minimum을 준수), 추가 필드는 필요하지 않습니다.

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'pdt_pwyw_demo', quantity: 1 }
  ],
  return_url: 'https://yoursite.com/checkout/success'
});
```

## 권장 사항

- **합리적인 minimum 선택**: 참여를 쉽게 유지하면서 비용을 충당하세요
- **제안 가격 사용**: 기대치를 설정하여 평균 주문 금액을 높이세요
- **가치를 명확하게 설명**: 구매자에게 자신의 기여로 무엇을 이용할 수 있는지 알려주세요
- **A/B 테스트 캠페인**: 제안 기간을 제한하고 메시지를 실험하세요
- **분포 모니터링**: 결제 금액을 추적하여 minimum 및 제안 가격을 개선하세요

<Info>
PWYW는 수익의 하한선을 유지하면서 더 많은 고객을 초대할 수 있는 유연한 방법입니다. 간단하게 시작하고 철저히 테스트한 후 전환율, 기여 금액 분포 및 환불률을 기준으로 반복 개선하세요.
</Info>
