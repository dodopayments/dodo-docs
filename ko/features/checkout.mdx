## 적응형 통화

적응형 통화는 고객이 선호하는 지역 통화로 결제할 수 있도록 하여 신뢰와 전환율을 향상시킵니다.

### 작동 방식

1. **활성화**: 비즈니스 설정에서 적응형 통화를 활성화합니다.
2. **선택**: 고객은 체크아웃에서 직접 통화를 전환할 수 있습니다.
3. **변환**: 가격은 실시간 FX 환율을 사용하여 동적으로 변환됩니다.
4. **표시**: 최종 지불 금액이 결제 전에 투명하게 표시됩니다.

## 자동 세금 계산

세금은 고객의 청구 위치에 따라 자동으로 계산되어 세금 GST, VAT 및 판매세 요구사항에 대한 규정을 준수합니다.

### 세금 계산 방법

<Steps>
<Step title="위치 감지">
  세금 규칙은 고객의 국가(해당되는 경우 지역)에 따라 적용됩니다.
</Step>

<Step title="동적 업데이트">
  세금 금액은 다음과 같을 때 자동으로 업데이트됩니다:
  - 국가 변경
  - 주소 업데이트
</Step>

<Step title="투명한 표시">
  결제 전 최종 세금 내역이 명확하게 표시됩니다.
</Step>
</Steps>

<Tip>
세금 계산은 완전히 자동화되어 있습니다. 표준 디지털 상품 및 SaaS 제품에 대해 수동 구성은 필요하지 않습니다.
</Tip>

## 사업자 세금 ID 지원

등록된 사업자의 경우, 결제 시 고객이 사업자 세금 ID(예: VAT/GST 번호)를 입력할 수 있습니다.

### 세금 ID가 입력되면 어떤 일이 발생하나요

- 세금 적격성이 실시간으로 검증됩니다.
- 해당 세금 면제 또는 역세금 규칙이 적용됩니다.
- 결제 시 세금 금액이 즉시 업데이트됩니다.

## 할인 코드

고객은 대시보드에서 만든 할인 코드 또는 프로모션 코드를 결제 페이지에서 직접 적용할 수 있습니다.

### 결제 경험

1. 고객이 할인 코드를 입력합니다.
2. 할인이 즉시 검증됩니다.
3. 업데이트된 가격 및 절감액이 명확하게 표시됩니다.

<Frame>
  <img src="/images/checkout/c4.png" alt="Checkout에서 할인 코드 입력" style={{ width: '70%' }}/>

### API 통합

할인 코드를 미리 적용하거나 할인 입력 필드를 활성화합니다:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  discount_code: 'WELCOME20', // Pre-apply a code
  feature_flags: {
    allow_discount_code: true // Show discount input field
  },
  return_url: 'https://yoursite.com/return'
});
```

## 스마트 주소 수집

결제는 더 빠른 완성을 위한 유연한 주소 입력을 지원합니다.

### 사용 가능한 옵션

| 옵션 | 설명 |
|--------|-------------|
| **구글 주소 자동 완성** | 자동 완성 기능으로 빠른 선택 |
| **수동 입력** | 전체 주소에 대한 완전한 제어 |
| **국가 선택** | 세금 및 규정 준수 로직을 추진합니다 |

<Tip>
주소 수집은 속도, 정확성 및 전 세계 범위를 균형 있게 맞추어 전환율을 극대화하면서 규정 준수를 보장합니다.
</Tip>

## 사용자 정의 필드

결제 시 고객으로부터 추가 정보를 수집하기 위해 사용자 정의 양식 필드를 정의할 수 있습니다. 이는 회사 이름, 팀 규모, 추천 출처 또는 기타 비즈니스 특정 정보를 수집하는 데 유용합니다.

### 사용 가능한 필드 유형

| 유형 | 설명 |
|------|-------------|
| `text` | 단일 행 텍스트 입력 |
| `number` | 숫자 입력 |
| `email` | 유효성 검사가 있는 이메일 주소 |
| `url` | 유효성 검사가 있는 URL |
| `date` | 날짜 선택기 |
| `dropdown` | 미리 정의된 옵션에서 선택 |
| `boolean` | 예/아니오 토글 |

### 예시

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '200+']
    }
  ],
  return_url: 'https://yoursite.com/return'
});
```

<Info>
고객 응답은 자동으로 웹후크 페이로드에 포함되며 (`payment.succeeded`, `subscription.created`) 및 API 응답의 `custom_field_responses` 배열을 통해 포함됩니다. 결제 세션당 최대 5개의 사용자 정의 필드를 정의할 수 있습니다.
</Info>

## 컬렉션 결제

제품 컬렉션은 고객이 여러 관련 제품(예: Starter, Pro, Enterprise 플랜)을 한 번의 결제로 보고 선택할 수 있는 통합 결제 경험을 제공합니다.

### 작동 방식

1. **모든 제품 표시**: 고객은 컬렉션의 모든 활성 제품을 봅니다.
2. **첫 번째 제품 미리 선택**: 컬렉션의 첫 번째 제품이 자동으로 선택됩니다.
3. **옵션 비교**: 고객은 선택하기 전에 가격 및 기능을 비교할 수 있습니다.
4. **단일 선택**: 제품을 선택한 후 결제는 표준 결제 흐름으로 진행됩니다.

### 컬렉션 결제 생성

```typescript
const session = await client.checkoutSessions.create({
  product_collection_id: 'pdc_abc123',
  product_cart: [], // Required: pass an empty array for collection checkout
  return_url: 'https://yoursite.com/return'
});
```

<Warning>
`product_collection_id`를 사용할 때 비어 있는 `product_cart` 배열을 전달하십시오. 할인 코드는 세션 생성 시 미리 적용할 수 없습니다.
</Warning>

## 결제 세션 구성

Checkout Sessions API를 사용하여 결제 동작을 제어합니다:

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customer: {
    email: 'customer@example.com',
    name: 'Jane Doe'
  },
  billing_currency: 'EUR', // Set specific currency
  discount_code: 'PROMO10',
  feature_flags: {
    allow_discount_code: true
  },
  return_url: 'https://yoursite.com/return',
  metadata: {
    order_ref: 'ORD-12345'
  }
});
```

<Info>
결제 후 고객은 자동으로 쿼리 매개변수가 추가된 `return_url`로 리디렉션됩니다 -- 여기에는 `payment_id` 또는 `subscription_id`, `status`, `email` 및 `license_key` (해당되는 경우)가 포함됩니다. 전체 목록은 [Checkout Sessions 가이드](/developer-resources/checkout-session#request-body)를 참조하세요.
</Info>

## 결제 테마 사용자 정의

API를 통해 결제 세션을 생성할 때 `customization.theme_config` 매개변수를 사용하여 결제 페이지의 외관을 브랜드에 맞게 사용자 정의할 수 있습니다. 색상, 글꼴, 경계 반경 및 버튼 텍스트를 밝은 모드와 어두운 모드 모두에 대해 구성할 수 있습니다.

<Frame>
  <img src="/images/checkout/theme-example.png" alt="사용자 정의 테마 결제 페이지"/>
</Frame>

<Info>
이 섹션은 `customization.theme_config`을 사용하여 **서버 측 API** 테마 구성을 다룹니다. **Checkout SDK**(오버레이 또는 인라인 결제)를 사용하는 경우 [Overlay Checkout](/developer-resources/overlay-checkout#theme-customization) 또는 [Inline Checkout](/developer-resources/inline-checkout#theme-customization)에서 카멜 케이스 속성을 사용하는 테마 사용자 정의 섹션을 참조하세요 (예: `bgPrimary` 대신 `bg_primary`).
</Info>

### 테마 구성 옵션

| 속성 | 설명 |
|----------|-------------|
| `light` | 밝은 모드의 색상 구성 |
| `dark` | 어두운 모드의 색상 구성 |
| `font_primary_url` | 기본 글꼴의 URL |
| `font_secondary_url` | 보조 글꼴의 URL |
| `font_size` | 글꼴 크기: `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `font_weight` | 글꼴 두께: `normal`, `medium`, `bold`, `extraBold` |
| `radius` | UI 요소의 경계 반경 (예: `4px`, `0.5rem`, `8px`) |
| `pay_button_text` | 지불 버튼의 사용자 정의 텍스트 (예: "구매 완료", "지금 구독") |

### 색상 구성 (밝은/어두운 모드)

각 모드 (`light` 및 `dark`)는 다음 색상 속성을 지원합니다:

| 속성 | 설명 |
|----------|-------------|
| `bg_primary` | 배경 기본 색상 |
| `bg_secondary` | 배경 보조 색상 |
| `text_primary` | 텍스트 기본 색상 |
| `text_secondary` | 텍스트 보조 색상 |
| `text_placeholder` | 텍스트 플레이스홀더 색상 |
| `text_error` | 텍스트 오류 색상 |
| `text_success` | 텍스트 성공 색상 |
| `border_primary` | 경계 기본 색상 |
| `border_secondary` | 경계 보조 색상 |
| `button_primary` | 기본 버튼 배경 색상 |
| `button_primary_hover` | 기본 버튼 호버 색상 |
| `button_secondary` | 보조 버튼 배경 색상 |
| `button_secondary_hover` | 보조 버튼 호버 색상 |
| `button_text_primary` | 기본 버튼 텍스트 색상 |
| `button_text_secondary` | 보조 버튼 텍스트 색상 |
| `input_focus_border` | 입력 포커스 경계 색상 |

<Info>
모든 색상 필드는 표준 CSS 색상 형식을 허용합니다:
- Hex: `#fff`, `#ffffff`, `#ffffffff`
- RGB/RGBA: `rgb(255, 255, 255)`, `rgba(255, 255, 255, 0.5)`
- HSL/HSLA: `hsl(120, 100%, 50%)`, `hsla(120, 100%, 50%, 0.5)`
- 이름이 지정된 색상: `red`, `blue`, `transparent`
</Info>

### 예시

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [
    { product_id: 'prod_abc', quantity: 1 }
  ],
  customization: {
    theme_config: {
      // Custom fonts
      font_primary_url: 'https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap',
      font_size: 'md',
```
