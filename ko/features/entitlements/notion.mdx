<Info>
Notion 권한은 준비한 템플릿을 결제 고객의 Notion 작업 공간에 복제합니다. 고객은 OAuth를 통해 권한을 부여하고 템플릿을 복사할 작업 공간을 선택하며, Dodo Payments가 복제를 처리합니다.
</Info>

## 전달 내용

- 고객에게 OAuth를 통해 Notion workspace를 연결하라는 메시지가 표시됩니다.
- 권한이 부여되면 Dodo Payments는 설정된 template을 고객이 선택한 workspace에 복제합니다.
- 취소해도 복제된 template은 고객의 workspace에 남아 있습니다(Notion은 원격 삭제를 지원하지 않음). 기록을 위해 권한 부여가 `Revoked`로 표시됩니다.

일반적인 사용 사례로는 유료 Notion 템플릿, 생산성 시스템, OS/CRM 템플릿 등이 있습니다.

## 고객 흐름

1. 고객이 checkout을 완료합니다.
2. Dodo Payments는 `Pending` 상태로 권한 부여를 생성하며, 고객이 workspace를 연결할 수 있도록 Notion `oauth_url`을 제공합니다.
3. 고객은 이메일 또는 Customer Portal의 링크를 통해 권한을 부여하고, template을 복제할 workspace를 선택합니다.
4. Dodo Payments가 template을 복제합니다. 권한 부여 상태가 `Delivered`로 변경됩니다.
5. 권한이 취소되면 권한 부여가 `Revoked`로 표시되며, 복제된 사본은 고객의 workspace에 남아 있습니다.

<Note>
Notion은 복제된 페이지를 수신자의 자체 콘텐츠로 의도적으로 취급합니다. Dodo Payments는 취소 시 복사본을 삭제할 수 없습니다.
</Note>

## 필수 구성

| Field | Required | Description |
|---|---|---|
| `notion_template_id` | Yes | 템플릿 ID입니다. 대시보드 선택기가 여기에 입력됩니다. |

## API를 통한 생성

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Study Notes',
  integration_type: 'notion',
  integration_config: {
    notion_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Study Notes",
    integration_type="notion",
    integration_config={"notion_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Study Notes"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeNotion),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigNotionConfigParam{
      NotionTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

[`entitlement_grant.*` webhook events](/developer-resources/webhooks/intents/entitlement-grant) 참고:

- `entitlement_grant.created`에는 Notion `oauth_url`가 포함되어 있습니다.
- 템플릿이 복제되면 `entitlement_grant.delivered`가 실행됩니다.
- 취소 시 `entitlement_grant.revoked`가 실행되며, 고객의 복사본은 그대로 남아 있습니다.

## 문제 해결

<AccordionGroup>
<Accordion title="Customer didn't get the template">
고객이 Notion OAuth를 완료할 때까지 권한 부여는 `Pending` 상태로 유지됩니다. delivery email을 다시 보내세요. OAuth 링크는 1주일 후 만료되며, 그 이후에는 권한 부여를 취소하고 다시 생성할 수 있습니다.
</Accordion>

<Accordion title="Template picker is empty">
소스 템플릿을 소유한 작업 공간과 함께 **Entitlements → Integrations → Notion**에서 Notion을 다시 연결하십시오.
</Accordion>

<Accordion title="Customer wants the template removed after refund">
Notion은 복제된 페이지의 원격 삭제를 허용하지 않습니다. 고객은 자신의 작업 공간에서 복사본을 삭제해야 합니다.
</Accordion>
</AccordionGroup>
