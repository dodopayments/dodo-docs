<Info>
Discord 권한은 결제가 완료되면 고객을 서버에 추가하고 (선택적으로 역할을 할당) 합니다. 취소, 환불, 플랜 변경 시 역할이 자동으로 해제됩니다.
</Info>

## 제공되는 항목

- 고객은 배달 이메일이나 고객 포털의 OAuth 링크를 통해 Discord 계정을 연결합니다.
- 권한을 부여하면 Dodo Payments가 서버에 그들을 추가하거나 기존 멤버십을 찾아 설정한 역할을 할당합니다.
- 특정 역할을 선택하지 않으면 서버 멤버십만 부여됩니다.

이 통합은 유료 커뮤니티, 후원자 특전, 계층화된 접근 채널에 이상적입니다.

## 고객 흐름

1. 고객이 결제를 완료합니다.
2. Dodo Payments는 `pending` 상태로 권한을 생성하고, Discord를 가리키는 `oauth_url`를 생성합니다.
3. 고객은 "Join the Discord" 버튼(OAuth 링크)이 포함된 이메일을 받습니다. 링크는 고객 포털에서도 볼 수 있습니다.
4. 고객이 권한을 부여하면 봇이 고객을 서버에 추가하고 설정된 역할을 할당합니다. 권한은 `delivered`로 이동합니다.
5. 구독이 취소, 일시 중지되거나 만료되거나 상인이 수동으로 해제하면 봇이 역할을 제거하고 권한은 `revoked`로 이동합니다.

<Tip>
Dodo Payments 봇의 역할이 부여한 역할의 **위**에 위치하도록 하십시오. Discord는 봇이 자신의 역할보다 높은 역할을 할당하는 것을 방지합니다.
</Tip>

## 필수 구성

| Field | Required | Description |
|---|---|---|
| `guild_id` | Yes | Discord 서버 ID. 대시보드 선택기가 자동으로 입력합니다. |
| `role_id` | No | 배송 시 할당할 역할입니다. 서버 멤버십 전용 액세스의 경우 생략하세요. |

## API를 통한 생성

<CodeGroup>

```typescript TypeScript theme={null}
import DodoPayments from 'dodopayments';

const client = new DodoPayments({
  bearerToken: process.env['DODO_PAYMENTS_API_KEY'],
  environment: 'test_mode',
});

const entitlement = await client.entitlements.create({
  name: 'Patrons Discord Role',
  integration_type: 'discord',
  integration_config: {
    guild_id: '123456789012345678',
    role_id: '987654321098765432',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Patrons Discord Role",
    integration_type="discord",
    integration_config={
        "guild_id": "123456789012345678",
        "role_id": "987654321098765432",
    },
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
```

## Webhooks

[`entitlement_grant.*` 웹훅 이벤트](/developer-resources/webhooks/intents/entitlement-grant)를 구독하여 Discord 권한을 추적합니다:

- 고객이 권한을 부여하도록 하는 `status: "pending"` 및 `oauth_url`로 `entitlement_grant.created`가 실행됩니다.
- 역할이 할당되면 `entitlement_grant.delivered`가 실행됩니다.
- 역할이 제거되면 `entitlement_grant.revoked`가 실행됩니다.

## 문제 해결

<AccordionGroup>
<Accordion title="Customer never sees the role assigned">
권한은 고객이 OAuth 흐름을 완료할 때까지 `pending`에 있습니다. 권한 목록을 확인하고 고객이 OAuth 링크를 클릭했는지 확인하세요. 필요한 경우 배달 이메일을 다시 보냅니다.
</Accordion>

<Accordion title="Grant moves to failed with permission errors">
Dodo Payments 봇이 서버에 남아 있고 `Manage Roles` 권한이 있으며 할당된 역할 위에 위치해 있는지 확인하세요. 권한을 다시 저장하면 검증이 재실행됩니다.
</Accordion>

<Accordion title="Customer cancelled but still has the role">
Discord는 역할 제거를 즉시 전파하지만, 고객의 로컬 Discord 클라이언트가 캐시될 수 있습니다. 그들은 다시 연결하거나 새로고침해야 합니다; 서버 측 상태는 정확합니다.
</Accordion>
</AccordionGroup>
