<Info>
Framer 권한을 사용하면 결제 고객을 위한 Framer 템플릿 remix 링크를 잠금 해제할 수 있습니다. 템플릿을 Dodo Payments에 업로드하고 제품에 권한을 연결하면, 고객은 자신의 Framer 계정으로 템플릿을 복제할 수 있는 remix 링크를 받게 됩니다.
</Info>

## 제공되는 항목

- 업로드한 Framer 템플릿으로 연결되는 고유 remix 링크입니다.
- 고객은 링크를 클릭하여 자신의 Framer workspace로 템플릿을 remix합니다.
- 취소 또는 환불 시 remix 링크가 무효화됩니다.

일반적인 사용 사례로는 유료 Framer 랜딩 페이지 템플릿, 포트폴리오 키트, 컴포넌트 라이브러리 등이 있습니다.

## Framer 연결

Framer는 템플릿 권한을 처음 생성할 때 암시적으로 연결됩니다. 별도의 OAuth 단계는 없습니다.

<Steps>
<Step title="Open Entitlements">
Dodo Payments 대시보드에서 **Entitlements**로 이동한 다음 **+**를 클릭합니다.
</Step>

<Step title="Pick Framer">
통합 항목으로 **Framer Template**을 선택합니다.
</Step>

<Step title="Grab the remix link from Framer">
Framer 프로젝트를 엽니다. 왼쪽 상단 메뉴에서 **File → Copy Remix Link**로 이동합니다. 그러면 누구나 프로젝트를 자신의 Framer 계정으로 복제할 수 있는 공개 remix URL이 생성됩니다. 이 링크를 Dodo Payments이 결제 고객에게 공유합니다.

<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">
<img src="/images/entitlements/framer/copy-remix-link.png" alt="Framer File 메뉴에서 Copy Remix Link 옵션이 강조 표시된 모습" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Add the template and create the entitlement">
다시 Dodo Payments 대시보드로 돌아가 **Template** 드롭다운에서 템플릿을 선택합니다. 새 템플릿에 대해 처음 이 작업을 수행할 때는 복사한 remix 링크를 붙여넣어 등록합니다. 권한에 **name**을 지정하고 **Create Entitlement**를 클릭합니다.

<Frame>
<img src="/images/entitlements/framer/create.png" alt="템플릿 선택기와 이름 필드가 포함된 Framer 템플릿 권한 양식" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Dodo Payments이 템플릿을 등록하고 프로그래밍 방식으로 참조할 수 있는 `framer_template_id`를 반환합니다.
</Step>
</Steps>

## 고객 흐름

1. 고객이 결제를 완료합니다.
2. Dodo Payments이 `pending` grant를 생성하고 해당 고객에게 연결된 고유 remix 링크를 발급합니다.
3. remix 링크가 프로비저닝되면 grant가 `delivered`로 전환되고, 링크가 고객의 이메일과 포털에 포함됩니다.
4. 고객이 링크를 클릭하고 Framer에 로그인한 다음 템플릿을 remix합니다.
5. 취소되면 remix 링크가 무효화됩니다. Framer는 이미 고객의 Framer 계정에 remix된 복사본을 취소할 방법을 제공하지 않으므로 해당 복사본은 유지됩니다.

## 필수 구성

| Field | Required | Description |
|---|---|---|
| `framer_template_id` | Yes | 템플릿을 업로드할 때 반환된 템플릿 ID입니다. |

## API를 통한 생성

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Portfolio Kit',
  integration_type: 'framer',
  integration_config: {
    framer_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Portfolio Kit",
    integration_type="framer",
    integration_config={"framer_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Portfolio Kit"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFramer),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFramerConfigParam{
      FramerTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

[`entitlement_grant.*` webhook events](/developer-resources/webhooks/intents/entitlement-grant)를 참조하세요. Framer grant는 `pending`로 도착하며, remix 링크가 프로비저닝되면 `delivered`로 전환됩니다.

## 문제 해결

<AccordionGroup>
<Accordion title="Customer's remix link doesn't work">
remix 링크는 한 번만 사용할 수 있으며 고객에게 연결됩니다. 고객이 remix하기 전에 링크를 삭제했다면 grant를 취소하고 다시 발급하세요.
</Accordion>

<Accordion title="Refunded customer still has a remixed copy">
이는 정상적인 동작입니다. Framer는 복제된 remix를 고객의 자체 프로젝트로 취급하므로, Dodo Payments은 원본 링크를 무효화하지만 고객 계정에 있는 복사본을 삭제할 수는 없습니다.
</Accordion>
</AccordionGroup>
