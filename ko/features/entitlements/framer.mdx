<Info>
Framer 자격 부여는 유료 고객에게 Framer 템플릿 리믹스 링크를 잠금 해제합니다. 템플릿을 Dodo Payments에 업로드하고 제품에 자격 부여를 연결하면 고객은 해당 템플릿을 자신의 Framer 계정으로 복제하는 리믹스 링크를 받습니다.
</Info>

## 전달 내용

- 업로드한 Framer 템플릿에 대한 고유한 리믹스 링크.
- 고객이 링크를 클릭하여 자신의 Framer 작업 공간으로 템플릿을 리믹스합니다.
- 취소 또는 환불 시 리믹스 링크가 무효화됩니다.

일반적인 사용 사례로는 유료 Framer 랜딩 페이지 템플릿, 포트폴리오 키트 및 구성 요소 라이브러리가 포함됩니다.

## Framer 연결

템플릿 자격 부여를 처음 생성할 때 Framer가 암묵적으로 연결됩니다. 별도의 OAuth 단계는 없습니다.

<Steps>
<Step title="Open Entitlements">
Dodo Payments 대시보드에서 **Entitlements**로 이동하고 **+**를 클릭합니다.
</Step>

<Step title="Pick Framer">
**Framer Template**을 통합으로 선택합니다.
</Step>

<Step title="Grab the remix link from Framer">
Framer 프로젝트를 열고 왼쪽 상단 메뉴에서 **File → Copy Remix Link**로 이동합니다. 이렇게 하면 누구나 프로젝트를 자신의 Framer 계정으로 복제할 수 있는 공개 리믹스 URL이 생성됩니다. 이 링크는 Dodo Payments가 유료 고객과 공유할 것입니다.

<Frame caption="Framer File menu: click Copy Remix Link to copy the template's remix URL.">
<img src="/images/entitlements/framer/copy-remix-link.png" alt="Framer 파일 메뉴의 'Copy Remix Link' 옵션 강조 표시" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>
</Step>

<Step title="Add the template and create the entitlement">
Dodo Payments 대시보드로 돌아가서 **Template** 드롭다운에서 템플릿을 선택합니다. 새로운 템플릿에 대해 처음으로 이렇게 할 때, 복사한 리믹스 링크를 붙여넣어 등록하세요. 자격 부여에 **이름**을 지정하고 **Create Entitlement**를 클릭합니다.
<Step title="Add the template and create the entitlement">

<Frame>
<img src="/images/entitlements/framer/create.png" alt="템플릿 선택기와 이름 입력 필드가 있는 Framer 템플릿 자격 부여 양식" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

Dodo Payments는 템플릿을 등록하고 프로그램적으로 참조할 수 있는 `framer_template_id`를 반환합니다.
</Step>
</Steps>

## 고객 흐름

1. 고객이 결제를 완료합니다.
2. Dodo Payments는 `pending` 권한을 생성하고 고객에게 연결된 고유한 리믹스 링크를 발급합니다.
3. 리믹스 링크가 제공되면 권한이 `delivered`로 전환되며 고객의 이메일과 포털에 링크가 포함됩니다.
4. 고객은 링크를 클릭하고 Framer에 로그인하여 템플릿을 리믹스합니다.
5. 철회할 경우 리믹스 링크가 무효화됩니다. Framer는 이미 리믹스된 복사본을 철회할 수 있는 방법을 제공하지 않으므로 고객의 Framer 계정에 남습니다.

## 필수 구성

| 필드 | 필수 | 설명 |
|---|---|---|
| `framer_template_id` | 예 | 템플릿을 업로드할 때 반환되는 템플릿 ID. |

## API로 생성

<CodeGroup>

```typescript TypeScript theme={null}
const entitlement = await client.entitlements.create({
  name: 'Portfolio Kit',
  integration_type: 'framer',
  integration_config: {
    framer_template_id: 'tmpl_abc123',
  },
});
```

```python Python theme={null}
client.entitlements.create(
    name="Portfolio Kit",
    integration_type="framer",
    integration_config={"framer_template_id": "tmpl_abc123"},
)
```

```go Go theme={null}
client.Entitlements.New(ctx, dodopayments.EntitlementNewParams{
  Name:            dodopayments.F("Portfolio Kit"),
  IntegrationType: dodopayments.F(dodopayments.EntitlementIntegrationTypeFramer),
  IntegrationConfig: dodopayments.F[dodopayments.IntegrationConfigUnionParam](
    dodopayments.IntegrationConfigFramerConfigParam{
      FramerTemplateID: dodopayments.F("tmpl_abc123"),
    },
  ),
})
```

</CodeGroup>

## Webhooks

[`entitlement_grant.*` 웹훅 이벤트](/developer-resources/webhooks/intents/entitlement-grant)를 참조하세요. Framer 권한은 `pending`에 도달하고 리믹스 링크가 제공되면 `delivered`로 전환됩니다.

## 문제 해결

<AccordionGroup>
<Accordion title="Customer's remix link doesn't work">
리믹스 링크는 단일 사용에 국한되며 고객에게 연결됩니다. 리믹스하기 전에 링크를 제거한 경우, 권한을 철회하고 다시 발급하세요.
</Accordion>

<Accordion title="Refunded customer still has a remixed copy">
이는 예상된 결과입니다. Framer는 리믹스된 프로젝트를 고객의 프로젝트로 간주하며, Dodo Payments는 원본 링크를 무효화하지만 고객 계정의 복사본을 삭제할 수 없습니다.
</Accordion>
</AccordionGroup>
