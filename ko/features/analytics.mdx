고객 여정이 상점으로부터 결제 및 구매 완료까지 어떻게 진행되는지 추적합니다. Dodo Payments는 Google Analytics 4, Google Tag Manager 및 Meta Pixel과 통합되어 모든 호스팅 페이지에서 포괄적인 분석을 제공합니다.

<Info>
대시보드에 추적 ID를 추가하면 매장, 체크아웃 페이지, 고객 포털에서 분석 추적이 자동으로 활성화됩니다.
</Info>

<Warning>
고객 브라우저의 광고 차단기가 일부 방문자의 분석 추적 작동을 방해할 수 있습니다.
</Warning>

## 시작하기

<Steps>
<Step title="비즈니스 설정 열기">
  Dodo Payments 대시보드에서 **설정**으로 이동한 후 **분석** 섹션까지 스크롤하세요.
</Step>

<Step title="추적 플랫폼 활성화">
  사용하려는 분석 플랫폼을 토글하여 활성화한 후, 추적 ID를 입력하세요:
  - **Google Analytics**: 측정 ID 입력 (형식: `G-XXXXXXXXXX`)
  - **Google Tag Manager**: 컨테이너 ID 입력 (형식: `GTM-XXXXXXX`)
  - **Meta Pixel**: Pixel ID 입력 (숫자, 10-20 자리)
</Step>

<Step title="설정 저장하기">
  **저장**을 클릭하여 추적 구성을 적용하세요.
</Step>

<Step title="추적 확인">
  매장으로 방문하거나 테스트 체크아웃을 만들어서 이벤트가 분석 대시보드에서 추적되는지 확인하세요.
</Step>
</Steps>

## Google Analytics 4

[Google Analytics 4](https://marketingplatform.google.com/about/analytics/)는 전자상거래 추적 기능을 갖춘 포괄적인 웹 분석을 제공합니다. Dodo Payments 통합으로 매장 탐색부터 구매 완료까지의 전체 고객 여정을 추적할 수 있습니다.

### Google Analytics 측정 ID 추가

1. Google Analytics에서 **관리** → **데이터 스트림**으로 이동하여 웹 스트림 선택
2. **측정 ID**를 복사합니다 (형식: `G-`)
3. Dodo Payments 대시보드에서 **설정** → **분석**으로 이동
4. **Google Analytics**를 활성화하고 측정 ID를 붙여넣습니다
5. **저장** 클릭

<Tip>
Google Analytics 속성이 없으면, [구글의 설정 가이드](https://support.google.com/analytics/answer/9304153)를 따라 하나를 생성하세요.
</Tip>

### Google Analytics에서 추적되는 이벤트

호스팅된 매장 및 체크아웃 페이지에서 다음과 같은 이벤트를 추적합니다. 이벤트 데이터에는 제품 정보, 거래 총액 및 통화가 각각의 이벤트와 함께 전송됩니다.

#### 매장 이벤트

| 이벤트 | 설명 |
|-------|-------------|
| `view_item_list` | 매장 페이지가 제품과 함께 로드될 때 발생 |
| `select_item` | 고객이 체크아웃을 시작하기 위해 제품을 클릭할 때 발생 |

#### 체크아웃 이벤트

| 이벤트 | 설명 |
|-------|-------------|
| `view_item` | 체크아웃 페이지가 로드될 때 발생 |
| `view_cart` | 체크아웃이 로드되고 변형이 선택될 때 발생 |
| `apply_discount`* | 유효한 할인 코드가 성공적으로 적용될 때 발생 |
| `remove_discount`* | 할인 코드가 제거될 때 발생 |
| `add_payment_info` | 고객이 지불 양식을 제출할 때 발생 |
| `purchase` | 지불이 성공적으로 완료될 때 발생 |

<Note>
`apply_discount` 및 `remove_discount`는 [표준 Google Analytics 전자상거래 이벤트](https://support.google.com/analytics/answer/9267735)에 포함되지 않은 사용자 지정 이벤트입니다.
</Note>

### 오버레이/인라인 체크아웃과 GA4 사용

자신의 웹사이트에 통합된 오버레이나 인라인 체크아웃의 Google Analytics 이벤트를 추적하려면 체크아웃이 포함된 웹사이트에 Google Analytics 추적 코드를 설치해야 합니다.

설치가 완료되면, 위에 나열된 모든 추적 이벤트가 자동으로 Google Analytics 계정으로 전송됩니다 - 추가 설정이 필요하지 않습니다.

## Google Tag Manager

[Google Tag Manager](https://marketingplatform.google.com/about/tag-manager/)는 코드를 수정하지 않고도 마케팅 및 분석 태그를 관리할 수 있도록 해줍니다. GTM을 통해 배포된 태그는 모든 Dodo Payments 호스팅 페이지에서 작동합니다.

### GTM 컨테이너 ID 추가

1. Google Tag Manager에서 **컨테이너 ID**를 복사합니다 (형식: `GTM-`)
2. Dodo Payments 대시보드에서 **설정** → **분석**으로 이동
3. **Google Tag Manager**를 활성화하고 컨테이너 ID를 붙여넣습니다
4. **저장** 클릭

<Info>
GTM을 사용할 때, Google Ads 전환과 같은 추가 추적을 GTM 컨테이너 내에서 직접 구성할 수 있습니다. Dodo Payments 통합은 최대 호환성을 위해 GTM 스크립트와 noscript 대체 코드를 주입합니다.
</Info>

### 오버레이/인라인 체크아웃과 GTM 사용

웹사이트에 통합된 오버레이 또는 인라인 체크아웃의 경우, 자신의 사이트에 GTM을 설치하세요. 체크아웃은 GTM 구성 프로그램을 상속하고 임베드된 프레임 내에서 이벤트를 발생시킵니다.

## Meta Pixel

[Meta Pixel](https://www.facebook.com/business/tools/meta-pixel/)는 매장에서 고객 행동을 추적하여 Facebook 및 Instagram 광고 캠페인의 효과를 측정합니다. 광고 클릭부터 구매 완료까지의 전환을 추적하세요.

### Meta Pixel ID 추가

1. [Meta 이벤트 관리자](https://www.facebook.com/events_manager2/)에서 픽셀을 생성하거나 선택합니다.
2. **픽셀 ID**를 복사합니다 (숫자, 일반적으로 15-16 자리)
3. Dodo Payments 대시보드에서 **설정** → **분석**으로 이동
4. **Meta Pixel**을 활성화하고 픽셀 ID를 붙여넣습니다
5. **저장** 클릭

<Tip>
픽셀을 아직 생성하지 않았다면 Meta의 [픽셀 설정 가이드](https://www.facebook.com/business/help/952192354843755)를 따르세요.
</Tip>

### Meta Pixel로 추적되는 이벤트

다음 이벤트를 추적하며, 이는 [Meta 이벤트 관리자](https://www.facebook.com/events_manager2/)에 나타납니다. 이벤트 데이터에는 콘텐츠 ID, 값 및 통화가 포함되어 전송됩니다.

<Note>
이벤트는 Meta 이벤트 관리자에 즉시 나타나지 않을 수 있으며, 수 분의 지연이 있을 수 있습니다.
</Note>

#### 매장 이벤트

| 이벤트 | 설명 |
|-------|-------------|
| `PageView` | 매장 페이지가 로드될 때 발생 |
| `ViewContent` | 매장에 제품과 함께 로드될 때 발생 |
| `InitiateCheckout` | 고객이 체크아웃을 시작하기 위해 제품을 클릭할 때 발생 |

#### 체크아웃 이벤트

| 이벤트 | 설명 |
|-------|-------------|
| `PageView` | 체크아웃 페이지가 로드될 때 발생 |
| `AddToCart` | 체크아웃이 로드되고 변형이 선택될 때 발생 |
| `ApplyDiscount`* | 유효한 할인 코드가 성공적으로 적용될 때 발생 |
| `RemoveDiscount`* | 할인 코드가 제거될 때 발생 |
| `AddPaymentInfo` | 고객이 지불 양식을 제출할 때 발생 |
| `Purchase` | 지불이 성공적으로 완료될 때 발생 |

<Note>
`ApplyDiscount` 및 `RemoveDiscount`는 [Meta의 표준 이벤트](https://developers.facebook.com/docs/meta-pixel/reference#standard-events)에 포함되지 않은 사용자 지정 이벤트입니다.
</Note>

## 전체 이벤트 참조

다음 표는 Google Analytics 4 및 Meta Pixel에서 추적된 모든 이벤트를 보여줍니다:

| 트리거 | GA4 이벤트 | Meta Pixel 이벤트 | 위치 |
|---------|-----------|------------------|----------|
| 매장 페이지 로드 | `view_item_list` | `ViewContent` | 매장 |
| 고객이 제품 클릭 | `select_item` | `InitiateCheckout` | 매장 |
| 체크아웃 페이지 로드 | `view_item` | `AddToCart` | 체크아웃 |
| 장바구니 보기/변형 선택 | `view_cart` | - | 체크아웃 |
| 할인 코드 적용 | `apply_discount` | `ApplyDiscount` | 체크아웃 |
| 할인 코드 제거 | `remove_discount` | `RemoveDiscount` | 체크아웃 |
| 결제 양식 제출 | `add_payment_info` | `AddPaymentInfo` | 체크아웃 |
| 결제 성공 | `purchase` | `Purchase` | 체크아웃 |

</Info>

## 포함된 이벤트 데이터

각 추적 이벤트는 고객 행동을 분석하는 데 도움이 되는 관련 전자상거래 데이터를 포함합니다:

### 제품 데이터
- 제품 ID
- 제품 이름
- 가격
- 통화
- 수량

### 거래 데이터 (구매 이벤트)
- 거래/지불 ID
- 총 금액
- 세금 금액
- 통화
- 적용된 할인

### 고객 데이터
- 고객 ID (재구매 고객의 경우)
- 이메일 (적용 가능한 경우 개인정보 보호를 위해 해시 처리됨)

## 모범 사례

<AccordionGroup>
<Accordion title="통합 테스트">
추적 ID를 추가한 후 매장을 방문하여 테스트 체크아웃을 완료하여 이벤트가 분석 대시보드에 나타나는지 확인하세요. Google Analytics 실시간 보고서나 Meta 이벤트 관리자의 테스트 이벤트 기능을 사용하세요.
</Accordion>

<Accordion title="UTM 매개변수 사용">
마케팅 링크에 UTM 매개변수를 추가하여 어떤 캠페인이 전환을 유도하는지 추적하세요. Dodo Payments는 체크아웃 흐름 전반에서 UTM 매개변수를 보존합니다.
</Accordion>

<Accordion title="전환 목표 설정">
Google Analytics에서 `purchase`에 대한 전환 이벤트를 생성하여 전환율을 추적하세요. Meta 광고 관리에서는 `Purchase` 이벤트를 최적화 목표로 사용하세요.
</Accordion>

<Accordion title="강화된 전자상거래 활성화">
Google Tag Manager를 사용하는 경우, 세부적인 퍼널 분석 및 제품 성능 지표를 위한 강화된 전자상거래 보고서를 설정하는 것을 고려하세요.
</Accordion>
</AccordionGroup>

## 문제 해결

<AccordionGroup>
<Accordion title="Google Analytics에 이벤트가 나타나지 않음">
- 측정 ID가 올바른지 확인하세요 (형식: `G-XXXXXXXXXX`)
- Google Analytics 실시간 보고서를 확인하세요 - 이벤트는 여기에서 가장 먼저 나타납니다
- Dodo Payments 설정에서 토글이 활성화되어 있는지 확인하세요
- 처리 지연이 있을 수 있으므로 몇 분 기다려보세요
- 광고 차단기를 배제하기 위해 시크릿 모드에서 테스트하세요
</Accordion>

<Accordion title="Meta 이벤트 관리자에 이벤트가 나타나지 않음">
- 픽셀 ID가 올바른지 확인하세요 (숫자, 10-20 자리)
- Meta Pixel Helper 브라우저 확장자를 사용하여 디버그하세요
- 이벤트 관리자에서 테스트 이벤트 탭을 확인하세요
- 이벤트가 나타나기까지 몇 분 걸릴 수 있습니다
- 테스트하는 동안 광고 차단기가 꺼져 있는지 확인하세요
</Accordion>

<Accordion title="GTM 태그가 실행되지 않음">
- 컨테이너 ID가 올바른지 확인하세요 (형식: `GTM-XXXXXXX`)
- GTM 미리보기 모드를 사용하여 태그 실행을 디버그하세요
- GTM 컨테이너에서 트리거가 올바르게 구성되었는지 확인하세요
- 컨테이너가 퍼블리시 상태인지 확인하세요 (초안 상태가 아님)
</Accordion>

<Accordion title="오버레이/인라인 체크아웃이 추적되지 않음">
- 먼저 자신의 웹사이트에 추적 코드를 설치하세요
- 체크아웃 오버레이가 열리기 전까지 추적이 로드되도록 하세요
- 브라우저 콘솔에서 JavaScript 오류를 확인하세요
- GA4를 사용하는 경우 교차 도메인 추적이 구성되어 있는지 확인하세요
</Accordion>

<Accordion title="구매 이벤트가 잘못된 금액을 표시함">
- 금액은 가장 작은 통화 단위(센트)로 전송됩니다
- 분석 도구가 올바른 통화를 표시하도록 구성되었는지 확인하세요
- 세금이 예상대로 포함/제외되어 있는지 확인하세요
</Accordion>
</AccordionGroup>
