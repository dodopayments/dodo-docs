## 새로운 기능

### 1. **커뮤니케이션 기본 설정**

   개편된 커뮤니케이션 기본 설정으로 알림 수신 방식을 제어하세요. 워크플로우에 맞게 이메일, 푸시 및 인앱 알림을 구성합니다.

   <Frame>
     <img src="/images/communication-preferences/overview.png" alt="커뮤니케이션 기본 설정 개요 - 알림 설정" />
   </Frame>

   **주요 기능**

   - **개편된 이메일 디자인**: 명확한 콜 투 액션과 향상된 가독성을 갖춘 신선하고 현대적인 이메일 템플릿
   - **푸시 알림**: 새로운 판매, 분쟁 및 지급과 같은 중요한 이벤트에 대한 즉각적인 경고를 모바일 장치로 수신
   - **세분화된 제어**: 알림이 트리거되는 이벤트를 정확히 선택하고 어떤 채널로 전달할지 결정
   - **다중 이메일 지원**: 알림을 받을 여러 이메일 주소 추가
   - **고객 이메일 기본 설정**: 고객이 받을 이메일을 구성

   **알림 카테고리**

   | 카테고리 | 설명 |
   |----------|-------------|
   | **판매 및 결제** | 새로운 판매, 성공적인 결제, 실패한 결제 |
   | **지급 및 환불** | 지급 완료, 환불 요청, 환불 완료 |
   | **구독** | 새로운 구독, 갱신, 취소, 계획 변경 |
   | **분쟁** | 분쟁 개설, 증거 요구, 분쟁 해결 |

   <Check>
   결과: 원하는 방식과 시간에 맞춰 제공되는 알림으로 비즈니스에 대한 정보를 유지하세요.
   </Check>

   자세히 알아보기: [커뮤니케이션 기본 설정 가이드](/features/communication-preferences)

### 2. **체크아웃 세션의 사용자 정의 필드**

   체크아웃 동안 고객으로부터 추가 정보를 수집하기 위해 사용자 정의 필드를 사용하세요. 텍스트 입력, 드롭다운, 날짜 등 데이터를 수집하는 데 필요한 항목을 추가합니다.

   **지원되는 필드 유형**

   | 유형 | 설명 | 사용 사례 |
   |------|-------------|----------|
   | `text` | 단일 행 텍스트 입력 | 회사 이름, 주문 메모 |
   | `number` | 숫자 입력 | 수량, 나이 |
   | `email` | 유효성 검사와 함께 이메일 입력 | 청구 연락처 이메일 |
   | `url` | 유효성 검사와 함께 URL 입력 | 웹사이트, 소셜 프로필 |
   | `date` | 날짜 선택기 | 배달 날짜, 이벤트 날짜 |
   | `dropdown` | 미리 정의된 옵션 중 선택 | 사이즈, 색상, 계획 유형 |
   | `boolean` | 예/아니오 값에 대한 체크박스 | 약관 수락, 뉴스레터 신청 |

   **작동 방식**

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     custom_fields: [
       {
         name: 'company_name',
         label: 'Company Name',
         type: 'text',
         required: true
       },
       {
         name: 'team_size',
         label: 'Team Size',
         type: 'dropdown',
         options: ['1-10', '11-50', '51-200', '200+'],
         required: true
       },
       {
         name: 'newsletter',
         label: 'Subscribe to our newsletter',
         type: 'boolean',
         required: false
       }
     ],
     return_url: 'https://yoursite.com/success'
   });
   ```

   **장점**

   - **유연한 데이터 수집**: 이행 또는 개인화에 필요한 모든 정보를 수집
   - **내장된 유효성 검사**: 이메일 및 URL 필드는 입력 형식을 자동으로 검증
   - **필수/선택 제어**: 필요에 따라 필드를 필수 또는 선택으로 표시
   - **웹후크 전송**: 사용자 정의 필드 값은 결제 웹후크 이벤트에 포함됨

   <Info>
   사용자 정의 필드 값은 결제 및 체크아웃 세션 응답 내의 `custom_fields` 객체에서 반환됩니다.
   </Info>

   자세히 알아보기: [체크아웃 세션 사용자 정의 필드](/developer-resources/checkout-session#custom-fields)

### 3. **확장된 체크아웃 언어 지원**

   체크아웃 페이지는 이제 **21개 언어**를 지원하며, 이는 16개에서 증가한 것입니다. 더 많은 고객들이 자신의 모국어로 보다 나은 체크아웃 경험을 할 수 있도록 하세요.

   **새로 추가된 언어**

   | 언어 | 코드 |
   |----------|------|
   | 한국어 | `ko` |
   | 말레이어 | `ms` |
   | 루마니아어 | `ro` |
   | 러시아어 | `ru` |
   | 태국어 | `th` |

   **지원되는 모든 언어**

   아랍어, 중국어, 네덜란드어, 영어, 프랑스어, 독일어, 힌디어, 인도네시아어, 이탈리아어, 일본어, 한국어, 말레이어, 포르투갈어, 루마니아어, 러시아어, 스페인어, 스웨덴어, 태국어, 터키어, 우크라이나어, 베트남어.

   **특정 언어 강제 지정**

   `force_language` 매개변수를 사용하여 자동 언어 감지를 무시할 수 있습니다:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_cart: [{ product_id: 'prod_123', quantity: 1 }],
     force_language: 'ko', // Force Korean language
     return_url: 'https://yoursite.com/success'
   });
   ```

   <Tip>
   기본적으로 체크아웃 페이지는 고객의 브라우저 설정에서 기본 언어를 자동으로 감지합니다. 웹사이트의 언어와 일관성을 유지하려면 `force_language`를 사용하세요.
   </Tip>

   자세히 알아보기: [체크아웃 언어 지원](/features/checkout#supported-languages)
