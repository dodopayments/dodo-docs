## 새로운 기능 🚀

- **주소 자동 완성**: 사용자의 입력에 기반하여 스마트 주소 필드 자동 완성으로 간소화된 결제 프로세스.

    <Frame><img src="/images/changelog/address_autofill.png" alt="Address Autofill" style={{ maxHeight: '500px', width: 'auto' }} /></Frame>

- **알림 센터**: 중요한 시스템 이벤트 및 업데이트를 위한 새로운 전용 알림 탭으로 정보를 유지하세요.

    <Frame><img src="/images/changelog/notifications.png" alt="Notifications" style={{ maxHeight: '500px', width: 'auto' }} /></Frame>

- **결제 링크 쿼리 빌더**: 새로운 시각적 쿼리 빌더를 사용하여 결제 링크를 보다 효율적으로 생성하고 사용자 정의하세요.

    <Frame><img src="/images/changelog/query_selector.png" alt="Query Builder" style={{ maxHeight: '500px', width: 'auto' }} /></Frame>

- **저장된 결제 수단**: 결제 링크 구성에서 `show_saved_payment_methods: true` 값을 설정하여 체크아웃 중 이전에 사용한 결제 수단 표시를 활성화합니다.

- **청구 통화 제어**: `billing_currency` 매개변수를 설정하여 결제 링크에 대해 특정 청구 통화를 적용합니다.

- **개선 사항**: 다양한 개선 사항 및 버그 수정이 포함되었습니다.
