## 신규 기능

### 1. **제품 컬렉션**  
   
   관련 제품을 그룹화하여 고객 포털 내에서 통합된 체크아웃 경험, 플랜 선택 및 원활한 업그레이드/다운그레이드 경로를 제공합니다.

   <Frame>
     <img src="/images/product-collection/checkout-page.png" alt="여러 플랜 옵션을 보여주는 제품 컬렉션 체크아웃 페이지" />
   </Frame>

  **주요 이점**

   - **컬렉션 기반 체크아웃**: 컬렉션에 있는 모든 제품을 하나의 체크아웃 보기로 표시하여 고객이 선호하는 플랜을 비교하고 선택할 수 있도록 합니다.
   - **조직화된 제품 관리**: 관련 제품(예: Starter, Pro, Enterprise)을 단일 컬렉션 아래에 그룹화합니다.
   - **고객 포털 통합**: 고객이 동일한 컬렉션 내에서 제품을 업그레이드하거나 다운그레이드할 수 있게 합니다.
   - **상인 제어**: 각 컬렉션 내에서 제품을 활성화, 비활성화 및 재정렬할 수 있습니다.

   **작동 방식**

   컬렉션의 체크아웃 세션을 생성합니다:

   ```typescript
   const session = await client.checkoutSessions.create({
     product_collection_id: 'pdc_abc123',
     product_cart: [], // Required: pass an empty array for collection checkout
     return_url: 'https://yoursite.com/return'
   });

   // Redirect customer to the checkout
   window.location.href = session.url;
   ```

   <Check>
   결과: 고객이 컬렉션 내에서 사용 가능한 모든 제품을 보고 선택할 수 있는 통합된 체크아웃 경험이 제공됩니다.
   </Check>

   <Info>
   컬렉션 체크아웃은 고객이 구매하기 전에 플랜을 나란히 비교하기를 원하는 구독 비즈니스에 이상적입니다.
   </Info>

   자세히 알아보기: [제품 컬렉션 가이드](/features/product-collections)

### 2. **GBP 통화를 위한 RevolutPay 및 Billie 결제 수단**  
   
   전 세계적으로 GBP 일회성 결제 거래를 위한 RevolutPay 및 Billie의 결제 옵션이 확장되어, 고객에게 더 많은 결제 유연성을 제공합니다.

   **새로운 결제 수단**

   | 결제 수단 | 지원 국가 | 통화 | 구독 지원 |
   |----------|-----------|------|-----------|
   | **RevolutPay** | 전 세계 | GBP | 아니요 (일회성만) |
   | **Billie** | 전 세계 | GBP | 아니요 (일회성만) |

   - **RevolutPay** – 전 세계 Revolut 사용자를 위한 빠르고 원활한 결제
   - **Billie** – B2B 지금 구매하고 나중에 결제하는 솔루션으로 비즈니스가 고객에게 유연한 결제 조건을 제공할 수 있게 합니다.

   <Info>
   이러한 결제 수단은 GBP 거래에 대해 자동으로 사용 가능합니다. 추가 구성이 필요하지 않습니다.
   </Info>

   자세히 알아보기: [결제 방법](/features/payment-methods)

### 3. **체크아웃 세션 미리보기**  
   
   체크아웃 세션을 생성하기 전에 미리보기하여 정확한 가격, 세금, 할인 및 총액을 계산합니다. 고객이 체크아웃을 진행하기 전에 실제 가격을 표시합니다.

   **작동 방식**

   ```typescript
   const preview = await client.checkoutSessions.preview({
     product_cart: [
       { product_id: 'prod_123', quantity: 1 }
     ],
     billing_address: {
       country: 'US',
       state: 'CA',
       zipcode: '94102'
     },
     discount_code: 'SAVE20'
   });

   console.log('Subtotal:', preview.subtotal);
   console.log('Tax:', preview.tax);
   console.log('Discount:', preview.discount);
   console.log('Total:', preview.total);
   ```

   **사용 사례**

   - **맞춤형 가격 표시**: 체크아웃 전에 세금을 포함하여 정확한 총액을 표시합니다.
   - **할인 검증**: 할인 코드를 확인하고 고객에게 절약액을 보여줍니다.
   - **다중 통화 지원**: 다양한 통화로 가격을 미리 봅니다.
   - **장바구니 요약**: 실시간 가격으로 커스텀 장바구니 UI를 만듭니다.

### 4. **계획 변경 요청의 메타데이터 지원**  
   
   구독 계획을 변경할 때 사용자 정의 메타데이터를 전달하여 계획 전환 중 내부 시스템과의 더 나은 추적 및 통합을 가능하게 합니다.

   ```javascript
   // Adding metadata when changing a subscription plan
   await client.subscriptions.changePlan('sub_123', {
     product_id: 'prod_premium',
     proration_billing_mode: 'prorated_immediately',
     quantity: 1,
     metadata: {
       upgrade_reason: 'feature_request',
       previous_plan: 'basic',
       sales_rep: 'john@company.com'
     }
   });
   ```

  **사용 사례**

   - **업그레이드/다운그레이드 이유 추적**: 고객이 플랜을 변경한 이유를 저장합니다.
   - **CRM 레코드 링크**: 계획 변경을 영업 활동과 연결합니다.
   - **내부 분류**: 보고 및 분석을 위해 계획 변경을 태그합니다.
   - **감사 추적**: 계획 변경을 누가 시작했는지에 대한 기록을 유지합니다.

   <Info>
   메타데이터는 웹후크 이벤트에 포함되므로 사용자 정의 데이터로 계획 변경을 쉽게 처리할 수 있습니다.
   </Info>

   자세히 알아보기: [메타데이터 가이드](/api-reference/metadata) | [계획 변경 API](/api-reference/subscriptions/change-plan)

### 5. **결제 응답 및 결제 링크 응답의 `invoice_url` 필드**  
   
   결제 응답 및 결제 링크 응답에 이제 `invoice_url` 필드가 포함되어 각 결제와 관련된 청구서에 직접 접근할 수 있습니다.

   ```json
   {
     "payment_id": "pay_2IjeQm4hqU6RA4Z4kwDee",
     "status": "succeeded",
     "invoice_url": "https://dodopayments.com/invoices/inv_2IsUnWGtRKFLxk7xAQeyt",
     "amount": 9900,
     "currency": "USD",
     // ... other fields
   }
   ```

  **사용 사례**

   - **고객 소통**: 인보이스 링크를 고객에게 직접 보냅니다.
   - **회계 통합**: 회계 소프트웨어에서 결제를 청구서와 연결합니다.
   - **셀프 서비스 포털**: 고객이 쉽게 청구서를 접근할 수 있도록 합니다.
   - **기록 유지**: 청구서 문서에 대한 직접 참조를 유지합니다.

### 6. **코드 이름으로 할인 검증 엔드포인트**  
   
   할인 코드 이름(예: "SAVE20")으로 할인 코드를 검증하고 검색하는 새로운 API 엔드포인트입니다. 체크아웃 시 적용하기 전에 할인 적격성을 확인합니다.

   ```javascript
   // Validate a discount code before checkout
   const discount = await client.discounts.getByCode('SAVE20');

   console.log('Discount type:', discount.type);
   console.log('Discount value:', discount.amount);
   console.log('Valid until:', discount.expires_at);
   ```

  **이점**

   - **체크아웃 전 검증**: 체크아웃 세션을 생성하기 전에 할인 코드를 검증합니다.
   - **실시간 피드백**: 고객에게 코드가 유효한지 여부를 보여줍니다.
   - **오류 처리**: 잘못된 또는 만료된 코드를 조기에 파악합니다.
   - **커스텀 할인 UI**: 즉시 검증이 가능한 할인 코드 입력 필드를 만듭니다.

### 7. **고객, 할인 및 라이센스 키에 대한 향상된 필터링 기능**  
   
   고객, 할인 및 라이센스 키 나열을 위한 새로운 API 필터로 데이터를 프로그래밍 방식으로 찾고 관리하는 것이 더 쉬워졌습니다.

   **고객 API 필터**

   | 필터 | 설명 |
   |--------|-------------|
   | `email` | 고객 이메일로 필터링 |
   | `name` | 고객 이름으로 필터링 (부분 일치, 대소문자 무시) |
   | `created_at_gte` | 이 타임스탬프 이후에 생성된 고객 필터링 |
   | `created_at_lte` | 이 타임스탬프 이전에 생성된 고객 필터링 |

   ```javascript
   // Find customers by name created in the last 30 days
   const customers = await client.customers.list({
     name: 'John',
     created_at_gte: '2026-01-01T00:00:00Z'
   });
   ```

   **할인 API 필터**

   | 필터 | 설명 |
   |--------|-------------|
   | `code` | 할인 코드로 필터링 (부분 일치, 대소문자 무시) |
   | `discount_type` | 할인 유형으로 필터링 (백분율) |
   | `active` | 활성 상태로 필터링 (true = 만료되지 않음, false = 만료됨) |
   | `product_id` | 제품 제한으로 필터링 (이 제품에 적용되는 할인만) |

   ```javascript
   // Find active percentage discounts for a specific product
   const discounts = await client.discounts.list({
     active: true,
     discount_type: 'percentage',
     product_id: 'prod_123'
   });
   ```

   **라이센스 키 API 필터**

   | 필터 | 설명 |
   |--------|-------------|
   | `customer_id` | 고객 ID로 필터링 |
   | `status` | 라이센스 키 상태로 필터링 (`active`, `expired`, `disabled`) |
   | `product_id` | 제품 ID로 필터링 |
   | `created_at_gte` | 이 타임스탬프 이후에 생성된 라이센스 키 필터링 |
   | `created_at_lte` | 이 타임스탬프 이전에 생성된 라이센스 키 필터링 |

   ```javascript
   // Find active license keys for a specific product
   const licenseKeys = await client.licenseKeys.list({
     status: 'active',
     product_id: 'prod_123'
   });
   ```
