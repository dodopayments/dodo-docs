## 새로운 기능

### 1. **버려진 장바구니 복구**

완료되지 않거나 실패한 결제를 자동으로 감지하고 고객을 되돌리기 위한 타겟 이메일 시퀀스를 보냅니다. ACR은 60분 후에 성공하지 못한 결제를 모니터링하고 이를 **결제 실패** 또는 **체크아웃 미완료**로 분류한 후, 시퀀스당 최대 3개의 구성 가능한 복구 이메일을 보냅니다.

<Frame>
<img src="/images/recovery/recovery-analytics.png" alt="버려진 체크아웃 수, 복구율, 회수된 수익을 보여주는 복구 분석 대시보드" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

주요 기능:
- **이메일 두 가지 시퀀스** — 결제 실패와 체크아웃 미완료 각각 최대 3개의 이메일
- **복구 할인** — 복구를 유도하기 위한 단일 사용 할인 코드를 자동 생성하는 옵션
- **고객 복구 페이지** — 고유한 복구 링크가 고객을 구매 완료 전용 페이지로 안내
- **복구 분석** — 버려진 체크아웃 수, 복구율, 회수된 수익, 이메일/제품별 분석 추적

<Tip>
기본 이메일 타이밍(1시간, 24시간, 72시간)을 시작으로 하고 복구 분석 데이터를 기반으로 반복합니다.
</Tip>

자세히 알아보기: [버려진 장바구니 복구](/features/recovery/abandoned-cart-recovery)

### 2. **구독 징수**

만료되거나 취소된 구독을 복구하기 위한 이메일 시퀀스를 자동으로 보냅니다. 구독이 **대기 상태**(결제 실패)이거나 고객 포털에서 고객에 의해 **취소**될 때 징수가 시작됩니다.

주요 기능:
- **이메일 두 가지 시퀀스** — 대기 상태와 취소됨 각각 최대 4개의 이메일
- **자동 청구** — 고객이 결제 방식을 업데이트하면 미지급액이 자동으로 청구됨
- **구성 가능한 타이밍** — 기본 간격은 1일, 3일, 5일, 7일이며 이메일당 완전히 맞춤화 가능

자세히 알아보기: [구독 징수](/features/recovery/subscription-dunning)

### 3. **할인 메타데이터**

이제 API를 통해 생성하거나 업데이트할 때 할인에 **메타데이터**(키-값 쌍)를 첨부할 수 있습니다. 메타데이터를 사용하여 캠페인, 소스 또는 내부 참조에 따라 할인을 태그하고 추적 및 조정할 수 있습니다.

```typescript
const discount = await client.discounts.create({
  type: 'percentage',
  amount: 1500, // 15%
  code: 'SUMMER2025',
  metadata: {
    campaign: 'summer_promo',
    source: 'email_blast'
  }
});
```

자세히 알아보기: [할인 코드](/features/discount-codes) | [Metadata Guide](/api-reference/metadata)

### 4. **복구 웹훅**

복구 라이프사이클을 추적하기 위한 새로운 웹훅 이벤트:

| 이벤트 | 설명 |
|-------|-------------|
| `abandoned_checkout.detected` | 버려진 체크아웃이 감지됨 |
| `abandoned_checkout.recovered` | 고객이 복구 링크를 통해 결제를 완료함 |
| `dunning.started` | 구독에 대해 징수 시도가 시작됨 |
| `dunning.recovered` | 고객이 결제 방식을 업데이트하고 결제가 성공함 |

자세히 알아보기: [Recovery Webhooks](/developer-resources/webhooks/intents/recovery)
