## 새로운 기능

### 1. **현지화된 가격**

이제 고객이 볼 금액을 환율 대신 **통화별 또는 국가별 고정 가격**으로 설정할 수 있습니다. 제품에 `pricing_mode`을 설정하여 활성화한 후, 시장마다 하나의 가격 규칙을 첨부하세요:

<Frame>
<img src="/images/localized-pricing/pricing-section.png" alt="By Country 선택된 제품 양식에서 활성화된 현지화된 가격" style={{ maxHeight: '450px', width: 'auto' }} />
</Frame>

| 모드 | 동작 | 예 |
|------|--------------|---------|
| `by_currency` | 국가에 상관없이 통화당 하나의 고정 가격 | 모든 EUR 결제자에게 **€9.99** 표시 |
| `by_country` | 여러 국가가 통화를 공유하더라도 특정 국가에 대한 가격 | $20 기본 제품이 인도에서 **₹999** |

새로운 `/products/{product_id}/localized-prices` 엔드포인트(생성, 목록, 가져오기, 패치, 보관됨)를 통해 규칙을 관리하세요. 각 규칙의 `amount`은 통화의 최소 단위로 된 정수 — 설정한 가격이며, 변환된 값이 아닙니다.

규칙이 일치하지 않으면 제품은 기존 동작을 유지합니다: 기본 통화의 고객은 기본 가격을 직접 지불하고, 나머지는 Adaptive Currency를 통해 변환됩니다. 규칙이 **일치할** 때, 고객은 설정한 금액을 **정확하게** 지불하며, Adaptive Currency FX 수수료는 추가되지 않고 흡수됩니다.

이것은 **구매력 평등(구매력 패리티, PPP)**, 매혹적인 가격 설정 (€9.99, ¥1000, ₹499), 가역적인 시장 진입 프로모션, 경쟁적 가격 매칭을 실행하는 권장되는 기본 방법입니다.

자세히 알아보기: [Localized Pricing](/features/localized-pricing) | [Adaptive Currency](/features/adaptive-currency) | [Purchasing Power Parity](/features/purchasing-power-parity)

### 2. **새로운 결제 방법: 구독을 위한 Satispay, BLIK 및 Klarna**

세 가지 추가 사항은 유럽에서의 지역 커버리지를 확장하고 반복 청구에 대해 '지금 구매하고 나중에 결제하기' 기능을 가져옵니다.

| 방법 | API 유형 | 지역 | 통화 | 구독 |
|--------|----------|--------|----------|---------------|
| **Satispay** | `satispay` | 유럽 (이탈리아) | EUR | 예 |
| **BLIK** | `blik` | 폴란드 | PLN | 아니오 (일회성) |
| **Klarna** | `klarna` | 미국 | USD | **예 (새로 추가됨)** |

- **Satispay**는 지원 금액 범위 내에서 일회성 및 구독 결제를 위해 EUR 체크아웃 시 나타납니다.
- **BLIK**, 폴란드의 가장 인기 있는 온라인 결제 방법(~60% 시장 점유율), `PLN`로 결제되며, 일회성 결제를 지원합니다.
- **Klarna**는 이제 미국 청구 시 $50 이상 USD 체크아웃에서 **구독**에 사용될 수 있으며 — 이전에는 일회성 결제로 제한되었었습니다.

자세히 알아보기: [European Payment Methods](/features/payment-methods/europe) | [Buy Now, Pay Later](/features/payment-methods/bnpl) | [Payment Methods Overview](/features/payment-methods)

### 3. **기능 플래그 할당량**

새로운 **기능 플래그** 할당량 유형은 Dodo Payments를 청구 인식 기능 플래그 저장소로 전환합니다. `advanced_reports`와 같은 플래그를 제품에 연결하면, 모든 유료 고객은 애플리케이션이 확인할 수 있는 즉시 부여를 받습니다 — 외부 플랫폼, OAuth 또는 실패할 수 있는 전달 단계가 없습니다.

<Frame>
<img src="/images/entitlements/feature-flags/create.png" alt="표시 이름, 기능 ID, 설명 및 메타데이터 키-값 항목이 포함된 새 기능 플래그 양식" style={{ maxHeight: '500px', width: 'auto' }} />
</Frame>

- 구매 시, 부여는 생성되어 곧바로 `delivered`로 이동됩니다. `pending` 단계도, 고객의 행동도 없습니다.
- 부여는 타이핑된 `feature` payload — `{ "feature_type": "boolean", "feature_id": "advanced_reports" }`를 포함하며, 애플리케이션이 `feature_id`를 읽어 무엇을 해제할지 결정합니다.
- 취소, 환불, 수동 취소는 부여를 `revoked`로 이동하며, 플래그는 자동으로 사라집니다.

새로운 **`GET /customers/{customer_id}/entitlement-grants`** 엔드포인트 (상태 및 통합 유형 필터, 페이지 매김 가능)를 사용하여 고객 부여를 읽거나 웹훅을 통해 동기화할 수 있습니다. 할당량 메타데이터는 이제 `string | number | boolean` 스칼라 유니온을 지원하여 플래그와 함께 제한 및 할당량을 첨부할 수 있습니다.

자세히 알아보기: [Feature Flag Entitlement](/features/entitlements/feature-flags) | [Entitlements](/features/entitlements/introduction)

### 4. **Apple Pay 도메인 등록**

이제 대시보드에서 **자신의 도메인**을 직접 등록 및 인증하여, 사이트에 호스팅된 인라인(임베디드) 체크아웃에서 원터치 Apple Pay를 활성화할 수 있습니다.

**설정 → 결제 방법**에서 설정하세요: **Apple Pay** 행에서 **도메인 관리**를 클릭하고, 도메인 연결 파일을 다운로드한 다음, 도메인에 호스팅한 후 등록 및 인증하세요. 도메인 인증은 인라인(임베디드) 체크아웃에만 필요합니다 — 오버레이 체크아웃, 호스팅된 체크아웃 및 결제 링크는 인증이 필요하지 않습니다.

<Info>

</Info>

### 5. **체크아웃 시 편집 가능한 애드온**

새로운 `allow_editing_addons` 기능 플래그는 체크아웃 세션에서 고객이 **구독 제품의 애드온을 추가하거나 제거**할 수 있도록 합니다, 대신 고정된 애드온 세트로 카트를 잠그는 대신에.

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_abc', quantity: 1 }],
  feature_flags: {
    allow_editing_addons: true // customers can edit add-ons at checkout
  },
  return_url: 'https://yoursite.com/return'
});
```

플래그는 기본적으로 `false`로 설정되며 구독 제품에만 적용됩니다. 또한 `GET /checkouts/{id}`에 표시되어 프론트엔드가 특정 세션에 대한 애드온 편집이 활성화되었는지 알 수 있습니다.

자세히 알아보기: [Checkout Session](/developer-resources/checkout-session) | [Add-ons](/features/addons)

## 개선 사항 및 버그 수정

### 6. **`PATCH /subscriptions`로 구독 기간 연장**

`PATCH /subscriptions/{id}`은 이제 `subscription_period_count` 및 `subscription_period_interval`을 허용하여 구독의 현재 기간을 **연장**할 수 있습니다 — 예를 들어 추가 시간을 부여하기 위해. 구독의 만료일(`expires_at`)은 새 카운트 및 간격으로부터 재계산되어 지속됩니다.

<Note>
구독의 기간은 **늘리기만** 할 수 있으며, 줄일 수는 없습니다.
</Note>

자세히 알아보기: [Update Subscription](/api-reference/subscriptions/patch-subscriptions)

### 7. **애드온 이미지 제거**

`PATCH /addons/{id}`는 이제 `image_id: null`을 보내어 애드온의 이미지를 지우는 것을 지원합니다. 명시적인 `null`는 이미지를 제거하며, 필드 생략은 변경되지 않도록 그대로 둡니다 — 제품 및 제품 컬렉션에 사용되는 동일한 규칙과 일치합니다.

자세히 알아보기: [Update Add-on](/api-reference/addons/update-addon)
