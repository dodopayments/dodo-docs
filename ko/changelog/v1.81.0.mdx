## 새로운 기능

### 1. **서드파티 분석 지원**

Google Analytics 4, Google Tag Manager, 및 Meta Pixel을 사용하여 Storefront, Checkout, 및 Customer Portal에서 고객 행동을 추적하세요. **설정 → 분석**에서 추적 ID를 추가하여 전자상거래 이벤트 수집을 시작하세요.

**지원 플랫폼**

| 플랫폼 | ID 형식 |
|----------|-----------|
| Google Analytics 4 | `G-XXXXXXXXXX` |
| Google Tag Manager | `GTM-XXXXXXX` |
| Meta Pixel | 숫자 (10-20자리) |

**추적 이벤트**

`purchase`, `add_payment_info`, `view_item`, 및 `view_item_list`와 같은 이벤트는 고객이 탐색하고 구매를 완료할 때 자동으로 분석 플랫폼으로 전송됩니다.

<Check>
Storefront, 호스팅된 Checkout, 오버레이/인라인 Checkout, 및 Customer Portal에서 지원됩니다.
</Check>

자세히 알아보기: [서드파티 분석](/features/analytics)

### 2. **체크아웃 테마 사용자화**

체크아웃 세션을 생성할 때 `customization.theme_config` 매개변수를 사용하여 체크아웃 외관을 사용자화하세요. 라이트 및 다크 모드 모두에 대해 색상, 글꼴, 경계 반경 및 버튼 텍스트를 구성할 수 있습니다.

**구성 옵션**

| 속성 | 설명 |
|----------|-------------|
| `light` / `dark` | 각 모드에 대한 색 구성표 |
| `font_primary_url` | 사용자 정의 글꼴 URL |
| `font_size` | `xs`, `sm`, `md`, `lg`, `xl`, `2xl` |
| `radius` | 경계 반경 (예: `8px`) |
| `pay_button_text` | 사용자 정의 버튼 텍스트 |

```typescript
const session = await client.checkoutSessions.create({
  product_cart: [{ product_id: 'prod_123', quantity: 1 }],
  customization: {
    theme_config: {
      radius: '8px',
      pay_button_text: 'Complete Purchase',
      light: { button_primary: '#0066ff', text_primary: '#1a1a1a' },
      dark: { button_primary: '#3385ff', text_primary: '#ffffff' }
    }
  },
  return_url: 'https://yoursite.com/return'
});
```

자세히 알아보기: [체크아웃 테마 사용자화](/features/checkout#checkout-theme-customization)

### 3. **결제 실패 시 요금제 변경 방지**

새로운 `on_payment_failure` 매개변수는 결제 실패 시 요금제 변경 동작을 제어합니다.

| 모드 | 동작 |
|------|----------|
| `prevent_change` | 결제가 성공할 때까지 현재 요금제를 유지 |
| `apply_change` | 결제 결과와 관계없이 즉시 요금제 변경 적용 (기본값) |

```typescript
await client.subscriptions.changePlan('sub_123', {
  product_id: 'prod_pro',
  proration_billing_mode: 'prorated_immediately',
  on_payment_failure: 'prevent_change'
});
```

<Tip>
프리미엄 기능에 대한 접근을 보장하기 위해 결제를 확실히 하고 싶다면 `prevent_change`를 사용하세요.
</Tip>

자세히 알아보기: [결제 실패 처리](/developer-resources/subscription-upgrade-downgrade#handling-payment-failures)

## API 업데이트

### 잔고 원장 API

계정의 원장 항목을 필터링 및 페이지 매김하여 조회할 수 있는 새로운 `GET /balances/ledger` 엔드포인트가 추가되었습니다.

| 매개변수 | 설명 |
|-----------|-------------|
| `created_at_gte` / `created_at_lte` | 날짜 범위로 필터링 |
| `event_type` | `payment`, `refund`, `dispute`, `payout` 등으로 필터링 |
| `currency` | 통화 코드로 필터링 |
| `reference_object_id` | 특정 결제/환불/분쟁 ID로 필터링 |

자세히 알아보기: [잔고 원장 API](/api-reference/balance-ledger/list-ledger-entries)

### 결제 응답: `refund_status`

환불이 되었는지 빠르게 확인할 수 있도록 `refund_status` 필드를 `GET /payments/{paymentId}` 응답에 추가했습니다.
