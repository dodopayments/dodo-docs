## 새로운 기능
- **Atlas 오픈 소스 공개**: Dodo Payments 통합을 보여주기 위해 Next.js로 작성된 데모 애플리케이션입니다. [GitHub Repository](https://github.com/dodopayments/dodo-checkout-demo)와 문서 [여기](/developer-resources/integration-guide)를 확인해 보세요.
- **기능 요청 섹션**: 사용자 피드백을 바탕으로 제품 로드맵의 우선순위를 정할 수 있도록 Dodo Payments 대시보드에 기능 요청 섹션을 추가했습니다.
- **Webhook Request Logs API**: Webhook 요청 로그를 조회하고 세부 정보를 확인할 수 있는 API를 추가했습니다.
- **정적 결제 링크**: 결제 프로세스에서 더 많은 유연성을 제공하기 위해 정적 결제 링크에 쿼리 매개변수를 추가했습니다. 자세한 내용은 [여기](/developer-resources/integration-guide#4-static-payment-links)를 클릭하세요.
- **Subscription List API**: 모든 구독을 가져오는 API를 추가했습니다. 자세한 내용은 [API Reference](/api-reference/subscriptions/get-subscriptions-1)를 참조하세요.

## 사소한 개선 사항 및 버그 수정
- 추가 매개변수로 제품 및 구독 API 응답을 향상시켰습니다.
- API 요청에 대한 속도 제한을 구현했으며, 현재 초당 20 요청으로 설정되어 있습니다.
- 문서를 보다 사용자 친화적이고 탐색하기 쉽게 개선했습니다.
- 다양한 사소한 버그 수정 및 개선 사항이 포함되어 있습니다.
