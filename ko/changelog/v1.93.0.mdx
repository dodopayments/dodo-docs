## 새로운 기능

### 1. **체크아웃 재설계**

페이지 전환 시 깜박임을 방지하는 **개선된 로딩 상태**로 체크아웃 경험이 완전히 재설계되었습니다. 이제 고객은 갑작스러운 콘텐츠 이동 대신 매끄러운 스켈레톤 로딩을 볼 수 있어 더욱 다듬어진 결제 경험을 만듭니다.

또한, 이제 **취소 URL 지원**이 가능하여, 고객이 구매를 완료하지 않기로 결정할 경우 사이트로 돌아갈 수 있습니다.

### 2. **순수 수익 분석**

새로운 **순수 수익** 메트릭이 분석 페이지에 추가되어 환불, 분쟁 및 수수료 후 실제 수익을 명확하게 볼 수 있습니다. 기간별 순수 수익 추세를 추적하고 비즈니스 성과를 이해하기 위해 기간 별로 비교하세요.

### 3. **비즈니스 레벨 결제 수단 비활성화**

이제 **비즈니스 레벨에서 특정 결제 수단을 비활성화**할 수 있습니다. 모든 체크아웃 세션에서 고객에게 제공되는 결제 옵션에 대한 세세한 제어가 가능하며, 제품이나 세션 별로 설정할 필요가 없습니다.

### 4. **지급금 내역**

지급 섹션에 **상세한 지급금 내역**이 포함되어 각각의 지급 금액이 어떻게 계산되었는지를 정확히 보여줍니다. 대시보드에서 직접 각 지급금을 구성하는 개별 거래 — 결제, 환불, 분쟁 및 수수료를 볼 수 있습니다.

새로운 **지급 분할 API**도 지급 구성 데이터에 대한 프로그래밍적 접근을 제공합니다.

### 5. **비자 RDR 구성**

### 6. **체크아웃 및 고객 포털의 뒤로 가기 버튼**

체크아웃 세션과 고객 포털에는 이제 **뒤로 가기 버튼**이 포함되어 있어 고객이 진행 상황을 잃지 않고 이전 단계로 이동할 수 있습니다.

### 7. **다음 청구일에 플랜 변경**

구독 플랜 변경은 이제 즉시가 아닌 **다음 청구일에 발효되도록 예약**할 수 있습니다. 특히 다운그레이드의 경우, 고객이 청구 기간이 끝날 때까지 현재 플랜에 대한 액세스를 유지할 수 있어 부드러운 전환 경험을 제공합니다.

더 알아보기: [플랜 변경 API](/api-reference/subscriptions/change-plan)

### 8. **DoNotBill 비례 배분 모드**

구독 플랜 변경에 사용할 수 있는 새로운 `do_not_bill` 비례 배분 모드가 제공됩니다. 이 모드를 사용할 경우, 비례 배분 요금이나 크레딧이 계산되지 않으며 고객은 청구 조정 없이 새 플랜으로 이동합니다.

| 비례 배분 모드 | 동작 |
|----------------|----------|
| `prorated_immediately` | 차이 금액을 즉시 청구하거나 크레딧 제공 |
| `prorated_next_billing` | 다음 청구 주기에 비례 배분 적용 |
| `do_not_bill` | 비례 배분 없음 — 청구 조정 없이 플랜 변경 |

더 알아보기: [구독 업그레이드 및 다운그레이드](/developer-resources/subscription-upgrade-downgrade)

### 9. **고객 결제 수단 삭제**

새로운 API 엔드포인트를 통해 **고객의 저장된 결제 수단을 프로그래밍 방식으로 삭제**할 수 있습니다. API 또는 대시보드를 통해 고객 계정에서 오래되거나 불필요한 결제 수단을 제거하세요.

더 알아보기: [고객 결제 수단](/features/customers)

## 개선 사항

- 대시보드 전체에 걸쳐 **스켈레톤 로딩** 구현으로 빠른 체감 로딩 시간 제공
- 페이지 간 탐색 시 **필터 유지** — 떠났다가 돌아올 때 선택한 필터가 보존됩니다
- 대시보드 뷰 전반에 걸친 데이터 탐색을 용이하게 하는 **맥락적 드릴 다운 탐색** 추가
- 크레딧 기반 청구 플로우 테스트를 위한 **CBB 데모**가 Atlas에 추가됨

## 버그 수정

- 특정 구독 뷰에서 잘못된 만료 시간 표시 수정
- 푸시 알림에 대해 iOS 알림음이 재생되지 않던 문제 수정
