## 테스트 카드 세부정보

Dodo Payments는 다양한 결제 시나리오를 시뮬레이션할 수 있는 테스트 카드 번호 세트를 제공합니다. 이 테스트 카드 번호를 사용하여 실제 결제나 요금을 처리하지 않고 테스트 모드에서 시뮬레이션된 결제를 생성할 수 있습니다.

테스트 카드 번호는 테스트 모드에서만 유효합니다. 실제 결제에 사용하지 마세요.

## 테스트 Afterpay 세부정보

체크아웃 통합을 테스트할 때 Afterpay를 결제 방법으로 선택하고 결제 버튼을 클릭하세요.

### 성공적인 결제
- 성공적인 결제를 위해 유효한 이메일 주소와 배송 주소를 사용하세요.

| 상태 | UPI ID |
| :----- | :----- |
| 성공 | `success@upi` |
| 실패 | `failure@upi` |

**참고**: Afterpay 거래에 필요한 최소 금액은 $50입니다.

- 청구 국가를 `IN`로 설정해야 합니다.
- 통화는 `INR`이어야 합니다.
- 인도 외의 상인을 위한: 적응형 통화가 활성화되어 있어야 합니다.

## 애플 페이 테스트

Dodo Payments 테스트 계정을 사용하여 애플 페이를 테스트할 수 있습니다.

<Info>
애플 페이를 테스트하려면 iPad, iPhone 또는 Mac이 필요합니다. Mac에서는 Safari를 사용하세요.
</Info>

<Steps>
<Step title="Dodo Payments 계정에서 애플 페이 활성화">
Dodo Payments 계정 설정에서 애플 페이를 활성화하세요.
</Step>

<Step title="애플 ID 등록">
아직 애플 ID가 없다면, [애플 ID 등록](https://support.apple.com/apple-id)하세요.
</Step>

<Step title="애플 페이에 카드 최소 1장 추가">
[애플 페이에 카드 최소 1장 추가](https://support.apple.com/HT204506)하세요. 애플 페이를 테스트할 때는 실제 카드 정보를 사용하지만 카드가 청구되지는 않습니다.
</Step>

<Step title="체크아웃 열고 애플 페이 선택">
테스트 모드에서 체크아웃을 열고 결제 방법으로 애플 페이를 선택하세요.
</Step>

<Step title="카드를 선택하고 테스트 구매 완료">
애플 페이 지갑에서 카드를 선택하고 테스트 구매를 완료하세요.
</Step>
</Steps>

<Warning>
Apple Pay가 나타나려면 체크아웃이 `https`를 통해 제공되어야 합니다.
</Warning>

## 구글 페이 테스트

<Step title="인증 실패 테스트">
실패를 시뮬레이션하려면 리디렉션 페이지의 Afterpay 모달 창을 닫으십시오. 결제가 `requires_action`에서 `requires_payment_method`로 전환됩니다.
</Step>
</Steps>

<Info>
구글 페이를 테스트하려면 구글 크롬 또는 안드로이드 기기를 사용해야 합니다.
</Info>

<Steps>
<Step title="Dodo Payments 계정에서 구글 페이 활성화">
Dodo Payments 계정 설정에서 구글 페이를 활성화하세요.
</Step>

<Step title="구글 계정 등록">
아직 구글 계정이 없다면, [구글 계정 등록](https://accounts.google.com/signup)하세요.
</Step>

<Step title="구글 페이에 카드 최소 1장 추가">
[구글 페이에 카드 최소 1장 추가](https://payments.google.com/)하세요. 구글 페이 작업 시 테스트 카드를 사용할 수 있지만, 지갑에 유효한 카드가 최소 1장은 있어야 합니다.
</Step>

<Step title="테스트 카드용 구글 그룹 가입">
[테스트 카드용 구글 그룹 가입](https://groups.google.com/g/googlepay-test-mode-stub-data)하세요. 이는 구글 페이가 Dodo Payments 테스트 모드와 같은 테스트 환경을 감지할 때 자동으로 테스트 카드를 지갑에 추가합니다.
</Step>

<Step title="체크아웃 열고 구글 페이 선택">
테스트 모드에서 체크아웃을 열고 결제 방법으로 구글 페이를 선택하세요.
</Step>

<Step title="구글 페이 테스트 카드 중 하나 선택하고 구매 완료">
지갑에서 구글 페이 테스트 카드 중 하나를 선택하고 테스트 구매를 완료하세요.
</Step>
</Steps>

<Warning>
Apple Pay는 HTTPS가 필요합니다. 적절한 SSL 설정 없이 `localhost`에 나타나지 않습니다. 도메인 검증도 완료되어야 합니다.
</Warning>

## 기타 결제 방법

아마존 페이 및 캐시 앱과 같은 기타 결제 방법을 테스트하려면 일반적인 테스트 절차를 따르세요.

<Steps>
<Step title="테스트 모드 활성화">
Dodo Payments 테스트 API 키를 사용하세요.
</Step>

<Step title="테스트 구매 완료">
Google Pay에서 테스트 카드 중 하나를 선택하여 거래를 완료하세요.
</Step>
</Steps>

### 아마존 페이, 캐시 앱 페이 및 레볼루트 페이

테스트 API 키를 사용하고 표준 체크아웃 흐름을 따르세요. 테스트 거래는 실제 요금 없이 시뮬레이션됩니다.

Apple Pay를 위한 도메인 검증을 포함한 전체 디지털 지갑 문서는 [디지털 지갑](/features/payment-methods/digital-wallets) 페이지를 참조하세요.

## 유럽 방법 테스트

유럽 결제 방법(iDEAL, Bancontact, EPS, Multibanco)은 샌드박스 모드에서 테스트할 수 있습니다.

<Steps>
<Step title="테스트 모드 활성화">
Dodo Payments 테스트 API 키를 사용하세요.
</Step>

<Step title="청구 주소 설정">
결제 방법에 맞게 청구 주소 국가를 설정하십시오:
- iDEAL의 경우 `NL`
- Bancontact의 경우 `BE`
- EPS의 경우 `AT`
- Multibanco의 경우 `PT`
</Step>

<Step title="통화 설정">
유럽 방법은 EUR 통화를 요구합니다.
</Step>

<Step title="테스트 흐름 완료">
테스트 환경에서 시뮬레이션된 은행 인증 흐름을 따르세요.
</Step>
</Steps>

전체 유럽 결제 방법 문서는 [유럽](/features/payment-methods/europe) 페이지를 참조하세요.

## 테스트 모범 사례

<AccordionGroup>
<Accordion title="모든 결제 시나리오 테스트">
성공적인 결제뿐만 아니라 실패, 취소 및 자금 부족과 같은 엣지 케이스도 테스트하세요.
</Accordion>

<Accordion title="웹훅 처리 검증">
웹훅 엔드포인트가 모든 이벤트 유형을 올바르게 처리하는지 확인하십시오. 특히 `payment.succeeded`, `payment.failed`, 및 구독 이벤트.


Dodo Payments CLI를 사용하여 웹훅을 로컬에서 테스트하십시오:
- `dodo wh listen`는 실제 테스트 웹훅을 로컬 서버로 전달합니다.
- `dodo wh trigger`는 모든 22개 이벤트 유형에 대한 모의 페이로드를 전송합니다.
</Accordion>

<Accordion title="실제 장치에서 테스트">
Apple Pay 및 Google Pay는 실제 iOS 및 Android 장치에서 테스트하십시오. 시뮬레이터는 지갑 동작을 완전히 복제하지 않습니다.
</Accordion>

<Accordion title="올바른 주소로 지역 방법 테스트">
지역 결제 방법(UPI, iDEAL 등)은 일치하는 청구 주소가 필요합니다. 미국 청구 주소는 iDEAL을 표시하지 않습니다.
</Accordion>

<Accordion title="최소 금액 검증">
BNPL 방법은 최소 $50.01이 필요합니다. 장바구니 총액에 따라 올바르게 나타나고 숨겨지는지 테스트하십시오.
</Accordion>
</AccordionGroup>
