## Dodo Payments란 무엇인가요?

Dodo Payments는 전 세계에서 출시, 확장 및 수익화를 지원하는 **올인원 엔진**입니다. 차세대 디지털 SaaS 및 AI 제품을 위해 설계되었으며, 별도의 엔지니어링 없이 **결제부터 청구, 유통까지** 모든 것을 처리합니다.

<Info>
**SaaS 및 AI 제품을 위해 구축**: 최적화된 청구 인프라로 일회성 결제, 구독, 크레딧, 좌석, 토큰 또는 모든 사용량 지표를 처리하세요.
</Info>

<Tip>
  <strong>Sentra를 만나보세요: AI 기반 청구 어시스턴트</strong><br/>
  Sentra는 IDE에서 직접 청구 및 결제를 통합하고 분석하며 작업을 수행하는 AI 에이전트입니다. 질문하고, 통합을 구축하거나, 청구 아키텍처를 계획하세요. 원하는 내용을 설명하기만 하면 됩니다.
  <a href="/developer-resources/sentra">
    Sentra 시작하기 &rarr;
  </a>
</Tip>

## 빠른 시작 가이드

몇 단계만 거치면 Dodo Payments를 시작하고 실행할 수 있습니다.

<AccordionGroup>
<Accordion title="For Humans">
  직접 통합을 진행하고 싶으신가요? 아래 단계에서는 5분 이내에 계정을 만들고, 제품을 추가하고, 통합 방법을 선택하는 과정을 안내합니다. no-code 방식에는 코드가 필요하지 않으며, 원하는 경우 주요 언어별 SDK 샘플을 사용할 수 있습니다.

  AI 코딩 어시스턴트에게 통합 스캐폴딩, webhook 핸들러, 구독 플로우 등의 작업을 맡기고 싶다면 VS Code, Cursor 및 Windsurf용 AI 청구 어시스턴트인 **[Sentra](/developer-resources/sentra)**를 설치하세요. 원하는 내용을 설명하면 Sentra가 계획하고, 스캐폴딩하고, 배포합니다.
</Accordion>

<Accordion title="For AI Agents">
  Dodo Payments는 에이전트 네이티브 워크플로를 위해 구축되었습니다. 이 내용을 읽는 LLM이거나 LLM을 구성하는 개발자라면 여기서 시작하세요.

  **설치**. Claude Code, Codex CLI, Cursor 또는 OpenCode의 경우 [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents)이 한 단계로 MCP 서버와 모든 스킬을 연결합니다. 에이전트별 설치 명령은 [AI Coding Agents 가이드](/developer-resources/build-with-ai-coding-agents)를 참조하세요.

  **탐색**. 전체 문서 색인은 [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt)에서 제공되며, URL 끝에 `.md`를 추가하면 모든 문서 페이지를 일반 markdown으로 확인할 수 있습니다(예: `/api-reference/introduction.md`).

  **연결**. 두 개의 MCP 서버를 통해 에이전트가 플랫폼에 실시간으로 액세스할 수 있습니다:

  - **[Dodo Knowledge MCP](/developer-resources/mcp-server#dodo-knowledge-mcp)** - 모든 Dodo 문서에서 시맨틱 검색
  - **[Dodo Payments MCP](/developer-resources/mcp-server)** - API 작업 실행(결제 생성, 구독 관리, 환불 처리)

  전체 클라이언트 구성을 확인하려면 [MCP Server 가이드](/developer-resources/mcp-server)를 참조하세요.

  **확장**. 공식 [Dodo Payments Skills](/developer-resources/agent-skills)을 설치하여 에이전트가 checkout, 구독, 사용량 기반 청구, 크레딧 기반 청구, webhook 등을 처리하는 방법을 학습하도록 하세요:

  ```bash
  npx skills add dodopayments/skills
  ```

  Claude Code, OpenCode, Cursor 및 모든 MCP 호환 에이전트에서 사용할 수 있습니다.
</Accordion>
</AccordionGroup>

<Accordion title="Quick MCP Setup for Cursor/Claude Desktop">
두 서버를 MCP 구성( `~/.cursor/mcp.json` 또는 Claude Desktop 구성)에 추가하세요:

```json
{
  "mcpServers": {
    "dodo-knowledge": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://knowledge.dodopayments.com/mcp"]
    },
    "dodopayments": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://mcp.dodopayments.com/sse"]
    }
  }
}
```

<Info>
Node.js 18 이상이 필요합니다. 지원되는 모든 클라이언트의 자세한 설정 지침은 [MCP Server 문서](/developer-resources/mcp-server)를 참조하세요.
</Info>

### Dodo CLI

터미널에서 Dodo Payments를 관리하세요. Dodo CLI에는 대화형 TUI, 기본 제공 AI 어시스턴트 및 오프라인 webhook 테스트가 포함되어 있습니다. 한 줄로 설치하세요:
