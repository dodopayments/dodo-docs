## API 엔드포인트

| 환경 | 기본 URL | 결제 확인 엔드포인트 |
| --- | --- | --- |
| **테스트 모드** | `https://test.dodopayments.com` | `https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm` |
| **실운영 모드** | `https://live.dodopayments.com` | `https://api.hs.dodopayments.com/payments/<payment_id>/confirm` |

## 단계별 카드 결제 흐름

### 1단계: 클라이언트 시크릿 획득

다음 API를 사용하여 결제를 생성하여 시작하세요:

- **Payments**: [Create Payment API](/api-reference/payments/post-payments)

이 API는 이후 단계에 필요한 **`client_secret`**을 반환합니다.

<Warning>
`POST /payments`은 더 이상 사용되지 않습니다. raw-card 통합에서는 전체 `client_secret`을 반환하는 유일한 endpoint이므로 계속 사용할 수 있지만, 그 외의 모든 일회성 결제 흐름에는 [Checkout Sessions](/api-reference/checkout-sessions/create)을 사용하세요.
</Warning>

### 2단계: 결제 확인

`payments confirm` endpoint를 호출하여 결제를 확인합니다:

- **Test Mode**: `POST https://api.custom.hs.dodopayments.com/payments/<payment_id>/confirm`
- **Live Mode**: `POST https://api.hs.dodopayments.com/payments/<payment_id>/confirm`

요청 본문에 다음 세부 정보를 포함합니다:

- `client_secret`: 1단계의 `client_secret`
- `payment_method`: `card`로 설정
- `payment_method_data`: 카드 및 청구 정보
- `browser_info`: 브라우저별 데이터(user agent, 화면 세부 정보 등)
- `payment_type`: `normal`로 명시적으로 설정(일회성 결제의 경우)

필수 헤더:

- DodoPayments support에서 publishable key를 받습니다.
- `api-key`: publishable key(Dodo Payments Team에서 받음)
- `content-type`: `application/json`

**요청 본문 예시:**

```json
{
  "client_secret": "<client_secret>",

  "payment_method_data": {

      }
    }
  },

    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
```

브라우저 정보는 일반적으로 다음과 같은 형식입니다(실제 값은 다릅니다).

```json
  "language": "en-GB",
  "color_depth": 24,
  "screen_height": 1080,
  "screen_width": 1920,
  "time_zone": -330,
```

가맹점은 checkout 중 고객의 브라우저에서 이러한 세부 정보를 직접 수집해야 합니다.

### 응답 처리

- 응답의 **`status`**가 **`requires_customer_action`**인 경우, 추가 인증을 위해 **`next_action`** 필드에 제공된 URL로 고객을 리디렉션합니다.

<Warning>
raw card 데이터를 처리할 때 PCI compliance guidelines를 준수해야 합니다.
</Warning>

## Apple Pay 통합

Apple Pay를 사용하려면 `payment_method`를 `wallet`로 설정하고 Apple Pay 데이터를 `payment_method_data`에 포함합니다.

### 요청 본문 구조

```json
{
  "client_secret": "<client_secret>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "apple_pay": {
        "payment_data": "<decrypted_payment_data>",
        "payment_method": {
          "display_name": "Visa 1234",
          "network": "Visa",
          "type": "debit"
        },
        "transaction_identifier": "UNIQUE_TRANSACTION_ID_FROM_APPLE"
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Apple Pay 필드 참조

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `payment_data` | string | Yes | 암호화되거나 복호화된 Apple Pay 결제 데이터를 나타내는 데 사용되는 enum입니다. |
| `payment_method.display_name` | string | Yes | Apple Pay 버튼에 표시되는 이름(예: "Visa 1234") |
| `payment_method.network` | string | Yes | 카드 네트워크(예: "Visa", "Mastercard", "Amex") |
| `payment_method.type` | string | Yes | 결제 수단 유형(예: "debit", "credit") |
| `payment_method.card_exp_month` | string | No | 카드 만료 월(예: "12") |
| `payment_method.card_exp_year` | string | No | 카드 만료 연도(예: "25") |
| `transaction_identifier` | string | Yes | Apple Pay의 고유 거래 식별자 |

## Google Pay 통합

Google Pay를 사용하려면 `payment_method`를 `wallet`로 설정하고 Google Pay 데이터를 `payment_method_data`에 포함합니다.

### 요청 본문 구조

```json
{
  "client_secret": "<client_secret>",
  "payment_method": "wallet",
  "payment_method_data": {
    "wallet": {
      "google_pay": {
        "type": "CARD",
        "description": "Visa ending in 1234",
        "info": {
          "card_network": "VISA",
          "card_details": "1234"
        },
        "tokenization_data": {
          "type": "PAYMENT_GATEWAY",
          "token": "<encrypted_payment_token>"
        }
      }
    }
  },
  "browser_info": {
    "user_agent": "<user_agent>",
    "accept_header": "<accept_header>",
    "language": "<language>",
    "color_depth": "<color_depth>",
    "screen_height": "<screen_height>",
    "screen_width": "<screen_width>",
    "time_zone": "<time_zone>",
    "java_enabled": true,
    "java_script_enabled": true,
    "ip_address": "<ip_address_of_client>",
    "device_model": "<device_model>",
    "os_type": "<os_type>",
    "os_version": "<version>"
  },
  "payment_type": "normal"
}
```

### Google Pay 필드 참조

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | string | Yes | 결제 수단 유형(일반적으로 "CARD") |
| `description` | string | Yes | 사용자를 위한 결제 수단 설명 |
| `info.card_network` | string | Yes | 카드 네트워크(예: "VISA", "MASTERCARD", "AMEX") |
| `info.card_details` | string | Yes | 카드 마지막 4자리 |
| `info.assurance_details` | object | No | 인증 보증 세부 정보 |
| `tokenization_data.type` | string | Yes | 토큰화 유형(예: "PAYMENT_GATEWAY") |
| `tokenization_data.token` | string | Yes | Google Pay의 암호화된 결제 토큰 |
