## 개요

FastAPI 보일러플레이트는 Python 백엔드에 Dodo Payments을(를) 통합할 수 있는 프로덕션 준비가 완료된 시작점을 제공합니다. 이 템플릿에는 결제 수락을 빠르게 시작할 수 있도록 checkout session 처리, webhook 검증, Customer Portal 통합 및 비동기 API 패턴이 포함되어 있습니다.

<Info>
이 보일러플레이트는 async/await 패턴을 사용하는 FastAPI, 검증을 위한 Pydantic, 원활한 API 통합을 위한 `dodopayments` Python SDK로 구성되어 있습니다.
</Info>

### 기능

- **빠른 설정** - 5분 이내에 시작
- **비동기 지원** - FastAPI의 기본 async/await 패턴으로 구축
- **Checkout Sessions** - Python SDK를 사용하는 사전 구성된 checkout flow
- **Webhook 처리** - signature verification 기능을 갖춘 보안 webhook endpoint
- **Customer Portal** - 간편한 customer portal session 생성
- **타입 안전성** - 완전한 Pydantic validation 및 type hints
- **환경 구성** - 바로 사용할 수 있는 environment variable 설정

## 사전 요구 사항

시작하기 전에 다음 항목을 준비하세요:

- **Python 3.9+** (권장: Python 3.11+)
- 패키지 관리를 위한 **pip** 또는 **uv**
- **Dodo Payments account** (dashboard에서 API 및 Webhook Keys에 액세스하기 위해 필요)

## 빠른 시작

<Steps>
<Step title="Clone the Repository">

```bash
git clone https://github.com/dodopayments/fastapi-boilerplate.git
cd fastapi-boilerplate
```

</Step>

<Step title="Create Virtual Environment">
격리된 Python 환경을 설정합니다:

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

더 빠른 dependency management를 위해 uv를 사용하는 방법:

```bash
uv venv
source .venv/bin/activate
```

</Step>

<Step title="Install Dependencies">

```bash
pip install -r requirements.txt
```

또는 uv를 사용합니다:

```bash
uv pip install -r requirements.txt
```

</Step>

<Step title="Get API Credentials">
[Dodo Payments](https://dodopayments.com/)에서 가입하고 dashboard에서 자격 증명을 가져옵니다:

- **API Key:** [Dashboard → Developer → API Keys](https://app.dodopayments.com/developer/api-keys)
- **Webhook Key:** [Dashboard → Developer → Webhooks](https://app.dodopayments.com/developer/webhooks)

<Tip>
개발 중에는 **Test Mode**인지 확인하세요!
</Tip>
</Step>

<Step title="Configure Environment Variables">
루트 디렉터리에 `.env` 파일을 생성합니다:

```bash
cp .env.example .env
```

Dodo Payments 자격 증명으로 값을 업데이트합니다:

```bash .env
DODO_PAYMENTS_API_KEY=your_api_key_here
DODO_PAYMENTS_WEBHOOK_KEY=your_webhook_signing_key_here
DODO_PAYMENTS_ENVIRONMENT=test_mode
```

<Warning>
`.env` 파일을 version control에 커밋하지 마세요. 이미 `.gitignore`에 포함되어 있습니다.
</Warning>
</Step>

<Step title="Run the Development Server">

```bash
uvicorn main:app --reload
```

[http://localhost:8000/docs](http://localhost:8000/docs)를 열어 interactive API documentation을 확인하세요!

<Check>
테스트할 수 있는 모든 endpoint가 준비된 FastAPI의 Swagger UI가 표시됩니다.
</Check>
</Step>
</Steps>

## API Endpoint

보일러플레이트에는 다음과 같이 사전 구성된 endpoint가 포함되어 있습니다:

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/checkout` | POST | 새 checkout session 생성 |
| `/webhook` | POST | Dodo Payments webhook 처리 |
| `/customer-portal` | POST | customer portal URL 생성 |

## 코드 예제

### Checkout Session 생성

```python
from fastapi import APIRouter, HTTPException
from dodopayments import AsyncDodoPayments
from pydantic import BaseModel
from config import settings

router = APIRouter()
dodo = AsyncDodoPayments(
    bearer_token=settings.DODO_PAYMENTS_API_KEY,
    environment=settings.DODO_PAYMENTS_ENVIRONMENT
)

class CheckoutRequest(BaseModel):
    product_id: str
    quantity: int = 1
    customer_email: str | None = None
    customer_name: str | None = None

@router.post("/checkout")
async def create_checkout(request: CheckoutRequest):
    try:
        session = await dodo.checkout_sessions.create(
            product_cart=[{
                "product_id": request.product_id,
                "quantity": request.quantity
            }],
            customer={
                "email": request.customer_email,
                "name": request.customer_name
            } if request.customer_email else None,
            return_url="http://localhost:8000/success"
        )
        return {"checkout_url": session.checkout_url, "session_id": session.session_id}
    except Exception as e:
        raise HTTPException(status_code=400, detail=str(e))
```

### Webhook 처리

```python
from fastapi import APIRouter, Request, HTTPException
from standardwebhooks import Webhook
from config import settings

router = APIRouter()
webhook = Webhook(settings.DODO_PAYMENTS_WEBHOOK_KEY)

@router.post("/webhook")
async def handle_webhook(request: Request):
    payload = await request.body()

    # Dodo Payments follows the Standard Webhooks spec: the signature covers
    # `id.timestamp.body`, so all three webhook-* headers must be passed in.
    try:
        webhook.verify(payload, dict(request.headers))
    except Exception:
        raise HTTPException(status_code=401, detail="Invalid signature")

    event = await request.json()
    event_type = event.get("type")
    
    match event_type:
        case "payment.succeeded":
            # Handle successful payment
            payment_id = event["data"]["payment_id"]
            print(f"Payment succeeded: {payment_id}")
            
        case "subscription.active":
            # Handle subscription activation
            subscription_id = event["data"]["subscription_id"]
            print(f"Subscription activated: {subscription_id}")
            
        case "refund.succeeded":
            # Handle refund
            refund_id = event["data"]["refund_id"]
            print(f"Refund processed: {refund_id}")
    
    return {"status": "received"}
```

### Customer Portal 통합

```python
from fastapi import APIRouter, HTTPException
from dodopayments import AsyncDodoPayments
from pydantic import BaseModel
from config import settings

router = APIRouter()
dodo = AsyncDodoPayments(
    bearer_token=settings.DODO_PAYMENTS_API_KEY,
    environment=settings.DODO_PAYMENTS_ENVIRONMENT
)

class PortalRequest(BaseModel):
    customer_id: str

@router.post("/customer-portal")
async def create_portal_session(request: PortalRequest):
    try:
        session = await dodo.customers.customer_portal.create(
            customer_id=request.customer_id,
        )
        return {"portal_url": session.link}
    except Exception as e:
        raise HTTPException(status_code=400, detail=str(e))
```

## Webhook 이벤트

보일러플레이트는 다음과 같은 일반적인 webhook 이벤트 처리를 보여 줍니다:

| Event | Description |
|-------|-------------|
| `payment.succeeded` | 결제가 성공적으로 완료됨 |
| `payment.failed` | 결제 시도 실패 |
| `subscription.active` | Subscription이 활성화됨 |
| `subscription.cancelled` | Subscription이 취소됨 |
| `refund.succeeded` | 환불이 성공적으로 처리됨 |

webhook handler 내부에 비즈니스 로직을 추가하여 다음 작업을 수행하세요:
- 데이터베이스의 사용자 권한 업데이트
- 확인 이메일 전송
- 디지털 제품에 대한 액세스 제공
- 분석 및 지표 추적

## 로컬에서 Webhook 테스트

로컬 개발에서는 [ngrok](https://ngrok.com/)과 같은 도구를 사용하여 로컬 서버를 외부에 노출합니다:

```bash
ngrok http 8000
```

[Dodo Payments Dashboard](https://app.dodopayments.com/developer/webhooks)에서 webhook URL을 업데이트합니다:

```
https://your-ngrok-url.ngrok.io/webhook
```

## 문제 해결

<AccordionGroup>
<Accordion title="Import errors or missing modules">
가상 환경이 활성화되어 있고 dependencies가 설치되어 있는지 확인하세요:

```bash
source venv/bin/activate
pip install -r requirements.txt
```

</Accordion>

<Accordion title="Checkout session creation fails">
**일반적인 원인:**
- 잘못된 product ID - Dodo dashboard에서 존재하는지 확인
- `.env`의 API key 또는 environment 설정 오류
- 자세한 오류 메시지는 FastAPI logs에서 확인
</Accordion>

<Accordion title="Webhooks not receiving events">
로컬 테스트에서는 [ngrok](https://ngrok.com)을 사용하여 서버를 외부에 노출합니다:

```bash
ngrok http 8000
```

[Dodo dashboard](https://app.dodopayments.com/developer/webhooks)에서 webhook URL을 ngrok URL로 업데이트합니다. `.env` 파일을 올바른 webhook verification key로 업데이트하세요.
</Accordion>

<Accordion title="Webhook signature verification fails">
- `.env`에서 `DODO_PAYMENTS_WEBHOOK_KEY`이(가) 올바르게 설정되어 있는지 확인하세요
- signature verification에 raw request body를 사용하고 있는지 확인하세요
- 세 가지 `webhook-id`, `webhook-timestamp` 및 `webhook-signature` 헤더를 모두 `webhook.verify()`에 전달하세요 — Standard Webhooks signature는 body만이 아니라 `id.timestamp.body`을(를) 포함합니다
</Accordion>
</AccordionGroup>
