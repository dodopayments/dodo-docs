Dodo Agent Plugin은 두 개의 MCP 서버와 여덟 개의 통합 기술을 단일 설치로 AI 코딩 에이전트에 연결합니다. **Claude Code**, **Codex CLI**, **Cursor**, **OpenCode**와 함께 작동합니다 — MCP 서버 및 기술 CLI는 MCP 호환 클라이언트와 함께 작동합니다.

{/ LOCKED_PATTERN_6fa96040307d68e9fa44436559d63ee8 /}
**세 가지 기본 요소, 하나의 플러그인.** 에이전트 플러그인은 다음을 포함합니다:
- **API MCP 서버** — 결제, 구독, 고객, 제품, 환불, 라이선스, 사용에 대한 실시간 액세스. 브라우저 OAuth를 통해 인증(로컬 키 불필요).
- **Knowledge MCP 서버** — 모든 Dodo Payments 문서에 대한 의미론적 검색. 자격 증명이 필요하지 않음.
- **여덟 개의 에이전트 기술** — 체크아웃, 구독, 웹훅, 사용량 기반 청구, 크레딧 기반 청구, 라이선스 키, BillingSDK, 모범 사례를 위한 에이전트 로드.
{/ LOCKED_PATTERN_07427f62e4e59df6149fbd24d60de439 /}

## 플러그인 설치

아래에서 코딩 에이전트를 선택하세요. 설치는 두 MCP 서버와 여덟 기술을 자동으로 추가합니다.

{/ LOCKED_PATTERN_3a00efd457b01f610250031fcbf16962 /}
{/ LOCKED_PATTERN_4a8834981e85a0683f67cb5c6c6a23be /}
마켓플레이스에서 설치:

```bash
claude plugins marketplace add dodopayments/dodo-agent-plugin
claude plugins install dodopayments@dodopayments
```

API MCP 서버는 기본적으로 브라우저 OAuth를 사용합니다 — 설치 시 키가 필요하지 않습니다. 에이전트가 처음으로 Dodo 도구를 호출할 때 로그인을 요청받게 됩니다.

{/ LOCKED_PATTERN_0635b8ed40810206be8dda28e5867a17 /}
  소스 코드, 구성 옵션 및 로컬 개발 지침

```bash
codex plugin marketplace add dodopayments/dodo-agent-plugin
codex plugin install dodopayments@dodopayments
```

두 MCP 서버와 여덟 가지 기술이 자동으로 등록됩니다.
{/ LOCKED_PATTERN_aae63d8bf6b6da4ac6fb501e13691e4d /}

{/ LOCKED_PATTERN_7a3a6bd5c5bdae386791b77f66b0ef47 /}
수동 설치 — 플러그인 디렉토리를 Cursor의 로컬 플러그인으로 클론하세요:

```bash
git clone https://github.com/dodopayments/dodo-agent-plugin.git ~/.cursor/plugins/local/dodo-agent-plugin
```

Cursor를 다시 시작하세요. 플러그인은 `.claude/skills/` (Cursor의 Claude Code 호환성 레이어를 통해)에서 기술을 로드하고 `.mcp.json`에서 MCP 서버를 로드합니다.

OpenCode는 npm을 통해 배포합니다. 플러그인을 `opencode.json`에 추가합니다:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"]
}
```

OpenCode를 다시 시작하세요. 두 MCP 서버(`dodopayments-api`, `dodo-knowledge`)가 플러그인의 config hook을 통해 자동으로 등록되며, 설치된 패키지에서 여덟 가지 기술이 자동으로 감지됩니다. 수동 `mcp` 블록이 필요하지 않습니다.

## 얻을 수 있는 것

플러그인이 설치되면, 에이전트는 두 MCP 서버와 여덟 가지 기술에 액세스할 수 있습니다.

### MCP 서버

| 서버 | 목적 | 인증 |
|--------|---------|------|
| `dodopayments-api` | 실시간 API 액세스 — 결제, 구독, 고객, 제품, 환불, 라이선스, 사용 | OAuth (브라우저) |
| `dodo-knowledge` | 모든 Dodo Payments 문서에 대한 의미론적 검색 | 없음 |

두 서버는 `mcp-remote`를 통해 연결되어 모든 MCP 호환 클라이언트에서 실행됩니다.

### 에이전트 기술

| 기술 | 설명 |
|-------|-------------|
| `best-practices` | Dodo Payments와 통합하는 모범 사례에 대한 포괄적 안내 |
| `checkout-integration` | 체크아웃 세션 및 결제 흐름 생성 |
| `subscription-integration` | 구독 청구 흐름 구현 |
| `webhook-integration` | 결제 이벤트에 대한 웹훅 설정 및 처리 |
| `usage-based-billing` | 이벤트 및 미터기를 통한 사용량 기반 청구 구현 |
| `credit-based-billing` | 크레딧 권리, 잔액, 미터기 크레딧 공제 |
| `license-keys` | 디지털 제품의 라이선스 키 관리 |
| `billing-sdk` | BillingSDK React 구성 요소 사용 |

기술은 자동으로 로드됩니다 — 에이전트가 관련 작업을 감지하면 적절한 기술을 선택합니다. [에이전트 기술 문서](/developer-resources/agent-skills)를 통해 전체 목록과 개별 설치를 확인하세요.

### 먼저 시도할 프롬프트

플러그인이 활성화되면 시도해보세요:

```
Set up Dodo Payments webhook handlers in my Next.js app for payment.succeeded and subscription.active events.
```

에이전트는 `webhook-integration` 기술을 로드하고, `dodo-knowledge` MCP를 사용하여 최신 페이로드 형태를 가져오며, 표준 웹훅 사양에 따른 서명 검증으로 핸들러를 작성합니다.

## 다른 지원 에이전트

에이전트 플러그인은 Claude Code, Codex CLI, Cursor, OpenCode를 다룹니다. 다른 에이전트를 사용하는 경우, MCP 서버와 기술 CLI를 통해 Dodo Payments에 연결하세요:

| 에이전트 | 가장 빠른 경로 | 추가 지원 |
|-------|-------------|---------------|
| **Claude Code** | 에이전트 플러그인 (한 명령) | MCP 서버, 개별 기술 |
| **Codex CLI** | 에이전트 플러그인 (한 명령) | MCP 서버 |
| **Cursor** | 에이전트 플러그인 (git clone) | MCP 서버 구성, 기술 CLI |
| **OpenCode** | 에이전트 플러그인 (npm) | MCP 서버 구성, 기술 CLI |
| GitHub Copilot (VS Code) | [MCP Server guide](/developer-resources/mcp-server) | [Skills CLI](/developer-resources/agent-skills) |
| Claude Desktop | [MCP Server guide](/developer-resources/mcp-server) | — |
| Windsurf | [MCP Server guide](/developer-resources/mcp-server) | [Skills CLI](/developer-resources/agent-skills) |
| Cline / Zed / 기타 | [MCP Server guide](/developer-resources/mcp-server) | [Skills CLI](/developer-resources/agent-skills) |

## 에이전트를 위한 문서

모든 Dodo Payments 문서 페이지는 AI 소비에 최적화된 형식으로 제공됩니다:

- **전체 문서 인덱스**: [`docs.dodopayments.com/llms.txt`](https://docs.dodopayments.com/llms.txt) — 컨텍스트 수집을 위한 전체 문서 인덱스를 제공합니다.
- **평문 마크다운**: 대부분의 문서 URL에 `.md`를 추가하여 원시 마크다운 버전을 가져옵니다 (예: `/api-reference/introduction.md`).
- **소스 저장소**: [`github.com/dodopayments/dodo-docs`](https://github.com/dodopayments/dodo-docs) — 오프라인 인덱싱을 위해 클론합니다.

## API 키로 구성하기

기본적으로 에이전트 플러그인은 브라우저 OAuth와 함께 원격 MCP 서버를 사용합니다 — 로컬 자격 증명이 불필요합니다. 워크플로우에서 로컬 API 키가 필요할 경우 (예: CI 환경, 헤드리스 서버) stdio 모드로 전환할 수 있습니다.

{/ LOCKED_PATTERN_3a00efd457b01f610250031fcbf16962 /}
{/ LOCKED_PATTERN_f22e427153b199e505630b6831e2b3fb /}
Claude Code에서 `/plugins`를 열고 **Dodo Payments**를 선택한 후 **구성 옵션**을 선택합니다. 다음을 입력하세요:

- `dodo_api_key` — `dodo_test_...` 또는 `dodo_live_...` 키
- `dodo_webhook_key` — 웹훅 서명 비밀
- `dodo_environment` — `test_mode` 또는 `live_mode`

그런 다음 `.mcp.json`를 편집하여 `dodopayments-api`이 로컬 stdio 서버를 가리키도록 합니다:

```json
{
  "mcpServers": {
    "dodopayments-api": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "dodopayments-mcp@latest"],
      "env": {
        "DODO_PAYMENTS_API_KEY": "${user_config.dodo_api_key}",
        "DODO_PAYMENTS_WEBHOOK_KEY": "${user_config.dodo_webhook_key}",
        "DODO_PAYMENTS_ENVIRONMENT": "${user_config.dodo_environment}"
      }
    }
  }
}
```

현재 세션에 변경 사항을 적용하려면 `/reload-plugins`를 실행하세요.
{/ LOCKED_PATTERN_aae63d8bf6b6da4ac6fb501e13691e4d /}

{/ LOCKED_PATTERN_b7dd62d9b26c1f6d29d920e3d296523a /}
`dodopayments-api`를 `opencode.json`에 직접 선언하세요 — 기본 원격 서버보다 우선합니다:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "mcp": {
    "dodopayments-api": {
      "type": "local",
      "command": ["npx", "-y", "dodopayments-mcp@latest"],
      "environment": {
        "DODO_PAYMENTS_API_KEY": "dodo_test_...",
        "DODO_PAYMENTS_WEBHOOK_KEY": "whsec_...",
        "DODO_PAYMENTS_ENVIRONMENT": "test_mode"
      },
      "enabled": true
    }
  }
}
```

적용하려면 OpenCode를 다시 시작하세요.
