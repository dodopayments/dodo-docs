Dodo Payments는 여러 프로그래밍 언어에 대한 공식 SDK를 제공하며, 각 SDK는 언어별 모범 사례와 현대적인 기능으로 원활한 결제 통합을 위해 설계되었습니다.

<Tip>
항상 최신 SDK 버전을 사용하여 최신 기능과 개선 사항을 이용하세요. 패키지 관리자를 통해 정기적으로 업데이트를 확인하여 모든 Dodo Payments 기능을 이용할 수 있도록 하세요.
</Tip>

## 빠른 시작

몇 분 만에 SDK 시작하기:

<Steps>
<Step title="Install the SDK">
  언어의 패키지 매니저를 사용하여 SDK 설치
  
  <Tabs>
  <Tab title="TypeScript/Node.js">

  ```bash
  npm install dodopayments
  ```

  </Tab>
  
  <Tab title="Python">

  ```bash
  pip install dodopayments
  ```

  </Tab>
  
  <Tab title="PHP">

  ```bash
  composer require dodopayments/client
  ```

  </Tab>
  
  <Tab title="Go">

  ```bash
  go get github.com/dodopayments/dodopayments-go
  ```

  </Tab>

  <Tab title="Rust">

  ```bash
  cargo add dodopayments
  ```

  </Tab>
  </Tabs>
</Step>

<Step title="Initialize the Client">
  API 키로 클라이언트 구성
  
  <Tabs>
  <Tab title="TypeScript">

  ```typescript
  import DodoPayments from 'dodopayments';
  const client = new DodoPayments({ bearerToken: 'your_api_key' });
  ```

  </Tab>
  
  <Tab title="Python">

  ```python
  from dodopayments import DodoPayments
  client = DodoPayments(bearer_token="your_api_key")
  ```

  </Tab>
  
  <Tab title="PHP">

  ```php
  use Dodopayments\Client;
  $client = new Client(bearerToken: 'your_api_key');
  ```

  </Tab>
  
  <Tab title="Go">

  ```go
  import "github.com/dodopayments/dodopayments-go"
  client := dodopayments.NewClient(option.WithBearerToken("your_api_key"))
  ```

  </Tab>

  <Tab title="Rust">

  ```rust
  use dodopayments::Client;
  let client = Client::from_env()?; // reads DODO_PAYMENTS_API_KEY
  ```

  </Tab>
  </Tabs>
  
  <Warning>
  API 키를 항상 환경 변수를 사용하여 안전하게 저장하십시오. 절대 버전 관리에 커밋하지 마십시오.
  </Warning>
</Step>

<Step title="Make Your First API Call">
  결제 세션 또는 결제 생성
  
  <Check>

  </Check>

## 주요 기능

모든 **backend** SDK는 다음과 같은 핵심 기능을 공유합니다. 아래의 모바일 checkout SDK는
의도적으로 더 제한적인 범위만 지원합니다. API key를 보유하지 않으며 API를 호출하지도 않습니다:

- **Type Safety**: 컴파일 타임 안전성과 향상된 IDE 지원을 위한 강력한 typing
- **Error Handling**: 자세한 오류 메시지를 제공하는 포괄적인 exception handling
- **Authentication**: environment variable 지원을 포함한 간단한 API key authentication
- **Async Support**: 해당하는 경우 최신 async/await 패턴 지원
- **Auto-Pagination**: list response에 대한 자동 pagination
- **Usage-Based Billing**: usage event 추적 및 수집을 위한 기본 제공 지원
- **Testing**: 개발 및 테스트를 위한 전체 Test Mode 지원

## Mobile Checkout SDKs

네이티브 payment sheet를 직접 구축하는 대신 Dodo의 **hosted checkout page**를 열고 싶다면
플랫폼에 맞는 mobile checkout SDK를 사용하세요. 네 가지 SDK는 모두 동일한 one-call contract를 따릅니다. `start(...)`는 typed `CheckoutResult`를 반환하고,
어느 SDK도 API key를 보유하지 않습니다. 또한 checkout이 `WebView`가 아닌 플랫폼의 실제 browser surface
(`SFSafariViewController` / Custom Tabs)에서 열리므로 Apple Pay/Google Pay는
open web에서와 동일하게 작동합니다:

<CardGroup cols={2}>
<Card title="Android" icon="android" href="/developer-resources/sdks/android">
  Chrome Custom Tab을 여는 Kotlin SDK입니다. `minSdk` 23이 필요합니다
</Card>

<Card title="iOS" icon="apple" href="/developer-resources/sdks/ios">
  `SFSafariViewController`를 여는 Swift SDK입니다. iOS 16 이상이 필요합니다
</Card>

<Card title="React Native" icon="react" href="/developer-resources/sdks/react-native">
  두 native core 모두에서 작동하는 Turbo Module입니다. React Native 0.76 이상이 필요합니다
</Card>

<Card title="Flutter" icon="layer-group" href="/developer-resources/sdks/flutter">
  두 native core 모두에서 작동하는 Pigeon channel입니다. Flutter 3.44 이상이 필요합니다
</Card>
</CardGroup>

<Card title="Mobile Integration Guide" icon="mobile" href="/developer-resources/mobile-integration">
  backend checkout session부터 callback scheme 설정까지의 end-to-end 모바일 payment flow
</Card>

## Command-Line Interface

터미널 기반 workflow와 자동화를 위한 도구입니다:

<Card title="CLI" icon="terminal" href="/developer-resources/sdks/cli">
  Dodo Payments API를 지원하는 자동 생성 명령줄 인터페이스
</Card>

**기능:**
- 직관적인 사용을 위한 resource 기반 command 구조
- 다양한 output 형식 (JSON, YAML, pretty, interactive)
- bash, zsh, fish용 shell completion
- scripting 및 CI/CD 자동화에 적합

```bash
# Quick example
dodopayments payments list --format json | jq '.items[] | {payment_id, total_amount}'
```
