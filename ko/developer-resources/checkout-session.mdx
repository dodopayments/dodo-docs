<Info>
**세션 유효 기간**: Checkout 세션은 기본적으로 24시간 동안 유효합니다. 요청에 `confirm=true`를 전달하면 세션은 15분 동안만 유효합니다.
</Info>

<Warning>
**일회용 링크**: API에서 반환되는 `checkout_url`는 재사용할 수 없으며 24시간 이내에 만료됩니다(`confirm=true`인 경우 15분). 하나의 고객이 한 번의 결제를 완료하도록 설계되었습니다. 링크를 공유하거나 재사용하지 말고 고객 및 결제 시도마다 새 Checkout 세션을 생성하세요.
</Warning>

## 첫 Checkout 세션 생성

<Tabs>
<Tab title="Node.js SDK">

```javascript expandable
import DodoPayments from 'dodopayments';

// Initialize the Dodo Payments client
const client = new DodoPayments({
  bearerToken: process.env.DODO_PAYMENTS_API_KEY,
  environment: 'test_mode', // defaults to 'live_mode'
});

async function createCheckoutSession() {
  try {
    const session = await client.checkoutSessions.create({
      // Products to sell - use IDs from your Dodo Payments dashboard
      product_cart: [
        {
          product_id: 'prod_123', // Replace with your actual product ID
          quantity: 1
        }
      ],
      
      // Pre-fill customer information to reduce friction
      customer: {
        email: 'customer@example.com',
        name: 'John Doe',
        phone_number: '+1234567890'
      },
      
      // Billing address for tax calculation and compliance
      billing_address: {
        street: '123 Main St',
        city: 'San Francisco',
        state: 'CA',
        country: 'US', // Required: ISO 3166-1 alpha-2 country code
        zipcode: '94102'
      },
      
      // Where to redirect after successful payment
      return_url: 'https://yoursite.com/checkout/success',
      
      // Custom data for your internal tracking
      metadata: {
        order_id: 'order_123',
        source: 'web_app'
      }
    });

    // Redirect your customer to this URL to complete payment
    console.log('Checkout URL:', session.checkout_url);
    console.log('Session ID:', session.session_id);
    
    return session;
    
  } catch (error) {
    console.error('Failed to create checkout session:', error);
    throw error;
  }
}

// Example usage in an Express.js route
app.post('/create-checkout', async (req, res) => {
  try {
    const session = await createCheckoutSession();
    res.json({ checkout_url: session.checkout_url });
  } catch (error) {
    res.status(500).json({ error: 'Failed to create checkout session' });
  }
});
```

```python expandable
import os
from dodopayments import DodoPayments

                "phone_number": "+1234567890"
            },
            
            # Billing address for tax calculation and compliance
            billing_address={
                "street": "123 Main St",
                "city": "San Francisco", 
                "state": "CA",
                "country": "US",  # Required: ISO 3166-1 alpha-2 country code
                "zipcode": "94102"

            # Where to redirect after successful payment
            return_url="https://yoursite.com/checkout/success",
            
            # Custom data for your internal tracking
            metadata={
                "order_id": "order_123",
                "source": "web_app"
            }
        )
        
        # Redirect your customer to this URL to complete payment
        print(f"Checkout URL: {session.checkout_url}")

# Example usage in a Flask route

@app.route('/create-checkout', methods=['POST'])
```

### API 응답

위의 모든 메서드는 동일한 응답 구조를 반환합니다.

```json
{
  "session_id": "cks_Gi6KGJ2zFJo9rq9Ukifwa",
  "checkout_url": "https://test.checkout.dodopayments.com/session/cks_Gi6KGJ2zFJo9rq9Ukifwa"
}
```

<Note>
생성된 `checkout_url`는 일회용이며 24시간 이내에 만료됩니다. 고객 또는 결제 시도 간에 캐시하거나 재사용하지 마세요. 새 링크가 필요할 때마다 새 Checkout 세션을 생성하세요.
</Note>

<Steps>
<Step title="Get the checkout URL">
API 응답에서 `checkout_url`를 추출하세요.
</Step>

<Step title="Redirect your customer">
고객이 구매를 완료할 수 있도록 Checkout URL로 안내하세요.

```javascript
// Redirect immediately
window.location.href = session.checkout_url;

// Or open in new window
window.open(session.checkout_url, '_blank');
```

<Tip>
**대체 통합 옵션**: 리디렉션하는 대신 [Overlay Checkout](/developer-resources/overlay-checkout)(모달 오버레이) 또는 [Inline Checkout](/developer-resources/inline-checkout)(완전 임베드)을 사용하여 Checkout을 페이지에 직접 삽입할 수 있습니다. 두 옵션 모두 동일한 Checkout 세션 URL을 사용합니다.
</Tip>
</Step>

<Step title="Handle the return">
결제 후 고객은 결제/구독 ID, 상태, 고객 이메일 및 라이선스 키를 포함한 query parameters와 함께 `return_url`로 리디렉션됩니다. 전체 목록은 [`return_url` parameter 문서](#request-body)를 참조하세요.
</Step>
</Steps>

### 필수 필드

<ParamField body="product_cart" type="array" required>
Checkout 세션에 포함할 제품의 배열입니다. 각 제품에는 Dodo Payments 대시보드의 유효한 `product_id`가 있어야 합니다.

<Tip>
**혼합 Checkout**: 동일한 Checkout 세션에서 일회성 결제 제품과 구독 제품을 함께 사용할 수 있습니다. 이를 통해 구독 설정 수수료, SaaS와 하드웨어 번들 등 강력한 사용 사례를 구현할 수 있습니다.
</Tip>

<ParamField body="addon_id" type="string" required />

<ParamField body="quantity" type="integer" required />
</Expandable>
</ParamField>

<ParamField body="amount" type="integer">
pay_what_you_want가 활성화된 경우 고객이 지불하는 금액입니다. 비활성화된 경우 이 필드는 무시됩니다.

**형식**: 통화의 최소 단위로 표시합니다(예: USD의 센트). $1.00를 청구하려면 `100`를 전달합니다.

<Info>

</Info>

이 Checkout 세션에 부여할 크레딧 수로, 제품 수준의 `credits_amount`를 재정의합니다. 0보다 커야 합니다.

<Accordion title="Session Management">

<ParamField body="return_url" type="string">
결제 완료 후 고객을 리디렉션할 URL입니다. Dodo Payments는 리디렉션 시 다음 query parameters를 URL에 추가합니다.

| Parameter | Type | Condition |
|-----------|------|-----------|
| `payment_id` | `string` | 일회성 결제에 항상 포함 |
| `subscription_id` | `string` | 구독 결제에 항상 포함 |
| `status` | `string` | 항상 포함 |
| `license_key` | `string` | 제품에서 라이선스 키가 활성화된 경우 포함. 키가 여러 개면 쉼표로 구분 |
| `email` | `string` | 고객의 이메일이 등록되어 있는 경우 포함 |

**리디렉션 URL 예시:**

```text
# One-time payment with license key
https://yoursite.com/return?payment_id=pay_xxx&status=succeeded&license_key=LK-001&email=customer%40example.com

# Subscription payment with multiple license keys
https://yoursite.com/return?subscription_id=sub_xxx&status=active&license_key=LK-001,LK-002&email=customer%40example.com

# Payment without license keys
https://yoursite.com/return?payment_id=pay_xxx&status=succeeded&email=customer%40example.com
```

<Tip>

```javascript expandable
    'afterpay_clearpay',
    'credit',
    'debit'
  ],
  customer: {
    email: 'fashion.lover@example.com',
    name: 'Emma Thompson',
    phone_number: '+1234567890'
  },
  billing_address: {
    street: '555 Fashion Ave',
    city: 'Los Angeles',
    state: 'CA',

  },

  metadata: {
    product_category: 'luxury',
    price_range: 'high_value'
  }
});
```

### 11. 즉시 Checkout을 위한 기존 결제 수단 사용

고객이 저장한 결제 수단을 사용하여 즉시 처리되는 Checkout 세션을 생성하고 결제 수단 수집을 건너뜁니다.

```javascript expandable
const session = await client.checkoutSessions.create({
  product_cart: [
    {
      product_id: 'prod_premium_plan',
      quantity: 1
    }
  ],
  customer: {
    customer_id: 'cus_123'  // Required when using payment_method_id
  },
  payment_method_id: 'pm_abc123',  // Use customer's saved payment method
  confirm: true,  // Required when using payment_method_id
  return_url: 'https://yourapp.com/success'
});
```

<Warning>
`payment_method_id`를 사용할 때 `confirm`는 `true`로 설정되어야 하며 기존 `customer_id`를 제공해야 합니다. 결제 수단은 결제 통화와의 적합성 여부를 확인받습니다.
</Warning>

<Info>
결제 수단은 고객에게 속해야 하며 결제 통화와 호환되어야 합니다. 이를 통해 재방문 고객에게 원클릭 구매를 제공할 수 있습니다.
</Info>

### 12. 깔끔한 결제 URL을 위한 Short Links

사용자 지정 slug가 포함된 짧고 공유 가능한 결제 링크를 생성합니다.

```javascript expandable
const session = await client.checkoutSessions.create({
  product_cart: [
    {
      product_id: 'prod_monthly_subscription',
      quantity: 1
    }
  ],
  short_link: true,  // Generate a shortened payment link
  return_url: 'https://yourapp.com/success',
  customer: {
    email: 'customer@example.com',
    name: 'John Doe'
  }
});

// The checkout_url will be a shortened, cleaner link
console.log(session.checkout_url);  // e.g., https://checkout.dodopayments.com/buy/abc123
```

<Tip>
Short links는 SMS, 이메일 또는 소셜 미디어 공유에 적합합니다. 긴 URL보다 기억하기 쉽고 고객 신뢰를 높일 수 있습니다.
</Tip>

### 13. 결제 성공 페이지를 건너뛰고 즉시 리디렉션

기본 성공 페이지를 거치지 않고 결제가 완료되면 즉시 고객을 리디렉션합니다.

```javascript expandable
const session = await client.checkoutSessions.create({
  product_cart: [
    {
      product_id: 'prod_digital_product',
      quantity: 1
    }
  ],
  feature_flags: {
    redirect_immediately: true  // Skip success page, redirect immediately
  },
  return_url: 'https://yourapp.com/success',
  customer: {
    email: 'customer@example.com',
    name: 'Jane Smith'
  }
});
```

<Tip>
기본 결제 성공 페이지보다 나은 사용자 경험을 제공하는 사용자 지정 성공 페이지가 있는 경우 `redirect_immediately: true`를 사용하세요. 모바일 앱 및 임베드된 Checkout 흐름에 특히 유용합니다.
</Tip>

<Note>
`redirect_immediately`가 활성화되면 결제가 완료된 직후 고객이 기본 성공 페이지를 완전히 건너뛰고 `return_url`로 리디렉션됩니다.
</Note>

### 14. 언어 강제 지정

고객의 브라우저 언어 감지를 재정의하여 Checkout을 특정 언어로 표시합니다.

```javascript expandable
const session = await client.checkoutSessions.create({
  product_cart: [
    {
      product_id: 'prod_subscription',
      quantity: 1
    }
  ],
  customization: {
    force_language: 'ja'  // Force Japanese language
  },
  customer: {
    email: 'customer@example.jp',
    name: 'Tanaka Yuki'
  },
  return_url: 'https://yourapp.com/success'
});
```

<Tip>
고객이 선호하는 언어를 알고 있는 경우(예: 계정 설정에서 확인) 또는 특정 지역 시장을 대상으로 하는 경우 `force_language`를 사용하세요.
</Tip>

**지원되는 언어:** 아랍어(`ar`), 카탈루냐어(`ca`), 중국어(`zh`), 네덜란드어(`nl`), 영어(`en`), 프랑스어(`fr`), 독일어(`de`), 히브리어(`he`), 인도네시아어(`id`), 이탈리아어(`it`), 일본어(`ja`), 한국어(`ko`), 말레이어(`ms`), 폴란드어(`pl`), 포르투갈어(`pt`), 루마니아어(`ro`), 러시아어(`ru`), 스페인어(`es`), 스웨덴어(`sv`), 태국어(`th`), 터키어(`tr`)

### 15. 사용자 지정 필드 수집

사용자 지정 필드를 사용하여 Checkout 중 고객으로부터 추가 정보를 수집합니다.

```javascript expandable
const session = await client.checkoutSessions.create({
  product_cart: [
    {
      product_id: 'prod_saas_plan',
      quantity: 1
    }
  ],
  custom_fields: [
    {
      key: 'company_name',
      label: 'Company Name',
      field_type: 'text',
      required: true,
      placeholder: 'Acme Inc.'
    },
    {
      key: 'team_size',
      label: 'Team Size',
      field_type: 'dropdown',
      required: true,
      options: ['1-10', '11-50', '51-200', '201-500', '500+']
    },
    {
      key: 'referral_source',
      label: 'How did you hear about us?',
      field_type: 'dropdown',
      required: false,
      options: ['Google', 'Twitter', 'Friend referral', 'Blog post', 'Other']
    },
    {
      key: 'website',
      label: 'Company Website',
      field_type: 'url',
      required: false,
      placeholder: 'https://example.com'
    }
  ],
  customer: {
    email: 'buyer@company.com',
    name: 'Jane Doe'
  },
  return_url: 'https://yourapp.com/success'
});
```

<Info>
사용자 지정 필드 응답은 webhook payload(`payment.succeeded`, `subscription.active` 등)에 자동으로 포함되며 API를 통해 조회할 수 있습니다. CRM을 보강하거나 onboarding 흐름을 트리거하거나 고객 경험을 사용자 지정하는 데 활용하세요.
</Info>

**사용 가능한 필드 유형:** `text`, `number`, `email`, `url`, `date`, `dropdown`, `boolean`

## Checkout 세션 미리 보기

Checkout 세션을 생성하기 전에 세금, 할인 및 합계를 포함한 가격 내역을 미리 확인할 수 있습니다. 고객이 Checkout을 진행하기 전에 정확한 가격을 표시할 때 유용합니다.

<Note>
장바구니에 구독 제품이 포함된 경우 preview response는 `next_billing_date`도 반환합니다. 이는 예정된 청구일의 미리 보기이므로 구독이 생성되기 전에 표시할 수 있습니다. 현재 시점을 기준으로 계산되며 trial이 적용되면 `now + trial period`, 그렇지 않으면 `now + one payment frequency`입니다. 일회성 제품만 포함된 장바구니에서는 이 필드가 생략됩니다. 이는 preview time을 기준으로 한 추정치이며, 권위 있는 `next_billing_date`는 구독이 활성화될 때 설정됩니다.
</Note>

<Tabs>
<Tab title="Node.js SDK">

```javascript
const preview = await client.checkoutSessions.preview({
  product_cart: [
    { product_id: 'prod_123', quantity: 1 }
  ],
  billing_address: {
    country: 'US',
    state: 'CA',
    zipcode: '94102'
  },
  discount_codes: ['SAVE20']
});

console.log('Subtotal:', preview.subtotal);
console.log('Tax:', preview.tax);
console.log('Discount:', preview.discount);
console.log('Total:', preview.total);

// Present only when the cart contains a subscription product
console.log('Next billing date:', preview.next_billing_date);
```

</Tab>

<Tab title="Python SDK">

```python
    },

```

## Dynamic Links에서 Checkout 세션으로 마이그레이션

### 주요 차이점
이전에는 Dynamic Links를 사용하여 payment link를 생성할 때 고객의 전체 청구지 주소를 제공해야 했습니다.

Checkout 세션에서는 더 이상 필요하지 않습니다. 보유한 정보를 그대로 전달하면 나머지는 저희가 처리합니다. 예를 들면 다음과 같습니다.

- 고객의 청구 국가만 알고 있다면 해당 정보만 제공하면 됩니다.
- Checkout 흐름에서 결제 페이지로 이동하기 전에 누락된 세부 정보를 자동으로 수집합니다.
- 반대로 필요한 정보를 모두 이미 보유하고 결제 페이지로 바로 이동하려면 전체 데이터 세트를 전달하고 요청 본문에 `confirm=true`를 포함하면 됩니다.

### 마이그레이션 과정

Dynamic Links에서 Checkout 세션으로의 마이그레이션은 간단합니다.

<Steps>
<Step title="Update your integration">
새 API 또는 SDK 메서드를 사용하도록 통합을 업데이트하세요.
</Step>

<Step title="Adjust request payload">
Checkout Sessions 형식에 따라 요청 payload를 조정하세요.
</Step>

<Step title="That's it!">
예. 추가 처리나 특별한 마이그레이션 단계는 필요하지 않습니다.
</Step>
</Steps>
