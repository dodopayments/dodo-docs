## 개요

Agent Skills는 Dodo Payments와 함께 작업할 때 AI 코딩 assistant의 기능을 확장하는 재사용 가능한 기능입니다. checkout 흐름 통합부터 사용량 기반 billing 설정까지, agent가 특정 작업을 더욱 효과적으로 수행할 수 있도록 절차 지식과 모범 사례를 제공합니다.

<Info>
**skills를 AI assistant용 플러그인이라고 생각해 보세요.** agent가 권장 패턴과 모범 사례에 따라 Dodo Payments 기능을 올바르게 구현하는 방법을 학습하도록 지원합니다.
</Info>

Skills는 다음을 포함한 모든 MCP 호환 AI agent에서 작동합니다:
- **Claude Code** - Anthropic의 CLI 코딩 assistant
- **OpenCode** - 오픈 소스 AI 코딩 agent
- **Cursor** - AI 중심 코드 editor
- **기타 MCP client** - skills protocol을 지원하는 모든 agent

## 설치

AI 코딩 assistant에 맞춰 원하는 설치 방법을 선택하세요.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Claude Code, Codex CLI, Cursor 또는 OpenCode를 사용하는 경우 [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents)이 8개의 skills와 두 개의 MCP server를 한 번에 설치합니다. agent가 관련 작업을 감지하면 skills가 자동으로 로드됩니다.

agent별 설치 명령은 [AI Coding Agents 가이드](/developer-resources/build-with-ai-coding-agents)를 참조하세요.
</Tab>

<Tab title="Skills CLI">
모든 MCP 호환 agent에서 작동하는 universal skills CLI를 사용하여 skills를 설치하세요:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

또는 필요한 개별 skills를 설치하세요:

```bash
# Best practices guide
npx skills add dodopayments/skills/dodo-payments/best-practices

# Webhook integration
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Subscription billing
npx skills add dodopayments/skills/dodo-payments/subscription-integration

# Checkout flows
npx skills add dodopayments/skills/dodo-payments/checkout-integration

# Usage-based billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing

# BillingSDK components
npx skills add dodopayments/skills/dodo-payments/billing-sdk

# License key management
npx skills add dodopayments/skills/dodo-payments/license-keys

# Credit-based billing
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
```

<Tip>
필요한 skills만 설치하여 agent가 작업에 집중하도록 하고 context overhead를 줄이세요.
</Tip>
</Tab>

<Tab title="Claude Code">
Claude Code에 Dodo Payments skills marketplace를 추가하세요:

```bash
/plugin marketplace add dodopayments/skills
```

그런 다음 개별 plugin을 설치하세요:

```bash
# Install best practices
/plugin install dodo-best-practices

# Install webhook integration
/plugin install webhook-integration

# Install subscription integration
/plugin install subscription-integration

# Install checkout integration
/plugin install checkout-integration

# Install usage-based billing
/plugin install usage-based-billing

# Install BillingSDK
/plugin install billing-sdk

# Install license keys
/plugin install license-keys

# Install credit-based billing
/plugin install credit-based-billing
```

</Tab>

<Tab title="OpenCode">
OpenCode 설정에서 구성하면 skills를 자동으로 사용할 수 있습니다. Dodo Payments skills repository를 configuration에 추가하세요:

```json
{
  "skills": {
    "repositories": [
      "dodopayments/skills"
    ]
  }
}
```

</Tab>
</Tabs>

## Skills 사용

설치가 완료되면 AI assistant에 Dodo Payments 기능을 구현하도록 요청할 때 이러한 skills를 활용할 수 있습니다. 다음은 예시 prompt입니다:

### 모범 사례

```
Help me integrate Dodo Payments into my Next.js app following best practices
```

### Webhook

```
Set up webhook handlers for payment and subscription events
```

### Subscription

```
Implement a subscription flow with free trial and multiple pricing tiers
```

### Checkout

```
Create a checkout session for my SaaS product
```

### 사용량 기반 Billing

```
Add usage-based billing to track API calls for my AI product
```

### BillingSDK

```
Add a pricing page using BillingSDK components
```

### License Key

```
Implement license key validation for my desktop app
```

### Credit 기반 Billing

```
Set up credit entitlements and metered credit deduction for my AI product
```

## Skills 작동 방식

Skills는 AI assistant에 다음을 제공합니다:

1. **절차 지식** - 기능 구현을 위한 단계별 지침
2. **코드 template** - production-ready 코드 패턴 및 snippet
3. **모범 사례** - security, error handling 및 UX를 위한 권장 접근 방식
4. **context 인식** - 서로 다른 Dodo Payments 기능이 함께 작동하는 방식에 대한 이해

AI assistant에 기능 구현을 요청하면 관련 skill을 사용하여 다음을 수행합니다:
- 올바른 구현 방식 이해
- 정확하고 작동하는 코드 생성
- Dodo Payments convention 준수
- edge case 및 error의 적절한 처리

<Note>
Skills는 [MCP Server](/developer-resources/mcp-server)와 [Sentra](/developer-resources/sentra)를 보완합니다. API operation에는 MCP를, guided integration에는 Sentra를, 향상된 AI assistant 기능에는 Skills를 사용하세요.
</Note>
