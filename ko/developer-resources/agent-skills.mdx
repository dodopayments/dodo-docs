## 개요

Agent Skills는 Dodo Payments와 함께 작업할 때 AI 코딩 assistant의 기능을 확장하는 재사용 가능한 기능입니다. checkout 흐름 통합부터 사용량 기반 billing 설정까지, agent가 특정 작업을 더욱 효과적으로 수행할 수 있도록 절차 지식과 모범 사례를 제공합니다.

<Info>
**skills를 AI assistant용 플러그인이라고 생각해 보세요.** agent가 권장 패턴과 모범 사례에 따라 Dodo Payments 기능을 올바르게 구현하는 방법을 학습하도록 지원합니다.
</Info>

Skills는 다음을 포함한 모든 MCP 호환 AI agent에서 작동합니다:
- **Claude Code** - Anthropic의 CLI 코딩 assistant
- **OpenCode** - 오픈 소스 AI 코딩 agent
- **Cursor** - AI 중심 코드 editor
- **기타 MCP client** - skills protocol을 지원하는 모든 agent

## 설치

AI coding assistant에 따라 원하는 설치 방법을 선택하세요.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Claude Code, Codex CLI, Cursor 또는 OpenCode를 사용하는 경우 [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents)을 통해 17개의 스킬과 두 개의 MCP 서버를 한 번에 설치할 수 있습니다. 에이전트가 관련 작업을 감지하면 스킬이 자동으로 로드됩니다.

에이전트별 설치 명령은 [AI Coding Agents 가이드](/developer-resources/build-with-ai-coding-agents)를 참조하세요.
</Tab>

<Tab title="Skills CLI">
모든 MCP 호환 에이전트에서 작동하는 universal skills CLI를 사용하여 스킬을 설치하세요:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

또는 필요에 따라 개별 스킬을 설치하세요:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
필요한 스킬만 설치하여 에이전트가 작업에 집중하도록 하고 context overhead를 줄이세요.
</Tip>
</Tab>

## 스킬 사용

설치가 완료되면 AI assistant에 Dodo Payments 기능 구현을 요청할 때 관련 스킬이 자동으로 로드됩니다. 스킬 이름을 지정할 필요 없이 작업을 설명하기만 하면 됩니다.

| Example prompt | Skill that loads |
|----------------|------------------|
| 모범 사례에 따라 내 Next.js 앱에 Dodo Payments 통합하기 | `dodo-best-practices` |
| 내 Hono 앱에 Dodo Payments checkout route handler 추가하기 | `framework-adapters` |
| 결제 테스트 및 라이브 전환 과정을 안내해 줘 | `testing-and-go-live` |
| 내 SaaS 제품을 위한 checkout session 생성하기 | `checkout-integration` |
| 무료 체험과 여러 가격 등급을 포함한 구독 흐름 구현하기 | `subscription-integration` |
| 내 React Native 앱에 인앱 checkout 추가하기 | `mobile-checkout` |
| 결제 및 구독 이벤트를 위한 webhook handler 설정하기 | `webhook-integration` |
| 내 AI 제품을 위한 크레딧 권한 및 미터링 기반 크레딧 차감 설정하기 | `credit-based-billing` |
| 내 AI 제품의 API 호출을 추적하기 위한 usage-based billing 추가하기 | `usage-based-billing` |
| 내 데스크톱 앱을 위한 라이선스 키 검증 구현하기 | `license-keys` |
| 추가 기능과 등급별 가격이 포함된 제품 카탈로그 생성하기 | `product-catalog-management` |
| 처음 3번의 청구 주기에 20% 할인을 제공하는 프로모션 코드 추가하기 | `discounts-and-promotions` |
| 구매력 평가를 적용하여 방문자의 현지 통화로 가격 표시하기 | `localized-pricing` |
| 고객이 결제 수단을 관리할 수 있는 셀프 서비스 포털 제공하기 | `customer-management` |
| 부분 환불을 처리하고 분쟁이 열리면 액세스 철회하기 | `refunds-and-disputes` |
| BillingSDK 컴포넌트를 사용하여 가격 페이지 추가하기 | `billing-sdk` |
| Dodo Payments를 내 Better Auth 설정에 연결하기 | `better-auth-integration` |

## 스킬 작동 방식

스킬은 AI assistant에 다음을 제공합니다:

1. **절차 지식** - 기능 구현을 위한 단계별 지침
2. **코드 템플릿** - 프로덕션에 바로 사용할 수 있는 코드 패턴 및 snippet
3. **모범 사례** - 보안, 오류 처리, UX를 위한 권장 접근 방식
4. **컨텍스트 인식** - 서로 다른 Dodo Payments 기능이 함께 작동하는 방식에 대한 이해

AI assistant에 기능 구현을 요청하면 관련 스킬을 사용하여 다음을 수행합니다:
- 올바른 구현 방식 이해
- 정확하고 작동하는 코드 생성
- Dodo Payments 규칙 준수
- edge case 및 오류의 적절한 처리

<Note>
스킬은 [MCP Server](/developer-resources/mcp-server) 및 [Sentra](/developer-resources/sentra)를 보완합니다. API 작업에는 MCP를, 안내형 통합에는 Sentra를, 향상된 AI assistant 기능에는 스킬을 사용하세요.
</Note>
