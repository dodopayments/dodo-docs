## 개요

에이전트 기술은 Dodo Payments와 작업할 때 AI 코딩 도우미의 능력을 강화하는 재사용 가능한 기능입니다. 이들은 에이전트가 체크아웃 흐름 통합부터 사용 기반 청구 설정에 이르기까지 특정 작업을 보다 효과적으로 수행할 수 있도록 도와주는 절차적 지식과 모범 사례를 제공합니다.

<Info>
**기술을 AI 도우미의 플러그인으로 생각하세요.** 이들은 에이전트에게 Dodo Payments 기능을 올바르게 구현하는 방법을 가르치며, 우리의 권장 패턴과 모범 사례를 따릅니다.
</Info>

기술은 다음과 같은 모든 MCP 호환 AI 에이전트와 함께 작동합니다:
- **Claude Code** - Anthropic의 CLI 코딩 도우미
- **OpenCode** - 오픈 소스 AI 코딩 에이전트
- **Cursor** - AI 우선 코드 편집기
- **기타 MCP 클라이언트** - 기술 프로토콜을 지원하는 모든 에이전트

## 설치

AI 코딩 도우미에 따라 선호하는 설치 방법을 선택하세요.

<Tabs>
<Tab title="Skills CLI">
모든 MCP 호환 에이전트에서 작동하는 보편적인 기술 CLI를 사용하여 기술을 설치하십시오:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

또는 필요에 따라 개별 기술을 설치하십시오:

```bash
# Best practices guide
npx skills add dodopayments/skills/dodo-best-practices

# Webhook integration
npx skills add dodopayments/skills/webhook-integration

# Subscription billing
npx skills add dodopayments/skills/subscription-integration

# Checkout flows
npx skills add dodopayments/skills/checkout-integration

# Usage-based billing
npx skills add dodopayments/skills/usage-based-billing

# BillingSDK components
npx skills add dodopayments/skills/billing-sdk

# License key management
npx skills add dodopayments/skills/license-keys
```

<Tip>
에이전트를 집중시키고 컨텍스트 오버헤드를 줄이기 위해 필요한 기술만 설치하십시오.
</Tip>
</Tab>

<Tab title="Claude Code">
Claude Code에 Dodo Payments 기술 마켓플레이스를 추가하십시오:

```bash
/plugin marketplace add dodopayments/skills
```

그런 다음 개별 플러그인을 설치하십시오:

```bash
# Install best practices
/plugin install dodo-best-practices

# Install webhook integration
/plugin install webhook-integration

# Install subscription integration
/plugin install subscription-integration

# Install checkout integration
/plugin install checkout-integration

# Install usage-based billing
/plugin install usage-based-billing

# Install BillingSDK
/plugin install billing-sdk

# Install license keys
/plugin install license-keys
```

</Tab>

<Tab title="OpenCode">
기술은 OpenCode 설정에 구성되면 자동으로 사용 가능해집니다. Dodo Payments 기술 리포지토리를 구성에 추가하십시오:

```json
{
  "skills": {
    "repositories": [
      "dodopayments/skills"
    ]
  }
}
```

</Tab>
</Tabs>

## 기술 사용하기

설치가 완료되면 AI 도우미는 Dodo Payments 기능 구현을 요청할 때 이러한 기술을 활용할 수 있습니다. 다음은 몇 가지 예시 프롬프트입니다:

### 모범 사례

```
Help me integrate Dodo Payments into my Next.js app following best practices
```

### 웹훅

```
Set up webhook handlers for payment and subscription events
```

### 구독

```
Implement a subscription flow with free trial and multiple pricing tiers
```

### 체크아웃

```
Create a checkout session for my SaaS product
```

### 사용 기반 청구

```
Add usage-based billing to track API calls for my AI product
```

### BillingSDK

```
Add a pricing page using BillingSDK components
```

### 라이선스 키

```
Implement license key validation for my desktop app
```

## 기술 작동 방식

기술은 AI 도우미에게 다음을 제공합니다:

1. **절차적 지식** - 기능 구현을 위한 단계별 지침
2. **코드 템플릿** - 생산 준비가 완료된 코드 패턴과 스니펫
3. **모범 사례** - 보안, 오류 처리 및 UX에 대한 추천 접근법
4. **컨텍스트 인식** - 다양한 Dodo Payments 기능이 어떻게 함께 작동하는지에 대한 이해

AI 도우미에게 기능 구현을 요청하면, 관련 기술을 사용하여 다음을 수행합니다:
- 올바른 구현 접근 방식 이해
- 정확하고 작동하는 코드 생성
- Dodo Payments 관례 따르기
- 엣지 케이스 및 오류를 적절하게 처리하기

<Note>
기술은 [MCP 서버](/developer-resources/mcp-server) 및 [Sentra](/developer-resources/sentra)를 보완합니다. API 작업을 위해 MCP를 사용하고, 가이드 통합을 위해 Sentra를 사용하며, 기능 향상을 위해 기술을 사용하십시오.
</Note>
