## 개요

Agent Skills는 Dodo Payments와 함께 작업할 때 AI 코딩 assistant의 기능을 확장하는 재사용 가능한 기능입니다. checkout 흐름 통합부터 사용량 기반 billing 설정까지, agent가 특정 작업을 더욱 효과적으로 수행할 수 있도록 절차 지식과 모범 사례를 제공합니다.

<Info>
**skills를 AI assistant용 플러그인이라고 생각해 보세요.** agent가 권장 패턴과 모범 사례에 따라 Dodo Payments 기능을 올바르게 구현하는 방법을 학습하도록 지원합니다.
</Info>

Skills 프로토콜을 지원하는 모든 AI agent에서 Skills를 사용할 수 있습니다. 다음을 포함합니다:
- **Claude Code** - Anthropic의 CLI 코딩 assistant
- **Codex CLI** - OpenAI의 CLI 코딩 agent
- **Cursor** - AI 중심 코드 편집기
- **VS Code / GitHub Copilot** - Agent Plugin을 통해 사용
- **Kiro** - Skills를 Power로 로드
- **OpenCode** - 오픈 소스 AI 코딩 agent
- **기타 클라이언트** - Skills 프로토콜을 지원하는 모든 agent

<Note>
**Gemini CLI는 예외입니다.** Gemini CLI에는 agent-skill primitive가 없으므로 Skills를 사용할 수 없습니다 — [MCP servers](/developer-resources/mcp-server) 두 개만 사용할 수 있습니다.
</Note>

## 설치

사용 중인 AI coding assistant에 따라 원하는 설치 방법을 선택하세요.

<Tabs>
<Tab title="Agent Plugin (recommended)">
Claude Code, Codex CLI, Cursor, VS Code / GitHub Copilot, Kiro 또는 OpenCode를 사용하는 경우 [Dodo Agent Plugin](/developer-resources/build-with-ai-coding-agents)이 17개의 Skills와 두 개의 MCP servers를 한 번에 설치합니다. Agent가 관련 작업을 감지하면 Skills가 자동으로 로드됩니다.

Agent별 설치 명령은 [AI Coding Agents 가이드](/developer-resources/build-with-ai-coding-agents)를 참조하세요.
</Tab>

<Tab title="Skills CLI">
모든 MCP-compatible agent에서 작동하는 universal skills CLI를 사용해 Skills를 설치하세요:

```bash
# Install all Dodo Payments skills
npx skills add dodopayments/skills
```

또는 필요한 Skills를 개별적으로 설치하세요:

```bash expandable
# Getting started
npx skills add dodopayments/skills/dodo-payments/dodo-best-practices
npx skills add dodopayments/skills/dodo-payments/framework-adapters
npx skills add dodopayments/skills/dodo-payments/testing-and-go-live

# Accepting payments
npx skills add dodopayments/skills/dodo-payments/checkout-integration
npx skills add dodopayments/skills/dodo-payments/subscription-integration
npx skills add dodopayments/skills/dodo-payments/mobile-checkout
npx skills add dodopayments/skills/dodo-payments/webhook-integration

# Billing models
npx skills add dodopayments/skills/dodo-payments/credit-based-billing
npx skills add dodopayments/skills/dodo-payments/usage-based-billing
npx skills add dodopayments/skills/dodo-payments/license-keys

# Catalog and pricing
npx skills add dodopayments/skills/dodo-payments/product-catalog-management
npx skills add dodopayments/skills/dodo-payments/discounts-and-promotions
npx skills add dodopayments/skills/dodo-payments/localized-pricing

# Customers and operations
npx skills add dodopayments/skills/dodo-payments/customer-management
npx skills add dodopayments/skills/dodo-payments/refunds-and-disputes

# UI and integrations
npx skills add dodopayments/skills/dodo-payments/billing-sdk
npx skills add dodopayments/skills/dodo-payments/better-auth-integration
```

<Tip>
필요한 Skills만 설치하면 agent의 작업 집중도를 높이고 context overhead를 줄일 수 있습니다.
</Tip>
</Tab>

<Tab title="OpenCode">
OpenCode는 지정한 directories에서 Skills를 로드합니다. 설치된 packages를 스캔하지 않으므로 명시적인 `skills.paths` entry가 필요합니다.

Agent Plugin package 사용:

```bash
npm install --save-dev @dodopayments/opencode-plugin
```

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugin": ["@dodopayments/opencode-plugin"],
  "skills": {
    "paths": ["node_modules/@dodopayments/opencode-plugin/skills"]
  }
}
```

Relative paths는 **project directory**를 기준으로 확인되므로 package가 해당 프로젝트의 `node_modules`에 있어야 합니다. Absolute path를 사용할 수도 있으며, 이 경우 local-install requirement가 필요하지 않습니다.

<Warning>
존재하지 않는 Skills path는 **조용히** 무시됩니다 — error도 warning도 표시되지 않습니다. Skills가 실제로 로드되었는지 확인하세요:

```bash
opencode run "List every skill available to you by name."
```

17개가 모두 표시되어야 합니다.
</Warning>
</Tab>
</Tabs>

## Skills 사용

설치가 완료되면 Dodo Payments feature 구현을 요청할 때 AI assistant가 관련 Skill을 자동으로 로드합니다. Skill 이름을 지정할 필요 없이 작업을 설명하기만 하면 됩니다.

| 예시 prompt | 로드되는 Skill |
|----------------|------------------|
| 모범 사례에 따라 내 Next.js 앱에 Dodo Payments를 통합해 줘 | `dodo-best-practices` |
| 내 Hono 앱에 Dodo Payments checkout route handler를 추가해 줘 | `framework-adapters` |
| 결제를 테스트하고 출시하는 과정을 안내해 줘 | `testing-and-go-live` |
| 내 SaaS product용 checkout session을 생성해 줘 | `checkout-integration` |
| 무료 trial과 여러 pricing tiers를 사용하는 subscription flow를 구현해 줘 | `subscription-integration` |
| 내 React Native 앱에 인앱 checkout을 추가해 줘 | `mobile-checkout` |
| payment 및 subscription events를 위한 webhook handlers를 설정해 줘 | `webhook-integration` |
| 내 AI product에 credit entitlements와 metered credit deduction을 설정해 줘 | `credit-based-billing` |
| 내 AI product의 API calls를 추적하도록 usage-based billing을 추가해 줘 | `usage-based-billing` |
| 내 desktop app에 license key validation을 구현해 줘 | `license-keys` |
| add-ons와 tiered pricing을 포함한 product catalog를 생성해 줘 | `product-catalog-management` |
| 처음 세 billing cycles에 20% 할인을 제공하는 promo code를 추가해 줘 | `discounts-and-promotions` |
| purchasing power parity를 적용해 방문자의 현지 통화로 가격을 표시해 줘 | `localized-pricing` |
| 고객이 payment methods를 관리할 수 있는 self-service portal을 제공해 줘 | `customer-management` |
| 부분 refund를 발행하고 dispute가 열리면 access를 취소해 줘 | `refunds-and-disputes` |
| BillingSDK components를 사용해 pricing page를 추가해 줘 | `billing-sdk` |
| 내 Better Auth 설정에 Dodo Payments를 연결해 줘 | `better-auth-integration` |

## Skills 작동 방식

Skills는 AI assistant에 다음을 제공합니다:

1. **절차적 지식** - feature 구현을 위한 단계별 instructions
2. **Code Templates** - production-ready code patterns 및 snippets
3. **Best Practices** - security, error handling 및 UX를 위한 권장 방식
4. **Context Awareness** - 서로 다른 Dodo Payments features가 함께 작동하는 방식에 대한 이해

AI assistant에게 feature 구현을 요청하면 관련 Skill을 사용해 다음을 수행합니다:
- 올바른 구현 방식 이해
- 정확하고 작동하는 code 생성
- Dodo Payments conventions 준수
- edge cases 및 errors의 적절한 처리

<Note>
Skills는 [MCP Server](/developer-resources/mcp-server) 및 [Sentra](/developer-resources/sentra)를 보완합니다. API operations에는 MCP를, guided integration에는 Sentra를, 향상된 AI assistant capabilities에는 Skills를 사용하세요.
</Note>
