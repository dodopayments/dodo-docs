## 구독 웹훅 이벤트

다음 웹훅 이벤트는 구독 생애 주기 변경 사항을 추적하는 데 사용할 수 있습니다:

| 이벤트 | 설명 |
|-------|-------------|
| `subscription.active` | 구독이 성공적으로 활성화됨 |
| `subscription.updated` | 구독 객체가 업데이트됨(어떤 필드가 변경되어도 이 이벤트가 트리거됨) |
| `subscription.on_hold` | 갱신에 실패하여 구독이 보류됨 |
| `subscription.paused` | 구독이 일시 중지됨 |
| `subscription.renewed` | 다음 청구 기간으로 구독이 갱신됨 |
| `subscription.plan_changed` | 구독 플랜이 업그레이드, 다운그레이드 또는 수정됨 |
| `subscription.update_payment_method` | 구독의 결제 수단이 업데이트됨 |
| `subscription.cancelled` | 구독이 취소됨 |
| `subscription.failed` | mandate 생성 중 구독 생성에 실패함 |
| `subscription.expired` | 구독이 약정 기간의 종료 시점에 도달함 |

### 실시간 동기화를 위한 `subscription.updated` 사용

`subscription.updated` 웹후크는 구독의 필드가 변경될 때마다 작동하여 폴링 없이 애플리케이션 상태를 동기화할 수 있습니다:

```javascript
app.post('/webhooks/dodo', async (req, res) => {
  const event = req.body;
  
  if (event.type === 'subscription.updated') {
    const subscription = event.data;
    
    // Sync subscription changes to your database
    await syncSubscription(subscription.subscription_id, {
      status: subscription.status,
      next_billing_date: subscription.next_billing_date,
      metadata: subscription.metadata,
      // ... other fields you want to track
    });
    
    console.log(`Subscription ${subscription.subscription_id} updated`);
  }
  
  res.json({ received: true });
});
```

<Tip>
`subscription.updated`을(를) 구독하여 구독 변경 사항에 대한 실시간 알림을 받고 API를 폴링할 필요를 없애십시오.
</Tip>
