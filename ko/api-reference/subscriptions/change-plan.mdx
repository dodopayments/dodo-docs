## 결제 실패 처리

요금제 변경 결제가 실패할 때 수행할 작업을 제어하려면 `on_payment_failure` 매개변수를 사용하세요:

| 값 | 동작 |
|-------|----------|
| `prevent_change` | 결제가 성공할 때까지 구독을 현재 요금제에 유지합니다. 요금제 변경은 보류 상태로 유지됩니다. |
| `apply_change` | 결제 결과에 관계없이 즉시 요금제 변경을 적용합니다. 기본값입니다. |

<Info>
`on_payment_failure`이 지정되지 않은 경우 동작은 대시보드에서 구성된 비즈니스 수준 설정으로 기본 설정됩니다.
</Info>

## 할인 코드

계획을 변경할 때 `discount_code` 매개변수를 전달하여 할인 코드를 적용할 수 있습니다.

| 시나리오 | 동작 |
|----------|----------|
| `discount_code` 제공됨 | 할인을 검증하고 새 계획에 적용합니다. |
| `discount_code` 제공되지 않음, `preserve_on_plan_change=true`가 있는 기존 할인 | 새 제품에 적용 가능한 경우 기존 할인이 유지됩니다. |
| `discount_code` 제공되지 않음, 보존 가능한 할인 없음 | 할인이 적용되지 않습니다. |

<Tip>
계획 변경 시 할인 코드를 사용하여 업그레이드에 대해 프로모션 가격을 제공하거나, 고객을 새로운 계획 등급으로 이동할 때 코드를 전달하세요.
</Tip>

<Tip>
프리미엄 기능에 대한 접근을 허용하기 전에 결제를 보장하고자 하는 중요한 업그레이드에 `prevent_change`를 사용하세요.
</Tip>
