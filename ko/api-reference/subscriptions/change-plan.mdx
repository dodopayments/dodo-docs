## 결제 실패 처리

플랜 변경 결제가 실패할 때 발생하는 상황을 제어하려면 `on_payment_failure` 매개변수를 사용하세요:

| 값 | 동작 |
|-------|----------|
| `prevent_change` | 결제가 성공할 때까지 현재 플랜에서 구독 유지. 플랜 변경은 보류 상태로 유지. |
| `apply_change` | 결제 결과와 관계없이 플랜 변경을 즉시 적용. 기본값입니다. |

<Info>
`on_payment_failure`이 지정되지 않은 경우, 동작은 대시보드에 구성된 비즈니스 수준 설정의 기본값으로 설정됩니다.
</Info>

<Tip>
프리미엄 기능의 접근을 부여하기 전에 결제를 확실히 하고 싶을 경우에는 `prevent_change`를 사용하세요.
</Tip>
