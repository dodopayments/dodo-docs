<Info>
이 엔드포인트는 이미 보유한 키를 가져옵니다 — `key`, `customer_id` 및 `product_id`은 모두 필수입니다. 이 엔드포인트는 사용자를 대신해 키 값을 생성하지 않습니다. 이미 존재하는 `key`을 가져오면 `409 Conflict`이 반환됩니다.
</Info>

<Info>
API를 통해 생성하거나 업데이트한 라이선스 키는 고객에게 이메일 알림을 보내지 않습니다. 고객에게 라이선스 키를 알리려면 애플리케이션에서 별도로 처리해야 합니다.
</Info>
