<Warning>
**사용 중단된 API**: 라이선스 키는 이제 [Entitlements](/features/entitlements/introduction) 시스템을 통해 관리됩니다. [List Grants](/api-reference/entitlements/list-grants) (`integration_type=license_key`로 필터링)을 사용하여 키의 부여 및 `license_key` 세부 정보를 검색하십시오. 이 엔드포인트는 향후 릴리스에서 제거될 예정입니다.
</Warning>
