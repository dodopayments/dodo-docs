<Warning>
**사용 중단된 API**: 라이선스 키는 이제 [Entitlements](/features/entitlements/introduction) 시스템을 통해 관리됩니다. [License Key entitlement](/api-reference/entitlements/update-entitlement)에서 활성화 제한 및 기간을 구성하고, [Revoke Grant](/api-reference/entitlements/revoke-grant)를 사용하여 고객의 키를 비활성화합니다. 이 엔드포인트는 향후 릴리스에서 제거될 예정입니다.
</Warning>

<Info>
API를 통해 라이선스 키를 업데이트해도 고객에게 이메일 알림이 전송되지 않습니다.
</Info>
