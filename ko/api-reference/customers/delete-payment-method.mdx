고객 계정에서 저장된 결제 수단을 제거합니다. 오래되거나 원하지 않는 결제 수단을 정리할 때 사용하세요.

<Warning>
활성 구독에서 사용 중인 결제 수단은 삭제할 수 없습니다. API는 `409 Conflict`와 함께 `Payment method is in use by an active subscription`를 반환합니다. 먼저 [결제 수단 업데이트](/api-reference/subscriptions/update-payment-method)를 사용하여 구독을 다른 결제 수단으로 변경한 다음 기존 결제 수단을 삭제하세요.
</Warning>

삭제가 성공하면 `204 No Content`를 반환합니다.

## 사용 사례

- **고객 요청**: 고객이 더 이상 등록해 두기를 원하지 않는 결제 수단 제거
- **만료된 카드**: 만료된 카드 정보가 있는 결제 수단 정리
- **보안**: 보안이 침해된 결제 수단 즉시 제거
