<Info>
이 endpoint는 `fulfillment_mode: manual`가 포함된 License Key entitlement에 따라 생성된 grant에만 사용하세요. grant는 연결된 key가 없는 `Pending` 상태여야 합니다. 전체 플로우는 [수동 Fulfillment](/features/license-keys#manual-fulfillment) 및 [수동 License Key Fulfillment 통합 가이드](/developer-resources/manual-license-key-fulfillment)를 참조하세요.
</Info>
