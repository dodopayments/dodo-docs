<Info>
이 엔드포인트는 `fulfillment_mode: manual` 권한이 있는 라이선스 키에 대해 생성된 부여에만 사용하십시오. 부여는 첨부된 키 없이 `pending` 상태에 있어야 합니다. [수동 이행](/features/license-keys#manual-fulfillment) 및 [수동 라이선스 키 이행 통합 가이드](/developer-resources/manual-license-key-fulfillment)를 참조하여 전체 프로세스를 확인하십시오.
</Info>
